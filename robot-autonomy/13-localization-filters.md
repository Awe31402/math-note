## 1. 兩種定位思路：行為式 vs. 地圖式

[▶ 03:18](https://youtu.be/dG3-D-vDwe8?t=198)

| | 行為式（behavioral） | 地圖式（map-based） |
|---|---|---|
| 想法 | 設計一組行為，合起來產生想要的運動。例：「永遠讓牆在右手邊、沿牆走」，很可能就把整個房間走遍 | 明確地相對一張**地圖**定位；地圖可以事先知道，或邊走邊估（**SLAM**） |
| 優點 | 不必明確推理定位和地圖；好實作、很穩健（對世界的假設很少）；有點生物啟發 | 很有彈性，只要偵測得到地標就能推廣到幾乎任何環境；最受歡迎 |
| 缺點 | 通常**不能推廣**到一般環境（沿牆走適合這個房間，不適合世界上任何地方） | 較複雜（要推理地圖、機率地推理位置）；假設越多越脆弱；內部表示可能**發散**（以為在某處，其實差了三公尺——對自駕車可能是災難） |

`【口頭】` 自駕車通常**事先**建好地圖（第一週週五的講者提過）；有時機器人要在定位的同時估計地圖，就是 SLAM。本課用地圖式方法。

**地圖式的兩個問題**（[▶ 06:58](https://youtu.be/dG3-D-vDwe8?t=418)）：

1. **地圖怎麼表示**：很細的 3D 格點？還是抽象的**拓樸地圖**（不離散化空間，只推理桌子、牆等高階概念）？下週講。
2. **信念怎麼表示**：在地圖中位置的「信念」怎麼建模、收到感測資料（光達、相機）時怎麼更新？今天和接下來幾堂講。

## 2. 信念的表示：單峰／多峰、連續／離散

[▶ 08:15](https://youtu.be/dG3-D-vDwe8?t=495)

核心想法（不只在機器人學）：把信念表示成**機率分布**，它 (1) 編碼位置的估計，(2) 同時維護那個位置的**不確定性**。這是高階概念，實作方式很多；對信念表示做不同假設，就得到不同的定位演算法。

**選擇 1：單峰 vs. 多峰**

- **單峰（unimodal）**：例如高斯分布（`【口頭】` 「像本課的成績分布」）——只有一個峰：很可能在這裡，周圍有點不確定。濾波器每次都把估計「投影」回高斯。
- **多峰（multimodal）**：可以有多個峰，比較有彈性，也更符合現實：`【口頭】` 把你突然丟進 Stanford 某間教室，你可能覺得「可能是這間視訊教室，也可能是另一間大講堂」——兩個峰。
- 為什麼還用單峰？計算上比較好處理；而且常是不錯的近似，例如沿著一條軌跡走時，你知道自己大概就在軌跡附近，不必費事處理多個峰。工程就是表示能力和效率的折衷。

**選擇 2：連續 vs. 離散**

- **連續**：可以在環境中任何一點。
- **離散**：得到一個**直方圖**，每根長條代表「我在這個位置的機率」。

**關鍵問題**：怎麼根據一組量測更新信念？工具：**Bayes 濾波**。它是機率工具，所以定位與建圖中的所有量都當成**隨機變數**。

## 3. 機率複習

### 3.1 隨機變數

[▶ 11:49](https://youtu.be/dG3-D-vDwe8?t=709)

**隨機變數**：把不可預測過程的結果對應到實數的函數（`【口頭】` 名字有點誤導，它其實是函數）。本課用大寫字母表示隨機變數。

| | 離散 | 連續 |
|---|---|---|
| 描述 | **機率質量函數（PMF）** $p(x) := P(X = x)$ | **機率密度函數（PDF）** $p(x)$ |
| 正規化 | $\sum_x p(x) = 1$（機率公理之一） | $\int p(x)\,dx = 1$ |
| 單點機率 | 有意義 | $P(X = x) = 0$（`【口頭】` 機率 0 不代表不可能） |
| 區間 | — | $P(a \le X \le b) = \int_a^b p(x)\,dx$ |

$p(x)$ 永遠讀成「$P(X = x)$」。連續的情況大致就是「把加總換成積分」；嚴格來說還有 Lebesgue 積分等細節，屬於更進階的機率課。

### 3.2 聯合機率、獨立、條件機率

[▶ 15:29](https://youtu.be/dG3-D-vDwe8?t=929)

要同時推理狀態、量測序列、控制序列，所以需要多個隨機變數。

- **聯合機率**：$p(x, y) := P(X = x \text{ 且 } Y = y)$。
- **獨立**：$p(x, y) = p(x)\,p(y)$（聯合機率可以分解）。
- **條件機率**：給定 $p(y) > 0$，

  $$
  p(x \mid y) := \frac{p(x, y)}{p(y)}
  $$

  `【口頭】` 這是**定義**，不是推導出來的定理（有些書把它當公理）。

**用樣本空間理解條件機率**（[▶ 18:25](https://youtu.be/dG3-D-vDwe8?t=1105)）：`【口頭】` 對機率結果有疑惑時，**永遠回到樣本空間**（所有可能結果的空間 $\Omega$）去想——「相信我，這是唯一能釐清困惑的方法」。

例：面積為 1 的矩形，裡面有集合 $A$（面積 0.75）、$B$（0.5）、$C$（0.25）。閉著眼睛隨機丟一個點（保證丟進矩形、均勻分布）：

- `【課堂討論】` 落在 $A$ 的機率？→ 75%（均勻分布下，機率就是面積）。
- `【課堂討論】` 告訴你點落在 $B$，那它也在 $A$ 的機率？→ 既然已知在 $B$ 裡，重要的是「交集 / 已知所在集合」的比例。$A \cap B$ 面積 0.25、$B$ 面積 0.5：$P(A \mid B) = 0.25 / 0.5 = 0.5$。
- 告訴你點落在 $C$（$C \subset A$），也在 $A$ 的機率？→ 交集 0.25、$C$ 也是 0.25 → **100%**。

> ⚠️ 逐字稿缺字 [▶ 22:25](https://youtu.be/dG3-D-vDwe8?t=1345)：Whisper 寫「0.25 over 0.5, it is equal to 1,000」，應是 0.5。圖中各集合的重疊關係只能從口述推斷。

**為什麼獨立要這樣定義**（[▶ 24:12](https://youtu.be/dG3-D-vDwe8?t=1452)）：若 $X, Y$ 獨立，

$$
p(x \mid y) = \frac{p(x, y)}{p(y)} = \frac{p(x)p(y)}{p(y)} = p(x)
$$

給定 $Y$ 的條件機率等於無條件機率：$Y$ 不帶有任何關於 $X$ 的資訊。

### 3.3 全機率定理

[▶ 25:28](https://youtu.be/dG3-D-vDwe8?t=1528)

$$
p(x) = \sum_y p(x, y) = \sum_y p(x \mid y)\,p(y), \qquad
p(x) = \int p(x \mid y)\,p(y)\,dy
$$

`【口頭】` 對我們來說它是個方便的技巧：不知道 $p(x)$、但知道 $X$ 和另一個 $Y$ 的聯合（或條件）機率時，對 $Y$ 的所有可能值加總就得到 $p(x)$。證明不重要（維基上兩行）。

【課本補充】§11.1.3 稱這個過程為**邊際化（marginalization）**，$p(x)$ 叫 $X$ 的**邊際機率**。

### 3.4 Bayes 定理

[▶ 27:41](https://youtu.be/dG3-D-vDwe8?t=1661)

**動機**：把 $Y$ 想成**資料**（量測），$X$ 想成要估計的量（例如位置）。我們想要的是「給定資料，在某位置的機率」$p(x \mid y)$；手上有的通常是反過來的「在某位置時，得到某資料的機率」$p(y \mid x)$——例如「如果我在 $x$，光達量到 30 公分的機率是多少」，這可以藉由描述感測器得到。Bayes 定理讓我們**反轉**條件。

**推導**：由條件機率的定義用兩次：

$$
p(x \mid y) = \frac{p(x, y)}{p(y)}, \qquad p(x, y) = p(y \mid x)\,p(x)
$$

所以

$$
p(x \mid y) = \frac{p(y \mid x)\,p(x)}{p(y)} = \frac{p(y \mid x)\,p(x)}{\sum_{x'} p(y \mid x')\,p(x')}
$$

分母用全機率定理寫開（用 $x'$ 是為了和要估計的那個特定 $x$ 區分）；連續情況把加總換成積分。

**解讀**：

$$
\underbrace{p(x \mid y)}_{\text{後驗：給定資料的位置}} = \frac{\overbrace{p(y \mid x)}^{\text{感測器模型}}\ \overbrace{p(x)}^{\text{先驗}}}{p(y)}
$$

- **先驗** $p(x)$：大概知道自己在哪（Bayes 濾波是迭代的，從一個初始猜測開始）。
- **感測器模型** $p(y \mid x)$：描述感測器得到，存在電腦裡的表。
- 分母用這兩者算得出來。所以拿到新資料 $y$ 時，後驗完全算得出來。

`【口頭】` 「如果你懂這個，接下來五堂課會相當直接；不懂的話，接下來五堂課會是地獄。」因為接下來就是把這個推到極致——一再重複做同一件事。

**正規化常數**（[▶ 34:06](https://youtu.be/dG3-D-vDwe8?t=2046)）：分母**不管 $x$ 是多少都一樣**，所以簡寫：

$$
p(x \mid y) = \eta\, p(y \mid x)\,p(x), \qquad \eta = \frac{1}{p(y)}
$$

`【口頭】` 這沒什麼神奇的：叫它常數 $\eta$ 只是因為它不依賴 $x$。程式裡不要為每個 $x$ 重算。

- `【Q&A】` [▶ 35:42](https://youtu.be/dG3-D-vDwe8?t=2142) 你說不用重算，但會一直拿到新資料啊？→ 有新資料當然要重算；意思是**對所有可能的 $x$**（算 $x = 2$、$x = 3$ 的機率時）用同一個 $\eta$。$\eta$ 依賴 $y$。

### 3.5 條件獨立

[▶ 36:22](https://youtu.be/dG3-D-vDwe8?t=2182)

前面的結果都可以加上對任意隨機變數 $Z$ 的條件，只要一路保持這個條件：

$$
p(x \mid y, z) = \frac{p(y \mid x, z)\,p(x \mid z)}{p(y \mid z)}
$$

**條件獨立**：$X$、$Y$ 在給定 $Z$ 下獨立，若

$$
p(x, y \mid z) = p(x \mid z)\,p(y \mid z)
$$

`【口頭】` 常被混淆的一點：**條件獨立 ⇏ 絕對獨立**，**絕對獨立 ⇏ 條件獨立**（$Z$ 可能帶了把 $X$、$Y$ 連起來的資訊）。兩者不等價，後面會看到機器人學的例子。

【課本補充】§11.1.2 例子：左右輪編碼器的讀數 $X$、$Y$ 看起來相關（都受機器人運動影響）；但給定隱藏變數 $Z$ = 「真實走過的距離」，兩者條件獨立。

### 3.6 期望值與共變異數

[▶ 39:11](https://youtu.be/dG3-D-vDwe8?t=2351)

機率分布完整描述了隨機變數，但它是函數（高維物件），計算上難處理，所以想要幾個代表性的數字。

**期望值**：

$$
E[X] = \sum_x x\,p(x), \qquad E[X] = \int x\,p(x)\,dx
$$

- 是**線性算子**：$E[aX + b] = aE[X] + b$。`【口頭】` 這是機率論中少數不需要任何假設就成立的結果，純粹來自加總的結構。
- 向量隨機變數的期望值 = 各分量的期望值組成的向量。

**共變異數**：兩個隨機變數**共同變化**的程度：

$$
\operatorname{cov}(X, Y) = E\left[ (X - E[X])(Y - E[Y])^\top \right] = E\left[ XY^\top \right] - E[X]\,E[Y]^\top
$$

$X$ 往一個方向動、$Y$ 完全隨機地動 → 共變異數為 0；兩者沿一條線對齊 → （正規化後）為 1 或 $-1$。第二種寫法有時比較好用，`【口頭】` 證明當練習。

> ⚠️ 待確認 [▶ 39:54](https://youtu.be/dG3-D-vDwe8?t=2394)：老師說期望值「基本上是最可能的事件」，嚴格來說期望值是平均，不一定是最可能的值（眾數）；可能只是口語說法。

## 4. 狀態、量測、控制

[▶ 42:17](https://youtu.be/dG3-D-vDwe8?t=2537)

接下來兩堂假設**地圖已知**，只在地圖中定位；下週處理地圖未知（同時定位與建圖）。

機器人和環境互動的兩種方式：**行動**（施加控制、在環境中移動）和**蒐集資訊**（量測）。所以定義三個概念：

| 概念 | 定義 | 記號 |
|---|---|---|
| **狀態** $x_t$ | 時間 $t$ 時，機器人和環境中**所有會影響未來的面向**的集合，讓我能（機率地）預測未來。例：機器人姿態、朝向、速度、周圍物體的位置 | $x_{t_1:t_2} = x_{t_1}, x_{t_1+1}, \dots, x_{t_2}$ |
| **量測** $z_t$ | 關於環境當下狀態的資訊，例如光達的距離 | $z_{t_1:t_2}$ |
| **控制** $u_t$ | 關於環境中狀態**改變**的資訊 | $u_{t_1:t_2}$ |

**完整狀態（complete state）**：$x_t$ 之前的任何變數都無法再影響未來狀態的演化——**馬可夫性質**。意思：告訴你 $x_t$ 和機器人之後要做什麼，你就能預測它未來在哪；再給更早的狀態不會讓預測更好。`【口頭】` 重點：不是說預測是確定性的；預測一般是隨機的（例如陣風），只是更早的資訊無法改善它。

**量測 vs. 控制對不確定性的影響**（[▶ 45:54](https://youtu.be/dG3-D-vDwe8?t=2754)）：

- **量測**通常**增加**機器人的知識：它約束了要估計的量（例如位置）。
- **控制**通常**造成知識流失**。`【課堂討論】` 為什麼？→ 學生答：施加控制後，實際運動不會剛好如預期。老師補充：有擾動、模型誤差；本來可能在這一區的任何一點，每一點移動後又可能落在一片區域裡，所以可能所在的集合**變大**了。

`【口頭】` 用 Bayes 濾波定位，就是「量測降低不確定性、控制增加不確定性」之間的一支芭蕾。

## 5. 馬可夫模型

[▶ 47:44](https://youtu.be/dG3-D-vDwe8?t=2864)

假設狀態是由一個**生成模型**隨機產生的。一般形式：

$$
p\left( x_t \mid x_{0:t-1},\ z_{1:t-1},\ u_{1:t} \right)
$$

**注意下標**：狀態到 $t-1$、量測到 $t-1$、控制到 $t$——不是打錯字。慣例是：進入狀態 $x_t$ → 得到量測 $z_t$ → 下控制 $u_{t+1}$ → 移到下一個狀態。（也可以反過來約定，但這最自然。）

**馬可夫假設**（狀態完整）：

$$
p\left( x_t \mid x_{0:t-1}, z_{1:t-1}, u_{1:t} \right) = p\left( x_t \mid x_{t-1}, u_t \right)
\qquad\text{（狀態轉移模型）}
$$

這是**條件獨立**的應用：給定 $x_{t-1}$，$x_t$ 的機率不依賴其他東西。要預測 $t$ 時的狀態，只需要知道 $t-1$ 時在哪、下了什麼控制。

`【口頭】` 什麼時候不是好假設？只要把狀態向量擴充得夠大，任何問題都能變成馬可夫的。但不做技巧的話：例如推測人類駕駛的**意圖**——你要變換車道時，對對方的預測不只取決於他現在在做什麼，還取決於他過去兩、三秒的行為（一直在亂開的話，預測就不同），光有相對距離和相對速度不夠。這是老師實驗室的研究方向；本課用馬可夫性質就夠了。

- `【Q&A】` [▶ 51:37](https://youtu.be/dG3-D-vDwe8?t=3097) 為什麼對過去量測的條件消失了？→ 量測的作用是幫你推斷出 $x_{t-1}$；既然已經告訴你 $x_{t-1}$，就夠了。

**量測模型**也做同樣的馬可夫假設：

$$
p\left( z_t \mid x_{0:t}, z_{1:t-1}, u_{1:t} \right) = p\left( z_t \mid x_t \right)
$$

`【口頭】` 在真實位置 $x_t$ 量到距離 30 公尺的機率，不管你過去是從舊金山還是聖荷西來的都一樣——很合理。

**動態 Bayes 網路**（[▶ 52:46](https://youtu.be/dG3-D-vDwe8?t=3166)）：下控制 → 進入狀態 → 量測 → 根據量測算控制 $u_t$ → 進入 $x_t$ → 重複。我們知道控制（自己決定的）和量測，但**不知道**狀態——它是要估計的**潛在變數**，所以也叫**隱藏馬可夫模型（hidden Markov model, HMM）**。

【課本補充】§11.2：轉移模型描述**過程不確定性**（例如施加控制時輪子打滑），量測模型描述**感測器雜訊**（例如測距儀的變動）。沒有控制輸入時就是 HMM。

## 6. 信念與預測信念

[▶ 53:32](https://youtu.be/dG3-D-vDwe8?t=3212)

**信念（belief）**：對真實狀態的每個假設指定一個機率的分布：

$$
\operatorname{bel}(x_t) := p\left( x_t \mid z_{1:t},\ u_{1:t} \right)
$$

給你從時間 1 到 $t$ 的所有量測和控制，機器人在 $x_t$ 的機率。機器人一般可能在任何地方，每個可能位置都有一個機率，整個函數就是信念。

**預測信念（prediction belief）**：計算上的中間物件：

$$
\overline{\operatorname{bel}}(x_t) := p\left( x_t \mid z_{1:t-1},\ u_{1:t} \right)
$$

量測只到 $t-1$：**考慮了最新的控制，還沒考慮最新的量測**。信念則兩者都考慮了。

分開的原因：計算信念的最一般結果是**依序**的演算法：先考慮控制、再考慮量測——先算預測信念，再算信念。由預測信念算出信念叫**修正（correction）**或**量測更新（measurement update）**。

## 7. Bayes 濾波器

### 7.1 演算法與直覺

[▶ 56:17](https://youtu.be/dG3-D-vDwe8?t=3377)

**Bayes 濾波器**：地圖式定位與建圖最基本的演算法，計算信念最一般的方法；適用範圍遠超機器人學，可用於任何 Bayes 網路模型。唯一的關鍵假設是**狀態完整**（馬可夫過程）。`【口頭】` 一般性的代價是計算：直接照定義很難實作，很少直接用；接下來兩堂講讓它可計算的簡化和近似。

**Bayes 濾波器**

- **在解什麼**：在隱藏馬可夫模型中，依序吸收控制和量測，遞迴地計算對狀態的信念。
- **步驟**：
  - **初始化**：給定 $\operatorname{bel}(x_0)$。完全沒概念就放均勻分布——在整個 Stanford 校園（如果確定在 Stanford），或整個地球表面。
  - **每一步**（輸入 $\operatorname{bel}(x_{t-1})$、$u_t$、$z_t$），對**每一個**可能的 $x_t$：
    1. **預測（考慮控制）**：

       $$
       \overline{\operatorname{bel}}(x_t) = \int p\left( x_t \mid u_t, x_{t-1} \right) \operatorname{bel}(x_{t-1})\,dx_{t-1}
       $$

    2. **修正（考慮量測）**：

       $$
       \operatorname{bel}(x_t) = \eta\, p\left( z_t \mid x_t \right) \overline{\operatorname{bel}}(x_t)
       $$

  - 輸出 $\operatorname{bel}(x_t)$。
- **什麼時候會失敗**：
  - 連續狀態空間要對整個空間積分，一般**算不出來**；離散狀態的加總則隨狀態數成長，高維時爆炸（課本）——所以需要卡爾曼濾波、粒子濾波等近似。
  - 馬可夫假設不成立時（狀態不完整），推導不再成立。
  - 運動模型或感測器模型錯誤 → 信念可能發散。

**預測步驟的直覺**（[▶ 59:47](https://youtu.be/dG3-D-vDwe8?t=3587)）：不知道 $t-1$ 時確切在哪，只知道各個假設 $x_{t-1}^{(1)}, x_{t-1}^{(2)}, \dots$ 的機率（就是信念）。這些都是可能透過控制 $u_t$ 抵達 $x_t$ 的起點。合理的做法：對每個假設，「它為真的機率」乘上「如果它為真，用 $u_t$ 到達 $x_t$ 的機率」，再把所有假設加起來。若從某個 $x_{t-1}$ 到 $x_t$ 的機率是 0，那從那裡不可能到 $x_t$。

**修正步驟的直覺**（[▶ 62:35](https://youtu.be/dG3-D-vDwe8?t=3755)）：已經知道給定控制時在 $x_t$ 的機率，再看這些機率和**收到的量測**多相容，據此**調升或調降**。例：量測前在 $x_t$ 的機率是 0.7，但「在 $x_t$ 時量到距離 0.3 公尺」的機率是 0——那現在在 $x_t$ 的機率應該變成 0。

**正規化**：$\eta$ 不依賴 $x_t$；實務上先算出所有 $p(z_t \mid x_t)\,\overline{\operatorname{bel}}(x_t)$，加總得到 $1/\eta$，再正規化。

- `【Q&A】` [▶ 64:23](https://youtu.be/dG3-D-vDwe8?t=3863)（問正規化在什麼空間做）→ 在哪做都行，只要正規化讓它是機率分布（積分為 1）。

`【口頭】` 作業 4 會在「信念是高斯」的假設下實作 Bayes 濾波器——也就是 **EKF**。

### 7.2 推導：修正步驟

[▶ 65:30](https://youtu.be/dG3-D-vDwe8?t=3930)

老師說第二步比較簡單，就是 Bayes 定理的直接應用。

**Step 1**：信念的定義：

$$
\operatorname{bel}(x_t) = p\left( x_t \mid z_t, z_{1:t-1}, u_{1:t} \right)
$$

**Step 2**：對 $x_t$ 和 $z_t$ 套 Bayes 定理（$x_t$ 當 $x$、$z_t$ 當 $y$），其他變數 $z_{1:t-1}, u_{1:t}$ 當額外的條件一路保留：

$$
= \frac{p\left( z_t \mid x_t, z_{1:t-1}, u_{1:t} \right)\, p\left( x_t \mid z_{1:t-1}, u_{1:t} \right)}{p\left( z_t \mid z_{1:t-1}, u_{1:t} \right)}
$$

分母不依賴 $x_t$，就是 $1/\eta$。

**Step 3（馬可夫）**：給定目前狀態，量測只依賴目前狀態；過去的量測和控制不帶有關於 $z_t$ 的額外資訊（條件獨立）：

$$
p\left( z_t \mid x_t, z_{1:t-1}, u_{1:t} \right) = p\left( z_t \mid x_t \right)
$$

`【口頭】` 這是我們做的假設；相信它，這就對；它通常是好假設。

**Step 4**：第二項依定義就是**預測信念**：

$$
\operatorname{bel}(x_t) = \eta\, p\left( z_t \mid x_t \right)\, \overline{\operatorname{bel}}(x_t)
$$

信念和預測信念之間差一個考慮最新量測的乘法因子。$p(z_t \mid x_t)$ 是已知的（描述過感測器）。

### 7.3 推導：預測步驟

[▶ 70:20](https://youtu.be/dG3-D-vDwe8?t=4220)

已知：$\operatorname{bel}(x_{t-1})$、狀態轉移模型、量測模型（這一步用不到量測模型）。

**Step 1**：預測信念的定義：

$$
\overline{\operatorname{bel}}(x_t) = p\left( x_t \mid z_{1:t-1}, u_{1:t} \right)
$$

**Step 2（全機率定理）**：加上對 $x_{t-1}$ 的條件。直覺：想利用已知的轉移模型（從 $x_{t-1}$ 用 $u_t$ 到 $x_t$ 的機率），把要算的東西和已知的東西連起來：

$$
= \int p\left( x_t \mid x_{t-1}, z_{1:t-1}, u_{1:t} \right)\, p\left( x_{t-1} \mid z_{1:t-1}, u_{1:t} \right)\, dx_{t-1}
$$

（就是 $p(x) = \sum_y p(x \mid y)p(y)$，只是多了額外的條件變數；連續空間用積分。）

**Step 3（馬可夫，用在狀態轉移）**：知道前一個狀態和目前的控制，就是預測 $x_t$ 所需的全部：

$$
p\left( x_t \mid x_{t-1}, z_{1:t-1}, u_{1:t} \right) = p\left( x_t \mid x_{t-1}, u_t \right)
$$

這就是狀態轉移模型——和第 1 集的運動學模型相關，只是現在是機率版本，不是確定性的。

**Step 4（微妙的一步）**：

$$
p\left( x_{t-1} \mid z_{1:t-1}, u_{1:t} \right) = p\left( x_{t-1} \mid z_{1:t-1}, u_{1:t-1} \right)
$$

把對 $u_t$ 的條件拿掉。為什麼？看動態 Bayes 網路：$u_{t-1} \to x_{t-1} \to z_{t-1} \to u_t \to x_t$。我們要估計 $x_{t-1}$；告訴你「接下來要用來移到 $x_t$ 的控制 $u_t$」，能帶來什麼關於 $x_{t-1}$ 的新資訊？$u_t$ 頂多是用 $z_{t-1}$ 和更早的量測算出來的（**輸出回授**策略：控制是量測的函數），也就是已經在條件裡的東西的一種壓縮版本，不帶新資訊。

**Step 5**：右邊依定義就是 $\operatorname{bel}(x_{t-1})$：

$$
\overline{\operatorname{bel}}(x_t) = \int p\left( x_t \mid x_{t-1}, u_t \right)\, \operatorname{bel}(x_{t-1})\, dx_{t-1}
$$

**下一堂**：從 Bayes 濾波器出發，做近似讓它能即時計算，用來在地圖中定位機器人。

【課本補充】§11.3.3 **離散 Bayes 濾波器**：狀態有限時，積分換成加總：$\bar p_{k,t} = \sum_i p(x_k \mid u_t, x_i)\,p_{i,t-1}$、$p_{k,t} = \eta\, p(z_t \mid x_k)\,\bar p_{k,t}$。§11.3.4 走廊例子：預測讓信念變寬（運動帶來不確定），修正在量測有資訊時讓信念變尖；走廊有重複結構時信念可能一直是多峰的，觀測多了才收斂。

## 8. 一頁速查表

### 機率

| 名稱 | 式子 |
|---|---|
| 條件機率（定義） | $p(x \mid y) = \frac{p(x, y)}{p(y)}$ |
| 獨立 | $p(x, y) = p(x)p(y)$ ⇔ $p(x \mid y) = p(x)$ |
| 全機率 | $p(x) = \sum_y p(x \mid y)p(y)$ |
| Bayes | $p(x \mid y) = \eta\, p(y \mid x)\,p(x)$，$\eta = 1/p(y)$ |
| 條件獨立 | $p(x, y \mid z) = p(x \mid z)\,p(y \mid z)$（和絕對獨立互不蘊含） |
| 期望值 | $E[aX + b] = aE[X] + b$ |
| 共變異數 | $E[XY^\top] - E[X]E[Y]^\top$ |

Bayes 推導關鍵：條件機率定義用兩次，$p(x,y) = p(x \mid y)p(y) = p(y \mid x)p(x)$。

### 馬可夫模型

- 轉移：$p(x_t \mid x_{t-1}, u_t)$；量測：$p(z_t \mid x_t)$。
- 順序：狀態 → 量測 → 控制 → 下一狀態。
- 量測降低不確定性；控制增加不確定性。

### Bayes 濾波器

$$
\overline{\operatorname{bel}}(x_t) = \int p(x_t \mid u_t, x_{t-1})\,\operatorname{bel}(x_{t-1})\,dx_{t-1}, \qquad
\operatorname{bel}(x_t) = \eta\, p(z_t \mid x_t)\,\overline{\operatorname{bel}}(x_t)
$$

- 修正推導：Bayes（對 $x_t$、$z_t$）＋ 馬可夫（$z_t$ 只看 $x_t$）。
- 預測推導：全機率（對 $x_{t-1}$）＋ 馬可夫（$x_t$ 只看 $x_{t-1}, u_t$）＋ $u_t$ 不帶 $x_{t-1}$ 的新資訊。
- 初始：$\operatorname{bel}(x_0)$，沒概念就均勻。
