  -   Transform Coding: Decorrelate data, and then use simpler (scalar)

JPEG Compression Summary
 -   Color Conversion: RGB is converted to YUV color space
 -   Color Channels: Each color channel is encoded independently of
     each other
 -   Block Coding: JPEG encodes each 8x8 almost independently
     (except the DC coefficient)
 -   Huffman/Arithmetic: JPEG also has support for using Arithmetic
     coding, but is rarely used. Lots of caveats on how Huffman is used!
