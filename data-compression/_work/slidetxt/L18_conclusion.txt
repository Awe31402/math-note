EE274 Summary -> Non-iid data (aka real data)
 ‣ Lossless compression of non-iid data:
   Key-idea -> “Good predictor => good compressor” (we saw kth order adaptive coders & LLMs!)
 ‣ What if you don’t want to model your data?
   Universal Lossless compressors -> can be shown to be optimal asymptotically on any source
   LZ77, LZ78, BZIP, ZStandard …
 ‣ We ended with some tips on lossless compression in practice - always start with zstd and then
   move ahead with the tips!
   ‣ One key idea: transform your data into a form that existing compressors can work well on!
