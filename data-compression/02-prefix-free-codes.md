## 1. 小考檢討：分組編碼

### 1.1 9 個符號的固定長度碼

[▶ 00:05](https://youtu.be/EKdlz3vae04?t=5) 小考第 1 題：字母集 $\mathcal{X}=\{A,B,\dots,I\}$ 有 9 個符號，固定長度碼每個符號要幾位元？

[▶ 00:38](https://youtu.be/EKdlz3vae04?t=38) 用上一集的公式 $\lceil\log_2|\mathcal{X}|\rceil$：$8<9\le16$，所以 $\lceil\log_2 9\rceil=\log_2 16=4$。

[▶ 01:13](https://youtu.be/EKdlz3vae04?t=73) 符號數是 2 的冪時剛好（8 → 3 位元、16 → 4 位元），但 9 介於中間：我們「想要」的是 3 和 4 之間的某個數，卻拿到 4，浪費了。

### 1.2 兩個一組

[▶ 01:46](https://youtu.be/EKdlz3vae04?t=106) 改進的想法：**不要一次編一個符號，一次編兩個**。

- 把 AA、AB、AC、……、II 當成新的符號，等於一個 $9\times9=81$ 個符號的**乘積字母集**（product alphabet）[▶ 02:30](https://youtu.be/EKdlz3vae04?t=150)。
- $64<81\le128$，所以每**組**要 $\lceil\log_2 81\rceil=7$ 位元 [▶ 03:08](https://youtu.be/EKdlz3vae04?t=188)。
- 每組有 2 個符號，所以每**符號** $7/2=3.5$ 位元 [▶ 03:43](https://youtu.be/EKdlz3vae04?t=223)。

> 【口頭】[▶ 04:18](https://youtu.be/EKdlz3vae04?t=258) 小考題目把「bits/block」誤寫成「bits/symbol」，所以答 7 的同學也給分。講者提醒：**單位一律寫「位元／符號」**，就不會犯這種錯 [▶ 07:35](https://youtu.be/EKdlz3vae04?t=455)。

結果：4 → 3.5 位元／符號，分組有效。

### 1.3 越大組越好【課堂討論】

[▶ 04:53](https://youtu.be/EKdlz3vae04?t=293) 講者問 $\log_2 9$ 是多少？學生答約 **3.17**。3.5 還沒到 3.17，要怎麼更接近？

[▶ 05:28](https://youtu.be/EKdlz3vae04?t=328) 學生答：**更大的組**。三個一組就有 $9^3$ 種組合，依此類推；可以證明最後會收斂到 $\log_2 9\approx3.17$。缺點：組越大，字母集指數成長，所以這不是很好的方法，後面會看到更好的辦法。

> 以下**不是逐字稿內容**，是依上面的公式推論的：$n$ 個一組時，每符號 $\frac{\lceil n\log_2 9\rceil}{n}$ 位元。因為 $n\log_2 9\le\lceil n\log_2 9\rceil<n\log_2 9+1$，除以 $n$ 得
> $$\log_2 9\le\frac{\lceil n\log_2 9\rceil}{n}<\log_2 9+\frac1n,$$
> 所以 $n\to\infty$ 時夾到 $\log_2 9$。例：$n=1$ 是 4；$n=2$ 是 3.5；$n=3$：$\lceil 9.51\rceil/3=10/3\approx3.33$；$n=5$：$\lceil15.85\rceil/5=3.2$。

### 1.4 期望碼長

[▶ 06:01](https://youtu.be/EKdlz3vae04?t=361) 小考第 2 題：$P(A)=0.5$、$P(B)=0.3$、$P(C)=0.2$，碼字長度 1、2、2 [▶ 06:44](https://youtu.be/EKdlz3vae04?t=404)：

$$\mathbb{E}[l(X)]=0.5\times1+0.3\times2+0.2\times2=0.5+0.6+0.4=1.5\ \text{位元／符號}$$

【投影片補充】`L2_ann.pdf` p.6：這題的碼是 A→`0`、B→`01`、C→`11`。

> 以下**不是逐字稿內容**，是依本集後面的定義推論的：這組碼**不是**前綴碼（`0` 是 `01` 的開頭），但它是唯一可解碼的：倒過來讀，它就是前綴碼（`0`、`10`、`11`），所以從尾巴往回解就不會搞混。正好是本集 §5 說的「唯一可解碼但不是前綴碼」的例子。

## 3. 什麼叫無損？唯一可解碼

### 3.1 兩個例子【課堂討論】

[▶ 11:32](https://youtu.be/EKdlz3vae04?t=692) **碼 1**：A→`0`、B→`0`。無損嗎？學生答：不是，因為 A 和 B 的碼一樣，看到 0 分不出是誰。

[▶ 12:17](https://youtu.be/EKdlz3vae04?t=737) **碼 2**：A→`0`、B→`00`。學生意見不一。講者：

- 如果**只送一個符號**，它是無損的：一個 0 是 A，兩個 0 是 B。
- 但通常要送**一串符號**：AA 編成 `00`，B 也編成 `00`。收到 `00` 分不出是 AA 還是 B [▶ 12:57](https://youtu.be/EKdlz3vae04?t=777)。所以不是無損。

重點：「無損」的定義不明顯，要小心定義。

### 3.2 定義

[▶ 13:53](https://youtu.be/EKdlz3vae04?t=833) **唯一可解碼碼**（uniquely decodable code）：

> 沒有兩個輸入序列 $x^n$、$y^m$（$m,n\ge1$，$x^n\ne y^m$）會被編成同一個輸出。

[▶ 15:26](https://youtu.be/EKdlz3vae04?t=926) 所以碼 2 不是唯一可解碼的：取 $x^2=(x_1,x_2)=(A,A)$、$y^1=(y_1)=(B)$，$\mathrm{Enc}(x^2)=\mathrm{Enc}(y^1)=00$。

【Q&A】[▶ 20:43](https://youtu.be/EKdlz3vae04?t=1243) 學生請講者回到定義頁，問 $x^n$、$y^m$ 是什麼。講者：就是兩個輸入序列（tuple）。$x^2=(A,A)$ 是長度 2 的序列，$y^1=(B)$ 是長度 1 的序列。[▶ 21:28](https://youtu.be/EKdlz3vae04?t=1288) $n$ 和 $m$ **不必相等**：任何兩個不同的序列，長度不同也一樣，都不能對到同一個輸出。所以只看輸出，連「原本有幾個符號」都能知道。這是很強的性質。

【課本補充】§5.1 用三層定義（書頁 105）：

1. **非奇異**（nonsingular）：$x\ne x'\Rightarrow C(x)\ne C(x')$，也就是單一符號不撞碼。
2. **延伸**（extension）：$C(x_1x_2\cdots x_n)=C(x_1)C(x_2)\cdots C(x_n)$，碼字直接接起來。
3. **唯一可解碼**：延伸碼 $C^*$ 是非奇異的。

這和課堂的定義是同一件事。碼 1 連非奇異都不是；碼 2 非奇異，但不是唯一可解碼。

[▶ 22:04](https://youtu.be/EKdlz3vae04?t=1324) 講者說：課堂之後**不會再研究**唯一可解碼碼本身（作業有一題要證明相關性質），因為只要一個更小、更好處理的類別就夠了（§5）。

## 4. 摩斯電碼：靠停頓分開的碼

[▶ 15:26](https://youtu.be/EKdlz3vae04?t=926) 先想想日常生活：兩個字各自是字，接起來又是另一個字。說話時對方怎麼知道一個字在哪裡結束？學生答：**有空格**。[▶ 16:36](https://youtu.be/EKdlz3vae04?t=996) 但在我們的設定裡，`00` 就是 0 後面接 0，中間沒有空隙。電腦只有 0 和 1，**沒有第三個符號**可以當「這個碼字結束了」的記號。

[▶ 17:14](https://youtu.be/EKdlz3vae04?t=1034) **摩斯電碼**（Morse code）：電報用的碼，只有點（dot）和劃（dash）。【口頭】講者說在他父親那一代的印度，電報還是送急件的方式。

[▶ 17:47](https://youtu.be/EKdlz3vae04?t=1067) 例：E = `·`、S = `···`、Q = `−−·−`。[▶ 18:21](https://youtu.be/EKdlz3vae04?t=1101) E 接 T 是 `·−`，A 也是 `·−`，所以**照我們的定義，摩斯電碼不是唯一可解碼的**。它能用，是因為字母之間會**停頓**，等於每個字母後面加一個逗號 [▶ 18:58](https://youtu.be/EKdlz3vae04?t=1138)。

【投影片補充】`L2_ann.pdf` 摩斯電碼頁的規則：點長 1 單位、劃長 3 單位；同一字母內各部分間隔 1 單位、字母之間間隔 3 單位、單字之間間隔 7 單位。

【課堂討論】[▶ 19:28](https://youtu.be/EKdlz3vae04?t=1168) 碼長有什麼規律？學生答：**母音比較短**。[▶ 20:02](https://youtu.be/EKdlz3vae04?t=1202) 講者：對，E 是一個點、I 是兩個點；但 T 也很短。英文最常見的字母是 E 和 T。所以摩斯電碼那時就知道「常用的字母用短碼」。

【課本補充】§5.1 Example 5.1.3 也提到摩斯電碼：它其實用四種符號（點、劃、字母間空格、單字間空格），而且對四符號字母集來說不是最佳的。

## 5. 解碼演算法與前綴碼

### 5.1 一個解碼演算法

[▶ 22:49](https://youtu.be/EKdlz3vae04?t=1369) 對碼 A→`0`、B→`10`、C→`110`、D→`111`：

```
C = 空字串
重複：
    把下一個位元接到 C 後面
    如果 C 在碼表裡：
        輸出對應的符號
        C = 空字串
    否則：
        繼續
```

[▶ 25:07](https://youtu.be/EKdlz3vae04?t=1507) 很簡單，線性時間。

【口頭】[▶ 25:07](https://youtu.be/EKdlz3vae04?t=1507) 學過資訊理論的人，這集和下一集大多是複習；之後就會有很多新東西。

**例** [▶ 25:43](https://youtu.be/EKdlz3vae04?t=1543)：位元串 `0110001110`（投影片上的例子）：

| 步驟 | C | 在碼表裡？ | 輸出 |
|---|---|---|---|
| 1 | `0` | 是 | A，C 清空 |
| 2 | `1` | 否 | |
| 3 | `11` | 否 | |
| 4 | `110` | 是 | C，C 清空 |
| 5 | `0` | 是 | A，C 清空 [▶ 27:20](https://youtu.be/EKdlz3vae04?t=1640) |
| … | | | |

> 以下**不是逐字稿內容**，是照同一演算法自己做完的：接下來 `0` → A、`111` → D、`0` → A，整串解成 `ACAADA`。

### 5.2 為什麼行得通？【課堂討論】

[▶ 27:56](https://youtu.be/EKdlz3vae04?t=1676) 學生答：**沒有一個碼字是另一個碼字的開頭（前綴）**。[▶ 28:30](https://youtu.be/EKdlz3vae04?t=1710) 0 不是其他碼字的開頭，所以看到 0 就一定是 A；10 也不是其他碼字的開頭，所以看到 10 就一定是 B。

### 5.3 定義

[▶ 29:01](https://youtu.be/EKdlz3vae04?t=1741) **前綴碼**（prefix code），也叫**無前綴碼**（prefix-free code）、**即時碼**（instantaneous code）：

> 沒有一個碼字是另一個碼字的前綴。

[▶ 29:53](https://youtu.be/EKdlz3vae04?t=1793) 三個名字的由來：

- **即時**：每個碼字一讀完就能立刻解出來，不用往後看，可以邊收邊解（streaming）。
- **無前綴**：就是定義本身。
- **前綴碼**：講者猜是大家懶得一直寫「prefix-free」。

### 5.4 兩個性質

[▶ 30:32](https://youtu.be/EKdlz3vae04?t=1832)

1. **前綴碼一定唯一可解碼。**
2. **反過來不成立**：有唯一可解碼但不是前綴碼的碼 [▶ 32:22](https://youtu.be/EKdlz3vae04?t=1942)，作業會看到例子。

【課堂討論】[▶ 31:06](https://youtu.be/EKdlz3vae04?t=1866) 為什麼 1 成立？學生答：解碼時在碼表裡找到 C，就百分之百確定它不是另一個碼字的一部分。[▶ 31:45](https://youtu.be/EKdlz3vae04?t=1905) 講者：對，**解碼演算法本身就是證明**：每一步都只有一種可能，沒有選擇。要正式證明可以看課本。

> 以下**不是逐字稿內容**，是依上面的直覺寫成的證明：設 $C$ 是前綴碼，兩個序列 $x^n\ne y^m$ 的編碼相同。找第一個不同的位置 $i$（若一個序列是另一個的開頭，見下面）。前 $i-1$ 個符號的碼字一樣，所以從同一個位置開始，輸出接著是 $C(x_i)$ 和 $C(y_i)$。兩串位元相同，所以較短的那個碼字是較長那個的前綴；前綴碼裡這只可能是 $C(x_i)=C(y_i)$，也就是 $x_i=y_i$（前綴碼的碼字兩兩不同），矛盾。若 $y^m$ 是 $x^n$ 的開頭（$m<n$），那 $x^n$ 的編碼比 $y^m$ 多出 $C(x_{m+1})\cdots$，至少多一個位元（碼字非空），長度不同，也矛盾。

【課本補充】§5.1 表 5.1（書頁 107）有「唯一可解碼但不是即時碼」的例子：1→`10`、2→`00`、3→`11`、4→`110`。讀到 `11` 時要往後看：後面的 0 個數是奇數，第一個碼字就是 `110`（符號 4）；是偶數就是 `11`（符號 3）。所以能解，但不「即時」。

[▶ 32:59](https://youtu.be/EKdlz3vae04?t=1979) 本課**只研究前綴碼**，後面會說明為什麼前綴碼就夠用（第 3 集）。

## 6. 前綴碼 = 碼字都在葉子上的二元樹

### 6.1 把碼畫成樹

[▶ 33:33](https://youtu.be/EKdlz3vae04?t=2013) 第二種解碼方法要用**二元樹**（binary tree）。[▶ 34:42](https://youtu.be/EKdlz3vae04?t=2082)

- 樹有一個**根**（root）；每個節點不是**葉子**（leaf），就是有兩個子節點。
- 往左走標 0、往右走標 1。
- **從根走到葉子的路徑 = 碼字** [▶ 35:30](https://youtu.be/EKdlz3vae04?t=2130)。

碼 A→`0`、B→`10`、C→`110`、D→`111` 的樹：

```
        根
       /  \
     0/    \1
     A      ●
          0/ \1
          B   ●
            0/ \1
            C   D
```

### 6.2 用樹解碼

[▶ 36:27](https://youtu.be/EKdlz3vae04?t=2187)

1. 從根開始。
2. 讀一個位元，0 往左、1 往右。
3. 走到葉子 → 輸出該符號，回到根。

[▶ 37:01](https://youtu.be/EKdlz3vae04?t=2221) 例 `0110 10`：0 → 葉子 A，回根；1、1、0 → 葉子 C，回根；1、0 → 葉子 B。解出 `ACB`。

### 6.3 不是前綴碼的樹【課堂討論】

[▶ 38:08](https://youtu.be/EKdlz3vae04?t=2288) 碼 A→`0`、B→`10`、C→`100`。學生幫忙畫樹：A 在 0 分支；B 和 C 都是 1 開頭，所以走 1；B 再走 0；C 在 B 下面再走 0 [▶ 38:40](https://youtu.be/EKdlz3vae04?t=2320)。

這棵樹和前面有什麼不同？學生答：**C 是 B 的子節點**；前一棵樹走到字母就沒有子節點了。[▶ 39:20](https://youtu.be/EKdlz3vae04?t=2360) 講者：對，B 不是葉子，因為 B（`10`）是 C（`100`）的前綴。所以這不是前綴碼。

### 6.4 等價關係

[▶ 39:20](https://youtu.be/EKdlz3vae04?t=2360)

> **前綴碼 ⟺ 所有碼字都在葉子上的二元樹。**

[▶ 40:20](https://youtu.be/EKdlz3vae04?t=2420) 直覺：如果某個碼字不是葉子而是內部節點，就能從它往下延伸出另一個碼字，那它就是那個碼字的前綴。

【課本補充】§5.2（書頁 108）用同一個圖（Figure 5.2）證明 Kraft 不等式：前綴條件 = 沒有碼字是另一個碼字的祖先（ancestor），所以每個碼字會「吃掉」它下面所有的後代。

## 7. 什麼是「好」的前綴碼

[▶ 40:55](https://youtu.be/EKdlz3vae04?t=2455) 回顧：唯一可解碼碼、前綴碼、前綴碼可以畫成樹。

[▶ 41:36](https://youtu.be/EKdlz3vae04?t=2496) 想看嚴謹證明的，推薦課本 Cover & Thomas《Information Theory》第 5 章；【口頭】Cover 以前是 Stanford 的教授，書裡的習題也很好。

### 7.1 定義

[▶ 42:57](https://youtu.be/EKdlz3vae04?t=2577) **好的前綴碼** = 在前綴碼裡，讓期望碼長最小的碼：

$$\min\ \mathbb{E}\left[l(X)\right]\quad\text{subject to 是前綴碼}$$

### 7.2 性質 1：機率大的碼短

[▶ 42:21](https://youtu.be/EKdlz3vae04?t=2541) 若 $P(s_1)>P(s_2)$，則 $l(s_1)\le l(s_2)$。

【課堂討論】學生答：機率大的應該比較**短**。

[▶ 43:31](https://youtu.be/EKdlz3vae04?t=2611) **一行證明**：如果某個碼有 $l(s_1)>l(s_2)$，就把 $s_1$ 和 $s_2$ 的碼字**交換**，期望碼長會嚴格變小 [▶ 44:27](https://youtu.be/EKdlz3vae04?t=2667)。所以最佳碼不會有這種情況。

> 以下**不是逐字稿內容**，是把「交換會變好」算出來：交換前後只有 $s_1$、$s_2$ 兩項改變，差是
> $$\left[P(s_1)l(s_2)+P(s_2)l(s_1)\right]-\left[P(s_1)l(s_1)+P(s_2)l(s_2)\right]=-\left(P(s_1)-P(s_2)\right)\left(l(s_1)-l(s_2)\right)<0.$$
> 兩個括號都是正的，所以交換後的期望碼長嚴格變小。交換不改變碼字集合，所以還是前綴碼。

### 7.3 性質 2：$l(x)\approx\log_2\frac{1}{P(x)}$（先相信，第 3 集證）

[▶ 45:18](https://youtu.be/EKdlz3vae04?t=2718) 好的碼長大約是

$$l(x)\approx\log_2\frac{1}{P(x)}$$

[▶ 45:52](https://youtu.be/EKdlz3vae04?t=2752) 這比性質 1 更強：性質 1 只說「機率大 → 短」，這條直接說「機率 $p$ → 長度 $\log_2\frac1p$」。這就是其他領域看到的**負對數概似**（negative log-likelihood）。

**例 1：均勻分布** [▶ 46:35](https://youtu.be/EKdlz3vae04?t=2795)：$P(A)=P(B)=\frac12$，$\log_2 2=1$，所以好的碼是 A→`0`、B→`1`。

[▶ 47:11](https://youtu.be/EKdlz3vae04?t=2831) 一般地，$X$ 在 $\{1,\dots,k\}$ 上均勻，好的碼 $l(x)\approx\log_2 k$。【課堂討論】什麼時候能剛好相等？學生答：**$k$ 是 2 的冪時** [▶ 47:48](https://youtu.be/EKdlz3vae04?t=2868)。那就是固定長度碼。一般情況固定長度碼最多做到 $\lceil\log_2 k\rceil$，因為 $\log_2 k$ 可能不是整數。

[▶ 48:23](https://youtu.be/EKdlz3vae04?t=2903) 均勻分布時大家機率一樣，長度也該一樣，直覺也合理。

**例 2** [▶ 49:12](https://youtu.be/EKdlz3vae04?t=2952)：碼 `0`、`10`、`110`、`111`，配分布 $\left(\frac12,\frac14,\frac18,\frac18\right)$：

| 符號 | $P(x)$ | $\log_2\frac{1}{P(x)}$ | 碼字 | $l(x)$ |
|---|---|---|---|---|
| A | 1/2 | 1 | 0 | 1 |
| B | 1/4 | 2 | 10 | 2 |
| C | 1/8 | 3 | 110 | 3 |
| D | 1/8 | 3 | 111 | 3 |

碼長剛好等於 $\log_2\frac1{P(x)}$ [▶ 49:49](https://youtu.be/EKdlz3vae04?t=2989)。下一集會證明這組碼對這個分布是最佳的。

【課本補充】這就是 §5.1 Example 5.1.1：期望長度 = 熵 = 1.75 位元。

[▶ 50:24](https://youtu.be/EKdlz3vae04?t=3024) 記住：**重點是性質 2**，碼長應該約等於 $\log\frac{1}{\text{機率}}$。

## 8. Shannon 碼

### 8.1 背景

[▶ 50:24](https://youtu.be/EKdlz3vae04?t=3024) Claude Shannon 創立了資訊理論，有兩大部分 [▶ 51:01](https://youtu.be/EKdlz3vae04?t=3061)：**壓縮**（本課）和**錯誤更正碼**（error correction coding，所有通訊都用到）。Shannon 碼是他自己提出的、一個符合性質 2 的好前綴碼。

【口頭】[▶ 51:37](https://youtu.be/EKdlz3vae04?t=3097) 推薦讀 Shannon 1948 年的論文〈A Mathematical Theory of Communication〉的壓縮部分，用很簡單、直覺的文字寫成，不需要花俏的數學。

### 8.2 目標

[▶ 52:30](https://youtu.be/EKdlz3vae04?t=3150) Shannon 碼是前綴碼，而且符號 $x$ 的碼長是

$$l(x)=\left\lceil\log_2\frac{1}{P(x)}\right\rceil$$

（逐字稿只說「log base 2 1 over p of x」；投影片 `L2_ann.pdf` 寫明有**取上整**，因為碼長必須是整數。）

【課堂討論】[▶ 52:30](https://youtu.be/EKdlz3vae04?t=3150) 為什麼是 $\log_2$，不是 $\log_3$、$\ln$、$\log_{10}$？學生答：因為輸出是二元的，編成位元。[▶ 53:02](https://youtu.be/EKdlz3vae04?t=3182) 講者：如果哪天半導體有三個電位，就會用 $\log_3$。

> [▶ 53:51](https://youtu.be/EKdlz3vae04?t=3231) 約定：本課看到 $\log$ 沒寫底數，就是 $\log_2$。

### 8.3 建構（貪婪演算法）

[▶ 53:51](https://youtu.be/EKdlz3vae04?t=3231)

1. 對每個 $x$，算 $l(x)=\left\lceil\log_2\frac{1}{P(x)}\right\rceil$。
2. 把符號照碼長**由短到長**排序：$l(x_1)\le l(x_2)\le\cdots$。
3. 照這個順序，對每個符號 $x$：在樹上深度 $l(x)$ 的地方找一個**不違反前綴條件**的葉子給它 [▶ 54:36](https://youtu.be/EKdlz3vae04?t=3276)。

> ⚠️ 逐字稿缺字 [▶ 53:51](https://youtu.be/EKdlz3vae04?t=3231)：字幕說「sort … $l(x_1)$ greater than or equal to $l(x_2)$」，但接著說「increasing order of the lengths」；投影片寫的是 $l(x_1)\le l(x_2)\le\cdots$，所以是由短到長。

[▶ 55:35](https://youtu.be/EKdlz3vae04?t=3335) 第一份作業要實作它。[▶ 56:06](https://youtu.be/EKdlz3vae04?t=3366) 不用想太多：每個符號就在對應深度找一個「還不是別人後代」的節點。[▶ 58:39](https://youtu.be/EKdlz3vae04?t=3519) 實作時建議**照字典順序**挑節點，演算法比較確定；示範時隨便挑都可以。

### 8.4 例子

[▶ 56:54](https://youtu.be/EKdlz3vae04?t=3414)（機率依投影片 `L2_ann.pdf` p.23；碼長講者在家算好）

| $x$ | $P(x)$ | $\log_2\frac1{P(x)}$ | $l(x)$ | 課堂給的碼字 |
|---|---|---|---|---|
| A | 0.3 | 1.74 | 2 | `00` |
| B | 0.3 | 1.74 | 2 | `01` |
| C | 0.2 | 2.32 | 3 | `111` |
| D | 0.15 | 2.74 | 3 | `101` |

（中間那欄是自己算的，取到小數第二位。）

過程【課堂討論】：

## 9. 證明：Shannon 碼的建構一定成功

### 9.1 要證什麼

[▶ 1:02:07](https://youtu.be/EKdlz3vae04?t=3727) 步驟 1、2 一定做得到。步驟 3 需要「每次都**還有葉子可以用**」。[▶ 1:02:44](https://youtu.be/EKdlz3vae04?t=3764) 就像學過的貪婪演算法（例如最小生成樹），要證明下一步一定可行。用歸納法。

> **要證**：在深度 $l(x)$ 一定找得到一個不違反前綴條件的葉子。

【口頭】[▶ 1:03:28](https://youtu.be/EKdlz3vae04?t=3808) 沒做過證明的人別擔心，課程只有很小一部分靠它；這個證明很直覺，不是那種「突然就證完了」的證明。

### 9.2 第一步：$\sum 2^{-l(x)}\le1$

[▶ 1:03:28](https://youtu.be/EKdlz3vae04?t=3808)

$$
\begin{aligned}
\sum_{x\in\mathcal{X}}2^{-l(x)}
&=\sum_{x\in\mathcal{X}}2^{-\left\lceil\log_2\frac{1}{P(x)}\right\rceil}\\
&\le\sum_{x\in\mathcal{X}}2^{-\log_2\frac{1}{P(x)}}&&\left(\lceil a\rceil\ge a\Rightarrow-\lceil a\rceil\le-a\right)\\
&=\sum_{x\in\mathcal{X}}P(x)=1 \qquad\text{①}
\end{aligned}
$$

[▶ 1:04:16](https://youtu.be/EKdlz3vae04?t=3856) 關鍵：$\lceil a\rceil\ge a$，所以 $-\lceil a\rceil\le-a$，拿掉上整只會讓式子變大；之後 $2^{-\log_2(1/p)}=p$ [▶ 1:04:50](https://youtu.be/EKdlz3vae04?t=3890)。

### 9.3 第二步：代數整理

[▶ 1:05:25](https://youtu.be/EKdlz3vae04?t=3925) 假設已經放好 $x_1,\dots,x_m$，現在要放 $x_{m+1}$。① 是對**所有**符號加總，前 $m+1$ 項只是一部分 [▶ 1:06:08](https://youtu.be/EKdlz3vae04?t=3968)：

$$\sum_{i=1}^{m}2^{-l(x_i)}+2^{-l(x_{m+1})}\le1$$

[▶ 1:06:46](https://youtu.be/EKdlz3vae04?t=4006) 兩邊乘 $2^{l(x_{m+1})}$，再把一項移到右邊：

$$\sum_{i=1}^{m}2^{\,l(x_{m+1})-l(x_i)}\le2^{\,l(x_{m+1})}-1\qquad\text{②}$$

### 9.4 第三步：用樹來解讀

[▶ 1:08:08](https://youtu.be/EKdlz3vae04?t=4088) 數數看：

- 二元樹在深度 $l$ 有 $2^{l}$ 個節點 [▶ 1:08:44](https://youtu.be/EKdlz3vae04?t=4124)。
- 深度 $l_i$ 的節點，在深度 $l_{m+1}$ 有 $2^{\,l_{m+1}-l_i}$ 個後代 [▶ 1:09:17](https://youtu.be/EKdlz3vae04?t=4157)。

[▶ 1:10:02](https://youtu.be/EKdlz3vae04?t=4202) 所以 ② 的意思是：

- 左邊每一項 $2^{\,l(x_{m+1})-l(x_i)}$ = 已放好的碼字 $x_i$ 在深度 $l(x_{m+1})$ 的後代數，這些位置**不能用**（用了 $x_i$ 就變成它的前綴）[▶ 1:12:06](https://youtu.be/EKdlz3vae04?t=4326)。
- 右邊 $2^{l(x_{m+1})}$ = 深度 $l(x_{m+1})$ 的節點總數 [▶ 1:10:44](https://youtu.be/EKdlz3vae04?t=4244)。

[▶ 1:13:31](https://youtu.be/EKdlz3vae04?t=4411) 移項：

$$\underbrace{2^{\,l(x_{m+1})}}_{\text{深度 }l(x_{m+1})\text{ 的節點總數}}-\underbrace{\sum_{i=1}^{m}2^{\,l(x_{m+1})-l(x_i)}}_{\text{被已放碼字擋掉的節點數}}\ge1$$

[▶ 1:14:34](https://youtu.be/EKdlz3vae04?t=4474) 所以**每一步至少還剩一個葉子**可以給 $x_{m+1}$。證畢。

[▶ 1:11:20](https://youtu.be/EKdlz3vae04?t=4280) 圖像：把每個已放的碼字往下延伸到 $x_{m+1}$ 的深度，那些範圍都不能用；扣掉之後至少還剩一個節點。例如 $x_1=$`00`，深度 4 的 `0000`、`0001`、`0010`、`0011` 都不能用 [▶ 1:12:06](https://youtu.be/EKdlz3vae04?t=4326)。

> 以下**不是逐字稿內容**，是補一個證明裡沒明講的細節：為什麼「被擋掉的節點」可以直接相加、不會重複算？因為已放的碼字兩兩不是彼此的前綴，它們的子樹互不重疊。另外，也要確認 $x_{m+1}$ 本身不會是已放碼字的**祖先**：已放的碼字長度都 $\le l(x_{m+1})$（照長度排序），所以深度 $l(x_{m+1})$ 的節點不可能在它們上面。這就是為什麼步驟 2 要先排序。

[▶ 1:15:52](https://youtu.be/EKdlz3vae04?t=4552) Kraft 不等式沒時間講，下一講再講。【口頭】別怕證明，只有兩講；之後大多是演算法。怕的話就自己畫幾棵樹，看看每一步的這些數量。

【課本補充】§5.4（書頁 112–113）用同一個 $l(x)=\lceil\log\frac1{p(x)}\rceil$，並證明 $H(X)\le L<H(X)+1$。第 3 集會講。

## 10. 一頁速查表

### 碼的類別

| 類別 | 定義 | 例子 |
|---|---|---|
| 非奇異 | 不同符號 → 不同碼字 | A→`0`、B→`00` |
| 唯一可解碼 | 不同的**序列** → 不同輸出（長度可不同） | A→`0`、B→`01`、C→`11` |
| 前綴碼（即時碼） | 沒有碼字是另一個的前綴 | A→`0`、B→`10`、C→`110`、D→`111` |

前綴碼 ⊂ 唯一可解碼 ⊂ 非奇異。**關鍵一步**（前綴 ⇒ 唯一可解碼）：解碼演算法每一步只有一種選擇。

### 前綴碼和樹

- 前綴碼 ⟺ 碼字全在葉子上的二元樹；根到葉子的路徑 = 碼字。
- 深度 $l$ 有 $2^l$ 個節點；深度 $l_i$ 的節點在深度 $L$ 有 $2^{L-l_i}$ 個後代。

### 分組

- $n$ 個一組的固定長度碼：每符號 $\frac{\lceil n\log_2|\mathcal{X}|\rceil}{n}\in\left[\log_2|\mathcal{X}|,\ \log_2|\mathcal{X}|+\frac1n\right)$。

### 好的前綴碼

- 定義：$\min\mathbb{E}[l(X)]$，限制是前綴碼。
- 性質 1：$P(s_1)>P(s_2)\Rightarrow l(s_1)\le l(s_2)$。**關鍵一步**：交換碼字，差 $=-(P_1-P_2)(l_1-l_2)<0$。
- 性質 2：$l(x)\approx\log_2\frac{1}{P(x)}$（第 3 集證）。

### Shannon 碼

- $l(x)=\left\lceil\log_2\frac{1}{P(x)}\right\rceil$；由短到長排序，貪婪地放在樹上。
- **關鍵一步**：$\sum_x2^{-l(x)}\le\sum_x P(x)=1$ ⇒ 總節點 $2^{l_{m+1}}$ 減掉被擋的 $\sum_{i\le m}2^{l_{m+1}-l_i}$ 還 $\ge1$。
- 很好，但不一定最佳（例：$(0.3,0.3,0.2,0.15,0.05)$ 課堂碼 2.5，可改進到 2.2）。

## 附：本集一句話總結

> **「無損」要對整串符號定義：唯一可解碼 = 不同序列不會編成同一個輸出。前綴碼（沒有碼字是另一個的開頭）一定唯一可解碼，可以邊讀邊解，等於碼字都在葉子上的二元樹。好的碼長大約是 $\log_2\frac1{P(x)}$；Shannon 碼取 $\lceil\log_2\frac1{P(x)}\rceil$ 再貪婪地放到樹上，因為 $\sum2^{-l(x)}\le1$，一定放得下。**
