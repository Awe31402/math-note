## 1. 策略最佳化收尾：TRPO 與 PPO

### 1.1 動機：像監督式學習那樣「解到收斂」

[▶ 00:35](https://youtu.be/ZXMThMHFD_w?t=35) 機器學習最先進的做法，最後都歸結為**數值最佳化問題**：例如迴歸——定義訓練誤差，用資料集反覆最佳化到收斂到某個局部最佳。

RL 到目前不是這樣：

- **基於值**（Q-learning）[▶ 01:36](https://youtu.be/ZXMThMHFD_w?t=96)：不是在最佳化一個目標，而是不動點迭代（可以把離線資料集的所有轉移都放進去）；但沒有在最佳化真正的 RL 目標。
- **策略最佳化** [▶ 02:06](https://youtu.be/ZXMThMHFD_w?t=126)：確實在最佳化真正的 RL 目標，但**一次只走一步梯度**（同策略：互動 → 收集資料 → 一步 → 重複）。

**TRPO**（trust region policy optimization）和 **PPO**（proximal policy optimization）的出發點：定義一個**替代問題**，可以對策略做**連續多步**更新，之後才去環境收集新經驗。

### 1.2 替代目標與重要性取樣

[▶ 03:07](https://youtu.be/ZXMThMHFD_w?t=187) 策略梯度（用優勢 $\hat A$）：

$$\nabla_\theta J=\mathbb E\left[\nabla_\theta\log\pi_\theta(u_t\mid x_t)\,\hat A_t\right]$$

**替代目標**（surrogate objective）[▶ 04:10](https://youtu.be/ZXMThMHFD_w?t=250)：一個本身不太在乎的量，但**對它微分就得到策略梯度**。實務上（作業裡）用自動微分就是這樣做：

$$L^{PG}(\theta)=\mathbb E\left[\log\pi_\theta(u_t\mid x_t)\,\hat A_t\right]$$

**重要性取樣版本** [▶ 04:41](https://youtu.be/ZXMThMHFD_w?t=281)（IS = importance sampling）：

$$L^{IS}(\theta)=\mathbb E\left[\frac{\pi_\theta(u_t\mid x_t)}{\pi_{\theta_{\text{old}}}(u_t\mid x_t)}\hat A_t\right]$$

- 分母是**舊版**策略（參數 $\theta_{\text{old}}$），分子是**新版**。
- **檢查** [▶ 05:12](https://youtu.be/ZXMThMHFD_w?t=312)：由鏈鎖法則，$\nabla\log\pi_\theta=\nabla\pi_\theta/\pi_\theta$，所以在 $\theta=\theta_{\text{old}}$ 時兩個替代目標的梯度相同。
- **好處** [▶ 05:43](https://youtu.be/ZXMThMHFD_w?t=343)：即使資料是用**舊版**策略 $\pi_{\theta_{\text{old}}}$ 收集的，這個目標仍然定義良好。所以連續更新策略好幾步（離 $\theta_{\text{old}}$ 越來越遠）時，它仍有效——重要性比率會依舊策略重新加權動作的機率。

### 1.3 TRPO：信任域

[▶ 07:49](https://youtu.be/ZXMThMHFD_w?t=469) 但離 $\theta_{\text{old}}$ 越遠，優勢的估計越不準，比率也可能讓學習停滯。所以要在原策略的一個**鄰域**內走多步——**信任域**（trust region），最佳化中很常見的技巧：

$$\max_\theta\ L^{IS}(\theta)\quad\text{s.t.}\quad\mathbb E\left[D_{KL}\left(\pi_{\theta_{\text{old}}}(\cdot\mid x)\ \|\ \pi_\theta(\cdot\mid x)\right)\right]\le\delta$$

- $D_{KL}$：**KL 散度**，衡量兩個分布差多少。
- **為什麼用 KL** [▶ 09:23](https://youtu.be/ZXMThMHFD_w?t=563)：衡量兩個策略「多近」有很多方法，最直觀的是參數空間的距離 $\|\theta-\theta_{\text{old}}\|$。但 KL 直接在**策略分布空間**量距離——這才是我們真正在乎的。參數可能變很多，但只要策略誘導的動作分布相近就好。

【Q&A】[▶ 09:54](https://youtu.be/ZXMThMHFD_w?t=594) 學生問 KL 外面也有期望嗎？答：要看是否對不同軌跡平均；實際上會抽多條軌跡取經驗平均。

**評價** [▶ 10:28](https://youtu.be/ZXMThMHFD_w?t=628)：

- 當時非常成功、相當可靠，尤其在**連續控制**問題。
- 缺點：從無約束變成**有約束**的問題 → 通常要用**共軛梯度法**，實作麻煩；經驗上配深度網路（CNN、大型 Transformer）表現偏弱。
- 但影響很大：啟發了後續簡化它的演算法——**PPO**。

### 1.4 PPO：截斷

[▶ 11:59](https://youtu.be/ZXMThMHFD_w?t=719) PPO 想回答：能不能達到 TRPO 同樣的目標，但不用二階最佳化／有約束的問題？兩個常見版本：

**版本 1：懲罰** [▶ 12:36](https://youtu.be/ZXMThMHFD_w?t=756)：用 Lagrange 乘數把約束搬進目標，變成無約束，用 SGD 解：

$$\max_\theta\ L^{IS}(\theta)-\beta\,\mathbb E\left[D_{KL}\left(\pi_{\theta_{\text{old}}}\|\pi_\theta\right)\right]$$

**版本 2：截斷**（最流行）[▶ 13:07](https://youtu.be/ZXMThMHFD_w?t=787)：用經驗式模仿約束的效果。記比率 $r_t(\theta)=\dfrac{\pi_\theta(u_t\mid x_t)}{\pi_{\theta_{\text{old}}}(u_t\mid x_t)}$（在 $\theta_{\text{old}}$ 時 $r=1$）：

$$\boxed{L^{CLIP}(\theta)=\mathbb E\left[\min\left(r_t(\theta)\hat A_t,\ \mathrm{clip}\left(r_t(\theta),1-\varepsilon,1+\varepsilon\right)\hat A_t\right)\right]}$$

- **clip** [▶ 14:11](https://youtu.be/ZXMThMHFD_w?t=851)：把 $r$ 限制在 $[1-\varepsilon,1+\varepsilon]$：在範圍內保留原值，超出就截在邊界。直覺上讓新策略不要跟舊策略差太多。
- **min**：讓整個目標成為 $r\hat A$ 的**下界**。

【Q&A】[▶ 15:44](https://youtu.be/ZXMThMHFD_w?t=944) 學生問 min 的作用？答：我們在乎的是這個目標給的**梯度**。想要：離舊策略很遠、而且是往**對表現不利**的方向時，讓梯度**飽和**（截掉）；如果走大一點反而能回到舊策略附近，就讓梯度通過。建議自己畫圖、逐一分情況看。兩個直覺：（1）給實際目標一個下界；（2）梯度在該飽和時飽和，需要恢復時不飽和。

【口頭】[▶ 17:18](https://youtu.be/ZXMThMHFD_w?t=1038) PPO 大概是現在**最流行**（甚至就是最流行）的 RL 演算法。

## 2. 無模型 RL 總複習

[▶ 17:50](https://youtu.be/ZXMThMHFD_w?t=1070) 講者花幾分鐘把重點講一遍：

| 主題 | 重點 |
|---|---|
| **DP** | 用動態精確算一步期望；精確但要知道 MDP |
| **MC** | 跟環境互動、走到終端、往觀察到的回報更新；**無偏、高變異**，要終端狀態 |
| **TD** | MC 的取樣 + DP 的自舉；**低變異**、可線上學，但**有偏** |
| $V$ 和 $Q$ | 以上都適用 |
| **表格 → 函數近似** | 回報和 TD 目標變成參數空間更新的迴歸標籤 |
| **基於值** | 廣義策略迭代（評估 ↔ 貪婪改進）；SARSA（同策略）、Q-learning（離策略）；DQN |
| **策略最佳化** | 參數化 $\pi_\theta$，直接最佳化 RL 目標：估梯度 → 近似梯度上升；策略梯度 = 加權最大概似（試誤）；高變異 → 基準線、評論家（actor-critic） |

**RL 骨架**（再看一次）[▶ 24:13](https://youtu.be/ZXMThMHFD_w?t=1453)：產生樣本 → 估回報／值函數，**或擬合模型**（今天）→ 改進策略（貪婪或梯度）。

**取捨現在具體了** [▶ 24:45](https://youtu.be/ZXMThMHFD_w?t=1485)：

- 樣本效率 vs 穩定：同策略 vs 離策略（跟環境互動有多貴）。
- 連續 vs 離散動作 → 基於值 vs 策略最佳化。
- 回合制 vs 無限時域 → MC 需要回合制。
- **樣本效率光譜**（由低到高）[▶ 25:46](https://youtu.be/ZXMThMHFD_w?t=1546)：同策略策略梯度 → actor-critic（用值函數近似）→ 離策略 Q-learning（能用離線資料）→ **基於模型 RL**。

## 3. 基於模型 RL：基本食譜

### 3.1 食譜與它什麼時候行

[▶ 27:51](https://youtu.be/ZXMThMHFD_w?t=1671) 如果知道動態 $f(x,u)\to x'$，就能用前半學期任何最佳控制工具（直接法、間接法……）。所以：用互動收集轉移資料，學一個近似的動態模型。

```
1. 跑基礎策略 π₀（可以隨機、探索性、或來自領域知識），收集 D = {(x_t, u_t, x_{t+1})}
2. 擬合動態模型 f_θ：例如最小化 Σ ‖f_θ(x_t,u_t) − x_{t+1}‖²（或最大化對數概似）
3. 用 f_θ 規劃
```

**行得通嗎？** [▶ 29:57](https://youtu.be/ZXMThMHFD_w?t=1797)

- **有時行**：動態相對簡單（例如線性時不變）時效果很好。跟**系統辨識**的討論相關：模型理解得不錯、真實動態落在要擬合的函數類別裡、只需調少數參數，就能泛化到真系統。
- **大多數情況不行**：動態複雜、非線性，尤其配上**高容量**近似模型（神經網路）時。因為從觀察到的資料**外推**到分布外很難、而且可能誤導。

【課本補充】課本 §18.6.1 也有同樣的三步食譜，並註明它本質上就是**系統辨識**；課本 §18.5.3 列出無模型 RL 的限制（樣本效率差、基本上只學單一任務、稀疏／延遲／雜訊的獎勵很難學），作為基於模型 RL 的動機。

### 3.2 問題：分布偏移

[▶ 31:33](https://youtu.be/ZXMThMHFD_w?t=1893) 示意例子：agent（黑點）要盡量往北走，中間有障礙物。

- 探索策略 $\pi_0$ 只涵蓋狀態空間的一部分 $p_{\pi_0}(x)$。
- 在這些轉移上學模型、拿來規劃：在**看過的狀態**裡可能做得很合理；一旦走出涵蓋的分布，就不是了。
- 這又是**共變量偏移／分布偏移**（像模仿學習）：把學到的模型當規劃演算法的內部元件時，會觀察到**不同的**狀態分布。泛化和外推才是關鍵。

### 3.3 簡單改進：MPC＋資料聚合

[▶ 33:07](https://youtu.be/ZXMThMHFD_w?t=1987) 兩個簡單但實務上改善很大的步驟：

1. **滾動時域規劃（MPC）**：計畫可能有點偏（靠近起點較準），所以重新評估實際位置、重新規劃。
2. **把部署時看到的轉移加回資料集，重新擬合模型** [▶ 33:41](https://youtu.be/ZXMThMHFD_w?t=2021)：逐漸縮小「原策略的狀態分布」和「規劃策略的狀態分布」之間的差距。

（第 2 點類似模仿學習的 DAgger。）

### 3.4 核心問題：最佳化器會利用模型的錯誤

[▶ 34:42](https://youtu.be/ZXMThMHFD_w?t=2082) 今天的重點是**不確定性量化**。為什麼？

- 想要**高容量**模型，在資料多時表示複雜動態。
- 但資料少時又**不能過擬合**。
- 因為如果用最佳化器／規劃演算法在學到的模型上最佳化，最佳化會傾向於**利用模型「往好的方向」的錯誤**。

**圖** [▶ 35:45](https://youtu.be/ZXMThMHFD_w?t=2145)：幾個紅色資料點，兩條曲線都擬合得很好；藍色（高容量、過擬合）在資料點上完美，但資料外**亂跳**。想最大化藍色模型預測表現的最佳化器，會被吸引去選那些模型**預測獎勵很高**（其實是模型錯誤）的行為。

**緊張關係**：學到的模型可能外推不好 + 最佳化器像黑盒，會利用正向的錯誤。解法：考慮模型對自己預測**有多確定**。

【課本補充】課本 §18.6.1 同樣強調：最佳化演算法會自然地利用模型中「預測表現高、但實際不一定高」的不準確處。

## 4. 不確定性量化

### 4.1 為什麼不確定性能幫規劃

[▶ 37:25](https://youtu.be/ZXMThMHFD_w?t=2245) **不確定性** = 對可能結果的**分布**。不是預測一個「最可能的下一狀態」點估計，而是預測一整個分布和對應的機率——一組可能情境。這讓我們能用**模型下的期望**來推理。

**例子** [▶ 38:28](https://youtu.be/ZXMThMHFD_w?t=2308)：黑點要到綠星（目標），旁邊是**懸崖**（越過線就結束）。兩條候選的開迴路動作序列，在腦中模擬：

| 情況 | 序列 A（終點離目標近） | 序列 B（終點離目標遠） | 選誰 |
|---|---|---|---|
| 兩者預測都很確定（小圓圈） | — | — | A |
| A 的終點不確定性很大（大圓圈，但期望值一樣） | 很多可能結果掉下懸崖 → **期望獎勵較低** | — | 可能 B |

重點 [▶ 40:32](https://youtu.be/ZXMThMHFD_w?t=2432)：能估計不確定性，就能把表現寫成**模型下的期望獎勵**。

### 4.2 偶然 vs 認知不確定性

**方法 1：用模型輸出的熵** [▶ 41:36](https://youtu.be/ZXMThMHFD_w?t=2496)：學 $p_\theta(x'\mid x,u)$——離散狀態用類別分布，連續用高斯（均值 + 標準差）。可以用分布本身的熵（例如高斯的標準差）。

**但熵不等於認知不確定性** [▶ 42:36](https://youtu.be/ZXMThMHFD_w?t=2556)：

| 類型 | 意思 | 例子 |
|---|---|---|
| **偶然不確定性**（aleatoric） | 過程本身**固有**的雜訊，無法建模 | 觀察一條拋物線，資料點有固有雜訊；拋物線參數本身是確定的 |
| **認知不確定性**（epistemic） | 對**模型本身**不確定 | 兩條參數不同的曲線（綠、藍）都同樣擬合資料——哪一組參數才對？ |

輸出熵能抓到一部分，但抓不到真正在乎的：**可能同時成立的、不同模型的解釋**。

### 4.3 貝氏觀點：後驗預測分布

[▶ 44:49](https://youtu.be/ZXMThMHFD_w?t=2689) 最常見的做法：**貝氏**方法。不是收斂到一組參數，而是建模**給定資料下參數的分布**：

$$p(\theta\mid\mathcal D)$$

所有可信假設的完整分布。

**後驗預測分布**（posterior predictive）[▶ 45:51](https://youtu.be/ZXMThMHFD_w?t=2751)：用學到的模型預測時，對**所有參數**平均：

$$p(x'\mid x,u,\mathcal D)=\int p(x'\mid x,u,\theta)\,p(\theta\mid\mathcal D)\,d\theta$$

**離散情況的直覺** [▶ 46:52](https://youtu.be/ZXMThMHFD_w?t=2812)：只有兩個 $\theta$ 值 → 用兩個都預測一次，依各自的機率加權。積分是連續版。

【課本補充】課本 §18.6.1 用貝氏定理寫出後驗 $p(\theta\mid\mathcal D)=\dfrac{p(\mathcal D\mid\theta)p(\theta)}{p(\mathcal D)}$，並推薦 Murphy 的教科書。

**例子：貝氏線性迴歸** [▶ 47:23](https://youtu.be/ZXMThMHFD_w?t=2843)：擬合一條直線（兩個參數：截距、斜率），真實過程是虛線。

| 資料量 | 後驗 $p(\theta\mid\mathcal D)$（參數平面） | 抽樣出的直線 | 預測信賴帶 |
|---|---|---|---|
| 1 個點 | 很寬（無限多條線都通過那點） | 各方向都有 | 很寬 |
| 較多點 | 較窄、靠近真值（紅叉） | 較集中 | 較窄 |
| 夠多點 | 很集中 | 幾乎重合 | 可靠地貼近真模型 |

### 4.4 高斯過程

[▶ 49:58](https://youtu.be/ZXMThMHFD_w?t=2998) 兩個最流行的「考慮不確定性的動態模型」：高斯過程、集成。

**高斯過程**（Gaussian process，GP）：**函數上的分布**。

- 從**先驗**函數分布抽樣（還沒看資料）→ 行為差很多。
- GP 用**解析**方式從先驗更新到**後驗**函數分布——跟資料一致的函數分布。

**「函數上的分布」是什麼意思？** [▶ 50:59](https://youtu.be/ZXMThMHFD_w?t=3059)

- GP 把資料建模成**多變量高斯**。
- 從二維高斯抽一個點，例如 $(5,4)$；把兩個座標依序畫出來（第一個值 5、第二個值 4、連起來）→ 一個只在小區間上的、離散化的函數。
- 從 $n$ 維高斯（例如 100 維）抽一個向量，同樣畫出來 → 在很細的格子上近似一個函數。

【Q&A】[▶ 54:22](https://youtu.be/ZXMThMHFD_w?t=3262) 學生問：維度的順序是隱含假設的？答：對，畫圖時隱含了維度的順序。但對學習沒影響——資料活在高維空間，我們是把 $n$ 維高斯擬合到那個資料；畫法只是畫法。

**優缺點** [▶ 55:24](https://youtu.be/ZXMThMHFD_w?t=3324)：

| 優點 | 缺點 |
|---|---|
| **非常省資料** | 解析後驗需要**矩陣求逆**，大小隨資料點數 $n$ 成長 → 擴展到大資料、高維很難（有延伸版處理） |
| 給出**精確**的解析後驗（在高斯假設下）：在極少資料下就有很好的信賴帶——用神經網路很難做到 | |

### 4.5 自助集成

[▶ 56:57](https://youtu.be/ZXMThMHFD_w?t=3417) **自助集成**（bootstrap ensembles）：訓練**多個**模型，看它們在哪裡同意。

- 獨立訓練去擬合同一份資料的不同模型，在**有把握**的地方（靠近資料）會同意，在**不確定**的地方（離資料遠）會不同意。
- 演算法 [▶ 58:30](https://youtu.be/ZXMThMHFD_w?t=3510)：獨立訓練 $N$ 份模型（例如五個神經網路），得到五個下一狀態預測，例如取平均當預測。

**跟後驗的關係** [▶ 59:01](https://youtu.be/ZXMThMHFD_w?t=3541)：圖中真實後驗是多峰的陰影分布。四個獨立訓練的模型（藍色）因為**隨機初始化**和 **SGD 的隨機性**，會收斂到不同的局部最小 → 是真實後驗的**經驗近似**，探索了後驗地形的不同峰。

【Q&A】[▶ 60:35](https://youtu.be/ZXMThMHFD_w?t=3635) 學生確認：每個網路代表後驗的一個峰？答：對。這個學習問題的解很可能高度多峰；GP 那類方法推導精確的解析式；集成則放棄形式化，直接建 $N$ 份、不同初始化，靠 SGD 的隨機性收斂到不同解，希望涵蓋後驗中有意義的不同峰。怎麼區分這些複本？神經網路的初始參數隨機、SGD 的方向也有隨機性，自然就不同。

【Q&A】[▶ 62:10](https://youtu.be/ZXMThMHFD_w?t=3730) 學生問：為什麼是 Dirac 分布？答：正式地說，是用 **Dirac 分布**的平均近似真實後驗：一個觀察到的 $\theta_k$ 對應一個「尖刺」分布，把全部機率質量放在那一點：

$$p(\theta\mid\mathcal D)\approx\frac1N\sum_{k=1}^N\delta\left(\theta-\theta_k\right)$$

代進後驗預測分布，就變成「各模型預測的平均」。

> 講者說圖上的 VI（變分推論）和 multi-SWAG 先不管。

## 5. 用不確定性規劃；PETS

[▶ 65:18](https://youtu.be/ZXMThMHFD_w?t=3918) 怎麼用？

**評估一個候選動作序列** [▶ 65:48](https://youtu.be/ZXMThMHFD_w?t=3948)（序列來自某個規劃演算法）：

```
重複 K 次：
    1. 從後驗抽一組參數 θ_k ~ p(θ | D)
    2. 用 f_{θ_k} 把動作序列往前推，得到一條預測軌跡
    3. 算這條軌跡的獎勵總和
平均 K 條的獎勵 → 模型不確定性下的期望獎勵
```

這正是 4.1 懸崖例子的實作：把表現寫成模型下的期望獎勵。

【口頭】[▶ 68:28](https://youtu.be/ZXMThMHFD_w?t=4108) 這只是**一種選擇**，不是「基於模型 RL 的最佳做法」。看問題：線性時不變模型估得夠好時，根本不需要不確定性量化。但動態難近似、要用高容量模型時，不確定性很重要。

【課本補充】課本 §18.6.1 的五步流程完全一樣：收集資料 → 估後驗 → 抽 $K$ 個模型 → 對候選計畫算期望回報 $V(u_{1:T-1})=\frac1K\sum_k\sum_tR(x_t,u_t)$（$x_{t+1}\sim p_{\theta_k}$）→ 執行最佳計畫的第一個動作。課本 §18.6.2 另外介紹**基於模型的策略最佳化**：用學到的模型產生**合成資料**來加速無模型學習，例如 **Dyna-Q**（課堂沒講）。

**PETS** [▶ 70:02](https://youtu.be/ZXMThMHFD_w?t=4202)（有影響力的論文，有幾年了）：

- 模型：**神經網路集成**，近似模型的後驗。
- 從集成中抽不同模型，產生不同的未來預測（同上）。
- 用**交叉熵法**（cross-entropy method，CEM）產生候選計畫，依集成樣本評分，選最好的。
- 以 **MPC**（滾動時域）方式執行：預測整個計畫，只執行第一步，重複。

**結果** [▶ 71:39](https://youtu.be/ZXMThMHFD_w?t=4299)：跟 PPO、**soft actor-critic**（SAC，actor-critic 的一種）等基準比較多個任務。收斂時的表現差不多，但基於模型的方法（藍線）**樣本效率高很多**——收斂快得多，因為學了模型就能省掉很多跟環境的互動。

【口頭】基於模型 RL 的好處通常就在**樣本效率**。

> PETS 一般指 Chua 等（2018）*Probabilistic Ensembles with Trajectory Sampling*，講者沒說全名。

【Q&A】[▶ 73:09](https://youtu.be/ZXMThMHFD_w?t=4389) 學生問：你最喜歡哪個方法？（全班笑）講者：「我喜歡看問題、務實。」（學生說這是外交辭令。）無模型演算法技術上**更成熟**；連續控制通常首選 **PPO** 和 **SAC**。基於模型 RL 仍是很活躍的研究領域。真的要選，選 SAC 或 PPO——「好吧，那是兩個。」

## 6. 課程總結：方法怎麼組合在一起

[▶ 74:10](https://youtu.be/ZXMThMHFD_w?t=4450) 這門課介紹了一大堆方法：開迴路（間接、直接）、閉迴路、DP、RL、模仿學習……「現在我得從幾百個演算法裡挑，怎麼辦？」

**這些方法不是在競爭**，而是適合不同應用，而且大多數時候**組合使用**——因為決策流程通常是**分層**的 [▶ 74:42](https://youtu.be/ZXMThMHFD_w?t=4482)。以**自駕車**為例：

```
世界表示（例如語意地圖）
        ↓
┌───────────────────────────────┐
│ 高層決策：要不要換車道？        │  閉迴路、類 DP 方法（要處理隨機性）
│   輸出：目標（例如換車道）       │
└──────────────┬────────────────┘
               ↓
┌───────────────────────────────┐
│ 軌跡：把目標變成可執行的軌跡    │  開迴路方法（低保真動態、安全與動態約束）
└──────────────┬────────────────┘
               ↓
┌───────────────────────────────┐
│ 追蹤：讓軌跡在硬體上可行       │  MPC（追蹤版），更精細的動態、安全約束
└──────────────┬────────────────┘
               ↓
┌───────────────────────────────┐
│ 致動器                         │  PID
└───────────────────────────────┘

安全概念（例如 HJ 可達性算出的不安全狀態集合）→ 告知開迴路和／或追蹤模組
```

【口頭】[▶ 79:58](https://youtu.be/ZXMThMHFD_w?t=4798) 希望這門課給了大家所有這些概念的廣泛理解，以及這些模組怎麼組合、各自的優缺點的高層理解。演算法細節依應用而定。

**學習型、端到端方法在這個階層中的位置** [▶ 80:28](https://youtu.be/ZXMThMHFD_w?t=4828)：

- 歷史上，學習從**最高層**開始：**感知**是第一個學習成為事實標準的地方。
- 端到端方法正**一路往下**侵入這個階層，講者說目前大概在**開迴路和閉迴路軌跡追蹤之間**。
- 即使最看好端到端的公司或方法，通常也**不碰最底層**：那裡要細緻的控制、硬約束的保證、確保一切在實務上真的能動。

**結語** [▶ 81:28](https://youtu.be/ZXMThMHFD_w?t=4888)：謝謝大家這學期一路跟著，祝期末考順利。（掌聲）

## 7. 演算法整理

### PPO（clip 版）

**在解什麼**：策略梯度一次只走一步、樣本效率差；想用同一批資料做多步更新，又不讓策略跑太遠。

```
重複：
    1. 用 π_θold 收集一批軌跡；估優勢 Â_t（例如用評論家）
    2. 對這批資料做多個 epoch 的 SGD，最大化
         L(θ) = E[ min( r_t(θ) Â_t, clip(r_t(θ), 1−ε, 1+ε) Â_t ) ]，
         r_t(θ) = π_θ(u_t|x_t) / π_θold(u_t|x_t)
    3. θ_old ← θ
```

**什麼時候會失敗**：走太多步、離 $\theta_{\text{old}}$ 太遠 → 優勢估計失準（clip 只是經驗式的保護）；仍然本質上同策略，比基於模型的方法耗樣本。

### TRPO

```
max_θ E[ r_t(θ) Â_t ]  s.t.  E[ KL(π_θold ‖ π_θ) ] ≤ δ   （共軛梯度法求解）
```

**什麼時候會失敗**：有約束的最佳化實作麻煩；配大型深度網路表現偏弱。

### 基於模型 RL（含不確定性，PETS 式）

**在解什麼**：動態未知、互動很貴，想要樣本效率。

```
D ← 用 π₀ 收集的轉移
重複：
    1. 擬合模型集成 {f_{θ_k}}（或 GP）到 D
    2. 每個時刻（MPC）：
         用 CEM 產生候選動作序列
         對每個候選：抽多個 θ_k，往前推、算獎勵、取平均 → 期望獎勵
         執行最佳序列的第一個動作
    3. 把新轉移加入 D（資料聚合）
```

**什麼時候會失敗**：模型外推到分布外 → 規劃走到沒看過的地方（分布偏移）；高容量模型過擬合 → 最佳化器利用正向錯誤；只用輸出熵 → 抓不到認知不確定性；GP 擴展不到大資料；動態很簡單時這些都是多餘的。

## 8. 一頁速查表

### TRPO／PPO

| 項目 | 式子 |
|---|---|
| 替代目標 | $L^{PG}=\mathbb E[\log\pi_\theta\,\hat A]$；$L^{IS}=\mathbb E\left[\frac{\pi_\theta}{\pi_{\theta_{\text{old}}}}\hat A\right]$（在 $\theta_{\text{old}}$ 梯度相同） |
| TRPO | $\max L^{IS}$ s.t. $\mathbb E[D_{KL}(\pi_{\theta_{\text{old}}}\|\pi_\theta)]\le\delta$（在分布空間量距離） |
| PPO 懲罰 | $L^{IS}-\beta\,\mathbb E[D_{KL}]$ |
| PPO 截斷 | $\mathbb E\left[\min\left(r\hat A,\ \mathrm{clip}(r,1-\varepsilon,1+\varepsilon)\hat A\right)\right]$ |

### 基於模型 RL

| 項目 | 重點 |
|---|---|
| 食譜 | 收集 → 擬合 $f_\theta$ → 規劃（＝系統辨識） |
| 行得通 | 簡單（例如 LTI）動態、模型類別對 |
| 問題 | 分布偏移；最佳化器利用模型的正向錯誤 |
| 簡單改進 | MPC（滾動時域）＋把新轉移加回資料集重新擬合 |
| 好處 | 樣本效率（PETS vs PPO、SAC） |

### 不確定性

| 項目 | 式子／重點 |
|---|---|
| 偶然 vs 認知 | 固有雜訊 vs 對模型本身不確定 |
| 後驗 | $p(\theta\mid\mathcal D)=p(\mathcal D\mid\theta)p(\theta)/p(\mathcal D)$ |
| 後驗預測 | $p(x'\mid x,u,\mathcal D)=\int p(x'\mid x,u,\theta)p(\theta\mid\mathcal D)d\theta$ |
| GP | 函數上的分布；解析精確後驗、省資料；矩陣求逆擴展差 |
| 集成 | $N$ 個獨立訓練的模型；$p(\theta\mid\mathcal D)\approx\frac1N\sum_k\delta(\theta-\theta_k)$ |
| 規劃 | 對候選序列抽 $K$ 個模型往前推、平均獎勵 → 期望獎勵 |
| PETS | 機率集成 + CEM + MPC |

### 課程分層

高層決策（類 DP，處理隨機性）→ 軌跡（開迴路）→ 追蹤（MPC）→ 致動器（PID）；安全集（HJ 可達性）告知中間兩層。端到端學習從感知往下，目前約在軌跡與追蹤之間。

## 附：本集一句話總結

> **PPO 用重要性取樣的替代目標讓同一批資料能更新多步，再用截斷（TRPO 用 KL 信任域）防止新策略離舊策略太遠，成為目前最流行的 RL 演算法。基於模型 RL 先從資料擬合動態再規劃（本質是系統辨識），樣本效率高，但高容量模型在資料外會亂猜、最佳化器又會專挑模型猜錯的「好」地方；解法是量化認知不確定性（貝氏後驗、高斯過程、模型集成），用多個可能模型的平均獎勵評估計畫，PETS 就是集成 + CEM + MPC。整門課的方法不是互相競爭，而是在自主系統的分層架構中各司其職。**
