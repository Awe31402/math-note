## 1. 回顧：MDP、值函數、Bellman 方程

[▶ 02:41](https://youtu.be/cqPbt3OfRK4?t=161)

**MDP**：$\mathcal M=(\mathcal X,\mathcal U,p,R,\gamma)$。$\gamma\in(0,1)$ 既在直覺上權衡長短期獎勵，也讓無限和可處理。

**目標** [▶ 03:43](https://youtu.be/cqPbt3OfRK4?t=223)：找 $\pi^*$ 最大化期望累積折扣獎勵。

| | Bellman **期望**方程（給定 $\pi$） | Bellman **最佳**方程 |
|---|---|---|
| $V$ | $V^\pi(x)=\mathbb E_{u\sim\pi}\left[R(x,u)+\gamma\,\mathbb E_{x'}V^\pi(x')\right]$ | $V^*(x)=\max_u\left[R(x,u)+\gamma\,\mathbb E_{x'}V^*(x')\right]$ |
| $Q$ | $Q^\pi(x,u)=R(x,u)+\gamma\,\mathbb E_{x'}\mathbb E_{u'\sim\pi}Q^\pi(x',u')$ | $Q^*(x,u)=R(x,u)+\gamma\,\mathbb E_{x'}\max_{u'}Q^*(x',u')$ |

（$\mathbb E_{x'}$ 是對 $p(x'\mid x,u)$ 取期望。）

**為什麼要 Q 函數** [▶ 05:45](https://youtu.be/cqPbt3OfRK4?t=345)：可以**隱含地**定義策略：$\pi(x)=\arg\max_uQ(x,u)$。

**表格法的圖像** [▶ 06:19](https://youtu.be/cqPbt3OfRK4?t=379)：今天不講函數近似，把值函數想成**查表**：$V$ 是長度 $n$ 的向量（每個狀態一個值）；$Q$ 是「狀態 × 動作」的矩陣。

## 2. 精確方法：策略迭代

### 2.1 演算法

[▶ 07:21](https://youtu.be/cqPbt3OfRK4?t=441) 第 10 集把 Bellman 方程變成演算法：反覆**強制**這些不動點方程直到收斂。

- **值迭代**：反覆套用 Bellman **最佳**方程。
- **策略迭代**：交替兩步：

| 步驟 | 做什麼 |
|---|---|
| **策略評估**（policy evaluation） | 反覆套用 Bellman **期望**方程，估給定策略的值 $V^\pi$ |
| **策略改進**（policy improvement） | 用最新的值函數做**貪婪**改進：$\pi'(x)=\arg\max_u\left[R(x,u)+\gamma\sum_{x'}p(x'\mid x,u)V^\pi(x')\right]$ |

注意：兩步都用到**動態** $p$。

### 2.2 例子：4×4 格子世界

[▶ 09:58](https://youtu.be/cqPbt3OfRK4?t=598)

- 16 格：14 個非終端狀態（白格），2 個**終端**（目標）狀態。
- 目標：從任何格子出發，**越快**到終點越好。
- 怎麼編碼「越快越好」？[▶ 10:28](https://youtu.be/cqPbt3OfRK4?t=628) 每走一步獎勵 $-1$，直到終點。
- 動作：上下左右。會走出格子的動作 → 留在原地。
- 為了好算：**不折扣**，$\gamma=1$。

**策略評估** [▶ 11:00](https://youtu.be/cqPbt3OfRK4?t=660)：初始策略 = **隨機策略**（每個方向機率 0.25）；值函數初始化為全 0。

例：更新格子 $(2,2)$ [▶ 12:00](https://youtu.be/cqPbt3OfRK4?t=720)：

$$V_1(x)=-1+\sum_{x'}p(x'\mid x,u)\,\pi(u\mid x)\,V_0(x')=-1+0.25\left[V_0(1,2)+V_0(3,2)+V_0(2,1)+V_0(2,3)\right]=-1$$

因為 $V_0$ 全 0，所以 $k=1$ 時**每個**非終端格都是 $-1$。重複迭代 → 值函數的「曲面」不斷演化，收斂到某個值函數 [▶ 14:37](https://youtu.be/cqPbt3OfRK4?t=877)。

【Q&A】[▶ 13:36](https://youtu.be/cqPbt3OfRK4?t=816) 學生問：$k=0$ 一定要全 0 嗎？不能用每格的獎勵初始化？答：只是選擇。如果有想編碼的知識，用它當起點是好主意（收斂更快）。這裡假設什麼都不知道。

**策略改進** 【課堂討論】[▶ 15:07](https://youtu.be/cqPbt3OfRK4?t=907)：講者問完成策略評估後下一步是什麼？學生：用這些期望值推出不同的策略。講者：對。

- 獎勵永遠是 $-1$，所以改進後的策略在每格都**指向值最高的鄰居** [▶ 16:08](https://youtu.be/cqPbt3OfRK4?t=968)。
- 不一定要評估到收斂才改進。這題很簡單，提早停也會得到最佳策略；但一般**不保證**。例如只評估一步就改進，策略只比隨機稍微好一點。

> 這個 4×4 格子世界是 Sutton & Barto 教科書的經典例子（Example 4.1），講者沒說出處。

【Q&A】[▶ 17:43](https://youtu.be/cqPbt3OfRK4?t=1063) 學生問：策略不再變就代表收斂了嗎？會不會值函數還在變、之後策略又變？答：在可以列舉所有狀態（和狀態-動作）的**表格**情況，策略迭代**證明會收斂**，跑夠久就會到最佳值函數和策略。停止條件有很多種（例如看兩輪之間變化多大），沒有唯一最好的規則。

【課本補充】課本 Example 18.2.1 給了格子世界策略迭代的程式（`StanfordASL/pora-exercises`）。

### 2.3 精確方法的限制

[▶ 18:44](https://youtu.be/cqPbt3OfRK4?t=1124)

| 限制 | 解法 |
|---|---|
| 1. 更新式需要**動態** $p$ | 用**取樣**近似（今天） |
| 2. 要遍歷、儲存所有狀態和動作的值 → 大狀態-動作空間時記憶體爆炸、收斂很慢 | **函數近似**（下週起） |

## 3. 蒙地卡羅學習

### 3.1 想法：用回報的平均估期望

[▶ 20:19](https://youtu.be/cqPbt3OfRK4?t=1219) 想估值函數，但用**樣本**。

- **樣本**＝跟環境互動得到的**展開**（rollout）：讓策略在環境裡跑，收集狀態和控制的序列直到終止。
- 原本想要的：$V^\pi(x_1)$ ＝ 如果能模擬**無限多**個情境時的期望未來獎勵。以前用動態算；現在不行。

**回報**（return）[▶ 22:03](https://youtu.be/cqPbt3OfRK4?t=1323)：從時刻 $t$ 起的折扣獎勵總和

$$G_t=\sum_{k=0}^{T-t-1}\gamma^kr_{t+k}$$

**值函數 = 回報的期望** [▶ 24:23](https://youtu.be/cqPbt3OfRK4?t=1463)：

$$V^\pi(x)=\mathbb E_\pi\left[G_t\mid x_t=x\right]$$

**蒙地卡羅**（Monte Carlo，MC）：不精確計算期望，而是收集多條軌跡，用回報的**經驗平均**估計。

- 直接從**回合經驗**學。
- **無模型**：不用轉移的知識。
- **限制** [▶ 23:52](https://youtu.be/cqPbt3OfRK4?t=1432)：只適用於**回合制**（episodic）MDP——回合一定要終止，不然回報要一直加下去。

### 3.2 首次造訪 vs 每次造訪

[▶ 25:57](https://youtu.be/cqPbt3OfRK4?t=1557)

| 變體 | 做法 |
|---|---|
| **首次造訪 MC**（first-visit） | 一個回合中**第一次**造訪 $x$ 時：計數 $N(x)\mathrel{+}=1$，總回報 $S(x)\mathrel{+}=G_t$；$V(x)=S(x)/N(x)$ |
| **每次造訪 MC**（every-visit） | 回合中每次造訪 $x$（例如繞路又回到起點）都當成獨立的一次，照樣更新 |

$N(x)\to\infty$ 時收斂到真正的期望。

【Q&A】[▶ 27:32](https://youtu.be/cqPbt3OfRK4?t=1652) 學生問：如果一直回到同一個狀態，首次造訪不就把那些資料丟掉了，好像不公平？答：在策略一直重複造訪某狀態的退化情況，確實值得考慮用哪一種。一般來說這歸結到**探索要夠**：策略要把狀態-動作空間探索得夠好，這些工具才有效。

【Q&A】[▶ 28:32](https://youtu.be/cqPbt3OfRK4?t=1712) 學生問：實務上如果不能在模擬器跑，很難收集這麼多資料吧？答：「無模型」指的是**計算中不用已知的動態模型**。可以間接用——跟模擬器互動。例：在駕駛模擬器裡用這些工具估值函數，但不使用模擬器背後可能極複雜的模型。

> ⚠️ 逐字稿缺字 [▶ 30:07](https://youtu.be/cqPbt3OfRK4?t=1807)：字幕寫「model **3**」，應為 model-free。

### 3.3 例子：21 點

[▶ 30:37](https://youtu.be/cqPbt3OfRK4?t=1837)

| 元素 | 定義 |
|---|---|
| 狀態 | 手上兩張牌的**和**（12–21）；莊家**亮出的那張**（A–10）；手上有沒有**可用的 A**（usable ace） |
| 動作 | **停牌**（stand，回合結束）／**要牌**（hit，再拿一張，不放回） |
| 獎勵 | 停牌時：贏莊家 +1、平手 0、輸 −1；要牌時：爆掉（超過 21）−1 並結束，否則 0 |
| 假設 | 和小於 12 自動要牌 |

**給定策略** [▶ 32:40](https://youtu.be/cqPbt3OfRK4?t=1960)：和 $\ge 20$ 就停，否則要牌。用 MC 評估它。

**結果** [▶ 33:10](https://youtu.be/cqPbt3OfRK4?t=1990)：跑 10,000 和 500,000 回合，畫出值函數的三維曲面（軸：莊家亮牌、玩家點數；分成有／沒有可用 A）。

- 10,000 回合的估計**雜訊較多**；500,000 回合較平滑——用經驗平均近似期望，回合越多越接近真值。

【課堂討論】[▶ 34:45](https://youtu.be/cqPbt3OfRK4?t=2085)：

- 為什麼最後兩列（玩家 20、21）值突然跳高？學生：策略只在 20、21 停牌，其他都要牌、多半會爆；但如果真的到 20、21，很可能會贏。講者：完全正確。
- 為什麼最左邊一整列值都掉下來？學生：莊家亮 A，有很大機會湊到 21。講者：對，有 A 本身就是好手牌，平均來說莊家處境很好。

【口頭】[▶ 36:19](https://youtu.be/cqPbt3OfRK4?t=2179) 重點：完全沒有給遊戲規則或動態的資訊，只靠模擬（互動）就得到每個可能狀態的完整值函數表示——精確刻畫了這個策略在各狀態的效果，而且大致**可解釋**、合理。

> 這是 Sutton & Barto 教科書的經典例子（Example 5.1），講者沒說出處。

### 3.4 增量平均

[▶ 36:50](https://youtu.be/cqPbt3OfRK4?t=2210) 回合是一個一個來的，不必每次從頭重算平均、也不用存所有回報。**增量平均**：

$$\mu_k=\mu_{k-1}+\frac1k\left(x_k-\mu_{k-1}\right)$$

套到值函數 [▶ 37:54](https://youtu.be/cqPbt3OfRK4?t=2274)：

$$V(x_t)\leftarrow V(x_t)+\frac{1}{N(x_t)}\left(G_t-V(x_t)\right)$$

實務上常寫成類似梯度下降的形式，用可變的步長 $\alpha$：

$$\boxed{V(x_t)\leftarrow V(x_t)+\alpha\left(G_t-V(x_t)\right)}$$

## 4. 時間差分學習

### 4.1 TD 更新

[▶ 39:00](https://youtu.be/cqPbt3OfRK4?t=2340) **時間差分學習**（temporal-difference learning，TD）是 MC 和 DP 的結合：

| | 像 MC | 像 DP |
|---|---|---|
| 無模型、從經驗學 | ✓ | — |
| **自舉**（bootstrap）：部分根據其他學到的估計更新，不等最後結果——「用猜測更新猜測」 | — | ✓ |

**想法** [▶ 40:39](https://youtu.be/cqPbt3OfRK4?t=2439)：DP 有遞迴 $V(x_t)=\mathbb E[r_t+\gamma V(x_{t+1})]$；TD 不能精確算期望，就用**樣本**近似：

- MC：用**整條**軌跡直接估回報。
- TD：只看**一步**：往「立即獎勵 + 下一狀態的折扣估值」的方向更新。

$$\text{MC：}\ V(x_t)\leftarrow V(x_t)+\alpha\left(G_t-V(x_t)\right)$$

$$\text{TD(0)：}\ V(x_t)\leftarrow V(x_t)+\alpha\left(\underbrace{r_t+\gamma V(x_{t+1})}_{\text{TD 目標}}-V(x_t)\right)$$

- **TD 目標**（TD target）：$r_t+\gamma V(x_{t+1})$。
- **TD 誤差**（TD error）：$\delta_t=r_t+\gamma V(x_{t+1})-V(x_t)$。

TD 結合 MC 的**取樣**（只靠互動估值）和 DP 的**自舉**（用猜測更新猜測）。

【Q&A】[▶ 43:14](https://youtu.be/cqPbt3OfRK4?t=2594) 學生問：$G_t$ 是不是每次更新都要跑一堆展開才知道真正回報？答：跟跑幾次無關。$G_t$ 就是回報的定義（未來獎勵總和）；一條軌跡給一個 $G_t$ 樣本，是期望的單樣本估計。TD 不看最終回報，而看回報的**一步估計**（$r_1$ + 對之後的猜測），是避免跑完整個回合的機制。

【Q&A】[▶ 45:16](https://youtu.be/cqPbt3OfRK4?t=2716) 學生問互動方式有沒有不同？答：互動都一樣是完整展開；差別在**怎麼更新**估值。MC 一個回合更新一次（只有一個回報）；TD 可以更頻繁，甚至回合**還沒結束**就更新。

### 4.2 MC vs TD：何時能學

[▶ 45:47](https://youtu.be/cqPbt3OfRK4?t=2747)

| | MC | TD |
|---|---|---|
| 要等什麼 | 回合**結束**才能拿到回報 | 每一步之後就能學（線上） |
| 不完整序列 | 不能 | 能 |
| 不會終止的環境 | 不能（需要回合制） | **能** |

【口頭】[▶ 47:25](https://youtu.be/cqPbt3OfRK4?t=2845) MC 和 TD 是估計目標量（多半是值）的基本機制，所有其他 RL 演算法（基於值、策略最佳化、actor-critic……）都建立在它們之上：不知道轉移時，只能靠互動和類似 MC、TD 的工具估值函數。

【Q&A】[▶ 47:55](https://youtu.be/cqPbt3OfRK4?t=2875) 學生問：TD 不從終點往回推，那估計最終要錨定在什麼真實值上？答：直覺對。這就是**折扣因子**的角色：在極端情況下（第 500,000 步），未來的值會非常接近 0，所以估計不會爆到無限大。

### 4.3 偏差與變異數

[▶ 49:30](https://youtu.be/cqPbt3OfRK4?t=2970) 兩者都是「期望未來獎勵」的**估計量**。

**偏差** [▶ 50:01](https://youtu.be/cqPbt3OfRK4?t=3001)：

| 估計量 | 偏差 |
|---|---|
| 回報 $G_t$ | **無偏**：它是期望的一個樣本，無限多回合會收斂到真值 |
| 「真」TD 目標 $r_t+\gamma V^\pi(x_{t+1})$ | 無偏——但前提是**已經知道**真正的值函數 |
| 實際 TD 目標 $r_t+\gamma\hat V(x_{t+1})$ | **有偏**：學習時用的是估計 $\hat V$，不精確 |

**變異數** [▶ 52:14](https://youtu.be/cqPbt3OfRK4?t=3134)：

- $G_t$ 依賴一**整串**隨機的動作、轉移、獎勵 → **高變異數**（要考慮的可能未來多太多）。
- TD 目標只依賴**一步**的隨機性 → **低變異數**。

| | 偏差 | 變異數 |
|---|---|---|
| MC | 無偏 | 高 |
| TD | 有偏 | 低 |

### 4.4 備份圖：統一的觀點

[▶ 54:23](https://youtu.be/cqPbt3OfRK4?t=3263) 用樹狀圖看（白點 = 狀態，黑點 = 動作，T = 終端狀態）：

| 方法 | 備份（backup）方式 |
|---|---|
| **MC** | 沿著**一條**完整回合走到終端，用觀察到的回報更新 |
| **TD** | 只看**一步**轉移，然後用估值 |
| **DP** | 用動態**精確**算期望——考慮**所有**分支，但只深一步 |

**兩個軸** [▶ 57:30](https://youtu.be/cqPbt3OfRK4?t=3450)：

| | 取樣（sampling） | 自舉（bootstrapping） |
|---|---|---|
| MC | ✓ | ✗ |
| TD | ✓ | ✓ |
| DP | ✗（用動態精確計算） | ✓ |

**光譜** [▶ 58:04](https://youtu.be/cqPbt3OfRK4?t=3484)：

```
                 淺（一步、自舉）        深（到終點）
寬（全部分支）    動態規劃                窮舉搜尋
窄（取樣）        TD 學習                 蒙地卡羅
```

這只是四個極端，中間還有很多。例：不是一步就自舉，而是累積**四步**經驗再用第四步之後的值函數——各有優缺點。

> 以下**不是逐字稿內容**：「累積 $n$ 步再自舉」一般叫 **$n$ 步 TD**；講者沒說這個名字。

【課本補充】課本 §18.3.4「A Unifying View of Reinforcement Learning」是同一個觀點。

## 5. 第一個能用的 RL 演算法

### 5.1 廣義策略迭代

[▶ 60:10](https://youtu.be/cqPbt3OfRK4?t=3610) **廣義策略迭代**（generalized policy iteration，GPI）：泛指「在策略評估和策略改進之間交替」的骨架，不管兩步具體怎麼定義。很多演算法都套用這個骨架。

策略迭代是其中一例：評估 = 反覆套 Bellman 期望方程；改進 = 貪婪。兩步都要動態。

### 5.2 為什麼要用 Q 函數

[▶ 62:13](https://youtu.be/cqPbt3OfRK4?t=3733)

**嘗試 1**：評估改用 **MC 評估 $V$**，改進保持貪婪？

- MC 評估可以（今天就做了）。
- 但貪婪改進 $\arg\max_u[R+\gamma\sum_{x'}p\,V]$ **還是要動態** → 不行。

**嘗試 2** [▶ 63:22](https://youtu.be/cqPbt3OfRK4?t=3802)：把 $V$ 換成 **$Q$**——**MC 評估 $Q$** + 貪婪改進 $\pi(x)=\arg\max_uQ(x,u)$（不需要動態）。

【課堂討論】這樣行嗎？投影片上有「劇透」——一般**不行**。

### 5.3 探索：ε-貪婪

[▶ 63:55](https://youtu.be/cqPbt3OfRK4?t=3835) 這觸及 RL 的根本挑戰：**探索 vs 利用**。

**兩扇門的例子** [▶ 64:25](https://youtu.be/cqPbt3OfRK4?t=3865)（無狀態的環境，永遠在同一個狀態）：

1. 隨機初始化 $Q$；隨機選了**左門**，獎勵 0 → $Q(\text{左})=0$。
2. 選**右門**，獎勵 1 → $Q(\text{右})=1$。
3. 現在策略是**確定性**的 $\arg\max Q$ → 永遠選右門。
4. 左門可能其實有更好的獎勵（例如第一次只是運氣差），但再也不會被試到。

**問題** [▶ 65:29](https://youtu.be/cqPbt3OfRK4?t=3929)：用樣本估狀態-動作值，就需要造訪**每個**狀態-動作對；確定性策略**不允許**這種探索。

**ε-貪婪探索**（ε-greedy）[▶ 65:59](https://youtu.be/cqPbt3OfRK4?t=3959)：

$$
u=\begin{cases}\arg\max_uQ(x,u) & \text{機率 }1-\varepsilon\\ \text{隨機動作} & \text{機率 }\varepsilon\end{cases}
$$

很簡單，但保證**每個動作都以非零機率被嘗試** → 長期下來能涵蓋整個狀態-動作空間。

**第一個能用的 RL 演算法** [▶ 67:04](https://youtu.be/cqPbt3OfRK4?t=4024)：**MC 評估 $Q$** + **ε-貪婪策略改進**。

### 5.4 例子：21 點的最佳策略

[▶ 67:34](https://youtu.be/cqPbt3OfRK4?t=4054) 之前是評估給定策略；現在解**完整**問題：推出最佳策略。

照上面的演算法跑，會收斂到一個明確的規則：依有無可用 A、手上點數、莊家亮牌，決定停牌或要牌。

- 直覺：沒有可用 A 時策略**比較保守**。
- 【口頭】「我絕對不建議你真的去賭場試這個策略，誰知道呢。」
- 重點：完全沒給環境怎麼行動的提示，只靠互動就推出最佳策略和它的值函數。

【課本補充】課本 §18.3.3「Example: Monte Carlo Control」是對應的內容。

**回顧** [▶ 69:07](https://youtu.be/cqPbt3OfRK4?t=4147)：精確方法（策略迭代、值迭代）在 Bellman 更新和貪婪改進中都隱含地用了轉移動態；今天用 MC 和 TD 透過**互動**解決。高維狀態-動作空間（函數近似）之後講。

## 6. RL 演算法的共同骨架

[▶ 70:42](https://youtu.be/cqPbt3OfRK4?t=4242) 之後的順序：基於值的方法 → 策略最佳化 → 基於模型的方法。（下週一放假。）

【口頭】把所有演算法看成同一個骨架的不同實例，很有價值。三個過程：

```
     ┌────────────────────────┐
     │ 1. 產生樣本             │  跟環境互動，收集軌跡 τ
     └──────────┬─────────────┘
                ↓
     ┌────────────────────────┐
     │ 2. 擬合模型 / 估計回報   │  估值函數、Q 函數；或擬合動態模型（基於模型 RL）
     └──────────┬─────────────┘
                ↓
     ┌────────────────────────┐
     │ 3. 改進策略             │  ε-貪婪／貪婪（今天）；或對策略參數 θ 做梯度步（策略最佳化）
     └──────────┬─────────────┘
                └──────→ 回到 1
```

> ⚠️ 逐字稿缺字 [▶ 72:19](https://youtu.be/cqPbt3OfRK4?t=4339)：字幕寫「estimate a learned model of our dynamics in **model free** RL」，依上下文應為 **model-based** RL。

## 7. 演算法整理

### 策略迭代（精確，需要動態）

```
初始化 π（例如隨機）、V ← 0
重複：
    評估：重複 V(x) ← Σ_u π(u|x)[R(x,u) + γ Σ_x' p(x'|x,u) V(x')] 直到收斂
    改進：π(x) ← argmax_u [R(x,u) + γ Σ_x' p(x'|x,u) V(x')]
    策略不變 → 停
```

**什麼時候會失敗**：不知道 $p$；狀態-動作太多，存不下、跑不完。

### MC 策略評估

```
對每個回合（照 π 跑到終止）：
    倒著算每一步的回報 G_t
    對（首次或每次）造訪的 x_t：V(x_t) ← V(x_t) + α (G_t − V(x_t))
```

**什麼時候會失敗**：回合不會終止；回報變異數高 → 需要很多回合（例：10,000 回合雜訊多）。

### TD(0) 策略評估

```
每一步：觀察 (x_t, u_t, r_t, x_{t+1})
    V(x_t) ← V(x_t) + α (r_t + γ V(x_{t+1}) − V(x_t))
```

**什麼時候會失敗**：$\hat V$ 不準時目標有偏。

### MC 控制（ε-貪婪）

```
初始化 Q
重複：
    用 ε-貪婪（相對於 Q）跑一個回合
    對造訪的 (x_t, u_t)：Q(x_t,u_t) ← Q(x_t,u_t) + α (G_t − Q(x_t,u_t))
```

**什麼時候會失敗**：$\varepsilon=0$（純貪婪）→ 不探索、卡在次佳（兩扇門）；需要回合制。

## 8. 一頁速查表

### 精確 vs 無模型

| | 需要 $p$ | 取樣 | 自舉 |
|---|---|---|---|
| DP（策略／值迭代） | ✓ | ✗ | ✓ |
| MC | ✗ | ✓ | ✗ |
| TD | ✗ | ✓ | ✓ |

### 更新式

| 方法 | 更新 |
|---|---|
| 增量平均 | $\mu_k=\mu_{k-1}+\frac1k(x_k-\mu_{k-1})$ |
| MC | $V(x_t)\leftarrow V(x_t)+\alpha\left(G_t-V(x_t)\right)$，$G_t=\sum_k\gamma^kr_{t+k}$ |
| TD(0) | $V(x_t)\leftarrow V(x_t)+\alpha\left(r_t+\gamma V(x_{t+1})-V(x_t)\right)$ |
| TD 目標／誤差 | $r_t+\gamma V(x_{t+1})$ ／ $\delta_t=r_t+\gamma V(x_{t+1})-V(x_t)$ |

### MC vs TD

| | MC | TD |
|---|---|---|
| 偏差 | 無偏 | 有偏（用 $\hat V$） |
| 變異數 | 高（整串隨機） | 低（一步隨機） |
| 需要回合結束 | ✓ | ✗（線上、可處理不終止環境） |

### 控制

- 用 $V$ 做貪婪改進需要 $p$；用 $Q$ 不需要：$\pi(x)=\arg\max_uQ(x,u)$。
- 純貪婪不探索 → ε-貪婪：機率 $1-\varepsilon$ 選 argmax、$\varepsilon$ 隨機。
- 第一個 RL 演算法：MC 評估 $Q$ + ε-貪婪改進（GPI 骨架）。

### RL 骨架

產生樣本 → 估值／擬合模型 → 改進策略 → 重複。

## 附：本集一句話總結

> **策略迭代、值迭代是「精確」方法，因為評估和改進都用到已知的轉移動態。RL 把動態換成互動樣本：蒙地卡羅用完整回合的回報 $G_t$ 平均估值（無偏、高變異、要等回合結束），時間差分用一步的 $r_t+\gamma V(x_{t+1})$ 自舉（有偏、低變異、可線上學）；兩者和 DP 可用「取樣／自舉」或「備份寬度／深度」統一看待。改用 Q 函數就能不靠動態做貪婪改進，再加上 ε-貪婪保證探索，就得到第一個能用的 RL 演算法。**
