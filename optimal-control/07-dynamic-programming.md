## 1. 回顧開迴路，轉向閉迴路

[▶ 00:35](https://youtu.be/hy-e9g4nugE?t=35) 前面都在課程地圖的**左邊**：開迴路，算一串以時間為參數的控制。

- **間接法**：推必要條件（梯度 = 0 的無限維推廣）→ 兩點邊界值問題。歷史上最早。
- **直接法**：離散化 → 非線性最佳化。現在機器人比較常用，因為演算法和硬體進步，能在邊緣裝置上即時解（60、70 年代做不到）。

【口頭】[▶ 02:42](https://youtu.be/hy-e9g4nugE?t=162) 間接法還是有用：有時能給**封閉解**（closed-form），那是「皇冠上的寶石」，實作時間為 0。兩種方法也可以混合，本課不深入。

**今天轉到右邊：閉迴路** [▶ 03:13](https://youtu.be/hy-e9g4nugE?t=193)

問題**不變**，變的是**最佳化的對象**：

$$u^*=\pi^*\left(x(t),t\right)\quad\text{對所有可能達到的狀態 }x(t)$$

**為什麼要閉迴路** [▶ 04:20](https://youtu.be/hy-e9g4nugE?t=260)：

- 如果系統剛好沿著標稱軌跡走，閉迴路策略和開迴路序列的行為**完全一樣**。
- 但基本的問題敘述沒有考慮**擾動**和**模型誤差**。實際部署時，真實系統跟設計用的模型不一樣。
- 閉迴路策略比較**強健**：一偏離標稱軌跡，你知道怎麼做。開迴路只會盲目套用時間 $t$ 預先算好的控制。

【Q&A】[▶ 05:55](https://youtu.be/hy-e9g4nugE?t=355) 學生問 $x$ 是什麼？答：就是狀態，你在世界中的任何狀態。$u(t)$ 是「剛好在標稱軌跡上時」的正確動作；一離開它，就沒有保證那還是最佳的。

【課本補充】課本 §17.1 旁註 2：在**確定性**設定下，系統演化完全可預測，閉迴路和開迴路最佳解其實**一樣**；閉迴路的真正好處主要出現在**隨機**設定（下一集的內容）。

**計畫** [▶ 06:27](https://youtu.be/hy-e9g4nugE?t=387)：

| 方法 | 能力 | 計算 |
|---|---|---|
| 動態規劃（今天） | 閉迴路，強 | **很貴** |
| 開迴路（前幾週） | 弱 | 便宜 |
| MPC（幾週後） | 兩者兼得：閉迴路的思路，開迴路的計算量 | |

今天先推**離散時間**版本；下週推廣到連續時間。

## 2. 離散時間最佳控制問題

[▶ 08:07](https://youtu.be/hy-e9g4nugE?t=487) 跟第 1 集一樣，只是時間離散化。時刻 $t_k$ 也叫**階段**（stage）$k$（例如 $k=0,1,2$ 對應 $t=0,0.1,0.2$）。

**動態**：差分方程

$$x_{k+1}=f(x_k,u_k,k)$$

可以由連續時間離散化得到（例如 Euler：$x(t+\Delta t)=x(t)+\Delta t\,f(x,u,t)$ [▶ 09:38](https://youtu.be/hy-e9g4nugE?t=578)），也可以本來就是自然的離散模型。

**控制約束** [▶ 10:42](https://youtu.be/hy-e9g4nugE?t=642)：$u_k\in U(x_k)$。控制集合可以**依狀態而變**。

**成本**（加法形式）[▶ 11:15](https://youtu.be/hy-e9g4nugE?t=675)：

$$J=h_N(x_N)+\sum_{k=0}^{N-1}g_k(x_k,u_k)$$

- $g_k$：在階段 $k$、狀態 $x_k$、用控制 $u_k$ 付的成本（燃料，或你對處在 $x_k$ 有多不開心）。
- $h_N$：終端成本，$N$ 步後在 $x_N$ 有多不開心。

**目標** [▶ 12:17](https://youtu.be/hy-e9g4nugE?t=737)：找**閉迴路策略**

$$u_k^*=\pi_k^*(x_k)$$

以前開迴路找的是一串數 $u_0^*,u_1^*,\dots$；現在找的是**狀態的函數**。

【口頭】看起來只是術語不同，其實影響很深。

## 3. 最佳性原理

[▶ 13:20](https://youtu.be/hy-e9g4nugE?t=800) 破解這個問題的關鍵是它的**結構**：**最佳性原理**（principle of optimality）。它是**成本是加法形式**的結果。如果換成別的（例如「總和的 tan」），就不成立了。

【口頭】這顯示我們的問題敘述是好的折衷：夠一般，又有足夠結構讓我們推出可用的演算法。

【口頭】[▶ 14:23](https://youtu.be/hy-e9g4nugE?t=863) 「第一次聽覺得很明顯；想多一點會有點困惑；再過一陣子又覺得很明顯了。」

### 3.1 敘述與反證

[▶ 14:53](https://youtu.be/hy-e9g4nugE?t=893) **白話**：多步最佳控制問題的最佳策略，其**尾段**對截斷後的問題也是最佳的。

**圖** [▶ 15:27](https://youtu.be/hy-e9g4nugE?t=927)：要從 $a$ 到 $e$。最佳路徑先到 $b$，再沿某條路到 $e$。

- $J_{ab}$：$a\to b$ 那段的成本；$J_{be}$：$b\to e$ 那段的成本。
- 【課堂討論】[▶ 17:45](https://youtu.be/hy-e9g4nugE?t=1065) 老師問總成本是多少？學生：$J^*_{ae}=J_{ab}+J_{be}$。老師：對，因為成本是**加法**的。

**主張**：如果 $a\to b\to e$ 是從 $a$ 到 $e$ 的最佳路徑，那麼尾段 $b\to e$ 對「從 $b$ 出發」的問題也是最佳的。

**反證** [▶ 19:22](https://youtu.be/hy-e9g4nugE?t=1162)：

1. 假設不是：從 $b$ 出發有更好的路，例如先到 $c$ 再到 $e$，$J_{bce}<J_{be}$。
2. 那 $a\to b\to c\to e$ 的成本 $J_{ab}+J_{bce}<J_{ab}+J_{be}$。
3. 找到比「最佳路徑」更好的路 → 矛盾。∎

**正式敘述** [▶ 22:33](https://youtu.be/hy-e9g4nugE?t=1353)：

> 設 $u_0^*,\dots,u_{N-1}^*$ 是最佳控制序列，和 $x_0^*$ 一起決定狀態序列 $x_0^*,\dots,x_N^*$。考慮子問題：在時間 $k$ 從 $x_k^*$ 出發，最小化
> $$h_N(x_N)+\sum_{i=k}^{N-1}g_i(x_i,u_i)$$
> 那麼截斷序列 $u_k^*,\dots,u_{N-1}^*$ 對這個子問題是最佳的。

**好記版**：**最佳序列的尾段，對尾部子問題是最佳的。**

【課本補充】課本 Theorem 17.1.2 是同樣的敘述（記號用 $T$、$g_T$）。

【Q&A】[▶ 22:02](https://youtu.be/hy-e9g4nugE?t=1322) 學生問：只有尾段嗎？還是任何子段？答：目前就說尾段。

【Q&A】[▶ 23:36](https://youtu.be/hy-e9g4nugE?t=1416) 學生問這是不是類似三角不等式或 Jensen 不等式？答：比那更基本，只來自成本的**加法**假設。而且條件很弱——不管最佳化在多奇怪的空間上，只要成本是加法就成立。所以這個性質非常一般。

【Q&A】[▶ 53:35](https://youtu.be/hy-e9g4nugE?t=3215) 學生問：如果是全域最小，任何子路徑不也都是最短的嗎？答：對，每條尾路徑都是最佳的——這就是最佳性原理。

### 3.2 為什麼有用：重用計算

[▶ 24:41](https://youtu.be/hy-e9g4nugE?t=1481) 想像一個「神諭」已經告訴你：從 $c$、$d$、$e$ 到 $f$ 的**最佳**路徑和成本 $J^*_{cf}$、$J^*_{df}$、$J^*_{ef}$（背後可能用了 324 個控制輸入，算了很久）。

期中考三分鐘內：從 $b$ 到 $f$ 的最佳路徑？從 $b$ 只能直接到 $c$、$d$、$e$，成本 $J_{bc}$、$J_{bd}$、$J_{be}$。

- **不知道最佳性原理**：每個選項都要把尾段的所有控制組合重算一遍。
- **知道最佳性原理** [▶ 26:15](https://youtu.be/hy-e9g4nugE?t=1575)：如果 $b\to c$ 是最佳路徑的開頭，尾段 $c\to f$ 一定就是那條最佳尾路。不用再搜尋尾段。只要比較三個選項：
$$J^*_{bf}=\min\left\{J_{bc}+J^*_{cf},\ J_{bd}+J^*_{df},\ J_{be}+J^*_{ef}\right\}$$

【課本補充】課本 Example 17.1.1 列出暴力法要比較的 9 條路徑（$b\to c\to f$、$b\to c\to d\to f$……），用最佳性原理只要比較 3 個。

【Q&A】[▶ 27:53](https://youtu.be/hy-e9g4nugE?t=1673) 學生問三條尾段的成本一樣嗎？答：不一定，通常不同。只是各自對各自的子問題是最佳的。

【Q&A】[▶ 28:26](https://youtu.be/hy-e9g4nugE?t=1706) 學生問：如果決定先去 $c$，接著走 $c\to f$ 不是很明顯嗎？答：如果已經決定去 $c$，是很明顯——但那正是因為剛學了最佳性原理。**不明顯**的是：從 $b$ 出發，三個選項選哪個。老師說最佳性原理「明顯到大家常常低估它的深度」。

**重點** [▶ 30:29](https://youtu.be/hy-e9g4nugE?t=1829)：比較「眼前的決策 + 尾部最佳解」的串接，就能把問題延長一步。

## 4. 動態規劃演算法

[▶ 30:59](https://youtu.be/hy-e9g4nugE?t=1859) 誰幫你解尾部問題？沒有神諭。動態規劃的「不直觀」想法：**倒著時間解**。

- 策略部署時是往前走的；問題是**往回解**的。
- 從**終點**開始：在終點，最佳解很明顯（什麼都不用做），成本就是終端成本。
- 然後一次退一步，把眼前成本和尾部解串起來。

### 4.1 例子：最短路徑手算

[▶ 32:32](https://youtu.be/hy-e9g4nugE?t=1952) 從 $a$ 到 $h$，箭頭表示允許的移動和成本。

> 圖在投影片上。以下各邊成本是依老師口述的計算重建：$a\to b$：5，$a\to d$：8，$b\to c$：9，$c\to d$：5，$c\to f$：3，$d\to e$：3，$e\to h$：8，$e\to f$：2，$f\to g$：3，$g\to h$：2。
>
> 【課本補充】課本 Example 17.1.2（Grid Navigation，書頁 443）是同一張圖（改編自 Kirk 第 3 章），答案同為 $a\to d\to e\to f\to g\to h$；課本列出的 $e\to h$=8、$g\to h$=2、$d\to e$=3、$f\to g$=3 和上面一致。課本的寫法是「從 $h$ 起每多一步往回推一層」，並允許到 $h$ 後以 0 成本停留。

**從後往前** [▶ 34:13](https://youtu.be/hy-e9g4nugE?t=2053)（$J(\cdot)$ = 到 $h$ 的最佳成本，也叫**剩餘成本** cost-to-go）：

| 節點 | 計算 | $J$ | 選擇 |
|---|---|---|---|
| $h$ | 已經在終點 | 0 | — |
| $g$ | $2+J(h)$ | 2 | $\to h$ |
| $f$ | $3+J(g)$ | 5 | $\to g$ |
| $e$ | $\min\{8+J(h),\ 2+J(f)\}=\min\{8,7\}$ | 7 | $\to f$ |
| $d$ | $3+J(e)$ | 10 | $\to e$ |
| $c$ | $\min\{3+J(f),\ 5+J(d)\}=\min\{8,15\}$ | 8 | $\to f$ |
| $b$ | $9+J(c)$ | 17 | $\to c$ |
| $a$ | $\min\{8+J(d),\ 5+J(b)\}=\min\{18,22\}$ | **18** | $\to d$ |

【課堂討論】[▶ 34:13](https://youtu.be/hy-e9g4nugE?t=2053) 老師問從 $h$ 到 $h$ 成本多少？學生：0。

**回溯** [▶ 39:07](https://youtu.be/hy-e9g4nugE?t=2347)：$a\to d\to e\to f\to g\to h$，成本 18。

【口頭】重點是：算 $J(e)$ 時**不用重算** $J(f)$，直接拿來用。

【Q&A】[▶ 39:38](https://youtu.be/hy-e9g4nugE?t=2378) 學生問：怎麼知道處理節點的順序？答：要先把問題寫成標準形式——定義狀態和階段。最短路徑可以這樣寫：階段 $k$ = 到目的地的**步數**（hop 數）。先最佳化一步到終點的路徑，再兩步，以此類推。老師說會把參考資料放上 Canvas（也可能有作業）。這正是 DP 棘手的地方。

### 4.2 DP 遞迴

[▶ 40:41](https://youtu.be/hy-e9g4nugE?t=2441) 問題寫成標準形式後（離散動態、加法成本），演算法**概念上很簡單**：

> **動態規劃演算法**
>
> 邊界條件：
> $$J_N^*(x_N)=h_N(x_N)\qquad\text{對所有 }x_N$$
> 從 $k=N-1$ 倒推到 $k=0$，對每個 $x_k$：
> $$J_k^*(x_k)=\min_{u_k\in U(x_k)}\left[g_k(x_k,u_k)+J_{k+1}^*\left(f(x_k,u_k,k)\right)\right]$$
> 最佳策略 $\pi_k^*(x_k)$ = 達到上面最小值的 $u_k$。

每一步：對給定的 $x_k$，找**眼前成本**和**剩餘成本**之間的最佳折衷。

**建立策略** [▶ 47:21](https://youtu.be/hy-e9g4nugE?t=2841)：對每個狀態記下最佳控制，就一步步建出 $\pi$。

【口頭】[▶ 47:52](https://youtu.be/hy-e9g4nugE?t=2872) 這是控制最基本的結果之一：離散時間閉迴路最佳控制、連續時間閉迴路最佳控制、學習型控制、策略學習的基礎。現在大家講的策略學習、視覺語言動作模型（VLA）……都根植在這個方程（加上很多推廣）。

**直覺：為什麼你在教室不在海灘** [▶ 48:23](https://youtu.be/hy-e9g4nugE?t=2903)

【口頭】最佳的動作 = 最小化「對眼前成本的影響」+「今天的決定對明天之後的影響」。去海灘游泳降低你現在的成本，但影響你未來的教育（剩餘成本）。你在這裡，是犧牲眼前的享受去最佳化未來。DP 用數學原則做這個取捨。

**不直觀之處：倒著解** [▶ 54:05](https://youtu.be/hy-e9g4nugE?t=3245)

【口頭】老師引用一位（比 Bellman 更早的）哲學家：「人生要往前活，但只能往回理解。」有時你回頭看才明白，四年前的決定把你帶到了這裡。

> 這句話一般認為出自丹麥哲學家齊克果（Kierkegaard），老師沒說出名字，待確認。

【Q&A】[▶ 49:54](https://youtu.be/hy-e9g4nugE?t=2994) 學生問：如果終點離起點很遠，倒著解怎麼會走到起點？答：DP 其實解了**所有**初始條件的問題。你再告訴我你關心的初始條件，就查出那個的策略。最後一步可以只對 $x_0$ 做；但中間每一步都要對**所有可達狀態**解尾部問題，因為不知道會經過哪些中間狀態。有點浪費，但比暴力法省很多；而且初始條件改變時，答案已經都有了。

【Q&A】[▶ 55:52](https://youtu.be/hy-e9g4nugE?t=3352) 學生問：DP 哪裡讓它是閉迴路？答：它解了**從所有可能狀態出發的所有尾部問題**，等於對每個狀態都算出最佳控制——這正是閉迴路控制的定義。心態上跟以前很不同。

【口頭】[▶ 55:21](https://youtu.be/hy-e9g4nugE?t=3321) 期末考**很可能**要你手算一步 DP 遞迴（五分鐘的題目），要確定你內化了一步 DP 在做什麼。

### 4.3 維度詛咒

[▶ 41:42](https://youtu.be/hy-e9g4nugE?t=2502) 兩個難處：

1. **建模**：很多問題乍看跟這個形式完全不同（例如 DNA 定序），要聰明地把它們寫成標準形式。
2. **計算** [▶ 43:14](https://youtu.be/hy-e9g4nugE?t=2594)：每一步、**每個狀態**都要解一次最小化。時間離散了，但狀態不一定——連續的話有無限多個。

**數一數** [▶ 44:16](https://youtu.be/hy-e9g4nugE?t=2656)（時間 $[0,1]$ 每 0.1 一格 = 10 步；狀態每維 $[0,1]$ 每 0.1 一格 = 10 格）：

| 狀態維度 $d$ | 每步狀態數 | 總最小化次數 |
|---|---|---|
| 1 | 10 | $10\times 10=100$ |
| 2（例如位置＋速度） | 100 | $10\times 100$ |
| 3 | 1000 | $10\times 1000$ |
| $d$ | $10^d$ | $10\times 10^d$ |

【課堂討論】[▶ 45:18](https://youtu.be/hy-e9g4nugE?t=2718) 老師問二維時每步有幾種狀態組合？學生：100。

計算量隨狀態維度**指數成長**，這叫**維度詛咒**（curse of dimensionality）。DP 比暴力法省非常多，但高維狀態空間還是要算很多。

解法：**近似動態規劃**（approximate dynamic programming）→ 通往課程後半的學習型控制。

### 4.4 DP 的性質

[▶ 52:29](https://youtu.be/hy-e9g4nugE?t=3149)

- 要先把微分方程離散成差分方程；連續狀態要**量化**。
- 每一步遞迴找的是**全域**最小 → 得到**全域最佳解**。
- **約束反而讓問題變簡單** [▶ 53:02](https://youtu.be/hy-e9g4nugE?t=3182)：直接法裡約束讓最佳化變難；DP 裡約束**減少**要考慮的動作。
- 給出**閉迴路**解。
- 受**維度詛咒**影響。

### 4.5 DP 整理：在解什麼／步驟／什麼時候會失敗

**在解什麼**：離散時間、加法成本的最佳控制問題；要的是閉迴路策略 $\pi_k^*(x_k)$（對所有狀態）。

**步驟**：

```
1. 把問題寫成標準形式：狀態 x_k、階段 k、動態 x_{k+1}=f(x_k,u_k)、加法成本
2. 連續狀態 → 量化成格點
3. 對所有 x_N：J_N(x_N) ← h_N(x_N)
4. for k = N−1, …, 0：
       for 每個格點 x_k：
           J_k(x_k) ← min_{u∈U(x_k)} [ g_k(x_k,u) + J_{k+1}(f(x_k,u)) ]
           π_k(x_k) ← 達到最小的 u
5. 部署時往前走：u_k = π_k(x_k)
```

**什麼時候會失敗**：

| 情況 | 會怎樣 | 來源 |
|---|---|---|
| 狀態維度高 | 格點數 $10^d$，算不完（維度詛咒） | 4.3 |
| 成本不是加法 | 最佳性原理不成立，DP 不能用 | 第 3 節 |
| 問題不容易寫成標準形式 | 要聰明建模（狀態、階段怎麼定義） | 4.1、4.3 |
| 連續狀態量化 | $f(x_k,u)$ 不一定落在格點上（要內插，待後續集數） | 推論 |

## 5. 線性二次調節器（LQR）

### 5.1 問題

[▶ 56:53](https://youtu.be/hy-e9g4nugE?t=3413) 簡單但非常基礎。

$$
\begin{aligned}
x_{k+1}&=A_kx_k+B_ku_k \\
J&=\frac12x_N^\top Hx_N+\frac12\sum_{k=0}^{N-1}\left(x_k^\top Q_kx_k+u_k^\top R_ku_k\right)
\end{aligned}
$$

- $A$：**狀態矩陣**；$B$：**輸入矩陣**。都是給定的數字矩陣，不依賴狀態或控制。
- $u^\top Ru$：對用控制 $u$ 有多不開心（能量）。$x^\top Qx$：對處在狀態 $x$ 有多不開心。
- 目標：到**原點**（$x=0$ 不付成本），同時用最少能量。

**取捨** [▶ 58:26](https://youtu.be/hy-e9g4nugE?t=3506)：$u$ 大 → 較快到原點，但力氣大；$u$ 小 → 省力，但很多步都離原點遠，不開心很久。

叫**調節器**（regulator）是因為它建模「用最小成本到原點」。

**條件** [▶ 58:59](https://youtu.be/hy-e9g4nugE?t=3539)：$H,Q\succeq 0$（半正定），讓這些項非負；$R\succ 0$（**正定**，後面會用到）。

**為什麼重要** [▶ 59:33](https://youtu.be/hy-e9g4nugE?t=3573)：

- 看起來「誰在乎到原點」，但它能直接用在**軌跡追蹤**（週三講），也能透過**反覆線性化**解非線性最佳化問題。
- 【口頭】就算是最複雜的端到端自駕模型（VLA、世界模型、基礎模型），軌跡追蹤演算法很可能還是 LQR 衍生的。
- 也是示範 DP 的好例子：離散動態 + 加法成本，正好能用 DP。

【課本補充】課本 §3.2.1 Discrete-time LQR 的寫法沒有 $\frac12$，終端權重記 $Q_f$，控制律寫成 $u_t=-K_tx_t$。

### 5.2 用 DP 解：退一步

[▶ 61:06](https://youtu.be/hy-e9g4nugE?t=3666) **邊界條件**：

$$J_N^*(x_N)=\frac12x_N^\top Hx_N\equiv\frac12x_N^\top P_Nx_N,\qquad P_N:=H$$

**退到 $N-1$** [▶ 61:37](https://youtu.be/hy-e9g4nugE?t=3697)：不知道最佳軌跡會經過哪個 $x_{N-1}$，所以對**所有**可達的 $x_{N-1}$ 都要解：

$$J_{N-1}^*(x_{N-1})=\min_{u_{N-1}}\ \frac12\left[x_{N-1}^\top Qx_{N-1}+u_{N-1}^\top Ru_{N-1}+x_N^\top P_Nx_N\right],\quad x_N=Ax_{N-1}+Bu_{N-1}$$

（下標 $N-1$ 省略。）

代入動態後，$x_{N-1}$ 是固定的（每次遞迴針對一個特定的 $x_{N-1}$），**唯一變數是 $u_{N-1}$**——一個 $u$ 的二次函數 [▶ 63:51](https://youtu.be/hy-e9g4nugE?t=3831)。

**展開** $x_N^\top P_Nx_N$ [▶ 64:28](https://youtu.be/hy-e9g4nugE?t=3868)：

$$(Ax+Bu)^\top P_N(Ax+Bu)=\underbrace{u^\top B^\top P_NBu}_{u\text{ 的二次}}+\underbrace{x^\top A^\top P_NAx}_{\text{不含 }u}+\underbrace{u^\top B^\top P_NAx+x^\top A^\top P_NBu}_{u\text{ 的一次（交叉項）}}$$

> ⚠️ 逐字稿缺字 [▶ 64:28](https://youtu.be/hy-e9g4nugE?t=3868)：老師板書時把終端矩陣寫成 $H$（字幕「hbn minus 1」）。因為已定義 $P_N:=H$，上式統一寫成 $P_N$。

**一階條件** [▶ 66:08](https://youtu.be/hy-e9g4nugE?t=3968)：對 $u$ 微分 = 0（別忘了外面的 $\frac12$；細節老師留作練習）：

$$Ru+B^\top P_NBu+B^\top P_NAx=0$$

**二階條件** [▶ 66:44](https://youtu.be/hy-e9g4nugE?t=4004)：再微分一次得 $R+B^\top P_NB$。$R\succ 0$、$B^\top P_NB\succeq 0$ → 和**正定** → 是最小值，而且**可逆**。

**最佳控制** [▶ 67:45](https://youtu.be/hy-e9g4nugE?t=4065)：

$$u_{N-1}^*=F_{N-1}x_{N-1},\qquad F_{N-1}=-\left(R+B^\top P_NB\right)^{-1}B^\top P_NA$$

【口頭】[▶ 68:16](https://youtu.be/hy-e9g4nugE?t=4096) 有趣的地方：一堆醜醜的矩陣乘法，但都是**問題資料**，乘上狀態。所以最佳控制是**狀態的線性回饋**。跟線性控制有更深的關係。

**剩餘成本** [▶ 68:46](https://youtu.be/hy-e9g4nugE?t=4126)：把 $u=Fx$ 代回成本，得到 $x_{N-1}$ 的**二次型**：

$$J_{N-1}^*(x_{N-1})=\frac12x_{N-1}^\top P_{N-1}x_{N-1}$$

### 5.3 Riccati 遞迴

**發現規律** [▶ 70:17](https://youtu.be/hy-e9g4nugE?t=4217)：

- 從二次的剩餘成本 $\frac12x^\top P_Nx$ 出發 → 最佳控制是線性回饋 → 新的剩餘成本又是二次的。
- 【課堂討論】老師問：再退一步，成本會是二次、三次？——數學結構**一模一樣**，只是下標從 $N-1$ 變 $N-2$。

所以不用每步解最佳化問題，只要遞迴更新矩陣 $F_k$、$P_k$：

> **LQR 的 Riccati 遞迴**
>
> $P_N=H$。對 $k=N-1,\dots,0$：
> $$
> \begin{aligned}
> F_k&=-\left(R_k+B_k^\top P_{k+1}B_k\right)^{-1}B_k^\top P_{k+1}A_k \\
> P_k&=Q_k+F_k^\top R_kF_k+\left(A_k+B_kF_k\right)^\top P_{k+1}\left(A_k+B_kF_k\right)
> \end{aligned}
> $$
> 最佳策略：$u_k^*=F_kx_k$；最佳剩餘成本：$J_k^*(x_k)=\frac12x_k^\top P_kx_k$。

> 以下**不是逐字稿內容**：$P_k$ 的式子投影片上有、字幕只說「relatively ugly but simple to implement」。上式是把 $u=Fx$ 代回成本得到的標準形式；它等價於課本式的
> $$P_k=Q_k+A_k^\top P_{k+1}A_k-A_k^\top P_{k+1}B_k\left(R_k+B_k^\top P_{k+1}B_k\right)^{-1}B_k^\top P_{k+1}A_k$$

**名字** [▶ 71:49](https://youtu.be/hy-e9g4nugE?t=4309)：這叫 **Riccati 方程**（Riccati equation），以義大利數學家 Riccati 命名。

【口頭】[▶ 72:21](https://youtu.be/hy-e9g4nugE?t=4341) 老師（義大利人）特別強調拼法：**兩個 c、一個 t**——Riccati。美國常拼錯成 Riccatti 或 Ricatti。「而且 Riccati 在義大利文是『勒索』的意思。」

【課本補充】課本 §3.2.1：

- 這個遞迴是連續時間**微分 Riccati 方程**從 $t_f$ 倒積到 0 的離散類比：每一步把未來成本的資訊往回傳。
- **無限時域**時（在可穩定性、可偵測性條件下），遞迴收斂到穩態 $P$，滿足**離散代數 Riccati 方程**（DARE）：
$$P=Q+A^\top PA-A^\top PB\left(R+B^\top PB\right)^{-1}B^\top PA,\qquad K=\left(R+B^\top PB\right)^{-1}B^\top PA$$
增益變成**時不變**。

**總結** [▶ 72:51](https://youtu.be/hy-e9g4nugE?t=4371)

- DP 是**純程序化**的：問題給好就能寫成 Python（「現在可以叫 Claude 寫遞迴」）。簡單的部分是寫程式；難的是**建模**，以及大規模時需要的**近似**。
- LQR 是幸運的特例：DP 遞迴簡化成兩個矩陣的遞迴——最佳**線性回饋**的增益 $F$，和每個子問題的成本矩陣 $P$。
- 週三：LQR 在機器人的更多應用。

## 6. 一頁速查表

### DP

| 項目 | 式子 |
|---|---|
| 問題 | $x_{k+1}=f(x_k,u_k,k)$，$u_k\in U(x_k)$，$J=h_N(x_N)+\sum_{k=0}^{N-1}g_k(x_k,u_k)$ |
| 最佳性原理 | 最佳序列的尾段對尾部子問題最佳（反證：否則接上更好的尾段，總成本更低；需要加法成本） |
| 邊界 | $J_N^*(x)=h_N(x)$ |
| 遞迴 | $J_k^*(x)=\min_{u\in U(x)}\left[g_k(x,u)+J_{k+1}^*(f(x,u,k))\right]$ |
| 策略 | $\pi_k^*(x)=\arg\min$ |
| 計算量 | 每步 × 每個狀態一次最小化；格點數 $\sim 10^d$（維度詛咒） |
| 性質 | 全域最佳、閉迴路、約束讓問題變簡單 |

### 最短路徑例子

$J(h)=0$，$J(g)=2$，$J(f)=5$，$J(e)=7$，$J(d)=10$，$J(c)=8$，$J(b)=17$，$J(a)=18$；路徑 $a\to d\to e\to f\to g\to h$。

### LQR（有限時域、離散）

$$x_{k+1}=Ax_k+Bu_k,\qquad J=\tfrac12x_N^\top Hx_N+\tfrac12\sum\left(x_k^\top Qx_k+u_k^\top Ru_k\right)$$

| 項目 | 式子 |
|---|---|
| 邊界 | $P_N=H$ |
| 增益 | $F_k=-(R+B^\top P_{k+1}B)^{-1}B^\top P_{k+1}A$ |
| 成本矩陣 | $P_k=Q+F_k^\top RF_k+(A+BF_k)^\top P_{k+1}(A+BF_k)$ |
| 策略 | $u_k^*=F_kx_k$（線性回饋） |
| 剩餘成本 | $J_k^*(x)=\frac12x^\top P_kx$ |
| 關鍵一步 | 二次剩餘成本 + 二次成本 + 線性動態 → 對 $u$ 是二次 → 一階條件給線性 $u$ → 代回仍是二次（$R\succ0$ 保證可逆） |
| 無限時域 | DARE 的穩態 $P$，時不變增益 |

## 附：本集一句話總結

> **加法成本帶來最佳性原理：最佳序列的尾段對尾部問題也最佳。所以可以從終點倒著解，每一步只比較「眼前成本 + 已算好的剩餘成本」，得到對所有狀態都適用的閉迴路策略（代價是維度詛咒）。套到線性動態 + 二次成本（LQR），剩餘成本一直是二次的，DP 簡化成 Riccati 矩陣遞迴，最佳控制是線性回饋 $u=F_kx$。**
