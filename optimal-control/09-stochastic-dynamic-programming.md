## 1. 馬可夫決策過程（有限時域）

### 1.1 問題設定

[▶ 00:35](https://youtu.be/C9mLpI8Td9g?t=35) **動態**多了擾動 $w_k$：

$$x_{k+1}=f_k(x_k,u_k,w_k)$$

$w_k$ 的意義看應用：控制飛機 → 陣風；買賣股票 → 市場的不確定性。

**事件順序** [▶ 01:45](https://youtu.be/C9mLpI8Td9g?t=105)：觀察 $x_k$ → 選 $u_k$ → 大自然決定 $w_k$。（順序有點任意，但要固定一個才能用。）

**控制約束**：$u_k\in U(x_k)$。

**擾動的分布** [▶ 02:50](https://youtu.be/C9mLpI8Td9g?t=170)：$w_k$ 是隨機變數，分布任意（高斯或其他），

$$w_k\sim P_k(\cdot\mid x_k,u_k)$$

- **可以**依賴目前的 $x_k$、$u_k$（也可以都不依賴）。
- **不可以**依賴過去的狀態 $x_{k-1},x_{k-2},\dots$（不能依賴歷史）。這是模型的**基本假設**。

【口頭】[▶ 04:24](https://youtu.be/C9mLpI8Td9g?t=264) 這通常是好假設：開車時行人下一步做什麼（擾動）取決於你的車現在在哪、打算左轉右轉。但有時你確實想建模對過去的依賴——這個框架不允許。是個溫和的限制，為了在一般性和可計算性之間取得平衡。

**策略**：閉迴路 $u_k=\pi_k(x_k)$。

**成本** [▶ 05:58](https://youtu.be/C9mLpI8Td9g?t=358)：階段成本**可以依賴擾動**，所以總成本是**隨機變數**。要把它變成可以最佳化的確定數字——取**期望值**：

$$J_\pi(x_0)=\mathbb{E}_{w_0,\dots,w_{N-1}}\left[h_N(x_N)+\sum_{k=0}^{N-1}g_k\left(x_k,\pi_k(x_k),w_k\right)\right]$$

**問題**：找 $\pi^*=\{\pi_0^*,\dots,\pi_{N-1}^*\}$ 最小化 $J_\pi$。

【Q&A】[▶ 07:29](https://youtu.be/C9mLpI8Td9g?t=449) 學生問：每一步的擾動依賴上一步的擾動嗎？答：只**間接**透過狀態。所有歷史（過去的狀態、控制、擾動）都由目前狀態「中介」。

【Q&A】[▶ 08:01](https://youtu.be/C9mLpI8Td9g?t=481) 學生問：成本會隨抽到的 $w_k$ 改變嗎？答：當然。風的實際狀況不同，軌跡成本就不同。我們要的策略要對**所有可能的實現**都好；把它們濃縮成一個數的方法就是取期望——有時運氣差、有時運氣好，要的是**平均**夠好。

【Q&A】[▶ 10:36](https://youtu.be/C9mLpI8Td9g?t=636) 學生問：為什麼期望要對整串擾動取？答：成本是加法的，算的是整條軌跡；整條軌跡依賴所有擾動。但狀態的演化只直接受目前的擾動影響。DP 會把這個「巢狀」的期望拆成**一次只對一個擾動**取期望。

【Q&A】[▶ 12:11](https://youtu.be/C9mLpI8Td9g?t=731) 學生問：狀態只依賴上一步嗎？答：$x_{k+2}$ **直接**受 $w_{k+1}$ 影響，**間接**受 $w_k$ 影響（因為 $x_{k+1}$ 受 $w_k$ 影響）。所以每個狀態其實依賴所有過去的擾動，但只**直接**依賴最近一個。

### 1.2 重點：馬可夫、閉迴路、風險中性

[▶ 13:11](https://youtu.be/C9mLpI8Td9g?t=791)

| 特點 | 意思 |
|---|---|
| **馬可夫**（Markovian） | 沒有對歷史的明確依賴，一切由目前狀態中介；擾動分布只能依賴 $x_k,u_k$ |
| **閉迴路** | 隨機性會把你推來推去，更需要「對每個狀態都有最佳動作」的策略 |
| **加法成本** | 跟確定性一樣 |
| **風險中性**（risk-neutral） | 只看**期望**，不考慮變異度等 |

**風險敏感** [▶ 14:20](https://youtu.be/C9mLpI8Td9g?t=860)：

- 人生中你會最佳化平均收入，但也會保護自己避免最壞情況、避免太大的變異。
- **風險敏感**（risk-sensitive）的問題會加入例如變異數的項。
- 問題是計算複雜很多：最天真的做法下，標準 DP 方程**不再成立**，最佳性原理也不成立，要額外分析。
- 【口頭】老師說這是他過去做過很多研究的題目。本課只講風險中性。

**另一種變化** [▶ 09:34](https://youtu.be/C9mLpI8Td9g?t=574)：把擾動建成**對抗的**（adversarial），每一刻都是最壞的 → **極小極大**（minimax）問題，變成跟大自然的賽局。本集不講。

**期望為什麼好** [▶ 15:22](https://youtu.be/C9mLpI8Td9g?t=922)：期望是**線性**的，讓你能把問題切成多個階段。

【Q&A】[▶ 10:36](https://youtu.be/C9mLpI8Td9g?t=636) 有學生問「Markov」的名字。老師開玩笑：「不是我發明的，不然我會拿好幾座諾貝爾獎。」

[▶ 15:52](https://youtu.be/C9mLpI8Td9g?t=952)

## 2. 隨機 DP

**隨機最佳性原理** [▶ 17:26](https://youtu.be/C9mLpI8Td9g?t=1046)：因為用了**期望**、又有**馬可夫**假設，問題還是能切成小塊。

> 設 $\pi^*=\{\pi_0^*,\dots,\pi_{N-1}^*\}$ 是最佳策略。考慮從時間 $i$、狀態 $x_i$ 出發的尾部子問題（只看 $i$ 之後的期望成本）。那麼尾部策略 $\{\pi_i^*,\dots,\pi_{N-1}^*\}$ 對這個子問題是最佳的。

直覺跟確定性一樣，證明比較麻煩，參考 Bertsekas 的最佳控制書。

【課本補充】課本 Theorem 17.2.2 加了一句：對「在 $\pi^*$ 下**可到達**」的狀態 $x_t$ 成立。

**隨機 DP 演算法** [▶ 19:33](https://youtu.be/C9mLpI8Td9g?t=1173)：形式跟確定性**完全一樣**，從後往前：

> $$J_N^*(x_N)=h_N(x_N)$$
> $$J_k^*(x_k)=\min_{u_k\in U(x_k)}\ \mathbb{E}_{w_k}\left[g_k(x_k,u_k,w_k)+J_{k+1}^*\left(f_k(x_k,u_k,w_k)\right)\right]$$
> $$\pi_k^*(x_k)=\arg\min\ (\text{上式})$$

跟確定性的差別 [▶ 21:06](https://youtu.be/C9mLpI8Td9g?t=1266)：

- 轉移依賴 $w_k$。
- 眼前成本和剩餘成本都是隨機的 → 要取期望。
- **關鍵**：只對 $w_k$ **一個**取期望，不是對整串 $w_0,\dots,w_{N-1}$。大幅簡化。

最後 $J_0^*(x_0)$ 就是最佳成本。

【Q&A】[▶ 22:11](https://youtu.be/C9mLpI8Td9g?t=1331) 學生問：擾動分布只依賴目前狀態的假設，是為了讓最佳性原理成立嗎？答：對。隨機情況要保持結構，需要（1）加法成本，（2）擾動分布的馬可夫假設。

【口頭】[▶ 23:12](https://youtu.be/C9mLpI8Td9g?t=1392) 老師當年在 MIT 當過 Bertsekas 動態規劃課的助教。

## 3. 例子：庫存控制

[▶ 23:43](https://youtu.be/C9mLpI8Td9g?t=1423) 倉庫存貨、預期需求進貨、需求實現就出貨。

| 符號 | 意思 |
|---|---|
| $x_k$ | 目前庫存（例如冰箱台數） |
| $u_k$ | 進貨量（買了立刻到貨） |
| $w_k$ | 時刻 $k$ 實現的需求 |

**動態** [▶ 24:44](https://youtu.be/C9mLpI8Td9g?t=1484)：

$$x_{k+1}=\max\{0,\ x_k+u_k-w_k\}$$

例：有 2、買 1 → 3；需求 2 → 剩 1。需求大於庫存 → 下一刻是 0，沒滿足的需求就算了。

**倉庫很小** [▶ 25:14](https://youtu.be/C9mLpI8Td9g?t=1514)：$x_k+u_k\le 2$。（玩具問題，為了手算時狀態不要有 25 種。）

**需求分布**（跟狀態和控制無關）[▶ 26:18](https://youtu.be/C9mLpI8Td9g?t=1578)：

$$P(w_k=0)=0.1,\quad P(w_k=1)=0.7,\quad P(w_k=2)=0.2$$

**成本** [▶ 26:50](https://youtu.be/C9mLpI8Td9g?t=1610)：時域 $N=3$，終端成本 0（剩多少貨都免費處理掉）。

$$J=\mathbb{E}_{w_0,w_1,w_2}\left[\sum_{k=0}^{2}\left(u_k+\left(x_k+u_k-w_k\right)^2\right)\right]$$

- $u_k$：每單位進貨 1 元。
- $(x_k+u_k-w_k)^2$：如果是正的 → 要存到下一期，**存貨很貴**；如果是負的 → 需求沒被滿足，**傷害顧客信任**。兩者都用平方懲罰。

【口頭】成本怎麼設本來就有點任意，只是把「在不同情況下有多開心」注入模型。

【Q&A】[▶ 31:03](https://youtu.be/C9mLpI8Td9g?t=1863) 學生問：為什麼庫存上限變成控制的約束？答：倉庫最多放 2 個；放多少 = 現有 + 進貨（立刻到）。這也是一個 $U(x_k)$ **明確依賴狀態**的例子。

【Q&A】[▶ 31:34](https://youtu.be/C9mLpI8Td9g?t=1894) 學生問：為什麼約束是 $x_k+u_k$ 而不扣掉 $w_k$？答：進貨到了、需求還沒實現的那段時間，倉庫要放得下。

【Q&A】[▶ 29:28](https://youtu.be/C9mLpI8Td9g?t=1768) 學生猜「預期需求是 1，就買到 1」。老師：需求 1 的機率是 70%，但也可能 0（10%）或 2（20%）。你知道的是**機率**，不是實際值——就像買股票不知道中午時 Tesla 的股價。

**DP 手算** [▶ 33:12](https://youtu.be/C9mLpI8Td9g?t=1992)

$J_3^*(x_3)=0$。

$$J_2^*(x_2)=\min_{0\le u_2\le 2-x_2}\ \mathbb{E}_{w_2}\left[u_2+\left(x_2+u_2-w_2\right)^2\right]$$

> ⚠️ 逐字稿缺字 [▶ 35:59](https://youtu.be/C9mLpI8Td9g?t=2159)：老師板書一開始把上界寫成 $x_2-2$，學生指出後更正為 $2-x_2$。

狀態只有 $0,1,2$ 三種。**$J_2^*(0)$**（$u_2\in\{0,1,2\}$）[▶ 37:30](https://youtu.be/C9mLpI8Td9g?t=2250)：把期望展開成三種需求的加權和

$$
\begin{aligned}
J_2^*(0)&=\min_{u_2\in\{0,1,2\}}\ 0.1\left[u_2+u_2^2\right]+0.7\left[u_2+(u_2-1)^2\right]+0.2\left[u_2+(u_2-2)^2\right] \\
&=\min_{u_2}\ u_2+0.1u_2^2+0.7(u_2-1)^2+0.2(u_2-2)^2
\end{aligned}
$$

（機率和為 1，所以 $u_2$ 項加起來就是 $u_2$。）

代入三個值：

| $u_2$ | 值 |
|---|---|
| 0 | $0+0+0.7+0.8=1.5$ |
| 1 | $1+0.1+0+0.2=\mathbf{1.3}$ |
| 2 | $2+0.4+0.7+0=3.1$ |

最佳 $u_2=1$，$J_2^*(0)=1.3$。

> 數值表**不是逐字稿內容**：老師只說「代入三個值，最佳是 1」；上表是代入計算，和課本 Example 17.2.1 的 $J_2^*(0)=1.3$ 一致。

【口頭】[▶ 42:28](https://youtu.be/C9mLpI8Td9g?t=2548) 不意外：需求 1 的機率很高，所以買一個來滿足它。

【口頭】[▶ 37:00](https://youtu.be/C9mLpI8Td9g?t=2220) 期末考會要你手算 Bellman 方程。「就像打疫苗：有點煩，但打一次就終身有效。」

【Q&A】[▶ 40:19](https://youtu.be/C9mLpI8Td9g?t=2419) 學生問：如果起始庫存是 1，每個括號裡第一項都變 1？答：對，而且約束變成 $u_2\in\{0,1\}$。機率不變（不依賴狀態）。

**完整結果** [▶ 42:58](https://youtu.be/C9mLpI8Td9g?t=2578)：老師放了試算表連結。

【課本補充】課本 Example 17.2.1 給出所有數值：

| | $x=0$ | $x=1$ | $x=2$ |
|---|---|---|---|
| $J_2^*$ | 1.3 | 0.3 | 1.1 |
| $\pi_2^*$ | 1 | 0 | 0 |
| $J_1^*$ | 2.5 | 1.5 | 1.68 |
| $\pi_1^*$ | 1 | 0 | 0 |
| $J_0^*$ | 3.7 | **2.7** | 2.818 |
| $\pi_0^*$ | 1 | 0 | 0 |

最佳策略剛好**不隨時間變**：庫存空了就買一個，否則不買。

【Q&A】[▶ 43:31](https://youtu.be/C9mLpI8Td9g?t=2611) 學生問：從庫存 1 開始最好？答：對（成本最低），因為在中間：不怕缺貨，也不用買很多。

【Q&A】[▶ 44:01](https://youtu.be/C9mLpI8Td9g?t=2641) 學生問：之後實際需求出來了，要重算嗎？答：不用。$\pi_0,\pi_1,\pi_2$ 對所有階段、所有狀態都給出最佳動作，不用再最佳化。很強大——但計算量依狀態數成長；這裡是 3 個狀態 × 3 階段 = 9 次。

【Q&A】[▶ 45:34](https://youtu.be/C9mLpI8Td9g?t=2734) 學生問連續狀態怎麼辦？答：不能列舉所有狀態，不能直接跑。可以離散化，或先把狀態映射到低維再離散化。

## 4. 例子：隨機 LQR

[▶ 46:04](https://youtu.be/C9mLpI8Td9g?t=2764) 「我們最愛的問題」再加一個變化：

$$x_{k+1}=A_kx_k+B_ku_k+w_k,\qquad w_k\sim\mathcal N(0,\Sigma)$$

成本一樣是二次的。

> ⚠️ 逐字稿缺字 [▶ 46:35](https://youtu.be/C9mLpI8Td9g?t=2795)：字幕寫「only difference is that the dynamics are **not** stochastic」，依上下文應為「**now** stochastic」。

**猜測**（受確定性 LQR 啟發）[▶ 47:08](https://youtu.be/C9mLpI8Td9g?t=2828)：剩餘成本是二次加常數，

$$J_{k+1}^*(x)=x^\top P_{k+1}x+c_{k+1}$$

> 老師提到投影片有兩三個筆誤（下標 $k$ 和 $k+1$ 混用），說之後會修。本筆記用正確下標。

**Bellman 方程** [▶ 48:22](https://youtu.be/C9mLpI8Td9g?t=2902)：

$$J_k^*(x_k)=\min_{u_k}\ \mathbb{E}_{w_k}\left[x_k^\top Qx_k+u_k^\top Ru_k+x_{k+1}^\top P_{k+1}x_{k+1}+c_{k+1}\right]$$

展開 $x_{k+1}^\top P_{k+1}x_{k+1}$，$x_{k+1}=(Ax+Bu)+w$：

$$(Ax+Bu)^\top P_{k+1}(Ax+Bu)+w^\top P_{k+1}w+2(Ax+Bu)^\top P_{k+1}w$$

**逐項取期望** [▶ 49:25](https://youtu.be/C9mLpI8Td9g?t=2965)：

| 項 | 期望 | 理由 |
|---|---|---|
| $x^\top Qx$、$u^\top Ru$、$(Ax+Bu)^\top P(Ax+Bu)$ | 不變 | 不含 $w$ |
| $2(Ax+Bu)^\top P_{k+1}w$ | **0** | 對 $w$ 線性，$\mathbb E[w]=0$ |
| $w^\top P_{k+1}w$ | $\mathrm{tr}\left(P_{k+1}\Sigma\right)$ | 給定的事實（見下） |

【課堂討論】[▶ 49:55](https://youtu.be/C9mLpI8Td9g?t=2995) 老師問：$\mathbb E[x]=0$，$a$ 是實數，$\mathbb E[ax]$ 是多少？學生：0。

**事實** [▶ 50:25](https://youtu.be/C9mLpI8Td9g?t=3025)：$w$ 是零均值、共變異數 $\Sigma$ 的高斯，則
$$\mathbb E\left[w^\top Pw\right]=\mathrm{tr}(P\Sigma)$$
（跡 trace = 對角元素的和。）老師說證明要兩三步線性代數，不太有啟發性，略過。

> 以下**不是逐字稿內容**，是補上的兩步證明：$w^\top Pw$ 是純量，等於自己的跡；跡有循環性：$\mathbb E[w^\top Pw]=\mathbb E[\mathrm{tr}(Pww^\top)]=\mathrm{tr}(P\,\mathbb E[ww^\top])=\mathrm{tr}(P\Sigma)$。（其實只用到零均值和共變異數，不需要高斯。）

**結論** [▶ 52:01](https://youtu.be/C9mLpI8Td9g?t=3121)：Bellman 右邊 = **確定性 LQR 的右邊 + 常數** $\mathrm{tr}(P_{k+1}\Sigma)+c_{k+1}$。

- 對 $u$ 微分時常數消失 → 最佳控制**跟確定性 LQR 完全一樣**（線性回饋）。
- 代回去 → 二次 + 常數 → 結構保持。

$$\boxed{\text{隨機 LQR：策略一樣；成本多一個跟雜訊大小有關的常數}}$$

【口頭】[▶ 53:02](https://youtu.be/C9mLpI8Td9g?t=3182) 很合理：在不確定的環境裡運作，總要付出一點代價。

> 以下**不是逐字稿內容**：常數的遞迴是 $c_k=c_{k+1}+\mathrm{tr}(P_{k+1}\Sigma)$，所以總代價是 $\sum_k\mathrm{tr}(P_{k+1}\Sigma)$。這個「策略不受雜訊影響」的性質常叫**確定性等價**（certainty equivalence）。老師沒用這個名字。

【Q&A】[▶ 53:32](https://youtu.be/C9mLpI8Td9g?t=3212) 學生問：如果共變異數依賴控制呢？答：那就不一樣了，對 $u$ 微分時這項不會消失。這裡利用的是 $\Sigma$ 是給定的、不依賴狀態和控制。

## 5. 無限時域 MDP

[▶ 54:32](https://youtu.be/C9mLpI8Td9g?t=3272) 這部分對課程後半（強化學習、模仿學習）很重要。

### 5.1 設定與折扣因子

[▶ 55:04](https://youtu.be/C9mLpI8Td9g?t=3304) RL 問題通常用**無限時域**（infinite horizon）表述。

- 實際上不可能無限（人生有限，宇宙壽命大概也有限），但對「有限但很多步」的問題是好近似。
- 而且會**大幅簡化**問題。

**無限時域 MDP** 由五個東西定義 [▶ 55:36](https://youtu.be/C9mLpI8Td9g?t=3336)：

$$(\mathcal X,\ \mathcal U,\ T,\ R,\ \gamma)$$

- 狀態 $x$（電腦科學記 $s$）、動作 $u$。
- 轉移函數 $T(x_t\mid x_{t-1},u_{t-1})$：下一個狀態的機率分布。
- **獎勵** $R(x,u)$：RL 通常說獎勵、**最大化**（跟最小化成本只差一個負號）。
- **折扣因子** $\gamma\in(0,1)$。

**平穩性**（stationary）[▶ 57:09](https://youtu.be/C9mLpI8Td9g?t=3429)：轉移機率**不依賴**時刻 $t$。（以前有限時域允許 $f_k$ 隨時間變。）為什麼：

- 動態不太隨時間變的過程，這是不錯的假設。
- 無限時域要用到**極限**；問題本身一直變的話，取極限會非常難。

**目標** [▶ 58:15](https://youtu.be/C9mLpI8Td9g?t=3495)：

$$\max_\pi\ \mathbb E\left[\sum_{t=0}^{\infty}\gamma^tR\left(x_t,\pi(x_t)\right)\right]$$

**為什麼要折扣？** 【課堂討論】[▶ 58:47](https://youtu.be/C9mLpI8Td9g?t=3527)

- 學生：遠在未來的獎勵沒那麼重要。老師：對，這是**「知性」的解釋**——你會很重視未來幾步的後果，不太在乎一個月或一年後。
- 學生：要讓總和收斂。老師：對，這是**務實的解釋**——無限項加總，任何合理的獎勵都會是 $+\infty$；如果所有策略都是 $+\infty$，哪個最佳？全都「很棒」。乘上指數權重通常能讓級數收斂。

**平穩策略** [▶ 60:51](https://youtu.be/C9mLpI8Td9g?t=3651)：問題平穩、時域無限 → 最佳策略**不依賴階段**。不再有 $\pi_0,\pi_1,\pi_2,\dots$，只要找**一個** $\pi$。

【Q&A】[▶ 61:22](https://youtu.be/C9mLpI8Td9g?t=3682) 學生問：最佳策略一定是平穩的嗎？答：我們只考慮平穩策略。

### 5.2 Bellman 方程變成不動點方程

[▶ 61:57](https://youtu.be/C9mLpI8Td9g?t=3717) 怎麼解？重用有限時域的 Bellman 方程。如果讓階段數趨近無限、兩邊取極限，會不會收斂？

**會** [▶ 64:10](https://youtu.be/C9mLpI8Td9g?t=3850)：成本函數收斂到一個穩態量，而且它滿足的不再是**遞迴**，而是**不動點方程**（fixed-point equation）：

> **Bellman 方程（無限時域）**
> $$V^*(x)=\max_u\left[R(x,u)+\gamma\sum_{x'}T(x'\mid x,u)\,V^*(x')\right]$$

- $V$ 跟 $J$ 是同一個東西；講獎勵時大家習慣叫 $V$（value，**值函數**）。「至於 $J$ 代表什麼，我也不知道。」
- $V^*(x)$ = 從 $x$ 出發、照最佳策略走的值。
- 證明用到極限論證；這裡當成事實。

**給定策略的值** [▶ 66:44](https://youtu.be/C9mLpI8Td9g?t=4004)：如果只想知道某個固定策略 $\pi$ 能拿多少獎勵：

$$V^\pi(x)=R\left(x,\pi(x)\right)+\gamma\sum_{x'}T\left(x'\mid x,\pi(x)\right)V^\pi(x')$$

沒有 max（策略固定了）。如果狀態有限個，這是對 $V^\pi$ 的**線性方程組**，可以直接解。

【Q&A】[▶ 65:42](https://youtu.be/C9mLpI8Td9g?t=3942) 學生問：演算法怎麼知道不用再搜下去？答：這裡還沒給演算法，只是一個性質。下一講開頭會講兩種演算法：**值迭代**（value iteration）和**策略迭代**（policy iteration）。

【Q&A】[▶ 67:47](https://youtu.be/C9mLpI8Td9g?t=4067) 學生問：以前成本依賴擾動，這裡呢？答：還是依賴，只是藏在轉移函數 $T$ 裡。$x_{k+1}=f(x_k,u_k,w_k)$ 加上 $w_k\sim P(\cdot\mid x_k,u_k)$，跟直接給 $T(x_{k+1}\mid x_k,u_k)$ 是**等價**的，可以互相轉換。差別只在記號上擾動是不是明寫。這個模型顯然是馬可夫的。

### 5.3 Q 函數：為什麼很重要

[▶ 69:57](https://youtu.be/C9mLpI8Td9g?t=4197) 一個看似無害、但對推導**學習演算法**有革命性影響的改寫。

**定義** [▶ 70:27](https://youtu.be/C9mLpI8Td9g?t=4227)：Q 函數就是 Bellman 方程的右邊：

$$Q^*(x,u)=R(x,u)+\gamma\sum_{x'}T(x'\mid x,u)\,V^*(x')$$

**意思**：在 $x$ 先用動作 $u$，**之後**都照最佳策略走，能拿到的累積獎勵。（下一個狀態是隨機的，所以要平均。）

**Q 函數的 Bellman 方程** [▶ 72:04](https://youtu.be/C9mLpI8Td9g?t=4324)：因為 $V^*(x)=\max_uQ^*(x,u)$，代進去：

$$Q^*(x,u)=R(x,u)+\gamma\sum_{x'}T(x'\mid x,u)\,\max_{u'}Q^*(x',u')$$

**為什麼在乎？** [▶ 72:36](https://youtu.be/C9mLpI8Td9g?t=4356) 假設模型的一部分**未知**——例如不知道轉移機率 $T$——但有某個（強化學習）演算法能近似學到 Q 函數。現在在狀態 $x$，最佳動作是什麼？

| 神諭給你 | 最佳動作 | 需要知道 $T$ 嗎？ |
|---|---|---|
| $Q^*$ | $\pi^*(x)=\arg\max_uQ^*(x,u)$ | **不用** |
| $V^*$ | $\pi^*(x)=\arg\max_u\left[R(x,u)+\gamma\sum_{x'}T(x'\mid x,u)V^*(x')\right]$ | **要** |

【口頭】[▶ 75:13](https://youtu.be/C9mLpI8Td9g?t=4513) 在不知道轉移核的學習情境下，這就是大問題。所以這個看似無聊的改寫影響很大：用 Q 函數重新表述後，在模型部分未知時求最佳動作變得自然得多。「通常大家不會特別講這點，但差別很大。」

**給定策略的 Q 函數** [▶ 75:45](https://youtu.be/C9mLpI8Td9g?t=4545)：$Q^\pi(x,u)$ = 在 $x$ 用 $u$，之後都照 $\pi$ 走的值。也有類似的方程。

> 以下**不是逐字稿內容**，是依定義寫出的方程：
> $$Q^\pi(x,u)=R(x,u)+\gamma\sum_{x'}T(x'\mid x,u)\,Q^\pi\left(x',\pi(x')\right)$$

**下次** [▶ 76:20](https://youtu.be/C9mLpI8Td9g?t=4580)：值迭代、策略迭代；然後進入連續時間閉迴路最佳控制。幾週後再回到無限時域 MDP 和學習型控制。

## 6. 演算法整理

### 隨機 DP（有限時域）

**在解什麼**：$x_{k+1}=f_k(x_k,u_k,w_k)$，$w_k\sim P(\cdot\mid x_k,u_k)$，最小化期望加法成本；要閉迴路策略。

**步驟**：

```
1. J_N(x) ← h_N(x)，對所有 x
2. for k = N−1, …, 0：
       for 每個 x：
           for 每個 u ∈ U(x)：
               算 E_w[ g_k(x,u,w) + J_{k+1}(f_k(x,u,w)) ]
               （離散 w：Σ_w P(w|x,u)·[…]）
           J_k(x) ← 最小值；π_k(x) ← 最小的 u
3. 部署：觀察 x_k → u_k = π_k(x_k)（不用再最佳化）
```

**什麼時候會失敗**：擾動依賴歷史（不是馬可夫）→ 最佳性原理不成立；想考慮風險（變異數）→ 標準 DP 不成立；連續或高維狀態 → 不能列舉（維度詛咒）。

### 隨機 LQR

**結論**：跑確定性 LQR 的 Riccati 遞迴即可；增益一樣，成本多 $\sum\mathrm{tr}(P_{k+1}\Sigma)$。

**什麼時候會失敗**：雜訊共變異數依賴控制或狀態 → 這個簡化不成立。

## 7. 一頁速查表

### 有限時域 MDP

| 項目 | 式子 |
|---|---|
| 動態 | $x_{k+1}=f_k(x_k,u_k,w_k)$，$w_k\sim P_k(\cdot\mid x_k,u_k)$（不依賴歷史） |
| 成本 | $\mathbb E_{w}\left[h_N(x_N)+\sum g_k(x_k,\pi_k(x_k),w_k)\right]$（風險中性） |
| DP | $J_k^*(x)=\min_{u\in U(x)}\mathbb E_{w_k}\left[g_k(x,u,w_k)+J_{k+1}^*(f_k(x,u,w_k))\right]$ |
| 關鍵 | 一次只對一個 $w_k$ 取期望（期望線性 + 馬可夫） |

### 庫存例子

$x_{k+1}=\max\{0,x_k+u_k-w_k\}$，$x+u\le 2$，$w\in\{0,1,2\}$ 機率 $\{0.1,0.7,0.2\}$，成本 $u+(x+u-w)^2$，$N=3$：
$J_2^*(0)=1.3$（$u=1$）；最佳策略：庫存 0 就買 1，否則不買。

### 隨機 LQR

$$\mathbb E[w^\top Pw]=\mathrm{tr}(P\Sigma),\qquad \mathbb E[(Ax+Bu)^\top Pw]=0$$

策略 = 確定性 LQR；$J_k^*(x)=x^\top P_kx+c_k$，$c_k=c_{k+1}+\mathrm{tr}(P_{k+1}\Sigma)$。

### 無限時域 MDP $(\mathcal X,\mathcal U,T,R,\gamma)$

| 項目 | 式子 |
|---|---|
| 目標 | $\max_\pi\mathbb E\left[\sum_{t\ge 0}\gamma^tR(x_t,\pi(x_t))\right]$，平穩策略 |
| 折扣 | 遠期不重要 + 讓總和收斂 |
| $V^*$ | $V^*(x)=\max_u\left[R+\gamma\sum_{x'}T\,V^*(x')\right]$（不動點） |
| $V^\pi$ | $V^\pi(x)=R(x,\pi(x))+\gamma\sum_{x'}T\,V^\pi(x')$（有限狀態 → 線性方程組） |
| $Q^*$ | $Q^*(x,u)=R+\gamma\sum_{x'}T\max_{u'}Q^*(x',u')$ |
| 為什麼用 $Q$ | $\pi^*(x)=\arg\max_uQ^*(x,u)$ 不需要 $T$；用 $V^*$ 求動作需要 $T$ |

### 記號對照

控制 $(x,u,f,J\ \min)$ ⟷ 電腦科學 $(s,a,T,R/V\ \max)$
