## 1. 用 HJI 計算後向可達集

### 1.1 回顧定義

[▶ 01:06](https://youtu.be/3_gxaB_Pp3k?t=66) （終端時刻 = 0）

| 集合 | 定義 | 怎麼用 |
|---|---|---|
| **避開集** $\mathcal A(t)$（avoidance set） | 存在擾動，使得**對所有**控制，系統在 $t=0$ 進入目標集 | 要從**外面**出發 |
| **到達集** $\mathcal R(t)$（reach set） | **對所有**擾動，存在控制，使系統在 $t=0$ 進入目標集 | 要從**裡面**出發 |

[▶ 02:07](https://youtu.be/3_gxaB_Pp3k?t=127) 這些自然變成軌跡最佳化的**約束**：避開集 → 軌跡待在外面；到達集 → 初始條件在裡面。

### 1.2 把「屬於集合」變成成本：水平集方法

[▶ 02:40](https://youtu.be/3_gxaB_Pp3k?t=160) 算後向可達集 = 解一個**結果是布林值**的微分賽局（兩個玩家：你和大自然）。HJI 的雙人結構很適合，但問題是：**屬於集合是二元的**，最佳控制只認得成本函數。能不能把「屬於集合」寫成成本？

**可以** [▶ 04:14](https://youtu.be/3_gxaB_Pp3k?t=254)：

1. **拿掉運行成本**：$g=0$。只在乎終端時刻有沒有在目標集裡。
2. **選終端成本** $h$ 來表示集合：目標集是 $h$ 的 **0 下水平集**（0 sublevel set）：
$$x\in\mathcal T\iff h(x)\le 0$$

這叫**水平集方法**（level set method）。這樣的 $h$ **一定找得到**；集合越複雜，$h$ 越複雜，但沒問題。

**例子** [▶ 06:17](https://youtu.be/3_gxaB_Pp3k?t=377)：目標集是半徑 $R$ 的圓。系統是**獨輪車**（unicycle），狀態三維：位置 $x,y$ 和航向 $\theta$。

$$h(x,y,\theta)=\sqrt{x^2+y^2}-R$$

> ⚠️ 逐字稿缺字 [▶ 06:48](https://youtu.be/3_gxaB_Pp3k?t=408)：字幕寫「$x^2+y^2\le R$」，依半徑 $R$ 的圓應為 $x^2+y^2\le R^2$（或等價的 $\sqrt{x^2+y^2}\le R$）。$h$ 的具體式子是依「$h\le 0$ ⟺ 距離小於 $R$」寫出的。

【課堂討論】[▶ 07:53](https://youtu.be/3_gxaB_Pp3k?t=473) 老師問 $h\le 0$ 時獨輪車在哪？學生：圓裡面。

- $h\le 0$：在圓內。越負 = 越深入圓內。
- $h>0$：在圓外。越正 = 離圓越遠。
- $h$ 的**大小**也有意義：離危險有多少**緩衝**（安全／不安全的程度）。

【Q&A】[▶ 11:03](https://youtu.be/3_gxaB_Pp3k?t=663) 學生問 $h$ 越正代表越安全嗎？答：對。$h$ 的大小除了讓我們能用 HJI 框架，還額外告訴你離危險線（$h=0$）還有多少緩衝。

**避開問題** [▶ 09:31](https://youtu.be/3_gxaB_Pp3k?t=571)：你（玩家 1）想讓 $h$ **正**（待在外面），對 $u$ 最大化；對手（玩家 2）想讓 $h$ **負**。就是 HJI 的形式，只是沒有運行成本：

$$J(x,t)=h\left(x(0)\right),\qquad \frac{\partial J}{\partial t}+\max_u\min_d\ \frac{\partial J}{\partial x}^\top f(x,u,d)=0,\qquad J(x,0)=h(x)$$

[▶ 10:33](https://youtu.be/3_gxaB_Pp3k?t=633) 圖：紅圈是避開集。終點在圈外的軌跡 → $h>0$ → 成本正；終點在圈內 → 成本負。

> 上式是把第 10 集的 HJI 代入 $g=0$、終端成本 $h$ 寫出的；投影片原式字幕沒唸。

### 1.3 避開 vs 到達：交換 min 和 max

[▶ 12:33](https://youtu.be/3_gxaB_Pp3k?t=753)

| 問題 | 你想讓 $h$ | 對手想讓 $h$ | 瞬間的最佳化 |
|---|---|---|---|
| 避開 | 正（$\max_u$） | 負（$\min_d$） | $\max_u\min_d$ |
| 到達 | 負（$\min_u$） | 正（$\max_d$） | $\min_u\max_d$ |

推導完全一樣，只是 min、max 對調。

【Q&A】[▶ 13:03](https://youtu.be/3_gxaB_Pp3k?t=783) 學生問：可以把可達集當成新的目標集，繼續往回推嗎？答：當然可以。

**判斷** [▶ 21:00](https://youtu.be/3_gxaB_Pp3k?t=1260)：避開問題中，保證不出事的初始條件 = 值函數 $J>0$ 的那些。

### 1.4 從集合到管：整條軌跡都要安全

[▶ 13:37](https://youtu.be/3_gxaB_Pp3k?t=817) 目前的表述只看**終點**。但你通常要的是**整條軌跡**都安全。

**問題** [▶ 14:39](https://youtu.be/3_gxaB_Pp3k?t=879)：一條軌跡中途穿過避開集，但 $t=0$ 時在外面 → 照上面的表述算「安全」（成本為正）。但中途你可能跟另一架飛機太近——**險些相撞**（near-miss）。

**解法：後向可達管**（backward reachable tube，BRT）[▶ 15:41](https://youtu.be/3_gxaB_Pp3k?t=941)：把成本從 $h(x(0))$ 改成

$$J=\min_{\tau\in[t,0]}h\left(x(\tau)\right)$$

意思：不只終點 $h>0$，整條軌跡上 $h$ 的**最小值**都要 $>0$ → 每一刻都在避開集外面。

這個成本跟上次不同，HJI 方程會多一個最小化，比較複雜。老師不推導，只說有工具可以算，參考資料在投影片。

> 以下**不是逐字稿內容**：BRT 常見的 HJI 變分不等式形式是
> $$\min\left\{\frac{\partial J}{\partial t}+\max_u\min_d\frac{\partial J}{\partial x}^\top f,\ \ h(x)-J(x,t)\right\}=0$$
> 多出來的 $\min$ 就是讓值函數不超過沿途的 $h$。待對照投影片。

【Q&A】[▶ 18:23](https://youtu.be/3_gxaB_Pp3k?t=1103) 學生問 BRS 和 BRT 都是初始狀態的集合？答：對。BRS：終點不在危險裡；BRT：整個時域都不在危險裡。

【Q&A】[▶ 18:53](https://youtu.be/3_gxaB_Pp3k?t=1133) 學生問：解的是集合還是控制？答：**兩個都要**。在避開問題中，就算從集合外出發，如果不用最佳控制策略，擾動還是可能把你推進去。不過解完 HJI 後，最佳控制很容易算出來。

【Q&A】[▶ 19:57](https://youtu.be/3_gxaB_Pp3k?t=1197) 學生問有沒有「到達型的管」（例如要穿過某條走廊）？答：有，但比較少用。可達性計算最常用在**安全**：在軌跡最佳化中加上額外約束，確保有足夠緩衝避免碰撞。所以最常見的是避開型。

【Q&A】[▶ 21:35](https://youtu.be/3_gxaB_Pp3k?t=1295) 學生問：如果動態讓你永遠到不了目標集呢？答：集合就是空的。要嘛改問題（可能太保守了），要嘛不要部署機器人。至少它給你很強的資訊：可能是問題表述太保守，或控制權限不夠（該花錢買更好的致動器、設計更好的機器人）。

## 2. 例子：兩架飛機防撞

[▶ 22:37](https://youtu.be/3_gxaB_Pp3k?t=1357) 兩架飛機都用**獨輪車動態**：

$$\dot x_A=v\cos\theta_A,\quad \dot y_A=v\sin\theta_A,\quad \dot\theta_A=u_A$$

B 同理（控制 $u_B$）。控制的是**航向變化率**，速度 $v$ 固定。

**問題** [▶ 23:42](https://youtu.be/3_gxaB_Pp3k?t=1422)：哪些**聯合**初始條件下，存在 B 的軌跡使得不管 A 多努力閃避都會「碰撞」？碰撞定義為相對距離 $<r$。所以避開集是**相對位置**空間裡的圓：以 A 為中心，B 不能進入。

【口頭】[▶ 24:46](https://youtu.be/3_gxaB_Pp3k?t=1486) 「這是真的東西，大家就是這樣實作飛機某種程度的防撞。」

**程式** [▶ 25:16](https://youtu.be/3_gxaB_Pp3k?t=1516)：老師放了程式碼，終端集是半徑 5 的圓（就是 $h$）。用的是他實驗室開發的套件 **hj_reachability**（字幕「HJ reachability」）。

**結果：一個怪形狀** [▶ 25:48](https://youtu.be/3_gxaB_Pp3k?t=1548)：三維圖，軸是相對座標——$x$：相對縱向距離，$y$：相對橫向距離，$z$：相對航向。畫的是值函數的 **0 水平集**：在綠色形狀**裡面**（$J<0$）可能碰撞；外面不會。

**怎麼解讀**：

| 相對航向 | 形狀 | 直覺 |
|---|---|---|
| 0（同方向） [▶ 27:26](https://youtu.be/3_gxaB_Pp3k?t=1646) | 就是避開集本身（圓） | 兩架飛機互相跟著飛：一開始在圈外就永遠在外；在圈內就永遠在內 |
| 約 $\pi$（相向） [▶ 28:33](https://youtu.be/3_gxaB_Pp3k?t=1713) | 往某方向**突出**一塊 | B 正對著你飛來，需要**更多分離**來閃避；如果 B 在你後方，只要一開始不在圈內就能逃開 |

【口頭】[▶ 30:45](https://youtu.be/3_gxaB_Pp3k?t=1845) 這說的是很明顯的事——相撞航線上需要更多分離——但很棒的是我們從**第一原理**算出來，而且對每個相對航向都知道確切要多少縱向分離（同時考慮橫向分離）。這也反映出形狀**不對稱**。

【Q&A】[▶ 31:15](https://youtu.be/3_gxaB_Pp3k?t=1875) 學生問：假設速度一樣？答：對，都是 $v$。速度不同的話形狀會變。

**二維切片** [▶ 31:45](https://youtu.be/3_gxaB_Pp3k?t=1905)：固定相對航向 3.7（略大於 $\pi$），畫 $x$-$y$ 投影。深藍 = 負。

【課堂討論】[▶ 33:20](https://youtu.be/3_gxaB_Pp3k?t=2000) 固定縱向分離 5，老師問：B 從負的橫向距離出發比較安全，還是正的？大家投票選對了。老師：「很高興跟你們一起搭飛機。」因為一種情況下 B 要做複雜得多的機動才撞得到你，你有更多空間閃避。所以可達集是**傾斜的**：一邊需要的緩衝少、一邊多（最多約 5）。

**隨時間演化** [▶ 34:20](https://youtu.be/3_gxaB_Pp3k?t=2060)：從 $t=-2.5,-3,-3.5$ 算後向可達集（終端時刻永遠是 0），形狀會變；但約 3.5 單位時間後就**收斂**成常數。原因：大部分平穩問題經過暫態後會進入穩態——要嘛 B 一直追著你，要嘛已經撞了；多給時間不會改變什麼。

**模擬** [▶ 35:23](https://youtu.be/3_gxaB_Pp3k?t=2123)（藍 = 玩家 1，紅 = 玩家 2；雙方都照 HJI 的最佳策略玩）：

1. 從可達集**外面**出發：B 怎麼追都追不到；之後進入穩態。
2. B 一開始就在你的保護空間**裡**：鎖住，一直待在裡面。
3. 有趣的情況 [▶ 36:29](https://youtu.be/3_gxaB_Pp3k?t=2189)：B **短暫**進入你的保護空間，但你機動逃出去，之後 B 再也追不上。照這次的（BRS）表述算**成功**；但實際上中途有一段被侵入，是不理想的——這正是要用 **BRT** 的動機；用 BRT 算的話這會是失敗案例。

【口頭】[▶ 37:30](https://youtu.be/3_gxaB_Pp3k?t=2250) 「很酷吧？而且大家真的在用。」好幾個量產等級的汽車自動駕駛系統，在最低層的安全保障裡都有類似後向可達集的東西：不管旁邊的駕駛做什麼，都保留足夠緩衝讓你閃開。

【Q&A】[▶ 37:30](https://youtu.be/3_gxaB_Pp3k?t=2250) 學生問是否保證收斂？答：這裡算的是 BRS 不是 BRT。一般時變表述會收斂到穩態解。

## 3. 怎麼解：維度詛咒

[▶ 38:33](https://youtu.be/3_gxaB_Pp3k?t=2313) 解 PDE 很難。

- 範例用的是老師實驗室開發的套件，「Python 裡解 HJ 可達性方程最快的套件之一」。

## 4. MPC：兩者兼得

[▶ 40:36](https://youtu.be/3_gxaB_Pp3k?t=2436) 「相比之下，MPC 是公園散步。」而且很直觀，「感覺就是對的控制策略」。

| | 開迴路 | 閉迴路（DP、HJB、HJI） | **MPC** |
|---|---|---|---|
| 計算 | 快 | 複雜 | 接近開迴路 |
| 能力 | 弱（開迴路序列） | 強（閉迴路策略） | 接近閉迴路 |

**模型預測控制**（model predictive control，MPC）是一個**框架**，不是特定演算法。老師說它是 PID 之後最廣泛使用的控制方法。

### 4.1 歷史與動機

[▶ 41:39](https://youtu.be/3_gxaB_Pp3k?t=2499) 70、80 年代主要在**化學工程**當成啟發式方法發展。為什麼是化工？

1. **需要**：要處理**約束**——混合物溫度不能失控，不然整個爆掉。頻域控制很難直接處理約束。
2. **時間尺度慢**：化學過程在好幾秒的尺度演化。MPC 要線上最佳化，當時電腦很慢，但在幾秒內解得完（約 0.5 或 0.1 Hz）。剛好是甜蜜點。

[▶ 43:11](https://youtu.be/3_gxaB_Pp3k?t=2591) 參考書：**Borrelli, Bemporad, Morari** 和 **Rawlings, Mayne, Diehl**。90 年代前 MPC 主要是啟發式；90 年代到 2000 年代，大家開始建立理論，讓 MPC 有數學保證。最近的趨勢：線上解法器大幅進步，把 MPC 推進重新規劃頻率越來越高的控制迴路（10 Hz、30 Hz、kHz……）。

【課本補充】課本 §3.4 同樣介紹這段歷史和這兩本參考書，並說 MPC 也叫**滾動時域控制**（receding horizon control，RHC）。

### 4.2 滾動時域的想法

[▶ 44:15](https://youtu.be/3_gxaB_Pp3k?t=2655)

- 背後真正想解的是**無限時域**最佳控制問題，但最佳地解很貴。願意**次佳**地解，但還是要閉迴路。
- 每個取樣時間 $t$：量測狀態 → 解一個**有限時域**（$t$ 到 $t+N$）的開迴路最佳控制問題 → 得到控制序列和預測的狀態序列。
- **只用第一個控制** [▶ 45:52](https://youtu.be/3_gxaB_Pp3k?t=2752)，系統走到 $t+1$。
- 其他全部丟掉，從新狀態重新解。
- 每一刻解的都是**開迴路**問題；但因為一直重新量測、重新規劃，整體是**閉迴路**。

【口頭】[▶ 47:29](https://youtu.be/3_gxaB_Pp3k?t=2849) 看起來很浪費：第一步之後算的全丟進垃圾桶。不一定——可以拿來幫下一步（例如當初始猜測）；但最基本版本就是丟掉。也有變化：例如控制只最佳化到 $N_m$，但預測多看幾步。MPC 是框架。

【口頭】[▶ 48:00](https://youtu.be/3_gxaB_Pp3k?t=2880) 這也是人類的做法：規劃、走一點、收集資訊、修改計畫。

### 4.3 線性系統的 MPC 表述

[▶ 49:00](https://youtu.be/3_gxaB_Pp3k?t=2940) 調節到原點：

$$x_{t+1}=Ax_t+Bu_t,\qquad x\in\mathcal X,\quad u\in\mathcal U$$

- 很像古典頻域控制，但**有約束**——古典頻域控制做不到。
- $\mathcal X$、$\mathcal U$ 是**多面體**（polyhedra）：由有限多個線性不等式（半平面）定義，例如一個方塊。

**每個時刻 $t$ 解** [▶ 50:35](https://youtu.be/3_gxaB_Pp3k?t=3035)（假設能量測完整狀態 $x_t$）：

$$
\begin{aligned}
J_t^*(x_t)=\min_{u_{t|t},\dots,u_{t+N-1|t}}\quad & p\left(x_{t+N|t}\right)+\sum_{k=0}^{N-1}q\left(x_{t+k|t},u_{t+k|t}\right) \\
\text{s.t.}\quad & x_{t+k+1|t}=Ax_{t+k|t}+Bu_{t+k|t} \\
& x_{t+k|t}\in\mathcal X,\quad u_{t+k|t}\in\mathcal U,\quad k=0,\dots,N-1 \\
& x_{t+N|t}\in\mathcal X_f \\
& x_{t|t}=x_t
\end{aligned}
$$

- $x_{t|t}=x_t$：**初始條件 = 現在的狀態**，這就是閉迴路的方式。
- $x_{t+N|t}\in\mathcal X_f$：**終端約束**（為什麼要加，下面講）。

**記號** [▶ 51:37](https://youtu.be/3_gxaB_Pp3k?t=3097)：

- $x_{t+k|t}$：在時刻 $t$ 預測的、時刻 $t+k$ 的狀態。
- $u_{t+k|t}$：在時刻 $t$ 算的、時刻 $t+k$ 的控制。
- 從時刻 1 預測的「時刻 3 的狀態」，跟從時刻 2 預測的不一定一樣——中間可能有擾動推離標稱軌跡。

**三個調整旋鈕** [▶ 52:42](https://youtu.be/3_gxaB_Pp3k?t=3162)：

| 旋鈕 | 意思 |
|---|---|
| 終端成本 $p(\cdot)$ | 加在預測終點上的輔助成本 |
| 終端約束集 $\mathcal X_f$ | 預測終點必須落在這裡 |
| 時域 $N$ | 往前看幾步 |

接下來兩堂就是講**怎麼調這三個旋鈕**，讓 MPC 部署後表現良好。

【課本補充】課本 §3.4.2 式 (3.52) 是同一個表述（終端成本記為 $h$、階段成本記為 $g$）；課本說 $\mathcal X$、$\mathcal U$ 是**凸**多面體。

### 4.4 閉迴路策略與常用成本

**閉迴路策略** [▶ 55:22](https://youtu.be/3_gxaB_Pp3k?t=3322)：

$$\pi_t(x_t):=u_{t|t}^*(x_t),\qquad x_{t+1}=Ax_t+B\pi_t(x_t)=f_{cl}(x_t)$$

「這是 MPC 的核心」：用「從 $x_t$ 解開迴路問題得到的第一個控制」定義一個閉迴路策略——這就是開迴路和閉迴路之間的橋樑。

**時不變時簡化記號** [▶ 56:24](https://youtu.be/3_gxaB_Pp3k?t=3384)：$A,B$、成本、約束都不隨時間變時，每次規劃只有**初始條件**不同。所以可以丟掉「$|t$」的記號，寫成：

$$J_0^*(x_t)=\min_{u_0,\dots,u_{N-1}}\ p(x_N)+\sum_{k=0}^{N-1}q(x_k,u_k)\quad\text{s.t. 動態、約束、}x_N\in\mathcal X_f,\ x_0=x_t$$

用 $u_0^*$，走到 $x_{t+1}$，再以 $x_0=x_{t+1}$ 解同一個問題。

【Q&A】[▶ 57:26](https://youtu.be/3_gxaB_Pp3k?t=3446) 學生問：時域要夠長才能讓終點落在 $\mathcal X_f$？答：對，不然到不了。最好把 MPC 看成背後要解一個無限時域問題。學生追問：時域短，控制會比較激進？答：會。太短甚至可能無法收斂、無法調節狀態。

**取捨** [▶ 58:34](https://youtu.be/3_gxaB_Pp3k?t=3514)：時域越長，決策越有根據，但計算越貴；越短，可能太**貪心**甚至**短視**，達不成任務。$N$、$p$、$\mathcal X_f$ 要小心調。

**常用成本** [▶ 59:35](https://youtu.be/3_gxaB_Pp3k?t=3575)：

- 二次（類似 LQR）：$q(x,u)=x^\top Qx+u^\top Ru$，$p(x)=x^\top Px$。
- 其他 $p$ 範數：1 範數（各分量**絕對值**的和）、無限範數。

【課本補充】課本 §3.4.2：二次成本配上多面體約束會得到**凸**最佳化問題；$\ell_1$ 懲罰常用在有致動器限制的系統，或要讓控制**稀疏**時。

**線上 MPC 流程** [▶ 60:12](https://youtu.be/3_gxaB_Pp3k?t=3612)：

1. 量測 $x_t$。
2. 解有限時域最佳控制問題。萬一**不可行**——卡住了，求救。
3. 把第一個控制 $u_0^*$ 送進系統。
4. 時間前進到 $t+1$，量測 $x_{t+1}$，重複。

叫「線上」是因為在部署時即時解。下次會簡短提**離線**版本（事先預想所有可能情況做最佳化）。本課大部分講線上版本。

## 5. 兩個關心的性質：持續可行與穩定

[▶ 61:15](https://youtu.be/3_gxaB_Pp3k?t=3675)

| 性質 | 意思 |
|---|---|
| **持續可行**（persistent feasibility） | 走到新狀態後，新的最佳控制問題**仍然可行**。否則就卡住了——不管做什麼都會違反約束（類似可達集為空的情況） |
| **穩定**（stability） | 產生的控制讓軌跡**收斂到原點**（完成調節任務） |

問題：怎麼調三個旋鈕，讓這兩個性質成立？

**兩種做法** [▶ 62:21](https://youtu.be/3_gxaB_Pp3k?t=3741)：

1. 直接分析閉迴路系統 $x_{t+1}=f_{cl}(x_t)$ 如何依旋鈕演化，再調旋鈕。**很難**：$f_{cl}$ 是非線性的，而且裡面包了一個最佳化。大家以前卡在這裡。
2. **直接對 $p$ 和 $\mathcal X_f$ 推條件**，讓閉迴路的可行性和穩定性**由設計保證**，不用逐條分析軌跡。

先處理**持續可行**（連問題都解不了的話，穩定性根本無從談起），再處理穩定。

【課本補充】課本 §3.4.2 舉例說明持續可行：自駕車高速衝向障礙物，MPC 時域太短、煞車太晚，最後進入「怎樣都停不下來」的狀態，之後的控制步都不可行。課本也指出：可行**不保證**穩定——MPC 可能永遠滿足約束卻沒有收斂。課本的核心觀點：終端成本是無限時域尾段的**替身**，終端集讓系統待在行為已知、好處理的區域。課本不深入，轉介 Borrelli 等人的書。

## 6. 不變集理論

[▶ 63:55](https://youtu.be/3_gxaB_Pp3k?t=3835) 工具：**不變集理論**（invariant set theory）。

【口頭】「MPC 數學沒有可達性那麼重，但術語比較無聊。」

### 6.1 可行初始狀態集

[▶ 63:55](https://youtu.be/3_gxaB_Pp3k?t=3835)

$$\mathcal X_0=\left\{x_0\in\mathcal X:\ \exists\,(u_0,\dots,u_{N-1}),\ u_k\in\mathcal U,\ x_k\in\mathcal X,\ x_N\in\mathcal X_f\right\}$$

最佳控制問題**至少有一個解**的初始條件集合。只有當前狀態在 $\mathcal X_0$ 裡，才找得到控制。

### 6.2 一步可控集（Pre 集）

[▶ 65:02](https://youtu.be/3_gxaB_Pp3k?t=3902)

**自主系統** $x_{t+1}=\phi(x_t)$：

$$\mathrm{Pre}(S)=\left\{x:\ \phi(x)\in S\right\}$$

給一個集合 $S$，問：從哪些狀態出發，照系統自然的動態走**一步**就落進 $S$？

**控制系統** $x_{t+1}=f(x_t,u_t)$ [▶ 66:40](https://youtu.be/3_gxaB_Pp3k?t=4000)：

$$\mathrm{Pre}(S)=\left\{x\in\mathcal X:\ \exists\,u\in\mathcal U,\ f(x,u)\in S\right\}$$

**存在**某個 $u$，一步就落進 $S$。

### 6.3 控制不變集

[▶ 67:10](https://youtu.be/3_gxaB_Pp3k?t=4030) MPC 裡到處都會出現的概念。

> 集合 $\mathcal C\subseteq\mathcal X$ 是系統 $x_{t+1}=f(x_t,u_t)$ 的**控制不變集**（control invariant set），如果
> $$x_t\in\mathcal C\ \Rightarrow\ \exists\,u_t\in\mathcal U,\ f(x_t,u_t)\in\mathcal C$$

把 $\mathcal C$ 想成**安全集**（離危險夠遠的相對狀態）：從裡面出發，總有控制能讓你**待在裡面**。當然要選 $\mathcal C$ 是「想要的」狀態。

- **最大控制不變集** $\mathcal C_\infty$ [▶ 68:48](https://youtu.be/3_gxaB_Pp3k?t=4128)：包含所有（包含在 $\mathcal X$ 裡的）控制不變集，也就是最大的那個。
- **正不變集**（positive invariant set）[▶ 69:20](https://youtu.be/3_gxaB_Pp3k?t=4160)：自主系統版本——從 $\mathcal O$ 出發，套用動態後還在 $\mathcal O$。

**計算工具**：MATLAB 的 **MPT**（Multi-Parametric Toolbox）。作業會用到。

【Q&A】[▶ 69:51](https://youtu.be/3_gxaB_Pp3k?t=4191) 學生問：控制不變集怎麼可能不是最大的？舉個例子？答：例如**只含原點的集合** $\{0\}$：線性系統從 $x=0$ 出發，用 $u=0$（假設可行），下一個狀態 $Ax+Bu=0$，還在集合裡。所以 $\{0\}$ 是控制不變集——但顯然可能還有更大的。

### 6.4 第一個結果：持續可行的引理

[▶ 70:54](https://youtu.be/3_gxaB_Pp3k?t=4254) 定義**截斷可行集** $\mathcal X_1$：時域為 $N-1$ 的問題可行的狀態集合，

$$\mathcal X_1=\left\{x_1\in\mathcal X:\ \exists\,(u_1,\dots,u_{N-1}),\ u_k\in\mathcal U,\ x_k\in\mathcal X,\ x_N\in\mathcal X_f\right\}$$

（從 $u_1$ 而不是 $u_0$ 開始。）

> **引理**：如果 $\mathcal X_1$ 是系統的**控制不變集**，那麼 MPC 律是**持續可行**的。

**直覺** [▶ 72:01](https://youtu.be/3_gxaB_Pp3k?t=4321)：$\mathcal X_1$ 控制不變 → 可以用它「買」一步待在集合裡，再解剩下 $N-1$ 步的問題。

**但這個引理本身沒用** [▶ 72:36](https://youtu.be/3_gxaB_Pp3k?t=4356)：我們能調的是 $\mathcal X_f$、$p$、$N$，不是 $\mathcal X_1$。它是一個引理，下次用它推出**可以實際調旋鈕**的定理。下次證明（最多 30 分鐘），然後繼續持續可行和穩定，最後得到「怎麼選 $p$ 和 $\mathcal X_f$ 保證持續可行和穩定」的明確條件。作業會讓你實際體會這個定理。

## 7. 演算法整理

### 用 HJI 算後向可達集（避開型）

**在解什麼**：有對手時，哪些初始狀態「可能被逼進危險集」；以及閃避的最佳控制。

```
1. 寫出危險集 T，找 h 使 T = {x : h(x) ≤ 0}（h 越正越安全）
2. 運行成本 g = 0；終端成本 = h（BRS）或沿途最小值 min_τ h(x(τ))（BRT）
3. 解 HJI：∂J/∂t + max_u min_d ∂J/∂xᵀ f(x,u,d) = 0，J(x,0) = h(x)，往回解到 t
   （到達型改成 min_u max_d）
4. 避開集 = {x : J(x,t) ≤ 0}；從 J > 0 出發才安全
5. 最佳控制 u*(x) = argmax_u min_d [∂J/∂xᵀ f]
```

**什麼時候會失敗**：狀態超過五、六維 → 格點解不了（維度詛咒），要用近似；只用 BRS 時中途可能被侵入（要改用 BRT）；不用最佳控制的話，從安全區出發也可能被推進危險區；對手模型太悲觀 → 集合太大、太保守，甚至沒有安全的地方。

### 線上 MPC

**在解什麼**：有狀態、控制約束的調節（或追蹤）問題，要閉迴路行為但只能負擔開迴路的計算量。

```
每個取樣時間 t：
1. 量測 x_t
2. 解有限時域問題（初始 x₀ = x_t；動態、約束、終端約束 x_N ∈ X_f；成本 p(x_N) + Σ q）
3. 不可行 → 求救（安全備案）
4. 送出 u₀*；丟掉其餘
5. t ← t + 1
```

**什麼時候會失敗**：時域太短 → 短視，可能走進之後不可行的狀態（例：煞車太晚）；可行不代表穩定；線上解太慢 → 跟不上控制頻率；$N$、$p$、$\mathcal X_f$ 沒設計好就沒有保證（下一集）。

## 8. 一頁速查表

### 可達性

| 項目 | 式子／重點 |
|---|---|
| 水平集 | $x\in\mathcal T\iff h(x)\le 0$；例：$h=\sqrt{x^2+y^2}-R$ |
| BRS 成本 | $h(x(0))$，$g=0$ |
| BRT 成本 | $\min_{\tau\in[t,0]}h(x(\tau))$（整條軌跡） |
| 避開 | $\max_u\min_d$；安全 ⟺ $J>0$ |
| 到達 | $\min_u\max_d$ |
| 實作 | hj_reachability（Python）；約 5–6 維以內 |
| 飛機例子 | 相向時需要更多分離；形狀不對稱；約 3.5 時間單位後收斂 |

### MPC

$$\min_{u_0..u_{N-1}}\ p(x_N)+\sum_{k=0}^{N-1}q(x_k,u_k)\ \ \text{s.t.}\ x_{k+1}=Ax_k+Bu_k,\ x_k\in\mathcal X,\ u_k\in\mathcal U,\ x_N\in\mathcal X_f,\ x_0=x_t$$

| 項目 | 重點 |
|---|---|
| 策略 | $\pi(x_t)=u_0^*(x_t)$，只用第一步 |
| 記號 | $x_{t+k|t}$：時刻 $t$ 預測的 $t+k$ 狀態 |
| 旋鈕 | $p$、$\mathcal X_f$、$N$ |
| 想要 | 持續可行、穩定 |

### 不變集

| 名稱 | 定義 |
|---|---|
| 可行集 $\mathcal X_0$ | 問題有解的初始狀態 |
| $\mathrm{Pre}(S)$ | $\{x:\exists u\in\mathcal U,\ f(x,u)\in S\}$ |
| 控制不變 $\mathcal C$ | $x\in\mathcal C\Rightarrow\exists u,\ f(x,u)\in\mathcal C$ |
| 最大控制不變 $\mathcal C_\infty$ | 包含所有控制不變集 |
| 正不變 $\mathcal O$ | 自主系統：$x\in\mathcal O\Rightarrow\phi(x)\in\mathcal O$ |
| 引理 | $\mathcal X_1$ 控制不變 ⟹ MPC 持續可行 |

## 附：本集一句話總結

> **把「屬於集合」寫成終端成本 $h\le 0$、拿掉運行成本，就能用 HJI 算後向可達集（只看終點）或可達管（整條軌跡取 $\min h$），得到「哪些初始狀態保證安全」和閃避策略，但只能到五、六維。MPC 則每一步都從量到的狀態解一個有限時域開迴路問題、只執行第一步，以開迴路的計算量得到閉迴路行為；要讓它持續可行又穩定，就得設計終端成本 $p$、終端集 $\mathcal X_f$ 和時域 $N$——工具是控制不變集。**
