## 1. 行為複製的兩個陷阱

[▶ 03:13](https://youtu.be/udHX5Auj7ik?t=193) BC 的骨架看起來就是「把監督式學習用在行為上」。這樣就好了嗎？大多數時候**不行**。

### 1.1 誤差累積與共變量偏移

[▶ 04:49](https://youtu.be/udHX5Auj7ik?t=289) 統計學習理論假設資料 **i.i.d.**：從要近似的分布 $p(x)$ 獨立抽樣。學**行為**時，預測的控制會**影響未來觀察到的狀態**；策略就算只犯很小的錯，也會沿著軌跡**累積**，越錯越大。

**正式說法：共變量偏移**（covariate shift）[▶ 06:24](https://youtu.be/udHX5Auj7ik?t=384)：專家策略誘導的狀態分布和學習者策略誘導的狀態分布**不一樣**：

$$p_{\text{expert}}(x)\ne p_{\pi_\theta}(x)$$

其中（講者寫的軌跡分布形式）

$$p_{\text{expert}}(\tau)=p(x_0)\prod_{t=1}^{T}\pi_{\text{expert}}(u_t\mid x_t)\,p(x_{t+1}\mid x_t,u_t)$$

$p_{\pi_\theta}$ 同樣定義，只是把專家策略換成正在學的策略。

**理論結果** [▶ 08:13](https://youtu.be/udHX5Auj7ik?t=493)：假設策略每步犯錯的機率是 $\varepsilon$（離散世界，從 $n$ 個動作選一個），那麼犯錯的期望次數隨軌跡長度 $T$ **平方成長**：

$$\mathbb E[\text{錯誤數}]=O\left(\varepsilon T^2\right)$$

講者推薦投影片上的參考文獻（理論細節很多）。

> 參考文獻名稱字幕沒唸。這個 $O(\varepsilon T^2)$ 結果一般出自 Ross & Bagnell（2010）以及 Ross、Gordon、Bagnell（2011，DAgger 論文，課本參考文獻也有引用），待確認。

【Q&A】[▶ 08:47](https://youtu.be/udHX5Auj7ik?t=527) 學生問：軌跡本身是獨立的？資料長什麼樣？答：軌跡之間是獨立的。這堂課假設要學的是**回饋策略**：從**瞬間**狀態 $x_t$ 映射到瞬間控制 $u_t$；資料集就是這些 $(x_t,u_t)$ 配對的集合。

### 1.2 多模態行為

[▶ 09:56](https://youtu.be/udHX5Auj7ik?t=596) 很多任務有**多個等價的解**。

**例子**：遙控無人機飛過一棵樹——從左邊或右邊繞過去差不多一樣好。

**問題** [▶ 10:28](https://youtu.be/udHX5Auj7ik?t=628)：要學的策略其實是**多模態**（例如雙峰）的分布 $\pi(u\mid x)$。如果用標準的**均方誤差**擬合（例如神經網路 + MSE），策略會學到**預測分布的平均值**——兩個峰的正中間。

【口頭】[▶ 12:01](https://youtu.be/udHX5Auj7ik?t=721) 這大概是**最糟**的結果：正好撞上樹（它在兩個峰之間取折衷）。實務上很常見，例如資料來自**多個專家**，同樣情況下各自做法不同。

**解法的心智模型** [▶ 12:31](https://youtu.be/udHX5Auj7ik?t=751)：

| 解法 | 對付 |
|---|---|
| 針對性的**演算法**（DAgger） | 誤差累積 |
| **資料收集**（擴增） | 誤差累積 |
| 表達力更強的**模型** | 多模態 |

## 2. 解法一：演算法——DAgger

### 2.1 修正資料的價值

[▶ 13:34](https://youtu.be/udHX5Auj7ik?t=814) 直覺是：資料品質越好越好，所以要收集**超級好**的示範。問題是這樣的資料集會**非常窄**，集中在某一種解法附近。

**反直覺的事實** [▶ 15:04](https://youtu.be/udHX5Auj7ik?t=904)：

- 部署時策略**一定會犯錯**。
- 如果資料完美、沒有任何錯誤，策略在犯錯後的狀態**完全不知道怎麼恢復**。
- 所以：一組**較廣**、有犯錯**也示範怎麼修正**的軌跡，通常比一組窄而完美的示範**更有價值**。

### 2.2 DAgger 演算法

[▶ 15:34](https://youtu.be/udHX5Auj7ik?t=934) **DAgger**（Dataset Aggregation，資料聚合）：自動標註、收集修正資料，對付共變量偏移。

```
輸入：初始專家示範資料集 D；初始策略 π_θ¹（例如在 D 上 BC 訓練）
for i = 1 … n：
    1. 讓目前的學習者策略 π_θⁱ 跟環境互動，收集軌跡（造訪到的狀態 x_t）
    2. 在這些狀態 x_t 上「詢問專家」：把學習者做的控制，換成專家會做的控制 u_t*
       → 得到新資料集 Dⁱ = {(x_t, u_t*)}
    3. 聚合：D ← D ∪ Dⁱ
    4. 在聚合後的 D 上訓練新策略 π_θⁱ⁺¹
```

（上標 $i$ 是 DAgger 的第幾次迭代。）

**為什麼有用** [▶ 19:16](https://youtu.be/udHX5Auj7ik?t=1156)：直接在**學習者自己會造訪的狀態**上請專家標註。共變量偏移是「學習者的狀態分布 ≠ 專家的」——DAgger 正是在從**學習者分布**抽出的狀態上詢問專家。

【Q&A】[▶ 19:49](https://youtu.be/udHX5Auj7ik?t=1189) 學生問：是重新標註後拿新專家訓練，還是用原來的專家？答：假設有一個**可以隨時詢問**的專家——任何你認為夠好的策略都可以——用它產生新的標註資料。

【Q&A】[▶ 20:21](https://youtu.be/udHX5Auj7ik?t=1221) 學生問：專家是人類時，是不是要一個狀態一個狀態地停下來給離散的輸入？答：好問題，這是 DAgger 的基本版（v0）。有延伸版叫**人類閘控 DAgger**（human-gated DAgger）：人看著機械手臂做事，看到它出錯（例如打翻東西）就接手，從那裡遙控產生一整段新的延續軌跡。學生追問：這樣犯錯之後可以探索不同的部分？答：對。而且這只是一次迭代；重複之後新策略 $\pi^2$ 有不同的狀態分布，會涵蓋新的狀態。

**高層總結** [▶ 22:22](https://youtu.be/udHX5Auj7ik?t=1342)：

- DAgger = 拿現有策略去跟環境互動，**暴露失敗模式**，修正它們；之後可能出現或觀察到新的失敗模式，繼續迭代。
- 是一種**迭代式監督學習**：內迴圈是監督式學習，外面是「在不斷演化的策略造訪的狀態上詢問專家」。
- **資料效率高**：只在策略實際失敗的狀態上請專家修正。另一個極端是在策略可能遇到的**所有**狀態上都標註——極貴。
- 但**詢問專家**本身通常很貴，看任務決定可不可行。

### 2.3 DAgger 的變體

[▶ 24:26](https://youtu.be/udHX5Auj7ik?t=1466)

| 變體 | 做法 |
|---|---|
| **基於信心** | 不是在所有造訪狀態都詢問；用學習者自己的**不確定性**指標，只在它特別不確定的狀態詢問 |
| **人類閘控** | 人監督學習者運作，出錯時直接介入 |

【Q&A】[▶ 24:56](https://youtu.be/udHX5Auj7ik?t=1496) 學生問：既然已經有專家策略，這是不是為了得到一個線上跑得更快的輕量策略？答：可能是其中一種用途。雖然越來越走向學習型、端到端架構，但為它們取得可靠資料，即使在前沿模型中，通常還是依賴比較**古典**的方法產生標註。所以可以把它看成：把一個極貴的（例如間接法）最佳控制器**蒸餾**成一個能近似它的快速神經網路。

## 3. 解法二：資料收集與擴增

[▶ 26:32](https://youtu.be/udHX5Auj7ik?t=1592) 兩個案例。

**案例 1：NVIDIA 自駕（約 2016）** [▶ 26:32](https://youtu.be/udHX5Auj7ik?t=1592)

- 學一個神經網路，從車上攝影機影像決定**方向盤角度**。
- 一開始明顯不行（還有點危險）；收集越來越多人類駕駛的「影像 + 方向盤角度」示範後，表現相當驚人（以當時來說）。
- **關鍵技巧** [▶ 28:43](https://youtu.be/udHX5Auj7ik?t=1723)：三台攝影機（中、左、右），但只記錄一個方向盤角度（人實際做的）。
  - **側邊攝影機**可以當成「車子稍微偏離車道中央」的例子。
  - 把側邊影像當成前方影像，**手動調整**方向盤角度（往回修正到車道中央），**虛擬地擴增**資料集。
  - 為什麼重要：故意收集「開出路外再開回來」的修正資料既**危險**又**昂貴**。

> 講者沒說論文名，一般認為是 NVIDIA 的 *End to End Learning for Self-Driving Cars*（Bojarski 等，2016），待確認。

**案例 2：蘇黎世大學的無人機** [▶ 30:19](https://youtu.be/udHX5Auj7ik?t=1819)

- 用前方攝影機影像控制四旋翼沿**登山步道**飛（瑞士山區），輸出**離散**動作分布：直走、左轉、右轉。
- 研究人員戴著裝了**三台 GoPro** 的頭帶，實際走在步道上收集資料，用同樣的擴增方式標註：

| 攝影機 | 標籤 |
|---|---|
| 正前方 | 直走 |
| 左邊 | 右轉 |
| 右邊 | 左轉 |

- 當時相當可靠地沿步道飛行。

**重點** [▶ 31:59](https://youtu.be/udHX5Auj7ik?t=1919)：從資料角度對付共變量偏移，就是**有意地**收集資料——**故意加入錯誤和對錯誤的修正**。可以像這兩例用擴增產生假的修正示範，或像 DAgger 用演算法自動收集修正資料。

【Q&A】[▶ 33:04](https://youtu.be/udHX5Auj7ik?t=1984) 學生問：用人走路的資料訓練無人機，能不能讓無人機的決策不受人類動態限制？（例如人不能突然往上飛兩英尺，但無人機可以，那可能是更好的閃樹方式。）答：從**模仿學習**的角度，一般**不行**。IL 就是要模仿專家，不會超越專家能做的，也通常拿不到超出專家經驗的資料。這比較是 **RL** 的領域：不是近似專家行為，而是跟環境（例如模擬器）互動、試驗不同策略。

## 4. 解法三：表達力更強的模型

[▶ 35:07](https://youtu.be/udHX5Auj7ik?t=2107) 兩類：加入觀測歷史；用表達力強的函數類別捕捉資料的多模態。

### 4.1 加入觀測歷史

[▶ 35:39](https://youtu.be/udHX5Auj7ik?t=2139)

- MDP 理論假設狀態完美、包含所有歷史資訊。實際上（尤其用影像時）拿到的是**觀測**——系統的**部分**資訊。
- 所以有時把策略從 $\pi(u_t\mid x_t)$ 改成依賴一串過去的觀測：
$$\pi\left(u_t\mid x_{t-H},\dots,x_t\right)$$

**在 BC 特別相關** [▶ 36:41](https://youtu.be/udHX5Auj7ik?t=2201)：只用瞬間觀測，等於假設人類示範者「給定同樣的觀測就一定做同樣的事」。歷史可以當成區分不同情況的因素。

- 例：$x$ 只是前方攝影機的一張快照 → 完全不知道車速等決策需要的資訊。有一段影像歷史就能捕捉更多。

**實作** [▶ 38:13](https://youtu.be/udHX5Auj7ik?t=2293)：用你喜歡的**序列模型**（Transformer、RNN……），輸入一串狀態／觀測，輸出下一個動作。

【口頭】講者的經驗：要不要加歷史、加多長，通常很**經驗性**——做消融實驗（ablation），用同樣資料、不同歷史長度訓練，看哪個最好。

### 4.2 離散 vs 連續分布

[▶ 39:15](https://youtu.be/udHX5Auj7ik?t=2355) 目標不是擬合平均，而是**表示整個分布**。用神經網路輸出分布的**參數**：

| | 離散（類別分布） | 連續（例如高斯） |
|---|---|---|
| 網路輸出 | 每個離散動作的 logit／機率（例如上下左右） | 均值和標準差（例如方向盤角度） |
| 多模態 | **天然能處理**：把連續動作分成很多格（bin），每格一個機率 | **表達力不夠**：用單峰高斯擬合雙峰分布，會得到一個中間寬寬的高斯 |
| 訓練 | 交叉熵，很標準 | 最大概似 |
| 缺點 | 格子數隨動作**維度**爆炸 | 不能表示多峰 |

【Q&A】[▶ 42:55](https://youtu.be/udHX5Auj7ik?t=2575) 學生問：連續分布在高維也不好擴展嗎？答：看分布。$n$ 維高斯只要均值向量和共變異數矩陣，比 $n$ 維格子便宜很多。

【Q&A】[▶ 43:27](https://youtu.be/udHX5Auj7ik?t=2607) 學生問：能不能多加幾個高斯來處理多峰？答：對，正好接下一頁。

### 4.3 高斯混合模型

[▶ 43:58](https://youtu.be/udHX5Auj7ik?t=2638) **高斯混合模型**（Gaussian mixture model，GMM）：學 $K$ 個高斯的參數和權重：

$$\pi(u\mid x)=\sum_{k=1}^{K}w_k(x)\,\mathcal N\left(u;\ \mu_k(x),\Sigma_k(x)\right),\qquad\sum_kw_k=1$$

- 很強：透過組合高斯可以近似很複雜的分布（例如三個高斯組出非單峰的分布）。
- **$K$ 是超參數**，要事先選 [▶ 45:32](https://youtu.be/udHX5Auj7ik?t=2732)：通常很經驗性（試不同 $K$）；取捨是過擬合 vs 欠擬合；或用領域知識（知道策略有三種模式就選 3）。

> 上式的寫法（權重依賴 $x$）是依講者描述寫出的標準形式。

### 4.4 離散化＋自迴歸

[▶ 46:02](https://youtu.be/udHX5Auj7ik?t=2762) 離散化能表示多峰，但高維很貴。

**問題** [▶ 46:32](https://youtu.be/udHX5Auj7ik?t=2792)：二維分布離散化 = 在二維空間畫格子、每格估一個值。

- 參數量爆炸。
- 也有**維度詛咒**：只能從樣本估分布，要填滿所有格子需要指數多的樣本。

**技巧：自迴歸分解** [▶ 47:37](https://youtu.be/udHX5Auj7ik?t=2857)：

$$p(x_1,x_2)=p(x_1)\,p(x_2\mid x_1)$$

- 這是**精確**的改寫，沒有損失。
- 只要學兩個**一維**離散化：$p(x_1)$ 和 $p(x_2\mid x_1)$。
- 參數更少；同樣四個樣本在一維格子裡也**密**得多。

**Transformer 機器人策略就是這樣做** [▶ 49:46](https://youtu.be/udHX5Auj7ik?t=2986)：

- 像 LLM：給一串 token，預測下一個 token，再把預測放回去預測再下一個（自迴歸）。
- 這裡 token 換成**動作的某一維**。例：$u=(\text{方向盤角度},\ \text{加速度})$ → 先預測方向盤角度，再把它餵回模型預測加速度。
- 上下文可以是攝影機影像、描述任務的自然語言提示。

【Q&A】[▶ 51:54](https://youtu.be/udHX5Auj7ik?t=3114) 學生問：維度很多時還是要把每一維跟其他維的關係都弄懂嗎？答：維度上不會爆炸；取捨是**計算**：不是一次全部取樣，而是自迴歸取樣——$n$ 維向量要呼叫模型 $n$ 次。

### 4.5 擴散模型與流匹配

[▶ 52:29](https://youtu.be/udHX5Auj7ik?t=3149) 這幾年非常流行。

**想法**：想從一個複雜的分布取樣，但不知道怎麼取樣；卻知道怎麼從簡單分布（例如高斯）取樣。把簡單分布的樣本**轉換**成目標分布的樣本。

**擴散模型**（diffusion model）[▶ 53:32](https://youtu.be/udHX5Auj7ik?t=3212)：

- 原本用於**影像生成**；講者說現在幾乎所有影像生成都用某種擴散或流匹配模型。
- **取樣**：從純雜訊出發，給定條件（例如「生成一隻貓的圖」），用學到的轉換**逐步去雜訊**，得到影像。
- **訓練**（難的方向）[▶ 54:32](https://youtu.be/udHX5Auj7ik?t=3272)：學**單步去雜訊**。
  - 前向：從資料 $x_0$ 出發，一步步加雜訊：$x_1=x_0+\text{雜訊}$，$x_2=x_1+\text{雜訊}$，……直到純雜訊。
  - 用參數化映射 $f_\theta$ 近似加進去的雜訊項 $\varepsilon$，就能反過來走。

【口頭】講者承認這是很粗略的描述，可以提供參考資料。

**流匹配**（flow matching）[▶ 56:06](https://youtu.be/udHX5Auj7ik?t=3366)：擴散學雜訊項；流匹配學一個**向量場**來做迭代去雜訊——一個「統計運輸」問題：把簡單雜訊分布的樣本搬到複雜分布。

**推論** [▶ 56:39](https://youtu.be/udHX5Auj7ik?t=3399)：假設已學到向量場 $v_\theta$。從雜訊分布抽 $x_0$，沿向量場**往前積分**（例如 Euler）得到目標分布的樣本：

$$x_{t+\Delta t}=x_t+\Delta t\,v_\theta(x_t,t),\qquad t:0\to 1$$

**訓練** [▶ 57:11](https://youtu.be/udHX5Auj7ik?t=3431)：

```
重複：
    抽 x₀ ~ 簡單分布（例如高斯）
    抽 x₁ ~ 資料集（目標分布）
    抽 t ~ Uniform(0, 1)
    線性內插：x_t = (1 − t) x₀ + t x₁   （從樣本到目標樣本畫一條直線）
    目標速度 = x₁ − x₀
    更新 θ 最小化 ‖ v_θ(x_t, t) − (x₁ − x₀) ‖²
```

> 內插和損失的具體式子是依講者描述（「線性內插」「最小化預測速度和目標速度 $x_1-x_0$ 的距離」）寫出的標準形式。

圖像 [▶ 58:49](https://youtu.be/udHX5Auj7ik?t=3529)：左邊簡單分布、右邊複雜分布；學一個向量場引導每個點；取樣時沿它積分。

【口頭】[▶ 59:21](https://youtu.be/udHX5Auj7ik?t=3561) 流匹配現在很紅，因為非常擅長表示**連續**分布——機器人控制最終在乎的正是這個。

### 4.6 動作分塊

[▶ 59:53](https://youtu.be/udHX5Auj7ik?t=3593) 到目前為止都是回饋策略：觀察 $x_t$ → 從 $\pi$ 抽一個動作 → 執行 → 觀察新狀態 → ……（每個時間步一個動作）。

**動作分塊**（action chunking）[▶ 60:56](https://youtu.be/udHX5Auj7ik?t=3656)：一次預測未來 $k$ 步的動作，然後執行這 $k$ 個。講者說這大概是目前機器人學習策略**最流行**的參數化方式。有點像 MPC（預測未來 $k$ 個動作）。

$$\pi\left(u_t,u_{t+1},\dots,u_{t+k-1}\mid x_t\right)$$

**為什麼流行** [▶ 61:30](https://youtu.be/udHX5Auj7ik?t=3690)：

1. **效果好**，所以大家就採用了。
2. **推論時間更充裕**：預先算好未來 $k$ 步，接下來 $k$ 步信任預測，之後才重算。
3. **控制更平滑**：學到的策略不完美，每步呼叫都會引入一點隨機性，訊號有點**抖動**；一次預測整段時，段內的生成彼此比較**一致** → 更平滑 → 部署時表現更好。

### 4.7 例子：Diffusion Policy、RT 系列

[▶ 63:04](https://youtu.be/udHX5Auj7ik?t=3784)

- **Diffusion Policy**（約三四年前）：最早大規模使用擴散模型的例子之一。從影像觀測，用擴散模型生成機械手臂的**整段軌跡**（也用了動作分塊）。能做極具挑戰的任務、跨條件泛化。
- **Robotics Transformer（RT）系列** [▶ 64:09](https://youtu.be/udHX5Auj7ik?t=3849)：Transformer 從**一段影像歷史**和**任務的語言描述**，映射到**離散化**的動作表示，用離散化 + 自迴歸逐維生成（每一維條件在前一維上）。

## 5. 行為複製的優缺點

[▶ 65:48](https://youtu.be/udHX5Auj7ik?t=3948)

| 優點 | 缺點 |
|---|---|
| 核心就是監督式學習：容易實作和監控，有好的指標，梯度下降通常表現良好 | **強烈依賴示範品質**：示範不好，策略不可能好 |
| **有效率**：不需要試誤學習（RL 才需要） | 誤差累積：上面的策略能緩解，但問題還在；學到的策略**泛化**是大課題 |
| **不需要明確的獎勵**：有時定義獎勵比學策略還難（例：怎麼用數字量化「好的駕駛」？模仿駕駛示範反而容易得多） | **完全沒有探索**：無法發現專家沒示範過的新解 → 這是 RL 的切入點 |

## 6. 用監督式學習逼近 RL 目標

[▶ 67:51](https://youtu.be/udHX5Auj7ik?t=4071) 能不能用 BC 的想法去逼近 RL 的目標？也就是過濾資料、盡量接近資料中最好的表現，甚至超越？

想法：不只依賴最佳示範，而是利用**更廣**的示範（次佳策略、相關任務……），稍微改變學習問題，從資料中榨出最好的部分。兩類：

**1. 過濾或加權示範** [▶ 69:24](https://youtu.be/udHX5Auj7ik?t=4164)：把獎勵函數**重新引入**：

| 做法 | 式子 |
|---|---|
| **過濾** | 對每條軌跡加總獎勵 $R(\tau)=\sum_tr(x_t,u_t)$，只保留 $R(\tau)>\bar r$ 的，再做 BC |
| **加權** | 加權最大概似：$\max_\theta\sum_\tau w(\tau)\sum_t\log\pi_\theta(u_t\mid x_t)$，權重 $w$ 來自表現 |

> 加權目標的式子是依講者描述（「不要盲目最大化所有軌跡的機率，而是最大化以表現加權的機率」）寫出的。

【Q&A】[▶ 71:26](https://youtu.be/udHX5Auj7ik?t=4286) 學生問：這種「過濾出最好的軌跡」跟前面說「故意加入次佳的修正資料」怎麼區分？答：很依案例。過濾特別適合：任務很**窄**、不需要收集修正行為，只想利用那些很好的軌跡；或資料集很廣、裡面有極差的軌跡，而且資料量大到沒辦法人工標註哪些有用，就設計簡單規則濾掉壞的。兩者算是平行的設計軸。

**2. 改變策略的條件** [▶ 72:59](https://youtu.be/udHX5Auj7ik?t=4379)：

| 做法 | 策略 |
|---|---|
| **目標條件**（goal-conditioned） | $\pi(u\mid x,g)$：條件在想到達的目標狀態 $g$ 上 |
| **獎勵條件**（reward-conditioned） | $\pi(u\mid x,R)$：條件在想要的總獎勵上 |

**為什麼目標條件有用** [▶ 73:29](https://youtu.be/udHX5Auj7ik?t=4409)：

- 一條從 $x_1$ 走到 $x_T$ 的軌跡，如果任務的目標是別的地方，對任務來說它很**爛**。
- 但它是「**如何到達 $x_i$**」的好示範（$x_i$ 是軌跡上任何一點）。
- 如果目標是「到達某個狀態」，**每條軌跡都是有效的**——它示範了如何到達軌跡上所有的狀態。
- 學到「到達任意目標」的通用策略後，測試時把條件設成**對你有利的狀態**即可。

（獎勵條件同理。）

## 7. 逆強化學習

[▶ 75:34](https://youtu.be/udHX5Auj7ik?t=4534) 簡短提一下，主要給指引。

- BC：近似專家的**策略**。IRL：學專家在最佳化的**目標**——恢復我們認為專家在最佳化的獎勵函數。
- 通常把獎勵參數化為 $r_w(x,u)$，找最能**解釋**專家示範的 $w$。

> ⚠️ 逐字稿缺字 [▶ 75:34](https://youtu.be/udHX5Auj7ik?t=4534)：字幕寫「the goal of **reinforcement learning** is to recover the reward function」，依上下文應為「**inverse** reinforcement learning」。

**骨架** [▶ 76:04](https://youtu.be/udHX5Auj7ik?t=4564)：大部分 IRL 演算法都交替兩個步驟：

```
輸入：專家示範資料集 D；初始化獎勵參數 w、策略參數 θ
重複：
    1. 依某個目標更新獎勵參數 w
    2. 用新的 w，最佳化策略 θ（最大化 r_w 的預期獎勵）
    （再用這個策略去改進 w 的估計……）
```

**常見演算法** [▶ 77:07](https://youtu.be/udHX5Auj7ik?t=4627)：

- 學徒學習（apprenticeship learning）
- 最大邊界規劃（maximum margin planning）
- 最大熵 IRL（maximum entropy IRL）

**核心挑戰：獎勵模糊性**（reward ambiguity）[▶ 77:38](https://youtu.be/udHX5Auj7ik?t=4658)：**很多不同的獎勵函數都能解釋同一份資料**。上面這些演算法都在設計那兩個步驟，避免落入獎勵模糊。

> 以下**不是逐字稿內容**：一個極端例子是 $r\equiv 0$——任何行為在它之下都是最佳的，所以它「解釋」了任何示範。

**總結** [▶ 78:14](https://youtu.be/udHX5Auj7ik?t=4694)：BC 的 v0 版本有兩大挑戰（誤差累積、多模態）；從資料收集（擴增）、演算法（DAgger）、表達力強的模型三方面解決；另外簡短提到用監督式學習做 RL、以及逆 RL。

## 8. 演算法整理

### 行為複製

**在解什麼**：有專家 $(x,u)$ 示範，學一個模仿專家的策略。

```
1. 收集 D = {(x_i, u_i)}（盡量包含錯誤和修正；可用多攝影機擴增）
2. 選分布類別：多模態時用 GMM、離散化 + 自迴歸、擴散／流匹配；
   部分可觀測時加觀測歷史；可輸出動作分塊
3. 最大概似 / 交叉熵訓練 π_θ
```

**什麼時候會失敗**：共變量偏移（誤差 $O(\varepsilon T^2)$ 累積）；用 MSE 擬合多模態資料 → 平均到兩峰中間（撞樹）；示範太窄太完美 → 不會恢復；示範品質差；無法超越專家、無法探索。

### DAgger

**在解什麼**：BC 的共變量偏移；有可隨時詢問的專家。

```
D ← 專家示範；π ← BC(D)
重複：
    用 π 互動，收集造訪狀態 {x_t}
    請專家標註 u_t* = π_expert(x_t)
    D ← D ∪ {(x_t, u_t*)}
    π ← BC(D)
```

**什麼時候會失敗**：詢問專家太貴（人類專家很難逐狀態標註 → 用人類閘控或基於信心的變體）；專家本身不好。

### 流匹配策略

**在解什麼**：表示連續、多模態的動作分布。

```
訓練：抽 x₀~N(0,I)、x₁~資料、t~U(0,1)；x_t=(1−t)x₀+t x₁；最小化 ‖v_θ(x_t,t)−(x₁−x₀)‖²
推論：x₀~N(0,I)；沿 v_θ 用 Euler 從 t=0 積到 1
```

（實際的機器人策略還會把觀測 $x$ 當條件。）

**什麼時候會失敗**：推論要積分多步，比單次前向傳遞慢。

### 逆強化學習

**在解什麼**：從示範恢復獎勵，希望更能泛化。

```
交替：更新獎勵參數 w ↔ 在 r_w 下最佳化策略 θ
```

**什麼時候會失敗**：獎勵模糊（很多獎勵都解釋同一份資料）；每輪內迴圈都要解一個 RL／最佳控制問題，很貴。

## 9. 一頁速查表

### 兩個陷阱

| 陷阱 | 原因 | 解法 |
|---|---|---|
| 誤差累積／共變量偏移 | $p_{\text{expert}}(x)\ne p_{\pi_\theta}(x)$；錯誤 $O(\varepsilon T^2)$ | DAgger；故意收集錯誤＋修正；資料擴增（側邊攝影機） |
| 多模態 | MSE 學到分布的平均 | 觀測歷史；GMM；離散化＋自迴歸；擴散／流匹配 |

### 分布表示

| 方法 | 多模態 | 高維 | 代價 |
|---|---|---|---|
| 單一高斯 | ✗ | ✓ | — |
| 離散格子 | ✓ | ✗（格子爆炸） | 交叉熵 |
| GMM | ✓（$K$ 個峰） | ✓ | $K$ 是超參數 |
| 離散＋自迴歸 | ✓ | ✓ | $n$ 維要呼叫 $n$ 次 |
| 擴散／流匹配 | ✓ | ✓ | 推論要多步積分 |

- 自迴歸：$p(x_1,x_2)=p(x_1)p(x_2\mid x_1)$（精確）。
- 流匹配：$x_t=(1-t)x_0+tx_1$，目標速度 $x_1-x_0$。
- 動作分塊：一次預測 $k$ 步 → 推論時間充裕、控制平滑。

### 其他

- 修正資料的悖論：廣而有錯（含修正）> 窄而完美。
- BC 做 RL：過濾（$R(\tau)>\bar r$）、加權最大概似、目標條件 $\pi(u\mid x,g)$、獎勵條件。
- IRL：交替更新 $w$ 和 $\theta$；挑戰是獎勵模糊；學徒學習、最大邊界規劃、最大熵 IRL。
