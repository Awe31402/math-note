## 1. 循環子群

### 1.1 定義（以及老師的一個錯）

[▶ 00:00](https://youtu.be/rh1OBkyz3Rw?t=0)

> **定義（$a$ 生成的循環子群 cyclic subgroup generated by $a$）**　$G$ 是群，$a\in G$。
> - 乘法群：$\langle a\rangle = \{a^n : n\in\mathbb{Z}\}$。
> - 加法群：$\langle a\rangle = \{na : n\in\mathbb{Z}\}$。

**老師一開始寫錯了**：他先寫成 $\langle a\rangle = \{e,a,a^2,a^3,\dots\}$（只有非負次方）。證明寫到一半 [▶ 05:07](https://youtu.be/rh1OBkyz3Rw?t=307)，學生指出問題。

【口頭】[▶ 05:37](https://youtu.be/rh1OBkyz3Rw?t=337)「我離講義太遠就出事了。我是白痴。這個定義在某些例子裡會對，但在其他例子裡完全錯。」正確的定義要**包含負次方**，$n$ 跑遍所有**整數**。

（為什麼「某些例子會對」：在有限群裡，$a^n = e$ 對某個 $n$ 成立，於是 $a^{-1} = a^{n-1}$ 本來就在非負次方裡。在無限群裡就不行，例如 $\mathbb{Z}$ 裡 $\{0,1,2,\dots\}$ 沒有 $-1$。）

### 1.2 定理：循環子群是子群

[▶ 01:30](https://youtu.be/rh1OBkyz3Rw?t=90)

> **定理**　$G$ 是群，$a\in G$。則 $\langle a\rangle\le G$。

**證明**（乘法記號，兩步子群判別法）[▶ 02:01](https://youtu.be/rh1OBkyz3Rw?t=121)

1. **非空、是子集**：$e = a^0\in\langle a\rangle$，所以非空。$a$ 的次方都在 $G$ 裡（群對乘法和反元素封閉），所以 $\langle a\rangle\subseteq G$ [▶ 02:31](https://youtu.be/rh1OBkyz3Rw?t=151)。
2. **乘法封閉**[▶ 03:32](https://youtu.be/rh1OBkyz3Rw?t=212)：設 $a^j,a^k\in\langle a\rangle$，$j,k\in\mathbb{Z}$。
$$a^ja^k = a^{j+k}.$$
   $j+k\in\mathbb{Z}$，所以 $a^{j+k}\in\langle a\rangle$。（$a^ja^k = a^{j+k}$ 是指數律，「可以用歸納法證」。）
3. **反元素封閉**[▶ 06:38](https://youtu.be/rh1OBkyz3Rw?t=398)：設 $a^j\in\langle a\rangle$。$-j\in\mathbb{Z}$，所以
$$(a^j)^{-1} = a^{-j}\in\langle a\rangle.$$
   【口頭】「這一步就是定義要包含負次方的地方，這裡才是『任務關鍵』。」

由兩步子群判別法，$\langle a\rangle\le G$。$\blacksquare$

【口頭】[▶ 07:40](https://youtu.be/rh1OBkyz3Rw?t=460)「這是目前看過最重要的子群例子。我們會花好幾天講循環群。」Gallian 在 p.63 上面有「比我更俐落」的證明，用一步法。

> 📘 講義 Def 2.4.10 也定義：如果 $G = \langle a\rangle$ 對某個 $a$ 成立，就說 $G$ 是**循環群（cyclic group）**。

### 1.3 例：Z14 的循環子群

[▶ 08:10](https://youtu.be/rh1OBkyz3Rw?t=490)（學生提議 $U(10)$、$U(100)$，老師改用 $\mathbb{Z}_{14} = \{0,1,\dots,13\}$，加法。）

| 生成元 | 依序加上去 | $\langle a\rangle$ 的元素個數 |
|---|---|---|
| $2$ | $0,2,4,6,8,10,12$，再加 2 回到 $0$ | 7 |
| $3$ [▶ 09:11](https://youtu.be/rh1OBkyz3Rw?t=551) | $0,3,6,9,12,1,4,7,10,13,2,5,8,11$，然後回到 $0$ | 14（整個 $\mathbb{Z}_{14}$） |
| $1$ | $0,1,2,\dots,13$ | 14 |
| $4$ [▶ 10:42](https://youtu.be/rh1OBkyz3Rw?t=642) | $0,4,8,12,16\equiv2,6,10$，然後回到 $0$ | 7 |

【口頭】[▶ 09:41](https://youtu.be/rh1OBkyz3Rw?t=581)「這很怪吧？」$\langle3\rangle$ 跟 $\langle1\rangle$ 一樣是整個 $\mathbb{Z}_{14}$。所以 **1 和 3 都是 $\mathbb{Z}_{14}$ 的生成元**——一個群可以有不同的生成元。

（老師又寫成角括號，自己糾正：「列元素要用大括號，角括號是生成的循環子群。」另外：「這些是**集合**，不是多重集合，沒有順序。」[▶ 10:11](https://youtu.be/rh1OBkyz3Rw?t=611)）

## 2. 群的中心

[▶ 11:46](https://youtu.be/rh1OBkyz3Rw?t=706)

> **定義（中心 center）**
> $$Z(G) = \{g\in G : gx = xg\ \text{對所有}\ x\in G\}.$$
> 也就是：**跟群裡每個元素都交換**的元素。

> **定理**　$Z(G)\le G$。

（講義把它留作習題；老師說「我陪你們走一遍可能比較好」。）

**證明**（一步子群判別法）

**Step 1：非空**[▶ 12:47](https://youtu.be/rh1OBkyz3Rw?t=767)：$ex = x = xe$ 對所有 $x\in G$，所以 $e\in Z(G)$。

**Step 2：先證一個小引理**[▶ 13:18](https://youtu.be/rh1OBkyz3Rw?t=798)：如果 $b\in Z(G)$，那 $b^{-1}$ 也跟所有東西交換。

$b\in Z(G)$ 表示 $bx = xb$ 對所有 $x$。兩邊**左乘、右乘** $b^{-1}$ [▶ 13:50](https://youtu.be/rh1OBkyz3Rw?t=830)：
$$b^{-1}(bx)b^{-1} = b^{-1}(xb)b^{-1}$$
$$(b^{-1}b)xb^{-1} = b^{-1}x(bb^{-1})$$
$$xb^{-1} = b^{-1}x.$$

【口頭】[▶ 14:23](https://youtu.be/rh1OBkyz3Rw?t=863)「這裡我用的是加強版的結合律（任意加括號），要仔細證得花好幾天。原諒我不要求你們學——現在不用，也許永遠不用。」

**Step 3：$ab^{-1}\in Z(G)$**[▶ 14:54](https://youtu.be/rh1OBkyz3Rw?t=894)：設 $a,b\in Z(G)$，取任意 $x\in G$。
$$
\begin{aligned}
(ab^{-1})x &= a(b^{-1}x) &&(\text{結合律})\\
&= a(xb^{-1}) &&(\text{Step 2})\\
&= (ax)b^{-1} &&(\text{結合律})\\
&= (xa)b^{-1} &&(a\in Z(G))\\
&= x(ab^{-1}). &&(\text{結合律})
\end{aligned}
$$
對所有 $x$ 成立，所以 $ab^{-1}$ 跟每個元素交換，$ab^{-1}\in Z(G)$ [▶ 16:27](https://youtu.be/rh1OBkyz3Rw?t=987)。

由一步子群判別法，$Z(G)\le G$。$\blacksquare$

> 📘 講義補充：加法記號是 $Z(G) = \{a : a+x = x+a,\ \forall x\}$。例：$Z(\mathbb{Z}_n) = \mathbb{Z}_n$，因為加法交換。**中心對非交換群才有意思**。

## 3. 中心化子

[▶ 17:04](https://youtu.be/rh1OBkyz3Rw?t=1024) 老師問要不要順便證中心化子是子群，「也許我等下會後悔，想到今天還沒講的東西」。

> **定義（中心化子 centralizer）**[▶ 17:36](https://youtu.be/rh1OBkyz3Rw?t=1056)　$a\in G$ 固定。
> $$C(a) = \{x\in G : ax = xa\}.$$
> 也就是：**跟某個固定元素 $a$ 交換**的元素。

**中心 vs. 中心化子**[▶ 19:09](https://youtu.be/rh1OBkyz3Rw?t=1149)：
- 中心 $Z(G)$：跟**每個**元素都交換的元素。
- 中心化子 $C(a)$：跟**一個特定的** $a$ 交換的元素。
- 「相似但不同。」

> **定理**　對每個 $a\in G$，$C(a)\le G$。

【口頭】[▶ 18:07](https://youtu.be/rh1OBkyz3Rw?t=1087)「這些東西在之後的應用裡很有意思，所以才介紹。不只是因為我們用一步、兩步子群判別法時會很興奮——雖然對我來說可能是。」

**證明**（兩步子群判別法）

**Step 1：非空**[▶ 18:38](https://youtu.be/rh1OBkyz3Rw?t=1118)：$ea = a = ae$，所以 $e\in C(a)$。

**Step 2：反元素封閉**[▶ 19:40](https://youtu.be/rh1OBkyz3Rw?t=1180)：設 $x\in C(a)$，即 $ax = xa$。

老師先乘了 $a^{-1}$，得到 $xa^{-1} = a^{-1}x$，然後發現 [▶ 20:10](https://youtu.be/rh1OBkyz3Rw?t=1210)：「我是白痴，這不是我要的。我不是要證 $a^{-1}$ 在中心化子裡——它是在，但不是重點。我要證 **$x^{-1}$** 在裡面。」

正確做法：兩邊**左乘、右乘** $x^{-1}$：
$$x^{-1}(ax)x^{-1} = x^{-1}(xa)x^{-1}$$
$$x^{-1}a(xx^{-1}) = (x^{-1}x)ax^{-1}$$
$$x^{-1}a = ax^{-1}.$$
所以 $x^{-1}\in C(a)$ [▶ 20:41](https://youtu.be/rh1OBkyz3Rw?t=1241)。

**Step 3：乘法封閉**[▶ 21:11](https://youtu.be/rh1OBkyz3Rw?t=1271)：設 $x,y\in C(a)$，即 $ax = xa$、$ay = ya$。目標是 $a(xy) = (xy)a$：
$$a(xy) = (ax)y = (xa)y = x(ay) = x(ya) = (xy)a.$$
所以 $xy\in C(a)$ [▶ 21:42](https://youtu.be/rh1OBkyz3Rw?t=1302)。

由兩步子群判別法，$C(a)\le G$。$\blacksquare$

（老師說他已經把這個證明打進講義，「我擅自改了上一頁，抱歉，但錯得太離譜，非改不可」[▶ 22:13](https://youtu.be/rh1OBkyz3Rw?t=1333)。）

> 📘 講義補充：
> - 交換群裡 $C(x) = G$ 對每個 $x$ 成立（「蠢例子」）。
> - 好玩的習題：**所有中心化子的交集就是中心**，$\bigcap_{x\in G}C(x) = Z(G)$。
> - 講義 Thm 2.4.17 用一步法證：由 $bx = xb$ 推出 $xb^{-1} = b^{-1}x$，再算 $(ab^{-1})x = x(ab^{-1})$。

## 4. 置換群

[▶ 23:44](https://youtu.be/rh1OBkyz3Rw?t=1424) **Lecture 3 開始。**「對稱是什麼？放在整個故事的哪裡？」它屬於一個更大的題目：**置換**。

> **定義（置換 permutation）**[▶ 24:14](https://youtu.be/rh1OBkyz3Rw?t=1454)　$S$ 是**非空**集合（「避免一些我不知道的病態情況」）。雙射 $\sigma:S\to S$（一對一而且映成）叫做 $S$ 的**置換**。

【口頭】[▶ 25:15](https://youtu.be/rh1OBkyz3Rw?t=1515)「這其實更貼近 Galois 一開始做的事：研究根的置換。」

> **定理**[▶ 25:46](https://youtu.be/rh1OBkyz3Rw?t=1546)　設 $G$ 是非空集合 $S$ 上所有置換的集合。則 $G$ 在**函數合成**下是群。

（學生提醒老師寫成了「空集合」，老師：「我說的是非空，寫的不是。謝謝。」[▶ 26:16](https://youtu.be/rh1OBkyz3Rw?t=1576)）

**課堂上證單位元素**[▶ 26:48](https://youtu.be/rh1OBkyz3Rw?t=1608)：

定義**恆等映射** $\operatorname{Id}_S(x) = x$，對所有 $x\in S$。它是雙射，所以 $\operatorname{Id}_S\in G$（$G$ 非空）。

對任意 $F\in G$ 和 $x\in S$ [▶ 27:54](https://youtu.be/rh1OBkyz3Rw?t=1674)：
$$(F\circ\operatorname{Id}_S)(x) = F(\operatorname{Id}_S(x)) = F(x).$$
所以 $F\circ\operatorname{Id}_S = F$。同理 $\operatorname{Id}_S\circ F = F$。因此 $\operatorname{Id}_S$ 是 $G$ 的單位元素 [▶ 28:26](https://youtu.be/rh1OBkyz3Rw?t=1706)。

**其他部分是作業**[▶ 28:57](https://youtu.be/rh1OBkyz3Rw?t=1737)：證明對合成封閉、對取反函數封閉。「不難，因為給你的是雙射的集合，用這點。」（結合律來自函數合成本身就結合。）

## 5. 等距變換

（這一段老師用投影片快速講過 [▶ 29:27](https://youtu.be/rh1OBkyz3Rw?t=1767)。「我希望你們做得到，但我不介意不把重點放在這裡。」）

### 5.1 距離與等距變換

[▶ 31:00](https://youtu.be/rh1OBkyz3Rw?t=1860) 在 $\mathbb{R}^n$ 上所有雙射裡，特別有趣的是**保持距離**的那些。

**長度（範數 norm）**：
$$\|(x_1,\dots,x_n)\| = \sqrt{x_1^2+\cdots+x_n^2}.$$
它滿足：三角不等式 $\|x+y\|\le\|x\|+\|y\|$、絕對齊次 $\|cx\| = |c|\,\|x\|$、正定（$\|x\|\ge0$，等號只在 $x = 0$）。

**距離**：$d(P,Q) = \|P-Q\| = \sqrt{(P-Q)\cdot(P-Q)}$。

【口頭】[▶ 31:31](https://youtu.be/rh1OBkyz3Rw?t=1891)「你們在微積分 3、我的線性代數、或另一位老師的線性代數學過。我知道他花了前兩週講 Cauchy–Schwarz 不等式，因為他超愛。」

> **定義（等距變換 isometry）**[▶ 32:33](https://youtu.be/rh1OBkyz3Rw?t=1953)　$\varphi:\mathbb{R}^n\to\mathbb{R}^n$ 如果滿足
> $$\|\varphi(P)-\varphi(Q)\| = \|P-Q\|\quad\text{對所有}\ P,Q,$$
> 就叫**等距變換**。（isometry 的意思是「相同的度量」。）

注意：定義**沒有**要求 $\varphi$ 是線性的，甚至沒要求是雙射。

【口頭】[▶ 32:03](https://youtu.be/rh1OBkyz3Rw?t=1923) Gallian 主要只講 $\mathbb{R}^2$，但老師認為重要的是：這些事在 $\mathbb{R}^n$ 也成立（講義有一處寫成 2，他會改成 $n$）。

### 5.2 保持內積、保持角度

> **定理**[▶ 32:33](https://youtu.be/rh1OBkyz3Rw?t=1953)　$\varphi$ 是 $\mathbb{R}^n$ 的等距變換。則 $\varphi$ 保持內積（$\varphi(P)\cdot\varphi(Q) = P\cdot Q$）⟺ $\varphi(0) = 0$。

「證明其實很好懂，就是一個小小的內積恆等式。」（課堂沒走，說可以來辦公時間。）

> 📘 **講義 Thm 2.5.4 的證明**：
> - (⇒) $\varphi(0)\cdot\varphi(0) = 0\cdot0 = 0$，所以 $\varphi(0) = 0$。
> - (⇐) 設 $\varphi(0) = 0$。先有 $\|P\| = \|\varphi(P)-\varphi(0)\| = \|\varphi(P)\|$。再展開
> $$\|\varphi(P)\|^2+\|\varphi(Q)\|^2-2\varphi(P)\cdot\varphi(Q) = \|\varphi(P)-\varphi(Q)\|^2 = \|P-Q\|^2 = \|P\|^2+\|Q\|^2-2P\cdot Q.$$
>   長度相等的項消掉，得 $\varphi(P)\cdot\varphi(Q) = P\cdot Q$。

**角度**[▶ 33:03](https://youtu.be/rh1OBkyz3Rw?t=1983)：由 Cauchy–Schwarz $|v\cdot w|\le\|v\|\|w\|$，對非零向量
$$\left|\frac{v\cdot w}{\|v\|\|w\|}\right|\le1,$$
所以可以定義 $\theta\in[0,\pi]$ 使 $\cos\theta = \dfrac{v\cdot w}{\|v\|\|w\|}$。這樣在 $n$ 維也有「角度」。

> **定理**[▶ 33:34](https://youtu.be/rh1OBkyz3Rw?t=2014)　等距變換**保持向量之間的角度**。

【口頭】「我們只假設它保持點之間的距離，**免費**得到保持角度。很酷。」

⚠️ 老師當場發現投影片少了一個條件 [▶ 34:04](https://youtu.be/rh1OBkyz3Rw?t=2044)：這個定理要用到「保持內積」，所以需要 **$\varphi(0) = 0$**（固定原點的等距變換）。「少了東西，喔喔。別告訴別人。」

### 5.3 三種等距變換與兩個大定理

[▶ 34:34](https://youtu.be/rh1OBkyz3Rw?t=2074) 記號：
- $\operatorname{Isom}(\mathbb{R}^n)$：所有等距變換。
- $\operatorname{Orth}(n,\mathbb{R}) = \{\varphi\in\operatorname{Isom}(\mathbb{R}^n) : \varphi(0) = 0\}$：固定原點的，叫**正交變換（orthogonal transformations）**。它是 $\operatorname{Isom}(\mathbb{R}^n)$ 的子群——「這聽起來像作業。它就是你的作業。」

**三種等距變換**[▶ 35:04](https://youtu.be/rh1OBkyz3Rw?t=2104)：

| 種類 | 做什麼 |
|---|---|
| **旋轉（rotation）** | 固定原點，把向量轉一個角度 |
| **鏡射（reflection）** | 對一條直線翻過去；線上的點不動 |
| **平移（translation）** | $\tau_Q(x) = x+Q$，整個平移一個向量 |

還有**滑移鏡射（glide reflection）**，在 Gallian 後面的章節。「別現在讀，裡面全是你們還不懂的群論。」

**兩個大定理**（不證）[▶ 36:04](https://youtu.be/rh1OBkyz3Rw?t=2164)：

> **定理**　每個 $\mathbb{R}^n$ 的等距變換都是**雙射**。而且，每個**固定原點**的等距變換都是**非奇異線性變換**。

【口頭】「定義裡一個字都沒提到線性，這是花很大力氣才得到的。我們**不會**去做。放輕鬆。我考慮過放進這門課，但想讓課程友善一點，所以拿掉了。但它很重要，所以告訴你們。」（講義指向 Rotman《A First Course in Abstract Algebra》p.140–141 和老師的一支影片。）

> **定理**[▶ 36:35](https://youtu.be/rh1OBkyz3Rw?t=2195)　$\operatorname{Isom}(\mathbb{R}^n)$ 在函數合成下是群，而且 $\operatorname{Orth}(n,\mathbb{R})\le\operatorname{Isom}(\mathbb{R}^n)$。

證明提示 [▶ 37:05](https://youtu.be/rh1OBkyz3Rw?t=2225)：
- 有了上面的大定理就容易了。
- 小心：知道的是「等距變換是**雙射**」，「固定原點的才是**線性**的」。
- 好用的捷徑 [▶ 37:35](https://youtu.be/rh1OBkyz3Rw?t=2255)：$\operatorname{Isom}(\mathbb{R}^n)$ 是 $\mathbb{R}^n$ 上**所有置換**的子集。第 4 節已經證明置換構成群（取 $S = \mathbb{R}^n$），所以**直接用子群判別法**，「不用重新發明輪子」。
- 「抱歉，我一直在講你們的作業，這樣不好。那是你們的工作。」

### 5.4 正交矩陣

[▶ 38:06](https://youtu.be/rh1OBkyz3Rw?t=2286) 固定原點的等距變換是非奇異線性變換，所以有**標準矩陣**。

> **定義**　$O(n,\mathbb{R}) = \{[T] : T\in\operatorname{Orth}(n,\mathbb{R})\}$，叫**正交矩陣（orthogonal matrices）**。

作業：證明
$$O(n,\mathbb{R}) = \{R\in\mathbb{R}^{n\times n} : R^TR = I\}.$$
（老師：「線性代數可能出過，只是用的語言不太一樣。」）講義也說之後會看到 $O(n,\mathbb{R})\le GL(n,\mathbb{R})$。

## 6. 對稱群與二面體群

### 6.1 定義

[▶ 38:36](https://youtu.be/rh1OBkyz3Rw?t=2316) 專注在 $n = 2$（平面），「Gallian 住的地方，也是我們主要住的地方」。

等距變換對形狀做什麼 [▶ 39:06](https://youtu.be/rh1OBkyz3Rw?t=2346)：
- 圓變成圓，直線變成直線，線之間的角度保持。
- 形狀是由直線用固定角度拼起來的，所以等距變換**保持形狀**。
- 這就是為什麼等距變換也叫**剛體運動（rigid motions）**。

**對稱群**[▶ 39:36](https://youtu.be/rh1OBkyz3Rw?t=2376)：固定平面上的一個子集 $\Omega$（三角形、正方形、正五邊形……或「你最喜歡的二維汽車」）。問：哪些等距變換讓 $\Omega$ **保持不變**？

> 📘 講義 Def 2.5.10：
> $$\Sigma(\Omega) = \{\varphi\in\operatorname{Isom}(\mathbb{R}^2) : \varphi(\Omega) = \Omega\}.$$
> 它是 $\operatorname{Isom}(\mathbb{R}^2)$ 的子群。

【口頭】[▶ 40:06](https://youtu.be/rh1OBkyz3Rw?t=2406)「蠢例子：$\Omega = \mathbb{R}^2$，對稱群就是所有等距變換。不是好例子，抱歉。」

> **定義（二面體群 dihedral group）**[▶ 40:06](https://youtu.be/rh1OBkyz3Rw?t=2406)　$D_n$ 表示**邊長為 1 的正 $n$ 邊形**的對稱群。叫做 **$2n$ 階的二面體群**。

**記號警告**[▶ 41:44](https://youtu.be/rh1OBkyz3Rw?t=2504)：有些書把它記成 $D_{2n}$。例如三角形的對稱群，這裡叫 $D_3$，在網路上可能叫 $D_6$。

> 📘 講義註腳：「Dihedral」這個名字來自 Klein，他發起了研究對稱的 **Erlangen 綱領**。

### 6.2 D3：正三角形的對稱

[▶ 41:12](https://youtu.be/rh1OBkyz3Rw?t=2472) 最簡單的例子：正三角形。頂點編號 1、2、3。

**平移不行**[▶ 42:14](https://youtu.be/rh1OBkyz3Rw?t=2534)：平移後三角形就不在原位了。

**旋轉**[▶ 42:44](https://youtu.be/rh1OBkyz3Rw?t=2564)：逆時針轉。
- 老師一開始說「轉 60 度」，然後學生糾正：**應該是 120 度**。老師：「我的講義現在應該寫著 60 度，從紀錄中刪掉。顯然是 120 度。」[▶ 44:17](https://youtu.be/rh1OBkyz3Rw?t=2657)
- 記 $R$ = 逆時針轉 $120^\circ$。轉三次回到原位，所以 $R$ 的階是 3：$R^3 = e$。

**鏡射**[▶ 44:17](https://youtu.be/rh1OBkyz3Rw?t=2657)：
- $f_2$：對通過頂點 2 的軸翻轉，頂點 2 不動，1 和 3 交換。
- $f_1$：頂點 1 不動，2 和 3 交換 [▶ 45:18](https://youtu.be/rh1OBkyz3Rw?t=2718)。
- 鏡射再加旋轉，還能得到更多 [▶ 45:51](https://youtu.be/rh1OBkyz3Rw?t=2751)。

> ⚠️ 板書上每個對稱作用後頂點的位置，字幕無法完全還原。以講義 Example 2.5.12 為準：

> 📘 **講義 Example 2.5.12**：$R$ = 轉 $120^\circ$（$2\pi/3$），$f$ = 對垂直軸的鏡射（三角形一邊水平放）。
> $$D_3 = \{e,\ R,\ R^2,\ f,\ fR,\ fR^2\},\qquad|D_3| = 6.$$

**更大的 $n$**[▶ 46:22](https://youtu.be/rh1OBkyz3Rw?t=2782)：「這種畫圖到 $D_6$、$D_7$（七邊形……不是霸天虎）、$D_8$ 會變得很糟。」所以需要不畫圖的方法。

### 6.3 關鍵關係 fRf = R⁻¹

[▶ 46:52](https://youtu.be/rh1OBkyz3Rw?t=2812)「二面體群有一件美麗的事。」

> **關鍵關係**　$R$ 是基本旋轉（逆時針轉 $2\pi/n$），$f$ 是一個鏡射。則
> $$fRf = R^{-1}.$$

而且很明顯：
$$R^n = e,\qquad f^2 = e$$
（「鏡射再鏡射回到原位」[▶ 50:25](https://youtu.be/rh1OBkyz3Rw?t=3025)。）

**圖解論證**[▶ 47:22](https://youtu.be/rh1OBkyz3Rw?t=2842)：看正 $n$ 邊形，頂點 1 在 $f$ 的鏡射軸上，旁邊是 2 和 $n$。
1. 先做 $f$：1 不動，2 和 $n$ 交換位置 [▶ 48:22](https://youtu.be/rh1OBkyz3Rw?t=2902)。
2. 再做 $R$（逆時針）：每個頂點往逆時針方向移一格。
3. 再做 $f$：再翻回來 [▶ 48:52](https://youtu.be/rh1OBkyz3Rw?t=2932)。
4. 另一方面，從頭直接做 $R^{-1}$（順時針轉一格）[▶ 49:25](https://youtu.be/rh1OBkyz3Rw?t=2965)。
5. 比較兩個結果：「看，這個和那個一樣。」

**為什麼成立（直覺）**：鏡射會把「逆時針」變成「順時針」。先翻過去、逆時針轉、再翻回來，等於直接順時針轉。

- $n$ 是偶數時圖會有點不一樣（鏡射軸可能不經過頂點），但可以做類似的論證 [▶ 49:55](https://youtu.be/rh1OBkyz3Rw?t=2995)。
- 這不只是 $D_3$ 或 $D_4$ 的事，**是所有 $D_n$ 的事**。

> ⚠️ 板書圖每一步頂點的位置字幕不完整。上面依講義與論證邏輯整理。

【Q&A】[▶ 50:25](https://youtu.be/rh1OBkyz3Rw?t=3025) 學生問：$R$ 一定要逆時針嗎？老師：「我預設是逆時針，但你也可以用順時針來表示這個群，我不認為會改變這個關係式。」（確實：把 $R$ 換成 $R^{-1}$，關係式變成 $fR^{-1}f = R$，和原式等價。）

**為什麼這很棒**[▶ 49:55](https://youtu.be/rh1OBkyz3Rw?t=2995)：它讓你**不用畫圖**就能在二面體群裡計算。

### 6.4 用關係式計算：D3 不交換

[▶ 50:56](https://youtu.be/rh1OBkyz3Rw?t=3056) 在 $D_3$ 裡（$R^3 = e$，所以 $R^{-1} = R^2$、$R^{-2} = R$）。

從 $fRf = R^{-1}$ 兩邊右乘 $f$（$f^2 = e$）得到好用的形式：
$$fR = R^{-1}f.$$

> ⚠️ 板書的計算過程在字幕裡很混亂（學生中途糾正了一次，老師說「現在很痛，但謝謝」[▶ 52:58](https://youtu.be/rh1OBkyz3Rw?t=3178)）。下面用講義 Example 2.5.12 的計算，它達成的是同一個目的：

比較 $R^2$ 和 $fR$ 兩個元素，兩種順序相乘：
$$R^2(fR) = R^2R^{-1}f = Rf = fR^{-1} = fR^2,$$
（第三個等號 $Rf = fR^{-1}$：在 $fRf = R^{-1}$ 兩邊取反元素得 $fR^{-1}f = R$，再右乘 $f$。第四個等號用 $R^{-1} = R^2$。）
$$(fR)R^2 = fR^3 = f.$$
$fR^2\neq f$（否則 $R^2 = e$，但 $R$ 的階是 3）。所以
$$R^2(fR)\neq(fR)R^2.$$
**$D_3$ 是非交換群。**

【口頭】[▶ 53:30](https://youtu.be/rh1OBkyz3Rw?t=3210)
- $\{e,R,R^2,f,fR,fR^2\}$ 是 $D_3$ 的一個好的表示法，這 6 個元素都不同，所以 $D_3$ 有 6 個元素。（老師說「我不建議你們去證明」它們都不同。）
- 「要證明它不交換，需要做多少矩陣乘法？**零**。這就是厲害的地方：我們有一個非交換群，不用乘矩陣。」
- 「學會這個小技巧，你可以整天操作這些元素，不用畫圖。太棒了。」

### 6.5 【講義補充】Dn 的生成元與關係式表示

課堂沒講完，講義 p.59–60 有：

**$D_n$ 的元素**：$R$ 是逆時針轉 $2\pi/n$，$R^n = e$；$f$ 是一個鏡射。則
$$D_n = \{e,R,R^2,\dots,R^{n-1},\ f,fR,fR^2,\dots,fR^{n-1}\},\qquad|D_n| = 2n.$$
講義強調：「**這不是證明！**」要證明每個元素都是這種形式更微妙，見 Rotman p.144–145。

**代數定義**（Def 2.5.13）：
$$D_n = \{e,a,\dots,a^{n-1},b,ba,\dots,ba^{n-1}\},\quad|a| = n,\ |b| = 2,\ bab = a^{-1}.$$

**生成元與關係式（presentation）**：
$$D_n = \langle a,b\mid |a| = n,\ |b| = 2,\ bab = a^{-1}\rangle.$$
- 這屬於一個更大的故事：$a,b$ 上的**自由群（free group）**是所有由 $a,b,a^{-1},b^{-1}$ 組成的「字（words）」，運算是把字接起來，單位元素是空字。
- 加上關係 $|a| = n$、$|b| = 2$、$bab = a^{-1}$ 之後，任何字不管多長，都能改寫成上面 $2n$ 個字之一。

## 7. 一頁速查表

### 7.1 三個特殊子群

| 名稱 | 定義 | 是子群的證明關鍵一步 |
|---|---|---|
| 循環子群 $\langle a\rangle$ | $\{a^n : n\in\mathbb{Z}\}$（**要含負次方**） | $a^ja^k = a^{j+k}$；$(a^j)^{-1} = a^{-j}$ |
| 中心 $Z(G)$ | $\{g : gx = xg\ \forall x\}$ | $b\in Z(G)\Rightarrow xb^{-1} = b^{-1}x$（兩邊夾 $b^{-1}$），再算 $(ab^{-1})x = x(ab^{-1})$ |
| 中心化子 $C(a)$ | $\{x : ax = xa\}$ | 兩邊夾 $x^{-1}$ 得 $x^{-1}a = ax^{-1}$；$a(xy) = (xa)y = x(ay) = (xy)a$ |

- $Z(G) = \bigcap_{x}C(x)$；$G$ 交換 ⟺ $Z(G) = G$。

### 7.2 置換、等距變換

| 物件 | 結論 |
|---|---|
| 非空集合 $S$ 上的所有置換 | 在合成下是群，單位是 $\operatorname{Id}_S$ |
| 等距變換 | 保持距離；都是雙射 |
| 固定原點的等距變換 | 保持內積、保持角度；是非奇異線性變換 |
| $\operatorname{Orth}(n,\mathbb{R})\le\operatorname{Isom}(\mathbb{R}^n)$ | 用子群判別法（$\operatorname{Isom}$ 是所有置換的子群） |
| $O(n,\mathbb{R})$ | $\{R : R^TR = I\}$ |

### 7.3 二面體群 $D_n$

| 事實 | 內容 |
|---|---|
| 定義 | 正 $n$ 邊形的對稱群，$\lvert D_n\rvert = 2n$（有些書記作 $D_{2n}$） |
| 元素 | $e,R,\dots,R^{n-1},f,fR,\dots,fR^{n-1}$ |
| 關係 | $R^n = e$、$f^2 = e$、$fRf = R^{-1}$（等價：$fR = R^{-1}f$） |
| $D_3$ | $\{e,R,R^2,f,fR,fR^2\}$，$R$ 轉 $120^\circ$（不是 $60^\circ$） |
| 不交換 | $R^2(fR) = fR^2\neq f = (fR)R^2$ |
