# 第 35 集 · 答疑課：群作用、第三同構定理、格、$O(2)$ 的軌道 [▶ 影片](https://www.youtube.com/watch?v=LfLLJXALt3Y&list=PLBY4G2o7DhF0JCgapYKrqibGaJuvV4Gkb)

## 本集概要

講上次考試和最後幾份作業的解答：
- 共軛作用在**子群**上：軌道是共軛子群，穩定子是**正規化子**。左乘作用在**陪集**上。
- $A\le N_G(B)\Rightarrow AB\le G$。
- **第三同構定理**的分步證明。
- $\mathbb{Z}_{12}$ 的子群格，用**格定理**讀出各商群的格。
- **代值同態** $f\mapsto f(3)$：核是「過 $(3,0)$ 的多項式」。
- **$O(2)$ 作用在 $\mathbb{R}^2$ 上**：軌道是同心圓；非零點的穩定子是 $\{I,\text{過該點直線的鏡射}\}$（「幾何的復仇」）。
- $\mathbb{Z}_n\to\mathbb{Z}_k$ 的同態：$\varphi(1) = m$ 時需要 $k\mid mn$。

## 筆記

### 1. 共軛作用在子群上（考題）[▶ 00:30](https://youtu.be/LfLLJXALt3Y?t=30)

$G$ 作用在 $G$ 的所有子群上：$a\star H = aHa^{-1}$。
- **映入**：$aHa^{-1}$ 是內自同構 $\varphi_a$ 下 $H$ 的像；同態的像是子群 [▶ 01:00](https://youtu.be/LfLLJXALt3Y?t=60)。
- **公理**：$e\star H = H$；$a\star(b\star H) = abHb^{-1}a^{-1} = (ab)H(ab)^{-1} = (ab)\star H$（襪子鞋子）。
- **軌道**：所有和 $H$ 共軛的子群 [▶ 02:00](https://youtu.be/LfLLJXALt3Y?t=120)。
- **穩定子**：$\{a\mid aHa^{-1} = H\} = N_G(H)$，正規化子——$H$ 在其中正規的最大子群。

### 2. 左乘作用在陪集上（考題）[▶ 02:30](https://youtu.be/LfLLJXALt3Y?t=150)

$g\star xH = gxH$。結果顯然還是 $H$ 的左陪集，不用額外檢查；公理靠群的結合律。

**關於 $|HK|$ 那題** [▶ 03:30](https://youtu.be/LfLLJXALt3Y?t=210)：老師的哥哥 Bill 說，老師以為用的是 Lagrange，其實是**軌道穩定子定理**（代表元的重複由穩定子負責）。老師說：好吧，軌道穩定子定理是 Lagrange 的推廣，這是哲學問題；他本來想找一個「明顯不同於 Lagrange」的用法，這是他的錯。

### 3. $A\le N_G(B)\Rightarrow AB\le G$ [▶ 06:00](https://youtu.be/LfLLJXALt3Y?t=360)

- $A\le N_G(B)$：$A$ 的每個元素都把 $B$ 共軛回 $B$，即 $aBa^{-1} = B$，等價於 $aB = Ba$ [▶ 07:00](https://youtu.be/LfLLJXALt3Y?t=420)。
- 非空：$e = ee\in AB$。
- 一步法：$x = a_1b_1$、$y = a_2b_2$，
$$xy^{-1} = a_1b_1b_2^{-1}a_2^{-1} = a_1a_2^{-1}b_3\in AB,$$
  因為 $(b_1b_2^{-1})a_2^{-1}\in Ba_2^{-1} = a_2^{-1}B$ [▶ 08:30](https://youtu.be/LfLLJXALt3Y?t=510)。

最難的大概是消化「$A$ 是 $B$ 的正規化子的子群」到底是什麼意思。

**學生問：「求軌道」要寫到什麼程度？** [▶ 10:00](https://youtu.be/LfLLJXALt3Y?t=600)：看題目。說「幾何上描述」就說「是圓」；只說「求」，集合建構式就夠。如果剛好是有名字的東西（共軛類、中心化子、中心），就說出名字。
> 💬 老師說曾有拓撲學教授出「name this topology」，學生想了好幾小時，結果教授的意思是「幫它取個名字」——「你這個怪物」[▶ 12:00](https://youtu.be/LfLLJXALt3Y?t=720)。

### 4. 第三同構定理（作業）[▶ 12:30](https://youtu.be/LfLLJXALt3Y?t=750)

$H,K\trianglelefteq G$，$H\le K$。

**(a) $H\trianglelefteq K$**：$gHg^{-1} = H$ 對所有 $g\in G$，當然也對所有 $g\in K$。所以 $K/H$ 有意義 [▶ 13:00](https://youtu.be/LfLLJXALt3Y?t=780)。

**(b) $K/H\trianglelefteq G/H$** [▶ 13:30](https://youtu.be/LfLLJXALt3Y?t=810)：用 $(gH)^{-1} = g^{-1}H$，
$$(gH)(xH)(gH)^{-1} = gxg^{-1}H,$$
而 $gxg^{-1}\in K$（$K$ 正規），所以落在 $K/H$。由 Thm 9.1 得證。

**(c) 映射** $\varphi:G/H\to G/K$，$\varphi(gH) = gK$。
- **良定義** [▶ 15:00](https://youtu.be/LfLLJXALt3Y?t=900)：$g_1H = g_2H\Rightarrow g_2^{-1}g_1\in H\subseteq K\Rightarrow g_1K = g_2K$。（學生問：這裡是說「$H$ 陪集相同，推出 $K$ 陪集也相同」[▶ 20:00](https://youtu.be/LfLLJXALt3Y?t=1200)。）
- 同態（陪集乘法）；滿射。
- **核** [▶ 16:00](https://youtu.be/LfLLJXALt3Y?t=960)：$xK = K\iff x\in K$，所以 $\ker\varphi = \{xH\mid x\in K\} = K/H$。

**(d)** 第一同構定理：
$$(G/H)/(K/H)\cong G/K.$$

這是老師拆解 Dummit & Foote 的證明而來 [▶ 19:00](https://youtu.be/LfLLJXALt3Y?t=1140)。（如果只是在很簡單的題目裡宣稱滿射沒證，可能扣一半分。）

**學生問：有沒有很難找同態的情形？** [▶ 18:00](https://youtu.be/LfLLJXALt3Y?t=1080)：老師覺得小群之間的同構反而費力，例如找 $S_3$ 到某個同構群的映射，沒有公式，只能從生成元與關係慢慢對：「2 階元素送到 2 階元素、生成元送到生成元」。有行列式、陪集之類公式的反而簡單。「別人寫下公式後，總是看起來很顯然。」

### 5. $\mathbb{Z}_{12}$ 的子群格與格定理 [▶ 20:30](https://youtu.be/LfLLJXALt3Y?t=1230)

子群：$\langle1\rangle$、$\langle2\rangle = \{0,2,4,6,8,10\}$、$\langle3\rangle = \{0,3,6,9\}$、$\langle4\rangle = \{0,4,8\}$、$\langle6\rangle = \{0,6\}$、$\langle0\rangle$。

```
          ⟨1⟩
         /    \
       ⟨2⟩    ⟨3⟩
       /  \   /
     ⟨4⟩   ⟨6⟩
       \   /
        ⟨0⟩
```

**格定理（Strato 教授叫它「對應定理 correspondence theorem」）**：$\mathbb{Z}_{12}/N$ 的格就是格圖中 $N$ 以上的部分 [▶ 21:30](https://youtu.be/LfLLJXALt3Y?t=1290)。
- $\mathbb{Z}_{12}/\langle2\rangle$：只剩 $\langle1\rangle$—$\langle2\rangle$，就是 $\mathbb{Z}_2$ 的格。商群的兩個陪集是偶數和奇數 [▶ 22:30](https://youtu.be/LfLLJXALt3Y?t=1350)。嚴格說 $\mathbb{Z}_{12}/2\mathbb{Z}_{12}\cong\mathbb{Z}_2$，不是「等於」。
- $\mathbb{Z}_{12}/\langle3\rangle$：也只有兩層，是 $\mathbb{Z}_3$ 的格。**格一樣，群不一定同構**（$\mathbb{Z}_2\not\cong\mathbb{Z}_3$）；但同構的群格一定一樣（必要不充分）[▶ 23:30](https://youtu.be/LfLLJXALt3Y?t=1410)。
- $\mathbb{Z}_{12}/\langle6\rangle$：剩下一個菱形。
- $\mathbb{Z}_{12}/\langle4\rangle$：剩下 $\langle1\rangle$—$\langle2\rangle$—$\langle4\rangle$ 一條鏈，是 4 階循環群（有一個 2 階子群）的格 [▶ 24:30](https://youtu.be/LfLLJXALt3Y?t=1470)。

老師推薦一個網站，可以畫任何小群的 Cayley 表和子群圖，例如 $\mathbb{Z}_3\times\mathbb{Z}_8$——「可以浪費大量時間在上面」[▶ 26:00](https://youtu.be/LfLLJXALt3Y?t=1560)。

### 6. 代值同態 [▶ 27:00](https://youtu.be/LfLLJXALt3Y?t=1620)

$\psi:(\mathbb{R}[x],+)\to(\mathbb{R},+)$，$\psi(f) = f(3)$。
- 同態：$\psi(f+g) = (f+g)(3) = f(3)+g(3)$。
- **核** [▶ 28:00](https://youtu.be/LfLLJXALt3Y?t=1680)：$f(3) = 0$。由高中的**因式定理**，就是 $(x-3)$ 的倍數。幾何上（Gallian 書後答案的說法）：圖形通過 $(3,0)$ 的所有多項式。
- 寫成 $a_0+a_1x+\cdots$ 會把題目弄得很複雜；處理代值時，停在函數記號的層次比較好 [▶ 28:30](https://youtu.be/LfLLJXALt3Y?t=1710)。

### 7. $O(2)$ 作用在平面上（「幾何的復仇」）[▶ 29:30](https://youtu.be/LfLLJXALt3Y?t=1770)

$O(2)$：$2\times2$ **正交矩陣**（$R^TR = I$）。它們保持原點和距離；行列式 $\pm1$：$+1$ 是旋轉，$-1$ 是鏡射 [▶ 30:00](https://youtu.be/LfLLJXALt3Y?t=1800)。

**軌道**
- 原點：$R\mathbf 0 = \mathbf 0$，軌道 $\{\mathbf 0\}$ [▶ 30:30](https://youtu.be/LfLLJXALt3Y?t=1830)。
- $\mathbf v\neq\mathbf 0$：$\|R\mathbf v\|^2 = \mathbf v^TR^TR\mathbf v = \|\mathbf v\|^2$，所以軌道在半徑 $\|\mathbf v\|$ 的圓上 [▶ 31:30](https://youtu.be/LfLLJXALt3Y?t=1890)。
- 要證**整個圓**：若 $\mathbf v$ 的極角是 $\theta_0$，要到極角 $\theta$ 的點，就旋轉 $\theta-\theta_0$（和角公式）[▶ 33:00](https://youtu.be/LfLLJXALt3Y?t=1980)。
- 所以軌道是以原點為圓心的同心圓。（一般矩陣，例如 $\begin{pmatrix}1&2\\3&4\end{pmatrix}$ 生成的群，軌道不是圓。）

**$O(2)$ 的參數化** [▶ 34:00](https://youtu.be/LfLLJXALt3Y?t=2040)：$SO(2) = \ker\det$ 是正規子群，$O(2)$ 只有兩個陪集：旋轉，以及 $\begin{pmatrix}1&0\\0&-1\end{pmatrix}$ 乘旋轉。所以
$$R = \begin{pmatrix}\cos\theta&-\varepsilon\sin\theta\\ \sin\theta&\varepsilon\cos\theta\end{pmatrix},\quad\varepsilon = \pm1.$$
（「$SO(2)$ 的元素都長這樣」解答裡沒證，老師承認有缺口。）

**穩定子** [▶ 35:30](https://youtu.be/LfLLJXALt3Y?t=2130)：解 $R\begin{pmatrix}x\\y\end{pmatrix} = \begin{pmatrix}x\\y\end{pmatrix}$，未知數是 $\cos\theta$、$\sin\theta$，是線性方程組。
- $\varepsilon = 1$：$\cos\theta = 1$、$\sin\theta = 0$，恆等。
- $\varepsilon = -1$：解出一個**鏡射**，鏡射軸就是過原點和 $(x,y)$ 的直線 [▶ 37:00](https://youtu.be/LfLLJXALt3Y?t=2220)。
- 所以非零點的穩定子 $\cong\mathbb{Z}_2$。

幾何上一眼就看得出來：固定一點的只有恆等，以及沿著過該點直線的鏡射。「用代數做會有點痛，我花了不少時間」[▶ 38:00](https://youtu.be/LfLLJXALt3Y?t=2280)。

### 8. $\mathbb{Z}_n\to\mathbb{Z}_k$ 的同態 [▶ 40:00](https://youtu.be/LfLLJXALt3Y?t=2400)

- 同態完全由 $\varphi(1) = m$ 決定：$\varphi(x) = xm$（因為 $x = x\cdot1$，加法版的 $\varphi(g^n) = \varphi(g)^n$）[▶ 40:30](https://youtu.be/LfLLJXALt3Y?t=2430)。
- 良定義要求：$[n]_n = [0]_n$ 送到 $0$，即 $nm\equiv0\pmod k$，也就是 **$k\mid mn$** [▶ 42:00](https://youtu.be/LfLLJXALt3Y?t=2520)。
- 修改後的作業題：若是**滿**同態，第一同構定理給 $k\mid n$。原題「證 $k\mid n$」在沒有滿射時是錯的；老師的反例（$\mathbb{Z}_4\to\mathbb{Z}_6$）不是滿射 [▶ 43:00](https://youtu.be/LfLLJXALt3Y?t=2580)。
