## 1. 共軛作用在子群上

[▶ 00:30](https://youtu.be/LfLLJXALt3Y?t=30)「我想你們這題沒什麼困難，不要花太久。」

$G$ 作用在 $G$ 的**所有子群**上：$a\star H = aHa^{-1}$。

要檢查兩件事：
1. **真的映到子群**[▶ 01:00](https://youtu.be/LfLLJXALt3Y?t=60)：$aHa^{-1}$ 是內自同構 $\varphi_a$ 下 $H$ 的像。同態的像是子群。（也可以用兩步法。）
2. **兩條公理**：
   - $e\star H = H$。
   - $a\star(b\star H) = a(bHb^{-1})a^{-1} = (ab)H(ab)^{-1} = (ab)\star H$（襪子鞋子）[▶ 01:30](https://youtu.be/LfLLJXALt3Y?t=90)。

**軌道與穩定子**[▶ 02:00](https://youtu.be/LfLLJXALt3Y?t=120)：
- 軌道：所有和 $H$ **共軛的子群**。「我不知道它有沒有好名字。」
- 穩定子：$\{a : aHa^{-1} = H\} = N_G(H)$，**正規化子**——$H$ 在其中正規的最大子群（[[32-L21-同構定理與有限單群]]）。「我們證過穩定子是子群，所以我知道它是群。」

## 3. A ≤ N_G(B) ⇒ AB ≤ G

[▶ 06:00](https://youtu.be/LfLLJXALt3Y?t=360)（第二同構定理的第一步，[[32-L21-同構定理與有限單群]] 說是作業。）

**先消化條件**[▶ 06:30](https://youtu.be/LfLLJXALt3Y?t=390)：
- $N_G(B) = \{g : gBg^{-1} = B\}$——把 $B$ 共軛回 $B$ 的元素。
- $A\le N_G(B)$ ⇒ $A$ 的每個元素都「屬於這個俱樂部」：$aBa^{-1} = B$，即
$$aB = Ba\quad\text{對所有 }a\in A.$$

**證明**（一步法）[▶ 07:30](https://youtu.be/LfLLJXALt3Y?t=450)
- **非空**：$e = ee\in AB$。
- 取 $x = a_1b_1$、$y = a_2b_2$。$G$ 是大群，「所有平常的權利和特權」都在，可以用襪子鞋子：
$$xy^{-1} = a_1b_1b_2^{-1}a_2^{-1}.$$
- 「$a_2^{-1}$ 在它不該在的地方。」但 $Ba_2^{-1} = a_2^{-1}B$，所以 $(b_1b_2^{-1})a_2^{-1} = a_2^{-1}b_3$ [▶ 09:00](https://youtu.be/LfLLJXALt3Y?t=540)：
$$xy^{-1} = a_1a_2^{-1}b_3\in AB.\ \blacksquare$$

【口頭】「這比我之前做的某題還強：那題兩邊不能用同一個 $a$，這裡**同一個 $a$** 都可以。」「我想主要的困難是**內化**『$A$ 是 $B$ 的正規化子的子群』到底什麼意思。那有點嚇人，不容易一下子消化。」

## 5. 第三同構定理（分步證明）

[▶ 12:30](https://youtu.be/LfLLJXALt3Y?t=750) $H,K\trianglelefteq G$，$H\le K$。

**(a) $K/H$ 有意義**：$gHg^{-1} = H$ 對所有 $g\in G$——當然也對所有 $g\in K$（$K\subseteq G$）。所以 $H\trianglelefteq K$ [▶ 13:00](https://youtu.be/LfLLJXALt3Y?t=780)。

**(b) $K/H\trianglelefteq G/H$**[▶ 13:30](https://youtu.be/LfLLJXALt3Y?t=810)：用 $gH$ 共軛 $xH$（$x\in K$）：
$$(gH)(xH)(gH)^{-1} = (gH)(xH)(g^{-1}H) = gxg^{-1}H.$$
- 用到 $(gH)^{-1} = g^{-1}H$：「陪集的反元素是反元素的陪集。不信可以驗：$g^{-1}H\cdot gH = H$。」
- $K$ 正規 ⇒ $gxg^{-1}\in K$ ⇒ $gxg^{-1}H\in K/H$。由 Gallian Thm 9.1 得正規 [▶ 15:00](https://youtu.be/LfLLJXALt3Y?t=900)。
- 「把這個弄出你的系統之後，剩下的老實說很簡單。」

**(c) 定義 $\varphi:G/H\to G/K$，$\varphi(gH) = gK$**
- **良定義**[▶ 15:00](https://youtu.be/LfLLJXALt3Y?t=900)：「映射定義在陪集上，就要檢查公式跟代表無關。」若 $g_1H = g_2H$，則 $g_2^{-1}g_1\in H\subseteq K$，所以 $g_1K = g_2K$。（解答裡有個筆誤，該寫 $g_1H$。）
- 【Q&A】[▶ 20:00](https://youtu.be/LfLLJXALt3Y?t=1200) 學生問這步。老師：「$H$ 陪集相同 ⇒ $K$ 陪集相同。就是這樣。」
- **同態**[▶ 16:00](https://youtu.be/LfLLJXALt3Y?t=960)：陪集乘法的性質。
- **核**[▶ 16:30](https://youtu.be/LfLLJXALt3Y?t=990)：$xK = K\iff x\in K$。所以核 = 代表取自 $K$ 的 $H$ 陪集 $= K/H$。
- **滿射**：任何 $xK$ 都是 $\varphi(xH)$。

**(d) 第一同構定理**：$(G/H)/(K/H)\cong G/K$。$\blacksquare$

【口頭】[▶ 17:30](https://youtu.be/LfLLJXALt3Y?t=1050)「如果你沒寫良定義、只是宣稱——看題目多簡單。很簡單的題，我可能扣一半分數。」

【Q&A】[▶ 17:30](https://youtu.be/LfLLJXALt3Y?t=1050) 學生：「有沒有很難找到兩群之間同態的情況？」
- 老師：「**小群**的那種，基本上是**模式比對**，對我來說很累。例如 $S_3$ 和某個跟它同構的東西：你可能沒有公式，只能在生成元和關係裡翻，直到『喔，這是我的換位、這是我的 3-循環』。有行列式、陪集公式的反而簡單。」
- 原則：「蘋果對蘋果、橘子對橘子：2 階元素送到 2 階元素，從那裡延伸。循環群對循環群，就把生成元送到生成元。」
- 學生：「別人寫下公式後總是看起來很簡單。」老師：「我承認——或是我從書上抄的時候。這題我不能邀功：我只是把 **Dummit & Foote** 第三同構定理的證明**拆解**成作業。」

## 6. ℤ₁₂ 的子群格與格定理

[▶ 20:30](https://youtu.be/LfLLJXALt3Y?t=1230)「這題其實蠻好玩的。」

**$\mathbb{Z}_{12}$ 的子群**：
- $\langle1\rangle = \mathbb{Z}_{12}$
- $\langle2\rangle = \{0,2,4,6,8,10\}$（6 階）
- $\langle3\rangle = \{0,3,6,9\}$（4 階）
- $\langle4\rangle = \{0,4,8\}$（3 階）
- $\langle6\rangle = \{0,6\}$（2 階）
- $\langle0\rangle$

```
            ℤ₁₂
           /    \
        ⟨2⟩      ⟨3⟩
        /  \     /
     ⟨4⟩    ⟨6⟩
        \   /
         ⟨0⟩
```

**用格定理讀商群的格**[▶ 21:30](https://youtu.be/LfLLJXALt3Y?t=1290)（「Strato 博士叫它**對應定理**（correspondence theorem）」）：$N$ 以下的全部消失，只留 $N$ 以上的部分。

| 商 | 留下的格 | 同構於 |
|---|---|---|
| $\mathbb{Z}_{12}/\langle2\rangle$ | 頂、底 | $\mathbb{Z}_2$ |
| $\mathbb{Z}_{12}/\langle3\rangle$ | 頂、底 | $\mathbb{Z}_3$ |
| $\mathbb{Z}_{12}/\langle6\rangle$ | 菱形（頂、$\langle2\rangle$、$\langle3\rangle$、底） | $\mathbb{Z}_6$ |
| $\mathbb{Z}_{12}/\langle4\rangle$ | 頂、$\langle2\rangle$、底（一條鏈） | $\mathbb{Z}_4$ |

- $\mathbb{Z}_{12}/\langle2\rangle$ 技術上**不等於** $\mathbb{Z}_2$，它是兩個陪集 $\{0,2,4,6,8,10\}$ 和 $\{1,3,5,7,9,11\}$——但同構於 $\mathbb{Z}_2$ [▶ 22:30](https://youtu.be/LfLLJXALt3Y?t=1350)。（另一題作業證過 $\mathbb{Z}_{12}/2\mathbb{Z}_{12}\cong\mathbb{Z}_2$。）
- **注意**[▶ 23:30](https://youtu.be/LfLLJXALt3Y?t=1410)：$\mathbb{Z}_2$ 和 $\mathbb{Z}_3$ 的格**一樣**，但它們**不同構**。
  - 【課堂討論】學生：「所以同樣的格圖是必要條件？」老師：「對：**同構的群有同樣的格圖**，但反過來不成立。」

【口頭】[▶ 25:00](https://youtu.be/LfLLJXALt3Y?t=1500)「你們慶幸我沒用一開始想的 25 或 100 吧？」老師也展示一個網路工具：輸入 $\mathbb{Z}_{12}$ 或 $\mathbb{Z}_3\times\mathbb{Z}_8$，會畫出 Cayley 表和**子群格圖** [▶ 26:00](https://youtu.be/LfLLJXALt3Y?t=1560)。「你們可以在上面浪費大量時間，很好玩。要的話我寄連結給你們。」

## 7. 代值同態 f ↦ f(3)

## 8. O(2) 作用在 ℝ² 上：「幾何的復仇」

[▶ 29:00](https://youtu.be/LfLLJXALt3Y?t=1740)（學生提醒：「那題你今天應該要講。」——第 18 份的第 1 題。）

**背景**[▶ 30:00](https://youtu.be/LfLLJXALt3Y?t=1800)：$O(2)$ = $2\times2$ **正交矩陣**。之前有題連結到：它們恰好是**固定原點、保持距離**的變換。行列式 $\pm1$：$+1$ 是**旋轉**，$-1$ 是**鏡射**。

**軌道**
- **原點**[▶ 30:30](https://youtu.be/LfLLJXALt3Y?t=1830)：$R\mathbf 0 = \mathbf 0$。軌道 $\{\mathbf 0\}$。「不意外：線性變換不動 0。」
- **$\mathbf v\neq\mathbf 0$**[▶ 31:00](https://youtu.be/LfLLJXALt3Y?t=1860)：
$$\|R\mathbf v\|^2 = (R\mathbf v)^T(R\mathbf v) = \mathbf v^TR^TR\mathbf v = \mathbf v^T\mathbf v = \|\mathbf v\|^2.$$
  所以軌道在半徑 $\|\mathbf v\|$ 的圓上。
  - 【Q&A】學生：「軌道一定是圓嗎？」老師：「**不是**，可能是很多東西。這裡是因為正交。換成任意矩陣，例如 $\begin{pmatrix}1&2\\3&4\end{pmatrix}$，我不知道軌道是什麼，不會是圓。」
- **整個圓都打得到**[▶ 32:30](https://youtu.be/LfLLJXALt3Y?t=1950)：「這裡是**重活**。」設 $\mathbf v$ 在角度 $\theta_0$，目標在角度 $\theta$。旋轉 $\theta-\theta_0$，用和角公式驗證。所以軌道是以原點為圓心、過 $\mathbf v$ 的**整個圓**。

**$O(2)$ 的參數化**[▶ 34:00](https://youtu.be/LfLLJXALt3Y?t=2040)
- $SO(2)$（行列式 1）是行列式映射的**核** ⇒ 正規子群。它的陪集分割 $O(2)$：旋轉，以及旋轉左乘 $\begin{pmatrix}1&0\\0&-1\end{pmatrix}$。
- 旋轉的形式是 $\begin{pmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{pmatrix}$。「**承認解答裡有缺口**：我其實沒證這個。」
- 合起來：
$$R = \begin{pmatrix}\cos\theta&-\sin\theta\\\epsilon\sin\theta&\epsilon\cos\theta\end{pmatrix},\quad\epsilon = \pm1.$$

**穩定子**[▶ 35:30](https://youtu.be/LfLLJXALt3Y?t=2130)：解 $R(x,y)^T = (x,y)^T$，未知數是 $\cos\theta$、$\sin\theta$（對它們是**線性**的）。
- $\epsilon = 1$：$\cos\theta = 1$、$\sin\theta = 0$ ⇒ **恆等**。「不意外：穩定子是子群，一定有單位。」
- $\epsilon = -1$ [▶ 37:00](https://youtu.be/LfLLJXALt3Y?t=2220)：「**這個我一開始沒想到**。」解出一個鏡射 $R_{\mathbf v}$；驗證時乘出來的 $(x^2+y^2)$ 會消掉，得回 $(x,y)$。
- 所以非零點的穩定子 $\cong\mathbb{Z}_2$：$\{I,\ \text{對過 }\mathbf v\text{ 的直線的鏡射}\}$。

【口頭】[▶ 37:30](https://youtu.be/LfLLJXALt3Y?t=2250)「幾何上這**太明顯了**：固定一個點的，當然有恆等；再想一下，對**過那點的直線**做鏡射，線上的點都不動。$O(2)$ 裡只有一個這種鏡射。以後我要把這題命名為『**幾何的復仇**』——你們可以做那些代數，但會有點痛。這花了我一段時間。」

【口頭】[▶ 38:30](https://youtu.be/LfLLJXALt3Y?t=2310)「做完那題，下一題（代值同態）好清爽、好振奮人心。那題**之後研究擴張體時有用**。第 71 題我還沒做。」

## 9. ℤₙ → ℤₖ 的同態

【Q&A】[▶ 39:30](https://youtu.be/LfLLJXALt3Y?t=2370) 學生問那題 $\mathbb{Z}_n\to\mathbb{Z}_k$ 的題目。

**若 $\varphi(1) = m$，則 $k\mid mn$**[▶ 41:00](https://youtu.be/LfLLJXALt3Y?t=2460)
- 關鍵：$[x]_n = x\cdot[1]_n$，所以 $1$ 去哪，就決定了 $x$ 去哪：$\varphi(x) = xm$。
- $0 = [n]_n = n\cdot1$，同態把 0 送到 0：
$$0 = \varphi(n\cdot1) = n\varphi(1) = nm\ \text{（在 }\mathbb{Z}_k\text{ 裡）}\quad\Rightarrow\quad k\mid mn.$$
- （「$\varphi(g^n) = \varphi(g)^n$ 在加法記號下長這樣。」）

**修正過的那題**[▶ 42:30](https://youtu.be/LfLLJXALt3Y?t=2550)：加上「**滿射**」就有 $k\mid n$（見 [[31-答疑課]] 第 9 節）。
- 【口頭】「出題時我只是丟個東西給你們嚼。原本『證明 $k\mid n$』是胡說——除非滿射。我的反例 $\mathbb{Z}_4\to\mathbb{Z}_6$、$x\mapsto2x$ 不是滿射。」
- 【口頭】[▶ 43:00](https://youtu.be/LfLLJXALt3Y?t=2580)「在這裡說『**基數**』我覺得有點蠢——它們只是有限集合的元素個數。如果是無限的，商的基數我不認為有意義。」

（結尾：「今天怎麼這麼多人？」）

## 附：本集一句話總結

> **共軛作用在子群上的穩定子是正規化子，$A\le N_G(B)$ 就是「$aB = Ba$」所以 $AB$ 是子群；第三同構定理用 $gH\mapsto gK$（良定義靠 $H\subseteq K$）加第一同構定理；$\mathbb{Z}_{12}$ 的格說明同構的群有同樣的格、反之不然；$O(2)$ 在平面上的軌道是同心圓、非零點的穩定子是恆等加一個鏡射——幾何上一眼看出，代數上要做一陣子，所以叫「幾何的復仇」。**
