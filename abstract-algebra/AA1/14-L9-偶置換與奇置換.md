## 1. 複習：化成互斥循環

[▶ 00:30](https://youtu.be/laVj9YFTpyc?t=30)「先複習一下，回到記號的節奏。」$S_9$ 裡的
$$\alpha = \begin{pmatrix}1&2&3&4&5&6&7&8&9\\4&5&7&9&1&6&3&8&2\end{pmatrix}.$$

**做法**[▶ 02:00](https://youtu.be/laVj9YFTpyc?t=120)：從 1 開始跟著走。
- $1\to4\to9\to2\to5\to1$，閉合 [▶ 03:00](https://youtu.be/laVj9YFTpyc?t=180)。
- 挑還沒碰過的 3：$3\to7\to3$ [▶ 04:00](https://youtu.be/laVj9YFTpyc?t=240)。
- 6 和 8 不動（被 $\alpha$ **固定**）。

$$\alpha = (1\,4\,9\,2\,5)(3\,7).$$

這叫 $\alpha$ 的**（互斥）循環分解**（disjoint cycle decomposition）[▶ 05:00](https://youtu.be/laVj9YFTpyc?t=300)。

> **定理**　每個 $\sigma\in S_n$ 都能寫成互斥循環的乘積。

**證明**[▶ 06:00](https://youtu.be/laVj9YFTpyc?t=360)：跟剛才的例子差不多——從一個數開始，走到繞回來（一定會繞回來），再挑下一個沒碰過的數，一直做下去。（講義 Thm 1.3.10 有正式證明，見 [[12-L8-置換與循環記號]] 第 8 節。）

> 📘 講義補充：$\alpha$ 把集合 $U_1 = \{3,7\}$ 和 $U_2 = \{1,2,4,5,9\}$ 都送回自己（$\alpha(U) = U$）——每個循環就是一個這樣的「被固定的集合」。

## 2. 每個循環都是換位的乘積

[▶ 06:30](https://youtu.be/laVj9YFTpyc?t=390)「互斥循環分解不一定是最想要的。我們還能做別的。」

**例**：
$$(1\,4\,9\,2\,5) = (1\,5)(1\,2)(1\,9)(1\,4).$$
**模式**[▶ 07:00](https://youtu.be/laVj9YFTpyc?t=420)：第一個配最後一個，然後往回走。

**驗證**（從右往左）[▶ 07:30](https://youtu.be/laVj9YFTpyc?t=450)：
- 5：前三個都不動 5，$(1\,5)$ 送到 1。$5\to1$ ✓。
- 2：$(1\,4)$、$(1\,9)$ 不動；$(1\,2)$ 送到 1；$(1\,5)$ 送到 5。$2\to5$ ✓。
- 依此類推。

「這個循環沒什麼特別的，很容易推廣。」

> **定理**[▶ 08:00](https://youtu.be/laVj9YFTpyc?t=480)　$\alpha = (a_1\,a_2\,\dots\,a_k)$ 可以寫成 2-循環（換位）的乘積：
> $$(a_1\,a_2\,\dots\,a_k) = (a_1\,a_k)(a_1\,a_{k-1})\cdots(a_1\,a_2).$$

**換位（transposition）**[▶ 08:30](https://youtu.be/laVj9YFTpyc?t=510)：就是 2-循環。名字的由來：它只是把兩個數**對調**（transpose）。

**證明**（用公式；也可以用歸納法）[▶ 09:30](https://youtu.be/laVj9YFTpyc?t=570)：逐一檢查每個數，「case by case」。

【課堂討論】[▶ 10:00](https://youtu.be/laVj9YFTpyc?t=600)「$k$ 和 $n$ 的關係是什麼？$S_3$ 裡最長的循環是？」學生：3-循環。所以 $k\le n$。「我們昨天說服過自己：$S_3$ 裡沒有 4-循環。」

**示範一個情況：$a_2$**[▶ 11:00](https://youtu.be/laVj9YFTpyc?t=660)
- 左邊：由循環的定義，$\alpha(a_2) = a_3$。
- 右邊，從右往左：$(a_1\,a_2)$ 把 $a_2$ 送到 $a_1$；$(a_1\,a_3)$ 把 $a_1$ 送到 $a_3$；之後的 $(a_1\,a_4),\dots,(a_1\,a_k)$ 都沒有 $a_3$，所以不動它 [▶ 12:30](https://youtu.be/laVj9YFTpyc?t=750)。
- 輸出 $a_3$ ✓。

> **推論**（講義 Thm 1.3.11）　$n\ge2$ 時，$S_n$ 的每個置換都能寫成換位的乘積。（先化成互斥循環，再把每個循環拆開。）

## 3. 換位的幾個恆等式

[▶ 13:30](https://youtu.be/laVj9YFTpyc?t=810)「再玩一玩換位。一些巧妙的觀察。」設 $a,b,c,d$ 相異。

**(1) 互斥的換位可交換**[▶ 14:00](https://youtu.be/laVj9YFTpyc?t=840)：
$$(c\,d)(a\,b) = (a\,b)(c\,d).$$

**(2)**[▶ 14:30](https://youtu.be/laVj9YFTpyc?t=870)：「基本上就是把剛才的技巧反過來用。」
$$(b\,c)(a\,b) = (a\,c\,b).$$
驗證（老師中途說「我是白痴，再來一次」）[▶ 15:30](https://youtu.be/laVj9YFTpyc?t=930)：$a$：$(a\,b)$ 送到 $b$，$(b\,c)$ 送到 $c$，所以 $a\to c$ ✓；$b\to a$ ✓；$c\to b$ ✓。

循環可以旋轉：$(a\,c\,b) = (c\,b\,a)$。再用拆換位的技巧：
$$(b\,c)(a\,b) = (a\,c\,b) = (c\,b\,a) = (c\,a)(c\,b).$$

【課堂討論】[▶ 17:00](https://youtu.be/laVj9YFTpyc?t=1020) 學生指出也可以寫成別的形式。老師：「對，我們隨時可以在任何循環裡換字母（旋轉）。」

**(3)**[▶ 18:00](https://youtu.be/laVj9YFTpyc?t=1080)：
$$(a\,c)(a\,b) = (a\,b\,c) = (b\,c\,a) = (c\,a\,b).$$
再拆成換位：
$$(a\,c)(a\,b) = (b\,a)(b\,c) = (c\,b)(c\,a).$$

（學生 Audrey 指出：(2) 要先改寫成 $(a\,c\,b)$ 的形式才能用技巧；(3) 直接就能用。）

**(4)**：$(a\,b)(a\,b) = (1)$——「每個換位的階都是 2」[▶ 21:00](https://youtu.be/laVj9YFTpyc?t=1260)。

**解出單一換位**[▶ 20:00](https://youtu.be/laVj9YFTpyc?t=1200)：例如從 $(b\,c)(a\,b) = (a\,b)(a\,c)$（(2) 的另一種寫法：$(a\,c\,b) = (a\,b)(a\,c)$）兩邊**右乘** $(a\,b)$，用 $(a\,b)(a\,b) = (1)$：
$$(b\,c) = (a\,b)(a\,c)(a\,b).$$
**一個換位可以寫成三個換位的乘積。**

> 📘 講義 Example 1.3.14：$(1\,2) = (1\,a)(2\,1)(a\,2)$，例如 $(1\,2) = (1\,3)(2\,1)(3\,2) = (2\,4)(4\,2)(4\,1)$。

**再一個例子**[▶ 22:00](https://youtu.be/laVj9YFTpyc?t=1320)：
$$(5\,7\,9\,2) = (5\,2)(5\,9)(5\,7).$$

## 4. 觀察：換位個數的奇偶不變

[▶ 22:30](https://youtu.be/laVj9YFTpyc?t=1350)「看這些操作，它們暗示了什麼？」

| 恆等式 | 左邊換位數 | 右邊換位數 |
|---|---|---|
| $(a\,b)(a\,b) = (1)$ | 2 | 0 |
| $(c\,d)(a\,b) = (a\,b)(c\,d)$ | 2 | 2 |
| $(b\,c)(a\,b) = (c\,a)(c\,b)$ | 2 | 2 |
| $(b\,c) = (a\,b)(a\,c)(a\,b)$ | 1 | 3 |

**共同點**[▶ 23:00](https://youtu.be/laVj9YFTpyc?t=1380)：開始是偶數個、結束也是偶數個；開始是奇數個、結束也是奇數個。「不管你怎麼算，換位總數的**奇偶**保持不變。」

**注意：偶/奇不是指循環長度**[▶ 24:00](https://youtu.be/laVj9YFTpyc?t=1440)

【Q&A】學生問恆等置換——它不是換位的乘積吧？老師趁機先講定義，然後強調：
- 「這是個有點奇怪但真實的事：**奇數長度的循環是偶置換**，**偶數長度的循環是奇置換**。」
- 「偶和奇指的是**換位分解的個數**，不是循環長度。」
- 例：$(1\,4\,9\,2\,5)$（長度 5）= 4 個換位，是**偶**的；$(5\,7\,9\,2)$（長度 4）= 3 個換位，是**奇**的。

「你讓我說太快了。好問題。」

## 5. 引理：恆等置換只能寫成偶數個換位

[▶ 23:30](https://youtu.be/laVj9YFTpyc?t=1410)

> **引理**（講義 Lemma 1.3.15）　$n\ge2$。若恆等置換寫成換位的乘積，則換位的個數是**偶數**。

【口頭】[▶ 26:00](https://youtu.be/laVj9YFTpyc?t=1560)「我不確定我們有時間證，但我開始吧。」（老師照著講義念，證明來自哥哥 Bill。）

**證明**

**先有一個偶的寫法**：$n\ge2$，所以 $(1\,2)\in S_n$，而
$$(1) = (1\,2)(1\,2).$$

**一般情況**[▶ 26:30](https://youtu.be/laVj9YFTpyc?t=1590)：設
$$(1) = (a_1\,a_2)(a_3\,a_4)\cdots(a_{l-1}\,a_l).$$
要證明這裡換位的個數（$l/2$）是偶數。

【課堂討論】[▶ 27:30](https://youtu.be/laVj9YFTpyc?t=1650) 老師問這逼得 $l$ 是什麼。學生：「偶數。」「那還不夠——$l$ 一定是偶數（每個換位兩個符號）。我們希望 $l$ 是 **4 的倍數**：4、8、12、16……」

**四種「推過去」的情況**[▶ 28:00](https://youtu.be/laVj9YFTpyc?t=1680)（$a,b,c,d$ 相異）：

| 情況 | 改寫 | 效果 |
|---|---|---|
| $(c\,d)(a\,b)$ | $= (a\,b)(c\,d)$ | $a$ 往左移 |
| $(b\,c)(a\,b)$ | $= (c\,a)(c\,b)$ | $a$ 往左移 |
| $(a\,c)(a\,b)$ | $= (b\,a)(b\,c)$ | $a$ 往左移 |
| $(a\,b)(a\,b)$ | $= (1)$ | 兩個換位**一起消失** |

「在前三種情況，我們可以把 $a$ 往**左**移。最後一種，$a$ 完全被消掉。」[▶ 29:30](https://youtu.be/laVj9YFTpyc?t=1770)

**論證**[▶ 30:00](https://youtu.be/laVj9YFTpyc?t=1800)：
1. 設 $a$ 是所有換位裡出現的**最大**數字。
2. 取最右邊那個含 $a$ 的換位，用上面的規則把它往左推。
3. 一直推，$a$ **一定會在某處兩兩相消**（碰到 $(a\,b)(a\,b)$ 的情況）。
4. **為什麼一定會消？**若沒有，最後會變成
$$(1) = (a\,b)\,\tau,$$
   其中 $\tau$ 裡**沒有** $a$。但 $\tau$ 不動 $a$，而 $(a\,b)$ 把 $a$ 送到 $b$，所以 $(a\,b)\tau$ 把 $a$ 送到 $b$——**不是恆等**，矛盾。
5. 所以 $a$ 的所有出現都能**成對**消掉。接著對下一個最大的數重複。
6. 最後所有換位都消掉。每次消去都是**成對**的，換位總數在推的過程中又不變，所以原本的個數是**偶數**。$\blacksquare$

【口頭】[▶ 31:00](https://youtu.be/laVj9YFTpyc?t=1860)「我們要嘛移除一對，要嘛保留一對。所以它是偶的，不管怎麼改寫都保持偶。」「如果你不信，Gallian 有不同的證明。我講義裡的這個要歸功於我哥。」

## 6. 偶置換、奇置換、符號

[▶ 31:30](https://youtu.be/laVj9YFTpyc?t=1890)

> **定義**　$\sigma\in S_n$，$\sigma = \gamma_1\gamma_2\cdots\gamma_k$，$\gamma_i$ 都是換位。
> - $k$ 偶數：$\sigma$ 是**偶置換（even permutation）**。
> - $k$ 奇數：$\sigma$ 是**奇置換（odd permutation）**。

> **定義（符號 sign）**[▶ 32:30](https://youtu.be/laVj9YFTpyc?t=1950)
> $$\operatorname{sgn}(\sigma) = (-1)^\sigma = \begin{cases}1 & \sigma\text{ 偶}\\-1 & \sigma\text{ 奇}\end{cases}$$

**問題**[▶ 33:00](https://youtu.be/laVj9YFTpyc?t=1980)：這個定義**良定義嗎**？一個置換有很多種換位分解，會不會有的是偶數個、有的是奇數個？「我們剛證明了恆等是偶的。有了這個，其他的就不難。」

## 7. 定理：每個置換恰好是偶或奇

[▶ 33:00](https://youtu.be/laVj9YFTpyc?t=1980)

> **定理**（講義 Thm 1.3.17）　$S_n$ 的每個置換**恰好**是偶的或奇的，不會兩者都是。（「我用的是數學上精確的『二者擇一』。」）

**證明**[▶ 33:30](https://youtu.be/laVj9YFTpyc?t=2010)

設 $\sigma$ 有兩種換位分解：
$$\sigma = (a_1\,a_2)\cdots(a_{2l-1}\,a_{2l})\quad(l\text{ 個}),\qquad\sigma = (b_1\,b_2)\cdots(b_{2k-1}\,b_{2k})\quad(k\text{ 個}).$$

（老師提醒 [▶ 34:30](https://youtu.be/laVj9YFTpyc?t=2070)：別被下標 $2l$、$2k$ 騙了——那只是符號的個數。換位個數是 $l$ 和 $k$，可以是奇數或偶數。）

1. $(1) = \sigma\sigma^{-1}$。左邊的 $\sigma$ 用 $a$ 的寫法，$\sigma^{-1}$ 用 $b$ 的寫法 [▶ 35:00](https://youtu.be/laVj9YFTpyc?t=2100)。
2. **推廣的襪子-鞋子**（可以用歸納法證）：乘積的反元素 = 反順序的反元素乘積。
$$\sigma^{-1} = (b_{2k-1}\,b_{2k})^{-1}\cdots(b_1\,b_2)^{-1}.$$
3. 【課堂討論】[▶ 36:00](https://youtu.be/laVj9YFTpyc?t=2160)「換位的反元素是什麼？」**它自己**。所以
$$(1) = (a_1\,a_2)\cdots(a_{2l-1}\,a_{2l})\,(b_{2k-1}\,b_{2k})\cdots(b_1\,b_2).$$
4. 這是恆等置換的 $l+k$ 個換位的分解。由引理，**$l+k$ 是偶數** [▶ 37:00](https://youtu.be/laVj9YFTpyc?t=2220)。
5. 所以 $l,k$ **同為偶數或同為奇數**。

因此 $\sigma$ 的換位個數要嘛永遠是偶，要嘛永遠是奇。「如果兩者都可能，$l+k$ 就是奇數，違反恆等是偶置換。」$\blacksquare$

【口頭】[▶ 37:30](https://youtu.be/laVj9YFTpyc?t=2250)「這個論證很好玩。上面那個（引理）比較繁瑣，但這個很漂亮。」

> 📘 **推論 1.3.18**：偶 × 偶 = 偶，奇 × 奇 = 偶，偶 × 奇 = 奇。（$j$ 個換位接 $k$ 個換位，得 $j+k$ 個。）也就是
> $$\operatorname{sgn}(\sigma\beta) = \operatorname{sgn}(\sigma)\operatorname{sgn}(\beta).$$

> 📘 講義 Ex 1.3.19–1.3.20：$r$-循環需要 $r-1$ 個換位，所以 **$r$ 奇數的循環是偶置換，$r$ 偶數的循環是奇置換**。$(1)$、$(1\,2\,3)$、$(1\,2\,3\,4\,5)$ 偶；$(1\,2)$、$(1\,2\,3\,4)$、$(1\,2\,3\,4\,5\,6)$ 奇。

## 8. 【口頭】用置換定義行列式

[▶ 38:00](https://youtu.be/laVj9YFTpyc?t=2280)「一個好玩的事實：」
$$\det(A) = \sum_{\sigma\in S_n}\operatorname{sgn}(\sigma)\,A_{1\sigma(1)}A_{2\sigma(2)}\cdots A_{n\sigma(n)}.$$

- 「這是用置換的和寫出的行列式公式。」
- 【口頭】「如果你上過我的線性代數，我沒給你們這個，因為你們還不知道置換是什麼——用你不懂的東西定義行列式，好像有點殘忍。數學家比較喜歡這個定義。我給的是對**指標**求和，不是對置換求和，但它們是同一件事。」

> 📘 講義用 $2\times2$ 驗證：$S_2 = \{(1),(1\,2)\}$，$(1)$ 偶、$(1\,2)$ 奇，所以
> $$\det A = A_{11}A_{22}-A_{12}A_{21}.$$

## 9. Ruffini 定理

[▶ 39:30](https://youtu.be/laVj9YFTpyc?t=2370)「我們看到兩種分解：**互斥循環**和**換位**。兩個都有用，各有各的位置。」

【口頭】[▶ 40:00](https://youtu.be/laVj9YFTpyc?t=2400)「Ruffini 定理挺驚人的：照 Gallian 的說法它是 1799 年的。但讀 Rotman，他說 **Cayley 在 1815 年**才引入循環記號。所以不管 Ruffini 說了什麼，都不是用這種方式說的。」

> **定理（Ruffini）**　$\sigma = \gamma_1\gamma_2\cdots\gamma_k$，$\gamma_i$ **互斥**，長度分別是 $m_1,\dots,m_k$。則
> $$|\sigma| = \operatorname{lcm}(m_1,\dots,m_k).$$

【Q&A】[▶ 41:30](https://youtu.be/laVj9YFTpyc?t=2490)「長度是什麼意思？」老師：「好問題，我好像沒定義。$k$-循環的長度是 $k$。」

### 9.1 引理：循環的反元素與階

[▶ 41:30](https://youtu.be/laVj9YFTpyc?t=2490)「在證明之前，有幾顆更低垂的果實該摘。換個學期，我可能會把它放在上一講。」

> **引理**（講義 Lemma 1.3.22）　$\alpha = (a_1\,a_2\,\dots\,a_j)$。
> 1. $\alpha^{-1} = (a_j\,\dots\,a_2\,a_1)$——**倒過來寫**。
> 2. $|\alpha| = j$。

「如果我們聰明一點，上次就能用這些簡化 $S_3$ 的計算。」證明留給讀者（見 [[13-習題課-Gallian第5章]] 第 7 節）。

### 9.2 證明

[▶ 43:00](https://youtu.be/laVj9YFTpyc?t=2580) 令 $m = \operatorname{lcm}(m_1,\dots,m_k)$。

**Step 1：$\sigma^m = (1)$**[▶ 43:30](https://youtu.be/laVj9YFTpyc?t=2610)

互斥循環**可交換**，所以指數律可以用：
$$\sigma^m = (\gamma_1\gamma_2\cdots\gamma_k)^m = \gamma_1^m\gamma_2^m\cdots\gamma_k^m.$$

⚠️ [▶ 44:00](https://youtu.be/laVj9YFTpyc?t=2640)「這裡用到它們互斥、可交換。如果不交換就**不能**這樣做：$ab\neq ba$ 時，$(ab)^m = a^mb^m$ 是**錯的**。危險！」

$m$ 是每個 $m_i$ 的倍數（$m_i\mid m$）[▶ 44:30](https://youtu.be/laVj9YFTpyc?t=2670)。由引理 $|\gamma_i| = m_i$，而「元素的次方是它階的倍數時就是單位元素」，所以 $\gamma_i^m = (1)$ 對每個 $i$。因此
$$\sigma^m = (1)(1)\cdots(1) = (1),\qquad|\sigma|\le m.$$

**Step 2：沒有更小的**[▶ 46:00](https://youtu.be/laVj9YFTpyc?t=2760)

假設 $\sigma^j = (1)$，$j<m$。則
$$\gamma_1^j\gamma_2^j\cdots\gamma_k^j = (1).$$
各 $\gamma_i$ 互斥，動的是不同的數字，所以每個 $\gamma_i^j$ 都必須是 $(1)$。因此 $m_i\mid j$ 對每個 $i$——$j$ 是 $m_1,\dots,m_k$ 的**公倍數**，卻比**最小**公倍數還小，矛盾 [▶ 46:30](https://youtu.be/laVj9YFTpyc?t=2790)。

所以 $|\sigma| = m$。$\blacksquare$

（講義 Thm 1.3.23 是同一個證明；也可以看 Gallian p.100。講義還說：「兩兩互斥循環可交換」推廣到多個要用歸納法，留給讀者。）

### 9.3 例子

**例 1**[▶ 47:30](https://youtu.be/laVj9YFTpyc?t=2850)：回到第 1 節的 $\alpha = (1\,4\,9\,2\,5)(3\,7)$。
- 【課堂討論】「這些是互斥循環嗎？」是。長度 5 和 2。
$$|\alpha| = \operatorname{lcm}(5,2) = 10.$$
- 老師提醒：通常寫 $|\alpha|$，不寫「order($\alpha$)」。

**例 2**[▶ 48:30](https://youtu.be/laVj9YFTpyc?t=2910)：$\alpha = (1\,2\,3\,4)$、$\beta = (1\,7\,4)$。求 $|\alpha\beta|$。

【課堂討論】[▶ 49:30](https://youtu.be/laVj9YFTpyc?t=2970)「我建議**不要**直接算，太麻煩。」學生：「我以前就是那樣做的。」「但現在有了 Ruffini，可以做得更好。」

**先化成互斥循環**（從右往左）：
- $1$：$\beta$ 送到 7，$\alpha$ 不動 7 → 7；$7$：$\beta$ 送到 4，$\alpha$ 送到 1 → 1。閉合：$(1\,7)$。
- $2$：$\beta$ 不動，$\alpha$ 送到 3；$3\to4$；$4$：$\beta$ 送到 1，$\alpha$ 送到 2。閉合：$(2\,3\,4)$。

（老師一度算成「4 去 1 再去 2……等等」，然後理順。）

$$\alpha\beta = (1\,2\,3\,4)(1\,7\,4) = (1\,7)(2\,3\,4).$$

由 Ruffini：
$$|\alpha\beta| = \operatorname{lcm}(2,3) = 6.$$
「我們不用把它乘 6 次方就知道了。這對作業很有用，我想。」

> 📘 講義 Ex 1.3.24 的完整版：$\alpha^{-1} = (4\,3\,2\,1)$、$|\alpha| = 4$；$\beta^{-1} = (4\,7\,1)$、$|\beta| = 3$。用襪子-鞋子，
> $$\sigma^{-1} = (\alpha\beta)^{-1} = \beta^{-1}\alpha^{-1} = (4\,7\,1)(4\,3\,2\,1) = (1\,7)(2\,4\,3),$$
> 所以 $|\sigma^{-1}| = 6$，又 $|\sigma| = |\sigma^{-1}|$。再取反元素：$((1\,7)(2\,4\,3))^{-1} = (3\,4\,2)(7\,1) = (1\,7)(2\,3\,4)$，跟直接算一致。

## 10. 交錯群 An

[▶ 48:30](https://youtu.be/laVj9YFTpyc?t=2910)「喔，我忘了提：」

> **定義**　$A_n = \{\sigma\in S_n : \operatorname{sgn}(\sigma) = 1\}$，所有**偶置換**。叫做**交錯群（alternating group）**。

- 它是 $S_n$ 的**子群**（作業有一兩題）。
- 「讀講義：我**明確算出了 $A_3$ 和 $A_4$**，你們可以更了解 $A_n$ 是什麼。」[▶ 50:30](https://youtu.be/laVj9YFTpyc?t=3030)「我好煩，寫那些花了我一個小時，結果今天幾乎沒講到。」

> 📘 **講義 §2.4（Thm 2.4.18–Ex 2.4.22）的 $A_3$、$A_4$**：
> - **$A_n$ 是子群**：偶 × 偶 = 偶；偶置換的反元素（反序的同樣個數換位）還是偶的。用子群判別法。
> - 講義說：「要用 **degree（次數）**這個詞，因為 $A_n$ 的**階**不是 $n$。」**$|A_n| = n!/2$**（$n>1$；Gallian p.103）。
> - $A_3 = \{(1),\ (1\,3)(1\,2),\ (1\,2)(1\,3)\} = \{(1),(1\,2\,3),(1\,3\,2)\}$。兩個非單位元素的階都是 3。
> - $|A_4| = 4!/2 = 12$：
> $$A_4 = \{(1),\ (12)(34),\ (13)(24),\ (14)(23),\ (123),(132),(234),(243),(314),(341),(412),(421)\}.$$
>   恆等、三個「兩個互斥換位的乘積」（階 2）、八個 3-循環（各固定一個數）。$A_4$ 可由 $(1\,2)(3\,4)$ 和 $(1\,2\,3)$ 生成。

「週末愉快。我閉嘴了。」

## 11. 一頁速查表

### 11.1 分解

| 分解 | 方法 | 唯一？ |
|---|---|---|
| 互斥循環 | 跟著數字走，繞回來就閉合 | 唯一（不計順序和旋轉） |
| 換位 | $(a_1\cdots a_k) = (a_1a_k)(a_1a_{k-1})\cdots(a_1a_2)$ | 很不唯一，但**個數的奇偶**唯一 |

### 11.2 換位恆等式（$a,b,c,d$ 相異）

| 恆等式 | 用途 |
|---|---|
| $(c\,d)(a\,b) = (a\,b)(c\,d)$ | 互斥可交換 |
| $(b\,c)(a\,b) = (a\,c\,b) = (c\,a)(c\,b)$ | 把 $a$ 往左推 |
| $(a\,c)(a\,b) = (a\,b\,c) = (b\,a)(b\,c)$ | 把 $a$ 往左推 |
| $(a\,b)(a\,b) = (1)$ | 成對消去 |
| $(b\,c) = (a\,b)(a\,c)(a\,b)$ | 一個 = 三個 |

### 11.3 奇偶性

| 結果 | 關鍵一步 |
|---|---|
| $(1)$ 只能寫成偶數個換位 | 把最大的數 $a$ 往左推，最後一定成對消掉；否則 $(1) = (a\,b)\tau$ 把 $a$ 送到 $b$ |
| 每個置換恰好偶或奇 | $(1) = \sigma\sigma^{-1}$ 給出 $l+k$ 個換位，$l+k$ 偶 ⇒ $l,k$ 同奇偶 |
| $\operatorname{sgn}(\sigma\beta) = \operatorname{sgn}\sigma\operatorname{sgn}\beta$ | 換位個數相加 |
| $r$-循環的符號 $= (-1)^{r-1}$ | $r-1$ 個換位 |

**記住**：奇數長度的循環是**偶**置換；偶數長度的循環是**奇**置換。

### 11.4 Ruffini 定理

$$|\gamma_1\cdots\gamma_k| = \operatorname{lcm}(m_1,\dots,m_k)\quad(\gamma_i\text{ 互斥})$$

關鍵一步：互斥 ⇒ 可交換 ⇒ $\sigma^m = \gamma_1^m\cdots\gamma_k^m$。**不交換時 $(ab)^m\neq a^mb^m$。**

例：$(14925)(37)$ 的階 10；$(1234)(174) = (17)(234)$ 的階 6。

### 11.5 術語

| 中文 | English |
|---|---|
| 互斥循環分解 | disjoint cycle decomposition |
| 換位 | transposition |
| 偶置換；奇置換 | even permutation; odd permutation |
| 符號 | sign, $\operatorname{sgn}(\sigma) = (-1)^\sigma$ |
| 良定義 | well-defined |
| 循環的長度 | length of a cycle |
| 交錯群；次數 | alternating group; degree |

## 附：本集一句話總結

> **每個置換都能化成互斥循環，而每個 $k$-循環又能拆成 $k-1$ 個換位；換位分解雖然不唯一，但個數的奇偶是固定的（關鍵是恆等置換只能寫成偶數個換位——把最大的數往左推，一定成對消掉），所以「偶置換／奇置換」和符號 $\operatorname{sgn}$ 是良定義的；偶置換組成交錯群 $A_n$；Ruffini 定理則說互斥循環乘積的階就是長度的最小公倍數。**
