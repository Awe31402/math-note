# 第 14 集 · L9：偶置換與奇置換、Ruffini 定理 [▶ 影片](https://www.youtube.com/watch?v=laVj9YFTpyc&list=PLBY4G2o7DhF0JCgapYKrqibGaJuvV4Gkb)

## 本集概要

- 互斥循環分解的例子；每個循環都能寫成**換位**的乘積。
- 換位的計算技巧：$(bc)(ab) = (ca)(cb)$、$(ac)(ab) = (ba)(bc)$ 等。觀察：換位個數的**奇偶性**在這些操作下不變。
- **引理**：恆等置換寫成換位乘積時，換位個數一定是**偶數**。
- **定理**：每個置換要嘛是偶置換、要嘛是奇置換，**不會兩者都是**。定義**符號** $\operatorname{sgn}(\sigma) = \pm1$；行列式的置換公式。
- **Ruffini 定理**（完整證明）：互斥循環乘積的階 = 長度的 lcm。
- 交錯群 $A_n$（講義有 $A_3$、$A_4$ 的完整列表）。

> 📘 講義對應：2018 講義 §1.3 Prequel 3 後半（p.27–32）：Thm 1.3.10、1.3.11、Ex 1.3.13、Lemma 1.3.15、Def 1.3.16、Thm 1.3.17、Def 1.3.21、Lemma 1.3.22、Thm 1.3.23、Ex 1.3.24。證明出自老師的哥哥 Bill 的講義。

## 筆記

### 1. 互斥循環分解（複習）[▶ 00:30](https://youtu.be/laVj9YFTpyc?t=30)

$$\alpha = \begin{pmatrix}1&2&3&4&5&6&7&8&9\\4&5&7&9&1&6&3&8&2\end{pmatrix}\in S_9$$

- 從 1 開始：$1\to4\to9\to2\to5\to1$，得 $(14925)$ [▶ 02:30](https://youtu.be/laVj9YFTpyc?t=150)。
- 挑還沒用過的 3：$3\to7\to3$，得 $(37)$ [▶ 04:00](https://youtu.be/laVj9YFTpyc?t=240)。
- $6$、$8$ 不動。

$$\alpha = (14925)(37).$$
這叫**（互斥）循環分解 (cycle decomposition)**。

> **定理（講義 Thm 1.3.10）**　每個 $\sigma\in S_n$ 都能寫成互斥循環的乘積 [▶ 05:30](https://youtu.be/laVj9YFTpyc?t=330)。

證明就是上面的做法：從一個數開始追到繞回來，再挑新的數，直到用完。

### 2. 循環 → 換位 [▶ 06:30](https://youtu.be/laVj9YFTpyc?t=390)

$$(14925) = (15)(12)(19)(14).$$
規律：第一個數和最後一個配，然後和倒數第二個配……一路往回 [▶ 07:00](https://youtu.be/laVj9YFTpyc?t=420)。
- 驗證：$5$ 只被 $(15)$ 動，$5\to1$ ✓；$2$：$(12)$ 送到 $1$，$(15)$ 送到 $5$，所以 $2\to5$ ✓ [▶ 07:30](https://youtu.be/laVj9YFTpyc?t=450)。

> **定理（講義 Thm 1.3.11）**　$n\ge2$。每個置換都能寫成**換位 (transposition)**（2-循環）的乘積。關鍵公式：
> $$(a_1a_2\cdots a_k) = (a_1a_k)(a_1a_{k-1})\cdots(a_1a_3)(a_1a_2).$$

- 叫「換位」是因為 2-循環就是**交換兩個數** [▶ 08:30](https://youtu.be/laVj9YFTpyc?t=510)。
- 恆等置換也可以：$(1) = (12)(12)$（需要 $n\ge2$）。

**證明公式**（逐個元素檢查）[▶ 09:00](https://youtu.be/laVj9YFTpyc?t=540)：在 $S_n$ 裡（$k\le n$），以 $a_2$ 為例：
- 左邊：$\alpha(a_2) = a_3$。
- 右邊（由右往左）：$(a_1a_2)$ 送 $a_2\to a_1$；$(a_1a_3)$ 送 $a_1\to a_3$；之後的換位都不含 $a_3$，所以停在 $a_3$ ✓ [▶ 12:00](https://youtu.be/laVj9YFTpyc?t=720)。

想要更嚴格可以改用歸納法。

**另一個例子** [▶ 22:00](https://youtu.be/laVj9YFTpyc?t=1320)：$(5792) = (52)(59)(57)$。

### 3. 換位的計算技巧 [▶ 13:30](https://youtu.be/laVj9YFTpyc?t=810)（講義 Ex 1.3.13）

設 $a,b,c,d$ 互不相同。
1. **互斥換位可交換** [▶ 14:00](https://youtu.be/laVj9YFTpyc?t=840)：$(ab)(cd) = (cd)(ab)$。
2. **乘開、轉一圈、再拆開** [▶ 14:30](https://youtu.be/laVj9YFTpyc?t=870)：
$$(bc)(ab) = (acb) = (cba) = (ca)(cb).$$
（驗證：$a$ 先被 $(ab)$ 送到 $b$，再被 $(bc)$ 送到 $c$，所以 $a\to c$。）
3. 同樣地 [▶ 18:30](https://youtu.be/laVj9YFTpyc?t=1110)：
$$(ac)(ab) = (abc) = (bca) = (ba)(bc).$$
4. $(ab)(ab) = (1)$：每個換位的階都是 2 [▶ 21:00](https://youtu.be/laVj9YFTpyc?t=1260)。

**解出單一換位** [▶ 20:30](https://youtu.be/laVj9YFTpyc?t=1230)：從 $(ac)(ab) = (ba)(bc)$ 兩邊左乘 $(ab)$，得
$$(bc) = (ab)(ac)(ab).$$
一個換位可以寫成三個換位。

**關鍵觀察** [▶ 22:30](https://youtu.be/laVj9YFTpyc?t=1350)：上面每個等式，兩邊換位的個數**奇偶相同**：0 ↔ 2、1 ↔ 3、2 ↔ 2。怎麼化簡，奇偶都不變。

### 4. 引理：恆等置換是偶的 [▶ 23:30](https://youtu.be/laVj9YFTpyc?t=1410)

> **定義（偶置換、奇置換）**　能寫成偶數個換位的乘積，叫**偶置換 (even permutation)**；奇數個叫**奇置換 (odd permutation)**。

**容易搞混** [▶ 24:00](https://youtu.be/laVj9YFTpyc?t=1440)：奇偶指的是**換位的個數**，不是循環的長度。
- **奇數長度**的循環是**偶置換**：$(123) = (13)(12)$。
- **偶數長度**的循環是**奇置換**：$(1234) = (14)(13)(12)$、$(12)$。

> **引理（講義 Lemma 1.3.15）**　$n\ge2$。若恆等置換寫成換位的乘積，則換位個數是偶數。

**證明大意** [▶ 26:00](https://youtu.be/laVj9YFTpyc?t=1560)　設 $(1) = (a_1a_2)(a_3a_4)\cdots(a_{l-1}a_l)$。

相鄰兩個換位有四種情形（$a$ 是固定的某個數）[▶ 28:00](https://youtu.be/laVj9YFTpyc?t=1680)：
- $(cd)(ab) = (ab)(cd)$
- $(bc)(ab) = (ca)(cb)$
- $(ac)(ab) = (ba)(bc)$
- $(ab)(ab) = (1)$

前三種都能把 $a$ **往左移**，第四種把兩個 $a$ **一起消掉** [▶ 29:30](https://youtu.be/laVj9YFTpyc?t=1770)。
- 取出現過的最大數 $a$，把最右邊的 $a$ 一直往左移。
- 一定會遇到第四種情形而成對消掉。否則最後會得到 $(1) = (ab)\tau$，而 $\tau$ 裡沒有 $a$：$\tau$ 固定 $a$，$(ab)$ 把 $a$ 送到 $b$，所以 $(ab)\tau\neq(1)$，矛盾 [▶ 30:30](https://youtu.be/laVj9YFTpyc?t=1830)。
- 把所有 $a$ 消完，再處理下一個數。最後全部消光。
- 每次消掉**兩個**，所以原本的個數是偶數。$\blacksquare$

（Gallian 有不同的證明。）

### 5. 定理：每個置換恰好是偶或奇 [▶ 33:00](https://youtu.be/laVj9YFTpyc?t=1980)

> **定義（符號 sign）**
> $$\operatorname{sgn}(\sigma) = (-1)^\sigma = \begin{cases}1 & \sigma\text{ 是偶置換}\\ -1 & \sigma\text{ 是奇置換}\end{cases}$$

這要先確定定義合理（**良定義**）：會不會有置換既能寫成偶數個、又能寫成奇數個換位？

> **定理（講義 Thm 1.3.17）**　每個 $\sigma\in S_n$ 不是偶置換就是奇置換，**不會兩者都是**。

**證明** [▶ 33:30](https://youtu.be/laVj9YFTpyc?t=2010)
- 設 $\sigma = (a_1a_2)\cdots(a_{2l-1}a_{2l})$，也 $= (b_1b_2)\cdots(b_{2k-1}b_{2k})$（$l$ 個和 $k$ 個換位）。
- 用**推廣的襪子鞋子**規則，再用「換位的反元素是自己」[▶ 35:30](https://youtu.be/laVj9YFTpyc?t=2130)：
$$(1) = \sigma\sigma^{-1} = (a_1a_2)\cdots(a_{2l-1}a_{2l})\,(b_{2k-1}b_{2k})\cdots(b_1b_2).$$
- 這是恆等置換的 $l+k$ 個換位分解。由引理，$l+k$ 是偶數 [▶ 36:30](https://youtu.be/laVj9YFTpyc?t=2190)。
- 所以 $l$、$k$ 同為偶數或同為奇數。$\blacksquare$

老師說：引理的證明很繁瑣，但這個證明很漂亮 [▶ 37:30](https://youtu.be/laVj9YFTpyc?t=2250)。

**推論（講義 Cor 1.3.18）**：偶×偶 = 偶，奇×奇 = 偶，偶×奇 = 奇。所以 $\operatorname{sgn}(\sigma\beta) = \operatorname{sgn}(\sigma)\operatorname{sgn}(\beta)$。

**應用：行列式** [▶ 38:00](https://youtu.be/laVj9YFTpyc?t=2280)
$$\det(A) = \sum_{\sigma\in S_n}\operatorname{sgn}(\sigma)\,A_{1\sigma(1)}A_{2\sigma(2)}\cdots A_{n\sigma(n)}.$$
- 數學家偏好這個定義。老師的線性代數課用的是「對指標求和」的版本，因為學生當時還不懂置換 [▶ 39:00](https://youtu.be/laVj9YFTpyc?t=2340)。
- $2\times2$ 的例子（講義）：$S_2 = \{(1),(12)\}$，得 $\det A = A_{11}A_{22} - A_{12}A_{21}$。

### 6. Ruffini 定理 [▶ 40:00](https://youtu.be/laVj9YFTpyc?t=2400)

**兩種分解各有用處**：互斥循環分解、換位分解。

> 💬 歷史小插曲：Gallian 說這是 Ruffini 1799 年的結果，但 Rotman 說 Cauchy 1815 年才引入循環記號，所以 Ruffini 當時的寫法一定不一樣 [▶ 40:00](https://youtu.be/laVj9YFTpyc?t=2400)。（講義寫成 Cayley；依 Rotman 應是 Cauchy。）

> **引理（講義 Lemma 1.3.22）**　$(a_1a_2\cdots a_j)^{-1} = (a_j\cdots a_2a_1)$，且 $j$-循環的階是 $j$ [▶ 42:00](https://youtu.be/laVj9YFTpyc?t=2520)。（留作練習。）

> **定理（Ruffini；講義 Thm 1.3.23；Gallian Thm 5.3）**　設 $\sigma = \gamma_1\gamma_2\cdots\gamma_k$，$\gamma_i$ 是互斥循環，長度分別為 $m_1,\dots,m_k$。則
> $$|\sigma| = \operatorname{lcm}(m_1,\dots,m_k).$$
>
> （$k$-循環的**長度**就是 $k$ [▶ 41:30](https://youtu.be/laVj9YFTpyc?t=2490)。）

**證明** [▶ 43:00](https://youtu.be/laVj9YFTpyc?t=2580)　令 $m = \operatorname{lcm}(m_1,\dots,m_k)$。
- 互斥循環可交換，所以
$$\sigma^m = (\gamma_1\cdots\gamma_k)^m = \gamma_1^m\gamma_2^m\cdots\gamma_k^m.$$
  **警告**：若 $ab\neq ba$，$(ab)^m = a^mb^m$ 一般是**錯的** [▶ 44:00](https://youtu.be/laVj9YFTpyc?t=2640)。
- $m$ 是每個 $m_i$ 的倍數，$|\gamma_i| = m_i$，所以 $\gamma_i^m = (1)$。故 $\sigma^m = (1)$，$|\sigma|\le m$ [▶ 45:30](https://youtu.be/laVj9YFTpyc?t=2730)。
- 若有 $j<m$ 使 $\sigma^j = (1)$，則 $\gamma_1^j\cdots\gamma_k^j = (1)$。因為各循環移動的數互不重疊，每個 $\gamma_i^j$ 都必須是 $(1)$，所以 $m_i\mid j$ 對所有 $i$。於是 $j$ 是公倍數且比最小公倍數還小，矛盾 [▶ 46:00](https://youtu.be/laVj9YFTpyc?t=2760)。$\blacksquare$

**例** [▶ 47:30](https://youtu.be/laVj9YFTpyc?t=2850)：$\alpha = (14925)(37)$，$|\alpha| = \operatorname{lcm}(5,2) = 10$。

### 7. 計算例 [▶ 48:30](https://youtu.be/laVj9YFTpyc?t=2910)（講義 Ex 1.3.24）

$\alpha = (1234)$、$\beta = (174)$，求 $|\alpha\beta|$。

不要直接一次次乘；**先化成互斥循環，再用 Ruffini** [▶ 49:30](https://youtu.be/laVj9YFTpyc?t=2970)。由右往左：
- $1\xrightarrow{\beta}7\xrightarrow{\alpha}7$；$7\xrightarrow{\beta}4\xrightarrow{\alpha}1$。得 $(17)$。
- $2\xrightarrow{\alpha}3$；$3\xrightarrow{\alpha}4$；$4\xrightarrow{\beta}1\xrightarrow{\alpha}2$。得 $(234)$。

$$\alpha\beta = (1234)(174) = (17)(234),\qquad |\alpha\beta| = \operatorname{lcm}(2,3) = 6.$$

不用真的算到 6 次方。

講義另外示範用襪子鞋子求反元素：$(\alpha\beta)^{-1} = \beta^{-1}\alpha^{-1} = (471)(4321) = (17)(243)$。

### 8. 交錯群 $A_n$ [▶ 48:30](https://youtu.be/laVj9YFTpyc?t=2910)

只看 $\operatorname{sgn} = 1$ 的置換（偶置換），它們組成 $S_n$ 的子群，叫**交錯群** $A_n$。作業有一兩題。講義裡老師花了一小時把 $A_3$、$A_4$ 完整列出來，請自己讀 [▶ 50:30](https://youtu.be/laVj9YFTpyc?t=3030)。
