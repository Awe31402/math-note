## 1. 分式體的構造

> **定理**（講義 Thm 4.4.15）[▶ 00:30](https://youtu.be/DXG5msjmRS0?t=30)　$D$ 是整環 ⇒ 存在一個體 $F$，含有同構於 $D$ 的子環。

【課堂討論】「$D$ 是整環是什麼意思？」學生：「沒有零因子。」「還有呢？」「有單位元的交換環。」

【口頭】[▶ 01:30](https://youtu.be/DXG5msjmRS0?t=90)「典型例子：$\mathbb{Z}$ 和 $\mathbb{Q}$。某種意義上，這個定理**在整數存在的前提下證明了有理數存在**。」

### 1.1 配對與等價關係

[▶ 02:00](https://youtu.be/DXG5msjmRS0?t=120)
$$S = \{(a,b) : a,b\in D,\ b\neq0\}.$$
「直覺上，$(a,b)$ 是 $\dfrac ab$ 的**形式**版本。」

**定義**[▶ 03:30](https://youtu.be/DXG5msjmRS0?t=210)：
$$(a,b)\sim(c,d)\iff ad = bc.$$
「我的口訣：**外乘外 = 內乘內**。（跟 Gallian 的寫法不太一樣，是我的。）」【課堂討論】「這從哪來？」學生：「$a/b = c/d$ 當 $ad = bc$。」「對。有理數**啟發**了這個構造——但實際上這個構造**提供**了有理數的存在。」

**是等價關係**[▶ 04:30](https://youtu.be/DXG5msjmRS0?t=270)「我盡量快，不深。」
- **反身**：$ab = ba$ ⇒ $(a,b)\sim(a,b)$。
- **對稱**[▶ 05:00](https://youtu.be/DXG5msjmRS0?t=300)：$ad = bc$ ⇒ $cb = da$（用**交換**）⇒ $(c,d)\sim(a,b)$。
- **遞移**（「稍微麻煩一點，但不難多少」）[▶ 06:00](https://youtu.be/DXG5msjmRS0?t=360)：設 $ad = bc$、$cf = de$。
$$adf = (bc)f = b(cf) = b(de)\ ⇒\ (af)d = (be)d.$$
  - 【口頭】「這種論證的**經驗法則**：想辦法**用上所有給你的資料**。」
  - 【課堂討論】[▶ 08:00](https://youtu.be/DXG5msjmRS0?t=480)「為什麼可以說 $d\neq0$？」——它在**分母的位置**。「整環學過什麼？」——**消去律**：$af = be$ ⇒ $(a,b)\sim(e,f)$。✓

記 $[a,b]$ 為 $(a,b)$ 的等價類 [▶ 09:00](https://youtu.be/DXG5msjmRS0?t=540)，$F = S/\sim$。

### 1.2 運算良定義

[▶ 10:00](https://youtu.be/DXG5msjmRS0?t=600) 定義
$$[a,b]+[c,d] = [ad+bc,\ bd],\qquad[a,b][c,d] = [ac,\ bd].$$

「我在等價類的集合上定義了運算。這當然引出一個問題：**良定義嗎？**」設 $(a,b)\sim(a',b')$、$(c,d)\sim(c',d')$，要證 [▶ 11:30](https://youtu.be/DXG5msjmRS0?t=690)：
$$[ad+bc,\ bd] = [a'd'+b'c',\ b'd'],\qquad[ac,\ bd] = [a'c',\ b'd'].$$

【口頭】[▶ 13:00](https://youtu.be/DXG5msjmRS0?t=780)「我可以花 30 分鐘跟你們一起做，但看講義比較好。」（改投影；講義裡有「相當多可怕的細節」。）

**加法**[▶ 14:30](https://youtu.be/DXG5msjmRS0?t=870)：已知 $ab' = ba'$、$cd' = dc'$——「可以把有撇和沒撇的**交換位置**，有個很好的計算模式」。要證
$$(ad+bc)b'd' = bd(a'd'+b'c').$$
左邊 $= (ab')dd'+(cd')bb' = (ba')dd'+(dc')bb'$，提出 $bd$ 即得右邊。
- 【口頭】[▶ 16:30](https://youtu.be/DXG5msjmRS0?t=990)「不特別難，但需要我**忽略尖叫的小孩**之類的東西——要專心才做得對。」「如果用別的字母而不是撇號，天啊，會很可怕。有太多方法把它弄得更複雜。」
- 「試著邊抄邊懂，我覺得是**傻子的差事**。跟著走就好——這也是我打講義給你們的原因。」

**乘法**[▶ 17:00](https://youtu.be/DXG5msjmRS0?t=1020)：$acb'd' = (ab')(cd') = (ba')(dc') = bd\,a'c'$。✓

### 1.3 是體，而且含 D

[▶ 17:30](https://youtu.be/DXG5msjmRS0?t=1050)
- **加法、乘法交換**：用 $D$ 的交換性。
- **零**：$[0,x]$（$x\neq0$）[▶ 18:00](https://youtu.be/DXG5msjmRS0?t=1080)。
- **小引理**：$[ax,bx] = [a,b]$（$x\neq0$）。「也許該當作業。我寫越多就越**顯然**：$axb = bxa$。在這記號下，就是『分子分母**非零公因數可以約掉**』——但我沒假設這個，它是相似關係的**結果**。」
- **加法反元素**：$[-a,b]$，「就像 $-\frac12$ 是 $\frac12$ 的加法反元素」。
- **單位元**：$[1,1]$。
- **乘法反元素**[▶ 19:30](https://youtu.be/DXG5msjmRS0?t=1170)：$[a,b]\neq0$（即 $a\neq0$）⇒ $[b,a]$ 是反元素：$[a,b][b,a] = [ab,ba] = [1,1]$（用小引理）。

**作業**[▶ 20:00](https://youtu.be/DXG5msjmRS0?t=1200)：證明**乘法結合律**和**分配律**。「給了這麼多細節，那應該很直接。我只是要你們**擁有**這個構造。我全給你們、不讓你們做任何事，你們就不會完全懂。——而且我打字打累了。」

**嵌入 $D$**[▶ 20:30](https://youtu.be/DXG5msjmRS0?t=1230)：$\varphi(x) = [x,1]$（「把 $x$ 送到 $x/1$」）。
- 環同態（加法要一點功夫，乘法比較簡單）。
- $[x,1] = 0$ ⇒ $x = 0$，**核是 0**。
- 第一同構定理：$D/\{0\}\cong\varphi(D)$——「**雙重**同構，這裡打個星號」——所以 $F$ 含同構於 $D$ 的子環。$\blacksquare$

> **定義（分式體 field of fractions / field of quotients）**（講義 Def 4.4.16）[▶ 22:00](https://youtu.be/DXG5msjmRS0?t=1320)　上面構造的 $F$。之後的記號：
> $$F = \left\{\frac ab : a,b\in D,\ b\neq0\right\},\quad\frac ab+\frac cd = \frac{ad+bc}{bd},\quad\frac ab\cdot\frac cd = \frac{ac}{bd}.$$
> 「這記號**對證明很好，對其他任何事都很糟**。所以之後就照平常寫——但我**沒有假設**這些有意義，我用等價類**證明**了它們有意義。」

## 2. 1/2 和 3/6 是同一個數

【口頭】[▶ 22:30](https://youtu.be/DXG5msjmRS0?t=1350)「這是我想教你們環的部分原因。我想你們很多人考慮當老師——**老師在教小孩有理數之前，應該深刻理解有理數**。」

「$\frac12 = \frac36$ 嗎？**是，它們相等，是同一個數。**它們是不同的**分數**——兩個分數代表同一個數。我在這點上**跟另一位教授意見不同**，現在你們可以決定誰對誰錯——我是對的。」

- 嚴格定義：$\frac ab = \frac cd\iff ad = bc$。$1\cdot6 = 2\cdot3$ ⇒ $\frac12 = \frac36$。
- 「你要說它們是不同的分數，可以，那是真的。但它們是同一個數。如果你認為小孩能理解數和分數的差別——他們能嗎？做這種區分有幫助嗎？」（老師推薦某人的相關文章。）

## 3. 更多分式體：有理函數、ℤₚ(x)

[▶ 24:30](https://youtu.be/DXG5msjmRS0?t=1470)（講義 Ex 4.4.17–4.4.19）
- $D = \mathbb{Z}[x]$ ⇒ 分式體 $\{f(x)/g(x)\}$。
- $D = \mathbb{R}[x]$ ⇒ **有理函數**體 $\mathbb{R}(x)$。「有各種體。」
- **$\mathbb{Z}_p(x)$**[▶ 25:30](https://youtu.be/DXG5msjmRS0?t=1530)：$\mathbb{Z}_p[x]$ 的分式體。

## 4. 形式多項式：x 是不定元

[▶ 26:00](https://youtu.be/DXG5msjmRS0?t=1560)「這下一個構造我不會花那麼多時間……好吧，我收不起來。我很掙扎。」

【口頭】「**多項式是什麼？**我們想抽象地談多項式，把它和『多項式是函數』**分開**。我知道我們到目前為止都把多項式當函數。」「Gallian 有點草草帶過，我加了大約一頁。」

> **定義**（講義 Def 4.5.1–4.5.3）[▶ 27:30](https://youtu.be/DXG5msjmRS0?t=1650)
> - **形式冪級數**：$R$ 交換環，一個序列 $\sigma = (s_0,s_1,s_2,\dots)$，$s_j\in R$。
> - **多項式**：從某處以後**全為 0** 的形式冪級數。
> - $R[x]$ = 所有多項式。加法逐項；乘法
> $$(\sigma\tau)_n = \sum_{i+j = n}s_it_j = s_0t_n+s_1t_{n-1}+\cdots+s_nt_0.$$

「這就是你們熟悉的：加法加對應係數；乘法**分配、合併同次項**。我們只是把它形式化。」

- 和、積還是多項式 [▶ 31:00](https://youtu.be/DXG5msjmRS0?t=1860)。和的次數由次數大的決定——除非**領導係數抵消**：$(1+x^2)+(1-x^2) = 2$。
- 乘積的次數最多是兩者次數之和（字幕裡老師說成「$m$ 乘 $n$」，應是 $m+n$）。仔細的證明「比我說的難得多」，在 **Rotman《Elementary Abstract Algebra》**。
- 結合、分配：「你們得相信我。我不想花 30 分鐘。」

**$x$ 從哪來？**[▶ 33:00](https://youtu.be/DXG5msjmRS0?t=1980)
> **定義**（講義 Def 4.5.4）　$x = (0,1,0,0,\dots)$。

- 「這是**變數**嗎？能放實數進去嗎？**顯然不是**。」所以 $x$ 叫**不定元（indeterminate）**——只是**佔位符**。
- 【口頭】[▶ 33:30](https://youtu.be/DXG5msjmRS0?t=2010)「我知道這很微妙。我當學生第一次碰到這想法時，一直在想『**什麼？什麼？**』」

**計算**[▶ 34:30](https://youtu.be/DXG5msjmRS0?t=2070)：記 $\vec r = (r,0,0,\dots)$（「我自己的記號」）。
- $\vec c\,\tau = (ct_0,ct_1,\dots)$：可以把環元素提出來。
- $x^2 = (0,0,1,0,\dots)$、$x^3 = (0,0,0,1,\dots)$；歸納得 $x^n = e_{n+1}$（第 $n$ 個位置是 1）[▶ 36:00](https://youtu.be/DXG5msjmRS0?t=2160)。

> **定理**（講義 Thm 4.5.5）[▶ 37:00](https://youtu.be/DXG5msjmRS0?t=2220)　$\sigma = \sum_j\vec s_j\,x^j$。

【口頭】[▶ 38:00](https://youtu.be/DXG5msjmRS0?t=2280)「這一切的重點：**不把多項式看成函數**來構造它們是有意義的。$x,x^2,x^3$ 是**獨立的物件**，只是佔位符；兩個多項式相等，就看**係數是否一一相符**。」

## 5. 多項式 ≠ 多項式函數

> **例**（講義 Ex 4.5.6）[▶ 38:30](https://youtu.be/DXG5msjmRS0?t=2310)　在 $\mathbb{Z}_3[x]$：
> $$f(x) = x^3+2x,\qquad g(x) = x^5+2x.$$
> - **作為多項式不同**：$(0,2,0,1,0,\dots)\neq(0,2,0,0,0,1,\dots)$。
> - **作為函數相同**：在 $\mathbb{Z}_3$ 的每個點都是 0。

【口頭】[▶ 39:30](https://youtu.be/DXG5msjmRS0?t=2370)「我算出來兩個都是 0——我算錯了嗎？如果都是 0 我會開心得多。不過我不認為那是這例子的必要特徵。」

> 📘 筆記補充：由 Fermat 小定理，$\mathbb{Z}_3$ 中 $a^3 = a$，所以 $a^3+2a = 3a = 0$、$a^5+2a = a^3+2a = 0$。確實都是零函數。

【口頭】[▶ 40:00](https://youtu.be/DXG5msjmRS0?t=2400)「你們大多用 $\mathbb{R}$ 或 $\mathbb{C}$ 上的多項式。也許在那裡，**不同的多項式作為函數不可能相等**。我得打電話問朋友才能下定論。」——同學（Brett）提出一個好評論，老師：「對，謝謝，很好的觀點。」

> 💬 字幕沒錄到同學的話。標準事實：在**無限**整環上（例如 $\mathbb{R}$、$\mathbb{C}$），兩個多項式作為函數相等 ⇒ 差有無限多個根 ⇒ 差是零多項式。

**代值映射：兩個世界的橋**（講義 Def 4.5.7）[▶ 41:00](https://youtu.be/DXG5msjmRS0?t=2460)
$$\varphi_a\!\left(\sum s_jx^j\right) = \sum s_ja^j.$$
- 「我剛跳完一長段『多項式不必是函數』的歌舞，現在告訴你們怎麼**把它們變回函數**。抱歉。」
- 「把 $x$ 換成 $a$——你說：『謝謝，能把我人生的那 15 分鐘還我嗎？』我知道。但最後 15 分鐘**我們確實做了些事**。我不確定能說服你們，我還在努力。」

## 6. D[x] 是整環

> **定理**（講義 Thm 4.5.8）[▶ 42:00](https://youtu.be/DXG5msjmRS0?t=2520)　$D$ 整環 ⇒ $D[x]$ 整環。「**終於**今天說了點有實質的東西。」

**證明**：$f = a_nx^n+\cdots$、$g = b_mx^m+\cdots$，都非零（$a_n,b_m\neq0$）。
- 【課堂討論】「乘積的領導項怎麼來？」——**領導係數的乘積**：$fg = a_nb_mx^{n+m}+\cdots$。
- $D$ 無零因子 ⇒ $a_nb_m\neq0$ ⇒ $fg\neq0$ [▶ 43:00](https://youtu.be/DXG5msjmRS0?t=2580)。
- 【Q&A】學生指出零多項式沒有真正的領導係數。老師：「對。零多項式乘任何東西是 0，不違反整環。麻煩的是兩個**非零**的乘起來是 0——這裡不會。」
- 交換、單位元是常數多項式 1（「可以回到序列的世界去證，如果你有興趣——我沒興趣」）。$\blacksquare$

## 7. 除法算則與它的推論

> **定理（除法算則 division algorithm）**（講義 Thm 4.5.9）[▶ 45:00](https://youtu.be/DXG5msjmRS0?t=2700)　$F$ 是體，$f,g\in F[x]$，$g\neq0$。存在**唯一**的 $q,r\in F[x]$：
> $$f(x) = g(x)q(x)+r(x),\quad r = 0\ \text{或}\ \deg r<\deg g.$$

- **次數**[▶ 45:30](https://youtu.be/DXG5msjmRS0?t=2730)：非零常數多項式次數 0；**零多項式的次數沒有定義**。其他的看最高非零係數的次方。
- 證明在 Gallian p.286–287，「很好懂，推薦你們走一遍。也許改天講。」

> **推論（餘式定理）**（講義 Cor 4.5.10）[▶ 46:30](https://youtu.be/DXG5msjmRS0?t=2790)　$f(a)$ 是 $f(x)$ 除以 $x-a$ 的餘式。

證明：$f(x) = (x-a)q(x)+r$，$r = 0$ 或 $\deg r<1$ ⇒ $r$ 是常數。代 $a$：$f(a) = (a-a)q(a)+r = r$。「高中代數——也許，也許，也許學過。」

**定義**（講義 Def 4.5.11）[▶ 47:30](https://youtu.be/DXG5msjmRS0?t=2850)
- $c$ 是 $f$ 的**零點（根）**：$f(c) = 0$。
- **重數 $k$**：$(x-c)^k$ 是因式，但 $(x-c)^{k+1}$ 不是。（板書先寫成 $k-1$，學生糾正 [▶ 49:00](https://youtu.be/DXG5msjmRS0?t=2940)：「一定是 $+1$，謝謝，很好的評論。」）

> **推論（因式定理）**（講義 Cor 4.5.12）[▶ 48:00](https://youtu.be/DXG5msjmRS0?t=2880)　$a$ 是 $f$ 的零點 $\iff$ $x-a$ 是 $f$ 的因式。

**作業**：「你們該謝我，這題**很好玩**，幾行而已。它會幫你們內化除法算則和因式的思考方式。有些東西你們只是被**制約**去假設，我要你們想清楚邏輯。」

**不在體上會出怪事**[▶ 49:30](https://youtu.be/DXG5msjmRS0?t=2970)（講義 Ex 4.5.13）
- $\mathbb{Z}_6$ 上一個二次式有 **4 個零點**。
- **四元數**上的二次式有**無窮多**零點。「四元數幾乎是體——每個非零元素都可除，唯一的問題是**不交換**。」
- 有零因子的環上的多項式也有零因子。

> 📘 講義的例子：$\mathbb{Z}_6$ 中 $x^2+3x+2$ 的零點是 $1,2,4,5$；$(2x+2)(3x^2+3) = 0$。
>
> 📘 筆記補充（四元數）：$x^2+1 = 0$ 的解包括所有 $bi+cj+dk$，$b^2+c^2+d^2 = 1$。

> **推論**（講義 Cor 4.5.14）[▶ 50:30](https://youtu.be/DXG5msjmRS0?t=3030)　體上 $n$ 次多項式**最多 $n$ 個零點**（計重數）。

證明想法：若有 $n+1$ 個零點，每個零點給出一個因式，乘開次數至少 $n+1$，矛盾。「我個人喜歡這裡的**反證法**——對我來說有點不尋常。」

## 8. 預告：PID

[▶ 51:00](https://youtu.be/DXG5msjmRS0?t=3060)（講義 Def 4.5.16、Thm 4.5.17–18）
- **主理想整環（PID）**：每個理想都是主理想的整環。
- $F$ 是體 ⇒ $F[x]$ 是 PID。
- $I\neq\{0\}$ 是 $F[x]$ 的理想，$g\in I$：$I = \langle g\rangle\iff g$ 是 $I$ 中**次數最小**的非零多項式。

【口頭】「一如往常，結尾還剩一點。我好像永遠到不了下一整講——被上一講的 20% 卡住。」

## 9. 一頁速查表

### 9.1 分式體

| 步驟 | 關鍵一步 |
|---|---|
| $(a,b)\sim(c,d)\iff ad = bc$ | 外乘外 = 內乘內 |
| 遞移律 | $(af)d = (be)d$，**消去律**（$d\neq0$） |
| 加法良定義 | $ab' = ba'$、$cd' = dc'$ 交換撇號 |
| $[ax,bx] = [a,b]$ | 非零公因數可約 |
| 反元素 | $[a,b]^{-1} = [b,a]$ |
| 嵌入 | $x\mapsto[x,1]$，核 0 |

例：$\mathbb{Z}\to\mathbb{Q}$；$F[x]\to F(x)$；$\mathbb{Z}_p(x)$ 是特徵 $p$ 的**無限**體。

### 9.2 多項式

| 事實 | 內容 |
|---|---|
| 多項式 | 最後全為 0 的序列 $(s_0,s_1,\dots)$ |
| $x$ | $(0,1,0,\dots)$，不定元 |
| 相等 | 係數全相同 |
| 多項式 ≠ 函數 | $\mathbb{Z}_3$：$x^3+2x\neq x^5+2x$，但函數都是 0 |
| $D$ 整環 ⇒ $D[x]$ 整環 | 領導係數 $a_nb_m\neq0$ |
| 除法算則（體上） | $f = gq+r$，$r = 0$ 或 $\deg r<\deg g$ |
| 餘式定理 | 除以 $x-a$ 的餘式 $= f(a)$ |
| 因式定理 | $f(a) = 0\iff(x-a)\mid f$ |
| 根的個數 | 體上 $n$ 次 ⇒ $\le n$ 個 |

**反例**：$\mathbb{Z}_6$ 上 $x^2+3x+2$ 有 4 個根；四元數上 $x^2+1$ 有無窮多根。

### 9.3 術語

| 中文 | English |
|---|---|
| 分式體 | field of fractions / field of quotients |
| 有理函數 | rational function |
| 形式冪級數 | formal power series |
| 不定元 | indeterminate |
| 領導係數 | leading coefficient |
| 除法算則 | division algorithm |
| 餘式定理；因式定理 | remainder theorem; factor theorem |
| 零點；重數 | zero; multiplicity |
| 主理想整環 | principal ideal domain (PID) |

## 附：本集一句話總結

> **從整環 $D$ 取非零分母的配對、用「外乘外 = 內乘內」定等價（遞移律靠消去律），定義加乘並證明良定義，就得到含 $D$ 的分式體——這就是從 $\mathbb{Z}$ 嚴格造出 $\mathbb{Q}$，也說明 $\frac12$ 和 $\frac36$ 是同一個數；多項式則是最後全為 0 的係數序列，$x = (0,1,0,\dots)$ 只是不定元而非變數（$\mathbb{Z}_3$ 上 $x^3+2x$ 和 $x^5+2x$ 不同卻是同一個函數），而體上的除法算則給出餘式定理、因式定理和「$n$ 次最多 $n$ 個根」。**
