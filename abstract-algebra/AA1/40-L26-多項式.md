# 第 40 集 · L26：分式體、形式多項式、除法算則 [▶ 影片](https://www.youtube.com/watch?v=DXG5msjmRS0&list=PLBY4G2o7DhF0JCgapYKrqibGaJuvV4Gkb)

← 上一集：[[39-L25-環同態]] ｜ [總目錄](../README.md) ｜ 下一集：[[41-L27-Fx是PID-多項式分解]] →

## 本集概要

- **分式體 (field of fractions)** 的建構：配對 $(a,b)$，$b\neq0$；$(a,b)\sim(c,d)\iff ad = bc$（等價關係，遞移律要用消去律）；定義加法乘法並證明良定義；得到一個體，含有同構於 $D$ 的子環。從 $\mathbb{Z}$ 造出 $\mathbb{Q}$。
- 「$\frac12$ 和 $\frac36$ 是同一個數」。例：有理函數體；$\mathbb{Z}_p(x)$ 是**特徵 $p$ 的無限體**。
- **形式多項式**：係數序列，最後全為 0；$x = (0,1,0,\dots)$ 是**不定元 (indeterminate)**，不是變數。例：$\mathbb{Z}_3$ 上 $x^3+2x\neq x^5+2x$（多項式不同），但作為函數都是 0。
- **代值映射**連接兩個世界。
- $D$ 是整環 $\Rightarrow D[x]$ 是整環。**除法算則**；**餘式定理**；**$a$ 是根 $\iff(x-a)$ 是因式**（作業）；體上 $n$ 次多項式最多 $n$ 個根。
- 不在體上時會出怪事：$\mathbb{Z}_6$ 上的二次式有 4 個根；四元數上的二次式有無窮多根。
- 預告：**主理想整環 (PID)**；$F[x]$ 是 PID。

> 📘 講義對應：2018 講義 §4.4 Lecture 24「ring homomorphism and field of fractions」後半與 §4.5 Lecture 25「polynomials in an indeterminant」（p.137–147）；Gallian 第 15 章末、第 16 章。

## 筆記

### 1. 分式體 [▶ 00:30](https://youtu.be/DXG5msjmRS0?t=30)

> **定理（Gallian Thm 15.6）**　$D$ 是整環（沒有零因子、有單位元的交換環）。則存在一個體 $F$，含有和 $D$ 同構的子環。

**典型例子**：$\mathbb{Z}$ 和 $\mathbb{Q}$。這個定理某種意義上**證明了有理數存在**（給定整數存在的話）[▶ 01:30](https://youtu.be/DXG5msjmRS0?t=90)。

**建構** [▶ 02:00](https://youtu.be/DXG5msjmRS0?t=120)
$$S = \{(a,b)\mid a,b\in D,\ b\neq0\}.$$
直覺：$(a,b)$ 是 $\frac ab$ 的形式版本。

$$(a,b)\sim(c,d)\iff ad = bc\qquad(\text{外項乘積 = 內項乘積}).$$
（來自 $\frac ab = \frac cd\iff ad = bc$，但這裡是在**證明**有理數存在，不能先假設它 [▶ 04:00](https://youtu.be/DXG5msjmRS0?t=240)。）

**是等價關係** [▶ 04:30](https://youtu.be/DXG5msjmRS0?t=270)
- **自反**：$ab = ba$（交換）。
- **對稱**：$ad = bc\Rightarrow cb = da$（交換）。
- **遞移** [▶ 06:00](https://youtu.be/DXG5msjmRS0?t=360)：已知 $ad = bc$、$cf = de$，要 $af = be$。
$$adf = bcf = bde\quad\Rightarrow\quad (af)d = (be)d.$$
  $d$ 在「分母」位置，所以 $d\neq0$；整環有**消去律**，得 $af = be$ [▶ 08:30](https://youtu.be/DXG5msjmRS0?t=510)。
- **原則**：這類論證要想辦法把所有給定的資料都用上 [▶ 07:00](https://youtu.be/DXG5msjmRS0?t=420)。

記 $[a,b]$ 為 $(a,b)$ 的等價類。在 $S/{\sim}$ 上定義 [▶ 10:00](https://youtu.be/DXG5msjmRS0?t=600)：
$$[a,b]+[c,d] = [ad+bc,\ bd],\qquad [a,b][c,d] = [ac,\ bd].$$

**良定義**（講義有細節；老師說「試著邊抄邊理解是傻子的差事」，跟著看就好）[▶ 13:00](https://youtu.be/DXG5msjmRS0?t=780)：設 $[a,b] = [a',b']$、$[c,d] = [c',d']$，即 $ab' = ba'$、$cd' = dc'$（可以把有撇和沒撇的對調）。
- **加法**：要證 $(ad+bc)b'd' = bd(a'd'+b'c')$。左邊展開，把 $ab'$ 換成 $ba'$、$cd'$ 換成 $dc'$，再提出 $bd$ 即可 [▶ 15:00](https://youtu.be/DXG5msjmRS0?t=900)。
- **乘法**：$ac\,b'd' = (ab')(cd') = (ba')(dc') = bd\,a'c'$ [▶ 17:00](https://youtu.be/DXG5msjmRS0?t=1020)。
- 「要專心一點才能做完——還得忽略小孩的尖叫聲。」用撇號比換別的字母好得多。

**體的公理** [▶ 17:30](https://youtu.be/DXG5msjmRS0?t=1050)
- 加法、乘法交換（$D$ 交換）。
- **零**：$[0,x]$。需要小引理：$[ax,bx] = [a,b]$（$x\neq0$）——「分子分母的非零公因數可以約掉」，這要從等價關係推出來，不能假設（$axb = bxa$）[▶ 18:30](https://youtu.be/DXG5msjmRS0?t=1110)。
- **加法反元素**：$[-a,b]$，就像 $-\frac12$。
- **單位元**：$[1,1]$。
- **乘法反元素**：$[a,b]\neq0$（即 $a\neq0$）時，$[a,b]^{-1} = [b,a]$：$[ab,ba] = [1,1]$ [▶ 19:30](https://youtu.be/DXG5msjmRS0?t=1170)。
- **作業**：證明乘法結合律和分配律。「如果我全部做給你看，你就不會真的懂這個證明。另外我也打字打累了。」[▶ 20:00](https://youtu.be/DXG5msjmRS0?t=1200)

**嵌入** [▶ 20:30](https://youtu.be/DXG5msjmRS0?t=1230)：$\varphi:D\to S/{\sim}$，$\varphi(x) = [x,1]$（直覺：$x\mapsto\frac x1$）。它是環同態，核是 $\{0\}$。由環的第一同構定理，$D\cong D/\{0\}\cong\varphi(D)$。$\blacksquare$

**之後的記號** [▶ 22:00](https://youtu.be/DXG5msjmRS0?t=1320)：分式體記作 $\{\frac ab\mid a,b\in D,\ b\neq0\}$，加法乘法照常——只是現在我們**證明了**它們有意義。

### 2. $\frac12 = \frac36$？[▶ 22:30](https://youtu.be/DXG5msjmRS0?t=1350)

老師說很多人想當老師，這是教小孩有理數之前該有的理解。
- 老師的立場：**是同一個數**。$\frac12$ 和 $\frac36$ 是**不同的分數**，但在有理數的嚴格定義下，$\frac ab = \frac cd\iff ad = bc$，而 $1\cdot6 = 2\cdot3$，所以它們相等 [▶ 23:30](https://youtu.be/DXG5msjmRS0?t=1410)。
- 有理數是**分數的等價類**。
- 他和系上另一位教授在這點上意見不同；「小孩能分辨數和分數的差別嗎？這樣區分有幫助嗎？」

### 3. 更多分式體 [▶ 24:30](https://youtu.be/DXG5msjmRS0?t=1470)

- $\mathbb{Z}[x]$ 的分式體：$\{f(x)/g(x)\}$，整係數多項式之比。
- $\mathbb{R}[x]$ 的分式體：**有理函數 (rational functions)**，它們形成一個體 [▶ 25:00](https://youtu.be/DXG5msjmRS0?t=1500)。
- **$\mathbb{Z}_p(x)$**：$\mathbb{Z}_p$ 係數的有理函數。它是**無限體**，但**特徵是 $p$**：任何元素加自己 $p$ 次，分子的係數都乘 $p$，在 $\mathbb{Z}_p$ 裡是 0 [▶ 25:30](https://youtu.be/DXG5msjmRS0?t=1530)。**有限特徵不代表有限體**。

### 4. 形式多項式 [▶ 26:30](https://youtu.be/DXG5msjmRS0?t=1590)

目標：把「多項式」和「函數」分開。（Gallian 一筆帶過，老師補了約一頁。）

> **定義**
> - $R$ 上的**形式冪級數 (formal power series)**：一個無窮序列 $\sigma = (s_0,s_1,s_2,\dots)$，$s_i\in R$（$R$ 是交換環）。
> - **多項式**：從某處開始全是 0 的形式冪級數 [▶ 28:00](https://youtu.be/DXG5msjmRS0?t=1680)。零多項式是全 0。

- 把 $x,x^2,x^3$ 看成**佔位符 (placeholder)**，不是要代入東西的變數。$x$ 叫**不定元 (indeterminate)** [▶ 29:00](https://youtu.be/DXG5msjmRS0?t=1740)。
- 「你可以說多項式其實是函數，我沒辦法跟你爭太多——直到下面那個例子。」

**運算** [▶ 30:00](https://youtu.be/DXG5msjmRS0?t=1800)：$\sigma = (s_i)$、$\tau = (t_i)$。
$$\sigma+\tau = (s_i+t_i),\qquad \sigma\tau = (c_k),\quad c_k = \sum_{i+j = k}s_it_j.$$
（$c_0 = s_0t_0$、$c_1 = s_0t_1+s_1t_0$、$c_2 = s_0t_2+s_1t_1+s_2t_0$……「同次方收集」。）
- 和、積仍是多項式：和的次數最多是兩者較大的（最高項可能抵消，例如 $(1+x^2)+(1-x^2) = 2$）；積的次數最多 $m+n$ [▶ 31:00](https://youtu.be/DXG5msjmRS0?t=1860)。嚴格證明在 Rotman《Elementary Abstract Algebra》。
- 結合、分配律：「相信我」，不花 30 分鐘證。

**$x$ 是什麼** [▶ 33:00](https://youtu.be/DXG5msjmRS0?t=1980)
$$x = (0,1,0,0,\dots).$$
它顯然不是變數，沒辦法代入實數。

- 記 $\vec r = (r,0,0,\dots)$（老師自己的記號）[▶ 34:30](https://youtu.be/DXG5msjmRS0?t=2070)。則 $\vec c\,\tau = (ct_0,ct_1,\dots)$，可以把常數提出來。
- $x^2 = (0,0,1,0,\dots)$，$x^3 = (0,0,0,1,0,\dots)$；歸納法：$x^n = e_{n+1}$（第 $n$ 個位置是 1）[▶ 36:00](https://youtu.be/DXG5msjmRS0?t=2160)。
- 所以每個多項式 $= \vec s_0+\vec s_1x+\cdots+\vec s_nx^n$。

**重點** [▶ 38:00](https://youtu.be/DXG5msjmRS0?t=2280)：多項式可以不當函數看；$x,x^2,x^3$ 是獨立的佔位符；兩個多項式相等，就是**係數完全相同**。

**多項式 ≠ 函數的例子** [▶ 38:30](https://youtu.be/DXG5msjmRS0?t=2310)：在 $\mathbb{Z}_3[x]$ 中
$$x^3+2x = (0,2,0,1,0,\dots)\neq(0,2,0,0,0,1,0,\dots) = x^5+2x.$$
但作為 $\mathbb{Z}_3\to\mathbb{Z}_3$ 的函數，兩者都是**零函數**（$x^3\equiv x$，$x^5\equiv x$，Fermat）[▶ 39:30](https://youtu.be/DXG5msjmRS0?t=2370)。
- 在 $\mathbb{R}$、$\mathbb{C}$ 上會不會有這種事？老師要「打電話問朋友」才敢確定；學生提醒了一個重點（字幕聽不清）[▶ 40:00](https://youtu.be/DXG5msjmRS0?t=2400)。（補充：無限整環上不會——兩個多項式在無限多點相等，差就有無限多個根，只能是零多項式。）

**代值映射：兩個世界的橋** [▶ 41:00](https://youtu.be/DXG5msjmRS0?t=2460)：$R$ 交換、有單位元，
$$\operatorname{ev}_a(s_0+s_1x+\cdots+s_nx^n) = s_0+s_1a+\cdots+s_na^n.$$
「把 $x$ 換成 $a$。你會說『這 15 分鐘能還給我嗎？』但我們真的做了些事。」

### 5. 整環上的多項式 [▶ 42:00](https://youtu.be/DXG5msjmRS0?t=2520)

> **定理（Gallian Thm 16.1）**　$D$ 是整環，則 $D[x]$ 是整環。

**證明**：$f = a_nx^n+\cdots$、$g = b_mx^m+\cdots$，$a_n,b_m\neq0$（首項係數）。乘積的首項是 $a_nb_mx^{n+m}$；$D$ 沒有零因子，$a_nb_m\neq0$，所以 $fg\neq0$ [▶ 43:00](https://youtu.be/DXG5msjmRS0?t=2580)。單位元是常數多項式 1。$\blacksquare$

（學生問零多項式：零多項式乘任何東西是 0，不違反整環；問題只在兩個**非零**多項式乘出 0 [▶ 44:00](https://youtu.be/DXG5msjmRS0?t=2640)。）

### 6. 除法算則與根 [▶ 45:00](https://youtu.be/DXG5msjmRS0?t=2700)

> **定理（除法算則；Gallian Thm 16.2）**　$F$ 是體，$f,g\in F[x]$，$g\neq0$。存在唯一的 $q,r\in F[x]$ 使
> $$f(x) = g(x)q(x)+r(x),$$
> 其中 $r = 0$ 或 $\deg r<\deg g$。

- **次數**：最高非零係數那一項的次方。非零常數多項式次數 0；**零多項式沒有次數** [▶ 45:30](https://youtu.be/DXG5msjmRS0?t=2730)。
- 證明在 Gallian p.286–287，「很好懂，推薦自己讀」。

> **推論（餘式定理 remainder theorem）**　$F$ 是體，$f\in F[x]$。$f(a)$ 是 $f(x)$ 除以 $x-a$ 的餘式 [▶ 46:30](https://youtu.be/DXG5msjmRS0?t=2790)。

**證明**：$f = (x-a)g+r$，$r = 0$ 或 $\deg r<1$，所以 $r$ 是常數。代 $a$：$f(a) = 0\cdot g(a)+r = r$。

> **定義**　$f(c) = 0$ 時 $c$ 是 $f$ 的**根 (zero)**。若 $(x-c)^k$ 是因式但 $(x-c)^{k+1}$ 不是，$c$ 的**重數 (multiplicity)** 是 $k$ [▶ 47:30](https://youtu.be/DXG5msjmRS0?t=2850)。

（老師原本寫成 $k-1$，學生更正為 $k+1$ [▶ 49:00](https://youtu.be/DXG5msjmRS0?t=2940)。）

> **推論（因式定理 factor theorem）**　$F$ 是體。$a$ 是 $f$ 的根 $\iff(x-a)$ 是 $f$ 的因式。——**作業**，「你們會感謝我，幾行就好，很有趣」[▶ 48:30](https://youtu.be/DXG5msjmRS0?t=2910)。

**這些都要「在體上」** [▶ 49:30](https://youtu.be/DXG5msjmRS0?t=2970)
- $\mathbb{Z}_6$ 上的某個二次式有 **4 個根**。（補充：例如 Gallian 的 $x^2+3x+2$，根是 1、2、4、5。）
- 四元數上的二次式可以有**無窮多根**（例如 $x^2+1$）——四元數除了不交換，幾乎是體。
- 係數有零因子時，多項式也會有零因子。

> **定理（Gallian Cor 3 of Thm 16.2）**　體上 $n$ 次多項式最多有 $n$ 個根（計重數）[▶ 50:30](https://youtu.be/DXG5msjmRS0?t=3030)。

**證明（歸納/反證）**：每個根給一個一次因式；若有 $n+1$ 個根，乘起來次數超過 $n$，矛盾。老師說他難得偏好反證法。

### 7. 預告：主理想整環 [▶ 51:00](https://youtu.be/DXG5msjmRS0?t=3060)

> **定義**　**主理想整環 (principal ideal domain, PID)**：每個理想都是主理想的整環。

> **定理（Gallian Thm 16.3）**　$F$ 是體，則 $F[x]$ 是 PID。而且非零理想 $I = \langle g(x)\rangle\iff g$ 是 $I$ 中**次數最小**的非零多項式。

「我總是講不到下一講的開頭，上一講最後 20% 一直卡著。」
