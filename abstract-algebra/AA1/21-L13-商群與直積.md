## 1. Lagrange 的兩朵花

[▶ 01:30](https://youtu.be/4HWzJyS4bP8?t=90)「上次剩下的一些小東西——低垂的果實。」

> **推論 1**　$G$ 有限群。則對每個 $a\in G$，$|a|$ 整除 $|G|$。

**證明**[▶ 02:00](https://youtu.be/4HWzJyS4bP8?t=120)：$\langle a\rangle\le G$。由 Lagrange，$|\langle a\rangle|$ 整除 $|G|$；而 $|\langle a\rangle| = |a|$。$\blacksquare$

> **推論 2**[▶ 02:30](https://youtu.be/4HWzJyS4bP8?t=150)　$G$ 有限群。則 $a^{|G|} = e$。

**證明**[▶ 03:00](https://youtu.be/4HWzJyS4bP8?t=180)：由推論 1，$|G| = k|a|$。所以
$$a^{|G|} = a^{k|a|} = (a^{|a|})^k = e^k = e.\qquad\blacksquare$$

## 2. 引理：左右陪集何時相等

[▶ 04:00](https://youtu.be/4HWzJyS4bP8?t=240)「一個小引理，我大概不證，證明跟上次很像，留給你們。」

> **引理**　$H\le G$，$a,b\in G$。
> 1. $aH = Ha\iff H = aHa^{-1}$。
> 2. $a(hH) = aH$、$(Hh)b = Hb$ 對所有 $h\in H$。（$hH = H$：$H$ 把自己的元素「吞掉」。）

- (1) 說：**左陪集和右陪集相等，恰好當 $H$ 在 $a$ 的共軛下不變**[▶ 04:30](https://youtu.be/4HWzJyS4bP8?t=270)。
- (2)「很容易證，但計算上很好用。」

【口頭】[▶ 05:30](https://youtu.be/4HWzJyS4bP8?t=330)「陪集的概念比『子群造出的陪集』更大，但子群的情況才有最好的定理。證明就是追元素，跟上次一樣。」

## 3. 例：S₃ 裡左右陪集不同

[▶ 06:00](https://youtu.be/4HWzJyS4bP8?t=360)「我想示範左陪集和右陪集**不一樣**的情況。」
$$S_3 = \{(1),(12),(13),(23),(123),(132)\},\qquad H = \langle(13)\rangle = \{(1),(13)\}.$$
指數 $[S_3:H] = 6/2 = 3$ [▶ 07:30](https://youtu.be/4HWzJyS4bP8?t=450)，所以有三個陪集。

| 左陪集 | 右陪集 |
|---|---|
| $H = (13)H = \{(1),(13)\}$ | $H = H(13) = \{(1),(13)\}$ |
| $(12)H = (132)H = \{(12),(132)\}$ [▶ 09:00](https://youtu.be/4HWzJyS4bP8?t=540) | $H(12) = H(123) = \{(12),(123)\}$ [▶ 09:30](https://youtu.be/4HWzJyS4bP8?t=570) |
| $(23)H = (123)H = \{(23),(123)\}$ [▶ 10:00](https://youtu.be/4HWzJyS4bP8?t=600) | $H(23) = H(132) = \{(23),(132)\}$ [▶ 10:30](https://youtu.be/4HWzJyS4bP8?t=630) |

- 第一行看到引理 (2) 的作用：$(13)\in H$，被吞掉 [▶ 08:30](https://youtu.be/4HWzJyS4bP8?t=510)。
- **$(12)H\neq H(12)$**：左右陪集不同 [▶ 10:00](https://youtu.be/4HWzJyS4bP8?t=600)。
- 「六個元素都被這些陪集涵蓋，只是**分組方式不同**——分割不同。」[▶ 11:00](https://youtu.be/4HWzJyS4bP8?t=660)

## 4. 正規子群

[▶ 11:30](https://youtu.be/4HWzJyS4bP8?t=690)「這帶到一個定義，我等一下解釋它的重要性。」

> **定義（正規子群 normal subgroup）**　$H\le G$。如果
> $$aH = Ha\quad\text{對所有 }a\in G,$$
> 就說 $H$ 是 $G$ 的**正規子群**，記作 $H\trianglelefteq G$（老師畫一個三角形，有人加一橫）。

**三種記號**[▶ 12:30](https://youtu.be/4HWzJyS4bP8?t=750)：

| 記號 | 意思 |
|---|---|
| $H\trianglelefteq G$ | 正規子群 |
| $H\le G$ | 子群 |
| $H\subseteq G$ | 子集 |

**例**[▶ 13:00](https://youtu.be/4HWzJyS4bP8?t=780)：剛才算的 $\langle(13)\rangle$ **不是** $S_3$ 的正規子群。

> **定理**（Gallian Thm 9.1）[▶ 32:30](https://youtu.be/4HWzJyS4bP8?t=1950)　$H\le G$。$H\trianglelefteq G$ ⟺ $aHa^{-1}\subseteq H$ 對所有 $a\in G$。

【口頭】[▶ 33:00](https://youtu.be/4HWzJyS4bP8?t=1980)「這比較好用：只要檢查**共軛是子集**，不用證另一個方向——雖然另一個方向（$H\subseteq aHa^{-1}$）大概也很平凡。」

> 📘 講義直接用這個當定義（Def 3.2.2）：「$H$ 正規 ⟺ $aHa^{-1}\subseteq H$ 對所有 $a$」，因為「在很多情境下，共軛條件好檢查得多」。

## 5. 例：A₃ 正規，S₃/A₃

[▶ 13:30](https://youtu.be/4HWzJyS4bP8?t=810)「我不想替你們算，但結果是：」
$$A_3 = \{(1),(132),(123)\}\trianglelefteq S_3.$$
（「它是群的一半大。這總是如此：$A_n$ 是 $S_n$ 的一半。」）

**陪集**[▶ 14:00](https://youtu.be/4HWzJyS4bP8?t=840)：指數 $6/3 = 2$，兩個陪集。
- $A_3$ 本身。
- 另一個就是**剩下的**：$(12)A_3 = \{(12),(13),(23)\}$。「我不用真的乘出來就知道——陪集分割群，不在第一個就在第二個。」[▶ 15:00](https://youtu.be/4HWzJyS4bP8?t=900)
- 也等於 $A_3(12)$。

**陪集自成一個群？**[▶ 15:30](https://youtu.be/4HWzJyS4bP8?t=930)「如果你很有想像力，可以想像這些陪集**有自己的生命**。」畫 Cayley 表，用**代表元相乘**：
$$(aA_3)(bA_3) = abA_3.$$

例 [▶ 16:30](https://youtu.be/4HWzJyS4bP8?t=990)：$A_3 = (132)A_3$，所以
$$A_3\cdot(12)A_3 = (132)(12)A_3 = (23)A_3 = (12)A_3.$$
（$(132)(12)$：$1\to2\to1$……老師算得 $(23)$。）

兩個奇置換的乘積是偶置換 [▶ 17:30](https://youtu.be/4HWzJyS4bP8?t=1050)，所以 $(12)A_3\cdot(12)A_3 = A_3$。

| $S_3/A_3$ | $A_3$ | $(12)A_3$ |
|---|---|---|
| $A_3$ | $A_3$ | $(12)A_3$ |
| $(12)A_3$ | $(12)A_3$ | $A_3$ |

「看起來像 Cayley 表，有對的模式。」——它就是 $\mathbb{Z}_2$。

## 6. 陪集乘法不一定良定義

[▶ 18:00](https://youtu.be/4HWzJyS4bP8?t=1080)「如果對那個 $H = \{(1),(13)\}$ 試同樣的乘法，會怎樣？」提議：$aH\cdot bH = abH$。「在這個例子裡，它**不能**當群運算。」

**用一組代表元**[▶ 18:30](https://youtu.be/4HWzJyS4bP8?t=1110)：
$$(12)H\cdot(23)H = (12)(23)H = (123)H.$$
（$(12)(23)$：$1\to1\to2$、$2\to3\to3$、$3\to2\to1$。）

**換一組代表元**[▶ 19:30](https://youtu.be/4HWzJyS4bP8?t=1170)：$(12)H = (132)H$（同一個陪集）。
$$(132)H\cdot(23)H = (132)(23)H = (13)H.$$
（老師先算錯，學生更正：「這只是 $(13)$。」老師：「對，謝謝，我應該看講義。」[▶ 22:30](https://youtu.be/4HWzJyS4bP8?t=1350)）

**矛盾**[▶ 20:30](https://youtu.be/4HWzJyS4bP8?t=1230)：$(13)H = H$，而 $(123)H = \{(23),(123)\}\neq H$。**同樣的兩個陪集相乘，得到不同的結果**。

【口頭】「這不是二元運算：它**不是單值的**，至少是雙值的。不能當乘法。原因是 **$H$ 不是正規子群**。如果要讓這個成為陪集上的群運算，**你需要正規性**。這就是正規子群的意義：它讓陪集上的乘法**良定義**。」

> 📘 講義 Ex 3.2.1 用另一組例子：$(12)H(123)H = (23)H$，但 $(132)H(123)H = (1)H$。

## 7. 定理：正規 ⇒ 商群

【Q&A】[▶ 21:30](https://youtu.be/4HWzJyS4bP8?t=1290) 學生問：「如果是正規的，就夠了嗎？」老師：「我們來看看。」

> **定理（商群 factor group / quotient group）**　$H\trianglelefteq G$。令 $G/H$ 為 $H$ 的所有陪集。則
> $$(aH)(bH) = abH$$
> 是 $G/H$ 上的二元運算，使 $G/H$ 成為群，單位元素是 $H$。

> 📘 講義：照 Gallian，這是 **O. Hölder 在 1889** 年發現的；$G/H$ 這個記號來自 **Jordan**。

### 7.1 良定義

[▶ 22:30](https://youtu.be/4HWzJyS4bP8?t=1350)「陪集的特點是有歧義——代表元有選擇。所以**每次用陪集定義東西，我們都有義務證明構造與代表元的選擇無關**。」

設 $aH = a'H$、$bH = b'H$ [▶ 23:00](https://youtu.be/4HWzJyS4bP8?t=1380)。（「希望我這次的撇號比考卷上好。」）

$$
\begin{aligned}
a'b'H &= a'(b'H)\\
&= a'(bH) &&(b'H = bH)\\
&= a'(Hb) &&(H\text{ 正規})\\
&= (a'H)b\\
&= (aH)b &&(a'H = aH)\\
&= a(Hb)\\
&= a(bH) &&(H\text{ 正規})\\
&= abH.
\end{aligned}
$$

所以乘積與代表元無關。$\blacksquare$

### 7.2 群公理

[▶ 25:00](https://youtu.be/4HWzJyS4bP8?t=1500)「知道這個之後，就可以出發了。」

**單位元素**[▶ 25:30](https://youtu.be/4HWzJyS4bP8?t=1530)：$H = eH$。
$$H\cdot aH = eaH = aH,\qquad aH\cdot H = aeH = aH.$$
（「要真的證明，大概得追一些點。我今天有更大的故事要講，所以不做；打講義時會給你們血淋淋的細節。」）

**反元素**[▶ 26:30](https://youtu.be/4HWzJyS4bP8?t=1590)：
$$aH\cdot a^{-1}H = aa^{-1}H = eH = H.$$
「$e\in H$，被 $H$ 吞掉。」所以 **$(aH)^{-1} = a^{-1}H$**：陪集的反元素就是**代表元取反元素**的陪集。

**封閉**：$abH$ 是陪集，顯然。「複雜、不明顯的是**良定義**，那我們已經解決了。」[▶ 27:30](https://youtu.be/4HWzJyS4bP8?t=1650)

**結合律**[▶ 28:00](https://youtu.be/4HWzJyS4bP8?t=1680)：
$$aH\,(bH\,cH) = aH\,(bcH) = a(bc)H = (ab)cH = (abH)\,cH = (aH\,bH)\,cH.$$
**商群的結合律來自 $G$ 的結合律。**$\blacksquare$

【口頭】[▶ 29:00](https://youtu.be/4HWzJyS4bP8?t=1740)「我說今天要告訴你們怎麼乘、除群。**這就是怎麼除**。而且只有在**正規子群**的情況下才能除。」

> 📘 講義 Remark 3.2.9：商群的想法是**把 $H$ 的所有點黏成一個元素**。因為群乘法的結構，每個陪集也被同樣地黏起來。結果是一個比較小的群。上一講 $[G:H] = |G|/|H|$，現在可以寫成
> $$|G/H| = \frac{|G|}{|H|}.$$
> 「記號的勝利。」

## 8. 正規子群的例子

### 8.1 交換群的每個子群

[▶ 29:30](https://youtu.be/4HWzJyS4bP8?t=1770)「我還有幾個低垂的果實。一個非常重要的：$G$ 交換。」
$$a+H = \{a+h : h\in H\} = \{h+a : h\in H\} = H+a.$$
「這正是右陪集。在交換群裡，左右陪集以最簡單的方式**自動相等**。」

**交換群的每個子群都正規**，所以任何子群都能做商群。「交換群很寬容，不像對稱群，你得小心要用什麼來除。」

> 📘 講義：所以向量空間（加法群）的**每個子空間**都是正規子群。

### 8.2 中心、An、Dn 的旋轉

[▶ 31:00](https://youtu.be/4HWzJyS4bP8?t=1860)「Gallian 的清單很好。細節先略過，只告訴你們：」
- **中心 $Z(G)$ 是正規的**。「幾乎直接從定義得到：中心是跟所有元素交換的元素，這基本上逼出了正規性。」
- **交錯群 $A_n\trianglelefteq S_n$**。
- **$D_n$ 的旋轉子群 $\langle x\rangle\trianglelefteq D_n$**[▶ 32:00](https://youtu.be/4HWzJyS4bP8?t=1920)，基本上因為 $xy = yx^{-1}$。

> 📘 講義 Ex 3.2.5：$y\langle x\rangle = \{yx^k\} = \{x^{-k}y\} = \langle x\rangle y$。而且 $[D_n:\langle x\rangle] = 2$，只有一個非平凡陪集要檢查。
>
> 講義 Ex 3.2.16：**指數 2 的子群一定正規**。$H$ 自己是一個左陪集也是右陪集；陪集等大且分割 $G$，所以另一個（左或右）都是 $G-H$。

### 8.3 SL(n,ℝ) ⊴ GL(n,ℝ)

[▶ 32:00](https://youtu.be/4HWzJyS4bP8?t=1920)「更刺激的例子，我在另一講裡注意到的：」
$$SL(n,\mathbb{R}) = \{A : \det A = 1\}\trianglelefteq GL(n,\mathbb{R}).$$

**證明**（用 Thm 9.1）[▶ 34:00](https://youtu.be/4HWzJyS4bP8?t=2040)：取 $A\in GL(n,\mathbb{R})$，$B\in A\,SL(n,\mathbb{R})\,A^{-1}$，即 $B = AMA^{-1}$，$\det M = 1$。
$$\det B = \det A\cdot\det M\cdot\det(A^{-1}) = \det M = 1.$$
所以 $B\in SL(n,\mathbb{R})$，$A\,SL\,A^{-1}\subseteq SL$。$\blacksquare$

【口頭】[▶ 35:00](https://youtu.be/4HWzJyS4bP8?t=2100)「這裡的 $A$ 是 $GL(n)$ 裡任意的。這就是我前幾天的小抱怨：Gallian 另一個例子假設共軛矩陣在 $SL$ 裡，但計算在共軛矩陣只是 $GL$ 的情況下就成立，**不需要假設行列式是 1**。」「別要我給你們看這個商群。」（講義：上一講 Ex 3.1.8 其實已經證了——$SL$ 的左右陪集都是「行列式等於某值的矩陣」。）

## 9. 外直積

[▶ 36:30](https://youtu.be/4HWzJyS4bP8?t=2190)「現在我們知道一點怎麼除群了……接下來，乘群。」

> **定義（外直積 external direct product）**[▶ 37:30](https://youtu.be/4HWzJyS4bP8?t=2250)　$G_1,G_2,\dots,G_n$ 是有限多個群。
> $$G_1\times G_2\times\cdots\times G_n = \{(g_1,g_2,\dots,g_n) : g_i\in G_i\},$$
> 運算**逐分量**：
> $$(g_1,\dots,g_n)(h_1,\dots,h_n) = (g_1h_1,\dots,g_nh_n).$$

- 作為點集，就是**笛卡兒積**[▶ 38:00](https://youtu.be/4HWzJyS4bP8?t=2280)。
- 【Q&A】[▶ 39:00](https://youtu.be/4HWzJyS4bP8?t=2340)「單位元素是什麼？」$(e_1,e_2,\dots,e_n)$——各群單位元素的笛卡兒積。

## 10. 內直積

[▶ 42:30](https://youtu.be/4HWzJyS4bP8?t=2550)「還有一個叫**內直積**的東西。」

> **定義（內直積 internal direct product）**[▶ 43:00](https://youtu.be/4HWzJyS4bP8?t=2580)　$G$ 是群，$H,K\trianglelefteq G$，$H\cap K = \{e\}$，而且
> $$G = HK = \{hk : h\in H,\ k\in K\},$$
> 就說 $G$ 是 $H$ 和 $K$ 的**內直積**。

【課堂討論】[▶ 43:30](https://youtu.be/4HWzJyS4bP8?t=2610)「$HK$ 是什麼？好問題，你們怎麼定義？」答：所有可能的乘積，$H$ 取一個、$K$ 取一個。

**記號的混亂**[▶ 44:00](https://youtu.be/4HWzJyS4bP8?t=2640)：Gallian 把內直積寫成 $G = H\times K$。【口頭】「我真的不喜歡這個記號。我內心的一切都想把它們對調：用 $\times$ 表示外直積，用 $\oplus$ 表示內直積——線性代數裡兩個子空間的直和組成整個空間就是這樣寫。這個記號從來沒有大家都同意的。課堂上我用 Gallian 的。」

> 📘 講義的選擇（Remark 3.3.5）：**外直積用 $\times$，內直積用 $\oplus$**，「讓積群的記號自然配合笛卡兒積的記號，也跟 Math 321 一致」。講義也說這比文獻慣例更小心。

**例：$\mathbb{Z}_6 = \langle2\rangle\oplus\langle3\rangle$**[▶ 45:00](https://youtu.be/4HWzJyS4bP8?t=2700)
- 老師一開始寫成「$\mathbb{Z}_6 = \mathbb{Z}_2\times\mathbb{Z}_3$」，然後【課堂討論】學生指出：這應該是**等號**對**子群**，不是對 $\mathbb{Z}_2$、$\mathbb{Z}_3$。老師 [▶ 45:30](https://youtu.be/4HWzJyS4bP8?t=2730)：「這裡我是說**相等**，不是同構。」
- $\langle2\rangle = \{0,2,4\}$、$\langle3\rangle = \{0,3\}$。
- $\langle2\rangle+\langle3\rangle = \{2k+3l : k,l\in\mathbb{Z}\}$。因為 2、3 互質，「試一試就會發現得到全部 $\mathbb{Z}_6$」[▶ 46:30](https://youtu.be/4HWzJyS4bP8?t=2790)。（講義：$1 = 3+4$、$5 = 2+3$。）
- $\langle2\rangle\cap\langle3\rangle = \{0\}$。
- 交換群，子群都正規。

所以 $\mathbb{Z}_6$ 是 $\langle2\rangle$ 和 $\langle3\rangle$ 的內直積（$=$）；而且它**同構**於外直積 $\mathbb{Z}_2\times\mathbb{Z}_3$（$\cong$）[▶ 47:00](https://youtu.be/4HWzJyS4bP8?t=2820)。「畫 $\mathbb{Z}_6$ 的 Cayley 表比較，會看到模式吻合。」

【口頭】[▶ 47:30](https://youtu.be/4HWzJyS4bP8?t=2850)「這些是我們想更深入理解的同構和模式。我出了一些作業讓我們開始。理解商群和直積這個計畫要花好幾天——我們得花一陣子才能好好把腦袋繞過這些概念。」「我要**提早兩分鐘**下課，史無前例。」

## 11. 【講義補充】商群的例子、單群、內直積 ≅ 外直積

**商群的例子**（講義 Ex 3.2.10–3.2.11）：
- $\mathbb{Z}_6/\langle3\rangle$：陪集 $H = \{0,3\}$、$1+H = \{1,4\}$、$2+H = \{2,5\}$。Cayley 表跟 $\mathbb{Z}_3$ 一樣 ⇒ $\mathbb{Z}_6/\langle3\rangle\cong\mathbb{Z}_3$。
- $\mathbb{Z}_6/\langle2\rangle$：陪集 $\{0,2,4\}$、$\{1,3,5\}$ ⇒ $\cong\mathbb{Z}_2$。

**陪集的階 vs. 陪集的大小**：在 $G/H$ 中，$aH$ 的**階**是使 $a^k\in H$ 的最小正整數 $k$（因為 $(aH)^k = a^kH$）。這跟陪集的**元素個數**不同：例如 $(12)A_3$ 在 $S_3/A_3$ 裡階是 2，但它有 3 個元素。

**$\mathbb{Z}_4\times\mathbb{Z}_4$ 的商群**（Ex 3.2.15）：
- $H = 2\mathbb{Z}_4\times2\mathbb{Z}_4$：每個非單位元素階 2 ⇒ $G/H\cong\mathbb{Z}_2\times\mathbb{Z}_2$。
- $K = \mathbb{Z}_4\times\{0\}$：$(0,1)+K$ 階 4 ⇒ $G/K\cong\mathbb{Z}_4$。
- $N = \{(0,0),(1,1),(2,2),(3,3)\}$：$(1,0)+N$ 生成 ⇒ $G/N\cong\mathbb{Z}_4$。

**平凡的正規子群**：$\{e\}$、$Z(G)$、$G$ 都正規。$G/\{e\}\cong G$、$G/G\cong\{e\}$——「不有趣」。

> **定義（單群 simple group）**（Def 3.2.12）　$G$ 唯一的正規子群是 $\{e\}$ 和 $G$。

類比：分數 $25/100$ 可以約成 $1/4$；單群就像「最簡分數」，**不能再分解**。例：$\mathbb{Z}_p$（$p$ 質數）是單群。（講義說 $A_n$ 在 $n\ge5$ 時是單群，$A_4$ 不是。）**指數 2 的子群一定正規**，所以有一半大小子群的群**不是**單群。

**內直積 ≅ 外直積**（Lemma 3.3.9、Thm 3.3.10）：$H,K\trianglelefteq G$，$H\cap K = \{e\}$。
- **引理 (i)**：$ab = a'b'$（$a,a'\in H$；$b,b'\in K$）⇒ $a = a'$、$b = b'$。（$bb'^{-1} = a^{-1}a'\in H\cap K = \{e\}$。）
- **引理 (ii)**：$a\in H$、$b\in K$ ⇒ $ab = ba$。（$aba^{-1}b^{-1}$ 既在 $K$（$K$ 正規）又在 $H$（$H$ 正規），所以是 $e$。）
- **定理**：$G = HK$ ⇒ $\varphi:H\times K\to G$，$\varphi(x,y) = xy$ 是同構。（同態用 (ii)；映成因為 $G = HK$；核平凡用 (i)。）

**為什麼要正規**（Ex 3.3.8）：$D_3$ 裡 $H = \langle x\rangle$、$K = \{1,y\}$，$HK = D_3$、$H\cap K = \{1\}$，但 $K$ 不正規。$H\times K$ 有 6 階元素 $(x,y)$，所以 $H\times K\cong\mathbb{Z}_6\not\cong D_3$。

**直積元素的階**（Thm 3.3.11）：$|(x,y)| = \operatorname{lcm}(|x|,|y|)$。

## 12. 一頁速查表

### 12.1 正規子群

| 名稱 | 內容 |
|---|---|
| $H\trianglelefteq G$ | $aH = Ha\ \forall a$ ⟺ $aHa^{-1}\subseteq H\ \forall a$ |
| $aH = Ha$ | ⟺ $aHa^{-1} = H$ |
| 例 | 交換群的所有子群；$Z(G)$；$A_n\trianglelefteq S_n$；$\langle x\rangle\trianglelefteq D_n$；$SL\trianglelefteq GL$；指數 2 的子群 |
| 反例 | $\langle(13)\rangle\ntrianglelefteq S_3$ |

### 12.2 商群 $G/H$（$H\trianglelefteq G$）

| 項目 | 內容 |
|---|---|
| 元素 | 陪集 $aH$ |
| 運算 | $(aH)(bH) = abH$ |
| 良定義的關鍵 | $a'b'H = a'bH = a'Hb = aHb = abH$（用 $bH = Hb$） |
| 單位 | $H = eH$ |
| 反元素 | $(aH)^{-1} = a^{-1}H$ |
| 階 | $\lvert G/H\rvert = \lvert G\rvert/\lvert H\rvert$ |
| 不正規時 | 運算不是單值的（$S_3$ 的例子） |

### 12.3 直積

| | 外直積 $G_1\times G_2$ | 內直積 $G = H\oplus K$ |
|---|---|---|
| 元素 | 有序對 $(g_1,g_2)$ | $G$ 本身的元素 $hk$ |
| 運算 | 逐分量 | $G$ 的運算 |
| 條件 | 任意群 | $H,K\trianglelefteq G$、$H\cap K = \{e\}$、$G = HK$ |
| 關係 | | $H\oplus K\cong H\times K$ |

例：$\mathbb{Z}_6 = \langle2\rangle\oplus\langle3\rangle\cong\mathbb{Z}_3\times\mathbb{Z}_2$。

**記號警告**：Gallian 外直積寫 $\oplus$、內直積寫 $\times$；講義相反。

### 12.4 Lagrange 的推論

$|a|$ 整除 $|G|$；$a^{|G|} = e$。

## 附：本集一句話總結

> **左右陪集一般不同（$S_3$ 裡 $\langle(13)\rangle$ 就是），而用代表元相乘 $(aH)(bH) = abH$ 要成為良定義的運算，恰好需要 $aH = Ha$——這就是正規子群；正規時陪集組成商群 $G/H$（單位 $H$、反元素 $a^{-1}H$、$|G/H| = |G|/|H|$），這是「除」群；「乘」群則有逐分量運算的外直積，以及由兩個交集平凡的正規子群相乘而成的內直積，兩者同構。**
