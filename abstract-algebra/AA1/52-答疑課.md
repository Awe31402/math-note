# 第 52 集 · 答疑課：擴張體的次數與基底 [▶ 影片](https://www.youtube.com/watch?v=EFHVfIdshJI&list=PLBY4G2o7DhF0JCgapYKrqibGaJuvV4Gkb)

## 本集概要

講 Fraleigh §31 的作業：求擴張的次數和基底。
- $\mathbb{Q}(\sqrt2,\sqrt3,\sqrt{18})$：$\sqrt{18} = 3\sqrt2$ 是陷阱；次數 4，基底 $\{1,\sqrt2,\sqrt3,\sqrt6\}$。
- $\mathbb{Q}(\sqrt2+\sqrt3)$：次數 4。
- $\mathbb{Q}(\sqrt2\sqrt3) = \mathbb{Q}(\sqrt6)$，次數 2。
- $\mathbb{Q}(\sqrt[3]2,\sqrt[3]6,\sqrt[3]{24})$：次數 9；要證 $x^3-6$ 在 $\mathbb{Q}(\sqrt[3]2)$ 上不可約。
- $\operatorname{irr}(\sqrt2+i,\mathbb{Q}) = x^4-2x^2+9$。
- 重點：要算擴張的高度，**判斷不可約**是核心工具。

> ⚠️ 本集有兩處老師用「模 $p$ 無根」來推「四次式不可約」，這是**不對的**（「無根 ⇒ 不可約」只對 2、3 次成立）。結論本身是對的，正確理由見下面的補充。

## 筆記

### 1. $\mathbb{Q}(\sqrt2,\sqrt3,\sqrt{18})$ [▶ 00:30](https://youtu.be/EFHVfIdshJI?t=30)

- **陷阱**：$\sqrt{18} = 3\sqrt2$ 已經在裡面，所以 $= \mathbb{Q}(\sqrt2,\sqrt3)$。
- $\mathbb{Q}(\sqrt2,\sqrt3) = \{c_1+c_2\sqrt3\mid c_i\in\mathbb{Q}(\sqrt2)\}$，展開成 $1,\sqrt2,\sqrt3,\sqrt6$ 的有理組合。
- **為什麼 $\sqrt3$ 在 $\mathbb{Q}(\sqrt2)$ 上是 2 次** [▶ 02:00](https://youtu.be/EFHVfIdshJI?t=120)：$x^2-3$ 以 $\sqrt3$ 為根；唯一更低次的可能是一次 $x+\beta$，那表示 $\sqrt3 = a+b\sqrt2$（$a,b\in\mathbb{Q}$），不可能（Math 200 等級的事實）。
- **線性獨立**：不想直接證（又是 Math 200 的東西）。改用**次數乘法公式** [▶ 06:00](https://youtu.be/EFHVfIdshJI?t=360)：
$$[\mathbb{Q}(\sqrt2,\sqrt3):\mathbb{Q}] = [\mathbb{Q}(\sqrt2,\sqrt3):\mathbb{Q}(\sqrt2)]\,[\mathbb{Q}(\sqrt2):\mathbb{Q}] = 2\cdot2 = 4.$$
  4 維空間裡有 4 個張成向量，就是基底。

「沒化簡 $\sqrt{18}$ 的話，很容易在這題花很多時間。」

### 2. $\mathbb{Q}(\sqrt2+\sqrt3)$ [▶ 07:00](https://youtu.be/EFHVfIdshJI?t=420)

- 特徵 0 的代數擴張，由 Steinitz 定理是單擴張——就是 $\alpha = \sqrt2+\sqrt3$。問題是次數。
- 消去根號：$\alpha^4-10\alpha^2+1 = 0$。Eisenstein 不行，模 2 也沒幫助；老師說模 3 下「1、1、1，沒有根，所以不可約」[▶ 08:00](https://youtu.be/EFHVfIdshJI?t=480)。
- 所以次數 4，基底 $\{1,\alpha,\alpha^2,\alpha^3\}$。若接受 Gallian 的習題 $\mathbb{Q}(\sqrt2+\sqrt3) = \mathbb{Q}(\sqrt2,\sqrt3)$，另一個基底是 $\{1,\sqrt2,\sqrt3,\sqrt6\}$。

> 💬 補充：「模 3 無根」**不能**推出四次式不可約——$x^4-10x^2+1\equiv x^4+2x^2+1 = (x^2+1)^2\pmod3$，其實可約（這個多項式模每個質數都可約）。正確理由：$\mathbb{Q}(\sqrt2+\sqrt3) = \mathbb{Q}(\sqrt2,\sqrt3)$ 是 4 次擴張（§1），所以 $\sqrt2+\sqrt3$ 的次數是 4，它的最小多項式就是這個四次式。

### 3. $\mathbb{Q}(\sqrt2\sqrt3)$ [▶ 09:30](https://youtu.be/EFHVfIdshJI?t=570)

就是 $\mathbb{Q}(\sqrt6)$，基底 $\{1,\sqrt6\}$。「我還以為少了逗號——有逗號就無聊了。」

### 4. $\mathbb{Q}(\sqrt[3]2,\sqrt[3]6,\sqrt[3]{24})$ [▶ 10:00](https://youtu.be/EFHVfIdshJI?t=600)

- $\sqrt[3]{24} = 2\sqrt[3]3 = 2\sqrt[3]6/\sqrt[3]2$，已經在前兩個生成的體裡，丟掉。
- 看成 $\mathbb{Q}(\sqrt[3]2)$ 再添 $\sqrt[3]6$。
- **$x^3-6$ 在 $\mathbb{Q}(\sqrt[3]2)$ 上不可約** [▶ 11:00](https://youtu.be/EFHVfIdshJI?t=660)
  - 在 $\mathbb{Q}$ 上不可約（Eisenstein，$p = 2$ 或 3）。但我們需要的是在 $\mathbb{Q}(\sqrt[3]2)$ 上——**Eisenstein 只對基礎體 $\mathbb{Q}$ 有效**。（解答裡寫成「在 $\mathbb{Q}$ 上」不夠精確，「該扣一分」。）
  - 三次式可約就有一次因式：$(x+\alpha)(x^2+\beta x+\gamma)$，$\alpha,\beta,\gamma\in\mathbb{Q}(\sqrt[3]2)$。展開比較係數：$\alpha+\beta = 0$、$\alpha\beta+\gamma = 0$、$\alpha\gamma = -6$。得 $\gamma = \alpha^2$、$\alpha^3 = -6$，即 $\alpha = -\sqrt[3]6$ [▶ 13:00](https://youtu.be/EFHVfIdshJI?t=780)。
  - 但 $\sqrt[3]6\notin\mathbb{Q}(\sqrt[3]2)$，所以不可約。
- 次數：$[\,\cdot\,:\mathbb{Q}(\sqrt[3]2)] = 3$，$[\mathbb{Q}(\sqrt[3]2):\mathbb{Q}] = 3$（Eisenstein $p = 2$）。總共 **9**，有 9 個基底元素 [▶ 15:30](https://youtu.be/EFHVfIdshJI?t=930)。
- 「你們作業的缺口大概都是**沒證不可約**，直接假設——對吧？」[▶ 14:00](https://youtu.be/EFHVfIdshJI?t=840)

> 💬 補充：老師說這題「一開始覺得無聊，像第 3 題重來，後來發現不是」。上面 $\alpha = -\sqrt[3]6$ 不在 $\mathbb{Q}(\sqrt[3]2)$ 裡的理由，嚴格說還需要論證（例如次數考量），課堂沒細講。

### 5. $\mathbb{Q}(\sqrt2,\sqrt6)$ [▶ 16:00](https://youtu.be/EFHVfIdshJI?t=960)

$\sqrt6 = \sqrt2\sqrt3$，所以 $\mathbb{Q}(\sqrt3,\sqrt2)\supseteq\mathbb{Q}(\sqrt2,\sqrt6)$，其實相等。$x^2-2$ 在 $\mathbb{Q}(\sqrt3)$ 上不可約（同 §1 的論證），次數 4。（老師承認累了，還沒寫完這題的完整解答。）

### 6. $\operatorname{irr}(\sqrt2+i,\mathbb{Q})$（Fraleigh §29 #8）[▶ 21:00](https://youtu.be/EFHVfIdshJI?t=1260)

（老師選這題以為簡單，「我選錯了」。）

**旁白**：代數數通常指 $\mathbb{C}$ 中（不是 $\mathbb{R}$ 中）在 $\mathbb{Q}$ 上代數的數 [▶ 22:00](https://youtu.be/EFHVfIdshJI?t=1320)。

**消去根號** [▶ 22:30](https://youtu.be/EFHVfIdshJI?t=1350)
$$\alpha-\sqrt2 = i\ \Rightarrow\ \alpha^2-2\sqrt2\alpha+2 = -1\ \Rightarrow\ 2\sqrt2\alpha = \alpha^2+3\ \Rightarrow\ 8\alpha^2 = \alpha^4+6\alpha^2+9.$$
$$p(x) = x^4-2x^2+9.$$
- 這些步驟**可逆**，所以 $p(\alpha) = 0$ 確定 [▶ 24:00](https://youtu.be/EFHVfIdshJI?t=1440)。（老師好奇：這樣消根號會不會得到可約的？「也許平方過頭就會。」）
- **不可約？** Eisenstein 不行（2 和 9 沒有共同質因數）[▶ 25:00](https://youtu.be/EFHVfIdshJI?t=1500)。
  - 模 2：$x^4+1$，$p(1) = 0$，沒用。
  - 模 3：$x^4+x^2 = x^2(x^2+1)$，可約，沒用。
  - 模 5：$x^4-2x^2-1$。代 $0,\pm1,\pm2$：$-1,-2,-1$，都不是 0。偶函數，所以 $p(c) = p(-c)$，省一半工夫 [▶ 30:00](https://youtu.be/EFHVfIdshJI?t=1800)。老師結論：「在 $\mathbb{Z}_5$ 上不可約，所以在 $\mathbb{Q}$ 上不可約。」

> 💬 補充：這個論證有漏洞。四次式沒有根，仍可能拆成兩個二次式；事實上在 $\mathbb{Z}_5$ 中
> $$x^4-2x^2-1 = (x^2+x+2)(x^2+4x+2).$$
> 正確理由：$\mathbb{Q}(\sqrt2,i)$ 是 $\mathbb{Q}$ 的 4 次擴張（$i\notin\mathbb{Q}(\sqrt2)\subseteq\mathbb{R}$），而 $\sqrt2+i$ 生成整個 $\mathbb{Q}(\sqrt2,i)$，所以它的次數是 4，$x^4-2x^2+9$ 就是它的最小多項式。

**教訓** [▶ 28:00](https://youtu.be/EFHVfIdshJI?t=1680)：把係數先模 $p$ 化簡再找分解，能省很多時間。手上的工具只有 Eisenstein 和模 $p$ 約化——「我有忘了什麼工具嗎？」

**為什麼在乎不可約** [▶ 33:30](https://youtu.be/EFHVfIdshJI?t=2010)：學不可約性時好像沒什麼刺激，「誰在乎多項式在 $\mathbb{Q}$ 上可不可約」——但它決定了**擴張體有多高**，這些就是用來算次數的工具。
