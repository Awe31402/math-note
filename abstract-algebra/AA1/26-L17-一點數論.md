# 第 26 集 · L17：一點數論——$U(n)$ 的結構、中國剩餘定理、RSA [▶ 影片](https://www.youtube.com/watch?v=B-7SPCQacCA&list=PLBY4G2o7DhF0JCgapYKrqibGaJuvV4Gkb)

← 上一集：[[25-L16-外直積與內直積]] ｜ [總目錄](../README.md) ｜ 下一集：[[27-L18-群作用]] →

## 本集概要

- 補證 Euler $\varphi$ 函數的公式：$\varphi(p) = p-1$、$\varphi(p^k) = p^k-p^{k-1}$、互質時 $\varphi(st) = \varphi(s)\varphi(t)$。
- **$\gcd(s,t) = 1\Rightarrow U(st)\cong U(s)\times U(t)$**；滿射、單射靠**中國剩餘定理**。
- **中國剩餘定理**：構造式證明，並示範解 $x\equiv2\pmod3$、$x\equiv7\pmod{11}$。
- **$U(n)$ 的結構**：$U(2^n)$、$U(p^n)\cong\mathbb{Z}_{p^n-p^{n-1}}$；例：$U(200)$、$U(405)$、$U(195)$；$\operatorname{Aut}(\mathbb{Z}_{100})$ 中 4 階元素有 4 個。
- 用群論證明 **Fermat 小定理**和 **Euler 定理**。
- **RSA 加密**：陷門函數；玩具例子 $n = 13\cdot17$。

> 📘 講義對應：2018 講義 §3.4 Lecture 14「on units of $\mathbb{Z}_n$ and encryption」（p.100–105）；Gallian 第 8 章「$U(n)$ as external direct products」。

## 筆記

### 0. 開場 [▶ 00:00](https://youtu.be/B-7SPCQacCA?t=0)

上次和今天的工具很強，回頭看早期問過的很多問題都會變得很簡單。原本標題是「一點數論與有限交換群」，交換群移到上一講了 [▶ 01:00](https://youtu.be/B-7SPCQacCA?t=60)。

**注意記號**：本講 $\varphi$ 是 **Euler 函數**，不是同構 [▶ 02:00](https://youtu.be/B-7SPCQacCA?t=120)。

$U(n)$ 的其他記號：$\mathbb{Z}_n^\times$、$(\mathbb{Z}/n\mathbb{Z})^\times$（像 $\mathbb{C}^\times$ 表示非零複數乘法群）[▶ 03:30](https://youtu.be/B-7SPCQacCA?t=210)。課堂沿用 Gallian 的 $U(n)$。定義上 $\varphi(n) = |U(n)|$。

### 1. $\varphi(p) = p-1$ [▶ 02:30](https://youtu.be/B-7SPCQacCA?t=150)

$U(p) = \{1,2,\dots,p-1\}$：$p$ 是質數，正因數只有 1 和 $p$，所以 $1$ 到 $p-1$ 都和 $p$ 互質。數一數就是 $p-1$。

### 2. $\varphi(p^k) = p^k - p^{k-1}$ [▶ 05:00](https://youtu.be/B-7SPCQacCA?t=300)

- 和 $p^k$ **不**互質的數，就是 $p$ 的倍數：$p,2p,3p,\dots,p^{k-1}\cdot p$。
- 要找的不是「$p^k$ 的因數」，而是「和 $p^k$ 有公因數」的數。例如 $2p$ 不整除 $p^k$，但 $\gcd(2p,p^k) = p\neq1$，所以 $2p\notin U(p^k)$ [▶ 09:00](https://youtu.be/B-7SPCQacCA?t=540)。（例：$10\cdot5\equiv0\pmod{25}$，10 沒有模 25 反元素。）
- $p$ 的倍數共 $p^{k-1}$ 個，所以 $\varphi(p^k) = p^k - p^{k-1}$ [▶ 10:30](https://youtu.be/B-7SPCQacCA?t=630)。

> 💬 這段課堂上被學生問得有點亂（老師一度把「倍數」和「因數」混在一起），老師事後說應該先舉 $5^2$ 或 $7^3$ 的具體例子 [▶ 11:30](https://youtu.be/B-7SPCQacCA?t=690)。

### 3. $U(st)\cong U(s)\times U(t)$ [▶ 12:00](https://youtu.be/B-7SPCQacCA?t=720)

> **定理（Gallian 第 8 章）**　若 $\gcd(s,t) = 1$，則 $U(st)\cong U(s)\times U(t)$。
>
> **推論**　$\varphi(st) = \varphi(s)\varphi(t)$。

**映射** [▶ 13:30](https://youtu.be/B-7SPCQacCA?t=810)：有好幾個模數，所以用下標標明 $[x]_n$。
$$\psi([x]_{st}) = ([x]_s,\ [x]_t).$$

**(a) 單值** [▶ 15:00](https://youtu.be/B-7SPCQacCA?t=900)：若 $[x]_{st} = [x']_{st}$，則 $x' = x + jst$。所以
$$([x']_s,[x']_t) = ([x+(jt)s]_s,\ [x+(js)t]_t) = ([x]_s,[x]_t).$$

**(b) 映入 $U(s)\times U(t)$** [▶ 17:00](https://youtu.be/B-7SPCQacCA?t=1020)：$[x]_{st}\in U(st)$ 表示 $\gcd(x,st) = 1$。由 **Bézout**，$ax + bst = 1$。所以 $ax\equiv1\pmod s$ 且 $\pmod t$，$[a]_s$、$[a]_t$ 分別是反元素，$[x]_s\in U(s)$、$[x]_t\in U(t)$。

**(c) 同態** [▶ 20:30](https://youtu.be/B-7SPCQacCA?t=1230)
$$\psi([x][y]) = \psi([xy]) = ([xy]_s,[xy]_t) = ([x]_s,[x]_t)([y]_s,[y]_t) = \psi([x])\psi([y]).$$

**(d) 雙射** [▶ 22:30](https://youtu.be/B-7SPCQacCA?t=1350)
- 老師講義寫「有限集合，證單射或滿射之一就夠」，但他說這不太對：還要先知道兩邊**一樣大** [▶ 23:00](https://youtu.be/B-7SPCQacCA?t=1380)。所以直接證滿射。
- 給 $([y]_s,[z]_t)$，要解 $[x]_s = [y]_s$ 且 $[x]_t = [z]_t$，也就是
$$x\equiv y\pmod s,\qquad x\equiv z\pmod t.$$
- 模數互質，由**中國剩餘定理**，存在解，而且模 $st$ **唯一** [▶ 26:00](https://youtu.be/B-7SPCQacCA?t=1560)。存在給滿射，唯一給單射。$\blacksquare$

### 4. 中國剩餘定理 [▶ 26:30](https://youtu.be/B-7SPCQacCA?t=1590)

（不在先修課程裡；修過數論的人應該看過。證明值得看，因為它告訴你**怎麼算**。）

> **定理（中國剩餘定理 Chinese Remainder Theorem）**　$m_1,\dots,m_r$ 兩兩互質，$M = m_1m_2\cdots m_r$。則聯立同餘式
> $$x\equiv a_1\pmod{m_1},\ \dots,\ x\equiv a_r\pmod{m_r}$$
> 有解，而且解在模 $M$ 下唯一。

**構造** [▶ 29:00](https://youtu.be/B-7SPCQacCA?t=1740)
- 令 $M_k = M/m_k$：包含除了 $m_k$ 以外的所有模數。所以 $M_k\equiv0\pmod{m_j}$（$j\neq k$），而 $\gcd(M_k,m_k) = 1$。
- 例：$m_1 = 2$、$m_2 = 7$、$m_3 = 11$，$M = 154$，$M_1 = 77$、$M_2 = 22$、$M_3 = 14$ [▶ 30:30](https://youtu.be/B-7SPCQacCA?t=1830)。
- 由 Bézout，有 $y_k$ 使 $y_kM_k\equiv1\pmod{m_k}$（$y_k$ 是 $M_k$ 模 $m_k$ 的反元素）[▶ 31:30](https://youtu.be/B-7SPCQacCA?t=1890)。
- 令
$$x = a_1M_1y_1 + a_2M_2y_2 + \cdots + a_rM_ry_r.$$
- 模 $m_i$ 時，除了第 $i$ 項都是 0，而 $M_iy_i\equiv1$，所以 $x\equiv a_i\pmod{m_i}$ ✓

**例** [▶ 33:00](https://youtu.be/B-7SPCQacCA?t=1980)：$x\equiv2\pmod3$、$x\equiv7\pmod{11}$。
- $M = 33$，$M_1 = 11$、$M_2 = 3$。
- $11^{-1}\bmod 3$：$2\cdot11 = 22\equiv1$，所以 $y_1 = 2$。
- $3^{-1}\bmod 11$：$3\cdot4 = 12\equiv1$，所以 $y_2 = 4$。（數字大時要用擴展輾轉相除法。）
- $x = 2\cdot11\cdot2 + 7\cdot3\cdot4 = 44+84 = 128\equiv29\pmod{33}$ [▶ 34:30](https://youtu.be/B-7SPCQacCA?t=2070)。
- 檢查：$29\equiv2\pmod3$ ✓、$29\equiv7\pmod{11}$ ✓。

模數不互質時有更複雜的版本。為什麼叫「中國」？老師說「自己 Google」[▶ 35:30](https://youtu.be/B-7SPCQacCA?t=2130)。

**推廣** [▶ 36:00](https://youtu.be/B-7SPCQacCA?t=2160)：$m_1,\dots,m_r$ 兩兩互質，則
$$U(m_1\cdots m_r)\cong U(m_1)\times\cdots\times U(m_r).$$
證明完全一樣。有些書（如 Dummit & Foote）以中國剩餘定理為主，這只是它的推論；看觀點而定。

### 5. $U(n)$ 的結構 [▶ 37:00](https://youtu.be/B-7SPCQacCA?t=2220)

**交換群的同構類（複習）** [▶ 37:00](https://youtu.be/B-7SPCQacCA?t=2220)：例如 $18 = 2\cdot3^2$，18 階交換群只有 $\mathbb{Z}_2\times\mathbb{Z}_9$、$\mathbb{Z}_2\times\mathbb{Z}_3\times\mathbb{Z}_3$。今天則是把**單位群**拆成基本單位群的直積。

**基本事實**（不證）[▶ 38:30](https://youtu.be/B-7SPCQacCA?t=2310)
- $U(2)\cong\{0\}$（平凡群）
- $U(4)\cong\mathbb{Z}_2$
- $U(2^n)\cong\mathbb{Z}_2\times\mathbb{Z}_{2^{n-2}}$（$n\ge3$）
- $U(p^n)\cong\mathbb{Z}_{p^n-p^{n-1}}$（$p$ 是**奇**質數）——Gauss 的結果 [▶ 39:00](https://youtu.be/B-7SPCQacCA?t=2340)

**例** [▶ 40:00](https://youtu.be/B-7SPCQacCA?t=2400)
- $U(200) = U(8)\times U(25)\cong(\mathbb{Z}_2\times\mathbb{Z}_2)\times\mathbb{Z}_{20}$。（$U(8)$ 就是上次考試的 Klein 四元群。）階 $2\cdot2\cdot20 = 80$：恰有 80 個數和 200 互質。比一個個列出來簡單多了。
- $U(405) = U(5)\times U(81)\cong\mathbb{Z}_4\times\mathbb{Z}_{54}$（$405 = 5\cdot81$，$81-27 = 54$）[▶ 41:30](https://youtu.be/B-7SPCQacCA?t=2490)。$\mathbb{Z}_{54}$ 還可以再拆。
- $U(195) = U(3)\times U(5)\times U(13)\cong\mathbb{Z}_2\times\mathbb{Z}_4\times\mathbb{Z}_{12}$（$195 = 3\cdot5\cdot13$）。（講義投影寫錯了，老師當場更正 [▶ 42:30](https://youtu.be/B-7SPCQacCA?t=2550)。）

**$\operatorname{Aut}(\mathbb{Z}_{100})$ 中有幾個 4 階元素？** [▶ 43:00](https://youtu.be/B-7SPCQacCA?t=2580)
- 沒有理論的話這是很嚇人的問題。
- $\operatorname{Aut}(\mathbb{Z}_{100})\cong U(100) = U(4)\times U(25)\cong\mathbb{Z}_2\times\mathbb{Z}_{20}$。
- 同構保持各階元素的個數。在 $\mathbb{Z}_2\times\mathbb{Z}_{20}$ 中，$\operatorname{lcm}(|a|,|b|) = 4$ 要 $|b| = 4$（$\varphi(4) = 2$ 個）且 $|a|\in\{1,2\}$（2 個）。
- 共 **4** 個 4 階自同構 [▶ 44:30](https://youtu.be/B-7SPCQacCA?t=2670)。

### 6. Fermat 小定理與 Euler 定理 [▶ 45:00](https://youtu.be/B-7SPCQacCA?t=2700)

> **Fermat 小定理**　$p$ 是質數，$a\not\equiv0\pmod p$，則 $a^{p-1}\equiv1\pmod p$。

**證明**：$|U(p)| = p-1$。$\langle a\rangle\le U(p)$，由 Lagrange，$|a|$ 整除 $p-1$，所以 $a^{p-1} = (a^{|a|})^n = 1$。數論課的證法很不一樣，這個簡單多了。

> **Euler 定理**　若 $x\in U(k)$，則 $x^{\varphi(k)}\equiv1\pmod k$。

**證明** [▶ 46:00](https://youtu.be/B-7SPCQacCA?t=2760)：Lagrange 的推論說 $a^{|G|} = e$；套用到 $G = U(k)$，$|U(k)| = \varphi(k)$。老師說 Gallian 裡好像找不到，但這是重要的數論。

### 7. RSA 加密 [▶ 46:30](https://youtu.be/B-7SPCQacCA?t=2790)

網路銀行等安全通訊都靠加密；不然壞人就能攔截讀出你的信用卡號。

**陷門函數 (trapdoor function)** [▶ 47:00](https://youtu.be/B-7SPCQacCA?t=2820)：一個方向很好做，反方向幾乎做不到，除非你知道「讓門反轉的秘密」。

**RSA**（1970 年代；英國情報官 Clifford Cocks 也獨立發明過）[▶ 48:00](https://youtu.be/B-7SPCQacCA?t=2880)
1. 選兩個大質數 $p_1,p_2$，令 $n = p_1p_2$。
2. 選加密指數 $e$，$\gcd(e,\varphi(n)) = 1$。
3. **公開** $n$ 和 $e$。
4. 朋友把訊息編成整數 $m$，送出 $f(m) = m^e\bmod n$。公開送也沒關係。
5. 你知道 $p_1,p_2$，能算 $\varphi(n) = (p_1-1)(p_2-1)$，再求解密指數 $d = e^{-1}\bmod\varphi(n)$。別人不知道 $n$ 的分解；幾百位數的質數乘積在有限時間內無法分解，這就是安全的來源 [▶ 50:00](https://youtu.be/B-7SPCQacCA?t=3000)。
6. 解密：$ed = 1 + k\varphi(n)$，由 Euler 定理
$$(m^e)^d = m^{1+k\varphi(n)} = m\cdot(m^{\varphi(n)})^k = m.$$

**玩具例子**（講義）[▶ 50:30](https://youtu.be/B-7SPCQacCA?t=3030)：$p_1 = 13$、$p_2 = 17$，$n = 221$，$\varphi(n) = 192$；訊息 J $= 10$；$e = 37$。
- 加密：$10^{37}\equiv23\pmod{221}$。（實際計算用反覆平方：$37 = 32+4+1$。）
- 解密指數：$d = 37^{-1}\bmod192 = 109$；$23^{109}\equiv10\pmod{221}$ ✓

**隱藏的陷阱** [▶ 51:30](https://youtu.be/B-7SPCQacCA?t=3090)：老師在數論課用過 $e = 49$，結果學生「加密」後訊息 10 還是 10。原因：48 是那個群的**群指數 (group exponent)**，任何元素的 48 次方都是單位，所以 49 次方等於原來的元素。
