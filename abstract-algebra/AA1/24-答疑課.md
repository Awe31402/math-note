## 2. 題 2：K < H < G，|H| 可能是多少

[▶ 02:30](https://youtu.be/oOnNkaW_ElI?t=150)（第 5 版 Ch.7 #14）「我有出這題嗎？我不覺得。好吧，有出就有出。」

> **題目**　$K$ 是 $H$ 的真子群，$H$ 是 $G$ 的真子群。$|K| = 42$，$|G| = 420$。$|H|$ 可能是多少？

**Lagrange 雙向使用**[▶ 05:00](https://youtu.be/oOnNkaW_ElI?t=300)：
- $K\le H$：$|H|$ 是 **42 的倍數**。
- $H\le G$：$|H|$ **整除 420**。
- 真子群：$42<|H|<420$。

【課堂討論】列 42 的倍數 [▶ 06:00](https://youtu.be/oOnNkaW_ElI?t=360)：$84,126,168,210,\dots$
- 「我想只能到 210，因為那是 420 的一半。」（真子群的階整除 420 且小於 420，最大是 $420/2$。）

**檢查哪些整除 420**[▶ 07:00](https://youtu.be/oOnNkaW_ElI?t=420)：

| 候選 | 整除 420？ |
|---|---|
| 84 | ✓（$420 = 5\cdot84$） |
| 126 | ✗ |
| 168 | ✗ |
| 210 | ✓（$420 = 2\cdot210$） |

**答案**：$|H| = 84$ 或 $210$。

## 3. 插曲：找不到的定理

[▶ 08:00](https://youtu.be/oOnNkaW_ElI?t=480)「我要告訴你們：明天要交的作業有一題，需要用到後面某章的東西……」老師翻書找一個定理（「該死的東西在哪」），關於**兩個子群乘積的階**。「我還沒在課堂講，也沒背起來。它不複雜，但我不想說錯。」[▶ 10:30](https://youtu.be/oOnNkaW_ElI?t=630)

【口頭】[▶ 09:00](https://youtu.be/oOnNkaW_ElI?t=540)「我有點擔心：我在別的版本找到過它。我很確定舊版也有……」[▶ 14:30](https://youtu.be/oOnNkaW_ElI?t=870)「也許後面版本有、這個版本沒有，這讓我很怪。不過我們集體省了幾千塊，大概是贏了。」

**他記得的內直積情況**[▶ 12:00](https://youtu.be/oOnNkaW_ElI?t=720)：$H,K\trianglelefteq G$、$H\cap K = \{e\}$、$G = HK$ 時，$|G| = |H||K|$。
- 例 [▶ 13:30](https://youtu.be/oOnNkaW_ElI?t=810)：若 $|H| = 12$、$|K| = 18$、交集只有單位元素，則 $|HK| = 12\cdot18 = 216$——**在 36 階群裡不可能**。
- 「但那題作業的 $H$、$K$ 交集不一定是 $\{e\}$，所以這不是你們需要的。我幫不上忙，閉嘴吧。」

> 💬 老師要找的應是 Gallian Thm 7.2（非課堂內容，僅列出陳述）：對有限子群 $H,K$，
> $$|HK| = \frac{|H||K|}{|H\cap K|}.$$

## 4. 把 D₃ 變成 S₆ 的子群（Cayley 定理）

[▶ 15:00](https://youtu.be/oOnNkaW_ElI?t=900)「我想看左乘映射，給你們看一個怪點子。」

$$D_3 = \{1,x,x^2,y,xy,x^2y\},\qquad x^3 = 1,\ y^2 = 1,\ yx = x^{-1}y = x^2y.$$

**左乘 $L_x$**[▶ 15:30](https://youtu.be/oOnNkaW_ElI?t=930)【課堂討論】：
- $1\to x\to x^2\to1$；
- $y\to xy\to x^2y\to y$。

**「抽象循環記號」**[▶ 16:30](https://youtu.be/oOnNkaW_ElI?t=990)：可以寫成 $(1\ x\ x^2)(y\ xy\ x^2y)$——「如果你願意把循環記號推廣到抽象元素，而不只是 1 到 $n$」。「但我們不想這樣——作業（$Q_8$ 那題）不是這樣寫。」

**改成編號**[▶ 17:00](https://youtu.be/oOnNkaW_ElI?t=1020)：

| 元素 | $1$ | $x$ | $x^2$ | $y$ | $xy$ | $x^2y$ |
|---|---|---|---|---|---|---|
| 編號 | 1 | 2 | 3 | 4 | 5 | 6 |

於是 $L_x = (1\,2\,3)(4\,5\,6)\in S_6$。「這是一個**表示**：你可以把 $D_3$ 看成 $S_6$ 的一個特定子群。」

**$L_{x^2}$**[▶ 18:30](https://youtu.be/oOnNkaW_ElI?t=1110)：$1\to x^2\to x\to1$，$y\to x^2y\to xy\to y$，所以 $(1\,3\,2)(4\,6\,5)$。

【口頭】[▶ 20:00](https://youtu.be/oOnNkaW_ElI?t=1200)「如果我聰明一點就不用算：$L_{x^2} = L_x^{-1}$。這是一個**忠實的（faithful）**對應，反元素對應反元素。所以直接把 $L_x$ 的循環倒過來寫。」

**$L_y$**[▶ 20:30](https://youtu.be/oOnNkaW_ElI?t=1230)：
- $1\to y$；
- $x\to yx = x^{-1}y = x^2y$（「$x^{-1}$ 在這裡是 $x^2$」）；
- $x^2\to yx^2 = x^{-2}y = xy$；
- $y\to y^2 = 1$；$xy\to yxy = x^{-1} = x^2$；$x^2y\to yx^2y = x^{-2} = x$。

所以 $L_y = (1\,4)(2\,6)(3\,5)$。

（老師算 $L_y$ 時重複算了同一個循環兩次：「我是笨蛋，同樣的計算做了兩次。$x^2y$ 已經在上面了，問過也答過了。」[▶ 23:30](https://youtu.be/oOnNkaW_ElI?t=1410)）

**全部六個**：

| 元素 | 左乘映射（$S_6$） |
|---|---|
| $1$ | $(1)$ |
| $x$ | $(1\,2\,3)(4\,5\,6)$ |
| $x^2$ | $(1\,3\,2)(4\,6\,5)$ |
| $y$ | $(1\,4)(2\,6)(3\,5)$ |
| $xy$ | $(1\,5)(2\,4)(3\,6)$ |
| $x^2y$ | $(1\,6)(2\,5)(3\,4)$ |

> ⚠️ 課堂上算 $L_{xy}$、$L_{x^2y}$ 時有幾處寫錯或混亂（例如字幕念出「1 5 4 2」）。上表是用 $yx^k = x^{-k}y$ 重新核對過的版本。例：$L_{xy}(x) = xyx = x\cdot x^2y = y$，所以 $2\to4$；$L_{x^2y}(x) = x^2yx = x^2\cdot x^2y = xy$，所以 $2\to5$。

【口頭】[▶ 29:00](https://youtu.be/oOnNkaW_ElI?t=1740)「這種時候你們會很高興我讓你們合作。」「做久了你會有洞察力，變快，不再犯我這種蠢錯。」

**結論**[▶ 30:00](https://youtu.be/oOnNkaW_ElI?t=1800)：這六個置換組成 $S_6$ 的一個**真子群**，同構於 $D_3$。

**Cayley 定理的另一個版本**[▶ 31:00](https://youtu.be/oOnNkaW_ElI?t=1860)：
> 每個 $n$ 階有限群，都同構於 $S_n$（$n!$ 階）的某個子群。

「我想這對那題作業（$Q_8$ 嵌入 $S_8$）可能有幫助。」

## 5. 四元數

[▶ 32:00](https://youtu.be/oOnNkaW_ElI?t=1920)「沒問題的話，我來講一下四元數。」

### 5.1 Q₈ 和 ℍ 不一樣

| | 定義 | 元素數 |
|---|---|---|
| **四元數群** $Q_8$ | $\{\pm1,\pm i,\pm j,\pm k\}$ | 8 |
| **四元數** $\mathbb{H}$ [▶ 32:30](https://youtu.be/oOnNkaW_ElI?t=1950) | $\{a+bi+cj+dk : a,b,c,d\in\mathbb{R}\}$ | 無限 |

$\mathbb{H}$ 是 $Q_8$ 的**所有實線性組合**。規則：$i^2 = j^2 = k^2 = -1$，$ij = k$、$jk = i$、$ki = j$，反過來乘加負號；其他照**分配律**。

### 5.2 乘法公式

[▶ 33:30](https://youtu.be/oOnNkaW_ElI?t=2010)「定義是讓分配律照預期運作。」

$$(a+bi+cj+dk)(t+xi+yj+zk)$$
$$= (at-bx-cy-dz)+(ax+bt+cz-dy)\,i+(ay+ct+dx-bz)\,j+(az+dt+by-cx)\,k.$$

**怎麼記**[▶ 34:30](https://youtu.be/oOnNkaW_ElI?t=2070)：$i,j,k$ 排成一個圈（$i\to j\to k\to i$），順著乘是正，逆著乘是負。

**得到 $i$ 的四種方式**[▶ 35:30](https://youtu.be/oOnNkaW_ElI?t=2130)：$1\cdot i$、$i\cdot1$、$jk = i$、$kj = -i$。所以 $i$ 分量是 $ax+bt+cz-dy$。

（老師邊寫邊說「我選項的順序不太一致，抱歉」[▶ 37:30](https://youtu.be/oOnNkaW_ElI?t=2250)。）

**歷史**[▶ 34:30](https://youtu.be/oOnNkaW_ElI?t=2070)：
- 微積分三的 $\hat i,\hat j,\hat k$ 記號來自 **Hamilton 的四元數**。在有向量之前，向量分析是用四元數做的。向量分析出現時借用了 $ijk$ 記號，延續至今。
- 【口頭】「這是**很差的向量記號**。我們應該寫 $\langle a,b,c\rangle$，好太多了，理由多到數不完。我教微積分三不寫 $ijk$。」
- [▶ 44:00](https://youtu.be/oOnNkaW_ElI?t=2640)「人們用四元數大約 **40 年**才改用向量。那是一場**戰爭**——你知道物理學家和工程師是怎樣的，他們對記號有某種**形而上的依戀**。」

### 5.3 共軛、反元素、斜體

**共軛**[▶ 38:30](https://youtu.be/oOnNkaW_ElI?t=2310)：
$$\overline{a+bi+cj+dk} = a-bi-cj-dk.$$

**反元素**[▶ 39:00](https://youtu.be/oOnNkaW_ElI?t=2340)：$z\neq0$ 時
$$z^{-1} = \frac{\bar z}{z\bar z}.$$
（$z\bar z = a^2+b^2+c^2+d^2$ 是正實數。）

**幾乎是體**[▶ 39:30](https://youtu.be/oOnNkaW_ElI?t=2370)：
- 有加法、乘法、單位 1；
- 每個**非零**元素都有乘法反元素；
- 它是一個**環**。

**但不是體**[▶ 40:00](https://youtu.be/oOnNkaW_ElI?t=2400)：$ij = k$、$ji = -k$，乘法**不交換**。

> $\mathbb{H}$ 是**斜體（skew field）**——也叫除環（division ring）：除了乘法不交換，其他都像體。

【口頭】[▶ 40:30](https://youtu.be/oOnNkaW_ElI?t=2430)「如果你要我舉另一個斜體的例子，我給不出來。我只知道這一個。」

### 5.4 藏在裡面的內積與外積

[▶ 40:30](https://youtu.be/oOnNkaW_ElI?t=2430)「歪頭瞇眼看：」把四元數寫成「實部 + 三維向量」：
$$a+\mathbf A,\quad\mathbf A = \langle b,c,d\rangle;\qquad t+\mathbf R,\quad\mathbf R = \langle x,y,z\rangle.$$
（老師一度想用 $W$，「免得混淆，就用 $\mathbf R$ 吧，怪一點」。）

對照乘法公式 [▶ 42:00](https://youtu.be/oOnNkaW_ElI?t=2520)：
- 實部 $at-bx-cy-dz = at-\mathbf A\cdot\mathbf R$。
- 向量部分：$a\mathbf R+t\mathbf A$，再加上……
- 「外積的第一個分量是什麼？$cz-dy$。」[▶ 43:00](https://youtu.be/oOnNkaW_ElI?t=2580) 正好是 $i$ 分量剩下的那部分。

$$(a+\mathbf A)(t+\mathbf R) = \big(at-\mathbf A\cdot\mathbf R\big)+\big(a\mathbf R+t\mathbf A+\mathbf A\times\mathbf R\big).$$

【口頭】[▶ 43:30](https://youtu.be/oOnNkaW_ElI?t=2610)「**四元數乘積裡藏著三維向量的一般內積和外積**，再加一些額外的東西。」

**純空間四元數**（$a = t = 0$）[▶ 44:00](https://youtu.be/oOnNkaW_ElI?t=2640)：
$$\mathbf A\mathbf R = -\mathbf A\cdot\mathbf R+\mathbf A\times\mathbf R.$$
「微積分三能做的，用四元數都能做——只要適當地按摩這些式子。這就是為什麼人們用了 40 年。」

### 5.5 子群與圖像

[▶ 44:30](https://youtu.be/oOnNkaW_ElI?t=2670)「裡面有非常豐富的例子。」
- **加法子群**：$\{a+bi : a,b\in\mathbb{R}\}$ 是 $(\mathbb{H},+)$ 的子群——一份複數。「至少有三個這種，還有更多。」
- **乘法子群**：非零的 $a+bi$ 是非零四元數乘法群的子群。

**圖像**[▶ 45:30](https://youtu.be/oOnNkaW_ElI?t=2730)：$i$、$j$、$k$ 方向各有一份**複數**，三份互相**正交**，**共用同一條實數線**。

**還有**[▶ 46:00](https://youtu.be/oOnNkaW_ElI?t=2760)：四元數也可以看成某些 **$4\times4$ 矩陣**。「我不確定課堂會講到，但最後會有作業——到時候你們就會收割這段討論的回報。剛才推導的東西可能讓某些作業簡單很多。」

## 6. 一頁速查表

### 6.1 Lagrange 的用法

| 題目 | 方法 | 答案 |
|---|---|---|
| 60 階群的子群階 | 60 的因數 | 1, 2, 3, 4, 5, 6, 10, 12, 15, 20, 30, 60 |
| $K<H<G$，$\lvert K\rvert = 42$、$\lvert G\rvert = 420$ | $\lvert H\rvert$ 是 42 的倍數 **且** 整除 420，介於兩者之間 | 84、210 |
| $\lvert H\rvert = 12$、$\lvert K\rvert = 18$、$H\cap K = \{e\}$ in 36 階群 | $\lvert HK\rvert = 216>36$ | 不可能 |

（Gallian Thm 7.2：$\lvert HK\rvert = \lvert H\rvert\lvert K\rvert/\lvert H\cap K\rvert$。）

### 6.2 Cayley：$D_3\hookrightarrow S_6$

編號 $1,x,x^2,y,xy,x^2y\mapsto1,\dots,6$；$L_g$ 寫成置換。

$L_x = (123)(456)$、$L_{x^2} = (132)(465)$、$L_y = (14)(26)(35)$、$L_{xy} = (15)(24)(36)$、$L_{x^2y} = (16)(25)(34)$。

**技巧**：$L_{g^{-1}} = L_g^{-1}$，倒寫循環即可。

### 6.3 四元數 $\mathbb{H}$

| 項目 | 內容 |
|---|---|
| 規則 | $i^2 = j^2 = k^2 = -1$；$ij = k$、$jk = i$、$ki = j$；反向加負號 |
| 乘積 | $(a+\mathbf A)(t+\mathbf R) = (at-\mathbf A\cdot\mathbf R)+(a\mathbf R+t\mathbf A+\mathbf A\times\mathbf R)$ |
| 共軛 | $\overline{a+bi+cj+dk} = a-bi-cj-dk$ |
| 反元素 | $z^{-1} = \bar z/(z\bar z)$ |
| 結構 | 斜體（除環）：非零元素都可逆，但不交換 |

> **Lagrange 可以雙向用（$|H|$ 既是 $|K|$ 的倍數又整除 $|G|$，所以 $|H| = 84$ 或 $210$）；把 $D_3$ 的六個元素編號，左乘映射就成了 $S_6$ 的置換，具體實現 Cayley 定理；四元數 $\mathbb{H}$ 是 $Q_8$ 的實線性組合，每個非零元素可逆但乘法不交換（斜體），而它的乘法裡正好藏著三維向量的內積和外積——這就是 $\hat i,\hat j,\hat k$ 記號的由來。**
