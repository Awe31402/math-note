# 第 24 集 · 答疑課：Lagrange 習題、$D_3$ 嵌入 $S_6$、四元數 [▶ 影片](https://www.youtube.com/watch?v=oOnNkaW_ElI&list=PLBY4G2o7DhF0JCgapYKrqibGaJuvV4Gkb)

## 本集概要

- **Lagrange 定理的練習**：60 階群可能的子群階；$K<H<G$ 時 $|H|$ 的可能值（Lagrange 雙向用）。
- **Cayley 定理的具體化**：$D_3$ 的六個左乘映射寫成 $S_6$ 的置換，得到 $S_6$ 裡一個同構於 $D_3$ 的子群。
- **四元數 $\mathbb{H}$**：乘法公式；藏著三維向量的**內積**和**外積**；每個非零元素可逆但不交換，是**斜體 (skew field)**。

## 筆記

### 題 1：60 階群的子群可能是幾階（Ch.7 #13，第 5 版）[▶ 01:00](https://youtu.be/oOnNkaW_ElI?t=60)

由 Lagrange，子群的階整除 60：
$$1,2,3,4,5,6,10,12,15,20,30,60.$$

### 題 2：$K<H<G$ 時 $|H|$ 的可能值（Ch.7 #14，第 5 版）[▶ 02:30](https://youtu.be/oOnNkaW_ElI?t=150)

**題目**：$K$ 是 $H$ 的真子群，$H$ 是 $G$ 的真子群，$|K| = 42$，$|G| = 420$。$|H|$ 可能是多少？

**Lagrange 雙向用** [▶ 05:00](https://youtu.be/oOnNkaW_ElI?t=300)
- $K\le H$，所以 $|H|$ 是 **42 的倍數**；
- $H\le G$，所以 $|H|$ **整除 420**；
- 而且 $42<|H|<420$。

42 的倍數：84、126、168、210、……；真子群最多是 420 的一半，所以到 210 為止 [▶ 06:30](https://youtu.be/oOnNkaW_ElI?t=390)。
- $84\mid 420$ ✓
- $126\nmid 420$ ✗
- $168\nmid 420$ ✗
- $210\mid 420$ ✓

**答案**：$|H| = 84$ 或 $210$ [▶ 07:30](https://youtu.be/oOnNkaW_ElI?t=450)。

### 插曲：找不到的定理 [▶ 08:00](https://youtu.be/oOnNkaW_ElI?t=480)

老師說明天要交的作業有一題要用到「兩個子群乘積的階」的定理，但課堂還沒講，他一時在書裡找不到，也不想說錯 [▶ 10:30](https://youtu.be/oOnNkaW_ElI?t=630)。
- 他記得內直積的情形：$H,K\trianglelefteq G$，$H\cap K = \{e\}$，$G = HK$，則 $|G| = |H||K|$。
- 例：若 $|H| = 12$、$|K| = 18$ 且交集只有單位元素，則 $|HK| = 216$，在 36 階群裡不可能 [▶ 13:30](https://youtu.be/oOnNkaW_ElI?t=810)。
- 但作業那題的 $H$、$K$ 交集不一定是 $\{e\}$。

> 💬 補充（非課堂內容）：老師要找的應是 Gallian Thm 7.2：對有限子群 $H,K$，
> $$|HK| = \frac{|H||K|}{|H\cap K|}.$$

### 題 3：把 $D_3$ 變成 $S_6$ 的子群（Cayley 定理）[▶ 15:00](https://youtu.be/oOnNkaW_ElI?t=900)

$D_3 = \{1,x,x^2,y,xy,x^2y\}$，關係 $x^3 = 1$、$y^2 = 1$、$yx = x^{-1}y$。

**編號** [▶ 17:30](https://youtu.be/oOnNkaW_ElI?t=1050)：$1\to1$、$x\to2$、$x^2\to3$、$y\to4$、$xy\to5$、$x^2y\to6$。

**左乘 $L_x$** [▶ 15:30](https://youtu.be/oOnNkaW_ElI?t=930)：$1\to x\to x^2\to1$，$y\to xy\to x^2y\to y$。
- 用「抽象循環記號」可以寫成 $(1\ x\ x^2)(y\ xy\ x^2y)$，但作業不用這種寫法 [▶ 17:00](https://youtu.be/oOnNkaW_ElI?t=1020)。
- 編號後：$L_x = (123)(456)$。

**全部六個**

| 元素 | 左乘映射（$S_6$） |
|---|---|
| $1$ | $(1)$ |
| $x$ | $(123)(456)$ |
| $x^2$ | $(132)(465)$ |
| $y$ | $(14)(26)(35)$ |
| $xy$ | $(15)(24)(36)$ |
| $x^2y$ | $(16)(25)(34)$ |

- $L_{x^2} = L_x^{-1}$，所以不用算，直接把 $L_x$ 倒過來寫 [▶ 20:00](https://youtu.be/oOnNkaW_ElI?t=1200)。這個對應是**忠實的 (faithful)**，反元素對應反元素。
- 例：$L_y(x) = yx = x^{-1}y = x^2y$，所以 $2\to6$ [▶ 21:00](https://youtu.be/oOnNkaW_ElI?t=1260)。

> 💬 老師在課堂上算 $L_y$、$L_{xy}$ 時有幾次重複或寫錯，上表是重新核對過的版本。

**結論** [▶ 29:30](https://youtu.be/oOnNkaW_ElI?t=1770)：這六個置換組成 $S_6$ 的一個子群，同構於 $D_3$。

**Cayley 定理的另一種說法** [▶ 31:00](https://youtu.be/oOnNkaW_ElI?t=1860)：每個 $n$ 階有限群都同構於 $S_n$ 的某個子群（$|S_n| = n!$）。老師說這應該對 $Q_8$ 那題作業有幫助。

### 4. 四元數 [▶ 32:00](https://youtu.be/oOnNkaW_ElI?t=1920)

**區分** [▶ 32:30](https://youtu.be/oOnNkaW_ElI?t=1950)
- **四元數群** $Q_8 = \{\pm1,\pm i,\pm j,\pm k\}$，8 個元素。
- **四元數 (quaternions)** $\mathbb{H} = \{a+bi+cj+dk\mid a,b,c,d\in\mathbb{R}\}$，就是 $Q_8$ 的所有實線性組合。

規則：$i^2 = j^2 = k^2 = -1$，$ij = k$、$jk = i$、$ki = j$，反過來乘加負號；其他照分配律。

**乘法公式** [▶ 33:30](https://youtu.be/oOnNkaW_ElI?t=2010)
$$(a+bi+cj+dk)(t+xi+yj+zk) = (at-bx-cy-dz)$$
$$+\,(ax+bt+cz-dy)\,i + (ay+ct+dx-bz)\,j + (az+dt+by-cx)\,k.$$

（得到 $i$ 的四種方式：$1\cdot i$、$i\cdot1$、$jk = i$、$kj = -i$ [▶ 35:30](https://youtu.be/oOnNkaW_ElI?t=2130)。）

**歷史** [▶ 34:30](https://youtu.be/oOnNkaW_ElI?t=2070)：微積分三的 $\hat i,\hat j,\hat k$ 記號來自 **Hamilton 的四元數**。向量分析出現前，人們用四元數做這些事約 40 年。老師覺得 $\hat i,\hat j,\hat k$ 是很差的向量記號，比較喜歡 $\langle a,b,c\rangle$。物理學家和工程師對記號有「形而上的依戀」，改用向量還經過一番爭吵 [▶ 44:00](https://youtu.be/oOnNkaW_ElI?t=2640)。

**共軛與反元素** [▶ 38:30](https://youtu.be/oOnNkaW_ElI?t=2310)
$$\overline{a+bi+cj+dk} = a-bi-cj-dk,\qquad z^{-1} = \frac{\bar z}{z\bar z}\quad(z\neq0).$$

**斜體** [▶ 39:30](https://youtu.be/oOnNkaW_ElI?t=2370)：有加法、乘法、單位 1，每個非零元素都可逆，幾乎是**體**；但 $ij = k\neq -k = ji$，乘法不交換。這叫**斜體 (skew field)**。老師說他只知道這一個例子。

**藏在裡面的內積與外積** [▶ 40:30](https://youtu.be/oOnNkaW_ElI?t=2430)：把四元數寫成「實部 + 三維向量」，$(a,\mathbf A)$、$(t,\mathbf R)$，其中 $\mathbf A = \langle b,c,d\rangle$、$\mathbf R = \langle x,y,z\rangle$。則
$$(a,\mathbf A)(t,\mathbf R) = \big(at - \mathbf A\cdot\mathbf R,\ \ a\mathbf R + t\mathbf A + \mathbf A\times\mathbf R\big).$$
- 例如 $i$ 分量裡的 $cz-dy$ 就是 $\mathbf A\times\mathbf R$ 的第一個分量 [▶ 43:30](https://youtu.be/oOnNkaW_ElI?t=2610)。
- 只看「純向量」四元數（$a = t = 0$）：乘積 $= -\mathbf A\cdot\mathbf R + \mathbf A\times\mathbf R$。微積分三能做的，四元數都能做。

**子群** [▶ 44:30](https://youtu.be/oOnNkaW_ElI?t=2670)
- $\{a+bi\}$ 是 $(\mathbb{H},+)$ 的子群（就是一份複數）。
- $\{a+bi\neq0\}$ 是非零四元數乘法群的子群。
- 圖像：$i$、$j$、$k$ 方向各有一份複數，三份互相垂直，共用同一條實數線 [▶ 45:30](https://youtu.be/oOnNkaW_ElI?t=2730)。
- 四元數也可以看成某些 $4\times4$ 矩陣 [▶ 46:00](https://youtu.be/oOnNkaW_ElI?t=2760)。之後會有作業。
