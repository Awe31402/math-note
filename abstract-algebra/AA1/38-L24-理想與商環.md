# 第 38 集 · L24：理想與商環、質理想與極大理想 [▶ 影片](https://www.youtube.com/watch?v=fGCp5GwRLHA&list=PLBY4G2o7DhF0JCgapYKrqibGaJuvV4Gkb)

← 上一集：[[37-答疑課]] ｜ [總目錄](../README.md) ｜ 下一集：[[39-L25-環同態]] →

## 本集概要

- **理想 (ideal)**：子環 $A$，而且 $ar,ra\in A$ 對所有 $a\in A$、$r\in R$（「超級封閉」）。**理想判別法**。
- 例：$n\mathbb{Z}$；**主理想 (principal ideal)** $\langle a\rangle = aR$（證明它是理想）；$\langle x\rangle\subseteq\mathbb{R}[x]$ = 常數項為 0 的多項式；$\langle a_1,\dots,a_n\rangle$。
- **商環 (factor ring)** $R/A$：$(r+A)(s+A) = rs+A$ 良定義 $\iff A$ 是理想。
- 例：$\mathbb{R}[x]/\langle x^2+1\rangle$：$x$ 的行為就像 $i$，這其實是 $\mathbb{C}$。
- **質理想 (prime ideal)**、**極大理想 (maximal ideal)**；$\mathbb{Z}_{36}$ 的理想格，極大理想是 $\langle2\rangle$、$\langle3\rangle$。
- **$R/A$ 是整環 $\iff A$ 是質理想**（證明）；**$R/A$ 是體 $\iff A$ 是極大理想**（下次證）。

> 📘 講義對應：2018 講義 §4.2 Lecture 22「ideals and factor rings」與 §4.3 Lecture 23「prime and maximal ideals」（p.129–136）；Gallian 第 14 章。

## 筆記

### 0. 回顧 [▶ 00:00](https://youtu.be/fGCp5GwRLHA?t=0)

昨天的答疑課證了特徵定理和**整環的消去律**（$a\neq0$、$ab = ac\Rightarrow b = c$，即使 $a^{-1}$ 不存在）。但鏡頭沒往上拍，請自己看講義。

### 1. 理想 [▶ 01:00](https://youtu.be/fGCp5GwRLHA?t=60)

> **定義**　環 $R$ 的子環 $A$ 叫**理想**，若對所有 $a\in A$、$r\in R$，$ar\in A$ 且 $ra\in A$。

- 子環只要求 $A$ 裡的元素相乘還在 $A$；理想更強：**拿 $R$ 裡任何元素**（可能在 $A$ 外面）去乘，左乘右乘都還在 $A$。另一位教授叫它「**超級封閉 (uber closure)**」——老師提醒在別人面前別用這個詞 [▶ 02:00](https://youtu.be/fGCp5GwRLHA?t=120)。

> **定理（理想判別法 ideal test）**　$R$ 的非空子集 $A$ 是理想 $\iff$
> 1. $a,b\in A\Rightarrow a-b\in A$；
> 2. $a\in A$、$r\in R\Rightarrow ar,ra\in A$。

**和定義的差別** [▶ 03:30](https://youtu.be/fGCp5GwRLHA?t=210)：定義的開頭是「設 $A$ 是**子環**」。判別法說這兩條就**足以**推出子環：(1) 給減法封閉；(2) 取 $r\in A\subseteq R$，給乘法封閉。

**平凡的例子** [▶ 05:00](https://youtu.be/fGCp5GwRLHA?t=300)：$\{0\}$ 和 $R$ 都是理想。$\{0\}$ 是**真理想 (proper ideal)**（不是整個 $R$），但是平凡的；$R$ 不是真理想。

### 2. $n\mathbb{Z}$ 是理想 [▶ 06:00](https://youtu.be/fGCp5GwRLHA?t=360)

$A = n\mathbb{Z}$（$n = 1$ 時就是 $\mathbb{Z}$ 本身，不是真理想）。
- $a = na'$、$b = nb'$：$a-b = n(a'-b')\in n\mathbb{Z}$（用分配律）[▶ 07:30](https://youtu.be/fGCp5GwRLHA?t=450)。
- $r\in\mathbb{Z}$：$ar = n(a'r)\in n\mathbb{Z}$。交換環只要檢查一邊 [▶ 08:00](https://youtu.be/fGCp5GwRLHA?t=480)。

> 💬「你們來 Liberty 之前就懂整數了——我相信。」

### 3. 主理想 [▶ 09:00](https://youtu.be/fGCp5GwRLHA?t=540)

老師認為這應該有獨立的定義，不該埋在 Gallian 的例子裡。

> **定義（主理想）**　$R$ 是有單位元的交換環，$a\in R$。**$a$ 生成的主理想**
> $$\langle a\rangle = \{ar\mid r\in R\} = aR\ (= Ra).$$

例：$\langle n\rangle = n\mathbb{Z}$ [▶ 11:00](https://youtu.be/fGCp5GwRLHA?t=660)。但這例子不能證明「主理想」這個名字合理，要另外證：

> **定理**　$\langle a\rangle$ 是理想 [▶ 12:00](https://youtu.be/fGCp5GwRLHA?t=720)。

**證明**
- $a0 = 0\in\langle a\rangle$，非空。
- $x = ax'$、$y = ay'$：$x-y = a(x'-y')$，而 $x'-y'\in R$，所以在 $\langle a\rangle$ 裡 [▶ 13:30](https://youtu.be/fGCp5GwRLHA?t=810)。
- $r\in R$（**要說 $r$ 從哪裡來**——老師的小抱怨）：$xr = a(x'r)\in\langle a\rangle$ [▶ 14:00](https://youtu.be/fGCp5GwRLHA?t=840)。$\blacksquare$

**例：$\langle x\rangle\subseteq\mathbb{R}[x]$** [▶ 16:30](https://youtu.be/fGCp5GwRLHA?t=990)：$\{xf(x)\}$，也就是 $g(0) = 0$ 的多項式，**常數項為 0** 的多項式。

> **定義**　$\langle a_1,\dots,a_n\rangle = \{a_1r_1+\cdots+a_nr_n\mid r_i\in R\}$，**$a_1,\dots,a_n$ 生成的理想** [▶ 17:30](https://youtu.be/fGCp5GwRLHA?t=1050)。

- 一般**不是**主理想，除非 $n = 1$，或生成元彼此相依，例如 $\langle x,2x\rangle = \langle x\rangle$ [▶ 18:30](https://youtu.be/fGCp5GwRLHA?t=1110)。
- 證明它是理想：**作業**。

### 4. 商環 [▶ 20:00](https://youtu.be/fGCp5GwRLHA?t=1200)

**理想的意義**：讓我們能自然地造出**商環 (factor ring / quotient ring)**。

> **定理（Gallian Thm 14.2）**　$A$ 是 $R$ 的子環。在加法陪集 $R/A = \{r+A\mid r\in R\}$ 上定義
> $$(r+A)+(s+A) = (r+s)+A,\qquad (r+A)(s+A) = rs+A.$$
> 則 $R/A$ 是環 $\iff A$ 是理想。

（老師說「可能的運算」，因為不是理想時乘法可能不良定義。）

**證明（$A$ 是理想 $\Rightarrow$）** [▶ 23:00](https://youtu.be/fGCp5GwRLHA?t=1380)
- **加法**：$A$ 是子環，所以是 $(R,+)$ 的子群；交換群的子群都正規，所以加法陪集的商群已經定義好了，沒事做。
- **乘法良定義** [▶ 24:00](https://youtu.be/fGCp5GwRLHA?t=1440)：設 $s+A = s'+A$、$t+A = t'+A$，即 $s' = s+a$、$t' = t+b$（$a,b\in A$）。
$$s't' = (s+a)(t+b) = st + \underbrace{at}_{\in A} + \underbrace{sb}_{\in A} + \underbrace{ab}_{\in A}.$$
  $at$、$sb$ 靠超級封閉（左右都要！），$ab$ 靠子環封閉。所以 $s't'-st\in A$，$s't'+A = st+A$ [▶ 27:00](https://youtu.be/fGCp5GwRLHA?t=1620)。
- **結合律、分配律**：直接從 $R$ 繼承（講義有寫）。
- **這就是為什麼左右都要能吸收** [▶ 28:00](https://youtu.be/fGCp5GwRLHA?t=1680)。反方向（不是理想就會不良定義）在講義裡。

> 💬 老師提到考題裡關於陪集相等的那題有打字錯誤，「對有些人反而是幫忙」[▶ 25:00](https://youtu.be/fGCp5GwRLHA?t=1500)。

### 5. 例：$\mathbb{R}[x]/\langle x^2+1\rangle$ [▶ 29:00](https://youtu.be/fGCp5GwRLHA?t=1740)

（Gallian Example 12。）元素是 $g(x)+\langle x^2+1\rangle$。
- $g+\langle x^2+1\rangle = h+\langle x^2+1\rangle\iff g-h = (x^2+1)j(x)$ [▶ 30:30](https://youtu.be/fGCp5GwRLHA?t=1830)。
- **化簡** [▶ 31:30](https://youtu.be/fGCp5GwRLHA?t=1890)：$x^2+2x+2+\langle x^2+1\rangle = 2x+1+\langle x^2+1\rangle$（把 $x^2+1$ 吸進理想裡，就像 $h+H = H$）。
- **關鍵** [▶ 32:30](https://youtu.be/fGCp5GwRLHA?t=1950)：$x^2+\langle x^2+1\rangle = -1+\langle x^2+1\rangle$。也就是「模 $x^2+1$，$x^2\equiv-1$」——**$x$ 的行為就像虛數單位 $i$** [▶ 33:30](https://youtu.be/fGCp5GwRLHA?t=2010)。
- 任何 $a_0+a_1x+a_2x^2+a_3x^3+\cdots$ 都可以把 $x^2$ 換成 $-1$、$x^3$ 換成 $-x$……化成 $b_0+b_1x$ [▶ 34:30](https://youtu.be/fGCp5GwRLHA?t=2070)。
- 相乘時用 $x^2 = -1$ 化簡。越講越清楚：**這就是偽裝的複數** [▶ 35:30](https://youtu.be/fGCp5GwRLHA?t=2130)。

老師說他很想花 40 分鐘仔細講，但收穫不大；之後會學到用多項式「造出」像複數這樣的東西 [▶ 36:30](https://youtu.be/fGCp5GwRLHA?t=2190)。

### 6. 質理想與極大理想 [▶ 36:30](https://youtu.be/fGCp5GwRLHA?t=2190)

> **定義**　$R$ 是交換環。
> - **質理想 (prime ideal)**：真理想 $A$，使得 $ab\in A\Rightarrow a\in A$ 或 $b\in A$ [▶ 38:00](https://youtu.be/fGCp5GwRLHA?t=2280)。
> - **極大理想 (maximal ideal)**：真理想 $A$，使得若 $B$ 是理想且 $A\subseteq B\subseteq R$，則 $B = A$ 或 $B = R$ [▶ 39:30](https://youtu.be/fGCp5GwRLHA?t=2370)。

（老師一開始在質理想的定義裡加了「有單位元」，隨即刪掉；板書也有個打字錯誤，學生指出 [▶ 39:00](https://youtu.be/fGCp5GwRLHA?t=2340)。）

**白話**：質理想——乘積在理想裡，至少一個因子在理想裡。極大理想——夾在它和整個環之間的理想只有它自己和整個環。

**例：$\mathbb{Z}_{36}$ 的理想格** [▶ 41:00](https://youtu.be/fGCp5GwRLHA?t=2460)
```
              ⟨1⟩ = ℤ₃₆
             /     \
          ⟨2⟩       ⟨3⟩
         /   \     /   \
       ⟨4⟩    ⟨6⟩       ⟨9⟩
         \   /   \     /
         ⟨12⟩     ⟨18⟩
            \     /
             ⟨0⟩
```
（課堂只畫了部分。）**極大理想**：$\langle2\rangle$、$\langle3\rangle$——上面沒有其他真理想 [▶ 42:30](https://youtu.be/fGCp5GwRLHA?t=2550)。

### 7. 兩個重要定理 [▶ 43:00](https://youtu.be/fGCp5GwRLHA?t=2580)

> **定理（Gallian Thm 14.3）**　$R$ 是有單位元的交換環，$A$ 是理想。$R/A$ 是**整環** $\iff A$ 是**質理想**。

> **定理（Gallian Thm 14.4）**　$R$ 是有單位元的交換環，$A$ 是理想。$R/A$ 是**體** $\iff A$ 是**極大理想**。

**Gallian Example 15** [▶ 45:30](https://youtu.be/fGCp5GwRLHA?t=2730)：仔細證明 $\langle x^2+1\rangle$ 是 $\mathbb{R}[x]$ 的極大理想。不意外：我們猜商環是 $\mathbb{C}$，而 $\mathbb{C}$ 是體。值得自己讀。

**證明質理想定理** [▶ 46:30](https://youtu.be/fGCp5GwRLHA?t=2790)

**($\Rightarrow$)** 設 $R/A$ 是整環。
- 整環的定義含 $1\neq0$，所以 $A$ 是真理想 [▶ 47:30](https://youtu.be/fGCp5GwRLHA?t=2850)。
- 設 $ab\in A$。則 $(a+A)(b+A) = ab+A = A$，也就是商環的**零**。
- 整環沒有零因子：$a+A = A$ 或 $b+A = A$，即 $a\in A$ 或 $b\in A$。所以 $A$ 是質理想。

**($\Leftarrow$)** [▶ 49:00](https://youtu.be/fGCp5GwRLHA?t=2940) 設 $A$ 是質理想。
- 設 $(x+A)(y+A) = A$，即 $xy\in A$。
- $A$ 是質理想：$x\in A$ 或 $y\in A$，即 $x+A$ 或 $y+A$ 是零。所以沒有零因子。
- （交換、有單位元 $1+A$ 從 $R$ 繼承；$A$ 是真理想保證 $1+A\neq A$。）$\blacksquare$

老師：「我覺得這些定理證明比記住容易。幾週後我會想：要成為體需要什麼？」[▶ 50:30](https://youtu.be/fGCp5GwRLHA?t=3030)
