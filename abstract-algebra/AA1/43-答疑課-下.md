## 2. 所有 ℤ×ℤ → ℤ 的環同態（#27）

[▶ 01:30](https://youtu.be/QN0fGG5Ltow?t=90)「做這題，然後我累了，可能就停。」

> **題目**（Gallian Ch.15 #27）　找出所有環同態 $\varphi:\mathbb{Z}\times\mathbb{Z}\to\mathbb{Z}$。

要滿足 $\varphi((x,y)(a,b)) = \varphi(xa,yb) = \varphi(x,y)\varphi(a,b)$ 這種規則 [▶ 02:00](https://youtu.be/QN0fGG5Ltow?t=120)。

### 2.1 用 (1,0)、(0,1) 拆開

[▶ 02:30](https://youtu.be/QN0fGG5Ltow?t=150)「今天研究其他環同態很成功的招數：**用 1 一次次加出元素**。這裡能用嗎？」

$$(x,y) = (x,0)+(0,y) = x\cdot(1,0)+y\cdot(0,1),$$
這裡的「$\cdot$」是重複加法（或減法，或乘 0，看 $x,y$ 正負）。所以
$$\varphi(x,y) = x\cdot\varphi(1,0)+y\cdot\varphi(0,1).$$

### 2.2 冪等元送到冪等元

[▶ 04:00](https://youtu.be/QN0fGG5Ltow?t=240)「$(1,0)$、$(0,1)$ 有什麼特別？它們是**冪等元**：$(1,0)^2 = (1,0)$、$(0,1)^2 = (0,1)$。」

- 所以 $\varphi(1,0)^2 = \varphi(1,0)$、$\varphi(0,1)^2 = \varphi(0,1)$。
- $\mathbb{Z}$ 裡 $n^2 = n$ 的解：**0 和 1**。
- 老師先列出「三種」：$x+y$（兩個都 1）、$x$、$y$ [▶ 05:00](https://youtu.be/QN0fGG5Ltow?t=300)。「這題一開始看起來不可能，現在我有點擔心去看書後答案……不，我蠻有信心的，應該會得到——那個詞是什麼——**肯定**。」

【口頭】[▶ 06:00](https://youtu.be/QN0fGG5Ltow?t=360)「『我夠好、我夠聰明，**而且該死的，人們喜歡我**。』——抱歉，來自過去的爆炸。那個人現在是參議員：**Stuart Smalley**，Al Franken 在《週六夜現場》演的那個穿毛衣的心理勵志角色，對著鏡子重複這句話。我大概你們這年紀時的節目，差個十年。」

### 2.3 漏掉的兩件事

**書後答案**[▶ 06:30](https://youtu.be/QN0fGG5Ltow?t=390)：$0$、$(x,y)\mapsto x$、$(x,y)\mapsto y$。

**(1) 漏了零同態**：「可惡。$(0,0)$——**零永遠在那裡**，永遠有零同態。我是白痴。」（兩個都送到 0。）

**(2) 為什麼 $x+y$ 被禁止？**[▶ 07:00](https://youtu.be/QN0fGG5Ltow?t=420)
- 老師一時想不通：「我們用的是『冪等元必須送到冪等元』……」
- 直接驗證會失敗 [▶ 09:30](https://youtu.be/QN0fGG5Ltow?t=570)：$\varphi((x,y)(a,b)) = \varphi(xa,yb) = xa+yb$，但 $\varphi(x,y)\varphi(a,b) = (x+y)(a+b)$，一般不相等。「我完全相信他，它不是環同態。」
- 【課堂討論】[▶ 10:00](https://youtu.be/QN0fGG5Ltow?t=600)「**還有另一個冪等元**：$(1,1)$。」學生也提 $(-1,-1)$ 的像。老師：「很好，很好，很好。」
  - $\varphi(1,1)^2 = \varphi(1,1)$ 也要成立。
  - 但 $\varphi(1,1) = \varphi(1,0)+\varphi(0,1)$。兩個都設 1 ⇒ $\varphi(1,1) = 2$，$2^2 = 4\neq2$ [▶ 11:00](https://youtu.be/QN0fGG5Ltow?t=660)。
  - 所以不能兩個都是 1。

**結論**：
$$\varphi = 0,\qquad\varphi(x,y) = x,\qquad\varphi(x,y) = y.$$

「所以他是對的：冪等元必須送到冪等元。我只是一開始分析時**漏了一個**。」

**結尾**[▶ 11:30](https://youtu.be/QN0fGG5Ltow?t=690)「抱歉選舉日沒辦法見面，今天想補回來——反正我今天要待晚一點，去幫忙那些來參訪的準學生，說服他們**不要**來這裡——我是說**要**來，要來！開玩笑的，每個人都該來這裡。」

## 3. 一頁速查表

| 題目 | 結果 | 關鍵一步 |
|---|---|---|
| #26 | $(\mathbb{Z}\times\mathbb{Z})/(\langle a\rangle\times\langle b\rangle)\cong\mathbb{Z}_a\times\mathbb{Z}_b$ | 滿射：代表餵進去就跳出來 |
| #27 | $\mathbb{Z}\times\mathbb{Z}\to\mathbb{Z}$：$0$、$x$、$y$ | $\varphi(x,y) = x\varphi(1,0)+y\varphi(0,1)$ |

**找環同態的招數**：
1. 用 $1$（或 $(1,0)$、$(0,1)$）的重複加法拆開任何元素 ⇒ 同態由這幾個的像決定。
2. **冪等元送到冪等元**：$e^2 = e$ ⇒ $\varphi(e)^2 = \varphi(e)$。
3. 別忘了**所有**冪等元（這裡 $(1,1)$ 排除了 $x+y$），也別忘了**零同態**。

## 附：本集一句話總結

> **找 $\mathbb{Z}\times\mathbb{Z}\to\mathbb{Z}$ 的環同態：任何元素都是 $x(1,0)+y(0,1)$，所以同態由 $(1,0)$、$(0,1)$ 的像決定；冪等元必須送到冪等元，而 $\mathbb{Z}$ 的冪等元只有 0、1——再用另一個冪等元 $(1,1)$ 排除「兩個都送 1」，就只剩零同態和兩個投影 $(x,y)\mapsto x$、$(x,y)\mapsto y$。**
