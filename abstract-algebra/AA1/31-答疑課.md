## 本集概要

接續上次（Lecture 1–12），投影講解 Lecture 13、14 的作業解答。重點：
- $Q_8$ 經由 Cayley 定理同構於 $S_8$ 的一個子群。
- 兩個正規子群的交集是正規子群；$|H\cap K|$ 的可能值（Lagrange）。
- 用「是某同態的核」證明正規：$\{e\}\times H\trianglelefteq G\times H$。
- **6 階群的分類**：只有 $\mathbb{Z}_6$ 和 $S_3$。
- $(G_1\times G_2)/(N_1\times N_2)\cong G_1/N_1\times G_2/N_2$。
- 滿同態 $\mathbb{Z}_n\to\mathbb{Z}_k$ 存在 $\Rightarrow k\mid n$；$\mathbb{Z}_n\to\mathbb{Z}_m$（$m\mid n$）的自然同態。
- 正規子群的乘積是正規子群。

## 筆記

### 1. $Q_8$ 嵌入 $S_8$ [▶ 00:30](https://youtu.be/2ueB_Nbf4oM?t=30)

照 Cayley 定理，追蹤每個左乘映射怎麼移動 $Q_8$ 的 8 個元素（編號 1–8），就得到 $S_8$ 中一個同構於 $Q_8$ 的子群。
- $L_{-1}$ 是 4 個互斥換位的乘積。
- $L_i$、$L_j$、$L_k$ 各是兩個互斥 4-循環的乘積（因為 $i^4 = j^4 = k^4 = 1$）[▶ 03:00](https://youtu.be/2ueB_Nbf4oM?t=180)。
- 老師說他一開始算錯，發現 $i$ 和 $j$、$k$ 不對稱才察覺：$i,j,k$ 之間應有某種「輪換對稱」[▶ 01:30](https://youtu.be/2ueB_Nbf4oM?t=90)。
- 原則上任何 14 階群都能用同樣的方法在 $S_{14}$ 裡找到同構的子群。

### 2. 正規子群的交集 [▶ 04:00](https://youtu.be/2ueB_Nbf4oM?t=240)

$H,K\trianglelefteq G\Rightarrow H\cap K\trianglelefteq G$。
- 取 $x\in g(H\cap K)g^{-1}$：$x = gyg^{-1}$，$y\in H\cap K$。
- $H$ 正規 $\Rightarrow x\in H$；$K$ 正規 $\Rightarrow x\in K$。所以 $x\in H\cap K$。
- 用 Gallian Thm 9.1（共軛包含）比證左右陪集相等簡單。

### 3. $|H\cap K|$ 的可能值 [▶ 05:30](https://youtu.be/2ueB_Nbf4oM?t=330)

$|G| = 36$、$|H| = 12$、$|K| = 18$。
- 老師說當初回答同學時想太多（以為要用 $|HK|$ 的公式，見 [[24-答疑課]]）；其實只需要「$H\cap K$ 是 $H$ 和 $K$ 的子群」加上 Lagrange [▶ 06:00](https://youtu.be/2ueB_Nbf4oM?t=360)。
- $|H\cap K|$ 同時整除 12 和 18：只能是 **1、2、3、6**。

### 4. $D_9$ 中 3 階子群的陪集 [▶ 07:00](https://youtu.be/2ueB_Nbf4oM?t=420)

$H = \langle x^3\rangle = \{1,x^3,x^6\}$，$[D_9:H] = 18/3 = 6$，六個陪集。
- 判斷正規：比較 $yH$ 和 $Hy$。用 $x^my = yx^{-m}$，$x^{-3} = x^6$，所以 $Hy = yH$ 等 [▶ 08:00](https://youtu.be/2ueB_Nbf4oM?t=480)。
- 所以 $H\trianglelefteq D_9$，$D_9/H$ 是商群。

### 5. $\{e\}\times H\trianglelefteq G\times H$ [▶ 10:00](https://youtu.be/2ueB_Nbf4oM?t=600)

比逐一比對陪集更好的論證：投影 $\pi_1(x,y) = x$ 是同態，
$$\ker\pi_1 = \{(e,y)\mid y\in H\} = \{e\}\times H.$$
**核一定是正規子群**。所以「證明某集合是某同態的核」是證明正規的好方法 [▶ 12:00](https://youtu.be/2ueB_Nbf4oM?t=720)。

### 6. $G\times H\cong H\times G$ [▶ 12:30](https://youtu.be/2ueB_Nbf4oM?t=750)

「交換映射」$\psi(x,y) = (y,x)$。顯然是雙射；保持運算：
$$\psi\big((x,y)(a,b)\big) = \psi(xa,yb) = (yb,xa) = (y,x)(b,a) = \psi(x,y)\psi(a,b).$$
老師說：這題考出來，能分辨誰完全迷路、誰覺得「謝謝教授，請再給我一題」[▶ 14:00](https://youtu.be/2ueB_Nbf4oM?t=840)。

### 7. 6 階群的分類 [▶ 14:00](https://youtu.be/2ueB_Nbf4oM?t=840)

設 $|G| = 6$。元素的階只能是 1、2、3、6。

**(a) 一定有 2 階元素** [▶ 14:30](https://youtu.be/2ueB_Nbf4oM?t=870)
- 若 $G$ 循環，生成元 $a$ 的 $a^3$ 是 2 階。
- 若不循環，沒有 6 階元素。老師的論證是分情形看 3 階子群的配置。他坦承「不完全確定這個論證沒有漏洞，也許有更好的方法」。

> 💬 補充（非課堂內容）：更快的方法是 Cauchy 定理（2 整除 6）；或者：非單位元素可以和自己的反元素配對，$a\neq a^{-1}$ 的元素成對出現，5 個非單位元素是奇數，所以至少有一個 $a = a^{-1}$，即 2 階。

**(b) 不可能所有非單位元素都是 2 階** [▶ 18:30](https://youtu.be/2ueB_Nbf4oM?t=1110)
- 取 $a\neq b$，$a^2 = b^2 = e$。$ab$ 也是 2 階：$(ab)^2 = e$。
- 由 $abab = e$ 得 $ba = ab$（乘上 $a$、$b$ 消去）[▶ 21:00](https://youtu.be/2ueB_Nbf4oM?t=1260)。這裡**沒有**假設交換，是被推出來的。
- 於是 $\{e,a,b,ab\}$ 對乘法封閉，是 4 階子群。但 $4\nmid6$，矛盾。

**(c) 有 3 階 $a$ 和 2 階 $b$** [▶ 23:00](https://youtu.be/2ueB_Nbf4oM?t=1380)
- **若 $ab = ba$**：$x = ab$ 的次方依序為 $ab,\ a^2,\ b,\ a,\ a^2b,\ e$，所以 $|ab| = 6$，$G$ 是循環群 $\cong\mathbb{Z}_6$ [▶ 24:00](https://youtu.be/2ueB_Nbf4oM?t=1440)。
- **若 $ab\neq ba$**：$G = \{e,a,a^2,b,ab,ba\}$。用拉丁方陣規則填 Cayley 表，會被迫得到 $a\cdot ab = ba$，即
$$a^2b = ba$$
  （類比 $D_n$ 的 $xy = yx^{-1}$）[▶ 26:00](https://youtu.be/2ueB_Nbf4oM?t=1560)。這個關係加上 $a^3 = e$、$b^2 = e$ 決定整張表；調換一下順序，就和 $S_3$ 的表一樣（$a = (123)$、$b = (13)$）。

**結論** [▶ 27:30](https://youtu.be/2ueB_Nbf4oM?t=1650)：6 階群在同構意義下只有 $\mathbb{Z}_6$ 和 $S_3$。群論書做計算時常用這種「生成元與關係」的 $S_3$。

### 8. 直積的商 [▶ 29:00](https://youtu.be/2ueB_Nbf4oM?t=1740)

$N_1\trianglelefteq G_1$、$N_2\trianglelefteq G_2$，自然同態 $\pi_1:G_1\to G_1/N_1$、$\pi_2:G_2\to G_2/N_2$ 都是滿射。
$$\psi = \pi_1\times\pi_2:\ G_1\times G_2\to G_1/N_1\times G_2/N_2,\qquad \psi(x,y) = (xN_1,\ yN_2).$$
- 同態（逐分量）；滿射；$\ker\psi = N_1\times N_2$。
- 第一同構定理：
$$(G_1\times G_2)/(N_1\times N_2)\cong G_1/N_1\times G_2/N_2.$$

「硬幹的話會很嚇人。」[▶ 31:30](https://youtu.be/2ueB_Nbf4oM?t=1890)

### 9. $\mathbb{Z}_n$ 之間的同態 [▶ 32:30](https://youtu.be/2ueB_Nbf4oM?t=1950)

**更正之前那題**（老師說「那題浪費了大家的時間」）：
- 若有**滿**同態 $\varphi:\mathbb{Z}_n\to\mathbb{Z}_k$，則 $\mathbb{Z}_n/\ker\varphi\cong\mathbb{Z}_k$，所以 $n/|\ker\varphi| = k$，$k\mid n$ [▶ 33:30](https://youtu.be/2ueB_Nbf4oM?t=2010)。
- 老師在公告裡舉的例子是 $\varphi(x) = 2x$，$\mathbb{Z}_4\to\mathbb{Z}_6$：不是滿射，而 $6\nmid4$。

> 💬 補充（非課堂內容）：$x\mapsto2x$ 從 $\mathbb{Z}_4$ 到 $\mathbb{Z}_6$ 其實不是良定義的（$[0]_4 = [4]_4$，但 $0\mapsto0$、$4\mapsto8\equiv2$）。良定義的非滿射例子是 $x\mapsto3x$（因為 $3\cdot4 = 12\equiv0\pmod6$），像是 $\{0,3\}$。重點不變：沒有滿射，就沒有 $k\mid n$。

**$m\mid n$ 時的自然同態** [▶ 34:30](https://youtu.be/2ueB_Nbf4oM?t=2070)
$$\psi([x]_n) = [x]_m.$$
- **良定義**：$[x']_n = [x]_n\Rightarrow x' = x+nk = x + m(lk)$（$n = ml$），所以 $[x']_m = [x]_m$ [▶ 35:30](https://youtu.be/2ueB_Nbf4oM?t=2130)。
- 同態、滿射。核：$\{[x]_n\mid m\mid x\}$，也就是 $m$ 的倍數 [▶ 36:30](https://youtu.be/2ueB_Nbf4oM?t=2190)。
- 第一同構定理：$\mathbb{Z}_n/\langle m\rangle\cong\mathbb{Z}_m$。

**為什麼要寫下標** [▶ 37:00](https://youtu.be/2ueB_Nbf4oM?t=2220)：$[x]_n = x+n\mathbb{Z}$。這題的重點是「模 $n$ 和模 $m$ 之間的橋」，不寫下標，映射看起來就只是 $\psi(x) = x$，什麼都看不出來。（Beachy & Blair 一直用括號，即使已經不方便了。）

### 10. 單位圓是 $\mathbb{C}^\times$ 的子群 [▶ 39:00](https://youtu.be/2ueB_Nbf4oM?t=2340)

$\theta\mapsto\cos\theta+i\sin\theta$：$\cos$、$\sin$ 不會同時為 0，所以映到 $\mathbb{C}^\times$；和角公式給出同態；**同態的像是子群**，像就是單位圓。大家直接驗證子群的計算，其實和這裡一樣。

### 11. 正規子群的乘積是正規子群 [▶ 41:30](https://youtu.be/2ueB_Nbf4oM?t=2490)

**兩個的情形**：$H_1,H_2\trianglelefteq G$。
- **子群**（一步法）：$a = a_1a_2$、$b = b_1b_2$。$H_2$ 正規，$b_1^{-1}H_2 = H_2b_1^{-1}$，可以把 $b_1^{-1}$ 移到左邊 [▶ 42:00](https://youtu.be/2ueB_Nbf4oM?t=2520)：
$$ab^{-1} = a_1a_2b_2^{-1}b_1^{-1} = a_1b_1^{-1}h_2\in H_1H_2.$$
  非空：$e = ee\in H_1H_2$。
- **正規** [▶ 44:00](https://youtu.be/2ueB_Nbf4oM?t=2640)：$gx_1x_2g^{-1} = (gx_1g^{-1})(gx_2g^{-1})\in H_1H_2$。

**$n$ 個** [▶ 45:30](https://youtu.be/2ueB_Nbf4oM?t=2730)：$H_1H_2$ 已知正規，再和 $H_3$ 用兩個的情形……一路下去。老師說這「不太像真正的歸納」，因為只做到有限的 $k$。

**結尾** [▶ 47:30](https://youtu.be/2ueB_Nbf4oM?t=2850)：還有幾題（15 階、特徵子群、54 題）在寫，之後會上傳。老師咳嗽越來越嚴重，提早結束。
