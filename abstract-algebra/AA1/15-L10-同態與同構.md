## 1. 同態的定義

[▶ 01:30](https://youtu.be/hC_bOXIciGA?t=90)

> **定義（同態 homomorphism）**　函數 $\varphi:(G_1,\star)\to(G_2,\#)$ 叫做**同態**，若且唯若
> $$\varphi(a\star b) = \varphi(a)\,\#\,\varphi(b)\quad\text{對所有 }a,b\in G_1.$$

**類比線性代數**[▶ 03:00](https://youtu.be/hC_bOXIciGA?t=180)：Math 321 的線性變換 $T:V\to W$ 滿足 $T(x+y) = T(x)+T(y)$。同態是同樣的概念：
- $G_1$ 的運算**以自然的方式被搬到** $G_2$ 的運算。
- 它**保持結構**（structure preserving）[▶ 03:30](https://youtu.be/hC_bOXIciGA?t=210)。

**白話**：先在 $G_1$ 裡運算再送過去，等於先送過去再在 $G_2$ 裡運算。

## 2. 命題：同態把單位元素送到單位元素

[▶ 04:00](https://youtu.be/hC_bOXIciGA?t=240)

> **命題 1**　$\varphi:(G_1,\star)\to(G_2,\#)$ 是同態，$e_1$、$e_2$ 分別是 $G_1$、$G_2$ 的單位元素。則
> $$\varphi(e_1) = e_2.$$

「這不該讓你驚訝：線性變換有 $T(0) = 0$。我是說，這件事持續發生——不管是加法單位、乘法單位、合成的單位，還是各種我們叫不出名字的怪運算的單位。」[▶ 05:00](https://youtu.be/hC_bOXIciGA?t=300)

**證明**[▶ 06:00](https://youtu.be/hC_bOXIciGA?t=360)

已知：$e_1\star x = x = x\star e_1$ 對所有 $x\in G_1$；$e_2\,\#\,y = y = y\,\#\,e_2$ 對所有 $y\in G_2$。

**觀察 1**[▶ 07:00](https://youtu.be/hC_bOXIciGA?t=420)：取 $y = \varphi(e_1)$，
$$\varphi(e_1)\,\#\,e_2 = \varphi(e_1).$$

**觀察 2**[▶ 07:30](https://youtu.be/hC_bOXIciGA?t=450)：$e_1\star e_1 = e_1$，所以用同態性質：
$$\varphi(e_1) = \varphi(e_1\star e_1) = \varphi(e_1)\,\#\,\varphi(e_1).$$

**合起來**[▶ 09:00](https://youtu.be/hC_bOXIciGA?t=540)：
$$\varphi(e_1)\,\#\,e_2 = \varphi(e_1)\,\#\,\varphi(e_1).$$
由**消去律**（或兩邊左乘 $\varphi(e_1)^{-1}$）：
$$e_2 = \varphi(e_1).\qquad\blacksquare$$

【口頭】[▶ 08:00](https://youtu.be/hC_bOXIciGA?t=480)「我忍受這些 $\star$ 和 $\#$，是因為到目前為止考卷我只改了第 1 題（我一直在生病）。你們有一半的定義用並列寫，另一半用 $\star$……寫群的定義時你得做個選擇：要嘛用並列，要嘛用 $\star$。不能在一個定義裡混搭。那不 kosher。」

> 📘 講義 Prop 2.8.11 還多一條：**$\varphi(g^{-1}) = (\varphi(g))^{-1}$**。證明：$\varphi(g)\varphi(g^{-1}) = \varphi(gg^{-1}) = \varphi(e_1) = e_2$。

## 3. 【口頭】同一個定義，很多種樣子；為什麼要抽象

[▶ 10:00](https://youtu.be/hC_bOXIciGA?t=600)「說一下記號。」同態條件 $\varphi(a\star b) = \varphi(a)\#\varphi(b)$，依兩邊的運算不同，長得很不一樣：

| $G_1$ 的運算 | $G_2$ 的運算 | 條件 |
|---|---|---|
| $+$ | $+$ | $\varphi(a+b) = \varphi(a)+\varphi(b)$ |
| 並列 | $+$ | $\varphi(ab) = \varphi(a)+\varphi(b)$ |
| $+$ | 並列 | $\varphi(a+b) = \varphi(a)\varphi(b)$ |
| 合成 | 合成 | $\varphi(f\circ g) = \varphi(f)\circ\varphi(g)$ |

（置換群常把 $\circ$ 省略，用並列表示合成。）

**為什麼要抽象？**[▶ 12:00](https://youtu.be/hC_bOXIciGA?t=720)「你們會說：第十講了，你終於要講這個。理由簡單又明顯：如果我們能找出**幾百個例子共有的結構**，那麼對這個結構證明了一件事，就**一次對所有例子都證明了**。這就是抽象的威力之一。」「第 2 節的證明，想想看我們做了什麼——它說單位元素被送到單位元素，**不管那些群有什麼特殊的怪癖**。」「我們為了效率而抽象——不只如此，但那是一部分。」

## 4. 三個同態的例子

**例 1：指數函數**[▶ 13:00](https://youtu.be/hC_bOXIciGA?t=780)
$$\varphi_1:(\mathbb{R},+)\to((0,\infty),\cdot),\qquad\varphi_1(x) = e^x.$$
【課堂討論】「從公式你應該能想起高中的日子……值域是什麼？我得做所有的事嗎？好吧。」學生：正實數。

- 同態 [▶ 14:30](https://youtu.be/hC_bOXIciGA?t=870)：$\varphi_1(x+y) = e^{x+y} = e^xe^y = \varphi_1(x)\varphi_1(y)$。
- 它是函數嗎？「留給實分析。」
- 跟命題 1 一致 [▶ 15:00](https://youtu.be/hC_bOXIciGA?t=900)：加法單位 0 被送到 $e^0 = 1$，正是 $(0,\infty)$ 的乘法單位。

**例 2：行列式**[▶ 15:30](https://youtu.be/hC_bOXIciGA?t=930)（「比較刺激一點」）
$$\varphi_2:GL(n,F)\to F^\times,\qquad\varphi_2(A) = \det A.$$
（Gallian 好像用 $F^*$。）
- **映入 $F^\times$**[▶ 16:00](https://youtu.be/hC_bOXIciGA?t=960)：$A$ 可逆，所以 $\det A\neq0$。
- **同態**[▶ 17:30](https://youtu.be/hC_bOXIciGA?t=1050)：$\varphi_2(AB) = \det(AB) = \det A\det B = \varphi_2(A)\varphi_2(B)$。行列式的性質對任意體都成立（「如果這讓你不舒服，就讓 $F = \mathbb{R}$，會讓你對人生感覺好一點」）。

（中間一位新同學來旁聽：「你打算主修數學嗎？太好了，最好的主修。忘了工程吧——對雙主修的同學也一樣，抱歉。」）

**例 3：奇偶**[▶ 18:00](https://youtu.be/hC_bOXIciGA?t=1080)
$$\varphi_3:S_n\to\mathbb{Z}_2,\qquad\varphi_3(\sigma) = \begin{cases}0 & \sigma\in A_n\ (\text{偶})\\1 & \sigma\notin A_n\ (\text{奇})\end{cases}$$
【課堂討論】「我把對稱群分成兩塊，哪兩塊？」學生：偶、奇。

**檢查四種情況**[▶ 20:00](https://youtu.be/hC_bOXIciGA?t=1200)：

| $\sigma$ | $\beta$ | $\sigma\beta$ | 左邊 $\varphi_3(\sigma\beta)$ | 右邊 $\varphi_3(\sigma)+\varphi_3(\beta)$ |
|---|---|---|---|---|
| 偶 | 偶 | 偶 | 0 | $0+0 = 0$ |
| 偶 | 奇 | 奇 | 1 | $0+1 = 1$ |
| 奇 | 偶 | 奇 | 1 | $1+0 = 1$ |
| 奇 | 奇 | 偶 | 0 | $1+1 = 0$（模 2） |

所以 $\varphi_3$ 是同態（左邊是置換的合成，右邊是 $\mathbb{Z}_2$ 的加法）。

> 📘 講義 Ex 2.8.9：更俐落的版本是 $\varphi:S_n\to\{\pm1\}$，$\varphi(\sigma) = \operatorname{sgn}(\sigma)$。由 L9 的推論，$\operatorname{sgn}(\sigma\beta) = \operatorname{sgn}(\sigma)\operatorname{sgn}(\beta)$，不用分情況。講義：「有時候沒辦法，只能分情況。解題的經驗會讓你更知道什麼記號適合什麼問題。」

> 📘 講義 Ex 2.8.10：向量空間在加法下是群，線性變換 $T$ 滿足 $T(x+y) = T(x)+T(y)$，所以是同態——明確連到線性代數的思考。

## 5. 核與像

[▶ 21:00](https://youtu.be/hC_bOXIciGA?t=1260)

> **定義**　$G_1$、$G_2$ 是群，$\varphi:G_1\to G_2$ 是函數（最有趣的是同態的情況）。
> - **核（kernel）**：$\operatorname{Ker}(\varphi) = \{x\in G_1 : \varphi(x) = e_2\}$。
> - **像（image）**[▶ 22:00](https://youtu.be/hC_bOXIciGA?t=1320)：$\operatorname{Im}(\varphi) = \{\varphi(x) : x\in G_1\}$。

**用集合語言**[▶ 22:30](https://youtu.be/hC_bOXIciGA?t=1350)：
$$\operatorname{Ker}(\varphi) = \varphi^{-1}(\{e_2\}),\qquad\operatorname{Im}(\varphi) = \varphi(G_1).$$
核就是所有被送到 $e_2$ 的點（$\{e_2\}$ 的反像）。

> **定理**[▶ 23:00](https://youtu.be/hC_bOXIciGA?t=1380)　$\varphi:G_1\to G_2$ 是同態。則
> $$\operatorname{Ker}(\varphi)\le G_1,\qquad\operatorname{Im}(\varphi)\le G_2.$$

「證明留給讀者。」[▶ 24:00](https://youtu.be/hC_bOXIciGA?t=1440)「如果你上過我的線性代數，我在線性變換的情境證過：核和值域是子空間。同一個定理在這裡變成：同態的核和像是子群。證明幾乎一樣。」

> 📘 **講義 Prop 2.8.12 的證明**（更一般：子群的像、子群的反像都是子群）：
> - **像**：$e_2 = \varphi(e_1)\in\varphi(H)$。若 $x = \varphi(h_x)$、$y = \varphi(h_y)$，則 $xy^{-1} = \varphi(h_x)\varphi(h_y)^{-1} = \varphi(h_xh_y^{-1})\in\varphi(H)$。一步法。
> - **反像**：$\varphi(e_1) = e_2\in K$。若 $\varphi(a),\varphi(b)\in K$，則 $\varphi(ab^{-1}) = \varphi(a)\varphi(b)^{-1}\in K$。一步法。
> - 核 = $\{e_2\}$ 的反像；像 = $G_1$ 的像。

**例**[▶ 24:30](https://youtu.be/hC_bOXIciGA?t=1470)：【課堂討論】$\varphi_3$ 的核是什麼？「什麼被送到單位元素 0？」學生：**$A_n$**。

**重點**[▶ 25:00](https://youtu.be/hC_bOXIciGA?t=1500)：
> 如果能找到一個同態，**它的核恰好是某個子集**，那就證明了這個子集是**子群**。

「這是證明子群非常棒的方法。」例如：
- $A_n = \operatorname{Ker}(\varphi_3)$ ⇒ $A_n\le S_n$。
- $SL(n,F) = \operatorname{Ker}(\det)$ ⇒ $SL(n,F)\le GL(n,F)$（見第 7.2 節）。

## 6. 命題：同態是單射 ⟺ 核是 {e}

[▶ 25:30](https://youtu.be/hC_bOXIciGA?t=1530)

> **命題 2**　$\varphi:G_1\to G_2$ 是同態。則
> $$\varphi\text{ 是單射（一對一）}\iff\operatorname{Ker}(\varphi) = \{e_1\}.$$

**證明**

**(⇒)**[▶ 26:30](https://youtu.be/hC_bOXIciGA?t=1590) 設 $\varphi$ 一對一。
1. 由命題 1，$\varphi(e_1) = e_2$，所以 $e_1\in\operatorname{Ker}(\varphi)$。
2. 設 $x\in\operatorname{Ker}(\varphi)$。則 $\varphi(x) = e_2 = \varphi(e_1)$ [▶ 28:00](https://youtu.be/hC_bOXIciGA?t=1680)。
3. 由單射，$x = e_1$。
4. $x$ 是任意的，所以 $\operatorname{Ker}(\varphi) = \{e_1\}$。

【口頭】[▶ 28:30](https://youtu.be/hC_bOXIciGA?t=1710)「人們有時會得意忘形，把 $e_1$ 外面的大括號省掉。我們真的不該這樣，因為我們想小心。我承認有時候寫那個會煩我，但在這門課我會繼續寫。」

**(⇐)**[▶ 29:00](https://youtu.be/hC_bOXIciGA?t=1740) 設 $\operatorname{Ker}(\varphi) = \{e_1\}$。設 $\varphi(x) = \varphi(y)$。
1. 兩邊左乘 $\varphi(x^{-1})$ [▶ 30:30](https://youtu.be/hC_bOXIciGA?t=1830)：
$$\varphi(x^{-1})\varphi(x) = \varphi(x^{-1})\varphi(y).$$
2. 用同態性質：
$$\varphi(x^{-1}x) = \varphi(x^{-1}y)\ \Rightarrow\ \varphi(e_1) = \varphi(x^{-1}y)\ \Rightarrow\ e_2 = \varphi(x^{-1}y).$$
3. 所以 $x^{-1}y\in\operatorname{Ker}(\varphi) = \{e_1\}$ [▶ 31:30](https://youtu.be/hC_bOXIciGA?t=1890)，即 $x^{-1}y = e_1$。
4. 兩邊左乘 $x$：$y = x$。所以 $\varphi$ 一對一。$\blacksquare$

**為什麼這很厲害**[▶ 32:00](https://youtu.be/hC_bOXIciGA?t=1920)：
- 「如果你要我判斷一個實函數是不是處處一對一，我**不能**只看 0 發生什麼事。」
- 反例：$f(x) = x^2$。$f(0) = 0$，在加法群的意義下「核」只有 0，但 $f$ **不是**一對一（拋物線）。
- 因為 $f$ **不是**加法群的同態（$(x+y)^2\neq x^2+y^2$），這個定理不適用。
- 「**同態很特別**。一般來說判斷映射是否單射很麻煩。」

## 7. 同構

### 7.1 定義

[▶ 33:00](https://youtu.be/hC_bOXIciGA?t=1980)「你們會說：我以為這講是關於同構的。被你抓到了。」

> **定義（同構 isomorphism）**　同態 $\varphi:G_1\to G_2$ 如果也是**雙射**（一對一且映成），就叫**同構**。若存在 $G_1\to G_2$ 的同構，就說 **$G_1$ 同構於 $G_2$**，寫作 $G_1\cong G_2$ [▶ 35:00](https://youtu.be/hC_bOXIciGA?t=2100)。

- 跟線性代數一致 [▶ 34:00](https://youtu.be/hC_bOXIciGA?t=2040)：雙射的線性變換叫同構。
- 「同構」這個詞跨越數學的各個領域；有一個統一的概念叫**範疇論（category theory）**。【口頭】「別問我，問 Nathan BeDell。他比較在乎——他會在不相關的對話裡提起它，他真的很愛它。」
- **直覺**[▶ 35:30](https://youtu.be/hC_bOXIciGA?t=2130)：同構的群**是同一個群**，只是記號不同。它們有相同的結構。

### 7.2 三個例子哪個是同構

[▶ 35:30](https://youtu.be/hC_bOXIciGA?t=2130)【課堂討論】「你們覺得呢？」

**$\varphi_3$（奇偶）：不是**[▶ 36:00](https://youtu.be/hC_bOXIciGA?t=2160)：核是 $A_n$，顯然不只 $\{(1)\}$（$n\ge2$）。「事實上這是**二對一**的映射。」

**$\varphi_2$（行列式）：不是**[▶ 36:30](https://youtu.be/hC_bOXIciGA?t=2190)：「如果我告訴你某個矩陣的行列式是 3，只有一個這種矩陣嗎？」很多。

【課堂討論】[▶ 37:00](https://youtu.be/hC_bOXIciGA?t=2220)「$\varphi_2$ 的核是什麼？$F^\times$ 的乘法單位是什麼？」學生答錯一次（「你傷了我」），然後答：1。所以
$$\operatorname{Ker}(\det) = \{A\in GL(n,F) : \det A = 1\} = SL(n,F).$$
「**看！$SL(n,F)$ 是群，因為它是那個同態的核。**」

**$\varphi_1$（指數）：是！**[▶ 38:00](https://youtu.be/hC_bOXIciGA?t=2280)「如果這是個有趣的問題，我們最好希望例 1 是同構。」
- **核**：$\{x : e^x = 1\} = \{0\}$，所以一對一。
- **映成**[▶ 38:30](https://youtu.be/hC_bOXIciGA?t=2310)：給任意 $y>0$，$\varphi_1(\ln y) = e^{\ln y} = y$。
- 已知保持運算。

$$(\mathbb{R},+)\cong((0,\infty),\cdot),\quad\text{同構是指數函數。}$$

### 7.3 同構是等價關係

**恆等映射**[▶ 40:00](https://youtu.be/hC_bOXIciGA?t=2400)：$\varphi:G\to G$，$\varphi(x) = x$。
- 保持運算：$\varphi(xy) = xy = \varphi(x)\varphi(y)$。
- 映成：$\varphi(g) = g$。
- 一對一：$\varphi(a) = \varphi(b)\Rightarrow a = b$。「好啦，一對一。這很蠢。」
- 所以 $\operatorname{Id}_G$ 是同構：**每個群都同構於自己**[▶ 42:00](https://youtu.be/hC_bOXIciGA?t=2520)。

**還可以證明**（「看起來像好作業題」）[▶ 42:00](https://youtu.be/hC_bOXIciGA?t=2520)：
- 同構的**反函數**是同構 ⇒ $G_1\cong G_2\Rightarrow G_2\cong G_1$。
- 同構的**合成**是同構 ⇒ $G_1\cong G_2$、$G_2\cong G_3\Rightarrow G_1\cong G_3$。

所以**同構是一個等價關係**。所有的群被分成同構類；同一類裡的群「作為點集不一樣，但有相同的群結構」。

> 📘 **講義 Prop 2.9.1 的證明要點**：
> - $\varphi^{-1}$ 是同態：$\varphi(\varphi^{-1}(a)\varphi^{-1}(b)) = \varphi(\varphi^{-1}(a))\varphi(\varphi^{-1}(b)) = ab$，所以 $\varphi^{-1}(a)\varphi^{-1}(b) = \varphi^{-1}(ab)$。（講義註腳：線性代數裡「雙射線性映射的反函數自動是線性的」就是這個定理的特例。）
> - $\gamma\circ\varphi$ 是同態：$(\gamma\circ\varphi)(xy) = \gamma(\varphi(x)\varphi(y)) = \gamma(\varphi(x))\gamma(\varphi(y))$。

## 8. Cayley 定理

### 8.1 左乘映射不是同態

[▶ 43:00](https://youtu.be/hC_bOXIciGA?t=2580)

> **定義（左乘 left multiplication）**　$g\in G$。
> $$L_g:G\to G,\qquad L_g(x) = gx.$$

（「不要跟電子公司 LG 搞混。」Gallian 用 $T_g$，「大概是 transformation by $g$」；老師用 $L_g$ 表示「左乘」。）

**是良定義的映射**[▶ 44:00](https://youtu.be/hC_bOXIciGA?t=2640)：【課堂討論】「怎麼知道 $gx$ 在 $G$ 裡？」學生：群的運算封閉。

**但不是同態**[▶ 44:30](https://youtu.be/hC_bOXIciGA?t=2670)：
$$L_g(xy) = gxy,\qquad L_g(x)L_g(y) = gxgy.$$
一般不相等，除非 $g = e$——那時 $L_e(x) = ex = x$，$L_e = \operatorname{Id}_G$ [▶ 45:00](https://youtu.be/hC_bOXIciGA?t=2700)。

「所以左乘映射也許不是同構，但它們其實很有用。」

### 8.2 左乘映射組成一個群

**性質 1**[▶ 46:00](https://youtu.be/hC_bOXIciGA?t=2760)：
$$(L_g\circ L_h)(x) = L_g(hx) = g(hx) = (gh)x = L_{gh}(x).$$
【口頭】[▶ 46:30](https://youtu.be/hC_bOXIciGA?t=2790)「要從這裡到那裡，我們需要**結合律**——它是任務關鍵。」

對所有 $x$ 成立，所以
$$L_g\circ L_h = L_{gh}.$$
（「套用一位可敬的卡通人物的話：相信它！」）

**性質 2**[▶ 47:30](https://youtu.be/hC_bOXIciGA?t=2850)：
$$L_g\circ L_{g^{-1}} = L_{gg^{-1}} = L_e = \operatorname{Id}_G.$$

令（Gallian 叫它 $\bar G$）[▶ 48:00](https://youtu.be/hC_bOXIciGA?t=2880)
$$\bar G = \{L_g : g\in G\}.$$
- 封閉：$L_g\circ L_h = L_{gh}\in\bar G$。
- 單位：$L_e = \operatorname{Id}_G\in\bar G$。
- 反元素：$L_{g^{-1}}$，左右都是。
- 結合：函數合成本來就結合。

所以 **$\bar G$ 在合成下是群**[▶ 49:00](https://youtu.be/hC_bOXIciGA?t=2940)。而且每個 $L_g$ 是雙射（反函數是 $L_{g^{-1}}$），所以 $\bar G$ 是 $G$ 上**置換**組成的群。

### 8.3 G 同構於它

[▶ 49:30](https://youtu.be/hC_bOXIciGA?t=2970) 定義
$$\varphi:G\to\bar G,\qquad\varphi(g) = L_g.$$

- **保持運算**：$\varphi(gh) = L_{gh} = L_g\circ L_h = \varphi(g)\circ\varphi(h)$。
- **單射**[▶ 50:00](https://youtu.be/hC_bOXIciGA?t=3000)：【課堂討論】「它的核是什麼？什麼被送到恆等映射？」$L_g = \operatorname{Id}$ ⇒ $gx = x$ 對所有 $x$ ⇒ $g = e$。核 = $\{e\}$。
- **映成**[▶ 50:30](https://youtu.be/hC_bOXIciGA?t=3030)：「基本上按構造就是映成：$\bar G$ 裡任何 $L_g$ 都是 $\varphi(g)$。」

所以 $\varphi$ 是同構。

> **定理（Cayley 定理）**[▶ 51:00](https://youtu.be/hC_bOXIciGA?t=3060)　每個群 $G$ 都**同構於一個置換群**——具體地說，同構於 $G$ 上的左乘映射群 $\bar G\le\operatorname{Perm}(G)$。

「而且我還告訴你同構於**哪一個**置換群：就是這些從 $G$ 到 $G$ 的函數。」

> 📘 講義：這個構造叫做 $G$ 在置換上的**正則表示（regular representation）**。講義 §2.9 前言：「我們有選擇：可以把一個群表示成同構的**矩陣群**，或同構的**置換群**。打個比方，$S_n$ 或可逆矩陣就像原料，任何群都可以用它們做出來。」

【口頭】[▶ 51:30](https://youtu.be/hC_bOXIciGA?t=3090)「抱歉，講義還沒打出來，我又病倒了。我在努力。我會先指定一些週三要交的東西，然後再寫講義。這段時間，讀 Gallian，他寫得很好。」

## 9. 【講義補充】直積、Klein 四元群、反像、自同構

這些在講義 §2.8–2.9，本集課堂沒講（自同構在下一集講）。

**直積（direct product）**（Def 2.8.1）：
$$(x_1,\dots,x_n)(y_1,\dots,y_n) = (x_1y_1,\dots,x_ny_n),$$
第 $i$ 個分量用 $G_i$ 的運算。單位元素 $(e_1,\dots,e_n)$，反元素 $(x_1^{-1},\dots,x_n^{-1})$。交換群的直積是交換群（Thm 2.8.2）。

**Klein 四元群**（Def 2.8.4）：$K = \{e,a,b,c\}$，交換，$|a| = |b| = |c| = 2$，$ab = c$。任兩個相異的非單位元素相乘得第三個。
$$K\cong\mathbb{Z}_2\times\mathbb{Z}_2\cong U(8).$$
- $\Psi(1,0) = a$、$\Psi(0,1) = b$、$\Psi(1,1) = c$；例如 $\Psi((1,0)+(0,1)) = \Psi(1,1) = c = ab$。
- $U(8) = \{1,3,5,7\}$：$3\mapsto a$、$5\mapsto b$、$7\mapsto c$。「看 $U(8)$ 的 Cayley 表：déjà vu。」
- 講義：「常說 $U(8)$ 或 $\mathbb{Z}_2\times\mathbb{Z}_2$ **就是** Klein 四元群，這是**語言的濫用**。誠實地說：$U(8)$ 在**同構意義下**是 Klein 四元群。」「數學研究最難的部分往往是選對定義。」

> ⚠️ 講義 Klein 四元群 Cayley 表的 $b$ 列印成「$b\ c\ e\ c$」，應該是「$b\ c\ e\ a$」（$bc = a$）。

**反像不是函數**：$\varphi(x) = x^2$ 在 $\mathbb{R}^\times$ 上，$\varphi^{-1}\{4\} = \{-2,2\}$，所以 $\varphi^{-1}$ 不是函數。（講義問：$\varphi:\mathbb{R}^\times\to(0,\infty)$ 是同態嗎？）

**同態是單射 ⟺ 核平凡的應用**：$e^x$ 的核是 $\{0\}$，所以單射；又 $\varphi(\ln y) = y$，所以是同構 $\mathbb{R}\cong(0,\infty)$。

**自同構（automorphism）**（Def 2.9.2）：$G\to G$ 的同構。全部記作 $\operatorname{Aut}(G)$，是 $\operatorname{Perm}(G)$ 的子群。共軛映射 $\varphi_g(x) = gxg^{-1}$ 是自同構，叫**內自同構**，全部記作 $\operatorname{Inn}(G)$：
$$\operatorname{Inn}(G)\le\operatorname{Aut}(G)\le\operatorname{Perm}(G).$$
（詳見 [[16-L11-同構的性質]]。）

## 10. 一頁速查表

### 10.1 定義

| 名稱 | 定義 |
|---|---|
| 同態 | $\varphi(a\star b) = \varphi(a)\#\varphi(b)$ |
| 核 | $\operatorname{Ker}\varphi = \{x : \varphi(x) = e_2\} = \varphi^{-1}(\{e_2\})$ |
| 像 | $\operatorname{Im}\varphi = \varphi(G_1)$ |
| 同構 | 雙射的同態；$G_1\cong G_2$ |
| 左乘 | $L_g(x) = gx$ |

### 10.2 結果與證明關鍵一步

| 結果 | 關鍵一步 |
|---|---|
| $\varphi(e_1) = e_2$ | $\varphi(e_1)e_2 = \varphi(e_1) = \varphi(e_1e_1) = \varphi(e_1)\varphi(e_1)$，消去 |
| $\varphi(g^{-1}) = \varphi(g)^{-1}$ | $\varphi(g)\varphi(g^{-1}) = \varphi(e_1) = e_2$ |
| 核、像是子群 | 一步法，用 $\varphi(ab^{-1}) = \varphi(a)\varphi(b)^{-1}$ |
| 單射 ⟺ 核 $= \{e_1\}$ | ⇐：$\varphi(x) = \varphi(y)\Rightarrow\varphi(x^{-1}y) = e_2\Rightarrow x^{-1}y = e_1$ |
| 同構是等價關係 | $\operatorname{Id}$、反函數、合成都是同構 |
| **Cayley**：$G\cong\bar G = \{L_g\}$ | $L_g\circ L_h = L_{gh}$（結合律）；$L_g = \operatorname{Id}\Rightarrow g = e$ |

### 10.3 例子

| 映射 | 同態？ | 核 | 同構？ |
|---|---|---|---|
| $e^x:(\mathbb{R},+)\to((0,\infty),\cdot)$ | ✓ | $\{0\}$ | ✓（反函數 $\ln$） |
| $\det:GL(n,F)\to F^\times$ | ✓ | $SL(n,F)$ | ✗ |
| 奇偶：$S_n\to\mathbb{Z}_2$ | ✓ | $A_n$ | ✗（二對一） |
| $\operatorname{Id}_G$ | ✓ | $\{e\}$ | ✓ |
| $L_g$（$g\neq e$） | ✗ | | |

**技巧**：要證某個子集是子群，找一個同態以它為核。

## 附：本集一句話總結

> **同態是保持運算的函數 $\varphi(ab) = \varphi(a)\varphi(b)$（就像線性變換），它一定把單位送到單位、核和像都是子群，而且「單射 ⟺ 核只有單位元素」；雙射的同態叫同構，代表兩個群其實是同一個群（例如 $e^x$ 給出 $(\mathbb{R},+)\cong((0,\infty),\cdot)$）；Cayley 定理說每個群都同構於它自己上面的左乘映射所組成的置換群。**
