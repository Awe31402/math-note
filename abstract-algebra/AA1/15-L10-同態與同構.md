# 第 15 集 · L10：同態與同構、Cayley 定理 [▶ 影片](https://www.youtube.com/watch?v=hC_bOXIciGA&list=PLBY4G2o7DhF0JCgapYKrqibGaJuvV4Gkb)

← 上一集：[[14-L9-偶置換與奇置換]] ｜ [總目錄](../README.md) ｜ 下一集：[[16-L11-同構的性質]] →

## 本集概要

- **同態 (homomorphism)**：$\varphi(a\star b) = \varphi(a)\#\varphi(b)$，就像線性代數的線性變換，「保持結構」。
- 同態把單位元素送到單位元素。
- 三個例子：$e^x:(\mathbb{R},+)\to(\mathbb{R}^+,\cdot)$；$\det:GL(n,F)\to F^\times$；奇偶性 $S_n\to\mathbb{Z}_2$。
- **核 (kernel)** 和**像 (image)** 都是子群。所以「是某個同態的核」是證明子群的好方法：$A_n$、$SL(n,F)$。
- 同態是一對一 $\iff$ 核只有單位元素。
- **同構 (isomorphism)** = 雙射的同態。$e^x$ 是同構，所以 $(\mathbb{R},+)\cong(\mathbb{R}^+,\cdot)$。
- **Cayley 定理**：每個群都同構於某個置換群（用左乘映射 $L_g$）。

> 📘 講義對應：2018 講義 §2.8 後半（同態）與 §2.9「isomorphism and Cayley's Theorem」（p.71–78）。老師當時講義還沒打完，叫大家先讀 Gallian（第 6 章、第 10 章）。

## 筆記

### 0. 記號 [▶ 01:00](https://youtu.be/hC_bOXIciGA?t=60)

這一講會同時談好幾個群，所以寫 $(G,\star)$ 表示「群 $G$，運算 $\star$」。

### 1. 同態的定義 [▶ 01:30](https://youtu.be/hC_bOXIciGA?t=90)

> **定義**　函數 $\varphi:(G_1,\star)\to(G_2,\#)$ 是**同態**，若
> $$\varphi(a\star b) = \varphi(a)\,\#\,\varphi(b)\qquad\text{對所有 }a,b\in G_1.$$

**類比線性代數** [▶ 03:00](https://youtu.be/hC_bOXIciGA?t=180)：線性變換 $T(x+y) = T(x)+T(y)$。同態就是把 $G_1$ 的運算「搬到」$G_2$ 的運算上，**保持結構 (structure preserving)**。

**各種組合** [▶ 10:30](https://youtu.be/hC_bOXIciGA?t=630)：運算可以是加法、乘法（**並列 juxtaposition**，就是把兩個東西寫在一起）、合成……
- $\varphi(a+b) = \varphi(a)+\varphi(b)$
- $\varphi(ab) = \varphi(a)+\varphi(b)$
- $\varphi(f\circ g) = \varphi(f)\circ\varphi(g)$

**為什麼要抽象** [▶ 12:00](https://youtu.be/hC_bOXIciGA?t=720)：如果上百個例子有共同結構，對結構證一次，就等於對所有例子都證完了。抽象是為了**效率**（當然不只如此）。

### 2. 同態把單位元素送到單位元素 [▶ 04:00](https://youtu.be/hC_bOXIciGA?t=240)

> **命題 1**　$\varphi:(G_1,\star)\to(G_2,\#)$ 是同態，$e_1$、$e_2$ 是單位元素。則 $\varphi(e_1) = e_2$。

（類比：線性變換 $T(0) = 0$。但這裡對乘法、合成、各種奇怪的運算都成立 [▶ 05:00](https://youtu.be/hC_bOXIciGA?t=300)。）

**證明** [▶ 06:00](https://youtu.be/hC_bOXIciGA?t=360)
- 觀察 1：$e_2$ 是 $G_2$ 的單位元素，所以 $\varphi(e_1)\#e_2 = \varphi(e_1)$。
- 觀察 2：$e_1\star e_1 = e_1$，用同態性質：$\varphi(e_1) = \varphi(e_1\star e_1) = \varphi(e_1)\#\varphi(e_1)$ [▶ 07:30](https://youtu.be/hC_bOXIciGA?t=450)。
- 所以 $\varphi(e_1)\#e_2 = \varphi(e_1)\#\varphi(e_1)$。由**消去律**（兩邊左乘 $\varphi(e_1)^{-1}$），$e_2 = \varphi(e_1)$。$\blacksquare$

> 💬 考試改到第一題，老師抱怨：有人寫群的定義時，一半用並列記號、一半用 $\star$。**要選一種，不能混用** [▶ 08:30](https://youtu.be/hC_bOXIciGA?t=510)。

### 3. 三個例子 [▶ 13:00](https://youtu.be/hC_bOXIciGA?t=780)

**例 1：指數函數** [▶ 13:00](https://youtu.be/hC_bOXIciGA?t=780)
$$\varphi_1:(\mathbb{R},+)\to(\mathbb{R}^+,\cdot),\qquad \varphi_1(x) = e^x.$$
- $\varphi_1(x+y) = e^{x+y} = e^xe^y = \varphi_1(x)\varphi_1(y)$ ✓
- $\varphi_1(0) = e^0 = 1$：加法單位送到乘法單位 [▶ 15:00](https://youtu.be/hC_bOXIciGA?t=900)。

**例 2：行列式** [▶ 15:30](https://youtu.be/hC_bOXIciGA?t=930)
$$\varphi_2:GL(n,F)\to F^\times,\qquad \varphi_2(A) = \det A.$$
（$F$ 是體 (field)，$F^\times$ 是非零元素的乘法群。不習慣的話就想 $F = \mathbb{R}$。）
- 可逆矩陣的行列式非零，所以確實落在 $F^\times$ [▶ 16:30](https://youtu.be/hC_bOXIciGA?t=990)。
- $\det(AB) = \det A\det B$ ✓（對任何體都成立）

**例 3：奇偶性** [▶ 18:00](https://youtu.be/hC_bOXIciGA?t=1080)
$$\varphi_3:S_n\to\mathbb{Z}_2,\qquad \varphi_3(\sigma) = \begin{cases}0 & \sigma\text{ 偶}\\1 & \sigma\text{ 奇}\end{cases}$$
檢查四種情形 [▶ 19:30](https://youtu.be/hC_bOXIciGA?t=1170)：

| $\sigma$ | $\beta$ | $\sigma\beta$ | 左邊 $\varphi_3(\sigma\beta)$ | 右邊 $\varphi_3(\sigma)+\varphi_3(\beta)$ |
|---|---|---|---|---|
| 偶 | 偶 | 偶 | 0 | $0+0 = 0$ |
| 偶 | 奇 | 奇 | 1 | $0+1 = 1$ |
| 奇 | 偶 | 奇 | 1 | $1+0 = 1$ |
| 奇 | 奇 | 偶 | 0 | $1+1 = 0$ |

### 4. 核與像 [▶ 21:00](https://youtu.be/hC_bOXIciGA?t=1260)

> **定義**　$\varphi:G_1\to G_2$。
> - **核**：$\ker\varphi = \{x\in G_1\mid \varphi(x) = e_2\} = \varphi^{-1}(\{e_2\})$
> - **像**：$\operatorname{Im}\varphi = \{\varphi(x)\mid x\in G_1\} = \varphi(G_1)$

> **定理**　若 $\varphi$ 是同態，則 $\ker\varphi\le G_1$，$\operatorname{Im}\varphi\le G_2$ [▶ 23:00](https://youtu.be/hC_bOXIciGA?t=1380)。

證明留給讀者。和線性代數「核與值域都是子空間」幾乎一樣 [▶ 24:00](https://youtu.be/hC_bOXIciGA?t=1440)。

**應用：證明子群的好方法** [▶ 25:00](https://youtu.be/hC_bOXIciGA?t=1500)
- $\ker\varphi_3 = A_n$（偶置換）。所以 **$A_n$ 是子群**。
- $\ker\varphi_2 = \{A\mid\det A = 1\} = SL(n,F)$（**特殊線性群 special linear group**）。所以 $SL(n,F)$ 是子群 [▶ 38:00](https://youtu.be/hC_bOXIciGA?t=2280)。

**白話**：只要找到一個同態，它的核正好是你的集合，那個集合就是子群。

### 5. 一對一 $\iff$ 核是 $\{e\}$ [▶ 25:30](https://youtu.be/hC_bOXIciGA?t=1530)

> **命題 2**　同態 $\varphi:G_1\to G_2$ 是**單射 (injective)** $\iff \ker\varphi = \{e_1\}$。

**($\Rightarrow$)** [▶ 26:30](https://youtu.be/hC_bOXIciGA?t=1590)
- 由命題 1，$\varphi(e_1) = e_2$，所以 $e_1\in\ker\varphi$。
- 設 $x\in\ker\varphi$，則 $\varphi(x) = e_2 = \varphi(e_1)$。一對一，所以 $x = e_1$。
- 故 $\ker\varphi = \{e_1\}$。

（老師說：有人會省略大括號寫 $\ker\varphi = e_1$，但這門課要寫 $\{e_1\}$ [▶ 28:30](https://youtu.be/hC_bOXIciGA?t=1710)。）

**($\Leftarrow$)** [▶ 29:00](https://youtu.be/hC_bOXIciGA?t=1740)
- 設 $\varphi(x) = \varphi(y)$。左乘 $\varphi(x)^{-1}$ [▶ 30:30](https://youtu.be/hC_bOXIciGA?t=1830)，用同態性質：
$$\varphi(x^{-1}x) = \varphi(x^{-1}y)\ \Rightarrow\ e_2 = \varphi(e_1) = \varphi(x^{-1}y).$$
  （這裡也用到 $\varphi(x)^{-1} = \varphi(x^{-1})$。）
- 所以 $x^{-1}y\in\ker\varphi = \{e_1\}$，即 $x^{-1}y = e_1$，$y = x$。$\blacksquare$

**這很厲害** [▶ 32:00](https://youtu.be/hC_bOXIciGA?t=1920)：一般函數不能只看「什麼送到 0」來判斷一對一。例如 $f(x) = x^2$ 只有 $0\mapsto0$，但它不是一對一。因為 $f$ 不是 $(\mathbb{R},+)$ 的同態。**同態很特別。**

### 6. 同構 [▶ 33:00](https://youtu.be/hC_bOXIciGA?t=1980)

> **定義**　**同構**：既是同態又是**雙射**（一對一且映成）的函數。若 $G_1$ 到 $G_2$ 有同構，說 $G_1$ **同構於** $G_2$，記作 $G_1\cong G_2$ [▶ 35:00](https://youtu.be/hC_bOXIciGA?t=2100)。

**直覺**：同構的群是「同一個群」，只是記號不同。

（這和線性代數的「同構」一致。「同構」這個詞跨越許多數學領域；統一的概念在**範疇論 (category theory)**。老師說想問範疇論去問同事 Nathan，他真的很愛 [▶ 34:30](https://youtu.be/hC_bOXIciGA?t=2070)。）

**三個例子哪個是同構？** [▶ 36:00](https://youtu.be/hC_bOXIciGA?t=2160)
- $\varphi_3$：核是 $A_n$，不是 $\{(1)\}$（$n\ge2$），**不是**。其實是二對一。
- $\varphi_2$：行列式為 3 的矩陣有很多，**不是**。
- $\varphi_1 = e^x$：**是** [▶ 38:30](https://youtu.be/hC_bOXIciGA?t=2310)。
  - 核：$e^x = 1 \iff x = 0$，所以 $\ker = \{0\}$，一對一。
  - 映成：任給 $y>0$，$\varphi_1(\ln y) = e^{\ln y} = y$。

$$(\mathbb{R},+)\cong(\mathbb{R}^+,\cdot),\quad\text{同構就是指數函數。}$$

### 7. 恆等映射與同構是等價關係 [▶ 40:00](https://youtu.be/hC_bOXIciGA?t=2400)

**恆等映射** $\varphi(x) = x$ [▶ 40:30](https://youtu.be/hC_bOXIciGA?t=2430)：$\varphi(xy) = xy = \varphi(x)\varphi(y)$；映成、一對一都顯然。所以**每個群都同構於自己**。

**還可以證明**（好的作業題）[▶ 42:00](https://youtu.be/hC_bOXIciGA?t=2520)：
- 同構的反函數是同構 → 對稱。
- 同構的合成是同構 → 遞移。

所以**同構是等價關係**。所有群可以按「同構類」分組；同一類的群作為點集不同，但群結構相同。

### 8. 左乘映射與 Cayley 定理 [▶ 43:00](https://youtu.be/hC_bOXIciGA?t=2580)

> **定義**　**左乘 (left multiplication)**：$L_g:G\to G$，$L_g(x) = gx$。（Gallian 記作 $T_g$。）

- 由封閉性，$gx\in G$，所以 $L_g$ 是 $G\to G$ 的映射 [▶ 44:00](https://youtu.be/hC_bOXIciGA?t=2640)。
- 但 $L_g$ 一般**不是同態**：$L_g(xy) = gxy$，$L_g(x)L_g(y) = gxgy$，除非 $g = e$ 否則不相等 [▶ 44:30](https://youtu.be/hC_bOXIciGA?t=2670)。$L_e$ 就是恆等映射。

**$L_g$ 的性質** [▶ 46:00](https://youtu.be/hC_bOXIciGA?t=2760)
$$(L_g\circ L_h)(x) = L_g(hx) = g(hx) = (gh)x = L_{gh}(x).$$
最後一步要用**結合律**，這是關鍵 [▶ 46:30](https://youtu.be/hC_bOXIciGA?t=2790)。所以 $L_g\circ L_h = L_{gh}$。

特別地，$L_g\circ L_{g^{-1}} = L_e = \text{id}$ [▶ 47:30](https://youtu.be/hC_bOXIciGA?t=2850)，所以每個 $L_g$ 都是雙射，是 $G$ 上的置換。

**$\bar G = \{L_g\mid g\in G\}$ 是群**（對合成）[▶ 48:00](https://youtu.be/hC_bOXIciGA?t=2880)
- 封閉：$L_g\circ L_h = L_{gh}\in\bar G$。
- 單位：$L_e$。
- 反元素：$L_{g^{-1}}$。
- 結合律：函數合成本來就有。

**$\varphi:G\to\bar G$，$\varphi(g) = L_g$ 是同構** [▶ 49:30](https://youtu.be/hC_bOXIciGA?t=2970)
- 保持運算：$\varphi(gh) = L_{gh} = L_g\circ L_h = \varphi(g)\circ\varphi(h)$。
- 核：$L_g = \text{id}$ 只有 $g = e$（看 $L_g(e) = g$），所以一對一 [▶ 50:00](https://youtu.be/hC_bOXIciGA?t=3000)。
- 映成：依構造，$L_g = \varphi(g)$。

> **定理（Cayley 定理；Gallian Thm 6.1）**　每個群都同構於某個置換群。具體來說，$G\cong\bar G$，而 $\bar G$ 是 $G$ 上的置換組成的群 [▶ 51:00](https://youtu.be/hC_bOXIciGA?t=3060)。

**結尾** [▶ 51:30](https://youtu.be/hC_bOXIciGA?t=3090)：老師還在生病，講義還沒打完；先出週三要交的作業，講義之後補。這段時間請讀 Gallian。
