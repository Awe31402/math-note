## 1. 循環群的定義

[▶ 00:00](https://youtu.be/Ljwmll9UxuY?t=0) 回憶 L3：對任何 $a\in G$，$\langle a\rangle = \{a^n : n\in\mathbb{Z}\}$ 是 $G$ 的子群（**不管 $G$ 是不是循環群**）。

> **定義（循環群 cyclic group）**[▶ 00:30](https://youtu.be/Ljwmll9UxuY?t=30)　如果 $G = \langle a\rangle$ 對某個 $a\in G$ 成立，就說 $G$ 是**循環群**。任何滿足 $\langle b\rangle = G$ 的元素 $b$ 叫做 $G$ 的**生成元（generator）**。

**怎麼證明不是循環群**（講義）：證明**沒有任何元素**能生成整個 $G$。

【口頭】[▶ 01:00](https://youtu.be/Ljwmll9UxuY?t=60)「我回頭看 L3，終於找到我在哪裡『偷渡』了指數律——就是證明 $\langle a\rangle$ 是子群的那裡。」（見第 3 節。）

## 2. 例子

### 2.1 D3 不是循環群

[▶ 02:30](https://youtu.be/Ljwmll9UxuY?t=150)
$$D_3 = \{1,r,r^2,f,rf,r^2f\},\qquad r^3 = 1,\ f^2 = 1,\ frf = r^{-1}.$$

一個一個算循環子群：

| 生成元 | 循環子群 | 理由 |
|---|---|---|
| $r$ | $\{1,r,r^2\}$ | $r^3 = 1$ |
| $f$ | $\{1,f\}$ | $f^2 = 1$ |
| $rf$ [▶ 03:00](https://youtu.be/Ljwmll9UxuY?t=180) | $\{1,rf\}$ | 見下 |
| $r^2f$ [▶ 04:30](https://youtu.be/Ljwmll9UxuY?t=270) | $\{1,r^2f\}$ | 類似的計算 |
| $r^2$ | $\{1,r^2,r\}$ | $r^4 = r$，跟 $\langle r\rangle$ 一樣 |
| $1$ | $\{1\}$ | 「很無聊」 |

**$(rf)^2$ 的計算**[▶ 03:30](https://youtu.be/Ljwmll9UxuY?t=210)：
$$(rf)^2 = rfrf = r(frf) = rr^{-1} = 1.$$
（老師先寫錯方向，「抱歉，白痴」，改成 $frf = r^{-1}$。）所以 $rf$ 的**階是 2**。

> 📘 講義 Ex 2.6.2 的 $r^2f$：$r^2 = r^{-1}$，所以 $(r^2f)^2 = (r^{-1}f)(r^{-1}f) = r^{-1}(fr^{-1}f) = r^{-1}r = 1$。

【課堂討論】[▶ 05:00](https://youtu.be/Ljwmll9UxuY?t=300)「$D_3$ 是循環群嗎？」學生：不是。「為什麼？」**沒有一個元素能生成整個群**。「怎麼知道？**暴力法**：我們算了所有可能的單一元素生成的子群。」最大的只有 3 個元素，但 $|D_3| = 6$。

> 📘 講義：上面 5 個循環子群已經涵蓋 $D_3$ 的所有元素。「你懂為什麼這代表 $D_3$ 不是循環的嗎？」講義稱這種方法為「暴力法」，之後會學一些省力的工具。

### 2.2 整數加法

[▶ 05:30](https://youtu.be/Ljwmll9UxuY?t=330) **加法版**的循環子群：
$$\langle a\rangle = \{na : n\in\mathbb{Z}\}$$
——重複加法，也就是乘以 $n$ [▶ 07:00](https://youtu.be/Ljwmll9UxuY?t=420)。

$$\langle1\rangle = \{n\cdot1\} = \mathbb{Z},\qquad\langle-1\rangle = \{n\cdot(-1)\} = \mathbb{Z}.$$

所以 $(\mathbb{Z},+)$ 是**循環群**，有兩個生成元：$1$ 和 $-1$。

### 2.3 Zn 的生成元

**$\mathbb{Z}_4$**[▶ 07:30](https://youtu.be/Ljwmll9UxuY?t=450)：

| 生成元 | 依序加 | 子群 |
|---|---|---|
| $1$ | $0,1,2,3$ | $\mathbb{Z}_4$ |
| $2$ | $0,2$（$2+2 = 0$） | $\{0,2\}$ |
| $3$ [▶ 08:30](https://youtu.be/Ljwmll9UxuY?t=510) | $0,3,6\equiv2,5\equiv1$ | $\mathbb{Z}_4$ |

$\mathbb{Z}_4$ 有兩個生成元：1 和 3。

**一般規律**[▶ 09:00](https://youtu.be/Ljwmll9UxuY?t=540)：$\mathbb{Z}_n = \langle1\rangle$，所以 $\mathbb{Z}_n$ **永遠是循環群**。而且 $1$ 和 $-1$ 一定是生成元。「問題是：**還有誰**是生成元？」

**$\mathbb{Z}_{10}$**[▶ 09:30](https://youtu.be/Ljwmll9UxuY?t=570)：
- **生成元**：$1,3,7,9$。
- 不是生成元的例子 [▶ 10:00](https://youtu.be/Ljwmll9UxuY?t=600)：
  - $\langle5\rangle = \{0,5\}$；
  - $\langle6\rangle$：$6,12\equiv2,8,14\equiv4,\dots$，得到所有偶數 $\{0,2,4,6,8\}$；
  - $\langle8\rangle$：$8,16\equiv6,14\equiv4,22\equiv2,0$，也是偶數 [▶ 10:30](https://youtu.be/Ljwmll9UxuY?t=630)。

【課堂討論】[▶ 11:00](https://youtu.be/Ljwmll9UxuY?t=660)「我想你們開始看到規律了。」學生：**跟 $n$ 互質的數**就是生成元。「我們應該證明它。」（下一講證：$\mathbb{Z}_n$ 的生成元恰好是 $U(n)$。）

> 📘 講義 Ex 2.6.5：$\mathbb{Z}_7$ 的**每個非零元素**都是生成元。例如 $\langle2\rangle = \{0,2,4,6,1,3,5\}$、$\langle3\rangle = \{0,3,6,2,5,1,4\}$。（7 是質數，1 到 6 都跟 7 互質。）

### 2.4 單位群：有的循環、有的不是

[▶ 11:30](https://youtu.be/Ljwmll9UxuY?t=690)「再一個例子，把它從我的系統裡排出去。例子很重要。」

$$U(10) = \{1,3,7,9\},\quad U(8) = \{1,3,5,7\},\quad U(20) = \{1,3,7,9,11,13,17,19\}.$$

**$U(10)$ 是循環的**[▶ 12:30](https://youtu.be/Ljwmll9UxuY?t=750)：
- $\langle3\rangle$：$1,3,3^2 = 9,3\cdot9 = 27\equiv7$。得到全部，$U(10) = \langle3\rangle$。
- 也可以用 7 生成。
- 但 9 不行 [▶ 13:00](https://youtu.be/Ljwmll9UxuY?t=780)：$9\cdot9 = 81\equiv1$，$\langle9\rangle = \{1,9\}$。

**$U(8)$ 不是循環的**[▶ 13:30](https://youtu.be/Ljwmll9UxuY?t=810)：「去城裡大鬧一番吧。」
- $3\cdot3 = 9\equiv1$：$\langle3\rangle = \{1,3\}$。
- $5\cdot5 = 25\equiv1$：$\langle5\rangle = \{1,5\}$。
- $7\cdot7 = 49\equiv1$：$\langle7\rangle = \{1,7\}$。
- 沒有元素能生成 4 個元素。**$U(8)$ 不是循環的。**

**結論**：**單位群不一定是循環的**[▶ 14:00](https://youtu.be/Ljwmll9UxuY?t=840)。$U(20)$ 也不是（習題課證過，每個元素的階都是 1、2 或 4，見 [[06-習題課-Gallian第2-3章]]）。

> 📘 講義 Ex 2.6.7 問：「3 和 7 是 $U(10)$ 的生成元，9 不是。這些數和 10 的關係有什麼不同？」然後說：「我問這個**不是**期待你找到答案。哪些整數是單位群的生成元並不明顯。事實上，不是所有 $U(n)$ 都是循環的。」

## 3. 補上欠的：指數律

[▶ 14:30](https://youtu.be/Ljwmll9UxuY?t=870)「在進入正題前，我欠你們一個 L3 就該證的定理——或者我該把它出成作業。也許你們該慶幸我沒想到。」

> **定理（指數律 laws of exponents）**　$G$ 是群，$g\in G$，$m,n\in\mathbb{Z}$。則
> 1. $g^mg^n = g^{m+n}$；
> 2. $(g^m)^n = g^{mn}$。

- 證明不在課堂上做 [▶ 16:00](https://youtu.be/Ljwmll9UxuY?t=960)。(1) 在作業解答（Lecture 2 作業第 5 題的引理）裡，「三頁，很多情況，很多繁瑣的歸納法」。有了 (1)，(2) 只要大約半頁（講義 p.41）。
- 【口頭】[▶ 17:00](https://youtu.be/Ljwmll9UxuY?t=1020)「你們可以自由使用它們。但你們也要負責會證。我不會要你們在考試證**整個**，那不公平——那會是我唯一要改的東西，因為你們整場考試都在寫它。但我可能挑某個子情況，例如 $m,n$ 都是正的，那是合理的考題。」
- 「如果你們要我證 (2)，可以在下次習題課點題。」

【口頭】[▶ 21:00](https://youtu.be/Ljwmll9UxuY?t=1260)「這個定理以後就叫『指數律』——以 Laws 先生命名。」（學生沒笑。）「今天喜劇的標準很低。不過我收下了。」

## 4. 定理：⟨a⟩ 的結構

[▶ 18:00](https://youtu.be/Ljwmll9UxuY?t=1080)

> **定理**（講義 Thm 2.6.10）　$G$ 是群，$a\in G$。
> 1. 若 $|a| = \infty$，則 $i\neq j\Rightarrow a^i\neq a^j$。（所有次方都不同。）
> 2. 若 $|a| = n\in\mathbb{N}$，則
> $$\langle a\rangle = \{1,a,a^2,\dots,a^{n-1}\},$$
> 而且
> $$a^i = a^j\iff n\mid(i-j).$$

（這裡用乘法記號，單位元素寫 1。）

**第 2 部分其實有三件事**[▶ 30:30](https://youtu.be/Ljwmll9UxuY?t=1830)：
- (a) 前 $n$ 個次方 $1,a,\dots,a^{n-1}$ 互不相同；
- (b) $\langle a\rangle$ 就只有這些；
- (c) $a^i = a^j\iff n\mid(i-j)$。

### 4.1 無限階的情況

[▶ 19:30](https://youtu.be/Ljwmll9UxuY?t=1170)（反證法）

設 $|a| = \infty$，$i\neq j$，但 $a^i = a^j$。

**不失一般性（WLOG）**[▶ 20:00](https://youtu.be/Ljwmll9UxuY?t=1200)，設 $i>j$。「其中一個一定比較大。這個敘述對 $i,j$ 是對稱的，所以假設 $i$ 比較大就好。」

兩邊乘 $a^{-j}$，用指數律 [▶ 21:00](https://youtu.be/Ljwmll9UxuY?t=1260)：
$$a^ia^{-j} = a^ja^{-j}\ \Rightarrow\ a^{i-j} = a^0 = e.$$
$i-j$ 是正整數，所以 $|a|\le i-j<\infty$ [▶ 22:00](https://youtu.be/Ljwmll9UxuY?t=1320)。**矛盾**。

所以 $a^i\neq a^j$。$\blacksquare$

【口頭】[▶ 23:00](https://youtu.be/Ljwmll9UxuY?t=1380)「這部分我沒看 Gallian 就做出來了，它很合理。下一部分也不難，但需要多一點技術。」

### 4.2 有限階：前 n 個次方互不相同

[▶ 23:00](https://youtu.be/Ljwmll9UxuY?t=1380) 設 $|a| = n$。

假設 $a^i = a^j$，其中 $1\le j<i<n$。（老師把上標念成「sub」：「a sub i——聽聽我在說什麼——a 上標 i。」）

兩邊乘 $a^{-j}$ [▶ 24:30](https://youtu.be/Ljwmll9UxuY?t=1470)：
$$a^{i-j} = e,$$
所以 $|a|\le i-j$。

【課堂討論】[▶ 25:30](https://youtu.be/Ljwmll9UxuY?t=1530)「上面的不等式說 $i,j,n$ 有什麼關係？」$i<n$，所以 $i-j<n$。這跟 $|a| = n$ **矛盾**。

所以：$1\le j<i<n\Rightarrow a^i\neq a^j$ [▶ 26:00](https://youtu.be/Ljwmll9UxuY?t=1560)。

【口頭】[▶ 26:30](https://youtu.be/Ljwmll9UxuY?t=1590)「如果它們有希望相等，$i$ 和 $j$ 至少要相差 $n$。」

（講義的證明寫 $1\le j<i<n$；加上 $j = 0$ 的情況也一樣：$a^i = e$ 且 $0<i<n$ 直接矛盾。所以 $1,a,\dots,a^{n-1}$ 全部不同。）

### 4.3 有限階：⟨a⟩ 只有 n 個元素

[▶ 27:00](https://youtu.be/Ljwmll9UxuY?t=1620) 取任意 $k\in\mathbb{Z}$。由**除法算則**，存在 $q,r\in\mathbb{Z}$ 使
$$k = qn+r,\qquad 0\le r<n.$$

計算 [▶ 28:00](https://youtu.be/Ljwmll9UxuY?t=1680)：
$$
\begin{aligned}
a^k &= a^{qn+r}\\
&= a^{qn}a^r &&(\text{指數律 1})\\
&= (a^n)^qa^r &&(\text{指數律 2})\\
&= e^qa^r &&(a^n = e)\\
&= a^r.
\end{aligned}
$$

$r$ 只能是 $0,1,\dots,n-1$ [▶ 29:00](https://youtu.be/Ljwmll9UxuY?t=1740)。所以**任何**次方都能改寫成 $a^r$，$r$ 是 $k$ 除以 $n$ 的餘數。因此
$$\langle a\rangle = \{1,a,a^2,\dots,a^{n-1}\}$$
——原本「永遠一直下去」的清單，其實就這 $n$ 個 [▶ 30:00](https://youtu.be/Ljwmll9UxuY?t=1800)。

### 4.4 有限階：aⁱ = aʲ ⟺ n | (i−j)

**(⇒)**[▶ 31:30](https://youtu.be/Ljwmll9UxuY?t=1890) 設 $a^i = a^j$，$i,j\in\mathbb{Z}$。
1. 乘 $a^{-j}$：$a^{i-j} = e$。
2. 對 $i-j$ 用除法算則 [▶ 32:30](https://youtu.be/Ljwmll9UxuY?t=1950)：$i-j = qn+r$，$0\le r<n$。
3. 跟上面一樣算 [▶ 33:30](https://youtu.be/Ljwmll9UxuY?t=2010)：
$$e = a^{i-j} = a^{qn+r} = (a^n)^qa^r = a^r.$$
4. 所以 $a^r = e$，$0\le r<n$。【課堂討論】[▶ 34:00](https://youtu.be/Ljwmll9UxuY?t=2040)「這說 $r$ 是什麼？」有學生答「$r = n$」，老師：「$r$ 不能是 $n$。」若 $0<r<n$，就有比 $n$ 小的正次方給出 $e$，跟 $|a| = n$ 矛盾。所以 **$r = 0$**。
5. 因此 $i-j = qn$，$n\mid(i-j)$ [▶ 35:00](https://youtu.be/Ljwmll9UxuY?t=2100)。

【Q&A】[▶ 36:00](https://youtu.be/Ljwmll9UxuY?t=2160) 學生指出：這是「若且唯若」，只證了一個方向。老師：「對，我們只做了這部分。還要做逆向，逆向其實更簡單。」

**(⇐)**[▶ 36:30](https://youtu.be/Ljwmll9UxuY?t=2190) 設 $n\mid(i-j)$，即 $i-j = nk$。則
$$a^{i-j} = a^{nk} = (a^n)^k = e^k = e.$$
兩邊乘 $a^j$ [▶ 37:30](https://youtu.be/Ljwmll9UxuY?t=2250)：
$$a^{i-j}a^j = ea^j\ \Rightarrow\ a^i = a^j.\qquad\blacksquare$$

【口頭】[▶ 38:00](https://youtu.be/Ljwmll9UxuY?t=2280)「這跟 Gallian 定理 4.1 的證明很像。**關鍵就是恰當地使用除法算則**，並且搞清楚自己要證什麼。」

> 📘 講義補充：**跟 $\mathbb{Z}_n$ 的相似**。$|a| = n$ 時，$a^i = a^j$ ⟺ $i\equiv j\ (\mathrm{mod}\ n)$。所以 $\langle a\rangle = \{1,a,\dots,a^{n-1}\}$ 的指數律，跟 $\mathbb{Z}_n = \{0,1,\dots,n-1\}$ 的加法完全對應。「**$\mathbb{Z}_n$ 是典型的有限循環群**。」對一般循環群證明的事，對 $\mathbb{Z}_n$ 也成立。（Gallian p.76 Figure 4.1 有幫助。）

## 5. 推論：|a| = |⟨a⟩|

[▶ 38:30](https://youtu.be/Ljwmll9UxuY?t=2310)

> **推論**（講義 Cor 2.6.11）　$G$ 是群，$a\in G$。則
> $$|a| = |\langle a\rangle|.$$
> 元素的階 = 它生成的循環子群的階。

【口頭】[▶ 39:30](https://youtu.be/Ljwmll9UxuY?t=2370)「這叫推論。我最近在讀 Rotman 的抽象代數，他的嗜好之一是講字的意思。**theorem** 好像是古希臘文，意思是『**沉思**』——說 theorem 就像說『嘿，看看這個』。**corollary** 是拉丁文的『**花**』。在古羅馬，送花是流行的禮物。所以定理送了我們一份禮物：一束花。我們為定理努力工作，推論就不太費力。」

> 📘 講義也提到：Rotman 說 **mathematics** 是古希臘字，意思是「**學習**」。

**證明**[▶ 40:00](https://youtu.be/Ljwmll9UxuY?t=2400)
- **$|a| = \infty$**：由定理第 1 部分，
$$\langle a\rangle = \{1,a,a^{-1},a^2,a^{-2},\dots\}$$
  這些全部不同 [▶ 40:30](https://youtu.be/Ljwmll9UxuY?t=2430)，所以 $\langle a\rangle$ 是無限集合。
  【口頭】「我們沒有足夠的手指頭數。我從沒見過有無限多根手指的人——也許你可以說，如果那個人是完美的球形……」
- **$|a| = n$**[▶ 41:00](https://youtu.be/Ljwmll9UxuY?t=2460)：由定理第 2 部分，$\langle a\rangle = \{1,a,\dots,a^{n-1}\}$，而且這些互不相同。數一數：恰好 $n$ 個。$\blacksquare$

【口頭】[▶ 41:30](https://youtu.be/Ljwmll9UxuY?t=2490)「大約一週前的習題課，有人問我能不能證明元素的階等於子群的階。我拒絕了，因為我們今天要做，但它需要一些功夫。從例子看這很**明顯**——規律就在那裡。但**這就是證明它需要付出的代價**。」

## 6. 推論：aᵏ = e ⇒ |a| 整除 k

[▶ 43:00](https://youtu.be/Ljwmll9UxuY?t=2580)

> **推論**（講義 Cor 2.6.12）　$G$ 是群，$a\in G$，$|a| = n\in\mathbb{N}$。若 $a^k = e$，則 $n\mid k$。

（老師先寫「If G be a group」，說文法可疑：「我大一英文拿 B——好吧，B+。」）

**白話**[▶ 44:30](https://youtu.be/Ljwmll9UxuY?t=2670)：如果某個次方 $k$ 把 $a$ 送回單位元素，$k$ 一定是 $n$ 的倍數。

**證明**[▶ 45:00](https://youtu.be/Ljwmll9UxuY?t=2700)：$a^k = e = a^0$。由定理第 2 部分（取 $i = k$、$j = 0$），$n\mid(k-0) = k$。$\blacksquare$

「喔，我們證完了。」

### 怎麼用這個推論

[▶ 46:30](https://youtu.be/Ljwmll9UxuY?t=2790)「這對我們找生成元有什麼幫助？」

**例 1**[▶ 47:00](https://youtu.be/Ljwmll9UxuY?t=2820)：$|a| = 3$。那 $a^k = e$ 唯一的可能是 $k$ 是 3 的倍數。

**例 2**[▶ 47:30](https://youtu.be/Ljwmll9UxuY?t=2850)：$a^{50} = e$。關於 $|a|$ 能說什麼？
- **以前**只能說：$|a|\le50$。
- **現在**：$|a|$ 一定是 **50 的因數**。

【課堂討論】[▶ 48:30](https://youtu.be/Ljwmll9UxuY?t=2910) 列出可能：
$$|a|\in\{1,2,5,10,25,50\}.$$
（$|a| = 1$ 就是 $a = e$。）

**例 3：檢查到一半就能停**[▶ 49:30](https://youtu.be/Ljwmll9UxuY?t=2970)：老師說「如果 $a^{26}\neq e$……」學生搞糊塗了。老師更正 [▶ 50:30](https://youtu.be/Ljwmll9UxuY?t=3030)：「我的意思是：對所有 $j\le26$（或至少 $j\le25$），$a^j\neq e$。」那麼 $|a|$ 不是 1、2、5、10、25，**自動**就是 50。

【口頭】[▶ 50:30](https://youtu.be/Ljwmll9UxuY?t=3030)「找元素的階時，如果你知道群的階，算到某個點就不用再算了。你知道它一定是整個群的生成元，不用一路算到群的階那麼大的次方。善用它，這**非常省力**。」

> 📘 講義的版本：若 $a^{50} = e$，$|a|$ 可能是 2、5、10、25（或 1、50）。「如果你算出 $a^{26}\neq e$，能說什麼？如果 $a^{26}\neq e$ 且 $a^{50} = e$，$|a|$ 一定是多少？」（若 $a^{26}\neq e$，則 $|a|\nmid26$，排除 1、2；但還不能排除 5、10、25。要確定 $|a| = 50$，得驗證 $a^{10}\neq e$ 和 $a^{25}\neq e$——只要檢查 50 的「極大真因數」就夠。）

## 7. 一頁速查表

### 7.1 定義

| 名稱 | 內容 |
|---|---|
| 循環群 | $G = \langle a\rangle$ 對某個 $a$ |
| 生成元 | $\langle b\rangle = G$ 的元素 $b$ |
| 不是循環群 | 沒有元素能生成全部（例：$D_3$、$U(8)$、$U(20)$） |

### 7.2 例子

| 群 | 循環？ | 生成元 |
|---|---|---|
| $(\mathbb{Z},+)$ | ✓ | $\pm1$ |
| $\mathbb{Z}_4$ | ✓ | $1,3$ |
| $\mathbb{Z}_7$ | ✓ | $1,2,3,4,5,6$ |
| $\mathbb{Z}_{10}$ | ✓ | $1,3,7,9$ |
| $U(10)$ | ✓ | $3,7$ |
| $U(8)$ | ✗ | 每個非單位元素的階都是 2 |
| $D_3$ | ✗ | 最大的循環子群只有 3 個元素 |

### 7.3 結構定理與推論

| 結果 | 證明的關鍵一步 |
|---|---|
| $\lvert a\rvert = \infty\Rightarrow$ 次方全不同 | $a^i = a^j$（$i>j$）乘 $a^{-j}$ ⇒ $a^{i-j} = e$，矛盾 |
| $\lvert a\rvert = n\Rightarrow\langle a\rangle = \{1,\dots,a^{n-1}\}$ | 除法算則 $k = qn+r$ ⇒ $a^k = (a^n)^qa^r = a^r$ |
| $a^i = a^j\iff n\mid(i-j)$ | $a^{i-j} = e$；$i-j = qn+r$ ⇒ $a^r = e$ ⇒ $r = 0$ |
| $\lvert a\rvert = \lvert\langle a\rangle\rvert$ | 數 $\{1,\dots,a^{n-1}\}$（互不相同） |
| $a^k = e\Rightarrow\lvert a\rvert\mid k$ | $a^k = a^0$，套 $a^i = a^j\iff n\mid(i-j)$ |

### 7.4 指數律

$g^mg^n = g^{m+n}$、$(g^m)^n = g^{mn}$，對所有 $m,n\in\mathbb{Z}$。可以用；考試可能考某個子情況的證明。

### 7.5 術語

| 中文 | English |
|---|---|
| 循環群 | cyclic group |
| 生成元 | generator |
| 暴力法 | brute force |
| 不失一般性 | without loss of generality (WLOG) |
| 指數律 | laws of exponents |
| 定理；推論 | theorem（「沉思」）; corollary（「花」） |

## 附：本集一句話總結

> **$G = \langle a\rangle$ 就叫循環群；用除法算則可以證明：$a$ 無限階時所有次方都不同，$a$ 的階是 $n$ 時 $\langle a\rangle$ 恰好是 $\{1,a,\dots,a^{n-1}\}$、而且 $a^i = a^j\iff n\mid(i-j)$——所以元素的階等於它生成的子群的階，而且 $a^k = e$ 只在 $k$ 是 $|a|$ 的倍數時發生，這讓找元素的階變得很省力。**
