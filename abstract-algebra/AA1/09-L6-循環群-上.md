## 本集概要

- **循環群 (cyclic group)**：整個群可以由一個元素生成，$G = \langle a\rangle$；$a$ 叫**生成元 (generator)**。
- 例子：$D_3$、$U(8)$、$U(20)$ 不是循環群；$\mathbb{Z}$、$\mathbb{Z}_n$、$U(10)$ 是。觀察：$\mathbb{Z}_n$ 的生成元似乎就是和 $n$ 互質的數。
- **指數律**正式陳述（證明見講義）。
- **主定理**：$|a| = \infty$ 時各次方都不同；$|a| = n$ 時 $\langle a\rangle = \{e,a,\dots,a^{n-1}\}$，且 $a^i = a^j \iff n\mid(i-j)$。
- 兩個推論：**$|a| = |\langle a\rangle|$**；若 $a^k = e$ 則 **$|a|$ 整除 $k$**。

> 📘 講義對應：2018 講義 §2.6 Lecture 6「cyclic groups」（p.63–66）。老師口頭說的「Corollary 1.6.13、1.6.14」是 2016 版，2018 版是 Cor 2.6.11、2.6.12；主定理是 Thm 2.6.10（Gallian Thm 4.1）。

## 筆記

### 1. 循環群的定義 [▶ 00:00](https://youtu.be/Ljwmll9UxuY?t=0)

L3 證過：對任意 $a\in G$，$\langle a\rangle = \{\dots,a^{-1},e,a,a^2,\dots\}$ 一定是子群 [▶ 01:30](https://youtu.be/Ljwmll9UxuY?t=90)。

> **定義**　若 $G = \langle a\rangle$ 對某個 $a\in G$ 成立，就說 $G$ 是**循環群**，$a$ 是 $G$ 的**生成元**。

- 乘法記號：$\langle a\rangle = \{a^n\mid n\in\mathbb{Z}\}$。
- 加法記號：$\langle a\rangle = \{na\mid n\in\mathbb{Z}\}$（重複相加）[▶ 06:30](https://youtu.be/Ljwmll9UxuY?t=390)。

**要證明不是循環群**：說明**沒有任何一個元素**能生成整個群。

**今天的問題** [▶ 02:00](https://youtu.be/Ljwmll9UxuY?t=120)：循環群長什麼樣？它的生成元有什麼特徵？

> 💬 老師坦承：L3 證「$\langle a\rangle$ 是子群」時，偷偷用了還沒證的指數律 [▶ 01:00](https://youtu.be/Ljwmll9UxuY?t=60)。

### 2. 例子 [▶ 02:30](https://youtu.be/Ljwmll9UxuY?t=150)

**$D_3 = \{1,R,R^2,f,Rf,R^2f\}$ 不是循環群**（暴力法）
- $\langle R\rangle = \{1,R,R^2\}$
- $\langle f\rangle = \{1,f\}$
- $\langle Rf\rangle = \{1,Rf\}$，因為 $(Rf)^2 = R(fRf) = RR^{-1} = 1$ [▶ 03:30](https://youtu.be/Ljwmll9UxuY?t=210)
- $\langle R^2f\rangle = \{1,R^2f\}$，同理
- $\langle R^2\rangle = \{1,R^2,R\}$，因為 $R^4 = R$ [▶ 04:30](https://youtu.be/Ljwmll9UxuY?t=270)
- $\langle 1\rangle = \{1\}$

沒有一個是整個 $D_3$，所以 $D_3$ **不是循環群** [▶ 05:00](https://youtu.be/Ljwmll9UxuY?t=300)。

**$(\mathbb{Z},+)$ 是循環群** [▶ 06:00](https://youtu.be/Ljwmll9UxuY?t=360)：$\langle 1\rangle = \langle -1\rangle = \mathbb{Z}$。

**$\mathbb{Z}_4$** [▶ 07:30](https://youtu.be/Ljwmll9UxuY?t=450)
- $\langle 1\rangle = \{0,1,2,3\}$
- $\langle 2\rangle = \{0,2\}$
- $\langle 3\rangle = \{0,3,2,1\}$
- 生成元是 $1$ 和 $3 = -1$。一般地，**$\pm1$ 永遠是 $\mathbb{Z}_n$ 的生成元** [▶ 09:00](https://youtu.be/Ljwmll9UxuY?t=540)。

**$\mathbb{Z}_{10}$** [▶ 09:30](https://youtu.be/Ljwmll9UxuY?t=570)
- 生成元：$1,3,7,9$。
- $\langle 5\rangle = \{0,5\}$
- $\langle 6\rangle = \{0,6,2,8,4\}$（偶數）
- $\langle 8\rangle = \{0,8,6,4,2\}$
- **猜想** [▶ 11:00](https://youtu.be/Ljwmll9UxuY?t=660)：生成元就是和 $n$ **互質**的數。（還沒證；下一講證。）

**群的單位群** [▶ 11:30](https://youtu.be/Ljwmll9UxuY?t=690)
- **$U(10) = \{1,3,7,9\}$ 是循環群**：$\langle 3\rangle = \{1,3,9,7\}$（$27\equiv 7$），$7$ 也是生成元。但 $\langle 9\rangle = \{1,9\}$（$81\equiv 1$）[▶ 12:30](https://youtu.be/Ljwmll9UxuY?t=750)。
- **$U(8) = \{1,3,5,7\}$ 不是循環群** [▶ 13:00](https://youtu.be/Ljwmll9UxuY?t=780)：$3^2 = 9\equiv 1$，$5^2 = 25\equiv 1$，$7^2 = 49\equiv 1$。每個非單位元素的階都是 2。
- **$U(20)$ 不是循環群**：習題課證過，每個元素的階是 1、2 或 4 [▶ 14:00](https://youtu.be/Ljwmll9UxuY?t=840)。

**結論**：單位群 $U(n)$ **不一定**是循環群。哪些數是 $U(n)$ 的生成元，也沒那麼明顯。

### 3. 指數律（正式陳述）[▶ 14:30](https://youtu.be/Ljwmll9UxuY?t=870)

> **定理（指數律 laws of exponents）**　$G$ 是群，$g\in G$，$m,n\in\mathbb{Z}$。則
> 1. $g^mg^n = g^{m+n}$
> 2. $(g^m)^n = g^{mn}$

- (1) 的證明在 L2 作業第 5 題解答的引理裡，三頁，很多情況、很多歸納 [▶ 16:00](https://youtu.be/Ljwmll9UxuY?t=960)。
- 有了 (1)，(2) 只要半頁（講義 p.41）。
- 可以自由使用。考試不會要求證完整版，但可能考某一部分，例如 $m,n$ 都是正數的情形 [▶ 17:00](https://youtu.be/Ljwmll9UxuY?t=1020)。

### 4. 主定理：$\langle a\rangle$ 的結構 [▶ 18:00](https://youtu.be/Ljwmll9UxuY?t=1080)

> **定理（講義 Thm 2.6.10；Gallian Thm 4.1）**　$G$ 是群，$a\in G$。
> - 若 $|a| = \infty$，則 $i\neq j \Rightarrow a^i\neq a^j$。
> - 若 $|a| = n\in\mathbb{N}$，則 $\langle a\rangle = \{e,a,a^2,\dots,a^{n-1}\}$，而且
> $$a^i = a^j \iff n\mid (i-j).$$

**白話**：無限階時，每個次方都不一樣。有限階 $n$ 時，次方每 $n$ 個循環一次，就像模 $n$ 的時鐘。

**證明**

**(a) 無限階** [▶ 19:30](https://youtu.be/Ljwmll9UxuY?t=1170)
- 假設 $i\neq j$ 但 $a^i = a^j$。不失一般性 (without loss of generality)，設 $i>j$。
- 兩邊乘 $a^{-j}$，用指數律：$a^{i-j} = a^0 = e$ [▶ 21:00](https://youtu.be/Ljwmll9UxuY?t=1260)。
- 所以 $|a|\le i-j$，和 $|a| = \infty$ 矛盾。

**(b) 有限階 $n$：$e,a,\dots,a^{n-1}$ 互不相同** [▶ 23:00](https://youtu.be/Ljwmll9UxuY?t=1380)
- 假設 $a^i = a^j$，$1\le j<i<n$。同樣得 $a^{i-j} = e$。
- 但 $0<i-j<n$，和 $|a| = n$ 矛盾 [▶ 25:00](https://youtu.be/Ljwmll9UxuY?t=1500)。

**(c) 每個次方都在這張清單裡** [▶ 27:00](https://youtu.be/Ljwmll9UxuY?t=1620)
- 任取 $k\in\mathbb{Z}$。用除法算則：$k = qn + r$，$0\le r<n$。
- 則
$$a^k = a^{qn+r} = a^{qn}a^r = (a^n)^qa^r = e^qa^r = a^r.$$
- $r\in\{0,1,\dots,n-1\}$，所以 $\langle a\rangle = \{e,a,\dots,a^{n-1}\}$ [▶ 30:00](https://youtu.be/Ljwmll9UxuY?t=1800)。

**(d) $a^i = a^j \Rightarrow n\mid (i-j)$** [▶ 31:30](https://youtu.be/Ljwmll9UxuY?t=1890)
- $a^i = a^j$ 推得 $a^{i-j} = e$。
- 對 $i-j$ 用除法算則：$i-j = qn + r$，$0\le r<n$。
- 同 (c) 的計算：$e = a^{i-j} = a^r$ [▶ 33:30](https://youtu.be/Ljwmll9UxuY?t=2010)。
- 若 $r>0$，就有比 $n$ 小的正次方等於 $e$，矛盾。所以 $r = 0$，$i-j = qn$，即 $n\mid (i-j)$ [▶ 35:00](https://youtu.be/Ljwmll9UxuY?t=2100)。

**(e) 反方向：$n\mid (i-j) \Rightarrow a^i = a^j$** [▶ 36:30](https://youtu.be/Ljwmll9UxuY?t=2190)
- $i-j = nk$，所以 $a^{i-j} = (a^n)^k = e^k = e$。
- 兩邊乘 $a^j$：$a^i = a^j$。$\blacksquare$

**關鍵** [▶ 38:00](https://youtu.be/Ljwmll9UxuY?t=2280)：適當地使用**除法算則**，並清楚記得自己要證什麼。

### 5. 推論 1：元素的階 = 它生成的子群的階 [▶ 38:30](https://youtu.be/Ljwmll9UxuY?t=2310)

> **推論（講義 Cor 2.6.11）**　$|a| = |\langle a\rangle|$。

**證明** [▶ 40:30](https://youtu.be/Ljwmll9UxuY?t=2430)
- $|a| = \infty$：由定理，$e,a,a^{-1},a^2,a^{-2},\dots$ 全都不同，所以 $\langle a\rangle$ 是無限集。
- $|a| = n$：由定理，$\langle a\rangle = \{e,a,\dots,a^{n-1}\}$ 且互不相同，數一數剛好 $n$ 個。$\blacksquare$

**旁白：theorem 和 corollary 的字源** [▶ 39:30](https://youtu.be/Ljwmll9UxuY?t=2370)（出自 Rotman）
- **theorem** 來自希臘文「觀看、沉思」：值得好好想一想的東西。
- **corollary** 來自拉丁文「花」：古羅馬人常送花當禮物，所以推論是定理送的**禮物**。

> 💬 有同學在約一週前的答疑課問過這個；老師當時不證，就是因為要像這樣花力氣才能真正證明 [▶ 41:30](https://youtu.be/Ljwmll9UxuY?t=2490)。

### 6. 推論 2：$a^k = e \Rightarrow |a|$ 整除 $k$ [▶ 43:00](https://youtu.be/Ljwmll9UxuY?t=2580)

> **推論（講義 Cor 2.6.12）**　設 $|a| = n$。若 $a^k = e$，則 $n\mid k$。

**證明** [▶ 45:00](https://youtu.be/Ljwmll9UxuY?t=2700)：$a^k = e = a^0$，由定理 $n\mid (k-0) = k$。$\blacksquare$

**怎麼用** [▶ 46:30](https://youtu.be/Ljwmll9UxuY?t=2790)
- 若 $|a| = 3$，則 $a^k = e$ 只有在 $k$ 是 3 的倍數時發生。
- 若 $a^{50} = e$：以前只能說 $|a|\le 50$。現在可以說 **$|a|$ 是 50 的因數**：$1,2,5,10,25,50$ [▶ 48:30](https://youtu.be/Ljwmll9UxuY?t=2910)。
- 再加上 $a^j\neq e$ 對所有 $j\le 26$，那 $|a|$ 只能是 $50$ [▶ 50:00](https://youtu.be/Ljwmll9UxuY?t=3000)。

**省力的地方** [▶ 50:30](https://youtu.be/Ljwmll9UxuY?t=3030)：找元素的階時，算到一定程度就能停，不必一路算到群的階。
