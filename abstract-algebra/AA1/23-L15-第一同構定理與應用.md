# 第 23 集 · L15：第一同構定理的證明與應用 [▶ 影片](https://www.youtube.com/watch?v=8QcxaeeyxAw&list=PLBY4G2o7DhF0JCgapYKrqibGaJuvV4Gkb)

## 本集概要

- **直覺**：同態把 $G_1$ 按核的陪集分塊，每一塊壓成一個點；它是「$|\ker\varphi|$ 對 1」的映射。
- **第一同構定理**完整證明：良定義、同態、滿射、單射。
- $\varphi = \iota\circ\bar\varphi\circ\pi$（自然同態、誘導同構、包含映射）。任何函數都能這樣「變成雙射」（用到選擇公理）。
- **應用**：
  - $GL(n,\mathbb{R})/SL(n,\mathbb{R})\cong\mathbb{R}^\times$
  - 每個循環群同構於 $\mathbb{Z}$ 或 $\mathbb{Z}/n\mathbb{Z}$
  - $\mathbb{R}/2\pi\mathbb{Z}\cong S^1$（單位圓）
  - $(G\times H)/(\{e\}\times H)\cong G$；更一般地 $(G_1\times G_2)/(N_1\times N_2)\cong G_1/N_1\times G_2/N_2$
- 老師宣布**改用自己的直積記號**：$G\times H$ 表示外直積（笛卡兒積），和 Gallian 相反。

> 📘 講義對應：2018 講義 §3.5 Lecture 15「the isomorphism theorem」（p.106–110）；Gallian Thm 10.3（第一同構定理）。

## 筆記

### 1. 直覺：同態是「$K$ 對 1」的映射 [▶ 00:00](https://youtu.be/8QcxaeeyxAw?t=0)

**對比 $f(x) = x^2$** [▶ 02:00](https://youtu.be/8QcxaeeyxAw?t=120)：$f(\pm a) = a^2$，$a\neq0$ 時是二對一；但 $0$ 例外，只有它送到 $0$。普通函數「每個點幾對一」可以不一樣。

**同態不一樣** [▶ 03:00](https://youtu.be/8QcxaeeyxAw?t=180)
- 核 $K = \ker\varphi$ 是正規子群，$G_1$ 被分成 $K$ 的陪集：$K$、$aK$、$bK$、$abK$……每塊一樣大。
- $\varphi$ 把每一塊**整塊**送到一個點：$K\mapsto e$、$aK\mapsto\varphi(a)$……
- 所以 $\varphi$ 是 **$|K|$ 對 1** 的映射 [▶ 05:00](https://youtu.be/8QcxaeeyxAw?t=300)。

**於是定義** $\bar\varphi(aK) = \varphi(a)$，它是同態：
$$\bar\varphi(aK\cdot bK) = \bar\varphi(abK) = \varphi(ab) = \varphi(a)\varphi(b) = \bar\varphi(aK)\bar\varphi(bK).$$
它的核是「送到 $e$ 的陪集」，就是 $K$ 本身，也就是**商群的單位元素** [▶ 08:00](https://youtu.be/8QcxaeeyxAw?t=480)。核只有單位元素，所以 $\bar\varphi$ 是同構。這就是第一同構定理。

> 💬 老師說這套直覺是他哥哥的講法，哥哥說對學生有幫助，「我不完全確定」[▶ 09:00](https://youtu.be/8QcxaeeyxAw?t=540)。

### 2. 第一同構定理 [▶ 09:00](https://youtu.be/8QcxaeeyxAw?t=540)

> **定理（第一同構定理；Gallian Thm 10.3）**　$\varphi:G_1\to G_2$ 是同態，$K = \ker\varphi$。則
> $$\bar\varphi:G_1/K\to\varphi(G_1),\qquad \bar\varphi(xK) = \varphi(x)$$
> 是同構。所以 $G_1/\ker\varphi\cong\varphi(G_1)$。

**證明**

**(a) 良定義** [▶ 12:00](https://youtu.be/8QcxaeeyxAw?t=720)
- 值確實在 $\varphi(G_1)$ 裡（$x\in G_1$）。
- 要證**單值**：設 $xK = yK$。則 $xy^{-1}\in K$（$K$ 正規，左右陪集一樣），即 $\varphi(xy^{-1}) = e_2$ [▶ 13:00](https://youtu.be/8QcxaeeyxAw?t=780)。
- 所以 $\varphi(x)\varphi(y)^{-1} = e_2$，$\varphi(x) = \varphi(y)$。
- 故 $\bar\varphi(xK) = \varphi(x) = \varphi(y) = \bar\varphi(yK)$ [▶ 14:30](https://youtu.be/8QcxaeeyxAw?t=870)。

> 💬 「函數的定義仍然重要」：另一位教授的微積分第一次考試，第一題總是函數的定義 [▶ 15:00](https://youtu.be/8QcxaeeyxAw?t=900)。

**(b) 同態** [▶ 15:30](https://youtu.be/8QcxaeeyxAw?t=930)
$$\bar\varphi(xK\cdot yK) = \bar\varphi(xyK) = \varphi(xy) = \varphi(x)\varphi(y) = \bar\varphi(xK)\bar\varphi(yK).$$

**(c) 滿射** [▶ 17:00](https://youtu.be/8QcxaeeyxAw?t=1020)：$\varphi(G_1)$ 的任一元素是 $\varphi(x)$，而 $\bar\varphi(xK) = \varphi(x)$。

**(d) 單射** [▶ 18:00](https://youtu.be/8QcxaeeyxAw?t=1080)
$$\ker\bar\varphi = \{xK\mid\varphi(x) = e_2\} = \{xK\mid x\in K\} = \{K\}.$$
只含商群的單位元素，所以單射。$\blacksquare$

### 3. $\varphi$ 的分解 [▶ 19:30](https://youtu.be/8QcxaeeyxAw?t=1170)

$$G_1\xrightarrow{\ \pi\ }G_1/K\xrightarrow{\ \bar\varphi\ }\varphi(G_1)\xrightarrow{\ \iota\ }G_2$$
- $\pi$：自然同態 $\pi(g) = gK$。
- $\bar\varphi$：誘導出來的同構。
- $\iota$：**包含映射 (inclusion map)**，$A\subseteq X$ 時 $\iota(a) = a$。很無聊，只是把子集放回大集合 [▶ 21:00](https://youtu.be/8QcxaeeyxAw?t=1260)。

$$\varphi = \iota\circ\bar\varphi\circ\pi.$$

**更一般的觀點：任何函數都能變成雙射** [▶ 24:30](https://youtu.be/8QcxaeeyxAw?t=1470)
- $f:A\to B$。**纖維 (fiber)** $f^{-1}(\{p\})$ 把定義域分割成互不相交的部分（因為 $f$ 單值）。
- 從每條纖維挑一個點，形成**橫截面 (cross-section)** $C$。
- 把 $f$ 限制到 $C$，並把對應域換成值域 $f(A)$，就得到雙射。
- 「每條纖維挑一個點」要用到**選擇公理 (axiom of choice)**——這門課第一次用到 [▶ 27:00](https://youtu.be/8QcxaeeyxAw?t=1620)。

### 4. 應用 1：$GL(n,\mathbb{R})/SL(n,\mathbb{R})\cong\mathbb{R}^\times$ [▶ 27:30](https://youtu.be/8QcxaeeyxAw?t=1650)

- $\det:GL(n,\mathbb{R})\to\mathbb{R}^\times$ 是同態，核是 $SL(n,\mathbb{R})$。
- **滿射** [▶ 29:00](https://youtu.be/8QcxaeeyxAw?t=1740)：任給 $c\neq0$，$\det\operatorname{diag}(c,1,\dots,1) = c$。
- 由第一同構定理：
$$GL(n,\mathbb{R})/SL(n,\mathbb{R})\cong\mathbb{R}^\times.$$

### 5. 應用 2：每個循環群都是 $\mathbb{Z}$ 或 $\mathbb{Z}/n\mathbb{Z}$ [▶ 30:00](https://youtu.be/8QcxaeeyxAw?t=1800)

設 $G = \langle a\rangle$。定義 $\varphi:\mathbb{Z}\to G$，$\varphi(m) = a^m$。
- 同態：$\varphi(m+k) = a^{m+k} = a^ma^k$ [▶ 31:00](https://youtu.be/8QcxaeeyxAw?t=1860)。
- 滿射：$a^m = \varphi(m)$。

**情形 1：$|a| = \infty$** [▶ 31:30](https://youtu.be/8QcxaeeyxAw?t=1890)
- $\ker\varphi = \{0\}$（無限階，只有 $a^0 = e$）。
- 所以 $G\cong\mathbb{Z}/\{0\}\cong\mathbb{Z}$。

**$G/\{e\}\cong G$** [▶ 33:00](https://youtu.be/8QcxaeeyxAw?t=1980)：$\mathbb{Z}/\{0\} = \{x+\{0\}\}$，每個陪集只有一個點，$\psi(x+\{0\}) = x$ 是同構。就像給每個元素套上大括號，再用同樣規則相乘。「很煩，但現在我們知道了。」對任何群都成立。

**情形 2：$|a| = n$** [▶ 35:00](https://youtu.be/8QcxaeeyxAw?t=2100)
- $\ker\varphi = \{m\mid a^m = e\} = \{m\mid n\mid m\} = n\mathbb{Z}$（L6 的結果）[▶ 37:00](https://youtu.be/8QcxaeeyxAw?t=2220)。
- 所以 $G\cong\mathbb{Z}/n\mathbb{Z}$。

> 💬 老師一開始想直接從 $\mathbb{Z}/n\mathbb{Z}$ 定義映射到 $G$，隨即說「這樣把樂趣都拿掉了」：從 $\mathbb{Z}$ 出發才能用上第一同構定理 [▶ 36:00](https://youtu.be/8QcxaeeyxAw?t=2160)。

**副產品** [▶ 38:30](https://youtu.be/8QcxaeeyxAw?t=2310)：$\mathbb{Z}_n$ 不只同構於 $\mathbb{Z}/n\mathbb{Z}$，它**就是** $\mathbb{Z}/n\mathbb{Z}$（等號）。

### 6. 應用 3：$\mathbb{R}/2\pi\mathbb{Z}\cong S^1$ [▶ 39:30](https://youtu.be/8QcxaeeyxAw?t=2370)

$$\varphi:(\mathbb{R},+)\to(\mathbb{C}^\times,\cdot),\qquad \varphi(\theta) = \cos\theta + i\sin\theta.$$
- **同態**：$\varphi(\theta+\beta) = \varphi(\theta)\varphi(\beta)$，要用和角公式 [▶ 40:00](https://youtu.be/8QcxaeeyxAw?t=2400)。（老師說差點出在第一次考試；他假設學生會和角公式，「這可能是我對學生的誤解之一」。）
- **核** [▶ 41:00](https://youtu.be/8QcxaeeyxAw?t=2460)：$\mathbb{C}^\times$ 的單位是 $1$，要 $\cos\theta = 1$ 且 $\sin\theta = 0$。$\cos\theta = 1$ 給 $\theta = 2\pi k$；$\sin\theta = 0$ 給 $\theta = \pi j$。同時成立：$\ker\varphi = 2\pi\mathbb{Z}$。
- **像** [▶ 42:30](https://youtu.be/8QcxaeeyxAw?t=2550)：$|\varphi(\theta)|^2 = \cos^2\theta+\sin^2\theta = 1$，像是**單位圓** $S^1$。附帶證明了 $S^1$ 是乘法群（同態的像是子群）。

$$\mathbb{R}/2\pi\mathbb{Z}\cong S^1.$$

**幾何圖像** [▶ 43:30](https://youtu.be/8QcxaeeyxAw?t=2610)：把實數線上每隔 $2\pi$ 的點黏在一起；或者把直線一圈一圈繞在單位圓上，每 $2\pi$（圓周長）回到起點。

### 7. 新的直積記號 [▶ 45:00](https://youtu.be/8QcxaeeyxAw?t=2700)

老師覺得 Gallian 的內直積/外直積記號「完全反了」，決定改用：
- $G\times H$：**外直積**（笛卡兒積，逐分量運算）。之前在課上寫過 $G\oplus H$ [▶ 47:30](https://youtu.be/8QcxaeeyxAw?t=2850)。
- $G = G_1\oplus G_2$（他的想法）：表示 $G$ 是內直積，因而 $G\cong G_1\times G_2$。

會整理一份清楚的對照表給大家。

> 💬 老師的哥哥說：反正都同構，沒差。老師回應：你們正在學同構，所以需要知道兩個東西**作為點集**什麼時候不同；等成熟了、當了教授，再來「濫用同構」[▶ 49:00](https://youtu.be/8QcxaeeyxAw?t=2940)。

### 8. 應用 4：直積的商 [▶ 47:00](https://youtu.be/8QcxaeeyxAw?t=2820)

**投影 (projection)**：
$$\pi_1:G\times H\to G,\ \pi_1(g,h) = g;\qquad \pi_2:G\times H\to H,\ \pi_2(g,h) = h.$$
- $\ker\pi_1 = \{e_G\}\times H$，$\ker\pi_2 = G\times\{e_H\}$ [▶ 49:30](https://youtu.be/8QcxaeeyxAw?t=2970)。
- 兩個都是滿射。由第一同構定理：
$$(G\times H)/(\{e_G\}\times H)\cong G,\qquad (G\times H)/(G\times\{e_H\})\cong H.$$
  「$G$ 消掉、$H$ 消掉」[▶ 51:00](https://youtu.be/8QcxaeeyxAw?t=3060)。

**更一般** [▶ 51:30](https://youtu.be/8QcxaeeyxAw?t=3090)：若 $N_1\trianglelefteq G_1$、$N_2\trianglelefteq G_2$，則 $N_1\times N_2\trianglelefteq G_1\times G_2$，而且
$$(G_1\times G_2)/(N_1\times N_2)\cong G_1/N_1\times G_2/N_2.$$
同樣可以用第一同構定理證明。
