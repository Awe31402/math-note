## 1. 回顧：Lamé、Kummer、Dedekind

[▶ 00:30](https://youtu.be/Wt2RWtVkL4I?t=30)
- Lamé（「或 Lamé 或 Lom，反正我念錯」）假設某類代數整數有**唯一分解**，其實沒有。
- **Kummer** 知道這件事；**Dedekind** 把 Kummer 的論證補齊，讓「**理想數**」有堅實的邏輯基礎。
- 最後的定理：這些代數整數**元素層次**沒有唯一分解，但改用**理想**時，**理想層次有唯一分解**。
- 但 Lamé 的論證救不回來。Fermat 最後定理很多情形用 Dedekind 的技術證了，但不是全部，「直到近年才完全解決」[▶ 01:30](https://youtu.be/Wt2RWtVkL4I?t=90)。

**UFD 定義**（講義 Def 4.8.6）[▶ 02:00](https://youtu.be/Wt2RWtVkL4I?t=120)：每個非零非單位元素是不可約元的乘積；若 $x = x_1\cdots x_n = y_1\cdots y_m$，則 $n = m$，而且重新排序後 $x_i$ 和 $y_i$ **相伴**。（投影上下標寫錯了，「應該配對」。）

## 2. 升鏈條件（ACC）

[▶ 02:30](https://youtu.be/Wt2RWtVkL4I?t=150)「這種思考方式是 **Emmy Noether** 開創的。她把抽象代數帶到另一個層次——20 世紀初。她在德國的 Göttingen 學派（『在**希特勒毀掉這一切**之前』），後來短暫在 **Bryn Mawr College**。很不幸她**早逝**——她真的是很棒的數學家。我們知道的**現代環論**很大部分源自她和她的學生。」

> **定理（PID 的升鏈條件 ascending chain condition）**（講義 Thm 4.8.7）[▶ 03:30](https://youtu.be/Wt2RWtVkL4I?t=210)　PID 中，嚴格遞增的理想鏈 $I_1\subsetneq I_2\subsetneq\cdots$ 一定**有限長**。

**證明**
1. 令 $I = \bigcup_kI_k$。它是理想（差、超級封閉——「一點集合論，任意聯集」）[▶ 04:00](https://youtu.be/Wt2RWtVkL4I?t=240)。
2. PID ⇒ $I = \langle d\rangle$。
3. $d\in I$ ⇒ $d$ 在某個 $I_m$ 裡（聯集）。
4. 鏈裡每個都 $\subseteq I = \langle d\rangle\subseteq I_m$（$I_m$ 含 $d$ 就含 $\langle d\rangle$）[▶ 04:30](https://youtu.be/Wt2RWtVkL4I?t=270)。
5. 所以鏈在 $I_m$ 就停了。$\blacksquare$

【口頭】[▶ 06:00](https://youtu.be/Wt2RWtVkL4I?t=360)「順帶一提，這個升鏈條件跟**唯一分解**到底有什麼關係？**一點也不明顯。**」

## 3. PID ⇒ UFD

[▶ 06:30](https://youtu.be/Wt2RWtVkL4I?t=390) 已知的 UFD 例子：$\mathbb{Z}[x]$（Gallian p.235 附近「血淋淋的細節」）；$F[x]$（$F$ 體）是 PID（講義 Thm 4.5.17），下面的定理就給出它是 UFD。

> **定理**（講義 Thm 4.8.8）[▶ 07:00](https://youtu.be/Wt2RWtVkL4I?t=420)　**每個 PID 都是 UFD。**

「這個證明我覺得是我們會看的**最有趣**的之一。」

取 $a_0$ 非零非單位。**三個階段**[▶ 07:30](https://youtu.be/Wt2RWtVkL4I?t=450)：
1. $a_0$ 的分解裡**至少有一個不可約元**；
2. $a_0$ **能分解成**不可約元的乘積；
3. 分解在相伴下**唯一**。

（「我給單位集合取了名字 $U$，後來沒用——完全沒必要，我可以刪掉。告訴你們是因為很迷人。抱歉。」）

**階段 1**[▶ 08:00](https://youtu.be/Wt2RWtVkL4I?t=480)
- $a_0$ 不可約：完成。
- 否則 $a_0 = a_1b_1$，$a_1,b_1$ 都不是單位。$a_1$ 不可約就完成；否則 $a_1 = a_2b_2$……
- $a_n = a_{n+1}b_{n+1}$ ⇒ $\langle a_n\rangle\subsetneq\langle a_{n+1}\rangle$（$b_{n+1}$ 非單位所以嚴格）[▶ 09:00](https://youtu.be/Wt2RWtVkL4I?t=540)。
- 嚴格遞增的理想鏈 ⇒ 由 ACC 必須停 ⇒ 停在某個**不可約**的 $a_k$。✓

**階段 2**[▶ 10:00](https://youtu.be/Wt2RWtVkL4I?t=600)
- $a_0$ 不可約：完成（「有點蠢，但好」）。
- 否則由階段 1：$a_0 = p_1c_1$，$p_1$ 不可約、$c_1$ 非單位。$c_1$ 不可約就完成；否則 $c_1 = p_2c_2$……
- $\langle a_0\rangle\subsetneq\langle c_1\rangle\subsetneq\langle c_2\rangle\subsetneq\cdots$，ACC ⇒ 停在不可約的 $c_t$。
- $a_0 = p_1p_2\cdots p_t$。「在 PID 裡，任何元素都能分解成不可約元的乘積。」✓

**階段 3（唯一）**[▶ 11:30](https://youtu.be/Wt2RWtVkL4I?t=690)：對左邊不可約元個數 $t$ 歸納。
- **$t = 1$**：$a_0 = p_1 = q_1\cdots q_s$。若 $s>1$，就是 $p_1$ 的分解，矛盾 ⇒ $s = 1$，$p_1 = q_1$。「連相伴的空間都沒有。」
- **歸納步驟**[▶ 12:30](https://youtu.be/Wt2RWtVkL4I?t=750)：$p_1\cdots p_t = q_1\cdots q_s$。
  - $p_1\mid q_1\cdots q_s$；PID 中不可約 = 質元 ⇒ $p_1\mid q_j$，某個 $j$（「推廣的 Euclid 算則，我沒指定的一題習題」）。
  - $q_j$ 不可約 ⇒ $q_j = u_jp_1$，$u_j$ 單位。
  - 代入、**消去** $p_1$：$p_2\cdots p_t = u_j\cdot(\text{其餘的 }q)$。（學生指出 $j$ 可能是 1：「對，你說得對，我該放個 1 在那裡。」）
  - 少一個因數，由歸納假設唯一。$\blacksquare$

【口頭】[▶ 14:00](https://youtu.be/Wt2RWtVkL4I?t=840)「如果最近修過**數論**，你會認出這就是**質因數分解**的論證。」

> **推論**（講義 Cor 4.8.9）[▶ 14:30](https://youtu.be/Wt2RWtVkL4I?t=870)　$F$ 是體 ⇒ $F[x]$ 是 UFD。「**唾手可得的果實**。」

## 4. ED ⇒ PID；層級與反例

> **定理**（講義 Thm 4.8.10）[▶ 15:00](https://youtu.be/Wt2RWtVkL4I?t=900)　**每個 ED 都是 PID。**

「我不太難過沒在正課時間做這個，因為這論證**太熟了**。」
- $I\neq0$。$S = \{N(x) : x\in I,\ x\neq0\}$ 非空，**良序原理**取最小 $s_0 = N(x_0)$。
- 任取 $z\in I$，除法算則 $z = qx_0+r$；$r = z-qx_0\in I$（超級封閉）。$r\neq0$ 會跟 $x_0$ 最小矛盾 ⇒ $r = 0$ ⇒ $z\in\langle x_0\rangle$ [▶ 16:30](https://youtu.be/Wt2RWtVkL4I?t=990)。
- $I\subseteq\langle x_0\rangle$；含 $x_0$ 的最小理想是 $\langle x_0\rangle$ ⇒ $I = \langle x_0\rangle$。$I = 0$ 時 $= \langle0\rangle$。$\blacksquare$
- 「這**正是** $F[x]$ 是 PID 的論證，只是把『次數』換成『範數』——而次數就是 $F[x]$ 的範數。」

> **推論**（講義 Cor 4.8.11）[▶ 17:30](https://youtu.be/Wt2RWtVkL4I?t=1050)　ED ⇒ UFD。

$$\boxed{\text{ED}\ ⇒\ \text{PID}\ ⇒\ \text{UFD}}$$

**反方向都不成立**[▶ 18:00](https://youtu.be/Wt2RWtVkL4I?t=1080)「你們應該能舉反例。」
- **UFD 但不是 PID**：$\mathbb{Z}[x]$。$\langle2,x\rangle$（常數項偶數的多項式）是理想但**不是主理想**。
- **PID 但不是 ED**：「就是**很醜**。我給你們一個連結，有興趣再看。我不期望你們重現——老實說，這**有點超過我們目前的程度**。Gallian 也沒嘗試，只引了一位 40 年代末的作者。」

> **定理**[▶ 19:30](https://youtu.be/Wt2RWtVkL4I?t=1170)　$D$ 是 UFD ⇒ $D[x]$ 是 UFD。（$\mathbb{Z}[x]$ 是 UFD 是它的特例。）「我給的證明跟 Gallian 一樣多。」

## 5. Eisenstein 判別法的證明

[▶ 20:00](https://youtu.be/Wt2RWtVkL4I?t=1200)「最後，**如承諾的**，Eisenstein 判別法的證明。Gallian 歸功於 **Richard Singer**。」

條件：$p\nmid a_n$；$p\mid a_{n-1},\dots,a_0$；$p^2\nmid a_0$。

【口頭】[▶ 21:00](https://youtu.be/Wt2RWtVkL4I?t=1260)「我看過的證明**都是反證法**。我其實很好奇有沒有**構造性**的證明，還沒去問可能知道的人。」

**證明**（反證）
1. 設 $f$ 在 $\mathbb{Q}$ 上可約 ⇒（講義 Thm 4.6.11）在 $\mathbb{Z}$ 上可約：$f = gh$，$\deg g,\deg h<n$。
2. **模 $p$**[▶ 21:30](https://youtu.be/Wt2RWtVkL4I?t=1290)：除了領導係數全是 0：
$$\bar a_nx^n = \bar f = \bar g\,\bar h.$$
   「**很棒**。」（「我該把『約化同態』出成作業——還來得及。」）
3. $\mathbb{Z}_p[x]$ 是 UFD（$\mathbb{Z}_p$ 是體），$x$ 不可約。$\bar a_nx^n = \bar a_n\cdot x\cdot x\cdots x$ ⇒ $x$ 必須**同時**整除 $\bar g$ 和 $\bar h$ [▶ 22:30](https://youtu.be/Wt2RWtVkL4I?t=1350)。
   - 「這裡有個**小缺口**，但有理由 $x$ 必須整除兩個。」
4. 因式定理：$\bar g(0) = \bar h(0) = 0$，即 $p\mid g(0)$、$p\mid h(0)$。
5. $a_0 = f(0) = g(0)h(0)$ ⇒ $p^2\mid a_0$。**矛盾**。$\blacksquare$

> 📘 補那個缺口：由唯一分解，$\bar g = cx^k$、$\bar h = c'x^{n-k}$。若 $k = 0$，則 $\deg\bar h = n$，但 $\deg\bar h\le\deg h<n$，矛盾；同理 $k\neq n$。所以 $0<k<n$，兩邊都有因數 $x$。

【口頭】[▶ 23:30](https://youtu.be/Wt2RWtVkL4I?t=1410)「這比 Gallian 前面那個反證法**好懂多了**，我覺得。」

## 6. ℤ[√−5] 不是 UFD

[▶ 23:30](https://youtu.be/Wt2RWtVkL4I?t=1410)
- $\mathbb{Z}[\sqrt{-5}]$ 的單位**只有 $\pm1$**（$a^2+5b^2 = 1$）。對比高斯整數有 $\pm1,\pm i$。所以判斷相伴很容易：**不是彼此 $\pm$ 就不相伴**。
- $46 = 2\cdot23 = (1+3\sqrt{-5})(1-3\sqrt{-5})$。四個都不可約（講義用範數證），兩組互不相伴 ⇒ **不是 UFD**。

【口頭】[▶ 24:30](https://youtu.be/Wt2RWtVkL4I?t=1470)「下次考試**可能**有『舉一個不是 UFD 的例子』——這幾乎是**首選**。對比：$\mathbb{Z}[i]$ 是 UFD，因為它是 ED，ED ⇒ PID ⇒ UFD——今天證的。」

「好，我們終於到 lecture 29 的結尾了。」

## 7. 作業：x⁴+1 在 ℝ 上的分解

【Q&A】[▶ 25:30](https://youtu.be/Wt2RWtVkL4I?t=1530)（學生：「我也沒聰明到能回答。」老師：「我也沒有。」）學生問 Ch.17 #29（$x^4+1$）。

【口頭】[▶ 27:00](https://youtu.be/Wt2RWtVkL4I?t=1620)「我現在**不該**貿然做這題，得想一下——據傳這題有點**猛獸級**。但我可以告訴你們一些。」

（老師先算 $i$ 的四次方根 $e^{i\pi/8}$，然後 [▶ 29:00](https://youtu.be/Wt2RWtVkL4I?t=1740)：「喔，我是白痴，要解的是 $x^4 = -1$。我腦子在想別題的後半——我**無法解釋**我剛剛為什麼寫那些，真的很離譜。」）

**提示**
- **主 $n$ 次方根**[▶ 30:00](https://youtu.be/Wt2RWtVkL4I?t=1800)：$z^{1/n} = |z|^{1/n}e^{i\arg(z)/n}$，它解 $w^n = z$（不唯一，但是一個解）。
- $-1 = e^{i\pi}$ ⇒ 一個解是
$$e^{i\pi/4} = \cos\tfrac\pi4+i\sin\tfrac\pi4 = \tfrac{\sqrt2}2+i\tfrac{\sqrt2}2.$$
- **其他的解**[▶ 31:00](https://youtu.be/Wt2RWtVkL4I?t=1860)：乘上生成 4 次單位根的 $i$：$e^{i\pi/4},\ ie^{i\pi/4},\ i^2e^{i\pi/4},\ i^3e^{i\pi/4}$。
- 由因式定理分解，**把共軛的根配對**（實係數多項式必須如此）[▶ 32:00](https://youtu.be/Wt2RWtVkL4I?t=1920)。
- 【口頭】「任何實係數多項式都會分解成一次的（可重複）和不可約二次的（可有次方）——**沒有不可約的實係數四次式**。它會拆開，只是不漂亮。」

【口頭】[▶ 33:30](https://youtu.be/Wt2RWtVkL4I?t=2010)「乘開……$i$ 消掉……交叉項也消掉了？我說服你們了嗎？……我覺得有個交叉項在那裡，這讓我不安。」「你們乘開會得到**兩個不可約二次式**相乘是 $x^4+1$。其實只要找到一個，**長除法**就得到另一個。一般來說分解多項式是件難事。」

> 💬 筆記補充：交叉項**沒有**完全消掉：
> $$x^4+1 = (x^2-\sqrt2x+1)(x^2+\sqrt2x+1).$$
> 在 $\mathbb{R}$ 上可約；在 $\mathbb{Q}$ 上不可約（作業要證的部分）。

## 8. 作業：Eisenstein 與公因數

[▶ 35:00](https://youtu.be/Wt2RWtVkL4I?t=2100)（p.308 #10；「出這題主要是因為它在討論那章很顯眼，我覺得該做出來更懂 Gallian 在說什麼——我沒意識到有多麻煩。」）

- 前幾小題直接用 Eisenstein：例如 $p = 3$，$9\nmid6$ ⇒ 不可約 [▶ 36:30](https://youtu.be/Wt2RWtVkL4I?t=2190)。
- 有一小題的係數都有公因數 14（$14x^5$、$35\cdots$、$63\cdots$，老師算得很掙扎：「我腦袋……」）：$f = 14g$。
  - 「如果要用 Eisenstein，這**非常受限**：唯一的希望是 3。但這是本友善的書，可行。」⇒ $g$ 不可約。
- **連到 $f$**[▶ 39:00](https://youtu.be/Wt2RWtVkL4I?t=2340)：設 $f = f_1f_2$ 可約，則 $14g = f_1f_2$，除以 14：$g = \frac1{14}f_1f_2$ 是 $g$ 的分解（在 $\mathbb{Q}$ 上，乘非零常數不影響）。但 $g$ 不可約，矛盾。

> 📘 注意：在 $\mathbb{Z}$ 上 $f = 14g$ 本身就是可約的（14 不是單位）；這裡說的是**在 $\mathbb{Q}$ 上**不可約。

## 9. 作業：ℤₚ[x]/⟨f⟩ 是 pⁿ 元體

[▶ 40:30](https://youtu.be/Wt2RWtVkL4I?t=2430)（Ch.17 #12）

> **題目**　$f\in\mathbb{Z}_p[x]$ 不可約，$\deg f = n$。證明 $\mathbb{Z}_p[x]/\langle f\rangle$ 是 $p^n$ 個元素的體。

【口頭】[▶ 42:00](https://youtu.be/Wt2RWtVkL4I?t=2520)「我們現在證過很多東西，有很多玩具可以玩。這是第 17 章的題，用第 17 章的精神。」

**是體**[▶ 42:30](https://youtu.be/Wt2RWtVkL4I?t=2550)：

**有 $p^n$ 個元素**[▶ 44:00](https://youtu.be/Wt2RWtVkL4I?t=2640)：「這大概就是一個血淋淋的計算。」

$$x^n\equiv-\frac{a_{n-1}}{a_n}x^{n-1}-\cdots-\frac{a_0}{a_n}.$$
- 為什麼合法 [▶ 48:00](https://youtu.be/Wt2RWtVkL4I?t=2880)：「把這個叫**小精靈**、那個叫**鬼**——小精靈減鬼，乘 $a_n$，就是 $f$，在理想裡。所以它們代表同一個陪集。」
- 任何代表元裡 $x^n$ 以上的項，都能**一直往下化**，直到次數 $<n$ [▶ 52:00](https://youtu.be/Wt2RWtVkL4I?t=3120)。

## 10. 一頁速查表

### 10.1 層級

$$\text{ED}\ ⇒\ \text{PID}\ ⇒\ \text{UFD}\ ⇒\ \text{整環}$$

| 反方向 | 反例 |
|---|---|
| UFD ⇏ PID | $\mathbb{Z}[x]$：$\langle2,x\rangle$ 不是主理想 |
| PID ⇏ ED | 有，但很醜（不要求） |
| 整環 ⇏ UFD | $\mathbb{Z}[\sqrt{-5}]$：$46 = 2\cdot23 = (1+3\sqrt{-5})(1-3\sqrt{-5})$ |

### 10.2 證明

| 定理 | 關鍵一步 |
|---|---|
| ACC（PID） | $\bigcup I_k = \langle d\rangle$，$d$ 在某個 $I_m$ |
| PID ⇒ UFD | 不斷分解 ⇒ 理想鏈嚴格遞增 ⇒ ACC 讓它停；唯一性：不可約 = 質元，消去，歸納 |
| ED ⇒ PID | 範數最小的元素生成 |
| Eisenstein | 模 $p$：$\bar a_nx^n = \bar g\bar h$ ⇒ $p\mid g(0),h(0)$ ⇒ $p^2\mid a_0$ |
| $\mathbb{Z}_p[x]/\langle f\rangle$ 有 $p^n$ 元 | $x^n$ 可以用低次項取代 |

### 10.3 術語

| 中文 | English |
|---|---|
| 升鏈條件 | ascending chain condition (ACC) |
| 主 $n$ 次方根 | principal $n$-th root |
| 單位根 | root of unity |
| 理想數 | ideal numbers |

## 附：本集一句話總結

> **PID 裡嚴格遞增的理想鏈一定會停（Noether 的升鏈條件），所以不斷分解一定停在不可約元，再加上 PID 中不可約 = 質元就得到唯一分解：PID ⇒ UFD，而 ED ⇒ PID 的證明就是取範數最小的元素——於是 ED ⇒ PID ⇒ UFD，反向都有反例（$\mathbb{Z}[x]$、$\mathbb{Z}[\sqrt{-5}]$）；Eisenstein 的證明則是模 $p$ 後 $\bar a_nx^n = \bar g\bar h$ 逼出 $p^2\mid a_0$；而不可約的 $n$ 次 $f$ 讓 $\mathbb{Z}_p[x]/\langle f\rangle$ 成為 $p^n$ 元體。**
