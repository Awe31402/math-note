# 第 46 集 · 答疑課：PID ⇒ UFD、Eisenstein 的證明、作業 [▶ 影片](https://www.youtube.com/watch?v=Wt2RWtVkL4I&list=PLBY4G2o7DhF0JCgapYKrqibGaJuvV4Gkb)

## 本集概要

前半把上一講沒講完的證明講完（投影講義），後半回答作業問題：
- **升鏈條件 (ACC)**：PID 中嚴格遞增的理想鏈一定有限（Emmy Noether 的想法）。
- **PID ⇒ UFD**（三步證明）；**ED ⇒ PID**；所以 **ED ⇒ PID ⇒ UFD**，反向都不成立（$\mathbb{Z}[x]$ 是 UFD 但不是 PID）。
- $D$ 是 UFD $\Rightarrow D[x]$ 是 UFD。
- **Eisenstein 判別法的證明**（Gallian 歸功於 Richard Singer）。
- $\mathbb{Z}[\sqrt{-5}]$ 不是 UFD——考試的標準反例。
- 作業：$x^4+1$ 在 $\mathbb{R}$ 上的分解；用 Eisenstein 處理有公因數的多項式；**$\mathbb{Z}_p[x]/\langle f\rangle$ 是 $p^n$ 元體**。

## 筆記

### 1. 回顧：Lamé、Kummer、Dedekind [▶ 00:30](https://youtu.be/Wt2RWtVkL4I?t=30)

Lamé 假設某類代數整數有唯一分解，其實沒有。Kummer 知道這件事；Dedekind 把「理想數」嚴格化。結論是：這些環**元素**層次沒有唯一分解，但**理想**層次有。不過 Lamé 的論證救不回來；Fermat 最後定理很多情形用 Dedekind 的技術證了，但不是全部，直到近年才完全解決 [▶ 01:30](https://youtu.be/Wt2RWtVkL4I?t=90)。

**UFD 的定義**：每個元素都能寫成不可約元的乘積；若 $x = x_1\cdots x_n = y_1\cdots y_m$ 都是不可約分解，則 $n = m$，且重新排序後 $x_i$、$y_i$ 相伴 [▶ 02:00](https://youtu.be/Wt2RWtVkL4I?t=120)。

### 2. 升鏈條件 [▶ 02:30](https://youtu.be/Wt2RWtVkL4I?t=150)

> **引理（PID 的升鏈條件 ascending chain condition）**　PID 中，嚴格遞增的理想鏈 $I_1\subsetneq I_2\subsetneq\cdots$ 一定是有限長的。

- 這種想法由 **Emmy Noether** 開創，她把抽象代數帶到另一個層次；20 世紀初在德國哥廷根（「在希特勒毀掉一切之前」），後來短暫在 Bryn Mawr 學院，不幸早逝。現代環論很多出自她和她的學生 [▶ 03:00](https://youtu.be/Wt2RWtVkL4I?t=180)。

**證明** [▶ 04:00](https://youtu.be/Wt2RWtVkL4I?t=240)
- 令 $I = \bigcup I_k$。它是理想（差和吸收都檢查得過，要一點集合論）。
- PID：$I = \langle d\rangle$。$d\in I$，所以 $d\in I_m$ 對某個 $m$。
- 則 $I_k\subseteq I = \langle d\rangle\subseteq I_m$ 對所有 $k$。鏈在 $I_m$ 停住。$\blacksquare$

「這和唯一分解有什麼關係？一點也不明顯。」[▶ 06:00](https://youtu.be/Wt2RWtVkL4I?t=360)

### 3. PID ⇒ UFD [▶ 07:00](https://youtu.be/Wt2RWtVkL4I?t=420)

> **定理（Gallian Thm 18.3）**　每個 PID 都是 UFD。

老師說這是整門課最有趣的定理之一。取非零、非單位的 $a_0$。

**第一步：$a_0$ 至少有一個不可約因數** [▶ 08:00](https://youtu.be/Wt2RWtVkL4I?t=480)
- $a_0$ 不可約就結束。否則 $a_0 = a_1b_1$，$a_1$ 非單位、$b_1\neq0$。$a_1$ 不可約就結束，否則 $a_1 = a_2b_2$……
- 得到 $\langle a_0\rangle\subsetneq\langle a_1\rangle\subsetneq\langle a_2\rangle\subsetneq\cdots$（嚴格，因為 $b_i$ 不是單位）。
- 升鏈條件：鏈會停，停的地方 $a_k$ 是不可約的 [▶ 09:30](https://youtu.be/Wt2RWtVkL4I?t=570)。

**第二步：$a_0$ 是不可約元的乘積** [▶ 10:00](https://youtu.be/Wt2RWtVkL4I?t=600)
- 由第一步，$a_0 = p_1c_1$，$p_1$ 不可約。$c_1$ 不可約就結束；否則 $c_1 = p_2c_2$……
- $\langle a_0\rangle\subsetneq\langle c_1\rangle\subsetneq\langle c_2\rangle\subsetneq\cdots$，又一條升鏈，會停。所以 $a_0 = p_1p_2\cdots p_t$ [▶ 11:00](https://youtu.be/Wt2RWtVkL4I?t=660)。

**第三步：唯一性**（對 $t$ 歸納）[▶ 11:30](https://youtu.be/Wt2RWtVkL4I?t=690)
- $a_0 = p_1\cdots p_t = q_1\cdots q_s$。
- $t = 1$：$p_1$ 不可約，所以 $s = 1$ 且 $p_1 = q_1$。
- 歸納步驟：$p_1\mid q_1\cdots q_s$。PID 中不可約 = 質，所以 $p_1\mid q_j$（某個 $j$；推廣的 Euclid 引理，是沒指定的習題）[▶ 12:30](https://youtu.be/Wt2RWtVkL4I?t=750)。$q_j$ 不可約，所以 $q_j = u_jp_1$，$u_j$ 是單位。
- 代入、消去 $p_1$，得到 $t-1$ 個不可約元的兩個分解，由歸納假設唯一。$\blacksquare$
- 學生指出投影上某處應該放一個 1 [▶ 13:30](https://youtu.be/Wt2RWtVkL4I?t=810)。

**和整數的質因數分解證明非常像** [▶ 14:00](https://youtu.be/Wt2RWtVkL4I?t=840)。

**推論**：$F$ 是體 $\Rightarrow F[x]$ 是 PID（之前證過）$\Rightarrow$ UFD [▶ 14:30](https://youtu.be/Wt2RWtVkL4I?t=870)。

### 4. ED ⇒ PID [▶ 15:00](https://youtu.be/Wt2RWtVkL4I?t=900)

> **定理（Gallian Thm 18.4）**　每個 Euclid 整環都是 PID。

證明和「$F[x]$ 是 PID」完全一樣，只是把次數換成範數 [▶ 17:00](https://youtu.be/Wt2RWtVkL4I?t=1020)：
- 非零理想 $I$，看 $\{N(x)\mid x\in I,\ x\neq0\}$，良序原理取最小的 $x_0$。
- 任取 $z\in I$，除法算則 $z = qx_0+r$；$r = z-qx_0\in I$，若非零則範數比 $x_0$ 小，矛盾。所以 $r = 0$，$I = \langle x_0\rangle$。

**連鎖** [▶ 17:30](https://youtu.be/Wt2RWtVkL4I?t=1050)
$$\text{ED}\Rightarrow\text{PID}\Rightarrow\text{UFD}.$$
**反向都不成立**，要能舉反例 [▶ 18:00](https://youtu.be/Wt2RWtVkL4I?t=1080)：
- **UFD 但不是 PID**：$\mathbb{Z}[x]$。$\langle2,x\rangle$（常數項為偶數的多項式）不是主理想。
- **PID 但不是 ED**：例子很醜（老師給連結，Gallian 也只引用 1940 年代末的文獻），「有點超出我們目前的程度」。

> **定理（Gallian Thm 18.6）**　$D$ 是 UFD $\Rightarrow D[x]$ 是 UFD。（$\mathbb{Z}[x]$ 是 UFD 是特例。證明和 Gallian 一樣多——也就是沒有。）[▶ 19:30](https://youtu.be/Wt2RWtVkL4I?t=1170)

### 5. Eisenstein 判別法的證明 [▶ 20:00](https://youtu.be/Wt2RWtVkL4I?t=1200)

（Gallian 歸功於 Richard Singer。老師說他看過的都是反證法，好奇有沒有構造性證明。）

設 $f = a_nx^n+\cdots+a_0$ 滿足 Eisenstein 條件，但在 $\mathbb{Q}$ 上可約。
- 由「$\mathbb{Q}$ 上可約 $\Rightarrow\mathbb{Z}$ 上可約」：$f = gh$，$g,h\in\mathbb{Z}[x]$，次數都小於 $n$ [▶ 21:00](https://youtu.be/Wt2RWtVkL4I?t=1260)。
- **模 $p$**：$p$ 整除除了首項外的所有係數，所以 $\bar f = \bar a_nx^n$。而 $\bar f = \bar g\bar h$。
- $\mathbb{Z}_p[x]$ 是 UFD（$\mathbb{Z}_p$ 是體），$x$ 是不可約元。$\bar a_nx^n$ 的分解只能是 $x$ 的次方乘常數，所以 $x$ 同時整除 $\bar g$ 和 $\bar h$（「這裡有個小缺口」：兩邊次數都小於 $n$，所以 $x$ 不能全分到一邊）[▶ 22:30](https://youtu.be/Wt2RWtVkL4I?t=1350)。
- 由因式定理，$\bar g(0) = \bar h(0) = 0$，即 $p\mid g(0)$、$p\mid h(0)$。
- 所以 $a_0 = f(0) = g(0)h(0)$ 被 $p^2$ 整除，矛盾。$\blacksquare$

「比 Gallian 前面那個反證法好懂多了。」

### 6. $\mathbb{Z}[\sqrt{-5}]$ 不是 UFD [▶ 23:30](https://youtu.be/Wt2RWtVkL4I?t=1410)

- $\mathbb{Z}[\sqrt{-5}]$ 的單位只有 $\pm1$（$a^2+5b^2 = 1$），所以判斷相伴很容易：不是彼此 $\pm$ 就不相伴。（對比 Gaussian 整數有 $\pm1,\pm i$。）
- $46 = 2\cdot23 = (1+3\sqrt{-5})(1-3\sqrt{-5})$，四個都是不可約元（講義用範數證明），且兩組互不相伴。
- **考試可能問「舉一個不是 UFD 的例子」，這就是首選** [▶ 24:30](https://youtu.be/Wt2RWtVkL4I?t=1470)。
- 對比：$\mathbb{Z}[i]$ 是 ED，所以是 PID、是 UFD。

### 7. 作業：$x^4+1$（Ch.17 #29）[▶ 26:30](https://youtu.be/Wt2RWtVkL4I?t=1590)

老師說這題據說很難，現在不敢貿然做，但給了一些提示。（老師一開始在算 $i$ 的四次方根，後來發現是在想別的題的後半，「我無法解釋我剛剛為什麼寫那些」[▶ 29:00](https://youtu.be/Wt2RWtVkL4I?t=1740)。）
- $x^4 = -1$ 的一個解：**主四次方根** $e^{i\pi/4} = \frac{\sqrt2}2+i\frac{\sqrt2}2$。（主 $n$ 次方根：$|z|^{1/n}e^{i\arg z/n}$。）
- 其餘的根：乘上 $i$ 的次方（生成單位根的那個）：$e^{i\pi/4},\ ie^{i\pi/4},\ i^2e^{i\pi/4},\ i^3e^{i\pi/4}$ [▶ 31:00](https://youtu.be/Wt2RWtVkL4I?t=1860)。
- 由因式定理，把共軛的根配對，得到兩個實係數二次因式。實係數多項式一定能分解成一次和不可約二次的乘積——不存在不可約的實係數四次式 [▶ 32:00](https://youtu.be/Wt2RWtVkL4I?t=1920)。

> 💬 老師對「交叉項會不會消掉」不確定。補充（非課堂內容）：
> $$x^4+1 = (x^2+\sqrt2x+1)(x^2-\sqrt2x+1),$$
> 交叉項**沒有**完全消掉，留下 $\pm\sqrt2x$。這在 $\mathbb{R}$ 上可約；在 $\mathbb{Q}$ 上不可約（作業要證的部分）。

### 8. 作業：Eisenstein 與公因數（p.308）[▶ 35:30](https://youtu.be/Wt2RWtVkL4I?t=2130)

- 前幾題直接用 Eisenstein（例如 $p = 3$，$9\nmid6$）[▶ 36:30](https://youtu.be/Wt2RWtVkL4I?t=2190)。
- 有一題 $f(x) = 14g(x)$，所有係數都有公因數 14，Eisenstein 只能用 $p = 3$ 套在 $g$ 上。
- 若 $f = f_1f_2$ 可約，則 $g = \frac1{14}f_1f_2$ 也可約（在 $\mathbb{Q}$ 上，乘非零常數不影響）。但 $g$ 不可約，矛盾 [▶ 39:00](https://youtu.be/Wt2RWtVkL4I?t=2340)。

### 9. 作業：$\mathbb{Z}_p[x]/\langle f\rangle$ 是 $p^n$ 元體（Ch.17 #12）[▶ 40:30](https://youtu.be/Wt2RWtVkL4I?t=2430)

$f\in\mathbb{Z}_p[x]$ 不可約，$\deg f = n$。

**是體** [▶ 42:30](https://youtu.be/Wt2RWtVkL4I?t=2550)：$f$ 不可約 $\Rightarrow\langle f\rangle$ 極大（Thm 17.5）$\Rightarrow$ 商環是體（Gallian p.301 Cor 1）。

**有 $p^n$ 個元素** [▶ 44:00](https://youtu.be/Wt2RWtVkL4I?t=2640)：
- $f = a_nx^n+\cdots+a_0$，$a_n\neq0$。在商環中可以**解出 $x^n$**：
$$x^n\equiv-\frac{a_{n-1}}{a_n}x^{n-1}-\cdots-\frac{a_0}{a_n}\pmod f.$$
  （「直覺上 $f\equiv0$，所以把 $x^n$ 解出來。」）
- 任何代表元裡 $x^n$ 以上的項，都能一直往下化，直到次數 $<n$ [▶ 52:00](https://youtu.be/Wt2RWtVkL4I?t=3120)。
- 所以代表元是 $b_0+b_1x+\cdots+b_{n-1}x^{n-1}$，$n$ 個係數各有 $p$ 種，共 $p^n$ 個。

老師說他一直找不到好的記號把化簡過程寫得令人信服（「我暫時叫它小精靈和鬼」）[▶ 48:00](https://youtu.be/Wt2RWtVkL4I?t=2880)。這題是上一題（造 8 元體）的「超級版本」。

**造 27 元體** [▶ 53:30](https://youtu.be/Wt2RWtVkL4I?t=3210)：需要 $\mathbb{Z}_3$ 上的不可約**三次**式。老師隨口猜了一個（字幕：$x^3+2x^2+2$）。

> 💬 補充：$x^3+2x^2+2$ 在 $\mathbb{Z}_3$ 上有根 $x = 2$（$8+8+2 = 18\equiv0$），所以**可約**，不能用。可用的例子：$x^3+2x+1$（$f(0) = 1$、$f(1) = 4\equiv1$、$f(2) = 13\equiv1$，三次且無根，所以不可約）。另外，Eisenstein 是 $\mathbb{Q}$ 上的判別法，不能直接用來判斷 $\mathbb{Z}_3$ 上的不可約性。

**結尾** [▶ 55:00](https://youtu.be/Wt2RWtVkL4I?t=3300)：前半段鏡頭沒拍到投影畫面（「至少你們現在看得到了」）；老師說「某種意義上我講的話比畫的重要」。
