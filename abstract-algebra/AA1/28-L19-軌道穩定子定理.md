## 1. 再看幾個群作用

### 1.1 右邊的作用：軌道是左陪集

[▶ 01:00](https://youtu.be/KRcOMp07dp8?t=60) $H\le G$。上次定義 $h\star x = hx$；另一個作用：
$$h\cdot x = xh^{-1}.$$

**驗證公理**[▶ 01:30](https://youtu.be/KRcOMp07dp8?t=90)：
- $e\cdot x = xe^{-1} = x$ ✓
- $(ab)\cdot x = x(ab)^{-1} = xb^{-1}a^{-1} = (b\cdot x)a^{-1} = a\cdot(b\cdot x)$ ✓（**襪子-鞋子**）

【口頭】[▶ 02:30](https://youtu.be/KRcOMp07dp8?t=150)「它有點左撇子……我得花點時間才能進入這種思考。」

**軌道**[▶ 03:00](https://youtu.be/KRcOMp07dp8?t=180)：
$$\mathcal O(x) = \{xh^{-1} : h\in H\} = \{xk : k\in H\} = xH.$$
「在群裡遍歷反元素，等於遍歷所有元素——只是重新編號。」【課堂討論】這是什麼？**左陪集**。「上次那個作用得到右陪集；這個『反著看』的作用得到左陪集。」

**複習**[▶ 04:00](https://youtu.be/KRcOMp07dp8?t=240)：$G$ 作用在 $S$ 上，
$$\mathcal O(x) = \{g\star x : g\in G\}\subseteq S,\qquad G_x = \{g\in G : g\star x = x\}\le G.$$
（Fraleigh 把 $S$ 叫做 **$G$-集合（$G$-set）**，「很有用的術語」；也把穩定子叫 isotropy subgroup。）

### 1.2 純量乘法：軌道是去掉原點的直線

[▶ 05:30](https://youtu.be/KRcOMp07dp8?t=330) $V$ 是 $F$ 上的向量空間，$F^\times$ 用純量乘法作用：$c\star\mathbf v = c\mathbf v$。

【課堂討論】
- **零向量的軌道**[▶ 06:30](https://youtu.be/KRcOMp07dp8?t=390)：零向量的純量倍還是零向量，$\mathcal O(\mathbf 0) = \{\mathbf 0\}$。
- **非零向量的軌道**[▶ 07:00](https://youtu.be/KRcOMp07dp8?t=420)：所有非零純量倍。學生：「差不多是一條直線。」老師：「對：方向向量為 $\mathbf v$、過原點的直線，**去掉原點**。」

**圖像**[▶ 08:00](https://youtu.be/KRcOMp07dp8?t=480)（二維）：原點自己一個軌道；其他每條過原點的直線（去掉原點）是一個軌道。
- 軌道**互不相交**；
- 每個點都在某個軌道裡（「連原點都是自己的軌道」）。

### 1.3 共軛作用：軌道是共軛類、穩定子是中心化子

[▶ 09:00](https://youtu.be/KRcOMp07dp8?t=540) 取 $S = G$，**$G$ 用共軛作用在自己身上**：
$$g\star x = gxg^{-1}.$$
「可以驗證它是群作用，講義裡有。」

> 📘 講義 Ex 3.7.1：$e\star x = x$；$(ab)\star x = (ab)x(ab)^{-1} = a(bxb^{-1})a^{-1} = a\star(b\star x)$。

**軌道**[▶ 09:30](https://youtu.be/KRcOMp07dp8?t=570)：
$$\mathcal O(x) = \{gxg^{-1} : g\in G\},$$
叫做 $x$ 的**共軛類（conjugacy class）**——所有跟 $x$ 共軛的群元素。

**穩定子**[▶ 10:00](https://youtu.be/KRcOMp07dp8?t=600)：
$$G_x = \{g : gxg^{-1} = x\}.$$
【課堂討論】[▶ 10:30](https://youtu.be/KRcOMp07dp8?t=630)「把條件改寫成我們熟悉的東西。」$gxg^{-1} = x\iff gx = xg$：**跟 $x$ 交換的元素**——這就是**中心化子** $C(x)$。

**固定點集**[▶ 11:30](https://youtu.be/KRcOMp07dp8?t=690)：
$$S^G = \{x : gxg^{-1} = x\ \forall g\} = \{x : gx = xg\ \forall g\} = Z(G),$$
**中心**。

【口頭】[▶ 12:00](https://youtu.be/KRcOMp07dp8?t=720)「上次我講過這個例子嗎？我不記得了。有時候就像你記得一個夢，不確定它是不是真的發生過。」

| 共軛作用 | 是什麼 |
|---|---|
| 軌道 $\mathcal O(x)$ | 共軛類 $x^G$ |
| 穩定子 $G_x$ | 中心化子 $C(x)$ |
| 固定點集 $S^G$ | 中心 $Z(G)$ |

## 2. 定理：穩定子是子群

[▶ 12:30](https://youtu.be/KRcOMp07dp8?t=750)「我提過但還沒證。」

> **定理**（講義 Thm 3.6.11）　$G$ 作用在 $S$ 上，$x\in S$。則 $G_x\le G$。

**證明**（兩步子群判別法——「我今天不覺得特別聰明」）

**非空**[▶ 14:00](https://youtu.be/KRcOMp07dp8?t=840)：由群作用的定義 $e\star x = x$，所以 $e\in G_x$。

**乘法封閉**[▶ 14:30](https://youtu.be/KRcOMp07dp8?t=870)：設 $a,b\in G_x$。
$$(ab)\star x = a\star(b\star x) = a\star x = x.$$
所以 $ab\in G_x$。「我大概該把這出成作業的。好吧，我已經打好了。」

**反元素封閉**[▶ 16:00](https://youtu.be/KRcOMp07dp8?t=960)：設 $a\in G_x$。
$$x = e\star x = (a^{-1}a)\star x = a^{-1}\star(a\star x) = a^{-1}\star x.$$
「砰。」所以 $a^{-1}$ 也固定 $x$，$a^{-1}\in G_x$。$\blacksquare$

## 3. 定理：軌道分割集合

[▶ 17:30](https://youtu.be/KRcOMp07dp8?t=1050)

> **定理**（講義 Thm 3.6.12）　$G$ 作用在 $S$ 上。則軌道**分割** $S$。若 $S$ 有限，
> $$|S| = \sum_i|\mathcal O(x_i)|,$$
> 其中每個軌道挑一個 $x_i$（對**相異**的軌道求和）。

**策略**[▶ 19:00](https://youtu.be/KRcOMp07dp8?t=1140)：證明群作用自然地定義了 $S$ 上的一個**等價關係**，而它的等價類恰好是軌道。

**定義**[▶ 19:30](https://youtu.be/KRcOMp07dp8?t=1170)：
$$x\sim y\iff\text{存在 }g\in G\text{ 使 }y = g\star x.$$
「$x$ 和 $y$ 相關，恰好當你能用群作用把 $x$ 移到 $y$。」

**(1) 反身**[▶ 20:00](https://youtu.be/KRcOMp07dp8?t=1200)：$x = e\star x$，所以 $x\sim x$。

**(2) 對稱**[▶ 20:30](https://youtu.be/KRcOMp07dp8?t=1230)：設 $x\sim y$，$y = g\star x$。【課堂討論】「怎麼解出 $x$？」**用 $g^{-1}$ 作用**：
$$g^{-1}\star y = g^{-1}\star(g\star x) = (g^{-1}g)\star x = e\star x = x.$$
所以 $y\sim x$。

**(3) 遞移**[▶ 22:00](https://youtu.be/KRcOMp07dp8?t=1320)（「真該出成作業」）：$y = h\star x$、$z = g\star y$。
$$z = g\star(h\star x) = (gh)\star x,$$
所以 $x\sim z$。

**等價類 = 軌道**[▶ 23:00](https://youtu.be/KRcOMp07dp8?t=1380)：
$$\{y : x\sim y\} = \{g\star x : g\in G\} = \mathcal O(x).$$
等價關係分割集合，所以**軌道分割 $S$**。

**計數**[▶ 24:00](https://youtu.be/KRcOMp07dp8?t=1440)：軌道互不相交，所以 $|S|$ 就是一個一個軌道數、加起來。$\blacksquare$

## 4. 定理：軌道 ↔ 穩定子的陪集

[▶ 24:30](https://youtu.be/KRcOMp07dp8?t=1470)

> **定理**（講義 Thm 3.6.13）　$G$ 作用在 $S$ 上，$x\in S$。則 $\mathcal O(x)$ 的元素與 $G_x$ 在 $G$ 中的**左陪集**一一對應。所以
> $$|\mathcal O(x)| = [G:G_x].$$

【口頭】[▶ 26:00](https://youtu.be/KRcOMp07dp8?t=1560)「$G/G_x$ 不一定是商群——我沒假設穩定子是正規子群，一般來說它可能不是。但我們還是可以看陪集的集合，而且陪集有好性質：**即使不正規，陪集的個數也是 $|G|/|G_x|$**——Lagrange 定理的一部分或推論，看你怎麼看。」

**定義映射**[▶ 26:30](https://youtu.be/KRcOMp07dp8?t=1590)「有點狡猾」：
$$f:\mathcal O(x)\to G/G_x,\qquad y = g\star x\ \mapsto\ f(y) = gG_x.$$
「你說 $f(y)$，公式裡卻沒有 $y$——定義很間接。」

**映入**：顯然送到 $G_x$ 的某個陪集。

**良定義**[▶ 28:00](https://youtu.be/KRcOMp07dp8?t=1680)：同一個 $y$ 可能有不同的 $g$。設 $y = h\star x = g\star x$。用 $h^{-1}$ 作用：
$$(h^{-1}g)\star x = x\ \Rightarrow\ h^{-1}g\in G_x\ \Rightarrow\ hG_x = gG_x.$$
所以 $f$ 單值。

（老師在這裡改用投影片：「這個證明不複雜，但字很多。」[▶ 30:00](https://youtu.be/KRcOMp07dp8?t=1800)）

**一對一**[▶ 32:00](https://youtu.be/KRcOMp07dp8?t=1920)：「搞定良定義後，單射比較容易。」$f(y) = f(z)$，$y = h\star x$、$z = g\star x$ ⇒ $hG_x = gG_x$ ⇒ $h^{-1}g\in G_x$ ⇒ $h\star x = g\star x$ ⇒ $y = z$。

**映成**[▶ 32:30](https://youtu.be/KRcOMp07dp8?t=1950)：「有點蠢。」任何陪集 $gG_x$，令 $y = g\star x$，就有 $f(y) = gG_x$。

所以 $f$ 是**雙射**——「不是同構，只是雙射，但**雙射讓我們能數數**」。$|\mathcal O(x)| = |G/G_x| = [G:G_x]$。$\blacksquare$

## 5. 軌道穩定子定理

[▶ 33:00](https://youtu.be/KRcOMp07dp8?t=1980)

> **推論（軌道穩定子定理 Orbit-Stabilizer Theorem）**（講義 Cor 3.6.14）　有限群 $G$ 作用在 $S$ 上。則對每個 $x\in S$，
> $$|G| = |\mathcal O(x)|\cdot|G_x|.$$
> 特別地，**任何軌道的大小都整除 $|G|$**。

（$[G:G_x] = |G|/|G_x|$，再用上一個定理。）

【口頭】[▶ 33:30](https://youtu.be/KRcOMp07dp8?t=2010)「這出乎意料地好用。」「穩定子是子群，它的階整除 $|G|$——不意外，Lagrange 就知道。但**軌道的大小必須整除群的階**，這有點令人驚訝。」

## 6. 例：D₄ 作用在正方形的頂點上

[▶ 34:30](https://youtu.be/KRcOMp07dp8?t=2070)「我真希望把這個打好了。寫這個蠢東西要兩分鐘，其實沒什麼。」

$S = \{v_0,v_1,v_2,v_3\}$（記作 0、1、2、3），$G = D_4$。老師畫了 8 個正方形，表示 $D_4$ 的 8 個元素怎麼移動頂點 [▶ 35:00](https://youtu.be/KRcOMp07dp8?t=2100)：
- 第一列：恆等、轉 $90°$、轉 $180°$、轉 $270°$；
- 第二列：兩個對角線鏡射、兩個（對邊中點）鏡射。

**$v_0$ 的軌道**[▶ 37:00](https://youtu.be/KRcOMp07dp8?t=2220)【課堂討論】：「$v_0$ 會去哪？」「到處都去。」
$$\mathcal O(v_0) = S.$$

> **定義（遞移的 transitive）**[▶ 38:00](https://youtu.be/KRcOMp07dp8?t=2280)　如果某個元素的軌道是整個集合，就說群作用是**遞移的**。

$D_4$ **遞移地**作用在正方形的頂點上。

**$v_0$ 的穩定子**[▶ 38:30](https://youtu.be/KRcOMp07dp8?t=2310)：「什麼讓 0 留在 0？」恆等，以及**通過 $v_0$ 的對角線鏡射**——它交換 $v_1$ 和 $v_3$、固定 $v_0$ 和 $v_2$。用循環記號：
$$G_{v_0} = \{(1),\ (v_1\,v_3)\}.$$

**驗證軌道穩定子定理**[▶ 39:30](https://youtu.be/KRcOMp07dp8?t=2370)：
$$|\mathcal O(v_0)|\cdot|G_{v_0}| = 4\cdot2 = 8 = |D_4|.\ ✓$$

【口頭】[▶ 39:30](https://youtu.be/KRcOMp07dp8?t=2370)「我不覺得這特別有啟發性。所有書都舉這個例子。」

> 📘 講義 Ex 3.6.15 用循環記號列出 $D_4$：旋轉 $(1)$、$(v_0v_1v_2v_3)$、$(v_0v_2)(v_1v_3)$、$(v_0v_3v_2v_1)$；鏡射 $(v_1v_3)$、$(v_0v_2)$、$(v_0v_1)(v_2v_3)$、$(v_0v_3)(v_1v_2)$。$G_{v_1} = \{(1),(v_0v_2)\}$。
>
> 講義 Ex 3.6.16（正方體）：正方體的對稱作用在 6 個面上，是遞移的，所以軌道大小 6；一個面的穩定子是繞那個面中心的 4 個旋轉。所以正方體的（旋轉）對稱群有 $6\cdot4 = 24$ 個元素。

## 7. 例：⟨σ⟩ 作用在 {1,…,n} 上

[▶ 40:00](https://youtu.be/KRcOMp07dp8?t=2400)「最後，回到一個很老的討論。」

**具體例子**：$S = \mathbb{N}_6 = \{1,\dots,6\}$，$\sigma = (1\,2\,3)(5\,6)$，$G = \langle\sigma\rangle = \{\sigma^k : k\in\mathbb{Z}\}\le S_6$。$G$ 自然地作用在 $\{1,\dots,6\}$ 上。

（「$\mathbb{N}_6$ 是我的記號……有些人用手指數到 6——好吧，不是每個人都有六根手指，但我們有些人……抱歉，這堂課轉向了黑暗面。」）

【課堂討論】[▶ 41:30](https://youtu.be/KRcOMp07dp8?t=2490)：
- 1 的軌道：$\sigma$ 把 1 送到 2，平方送到 3，再回到 1。$\mathcal O(1) = \{1,2,3\}$。
- $\mathcal O(5) = \{5,6\}$。
- $\mathcal O(4) = \{4\}$。

$$|\mathcal O(1)|+|\mathcal O(5)|+|\mathcal O(4)| = 3+2+1 = 6 = |S|.$$
「不是巧合：軌道分割 $S$。」

> 📘 講義 Ex 3.7.2 還指出：軌道大小 3、2、1 都整除 $|G| = |\sigma| = \operatorname{lcm}(2,3) = 6$。

**一般**[▶ 43:00](https://youtu.be/KRcOMp07dp8?t=2580)：$\sigma\in S_n$ 有互斥循環分解 $\sigma = \beta_1\beta_2\cdots\beta_t$。若 $i$ 被 $\beta_j$ 移動，則
$$\mathcal O(i) = \{\beta_j\text{ 裡的數字}\}.$$
「互斥循環中，只有 $\beta_j$ 對 $i$ 有作用；作用下去就是在 $\beta_j$ 裡繞圈。」**軌道就是互斥循環裡的數字**，再加上沒出現的數字各自成為單點軌道。

## 8. 推論：共軛類的大小

[▶ 45:30](https://youtu.be/KRcOMp07dp8?t=2730)

> **推論**（講義 Cor 3.7.6）　$G$ 有限，$x\in G$。$x$ 的共軛元素個數等於它的中心化子的指數：
> $$|\{gxg^{-1} : g\in G\}| = [G:C(x)].$$

**證明**[▶ 47:30](https://youtu.be/KRcOMp07dp8?t=2850)：「用那個例子。」共軛作用下，軌道是共軛類，穩定子是中心化子（第 1.3 節）。套軌道穩定子定理：軌道大小 = 穩定子的左陪集個數。$\blacksquare$

> 📘 講義 Def 3.7.7：共軛類記作 $x^G = \{gxg^{-1} : g\in G\}$。所以 $|x^G| = [G:C(x)]$。

## 9. 例：S₄ 的共軛類

[▶ 48:00](https://youtu.be/KRcOMp07dp8?t=2880)「最後讓我給你們看這對我們意味著什麼，然後我就閉嘴。」

$S_4$ 的共軛類按**循環型（cycle type）**分 [▶ 48:30](https://youtu.be/KRcOMp07dp8?t=2910)：

| 代表元 | 循環型 | 個數 |
|---|---|---|
| $(1)$ | 恆等 | 1 |
| $(1\,2)$ | 換位 | 6 |
| $(1\,2\,3)$ | 3-循環 | 8 |
| $(1\,2\,3\,4)$ | 4-循環 | 6 |
| $(1\,2)(3\,4)$ | 兩個互斥換位 | 3 |

【課堂討論】學生一起數出各個個數。

**為什麼同循環型的在同一個共軛類**[▶ 49:30](https://youtu.be/KRcOMp07dp8?t=2970)：「之前那個早期計算（作業）：用 $\sigma$ 共軛時，你**得到同樣的數字，只是順序不同**。例如 $(1\,3\,7)$ 共軛後還是由 1、3、7 組成的循環，只是順序可能不同。」所以**共軛保持循環型**。

**驚人的地方**[▶ 50:00](https://youtu.be/KRcOMp07dp8?t=3000)：
$$1+6+8+6+3 = 24 = 4!.$$
「因為 4 個符號上共有 24 個置換。不同的循環型加起來一定是 24——**共軛類分割群**。」

> 📘 講義 Ex 3.7.4、3.7.5：用 $\sigma$ 共軛 $\alpha$，得到循環型相同的置換。例 $(123)(12)(34)(321) = (14)(23)$；$(12)(1234)(12) = (1342)$。若 $\sigma$ 是 $\alpha$ 自己循環分解的一部分，則 $\sigma\alpha\sigma^{-1} = \alpha$。
>
> 講義 Cor 3.7.8：**某個循環型的置換個數必須整除 $n!$**（因為 $|\sigma^{S_n}| = [S_n:C(\sigma)]$）。講義留給讀者：$S_5$ 的情況 $120 = 1+10+20+30+24+20+15$。

### 10.1 群作用的例子

| 作用 | 軌道 | 穩定子 | 固定點集 |

| $h\star x = hx$（$H\le G$ 作用在 $G$） | 右陪集 $Hx$ | $\{e\}$ | |

### 10.2 定理與證明關鍵一步

| 結果 | 關鍵一步 |
|---|---|
| $G_x\le G$ | $x = (a^{-1}a)\star x = a^{-1}\star(a\star x) = a^{-1}\star x$ |
| 軌道分割 $S$ | $x\sim y\iff y = g\star x$ 是等價關係（對稱性用 $g^{-1}$ 作用） |
| $\lvert S\rvert = \sum\lvert\mathcal O(x_i)\rvert$ | 不相交聯集 |
| $\lvert\mathcal O(x)\rvert = [G:G_x]$ | $g\star x\mapsto gG_x$；良定義：$h\star x = g\star x\Rightarrow h^{-1}g\in G_x$ |
| **軌道穩定子定理** $\lvert G\rvert = \lvert\mathcal O(x)\rvert\lvert G_x\rvert$ | 上一條 + Lagrange |
| $\lvert x^G\rvert = [G:C(x)]$ | 共軛作用 |

### 10.3 $S_4$ 的共軛類

$$24 = 1+6+8+6+3\quad(\text{恆等、換位、3-循環、4-循環、雙換位}).$$
共軛保持循環型；某循環型的個數整除 $n!$。

## 附：本集一句話總結

> **群作用的穩定子是子群，而「能用群元素把 $x$ 移到 $y$」是等價關係，所以軌道分割集合；軌道上的點和穩定子的左陪集一一對應（$g\star x\mapsto gG_x$），得到軌道穩定子定理 $|G| = |\mathcal O(x)||G_x|$——套在共軛作用上，共軛類的大小就是中心化子的指數，例如 $S_4$ 依循環型分成 $1+6+8+6+3 = 24$。**
