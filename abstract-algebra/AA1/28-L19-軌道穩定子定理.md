# 第 28 集 · L19：軌道穩定子定理 [▶ 影片](https://www.youtube.com/watch?v=KRcOMp07dp8&list=PLBY4G2o7DhF0JCgapYKrqibGaJuvV4Gkb)

## 本集概要

- 更多群作用：$h\cdot x = xh^{-1}$（軌道是**左陪集**）；純量乘法（軌道是去掉原點的直線）；**共軛作用** $g\cdot x = gxg^{-1}$（軌道是**共軛類**、穩定子是**中心化子**、固定點是**中心**）。
- **穩定子是子群**。
- **軌道分割集合**：$x\sim y\iff y = gx$ 是等價關係；$|S| = \sum|\text{軌道}|$。
- **軌道和穩定子的左陪集一一對應**，得到**軌道穩定子定理** $|G| = |Gx|\cdot|G_x|$。
- 例：$D_4$ 作用在正方形頂點；循環置換群的軌道就是互斥循環。
- 推論：共軛類的大小 $= [G:C(x)]$；$S_4$ 的共軛類 $1+6+8+6+3 = 24$。

> 📘 講義對應：2018 講義 §3.6 Lecture 16 後半與 §3.7 Lecture 17「conjugacy and the class equation」（p.111–118）。本週預計講 Sylow 定理、有限單群（介紹性質），週三講格定理 (lattice theorem)。

## 筆記

### 1. 另一個作用：右乘反元素 [▶ 01:00](https://youtu.be/KRcOMp07dp8?t=60)

$H\le G$，定義 $h\cdot x = xh^{-1}$。
- $e\cdot x = xe^{-1} = x$ ✓
- $(ab)\cdot x = x(ab)^{-1} = xb^{-1}a^{-1} = a\cdot(b\cdot x)$ ✓（襪子鞋子）[▶ 02:00](https://youtu.be/KRcOMp07dp8?t=120)

**軌道** [▶ 02:30](https://youtu.be/KRcOMp07dp8?t=150)：$\{xh^{-1}\mid h\in H\} = \{xk\mid k\in H\} = xH$。遍歷反元素等於遍歷整個 $H$（重新編號）。所以軌道是**左陪集**。上一講的作用（左乘）給右陪集。

**術語**：Fraleigh 說 $S$ 是一個 **$G$-集合 ($G$-set)** [▶ 04:30](https://youtu.be/KRcOMp07dp8?t=270)。

### 2. 純量乘法的軌道 [▶ 05:30](https://youtu.be/KRcOMp07dp8?t=330)

$F^\times$ 作用在向量空間 $V$ 上：$c\star\mathbf v = c\mathbf v$。
- $\mathbf 0$ 的軌道：$\{\mathbf 0\}$。
- $\mathbf v\neq\mathbf 0$ 的軌道：$\{c\mathbf v\mid c\neq0\}$，就是**過原點、方向為 $\mathbf v$ 的直線，去掉原點** [▶ 07:30](https://youtu.be/KRcOMp07dp8?t=450)。

**圖像** [▶ 08:00](https://youtu.be/KRcOMp07dp8?t=480)：平面上一束過原點的直線（各自挖掉原點），加上原點自己。它們**互不相交**，而且蓋滿整個空間。

### 3. 共軛作用 [▶ 09:00](https://youtu.be/KRcOMp07dp8?t=540)

$G$ 作用在自己身上：$g\star x = gxg^{-1}$。（驗證在講義。）

| | 共軛作用下 |
|---|---|
| 軌道 $\{gxg^{-1}\mid g\in G\}$ | **共軛類 (conjugacy class)** of $x$ |
| 穩定子 $\{g\mid gxg^{-1} = x\} = \{g\mid gx = xg\}$ | **中心化子** $C(x)$ |
| 固定點 $\{x\mid gxg^{-1} = x,\ \forall g\}$ | **中心** $Z(G)$ |

[▶ 10:00](https://youtu.be/KRcOMp07dp8?t=600)–12:30。

### 4. 穩定子是子群 [▶ 13:00](https://youtu.be/KRcOMp07dp8?t=780)

> **定理**　$G$ 作用在 $S$ 上，$x\in S$。則 $G_x\le G$。

**證明（兩步法）** [▶ 14:00](https://youtu.be/KRcOMp07dp8?t=840)
- **非空**：$e\star x = x$，所以 $e\in G_x$。
- **乘法封閉**：$a,b\in G_x$，則 $(ab)\star x = a\star(b\star x) = a\star x = x$ [▶ 15:00](https://youtu.be/KRcOMp07dp8?t=900)。
- **反元素封閉** [▶ 16:00](https://youtu.be/KRcOMp07dp8?t=960)：
$$x = e\star x = (a^{-1}a)\star x = a^{-1}\star(a\star x) = a^{-1}\star x.$$
  所以 $a^{-1}\in G_x$。$\blacksquare$

（老師說這應該出成作業，但已經打好了。）

### 5. 軌道分割集合 [▶ 17:30](https://youtu.be/KRcOMp07dp8?t=1050)

> **定理**　$G$ 作用在 $S$ 上，則軌道把 $S$ 分割。若 $S$ 有限，
> $$|S| = \sum_i|Gx_i|,$$
> 其中每個軌道恰取一個代表 $x_i$。

**證明**：定義 $x\sim y\iff$ 存在 $g$ 使 $y = g\star x$ [▶ 19:30](https://youtu.be/KRcOMp07dp8?t=1170)。
- **自反**：$x = e\star x$。
- **對稱** [▶ 21:00](https://youtu.be/KRcOMp07dp8?t=1260)：$y = g\star x\Rightarrow g^{-1}\star y = (g^{-1}g)\star x = x$。
- **遞移** [▶ 22:00](https://youtu.be/KRcOMp07dp8?t=1320)：$y = h\star x$、$z = g\star y\Rightarrow z = (gh)\star x$。

等價類 $\{y\mid y\sim x\} = \{g\star x\} = Gx$，就是**軌道** [▶ 23:00](https://youtu.be/KRcOMp07dp8?t=1380)。等價類分割集合，軌道互不相交，一個個加起來就是 $|S|$。$\blacksquare$

### 6. 軌道與穩定子的陪集一一對應 [▶ 24:30](https://youtu.be/KRcOMp07dp8?t=1470)

> **定理**　$G$ 作用在 $S$ 上，$x\in S$。軌道 $Gx$ 的元素和 $G_x$ 的**左陪集**一一對應。

（$G_x$ 不一定正規，所以 $G/G_x$ 只是陪集的**集合**，不一定是群；但陪集的個數仍是 $|G|/|G_x|$ [▶ 26:00](https://youtu.be/KRcOMp07dp8?t=1560)。）

**證明**（後半改用投影）[▶ 26:30](https://youtu.be/KRcOMp07dp8?t=1590)：定義 $f:Gx\to\{gG_x\}$，
$$f(y) = gG_x,\quad\text{其中 }y = g\star x.$$
公式裡沒有 $y$，是間接定義，所以要檢查良定義。

- **良定義** [▶ 30:30](https://youtu.be/KRcOMp07dp8?t=1830)：若 $y = h\star x = g\star x$，兩邊用 $h^{-1}$ 作用：$(h^{-1}g)\star x = x$，所以 $h^{-1}g\in G_x$，即 $hG_x = gG_x$。
- **單射**：倒推回去：$hG_x = gG_x\Rightarrow h^{-1}g\in G_x\Rightarrow h\star x = g\star x$ [▶ 32:00](https://youtu.be/KRcOMp07dp8?t=1920)。
- **滿射**：$gG_x = f(g\star x)$。

這只是雙射，不是同構；但雙射就能**數個數** [▶ 32:30](https://youtu.be/KRcOMp07dp8?t=1950)。

> **定理（軌道穩定子定理 Orbit-Stabilizer Theorem）**　$G$ 有限，作用在 $S$ 上。對任意 $x\in S$，
> $$|G| = |Gx|\cdot|G_x|.$$

**驚人的地方** [▶ 33:30](https://youtu.be/KRcOMp07dp8?t=2010)：$|G_x|$ 整除 $|G|$ 不意外（Lagrange）；但**軌道的大小也整除 $|G|$**，這就有點意外了。

### 7. 例：$D_4$ 作用在正方形的頂點上 [▶ 34:30](https://youtu.be/KRcOMp07dp8?t=2070)

頂點標 0、1、2、3。$D_4$ 的 8 個元素：轉 $0°$、$90°$、$180°$、$270°$，以及四個鏡射（兩條對角線、兩條中垂線）。

- **0 的軌道**：0 可以被送到每個頂點，所以 $D_4\cdot0 = S$ [▶ 37:30](https://youtu.be/KRcOMp07dp8?t=2250)。有一個元素的軌道是整個集合時，叫作用是**遞移的 (transitive)**。
- **0 的穩定子** [▶ 38:30](https://youtu.be/KRcOMp07dp8?t=2310)：恆等，和**過 0、2 那條對角線的鏡射** $(13)$。共 2 個。
- 檢查：$|D_4| = 8 = 4\times2$ ✓ [▶ 39:30](https://youtu.be/KRcOMp07dp8?t=2370)

老師：每本書都舉這個例子，但他不覺得特別有啟發性。

### 8. 例：循環置換群的軌道 [▶ 40:00](https://youtu.be/KRcOMp07dp8?t=2400)

$S = \{1,\dots,6\}$，$\sigma = (123)(56)$，$G = \langle\sigma\rangle\le S_6$，自然地作用在 $S$ 上。
- 1 的軌道：$1\to2\to3\to1$，$\{1,2,3\}$ [▶ 42:00](https://youtu.be/KRcOMp07dp8?t=2520)。
- 5 的軌道：$\{5,6\}$。
- 4 的軌道：$\{4\}$。
- $3+2+1 = 6 = |S|$ ✓（因為軌道分割 $S$）

**一般地** [▶ 43:00](https://youtu.be/KRcOMp07dp8?t=2580)：$\sigma\in S_n$ 寫成互斥循環 $\beta_1\cdots\beta_t$。若 $i$ 被 $\beta_j$ 移動，則其他循環都不動它，$\sigma$ 的次方只是沿著 $\beta_j$ 繞。所以 **$\langle\sigma\rangle$ 的軌道就是各個互斥循環裡的數字集合**，加上不動點各自成單點軌道 [▶ 45:00](https://youtu.be/KRcOMp07dp8?t=2700)。

### 9. 推論：共軛類的大小 [▶ 45:30](https://youtu.be/KRcOMp07dp8?t=2730)

> **推論**　$G$ 有限，$x\in G$。$x$ 的共軛元素個數 $= [G:C(x)]$：
> $$|\{gxg^{-1}\mid g\in G\}| = \frac{|G|}{|C(x)|}.$$

**證明** [▶ 47:30](https://youtu.be/KRcOMp07dp8?t=2850)：對共軛作用用軌道穩定子定理（軌道 = 共軛類，穩定子 = 中心化子）。

**例：$S_4$ 的共軛類** [▶ 48:00](https://youtu.be/KRcOMp07dp8?t=2880)：同一個**循環型 (cycle type)** 的置換彼此共軛。

| 循環型 | 代表 | 個數 |
|---|---|---|
| 恆等 | $(1)$ | 1 |
| 換位 | $(12)$ | 6 |
| 3-循環 | $(123)$ | 8 |
| 4-循環 | $(1234)$ | 6 |
| 兩個換位 | $(12)(34)$ | 3 |

$$1+6+8+6+3 = 24 = |S_4|.$$
不是巧合：共軛類是軌道，軌道分割 $S_4$ [▶ 50:30](https://youtu.be/KRcOMp07dp8?t=3030)。

> 💬 老師說「用 $\sigma$ 共軛 $(137)$，會得到同樣的 1、3、7，只是順序不同」[▶ 49:30](https://youtu.be/KRcOMp07dp8?t=2970)。這不精確。正確的是：
> $$\sigma(a_1a_2\cdots a_k)\sigma^{-1} = (\sigma(a_1)\,\sigma(a_2)\cdots\sigma(a_k)),$$
> 也就是**循環型不變**，數字會換成 $\sigma$ 的像。所以同循環型的置換都共軛。
