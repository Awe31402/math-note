## 1. 同餘的定義

[▶ 00:30](https://youtu.be/Ebbi2qr7HYc?t=30) 老師先改講義：把定義 1.52 和定理 1.53 **對調**，「因為這樣對我們比較方便」。

> **定義（同餘 congruence）**　$n\in\mathbb{N}$ 固定。$a,b\in\mathbb{Z}$。
> $$a\equiv b\pmod n\quad\Longleftrightarrow\quad n\mid(b-a).$$
> 讀作「$a$ 模 $n$ 同餘於 $b$」。

[▶ 01:30](https://youtu.be/Ebbi2qr7HYc?t=90) 講義原本的定義是：$a$ 和 $b$ **除以 $n$ 的餘數相同**。然後證明它跟上面等價。

**為什麼換**[▶ 02:00](https://youtu.be/Ebbi2qr7HYc?t=120)：「我們的重點不是數論，是代數。」$n\mid(b-a)$ 這個版本**實際用起來最方便**，後面一直用的就是它。

> 📘 **講義 Theorem 1.2.3：兩個定義等價**
>
> **(餘數相同 ⇒ 整除)** 由除法算則 $a = q_1n+r$、$b = q_2n+r$（同一個 $r$）。相減：$b-a = (q_2-q_1)n$，所以 $n\mid(b-a)$。
>
> **(整除 ⇒ 餘數相同)** 設 $b-a = qn$。由除法算則 $a = q_1n+r_1$、$b = q_2n+r_2$，$0\le r_1,r_2<n$，所以 $|r_2-r_1|<n$。代入：
> $$qn = (q_2-q_1)n+(r_2-r_1)\ \Rightarrow\ |q-q_2+q_1|\,n = |r_2-r_1|<n.$$
> 左邊是 $n$ 的非負整數倍、又小於 $n$，只能是 0。所以 $r_1 = r_2$。

## 2. 同餘是等價關係

[▶ 02:00](https://youtu.be/Ebbi2qr7HYc?t=120)

> **命題**　對所有 $x,y,z\in\mathbb{Z}$（以下省略「$\bmod n$」）：
> 1. $x\equiv x$；
> 2. $x\equiv y\Rightarrow y\equiv x$；
> 3. $x\equiv y$ 且 $y\equiv z\Rightarrow x\equiv z$。

【課堂討論】[▶ 03:00](https://youtu.be/Ebbi2qr7HYc?t=180)「用文字怎麼說這個命題？」答：模 $n$ 同餘是**反身的（reflexive）**、**對稱的（symmetric）**、**遞移的（transitive）**。也就是：

> **模 $n$ 同餘是 $\mathbb{Z}$ 上的一個等價關係（equivalence relation）。**

所以它把整數**分割（partition）**成互不相交、聯集是全部的幾塊 [▶ 03:30](https://youtu.be/Ebbi2qr7HYc?t=210)。

**證明 (3)**（「我證一個象徵性的」）[▶ 04:00](https://youtu.be/Ebbi2qr7HYc?t=240)

設 $x\equiv y$、$y\equiv z$。由定義（老師先寫反了，馬上改正）：
$$n\mid(y-x),\qquad n\mid(z-y).$$

**方法 1：用上次的定理**[▶ 04:30](https://youtu.be/Ebbi2qr7HYc?t=270)。$n$ 整除兩個數，就整除它們的和：
$$n\mid\big[(y-x)+(z-y)\big] = z-x.$$
$y$ 消掉了。所以 $x\equiv z$。

**方法 2：回到定義**[▶ 05:30](https://youtu.be/Ebbi2qr7HYc?t=330)。存在整數 $k,l$ 使
$$y-x = kn,\qquad z-y = ln.$$
則
$$z-x = (z-y)+(y-x) = ln+kn = n(l+k).$$
$l+k\in\mathbb{Z}$，所以 $n\mid(z-x)$ [▶ 07:00](https://youtu.be/Ebbi2qr7HYc?t=420)。

【口頭】「如果上次的整除定理沒有『寫死』在你腦裡——我大部分時候就是這樣——你永遠可以退回這種推理。只是比較花時間。」

> 📘 講義的 (1)(2)：$x-x = 0 = 0\cdot n$；$x-y = nk\Rightarrow y-x = n(-k)$。

## 3. 同餘類與 Zn（字幕缺口，依講義）

### 3.1 同餘類的寫法

[▶ 07:30](https://youtu.be/Ebbi2qr7HYc?t=450) 引入記號。$x$ 的**同餘類（equivalence class）**：
$$[x] = \{y\in\mathbb{Z} : x\equiv y\pmod n\}.$$

【課堂討論】老師一步步改寫 [▶ 08:00](https://youtu.be/Ebbi2qr7HYc?t=480)：
$$[x] = \{y\in\mathbb{Z} : y-x = nk,\ k\in\mathbb{Z}\} = \{x+nk : k\in\mathbb{Z}\}.$$
「$k$ 是什麼？」學生：「整數。」

再寫成**陪集記號（coset notation）**[▶ 09:00](https://youtu.be/Ebbi2qr7HYc?t=540)：
$$[x] = x+n\mathbb{Z},\qquad n\mathbb{Z} = \{nk : k\in\mathbb{Z}\}.$$

> ⚠️ **從這裡開始到 [▶ 39:30](https://youtu.be/Ebbi2qr7HYc?t=2370)，字幕和 Whisper 都失效。** 零星可辨的字有：「$\mathbb{Z}$」、「one plus…two plus…」（像在列同餘類）、「from $x$ equals $x'$ and $y$ equals $y'$」（約 15:00，像在證良定義）、「$x$ plus $y$」「the definition」（約 21:00）、「$\mathbb{Z}$ sub $n$」（約 22:30）、「gcd…$X$ plus $B\,N$ equal one」（約 33:00，像在用 Bézout 求反元素）。據此推測，這段講的就是講義 3.2–3.5 的內容。

> 📘 **講義例子**：
> - 模 2：$[0] = 2\mathbb{Z}$（偶數）、$[1] = 1+2\mathbb{Z}$（奇數）。
> - 模 4：$[0] = 4\mathbb{Z} = \{\dots,-4,0,4,8,\dots\}$、$[1] = 1+4\mathbb{Z} = \{\dots,-3,1,5,9,\dots\}$、$[2] = 2+4\mathbb{Z}$、$[3] = 3+4\mathbb{Z}$。

### 3.2 【講義補充】同餘類相等的條件

**注意**：$[x] = [y]$ **不代表** $x = y$。例如模 2：$[1] = [3] = [7]$、$[2] = [-2] = [-42]$。模 9：$[1] = [10] = [-8]$。

但模 9 時 $[1]\neq[3]$——「上面不是才說 $[1] = [3]$？」**看模數**。$[x]$ 這個記號其實不完整，寫成陪集比較清楚：
$$1+2\mathbb{Z} = 3+2\mathbb{Z},\qquad 1+9\mathbb{Z}\neq3+9\mathbb{Z}.$$

> **命題 1.2.12**　$[x] = [y]$ ⟺ $x\equiv y\pmod n$。（陪集記號：$x+n\mathbb{Z} = y+n\mathbb{Z}$ ⟺ $y-x\in n\mathbb{Z}$。）

**證明**：
- (⇒) $x\in[x] = [y]$，所以 $x = y+nk$，$x\equiv y$。
- (⇐) 設 $y-x = nk$。若 $a\in[x]$，$a = x+nj = (y-nk)+nj = y+n(j-k)\in[y]$，所以 $[x]\subseteq[y]$。反方向同理。

**好用的推論**：$[na+b] = [b]$，也就是 $na+b+n\mathbb{Z} = b+n\mathbb{Z}$。

### 3.3 【講義補充】運算與同餘相容（良定義）

> **命題 1.2.13**　若 $[x] = [x']$ 且 $[y] = [y']$，則
> 1. $[x+y] = [x'+y']$；
> 2. $[xy] = [x'y']$；
> 3. $[x-y] = [x'-y']$。

**證明**：寫 $x' = x+nj$、$y' = y+nk$。
- 加減：$x'\pm y' = (x\pm y)+n(j\pm k)$，所以 $x\pm y\equiv x'\pm y'$。
- 乘：
$$x'y' = (x+nj)(y+nk) = xy+n(jkn+jy+xk),$$
  所以 $xy\equiv x'y'$。

**白話**：**換一個代表元，答案的同餘類不變。**這就是「良定義（well-defined）」——下面定義的運算不會因為你挑哪個代表元而給出不同答案。

> **推論 1.2.14**（同餘版）　若 $x\equiv x'$、$y\equiv y'\pmod n$，則 $x+y\equiv x'+y'$、$xy\equiv x'y'$、$x-y\equiv x'-y'$。

**例 1.2.15**：$x+y\equiv3$、$x-y\equiv1\pmod4$。相加、相減得 $2x\equiv4$、$2y\equiv2$。逐一試 $[0],[1],[2],[3]$：$x\in[0]\cup[2]$、$y\in[1]\cup[3]$。（模 4 的方程組有**四組**解——跟 $\mathbb{Z}$ 上「無解、一解或無限多解」不同。原因是 $\mathbb{Z}_4$ 裡有些數沒有乘法反元素。）

### 3.4 【講義補充】Zn = Z/nZ 的模運算

> **定義 1.2.16（模運算 modular arithmetic）**
> $$[x]+[y] = [x+y],\qquad[x][y] = [xy].$$
> 陪集記號：
> $$(x+n\mathbb{Z})+(y+n\mathbb{Z}) = x+y+n\mathbb{Z},\qquad(x+n\mathbb{Z})(y+n\mathbb{Z}) = xy+n\mathbb{Z}.$$
> 所有同餘類的集合記作 $\mathbb{Z}/n\mathbb{Z}$，也寫 $\mathbb{Z}_n$。

- 命題 1.2.13 保證這是 $\mathbb{Z}/n\mathbb{Z}$ 上的**二元運算**（單值的函數）。注意：是在 $\mathbb{Z}/n\mathbb{Z}$ 上，不是在 $\mathbb{Z}$ 上。
- 整數的算術性質都搬過來：交換律、結合律、分配律、$[a]+[0] = [a]$、$[1][a] = [a]$。
- 還有：$[a_1]+\cdots+[a_k] = [a_1+\cdots+a_k]$、$[a_1]\cdots[a_k] = [a_1\cdots a_k]$、$[a]^k = [a^k]$。

所以 $(\mathbb{Z}_n,+)$ 是**交換群**：單位元素 $[0]$，$[x]$ 的反元素是 $[-x]$。這就是 L2 宣稱的事，現在有了根據。

### 3.5 【講義補充】誰有乘法反元素

（字幕約 33:00 出現「gcd」「… plus … N equal one」，應該是在講這個。）

要解 $[a][x] = [1]$：
$$ax-1 = nk\quad\Longrightarrow\quad ax+n(-k) = 1.$$
- 若 $a$ 和 $n$ 有大於 1 的公因數，它會整除左邊，卻不整除 1，矛盾。
- 所以**有解 ⟹ $\gcd(a,n) = 1$**。
- 反過來，$\gcd(a,n) = 1$ 時，Bézout 給出 $ax+ny = 1$，$x$ 就是反元素。

> **$[a]$ 在 $\mathbb{Z}_n$ 裡有乘法反元素 ⟺ $\gcd(a,n) = 1$。**

**例**（用 L4 的計算）：
- $\gcd(62,626) = 2$：62 在模 626 下**沒有**反元素，626 在模 62 下也沒有。
- $1 = 5\cdot240-109\cdot11$ ⇒ 模 11：$[5]^{-1} = [240]$；模 109：$[5]^{-1} = [240] = [22]$（檢查 $5\cdot22 = 110\equiv1$）；模 240：$[-109]^{-1} = [11]$；模 5：$[-109]^{-1} = [11]$。

**之後的記號**（Remark 1.2.32）：嚴謹的模型建好之後，回到簡單的寫法 $\mathbb{Z}_n = \{0,1,\dots,n-1\}$，只要記得 $k = k-n$。例如 $\mathbb{Z}_5 = \{0,1,2,3,4\} = \{0,\pm1,\pm2\}$。

## 4. 計算技巧

[▶ 39:30](https://youtu.be/Ebbi2qr7HYc?t=2370) 字幕恢復。老師在跟投影機奮鬥（「快點快點，你做得到——不，做不到」）。「我該跟王老師借他的投影機夾子的。」然後用投影片講幾個計算例子。

### 4.1 化簡大數

[▶ 41:00](https://youtu.be/Ebbi2qr7HYc?t=2460) **例：$1234\bmod5$。**
$$1234 = 1\cdot10^3+2\cdot10^2+3\cdot10+4.$$
$10 = 2\cdot5$，所以 $10^k = 2^k5^k\equiv0\pmod5$。
$$1234\equiv4\pmod5.$$

（講義：同樣的道理，任何整數模 5 只看**個位數**。）

### 4.2 次方：可以先取模，但指數不行

**例：$51^3\bmod7$**[▶ 42:00](https://youtu.be/Ebbi2qr7HYc?t=2520)（Whisper 聽成 57，依講義是 51）
$$51^3 = (49+2)^3\equiv2^3 = 8\pmod7.$$
「$49\equiv0\pmod7$。」可以**先把底數取模，再算次方**：$[a]^k = [a^k]$。

【Q&A】[▶ 43:00](https://youtu.be/Ebbi2qr7HYc?t=2580) 學生問：$[8]$ 不就是 $[1]$ 嗎？老師：「對對，你可以再化簡。」$8\equiv1$，所以 $51^3\equiv1\pmod7$。

**警告：不能把模數拿去化簡指數**[▶ 42:30](https://youtu.be/Ebbi2qr7HYc?t=2550)。「你不能把模運算搬到指數上。」講義的例子（Example 1.2.19）：$7^{100}\bmod6$。
- **正確**：$7\equiv1$，所以 $7^{100}\equiv1^{100} = 1$。
- **錯誤**：把指數 $100 = 6\cdot16+4$ 也模 6，得 $7^4\equiv1$……再亂算得到 $4$。「如果算對，得 1；用這種假的算法，得 4。別得意忘形。」

$$[a^k] = [a]^k\quad\text{但}\quad[a^k]\neq[a^{[k]}].$$

### 4.3 兩種代表元

[▶ 43:30](https://youtu.be/Ebbi2qr7HYc?t=2610)「這帶到下一個問題：你有選擇。」
- **最小非負代表元**：$\mathbb{Z}_n = \{0,1,\dots,n-1\}$。
- **最小絕對值代表元**：$\mathbb{Z}_n = \{0,\pm1,\pm2,\dots\}$。
- 在 $\mathbb{Z}_n$ 裡工作時，**括號直接省略**，「我們寫幾百個括號並不快樂」。
- 用 $\pm$ 版本數字比較小，「但要追蹤負號，有點掃興」。

> 📘 講義例子（取自 Jones & Jones《Elementary Number Theory》）：
> - $28\times33\bmod35$：$28\equiv-7$、$33\equiv-2$，所以 $\equiv14$。
> - $3^8\bmod13$：一再平方。$3^2 = 9\equiv-4$；$3^4\equiv16\equiv3$；$3^8\equiv9$。
> - $6\mid a(a+1)(a+2)$ 對所有整數 $a$：在 $\mathbb{Z}_6 = \{0,\pm1,\pm2,3\}$ 逐一驗證都是 0。或者分別驗證被 2 和 3 整除。

### 4.4 用模 n 證明多項式沒有整數根

[▶ 44:00](https://youtu.be/Ebbi2qr7HYc?t=2640)「算術基本定理，你知道它，你愛它，我不講了。」（講義 Thm 1.2.26：每個正整數有唯一的質因數分解，證明在數論課。）

**例：$f(x) = x^5-x^2+x-3$ 沒有整數根。**

**想法**：模 4 把整數分成四類：$4\mathbb{Z}$、$1+4\mathbb{Z}$、$2+4\mathbb{Z}$、$3+4\mathbb{Z}$。每類代一個代表元進去，模 4 看是不是 0。

| 代表元 | $f$ 的值 | 模 4 |
|---|---|---|
| $0$ | $-3$ | $\equiv1$ |
| $1$ | $1-1+1-3 = -2$ | $\equiv2$ |
| $-1$（即 3） | $-1-1-1-3 = -6$ | $\equiv2$ |
| $2$ | $32-4+2-3 = 27$ | $\equiv3$ |

**沒有一個是 0**[▶ 45:00](https://youtu.be/Ebbi2qr7HYc?t=2700)。所以不管代哪個整數，$f$ 的值都不是 4 的倍數，更不可能是 0。**$f$ 沒有整數根。**

> ⚠️ 課堂上口頭念的 $f(-1)$ 是 2（$-6\equiv2$ ✓），$f(2)$ 是 $-1$（$27\equiv3\equiv-1$ ✓）。字幕把順序念得有點亂，上表依講義 Example 1.2.28 整理。

【口頭】[▶ 45:30](https://youtu.be/Ebbi2qr7HYc?t=2730)「這很酷，因為我們不用分解它。我不想分解它。你想分解它嗎？如同第一天講的，一般來說根本沒有公式可以分解它。」

**背後的定理**[▶ 45:30](https://youtu.be/Ebbi2qr7HYc?t=2730)：

> **定理 1.2.29**　$f(x)$ 是整係數多項式。若 $a\equiv b\pmod n$，則 $f(a)\equiv f(b)\pmod n$。

**證明**：$f(x) = c_mx^m+\cdots+c_1x+c_0$。反覆用推論 1.2.14（加法、乘法都跟同餘相容）：
$$f(a) = c_ma^m+\cdots+c_0\equiv c_mb^m+\cdots+c_0 = f(b).$$

【口頭】[▶ 46:00](https://youtu.be/Ebbi2qr7HYc?t=2760)「這就是把今天講的這些和、積規則組合起來。剛才的計算就看到：立方的同餘類是同餘類的立方。可以推到 $n$ 次方。這大概是個不錯的歸納法證明，我該把它出成作業的。」

**為什麼能推出「沒有整數根」**（講義的逆否命題說明）：
- 若 $f(a) = 0$，則對**所有** $n$，$f(a)\equiv0\pmod n$。
- 逆否：只要找到**一個** $n$，使得對所有 $a$ 都 $f(a)\not\equiv0\pmod n$，就有 $f(a)\neq0$ 對所有整數 $a$。

（講義提醒：這方法**不是總能成功**，見 Jones & Jones p.45。）

## 5. 模 n 的矩陣

### 5.1 反矩陣公式

[▶ 46:30](https://youtu.be/Ebbi2qr7HYc?t=2790)「最後一點：矩陣。」

**你已經知道的照樣成立**[▶ 47:00](https://youtu.be/Ebbi2qr7HYc?t=2820)：
- 矩陣的加法、乘法**逐分量**做，只是改用模運算。
- 古典伴隨矩陣（classical adjoint）的恆等式
$$M\cdot\operatorname{adj}(M) = \det(M)\,I$$
  推導過程只用到加法和乘法，所以在 $\mathbb{Z}_n$ 裡照樣成立，**即使 $n$ 不是質數**。

**唯一的問題**[▶ 48:00](https://youtu.be/Ebbi2qr7HYc?t=2880)：要解出 $M^{-1}$，得「除以」$\det M$，也就是**乘上 $\det M$ 的乘法反元素**。所以只有在
$$\det M\in U(n)$$
時才行。

**$2\times2$ 公式（模 $n$）**[▶ 48:00](https://youtu.be/Ebbi2qr7HYc?t=2880)：
$$\begin{pmatrix}a&b\\c&d\end{pmatrix}^{-1} = (ad-bc)^{-1}\begin{pmatrix}d&-b\\-c&a\end{pmatrix},$$
**對角線交換、非對角線加負號**，跟以前一樣——只是 $\frac{1}{ad-bc}$ 換成「$ad-bc$ 的模反元素」。

【口頭】[▶ 47:00](https://youtu.be/Ebbi2qr7HYc?t=2820)「為了基本的人性，考試我幾乎只會考 $2\times2$——至少目前。因為這是一三五的課。如果能考帶回家的考試，或者像另一位老師那樣『晚上 9 點發考卷、9 點收』……聽起來很好玩，但我們不那樣做。」

### 5.2 GL(p, Zn) 與 GL(p, Z)

[▶ 48:30](https://youtu.be/Ebbi2qr7HYc?t=2910)

> **定義**
> $$GL(p,\mathbb{Z}_n) = \{A\in\mathbb{Z}_n^{p\times p} : \det A\in U(n)\}.$$
> $$GL(p,\mathbb{Z}) = \{A\in\mathbb{Z}^{p\times p} : \det A = \pm1\}.$$

為什麼 $GL(p,\mathbb{Z})$ 是 $\pm1$ [▶ 49:00](https://youtu.be/Ebbi2qr7HYc?t=2940)：在整數裡，**只有 $\pm1$ 有乘法反元素**。「就這兩個。」

（這跟 L2 講義補充的 $GL_n(R) = \{A : \det A\in U(R)\}$ 是同一個想法：$U(\mathbb{Z}_n) = U(n)$，$U(\mathbb{Z}) = \{\pm1\}$。）

### 5.3 例子

**行列式不可逆 ⇒ 沒有反矩陣**[▶ 49:00](https://youtu.be/Ebbi2qr7HYc?t=2940)：模 10，取
$$M = \begin{pmatrix}1&2\\3&1\end{pmatrix},\qquad\det M = 1-6 = -5\equiv5\pmod{10}.$$
（老師：「我隨便編的，碰巧行列式是 5，或 $-5$，看你怎麼看。」）$\gcd(5,10) = 5$，所以 $5\notin U(10)$。

而且可以找到**非零**矩陣乘上它得 0 [▶ 49:30](https://youtu.be/Ebbi2qr7HYc?t=2970)：
$$\begin{pmatrix}4&2\\2&6\end{pmatrix}\begin{pmatrix}1&2\\3&1\end{pmatrix} = \begin{pmatrix}10&10\\20&10\end{pmatrix}\equiv\begin{pmatrix}0&0\\0&0\end{pmatrix}\pmod{10}.$$
「發生這種事時，就**不可能**有反矩陣。」（若 $M^{-1}$ 存在，右乘 $M^{-1}$ 會得到 $\begin{pmatrix}4&2\\2&6\end{pmatrix} = 0$，矛盾。）

**矩陣的階**[▶ 49:30](https://youtu.be/Ebbi2qr7HYc?t=2970)（作業有相關題）：
- **加法的階**[▶ 50:00](https://youtu.be/Ebbi2qr7HYc?t=3000)：一直加自己，直到得到零矩陣。投影片上一個矩陣加法階是 6，另一個是 4。
- 「乘法的群比較有趣。」

【口頭】[▶ 50:30](https://youtu.be/Ebbi2qr7HYc?t=3030)（老師一直咳嗽）「抱歉，我會好起來——其實我不能保證。如果你們有人很虔誠，幫我禱告會很好。」

**模 4 的例子**[▶ 50:30](https://youtu.be/Ebbi2qr7HYc?t=3030)：某矩陣 $A$ 行列式是 3。模 4 下 $3\cdot3 = 9\equiv1$，所以 $3^{-1} = 3$。反矩陣 = $3\times$（對角交換、非對角加負號）。結果反矩陣**就是 $A$ 自己**：$A\cdot A = I$，所以 $A$ 的階是 2。「我沒在找這個，但它發生了。」（老師：「反矩陣就是矩陣。The Matrix。到處都是。」）

**模 5 的例子**[▶ 51:30](https://youtu.be/Ebbi2qr7HYc?t=3090)：某矩陣 $A$，算出 $A^{-1}$、$A^2$、$A^3$，發現 $A^3 = A^{-1}$。兩邊乘 $A$ 得
$$A^4 = I,$$
所以 $A$ 的階是 4。$\langle A\rangle$ 是 $GL(2,\mathbb{Z}_5)$ 裡一個 4 階的循環子群。

## 6. 一頁速查表

### 6.1 定義與基本事實

| 名稱 | 內容 |
|---|---|
| 同餘 | $a\equiv b\pmod n\iff n\mid(b-a)\iff$ 除以 $n$ 餘數相同 |
| 等價關係 | 反身、對稱、遞移 ⇒ 把 $\mathbb{Z}$ 分成 $n$ 類 |
| 同餘類 | $[x] = \{x+nk\} = x+n\mathbb{Z}$ |
| $[x] = [y]$ | $\iff x\equiv y\pmod n$（**不代表** $x = y$） |
| $\mathbb{Z}_n = \mathbb{Z}/n\mathbb{Z}$ | $[x]+[y] = [x+y]$、$[x][y] = [xy]$ |
| 良定義 | $x' = x+nj$、$y' = y+nk$ ⇒ $x'y' = xy+n(\dots)$ |
| 乘法反元素 | $[a]^{-1}$ 存在 $\iff\gcd(a,n) = 1$（Bézout 求出） |

### 6.2 證明關鍵一步

| 結果 | 關鍵一步 |
|---|---|
| 遞移性 | $z-x = (z-y)+(y-x)$，兩項都被 $n$ 整除 |
| 乘法良定義 | $(x+nj)(y+nk) = xy+n(jkn+jy+xk)$ |
| $f(a)\equiv f(b)$ | 反覆用和、積的相容性 |
| 沒有整數根 | 找一個 $n$，讓 $f$ 在每個同餘類都 $\not\equiv0$ |
| 有反元素 ⇒ 互質 | $ax+n(-k) = 1$，公因數會整除 1 |

### 6.3 計算規則

- 可以先把底數取模：$[a^k] = [a]^k$。
- **不能**把指數取模：$[a^k]\neq[a^{[k]}]$（$7^{100}\equiv1$，不是 4，模 6）。
- 靠近模數的數用負代表元。
- 模 10 只看個位，模 5 也只看個位。

### 6.4 模 n 的矩陣

$$\begin{pmatrix}a&b\\c&d\end{pmatrix}^{-1} = (ad-bc)^{-1}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}\quad(\text{需要 }ad-bc\in U(n))$$

- $GL(p,\mathbb{Z}_n) = \{A : \det A\in U(n)\}$。
- $GL(p,\mathbb{Z}) = \{A : \det A = \pm1\}$。
- 有非零 $B$ 使 $BM = 0$ ⇒ $M$ 不可逆。

## 附：本集一句話總結

> **$a\equiv b\pmod n$ 定義成 $n\mid(b-a)$；它是等價關係，把 $\mathbb{Z}$ 分成 $n$ 個同餘類 $x+n\mathbb{Z}$，而加法、乘法跟同餘相容（換代表元答案不變），所以 $\mathbb{Z}_n = \mathbb{Z}/n\mathbb{Z}$ 的模運算是良定義的；$[a]$ 可逆恰好當 $\gcd(a,n) = 1$。實用上：底數可以先取模、指數不行，模 $n$ 可以證明多項式沒有整數根，模 $n$ 的矩陣在行列式可逆時照用伴隨矩陣公式求反矩陣。**
