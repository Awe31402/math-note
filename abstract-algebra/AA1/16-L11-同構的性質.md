# 第 16 集 · L11：同構的性質、自同構 [▶ 影片](https://www.youtube.com/watch?v=geK7UuAMunQ&list=PLBY4G2o7DhF0JCgapYKrqibGaJuvV4Gkb)

## 本集概要

- 同構**保持**：元素的階、交換性、循環性、方程 $x^k = b$ 的解的個數。
- 小引理：$\varphi(a^{-1}) = \varphi(a)^{-1}$、$\varphi(a^n) = \varphi(a)^n$。
- 用來**證明不同構**：$\mathbb{R}^\times\not\cong\mathbb{C}^\times$（$x^4 = 1$ 的解數不同）；四元數群 $Q_8\not\cong\mathbb{Z}_8$（一個非交換、一個交換）。
- **自同構 (automorphism)**：群到自己的同構；$\operatorname{Aut}(G)\le\operatorname{Sym}(G)$。
- **內自同構 (inner automorphism)** $\varphi_g(x) = gxg^{-1}$（共軛）；$\operatorname{Inn}(G)\le\operatorname{Aut}(G)$。例：$SL(n,\mathbb{R})$ 上的共軛、複數共軛。
- **$\operatorname{Aut}(\mathbb{Z}_n)\cong U(n)$**，以 $\mathbb{Z}_{10}$ 為例。

> 📘 講義對應：2018 講義 §2.9（p.76–78）；本集主要跟著 Gallian 第 6 章（Thm 6.2、6.3、6.4、6.5）。老師說今天狀況不好（還在生病）。

## 筆記

### 1. 同構保持的性質 [▶ 02:30](https://youtu.be/geK7UuAMunQ?t=150)

> **定理（Gallian Thm 6.2、6.3）**　設 $\varphi:G\to\bar G$ 是同構（Gallian 常用 $G$、$\bar G$ 代替 $G_1$、$G_2$）。則
> 1. $|g| = |\varphi(g)|$ 對所有 $g\in G$。
> 2. $G$ 是交換群 $\iff \bar G$ 是交換群。
> 3. $G$ 是循環群 $\iff \bar G$ 是循環群。
> 4. 方程 $x^k = b$ 在 $G$ 中的解數，等於 $x^k = \varphi(b)$ 在 $\bar G$ 中的解數。

### 2. 小引理 [▶ 06:00](https://youtu.be/geK7UuAMunQ?t=360)

> **引理**　對同態 $\varphi$：
> - $\varphi(a^{-1}) = \varphi(a)^{-1}$
> - $\varphi(a^n) = \varphi(a)^n$ 對所有 $n\in\mathbb{Z}$

**反元素** [▶ 09:30](https://youtu.be/geK7UuAMunQ?t=570)：從 $aa^{-1} = e$ 出發，取 $\varphi$：
$$\varphi(a)\varphi(a^{-1}) = \varphi(e) = e.$$
所以 $\varphi(a^{-1})$ 就是 $\varphi(a)$ 的反元素。

**次方** [▶ 11:30](https://youtu.be/geK7UuAMunQ?t=690)：
- **正整數，歸納法**：$n = 1$ 顯然。設 $\varphi(a^n) = \varphi(a)^n$，則
$$\varphi(a^{n+1}) = \varphi(a^na) = \varphi(a^n)\varphi(a) = \varphi(a)^n\varphi(a) = \varphi(a)^{n+1}.$$
- **負整數** [▶ 07:00](https://youtu.be/geK7UuAMunQ?t=420)：$\varphi(a^{-n}) = \varphi((a^{-1})^n) = \varphi(a^{-1})^n = (\varphi(a)^{-1})^n = \varphi(a)^{-n}$。用到上面反元素那條。

> 💬 老師邊講邊發現：比較好的順序應該是先證「同構的反函數是同構」，再證這個引理，再證定理 [▶ 09:00](https://youtu.be/geK7UuAMunQ?t=540)。

### 3. 證明 (1)：階相同 [▶ 13:00](https://youtu.be/geK7UuAMunQ?t=780)

- 設 $|g| = n$，即 $g^n = e$。則 $\varphi(g)^n = \varphi(g^n) = \varphi(e) = e$，所以 $|\varphi(g)|\le n$。
- 若 $\varphi(g)^j = e$，$j<n$，則 $\varphi(g^j) = e = \varphi(e)$。$\varphi$ 一對一，所以 $g^j = e$，和 $|g| = n$ 矛盾 [▶ 14:00](https://youtu.be/geK7UuAMunQ?t=840)。
- 所以 $|\varphi(g)| = n$。無限階的情形類似。

### 4. 證明 (2)：交換性 [▶ 15:00](https://youtu.be/geK7UuAMunQ?t=900)

**錯誤示範**：只寫 $\varphi(ab) = \varphi(a)\varphi(b)$、$\varphi(ba) = \varphi(b)\varphi(a)$，然後說「所以相等」。這只是「看起來合理」，不是證明 [▶ 16:30](https://youtu.be/geK7UuAMunQ?t=990)。

**正確做法**：要證的是 $\bar G$ 裡**任意** $x,y$ 都交換 [▶ 16:30](https://youtu.be/geK7UuAMunQ?t=990)。
- $\varphi$ 是雙射，所以 $\varphi^{-1}$ 存在。
- 令 $a = \varphi^{-1}(x)$、$b = \varphi^{-1}(y)$，它們在 $G$ 裡。
$$xy = \varphi(a)\varphi(b) = \varphi(ab) = \varphi(ba) = \varphi(b)\varphi(a) = yx.$$
  中間用到 $G$ 是交換群 [▶ 18:00](https://youtu.be/geK7UuAMunQ?t=1080)。
- 反方向類似。一旦證明了「同構的反函數也是同構」，反方向就不用再證 [▶ 19:30](https://youtu.be/geK7UuAMunQ?t=1170)。

(3)、(4) 的證明類似，課堂沒做 [▶ 20:30](https://youtu.be/geK7UuAMunQ?t=1230)。

### 5. 用不變量證明「不同構」[▶ 21:30](https://youtu.be/geK7UuAMunQ?t=1290)

老師說：例子在某種意義上比證明更重要。

**例 1：$\mathbb{R}^\times\not\cong\mathbb{C}^\times$** [▶ 22:00](https://youtu.be/geK7UuAMunQ?t=1320)（非零實數、非零複數，都對乘法）
- $x^4 = 1$ 在 $\mathbb{R}^\times$ 中的解：$\pm1$，兩個。
- 在 $\mathbb{C}^\times$ 中：$\pm1,\pm i$，四個。（$i^4 = (i^2)^2 = (-1)^2 = 1$。）
- 解的個數不同，由 (4)，兩者不同構 [▶ 23:30](https://youtu.be/geK7UuAMunQ?t=1410)。

**例 2：四元數群 $Q_8$** [▶ 24:00](https://youtu.be/geK7UuAMunQ?t=1440)
$$Q_8 = \{\pm1,\pm i,\pm j,\pm k\}$$
乘法規則：
- $i^2 = j^2 = k^2 = -1$
- $ij = k$，$jk = i$，$ki = j$（像 $\mathbb{R}^3$ 的外積）
- 反過來乘加負號：$ji = -k$，$kj = -i$，$ik = -j$

$Q_8\cong\mathbb{Z}_8$ 嗎？**不**。兩個都有 8 個元素，但 $Q_8$ 不是交換群（$ij\neq ji$），$\mathbb{Z}_8$ 是 [▶ 25:30](https://youtu.be/geK7UuAMunQ?t=1530)。由 (2)，不同構。

### 6. 自同構 [▶ 26:30](https://youtu.be/geK7UuAMunQ?t=1590)

> **定義**　**自同構**：從 $G$ 到 $G$ 自己的同構。所有自同構的集合記作 $\operatorname{Aut}(G)$。

> **定理（Gallian Thm 6.4）**　$\operatorname{Aut}(G)$ 是 $G$ 上所有置換的群的子群 [▶ 27:30](https://youtu.be/geK7UuAMunQ?t=1650)。

**差別** [▶ 28:00](https://youtu.be/geK7UuAMunQ?t=1680)：$G$ 上的置換只要是雙射；自同構還要**保持結構**。之後會看到：自同構必須把生成元送到生成元。

### 7. 例：$SL(n,\mathbb{R})$ 上的共軛 [▶ 29:00](https://youtu.be/geK7UuAMunQ?t=1740)

$$\varphi:SL(n,\mathbb{R})\to SL(n,\mathbb{R}),\qquad \varphi(X) = MXM^{-1}.$$
（$SL(n,\mathbb{R}) = \{A\mid\det A = 1\}$。Gallian 要求 $M\in SL(n,\mathbb{R})$，老師說其實 $M\in GL(n,\mathbb{R})$ 就夠了。）

- **反函數** [▶ 30:00](https://youtu.be/geK7UuAMunQ?t=1800)：解 $MXM^{-1} = Y$，得 $X = M^{-1}YM$。驗證 $\varphi(\varphi^{-1}(Y)) = MM^{-1}YMM^{-1} = Y$，另一邊同理。所以是雙射。
- **落在 $SL(n,\mathbb{R})$ 裡** [▶ 31:30](https://youtu.be/geK7UuAMunQ?t=1890)：
$$\det(MXM^{-1}) = \det M\det X\det M^{-1} = \det X = 1.$$
（行列式是數，可以交換。）
- 保持運算：$\varphi(XY) = MXYM^{-1} = MXM^{-1}MYM^{-1} = \varphi(X)\varphi(Y)$。

所以這是 $SL(n,\mathbb{R})$ 的自同構。這種「前面乘 $M$、後面乘 $M^{-1}$」叫**共軛 (conjugation)** [▶ 33:00](https://youtu.be/geK7UuAMunQ?t=1980)。

### 8. 內自同構 [▶ 33:30](https://youtu.be/geK7UuAMunQ?t=2010)

> **定義**　$g\in G$。$\varphi_g:G\to G$，$\varphi_g(x) = gxg^{-1}$，叫 **$g$ 誘導的內自同構**。所有內自同構的集合記作 $\operatorname{Inn}(G)$。

> **定理（Gallian Thm 6.4）**　$\operatorname{Inn}(G)\le\operatorname{Aut}(G)$ [▶ 35:30](https://youtu.be/geK7UuAMunQ?t=2130)。

- 有些群的自同構全都是內自同構 [▶ 36:00](https://youtu.be/geK7UuAMunQ?t=2160)。
- 內自同構好找（只要試各種共軛）；找出**所有**自同構一般比較難。
- **反元素** [▶ 36:30](https://youtu.be/geK7UuAMunQ?t=2190)：解 $gxg^{-1} = y$，得 $x = g^{-1}yg$。所以 $\varphi_g^{-1} = \varphi_{g^{-1}}$，**還是內自同構**。
- 兩個內自同構的合成也是內自同構（好作業題）[▶ 39:00](https://youtu.be/geK7UuAMunQ?t=2340)。

> 💬 老師提到：數學系另一位教授盲腸破裂請假；自己只是「肺不太好」，不要緊 [▶ 34:30](https://youtu.be/geK7UuAMunQ?t=2070)。

### 9. 更多自同構的例子 [▶ 39:00](https://youtu.be/geK7UuAMunQ?t=2340)

**複數共軛** $\overline{a+bi} = a-bi$
- $\overline{z+w} = \bar z+\bar w$：是 $(\mathbb{C},+)$ 的自同構。
- $\overline{zw} = \bar z\,\bar w$：也是 $(\mathbb{C}^\times,\cdot)$ 的自同構 [▶ 40:30](https://youtu.be/geK7UuAMunQ?t=2430)。
- 老師說要出一些複數的作業，因為大家懂得不夠。

**$Q_8$ 上的猜測** [▶ 41:00](https://youtu.be/geK7UuAMunQ?t=2460)：老師猜「保持 $\pm1$、把 $i,j,k$ 前面的符號全部反過來」是 $Q_8$ 的自同構（他說「只是猜測」）。

> 💬 補充（非課堂內容）：這個猜測**不成立**。設 $\psi(\pm1) = \pm1$、$\psi(\pm i) = \mp i$ 等。則 $\psi(ij) = \psi(k) = -k$，但 $\psi(i)\psi(j) = (-i)(-j) = ij = k$。它其實滿足 $\psi(xy) = \psi(y)\psi(x)$（反自同構 anti-automorphism）。

> 💬 老師說 Gallian Example 12（$D_4$ 的內自同構）用 $R_{90}$、$D'$ 等記號很難讀，想之後用 $x,y$ 記號重做 [▶ 42:00](https://youtu.be/geK7UuAMunQ?t=2520)。

### 10. $\operatorname{Aut}(\mathbb{Z}_n)\cong U(n)$ [▶ 43:00](https://youtu.be/geK7UuAMunQ?t=2580)

**例：$\operatorname{Aut}(\mathbb{Z}_{10})$** [▶ 44:00](https://youtu.be/geK7UuAMunQ?t=2640)

設 $\alpha:\mathbb{Z}_{10}\to\mathbb{Z}_{10}$ 是自同構。
- **只要知道 $\alpha(1)$** [▶ 45:00](https://youtu.be/geK7UuAMunQ?t=2700)：$k = 1+1+\cdots+1$（$k$ 個），加法同態給
$$\alpha(k) = \alpha(1)+\cdots+\alpha(1) = k\,\alpha(1).$$
- **$\alpha(1)$ 必須是生成元** [▶ 46:00](https://youtu.be/geK7UuAMunQ?t=2760)：$|\alpha(1)| = |1| = 10$，所以 $\alpha(1)$ 是 $\mathbb{Z}_{10}$ 的生成元，即 $\alpha(1)\in U(10) = \{1,3,7,9\}$。
- 四個自同構 [▶ 47:00](https://youtu.be/geK7UuAMunQ?t=2820)：
$$\alpha_1(x) = x,\quad \alpha_3(x) = 3x,\quad \alpha_7(x) = 7x,\quad \alpha_9(x) = 9x.$$

**Cayley 表** [▶ 47:30](https://youtu.be/geK7UuAMunQ?t=2850)：例如 $(\alpha_3\circ\alpha_9)(x) = 27x = 7x$，所以 $\alpha_3\alpha_9 = \alpha_7$。

| $\circ$ | $\alpha_1$ | $\alpha_3$ | $\alpha_7$ | $\alpha_9$ |
|---|---|---|---|---|
| $\alpha_1$ | $\alpha_1$ | $\alpha_3$ | $\alpha_7$ | $\alpha_9$ |
| $\alpha_3$ | $\alpha_3$ | $\alpha_9$ | $\alpha_1$ | $\alpha_7$ |
| $\alpha_7$ | $\alpha_7$ | $\alpha_1$ | $\alpha_9$ | $\alpha_3$ |
| $\alpha_9$ | $\alpha_9$ | $\alpha_7$ | $\alpha_3$ | $\alpha_1$ |

> 💬 課堂只算了一格，上表依模 10 乘法補齊。和 $U(10)$ 的乘法表一模一樣。

**同構** [▶ 49:30](https://youtu.be/geK7UuAMunQ?t=2970)：$T(\alpha) = \alpha(1)$，也就是 $T(\alpha_k) = k$。

> **定理（Gallian Thm 6.5）**　$\operatorname{Aut}(\mathbb{Z}_n)\cong U(n)$。同構為 $T(\alpha) = \alpha(1)$；每個自同構都是 $\alpha_m(x) = mx$，$\gcd(m,n) = 1$ [▶ 50:00](https://youtu.be/geK7UuAMunQ?t=3000)。

**結尾** [▶ 51:00](https://youtu.be/geK7UuAMunQ?t=3060)：原本想講到 Lagrange 定理，沒講到。發回考卷。
