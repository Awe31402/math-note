## 1. 複習：同態、同構

[▶ 00:30](https://youtu.be/geK7UuAMunQ?t=30)【課堂討論】
- **同態**：$\varphi:G_1\to G_2$，$\varphi(xy) = \varphi(x)\varphi(y)$（或適當的運算保持）。
- **同構**：同態而且是**雙射**（一對一、映成）。存在同構就寫 $G_1\cong G_2$。

已知的事 [▶ 02:00](https://youtu.be/geK7UuAMunQ?t=120)：
- Cayley 定理（第一個版本）：任何群同構於一個置換群。
- 同態把單位送到單位。
- （作業）核與像是子群。

**記號**[▶ 03:30](https://youtu.be/geK7UuAMunQ?t=210)：跟 Gallian 一樣，常用 $G$ 和 $\bar G$ 代替 $G_1$、$G_2$。

## 2. 定理：同構保持的性質

[▶ 02:30](https://youtu.be/geK7UuAMunQ?t=150)（「我在收集第 6 章的各種結果。」）

> **定理**（Gallian Thm 6.2；講義 Thm 2.4.23–2.4.25）　$\varphi:G\to\bar G$ 是同構。
> 1. $|\varphi(g)| = |g|$ 對每個 $g\in G$。
> 2. $G$ 交換 ⟺ $\bar G$ 交換。
> 3. $G$ 循環 ⟺ $\bar G$ 循環。
> 4. 對 $b\in G$、$k\in\mathbb{Z}$，方程 $x^k = b$ 在 $G$ 裡的解數 = 方程 $x^k = \varphi(b)$ 在 $\bar G$ 裡的解數。

**用途**：這些是同構的「不變量」。只要有一個不同，兩個群就**不同構**。

## 3. 引理：φ(aⁿ) = φ(a)ⁿ

[▶ 06:00](https://youtu.be/geK7UuAMunQ?t=360)「要證 (1)，先有個引理比較有用。」

> **引理**　$\varphi$ 是同態，$a\in G$，$n\in\mathbb{Z}$。則
> $$\varphi(a^n) = \varphi(a)^n.$$

**策略**[▶ 07:00](https://youtu.be/geK7UuAMunQ?t=420)：先證正整數 $n$。為什麼這就夠？因為
$$\varphi(a^{-n}) = \varphi((a^{-1})^n) = \varphi(a^{-1})^n,$$
（$a^{-1}$ 也是群元素，正整數的結果對它也成立）——但還需要**另一個小引理**才能接下去。

> **小引理（「lemma-ito」）**[▶ 08:00](https://youtu.be/geK7UuAMunQ?t=480)　$\varphi(a^{-1}) = \varphi(a)^{-1}$。

（老師：「這是更小的引理，比較沒那麼有名。」先拼錯，「沒有 a，就是 lemma-ito」。學生問這是不是有正式名字，老師：「我不知道，但它現在已經被證明了。等我打講義時命名會好一點。」）

**證明**[▶ 09:30](https://youtu.be/geK7UuAMunQ?t=570)：「從真的東西開始。」$aa^{-1} = e$。兩邊送過去，用同態性質和 $\varphi(e) = e$：
$$\varphi(a)\varphi(a^{-1}) = \varphi(aa^{-1}) = \varphi(e) = \bar e.$$
所以 $\varphi(a^{-1})$ 就是 $\varphi(a)$ 的反元素（反元素唯一）。$\blacksquare$

【口頭】[▶ 09:00](https://youtu.be/geK7UuAMunQ?t=540)「我大概被逼著承認：應該先證『同構的反函數是同構』，再證乘積的恆等式，再做這些。我正在跟你們一起發現這件事。」

**正整數的歸納**[▶ 11:30](https://youtu.be/geK7UuAMunQ?t=690)：
- $n = 1$：顯然。
- 設 $\varphi(a^n) = \varphi(a)^n$。則
$$\varphi(a^{n+1}) = \varphi(a^na) = \varphi(a^n)\varphi(a) = \varphi(a)^n\varphi(a) = \varphi(a)^{n+1}.$$
  （同態性質 → 歸納假設 → 次方的定義。）

由**數學歸納法（PMI）**，對所有 $n\in\mathbb{N}$ 成立；由上面的論證，對所有整數成立（$n = 0$：$\varphi(e) = \bar e$）。$\blacksquare$

## 4. 證明 (1)：同構保持階

[▶ 13:00](https://youtu.be/geK7UuAMunQ?t=780)「這有什麼用？」

設 $|g| = n$，即 $g^n = e$。則
$$\varphi(g)^n = \varphi(g^n) = \varphi(e) = \bar e,$$
所以 $|\varphi(g)|\le n$ [▶ 14:00](https://youtu.be/geK7UuAMunQ?t=840)。

**不可能更小**：若 $\varphi(g)^j = \bar e$，$j<n$，則 $\varphi(g^j) = \bar e = \varphi(e)$。$\varphi$ 一對一，所以 $g^j = e$，跟 $|g| = n$ 矛盾 [▶ 14:30](https://youtu.be/geK7UuAMunQ?t=870)。

所以 $|\varphi(g)| = |g|$。無限階的情況論證類似。$\blacksquare$

「有了那個引理，這幾乎是立刻的。」

> 📘 講義的另一個證明（Thm 2.4.24 之後）：$|\langle a\rangle| = |\varphi(\langle a\rangle)|$（雙射不改變元素個數），而 $\varphi(\langle a\rangle) = \langle\varphi(a)\rangle$，所以
> $$|a| = |\langle a\rangle| = |\varphi(\langle a\rangle)| = |\langle\varphi(a)\rangle| = |\varphi(a)|.$$
> 講義說：「我喜歡這個論證。」

## 5. 證明 (2)：同構保持交換性

[▶ 15:00](https://youtu.be/geK7UuAMunQ?t=900) 老師先寫：「$\varphi(ab) = \varphi(a)\varphi(b)$，$\varphi(ba) = \varphi(b)\varphi(a)$，這兩個要相等唯一的可能是……」然後停下 [▶ 16:00](https://youtu.be/geK7UuAMunQ?t=960)：「天啊，讓我有系統一點。這是**合理性論證**，不是證明。我要證的是什麼？」

**目標**：若 $G$ 交換，則對任意 $x,y\in\bar G$，$xy = yx$。

**證明**[▶ 16:30](https://youtu.be/geK7UuAMunQ?t=990)：取任意 $x,y\in\bar G$。
1. $\varphi$ 是雙射，$\varphi^{-1}$ 存在 [▶ 17:30](https://youtu.be/geK7UuAMunQ?t=1050)。所以
$$xy = \varphi(\varphi^{-1}(x))\,\varphi(\varphi^{-1}(y)).$$
2. 同態性質：
$$= \varphi\big(\varphi^{-1}(x)\,\varphi^{-1}(y)\big).$$
3. 令 $a = \varphi^{-1}(x)$、$b = \varphi^{-1}(y)\in G$。$G$ 交換，所以 $ab = ba$ [▶ 18:00](https://youtu.be/geK7UuAMunQ?t=1080)：
$$= \varphi\big(\varphi^{-1}(y)\,\varphi^{-1}(x)\big).$$
4. 再用同態性質拆回來：
$$= \varphi(\varphi^{-1}(y))\,\varphi(\varphi^{-1}(x)) = yx.$$

所以 $\bar G$ 交換。$\blacksquare$

**反方向**[▶ 19:00](https://youtu.be/geK7UuAMunQ?t=1140)：類似。或者——**一旦證明同構的反函數是同構**，就不用再做一次（對 $\varphi^{-1}$ 套用同一個論證）。「我們還沒證那件事。」（見 [[15-L10-同態與同構]] 7.3 的講義補充。）

## 6. 【講義補充】(3)(4) 的證明

[▶ 20:00](https://youtu.be/geK7UuAMunQ?t=1200) 老師：「(3)(4) 的證明跟我剛才示範的類似。(4) 基本上是用保持結構的性質證明：這邊的方程怎麼走，那邊也得怎麼走；如果解的個數不同，會跟前面的某些結論矛盾……天啊，我說不出話了。」「也許我改天身體好一點再回來證。」

以下是講義 §2.4.1 的證明：

**(3) 循環性**（講義 Thm 2.4.24）

先證 $\varphi(\langle a\rangle) = \langle\varphi(a)\rangle$：
- $x\in\varphi(\langle a\rangle)$ ⇒ $x = \varphi(a^n) = \varphi(a)^n\in\langle\varphi(a)\rangle$。
- $y\in\langle\varphi(a)\rangle$ ⇒ $y = \varphi(a)^n = \varphi(a^n)\in\varphi(\langle a\rangle)$。

若 $G = \langle a\rangle$，則 $\bar G = \varphi(G) = \langle\varphi(a)\rangle$，所以 $\bar G$ 循環。反方向對 $\varphi^{-1}$ 用同樣論證。

**(4) 方程的解數**（講義 Thm 2.4.25）
- 若 $x^k = b$，則 $\varphi(x)^k = \varphi(x^k) = \varphi(b)$：$\varphi(x)$ 是 $y^k = \varphi(b)$ 的解。
- 若 $y^k = \varphi(b)$，則 $\varphi^{-1}(y)^k = \varphi^{-1}(y^k) = b$：$\varphi^{-1}(y)$ 是 $x^k = b$ 的解。
- 所以兩個解集之間有一一對應。

**附：同構保持中心**（講義 Thm 2.4.23）：$Z(\bar G) = \varphi(Z(G))$。所以 $G$ 交換 ⟺ $G = Z(G)$ ⟺ $\bar G = Z(\bar G)$——這是 (2) 的另一個證明。

## 7. 用來證明「不同構」

[▶ 21:30](https://youtu.be/geK7UuAMunQ?t=1290)「與其往下講，先給個例子。某種意義上，例子更重要。」

### 7.1 ℝ× 與 ℂ×

[▶ 22:00](https://youtu.be/geK7UuAMunQ?t=1320)「我喜歡這本書這個例子。」看方程
$$x^4 = 1.$$
- 【課堂討論】實數解：$x = \pm1$，**2 個**。
- 複數解 [▶ 22:30](https://youtu.be/geK7UuAMunQ?t=1350)：$i,i^2,i^3,i^4$，也就是 $x = \pm1,\pm i$，**4 個**。（驗證：$i^4 = (i^2)^2 = (-1)^2 = 1$。）

同一個方程，在兩邊的解數不同 [▶ 23:00](https://youtu.be/geK7UuAMunQ?t=1380)。由 (4)（取 $b = 1$，同構把 1 送到 1）：
$$\mathbb{R}^\times\not\cong\mathbb{C}^\times.$$
「它們不是同一個群。」

> 📘 講義 Ex 2.4.26 的另一個例子：$\mathbb{R}^\times$ 和 $(0,\infty)$（乘法）。$x^2 = 1$ 在 $\mathbb{R}^\times$ 有兩個解 $\pm1$，在 $(0,\infty)$ 只有一個解 1。所以 $\mathbb{R}^\times\not\cong(0,\infty)$——雖然 $(\mathbb{R},+)\cong(0,\infty)$（上一講）。

### 7.2 四元數群 Q₈ 與 Z₈

[▶ 23:30](https://youtu.be/geK7UuAMunQ?t=1410)「我還沒給你們看過**四元數群（quaternion group）**。」

$$Q_8 = \{\pm1,\pm i,\pm j,\pm k\},$$
乘法規則 [▶ 24:00](https://youtu.be/geK7UuAMunQ?t=1440)：
$$i^2 = j^2 = k^2 = -1,$$
$$ij = k,\quad jk = i,\quad ki = j,$$
$$ji = -k,\quad kj = -i,\quad ik = -j.$$
（「有點像 $\mathbb{R}^3$ 的外積。」$i,j,k$ 互不相同。它是 8 個四元數組成的集合，所以叫四元數 8 群。）

**$Q_8\cong\mathbb{Z}_8$？**[▶ 25:30](https://youtu.be/geK7UuAMunQ?t=1530)「兩個都是 8 元素的群，它們同構嗎？」很容易：**不**。
- $Q_8$ **不交換**：$ij = k\neq-k = ji$。
- $\mathbb{Z}_8$ 是加法群，當然交換。
- 由 (2)，不同構。

## 8. 自同構

[▶ 26:30](https://youtu.be/geK7UuAMunQ?t=1590)

> **定義（自同構 automorphism）**　從群 $G$ 到**自己**的同構。所有自同構的集合記作 $\operatorname{Aut}(G)$。

> **定理**[▶ 27:30](https://youtu.be/geK7UuAMunQ?t=1650)　$\operatorname{Aut}(G)\le\operatorname{Perm}(G)$。

**置換 vs. 自同構**[▶ 28:00](https://youtu.be/geK7UuAMunQ?t=1680)：
- $G$ 上的**置換**：任意雙射 $G\to G$，「很多很多」。
- **自同構**：不只是雙射，還要**保持結構**。
- 「我們會學到，這表示自同構必須**把生成元送到生成元**。」

> 📘 講義的證明：$\operatorname{Id}_G\in\operatorname{Aut}(G)$；若 $\varphi,\psi\in\operatorname{Aut}(G)$，則 $\varphi\circ\psi^{-1}$ 還是自同構（反函數、合成都是同構）。一步法。

## 9. 內自同構（共軛）

### 9.1 例：SL(n,ℝ) 上的共軛

[▶ 29:00](https://youtu.be/geK7UuAMunQ?t=1740)（Gallian 第 6 章 Example 7）
$$\varphi:SL(n,\mathbb{R})\to SL(n,\mathbb{R}),\qquad\varphi(X) = MXM^{-1}.$$
Gallian 要求 $M\in SL(n,\mathbb{R})$。【口頭】[▶ 29:30](https://youtu.be/geK7UuAMunQ?t=1770)「書上這個例子有點可疑——**其實不必要**。只要 $M$ 非奇異（$M\in GL(n,\mathbb{R})$），公式照樣成立。」

**反函數**[▶ 30:00](https://youtu.be/geK7UuAMunQ?t=1800)：設 $MXM^{-1} = Y$，解 $X$：左乘 $M^{-1}$、右乘 $M$：
$$\varphi^{-1}(Y) = M^{-1}YM.$$
驗證 [▶ 31:00](https://youtu.be/geK7UuAMunQ?t=1860)：$\varphi(\varphi^{-1}(Y)) = MM^{-1}YMM^{-1} = Y$；反過來也一樣。所以 $\varphi$ 是雙射。

**真的映到 $SL(n,\mathbb{R})$ 嗎？**[▶ 31:30](https://youtu.be/geK7UuAMunQ?t=1890)「我的腦子今天有點跳針。」
$$\det(MXM^{-1}) = \det M\cdot\det X\cdot\det(M^{-1}) = \det X = 1.$$
（行列式的乘積可以重排，$\det M\det M^{-1} = 1$。「所以我甚至不需要 $M\in SL$，只要可逆，行列式存在就好。」）

**保持運算**：$\varphi(XY) = MXYM^{-1} = (MXM^{-1})(MYM^{-1}) = \varphi(X)\varphi(Y)$。

所以 $\varphi$ 是 $SL(n,\mathbb{R})$ 的自同構 [▶ 33:00](https://youtu.be/geK7UuAMunQ?t=1980)。

**共軛（conjugation）**：前面乘 $M$、後面乘 $M^{-1}$。

### 9.2 一般定義

[▶ 33:30](https://youtu.be/geK7UuAMunQ?t=2010)

> **定義（內自同構 inner automorphism）**　$g\in G$。
> $$\varphi_g:G\to G,\qquad\varphi_g(x) = gxg^{-1}.$$
> 所有內自同構的集合記作 $\operatorname{Inn}(G)$。

（老師咳嗽：「有喉糖。情況可能更糟——至少我的盲腸沒事。」原來另一位老師盲腸破裂請假。「我只是肺不太好，沒什麼大不了。」）

> **定理**[▶ 35:30](https://youtu.be/geK7UuAMunQ?t=2130)　$\operatorname{Inn}(G)\le\operatorname{Aut}(G)$。

**說明**：
- 有些群的自同構**全部**都是內自同構 [▶ 36:00](https://youtu.be/geK7UuAMunQ?t=2160)。
- 「內自同構比較好找：只要探索共軛長什麼樣。找出**所有**自同構一般比較棘手。」
- 公式明顯給出 $G\to G$ 的映射：$gxg^{-1}$ 是群運算，反元素存在。

**反元素**[▶ 36:30](https://youtu.be/geK7UuAMunQ?t=2190)：設 $gxg^{-1} = y$，解出 $x = g^{-1}yg = \varphi_{g^{-1}}(y)$。所以
$$\varphi_g^{-1} = \varphi_{g^{-1}}$$
——**反函數本身也是內自同構**。

**單位元素**：$\varphi_e = \operatorname{Id}$。（學生提醒，老師：「謝謝。」）

**合成**[▶ 39:00](https://youtu.be/geK7UuAMunQ?t=2340)：可以驗證兩個內自同構的合成還是內自同構。「這些看起來是不錯的作業題，我該出給你們。」

> 📘 講義 Ex 2.9.3 給了公式：
> $$\varphi_e = \operatorname{Id}_G,\qquad\varphi_{gh} = \varphi_g\circ\varphi_h,\qquad\varphi_{g^{-1}} = (\varphi_g)^{-1}.$$
> 中間那條的計算：$\varphi_{gh}(x) = (gh)x(gh)^{-1} = g(hxh^{-1})g^{-1} = \varphi_g(\varphi_h(x))$。

【口頭】[▶ 37:30](https://youtu.be/geK7UuAMunQ?t=2250)（學生說了句什麼，老師）「我剛改完一份考卷，難說——可能是瀕死經驗。」接著講了一個物理系研究生說另一位教授「剛經歷瀕死經驗卻不知道」的故事：「別念物理，危險。」

### 9.3 其他自同構：複數共軛、Q₈

**複數共軛**[▶ 39:00](https://youtu.be/geK7UuAMunQ?t=2340)：$\overline{a+bi} = a-bi$。
- $\overline{z+w} = \bar z+\bar w$ ⇒ 複數共軛是 $(\mathbb{C},+)$ 的自同構。
- $\overline{zw} = \bar z\,\bar w$（「稍微沒那麼明顯，但是對的」）⇒ 也是 $(\mathbb{C}^\times,\cdot)$ 的自同構。
- 【口頭】「我得出一些複數的作業給你們，我覺得你們懂得不夠。」

**$Q_8$ 的猜測**[▶ 41:00](https://youtu.be/geK7UuAMunQ?t=2460)：老師「推測」把 $\pm i,\pm j,\pm k$ 都變號、$\pm1$ 不動的映射是 $Q_8$ 的自同構（「我只是推測，但我很確定」）。

> ⚠️ **這個猜測是錯的**（筆記驗證，非課堂內容）：設 $\varphi$ 把 $i,j,k$ 變號。則 $\varphi(ij) = \varphi(k) = -k$，但 $\varphi(i)\varphi(j) = (-i)(-j) = ij = k$。$-k\neq k$，所以**不是同態**。（$Q_8$ 的自同構要保持 $ij = k$，例如把 $i\mapsto j$、$j\mapsto k$、$k\mapsto i$ 的輪換才是。）

【口頭】[▶ 42:00](https://youtu.be/geK7UuAMunQ?t=2520)「Gallian 的 Example 12 很難看懂。我想用我們的 $x,y$ 記號重做。如果你喜歡那些 $V$、$D'$，很好；但直接寫 $R_{270}$、$R_{90}$……已經夠多了。」

## 10. 定理：Aut(Zn) ≅ U(n)

[▶ 42:30](https://youtu.be/geK7UuAMunQ?t=2550)「有一個情況，我們可以很漂亮地算出自同構：」

> **定理**（Gallian Thm 6.5；講義 Thm 2.9.6）
> $$\operatorname{Aut}(\mathbb{Z}_n)\cong U(n).$$

「在我愚蠢地試著證明之前，先看例子。」

**例：$\operatorname{Aut}(\mathbb{Z}_{10})$**[▶ 44:00](https://youtu.be/geK7UuAMunQ?t=2640)

設 $\alpha:\mathbb{Z}_{10}\to\mathbb{Z}_{10}$ 是自同構。

**Step 1：$\alpha$ 由 $\alpha(1)$ 決定**[▶ 45:00](https://youtu.be/geK7UuAMunQ?t=2700)：
$$\alpha(k) = \alpha(\underbrace{1+1+\cdots+1}_{k\text{ 個}}) = \underbrace{\alpha(1)+\cdots+\alpha(1)}_{k\text{ 個}} = k\,\alpha(1).$$
（加法群，同態保持加法。）「這個簡單的論證，對證明也一樣好用。」

**Step 2：$\alpha(1)$ 必須是生成元**[▶ 46:00](https://youtu.be/geK7UuAMunQ?t=2760)：同構保持階，
$$|\alpha(1)| = |1| = 10.$$
$\mathbb{Z}_{10}$ 裡 10 階的元素就是**生成元**，也就是 $U(10)$ 的元素 [▶ 47:00](https://youtu.be/geK7UuAMunQ?t=2820)。
$$\alpha(1)\in U(10) = \{1,3,7,9\}.$$
（「如果我真的證了循環群定理的細節，我們會發現：同構把生成元送到生成元。」）

**四個自同構**[▶ 47:30](https://youtu.be/geK7UuAMunQ?t=2850)：
$$\alpha_1(x) = x,\quad\alpha_3(x) = 3x,\quad\alpha_7(x) = 7x,\quad\alpha_9(x) = 9x.$$

**合成**[▶ 48:00](https://youtu.be/geK7UuAMunQ?t=2880)：
$$(\alpha_3\circ\alpha_9)(x) = 3(9x) = 27x = 7x = \alpha_7(x)\pmod{10}.$$
- 顯然可交換：先 3 後 9 或先 9 後 3，都是 $\alpha_7$。
- 一般：$\alpha_a\circ\alpha_b = \alpha_{ab\bmod10}$。

| $\circ$ | $\alpha_1$ | $\alpha_3$ | $\alpha_7$ | $\alpha_9$ |
|---|---|---|---|---|
| $\alpha_1$ | $\alpha_1$ | $\alpha_3$ | $\alpha_7$ | $\alpha_9$ |
| $\alpha_3$ | $\alpha_3$ | $\alpha_9$ | $\alpha_1$ | $\alpha_7$ |
| $\alpha_7$ | $\alpha_7$ | $\alpha_1$ | $\alpha_9$ | $\alpha_3$ |
| $\alpha_9$ | $\alpha_9$ | $\alpha_7$ | $\alpha_3$ | $\alpha_1$ |

（課堂開始填，「你們可以開始填這張表」；上表依 $\alpha_a\circ\alpha_b = \alpha_{ab}$ 補齊。跟 $U(10)$ 的 Cayley 表一模一樣。）

**同構是什麼？**[▶ 49:00](https://youtu.be/geK7UuAMunQ?t=2940)
- 「最懶的寫法」：$\varphi(\alpha_k) = k$。
- 「比較不令人不安的寫法」[▶ 50:00](https://youtu.be/geK7UuAMunQ?t=3000)：
$$\varphi(\alpha) = \alpha(1).$$
  例如 $\alpha_3(1) = 3$。

**一般情況**[▶ 50:00](https://youtu.be/geK7UuAMunQ?t=3000)：對 $\gcd(m,n) = 1$，$\alpha_m(x) = mx$ 是 $\mathbb{Z}_n$ 的自同構；而
$$\varphi:\operatorname{Aut}(\mathbb{Z}_n)\to U(n),\qquad\varphi(\alpha) = \alpha(1)$$
是同構。（講義：證明留作 Mission 3。）

> 📘 講義 Ex 2.9.5：$\operatorname{Aut}(\mathbb{Z}_3)$。生成元 1、2，所以 $\alpha_1(k) = k$、$\alpha_2(k) = 2k$。$\alpha_2\circ\alpha_2(k) = 4k = k$，所以 $\alpha_2^2 = \operatorname{Id}$。$\operatorname{Aut}(\mathbb{Z}_3)\cong U(3)$。Gallian 的例子是 $\operatorname{Aut}(\mathbb{Z}_8)\cong U(8)$。

> 📘 講義 Ex 2.9.7（用 $x,y$ 記號算 $D_3$ 的自同構）：$D_3 = \{1,x,x^2,y,xy,x^2y\}$。若 $\varphi(x) = x$、$\varphi(y) = x^2y$，則
> $$\varphi(x^m) = x^m = x\,x^m\,x^{-1},\qquad\varphi(x^my) = x^mx^2y = x^mxyx^{-1} = x(x^my)x^{-1}$$
> （用 $yx^{-1} = xy$，即 $xyx^{-1} = x^2y$）。所以 $\varphi = \varphi_x$ 是**內自同構**。

## 11. 一頁速查表

### 11.1 同構保持的性質（不變量）

| 性質 | 證明的關鍵一步 |
|---|---|
| $\varphi(a^{-1}) = \varphi(a)^{-1}$ | $\varphi(a)\varphi(a^{-1}) = \varphi(e) = \bar e$ |
| $\varphi(a^n) = \varphi(a)^n$ | 正整數歸納，負數用上一條 |
| 元素的階 | $\varphi(g)^n = \varphi(g^n) = \bar e$；單射 ⇒ 不會更小 |
| 交換性 | $xy = \varphi(\varphi^{-1}x\,\varphi^{-1}y) = \varphi(\varphi^{-1}y\,\varphi^{-1}x) = yx$ |
| 循環性 | $\varphi(\langle a\rangle) = \langle\varphi(a)\rangle$ |
| $x^k = b$ 的解數 | $\varphi$、$\varphi^{-1}$ 在解集間來回 |
| 中心 | $Z(\bar G) = \varphi(Z(G))$ |

### 11.2 不同構的例子

| 兩個群 | 為什麼不同構 |
|---|---|
| $\mathbb{R}^\times$、$\mathbb{C}^\times$ | $x^4 = 1$：2 個解 vs. 4 個解 |
| $\mathbb{R}^\times$、$(0,\infty)$ | $x^2 = 1$：2 個解 vs. 1 個解 |
| $Q_8$、$\mathbb{Z}_8$ | $Q_8$ 不交換 |

### 11.3 自同構

| 名稱 | 內容 |
|---|---|
| $\operatorname{Aut}(G)$ | $G\to G$ 的同構；$\le\operatorname{Perm}(G)$ |
| 內自同構 $\varphi_g$ | $\varphi_g(x) = gxg^{-1}$（共軛）；$\operatorname{Inn}(G)\le\operatorname{Aut}(G)$ |
| $\varphi_g^{-1}$ | $= \varphi_{g^{-1}}$ |
| $\varphi_{gh}$ | $= \varphi_g\circ\varphi_h$ |
| $\operatorname{Aut}(\mathbb{Z}_n)\cong U(n)$ | $\alpha(k) = k\alpha(1)$；$\alpha(1)$ 必須是生成元；同構 $\alpha\mapsto\alpha(1)$ |

## 附：本集一句話總結

> **同構保持一切「群論性質」——元素的階（靠 $\varphi(a^n) = \varphi(a)^n$）、交換性、循環性、方程 $x^k = b$ 的解數——所以只要一個不同就能斷定不同構（$\mathbb{R}^\times\not\cong\mathbb{C}^\times$、$Q_8\not\cong\mathbb{Z}_8$）；群到自己的同構叫自同構，其中共軛 $x\mapsto gxg^{-1}$ 叫內自同構；$\mathbb{Z}_n$ 的自同構完全由 1 送到哪個生成元決定，所以 $\operatorname{Aut}(\mathbb{Z}_n)\cong U(n)$。**
