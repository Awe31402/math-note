## 1. 群作用的定義

### 1.1 兩條公理

[▶ 00:30](https://youtu.be/Px2lDLRVzQE?t=30)（老師開玩笑：「group action」不是那種能賺錢的集體行動。）

> **定義（群作用）**　$G$ 是群，$S$ 是集合。函數
> $$\star : G\times S\to S$$
> 叫做 $G$ 在 $S$ 上的**群作用**，如果：
> 1. $a\star(b\star x) = (ab)\star x$，對所有 $a,b\in G$、$x\in S$；
> 2. $e\star x = x$，對所有 $x\in S$（$e$ 是 $G$ 的單位元）。

- **輸入**：一個群元素、一個集合元素。**輸出**：一個集合元素。
- **白話**[▶ 09:00](https://youtu.be/Px2lDLRVzQE?t=540)：先用 $b$ 作用、再用 $a$ 作用，等於先把 $a,b$ 乘起來，再一次作用。
- 單位元什麼都不動。

### 1.2 兩種乘法別搞混

[▶ 02:30](https://youtu.be/Px2lDLRVzQE?t=150) 公理 1 看起來像結合律，**但不是**：

$$\underbrace{a\star(b\star x)}_{\text{兩次作用}} = \underbrace{(ab)}_{\text{群乘法}}\star x$$

- **並列** $ab$：$G$ 裡的群乘法。
- **星號** $\star$：群作用。

老師說一開始用 $\star$ 比較清楚，等熟了就省略，就像群乘法我們早就不寫星號一樣 [▶ 02:00](https://youtu.be/Px2lDLRVzQE?t=120)。

### 1.3 【口頭】公理的順序

[▶ 12:30](https://youtu.be/Px2lDLRVzQE?t=750)【口頭】老師看了三本書，每本的公理順序都不一樣。他覺得單位元那條「應該是第一條」，然後自嘲：「誰在乎……顯然我在乎。」

> 📘 講義（Definition 3.6.1）就是把 $e\star x = x$ 放第一條、$a\star(b\star x)=(ab)\star x$ 放第二條。**本筆記照課堂順序**：結合那條是 (1)、單位那條是 (2)。後面證明引用「公理 1、2」時都是這個順序。

## 2. 四個例子

### 2.1 置換群作用在集合上

[▶ 05:30](https://youtu.be/Px2lDLRVzQE?t=330) **例 1**：任何一個置換群都決定一個群作用。

回憶：$S$ 上的**置換（permutation）**就是雙射 $\sigma:S\to S$。全部置換組成群，老師記作 $\operatorname{Perm}(S)$（也常寫 $\operatorname{Sym}(S)$）。取一個子群 $G\le\operatorname{Perm}(S)$。

**定義作用**[▶ 08:00](https://youtu.be/Px2lDLRVzQE?t=480)：直接代值。
$$\sigma\star x = \sigma(x).$$

【口頭】[▶ 07:30](https://youtu.be/Px2lDLRVzQE?t=450) 老師抱怨：書上只寫「顯然」，「那我們把他的想法補完吧」。

**驗證公理 2**[▶ 08:30](https://youtu.be/Px2lDLRVzQE?t=510)：$G$ 是群，所以單位元——恆等映射 $\operatorname{id}_S$——在 $G$ 裡。
$$\operatorname{id}_S\star x = \operatorname{id}_S(x) = x.\ ✓$$

**驗證公理 1**[▶ 09:30](https://youtu.be/Px2lDLRVzQE?t=570)：取 $\sigma_1,\sigma_2\in G$。
$$
\begin{aligned}
\sigma_1\star(\sigma_2\star x) &= \sigma_1\star\sigma_2(x) &&(\text{作用的定義})\\
&= \sigma_1(\sigma_2(x)) &&(\text{作用的定義})\\
&= (\sigma_1\circ\sigma_2)(x) &&(\text{函數合成的定義})\\
&= (\sigma_1\circ\sigma_2)\star x. ✓
\end{aligned}
$$

這裡 $\operatorname{Perm}(S)$ 的「群乘法」就是函數合成 $\circ$。

> 📘 講義補一句：取 $S=G$、用「左乘 $g$」得到的置換，就是 **Cayley 定理**證明裡的那一套。所以 Cayley 定理可以看成「用群作用研究群本身」的例子。更有趣的應用是 $S$ 和 $G$ **不同**的時候。

### 2.2 子群用左乘作用在大群上

[▶ 10:30](https://youtu.be/Px2lDLRVzQE?t=630) **例 2**：$H\le G$。$H$ 用群乘法作用在 $G$ 上。

**小心角色互換**[▶ 11:30](https://youtu.be/Px2lDLRVzQE?t=690)：

| 定義裡的 | 在這個例子裡是 |
|---|---|
| 群「$G$」 | $H$ |
| 集合「$S$」 | $G$ |

【課堂討論】[▶ 12:00](https://youtu.be/Px2lDLRVzQE?t=720) 老師問 $h\star x$ 該怎麼定義，學生答：$hx$。

$$h\star x = hx\qquad(h\in H,\ x\in G).$$

**驗證公理 2**：$e\star x = ex = x$ ✓（$e\in H$，因為 $H$ 是子群。）

**驗證公理 1**[▶ 12:30](https://youtu.be/Px2lDLRVzQE?t=750)：取 $a,b\in H$、$x\in G$。
$$
a\star(b\star x) = a\star(bx) = a(bx) = (ab)x = (ab)\star x. ✓
$$
中間那一步 $a(bx)=(ab)x$ 用的是 **$G$ 的結合律**。

**特例**[▶ 13:30](https://youtu.be/Px2lDLRVzQE?t=810)：取 $H=G$，**群用自己的乘法作用在自己身上**。

### 2.3 非零純量作用在向量空間上

[▶ 14:00](https://youtu.be/Px2lDLRVzQE?t=840) **例 3**：$F$ 是體，令 $G=F^\times=F\setminus\{0\}$（$F$ 去掉 0）。這是乘法群。例如：非零實數、非零複數、非零有理數、$\mathbb{Z}_p$ 去掉 0。

$V$ 是 $F$ 上的向量空間。定義
$$c\star\mathbf v = c\mathbf v\qquad(\text{純量乘法}).$$

兩條公理正好是向量空間的公理 [▶ 15:00](https://youtu.be/Px2lDLRVzQE?t=900)：
- $1\mathbf v = \mathbf v$ ✓
- $a(b\mathbf v) = (ab)\mathbf v$ ✓

【口頭】[▶ 15:30](https://youtu.be/Px2lDLRVzQE?t=930) 純量乘法其實比群作用多一點東西：它還牽涉到 0（例如 $0\mathbf v=\mathbf 0$）。但只看**非零**純量，它就是群作用。

### 2.4 可逆矩陣作用在行向量上

[▶ 15:30](https://youtu.be/Px2lDLRVzQE?t=930) **例 4**（老師說「我比較喜歡這個，比較好玩」）：

- $V=F^n$：分量在 $F$ 裡的 $n$ 維**行向量**（column vector）。
- $G\le GL(n,F)$，其中
$$GL(n,F) = \{A : A\text{ 是 }n\times n\text{ 矩陣，}\det A\neq 0\}$$
是**一般線性群**（general linear group）[▶ 16:00](https://youtu.be/Px2lDLRVzQE?t=960)。

【課堂討論】[▶ 16:30](https://youtu.be/Px2lDLRVzQE?t=990) 老師問作用該是什麼，要滿足 $I\star\mathbf v=\mathbf v$ 和 $A\star(B\star\mathbf v)=(AB)\star\mathbf v$。學生答：矩陣乘法。

$$A\star\mathbf v = A\mathbf v.$$

- $I\mathbf v = \mathbf v$ ✓
- $A(B\mathbf v) = (AB)\mathbf v$ ✓（矩陣乘法的結合律）

【口頭】[▶ 17:30](https://youtu.be/Px2lDLRVzQE?t=1050)「如果你跟我一樣，看完這四個例子你會開始想：**什麼東西不是群作用？**這是很廣的一類例子。」

### 2.5 【講義補充】右邊的作用、限制到子群

這兩點課堂沒講，講義有（Example 3.6.4、3.6.6 後的說明）。

**右邊的作用**：$H\le G$，定義
$$h\bullet x = xh^{-1}.$$
為什麼要加反元素？驗證公理 1：
$$
(ab)\bullet x = x(ab)^{-1} = xb^{-1}a^{-1} = (b\bullet x)a^{-1} = a\bullet(b\bullet x). ✓
$$
關鍵是**襪子-鞋子公式** $(ab)^{-1}=b^{-1}a^{-1}$。如果寫成 $h\bullet x = xh$，就會得到 $(ab)\bullet x = xab = b\bullet(a\bullet x)$，順序反了，不是（左）群作用。

**限制到子群**：如果 $G$ 作用在 $S$ 上，任何 $H\le G$ 用同一條規則也作用在 $S$ 上。例如例 4 不一定要用整個 $GL(n,F)$，任何子群都行。

## 3. 命題：群作用就是到置換群的同態

[▶ 18:00](https://youtu.be/Px2lDLRVzQE?t=1080)

> **命題**　$G$ 是群，$S$ 是集合。
> - 任何群同態 $G\to\operatorname{Perm}(S)$ 都定義一個 $G$ 在 $S$ 上的作用。
> - 反過來，$G$ 在 $S$ 上的每個作用都是這樣來的。

（老師抄的時候寫成「any group **of** homomorphism**s**」，隨即更正：多了一個 of 和一個 s，「完全不必要而且很有破壞性」[▶ 18:30](https://youtu.be/Px2lDLRVzQE?t=1110)。）

> 📘 講義（Theorem 3.6.7）的證明欄寫著：「課堂上 10-14-16 給過了，希望之後打出來……」。**講義沒有證明**，所以 3.1–3.3 的整段證明都是【口頭】，只有這集影片有。

### 3.1 從同態得到作用

[▶ 20:00](https://youtu.be/Px2lDLRVzQE?t=1200)【口頭】

**設定**：$\varphi:G\to\operatorname{Perm}(S)$ 是同態。對每個 $a\in G$，$\varphi(a)$ 是 $S$ 上的一個置換，記作
$$\lambda_a = \varphi(a).$$

**同態性質**[▶ 21:00](https://youtu.be/Px2lDLRVzQE?t=1260)：$\operatorname{Perm}(S)$ 的乘法是合成，所以
$$\lambda_a\circ\lambda_b = \varphi(a)\varphi(b) = \varphi(ab) = \lambda_{ab}.$$

**定義作用**[▶ 23:30](https://youtu.be/Px2lDLRVzQE?t=1410)：
$$a\star x = \lambda_a(x).$$
$\lambda_a(x)$ 是 $S$ 的元素，所以 $\star$ 確實是 $G\times S\to S$ 的函數。

**驗證公理 2**[▶ 24:00](https://youtu.be/Px2lDLRVzQE?t=1440)：同態把單位元送到單位元，$\operatorname{Perm}(S)$ 的單位元是恆等映射，所以 $\lambda_e=\operatorname{id}_S$：
$$e\star x = \lambda_e(x) = \operatorname{id}_S(x) = x. ✓$$

**驗證公理 1**：
$$
(ab)\star x = \lambda_{ab}(x) = (\lambda_a\circ\lambda_b)(x) = \lambda_a(\lambda_b(x)) = a\star(b\star x). ✓
$$

（老師寫到黑板邊緣，說「容我跳一步」[▶ 24:30](https://youtu.be/Px2lDLRVzQE?t=1470)；上面是補完的版本。）

**跟例 1 的差別**[▶ 23:00](https://youtu.be/Px2lDLRVzQE?t=1380)：例 1 的群元素**本身就是**置換。這裡的群元素是抽象的，同態把**不同的置換分配給不同的群元素**。「是稍微不一樣的動物。」

### 3.2 從作用得到同態

[▶ 25:00](https://youtu.be/Px2lDLRVzQE?t=1500)【口頭】

**設定**：$\star:G\times S\to S$ 是群作用。要造一個同態 $\varphi:G\to\operatorname{Perm}(S)$。

**Step 1：定義 $\varphi(g)$**[▶ 26:00](https://youtu.be/Px2lDLRVzQE?t=1560)

$\varphi(g)$ 要是 $S\to S$ 的函數。定義函數就是說它把每個 $x$ 送到哪。手上唯一能用的工具就是作用：
$$\varphi(g)(x) = g\star x.$$
[▶ 27:30](https://youtu.be/Px2lDLRVzQE?t=1650) 它是單值的（同一個 $x$ 只給一個答案），因為 $\star$ 本身是函數。

接下來要檢查兩件事：(a) $\varphi$ 是同態；(b) 每個 $\varphi(g)$ 真的是置換（雙射）。

**Step 2：$\varphi$ 是同態**[▶ 29:00](https://youtu.be/Px2lDLRVzQE?t=1740)

對任意 $x\in S$：
$$
\begin{aligned}
\varphi(gh)(x) &= (gh)\star x &&(\varphi\text{ 的定義})\\
&= g\star(h\star x) &&(\text{公理 1})\\
&= g\star\left(\varphi(h)(x)\right) &&(\varphi\text{ 的定義})\\
&= \varphi(g)\left(\varphi(h)(x)\right) &&(\varphi\text{ 的定義})\\
&= \left(\varphi(g)\circ\varphi(h)\right)(x).
\end{aligned}
$$
所以 $\varphi(gh)=\varphi(g)\circ\varphi(h)$。

【口頭】[▶ 30:00](https://youtu.be/Px2lDLRVzQE?t=1800)「這很陰險」：最後一行的 $\circ$ 是**函數合成**，也就是 $\operatorname{Perm}(S)$ 的群乘法。

### 3.3 【課堂討論】為什麼它是置換

[▶ 30:30](https://youtu.be/Px2lDLRVzQE?t=1830) 老師要證 $\varphi(g)$ 是雙射時卡住了，開玩笑說要「打電話問朋友」，學生回「你已經問過觀眾了」。接著學生提醒：**$G$ 是群**，有反元素。老師：「喔，我是白痴。」又說：「等我給你們看為什麼它是置換，你們會很失望（因為太簡單）。」

**單射**[▶ 31:30](https://youtu.be/Px2lDLRVzQE?t=1890)

設 $\varphi(g)(x)=\varphi(g)(y)$，也就是
$$g\star x = g\star y.$$
兩邊都是 $S$ 的元素。兩邊同時用 $g^{-1}$ **作用**（老師強調：不是「乘」$g^{-1}$，是「作用」）：
$$
\begin{aligned}
g^{-1}\star(g\star x) &= g^{-1}\star(g\star y)\\
(g^{-1}g)\star x &= (g^{-1}g)\star y &&(\text{公理 1})\\
e\star x &= e\star y &&(\text{反元素的定義})\\
x &= y. &&(\text{公理 2})
\end{aligned}
$$
[▶ 33:00](https://youtu.be/Px2lDLRVzQE?t=1980) 老師指出：**兩條公理都用到了**，這就是為什麼定義要有兩條。

（老師說也可以算核，但直接證單射比較容易。）

**滿射**[▶ 34:00](https://youtu.be/Px2lDLRVzQE?t=2040)

給任意 $y\in S$，要找 $x\in S$ 使 $\varphi(g)(x)=y$，也就是解
$$g\star x = y.$$
【課堂討論】[▶ 34:30](https://youtu.be/Px2lDLRVzQE?t=2070) 老師提示「空格裡有個星號」，學生答出：
$$x = g^{-1}\star y.$$
檢查：
$$g\star(g^{-1}\star y) = (gg^{-1})\star y = e\star y = y. ✓$$

所以 $\varphi(g)$ 是雙射，$\varphi(g)\in\operatorname{Perm}(S)$。再加上 Step 2，$\varphi$ 是同態。$\blacksquare$

### 3.4 換個角度看群作用

[▶ 35:00](https://youtu.be/Px2lDLRVzQE?t=2100)【口頭】

> 群作用 $G\times S\to S$ 和同態 $G\to\operatorname{Perm}(S)$ 是**同一件事的兩種寫法**。

| 群作用的寫法 | 同態的寫法 |
|---|---|
| $g\star x$ | $\varphi(g)(x)$ |
| 公理 1：$g\star(h\star x)=(gh)\star x$ | $\varphi(g)\circ\varphi(h)=\varphi(gh)$ |
| 公理 2：$e\star x = x$ | $\varphi(e)=\operatorname{id}_S$ |

所以每個群元素 $g$ 都對應一個「把 $S$ 打亂的方式」，而且這個對應尊重群乘法。

## 5. 軌道、穩定子、固定點集

[▶ 36:30](https://youtu.be/Px2lDLRVzQE?t=2190)

設 $G$ 作用在 $S$ 上，$x\in S$。

> **定義**
> - $x$ 的**軌道（orbit）**：
> $$\mathcal O(x) = \{s\in S : s = g\star x\text{，對某個 }g\in G\} = \{g\star x : g\in G\}.$$
> - $x$ 的**穩定子（stabilizer）**[▶ 37:30](https://youtu.be/Px2lDLRVzQE?t=2250)：
> $$G_x = \{g\in G : g\star x = x\}.$$
> - **被 $G$ 固定的子集**（subset of $S$ fixed by $G$）[▶ 38:30](https://youtu.be/Px2lDLRVzQE?t=2310)：
> $$S^G = \{x\in S : g\star x = x\text{，對所有 }g\in G\}.$$

**白話**：
- 軌道：$x$ 被 $G$ 裡所有元素推一推，能跑到的地方。
- 穩定子：$G$ 裡推不動 $x$ 的那些元素。
- 固定點集：誰都推不動的點。

**記號說明**：
- 【口頭】[▶ 37:00](https://youtu.be/Px2lDLRVzQE?t=2220) 書上用 $a$ 代表群元素，老師說「這很蠢」，改用 $g$。「沒事沒事，它是本好書。」
- 【口頭】[▶ 38:00](https://youtu.be/Px2lDLRVzQE?t=2280) 老師說 $S^G$ 這個記號他「不是百分之百確定」，先這樣寫。
- 講義把軌道記為 $\mathcal O(x)$。

**別名**[▶ 39:30](https://youtu.be/Px2lDLRVzQE?t=2370)：穩定子也叫 **isotropy subgroup**（迷向子群）。老師說某本書（⚠️ 逐字稿缺字：字幕是「freely」，推測是 **Fraleigh**《A First Course in Abstract Algebra》）用這個名字。

**穩定子是子群**：老師說「事實上可以證明它是 $G$ 的子群」，但這集沒證。

> 📘 講義有證明（Theorem 3.6.11，下一集講）。用兩步子群判別法：
> - $e\star x = x$，所以 $e\in G_x$，非空。
> - $a,b\in G_x$ ⇒ $(ab)\star x = a\star(b\star x) = a\star x = x$，所以 $ab\in G_x$。
> - $a\in G_x$ ⇒ $x = e\star x = (a^{-1}a)\star x = a^{-1}\star(a\star x) = a^{-1}\star x$，所以 $a^{-1}\in G_x$。

**最重要的區別**[▶ 41:00](https://youtu.be/Px2lDLRVzQE?t=2460)：

| | 住在哪裡 |
|---|---|
| 軌道 $\mathcal O(x)$ | $S$ 的子集 |
| 穩定子 $G_x$ | $G$ 的子集（而且是子群） |

它們住在不同的地方，但互相有關係（第 7 節預告）。

## 6. 例子：子群左乘作用的軌道與穩定子

[▶ 40:00](https://youtu.be/Px2lDLRVzQE?t=2400) 老師說例 3、例 4 有點太抽象，先算例 2：$H\le G$，$h\star x = hx$，集合是 $G$。

### 6.1 【課堂討論】軌道是左陪集還是右陪集

[▶ 41:30](https://youtu.be/Px2lDLRVzQE?t=2490) 照定義寫出 $x\in G$ 的軌道（「群」是 $H$，所以 $g$ 換成 $h$）：
$$\mathcal O(x) = \{s\in G : s = hx\text{，對某個 }h\in H\} = \{hx : h\in H\}.$$

【課堂討論】[▶ 42:30](https://youtu.be/Px2lDLRVzQE?t=2550) 老師問：這是左陪集還是右陪集？全班多數投「左陪集」。老師：「喔天啊，真的嗎？你們要害死我。」

**答案：右陪集** $Hx$。

記法：看**陪集代表 $x$ 在哪一邊**。$H$ 從左邊乘上來，$x$ 留在右邊，所以叫右陪集。

$$\boxed{\text{左乘作用的軌道}=\text{右陪集 } Hx}$$

> 📘 講義補充：用 2.5 的右邊作用 $h\bullet x = xh^{-1}$，軌道是 $\{xh^{-1}:h\in H\} = xH$，也就是**左陪集**。

### 6.2 穩定子

[▶ 43:30](https://youtu.be/Px2lDLRVzQE?t=2610) 要找 $h\in H$ 使 $hx = x$。

【課堂討論】學生答：只有 $e$。

**證明**：$hx = x$，右邊乘 $x^{-1}$ 得 $h = e$。所以
$$H_x = \{e\}\quad\text{對每個 }x\in G.$$

> 📘 講義補充：固定點集 $S^G$ 是空的——除非 $H=\{e\}$，那時整個 $G$ 都被固定。

**陪集的性質**[▶ 44:30](https://youtu.be/Px2lDLRVzQE?t=2670)：老師問「右陪集跟群有什麼關係？」學生答「它的大小整除群的階」。老師補充：陪集的**個數**是指數（index）$[G:H]$，這是 Lagrange 定理的推論。

### 6.3 【講義補充】純量作用的軌道與穩定子

這段課堂沒講（講義 Example 3.6.10）。看 2.3 的例子，$F^\times$ 作用在 $F^n$ 上：

| 點 | 軌道 | 穩定子 |
|---|---|---|
| $\mathbf v\neq\mathbf 0$ | $\{c\mathbf v : c\neq 0\}$ ＝ 過原點、方向 $\mathbf v$ 的直線，**去掉原點** | $\{1\}$ |
| $\mathbf v=\mathbf 0$ | $\{\mathbf 0\}$ | 整個 $F^\times$ |

為什麼去掉原點：$c\in F^\times$ 不能是 0。為什麼 $\mathbf v\neq\mathbf 0$ 的穩定子是 $\{1\}$：$c\mathbf v=\mathbf v$ ⇒ $(c-1)\mathbf v=\mathbf 0$，$\mathbf v\neq\mathbf 0$ 所以 $c=1$。

## 7. 預告：軌道穩定子定理

## 8. 一頁速查表

### 8.1 定義

| 名稱 | 定義 |
|---|---|
| 群作用 $\star:G\times S\to S$ | (1) $a\star(b\star x)=(ab)\star x$；(2) $e\star x=x$ |
| 軌道 $\mathcal O(x)$ | $\{g\star x : g\in G\}\subseteq S$ |
| 穩定子 $G_x$ | $\{g\in G : g\star x = x\}\le G$ |
| 固定點集 $S^G$ | $\{x\in S : g\star x=x,\ \forall g\}$ |

### 8.2 例子

| 群 | 集合 | 作用 | 軌道 | 穩定子 |
|---|---|---|---|---|
| $G\le\operatorname{Perm}(S)$ | $S$ | $\sigma(x)$ | | |
| $H\le G$ | $G$ | $hx$ | 右陪集 $Hx$ | $\{e\}$ |
| $H\le G$ | $G$ | $xh^{-1}$ | 左陪集 $xH$ | $\{e\}$ |
| $F^\times$ | 向量空間 $V$ | $c\mathbf v$ | 去掉原點的直線（$\mathbf v\neq\mathbf 0$） | $\{1\}$（$\mathbf v\neq\mathbf 0$） |
| $G\le GL(n,F)$ | $F^n$ | $A\mathbf v$ | | |

### 8.3 命題：群作用 ⟺ 同態 $G\to\operatorname{Perm}(S)$

- **對應**：$g\star x = \varphi(g)(x)$。
- **同態 ⇒ 作用**：$\varphi(e)=\operatorname{id}$ 給公理 2；$\varphi(ab)=\varphi(a)\circ\varphi(b)$ 給公理 1。
- **作用 ⇒ 同態**：
  - 同態：$(gh)\star x = g\star(h\star x)$，就是公理 1。
  - **關鍵一步——為什麼 $\varphi(g)$ 是雙射**：用 $g^{-1}$ **作用**。
    - 單射：$g\star x=g\star y$ ⇒ 兩邊作用 $g^{-1}$ ⇒ $x=y$。
    - 滿射：$g\star x=y$ 的解是 $x=g^{-1}\star y$。
  - 兩條公理都要用到。

### 8.4 穩定子是子群（講義 Thm 3.6.11）

關鍵一步：$a\in G_x$ ⇒ $x=(a^{-1}a)\star x = a^{-1}\star(a\star x) = a^{-1}\star x$。

### 8.5 常見陷阱

- 公理 1 **不是**結合律：左邊是兩次作用，右邊是群乘法。
- $hx$ 的集合是**右**陪集（看 $x$ 在哪邊）。
- 右邊作用要寫 $xh^{-1}$，不是 $xh$。
- 軌道在 $S$ 裡，穩定子在 $G$ 裡。

### 8.6 術語

| 中文 | English |
|---|---|
| 群作用 | group action |
| 作用（動詞） | act (on) |
| 置換群 | $\operatorname{Perm}(S)$ / $\operatorname{Sym}(S)$ |
| 一般線性群 | general linear group $GL(n,F)$ |
| 軌道 | orbit |
| 穩定子 | stabilizer |
| 迷向子群 | isotropy subgroup |
| 固定點集 | subset fixed by $G$, $S^G$ |
| 軌道穩定子定理 | orbit-stabilizer theorem |

## 附：本集一句話總結

> **群作用就是讓群元素「推動」集合裡的點，而且推兩次等於先乘再推；它和「群到置換群的同態」是同一件事——證明的關鍵是用 $g^{-1}$ 作用把 $g$ 撤銷，所以每個 $g$ 都是雙射。每個點有軌道（能跑到哪，住在 $S$）和穩定子（誰推不動它，住在 $G$），下一集把兩者的大小連起來。**
