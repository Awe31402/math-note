# 第 27 集 · L18：群作用 [▶ 影片](https://www.youtube.com/watch?v=Px2lDLRVzQE&list=PLBY4G2o7DhF0JCgapYKrqibGaJuvV4Gkb)

← 上一集：[[26-L17-一點數論]] ｜ [總目錄](../README.md) ｜ 下一集：[[28-L19-軌道穩定子定理]] →

## 本集概要

- **群作用 (group action)** $G\times S\to S$：$a\star(b\star x) = (ab)\star x$，$e\star x = x$。
- 例子：置換群作用在集合上；子群用乘法作用在大群上；非零純量作用在向量空間上；矩陣群作用在 $F^n$ 上。
- **命題**：群作用 $\iff$ 同態 $G\to\operatorname{Sym}(S)$。
- **軌道 (orbit)**、**穩定子 (stabilizer)**（又叫 **isotropy subgroup**）、**固定點集**。
- 例：子群 $H$ 左乘作用在 $G$ 上，軌道是**右陪集** $Hx$，穩定子是 $\{e\}$。
- 預告：軌道分割集合；**軌道穩定子定理**能解計數問題。

> 📘 講義對應：2018 講義 §3.6 Lecture 16「group actions and the orbit stabilizer theorem」前半（p.111–115）。老師說本講「直接偷」自 Beachy & Blair《Abstract Algebra》第 3 版。

## 筆記

### 1. 群作用的定義 [▶ 00:30](https://youtu.be/Px2lDLRVzQE?t=30)

（「group action」不是能賺錢的那種集體行動 [▶ 00:30](https://youtu.be/Px2lDLRVzQE?t=30)。）

> **定義**　$G$ 是群，$S$ 是集合。函數 $\star:G\times S\to S$ 叫做 $G$ 在 $S$ 上的**群作用**，若
> 1. $a\star(b\star x) = (ab)\star x$，對所有 $a,b\in G$、$x\in S$；
> 2. $e\star x = x$，對所有 $x\in S$。

- (1) 像結合律，但不完全是：左邊兩個 $\star$ 是**作用**，右邊 $ab$ 是**群乘法**（用並列表示）[▶ 02:30](https://youtu.be/Px2lDLRVzQE?t=150)。
- **白話**：先用 $b$ 作用、再用 $a$ 作用，等於先把 $a,b$ 乘起來再作用 [▶ 09:00](https://youtu.be/Px2lDLRVzQE?t=540)。
- 一開始用 $\star$，之後熟了就省略，就像群乘法一樣。

### 2. 例子 [▶ 04:00](https://youtu.be/Px2lDLRVzQE?t=240)

**例 1：置換群** [▶ 05:30](https://youtu.be/Px2lDLRVzQE?t=330)

$\operatorname{Sym}(S)$（老師記作 $\operatorname{Perm}(S)$）是 $S$ 上所有雙射。任何子群 $G\le\operatorname{Sym}(S)$ 都定義一個作用：
$$\sigma\star x = \sigma(x)\qquad(\text{代值}).$$
- $\operatorname{id}_S\star x = x$ ✓ [▶ 08:30](https://youtu.be/Px2lDLRVzQE?t=510)
- $\sigma_1\star(\sigma_2\star x) = \sigma_1(\sigma_2(x)) = (\sigma_1\circ\sigma_2)(x) = (\sigma_1\circ\sigma_2)\star x$ ✓ [▶ 09:30](https://youtu.be/Px2lDLRVzQE?t=570)

（書上只說「顯然」，老師把它補完。）

**例 2：子群用乘法作用** [▶ 10:30](https://youtu.be/Px2lDLRVzQE?t=630)

$H\le G$。這裡「群」是 $H$，「集合」是 $G$：
$$h\star x = hx.$$
- $e\star x = ex = x$ ✓ [▶ 12:00](https://youtu.be/Px2lDLRVzQE?t=720)
- $a\star(b\star x) = a(bx) = (ab)x = (ab)\star x$ ✓（群的結合律）[▶ 12:30](https://youtu.be/Px2lDLRVzQE?t=750)
- 特別地 $H = G$：**群用自己的乘法作用在自己身上** [▶ 13:30](https://youtu.be/Px2lDLRVzQE?t=810)。

**例 3：純量乘法** [▶ 14:00](https://youtu.be/Px2lDLRVzQE?t=840)

$G = F^\times$（體 $F$ 去掉 0 的乘法群：非零實數、非零複數、非零有理數、$\mathbb{Z}_p$ 去掉 0……）。$V$ 是 $F$ 上的向量空間。
$$c\star\mathbf v = c\mathbf v.$$
$1\mathbf v = \mathbf v$、$a(b\mathbf v) = (ab)\mathbf v$，正是向量空間的公理。（純量乘法還和 0 有關，但只看非零純量時就是群作用 [▶ 15:30](https://youtu.be/Px2lDLRVzQE?t=930)。）

**例 4：矩陣作用在行向量上** [▶ 15:30](https://youtu.be/Px2lDLRVzQE?t=930)（老師比較喜歡這個）

$V = F^n$（$n$ 維行向量），$G\le GL(n,F) = \{A\mid\det A\neq0\}$。
$$A\star\mathbf v = A\mathbf v\quad(\text{矩陣乘向量}).$$
$I\mathbf v = \mathbf v$、$A(B\mathbf v) = (AB)\mathbf v$ ✓

看完四個例子，老師說：「我開始想，什麼東西**不是**群作用？」[▶ 17:30](https://youtu.be/Px2lDLRVzQE?t=1050)

### 3. 群作用 $\iff$ 同態到 $\operatorname{Sym}(S)$ [▶ 18:00](https://youtu.be/Px2lDLRVzQE?t=1080)

> **命題**　$G$ 是群，$S$ 是集合。任何群同態 $G\to\operatorname{Sym}(S)$ 都定義一個 $G$ 在 $S$ 上的作用。反過來，每個作用都這樣產生。

> 💬 老師抄寫時多寫了一個「of」和一個「s」，變成「any group of homomorphisms」，隨即更正 [▶ 18:30](https://youtu.be/Px2lDLRVzQE?t=1110)。

**(同態 $\Rightarrow$ 作用)** [▶ 20:00](https://youtu.be/Px2lDLRVzQE?t=1200)
- 設 $\varphi:G\to\operatorname{Sym}(S)$ 是同態，記 $\lambda_a = \varphi(a)$（一個置換）。同態性質：$\lambda_a\circ\lambda_b = \lambda_{ab}$。
- 定義 $a\star x = \lambda_a(x)$ [▶ 23:30](https://youtu.be/Px2lDLRVzQE?t=1410)。
- $e\star x = \lambda_e(x) = \operatorname{id}(x) = x$（同態把單位送到單位，$\operatorname{Sym}(S)$ 的單位是恆等映射）。
- $(ab)\star x = \lambda_{ab}(x) = \lambda_a(\lambda_b(x)) = a\star(b\star x)$。

和例 1 的差別：例 1 直接處理置換；這裡是把**不同的置換分配給不同的群元素** [▶ 23:00](https://youtu.be/Px2lDLRVzQE?t=1380)。

**(作用 $\Rightarrow$ 同態)** [▶ 25:00](https://youtu.be/Px2lDLRVzQE?t=1500)
- 給定作用 $\star$，定義 $\varphi(g):S\to S$，$\varphi(g)(x) = g\star x$。它是單值的，因為 $\star$ 是函數 [▶ 27:30](https://youtu.be/Px2lDLRVzQE?t=1650)。
- **同態** [▶ 28:30](https://youtu.be/Px2lDLRVzQE?t=1710)：
$$\varphi(gh)(x) = (gh)\star x = g\star(h\star x) = \varphi(g)(\varphi(h)(x)) = (\varphi(g)\circ\varphi(h))(x).$$
- **$\varphi(g)$ 是單射** [▶ 31:30](https://youtu.be/Px2lDLRVzQE?t=1890)：若 $g\star x = g\star y$，兩邊用 $g^{-1}$ **作用**（不是乘）：
$$g^{-1}\star(g\star x) = (g^{-1}g)\star x = e\star x = x,$$
  同理右邊得 $y$。所以 $x = y$。兩條公理都用到了。
- **$\varphi(g)$ 是滿射** [▶ 34:00](https://youtu.be/Px2lDLRVzQE?t=2040)：要解 $g\star x = y$，取 $x = g^{-1}\star y$。
- 所以 $\varphi(g)\in\operatorname{Sym}(S)$，$\varphi$ 是同態。$\blacksquare$

**結論** [▶ 35:00](https://youtu.be/Px2lDLRVzQE?t=2100)：群作用其實就是「群到某集合的置換群的同態」換個角度看。

> 💬 冷知識：1024 階的群有 49,487,365,422 個同構類。「這不會是作業題」[▶ 36:00](https://youtu.be/Px2lDLRVzQE?t=2160)。

### 4. 軌道、穩定子、固定點 [▶ 36:30](https://youtu.be/Px2lDLRVzQE?t=2190)

設 $G$ 作用在 $S$ 上，$x\in S$。

> **定義**
> - **軌道 (orbit)**：$Gx = \{s\in S\mid s = g\star x,\ g\in G\}$
> - **穩定子 (stabilizer)**：$G_x = \{g\in G\mid g\star x = x\}$
> - **$G$ 固定的點**：$S^G = \{x\in S\mid g\star x = x,\ \forall g\in G\}$

（老師說不太確定固定點集的記號；書上用 $a$ 表示群元素，他覺得很蠢，改用 $g$ [▶ 37:00](https://youtu.be/Px2lDLRVzQE?t=2220)。）

- 穩定子也叫 **isotropy subgroup**（例如 Fraleigh 的用法）[▶ 39:30](https://youtu.be/Px2lDLRVzQE?t=2370)。可以證明它是 $G$ 的子群。
- 軌道和穩定子最重要。**注意位置不同**：軌道是 $S$ 的子集，穩定子是 $G$ 的子集 [▶ 41:00](https://youtu.be/Px2lDLRVzQE?t=2460)。

### 5. 例 2 的軌道與穩定子 [▶ 40:00](https://youtu.be/Px2lDLRVzQE?t=2400)

$H\le G$，$h\star x = hx$。

**軌道** [▶ 41:30](https://youtu.be/Px2lDLRVzQE?t=2490)
$$Hx = \{s\in G\mid s = hx,\ h\in H\}.$$
這是**右陪集**（$H$ 在左、$x$ 在右）。全班一開始投票說是左陪集，老師說「你們要害死我」[▶ 42:30](https://youtu.be/Px2lDLRVzQE?t=2550)。

**穩定子** [▶ 43:30](https://youtu.be/Px2lDLRVzQE?t=2610)：$\{h\in H\mid hx = x\} = \{e\}$（消去律）。

**右陪集的性質**：它們分割 $G$；個數是指數 $[G:H]$（Lagrange 的推論）[▶ 44:30](https://youtu.be/Px2lDLRVzQE?t=2670)。

### 6. 預告 [▶ 44:30](https://youtu.be/Px2lDLRVzQE?t=2670)

- 穩定子不一定是正規子群，但它是子群，所以可以看它的陪集。
- **軌道把集合 $S$ 分割**成互不相交的部分。
- **軌道穩定子定理**：把軌道大小、穩定子大小和群的大小連起來，能解有趣的計數問題。
