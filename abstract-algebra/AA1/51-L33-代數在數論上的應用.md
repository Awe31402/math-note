# 第 51 集 · L33：代數在數論上的應用（一）——四平方和、Pell 方程 [▶ 影片](https://www.youtube.com/watch?v=y50KT_6MuUI&list=PLBY4G2o7DhF0JCgapYKrqibGaJuvV4Gkb)

## 本集概要

- **二平方恆等式**：$(x_1^2+y_1^2)(x_2^2+y_2^2)$ 還是兩個平方和——來自複數模長的乘性。也有四平方、八平方恆等式，沒有三平方。
- **四元數**：$2\times2$ 複矩陣模型；範數 = 行列式 = 四個平方和；乘積裡藏著內積和外積。由此得到 **Euler 四平方恆等式**。
- **Hurwitz 整數**；**Lagrange 四平方定理**：每個正整數都是四個平方數之和。
- **Hurwitz 定理**：賦範可除代數只有 $\mathbb{R},\mathbb{C},\mathbb{H},\mathbb{O}$（維數 1、2、4、8）。
- **Pell 方程** $x^2-ny^2 = 1$：解就是 $\mathbb{Z}[\sqrt n]$ 中範數為 1 的元素（單位）；兩個解相乘得新解，所以有無窮多解。

> 📘 本講和接下來幾講是老師數論課的內容（講義 PDF 在他網站的數論課頁面），主要取自 John Stillwell《Elements of Number Theory》。屬於「代數數論的簡短導覽」，不是考試重點。

> 💬 開場禱告：「求讓學生把所有時間花在這門課上，忽略其他所有課，因為它們不重要——我們知道這是真的。也求讓我在這個溫度荒謬的教室裡能專心。」

## 筆記

### 1. 二平方恆等式 [▶ 00:30](https://youtu.be/y50KT_6MuUI?t=30)

$z_1 = x_1+iy_1$、$z_2 = x_2+iy_2$，$z = z_1z_2 = (x_1x_2-y_1y_2)+i(x_1y_2+x_2y_1)$。
- 模長乘性：$|z_1z_2| = |z_1||z_2|$，平方得 [▶ 02:30](https://youtu.be/y50KT_6MuUI?t=150)
$$(x_1^2+y_1^2)(x_2^2+y_2^2) = (x_1x_2-y_1y_2)^2+(x_1y_2+x_2y_1)^2.$$
- **二平方恆等式 (two-square identity)**：兩個平方和相乘，還是兩個平方和 [▶ 04:00](https://youtu.be/y50KT_6MuUI?t=240)。

**三個呢？** 不行。但**四個**可以（四平方恆等式），還有**八平方恆等式** [▶ 04:30](https://youtu.be/y50KT_6MuUI?t=270)。學生問有沒有更多：老師認為只有 2、4、8，這是 Hurwitz 定理的一種說法。

**來源** [▶ 05:30](https://youtu.be/y50KT_6MuUI?t=330)：複數是一個**代數**（向量空間 + 乘法），而且非零元素都有反元素——**可除代數 (division algebra)**，並有**乘性範數**。另一個這樣的東西是……

### 2. 四元數 [▶ 06:30](https://youtu.be/y50KT_6MuUI?t=390)

四元數是 4 維實向量空間配上乘法；乘法不交換，所以不是體，但是可除代數。

**矩陣模型**（Stillwell）[▶ 07:30](https://youtu.be/y50KT_6MuUI?t=450)：
$$q = \begin{pmatrix}\alpha&\beta\\-\bar\beta&\bar\alpha\end{pmatrix},\quad\alpha,\beta\in\mathbb{C}.$$
（老師認為這是四元數的**表示**，四元數本身更抽象。）
- **範數** = 行列式 $= |\alpha|^2+|\beta|^2$。例：$\alpha = 1+2i$、$\beta = 3+4i$ 時是 $1^2+2^2+3^2+4^2$ [▶ 08:30](https://youtu.be/y50KT_6MuUI?t=510)。
- 行列式乘性 $\Rightarrow$ 範數乘性。

**抽象定義** [▶ 09:00](https://youtu.be/y50KT_6MuUI?t=540)：$i^2 = j^2 = k^2 = -1$，$ij = k$、$jk = i$、$ki = j$，$ji = -k$ 等。（老師記得可以濃縮成 $ijk = -1$。）不一定要用矩陣。

**記號** [▶ 10:30](https://youtu.be/y50KT_6MuUI?t=630)：$\alpha = t+\boldsymbol\alpha$，$t$ 是**實部**，$\boldsymbol\alpha = xi+yj+zk$ 是**虛部（向量部）**。$i,j,k$ 傳統上叫 **versors**。
- 共軛：$\bar\alpha = t-\boldsymbol\alpha$。
- 範數：$\alpha\bar\alpha = t^2+x^2+y^2+z^2$ [▶ 11:30](https://youtu.be/y50KT_6MuUI?t=690)。

**歷史** [▶ 11:30](https://youtu.be/y50KT_6MuUI?t=690)：Hamilton（1843 年左右）發明；他認為四元數代表空間和時間，帶有許多形而上的包袱。他晚年寫了五六百頁的四元數書，兒子在他死後出版。四元數曾扮演今天向量的角色。

**乘積：內積 + 外積** [▶ 12:30](https://youtu.be/y50KT_6MuUI?t=750)：純虛四元數 $\boldsymbol\alpha_1$、$\boldsymbol\alpha_2$（對應三維向量）相乘，
$$\boldsymbol\alpha_1\boldsymbol\alpha_2 = -\boldsymbol\alpha_1\cdot\boldsymbol\alpha_2 + \boldsymbol\alpha_1\times\boldsymbol\alpha_2.$$
老師大學時和哥哥在父母家地下室算出這個：「哇，一個乘法同時有內積和外積。」一般情形：
$$(t_1+\boldsymbol\alpha_1)(t_2+\boldsymbol\alpha_2) = t_1t_2-\boldsymbol\alpha_1\cdot\boldsymbol\alpha_2+t_1\boldsymbol\alpha_2+t_2\boldsymbol\alpha_1+\boldsymbol\alpha_1\times\boldsymbol\alpha_2.$$

> 💬 學生問老師的初戀：「數學——當然。」接著閒聊 $\pi$ 的定義（「圓周比直徑？不在平面上的圓呢？」）、「化圓為方」、sup 範數下的「圓」是正方形等，老師說「我們真的離題了」[▶ 14:00](https://youtu.be/y50KT_6MuUI?t=840)–18:30。

**範數** [▶ 18:30](https://youtu.be/y50KT_6MuUI?t=1110)：$\alpha\bar\alpha = (t+\boldsymbol\alpha)(t-\boldsymbol\alpha) = t^2+\boldsymbol\alpha\cdot\boldsymbol\alpha$（自己和自己的外積是 0）。

### 3. 四平方恆等式 [▶ 19:30](https://youtu.be/y50KT_6MuUI?t=1170)

範數乘性 $N(q_1)N(q_2) = N(q_1q_2)$ 寫開：
$$(a_1^2+b_1^2+c_1^2+d_1^2)(a_2^2+b_2^2+c_2^2+d_2^2) = (\text{實部})^2+(i\text{ 部})^2+(j\text{ 部})^2+(k\text{ 部})^2.$$
這就是 **Euler 四平方恆等式**（18 世紀；「凡是碰到數論的東西，Euler 好像都做過」）[▶ 20:30](https://youtu.be/y50KT_6MuUI?t=1230)。

### 4. 四平方定理 [▶ 21:00](https://youtu.be/y50KT_6MuUI?t=1260)

> **定理（Lagrange 四平方定理）**　每個正整數都是四個整數的平方和（不一定唯一）。

**Hurwitz 整數** [▶ 21:30](https://youtu.be/y50KT_6MuUI?t=1290)：類似 Gaussian 整數，但整係數組合 $a+bi+cj+dk$ 太「稀疏」，不夠做除法算則；要加入「中點」：
$$\text{Hurwitz 整數} = \{a+bi+cj+dk\mid a,b,c,d\text{ 全是整數或全是半整數}\}.$$
（例如 $\frac{1+i+j+k}2$。）
- 範數仍是**整數**（論證「不太顯然」：括號裡的東西是 4 的倍數）[▶ 22:30](https://youtu.be/y50KT_6MuUI?t=1350)。
- 範數為（普通）質數的 Hurwitz 整數是 **Hurwitz 質元**（像 Gaussian 整數：範數 13 $\Rightarrow$ 不可約）。數論裡不太區分質與不可約 [▶ 23:30](https://youtu.be/y50KT_6MuUI?t=1410)。
- **普通質數 $p$ 若不是 Hurwitz 質元，則 $p$ 是四個整數平方和** [▶ 25:00](https://youtu.be/y50KT_6MuUI?t=1500)：分解 $p = \alpha\bar\alpha$ 時可能出現半整數，用 $\omega = \frac{\pm1\pm i\pm j\pm k}2$（$\omega\bar\omega = 1$）調整成整數係數。老師說這個計算「很美」。
- Hurwitz 整數是 UFD，但因為不交換，要分左右因數，「很麻煩」。有 Bézout；**質因數性質只對普通質數成立** [▶ 30:00](https://youtu.be/y50KT_6MuUI?t=1800)。「四元數幾乎可交換，就差那麼一點。」

**Lagrange 引理** [▶ 31:00](https://youtu.be/y50KT_6MuUI?t=1860)：$p$ 是奇質數，則有整數 $l,m$ 使 $p\mid1+l^2+m^2$。

**證明大意** [▶ 31:30](https://youtu.be/y50KT_6MuUI?t=1890)
- $1 = 1^2+0+0+0$、$2 = 1+1+0+0$、$3 = 1+1+1+0$、$4 = 1+1+1+1 = 2^2+0+0+0$（不唯一）。
- **合數**：$n = ab$，若 $a$、$b$ 都是四平方和，四平方恆等式給出 $n$ 也是。所以**只要證質數**；2 已經有了，只要證**奇質數** [▶ 32:30](https://youtu.be/y50KT_6MuUI?t=1950)。（「人家說 1 是最孤單的數字，我覺得錯了，2 才是——唯一的偶質數。」Three Dog Night 梗。）
- $p\mid1+l^2+m^2 = (1+li+mj)(1-li-mj)$。若 $p$ 是 Hurwitz 質元，它要整除其中一個因式，但那會讓 $\frac1p$ 出現在 Hurwitz 整數的係數裡，不可能（最多是 $\frac12$）[▶ 34:30](https://youtu.be/y50KT_6MuUI?t=2070)。
- 所以 $p$ 不是 Hurwitz 質元，是四平方和。

**歷史** [▶ 35:00](https://youtu.be/y50KT_6MuUI?t=2100)：二平方恆等式古老（Diophantus 約西元 200 年知道），之後 Euler、Gauss 等人。四平方恆等式從 Euler 開始；Rodrigues（1840）、Hamilton（1843）發現四元數。課程中大部分論證源自 **Dedekind** 的代數整數。**Hurwitz 整數**在四元數裡，用來研究四平方問題；**Gaussian 整數**在複數裡，用來研究二次問題。

### 5. Hurwitz 定理 [▶ 36:30](https://youtu.be/y50KT_6MuUI?t=2190)

> **定理（Hurwitz）**　$n$ 平方恆等式只在 $n = 1,2,4,8$ 存在。等價地，**賦範可除代數 (normed division algebra)**（實向量空間 + 乘法 + 乘性範數）在同構意義下只有 $\mathbb{R}$、$\mathbb{C}$、$\mathbb{H}$（四元數）、$\mathbb{O}$（**八元數 octonions**）。

- 16 不行「並不顯然」。老師的線性代數課本最後一節有證明，約三頁「血腥的線性代數」。
- 八元數失去了**結合律**，但仍是冪結合的 [▶ 37:30](https://youtu.be/y50KT_6MuUI?t=2250)。再往上是 sedenions 等。

### 6. Pell 方程 [▶ 38:00](https://youtu.be/y50KT_6MuUI?t=2280)

$$x^2-ny^2 = 1\quad(n\text{ 是正整數，非平方}).$$
（其實不是 Pell 的；Euler 誤稱，名字就留下來了。）

**在 $\mathbb{Z}[\sqrt n]$ 裡看** [▶ 39:00](https://youtu.be/y50KT_6MuUI?t=2340)：$x^2-ny^2 = (x+y\sqrt n)(x-y\sqrt n) = N(x+y\sqrt n)$。所以 **Pell 方程的解 = $\mathbb{Z}[\sqrt n]$ 中範數為 1 的元素 = 單位**。

**從兩個解造第三個** [▶ 41:30](https://youtu.be/y50KT_6MuUI?t=2490)
$$(x_1+y_1\sqrt n)(x_2+y_2\sqrt n) = (x_1x_2+ny_1y_2)+(x_1y_2+x_2y_1)\sqrt n.$$
範數乘性：$1\cdot1 = 1$，所以 $(x_3,y_3) = (x_1x_2+ny_1y_2,\ x_1y_2+x_2y_1)$ 也是解 [▶ 44:00](https://youtu.be/y50KT_6MuUI?t=2640)。
- 老師在數論課是用「硬算代數」證的，「很笨，但那些學生需要看到」[▶ 45:30](https://youtu.be/y50KT_6MuUI?t=2730)。
- 這些抽象數系不只是練習證明的工具，**它們本來就是為了研究具體的數論問題而發明的**。

**例：$n = 2$** [▶ 46:00](https://youtu.be/y50KT_6MuUI?t=2760)
- $(3,2)$：$9-8 = 1$ ✓。
- $(3+2\sqrt2)^2 = 17+12\sqrt2$：$289-288 = 1$ ✓。
- $(17+12\sqrt2)^2 = 577+408\sqrt2$ [▶ 47:30](https://youtu.be/y50KT_6MuUI?t=2850)。
- 一直乘下去：**無窮多解**。也就是 $\mathbb{Z}[\sqrt2]$ 有無窮多個單位。

**對比** [▶ 49:00](https://youtu.be/y50KT_6MuUI?t=2940)：$\mathbb{Z}[\sqrt{-2}]$ 這類**虛二次**的簡單得多，單位很少（老師說「最多八個」）。

**預告** [▶ 49:00](https://youtu.be/y50KT_6MuUI?t=2940)：明天答疑課講作業解答；週五自由問答；**週一考試**；之後簡短導覽代數數論。
