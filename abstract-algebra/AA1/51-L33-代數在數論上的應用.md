## 1. 二平方恆等式

[▶ 00:30](https://youtu.be/y50KT_6MuUI?t=30)「先從一個關於複數的**無害觀察**開始。」

$z_1 = x_1+iy_1$、$z_2 = x_2+iy_2$，
$$z = z_1z_2 = (x_1x_2-y_1y_2)+i(x_1y_2+x_2y_1).$$
模長是乘性的：$|z_1z_2| = |z_1||z_2|$。平方 [▶ 02:30](https://youtu.be/y50KT_6MuUI?t=150)：

> **二平方恆等式（two-square identity）**
> $$(x_1^2+y_1^2)(x_2^2+y_2^2) = (x_1x_2-y_1y_2)^2+(x_1y_2+x_2y_1)^2.$$

「兩個『兩平方和』相乘，可以再寫成兩平方和。」

【課堂討論】[▶ 04:00](https://youtu.be/y50KT_6MuUI?t=240)「能對**三個**這樣做嗎？」——**不行**。但**四個**可以（四平方恆等式），還有**八平方恆等式**。
- 【Q&A】學生問還有別的嗎。老師：「我想只有 2、4、8。這其實是 **Hurwitz 定理**，用一種不尋常的方式說。」

**來源**[▶ 05:30](https://youtu.be/y50KT_6MuUI?t=330)：二平方恆等式來自**複數**及其**乘性範數**。複數是 $\mathbb{R}$ 上的**代數**（algebra），而且是**可除代數**（division algebra）——非零元素都有乘法反元素。「還有另一個帶乘性範數的可除代數會給你四平方——叫什麼？」

## 2. 四元數

### 2.1 模型與範數

[▶ 06:30](https://youtu.be/y50KT_6MuUI?t=390)「我要去的地方是**四元數**。」
- $\mathbb{H}$：**4 維實向量空間**加上乘法。**不是體**（乘法不交換），但是**可除代數**。

**模型**（Stillwell）[▶ 07:30](https://youtu.be/y50KT_6MuUI?t=450)：$2\times2$ 複矩陣
$$q = \begin{pmatrix}\alpha&\beta\\-\bar\beta&\bar\alpha\end{pmatrix}.$$
- 【口頭】「我個人會把這看成四元數的**表示**，不是四元數本身。對我來說四元數更抽象。」
- **範數** = 行列式 $= \alpha\bar\alpha+\beta\bar\beta = |\alpha|^2+|\beta|^2$。若 $\alpha = 1+2i$、$\beta = 3+4i$，範數 $= 1^2+2^2+3^2+4^2$——**四個平方和**。
- **乘性**：行列式是乘性的。

**記號**[▶ 09:00](https://youtu.be/y50KT_6MuUI?t=540)：
$$i^2 = j^2 = k^2 = -1,\quad ij = k,\ jk = i,\ ki = j,\quad ji = -k,\dots$$
- 「可以把這些當**定義條件**；我想可以全部濃縮成 $ijk = -1$。我不是要極簡——只是說原則上**不需要** $2\times2$ 複矩陣，可以當形式系統定義。Stillwell 很具體，想給學生一個確實的模型。」

**實部與虛部**[▶ 10:30](https://youtu.be/y50KT_6MuUI?t=630)：$\alpha = t+xi+yj+zk = t+\vec\alpha$。
- $i,j,k$ 傳統上叫 **versors**（「別問我為什麼」）。
- 注意跟複數不同：這裡的「虛部」$\vec\alpha$ 是**向量**部分，不把 $i$ 拉出來。
- **共軛** $\bar\alpha = t-\vec\alpha$；**範數** $\alpha\bar\alpha = t^2+x^2+y^2+z^2$ [▶ 11:30](https://youtu.be/y50KT_6MuUI?t=690)。

**歷史**：Hamilton 的發明（約 1843 年）；另一位 19 世紀數學家（字幕：Graves）也差不多同時。「Hamilton 認為它是**空間和時間**的表示，有一堆形上學包袱——我不在乎。」

### 2.2 乘積裡的內積和外積

[▶ 12:00](https://youtu.be/y50KT_6MuUI?t=720)

【口頭】「我第一次看到這個是大學時，跟**我哥**在我爸媽家**地下室**算出來，然後『哇，酷』——因為**這一個乘積同時包含內積和外積**，一個橫掃一切的構造。」

純虛四元數 $\vec\alpha_1 = (x_1,y_1,z_1)$、$\vec\alpha_2 = (x_2,y_2,z_2)$：
$$\vec\alpha_1\vec\alpha_2 = -\vec\alpha_1\cdot\vec\alpha_2+\vec\alpha_1\times\vec\alpha_2.$$
- $i^2 = j^2 = k^2 = -1$ 給出（負的）**內積**；其餘項湊成**外積**。
- 「你們大概已經忘了外積——喔不，你們愛它，就像不會忘記初戀。」

【口頭】[▶ 13:30](https://youtu.be/y50KT_6MuUI?t=810)「對 Hamilton 非常非常重要。他人生最後幾年都在寫一本 500–600 頁的四元數書，寫完就死了，他兒子出版。四元數**以前**扮演的就是現在向量在你們教育裡的角色——以前用四元數做向量微積分。」

【Q&A】[▶ 14:00](https://youtu.be/y50KT_6MuUI?t=840) 學生問老師的初戀：「**數學**——當然。」（接著一長串離題 [▶ 14:30](https://youtu.be/y50KT_6MuUI?t=870)–18:30：研究生看老師上課時拿色鉛筆給筆記圖上色很火大；「$\pi$ 怎麼定義？周長除以直徑？如果圓不在**平面**上呢？可以定義成 cosine 的第一個正零點」；「化圓為方？數學家化圓為方已經幾百年了——你們看過 **sup 範數**嗎？它把圓變成方」；「謝謝 Bradley，我真的離題了。」）

**一般乘積**[▶ 18:30](https://youtu.be/y50KT_6MuUI?t=1110)：$\alpha_i = t_i+\vec\alpha_i$，
$$\alpha_1\alpha_2 = (t_1t_2-\vec\alpha_1\cdot\vec\alpha_2)+(t_1\vec\alpha_2+t_2\vec\alpha_1+\vec\alpha_1\times\vec\alpha_2).$$
「我跟你們說的，沒有一樣不能跟有興趣的**高中生**說——只要接受有 $i,j,k$ 平方是 $-1$、反交換。那有點離譜，但 $\pi$ 也是，我們只是比較習慣。」

**範數驗證**[▶ 18:30](https://youtu.be/y50KT_6MuUI?t=1110)：$\alpha\bar\alpha = (t+\vec\alpha)(t-\vec\alpha)$：交叉項相消；$-\vec\alpha\vec\alpha = \vec\alpha\cdot\vec\alpha-\vec\alpha\times\vec\alpha = \vec\alpha\cdot\vec\alpha$（自己跟自己的外積是 0）⇒ $t^2+x^2+y^2+z^2$。

## 3. Euler 四平方恆等式

[▶ 19:30](https://youtu.be/y50KT_6MuUI?t=1170)「一旦四元數有**乘性範數**，四平方恆等式就跟開場的二平方恆等式一樣容易。」

$$N(q_1)N(q_2) = N(q_1q_2)$$
$$(a_1^2+b_1^2+c_1^2+d_1^2)(a_2^2+b_2^2+c_2^2+d_2^2) = (\text{實部})^2+(i\text{ 部})^2+(j\text{ 部})^2+(k\text{ 部})^2.$$

「我不想寫出來。」「跟數論沾邊的東西似乎總是如此——**Euler** 在 18 世紀（『17 什麼的』）就找到了。」

## 4. Hurwitz 整數

[▶ 21:00](https://youtu.be/y50KT_6MuUI?t=1260)「四平方恆等式有什麼用？它讓我們證明這個**大定理**：**任何正整數都能寫成四個平方和**（不一定唯一）。主要工具之一是 **Hurwitz 整數**。」

- 類比 $\mathbb{Z}[\sqrt{-2}]$：四元數裡的**整數格點** $\mathbb{Z}+\mathbb{Z}i+\mathbb{Z}j+\mathbb{Z}k$。
- 但這格子「**有點太稀疏**，撐不起除法算則」，所以要加進**中點**：
$$\omega = \tfrac12(1+i+j+k)$$
  這類半整數點。這就是 **Hurwitz 整數**。它**有除法算則** [▶ 22:00](https://youtu.be/y50KT_6MuUI?t=1320)。
- **範數是整數**：不完全顯然（有 $\frac14$），但括號裡會是 4 的倍數，抵消掉 ⇒ 是我們這學期意義下的範數。

**範數是質數 ⇒ Hurwitz 質元**[▶ 23:00](https://youtu.be/y50KT_6MuUI?t=1380)：跟高斯整數一樣（範數 13 ⇒ 不可約）。
- 【口頭】「在數論裡我們不太講究**質元和不可約**的區別——這裡暫時忘掉我們這學期做的那個區分。」

**關鍵引理**[▶ 25:00](https://youtu.be/y50KT_6MuUI?t=1500)：**普通質數 $p$ 若不是 Hurwitz 質元，則 $p$ 是四個整數的平方和。**
- 任何 Hurwitz 整數可寫成 $2\times$（整數組合）加上某個 $\omega$ 型的元素，而 $\omega\bar\omega = \tfrac14\cdot4 = 1$。
- 若 $p = \alpha\beta$ 非平凡分解，取範數得 $p = a^2+b^2+c^2+d^2$，$a,b,c,d$ 是整數或**半整數**；用 $\omega$ 調整後可化成整數。
- 【口頭】[▶ 29:30](https://youtu.be/y50KT_6MuUI?t=1770)「這個計算**絕對漂亮**——不是我的，是 Stillwell 書裡的，我確定又是從別處來的。這些論證**精湛**，是**抽象代數解決具體數論問題**的有趣應用。」

**Hurwitz 整數的性質**[▶ 29:30](https://youtu.be/y50KT_6MuUI?t=1770)
- 是一種**唯一分解**——但**不交換**，要分**左右因數**。「很拖累，不好玩，有點複雜，但做得到。」
- 有 **Bézout 恆等式**。
- **質因數性質只對普通質數**成立：$p$ 普通質數，$p\mid\alpha\beta$ ⇒ $p\mid\alpha$ 或 $p\mid\beta$——對 Hurwitz 質元不一定。
- 「四元數總是這樣：**非常接近**交換的那套，但就是某處有個東西讓你失敗。它們**幾乎**交換，只是剛好過了一點。」

## 5. Lagrange 四平方定理

> **Lagrange 引理**[▶ 31:00](https://youtu.be/y50KT_6MuUI?t=1860)　$p = 2n+1$ 奇質數 ⇒ 存在整數 $l,m$ 使 $p\mid1+l^2+m^2$。（證明「對我們不那麼重要」。）

> **定理（Lagrange 四平方定理）**[▶ 31:30](https://youtu.be/y50KT_6MuUI?t=1890)　每個正整數 $n$ 都能寫成 $a^2+b^2+c^2+d^2$。

**小例子**（「有些很蠢」）：$1 = 1^2+0+0+0$、$2 = 1+1+0+0$、$3 = 1+1+1+0$、$4 = 1+1+1+1 = 2^2+0+0+0$——「即使在 4 就看得到**不唯一**」。

**化到質數**[▶ 32:00](https://youtu.be/y50KT_6MuUI?t=1920)：若 $n = ab$ 是合數，$a$、$b$ 各是四平方和，由**四平方恆等式**乘積還是四平方和（「雖然醜又複雜」）。所以只要證**奇質數**——唯一的偶質數 2 已經有了。
- 【口頭】[▶ 33:00](https://youtu.be/y50KT_6MuUI?t=1980)「**2 好孤單**。有人說 one is the loneliest number，我覺得他們錯了——好吧 1 不是質數，它有什麼好說的。抱歉，我會盡量限制 **Three Dog Night** 的梗。」

**奇質數**[▶ 33:30](https://youtu.be/y50KT_6MuUI?t=2010)
1. Lagrange 引理：$p\mid1+l^2+m^2$。
2. 用 Hurwitz 整數分解：
$$1+l^2+m^2 = (1-li-mj)(1+li+mj).$$
3. 若 $p$ 是 Hurwitz 質元，則 $p$ 整除其中一個因數（普通質數的質因數性質）⇒ 例如 $\frac1p(1+li+mj)$ 是 Hurwitz 整數。
4. 但 $\frac1p$（$p$ 奇質數）不可能是 Hurwitz 整數的係數——它們最多是**半整數** [▶ 34:30](https://youtu.be/y50KT_6MuUI?t=2070)。矛盾。
5. 所以 $p$ **不是** Hurwitz 質元 ⇒ 由 §4 的引理，$p$ 是四個平方和。$\blacksquare$

## 6. 歷史與 Hurwitz 定理

[▶ 35:00](https://youtu.be/y50KT_6MuUI?t=2100)
- **二平方恆等式**：相當古老——**Diophantus**（約 200 AD）就知道；1593 年 Viète（字幕不清）、Euler、Gauss 都用過。
- **Dedekind**：「這門課的論證，以某種方式，大多來自 Dedekind 在**代數整數**上的工作，我們現在還在做。」
- **四平方恆等式**：Euler 開始；**Rodrigues** 和 **Hamilton**（1840、1843）基本上都找到了四元數。
- **類比**：Hurwitz 整數坐在四元數裡，用來研究四平方問題；**高斯整數**坐在複數裡，用來研究二次問題。「關於後者我還有很多要說——今天說一些，不是全部。」

> **Hurwitz 定理**[▶ 36:30](https://youtu.be/y50KT_6MuUI?t=2190)　**賦範可除代數**（實向量空間 + 乘法 + 乘性範數）在同構意義下只有 $n = 1,2,4,8$ 維：
> $$\mathbb{R},\quad\mathbb{C},\quad\mathbb{H}\ (\text{四元數}),\quad\mathbb{O}\ (\text{八元數}).$$
> 所以 $n$ 平方恆等式只在 $n = 1,2,4,8$ 存在。

- 「16 會失敗並不顯然，這**不是最好證的**。如果上學期修過我的**線性代數**，課本最後一節有證明——大約三頁血淋淋的線性代數，看得懂，但要花你一小時。」
- **八元數失去什麼？**【課堂討論】——**結合律**。「但它們還是**冪結合**的。Cayley 數……再往上是 sedenions，一直下去。」

## 7. Pell 方程

[▶ 37:30](https://youtu.be/y50KT_6MuUI?t=2250)

> **Pell 方程**　$x^2-ny^2 = 1$，$n$ 是正整數（例如 2、3），找**整數解**。

「其實**不是 Pell 的**方程：Euler 叫它 Pell 方程，但顯然是誤稱，它更古老。我們可以用這學期發現／發明的數系來分析。」

**用 $\mathbb{Z}[\sqrt n]$**[▶ 39:00](https://youtu.be/y50KT_6MuUI?t=2340)：
$$x^2-ny^2 = (x+y\sqrt n)(x-y\sqrt n) = N(x+y\sqrt n)\quad(\text{範數 }|a^2-nb^2|).$$
**Pell 方程的解 = $\mathbb{Z}[\sqrt n]$ 中範數為 1 的元素。**

**兩個解得出第三個**[▶ 41:30](https://youtu.be/y50KT_6MuUI?t=2490)（老師先寫 $n = 2$：「其實換成 $n$ 計算一樣」）
- 設 $x_1^2-ny_1^2 = 1$、$x_2^2-ny_2^2 = 1$。宣稱
$$x_3 = x_1x_2+ny_1y_2,\qquad y_3 = x_1y_2+y_1x_2$$
  也是解。
- 【課堂討論】[▶ 43:00](https://youtu.be/y50KT_6MuUI?t=2580)「在 $\mathbb{Z}[\sqrt2]$ 裡這是什麼？」——
$$(x_1+y_1\sqrt n)(x_2+y_2\sqrt n) = x_3+y_3\sqrt n.$$
- 範數**乘性**：$1\cdot1 = 1$ ⇒ $(x_3,y_3)$ 是解 [▶ 44:30](https://youtu.be/y50KT_6MuUI?t=2670)。
- 【口頭】[▶ 45:30](https://youtu.be/y50KT_6MuUI?t=2730)「研究 Pell 方程被這些數系**幫助**，就像四平方和被四元數幫助。是的，這些抽象數是你們學習定義和寫證明的好工具——對數學系學生很重要——但它們**也是為了研究特定數論問題而發明的**。講義裡的證明只是硬算，有點蠢，但那是我數論學生當時需要看的。Jess，你覺得呢？」

**例：$n = 2$**[▶ 46:30](https://youtu.be/y50KT_6MuUI?t=2790)
- $(3,2)$：$9-8 = 1$ ✓。
- $(3+2\sqrt2)^2 = 17+12\sqrt2$：$289-2\cdot144 = 289-288 = 1$ ✓。「開始不那麼顯然了。」
- $(17+12\sqrt2)^2 = (289+288)+(2\cdot17\cdot12)\sqrt2 = 577+408\sqrt2$。

**意義**[▶ 48:30](https://youtu.be/y50KT_6MuUI?t=2910)
- Pell 方程有**無窮多解**。
- $\mathbb{Z}[\sqrt2]$ 是無限環；它的**單位**就是範數 1 的元素——用數論的語言，就是 **Pell 方程的解**。所以有**無窮多單位**（呼應 [[50-答疑課]] 的 $\mathbb{Z}[\sqrt6]$）。
- 換成 $\sqrt{-2}$——**虛二次體**——簡單得多，單位很少（「我相信最多 8 個」）。

> 💬 筆記補充：虛二次整數環的單位最多 **6** 個（$\mathbb{Z}[\omega]$，$\omega = e^{2\pi i/3}$）；$\mathbb{Z}[i]$ 有 4 個；其他都只有 $\pm1$。

## 8. 一頁速查表

### 8.1 平方和恆等式

| 恆等式 | 來源 | 範數 |
|---|---|---|
| 二平方 | $\mathbb{C}$ | $\lvert z\rvert^2 = x^2+y^2$ |
| 四平方（Euler） | $\mathbb{H}$ | $t^2+x^2+y^2+z^2$ |
| 八平方 | $\mathbb{O}$ | 八個平方 |
| 三平方 | **不存在** | — |

**Hurwitz 定理**：賦範可除代數只有 $\mathbb{R},\mathbb{C},\mathbb{H},\mathbb{O}$（1、2、4、8 維）。

### 8.2 四元數

| 事實 | 內容 |
|---|---|
| 規則 | $i^2 = j^2 = k^2 = ijk = -1$ |
| 範數 | $\alpha\bar\alpha = t^2+x^2+y^2+z^2$，乘性 |
| 純虛乘積 | $\vec a\vec b = -\vec a\cdot\vec b+\vec a\times\vec b$ |
| 性質 | 可除代數，不交換 |

### 8.3 四平方定理

| 步驟 | 關鍵一步 |
|---|---|
| 化到奇質數 | 四平方恆等式 |
| Lagrange 引理 | $p\mid1+l^2+m^2$ |
| $p$ 不是 Hurwitz 質元 | $1+l^2+m^2 = (1-li-mj)(1+li+mj)$；$\frac1p$ 不是半整數 |
| 非 Hurwitz 質元的質數是四平方和 | 範數 + $\omega\bar\omega = 1$ |

### 8.4 Pell 方程

| 事實 | 內容 |
|---|---|
| 方程 | $x^2-ny^2 = 1$ |
| 解 | $\mathbb{Z}[\sqrt n]$ 中範數 1 的元素 = 單位 |
| 新解 | $(x_1+y_1\sqrt n)(x_2+y_2\sqrt n)$ |
| $n = 2$ | $3+2\sqrt2,\ 17+12\sqrt2,\ 577+408\sqrt2,\dots$ |

## 附：本集一句話總結

> **複數的模長乘性給出二平方恆等式，四元數（$i^2 = j^2 = k^2 = ijk = -1$，乘積同時藏著內積和外積）的範數乘性給出 Euler 四平方恆等式——Hurwitz 定理說這種可除代數只有 1、2、4、8 維；用加了半整數點的 Hurwitz 整數和 Lagrange 引理就證出每個正整數都是四個平方和；而 Pell 方程 $x^2-ny^2 = 1$ 的解就是 $\mathbb{Z}[\sqrt n]$ 中範數 1 的單位，兩個解相乘就是新解，所以有無窮多個。**
