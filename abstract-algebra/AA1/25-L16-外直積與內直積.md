## 1. 外直積 vs. 內直積

[▶ 00:30](https://youtu.be/9grH-_5Pdr8?t=30)（$H,K$ 都是 $G$ 的子群。）

| | 外直積 $G' = H\times K$ | 內直積 $G = H\oplus K$ |
|---|---|---|
| 元素 | 有序對 $(h,k)$ | $G$ 的元素 $hk$ |
| 作為集合 | 笛卡兒積；$\subseteq G\times G$ | $= HK = \{hk : h\in H,k\in K\}$；$\subseteq G$ |
| 額外條件 | 無 | $H\cap K = \{e\}$，$H,K\trianglelefteq G$ |

【口頭】[▶ 01:00](https://youtu.be/9grH-_5Pdr8?t=60)「我用同一個符號表示直積和直和。我確定最後會造另一個符號，但還沒時間。」

**它們是不同的東西**[▶ 03:30](https://youtu.be/9grH-_5Pdr8?t=210)：一個是 $G$，一個在 $G\times G$ 裡。「它們不可能相等。」

**直覺**[▶ 04:00](https://youtu.be/9grH-_5Pdr8?t=240)：我們希望
$$H\times K\cong H\oplus K.$$
「說一個群是兩個子群的內直積，應該表示這個群**同構於**那兩個子群的外直積。這就是想法。」

**正面例子**[▶ 04:30](https://youtu.be/9grH-_5Pdr8?t=270)：$\mathbb{Z}_2\times\mathbb{Z}_3\cong\langle3\rangle\oplus\langle2\rangle = \mathbb{Z}_6$。（今天的結果之一。）

## 2. 為什麼要正規：D₃ 的反例

[▶ 05:00](https://youtu.be/9grH-_5Pdr8?t=300)「讓我給你們看，如果沒有正規性會發生什麼。」

【口頭】[▶ 05:30](https://youtu.be/9grH-_5Pdr8?t=330)「你們知道為什麼叫**二面體（dihedral）**嗎？不是一面的三角形，而是把三角形的對稱描述成**兩個面**——dihedral 就是『兩個面』的意思。」

$$D_3 = \{1,x,x^2,y,xy,x^2y\},\qquad H = \langle x\rangle = \{1,x,x^2\},\qquad K = \langle y\rangle = \{1,y\}.$$

**看起來很好**[▶ 06:30](https://youtu.be/9grH-_5Pdr8?t=390)：
- $HK$：$1,x,x^2$ 乘 1，再乘 $y$ 得 $y,xy,x^2y$——**$HK = D_3$**。
- 【課堂討論】$H\cap K = \{1\}$。
- $H\trianglelefteq D_3$（可以證）。

**但 $K$ 不正規**[▶ 07:30](https://youtu.be/9grH-_5Pdr8?t=450)：
$$xK = \{x,xy\},\qquad Kx = \{x,yx\} = \{x,x^2y\}.$$
（$yx = x^{-1}y = x^2y$。）$xy\neq x^2y$，所以 $xK\neq Kx$。

所以 $D_3$ **不是** $H$、$K$ 的內直積。「幾乎全部都對，就差一點。這是**好事**，因為——」

**外直積是什麼？**[▶ 08:30](https://youtu.be/9grH-_5Pdr8?t=510)
$$H\times K = \{(1,1),(1,y),(x,1),(x,y),(x^2,1),(x^2,y)\}.$$
也是 6 個元素。「也許它們同構？」

【Q&A】[▶ 09:00](https://youtu.be/9grH-_5Pdr8?t=540)「為什麼 $H\times K$ 跟 $D_3$ 不同構？」學生：「不是一對一……」老師：「你能更具體嗎？找一個具體的東西證明它們不同構。」挑 $(x,y)$——【課堂討論】它的階是？

$$(x,y)^2 = (x^2,1),\ (x,y)^3 = (1,y),\ (x,y)^4 = (x,1),\ (x,y)^5 = (x^2,y),\ (x,y)^6 = (1,1).$$
「要證是 6 階，得證前五個次方都不是單位。」[▶ 10:30](https://youtu.be/9grH-_5Pdr8?t=630) 第 6 次：$(x^6,y^6) = ((x^3)^2,(y^2)^3) = (1,1)$。

所以 **$H\times K\cong\mathbb{Z}_6$**，而 $D_3$ 不是循環的。**不同構**。

「或者更複雜：數兩個群的 2 階元素。攻擊方法很多。（學生）說的是對的：如果去研究同構，會發現行不通。但我們要**具體的論證**，這就是。」

【口頭】[▶ 11:30](https://youtu.be/9grH-_5Pdr8?t=690)「這說明了：子群**缺乏正規性**時，你得不到跟外直積同構的東西。所以**我們需要正規性**。」

## 3. 引理：唯一表示、互相交換

[▶ 11:30](https://youtu.be/9grH-_5Pdr8?t=690)「看它怎麼行得通。我們需要一個引理。」

> **引理**（講義 Lemma 3.3.9）　$H,K\trianglelefteq G$，$H\cap K = \{e\}$。
> 1. 若 $ab = a'b'$，$a,a'\in H$、$b,b'\in K$，則 $a = a'$、$b = b'$。
> 2. 若 $a\in H$、$b\in K$，則 $ab = ba$。

【口頭】[▶ 12:30](https://youtu.be/9grH-_5Pdr8?t=750)「(1) 說的是：每個 $G$ 的元素寫成 $H$ 的元素乘 $K$ 的元素，**寫法唯一**。(2) 為什麼需要還不清楚，等下一個定理就很明顯。這個引理就是用來證下一個定理的。」

**證明 (1)**[▶ 13:30](https://youtu.be/9grH-_5Pdr8?t=810)：$ab = a'b'$。左乘 $a^{-1}$、右乘 $b'^{-1}$：
$$bb'^{-1} = a^{-1}a'.$$
- 左邊在 $K$（$K$ 是子群）[▶ 15:00](https://youtu.be/9grH-_5Pdr8?t=900)。
- 右邊在 $H$。
- 所以兩邊都在 $H\cap K = \{e\}$。

因此 $a^{-1}a' = e$、$bb'^{-1} = e$，即 $a = a'$、$b = b'$。$\blacksquare$

【Q&A】[▶ 16:00](https://youtu.be/9grH-_5Pdr8?t=960) 學生：「好像沒用到正規性？」老師：「我想沒有……有意思。」（對，(1) 只需要 $H\cap K = \{e\}$。）

**證明 (2)**[▶ 16:30](https://youtu.be/9grH-_5Pdr8?t=990)：

**換個等價的目標**：$ab = ba\iff aba^{-1}b^{-1} = e$。「為什麼要換？因為這讓我**直接碰到正規性**。」[▶ 17:00](https://youtu.be/9grH-_5Pdr8?t=1020)

- **在 $H$ 裡**：$ba^{-1}b^{-1}\in bHb^{-1}\subseteq H$（$H$ 正規）[▶ 17:30](https://youtu.be/9grH-_5Pdr8?t=1050)。所以
$$aba^{-1}b^{-1} = a\cdot(ba^{-1}b^{-1})\in H.$$
- **在 $K$ 裡**[▶ 19:00](https://youtu.be/9grH-_5Pdr8?t=1140)：$aba^{-1}\in aKa^{-1}\subseteq K$（$K$ 正規）。所以
$$aba^{-1}b^{-1} = (aba^{-1})\cdot b^{-1}\in K.$$
- 所以 $aba^{-1}b^{-1}\in H\cap K = \{e\}$ [▶ 19:30](https://youtu.be/9grH-_5Pdr8?t=1170)。

因此 $ab = ba$ 對所有 $a\in H$、$b\in K$。$\blacksquare$

【口頭】[▶ 18:00](https://youtu.be/9grH-_5Pdr8?t=1080)「要證 $aba^{-1}b^{-1} = e$ 時，**一定要寫『我們希望證明』**，免得那個邪惡的、改你考卷的教授懷疑你用了可怕的**循環論證**——一開始就假設要證的東西。那很糟。我不是在讓它等於 $e$，我是在證它**必須**是 $e$。」

**正規性用在哪**[▶ 20:00](https://youtu.be/9grH-_5Pdr8?t=1200)：$bHb^{-1}\subseteq H$ 和 $aKa^{-1}\subseteq K$——兩個都要（Gallian Thm 9.1）。

## 4. 定理：內直積 ≅ 外直積

[▶ 20:30](https://youtu.be/9grH-_5Pdr8?t=1230)

> **定理**（講義 Thm 3.3.10）　若 $G = H\oplus K$（$H,K\trianglelefteq G$、$H\cap K = \{e\}$、$G = HK$），則
> $$H\times K\cong H\oplus K.$$

「寫 $H\oplus K$ 時，我就假設了那些條件，都打包在這個符號裡。」

**證明**：定義 [▶ 21:30](https://youtu.be/9grH-_5Pdr8?t=1290)
$$\varphi:H\times K\to G,\qquad\varphi(x,y) = xy.$$

**映入、映成**[▶ 22:00](https://youtu.be/9grH-_5Pdr8?t=1320)：$xy\in HK = G$。反過來，$G$ 的任意元素是某個 $xy$，就是 $\varphi(x,y)$。（擔心良定義？引理 (1) 說 $xy$ 的寫法唯一 [▶ 22:30](https://youtu.be/9grH-_5Pdr8?t=1350)。）

**同態**[▶ 23:00](https://youtu.be/9grH-_5Pdr8?t=1380)：$x,a\in H$；$y,b\in K$。
$$
\begin{aligned}
\varphi\big((x,y)(a,b)\big) &= \varphi(xa,yb) &&(\text{外直積：逐分量})\\
&= (xa)(yb)\\
&= x(ay)b\\
&= x(ya)b &&(\text{引理 (2)：}a\in H,\ y\in K)\\
&= (xy)(ab) = \varphi(x,y)\,\varphi(a,b).
\end{aligned}
$$
「**我們需要交換性才能得到同態性質**。」[▶ 24:00](https://youtu.be/9grH-_5Pdr8?t=1440)

**一對一**[▶ 24:30](https://youtu.be/9grH-_5Pdr8?t=1470)：
$$\operatorname{Ker}\varphi = \{(x,y) : xy = e\}.$$
$xy = e = ee$，由引理 (1)，$x = e$、$y = e$。核平凡。

所以 $\varphi$ 是同構。$\blacksquare$

## 5. 定理：|(x,y)| = lcm(|x|,|y|)

[▶ 25:30](https://youtu.be/9grH-_5Pdr8?t=1530)「下一個結果是**計算上的傑作**。這東西真是驚人——**蠢蠢地好用**。」

> **定理**（講義 Thm 3.3.11）　$|x|,|y|<\infty$，$(x,y)\in G\times H$。則
> $$|(x,y)| = \operatorname{lcm}(|x|,|y|).$$

**證明**[▶ 26:30](https://youtu.be/9grH-_5Pdr8?t=1590)：$|x| = m$、$|y| = n$、$s = \operatorname{lcm}(m,n)$。所以 $s = mk = nl$。

**Step 1：$(x,y)^s = (e,e)$**[▶ 27:30](https://youtu.be/9grH-_5Pdr8?t=1650)：
$$(x,y)^s = (x^s,y^s) = (x^{mk},y^{nl}) = ((x^m)^k,(y^n)^l) = (e,e).$$
所以 $|(x,y)|\le s$。

**Step 2：沒有更小的**[▶ 28:00](https://youtu.be/9grH-_5Pdr8?t=1680)：若 $(x,y)^j = (e,e)$，$j<s$，則 $x^j = e$、$y^j = e$。
【課堂討論】[▶ 29:00](https://youtu.be/9grH-_5Pdr8?t=1740)「某個次方給出單位元素，那個次方跟元素的階有什麼關係？」學生先說「$j$ 整除 $m$」，老師糾正：「$j$ 必須是 $m$ 的**倍數**——$m\mid j$。」同樣 $n\mid j$。
所以 $j$ 是 $m,n$ 的**公倍數**，卻比**最小**公倍數小——「我們有麻煩了」。矛盾。

所以 $|(x,y)| = s$。$\blacksquare$

【口頭】[▶ 30:00](https://youtu.be/9grH-_5Pdr8?t=1800)「回顧：今天稍早我們用明確（而不優雅）的計算證明 $(x,y)$ 的階是 6。$|x| = 3$、$|y| = 2$，$\operatorname{lcm}(2,3) = 6$。這個證明**正好是**那個元素階為 6 的原因。」

【Q&A】[▶ 35:30](https://youtu.be/9grH-_5Pdr8?t=2130) 學生：「這也是為什麼置換的階用 lcm（Ruffini）嗎？」老師：「嗯……我不知道，我從沒這樣想過。對我來說那只是計算原則。也許有個觀點可以讓這說法成立，我現在想不出來。有趣的問題。」

（筆記補充：確實相關——互斥循環可交換，所以 $\langle\gamma_1,\dots,\gamma_k\rangle$ 的行為就像循環群的直積。）

## 6. 例：Z₄₉ × Z₇ 的 7 階元素與子群

[▶ 30:30](https://youtu.be/9grH-_5Pdr8?t=1830)「這出乎意料地好用。例如：」

> **題目**　$\mathbb{Z}_{49}\times\mathbb{Z}_7$ 有幾個 7 階元素？幾個 7 階子群？

$(a,b)$ 的階是 $\operatorname{lcm}(|a|,|b|) = 7$ [▶ 31:00](https://youtu.be/9grH-_5Pdr8?t=1860)。

**分情況**（老師分兩種，講義分三種）[▶ 31:30](https://youtu.be/9grH-_5Pdr8?t=1890)：

| 情況 | $\lvert a\rvert$ | $\lvert b\rvert$ | 個數 |
|---|---|---|---|
| A | 7 | 1 或 7 | $6\times7 = 42$ |
| B | 1 | 7 | $1\times6 = 6$ |

**怎麼數**[▶ 32:30](https://youtu.be/9grH-_5Pdr8?t=1950)：「借用我們以前在循環群裡數東西的功夫。」
- 單位元素只有 1 個。「這從第一天就知道。」
- 【課堂討論】$\mathbb{Z}_7$ 有幾個 7 階元素？「$\mathbb{Z}_7$ 的生成元是什麼？$U(7)$ 裡的任何東西。」**6 個**。
- $\mathbb{Z}_{49}$ 有幾個 7 階元素？「也是 6 個——跟背景無關，我們談過。」（$\varphi(7) = 6$。）
- 情況 A：$a$ 有 6 種選擇，$b$ 是 $\mathbb{Z}_7$ 的任何元素（階 1 或 7），7 種。

**總共 48 個 7 階元素**[▶ 34:00](https://youtu.be/9grH-_5Pdr8?t=2040)。

**7 階子群有幾個**[▶ 34:30](https://youtu.be/9grH-_5Pdr8?t=2070)：「想想看，每個 7 階子群帶著幾個 7 階元素？」**6 個**（它的生成元，$\varphi(7) = 6$）。所以
$$\frac{48}{6} = 8\ \text{個 7 階子群}.$$

【口頭】[▶ 38:00](https://youtu.be/9grH-_5Pdr8?t=2280)「**動物學評論**——這很重要。7 階元素就像……螞蟻的腳。螞蟻有 6 隻腳。如果你用**數腳來數螞蟻**，就得除以 6。Gallian 有個用腳數**羊**的例子，除以 4。蜘蛛有 8 隻……這大概是我群論計數的極限了，動物不夠用。我看過七隻腳的蜘蛛，但……如果我們願意稍微彎一下倫理，可以造出任意隻腳的動物。」

> 📘 講義 Ex 3.3.14：$\mathbb{Z}_6\times\mathbb{Z}_2$ 的 6 階元素：$(1,0),(5,0),(2,1),(4,1)$，共 4 個；每個 6 階循環子群有 $\varphi(6) = 2$ 個生成元，所以有 2 個 6 階子群。
>
> 講義 Ex 3.3.16（Gallian）：$\mathbb{Z}_{100}\times\mathbb{Z}_{25}$ 有 24 個 10 階元素，$\varphi(10) = 4$，所以 6 個 10 階子群。

## 7. 定理：G × H 循環 ⟺ 階互質

[▶ 38:30](https://youtu.be/9grH-_5Pdr8?t=2310)（老師說證明「完美世界裡我會花十分鐘做給你們看，但世界不完美。想看可以明天習題課做。」）

> **定理**（講義 Thm 3.3.17）　$G,H$ 是有限循環群，$|G| = m$、$|H| = n$。則
> $$G\times H\text{ 循環}\iff\gcd(m,n) = 1.$$

「這個結果簡單得驚人，證明也不太難。」

**(⇐)**[▶ 39:30](https://youtu.be/9grH-_5Pdr8?t=2370)：$G = \langle a\rangle$、$H = \langle b\rangle$。互質時 $\operatorname{lcm}(m,n) = mn$，所以
$$|(a,b)| = \operatorname{lcm}(m,n) = mn = |G\times H|,$$
$(a,b)$ 生成整個 $G\times H$。

（$|G\times H| = mn$：「這只是集合論——兩個有限集合的笛卡兒積，大小是兩者的乘積。Math 200 就知道。可以花一天建一個 $G\times H$ 和 $\mathbb{Z}_{mn}$ 的雙射，但不太有教育意義。」[▶ 40:00](https://youtu.be/9grH-_5Pdr8?t=2400)）

**(⇒)**[▶ 40:30](https://youtu.be/9grH-_5Pdr8?t=2430)：設 $(x,y)$ 生成 $G\times H$，$d = \gcd(m,n)$。$mn/d$ 是整數，而
$$(x,y)^{mn/d} = \big((x^m)^{n/d},(y^n)^{m/d}\big) = (e,e).$$
（$x^m = e$、$y^n = e$：任何元素的群階次方都是單位——Lagrange 的推論。）所以 $mn = |(x,y)|\le mn/d$，$d = 1$。$\blacksquare$

「這是**合理的考題**，不算太糟。」

> **推論**（講義 Cor 3.3.18）
> $$\mathbb{Z}_{mn}\cong\mathbb{Z}_m\times\mathbb{Z}_n\iff\gcd(m,n) = 1.$$

例 [▶ 41:30](https://youtu.be/9grH-_5Pdr8?t=2490)：$\mathbb{Z}_6\cong\mathbb{Z}_3\times\mathbb{Z}_2$（本講開頭說的）。

## 8. 推廣到 n 個群

[▶ 41:30](https://youtu.be/9grH-_5Pdr8?t=2490)（投影片）

**$n$ 個子群的內直積**（講義 Def 3.3.19）：$H_1,\dots,H_n\trianglelefteq G$，
1. $G = H_1H_2\cdots H_n$；
2. $(H_1\cdots H_i)\cap H_{i+1} = \{e\}$，$i = 1,\dots,n-1$（「獨立」）。

【口頭】[▶ 42:00](https://youtu.be/9grH-_5Pdr8?t=2520)「**正規子群的乘積是正規的**——這是你們的作業。不難，別怕。不需要歸納法，寫出 $k$ 個的情況、解釋論證就好。如果寫正式歸納法讓你覺得自己是更好的數學家，我不會阻止你，我只是不在乎你做不做。」「看看那些我沒做、你們還因此被扣分的蠢歸納法……」

**引理推廣**[▶ 43:00](https://youtu.be/9grH-_5Pdr8?t=2580)：
- $a_1\cdots a_n = x_1\cdots x_n$（$a_i,x_i\in H_i$）⇒ $a_i = x_i$ 對每個 $i$。「它幾乎就是 $n$ 元組的另一種寫法——它們不是 $n$ 元組，是乘積，但行為像 $n$ 元組。」
- $a_i\in H_i$ ⇒ 乘積可以任意重排：$a_1\cdots a_n = a_{\sigma(1)}\cdots a_{\sigma(n)}$。「它們兩兩交換，任何順序都行。」
- 老師說講義裡「給了部分證明，然後就放棄了」。

**定理**（講義 Thm 3.3.21、3.3.22）：
$$H_1\oplus\cdots\oplus H_n\cong H_1\times\cdots\times H_n;\qquad|(x_1,\dots,x_n)| = \operatorname{lcm}(|x_1|,\dots,|x_n|).$$

**例：$\mathbb{Z}_6\times\mathbb{Z}_3\times\mathbb{Z}_4$ 的 6 階元素**[▶ 44:30](https://youtu.be/9grH-_5Pdr8?t=2670)

「如果你在這裡找到錯，別告訴我，我剛寫的還沒檢查——但我很確定。」$\operatorname{lcm}(|a|,|b|,|c|) = 6$：

| 情況 | $\lvert a\rvert$ | $\lvert b\rvert$ | $\lvert c\rvert$ | 個數 |
|---|---|---|---|---|
| 1 | 6 | 1 或 3 | 1 或 2 | $2\times3\times2 = 12$ |
| 2 | 3 | 1 | 2 | $2\times1\times1 = 2$ |
| 3 | 1 | 3 | 2 | $1\times2\times1 = 2$ |

（$\mathbb{Z}_6$：6 階 2 個；$\mathbb{Z}_3$：階 1 或 3 共 3 個；$\mathbb{Z}_4$：階 1 或 2 的是 0、2 共 2 個。）

**共 16 個 6 階元素**，每個 6 階循環子群有 $\varphi(6) = 2$ 個生成元，所以 **8 個 6 階循環子群**。「這就像用腳數某種兩腳動物——鴕鳥。」（另一位學生：「鴯鶓！」）

【口頭】[▶ 46:00](https://youtu.be/9grH-_5Pdr8?t=2760)「**某個階的元素個數總是一樣的**——希望你們注意到了。它不是特定於哪個群，只跟 Euler φ 函數有關：$d$ 階元素（在循環群裡）有 $\varphi(d)$ 個。」

**循環性判別推廣**（講義 Thm 3.3.24、Cor 3.3.25）[▶ 47:00](https://youtu.be/9grH-_5Pdr8?t=2820)：
$$H_1\times\cdots\times H_n\ \text{循環}\iff\text{各階兩兩互質};$$
$$\mathbb{Z}_{n_1n_2\cdots n_k}\cong\mathbb{Z}_{n_1}\times\cdots\times\mathbb{Z}_{n_k}\iff\gcd(n_i,n_j) = 1\ (i\neq j).$$

**例**：
- $105 = 3\cdot5\cdot7$ ⇒ $\mathbb{Z}_{105}\cong\mathbb{Z}_3\times\mathbb{Z}_5\times\mathbb{Z}_7$。
- $\gcd(2,10)\neq1$ ⇒ $\mathbb{Z}_{20}\not\cong\mathbb{Z}_2\times\mathbb{Z}_{10}$；但 $\gcd(4,5) = 1$ ⇒ $\mathbb{Z}_{20}\cong\mathbb{Z}_4\times\mathbb{Z}_5$ [▶ 48:00](https://youtu.be/9grH-_5Pdr8?t=2880)。

⚠️ 逐字稿缺字：老師另一個反例字幕聽起來像「$\mathbb{Z}_8\not\cong\mathbb{Z}_{32}\times\mathbb{Z}_2\times\mathbb{Z}_2$」，大小不合，應是類似 $\mathbb{Z}_8\not\cong\mathbb{Z}_2\times\mathbb{Z}_2\times\mathbb{Z}_2$ 的例子。

【口頭】[▶ 47:30](https://youtu.be/9grH-_5Pdr8?t=2850)「這是**若且唯若**。不是『互質就同構』，是『同構恰好當互質』。太棒了。你們真的應該**冥想並內化**這個結果，對計算非常重要。」

（老師發現投影片 $\mathbb{Z}_{20}$ 那句少了「**not**」：「有個非常重要的字漏了——not。打錯了。我得重寫這句，免得像我這樣的白痴被搞混。」[▶ 48:30](https://youtu.be/9grH-_5Pdr8?t=2910)）

## 9. 有限交換群的分類（不證）

[▶ 49:00](https://youtu.be/9grH-_5Pdr8?t=2940)「最後一分鐘，第 11 章：結果容易懂，但難證。」

> **定理（有限交換群基本定理）**（講義 Thm 3.3.28）　每個**有限交換群**都是**質數冪階循環群**的直積。而且，乘積的項數和各循環群的階由群唯一決定。

「這個看比讀容易。」

| 階 | 同構類 |
|---|---|
| $p$ | $\mathbb{Z}_p$ |
| $p^2$ | $\mathbb{Z}_{p^2}$；$\mathbb{Z}_p\times\mathbb{Z}_p$ |
| $p^3$ | $\mathbb{Z}_{p^3}$；$\mathbb{Z}_{p^2}\times\mathbb{Z}_p$；$\mathbb{Z}_p\times\mathbb{Z}_p\times\mathbb{Z}_p$ |

（講義：「$\mathbb{Z}_{p^2}$ 是循環的，$\mathbb{Z}_p\times\mathbb{Z}_p$ 不是。**由循環群的乘積組成，不等於是循環群！**」）

**例：100 階交換群**[▶ 50:00](https://youtu.be/9grH-_5Pdr8?t=3000)：$100 = 2^2\cdot5^2$。

| 分解 | 用互質合併後 |
|---|---|
| $\mathbb{Z}_4\times\mathbb{Z}_{25}$ | $\cong\mathbb{Z}_{100}$ |
| $\mathbb{Z}_2\times\mathbb{Z}_2\times\mathbb{Z}_{25}$ | $\cong\mathbb{Z}_2\times\mathbb{Z}_{50}$ |
| $\mathbb{Z}_4\times\mathbb{Z}_5\times\mathbb{Z}_5$ | $\cong\mathbb{Z}_{20}\times\mathbb{Z}_5$ |
| $\mathbb{Z}_2\times\mathbb{Z}_2\times\mathbb{Z}_5\times\mathbb{Z}_5$ | $\cong\mathbb{Z}_{10}\times\mathbb{Z}_{10}$ |

「這是 100 階交換群在同構意義下的**四種**。」

【口頭】[▶ 50:30](https://youtu.be/9grH-_5Pdr8?t=3030)「配合 lcm 定理、互質結果和這個宣稱，你基本上能拆解某個階的交換群**長什麼樣**、有哪些可能。如果有人說『我有一個某某階、有某某性質的交換群』，你可以逐一檢查可能的情況，看合不合理。第 11 章有一大堆可愛的題目。」「這些都沒有我給 Nathan 的帶回家小考那題難。」

## 10. 一頁速查表

### 10.1 內直積 ≅ 外直積

| 結果 | 關鍵一步 |
|---|---|
| 唯一表示：$ab = a'b'\Rightarrow a = a',b = b'$ | $bb'^{-1} = a^{-1}a'\in H\cap K = \{e\}$（不需正規） |
| 互相交換：$ab = ba$ | $aba^{-1}b^{-1}$ 同時在 $H$（$H$ 正規）和 $K$（$K$ 正規） |
| $H\times K\cong H\oplus K$ | $\varphi(x,y) = xy$；同態要用交換；核平凡用唯一表示 |
| 正規性必要 | $D_3$：$\langle x\rangle\langle y\rangle = D_3$，但 $\langle y\rangle$ 不正規，$\langle x\rangle\times\langle y\rangle\cong\mathbb{Z}_6\not\cong D_3$ |

### 10.2 計算工具

| 結果 | 用法 |
|---|---|
| $\lvert(x_1,\dots,x_n)\rvert = \operatorname{lcm}(\lvert x_i\rvert)$ | 數某個階的元素 |
| 每個 $d$ 階循環子群有 $\varphi(d)$ 個 $d$ 階元素 | 元素數 ÷ $\varphi(d)$ = 子群數（「數腳數動物」） |
| $G\times H$ 循環 ⟺ $\gcd(\lvert G\rvert,\lvert H\rvert) = 1$ | $\mathbb{Z}_{mn}\cong\mathbb{Z}_m\times\mathbb{Z}_n$ ⟺ 互質 |

### 10.3 例子

| 群 | 結果 |
|---|---|
| $\mathbb{Z}_{49}\times\mathbb{Z}_7$ | 48 個 7 階元素，8 個 7 階子群 |
| $\mathbb{Z}_6\times\mathbb{Z}_3\times\mathbb{Z}_4$ | 16 個 6 階元素，8 個 6 階循環子群 |
| $\mathbb{Z}_{105}$ | $\cong\mathbb{Z}_3\times\mathbb{Z}_5\times\mathbb{Z}_7$ |
| $\mathbb{Z}_{20}$ | $\cong\mathbb{Z}_4\times\mathbb{Z}_5$，$\not\cong\mathbb{Z}_2\times\mathbb{Z}_{10}$ |
| 100 階交換群 | 4 種 |

## 附：本集一句話總結

> **外直積是有序對、逐分量運算；內直積是由兩個交集平凡的正規子群相乘組成的群——正規性保證兩者的元素互相交換、表示唯一，所以 $H\oplus K\cong H\times K$（沒有正規性就失敗，例如 $D_3$）；直積中元素的階是各分量階的 lcm，由此 $\mathbb{Z}_m\times\mathbb{Z}_n$ 循環恰好當 $\gcd(m,n) = 1$，配合「元素數 ÷ φ(d) = 子群數」就能數子群，而有限交換群全都是質數冪階循環群的直積。**
