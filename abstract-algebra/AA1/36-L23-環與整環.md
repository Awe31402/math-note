## 1. 環的定義

[▶ 00:30](https://youtu.be/PNr02wON-2s?t=30)

> **定義（環 ring）**（講義 Def 4.1.1）　$R$ 是非空集合，有兩個二元運算：**加法** $(a,b)\mapsto a+b$ 和**乘法** $(a,b)\mapsto ab$（並列表示），滿足對所有 $a,b,c\in R$：
> 1. $a+b = b+a$
> 2. $(a+b)+c = a+(b+c)$
> 3. 存在 $0\in R$，$a+0 = a$
> 4. 每個 $a$ 有 $-a\in R$，$a+(-a) = 0$
> 5. $a(bc) = (ab)c$（**乘法結合律**）
> 6. $a(b+c) = ab+ac$，$(b+c)a = ba+ca$（**左、右分配律**）

【Q&A】[▶ 04:00](https://youtu.be/PNr02wON-2s?t=240)
- 學生：「加法單位叫 0？」老師：「對。」
- 學生：「有乘法單位嗎？」老師：「**沒有**——這裡完全沒提。我們很快會講，但那是**額外的**，不在基本條款裡。」

**1–4 說的是什麼**[▶ 04:30](https://youtu.be/PNr02wON-2s?t=270)：加上「加法是二元運算」，**$(R,+)$ 是交換群**。
- 【口頭】「每個環首先是一個交換群。但它**不是乘法群**：0 的存在會毀掉『每個元素都有乘法反元素』的任何希望。」

【口頭】[▶ 06:00](https://youtu.be/PNr02wON-2s?t=360)「分配律在高中代數被灌進你們腦袋。這就是我們怎麼因式分解、怎麼乘。我們應該**分配**，不該 **FOIL**——分配比較安全，可以推廣。」

## 2. 一串術語

「繼續這波術語的猛攻。你們得撐一下，最後會有例子。」

### 2.1 交換環、有單位元的環

[▶ 06:30](https://youtu.be/PNr02wON-2s?t=390)（講義 Def 4.1.2）
- **交換環（commutative ring）**：$ab = ba$ 對所有 $a,b$。說「交換環」指的是**乘法**；加法本來就交換。只要有一對不交換，就是**非交換環**。
- **有單位元（unity）**[▶ 07:30](https://youtu.be/PNr02wON-2s?t=450)：存在 $1\in R$，$1r = r1 = r$ 對所有 $r$。這樣的環叫 **unital ring**（有么環）。

【Q&A】[▶ 09:30](https://youtu.be/PNr02wON-2s?t=570) 學生問 $1$ 是不是數字 1。
- 老師：「1 是個**符號**。如果你想惹人厭，可以寫 $1_R$。你的系統裡可能有數字 1，但它不是這個環的單位元——那時這記號就有用。」
- 學生：「可以寫 $e$ 嗎？」老師：「可以，但別走太遠：**環永遠不會是乘法群**，因為 0。至少有趣的環不會。也許只有 $\{0\}$、$0 = 1$ 的那個環，在一種蠢的意義下是乘法群。」
- 【口頭】「抱歉講蠢事。選舉報導已經夠多了。」

### 2.2 整除、單位、零因子

**整除**[▶ 08:30](https://youtu.be/PNr02wON-2s?t=510)：若存在 $k\in R$，$a = kb$，以下三句同義：
- $b$ **整除** $a$（$b\mid a$）；
- $b$ 是 $a$ 的**因數**；
- $a$ 是 $b$ 的**倍數**。

「整除理論基本上一樣。」

**單位（unit）**[▶ 11:00](https://youtu.be/PNr02wON-2s?t=660)：$R$ 有單位元，$a\in R$，存在 $b$ 使 $ab = 1$。記 $b = a^{-1}$。
- 單位 = **有乘法反元素**的元素。
- 「在沒有單位元的環裡，這甚至沒有意義。」
- ⚠️ 注意：**unity**（單位元，就是 1）和 **unit**（單位，可逆元素）是不同的詞。

【Q&A】[▶ 15:30](https://youtu.be/PNr02wON-2s?t=930) 學生：「不用也要 $ba = 1$ 嗎？」
- 老師：「那會自動成立——在這個脈絡可以證明。我讓定義**精簡**，這樣你們要證某東西是單位時，**工作少一半**。你們會感謝我。」
- 「Gallian 在群的定義假設左右反元素都有；但 **Rotman** 只用左反元素定義群，再從結合律證明右反元素自動有。」

> 📘 筆記補充：在**交換環**裡 $ab = ba$，所以 $ab = 1$ 就夠。非交換環裡單邊反元素不一定是雙邊的；講義 Def 4.1.3 的「單位」是在交換環下定義的。

**零因子（zero divisor）**[▶ 12:30](https://youtu.be/PNr02wON-2s?t=750)：$a,b\neq0$ 但 $ab = 0$，則 $a$、$b$ 是零因子。

> **定理**（講義 Thm 4.1.4）[▶ 13:00](https://youtu.be/PNr02wON-2s?t=780)　環的單位元若存在則唯一；$a^{-1}$ 若存在則唯一。

「第一天的論證在這裡一樣成立。所以 $a^{-1}$ 這個記號不壞——它是一個**特定**的東西。」

**整數倍**[▶ 14:00](https://youtu.be/PNr02wON-2s?t=840)：跟加法群一樣，
$$n\cdot a = \underbrace{a+a+\cdots+a}_{n},\qquad(-n)\cdot a = \underbrace{(-a)+\cdots+(-a)}_{n}.$$
用點，因為這**不是環的乘法**，只是重複加減的簡寫。

### 2.3 整環、體、單位群

[▶ 16:30](https://youtu.be/PNr02wON-2s?t=990)「我要稍微偏離筆記，先給另一個定義，讓例子更有意思。」

> **定義**
> - **整環（integral domain）**：有單位元的交換環，**沒有零因子**。
> - **體（field）**[▶ 17:30](https://youtu.be/PNr02wON-2s?t=1050)：有單位元的交換環，**每個非零元素都是單位**。
> - **單位群（group of units）**[▶ 19:00](https://youtu.be/PNr02wON-2s?t=1140)：$R$ 有單位元，
> $$U(R) = \{r\in R : r\text{ 是單位}\}.$$

## 3. 例子 1–2：ℤ 和 ℤₙ

### 例 1：$\mathbb{Z}$

[▶ 19:30](https://youtu.be/PNr02wON-2s?t=1170)「最基本、最核心的例子。整數是**典型的環**——這整個定義部分就是照它的樣子做的。」

- **是環**：我們知道 $\mathbb{Z}$ 是加法群；乘法結合、分配。
- **是整環**[▶ 20:30](https://youtu.be/PNr02wON-2s?t=1230)：$ab = 0$ ⇒ $a = 0$ 或 $b = 0$，沒有零因子；交換；$1$ 是單位元。
- **不是體**[▶ 21:30](https://youtu.be/PNr02wON-2s?t=1290)：
  - 【課堂討論】學生從正面說：$U(\mathbb{Z}) = \{1,-1\}$。$ab = 1$ 的整數解只有 $a = b = 1$ 或 $a = b = -1$。
  - 具體說：$2x = 1$ ⇒ $x = 1/2\in\mathbb{Q}$，但 $1/2\notin\mathbb{Z}$。所以 $2\neq0$ 不是單位。

### 例 2：$\mathbb{Z}_n$

[▶ 23:00](https://youtu.be/PNr02wON-2s?t=1380) 模 $n$ 的加法和乘法，是環。單位群我們已經有記號：$U(n)$。

【口頭】[▶ 24:30](https://youtu.be/PNr02wON-2s?t=1470)「你們有些人很懂這個群。（嗯哼。）有些人沒那麼懂。（嗯哼。）抱歉，太早了嗎？」（剛考完試。）

- **$\mathbb{Z}_5$**：$U(5) = \{1,2,3,4\}$ = 所有非零元素 ⇒ **體**。這是**有限體**（finite field）的例子 [▶ 25:00](https://youtu.be/PNr02wON-2s?t=1500)。
- **$\mathbb{Z}_6$**：$U(6) = \{1,5\}$。更重要：$6 = 2\cdot3$，所以 $2\cdot3 = 0$，而 $2,3\neq0$ ⇒ **零因子** ⇒ **不是整環** [▶ 25:30](https://youtu.be/PNr02wON-2s?t=1530)。

**一般**[▶ 26:30](https://youtu.be/PNr02wON-2s?t=1590)：
- $p$ 質數 ⇒ $U(p) = \mathbb{Z}_p-\{0\}$ ⇒ $\mathbb{Z}_p$ 是體。
- $n$ 合數（$n = mk$，$1<m,k<n$）⇒ $mk = 0$ ⇒ $\mathbb{Z}_n$ 不是整環。但它仍是有單位元的交換環。

【口頭】[▶ 26:00](https://youtu.be/PNr02wON-2s?t=1560)「我寫 integral 寫累了。很多人乾脆把整環叫 **domain**。我會盡量不這樣——至少不會馬上。」

## 4. 特徵

[▶ 27:00](https://youtu.be/PNr02wON-2s?t=1620)（Gallian 第 13 章）

> **定義（特徵 characteristic）**（講義 Def 4.1.37）　使 $n\cdot x = 0$ 對**所有** $x\in R$ 成立的**最小**正整數 $n$，記 $\operatorname{char}(R) = n$。若不存在，$\operatorname{char}(R) = 0$。

【課堂討論】[▶ 27:30](https://youtu.be/PNr02wON-2s?t=1650)「不存在的話該叫什麼？」學生：「無限大。」老師：「差一點——其實是 **0**。我知道。但那是標準術語。」

> **定理**（講義 Thm 4.1.38；Gallian p.244）[▶ 28:00](https://youtu.be/PNr02wON-2s?t=1680)　$R$ 有單位元。若 $1$ 的加法階是 $n$（$n\cdot1 = 0$ 且 $n$ 最小），則 $\operatorname{char}(R) = n$；若 $1$ 的階無限，$\operatorname{char}(R) = 0$。

「對有單位元的環，只要看 **1 要加自己幾次才回到 0**。」

> 📘 講義的證明：$n\cdot x = x+\cdots+x = 1x+\cdots+1x = (n\cdot1)x = 0x = 0$。

**例**[▶ 29:00](https://youtu.be/PNr02wON-2s?t=1740)：$\operatorname{char}(\mathbb{Z}_5) = 5$；一般 $\operatorname{char}(\mathbb{Z}_n) = n$。

【口頭】[▶ 29:30](https://youtu.be/PNr02wON-2s?t=1770)「我個人喜歡住在**特徵 0** 的世界。1 加夠多次會回到 0——這讓我很不安，很煩。但你可以不同意。」

## 5. 例子 3–7：多項式、函數、體、矩陣、直積

【口頭】[▶ 30:00](https://youtu.be/PNr02wON-2s?t=1800)「這些定義很自然，你們大概不用硬背。真正的麻煩是**不要把定義說過頭**——很多東西是從定義**自動**推出的，但它們不是定義。」

### 例 3：$\mathbb{Z}[x]$

[▶ 30:30](https://youtu.be/PNr02wON-2s?t=1830) $\mathbb{Z}[x] = \{a_0+a_1x+\cdots+a_nx^n : a_j\in\mathbb{Z}\}$，**整數係數多項式**（「你們有一題作業做過」）。
- 和、積還是整數係數多項式 ⇒ 環。
- **是整環**[▶ 32:00](https://youtu.be/PNr02wON-2s?t=1920)：乘法交換；常數多項式 $1$ 是單位元；$f(x)g(x) = 0$ ⇒ $f = 0$ 或 $g = 0$。
- 係數換成 $\mathbb{R}$、$\mathbb{C}$、$\mathbb{Q}$——任何體都行。「想得更仔細，即使係數只來自**整環**，結果應該還是整環。」

### 例 4：函數環

[▶ 33:30](https://youtu.be/PNr02wON-2s?t=2010)「這個比較時髦一點。」$S$ 非空集合，$R$ 是環。$\mathcal F(S,R)$ = 所有 $f:S\to R$。**逐點**定義：
$$(f+g)(x) = f(x)+g(x),\qquad(fg)(x) = f(x)g(x).$$
（老師一開始把加法寫成乘，馬上改正。）所有公理都從**值域** $R$ 繼承。「這給我們一個從舊環做新環的方法。」

### 例 5：體

[▶ 36:00](https://youtu.be/PNr02wON-2s?t=2160) 我們最愛的體：$\mathbb{Q}$、$\mathbb{R}$、$\mathbb{C}$、$\mathbb{Z}_p$。

> **層級**[▶ 36:30](https://youtu.be/PNr02wON-2s?t=2190)：**體 ⇒ 整環 ⇒ 環**，反過來都不成立。
> - 每個體都是整環（沒有零因子），但 $\mathbb{Z}$ 是整環不是體。
> - 很多環不是整環（例如 $\mathbb{Z}_6$）。

### 例 6：矩陣環 $R^{n\times n}$

[▶ 37:00](https://youtu.be/PNr02wON-2s?t=2220)「例 6、例 7 是**從舊環造新環**的方法。」$R^{n\times n}$ = 元素取自 $R$ 的 $n\times n$ 矩陣。
- 加法逐分量：$(A+B)_{ij} = A_{ij}+B_{ij}$。
- 乘法 [▶ 38:00](https://youtu.be/PNr02wON-2s?t=2280)：$(AB)_{ij} = \sum_{k=1}^nA_{ik}B_{kj}$。「天啊，我以為我擺脫它了。不，它回來了。」
- 乘法**結合**，但**不交換**。
- $R$ 有單位元 ⇒ 對角線放 1 的矩陣是單位元 [▶ 38:30](https://youtu.be/PNr02wON-2s?t=2310)。
- **絕對不是整環**[▶ 39:00](https://youtu.be/PNr02wON-2s?t=2340)：不交換，而且例如
$$\begin{pmatrix}1&1\\1&1\end{pmatrix}\begin{pmatrix}-1&1\\1&-1\end{pmatrix} = \begin{pmatrix}0&0\\0&0\end{pmatrix}.$$
  「零因子多到爆。」（$R$ 有 1 就有 $-1$，因為環對加法反元素封閉。）
- **單位群**[▶ 40:00](https://youtu.be/PNr02wON-2s?t=2400)：$R$ 有單位元（交換）時，
$$U(R^{n\times n}) = \{A : \det A\in U(R)\}.$$

> 💬 板書的第二個矩陣字幕不清（「minus 1 1 minus 1 1」）；上面用的是乘積確實為零的版本。

### 例 7：直積環

[▶ 41:00](https://youtu.be/PNr02wON-2s?t=2460) $R_1,\dots,R_k$ 是環，$R = R_1\times\cdots\times R_k$，加法和乘法都**逐分量**：第 $i$ 個位置用 $R_i$ 的運算。

【口頭】[▶ 47:00](https://youtu.be/PNr02wON-2s?t=2820)「這個乘積環，即使 $n = 2$ 也**不是整環**。很容易看出為什麼。」

> 📘 講義 Ex 4.1.30：$\mathbb{Z}\times\mathbb{Z}$ 中 $(a,0)(0,b) = (0,0)$。

【口頭】[▶ 42:30](https://youtu.be/PNr02wON-2s?t=2550)「如果你現在有點迷路，**讀完 Gallian 第 12、13 章就會不迷路**。這些東西真的不難。我們今天沒講任何困難的定理，只是在習慣基本條款。」
- 「我們到底有沒有講過一個**我要求你們會的**複雜定理？Sylow 我沒要求，丟掉；Burnside 引理，丟掉。所以是**量**的問題，不是**難度**的問題。這是我的意見；你們當然有權有自己的意見——我們還沒活在希拉蕊的美國。」（2016 年 10 月 31 日，美國大選前一週。）

## 6. 環的自動性質

[▶ 44:30](https://youtu.be/PNr02wON-2s?t=2670)（講義 Thm 4.1.12）一旦有了環公理，這些就**自動**成立：

> **定理**　$a,b,c\in R$：
> 1. $a0 = 0a = 0$
> 2. $a(-b) = (-a)b = -(ab)$
> 3. $(-a)(-b) = ab$
> 4. $a(b-c) = ab-ac$，$(b-c)a = ba-ca$
> 5. 有單位元時：$(-1)a = -a$
> 6. 有單位元時：$(-1)(-1) = 1$

**證明 (1)**[▶ 45:00](https://youtu.be/PNr02wON-2s?t=2700)：
$$0+a0 = a0 = a(0+0) = a0+a0.$$
由**群的消去律**，$a0 = 0$。

> 📘 講義證 (5)：$0 = 0a = (1+(-1))a = a+(-1)a$，所以 $(-1)a = -a$。

【口頭】[▶ 46:00](https://youtu.be/PNr02wON-2s?t=2760)「這些是**很簡單的考題**——如果你讀過的話。但我個人如果走錯路，可以在其中一個上花很多時間。我的建議：自己試，**別在任何一個上花太久**。沒馬上想到，就去做別的，再回來。」（講義：「超過 10 分鐘就停下來。」）

## 7. 子環

[▶ 47:00](https://youtu.be/PNr02wON-2s?t=2820)

> **定義（子環 subring）**　環的子集，對環的加法和乘法本身是環。

> **定理（子環判別法）**（講義 Thm 4.1.14）　非空子集 $S\subseteq R$，若對所有 $a,b\in S$ 有 $a-b\in S$ 且 $ab\in S$，則 $S$ 是子環。

（「這是 $S$，很重要——別擔心，我還沒上傳，貼上前會改。」）證明「完全無趣」：跟線性代數的**子空間判別法**一樣——元素在 $R$ 裡，所以公理都成立；對減法和乘法封閉讓運算留在 $S$ 裡。

> ⚠️ **兩種慣例**：課堂（2016，跟 Gallian）的子環**不要求**含單位元。講義 2018 版 Def 4.1.13 要求子環**和 $R$ 共用單位元**，不含單位元的叫 **subrng**（「rng」：沒有 i 的 ring，沒有 identity）。

**例：$2\mathbb{Z}\subseteq\mathbb{Z}$**[▶ 48:30](https://youtu.be/PNr02wON-2s?t=2910)
- $2x-2y = 2(x-y)$、$(2x)(2y) = 2(2xy)$ 都是偶數。
- 非空：$2\in2\mathbb{Z}$（「或 0，或一百萬，隨便」）。
- **沒有單位元**：$1\notin2\mathbb{Z}$。「$\mathbb{Z}$ 有單位元，這個子環卻**失去**了它。」
- 奇數**不是**子環（$0\notin2\mathbb{Z}+1$）。

**例：$2\mathbb{Z}_6 = \{0,2,4\}\subseteq\mathbb{Z}_6$**[▶ 49:00](https://youtu.be/PNr02wON-2s?t=2940)「這個例子會讓你們覺得怪。」

| $\times$ | 0 | 2 | 4 |
|---|---|---|---|
| **0** | 0 | 0 | 0 |
| **2** | 0 | 4 | 2 |
| **4** | 0 | 2 | 4 |

- $2\cdot2 = 4$、$4\cdot4 = 16\equiv4$、$4\cdot2 = 8\equiv2$。
- **$4$ 是這個子環的單位元**：$4s = s4 = s$。（「某同學臉上的表情很好笑。」）
- 非零部分 $\{2,4\}$ 的乘法表「就像 $\{-1,1\}$ 的」。
- **更怪的是**[▶ 50:30](https://youtu.be/PNr02wON-2s?t=3030)：子環的單位元 $4$ **不是**大環的單位元 $1$。

【口頭】「**環裡的乘法很怪。**加法你大概不會錯——它只是群結構，我們熟。但乘法，**別太相信你的直覺**。」

**結尾**：還有其他例子下次講；發還考卷。

## 8. 講義補充：整環的消去律、有限整環是體

【講義補充】講義 §4.1 後半（p.126–128）課堂沒講到：

> **定理 4.1.31（消去律）**　整環中，$a\neq0$ 且 $ab = ac$ ⇒ $b = c$。

（$a(b-c) = 0$、沒有零因子。）

> **定理 4.1.33**　**有限整環是體。**
>
> **推論 4.1.34**　$p$ 質數 ⇒ $\mathbb{Z}_p$ 是體。

> **定理 4.1.39**　整環的特徵是 0 或質數。

（若 $n = st$，$0 = n\cdot1 = (s\cdot1)(t\cdot1)$，沒有零因子 ⇒ $s\cdot1 = 0$ 或 $t\cdot1 = 0$，由 $n$ 的最小性，$n$ 是質數。）

**更多例子**：
- $\mathbb{Z}[\sqrt2] = \{a+b\sqrt2 : a,b\in\mathbb{Z}\}$ 是整環（Ex 4.1.27）。
- $\mathbb{Z}[i]$：**高斯整數**（Ex 4.1.19）。
- $\mathbb{Z}_3[i] = \{a+bi : a,b\in\mathbb{Z}_3\}$：**9 個元素的體**（Ex 4.1.35）。
- $\mathbb{Q}[\sqrt2]$ 是體：$(a+b\sqrt2)^{-1} = \dfrac{a-b\sqrt2}{a^2-2b^2}$（Ex 4.1.36）。

## 9. 一頁速查表

### 9.1 定義層級

| 結構 | 條件 |
|---|---|
| 環 | $(R,+)$ 交換群；乘法結合；分配律 |
| 交換環 | $ab = ba$ |
| 有單位元 | 存在 $1$ |
| 整環 | 交換、有 1、**無零因子** |
| 體 | 交換、有 1、**非零都是單位** |

**體 ⇒ 整環 ⇒ 環**；有限整環 ⇒ 體。

## 附：本集一句話總結

> **環是加法交換群加上結合的乘法和分配律；有 1 的交換環若沒有零因子叫整環、若非零元素都可逆叫體（體 ⇒ 整環 ⇒ 環），例如 $\mathbb{Z}$ 是整環不是體、$\mathbb{Z}_p$ 是體、$\mathbb{Z}_6$ 有零因子 $2\cdot3 = 0$；特徵就是 1 要加自己幾次才回到 0；而 $2\mathbb{Z}_6 = \{0,2,4\}$ 這個子環的單位元竟然是 4——環裡的乘法很怪，別太相信直覺。**
