# 第 36 集 · L23：環與整環 [▶ 影片](https://www.youtube.com/watch?v=PNr02wON-2s&list=PLBY4G2o7DhF0JCgapYKrqibGaJuvV4Gkb)

## 本集概要

課程第三部分：**環與體**（Gallian 第 12、13 章）。
- **環 (ring)** 的定義：加法交換群 + 乘法結合 + 分配律。
- 術語：交換環、**有單位元 (unity)** 的環、**整除**、**單位 (unit)**、**零因子 (zero divisor)**、**整環 (integral domain)**、**體 (field)**、單位群 $U(R)$、**特徵 (characteristic)**。
- 例子：$\mathbb{Z}$（整環，不是體）；$\mathbb{Z}_n$（$n$ 質數時是體，否則有零因子）；$\mathbb{Z}[x]$；函數環；$\mathbb{Q},\mathbb{R},\mathbb{C},\mathbb{Z}_p$；矩陣環 $M_n(R)$；直積環。
- 環的基本性質：$a0 = 0$、$a(-b) = -ab$ 等。
- **子環判別法**；例：$2\mathbb{Z}$ 是沒有單位元的子環；$2\mathbb{Z}_6 = \{0,2,4\}$ 有自己的單位元 $4$，和 $\mathbb{Z}_6$ 的 $1$ 不同。

> 📘 講義對應：2018 講義 §4.1 Lecture 21「rings and integral domains」（p.122–128）；Gallian 第 12、13 章。老師說原本要分兩講，因為生病合成一講。

## 筆記

### 1. 環的定義 [▶ 00:30](https://youtu.be/PNr02wON-2s?t=30)

> **定義**　**環** $R$ 是非空集合，有兩個二元運算：加法 $(a,b)\mapsto a+b$、乘法 $(a,b)\mapsto ab$，滿足（對所有 $a,b,c\in R$）：
> 1. $a+b = b+a$
> 2. $(a+b)+c = a+(b+c)$
> 3. 有 $0\in R$ 使 $a+0 = a$
> 4. 每個 $a$ 有 $-a$ 使 $a+(-a) = 0$
> 5. $(ab)c = a(bc)$（乘法結合律）
> 6. $a(b+c) = ab+ac$、$(b+c)a = ba+ca$（左、右**分配律**）

- (1)–(4)：**$(R,+)$ 是交換群** [▶ 04:30](https://youtu.be/PNr02wON-2s?t=270)。
- 乘法**不是**群：0 的存在讓「每個元素都有乘法反元素」沒指望。
- 定義裡**沒有**要求乘法單位元（學生問）[▶ 04:30](https://youtu.be/PNr02wON-2s?t=270)。
- 分配律就是高中代數的因式分解和展開。「我們應該用分配律乘開，不該用 FOIL；分配律比較安全，也能推廣」[▶ 06:30](https://youtu.be/PNr02wON-2s?t=390)。

### 2. 術語 [▶ 06:30](https://youtu.be/PNr02wON-2s?t=390)

> **定義**
> 1. 若 $ab = ba$ 對所有 $a,b$，$R$ 是**交換環**；只要有一對不交換就是**非交換環**。（「交換」指乘法；加法本來就交換。）
> 2. 若有 $1\in R$ 使 $1r = r1 = r$ 對所有 $r$，說 $R$ **有單位元 (unity)**，或 $R$ 是 **unital ring** [▶ 07:30](https://youtu.be/PNr02wON-2s?t=450)。
> 3. **整除**：若 $a = kb$（$k\in R$），說 $b$ 整除 $a$、$b$ 是 $a$ 的**因數**、$a$ 是 $b$ 的**倍數** [▶ 08:30](https://youtu.be/PNr02wON-2s?t=510)。
> 4. 有單位元的環中，若有 $b$ 使 $ab = 1$，$a$ 叫**單位 (unit)**，記 $b = a^{-1}$ [▶ 11:00](https://youtu.be/PNr02wON-2s?t=660)。
> 5. 若 $a,b\neq0$ 但 $ab = 0$，$a$、$b$ 叫**零因子 (zero divisors)** [▶ 12:30](https://youtu.be/PNr02wON-2s?t=750)。

- 「1」只是符號。如果你處理的集合本身有數字 1、但它不是環的單位元，可以寫 $1_R$ 以免混淆 [▶ 10:00](https://youtu.be/PNr02wON-2s?t=600)。學生問能不能寫 $e$：可以，但別走太遠，環永遠不會是乘法群。（唯一例外是只有 0 的環，$0 = 1$，「愚蠢的例子」。）
- **只要 $ab = 1$ 就夠了**（學生問要不要 $ba = 1$）[▶ 15:30](https://youtu.be/PNr02wON-2s?t=930)：在這個脈絡可以證明另一邊自動成立，所以要證某元素是單位，只要做一半工作。（類似 Rotman 只用左反元素定義群。）

> **定理**　環中的 1 若存在則唯一；$a^{-1}$ 若存在則唯一 [▶ 13:00](https://youtu.be/PNr02wON-2s?t=780)。

證明和第一堂課群的單位元、反元素唯一一樣。所以 $a^{-1}$ 這個記號沒問題。

**整數倍** [▶ 14:00](https://youtu.be/PNr02wON-2s?t=840)：$n\cdot a = a+a+\cdots+a$（$n$ 個），$(-n)\cdot a = (-a)+\cdots+(-a)$。用點是因為這不是環的乘法，只是重複相加的簡寫。

> **定義** [▶ 16:30](https://youtu.be/PNr02wON-2s?t=990)
> - **整環 (integral domain)**：有單位元、沒有零因子的交換環。
> - **體 (field)**：有單位元、每個非零元素都是單位的交換環。
> - **單位群**：有單位元的環 $R$ 中，$U(R) = \{r\in R\mid r\text{ 是單位}\}$ [▶ 18:30](https://youtu.be/PNr02wON-2s?t=1110)。

### 3. 例子 [▶ 19:30](https://youtu.be/PNr02wON-2s?t=1170)

**例 1：$\mathbb{Z}$** [▶ 20:00](https://youtu.be/PNr02wON-2s?t=1200)——典型的環，「整個定義部分就是照著整數的樣子訂的」。
- **整環**：$ab = 0\Rightarrow a = 0$ 或 $b = 0$；交換；$1$ 是單位元 [▶ 21:00](https://youtu.be/PNr02wON-2s?t=1260)。
- **不是體**：$U(\mathbb{Z}) = \{\pm1\}$（$ab = 1$ 只有 $a = b = \pm1$）。$2x = 1$ 的解是 $\frac12\notin\mathbb{Z}$，所以 2 不是單位 [▶ 22:00](https://youtu.be/PNr02wON-2s?t=1320)。

**例 2：$\mathbb{Z}_n$** [▶ 23:00](https://youtu.be/PNr02wON-2s?t=1380)
- 是環（模運算）；單位群就是我們熟悉的 $U(n)$（「有些人很懂這個群，有些人……太快了嗎？」）。
- **$\mathbb{Z}_5$ 是體**：$U(5) = \{1,2,3,4\}$，就是除了 0 以外的所有元素。這是**有限體**的例子 [▶ 25:00](https://youtu.be/PNr02wON-2s?t=1500)。
- **$\mathbb{Z}_6$ 不是整環**：$2\cdot3 = 0$，2、3 是零因子 [▶ 25:30](https://youtu.be/PNr02wON-2s?t=1530)。
- 一般：$p$ 質數時 $\mathbb{Z}_p$ 是體；$n$ 是合數 $n = ab$（$a,b$ 非零非單位）時，$ab = 0$，$\mathbb{Z}_n$ 不是整環。但它仍是有單位元的交換環 [▶ 26:30](https://youtu.be/PNr02wON-2s?t=1590)。

（很多人把整環簡稱「domain」；老師暫時不這樣做。）

### 4. 特徵 [▶ 27:00](https://youtu.be/PNr02wON-2s?t=1620)

> **定義（Gallian 第 13 章）**　使 $nx = 0$ 對所有 $x\in R$ 成立的**最小**正整數 $n$，叫 $R$ 的**特徵** $\operatorname{char}R$。若不存在，**特徵為 0**（不是無限大！）[▶ 28:00](https://youtu.be/PNr02wON-2s?t=1680)。

> **定理（Gallian p.244）**　若 $R$ 有單位元，且 $n$ 是使 $n\cdot1 = 0$ 的最小正整數，則 $\operatorname{char}R = n$ [▶ 28:30](https://youtu.be/PNr02wON-2s?t=1710)。

- $\operatorname{char}\mathbb{Z}_5 = 5$；$\operatorname{char}\mathbb{Z}_n = n$ [▶ 29:00](https://youtu.be/PNr02wON-2s?t=1740)。
- 老師說他喜歡活在特徵 0 的世界：「1 加夠多次會回到 0，這讓我很不安。」

**提醒** [▶ 30:00](https://youtu.be/PNr02wON-2s?t=1800)：這些定義很自然，真正的麻煩是**不要把定義說過頭**——很多性質是從定義推出來的，不是定義本身。

### 5. 更多例子 [▶ 30:30](https://youtu.be/PNr02wON-2s?t=1830)

**例 3：$\mathbb{Z}[x]$**（整係數多項式）[▶ 30:30](https://youtu.be/PNr02wON-2s?t=1830)
- 加、乘照常，還是整係數多項式。是環。
- **整環** [▶ 32:00](https://youtu.be/PNr02wON-2s?t=1920)：交換；常數多項式 1 是單位元；$f(x)g(x) = 0\Rightarrow f = 0$ 或 $g = 0$。
- 係數換成 $\mathbb{R}$、$\mathbb{C}$、$\mathbb{Q}$ 或任何體也一樣；甚至係數取自任何整環，多項式環仍是整環。

**例 4：函數環** [▶ 33:30](https://youtu.be/PNr02wON-2s?t=2010)：$S$ 非空集合，$R$ 是環，$\{f:S\to R\}$，用**逐點**運算：
$$(f+g)(x) = f(x)+g(x),\qquad (fg)(x) = f(x)g(x).$$
交換、結合、分配律都從值域 $R$ 繼承。（板書一度把加法寫成乘法，隨即更正。）

**例 5：體** [▶ 36:00](https://youtu.be/PNr02wON-2s?t=2160)：$\mathbb{Q}$、$\mathbb{R}$、$\mathbb{C}$、$\mathbb{Z}_p$。
- 每個體都是整環；但不是每個整環都是體（例如 $\mathbb{Z}$）。
- 條件由強到弱：**體 ⊂ 整環 ⊂ 環**。

**例 6：矩陣環 $M_n(R)$** [▶ 37:00](https://youtu.be/PNr02wON-2s?t=2220)
- $n\times n$ 矩陣，元素取自環 $R$。加法逐元素；乘法 $(AB)_{ij} = \sum_kA_{ik}B_{kj}$（「我以為我擺脫它了，結果又回來了」）。
- 乘法結合，但**不交換**。若 $R$ 有單位元，對角線全是 1 的矩陣是 $M_n(R)$ 的單位元 [▶ 38:30](https://youtu.be/PNr02wON-2s?t=2310)。
- **不是整環**：除了不交換，還有一堆零因子 [▶ 39:00](https://youtu.be/PNr02wON-2s?t=2340)：
$$\begin{pmatrix}1&1\\1&1\end{pmatrix}\begin{pmatrix}-1&1\\1&-1\end{pmatrix} = \begin{pmatrix}0&0\\0&0\end{pmatrix}.$$
  （$1\in R$ 時 $-1$ 也在，因為環對加法反元素封閉。）
- **單位群** [▶ 40:00](https://youtu.be/PNr02wON-2s?t=2400)：$U(M_n(R)) = \{A\mid\det A\in U(R)\}$（$R$ 是有單位元的交換環）。
- 元素可以是多項式，甚至矩陣的矩陣的矩陣……「沒完沒了」[▶ 46:30](https://youtu.be/PNr02wON-2s?t=2790)。

**例 7：直積環** [▶ 40:30](https://youtu.be/PNr02wON-2s?t=2430)：$R = R_1\times\cdots\times R_k$，加法、乘法都**逐分量**。（即使 $k = 2$，它也不是整環：$(1,0)(0,1) = (0,0)$。）

### 6. 環的基本性質 [▶ 44:30](https://youtu.be/PNr02wON-2s?t=2670)

（講義投影）從公理**推出**，不是公理：
- $a0 = 0a = 0$
- $a(-b) = (-a)b = -(ab)$
- $(-a)(-b) = ab$ 等

**證明 $a0 = 0$** [▶ 45:00](https://youtu.be/PNr02wON-2s?t=2700)：
$$0 + a0 = a0 = a(0+0) = a0 + a0,$$
由加法群的消去律，$a0 = 0$。

**建議**：這些是很簡單的考題。自己試著推，但卡住不要太久，先做別的再回來；老師自己走錯方向時也會花很多時間 [▶ 46:00](https://youtu.be/PNr02wON-2s?t=2760)。

**為什麼重要** [▶ 46:30](https://youtu.be/PNr02wON-2s?t=2790)：每個關於環的定理，幾乎自動適用於你熟悉的所有例子：多項式、矩陣……

### 7. 子環 [▶ 47:00](https://youtu.be/PNr02wON-2s?t=2820)

> **定義**　**子環 (subring)**：環的子集，在原來的加法、乘法下也是環。

> **定理（子環判別法 subring test）**　環 $R$ 的非空子集 $S$ 是子環 $\iff$ $S$ 對**減法**和**乘法**封閉：$a,b\in S\Rightarrow a-b\in S$、$ab\in S$。

（講義裡「test」的 s 被打錯了，老師要更正。）證明和線性代數的子空間判別法一樣：元素都在大環裡，公理自動成立 [▶ 48:00](https://youtu.be/PNr02wON-2s?t=2880)。

**例：$2\mathbb{Z}\le\mathbb{Z}$** [▶ 48:30](https://youtu.be/PNr02wON-2s?t=2910)
- $2x-2y = 2(x-y)$、$(2x)(2y) = 2(2xy)$，都是偶數；非空（$0$、$2$ 都可以）。
- **沒有單位元**：1 不在裡面。大環有單位元，子環可以沒有 [▶ 49:00](https://youtu.be/PNr02wON-2s?t=2940)。
- 奇數**不是**子環（例如差是偶數）。

**怪例：$2\mathbb{Z}_6 = \{0,2,4\}\le\mathbb{Z}_6$** [▶ 49:30](https://youtu.be/PNr02wON-2s?t=2970)
- 乘法表：$2\cdot2 = 4$、$2\cdot4 = 2$、$4\cdot4 = 4$。
- **$4$ 是這個子環的單位元**：$4\cdot2 = 2$、$4\cdot4 = 4$ [▶ 50:00](https://youtu.be/PNr02wON-2s?t=3000)。
- 非零部分 $\{2,4\}$ 的乘法表就像 $\{-1,1\}$。
- 子環有單位元，但**和大環的單位元 1 不同**。

**教訓** [▶ 50:30](https://youtu.be/PNr02wON-2s?t=3030)：環的乘法很怪，別太相信直覺。加法只是群結構，我們已經熟悉。
