# 第 20 集 · 答疑課：$D_4$ 的內自同構、$\mathbb{C}$ 與矩陣、$\mathbb{Z}_n$ 上映射的良定義 [▶ 影片](https://www.youtube.com/watch?v=x6QGa_qTQ_s&list=PLBY4G2o7DhF0JCgapYKrqibGaJuvV4Gkb)

## 本集概要

- **Ch.6 #18**：$D_4$ 的自同構 $\varphi$，若 $\varphi(R_{90}) = R_{90}$、$\varphi(H) = V$，則 $\varphi$ 是 $R_{90}$ 誘導的內自同構。改用生成元與關係 $x$、$y$ 來算，簡單很多。
- **Ch.6 #27**：$\mathbb{C}\cong M = \left\{\begin{pmatrix}a&-b\\b&a\end{pmatrix}\right\}$，加法和乘法（去掉 0）都同構。複數的倒數對應 $2\times2$ 反矩陣公式。
- **Ch.6 #28**：$\mathbb{R}^n$ 上的**反演** $\varphi(\mathbf a) = -\mathbf a$ 是自同構。
- **更正上一堂**：$\mathbb{Z}_n$ 的元素應看成**同餘類**，不是 $\mathbb{Z}$ 的子集。在同餘類上定義函數，必須檢查**良定義**（和代表元的選擇無關）。

## 筆記

### 題 1：$D_4$ 的內自同構（Ch.6 #18）[▶ 00:30](https://youtu.be/x6QGa_qTQ_s?t=30)

**題目**：$\varphi$ 是 $D_4$ 的自同構，$\varphi(R_{90}) = R_{90}$、$\varphi(H) = V$。證明 $\varphi$ 是 $R_{90}$ 誘導的內自同構 [▶ 03:30](https://youtu.be/x6QGa_qTQ_s?t=210)。

**記號對照表** [▶ 01:00](https://youtu.be/x6QGa_qTQ_s?t=60)（Gallian → 生成元與關係）

| Gallian | $R_0$ | $R_{90}$ | $R_{180}$ | $R_{270}$ | $H$ | $D$ | $V$ |
|---|---|---|---|---|---|---|---|
| 老師 | $1$ | $x$ | $x^2$ | $x^3$ | $y$ | $xy$ | $x^2y$ |

（老師說這不是唯一的對照法，他有用幾何檢查過。$x$ 只能是 $R_{90}$ 或 $R_{270}$，因為只有它們是 4 階；$y$ 可以選 $H$ 或 $V$ [▶ 11:30](https://youtu.be/x6QGa_qTQ_s?t=690)。）

題目條件變成：$\varphi(x) = x$、$\varphi(y) = x^2y$ [▶ 02:30](https://youtu.be/x6QGa_qTQ_s?t=150)。

$$D_4 = \{1,x,x^2,x^3,\ y,xy,x^2y,x^3y\}.$$
所有元素都是 $x^m$ 或 $x^my$（$m = 0,1,2,3$），分兩類檢查 [▶ 04:30](https://youtu.be/x6QGa_qTQ_s?t=270)。要證 $\varphi(g) = xgx^{-1}$。

**旋轉 $x^m$** [▶ 05:00](https://youtu.be/x6QGa_qTQ_s?t=300)
$$\varphi(x^m) = \varphi(x)^m = x^m = x\,x^m\,x^{-1}.$$

**鏡射 $x^my$** [▶ 06:00](https://youtu.be/x6QGa_qTQ_s?t=360)
$$\varphi(x^my) = \varphi(x)^m\varphi(y) = x^m x^2y = x^{m+2}y.$$
另一方面，用 $yx^{-1} = xy$（由 $yx^{-1}y = x$，即 $fR^{-1}f = R$）[▶ 08:30](https://youtu.be/x6QGa_qTQ_s?t=510)：
$$x\,(x^my)\,x^{-1} = x^{m+1}(yx^{-1}) = x^{m+1}xy = x^{m+2}y.\ \checkmark$$

所以 $\varphi = \varphi_x$（$R_{90}$ 誘導的內自同構）。$\blacksquare$

> 💬 老師課堂上的寫法是先補 $x^4 = 1$：$x^{m+2}y = x^{m+2}y\,x^4 = \cdots$，再交換 $y$ 和 $x$ 的次方。上面是同一件事的精簡版。

**$\varphi_x = \varphi_{x^3}$** [▶ 44:30](https://youtu.be/x6QGa_qTQ_s?t=2670)：用 $x^my = yx^{-m}$，
$$x^3(x^my)x^{-3} = x^3(x^my)x = x^{m+3}yx = x^{m+3}x^{-1}y = x^{m+2}y.$$
旋轉部分更簡單：$x$ 和自己交換，兩邊只是多加減 4 次方。

**為什麼要用 $x,y$** [▶ 10:30](https://youtu.be/x6QGa_qTQ_s?t=630)：$D_4$ 用 $R_{90}$、$H$、$D'$ 還勉強可以；老師的哥哥會問喜歡 Gallian 記號的學生：「那 $D_5$ 你要怎麼記？」

### 題 2：$\mathbb{C}\cong$ 一類 $2\times2$ 矩陣（Ch.6 #27）[▶ 12:00](https://youtu.be/x6QGa_qTQ_s?t=720)

老師很喜歡這題：課程太常只看 $\mathbb{Z}_n$、$U(n)$，矩陣的例子也很重要。

$$M = \left\{\begin{pmatrix}a&-b\\b&a\end{pmatrix}\ \middle|\ a,b\in\mathbb{R}\right\},\qquad \psi(a+bi) = \begin{pmatrix}a&-b\\b&a\end{pmatrix}.$$

**(a) 加法同構** [▶ 14:30](https://youtu.be/x6QGa_qTQ_s?t=870)
- 保持加法：
$$\psi\big((a+bi)+(x+yi)\big) = \begin{pmatrix}a+x&-(b+y)\\b+y&a+x\end{pmatrix} = \psi(a+bi)+\psi(x+yi).$$
- 核：$\psi(a+bi) = 0$ 逼得 $a = b = 0$，所以 $\ker\psi = \{0\}$，一對一 [▶ 17:00](https://youtu.be/x6QGa_qTQ_s?t=1020)。
- 映成：任何 $\begin{pmatrix}a&-b\\b&a\end{pmatrix} = \psi(a+bi)$。

**(b) 乘法同構**（$\mathbb{C}^\times\to M^\times$，去掉零）[▶ 18:00](https://youtu.be/x6QGa_qTQ_s?t=1080)
- 嚴格說是新映射 $\tilde\psi$：定義域去掉 0，對應域也去掉零矩陣。老師說這「比限制還多一步」，但被拿掉的點正好互相配對，所以仍是雙射 [▶ 20:30](https://youtu.be/x6QGa_qTQ_s?t=1230)。
- **單位元素不同**：乘法的核是 $\{z\mid\tilde\psi(z) = I\}$，解得 $a = 1$、$b = 0$，所以 $\ker\tilde\psi = \{1\}$ [▶ 22:00](https://youtu.be/x6QGa_qTQ_s?t=1320)。加法核和乘法核是不同的東西。
- **保持乘法** [▶ 23:30](https://youtu.be/x6QGa_qTQ_s?t=1410)：$(a+bi)(x+yi) = (ax-by)+(ay+bx)i$，
$$\begin{pmatrix}a&-b\\b&a\end{pmatrix}\begin{pmatrix}x&-y\\y&x\end{pmatrix} = \begin{pmatrix}ax-by&-(ay+bx)\\ay+bx&ax-by\end{pmatrix} = \tilde\psi\big((a+bi)(x+yi)\big).$$
- 老師提醒：「核 $= \{e\}\Rightarrow$ 一對一」要先知道是同態才能用 [▶ 23:00](https://youtu.be/x6QGa_qTQ_s?t=1380)。

**附帶得到 $M^\times$ 是群** [▶ 25:30](https://youtu.be/x6QGa_qTQ_s?t=1530)：乘積還是同一型（封閉）；$I$ 在裡面（$a = 1,b = 0$）；反矩陣也是同一型：
$$\begin{pmatrix}a&-b\\b&a\end{pmatrix}^{-1} = \frac{1}{a^2+b^2}\begin{pmatrix}a&b\\-b&a\end{pmatrix} = \tilde\psi\!\left(\frac{a-bi}{a^2+b^2}\right) = \tilde\psi\!\left(\frac{1}{a+bi}\right).$$

**漂亮的地方** [▶ 26:30](https://youtu.be/x6QGa_qTQ_s?t=1590)：這個同構把**複數的倒數**變成 **$2\times2$ 反矩陣公式**。代數學家會說：這些矩陣**就是**複數，只是記號不同。

**延伸** [▶ 28:30](https://youtu.be/x6QGa_qTQ_s?t=1710)：有些 $2\times2$ **複**矩陣組成的群同構於四元數群 $Q_8$；二面體群也能用 $2\times2$ 矩陣表示。可能會出作業。

（學生問 $D_4$ 和 $M$ 的差別：$D_4$ 有 8 個元素，$M$、$\mathbb{C}$ 是無限群，很不一樣，但同一套群論都能描述 [▶ 29:30](https://youtu.be/x6QGa_qTQ_s?t=1770)。）

### 題 3：$\mathbb{R}^n$ 上的反演（Ch.6 #28）[▶ 30:00](https://youtu.be/x6QGa_qTQ_s?t=1800)

$$\varphi:(\mathbb{R}^n,+)\to(\mathbb{R}^n,+),\qquad \varphi(\mathbf a) = -\mathbf a.$$
（老師拒絕用 Gallian 逐分量的寫法：「我們學過線性代數了，向量就寫 $\mathbf a$」[▶ 30:30](https://youtu.be/x6QGa_qTQ_s?t=1830)。）

- **一對一**：$-\mathbf a = -\mathbf b\Rightarrow\mathbf a = \mathbf b$ [▶ 32:00](https://youtu.be/x6QGa_qTQ_s?t=1920)。
- **映成**：$\varphi(-\mathbf a) = \mathbf a$。
- **保持加法**：$\varphi(\mathbf a+\mathbf b) = -\mathbf a-\mathbf b = \varphi(\mathbf a)+\varphi(\mathbf b)$ [▶ 33:00](https://youtu.be/x6QGa_qTQ_s?t=1980)。

所以是自同構，叫**反演 (inversion)**。幾何上：把向量**對原點反射**到另一邊 [▶ 34:00](https://youtu.be/x6QGa_qTQ_s?t=2040)。

### 4. 更正：$\mathbb{Z}_n$ 是同餘類，要檢查良定義 [▶ 34:30](https://youtu.be/x6QGa_qTQ_s?t=2070)

**上一堂說錯了**：老師說「$\mathbb{Z}_n$ 是 $\mathbb{Z}$ 的子集」，這不是要的。$\mathbb{Z}_n$ 的元素是**同餘類（陪集）**。可以造一個和 $\mathbb{Z}_n$ 同構的 $\mathbb{Z}$ 子集，但那是另一回事。

**正確寫法** [▶ 35:00](https://youtu.be/x6QGa_qTQ_s?t=2100)
$$\psi:\mathbb{Z}_n\to\mathbb{C}^\times,\qquad \psi([j]) = e^{2\pi ij/n}.$$
$[j]$ 是一個陪集，所以要證：**換一個代表元，答案不變**。否則它根本不是函數（不是**單值的 single-valued**）[▶ 36:00](https://youtu.be/x6QGa_qTQ_s?t=2160)。

**壞例子** [▶ 36:30](https://youtu.be/x6QGa_qTQ_s?t=2190)：$\varphi:\mathbb{Z}_n\to\mathbb{Z}$，$\varphi([j]) = j$。
- $[j] = [j+n]$，但 $\varphi$ 會給出 $j$ 和 $j+n$ 兩個不同的值。
- 真正的「輸出」是整個集合 $j+n\mathbb{Z}$，所以**不是函數**。

**好例子：驗證 $\psi$ 良定義** [▶ 38:30](https://youtu.be/x6QGa_qTQ_s?t=2310)
- 若 $[j'] = [j]$，則 $j'-j\in n\mathbb{Z}$，即 $j' = j+kn$。（老師一開始誤寫成 $j+2\pi k$，隨即更正：這裡只有整數，沒有 $2\pi$ [▶ 39:30](https://youtu.be/x6QGa_qTQ_s?t=2370)。）
- 則
$$e^{2\pi ij'/n} = e^{2\pi i(j+kn)/n} = e^{2\pi ij/n}\,e^{2\pi ik} = e^{2\pi ij/n},$$
  因為 $e^{2\pi ik} = \cos2\pi k + i\sin2\pi k = 1$ [▶ 40:30](https://youtu.be/x6QGa_qTQ_s?t=2430)。
- 所以 $\psi$ 和代表元無關，是良定義的函數。

**為什麼要這樣看** [▶ 41:30](https://youtu.be/x6QGa_qTQ_s?t=2490)：把 $\mathbb{Z}_n$ 當成 $\mathbb{Z}$ 的子集，就得在「相加超過 $n$」時分情況（上一堂卡住的地方）。用同餘類，$[j]+[k] = [j+k]$ 直接成立，不用分情況。平常寫 $\psi(j)$ 只是 $\psi([j])$ 的簡寫。
