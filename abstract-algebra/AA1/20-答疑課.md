## 1. 題 1：D₄ 的內自同構（Ch.6 #18）

[▶ 00:30](https://youtu.be/x6QGa_qTQ_s?t=30)

> **題目**　$\varphi$ 是 $D_4$ 的自同構，$\varphi(R_{90}) = R_{90}$、$\varphi(H) = V$。證明 $\varphi$ 是 $R_{90}$ 誘導的內自同構。

### 1.1 記號對照表

[▶ 01:00](https://youtu.be/x6QGa_qTQ_s?t=60)「我做了一下，得到下面這個**字典**。」（Gallian 記號 → 生成元與關係式）

| Gallian | $R_0$ | $R_{90}$ | $R_{180}$ | $R_{270}$ | $H$ | $D$ | $V$ |
|---|---|---|---|---|---|---|---|
| 老師 | $1$ | $x$ | $x^2$ | $x^3$ | $y$ | $xy$ | $x^2y$ |

（$x^4 = 1$、$y^2 = 1$、$(xy)^2 = 1$。）

- 「這可能不唯一，但是一種。我有用幾何檢查過。」[▶ 01:30](https://youtu.be/x6QGa_qTQ_s?t=90)
- **怎麼得到的**[▶ 11:00](https://youtu.be/x6QGa_qTQ_s?t=660)：「蠢蠢的肉搏戰。我令 $R_{90}$ 是 $x$，然後用幾何看乘積，研究什麼必須是 $y$。」有人發現 Gallian 的順序剛好也對得上，「但那是巧合，他們運氣好」。
- **哪些可以選**[▶ 11:30](https://youtu.be/x6QGa_qTQ_s?t=690)：$x$ **只能**是 $R_{90}$ 或 $R_{270}$——它們是僅有的 4 階元素。$y$ 可以選 $H$ 或 $V$。「我不確定 $D$ 能不能當 $y$，我沒想過。」

【口頭】[▶ 02:00](https://youtu.be/x6QGa_qTQ_s?t=120)「要在二面體群做任何計算，我都會換成生成元與關係式，因為**簡單太多**。」[▶ 10:30](https://youtu.be/x6QGa_qTQ_s?t=630)「我哥會問那些很喜歡 Gallian 記號的學生：『好，那你的 $D_5$ 記號是什麼？』$D_4$ 還勉強可以，但之後……天啊，糟透了。」

**題目條件翻譯**[▶ 02:30](https://youtu.be/x6QGa_qTQ_s?t=150)：
$$\varphi(x) = x,\qquad\varphi(y) = x^2y.$$
要證：$\varphi = \varphi_x$，即 $\varphi(g) = xgx^{-1}$ 對所有 $g$。

### 1.2 證明

[▶ 04:00](https://youtu.be/x6QGa_qTQ_s?t=240)
$$D_4 = \{1,x,x^2,x^3,\ y,xy,x^2y,x^3y\}.$$
「有個簡單的命名把它們分成**兩大類**：$x^m$ 和 $x^my$（$m = 0,1,2,3$）。如果對這兩類證明我的宣稱，就搞定了。」

**旋轉 $x^m$**[▶ 05:00](https://youtu.be/x6QGa_qTQ_s?t=300)：用上次的引理（同構把次方提出來）：
$$\varphi(x^m) = \varphi(x)^m = x^m = x\,x^m\,x^{-1}.$$
「歪頭瞇眼看，就能看出最後一個等號——指數律。」所以 $\varphi$ 在這一半跟 $\varphi_x$ 一致。

**鏡射 $x^my$**[▶ 06:00](https://youtu.be/x6QGa_qTQ_s?t=360)：
$$\varphi(x^my) = \varphi(x^m)\varphi(y) = \varphi(x)^m\varphi(y) = x^m\,x^2y = x^{m+2}y.$$
「到目前為止只用了它是同態，現在用題目給的資料。」

目標是 $x(x^my)x^{-1}$。注意 $x^{-1} = x^3$ [▶ 07:30](https://youtu.be/x6QGa_qTQ_s?t=450)。老師的「偷懶」做法：
$$x^{m+2}y = x^{m+2}y\cdot x^4 = x\,x^{m+1}\,y\,x\,x^3.$$
【課堂討論】[▶ 08:30](https://youtu.be/x6QGa_qTQ_s?t=510) 學生提示：交換 $yx$——用 $yx = x^{-1}y$（等價地 $xy = yx^{-1}$）：
$$= x\,x^{m+1}x^{-1}y\,x^{-1} = x(x^my)x^{-1} = \varphi_x(x^my).$$

（精簡版：由 $xy = yx^{-1}$ 得 $yx^{-1} = xy$，所以 $x(x^my)x^{-1} = x^{m+1}(yx^{-1}) = x^{m+1}xy = x^{m+2}y$ ✓。）

兩類都一致，所以 $\varphi = \varphi_x$，是 $R_{90}$ 誘導的**內自同構**。$\blacksquare$

【口頭】[▶ 10:00](https://youtu.be/x6QGa_qTQ_s?t=600)「如果很貪心，也可以一次處理所有元素，寫成 $y^kx^m$。但我有點緊張，所以分開做。」

【口頭】[▶ 44:30](https://youtu.be/x6QGa_qTQ_s?t=2670)「離開他的記號之後，我對第 18 題很滿意：『喔，這沒那麼糟。』一開始我想：這太可怕了，我還要你們做八次這種東西。」

### 1.3 附帶：φₓ = φ_{x³}

[▶ 44:30](https://youtu.be/x6QGa_qTQ_s?t=2670)「我們做題時我就該注意到：$\varphi_x = \varphi_{x^3}$。用我的記號很容易看出。」

**鏡射**：用 $x^my = yx^{-m}$（老師提醒：$m$ 在這裡被重複用了）：
$$\varphi_{x^3}(x^my) = x^3(x^my)x^{-3} = x^3(x^my)x = x^{m+3}(yx) = x^{m+3}x^{-1}y = x^{m+2}y = \varphi_x(x^my).$$

**旋轉**[▶ 46:00](https://youtu.be/x6QGa_qTQ_s?t=2760)：「更簡單：直接是指數律。用 $x$ 共軛，是一邊放 $x$、一邊放 $x^3$；用 $x^3$ 共軛，是一邊放 $x^3$、一邊放 $x$。不管哪樣，都只是在元素上多加 4 次方的 $x$，而 $x$ 跟自己交換。」

（原因：$x^3 = x\cdot x^2$，而 $x^2$ 在 $D_4$ 的中心裡，所以用 $x^2$ 共軛不改變任何東西。）

## 2. 題 2：ℂ 同構於一類 2×2 矩陣（Ch.6 #27）

[▶ 12:00](https://youtu.be/x6QGa_qTQ_s?t=720)【口頭】「我本來打算上課講這題，只是一直沒湊上。**我很喜歡這題**。我們太常陷在 $\mathbb{Z}_n$、$U(n)$ 裡——那大致是 Gallian 的主軸——但**矩陣的例子很重要**，這是一個非常棒的例子。」

$$M = \left\{\begin{pmatrix}a&-b\\b&a\end{pmatrix} : a,b\in\mathbb{R}\right\},\qquad\psi(a+bi) = \begin{pmatrix}a&-b\\b&a\end{pmatrix}.$$

（老師用 $\psi$：「psi，就像我跟我爸說話時的嘆氣（sigh）。」）

### 2.1 加法同構

[▶ 14:30](https://youtu.be/x6QGa_qTQ_s?t=870)

**保持加法**：
$$\psi\left((a+bi)+(x+yi)\right) = \psi\left((a+x)+(b+y)i\right) = \begin{pmatrix}a+x&-(b+y)\\b+y&a+x\end{pmatrix} = \psi(a+bi)+\psi(x+yi).$$
「我很快就會厭倦把所有細節寫出來。這題要寫的東西很多，但沒有一個難。」

（$M$ 在加法下是群：兩個這種矩陣相加還是這種矩陣，「顯然是群」。）

**核**[▶ 17:00](https://youtu.be/x6QGa_qTQ_s?t=1020)【課堂討論】：$\psi(a+bi) = 0$（零矩陣）逼得 $a = b = 0$，所以 $\operatorname{Ker}\psi = \{0\}$，一對一。

**映成**：任意 $\begin{pmatrix}a&-b\\b&a\end{pmatrix} = \psi(a+bi)$。

所以 $\psi:(\mathbb{C},+)\to(M,+)$ 是同構。

（老師說他故意把作業出成有理數版本，把實數版留給課堂。）

### 2.2 乘法同構

[▶ 18:00](https://youtu.be/x6QGa_qTQ_s?t=1080)「它在乘法意義下**也**是同構，但要小心。」

**新映射**[▶ 20:00](https://youtu.be/x6QGa_qTQ_s?t=1200)：$\tilde\psi:\mathbb{C}^\times\to M^\times$（去掉 0 和零矩陣），公式一樣。

【口頭】「嚴格說它不是同一個映射，是**限制**（restriction）。一對一映射的限制還是一對一，而且這個限制剛好仍是映成。」[▶ 21:00](https://youtu.be/x6QGa_qTQ_s?t=1260)「其實不只是限制：我把一個點從定義域拿掉，**也把對應域砍掉了**一個點。但那兩個點是配對的，所以還是雙射。」

**單位元素**[▶ 18:30](https://youtu.be/x6QGa_qTQ_s?t=1110)：$\mathbb{C}^\times$ 的是 $1$，$M^\times$ 的是單位矩陣 $I$。

**核**[▶ 22:00](https://youtu.be/x6QGa_qTQ_s?t=1320)：
$$\operatorname{Ker}\tilde\psi = \{a+bi : \tilde\psi(a+bi) = I\}\Rightarrow a = 1,\ b = 0.$$
所以 $\operatorname{Ker}\tilde\psi = \{1\}$。**加法核和乘法核是不同的東西。**

【口頭】[▶ 23:00](https://youtu.be/x6QGa_qTQ_s?t=1380)「我又作弊了：在用『核平凡 ⇒ 一對一』之前，**得先證明它是同態**。那個定理只對群同態成立。」

**保持乘法**[▶ 23:30](https://youtu.be/x6QGa_qTQ_s?t=1410)：
$$(a+bi)(x+yi) = (ax-by)+(ay+bx)i,$$
所以
$$\tilde\psi\left((a+bi)(x+yi)\right) = \begin{pmatrix}ax-by&-(ay+bx)\\ay+bx&ax-by\end{pmatrix}.$$
另一邊（「兩邊夾擊，在中間會合」[▶ 24:30](https://youtu.be/x6QGa_qTQ_s?t=1470)）：
$$\begin{pmatrix}a&-b\\b&a\end{pmatrix}\begin{pmatrix}x&-y\\y&x\end{pmatrix} = \begin{pmatrix}ax-by&-ay-bx\\bx+ay&-by+ax\end{pmatrix}.\ ✓$$

**附帶證明 $M^\times$ 是群**[▶ 25:30](https://youtu.be/x6QGa_qTQ_s?t=1530)：
- **封閉**：上面的計算就說明兩個這種矩陣的乘積還是這種矩陣。
- **單位**：$a = 1,b = 0$ 給 $I$。
- **反元素**：見下一節。

【口頭】[▶ 19:30](https://youtu.be/x6QGa_qTQ_s?t=1170)「如果我考這題，希望我會寫：『已知這是矩陣乘法下的群，證明它同構於非零複數。』」

### 2.3 漂亮的地方：倒數 ↔ 反矩陣

[▶ 26:00](https://youtu.be/x6QGa_qTQ_s?t=1560)「這真的很美，看：」

由 $2\times2$ 反矩陣公式（$\det = a^2+b^2$）：
$$\begin{pmatrix}a&-b\\b&a\end{pmatrix}^{-1} = \frac{1}{a^2+b^2}\begin{pmatrix}a&b\\-b&a\end{pmatrix} = \tilde\psi\!\left(\frac{a-bi}{a^2+b^2}\right) = \tilde\psi\!\left(\frac{1}{a+bi}\right).$$
「如果你的複數算術還新鮮，你會認出那就是 $1/(a+bi)$。」

【口頭】[▶ 26:30](https://youtu.be/x6QGa_qTQ_s?t=1590)「這個同構把**複數的倒數**轉成**矩陣層級的 $2\times2$ 反矩陣公式**。這是同一個結構的兩種記號。**代數學家會說：這些 $2\times2$ 矩陣就是複數。**有時候我覺得自己是個代數學家。」

**延伸**[▶ 28:30](https://youtu.be/x6QGa_qTQ_s?t=1710)：
- 有一些 $2\times2$ **複**矩陣組成的群同構於**四元數群 $Q_8$**。「我可能很快會出相關作業。」
- 各種有趣的矩陣群：二面體群也能用 $2\times2$ 矩陣表示。

【Q&A】[▶ 29:30](https://youtu.be/x6QGa_qTQ_s?t=1770) 學生比較 $D_4$ 和 $M$。老師：「差很多：$D_4$ 有 8 個元素；$M$ 和 $\mathbb{C}$ 是無限群，是很不一樣的動物。但**同一套群論**描述它們兩個。」

## 3. 題 3：ℝⁿ 上的反演（Ch.6 #28）

[▶ 30:00](https://youtu.be/x6QGa_qTQ_s?t=1800)「28 很快。」

$$\varphi:(\mathbb{R}^n,+)\to(\mathbb{R}^n,+),\qquad\varphi(\mathbf a) = -\mathbf a.$$

【口頭】[▶ 30:30](https://youtu.be/x6QGa_qTQ_s?t=1830)「他有各種笨拙的記號想讓我們用（逐分量寫）。我會寫下來，但不用，因為它很糟、很蠢，是**錯的記號方式**——我們學過線性代數了，已經超越這個了。向量就寫 $\mathbf a$。」「他寫的方式預設讀者缺乏背景，細節血淋淋又不必要。」

**是映射嗎**：向量乘 $-1$ 還是向量。✓

**一對一**[▶ 32:00](https://youtu.be/x6QGa_qTQ_s?t=1920)（「用老派的方法」）：$\varphi(\mathbf a) = \varphi(\mathbf b)\Rightarrow-\mathbf a = -\mathbf b\Rightarrow\mathbf a = \mathbf b$。

**映成**：給 $\mathbf a$，$\varphi(-\mathbf a) = \mathbf a$。

**保持加法**[▶ 33:00](https://youtu.be/x6QGa_qTQ_s?t=1980)：「這是很複雜的計算，小心。」（反諷）
$$\varphi(\mathbf a+\mathbf b) = -(\mathbf a+\mathbf b) = -\mathbf a-\mathbf b = \varphi(\mathbf a)+\varphi(\mathbf b).$$
「如果用他想騙我用的分量記號，這會看起來複雜得多。我拒絕。」

所以 $\varphi$ 是 $\mathbb{R}^n$ 的自同構，叫**反演（inversion）**。

**幾何意義**[▶ 34:00](https://youtu.be/x6QGa_qTQ_s?t=2040)：把向量翻到原點的另一邊——「**對原點反射**」。「我通常就叫它反演，所以這說法對我來說有點循環。」

## 4. 更正：Zn 的元素是同餘類，要檢查良定義

[▶ 34:30](https://youtu.be/x6QGa_qTQ_s?t=2070)「我希望早點收到你們的 email。上次我說了**不對**的話：**$\mathbb{Z}_n$ 不是 $\mathbb{Z}$ 的子集**。那不是我們要的。我們可以定義一個跟 $\mathbb{Z}_n$ 同構的 $\mathbb{Z}$ 子集，但那是另一回事。我要 $\mathbb{Z}_n$ 包含**同餘類**。」

**正確寫法**[▶ 35:00](https://youtu.be/x6QGa_qTQ_s?t=2100)（上一次答疑課的映射）：
$$\psi:\mathbb{Z}_n\to\mathbb{C}^\times,\qquad\psi([j]) = e^{2\pi ij/n}.$$
（不是映成，但是同態。）

$[j]$ 是**陪集**。要證它是函數，**必須證明公式與代表元的選擇無關**：若 $[j] = [j']$，則 $\psi([j]) = \psi([j'])$ [▶ 36:00](https://youtu.be/x6QGa_qTQ_s?t=2160)。否則它**不是單值的（single-valued）**，就不是函數。「每次在陪集上定義函數，偏離單值性都在旁邊等著抓我們。」

**壞例子**[▶ 36:30](https://youtu.be/x6QGa_qTQ_s?t=2190)：
$$\varphi:\mathbb{Z}_n\to\mathbb{Z},\qquad\varphi([j]) = j.$$
- $[j] = [j+n]$，但 $\varphi([j+n]) = j+n\neq j$。
- 「它的輸出不只是 $j$。更精確地說，單一元素的像是整個集合 $j+n\mathbb{Z} = \{j+nk : k\in\mathbb{Z}\}$。」[▶ 37:30](https://youtu.be/x6QGa_qTQ_s?t=2250)
- **不是函數**：公式依賴代表元。

**好例子：驗證 $\psi$ 良定義**[▶ 38:30](https://youtu.be/x6QGa_qTQ_s?t=2310)

設 $[j'] = [j]$，即 $j'-j\in n\mathbb{Z}$，所以 $j' = j+kn$，$k\in\mathbb{Z}$。

（老師一開始寫成 $j' = j+2\pi k$，然後 [▶ 39:30](https://youtu.be/x6QGa_qTQ_s?t=2370)：「等一下，這是胡說。這只是整數，**沒有 $2\pi$**——這蠻重要的。」）

$$\psi([j']) = e^{2\pi ij'/n} = e^{2\pi i(j+kn)/n} = e^{2\pi ij/n}\,e^{2\pi ik}.$$
而
$$e^{2\pi ik} = \cos2\pi k+i\sin2\pi k = 1+0i = 1\quad(k\in\mathbb{Z}).$$
「那個 $2\pi$ **在這裡**是合法的，因為 sin、cos 就是這樣運作的。」[▶ 40:30](https://youtu.be/x6QGa_qTQ_s?t=2430)

所以 $\psi([j']) = e^{2\pi ij/n} = \psi([j])$。$\psi$ 是良定義的函數。

**為什麼要這樣看**[▶ 41:30](https://youtu.be/x6QGa_qTQ_s?t=2490)：
- 「上次我說不出來的就是這個：我把 $\mathbb{Z}_n$ 想成 $\mathbb{Z}$ 的子集，那會製造別的問題——得開始分情況，看和什麼時候超過 $n$。」
- 用同餘類：$[j]+[k] = [j+k]$ 直接成立，「模運算全都有了」。
- 平常寫 $\psi(j)$，只是 $\psi([j])$ 的**簡寫**。「當我們處理 $\mathbb{Z}_n$，我們其實是在處理陪集——這是我的觀點。」

### 6.1 本集結果

### 6.2 技巧

- 二面體群：換成 $x,y$ 和關係式計算；元素分成 $x^m$、$x^my$ 兩類。
- 加法核和乘法核不同：看陪域的單位元素是什麼（$0$ 還是 $1$、$I$）。
- 用「核平凡 ⇒ 單射」之前，先確認是同態。
- 在陪集（同餘類）上定義函數：**先證良定義**——換代表元答案不變。

## 附：本集一句話總結

> **把 $D_4$ 換成生成元 $x,y$ 計算，一下就能證明「$\varphi(x) = x$、$\varphi(y) = x^2y$」的自同構就是 $x$ 誘導的內自同構；$a+bi\mapsto\begin{pmatrix}a&-b\\b&a\end{pmatrix}$ 同時是加法和（非零）乘法的同構，連倒數都對應到 $2\times2$ 反矩陣公式；$\mathbf a\mapsto-\mathbf a$ 是 $\mathbb{R}^n$ 的自同構；最後更正：$\mathbb{Z}_n$ 的元素是同餘類，在它上面定義函數一定要先證良定義。**
