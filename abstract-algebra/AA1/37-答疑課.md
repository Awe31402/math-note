## 1. 子環的交集是子環（#9）

[▶ 00:30](https://youtu.be/PVFWHJsUuqk?t=30)

> **命題**　$S_1,\dots,S_n$ 是 $R$ 的子環 ⇒ $S = \bigcap_{i=1}^nS_i$ 是子環。

【課堂討論】「你們覺得怎麼開始？」

**證明**[▶ 02:30](https://youtu.be/PVFWHJsUuqk?t=150)
- **非空**：$0\in S_i$ 對所有 $i$ ⇒ $0\in S$。
- 取 $a,b\in S$，即 $a,b$ 在**每一個** $S_i$ 裡。
- 每個 $S_i$ 是子環 ⇒ $ab\in S_i$ 且 $a-b\in S_i$，對每個 $i$ [▶ 03:30](https://youtu.be/PVFWHJsUuqk?t=210)。
- 在每一個裡 ⇒ 由交集的定義，$ab,\ a-b\in S$。
- 子環判別法 ⇒ $S$ 是子環。$\blacksquare$

【口頭】[▶ 10:30](https://youtu.be/PVFWHJsUuqk?t=630)「『任意個子物件的交集還是子物件』這種題，對**群**也很有意思：任意個子群的交集是子群。」
- 學生問無限多個的情況。老師：「那裡確實有**更麻煩的集合論**。我的課在這方面大概有缺陷——Soprano 博士的課可能有更多講究的集合論；我比較偏矩陣。當然兩者交集很大。」

【課堂討論】[▶ 07:00](https://youtu.be/PVFWHJsUuqk?t=420) 在 $\mathbb{Z}_{12}$ 解 $2x = 4$：

## 3. {ara} 是子環，而且含 1（#37）

[▶ 11:30](https://youtu.be/PVFWHJsUuqk?t=690)

> **題目**　$R$ 有單位元，$a\in R$，$a^2 = 1$。令 $S = \{ara : r\in R\}$。證明 $S$ 是子環。$S$ 含 1 嗎？

【口頭】「$a$ 是單位，$a = a^{-1}$。從群論角度，這只是**用 $a$ 共軛**的集合。但就用子環判別法。」

**證明**
- **非空**[▶ 13:00](https://youtu.be/PVFWHJsUuqk?t=780)：$a0a = 0$（昨天證的定理）⇒ $0\in S$。
- **是子集**：由乘法封閉，$ara\in R$。「我不總是說，但技術上要說。」
- 取 $r' = ara$、$s' = asa$。【口頭】[▶ 14:00](https://youtu.be/PVFWHJsUuqk?t=840)「別用 $a$、$b$ 當任意元素——**$a$ 已經有固定的意義**，那是禁止的。」
- **乘法**[▶ 16:00](https://youtu.be/PVFWHJsUuqk?t=960)：
$$r's' = ara\cdot asa = ar(a^2)sa = a(rs)a\in S.$$
- **減法**[▶ 16:30](https://youtu.be/PVFWHJsUuqk?t=990)：
$$r'-s' = ara-asa = a(ra-sa) = a(r-s)a\in S,$$
  用了左、右兩個分配律。✓

**含 1 嗎？**[▶ 18:00](https://youtu.be/PVFWHJsUuqk?t=1080)
- 【口頭】「這問題**有歧義**：像上次的 $2\mathbb{Z}_6$，1 不在子環裡，但 4 在某種意義上就是 1。所以有兩個問題：子環有沒有單位元？那單位元是不是 $R$ 的 1？」
- $a\cdot1\cdot a = a^2 = 1$ ⇒ $1\in S$ ✓。「**歧義被擊敗了**。子環有單位元，而且剛好是同一個。」

## 4. ab = 0 但 ba ≠ 0（#31）

[▶ 20:00](https://youtu.be/PVFWHJsUuqk?t=1200)（沒人點，但老師喜歡。）顯然要找**非交換環**。

【課堂討論】「看到這種題該想什麼？」學生：「矩陣。」老師：「正是。我的首選是矩陣，或函數合成。矩陣比較容易想像——可以隨便試試。」

[▶ 20:30](https://youtu.be/PVFWHJsUuqk?t=1230) 試（中間算錯一次：「我最後會算對的」）：
$$A = \begin{pmatrix}1&1\\1&1\end{pmatrix},\quad B = \begin{pmatrix}1&1\\-1&-1\end{pmatrix}\ ⇒\ AB = \begin{pmatrix}0&0\\0&0\end{pmatrix}.$$
這也是**零因子**的例子。

反過來 [▶ 21:30](https://youtu.be/PVFWHJsUuqk?t=1290)：「可能還是 0，那就不行……喔，不是 0，是 $-2$。」
$$BA = \begin{pmatrix}2&2\\-2&-2\end{pmatrix}\neq0.$$

> 💬 字幕只聽得到「1 −1 1 −1……−1 −1」和「是 −2 吧」。上面的 $B$ 是同時符合 $AB = 0$、$BA$ 出現 $-2$ 的一種自然寫法（$B$ 的兩行都是 $(1,-1)^T$）。

**在哪個環？**[▶ 22:00](https://youtu.be/PVFWHJsUuqk?t=1320) $\mathbb{Z}^{2\times2}$；或 $\mathbb{Z}_3^{2\times2}$——「這種例子可以塞進很多不同的矩陣環。」

## 5. a² − b² = (a+b)(a−b) ⟺ 交換（#47）

[▶ 23:30](https://youtu.be/PVFWHJsUuqk?t=1410)（Blaine 的題。）

> **命題**　$R$ 是環。$a^2-b^2 = (a+b)(a-b)$ 對所有 $a,b$ 成立 $\iff$ $R$ 交換。

**(⇐)**[▶ 24:30](https://youtu.be/PVFWHJsUuqk?t=1470)
$$(a+b)(a-b) = a^2-ab+ba-b^2 = a^2-ab+ab-b^2 = a^2-b^2.$$

**(⇒)**[▶ 25:30](https://youtu.be/PVFWHJsUuqk?t=1530)：展開右邊
$$a^2-b^2 = a^2-ab+ba-b^2\ ⇒\ 0 = ba-ab\ ⇒\ ab = ba.\ \blacksquare$$

## 6. 高斯整數 ℤ[i] 是子環

【Q&A】[▶ 27:00](https://youtu.be/PVFWHJsUuqk?t=1620) 學生問：高斯整數的單位群怎麼找？（作業 #23）

老師先證它是環：$\mathbb{Z}[i] = \{a+bi : a,b\in\mathbb{Z}\}\subseteq\mathbb{C}$，運算就是複數的運算，$\mathbb{C}$ 是環 ⇒ 用子環判別法 [▶ 28:00](https://youtu.be/PVFWHJsUuqk?t=1680)。
- $0 = 0+0i\in\mathbb{Z}[i]$。「蠢的評論，但就是這樣。」
- $(a+bi)(x+yi) = (ax-by)+(bx+ay)i$；
- $(a+bi)-(x+yi) = (a-x)+(b-y)i$。
- 實部、虛部都是整數的和、差、積 ⇒ 都在 $\mathbb{Z}[i]$。✓

**Gallian 第 12 章末的子環格**[▶ 30:30](https://youtu.be/PVFWHJsUuqk?t=1830)「那張漂亮的圖」：
- $\mathbb{C}\supset\mathbb{R}\supset\mathbb{Q}\supset\mathbb{Z}$。
- 側邊：$\mathbb{Z}\subset\mathbb{Z}[i]\subset\mathbb{C}$；$\mathbb{Q}\subset\mathbb{Q}[\sqrt2]\subset\mathbb{R}$。
- $\mathbb{Z}$ 以下：$2\mathbb{Z}\supset4\mathbb{Z}$、$2\mathbb{Z}\supset10\mathbb{Z}$、$5\mathbb{Z}\supset10\mathbb{Z}$、$7\mathbb{Z}$……按整除一直下去。「它是**偏序**——可以一直一直下去。」

【口頭】[▶ 32:00](https://youtu.be/PVFWHJsUuqk?t=1920)「$\mathbb{Q}[\sqrt2]$ 裡你**加進一個無理數**——其實不只一個，但有一個『根本的』無理數。加進來之後就能加、減、乘，**像疾病一樣傳開**，從那一個得到一大堆無理數。」

**怎麼找 $U(\mathbb{Z}[i])$**[▶ 45:00](https://youtu.be/PVFWHJsUuqk?t=2700)（課末回來講）：
- 「就是個代數題。」解 $(a+bi)(c+di) = 1$。
- 可以用複數運算；或固定 $a,b$，把 $c,d$ 當未知數，寫成 $2\times2$ 線性方程組，用基本線性代數解。
- 「跟講義裡 $\mathbb{Z}_3[i]$ 的計算是**同一種動物**，只是那裡找零因子、右邊放 0。」

- **反例**[▶ 34:00](https://youtu.be/PVFWHJsUuqk?t=2040)：$2\in2\mathbb{Z}$、$3\in3\mathbb{Z}$，但 $2+3 = 5\notin2\mathbb{Z}\cup3\mathbb{Z}$。（學生也提：$3-2 = 1$ 不在裡面——「對，有很多。」）

【口頭】[▶ 35:30](https://youtu.be/PVFWHJsUuqk?t=2130)「遇到這種題，要說服我你懂，**給我一個具體的反例**。不要用三句話泛泛地說為什麼錯。模糊的概括行不通。」

## 8. 講義新增：消去律、有限整環是體

[▶ 36:00](https://youtu.be/PVFWHJsUuqk?t=2160)「剩下幾分鐘，給你們看我還沒講的。我今天還有更多筆記要寫——永無止境。不過寫這些筆記，正是讓我能跟你們解釋的原因。」（上週一的講義，昨晚加了兩頁，補完第 13 章。）

### 8.1 整環的消去律

> **定理**（講義 Thm 4.1.31）[▶ 37:30](https://youtu.be/PVFWHJsUuqk?t=2250)　$a,b,c$ 在整環中，$a\neq0$、$ab = ac$ ⇒ $b = c$。**不假設 $a^{-1}$ 存在。**

【Q&A】老師：「整環要有單位元嗎？」學生：「要。」老師：「更重要的是**沒有零因子**——這才是重點，我把重點埋了。」

**證明**（「出奇地簡單」）[▶ 38:30](https://youtu.be/PVFWHJsUuqk?t=2310)：
$$ab-ac = 0\ ⇒\ a(b-c) = 0.$$
$a\neq0$；若 $b-c\neq0$，它們就是零因子，整環不允許。所以 $b = c$。$\blacksquare$

**應用**[▶ 39:00](https://youtu.be/PVFWHJsUuqk?t=2340)
- 在 $\mathbb{Z}$：$2x = 6 = 2\cdot3$ ⇒ $x = 3$。「不好的例子——你們心裡偷偷除了。」
- 在 $\mathbb{Z}[x]$：$(x+3)(x^2+1) = (x+3)f(x)$ ⇒ $f(x) = x^2+1$。「突然間，這個消去律好像有點東西了。」

【口頭】[▶ 40:00](https://youtu.be/PVFWHJsUuqk?t=2400)「**劇透**：任何整環，都能找到一個更大的空間，讓那些非零非單位的東西變成單位——叫**分式體（field of fractions）**。之後會造。我跟你們講的比講義多，因為你們來了，我對你們好一點。」（「我擔心跟其他沒來的人說，他們會說我逼他們一週來五天。」）

### 8.2 有限整環是體

> **定理**（講義 Thm 4.1.33）[▶ 41:00](https://youtu.be/PVFWHJsUuqk?t=2460)　**每個有限整環都是體。**

- 「整環如果不是無限多元素，就是體。」對照：$\mathbb{Z}$ 是**無限**整環，不是體。
- $\mathbb{Z}_n$：只有 $n$ 是質數時才是體；$n$ 合數時，組成 $n$ 的因數是零因子（$2\cdot3 = 0$ 在 $\mathbb{Z}_6$、$2\cdot5 = 0$ 在 $\mathbb{Z}_{10}$）。

**證明**[▶ 42:30](https://youtu.be/PVFWHJsUuqk?t=2550)：$D$ 有限整環，取 $a\neq0$。
1. $a = 1$：它是自己的反元素。
2. 否則看 $a,a^2,a^3,\dots$。$D$ 有限，這串**一定會繞回來**——「不該假設回到開頭，誰知道回到哪，但一定要回來，不然是無限集合。」
3. 所以某 $a^i = a^j$，$i>j$。
4. 消去律（$a\neq0$，整環）：$a^{i-j} = 1$，即 $a^{i-j-1}\cdot a = 1$。
5. 所以 $a^{-1} = a^{i-j-1}$。$a$ 任意 ⇒ 每個非零元素可逆 ⇒ 體。$\blacksquare$

【口頭】[▶ 44:00](https://youtu.be/PVFWHJsUuqk?t=2640)「這是我第一次學抽象代數時記得的論證之一。第一次看到時我想：『哇，**太簡單了**。希望你把這放在考試上——這個我懂。』」

> **推論**（Cor 4.1.34）　$p$ 質數 ⇒ $\mathbb{Z}_p$ 是體。

證明 [▶ 44:00](https://youtu.be/PVFWHJsUuqk?t=2640)：$ab = 0$ 在 $\mathbb{Z}_p$ ⇒ $ab = pk$ ⇒ 由 **Euclid 引理** $p\mid a$ 或 $p\mid b$ ⇒ $a = 0$ 或 $b = 0$。所以是整環，有限 ⇒ 體。「我通常會說這是已知的，只是給有疑問的人一個細節。」

### 8.3 ℤ₃[i] 與 ℚ[√2]

**$\mathbb{Z}_3[i]$ 是整環**[▶ 45:30](https://youtu.be/PVFWHJsUuqk?t=2730)：找零因子，解 $(x+yi)(a+bi) = 0$，整理成
$$\begin{pmatrix}x&-y\\y&x\end{pmatrix}\begin{pmatrix}a\\b\end{pmatrix} = \begin{pmatrix}0\\0\end{pmatrix}.$$
- 「這是複數 $x+iy$ 的**矩陣表示**，不是巧合。」
- 非零的 $x+yi$ 都有 $x^2+y^2\neq0$（在 $\mathbb{Z}_3$ 裡算），所以可以乘反矩陣 ⇒ $a = b = 0$。
- 沒有零因子 ⇒ 整環（有限 ⇒ 9 元素的體）。「這些細節 Gallian 沒有，我加的。對第 23 題很有幫助。」

**$\mathbb{Q}[\sqrt2]$ 是體**[▶ 47:30](https://youtu.be/PVFWHJsUuqk?t=2850)：乘起來同形式；找反元素「就像複數公式」——乘共軛除共軛，共軛是 $\sqrt2\to-\sqrt2$：
$$(a+b\sqrt2)^{-1} = \frac{a-b\sqrt2}{a^2-2b^2}.$$
- $a,b\in\mathbb{Q}$ 不全為 0 時 $a^2-2b^2\neq0$——「Math 200 的小知識，這裡沒證，但是真的。」
- 「這是一個介於 $\mathbb{Q}$ 和 $\mathbb{R}$ 之間的體。」

**特徵**（上次講過）：看 1 就夠；整環的特徵是 0 或質數。「我讓你們自己看。我今天講夠了。」

### 8.4 沒指定的題

[▶ 49:30](https://youtu.be/PVFWHJsUuqk?t=2970)「Gallian 有幾題證明 $n\cdot a$ 這個點記號是合法的（#14、15、16）。我差點指定，但它們有點**冗長無聊**。我想讓你們專注在這節的『肉和馬鈴薯』：**子環判別法、子環判別法、子環判別法**，以及**環的例子、環的例子、環的例子**，學會證明某東西不是環。我基礎論的那一面很想指定，但我忍住了。承認這是我們發展裡的一個缺口。」

| #9 | 子環的交集是子環 | 在每個 $S_i$ 裡 ⇒ 在交集裡 |
| #4 | $2x = 4$ 在 $\mathbb{Z}_{12}$：$x = 2,8$ | 2 不是單位 |
| #37 | $\{ara\}$ 是子環，含 1 | $a^2 = 1$；$a(r-s)a$ |
| #31 | $ab = 0$、$ba\neq0$ | 矩陣 |
| #47 | $a^2-b^2 = (a+b)(a-b)\iff$ 交換 | 展開得 $ba-ab = 0$ |
| $\mathbb{Z}[i]$ | $\mathbb{C}$ 的子環 | 子環判別法 |
| #44 | $2\mathbb{Z}\cup3\mathbb{Z}$ 不是子環 | $2+3 = 5$ |
| 消去律 | 整環中 $ab = ac,\ a\neq0$ ⇒ $b = c$ | $a(b-c) = 0$ |
| 有限整環 | 是體 | $a^i = a^j$ ⇒ $a^{i-j} = 1$ |
| $\mathbb{Q}[\sqrt2]$ | 體 | 乘共軛 $a-b\sqrt2$ |

**$2\mathbb{Z}+3\mathbb{Z} = \mathbb{Z}$**（和），但 $2\mathbb{Z}\cup3\mathbb{Z}$ 不是子環（聯集）。

## 附：本集一句話總結

> **用子環判別法（對減法和乘法封閉）證交集、$\{ara\}$、$\mathbb{Z}[i]$ 是子環，用具體反例（$2+3 = 5$）證 $2\mathbb{Z}\cup3\mathbb{Z}$ 不是；環裡 $ax = b$ 可以有多個解、可以 $ab = 0$ 而 $ba\neq0$，但整環有消去律（$a(b-c) = 0$），而有限整環的每個非零元素的冪一定繞回來，所以有限整環就是體。**
