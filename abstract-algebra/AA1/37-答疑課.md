# 第 37 集 · 答疑課：子環習題、整環的消去律、有限整環是體 [▶ 影片](https://www.youtube.com/watch?v=PVFWHJsUuqk&list=PLBY4G2o7DhF0JCgapYKrqibGaJuvV4Gkb)

## 本集概要

- Gallian 第 12 章：子環的交集是子環；$ax = b$ 在環裡可以有多個解；$\{ara\}$（$a^2 = 1$）是子環且含 1；$ab = 0$ 但 $ba\neq0$ 的矩陣例子；$a^2-b^2 = (a+b)(a-b)\iff$ 交換；Gaussian 整數 $\mathbb{Z}[i]$ 是子環；$2\mathbb{Z}\cup3\mathbb{Z}$ 不是子環。
- 講義補充（第 13 章）：**整環的消去律**；**有限整環是體**；$\mathbb{Z}_p$ 是體；$\mathbb{Z}_3[i]$ 是整環；$\mathbb{Q}(\sqrt2)$ 是體；整環的特徵是 0 或質數。

> ⚠️ 題號說明：課堂用的是 Gallian **第 5 版**。

## 筆記

### 題 1：子環的交集是子環（Ch.12 #9）[▶ 00:30](https://youtu.be/PVFWHJsUuqk?t=30)

$S = \bigcap_{i=1}^nS_i$，每個 $S_i$ 是 $R$ 的子環。
- $0\in S_i$ 對所有 $i$，所以 $0\in S$，非空 [▶ 02:30](https://youtu.be/PVFWHJsUuqk?t=150)。
- $a,b\in S$：對每個 $i$，$a,b\in S_i$，由子環判別法 $ab\in S_i$、$a-b\in S_i$。
- 在每個 $S_i$ 裡，就在交集裡。由子環判別法，$S$ 是子環 [▶ 05:00](https://youtu.be/PVFWHJsUuqk?t=300)。

（「任意交集」對群也成立，也是好題。老師說另一位教授的課集合論比較細，他自己偏重矩陣 [▶ 10:30](https://youtu.be/PVFWHJsUuqk?t=630)。）

### 題 2：$ax = b$ 的解可以不唯一（Ch.12 #4）[▶ 06:00](https://youtu.be/PVFWHJsUuqk?t=360)

在 $\mathbb{Z}_{12}$ 中 $2x = 4$：$x = 2$ 和 $x = 8$ 都是解（$2\cdot8 = 16\equiv4$）[▶ 07:30](https://youtu.be/PVFWHJsUuqk?t=450)。

**對比群**：$ax = b\Rightarrow x = a^{-1}b$，唯一。這裡 2 不是單位（$U(12) = \{1,5,7,11\}$），沒辦法乘 $2^{-1}$ [▶ 09:30](https://youtu.be/PVFWHJsUuqk?t=570)。

### 題 3：$S = \{ara\mid r\in R\}$，$a^2 = 1$（Ch.12 #37）[▶ 11:30](https://youtu.be/PVFWHJsUuqk?t=690)

$R$ 有單位元，$a^2 = 1$（所以 $a^{-1} = a$，$S$ 就是用 $a$ 共軛的集合）。
- 非空：$a0a = 0\in S$。也要說 $S\subseteq R$（乘法封閉）[▶ 13:30](https://youtu.be/PVFWHJsUuqk?t=810)。
- **不能用 $a$ 當任意元素**：$a$ 已經是固定的了。設 $r' = ara$、$s' = asa$ [▶ 14:00](https://youtu.be/PVFWHJsUuqk?t=840)。
- 乘法：$r's' = ara\,asa = ar(a^2)sa = a(rs)a\in S$。
- 減法：$r'-s' = ara-asa = a(r-s)a\in S$（左右分配律都用到）[▶ 17:00](https://youtu.be/PVFWHJsUuqk?t=1020)。
- **含 1 嗎？** 問題有歧義：子環有沒有單位元？那個單位元是不是 $R$ 的 1？（回想 $2\mathbb{Z}_6$ 的單位元是 4。）這裡 $a1a = a^2 = 1$，所以 $1\in S$，而且就是 $R$ 的 1 [▶ 19:00](https://youtu.be/PVFWHJsUuqk?t=1140)。

### 題 4：$ab = 0$ 但 $ba\neq0$（Ch.12 #31）[▶ 20:00](https://youtu.be/PVFWHJsUuqk?t=1200)

要非交換環。老師的首選：**矩陣**（或函數合成）。
$$A = \begin{pmatrix}1&1\\1&1\end{pmatrix},\quad B = \begin{pmatrix}1&1\\-1&-1\end{pmatrix}:\quad AB = \begin{pmatrix}0&0\\0&0\end{pmatrix},\quad BA = \begin{pmatrix}2&2\\-2&-2\end{pmatrix}\neq0.$$
（也是零因子的例子。）可以放在 $M_2(\mathbb{Z})$、$M_2(\mathbb{Z}_3)$ 等很多矩陣環裡 [▶ 22:00](https://youtu.be/PVFWHJsUuqk?t=1320)。

> 💬 課堂上試了兩次才找到合適的 $B$；上面是對得上「$BA$ 出現 $-2$」的版本。

### 題 5：$a^2-b^2 = (a+b)(a-b)\iff$ 交換（Ch.12 #47）[▶ 23:30](https://youtu.be/PVFWHJsUuqk?t=1410)

- 展開：$(a+b)(a-b) = a^2 - ab + ba - b^2$。
- ($\Leftarrow$) 交換時 $-ab+ba = 0$。
- ($\Rightarrow$) 若對所有 $a,b$ 成立，則 $0 = ba-ab$，即 $ab = ba$ [▶ 26:00](https://youtu.be/PVFWHJsUuqk?t=1560)。

### 題 6：Gaussian 整數（Ch.12 #23 相關）[▶ 27:00](https://youtu.be/PVFWHJsUuqk?t=1620)

$$\mathbb{Z}[i] = \{a+bi\mid a,b\in\mathbb{Z}\}\subseteq\mathbb{C}.$$
- $\mathbb{C}$ 已經是環，用子環判別法。$0\in\mathbb{Z}[i]$。
- $(a+bi)(x+yi) = (ax-by)+(bx+ay)i$；$(a+bi)-(x+yi) = (a-x)+(b-y)i$。係數都是整數 [▶ 29:00](https://youtu.be/PVFWHJsUuqk?t=1740)。

**Gallian 第 12 章末的子環圖** [▶ 30:30](https://youtu.be/PVFWHJsUuqk?t=1830)：$\mathbb{C}\supset\mathbb{R}\supset\mathbb{Q}\supset\mathbb{Z}$；側邊有 $\mathbb{Z}[i]$（在 $\mathbb{Z}$ 和 $\mathbb{C}$ 之間）、$\mathbb{Q}(\sqrt2)$（在 $\mathbb{Q}$ 和 $\mathbb{R}$ 之間）；$\mathbb{Z}$ 下面還有 $2\mathbb{Z}\supset4\mathbb{Z}$、$2\mathbb{Z}\supset10\mathbb{Z}$、$5\mathbb{Z}\supset10\mathbb{Z}$……按整除關係無窮延伸。加進一個無理數 $\sqrt2$，「像傳染病一樣」，就多出一大堆無理數。

**$\mathbb{Z}[i]$ 的單位群**（學生問）[▶ 45:00](https://youtu.be/PVFWHJsUuqk?t=2700)：就是解代數題：$(a+bi)(c+di) = 1$。可以用複數運算，或把 $c,d$ 當未知數，寫成 $2\times2$ 線性方程組。（答案是 $\{\pm1,\pm i\}$。）

### 題 7：$2\mathbb{Z}\cup3\mathbb{Z}$ 不是子環（Ch.12 #44）[▶ 32:30](https://youtu.be/PVFWHJsUuqk?t=1950)

- 0 在裡面，所以不是靠「非空」失敗。
- **具體反例**：$2,3\in2\mathbb{Z}\cup3\mathbb{Z}$，但 $2+3 = 5$ 不在 $2\mathbb{Z}$ 也不在 $3\mathbb{Z}$（或 $3-2 = 1$）[▶ 34:00](https://youtu.be/PVFWHJsUuqk?t=2040)。
- 要說服老師你懂，就給**具體反例**，不要用三句模糊的話解釋為什麼不對 [▶ 35:30](https://youtu.be/PVFWHJsUuqk?t=2130)。
- 對比：集合的**和** $2\mathbb{Z}+3\mathbb{Z}$ 是 $\mathbb{Z}$（$\gcd(2,3) = 1$，有 $2j+3k = 1$）。和聯集完全不同 [▶ 35:00](https://youtu.be/PVFWHJsUuqk?t=2100)。

### 8. 講義補充：整環的性質 [▶ 36:30](https://youtu.be/PVFWHJsUuqk?t=2190)

> **定理（消去律）**　$D$ 是整環，$a\neq0$。若 $ab = ac$，則 $b = c$ [▶ 37:30](https://youtu.be/PVFWHJsUuqk?t=2250)。

**證明**：$ab-ac = a(b-c) = 0$。$a\neq0$，若 $b-c\neq0$，兩者就是零因子，矛盾。$\blacksquare$
- **不需要 $a^{-1}$ 存在**。
- 例：$\mathbb{Z}[x]$ 中 $(x+3)(x^2+1) = (x+3)f(x)\Rightarrow f(x) = x^2+1$ [▶ 39:30](https://youtu.be/PVFWHJsUuqk?t=2370)。
- 預告：任何整環都能放進一個更大的體，讓非零元素都可逆——**分式體 (field of fractions)** [▶ 40:00](https://youtu.be/PVFWHJsUuqk?t=2400)。

> **定理**　**有限整環是體** [▶ 41:00](https://youtu.be/PVFWHJsUuqk?t=2460)。

**證明** [▶ 42:30](https://youtu.be/PVFWHJsUuqk?t=2550)
- 取 $a\neq0$。若 $a = 1$，它自己就是反元素。
- 否則看 $a,a^2,a^3,\dots$。$D$ 有限，總會重複：$a^i = a^j$，$i>j$。
- 消去律（$a^j\neq0$，因為沒有零因子）：$a^{i-j} = 1$，即 $a^{i-j-1}\cdot a = 1$。所以 $a^{-1} = a^{i-j-1}$。$\blacksquare$

老師說他第一次學抽象代數時就記得這個論證：「太簡單了，希望考這個。」

**例**
- $\mathbb{Z}$ 是無限整環但不是體。
- $\mathbb{Z}_n$ 是體 $\iff n$ 是質數：合數 $n = ab$ 時 $a,b$ 是零因子（例 $2\cdot5 = 0$ 在 $\mathbb{Z}_{10}$）[▶ 41:30](https://youtu.be/PVFWHJsUuqk?t=2490)。
- **$\mathbb{Z}_p$ 是體** [▶ 44:00](https://youtu.be/PVFWHJsUuqk?t=2640)：$ab = 0$ 表示 $p\mid ab$，由 Euclid 引理 $p\mid a$ 或 $p\mid b$。
- **$\mathbb{Z}_3[i] = \{x+yi\mid x,y\in\mathbb{Z}_3\}$ 是整環**（作業 #23 的大幫助）[▶ 45:30](https://youtu.be/PVFWHJsUuqk?t=2730)：$(a+bi)(x+yi) = 0$ 寫成矩陣 $\begin{pmatrix}x&-y\\y&x\end{pmatrix}\begin{pmatrix}a\\b\end{pmatrix} = \mathbf 0$（「不是巧合，這就是複數的矩陣表示」）。非零的 $x+yi$ 讓 $x^2+y^2\neq0\pmod3$，矩陣可逆，所以 $a = b = 0$。（Gallian 沒寫這些細節。）
- **$\mathbb{Q}(\sqrt2)$ 是體** [▶ 48:00](https://youtu.be/PVFWHJsUuqk?t=2880)：
$$\frac{1}{a+b\sqrt2} = \frac{a-b\sqrt2}{a^2-2b^2}.$$
  乘「共軛」（把 $\sqrt2$ 換成 $-\sqrt2$），像複數一樣。$a,b$ 是有理數且不全為 0 時 $a^2-2b^2\neq0$（$\sqrt2$ 是無理數，Math 200 的事實）。
- **整環的特徵是 0 或質數**；有單位元時只要看 1（講義有證明）[▶ 49:00](https://youtu.be/PVFWHJsUuqk?t=2940)。

**關於 $n\cdot a$ 記號** [▶ 49:30](https://youtu.be/PVFWHJsUuqk?t=2970)：Gallian 有幾題證明這個記號的性質（#14–16），老師覺得繁瑣沒出，想讓大家專注在「子環判別法、例子、例子、例子、怎麼證明不是環」。承認這是發展上的缺口。
