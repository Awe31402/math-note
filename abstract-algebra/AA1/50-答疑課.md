**$\mathbb{Z}_2[x]/\langle x^2+x+1\rangle$ 是體**[▶ 02:30](https://youtu.be/YZzFYumnF8c?t=150)
- **用現在的技術**：$f(0) = 1$、$f(1) = 1$ ⇒ 沒有根 ⇒ 沒有一次因式 ⇒ 二次不可約 ⇒ 理想極大 ⇒ 商是體。

## 3. I 質 ⇒ I[x] 質（#38）

[▶ 08:30](https://youtu.be/YZzFYumnF8c?t=510)「這題比較複雜。」$R$ 有單位元的交換環，$I$ 是質理想。證明 $I[x]$（係數在 $I$ 的多項式）是 $R[x]$ 的質理想。

**錯的路**[▶ 09:00](https://youtu.be/YZzFYumnF8c?t=540)：直接取 $fg\in I[x]$，證 $f$ 或 $g\in I[x]$。
- 常數項 $c_0 = a_0b_0\in I$ ⇒ $a_0$ 或 $b_0\in I$。
- $c_1 = a_0b_1+a_1b_0$：若 $a_0\in I$，則 $a_0b_1\in I$ ⇒ $a_1b_0\in I$ ⇒ ……
- 「這**很快就很煩**。你開始發現這絕對不是做這題的方法——我**有**往前推一點，但它是組合式的，相當可怕。」

**好的路**[▶ 10:30](https://youtu.be/YZzFYumnF8c?t=630)
1. $I$ 質 ⇒ $R/I$ 是整環。
2. 自然同態 $\pi:R\to R/I$ **誘導** $\psi:R[x]\to(R/I)[x]$：每個係數取陪集。
3. $\psi$ 是同態（加法驗了，乘法「我沒費心」）。
4. **核**[▶ 11:30](https://youtu.be/YZzFYumnF8c?t=690)：$\psi(f) = 0\iff$ 所有 $a_i+I = I\iff a_i\in I$ ⇒ $\ker\psi = I[x]$。「**超棒**。」
5. **滿射**：任何 $\sum(a_i+I)x^i$ 是 $\sum a_ix^i$ 的像。
6. 第一同構定理：
$$R[x]/I[x]\cong(R/I)[x].$$
7. $R/I$ 是整環 ⇒ $(R/I)[x]$ 是整環（[[40-L26-多項式]]）⇒ $R[x]/I[x]$ 是整環 ⇒ **$I[x]$ 是質理想**。$\blacksquare$

【口頭】[▶ 13:00](https://youtu.be/YZzFYumnF8c?t=780)「**很棒的題**，用到這一段課程裡**最重要的大部分定理**。非常重要，要理解。」

## 4. F[x] 的 Bézout

[▶ 13:30](https://youtu.be/YZzFYumnF8c?t=810)

> **題目**　$F$ 是體，$f,g\in F[x]$。若沒有正次數的多項式同時整除 $f$ 和 $g$，則存在 $h,k$ 使 $fh+gk = 1$。

「這是**整數 gcd 的 Bézout 定理**的類比。」

1. 造理想 $I = \{fa+gb : a,b\in F[x]\}$——上面 $\langle a_1,\dots,a_n\rangle$ 那題 $n = 2$ 的情形。
2. $F[x]$ 是 PID ⇒ $I = \langle j\rangle$ [▶ 14:30](https://youtu.be/YZzFYumnF8c?t=870)。
3. $f = f\cdot1+g\cdot0\in I$ ⇒ $j\mid f$；同理 $j\mid g$。
4. 假設 ⇒ $\deg j = 0$ ⇒ $j = c$ 常數 [▶ 15:30](https://youtu.be/YZzFYumnF8c?t=930)。
5. $c = 0$ ⇒ $f = g = 0$，矛盾（題目假設排除）。所以 $c\neq0$。
6. $c = fa+gb$，除以 $c$：$1 = f(a/c)+g(b/c)$。$\blacksquare$

## 5. 27 元體；不可約判別

**造 27 元體**[▶ 16:00](https://youtu.be/YZzFYumnF8c?t=960)：$\mathbb{Z}_3[x]$ 模一個不可約**三次**式——商是 $\mathbb{Z}_3$ 上 3 維向量空間，$3^3 = 27$ 個元素。

**#113：哪些在 $\mathbb{Q}$ 上不可約**[▶ 17:00](https://youtu.be/YZzFYumnF8c?t=1020)

- $x^4+3x^2+3$：Eisenstein $p = 3$。「Eisenstein，**我們愛你**。」

## 6. x⁴+1 在每個 ℤₚ 上都可約（#29）

[▶ 19:30](https://youtu.be/YZzFYumnF8c?t=1170)「你們假期前一直問這題，我拒絕了，我堅持我的拒絕。這題**非常有趣**，裡面有很多東西。這學期大概只有**五題**我會說是真正困難的——我是說**計算上的陰險**——這是其中之一。」

**Gallian 的提示**：在任何 $\mathbb{Z}_p$ 中，下列三個方程至少一個有解：
$$a^2 = -1,\qquad a^2 = 2,\qquad a^2 = -2.$$

**各情況的分解**[▶ 20:30](https://youtu.be/YZzFYumnF8c?t=1230)
- $a^2 = -1$：$x^4+1 = x^4-a^2 = (x^2-a)(x^2+a)$。（投影上寫錯了：「應該是 $x^2-a$ 乘 $x^2+a$，抱歉。」）
- $a^2 = 2$：$x^4+1 = (x^2+ax+1)(x^2-ax+1)$（乘開中間是 $(2-a^2)x^2 = 0$）。
- $a^2 = -2$：$x^4+1 = (x^2+ax-1)(x^2-ax-1)$（中間是 $(-2-a^2)x^2 = 0$）[▶ 21:30](https://youtu.be/YZzFYumnF8c?t=1290)。

**為什麼總有一個有解**（「論證很狡猾」）[▶ 22:00](https://youtu.be/YZzFYumnF8c?t=1320)
1. 平方映射 $\varphi:\mathbb{Z}_p^\times\to\mathbb{Z}_p^\times$，$\varphi(x) = x^2$。同態：$(xy)^2 = x^2y^2$。
2. **核** $= \{x : x^2 = 1\} = \{1,-1\}$；$p>2$ 時 $|\ker\varphi| = 2$ [▶ 23:00](https://youtu.be/YZzFYumnF8c?t=1380)。
3. 令 $H = \varphi(\mathbb{Z}_p^\times)$（平方數）。第一同構定理：$\mathbb{Z}_p^\times/\ker\varphi\cong H$。
4. 「**狡猾的一步**」：
$$\mathbb{Z}_p^\times/H\ \cong\ \mathbb{Z}_p^\times/(\mathbb{Z}_p^\times/\ker\varphi)\ \text{「}\cong\text{」}\ \ker\varphi.$$
   「這些相消、倒數翻上去——基本上是**商記號不合理的成功**。」所以 $\mathbb{Z}_p^\times/H$ 有 **2 個元素**：$H$ 和另一個陪集 $xH$。

> 📘 筆記補充：嚴格一點：$|H| = (p-1)/2$，所以 $[\mathbb{Z}_p^\times:H] = 2$。

5. **分情況**[▶ 24:00](https://youtu.be/YZzFYumnF8c?t=1440)：設 $-1\notin H$ 且 $2\notin H$。只有兩個陪集 ⇒ $-H = 2H$（都是非 $H$ 的那個）。所以
$$(-H)(-H) = H,\quad (2H)(2H) = H\ ⇒\ H = (-H)(-H) = (-H)(2H) = -2H\ ⇒\ -2\in H.$$
   即存在 $a$ 使 $a^2 = -2$。
6. 否則 $-1\in H$ 或 $2\in H$，也有解。所以三種情況總有一個成立，$x^4+1$ 在 $\mathbb{Z}_p$ 上都可約。（$p = 2$：$x^4+1 = (x+1)^4$。）

【口頭】[▶ 25:00](https://youtu.be/YZzFYumnF8c?t=1500)（又有一位同學進來：「很高興又有一位同學加入——除了已經在這裡的 20 位。」）
【口頭】[▶ 26:00](https://youtu.be/YZzFYumnF8c?t=1560)「讓我卡住的是那個同構——我一直不懂它從哪來，直到**靈光一閃**。沒有提示，這題**完全荒謬**；有提示，它**只是**荒謬。」

## 7. 範數與高斯整數

**範數為 0 ⟺ 元素為 0**（#28）[▶ 27:30](https://youtu.be/YZzFYumnF8c?t=1650)：$d$ 無平方因子，$N(a+b\sqrt d) = 0$ ⇒ $a^2 = db^2$ ⇒ $\pm a/b = \sqrt d$——有理數等於無理數，不可能（除非 $a = b = 0$）。「謝謝你，**Math 200**。我拒絕在高年級的課再證一次。」乘性：「純代數——**漂亮**的代數。」

**#17：$\mathbb{Z}_2$ 上分解三次式**[▶ 28:00](https://youtu.be/YZzFYumnF8c?t=1680)：分組分解，用平方差，$x-1 = x+1$。「好玩。在 #29 之後，什麼都好玩。」

**相伴於不可約的也不可約**[▶ 29:00](https://youtu.be/YZzFYumnF8c?t=1740)：$a$ 不可約，$b = au$。若 $b = b_1b_2$，則 $a = b_1(b_2u^{-1})$ ⇒ $b_1$ 或 $b_2u^{-1}$ 是單位 ⇒ $b_1$ 或 $b_2$ 是單位。（「我累了。你沒照我這樣寫也可能是對的。」）

**#18：$\mathbb{Z}[i]$ 中 3 不可約，2、5 可約**[▶ 30:00](https://youtu.be/YZzFYumnF8c?t=1800)「展示研究範數的**意義**。」
- $3 = xy$ ⇒ $9 = N(x)N(y)$。$N = 1$ 是單位，不影響；要破壞不可約，需 $N(x) = N(y) = 3$。
- $a^2+b^2 = 3$ 沒有整數解 ⇒ **3 不可約**。
- 【口頭】[▶ 31:30](https://youtu.be/YZzFYumnF8c?t=1890)「『$a^2+b^2 = 3$ 沒整數解』的細節我不寫——可以輕易寫滿四分之一頁，又看不懂。但說某東西沒整數解時，要**確定**它真的沒有。」
- $2 = (1+i)(1-i)$、$5 = (2+i)(2-i)$ [▶ 32:00](https://youtu.be/YZzFYumnF8c?t=1920)：找範數 2、5 的元素——「$2^2+1 = 5$，所以看 $2+i$」。

**7 在 $\mathbb{Z}[\sqrt6]$ 中不可約**[▶ 32:30](https://youtu.be/YZzFYumnF8c?t=1950)（仿 Gallian p.313 Example 2）
- $N(a+b\sqrt6) = |a^2-6b^2|$。
- **單位**：「$a = \pm1,b = 0$……只要 $b\neq0$ 就得不到 1——還是可以？喔等等，**還有**！」（例如 $5+2\sqrt6$：$25-24 = 1$。）「這有**無窮多個單位**。這是**實二次體**——比**虛二次體**醜多了：虛的是 $a^2+db^2$，解有限；有負號就有一大堆單位。」
- 「我忘了這點——不過無所謂：不管單位是什麼，範數都是 1。上一題我其實也不需要知道單位是 $\pm1$，整個分析都在範數層次。」
- $7 = xy$ ⇒ $N(x) = N(y) = 7$ ⇒ $a^2-6b^2 = \pm7$ ⇒ 模 7：$a^2+b^2\equiv0$。逐一檢查 [▶ 35:00](https://youtu.be/YZzFYumnF8c?t=2100)：只有 $a\equiv b\equiv0$ ⇒ $49\mid a^2-6b^2 = \pm7$，矛盾。「這次我真的把細節寫出來了。」

**#121：$\mathbb{Z}[i]$ 輾轉相除**[▶ 36:00](https://youtu.be/YZzFYumnF8c?t=2160)：$12+3i$ 和 $6-9i$。
- 每一步都記錄怎麼用 $\alpha,\beta$ 組合出來；最有意思的是
$$-3i = \beta-2(\alpha-i\beta)$$
  （$\alpha-i\beta = 3-3i$，$\beta-2(3-3i) = -3i$ ✓）。下一步除得盡、餘 0，所以 $-3i$ 就是最後的非零餘數。

## 8. PID 中 ⟨p⟩ 極大 ⟺ p 不可約

[▶ 37:30](https://youtu.be/YZzFYumnF8c?t=2250)

**(⇒)** $\langle p\rangle$ 極大，$p = xy$。
- $pr = x(yr)$ ⇒ $\langle p\rangle\subseteq\langle x\rangle\subseteq D$。極大 ⇒ 兩種情況：
- **$\langle p\rangle = \langle x\rangle$**：$x = pr'$ ⇒ $p = xy = pr'y$ ⇒ 消去 $r'y = 1$ ⇒ $y$ 是單位 [▶ 39:30](https://youtu.be/YZzFYumnF8c?t=2370)。（「我一度看不出這個蘊含——中間那個等式一直不對勁。抱歉。」）
- **$\langle x\rangle = D$**：$xr' = 1$ ⇒ $x$ 是單位。
- ⇒ $p$ 不可約。

**(⇐)** $p$ 不可約，$\langle p\rangle\subseteq I\subseteq D$。PID ⇒ $I = \langle x\rangle$。$p\in\langle x\rangle$ ⇒ $p = xr$ ⇒ $x$ 或 $r$ 是單位 [▶ 41:00](https://youtu.be/YZzFYumnF8c?t=2460)。
- $x$ 單位 ⇒ $I = D$；$r$ 單位 ⇒ $p$、$x$ 相伴 ⇒ $I = \langle p\rangle$。
- 【Q&A】學生指出措辭。老師：「你說得對……**我的措辭不好**。我該扣自己至少一分。」

**$1-i$ 不可約**[▶ 42:00](https://youtu.be/YZzFYumnF8c?t=2520)：範數 2（質數）⇒ 任何分解有一個因數範數 1 ⇒ 單位。「這題簡單。耶。」

## 9. 質數 a²+b² ⇒ a+bi 不可約；2ℤ[x] 質；5+i 的分解

**#19：$p = a^2+b^2$ 質數 ⇒ $a+bi$ 在 $\mathbb{Z}[i]$ 不可約**[▶ 42:30](https://youtu.be/YZzFYumnF8c?t=2550)
- $N(a+bi) = p$。若 $a+bi = xy$，$p = N(x)N(y)$，$p$ 質數 ⇒ 一個範數為 1 ⇒ 單位。

**$2\mathbb{Z}[x]$（偶係數多項式）是質理想**[▶ 44:30](https://youtu.be/YZzFYumnF8c?t=2670)「抱歉超時，我想做完。」

- **用 #38**：$2\mathbb{Z}$ 是 $\mathbb{Z}$ 的質理想（$xy$ 偶 ⇒ $x$ 或 $y$ 偶），$2\mathbb{Z}[x] = (2\mathbb{Z})[x]$ ⇒ 質理想 [▶ 45:30](https://youtu.be/YZzFYumnF8c?t=2730)。
- **獨立證明**（「考試時你可能不能引用作業」）：$\psi:\mathbb{Z}[x]\to\mathbb{Z}_2[x]$ 係數取模 2；核 $= 2\mathbb{Z}[x]$；滿射（「公式幾乎就是滿射的證明」）⇒ $\mathbb{Z}[x]/2\mathbb{Z}[x]\cong\mathbb{Z}_2[x]$。$\mathbb{Z}_2$ 是體 ⇒ $\mathbb{Z}_2[x]$ 是整環 ⇒ 理想是質的。
