## 本集概要

感恩節假期後，投影講 Lecture 24–28 的作業解答：
- $\mathbb{Z}[i]/\langle2+2i\rangle$ 有 8 個元素；$\mathbb{Z}_2[x]/\langle x^2+x+1\rangle$ 是 4 元體。
- **$I$ 是質理想 $\Rightarrow I[x]$ 是 $R[x]$ 的質理想**（用係數模 $I$ 的同態 + 第一同構定理）。
- $F[x]$ 中的 **Bézout**：沒有公因式 $\Rightarrow fh+gk = 1$。
- 27 元體；Eisenstein 與模 2 判別。
- **$x^4+1$ 在每個 $\mathbb{Z}_p$ 上都可約**（用平方映射 $x\mapsto x^2$ 的同態）。
- 範數的性質；Gaussian 整數中 3 不可約、2 和 5 可約；7 在 $\mathbb{Z}[\sqrt6]$ 中不可約（$\mathbb{Z}[\sqrt6]$ 有無窮多個單位）。
- PID 中 $\langle p\rangle$ 極大 $\iff p$ 不可約；$p = a^2+b^2$ 質數 $\Rightarrow a+bi$ 不可約；$2\mathbb{Z}[x]$ 是質理想；$5+i = (1-i)(2+3i)$。

## 筆記

### 1. $\mathbb{Z}[i]/\langle2+2i\rangle$（#94）[▶ 00:30](https://youtu.be/YZzFYumnF8c?t=30)

$2+2i$ 和它的相伴元 $\pm(2+2i)$、$\pm(2i-2)$ 給出四個方向；用整數組合連起來的格點都在同一個陪集。在方格紙上取一個**基本區域**，數出每個陪集的代表：共 **8 個**陪集 [▶ 02:30](https://youtu.be/YZzFYumnF8c?t=150)。

### 2. $\mathbb{Z}_2[x]/\langle x^2+x+1\rangle$ 是 4 元體 [▶ 02:30](https://youtu.be/YZzFYumnF8c?t=150)

- 現在的工具：$f(0) = f(1) = 1$，沒有根，二次式所以不可約 $\Rightarrow\langle f\rangle$ 極大 $\Rightarrow$ 商環是體。
- 出題時還沒有這些定理，要用 Gallian 的提示**直接**證 [▶ 03:30](https://youtu.be/YZzFYumnF8c?t=210)：陪集是 $I$、$1+I$、$x+I$、$x+1+I$（$x^2\equiv x+1$，任何高次都能降下來）。
  - $1+I$ 是單位元。（一般原則：有單位元的環除以不含 1 的理想，$1+I$ 就是商環的單位元 [▶ 04:30](https://youtu.be/YZzFYumnF8c?t=270)。）
  - $(x+I)(x+1+I) = x^2+x+I = 1+I$。所以 $x$、$x+1$ 互為反元素 [▶ 05:00](https://youtu.be/YZzFYumnF8c?t=300)。
- 每個非零元素都可逆：4 元體。（之後講擴張體時也會提到。）

**$\langle a_1,\dots,a_n\rangle$ 是理想**：理想判別法（差、超級封閉）[▶ 05:30](https://youtu.be/YZzFYumnF8c?t=330)。

### 3. $x-1$ 是因式 $\iff$ 係數和為 0（#109）[▶ 07:30](https://youtu.be/YZzFYumnF8c?t=450)

$f(1) = a_n+\cdots+a_0$。因式定理：$x-1\mid f\iff f(1) = 0$。「這不是一看就知道嗎？」

### 4. 質理想的多項式版（#38）[▶ 08:30](https://youtu.be/YZzFYumnF8c?t=510)

**題目**：$R$ 是有單位元的交換環，$I$ 是質理想。證明 $I[x]$（係數在 $I$ 裡的多項式）是 $R[x]$ 的質理想。

**笨方法** [▶ 09:00](https://youtu.be/YZzFYumnF8c?t=540)：設 $f(x)g(x)\in I[x]$，一個個看係數：$c_0 = a_0b_0\in I\Rightarrow a_0\in I$ 或 $b_0\in I$；$c_1 = a_0b_1+a_1b_0$……「很快就變老、變組合式的噩夢。」

**好方法** [▶ 10:30](https://youtu.be/YZzFYumnF8c?t=630)
- $I$ 質 $\Rightarrow R/I$ 是整環。
- 自然同態 $R\to R/I$ 誘導 $\psi:R[x]\to(R/I)[x]$（把係數換成陪集）。是環同態。
- $\ker\psi$：所有係數 $a_k+I = I$，即 $a_k\in I$。所以 $\ker\psi = I[x]$ [▶ 11:30](https://youtu.be/YZzFYumnF8c?t=690)。
- 顯然滿射。第一同構定理：$R[x]/I[x]\cong(R/I)[x]$。
- 整環上的多項式環是整環，所以 $R[x]/I[x]$ 是整環 $\Rightarrow I[x]$ 是質理想。$\blacksquare$

「這題用到這一段課程裡最重要的定理，非常值得理解。」

### 5. $F[x]$ 中的 Bézout（#40）[▶ 13:30](https://youtu.be/YZzFYumnF8c?t=810)

**題目**：$f,g\in F[x]$ 沒有正次數的公因式。證明有 $h,k$ 使 $fh+gk = 1$。
- $I = \{fa+gb\}$ 是理想（上一題的 $n = 2$ 情形）。$F[x]$ 是 PID：$I = \langle j\rangle$。
- $f = f\cdot1+g\cdot0\in I$，所以 $j\mid f$；同理 $j\mid g$ [▶ 14:30](https://youtu.be/YZzFYumnF8c?t=870)。
- 沒有正次數公因式 $\Rightarrow\deg j = 0$，$j = c$ 常數。$c\neq0$（否則 $f = g = 0$）。
- $c\in I$：$c = fa+gb$，除以 $c$ 得 $1 = f(a/c)+g(b/c)$。

「整數裡 gcd 建構的多項式版。」

### 6. 27 元體、不可約判別（#113）[▶ 16:00](https://youtu.be/YZzFYumnF8c?t=960)

- **27 元體**：$\mathbb{Z}_3[x]$ 除以一個不可約**三次**式，得到 $\mathbb{Z}_3$ 上的 3 維向量空間，$3^3 = 27$ 個元素。解答用的三次式在 $0,1,2$ 的值都是 2（例如 $x^3+2x+2$），沒有根，所以不可約 [▶ 16:30](https://youtu.be/YZzFYumnF8c?t=990)。**「無根 ⇒ 不可約」只能用在 2、3 次**。
- 判斷 $\mathbb{Q}$ 上不可約 [▶ 17:00](https://youtu.be/YZzFYumnF8c?t=1020)：
  - Eisenstein $p = 3$（$3\mid9,12,6$，$9\nmid6$）；$x^4+3x^2+3$ 也是 $p = 3$。
  - 不能用 Eisenstein 時，試**模 2**：$\bar f(0) = \bar f(1) = 1$ 等。
  - 有分數的：乘上分母的最小公倍數（例如 14）變成整係數，再用 Eisenstein；$14f$ 不可約 $\Rightarrow f$ 不可約 [▶ 18:30](https://youtu.be/YZzFYumnF8c?t=1110)。

### 7. $x^4+1$ 在每個 $\mathbb{Z}_p$ 上可約（Ch.17 #29）[▶ 19:30](https://youtu.be/YZzFYumnF8c?t=1170)

老師假期前拒絕講，「堅持我的拒絕」。他說整學期大概只有五題是真正難的計算題，這是其中之一。

**想法**（跟著 Gallian 的提示）：在每個 $\mathbb{Z}_p$ 裡，下面至少一個方程有解，對應的分解：

| 條件 | 分解 |
|---|---|
| $a^2 = -1$ | $x^4+1 = (x^2-a)(x^2+a)$ |
| $a^2 = 2$ | $x^4+1 = (x^2+ax+1)(x^2-ax+1)$ |
| $a^2 = -2$ | $x^4+1 = (x^2+ax-1)(x^2-ax-1)$ |

（展開就能驗證：例如第二行 $= x^4+(2-a^2)x^2+1$。投影上有個打錯的地方 [▶ 21:00](https://youtu.be/YZzFYumnF8c?t=1260)。）

**為什麼三者之一一定成立**（$p>2$）[▶ 22:30](https://youtu.be/YZzFYumnF8c?t=1350)
- 平方映射 $\varphi:\mathbb{Z}_p^\times\to\mathbb{Z}_p^\times$，$\varphi(x) = x^2$ 是乘法群同態。$\ker\varphi = \{\pm1\}$，2 個元素。
- 令 $H = \varphi(\mathbb{Z}_p^\times)$（平方數）。第一同構定理：$\mathbb{Z}_p^\times/\ker\varphi\cong H$，所以
$$|\mathbb{Z}_p^\times/H| = |\ker\varphi| = 2$$
  （「商的記號好用得不合理：分母翻上來」）[▶ 23:30](https://youtu.be/YZzFYumnF8c?t=1410)。只有兩個陪集：$H$ 和另一個。
- 若 $-1\notin H$ 且 $2\notin H$，它們在同一個陪集：$-H = 2H$。則 $(-H)(2H) = (-H)(-H) = H$，所以 $-2H = H$，**$-2\in H$**——有 $a$ 使 $a^2 = -2$ [▶ 25:00](https://youtu.be/YZzFYumnF8c?t=1500)。
- 否則 $-1$ 或 $2$ 在 $H$ 裡，前兩種情形之一成立。$\blacksquare$

「沒有提示這題太扯；有提示，只是扯。」

### 8. 範數與不可約（Lecture 28 作業）[▶ 27:00](https://youtu.be/YZzFYumnF8c?t=1620)

- **$N(a+b\sqrt d) = 0\iff a = b = 0$**：否則 $a^2 = db^2$，$\pm a/b = \sqrt d$——有理數等於無理數（$d$ 無平方因子；Math 200 證過）。乘性：直接代數 [▶ 27:30](https://youtu.be/YZzFYumnF8c?t=1650)。
- 在 $\mathbb{Z}_2[x]$ 中把三次式分解：分組提公因式、平方差（$-1 = 1$）[▶ 28:00](https://youtu.be/YZzFYumnF8c?t=1680)。
- **不可約元的相伴元也不可約** [▶ 29:00](https://youtu.be/YZzFYumnF8c?t=1740)：$b = au$。若 $b = b_1b_2$，則 $a = b_1(b_2u^{-1})$，$a$ 不可約 $\Rightarrow b_1$ 或 $b_2u^{-1}$ 是單位 $\Rightarrow b_1$ 或 $b_2$ 是單位。
- **Gaussian 整數：3 不可約，2、5 可約** [▶ 30:00](https://youtu.be/YZzFYumnF8c?t=1800)
  - $3 = xy\Rightarrow9 = N(x)N(y)$。不是單位就要 $N(x) = N(y) = 3$，但 $a^2+b^2 = 3$ 無整數解。（老師不寫這部分細節，「可以寫滿四分之一頁，但沒人看得懂」；只要確定真的無解。）
  - $2 = (1+i)(1-i)$、$5 = (2+i)(2-i)$：要找範數 2 和 5 的元素——「哪些平方和等於 2、5？」
- **7 在 $\mathbb{Z}[\sqrt6]$ 中不可約** [▶ 32:30](https://youtu.be/YZzFYumnF8c?t=1950)（仿 Gallian p.313 Example 2）
  - $N = |a^2-6b^2|$。$7 = xy$，非單位就要 $a^2-6b^2 = \pm7$。
  - 模 7 列出所有平方，只有 $a\equiv b\equiv0$；則 $49\mid N(x) = 7$，矛盾。
  - **旁白**：$\mathbb{Z}[\sqrt6]$ 有**無窮多個單位**（例如 $5+2\sqrt6$，範數 $25-24 = 1$）——「實二次體比虛二次體醜多了」。但其實不需要知道單位是什麼，論證全在範數層次 [▶ 34:00](https://youtu.be/YZzFYumnF8c?t=2040)。
- **$\mathbb{Z}[i]$ 中的輾轉相除**（#121）：$12+3i$ 和 $6-9i$，一路除到餘 0；最後一個非零餘數是 $-3i$ [▶ 36:00](https://youtu.be/YZzFYumnF8c?t=2160)。gcd 差一個單位：可以說是 $\pm3$ 或 $\pm3i$；更恰當的說法是「gcd 是一個**理想**」。

### 9. PID 中 $\langle p\rangle$ 極大 $\iff p$ 不可約 [▶ 37:30](https://youtu.be/YZzFYumnF8c?t=2250)

- ($\Rightarrow$) $p = xy\Rightarrow\langle p\rangle\subseteq\langle x\rangle\subseteq D$。極大：$\langle p\rangle = \langle x\rangle$（則 $x = pr'$，代入得 $r'y = 1$，$y$ 是單位）或 $\langle x\rangle = D$（$x$ 是單位）[▶ 39:30](https://youtu.be/YZzFYumnF8c?t=2370)。
- ($\Leftarrow$) $\langle p\rangle\subseteq I = \langle x\rangle\subseteq D$。$p = xr$，$p$ 不可約：$x$ 是單位（$I = D$）或 $r$ 是單位（$I = \langle p\rangle$）[▶ 40:30](https://youtu.be/YZzFYumnF8c?t=2430)。老師說措辭不好，該扣一分。

### 10. 更多 Gaussian 整數 [▶ 42:00](https://youtu.be/YZzFYumnF8c?t=2520)

- **$1-i$ 不可約**：範數 2 是質數，任何分解都有一個範數 1 的因數（單位）。
- **$p = a^2+b^2$ 是質數 $\Rightarrow a+bi$ 不可約** [▶ 42:30](https://youtu.be/YZzFYumnF8c?t=2550)：$p = N(a+bi) = N(x)N(y)$，其中之一是 1。例：$5\to2+i$、$13\to2+3i$、$17\to4+i$。
- **$2\mathbb{Z}[x]$ 是質理想** [▶ 44:30](https://youtu.be/YZzFYumnF8c?t=2670)：直接做很難，用 §4（$2\mathbb{Z}$ 是 $\mathbb{Z}$ 的質理想）。獨立證明：$\mathbb{Z}[x]\to\mathbb{Z}_2[x]$ 係數模 2，核是 $2\mathbb{Z}[x]$，滿射；$\mathbb{Z}_2$ 是體，$\mathbb{Z}_2[x]$ 是整環，所以商是整環，理想是質的。（考試時可能不能引用作業題，所以要會獨立證明 [▶ 46:00](https://youtu.be/YZzFYumnF8c?t=2760)。）「這類題的英雄就是這兩個定理：商是整環 $\iff$ 質；商是體 $\iff$ 極大。」
- **分解** [▶ 49:00](https://youtu.be/YZzFYumnF8c?t=2940)：$13 = (2+3i)(2-3i)$；$5+i$ 範數 26，找範數 2 和 13 的：
$$5+i = (1-i)(2+3i)\quad(= 2+3i-2i+3).$$

**結尾** [▶ 51:00](https://youtu.be/YZzFYumnF8c?t=3060)：老師問了哥哥環同態那題，哥哥說「就是那樣，只是醜陋的數論題」——所以做法是對的，只是繁瑣。
