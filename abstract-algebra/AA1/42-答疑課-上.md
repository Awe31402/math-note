## 1. 環的中心是子環

[▶ 01:00](https://youtu.be/1hBJQDzF-T4?t=60)「我希望很多人做出這題，不難。」

中心 $H = \{a : ax = xa\ \forall x\in R\}$（解答裡叫 $H$）。
- 非空：$0\in H$。
- $a,b\in H$：$(a-b)x = ax-bx = xa-xb = x(a-b)$（分配、交換）。
- $(ab)x = a(bx) = a(xb) = (ax)b = (xa)b = x(ab)$：先用 $b$ 跟 $x$ 交換，再用 $a$。
- 子環判別法。$\blacksquare$

【口頭】[▶ 02:00](https://youtu.be/1hBJQDzF-T4?t=120)「抱歉，我從題目到解答時把 $a$ 和 $x$ 的角色對調了。就算你們不原諒，我也不擦——是用原子筆寫的，我在車上寫的，寫得還算整齊就收工了。」「如果我考這題，我**真心**希望只有很少很少人不會。」

## 2. U(R) 是群——不能用子群判別法

[▶ 02:30](https://youtu.be/1hBJQDzF-T4?t=150) $R$ 有單位元的交換環，$U(R)$ = 單位。

- 非空：$1$ 本身是單位。
- $a,b\in U(R)$：有 $x,y$ 使 $ax = 1$、$by = 1$（也 $xa = 1$、$yb = 1$）。
- **對反元素封閉**：$x = a^{-1}$，而 $xa = 1$ 說明 $x$ 也是單位 [▶ 03:00](https://youtu.be/1hBJQDzF-T4?t=180)。
- **對乘法封閉**[▶ 03:30](https://youtu.be/1hBJQDzF-T4?t=210)：「我**希望** $(ab)^{-1} = b^{-1}a^{-1}$——但不能假設，那是循環論證。這只是**引導**我去試 $yx$。」$(ab)(yx) = a(by)x = ax = 1$ ✓。

**關鍵的陷阱**[▶ 04:00](https://youtu.be/1hBJQDzF-T4?t=240)
- 「我正要說『由兩步子群判別法，是群』——然後我想到：**是誰的子群？**」
- 我們是在**建立**群結構，不能用子群判別法。
- 正確結論：乘法是 $U(R)$ 上**結合**的二元運算（環乘法本來就結合）、有單位元、對反元素封閉 ⇒ 群。而且 $R$ 交換 ⇒ **交換群**。

【Q&A】[▶ 05:30](https://youtu.be/1hBJQDzF-T4?t=330) 學生問封閉和反元素好像糾纏在一起。老師：「對，有混淆的空間：要證乘法封閉，就是要證乘積**有反元素**。概念有點纏在一起，但那就是定義。」

## 3. U(ℤ[i]) = {±1, ±i}

[▶ 06:00](https://youtu.be/1hBJQDzF-T4?t=360)「現在可以直接算。」

解 $(a+bi)(x+yi) = 1$：
- 這是複數，可以除、可以取共軛：$a+bi = \dfrac{1}{x+yi} = \dfrac{x-yi}{x^2+y^2}$。
- 實部、虛部分別相等。$a,b,x,y$ 都是整數，「分數不能等於整數，除非……」分母 $x^2+y^2 = 1$。
- 【口頭】[▶ 07:00](https://youtu.be/1hBJQDzF-T4?t=420)「我的解答**也有個缺口**：為什麼不能 $x = 2$、分子 4？——因為 $x = 10$ 時分母自動是 100 多，**一定比較大**。這是我沒寫下來的。」
- $x^2+y^2 = 1$ 的整數解：**單位圓和整數格點 $\mathbb{Z}\times\mathbb{Z}$ 的交點**——$(\pm1,0)$、$(0,\pm1)$ [▶ 08:00](https://youtu.be/1hBJQDzF-T4?t=480)。
- （「我解答裡所有的彆扭，都可以歸咎於我擠不下多一個字母、手邊又沒有擦得掉的筆。」）

$$U(\mathbb{Z}[i]) = \{1,-1,i,-i\}\cong\mathbb{Z}_4\quad(i\text{ 是 4 階}).$$

## 4. {n·1} 是子環

[▶ 10:00](https://youtu.be/1hBJQDzF-T4?t=600)「這題很好玩……簡單說，用子環判別法：差、積還在裡面，0 在裡面。」

「**這題就是煩，就是煩**」：要先接受引理 $m\cdot1-n\cdot1 = (m-n)\cdot1$、$(m\cdot1)(n\cdot1) = (mn)\cdot1$。

**為什麼這引理成立**[▶ 10:30](https://youtu.be/1hBJQDzF-T4?t=630)：「跟課程前面**指數律**的證明很像。」
- $m,n>0$：$m\cdot1 = 1+1+\cdots+1$，最終靠**加法結合律**（的歸納推廣）。
- 【Q&A】學生：「不就是分配律嗎？」老師：「**不是**——$n\cdot1$ 不是環的乘法。$n$ 甚至不必在環裡。$1$ 可能是**單位矩陣**，$n\cdot1$ 是單位矩陣加 $n$ 次。$n$ 和 $1$ 是不同的物件，這是**重複加法**的記號。」[▶ 11:30](https://youtu.be/1hBJQDzF-T4?t=690)
- 分情況：$m-n>0$、$= 0$、$<0$ [▶ 12:00](https://youtu.be/1hBJQDzF-T4?t=720)；$n$ 負時 $n\cdot1$ 是 $-n$ 個 $(-1)$ 相加 [▶ 13:00](https://youtu.be/1hBJQDzF-T4?t=780)……「其他情況類似。我累了，抱歉。我猜你們沒有人真的做這個。」

## 5. Boolean 環一定交換

[▶ 14:00](https://youtu.be/1hBJQDzF-T4?t=840)「這題比較好玩。」**假設**：$a^2 = a$ 對所有 $a$。證明 $R$ 交換。

（「跳過那段又長又笨重的論證，給你們看下面那個乾淨的。」）

**步驟 1**：$(-a)^2 = a^2$ ⇒ $-a = a$。

> 📘 筆記補充：$-a = (-a)^2 = a^2 = a$。（另一種常見寫法：$(a+a)^2 = a+a$ 展開得 $4a = 2a$，即 $2a = 0$。）

**步驟 2**[▶ 14:30](https://youtu.be/1hBJQDzF-T4?t=870)：$(a+b)^2 = a+b$：
$$a^2+ab+ba+b^2 = a+b\ ⇒\ a+ab+ba+b = a+b\ ⇒\ ab+ba = 0.$$
所以 $ab = -ba = ba$（步驟 1）。$\blacksquare$

【口頭】[▶ 15:30](https://youtu.be/1hBJQDzF-T4?t=930)（有同學在講話：「我的講話讓你們分心了，謝謝。」）摘要：證明任何元素等於自己的負；看 $(a+b)^2$，用分配律和 $a^2 = a$、$b^2 = b$，東西就消掉。

## 6. 整環的冪等元只有 0、1

[▶ 15:30](https://youtu.be/1hBJQDzF-T4?t=930)「這題我喜歡。」**冪等元（idempotent）**：$a^2 = a$。

- $0^2 = 0$：一個。
- $a\neq0$：$a\cdot a = a = a\cdot1$。整環有**消去律** ⇒ $a = 1$。

## 7. ℚ(√d) 是體

[▶ 17:30](https://youtu.be/1hBJQDzF-T4?t=1050)「這題可能很冗長。」$\mathbb{Q}(\sqrt d) = \{a+b\sqrt d : a,b\in\mathbb{Q}\}$。

- 【口頭】「Gallian 應該是要 $d$ **無平方因子**。$d = 25$ 時 $a+b\sqrt{25} = a+5b$——只是寫有理數的怪方法，當然是體。所以讓它有趣：**設 $d$ 不是平方數**。」
- 是 $\mathbb{R}$ 的子集 ⇒ 用子環判別法：差、積還是「有理數 + 有理數·$\sqrt d$」[▶ 18:30](https://youtu.be/1hBJQDzF-T4?t=1110)。
- 交換（$\mathbb{R}$ 的子集）；$1 = 1+0\sqrt d$。
- **反元素**[▶ 19:30](https://youtu.be/1hBJQDzF-T4?t=1170)「從晴朗的藍天裡抓出來——好吧不是，就是**乘共軛除共軛**」：
$$(a+b\sqrt d)^{-1} = \frac{a}{a^2-db^2}-\frac{b}{a^2-db^2}\sqrt d.$$
- **分母為什麼非零**[▶ 20:00](https://youtu.be/1hBJQDzF-T4?t=1200)：若 $a^2 = db^2$（$b\neq0$），則 $\sqrt d = a/b$ 是有理數——但 $d$ 非平方數時 $\sqrt d$ 是無理數。「你不能讓無理數等於有理數——就像**柯林頓等於川普**一樣。」
- 【Q&A】[▶ 20:30](https://youtu.be/1hBJQDzF-T4?t=1230) 學生：「$d$ 一定是正的嗎？」老師：「好問題……不一定。我該說它是 **$\mathbb{C}$ 的子環**，比較安全。我的錯，貼出前會改。」

## 8. ℤ₃[i] 的非零元素是 8 階循環群

[▶ 22:00](https://youtu.be/1hBJQDzF-T4?t=1320)（#93）$\mathbb{Z}_3[i]$ 的非零元素在乘法下是 8 階交換群。是哪一個？

- 列元素：$1,2,1+i,1+2i,2+i,2+2i$……「然後我突然想到：$i$ 和 $2i$ 也在。我的列舉方式永遠是我自己的，別問我從哪來。」數到 8 個。
- 「看過書後答案，我知道要找的是 $\mathbb{Z}_8$。」所以找 **8 階元素** [▶ 22:30](https://youtu.be/1hBJQDzF-T4?t=1350)：
  - $2^2 = 4 = 1$：2 是 2 階。
  - $(1+i)^2 = 1+2i+i^2 = 2i$。
  - $(1+i)^4 = (2i)^2 = -4 = 2$。
  - $(1+i)^8 = 2^2 = 1$。
- $1+i$ 是 8 階 ⇒ **循環群**，$\cong\mathbb{Z}_8$。

【口頭】[▶ 23:30](https://youtu.be/1hBJQDzF-T4?t=1410)「**同構意義下**：$\mathbb{Z}_8$ 是具體的東西——整數的陪集 $8\mathbb{Z}, 1+8\mathbb{Z},\dots$。$1+i$ 不是整數的陪集。但有個同構把這個單位群送到那些陪集。從群論的觀點它們是一樣的；它們是不同的物件，但有同樣的群結構。」

## 9. ⟨2+2i⟩ 不是質理想；8 個陪集

[▶ 24:30](https://youtu.be/1hBJQDzF-T4?t=1470)「這題我還沒做完。」

**不是質理想**[▶ 25:00](https://youtu.be/1hBJQDzF-T4?t=1500)
- 定理：$R/A$ 整環 $\iff$ $A$ 質。所以要證不是質理想，可以證**商不是整環**——找零因子。
- $2\cdot(1+i) = 2+2i\in\langle2+2i\rangle$，即商環中 $[2][1+i] = 0$。
- 「我好像還沒說服自己 $2$ 和 $1+i$ **不在**理想裡。我該再想想。」

> 💬 驗證：$\langle2+2i\rangle$ 的元素是 $(2+2i)(x+yi) = 2(x-y)+2(x+y)i$，實部虛部都偶數且和是 4 的倍數。$2$ 和 $1+i$ 都不符合，所以確實是零因子。

**8 個陪集**[▶ 26:00](https://youtu.be/1hBJQDzF-T4?t=1560)：老師的圖。
- 生成元 $2+2i$ 乘以**單位** $\pm1,\pm i$，還在理想裡 [▶ 26:30](https://youtu.be/1hBJQDzF-T4?t=1590)——「**謝謝你們**，那是我一直在找的說法，就在我眼前。這是我們該證的引理。」（呼應 [[39-L25-環同態]] 卡住的問題。）
- 得到四個「基本向量」，圍出一個基本格子，數裡面的點：8 個 [▶ 28:00](https://youtu.be/1hBJQDzF-T4?t=1680)。（「這個符號……我不知道是什麼，太陽？大概是一隻在轉的烏龜。」）

**方法**[▶ 28:30](https://youtu.be/1hBJQDzF-T4?t=1710)：
1. 找生成元的所有**相伴元（associates）**：$a = bu$，$u$ 是單位。（「下堂課學什麼是相伴元。」）對高斯整數就是 $\pm g$、$\pm ig$。
2. 它們都在理想裡；圍出一個**基本區域**。
3. 數區域裡不同的點 = 陪集個數。其他點都能加理想元素回到這區域。

【口頭】[▶ 30:00](https://youtu.be/1hBJQDzF-T4?t=1800)「Gallian 沒有這張圖。他用段落一步步：『這個加這個得那個，所以在理想裡……』也許有演算法，我沒看到。我是很**視覺**的人，這樣想我知道什麼時候做完了。用公式描述就沒這麼愉快。我需要更多顏色。」

> 📘 筆記補充：$|\mathbb{Z}[i]/\langle a+bi\rangle| = a^2+b^2$；這裡 $2^2+2^2 = 8$。

## 10. 環同態 ℤₙ → ℤₙ 是 x ↦ ax，a² = a

[▶ 30:30](https://youtu.be/1hBJQDzF-T4?t=1830)「今天我有**額外時間**——我要去那個……什麼東西，所以可以多跟你們聊 20 分鐘。」（閒聊大選，語帶諷刺：「我很難過。我本來很想明年多繳稅、被迫去看我不想看的醫生。那在我的待辦清單上。」）

【Q&A】[▶ 32:30](https://youtu.be/1hBJQDzF-T4?t=1950) 學生問 p.278 #8（第 15 章）。

> **題目**　每個環同態 $\varphi:\mathbb{Z}_n\to\mathbb{Z}_n$ 都是 $\varphi(x) = ax$，其中 $a^2 = a$。

**先看 $n = p$ 質數**[▶ 34:30](https://youtu.be/1hBJQDzF-T4?t=2070)：$\mathbb{Z}_p$ 是整環 ⇒ 冪等元只有 0、1（§6）⇒ 只有**零同態**和**恆等**。「有點無聊。」

**為什麼是 $ax$**[▶ 35:30](https://youtu.be/1hBJQDzF-T4?t=2130)
- $x = x\cdot1 = 1+1+\cdots+1$（$x$ 次）。
- 【口頭】[▶ 37:30](https://youtu.be/1hBJQDzF-T4?t=2250) 老師一度寫成 $\varphi(x\cdot1) = \varphi(x)\varphi(1)$：「我是白痴，我是白痴。**別讓我這樣蒙混過去**——不不不不不……我剛說服你們別這樣想！這**不是**環的乘法，是重複加法。」
- 正確：$\varphi(x\cdot1) = x\cdot\varphi(1)$（同態的**加法**性質，$\varphi(1)+\cdots+\varphi(1)$）。
- 令 $a = \varphi(1)$。**冪等**[▶ 39:00](https://youtu.be/1hBJQDzF-T4?t=2340)：$a = \varphi(1) = \varphi(1\cdot1) = \varphi(1)\varphi(1) = a^2$（這次真的是環乘法）。
- 所以 $\varphi(x) = xa = ax$。$\blacksquare$

**應用：$\mathbb{Z}_8\to\mathbb{Z}_8$**[▶ 40:00](https://youtu.be/1hBJQDzF-T4?t=2400)：找 $a^2 = a$ 在 $\mathbb{Z}_8$。
- 【課堂討論】$2^2 = 4$ ✗；$3^2 = 9 = 1$ ✗；$4^2 = 16 = 0$ ✗；$5^2 = 25 = 1$ ✗；$6^2 = 36 = 4$ ✗；$7^2 = 49 = 1$ ✗。
- 只有 0、1。「有趣。」「$\mathbb{Z}_6$ 有更多——但那是你們的作業，我不能說。」

**$\mathbb{Z}_{20}\to\mathbb{Z}_{30}$ 呢？**[▶ 42:00](https://youtu.be/1hBJQDzF-T4?t=2520)
- 加法層次上，環同態是群同態。之前（#72）證過：$\mathbb{Z}_n\to\mathbb{Z}_k$ 的群同態是 $x\mapsto mx$，條件 $k\mid mn$ [▶ 44:00](https://youtu.be/1hBJQDzF-T4?t=2640)。
- 「那是你們**該搜尋的宇宙**。然後還要尊重乘法，會再進一步限制。」

## 11. 環同態 ℤ → ℤ

[▶ 46:00](https://youtu.be/1hBJQDzF-T4?t=2760)（#21）「這題花了一陣子。」

## 12. (ℤ×ℤ)/(⟨a⟩×⟨b⟩) ≅ ℤₐ×ℤ_b

[▶ 54:00](https://youtu.be/1hBJQDzF-T4?t=3240)「我沒指定 #26，但它很好玩。」（「我是想做 23 的。」）

> **題目**　$(\mathbb{Z}\times\mathbb{Z})/(\langle a\rangle\times\langle b\rangle)\cong\mathbb{Z}_a\times\mathbb{Z}_b$（環同構）。

【課堂討論】[▶ 55:00](https://youtu.be/1hBJQDzF-T4?t=3300)「這種題幾乎一定用**第一同構定理**。要什麼同態？要一個以底下那東西為核的同態。我需要你們的反應。」

$$\varphi(x,y) = ([x]_a,[y]_b) = (x+a\mathbb{Z},\ y+b\mathbb{Z}).$$
- 定義在整數上，「**沒有良定義的問題**——$x,y$ 是具體的東西，沒有歧義」[▶ 56:30](https://youtu.be/1hBJQDzF-T4?t=3390)。
- **加法**：陪集加法的性質。
- **乘法**[▶ 57:00](https://youtu.be/1hBJQDzF-T4?t=3420)：
$$\varphi((x_1,y_1)(x_2,y_2)) = (x_1x_2+a\mathbb{Z},\ y_1y_2+b\mathbb{Z}) = (x_1+a\mathbb{Z},y_1+b\mathbb{Z})(x_2+a\mathbb{Z},y_2+b\mathbb{Z}).$$
  「這就是 $\mathbb{Z}_a\times\mathbb{Z}_b$ 裡陪集的乘法——乘代表元。」
- **核**[▶ 58:30](https://youtu.be/1hBJQDzF-T4?t=3510)：$x+a\mathbb{Z} = a\mathbb{Z}$ 且 $y+b\mathbb{Z} = b\mathbb{Z}$ ⇔ $x\in\langle a\rangle$、$y\in\langle b\rangle$ ⇒ $\ker\varphi = \langle a\rangle\times\langle b\rangle$。
- 剩下：證**滿射**——「那幾乎……」（錄影在這裡切段，接 [[43-答疑課-下]]。）

## 附：本集一句話總結

> **環的作業重點在分清楚兩種「乘」：$n\cdot1$ 是重複加法、不是環乘法，所以環同態 $\mathbb{Z}_n\to\mathbb{Z}_n$ 只能是 $x\mapsto ax$ 且 $a = \varphi(1)$ 是冪等元（整環裡只有 0、1）；$U(R)$ 要直接驗群公理而不是用子群判別法；高斯整數的單位是 $\pm1,\pm i$，乘上單位不改變主理想，所以畫格子圖數陪集最直觀（$\langle2+2i\rangle$ 有 8 個）；而 $\mathbb{Z}_3[i]$ 的非零元素由 $1+i$ 生成，是 8 階循環群。**
