## 本集概要

老師投影手寫解答，然後回答問題：
- 環的**中心**是子環；**單位群** $U(R)$ 是群（**不能用子群判別法**——是誰的子群？）。
- **$U(\mathbb{Z}[i]) = \{\pm1,\pm i\}\cong\mathbb{Z}_4$**。
- $\{n\cdot1\}$ 是子環（指數律式的繁瑣證明）。
- **Boolean 環**（$a^2 = a$）一定交換；**整環的冪等元只有 0、1**。
- $\mathbb{Q}(\sqrt d)$ 是體（$d$ 非平方數）。
- **$\mathbb{Z}_3[i]$ 的非零元素是 8 階循環群**。
- $\langle2+2i\rangle$ 不是 $\mathbb{Z}[i]$ 的質理想；$\mathbb{Z}[i]/\langle2+2i\rangle$ 有 8 個元素（格子圖）。
- **環同態 $\mathbb{Z}_n\to\mathbb{Z}_n$ 是 $x\mapsto ax$，$a^2 = a$**；$\mathbb{Z}\to\mathbb{Z}$ 只有零映射和恆等。
- $(\mathbb{Z}\times\mathbb{Z})/(\langle a\rangle\times\langle b\rangle)\cong\mathbb{Z}_a\times\mathbb{Z}_b$。

> 💬 週二（大選日）沒有答疑課。老師語帶諷刺地說他「很難過」希拉蕊沒選上：「我本來很期待明年多繳稅，還要被迫去看我不想看的醫生」[▶ 31:00](https://youtu.be/1hBJQDzF-T4?t=1860)。

## 筆記

### 1. 環的中心是子環 [▶ 01:00](https://youtu.be/1hBJQDzF-T4?t=60)

$Z(R) = \{a\mid ax = xa,\ \forall x\in R\}$。
- $0\in Z(R)$，非空。
- $(a-b)x = ax-bx = xa-xb = x(a-b)$（分配律）。
- $(ab)x = a(bx) = a(xb) = (ax)b = (xa)b = x(ab)$。
- 子環判別法得證。（解答裡 $a$ 和 $x$ 的角色和題目對調了，「是在車上用筆寫的，不改了」。）

「如果考這題，我真心希望只有很少很少人做不出來。」

### 2. 單位群是群 [▶ 02:30](https://youtu.be/1hBJQDzF-T4?t=150)

$R$ 是有單位元的交換環，$U(R)$ 是所有單位。
- 非空：$1$ 是單位。
- **反元素封閉**：$a$ 是單位，$ax = 1$，則 $x = a^{-1}$ 也是單位（$xa = 1$）。
- **乘法封閉** [▶ 04:00](https://youtu.be/1hBJQDzF-T4?t=240)：$ax = 1$、$by = 1$。猜 $(ab)^{-1} = yx$（從「如果它是群」得到靈感，但不能先假設它是群）：$(ab)(yx) = a(by)x = ax = 1$。
- **陷阱** [▶ 04:30](https://youtu.be/1hBJQDzF-T4?t=270)：不能用「兩步子群判別法」——**是誰的子群？** $R$ 在乘法下不是群。正確做法：乘法是封閉的二元運算、結合律從環繼承、有單位元 1、對反元素封閉，所以是群；$R$ 交換，所以是交換群。

### 3. $U(\mathbb{Z}[i])$ [▶ 06:00](https://youtu.be/1hBJQDzF-T4?t=360)

解 $(a+bi)(x+yi) = 1$。在 $\mathbb{C}$ 裡可以除、可以取共軛：
$$x+yi = \frac{1}{a+bi} = \frac{a-bi}{a^2+b^2}.$$
- 實部、虛部都要是**整數**，分數要等於整數，需要 $a^2+b^2 = 1$（老師承認解答漏了「為什麼不能是別的」：$x$ 是 $10$ 的話平方就是 100 以上）[▶ 07:00](https://youtu.be/1hBJQDzF-T4?t=420)。
- $a^2+b^2 = 1$ 的整數解：$(\pm1,0)$、$(0,\pm1)$——單位圓和整數格點的四個交點 [▶ 08:00](https://youtu.be/1hBJQDzF-T4?t=480)。
- 所以 $U(\mathbb{Z}[i]) = \{1,-1,i,-i\}\cong\mathbb{Z}_4$（$i$ 是 4 階）。

### 4. $\{n\cdot1\}$ 是子環 [▶ 10:00](https://youtu.be/1hBJQDzF-T4?t=600)

- 若接受引理 $m\cdot1 - n\cdot1 = (m-n)\cdot1$、$(m\cdot1)(n\cdot1) = (mn)\cdot1$，用子環判別法馬上得證。
- 引理的證明「很煩」，類似之前群的指數律。**不是分配律**：$n\cdot1$ 不是環裡的乘法，而是重複相加；$n$ 甚至不一定在環裡 [▶ 11:00](https://youtu.be/1hBJQDzF-T4?t=660)。例如 1 可以是單位矩陣，$n\cdot1$ 是 $n$ 個單位矩陣相加。
- 本質是加法結合律（及其歸納推廣）。$m,n$ 正負各種情形要分開處理（$n<0$ 時 $n\cdot1$ 是 $-n$ 個 $-1$ 相加）[▶ 12:30](https://youtu.be/1hBJQDzF-T4?t=750)。「我猜你們都沒做這題。」

### 5. Boolean 環一定交換 [▶ 14:00](https://youtu.be/1hBJQDzF-T4?t=840)

設 $a^2 = a$ 對所有 $a$。
1. $(-a)^2 = a^2$，而 $(-a)^2 = -a$、$a^2 = a$，所以 **$-a = a$**。
2. $(a+b)^2 = a+b$：
$$a^2+ab+ba+b^2 = a+b\ \Rightarrow\ a+ab+ba+b = a+b\ \Rightarrow\ ab = -ba = ba.$$

（老師講太多被打斷，「我本來想把這題拍賣出去」。）

### 6. 整環的冪等元 [▶ 15:30](https://youtu.be/1hBJQDzF-T4?t=930)

**冪等元 (idempotent)**：$a^2 = a$。**整環中只有 0 和 1**。
- $0^2 = 0$。
- $a\neq0$：$a\cdot a = a\cdot1$，用消去律得 $a = 1$ [▶ 16:30](https://youtu.be/1hBJQDzF-T4?t=990)。

（學生用 $a(a-1) = 0$ 直接證——老師說這正是消去律的證明。）

### 7. $\mathbb{Q}(\sqrt d)$ 是體 [▶ 17:30](https://youtu.be/1hBJQDzF-T4?t=1050)

$\{a+b\sqrt d\mid a,b\in\mathbb{Q}\}$。
- Gallian 應該是指 $d$ **不是完全平方**（例如 $d = 25$ 時 $a+5b$ 只是寫有理數的怪方法）[▶ 18:00](https://youtu.be/1hBJQDzF-T4?t=1080)。
- 是 $\mathbb{C}$ 的子環（老師原本說 $\mathbb{R}$，但 $d<0$ 時要用 $\mathbb{C}$，「比較安全」）[▶ 21:00](https://youtu.be/1hBJQDzF-T4?t=1260)。
- 交換、有 $1 = 1+0\sqrt d$。
- 反元素：乘共軛，$\dfrac{a-b\sqrt d}{a^2-db^2}$ [▶ 19:30](https://youtu.be/1hBJQDzF-T4?t=1170)。
- **分母非零**：若 $a^2 = db^2$，則 $\sqrt d = |a/b|$ 是有理數，和 $d$ 不是平方數矛盾。「無理數等於有理數，就像『柯林頓等於川普』。」

### 8. $\mathbb{Z}_3[i]$ 的乘法群 [▶ 22:00](https://youtu.be/1hBJQDzF-T4?t=1320)

非零元素：$1,2,i,2i,1+i,1+2i,2+i,2+2i$，共 8 個（老師一開始漏了 $i$、$2i$）。
- $2^2 = 4 = 1$，$|2| = 2$。
- $(1+i)^2 = 1+2i+i^2 = 2i$；$(2i)^2 = -4 = 2$；所以 $(1+i)^4 = 2$，$(1+i)^8 = 4 = 1$ [▶ 23:00](https://youtu.be/1hBJQDzF-T4?t=1380)。
- $1+i$ 是 **8 階**，所以這是 8 階循環群 $\cong\mathbb{Z}_8$。

**「同構意義下」是什麼意思** [▶ 24:00](https://youtu.be/1hBJQDzF-T4?t=1440)：$\mathbb{Z}_8$ 是整數陪集 $8\mathbb{Z},1+8\mathbb{Z},\dots$；$1+i$ 不是整數陪集。它們是**不同的集合**，但群結構相同。

### 9. $\langle2+2i\rangle$ 不是質理想 [▶ 24:30](https://youtu.be/1hBJQDzF-T4?t=1470)

- 用定理：質理想 $\iff$ 商環是整環。要證不是質理想，就在商環裡找**零因子**。
- $2\cdot(1+i) = 2+2i\in\langle2+2i\rangle$，即商環中 $[2][1+i] = 0$。而 $2$、$1+i$ 都不在理想裡（老師說「我還沒完全說服自己它們不在裡面」）[▶ 25:30](https://youtu.be/1hBJQDzF-T4?t=1530)。
- 所以商環不是整環，理想不是質的。

**$\mathbb{Z}[i]/\langle2+2i\rangle$ 有 8 個元素**（格子圖）[▶ 26:00](https://youtu.be/1hBJQDzF-T4?t=1560)
- **關鍵（學生點出，老師找了很久的詞）**：生成元乘上**單位** $\pm1,\pm i$，還在理想裡。
- **相伴元 (associates)**（下一講）：若 $a = bu$，$u$ 是單位，$a$ 和 $b$ 相伴 [▶ 28:30](https://youtu.be/1hBJQDzF-T4?t=1710)。
- 做法：取生成元的四個相伴元當作基本向量，在格點上畫出一個**基本區域**，數裡面有幾個不同的點，就是陪集的個數。這裡是 8 個。
- Gallian 是用一段段文字推（這個加那個得到哪個在理想裡），「也許裡面有演算法，我沒看出來」。老師是視覺型的人，喜歡這種圖：「我知道什麼時候算完。」

### 10. 環同態 $\mathbb{Z}_n\to\mathbb{Z}_n$（Ch.15 #8）[▶ 33:00](https://youtu.be/1hBJQDzF-T4?t=1980)

**證明：每個環同態都是 $\varphi(x) = ax$，且 $a^2 = a$。**
- $x = x\cdot1 = 1+1+\cdots+1$（重複相加）。加法版的同態性質：$\varphi(x\cdot1) = x\cdot\varphi(1)$。令 $a = \varphi(1)$：$\varphi(x) = ax$ [▶ 38:00](https://youtu.be/1hBJQDzF-T4?t=2280)。
- **$a$ 是冪等元**：$\varphi(1) = \varphi(1\cdot1) = \varphi(1)\varphi(1)$，所以 $a^2 = a$ [▶ 39:00](https://youtu.be/1hBJQDzF-T4?t=2340)。

> 💬 老師一度把 $x\cdot1$ 當成環裡的乘法，然後說「別讓我這樣蒙混過去——我剛說服你們別這樣想」[▶ 37:30](https://youtu.be/1hBJQDzF-T4?t=2250)。

**用法**：找所有環同態 $\Rightarrow$ 找所有冪等元。
- $p$ 質數：$\mathbb{Z}_p$ 是整環，冪等元只有 0、1，所以只有**零映射**和**恆等** [▶ 35:00](https://youtu.be/1hBJQDzF-T4?t=2100)。
- $\mathbb{Z}_8$（不是整環）：逐一試 $2^2 = 4$、$3^2 = 1$、$4^2 = 0$、$5^2 = 1$、$6^2 = 4$、$7^2 = 1$，都不等於自己。也只有 0、1 [▶ 41:00](https://youtu.be/1hBJQDzF-T4?t=2460)。
- $\mathbb{Z}_6$ 有更多（作業）。

**$\mathbb{Z}_{20}\to\mathbb{Z}_{30}$ 之類（Ch.15 #20）** [▶ 42:00](https://youtu.be/1hBJQDzF-T4?t=2520)：先看**加法群**同態（之前 #72：$\varphi(x) = mx$，需要 $k\mid mn$），那是可能性的範圍；再用乘法條件進一步篩選。

### 11. 環同態 $\mathbb{Z}\to\mathbb{Z}$（Ch.15 #21）[▶ 46:00](https://youtu.be/1hBJQDzF-T4?t=2760)

- 試 $\varphi(x) = nx$：加法沒問題；乘法要 $n(xy) = (nx)(ny)$ 對所有 $x,y$，即 $n = n^2$，$n = 0$ 或 $1$（學生指出 $-1$ 不行）[▶ 49:00](https://youtu.be/1hBJQDzF-T4?t=2940)。
- **為什麼沒有別的公式**：$\varphi(x) = \varphi(x\cdot1) = x\varphi(1)$（對負數也成立）[▶ 50:00](https://youtu.be/1hBJQDzF-T4?t=3000)。
- 答案：**零映射**和**恆等映射**。

**不能隨便推廣** [▶ 52:00](https://youtu.be/1hBJQDzF-T4?t=3120)：這招要求環裡的元素都能由 1 重複相加得到。矩陣環不行：$\varphi\begin{pmatrix}a&b\\c&d\end{pmatrix}$ 不是「某個整數乘 $\varphi(I)$」。

### 12. $(\mathbb{Z}\times\mathbb{Z})/(\langle a\rangle\times\langle b\rangle)\cong\mathbb{Z}_a\times\mathbb{Z}_b$（Ch.15 #26）[▶ 54:00](https://youtu.be/1hBJQDzF-T4?t=3240)

老師說「這題很好玩」（沒指定）。這種題幾乎一定用**第一同構定理**：找一個核正好是分母的同態 [▶ 55:00](https://youtu.be/1hBJQDzF-T4?t=3300)。
$$\varphi(x,y) = (x+a\mathbb{Z},\ y+b\mathbb{Z}).$$
- 定義在整數上，沒有良定義問題。
- 加法、乘法：陪集運算的性質（乘法 [▶ 57:00](https://youtu.be/1hBJQDzF-T4?t=3420)：$(x_1x_2+a\mathbb{Z},\ y_1y_2+b\mathbb{Z}) = (x_1+a\mathbb{Z},y_1+b\mathbb{Z})(x_2+a\mathbb{Z},y_2+b\mathbb{Z})$）。
- **核** [▶ 58:30](https://youtu.be/1hBJQDzF-T4?t=3510)：$x+a\mathbb{Z} = a\mathbb{Z}$ 且 $y+b\mathbb{Z} = b\mathbb{Z}$，即 $x\in\langle a\rangle$、$y\in\langle b\rangle$。所以 $\ker\varphi = \langle a\rangle\times\langle b\rangle$。
- 剩下滿射（顯然）——續見下一段影片。
