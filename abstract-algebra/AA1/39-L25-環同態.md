## 1. 更多理想與商環的例子

### 1.1 ⟨x, 2⟩ ⊆ ℤ[x]；可微函數不是理想

**$\langle x,2\rangle$**（講義 Ex 4.2.12）[▶ 01:00](https://youtu.be/0BRrFvdSWnU?t=60)「我想上次沒講到這個。」
- 元素：$xh(x)+2j(x)$。乘開、整理：**常數項是偶數**，其他係數任意。

【口頭】[▶ 02:00](https://youtu.be/0BRrFvdSWnU?t=120)「多項式環裡有各種有趣的理想。別小看多項式環，它們是故事的一大部分。希望星期一專心講**怎麼構造多項式**。我一直在借用你們高中代數的多項式操作，很快會更有系統。」

**可微函數**[▶ 02:30](https://youtu.be/0BRrFvdSWnU?t=150)：$\mathcal F(\mathbb{R},\mathbb{R})$ 用逐點運算是交換環。
- 【課堂討論】「可微函數的乘積可微嗎？」學生：「可以，**乘積法則**。」所以可微函數是**子環**。
- **不是理想**[▶ 03:30](https://youtu.be/0BRrFvdSWnU?t=210)：$f(x) = 1$ 可微（$f' = 0$）；$g(x) = |x|$ 是「典型的不可微函數，在 0 有個尖角」。$f\cdot g = |x|$ 不可微。
- 「這是**子環但不是理想**的例子。」

### 1.2 ℤ/3ℤ 和 2×2 矩陣模 2

**$\mathbb{Z}/3\mathbb{Z}$**（講義 Ex 4.2.15）[▶ 04:30](https://youtu.be/0BRrFvdSWnU?t=270)「一個有點蠢的商環例子。」
- 陪集 $3\mathbb{Z},\ 1+3\mathbb{Z},\ 2+3\mathbb{Z}$。寫出加法表和乘法表。
- 【口頭】「乘法表 0 那部分寫出來很蠢——聰明點畫個 $2\times2$ 小表就好。但寫出來有點**滿足感**，像在做你知道是對的事。也許那不是做事的好理由。」
- 模式就是 $\mathbb{Z}_3$——**字面上就是**：$\mathbb{Z}_3$ 就是這樣構造的，$[1]_3 = 1+3\mathbb{Z}$ [▶ 05:30](https://youtu.be/0BRrFvdSWnU?t=330)。「還好我不用這記號做模運算，每次 $x$ 都寫 $x+n\mathbb{Z}$ 會很快就煩了。」

**$\mathbb{Z}^{2\times2}/2\mathbb{Z}^{2\times2}$**（講義 Ex 4.2.16）[▶ 06:00](https://youtu.be/0BRrFvdSWnU?t=360)
- $A = 2\mathbb{Z}^{2\times2}$：元素都是偶數的矩陣。
- **理想**：差還是 2 乘整數矩陣；$X = 2X'$ 時 $XZ = 2(X'Z)\in A$。
- 【口頭】[▶ 07:30](https://youtu.be/0BRrFvdSWnU?t=450)「等等，這例子少了東西。理想判別法要**兩邊**：我只檢查了一半的超級封閉。我得修。」（$ZX = 2(ZX')$，「幾乎一樣」。）
- 【口頭】[▶ 07:00](https://youtu.be/0BRrFvdSWnU?t=420)「要小心乘的是 $A$ 的東西和 $R$ 的東西——你們有些人……好，傷口還太新鮮，我閉嘴。」（剛考完。）
- **幾個元素？**[▶ 08:00](https://youtu.be/0BRrFvdSWnU?t=480)「這通常比較煩。我**不能數** $R$——它是無限的。」代表元每格只能 0 或 1（2 就回到 0）：「基本上就是**二進位計數**」⇒ $2^4 = 16$ 個陪集。

### 1.3 ℤ[i]/⟨2−i⟩ 的格子圖

[▶ 09:30](https://youtu.be/0BRrFvdSWnU?t=570)「這個例子我花了點工夫，用跟 Gallian 不太一樣的方式給你們看。」（講義 Ex 4.2.17。）

**關鍵**[▶ 09:30](https://youtu.be/0BRrFvdSWnU?t=570)：$2-i\in\langle2-i\rangle$，所以
$$2+\langle2-i\rangle = i+\langle2-i\rangle,$$
在代表元層次 **$2\equiv i$**。「這給我們**巨大的簡化**。」

**圖**[▶ 11:00](https://youtu.be/0BRrFvdSWnU?t=660)
- 高斯整數是複平面上的格點（像 $\mathbb{Z}\times\mathbb{Z}$）。
- 模掉 $\langle2-i\rangle$，就是把**差一個理想元素**的格點連起來。例：0 加 2、減 $i$ ⇒ 到 $2-i$，跟 0 同陪集。
- 理想對乘法封閉，所以也可以走 $i(2-i) = 2i-i^2 = 1+2i$、$-(2-i)$、$-i(2-i) = -1-2i$ 這幾個方向 [▶ 12:00](https://youtu.be/0BRrFvdSWnU?t=720)。
- 所有連起來的點形成一個個**正方形**；畫陰影的那塊恰好含每個陪集一個代表：綠、紅、黃、粉紅、藍（藍色也是各角落的那個陪集）[▶ 13:30](https://youtu.be/0BRrFvdSWnU?t=810)。

**作業**[▶ 14:00](https://youtu.be/0BRrFvdSWnU?t=840)：$\mathbb{Z}[i]/\langle3-i\rangle$ 有幾個元素？可以用類似的圖。

【Q&A】[▶ 14:30](https://youtu.be/0BRrFvdSWnU?t=870) 學生問為什麼 $i(2-i)$ 也在理想裡。
- 老師先試：$2-i$ 在、$i-2$ 在、平方 $(2-i)^2 = 3-4i$ 也在……「我現在想不出怎麼講得有說服力。不難證，只是我腦袋一片空白。」
- 「我卡住的問題是：為什麼 $\pm i$ 乘上去也在理想裡？它**確實**在。而且這些是理想裡**最小**的元素，其他都更大——所以它們是格子的基本生成元。」
- 學生：「你說 $i$ 和 $-i$ 是單位？」老師：「也許是部分原因。我得往下走，下次開頭再解決。」

> 💬 答案其實就是理想的定義：$\langle2-i\rangle = \{(2-i)r : r\in\mathbb{Z}[i]\}$，$r$ 可以取 $\pm i$。

**結果**[▶ 17:30](https://youtu.be/0BRrFvdSWnU?t=1050)：$\mathbb{Z}[i]/\langle2-i\rangle = \{[0],[1],[2],[3],[4]\}$（實軸上 0、1、2、3、4，再過去就回來了）。（字幕說「這四個陪集」，但列出的是五個。）「這張圖 Gallian 沒有，是我加的。我的經驗是這樣想很有用。」

> 📘 筆記補充：$\mathbb{Z}[i]/\langle2-i\rangle\cong\mathbb{Z}_5$；陪集個數 $= 2^2+1^2 = 5$（$a+bi$ 生成的主理想，商的大小是 $a^2+b^2$）。

### 1.4 ℝ[x]/⟨x²+1⟩ 再看一次

[▶ 18:00](https://youtu.be/0BRrFvdSWnU?t=1080)（講義 Ex 4.2.18）
- $x^2 = (x^2+1)-1\equiv-1$。
- 例：$1+2x+x^4+x^2$：$x^4 = (x^2)^2\equiv1$，$x^2\equiv-1$，相消 ⇒ $\equiv1+2x$ [▶ 19:00](https://youtu.be/0BRrFvdSWnU?t=1140)。
- **更貪心**：任何 $f$ 用除法算法除以 $x^2+1$：
$$f(x) = q(x)(x^2+1)+(ax+b)\ ⇒\ f\equiv ax+b.$$
- 所以商環的元素都是 $a+bx+\langle x^2+1\rangle$；相乘時 $x^2\equiv-1$ 給出跟 $(a+bi)(c+di)$ 一樣的規則 [▶ 20:00](https://youtu.be/0BRrFvdSWnU?t=1200)。「$x$ 的行為就像虛數單位。」

## 2. ⟨x²+1⟩ 是極大理想

[▶ 21:00](https://youtu.be/0BRrFvdSWnU?t=1260) 先回顧定義（「上次我打了些可怕的錯字——或你們決定那不是錯字，隨你們」）：
- **質理想**：$ab\in A$ ⇒ $a\in A$ 或 $b\in A$。
  - 【口頭】[▶ 21:30](https://youtu.be/0BRrFvdSWnU?t=1290)「如果修過我的**數論**，我們用很不一樣的方式定義質理想，然後發現這是等價的。這個比較好用。」
- **極大理想**：夾在 $A$ 和 $R$ 之間的理想只能是 $A$ 或 $R$。

> **命題**（講義 Ex 4.3.4；Gallian Example 15）　$\langle x^2+1\rangle$ 是 $\mathbb{R}[x]$ 的極大理想。

**證明**[▶ 22:30](https://youtu.be/0BRrFvdSWnU?t=1350)：設 $A$ 是理想，$\langle x^2+1\rangle\subseteq A\subseteq\mathbb{R}[x]$，$A\neq\langle x^2+1\rangle$。要證 $A = \mathbb{R}[x]$。

1. 取 $f\in A$，$f\notin\langle x^2+1\rangle$。除法算法：$f = q(x^2+1)+(ax+b)$，**餘式非零**（否則 $f$ 在理想裡）[▶ 23:30](https://youtu.be/0BRrFvdSWnU?t=1410)。
2. $ax+b = f-q(x^2+1)$：$f\in A$、$q(x^2+1)\in\langle x^2+1\rangle\subseteq A$ ⇒ $ax+b\in A$。
3. $A$ 是理想 ⇒ $(ax+b)(ax-b) = a^2x^2-b^2\in A$ [▶ 24:30](https://youtu.be/0BRrFvdSWnU?t=1470)。（「乘積 produce——」全班笑。）
4. 又 $a^2(x^2+1)\in A$。相減：
$$a^2(x^2+1)-(a^2x^2-b^2) = a^2+b^2\in A.$$
   $a,b$ 不全為 0 ⇒ $a^2+b^2$ 是**非零實數** [▶ 25:30](https://youtu.be/0BRrFvdSWnU?t=1530)。「**非常狡猾的論證**——看它們消掉了。」
5. $1 = \dfrac{1}{a^2+b^2}\cdot(a^2+b^2)\in A$ [▶ 26:00](https://youtu.be/0BRrFvdSWnU?t=1560)。
6. $1\in A$ ⇒ $A\supseteq\langle1\rangle = \mathbb{R}[x]$。$\blacksquare$

> **關鍵引理**[▶ 26:30](https://youtu.be/0BRrFvdSWnU?t=1590)　有單位元的環中，**理想含 1 就是整個環**：$r = r\cdot1\in A$。「這是好幾個重要證明背後的**驅動力**。」

【口頭】[▶ 27:00](https://youtu.be/0BRrFvdSWnU?t=1620)「我覺得這個論證相當聰明——比我給你們看的大部分東西都聰明。它有某種真正**狡猾**的地方。」

## 3. R/A 是體 ⟺ A 極大

[▶ 27:30](https://youtu.be/0BRrFvdSWnU?t=1650) 先回顧上次證的：$R/A$ 整環 $\iff$ $A$ 質理想（「這節課還會用」）。

> **定理**（講義 Thm 4.3.7）　$R$ 有單位元的交換環，$A$ 是理想。$R/A$ 是體 $\iff$ $A$ 是極大理想。

**先注意**[▶ 28:30](https://youtu.be/0BRrFvdSWnU?t=1710)：$1+A$ 是 $R/A$ 的單位元：$(1+A)(r+A) = r+A$。
- 【口頭】「這大概該是講義前面的一個引理。抱歉，**時間旅行對我不可用**。我不是 NBC 那部製作粗糙、快被砍的影集。」
- （離題 [▶ 29:30](https://youtu.be/0BRrFvdSWnU?t=1770)：老師打電話問父親世界大賽——**小熊隊**幾乎要封王了——父母說：「我們沒電視，在 Netflix 看 *The Blacklist*。」「很怪。」「你們不看電視？很好。」）

**(⇒) 設 $R/A$ 是體**[▶ 30:00](https://youtu.be/0BRrFvdSWnU?t=1800)：設 $B$ 是理想，$A\subseteq B\subseteq R$，$B\neq A$。要證 $B = R$。
1. 取 $x\in B$、$x\notin A$。則 $x+A\neq0$，體 ⇒ 有 $y+A$ 使
$$(x+A)(y+A) = 1+A\iff xy+A = 1+A\iff1-xy\in A.$$
2. $x\in B$、$B$ 是理想 ⇒ $xy\in B$ [▶ 31:00](https://youtu.be/0BRrFvdSWnU?t=1860)。
3. $A\subseteq B$ ⇒ $1-xy\in B$。
4. $1 = xy+(1-xy)\in B$ ⇒ $B = R$。「我們**剛做完**的那個例子——一旦理想裡有 1，它就是整個環。」✓

**(⇐) 設 $A$ 極大**[▶ 32:00](https://youtu.be/0BRrFvdSWnU?t=1920)：取 $x\notin A$（$x+A\neq0$），要找它的反元素。
1. 造 $B = xR+A = \{xr+a : r\in R,\ a\in A\}$。**$B$ 是理想**——「留給讀者驗證，不難。」
2. $a\in A$ ⇒ $a = x\cdot0+a\in B$，所以 $A\subseteq B$。又 $x = x\cdot1+0\in B$、$x\notin A$ ⇒ $B\neq A$。
3. $A$ 極大 ⇒ $B = R$ ⇒ $1\in B$ [▶ 33:30](https://youtu.be/0BRrFvdSWnU?t=2010)：$1 = xr+a$，即 $1-xr\in A$。
4. 所以 $(x+A)(r+A) = 1+A$，$x+A$ 可逆。
5. 剩下：$1+A$ 是單位元；$R$ 交換 ⇒ $R/A$ 交換 [▶ 34:30](https://youtu.be/0BRrFvdSWnU?t=2070)。所以 $R/A$ 是體。$\blacksquare$

【口頭】[▶ 35:00](https://youtu.be/0BRrFvdSWnU?t=2100)「這證明不難，但**很難講出來**。」

## 4. 極大 ⇒ 質，反之不然

[▶ 35:00](https://youtu.be/0BRrFvdSWnU?t=2100)（講義 Ex 4.3.8）「這個例子重要，主要是因為我們在這講最後會用**更簡單的論證**重做它。我們先短暫受苦一下。」

- 體 ⇒ 整環。所以 $A$ 極大 ⇒ $R/A$ 體 ⇒ $R/A$ 整環 ⇒ $A$ 質。
- **反之不然**[▶ 36:00](https://youtu.be/0BRrFvdSWnU?t=2160)：$\langle x\rangle\subseteq\mathbb{Z}[x]$ 是質理想（講義有小論證），但**不極大**：
  - $2\in\langle x,2\rangle$、$2\notin\langle x\rangle$ ⇒ $\langle x\rangle\subsetneq\langle x,2\rangle$。
  - $\langle x,2\rangle\neq\mathbb{Z}[x]$：常數項奇數的多項式不在裡面。

## 5. 環同態

[▶ 37:00](https://youtu.be/0BRrFvdSWnU?t=2220)「這就到了 lecture 24。其實內容不多——**似曾相識**。」

> **定義（環同態 ring homomorphism）**（講義 Def 4.4.1）　$\varphi:R\to S$ 滿足
> $$\varphi(a+b) = \varphi(a)+\varphi(b),\qquad\varphi(ab) = \varphi(a)\varphi(b).$$
> **環同構**：雙射的環同態。記 $R\cong S$。

【口頭】[▶ 37:30](https://youtu.be/0BRrFvdSWnU?t=2250)「因為你們不讓我有好東西，『同態的』沒有記號——我本來要修的，但你們不讓。」學生：「子環也沒有記號。」老師：「對，只能用文字。抱歉。」

**例子**
1. **自然同態**（講義 Ex 4.4.2）[▶ 38:00](https://youtu.be/0BRrFvdSWnU?t=2280)：$\mathbb{Z}\to\mathbb{Z}_n$，$x\mapsto[x]_n = x+n\mathbb{Z}$——也叫**陪集映射**。
2. **複數共軛**（講義 Ex 4.4.3）[▶ 38:30](https://youtu.be/0BRrFvdSWnU?t=2310)：$\overline{zw} = \bar z\bar w$、$\overline{z+w} = \bar z+\bar w$。是自己的反函數 ⇒ $\mathbb{C}$ 的**自同構**，2 階。「這會是今天大部分內容中很受歡迎的喘息——簡單得要命。」「抱歉，又在很新鮮的傷口上撒鹽。」
3. **代值同態**（講義 Ex 4.4.4）[▶ 39:30](https://youtu.be/0BRrFvdSWnU?t=2370)：「一種**超級例子**。」$R$ 交換，$c\in R$：
$$\varphi_c:R[x]\to R,\quad\varphi_c(f) = f(c).$$
   逐點加法、乘法 ⇒ 同態。「看起來很簡單，其實**很重要**，之後的章節用很多。」

**性質**（講義 Thm 4.4.5）[▶ 40:30](https://youtu.be/0BRrFvdSWnU?t=2430)：
1. $\varphi(na) = n\varphi(a)$、$\varphi(a^n) = \varphi(a)^n$（加法、乘法的指數律）。**沒有**反元素律——環裡反元素不一定存在。
2. 子環的像是子環。
3. **理想的像是理想**（若 $\varphi$ 映成）。
4. 理想的原像是理想。
5. $R$ 交換 ⇒ $\varphi(R)$ 交換。
6. $R$ 有 1、$S\neq\{0\}$、**$\varphi$ 映成** ⇒ $\varphi(1)$ 是 $S$ 的單位元。
   - 【口頭】[▶ 41:30](https://youtu.be/0BRrFvdSWnU?t=2490)「我們找過違反這條的例子（$2\mathbb{Z}_6$ 的單位元是 4）。某種意義上那裡**缺了滿射**。我該回去看那個例子，試著把它連到這個概念——我現在才想到。」
7. $\varphi$ 同構 $\iff$ 映成且 $\ker\varphi = \{0\}$。核是**加法**的核：「環首先是加法群，加法群知道的一切對環的加法結構都對。」
8. $\varphi$ 同構 ⇒ $\varphi^{-1}$ 也是同構。「線性代數也有：線性的雙射，反函數自動線性。」

## 6. 核是理想、環的第一同構定理

> **定理**（講義 Thm 4.4.6）[▶ 43:00](https://youtu.be/0BRrFvdSWnU?t=2580)　$\varphi:R\to S$ 環同態 ⇒ $\ker\varphi$ 是 $R$ 的**理想**。

「Gallian 大多說『跟之前的證明一樣』。我覺得至少給一個證明好——而且這很重要，**考試考過**。」

**證明**（理想判別法）
- $a,b\in\ker\varphi$：$\varphi(a-b) = 0-0 = 0$。
- $r\in R$、$a\in\ker\varphi$ [▶ 43:30](https://youtu.be/0BRrFvdSWnU?t=2610)：
$$\varphi(ra) = \varphi(r)\varphi(a) = \varphi(r)0 = 0,\qquad\varphi(ar) = 0\cdot\varphi(r) = 0.$$
  （「看，我發現理想判別法要**兩邊**了。好樣的。」上次證過任何東西乘 0 是 0。）$\blacksquare$

【口頭】[▶ 44:00](https://youtu.be/0BRrFvdSWnU?t=2640)「我忍住沒說『我們已經知道核是加法意義下的正規子群』。我可以那樣說，但我覺得看一個**獨立的證明**比較健康。」

> **定理（環的第一同構定理）**（講義 Thm 4.4.7）[▶ 44:30](https://youtu.be/0BRrFvdSWnU?t=2670)
> $$R/\ker\varphi\cong\varphi(R),\qquad r+\ker\varphi\mapsto\varphi(r).$$

「精神完全一樣。」

> **定理**（講義 Thm 4.4.8）[▶ 45:00](https://youtu.be/0BRrFvdSWnU?t=2700)　每個理想都是某個環同態的核（$r\mapsto r+A$）。

「一個有點蠢的定理。我甚至寫了證明，讓你們自己讀，我不覺得那麼刺激。」

**用第一同構定理重做 §4**（講義 Ex 4.4.9）[▶ 46:00](https://youtu.be/0BRrFvdSWnU?t=2760)

「我**埋了重點**——這個例子很酷。記得十分鐘前那些討厭的細節嗎？看它們怎麼**被沖走**。」

- $\varphi:\mathbb{Z}[x]\to\mathbb{Z}$，$\varphi(f) = f(0)$（在 0 代值）。滿射環同態。
- $\ker\varphi = \langle x\rangle$：$f(0) = 0$ ⇒ 由高中的**因式定理**提出 $x$。
- 第一同構定理：
$$\mathbb{Z}[x]/\langle x\rangle\cong\mathbb{Z}.$$
- $\mathbb{Z}$ 是整環 ⇒ $\langle x\rangle$ **質**；$\mathbb{Z}$ 不是體 ⇒ $\langle x\rangle$ **不極大**。
- 「這比找出夾在中間的 $\langle x,2\rangle$ 簡單得多。**兩種方法你們都該懂。**」

## 7. n ↦ n·1 與 Steinitz 定理

> **定理**（講義 Thm 4.4.10）[▶ 48:00](https://youtu.be/0BRrFvdSWnU?t=2880)　$R$ 有單位元 ⇒ $\varphi:\mathbb{Z}\to R$，$\varphi(n) = n\cdot1 = 1+1+\cdots+1$ 是環同態。

證明在 Gallian p.274–275，「討厭的細節，大概該講」：歸結到 $(m+n)\cdot1 = m\cdot1+n\cdot1$、$(mn)\cdot1 = (m\cdot1)(n\cdot1)$。

**推論**
- **Cor 4.4.11**[▶ 49:00](https://youtu.be/0BRrFvdSWnU?t=2940)：$\operatorname{char}R = n>0$ ⇒ $R$ 含同構於 $\mathbb{Z}_n$ 的子環；$\operatorname{char}R = 0$ ⇒ $R$ 含同構於 $\mathbb{Z}$ 的子環。「非常非常漂亮的一般陳述。」
- **Cor 4.4.12**：$\mathbb{Z}\to\mathbb{Z}_m$，$x\mapsto[x]_m$ 是環同態。「我對這個**一點也不興奮**，很尷尬我剛剛唸給你們聽。」
- **Cor 4.4.13（Steinitz，1910）**[▶ 49:30](https://youtu.be/0BRrFvdSWnU?t=2970)：
  - 特徵 $p$ 的體含同構於 $\mathbb{Z}_p$ 的子體；
  - 特徵 0 的體含同構於 $\mathbb{Q}$ 的子體。

【口頭】[▶ 50:00](https://youtu.be/0BRrFvdSWnU?t=3000)「這就是**真的東西**了。給我完全一般的體——我們證過特徵只能是 0 或質數——所以這講的是**所有可能的體**：特徵 $p$ 的裡面有一份 $\mathbb{Z}_p$；特徵 0 的裡面坐著一份 $\mathbb{Q}$。很酷的結果。」

**預告：分式體**（講義 Thm 4.4.15）[▶ 50:30](https://youtu.be/0BRrFvdSWnU?t=3030)
- $D$ 是整環 ⇒ 存在一個體，含有同構於 $D$ 的子環。
- 整環裡有不可逆的元素，例如 $\mathbb{Z}$ 的 2——反元素 $1/2$ 不在裡面。
- 「就像怎麼**從整數造出有理數**，或更一般地，從任何整環造出包含它的體。我覺得這是**這學期最有趣、最美的構造之一**。下次做。」

## 8. 一頁速查表

### 8.1 商環例子

| 商環 | 結果 | 關鍵一步 |
|---|---|---|
| $\mathbb{Z}/3\mathbb{Z}$ | $= \mathbb{Z}_3$ | 定義就是這樣 |
| $\mathbb{Z}^{2\times2}/2\mathbb{Z}^{2\times2}$ | 16 個元素 | 每格 0 或 1 |
| $\mathbb{Z}[i]/\langle2-i\rangle$ | 5 個元素（$\cong\mathbb{Z}_5$） | $2\equiv i$ |
| $\mathbb{R}[x]/\langle x^2+1\rangle$ | $\cong\mathbb{C}$ | 餘式 $ax+b$，$x^2\equiv-1$ |
| $\mathbb{Z}[x]/\langle x\rangle$ | $\cong\mathbb{Z}$ | $f\mapsto f(0)$ |

**子環但非理想**：可微函數（$1\cdot|x|$）。

### 8.2 理想的三個定理

| 定理 | 證明關鍵一步 |
|---|---|
| 理想含 1 ⇒ 是整個環 | $r = r\cdot1$ |
| $\langle x^2+1\rangle$ 在 $\mathbb{R}[x]$ 極大 | $a^2(x^2+1)-(ax+b)(ax-b) = a^2+b^2$ |
| $R/A$ 體 $\iff A$ 極大 | (⇒) $1 = xy+(1-xy)\in B$；(⇐) $B = xR+A = R$ |

**極大 ⇒ 質**；$\langle x\rangle\subseteq\mathbb{Z}[x]$ 質而不極大。

### 8.3 環同態

| 事實 | 內容 |
|---|---|
| 定義 | 保持 $+$ 和 $\times$ |
| 例子 | $\mathbb{Z}\to\mathbb{Z}_n$；共軛；代值 $f\mapsto f(c)$ |
| 核 | 是理想 |
| 第一同構定理 | $R/\ker\varphi\cong\varphi(R)$ |
| $\varphi(1) = 1_S$ | 需要**映成** |
| $n\mapsto n\cdot1$ | ⇒ 特徵 $n$ 含 $\mathbb{Z}_n$，特徵 0 含 $\mathbb{Z}$ |
| Steinitz | 體含 $\mathbb{Z}_p$ 或 $\mathbb{Q}$ |

### 8.4 術語

| 中文 | English |
|---|---|
| 環同態；環同構 | ring homomorphism; ring isomorphism |
| 自然同態（陪集映射） | natural homomorphism (coset map) |
| 代值同態 | evaluation homomorphism |
| 環的第一同構定理 | First Isomorphism Theorem for rings |
| 質子體 | prime subfield |
| 分式體 | field of fractions / field of quotients |
