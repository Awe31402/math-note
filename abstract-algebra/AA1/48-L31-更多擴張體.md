## 1. 單擴張的基底（證明）

> **定理**（Fraleigh Thm 29.18；講義 Thm 4.9.26）[▶ 01:00](https://youtu.be/gWtF0EpNX04?t=60)　$E = F(\alpha)$，$\alpha$ 在 $F$ 上代數，$\deg\operatorname{irr}(\alpha,F) = n\ge1$。則每個 $\beta\in E$ **唯一**寫成
> $$\beta = b_0+b_1\alpha+\cdots+b_{n-1}\alpha^{n-1},\quad b_i\in F.$$

「我覺得這個證明值得講，它讓你們對我們在做的事有更好的**計算感**。」

### 1.1 存在：用 α 的關係一直往下化

[▶ 03:30](https://youtu.be/gWtF0EpNX04?t=210)
- $F(\alpha) = \varphi_\alpha(F[x])$：代值同態的像。$\varphi_\alpha(c_0+c_1x+\cdots+c_kx^k) = c_0+c_1\alpha+\cdots+c_k\alpha^k$。「主要是提醒記號。」
- $\operatorname{irr}(\alpha,F) = p(x) = x^n+a_{n-1}x^{n-1}+\cdots+a_0$（首一）[▶ 05:30](https://youtu.be/gWtF0EpNX04?t=330)。$p(\alpha) = 0$ ⇒ **解出 $\alpha^n$**：
$$\alpha^n = -a_{n-1}\alpha^{n-1}-\cdots-a_1\alpha-a_0.\quad(\star)$$
- **宣稱**：任何 $\alpha^m$（$m\ge n$）都能用 $(\star)$ 代換，化成 $1,\alpha,\dots,\alpha^{n-1}$ 的 $F$-線性組合 [▶ 07:00](https://youtu.be/gWtF0EpNX04?t=420)。
- **例 $\alpha^{n+1}$**[▶ 07:30](https://youtu.be/gWtF0EpNX04?t=450)：$\alpha^{n+1} = \alpha\cdot\alpha^n = -a_{n-1}\alpha^n-a_{n-2}\alpha^{n-1}-\cdots-a_0\alpha$。
  - 「喔，還不是我要的——**沒錯，只是還沒做完**。」還有 $\alpha^n$。
  - 【課堂討論】「然後呢？」學生：「再代換一次。」「正是。不漂亮，但做得到。」
  - 整理（「為了好玩」）[▶ 10:00](https://youtu.be/gWtF0EpNX04?t=600)：
$$\alpha^{n+1} = (a_{n-1}^2-a_{n-2})\alpha^{n-1}+(a_{n-1}a_{n-2}-a_{n-3})\alpha^{n-2}+\cdots+(a_{n-1}a_1-a_0)\alpha+a_{n-1}a_0.$$
- 「要正式證明，大概該用**歸納法**：假設某個冪能寫成線性組合，證明高一次也行——用歸納假設加上這種代換。我不打算在這裡做，這應該夠你們看出怎麼走。」

### 1.2 唯一：最小多項式的最小性

[▶ 12:00](https://youtu.be/gWtF0EpNX04?t=720)「唯一性**很重要**，我們走一遍。」

設 $\beta = \sum_{i<n}b_i\alpha^i = \sum_{i<n}b'_i\alpha^i$。目標：係數相同。

【口頭】[▶ 13:00](https://youtu.be/gWtF0EpNX04?t=780)「好笑的是，答疑課 Nicole 問的第 12 題——證明 $\mathbb{Z}_p[x]$ 模不可約多項式有那麼多元素——**本質上就是這個**，只是針對那個例子。那個例子麻煩的原因，跟這個一般證明麻煩的原因一樣，難度差不多。」

1. 定義（「我可以這樣做，你們阻止不了我，太遲了，我已經做了」）[▶ 14:00](https://youtu.be/gWtF0EpNX04?t=840)：
$$g(x) = (b_0-b'_0)+(b_1-b'_1)x+\cdots+(b_{n-1}-b'_{n-1})x^{n-1}.$$
2. 兩個表示相減：$g(\alpha) = 0$。
3. $\deg g\le n-1$ [▶ 15:30](https://youtu.be/gWtF0EpNX04?t=930)。「**這對 $p(x)$ 來說非常尷尬**」（「我不會拼 embarrassing」）：$p$ 是殺掉 $\alpha$ 的**次數最小的非零**多項式，次數是 $n$。
4. 所以 $g$ 必須是**零多項式**——零多項式代任何數都是 0 [▶ 16:30](https://youtu.be/gWtF0EpNX04?t=990)。
5. 所有係數為 0 ⇒ $b_i = b'_i$。$\blacksquare$

**推論**[▶ 17:00](https://youtu.be/gWtF0EpNX04?t=1020)：「線性組合的係數唯一，這說明元素怎樣？」——**線性獨立**（「比較係數性質」是線性獨立的等價刻劃之一）。所以
$$\{1,\alpha,\alpha^2,\dots,\alpha^{n-1}\}\text{ 是 }F(\alpha)\text{ 在 }F\text{ 上的基底，}\ F(\alpha)\text{ 是 }n\text{ 維向量空間}.$$

被擴張的體 $F$ 叫**基礎體（base field）**[▶ 18:00](https://youtu.be/gWtF0EpNX04?t=1080)。

【Q&A】[▶ 18:30](https://youtu.be/gWtF0EpNX04?t=1110) 學生問 $g = 0$ 那步。
- 老師：「若 $g$ 非零，它就是一個**次數比 $p$ 小**又殺掉 $\alpha$ 的多項式。這跟不可約多項式的定義矛盾：它是把 $\alpha$ 餵進代值同態後**歸零的次數最小**的首一多項式。」
- 「$p$ 的**存在**是我上次沒證的定理——發的講義裡有**血淋淋**的細節，我要加一句：**看得懂的**血淋淋細節。也許假期後週一講。我講或不講那個證明，都不會讓你們作業做得**更好**——不會讓你們的理解**更巨大（bigly）**。」（全班笑。）「今天想給你們一些**巨大**的例子，真正大聯盟的數學。抱歉，我閉嘴。」

**作業安排**[▶ 20:00](https://youtu.be/gWtF0EpNX04?t=1200)：從這兩節出題，「後面的題很好，有些**非常非常簡單**」。截止日放在假期後的**週三**而不是週一：「面對現實：你們今天在這裡的人，有很高機率至少一兩個人**計畫**假期後週一缺席。我們少了大約五個人。」學生：「今天也是**退選最後一天**。」老師：「喔天啊。**請不要這樣說。**」

## 2. 有限擴張與次數 [E:F]

> **定義（有限擴張 finite extension）**（講義 Def 4.10.2）[▶ 21:30](https://youtu.be/gWtF0EpNX04?t=1290)　擴張體 $E$ 作為 $F$-向量空間是有限維 $n$，就說 $E$ 是 $F$ 的 **$n$ 次有限擴張**，記
> $$[E:F] = n.$$

「你們說：這記號我們用過，意思不一樣。對。但在這裡它是個好意思。」

**例**[▶ 23:00](https://youtu.be/gWtF0EpNX04?t=1380)
- $[\mathbb{C}:\mathbb{R}] = 2$。
- $[\mathbb{Q}(\sqrt2):\mathbb{Q}] = 2$。
- $[\mathbb{Q}(\sqrt[3]2):\mathbb{Q}] = 3$。

## 3. 有限擴張是代數擴張

> **定義（代數擴張 algebraic extension）**（講義 Def 4.10.1）[▶ 25:00](https://youtu.be/gWtF0EpNX04?t=1500)　$E$ 的**每個元素**都在 $F$ 上代數。

（老師先說錯兩次：「每個 $F$ 的元素……我還是沒說對。等一下。」「這是這節的**第一個定義**，我沒寫下來，現在付出代價。」）

> **定理**（講義 Thm 4.10.3）[▶ 24:00](https://youtu.be/gWtF0EpNX04?t=1440)　有限擴張是代數擴張。

**證明**[▶ 26:00](https://youtu.be/gWtF0EpNX04?t=1560)：$[E:F] = n$，取 $\alpha\in E$。
- 考慮 $1,\alpha,\alpha^2,\dots,\alpha^n$——**$n+1$ 個**元素在 $n$ 維空間裡 ⇒ **線性相依**。
- 線性相依 = 一個**非平凡**的線性組合等於 0：
$$c_0+c_1\alpha+\cdots+c_n\alpha^n = 0,\quad c_i\in F\text{ 不全為 }0.$$
- 所以 $p(x) = c_nx^n+\cdots+c_1x+c_0\in F[x]$ 非零、$p(\alpha) = 0$ ⇒ $\alpha$ 在 $F$ 上代數。$\blacksquare$

## 4. 次數乘法公式

> **定理**（Fraleigh Thm 31.4；講義 Thm 4.10.4）[▶ 29:30](https://youtu.be/gWtF0EpNX04?t=1770)　$E$ 是 $F$ 的有限擴張，$K$ 是 $E$ 的有限擴張。則 $K$ 是 $F$ 的有限擴張，而且
> $$[K:F] = [K:E]\,[E:F].$$

「這個公式會**很眼熟**，雖然是新的。**擴張的擴張，維數相乘。**」（「我本來想讓字母反過來連，但我是白痴。」）

**圖**[▶ 31:30](https://youtu.be/gWtF0EpNX04?t=1890)：「這張圖差不多就是證明。」

```
   K
   |   基底 β₁,…,βₘ（[K:E] = m）
   E
   |   基底 α₁,…,αₙ（[E:F] = n）
   F
```

忽略中間，$K$ 在 $F$ 上的基底就用**兩兩乘積** $\alpha_i\beta_j$，共 $mn$ 個。

### 4.1 例：ℚ(√2, ∛2) = ℚ(2^{1/6})

[▶ 33:00](https://youtu.be/gWtF0EpNX04?t=1980)「證明之前先看個具體例子。」

$F = \mathbb{Q}$，$E = \mathbb{Q}(\sqrt2)$，$K = \mathbb{Q}(\sqrt2)(\sqrt[3]2)$。（老師先說「立方根 3」，改成「立方根 2」。）

- $E = \{a+b\sqrt2 : a,b\in\mathbb{Q}\}$，$[E:\mathbb{Q}] = 2$。
- $K$ 的元素 [▶ 35:00](https://youtu.be/gWtF0EpNX04?t=2100)：「我需要一個中間記號——**小精靈 1、2、3**，抱歉」：
$$\text{小精靈}_1+\text{小精靈}_2\sqrt[3]2+\text{小精靈}_3(\sqrt[3]2)^2,\quad\text{小精靈}_i\in\mathbb{Q}(\sqrt2).$$
- **$[K:E] = 3$**[▶ 35:30](https://youtu.be/gWtF0EpNX04?t=2130)：$\gamma = \sqrt[3]2$，$\gamma^3 = 2$；$x^3-2$ 由 Eisenstein 不可約。用上面的定理：元素是 $1,\gamma,\gamma^2$ 的組合。

> 📘 筆記補充：嚴格說，$[K:E] = 3$ 需要 $x^3-2$ 在 **$E = \mathbb{Q}(\sqrt2)$ 上**不可約（Eisenstein 只給在 $\mathbb{Q}$ 上）。可以用次數論證：若 $\sqrt[3]2\in E$，則 $3 = [\mathbb{Q}(\sqrt[3]2):\mathbb{Q}]$ 整除 $[E:\mathbb{Q}] = 2$，矛盾——這正是課末留的問題（§5）。

（插曲 [▶ 36:30](https://youtu.be/gWtF0EpNX04?t=2190)：有同學離開說「假期愉快」。「你也是。——白痴們。」「我差點覺得自己像白痴，好像我的麥克風開著。每次我說白痴，都會懷疑我那一刻在做什麼白痴的事——因為我相信**反諷**。」）

**展開**[▶ 37:00](https://youtu.be/gWtF0EpNX04?t=2220)：每個小精靈是 $c+c'\sqrt2$，所以
$$c_1+c_2\sqrt2+(c_3+c_4\sqrt2)\sqrt[3]2+(c_5+c_6\sqrt2)(\sqrt[3]2)^2,\quad c_i\in\mathbb{Q}.$$
6 個係數。

【課堂討論】[▶ 37:30](https://youtu.be/gWtF0EpNX04?t=2250) 看指數：
- $\sqrt2 = 2^{1/2}$、$\sqrt[3]2 = 2^{1/3}$、$(\sqrt[3]2)^2 = 2^{2/3}$。
- 學生：「這個是 $5/6$。」（$\sqrt2\sqrt[3]2 = 2^{1/2+1/3}$。）老師：「那個呢？……那是 $7/6$。」（$\sqrt2(\sqrt[3]2)^2 = 2^{7/6} = 2\cdot2^{1/6}$。）「你說得對，我沒反對——別把我的沉默當成不同意。我在想別的事。」
- 全都是 $2^{1/6}$ 的冪的有理組合 [▶ 39:00](https://youtu.be/gWtF0EpNX04?t=2340)：
$$K = \{b_0+b_1\,2^{1/6}+b_2\,2^{2/6}+\cdots+b_5\,2^{5/6} : b_i\in\mathbb{Q}\} = \mathbb{Q}(2^{1/6}).$$

「我們剛發現：**它其實是單擴張**，雖然是用雙重擴張造出來的。」

**計數**[▶ 41:00](https://youtu.be/gWtF0EpNX04?t=2460)：$[K:E][E:\mathbb{Q}] = 3\cdot2 = 6$，正是 $\mathbb{Q}(2^{1/6})$ 的維數。

### 4.2 本原元素定理

【Q&A】[▶ 40:30](https://youtu.be/gWtF0EpNX04?t=2430) 學生：「是不是總能找到對應的單擴張？」
- 老師：「好問題。Nathan，查一下第 21 章左右 **Steinitz** 的定理。」
- 學生唸出：

> **本原元素定理（Primitive Element Theorem）**（Steinitz，1910；講義 Thm 4.10.10）　$F$ 特徵 0，$a,b$ 在 $F$ 上代數 ⇒ 存在 $c\in F(a,b)$ 使 $F(a,b) = F(c)$。

- 老師：「所以在**特徵 0** 的情況，答案是**是**：任何有限擴張都能改寫成單擴張，只要選對元素——那叫**本原元素**。你會好奇特徵不是 0 呢？我們這裡基礎體是 $\mathbb{Q}$，特徵 0，所以在對的脈絡裡。」

### 4.3 證明：基底兩兩相乘

[▶ 42:00](https://youtu.be/gWtF0EpNX04?t=2520)「這個定理的證明差不多就是剛才的例子。」

設 $\alpha_1,\dots,\alpha_n$ 是 $E$ 在 $F$ 上的基底，$\beta_1,\dots,\beta_m$ 是 $K$ 在 $E$ 上的基底。**目標**：$\{\alpha_i\beta_j\}$ 是 $K$ 在 $F$ 上的基底。

**生成**[▶ 43:30](https://youtu.be/gWtF0EpNX04?t=2610)
- $\gamma\in K$ ⇒ $\gamma = \sum_jb_j\beta_j$，$b_j\in E$。
- 每個 $b_j\in E = \operatorname{span}_F\{\alpha_i\}$ ⇒ $b_j = \sum_ic_{ij}\alpha_i$，$c_{ij}\in F$。
- 代入：
$$\gamma = \sum_j\sum_ic_{ij}\alpha_i\beta_j.$$
- 【口頭】[▶ 46:00](https://youtu.be/gWtF0EpNX04?t=2760)「我都忘了**我有多愛線性代數**。」

**線性獨立**[▶ 46:30](https://youtu.be/gWtF0EpNX04?t=2790)
- 設 $\sum_{i,j}c_{ij}\alpha_i\beta_j = 0$，$c_{ij}\in F$。改寫成
$$\sum_j\left(\sum_ic_{ij}\alpha_i\right)\beta_j = 0.$$
- 括號是 $E$ 的元素；$\beta_j$ 在 $E$ 上線性獨立 ⇒ 每個括號 $= 0$。
- $\alpha_i$ 在 $F$ 上線性獨立 ⇒ 每個 $c_{ij} = 0$ [▶ 48:00](https://youtu.be/gWtF0EpNX04?t=2880)。
- 「線性獨立是**兩組基底都線性獨立**串起來的結果。」$\blacksquare$

所以 $[K:F] = mn$。

## 6. 一頁速查表

### 6.1 單擴張

| 事實 | 關鍵一步 |
|---|---|
| 每個 $\beta\in F(\alpha)$ 是 $1,\dots,\alpha^{n-1}$ 的組合 | $\alpha^n = -a_{n-1}\alpha^{n-1}-\cdots-a_0$ 一直代換 |
| 表示唯一 | $g(\alpha) = 0$、$\deg g<n$ ⇒ $g = 0$（$\operatorname{irr}$ 最小） |
| $[F(\alpha):F] = \deg(\alpha,F)$ | 基底 $1,\alpha,\dots,\alpha^{n-1}$ |

### 6.2 有限擴張

| 定理 | 關鍵一步 |
|---|---|
| 有限 ⇒ 代數 | $1,\alpha,\dots,\alpha^n$ 是 $n+1$ 個 ⇒ 線性相依 |
| $[K:F] = [K:E][E:F]$ | $\{\alpha_i\beta_j\}$ 是基底 |
| 本原元素定理（特徵 0） | $F(a,b) = F(c)$ |

**例**：$[\mathbb{C}:\mathbb{R}] = 2$；$[\mathbb{Q}(\sqrt2):\mathbb{Q}] = 2$；$[\mathbb{Q}(\sqrt[3]2):\mathbb{Q}] = 3$；$\mathbb{Q}(\sqrt2,\sqrt[3]2) = \mathbb{Q}(2^{1/6})$，次數 $2\cdot3 = 6$。

## 附：本集一句話總結

> **用 $\operatorname{irr}(\alpha,F)$ 把 $\alpha^n$ 換成低次項，$F(\alpha)$ 的每個元素就唯一寫成 $b_0+\cdots+b_{n-1}\alpha^{n-1}$（唯一性靠最小多項式的最小性），所以 $[F(\alpha):F] = \deg(\alpha,F)$；有限擴張一定是代數的（$n+1$ 個冪必相依），而且擴張的擴張次數相乘 $[K:F] = [K:E][E:F]$——基底就是兩組基底的兩兩乘積；例如 $\mathbb{Q}(\sqrt2,\sqrt[3]2)$ 是 6 次，其實就是單擴張 $\mathbb{Q}(2^{1/6})$，這是 Steinitz 本原元素定理的一個例子。**
