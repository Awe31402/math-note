# 第 48 集 · L31：單擴張的基底、有限擴張、次數乘法公式 [▶ 影片](https://www.youtube.com/watch?v=gWtF0EpNX04&list=PLBY4G2o7DhF0JCgapYKrqibGaJuvV4Gkb)

← 上一集：[[47-L30-擴張體]] ｜ [總目錄](../README.md) ｜ 下一集：[[49-L32-擴張體與代數閉包]] →

## 本集概要

- 證明：$F(\alpha)$ 的元素**唯一**寫成 $b_0+b_1\alpha+\cdots+b_{n-1}\alpha^{n-1}$（$n = \deg(\alpha,F)$）。所以 $\{1,\alpha,\dots,\alpha^{n-1}\}$ 是 $F(\alpha)$ 在**基礎體** $F$ 上的基底。
- **有限擴張**、**次數** $[E:F]$。例：$[\mathbb{C}:\mathbb{R}] = 2$、$[\mathbb{Q}(\sqrt2):\mathbb{Q}] = 2$、$[\mathbb{Q}(\sqrt[3]2):\mathbb{Q}] = 3$。
- **代數擴張**；**有限擴張是代數擴張**。
- **次數乘法公式** $[K:F] = [K:E][E:F]$（體塔）；證明：基底兩兩相乘。
- 例：$\mathbb{Q}(\sqrt2,\sqrt[3]2) = \mathbb{Q}(2^{1/6})$，次數 6。**本原元素定理**（Steinitz）。

> 📘 講義對應：2018 講義 §4.10 Lecture 30「algebraic extensions」（p.171–172）；Fraleigh §29 尾、§31。感恩節假期前最後一堂。

## 筆記

### 1. 單擴張的元素表示（證明）[▶ 00:30](https://youtu.be/gWtF0EpNX04?t=30)

> **定理（Fraleigh Thm 29.18）**　$E = F(\alpha)$，$\alpha$ 在 $F$ 上代數，$\deg\operatorname{irr}(\alpha,F) = n\ge1$。則每個 $\beta\in E$ 唯一寫成
> $$\beta = b_0+b_1\alpha+\cdots+b_{n-1}\alpha^{n-1},\quad b_i\in F.$$

老師說這個證明值得講，因為它給你更好的「計算感」。

**存在：降次** [▶ 03:30](https://youtu.be/gWtF0EpNX04?t=210)
- $F(\alpha) = \{f(\alpha)\mid f\in F[x]\}$——代值同態 $\varphi_\alpha$ 的像。
- $\operatorname{irr}(\alpha,F) = p(x) = x^n+a_{n-1}x^{n-1}+\cdots+a_0$（首一）。$p(\alpha) = 0$ 給出
$$\alpha^n = -a_{n-1}\alpha^{n-1}-\cdots-a_1\alpha-a_0.\tag{$\ast$}$$
- 任何 $\alpha^m$（$m\ge n$）都能用 $(\ast)$ 代換降次 [▶ 07:00](https://youtu.be/gWtF0EpNX04?t=420)。例：
$$\alpha^{n+1} = \alpha\cdot\alpha^n = -a_{n-1}\alpha^n - a_{n-2}\alpha^{n-1}-\cdots-a_0\alpha,$$
  裡面還有 $\alpha^n$，「再代換一次。不好看，但做得到」[▶ 09:30](https://youtu.be/gWtF0EpNX04?t=570)。整理後是 $1,\alpha,\dots,\alpha^{n-1}$ 的 $F$-線性組合。
- 嚴格證明要用歸納法；老師認為這個例子夠讓人看懂 [▶ 11:30](https://youtu.be/gWtF0EpNX04?t=690)。

**唯一** [▶ 12:30](https://youtu.be/gWtF0EpNX04?t=750)：設 $\beta = \sum b_i\alpha^i = \sum b_i'\alpha^i$。令
$$g(x) = (b_0-b_0')+(b_1-b_1')x+\cdots+(b_{n-1}-b_{n-1}')x^{n-1}.$$
- $g(\alpha) = 0$，而 $\deg g\le n-1$ [▶ 15:00](https://youtu.be/gWtF0EpNX04?t=900)。
- 「這對 $p(x)$ 來說很尷尬」：$p$ 是以 $\alpha$ 為根、次數最小的**非零**多項式。所以 $g$ 必須是**零多項式**，所有係數為 0，$b_i = b_i'$ [▶ 16:30](https://youtu.be/gWtF0EpNX04?t=990)。$\blacksquare$

**向量空間的語言** [▶ 17:30](https://youtu.be/gWtF0EpNX04?t=1050)：係數唯一 = **線性獨立**（等價說法：線性組合為 0 則係數全為 0）。所以 $\{1,\alpha,\dots,\alpha^{n-1}\}$ 是 $F(\alpha)$ 在 $F$ 上的**基底**，$F(\alpha)$ 是 $n$ 維向量空間。被擴張的 $F$ 叫**基礎體 (base field)** [▶ 18:30](https://youtu.be/gWtF0EpNX04?t=1110)。

（作業 Ch.17 #12「$\mathbb{Z}_p[x]/\langle f\rangle$ 有 $p^n$ 個元素」本質上就是這個證明，難度一樣 [▶ 13:30](https://youtu.be/gWtF0EpNX04?t=810)。）

**學生問：為什麼 $g$ 一定是 0？** [▶ 19:00](https://youtu.be/gWtF0EpNX04?t=1140)：若 $g\neq0$，它就是比 $p$ 次數低、又讓 $\alpha$ 為根的多項式，和 $\operatorname{irr}$ 的定義矛盾。$\operatorname{irr}$ 的存在性（上一講沒證的定理）在講義裡有「血腥但好懂」的細節。

### 2. 有限擴張 [▶ 21:30](https://youtu.be/gWtF0EpNX04?t=1290)

> **定義（Fraleigh 31.2）**　若 $E$ 作為 $F$-向量空間是有限維 $n$，說 $E$ 是 $F$ 的 **$n$ 次有限擴張 (finite extension of degree $n$)**，記作 $[E:F] = n$。

（「這個記號以前用過，意思不同，但這裡是好意思。」）

**例** [▶ 23:00](https://youtu.be/gWtF0EpNX04?t=1380)
- $[\mathbb{C}:\mathbb{R}] = 2$
- $[\mathbb{Q}(\sqrt2):\mathbb{Q}] = 2$
- $[\mathbb{Q}(\sqrt[3]2):\mathbb{Q}] = 3$

> **定義**　若 $E$ 的**每個**元素都在 $F$ 上代數，$E$ 叫 $F$ 的**代數擴張 (algebraic extension)** [▶ 25:00](https://youtu.be/gWtF0EpNX04?t=1500)。

（老師跳過了這節的第一個定義，「現在在付代價」。）

> **定理（Fraleigh Thm 31.3）**　有限擴張是代數擴張 [▶ 24:00](https://youtu.be/gWtF0EpNX04?t=1440)。

**證明** [▶ 26:00](https://youtu.be/gWtF0EpNX04?t=1560)：$[E:F] = n$，取 $\alpha\in E$。$\{1,\alpha,\alpha^2,\dots,\alpha^n\}$ 有 $n+1$ 個元素，在 $n$ 維空間裡一定**線性相依**：存在不全為 0 的 $c_i\in F$ 使
$$c_0+c_1\alpha+\cdots+c_n\alpha^n = 0.$$
所以 $p(x) = c_nx^n+\cdots+c_0$ 是 $F[x]$ 中的非零多項式，$p(\alpha) = 0$。$\alpha$ 在 $F$ 上代數。$\blacksquare$

### 3. 次數乘法公式 [▶ 29:00](https://youtu.be/gWtF0EpNX04?t=1740)

> **定理（Fraleigh Thm 31.4）**　若 $E$ 是 $F$ 的有限擴張，$K$ 是 $E$ 的有限擴張，則 $K$ 是 $F$ 的有限擴張，且
> $$[K:F] = [K:E]\,[E:F].$$

「擴張的擴張，次數相乘。」

**圖** [▶ 31:30](https://youtu.be/gWtF0EpNX04?t=1890)
```
  K
  |   基底 β₁,…,βₘ （m = [K:E]）
  E
  |   基底 α₁,…,αₙ （n = [E:F]）
  F
```
$K$ 在 $F$ 上的基底：$\{\alpha_i\beta_j\}$，共 $mn$ 個。

### 4. 例：$\mathbb{Q}(\sqrt2,\sqrt[3]2)$ [▶ 33:00](https://youtu.be/gWtF0EpNX04?t=1980)

$F = \mathbb{Q}$，$E = \mathbb{Q}(\sqrt2) = \{a+b\sqrt2\}$，$K = E(\sqrt[3]2)$。
- $[E:\mathbb{Q}] = 2$。
- $\gamma = \sqrt[3]2$ 滿足 $x^3-2$，Eisenstein（$p = 2$）不可約，所以 $\deg = 3$ [▶ 35:30](https://youtu.be/gWtF0EpNX04?t=2130)。$K$ 的元素是 $\square_1+\square_2\gamma+\square_3\gamma^2$，$\square_i\in E$（老師暫時叫它們「小精靈」）。
- 展開每個 $\square_i = c+c'\sqrt2$：
$$c_1+c_2\sqrt2+(c_3+c_4\sqrt2)2^{1/3}+(c_5+c_6\sqrt2)2^{2/3},\quad c_i\in\mathbb{Q}.$$
- 指數：$2^{1/2}\cdot2^{1/3} = 2^{5/6}$，$2^{1/2}\cdot2^{2/3} = 2^{7/6} = 2\cdot2^{1/6}$ [▶ 38:00](https://youtu.be/gWtF0EpNX04?t=2280)。（學生幫忙算對。）
- 全部都是 $2^{1/6}$ 的次方的有理組合：
$$K = \{b_0+b_1\,2^{1/6}+b_2(2^{1/6})^2+\cdots+b_5(2^{1/6})^5\} = \mathbb{Q}(2^{1/6}).$$
- 雖然是兩次擴張得來，其實是一個**單擴張** [▶ 40:00](https://youtu.be/gWtF0EpNX04?t=2400)。次數：$[K:\mathbb{Q}] = 3\cdot2 = 6$ ✓。

**學生問：一定能找到等價的單擴張嗎？** [▶ 40:30](https://youtu.be/gWtF0EpNX04?t=2430)（另一位學生查書回答）

> **定理（本原元素定理 Primitive Element Theorem；Steinitz, 1910）**　$F$ 的特徵是 0，$a,b$ 在 $F$ 上代數，則存在 $c\in F(a,b)$ 使 $F(a,b) = F(c)$。

所以特徵 0 時，答案是肯定的：任何有限擴張都能寫成單擴張。（特徵不是 0 呢？——留著好奇。）

### 5. 次數乘法公式的證明 [▶ 42:00](https://youtu.be/gWtF0EpNX04?t=2520)

$\{\alpha_1,\dots,\alpha_n\}$ 是 $E/F$ 的基底，$\{\beta_1,\dots,\beta_m\}$ 是 $K/E$ 的基底。要證 $\{\alpha_i\beta_j\}$ 是 $K/F$ 的基底。

**張成** [▶ 43:30](https://youtu.be/gWtF0EpNX04?t=2610)
- $\gamma\in K$：$\gamma = \sum_jb_j\beta_j$，$b_j\in E$。
- 每個 $b_j\in E = \operatorname{span}_F\{\alpha_i\}$：$b_j = \sum_ic_{ij}\alpha_i$，$c_{ij}\in F$。
- 代入：$\gamma = \sum_j\sum_ic_{ij}\alpha_i\beta_j$。

**線性獨立** [▶ 46:00](https://youtu.be/gWtF0EpNX04?t=2760)
- 設 $\sum_{i,j}c_{ij}\alpha_i\beta_j = 0$，即 $\sum_j\left(\sum_ic_{ij}\alpha_i\right)\beta_j = 0$。
- 括號裡的係數在 $E$ 裡，$\{\beta_j\}$ 在 $E$ 上線性獨立，所以 $\sum_ic_{ij}\alpha_i = 0$ 對每個 $j$。
- $c_{ij}\in F$，$\{\alpha_i\}$ 在 $F$ 上線性獨立，所以 $c_{ij} = 0$。$\blacksquare$

「我都忘了我有多愛線性代數。」[▶ 46:00](https://youtu.be/gWtF0EpNX04?t=2760)

### 6. 預告 [▶ 49:00](https://youtu.be/gWtF0EpNX04?t=2940)

- $x^3-2$ 在 $\mathbb{Q}(\sqrt2)$ 中有根嗎？$[\mathbb{Q}(\sqrt2):\mathbb{Q}] = 2$，而 $\sqrt[3]2$ 的次數是 3。（若有根，3 必須整除 2，不可能——要用到沒講完的推論。）
