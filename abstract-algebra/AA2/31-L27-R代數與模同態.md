# 第 31 集 · L27：$R$-代數、模同態、商模 [▶ 影片](https://www.youtube.com/watch?v=pkDujzEgn0w&list=PLBY4G2o7DhF1x_afv1rv_d0hFCoMWEb-j)

## 本集概要

D&F §10.1 尾、§10.2：
- 子模判別法的證明。
- **$R$-代數**（「阿嘎布拉」）：有 1 的環 $A$ + 環同態 $f:R\to A$，$f(R)$ 在 $A$ 的**中心**裡。例：任何有 1 的環是 $\mathbb{Z}$-代數；$R[x]$、$R[x,y]$、群環 $RG$、$R^{n\times n}$。$F$-代數一定含 $F$ 的同構副本。
- **$R$-模同態**、同構、核、像、$\mathrm{Hom}_R(M,N)$。環同態 ≠ 模同態。
- $\mathrm{Hom}_R(M,N)$ 是 $R$-模（$R$ 交換）；$\mathrm{End}_R(M)$ 是 $R$-代數。
- **商模** $M/N$；子模的和；模的同構定理。

> 📘 講義對應：Math422 Lecture 27「$R$-Algebras & Quotient Modules」；D&F §10.1–10.2（Prop. 1、Prop. 2）。

## 筆記

### 1. 子模判別法的證明 [▶ 00:30](https://youtu.be/pkDujzEgn0w?t=30)

> **命題 1**：$N\subseteq M$ 是子模 $\iff$ $N\ne\varnothing$ 且 $x+ry\in N$（$r\in R$，$x,y\in N$）。

- ⇒：$0\in N$；子模本身是模，$ry\in N$、和也在 $N$。
- ⇐：取 $x\in N$，$x+(-1)x = 0\in N$；$x-y = x+(-1)y\in N$，所以是加法子群；$ry = 0+ry\in N$。（用到 $R$ 有 1——§10.1 假設環有 1。）「這幾乎就是子空間判別法。」

### 2. $R$-代數 [▶ 06:30](https://youtu.be/pkDujzEgn0w?t=390)

「這是你們的第二門抽象代數，我們定義過『代數』嗎？好像沒有。今天是好日子。」

> **定義**：$R$ 是有 1 的交換環。**$R$-代數**（$R$-algebra）是有 1 的環 $A$，連同環同態 $f:R\to A$，$f(1_R) = 1_A$，且 $f(R)$ 包含在 $A$ 的**中心**（與所有元素交換的元素）裡。

- 老師把 algebra 唸成「阿嘎布拉」（algebruh），這班反應比他以前教的「更嚴肅的抽象代數班」熱烈得多（「Spano 博士說就不行，他是個嚴肅的人，會帶著意義引用詩句」）[▶ 09:00](https://youtu.be/pkDujzEgn0w?t=540)。
- $r\cdot a = a\cdot r := f(r)a = af(r)$：給出左（或右）$R$-模結構。

> **定義**：$R$-代數 $A,B$ 之間的 **$R$-代數同態**是環同態 $\varphi:A\to B$，$\varphi(1_A) = 1_B$，且 $\varphi(r\cdot a) = r\cdot\varphi(a)$。雙射的叫 $R$-代數同構 [▶ 10:30](https://youtu.be/pkDujzEgn0w?t=630)。

**例** [▶ 13:00](https://youtu.be/pkDujzEgn0w?t=780)
1. **任何有 1 的環都是 $\mathbb{Z}$-代數**：$f(n) = n\cdot1$。例 $\mathbb{Z}_2$：$nx = x+\cdots+x$，「在 $\mathbb{Z}_2$ 裡很荒謬，但算數」。
2. 若 $A$（有 1）有子環 $R$ 在它的中心裡，$A$ 就是 $R$-代數（$R$ 交換、有 1）：
   - (a) $R[x]$：$f(r) = r$（常數多項式）。多項式環是交換的，中心是全部 [▶ 21:00](https://youtu.be/pkDujzEgn0w?t=1260)。
   - (b) $R[x,y]$：同理。
   - (c) 群環 $RG$（$G$ 有限，$g_1 = e$）：$f(r) = re$。是環同態——「爵士手！」（學生：「那是手語的『耶』。」——「我討厭爵士。」）[▶ 22:30](https://youtu.be/pkDujzEgn0w?t=1350)
   - (d) $R^{n\times n}$（老師加的）：$f(r) = rI$。學生先猜「每個元素都是 $r$ 的矩陣」——不交換，不行。Math 321 算過：**矩陣環的中心就是單位矩陣的純量倍**，所以這是唯一選擇 [▶ 25:00](https://youtu.be/pkDujzEgn0w?t=1500)。

**$A$ 一定含 $R$ 的副本嗎？** [▶ 26:30](https://youtu.be/pkDujzEgn0w?t=1590)
- (d) 中 $r\mapsto rI$ 的核是 0，單射——$R^{n\times n}$ 含 $R$ 的同構副本。
- 但例 1：$\mathbb{Z}_2$ 裝不下 $\mathbb{Z}$，$\mathbb{Z}\to\mathbb{Z}_2$ 的核是偶數 [▶ 28:30](https://youtu.be/pkDujzEgn0w?t=1710)。
- 什麼時候保證單射？學生：**$R$ 是體**——體出發的同態要嘛為 0 要嘛單射，而它把 1 送到 1。所以 **$F$-代數的中心一定含 $F$ 的同構副本**。例：$\mathbb{C}$ 是 $\mathbb{R}$-代數，四元數是 $\mathbb{R}$-代數 [▶ 31:30](https://youtu.be/pkDujzEgn0w?t=1890)。
- （老師本想週末錄影補進度，被某人「勸阻」——學生追問是不是兒子 Daniel。）

### 3. 模同態（§10.2）[▶ 34:30](https://youtu.be/pkDujzEgn0w?t=2070)

> **定義**：$M,N$ 是 $R$-模。
> 1. $\varphi:M\to N$ 是 **$R$-模同態**，若 (a) $\varphi(x+y) = \varphi(x)+\varphi(y)$；(b) $\varphi(rx) = r\varphi(x)$（「齊次」）。
> 2. 雙射的模同態叫**同構**，記 $M\cong N$（「Kong 嗎？」——「叫 squiggle」）。
> 3. **核** $\ker\varphi = \{m\mid\varphi(m) = 0\}$；**像** $\varphi(M)$（也可以叫值域，「如果你不想被人尊重」）。
> 4. $\mathrm{Hom}_R(M,N)$ = 所有 $M\to N$ 的 $R$-模同態。

- 心裡可以把 (b) 想成「純量提出來」，但小心：別把體的性質套到環上 [▶ 35:30](https://youtu.be/pkDujzEgn0w?t=2130)。
- $R = F$ 時：模同態 = 線性變換；$\mathrm{Hom}_F(V,W) = \mathcal{L}_F(V,W)$ [▶ 39:00](https://youtu.be/pkDujzEgn0w?t=2340)。
- （作業什麼時候出？學生：「先出作業比先改考卷重要。」「乾脆全班 110%？」——「學校規定只能用分數，不能用百分比。」）

**環同態 ≠ 模同態** [▶ 41:00](https://youtu.be/pkDujzEgn0w?t=2460)（D&F 的例子）
- $M = R$ 當作 $R$-模時，$R$-模同態和環同態不同：例如 $\mathbb{Z}\to\mathbb{Z}$ 的乘 2 映射可加、可提出整數，是 $\mathbb{Z}$-模同態，但 $\varphi(1)\ne1$，**不是**環同態。（老師一開始說反了，被學生的哀號糾正。）
- $f(x)\mapsto f(x^2)$：$F[x]\to F[x]$ 的環同態，但不是 $F[x]$-模同態：$\varphi(xf) = x^2f(x^2)\ne x\,f(x^2)$ [▶ 44:00](https://youtu.be/pkDujzEgn0w?t=2640)。
- 對比：環同態保持乘法 $\varphi(rs) = \varphi(r)\varphi(s)$；模同態是 $\varphi(rx) = r\varphi(x)$——不同的模式。

**更多例子** [▶ 45:00](https://youtu.be/pkDujzEgn0w?t=2700)
- $R^n\to R$ 的第 $i$ 個座標投影是模同態，核是第 $i$ 個分量為 0 的那些。
- **$\mathbb{Z}$-模同態 = 交換群同態**：$\varphi(2x) = \varphi(x+x) = 2\varphi(x)$，可加就自動齊次。
- $I$ 零化 $M,N$ 時，$R$-模同態也是 $R/I$-模同態。例：$pA = 0$（$p$ 質數）的交換群 $A$，群同態就是 $\mathbb{Z}/p$ 上的線性變換；$\mathrm{Aut}(A) = GL(A)$ [▶ 47:00](https://youtu.be/pkDujzEgn0w?t=2820)。

### 4. Hom 與 End [▶ 49:00](https://youtu.be/pkDujzEgn0w?t=2940)

> **命題 2**（老師「最喜歡的命題」——就是線性代數）：
> 1. $\varphi$ 是模同態 $\iff\varphi(rx+y) = r\varphi(x)+\varphi(y)$（一步判別）。
> 2. $R$ 交換時，$\mathrm{Hom}_R(M,N)$ 用逐點加法 $(\varphi+\psi)(m) = \varphi(m)+\psi(m)$、$(r\varphi)(m) = r\varphi(m)$ 成為 $R$-模。
> 3. 模同態的合成仍是模同態。
> 4. $\mathrm{End}_R(M) = \mathrm{Hom}_R(M,M)$ 用加法和合成是有 1 的環；$R$ 交換時是 **$R$-代數**。

- 「函數怎麼加？永遠是微積分先修那樣——逐點。」[▶ 50:30](https://youtu.be/pkDujzEgn0w?t=3030)
- (2) 需要交換：$(r_1\varphi)(r_2m) = r_1r_2\varphi(m) = r_2r_1\varphi(m) = r_2(r_1\varphi)(m)$——交換 $r_1r_2$ 那一步 [▶ 53:00](https://youtu.be/pkDujzEgn0w?t=3180)。
- 定義其實只用到值域 $N$ 是模，定義域只要能當函數的定義域（D&F 順帶一提）。
- (3)：$\psi\circ\varphi(rx+y) = \psi(r\varphi(x)+\varphi(y)) = r\psi\varphi(x)+\psi\varphi(y)$。
- (4)：$R$ 在中心的副本是 $r\cdot\mathrm{id}$——**純量乘法**。$\mathrm{End}_R(M)$ 叫**自同態環**。
- （學生的東西差點掉下來：「保護它！」）

### 5. 商模 [▶ 56:00](https://youtu.be/pkDujzEgn0w?t=3360)

- $N\le M$ 子模：$N$ 是交換群的子群，自動正規，$M/N$ 是商群。定義 $r(x+N) = rx+N$，良定義，得到**商模** $M/N$。
- 投影 $\pi:M\to M/N$ 是模同態，核是 $N$。和商環、商向量空間一樣——證明就是逐條驗公理，「無聊但顯然」。
- **子模的和** $A+B = \{a+b\}$ 是子模——「真正值得考的題目，不太難，剛好適合這門課」：用子模判別法，$0 = 0+0$；$(a_1+b_1)+r(a_2+b_2) = (a_1+ra_2)+(b_1+rb_2)$ [▶ 57:30](https://youtu.be/pkDujzEgn0w?t=3450)。
- 模也有第一、二、三同構定理和格（對應）定理，「就是你們已經知道的那些」。
- 「這一講全是我們做過的東西——無事生非。」
