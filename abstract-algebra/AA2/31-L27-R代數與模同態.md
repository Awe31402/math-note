## 1. 子模判別法的證明

[▶ 00:00](https://youtu.be/pkDujzEgn0w?t=0) 課前禱告。「Lecture 27，講**商模**和**模同態**。不過 §10.1 還剩一點。」

> **命題 1（子模判別法）**（講義 p.1）[▶ 00:30](https://youtu.be/pkDujzEgn0w?t=30)　$N\subseteq M$ 是子模 $\iff$ (1) $N\neq\emptyset$（「開心吧？」「是。」）；(2) $x+ry\in N$，$\forall r\in R$、$x,y\in N$。

「看起來眼熟嗎？」「是。」「跟**子空間**幾乎一模一樣。」

**證明**[▶ 02:00](https://youtu.be/pkDujzEgn0w?t=120)
- (⇒) $0\in N$ ⇒ 非空；子模本身是模，$ry\in N$、和還在 $N$ ⇒ $x+ry\in N$。
- (⇐) 取 $x\in N$，$x+(-1)x = 0\in N$；$x,y\in N$ ⇒ $x-y = x+(-1)y\in N$ ⇒ 加法子群。（「這裡假設 $1,-1$ 在環裡——§10.1 一開始說我們在有 1 的環上。」）再用 $x = 0$ 得 $ry\in N$ ⇒ 對環作用封閉。$\blacksquare$

## 2. R-代數

[▶ 06:00](https://youtu.be/pkDujzEgn0w?t=360)「這是你們的**第二門抽象代數**課——我們**定義過『代數』了嗎**？我想沒有。今天是好時機。」（講義 p.2：「**終於要發生了**。」）

> **定義**（講義 p.2）[▶ 06:30](https://youtu.be/pkDujzEgn0w?t=390)　$R$ 是有 1 的**交換**環。**$R$-代數**是有 1 的環 $A$ 加上環同態 $f:R\to A$，$f(1_R) = 1_A$，且子環 $f(R)$ 落在 $A$ 的**中心**裡。

- 【課堂討論】[▶ 08:00](https://youtu.be/pkDujzEgn0w?t=480)「$A$ 的**中心**是什麼？」「**交換**的東西。」$Z(A) = \{b\in A : bx = xb\ \forall x\in A\}$。「0 總在裡面，1 也在。還有別的嗎？看例子。」
- （老師把 algebra 念成某種口音：「這班對我這樣念的**接受度**比我教過的某些**更嚴肅**的抽象代數班高多了。」）
- **自然的左右模結構**[▶ 09:00](https://youtu.be/pkDujzEgn0w?t=540)：
$$r\cdot a = a\cdot r = f(r)a = af(r)\quad(f(r)\in Z(A)).$$

> **定義**（講義 p.2）[▶ 10:00](https://youtu.be/pkDujzEgn0w?t=600)　$A,B$ 是 $R$-代數。**$R$-代數同態**是環同態 $\varphi:A\to B$，$\varphi(1_A) = 1_B$，且 $\varphi(r\cdot a) = r\cdot\varphi(a)$（左右的 $\cdot$ 分別是 $R$ 在 $A$、$B$ 上的作用）。**同構** = 雙射的同態；$A\cong B$（作為 $R$-代數）表示存在 $R$-代數同構。

## 4. 模同態、同構、核、像、Hom

[▶ 34:00](https://youtu.be/pkDujzEgn0w?t=2040)「終於到 §10.2：商模與模同態。先是一個**長**定義，值得寫下來——Violet，寫下來。」（講義 p.4：「這定義自然地把向量空間和線性變換的理論推廣到 $R$-模和 $R$-模同態。」）

> **定義**（講義 p.4）　$R$ 環，$M,N$ 是 $R$-模。
> 1. $\varphi:M\to N$ 是 **$R$-模同態**：(a) $\varphi(x+y) = \varphi(x)+\varphi(y)$（**可加**）；(b) $\varphi(rx) = r\varphi(x)$（**齊次**）。
> 2. 單射且滿射的模同態是**同構**；存在同構時寫 $M\cong N$。
> 3. $\ker\varphi = \{m\in M : \varphi(m) = 0\}$；**像** $\varphi(M) = \{n\in N : n = \varphi(m)\}$。
> 4. $\mathrm{Hom}_R(M,N)$：$M$ 到 $N$ 的所有 $R$-模同態。

- 【口頭】[▶ 35:30](https://youtu.be/pkDujzEgn0w?t=2130)「(b) 我有時說『純量乘法拉出來』——但那有**向量空間的偏見**，我盡量不這樣叫。不過**在我心裡它就是純量乘法**。要小心：如果不小心把它當純量乘法、賦予它**體的性質**，就會出事。環是體時，模就是向量空間，(b) 才**真的**是純量拉出來。」
- 「像也可以叫**值域**——如果你想讓人**不尊重你**。開玩笑的，叫值域吧，誰在乎。」
- （「$\cong$ 叫什麼？」學生：「**Kong**。」「**squiggle**。」）

**對照**（講義 p.4）[▶ 38:30](https://youtu.be/pkDujzEgn0w?t=2310)「我們要**一直把新想法連到舊想法**。」
| $R$-模 | $F$-向量空間 |
|---|---|
| $R$ | $F$ |
| $M$ | $V$ |
| $\varphi:M\to N$ | 線性變換 $T:V\to W$ |
| $\mathrm{Hom}_R(M,N)$ | $\mathcal{L}_F(V,W)$ |

「所以 Math 321 已經給了我們**一整類** $R$-模同態的例子。」

【講義補充】**讀者練習**（講義 p.5）：$\ker\varphi$ 和 $\mathrm{im}\,\varphi$ 都是 $R$-子模。「這好像**太簡單**，當作業都嫌簡單——但也許會是。」（學生催作業：「你們想要我**先出作業再改考卷**，對吧？」「如果你乾脆**不發回考卷、每人給 110%**？」「我們**不能談百分比**——學校規定，課程裡只能是**分數**。」「250 分。」「**67 分**。」）

## 5. 模同態 ≠ 環同態

**例 1**（講義 p.5）[▶ 41:00](https://youtu.be/pkDujzEgn0w?t=2460)：$M = R$ 是 $R$-模，但**小心**：$\varphi\in\mathrm{Hom}_R(R,R)$ **不必**是環同態。
- **(a)** $R = \mathbb{Z}$，$\varphi(x) = 2x$：$\varphi(x+y) = 2x+2y$、$\varphi(nx) = 2nx = n\varphi(x)$ ⇒ **$\mathbb{Z}$-模同態**。但 $\varphi(1) = 2\neq1$ ⇒ **不是**環同態。（老師一度說「這顯然是環同態」，馬上改口：「不，那**不是**環同態，我是白痴。」學生在後面**嗚咽**。「我該用紅筆把那個 **not** 畫底線。」）
- **(b)** $R = F[x]$，$\varphi(f(x)) = f(x^2)$：可加；但
$$\varphi(r(x)f(x)) = r(x^2)f(x^2)\neq r(x)\varphi(f(x)),$$
  所以**不是** $F[x]$-模同態。然而 $\varphi(r(x)f(x)) = \varphi(r(x))\varphi(f(x))$、$\varphi(1) = 1$——它**是**環同態。

**對照**[▶ 42:30](https://youtu.be/pkDujzEgn0w?t=2550)
| 環同態 $\varphi:R\to S$ | $R$-模同態 $\varphi:M\to N$ |
|---|---|
| $\varphi(x+y) = \varphi(x)+\varphi(y)$ | $\varphi(x+y) = \varphi(x)+\varphi(y)$ |
| $\varphi(xy) = \varphi(x)\varphi(y)$ | $\varphi(r\cdot x) = r\cdot\varphi(x)$ |
| $\varphi(1) = 1$ | |

「乘法那條**模式不一樣**：模同態是把 $r$ **拉出來**，不是 $\varphi(r)\varphi(x)$。」

## 6. 更多例子：投影、ℤ-模同態、ℤ/p 上的線性映射

（講義 p.6–7）[▶ 45:00](https://youtu.be/pkDujzEgn0w?t=2700)
- **(2) 投影**：$\pi_i:R^n\to R$，$\pi_i(x_1,\dots,x_n) = x_i$ 是滿射的 $R$-模同態，
$$\ker\pi_i = R\times\cdots\times\{0\}\times\cdots\times R\quad(\text{第 }i\text{ 格是 }0).$$
  「其他格想做什麼都行，只要第 $i$ 格是 0。」
- **(3)** $R = F$ 體：$R$-模同態就是**線性變換**。
- **(4)** $R = \mathbb{Z}$：$\varphi(n\cdot x) = n\varphi(x)$ 由可加性**自動**得到：$\varphi(2x) = \varphi(x+x) = 2\varphi(x)$……
> **定理**（講義 p.6）　**$\mathbb{Z}$-模同態就是 Abel 群同態**。
- **(5)** $I$ 是雙邊理想、**零化** $M$ 和 $N$ ⇒ $R$-模同態 $\varphi:M\to N$ 自然是 **$R/I$-模同態**（上堂課的延伸）。
  - **應用**：$p\mathbb{Z}$ 零化 $M,N$ ⇒ $\mathbb{Z}$-模同態是 $\mathbb{Z}/p\mathbb{Z}$-模同態——$\mathbb{Z}/p$ 是體，所以是**線性變換**。
  - **應用**：Abel 群 $A$ 滿足 $px = 0$（$\forall x$）⇒ 任何群同態 $A\to A$ 是 $\mathbb{Z}/p$-模同態。特別地 $\varphi\in\mathrm{Aut}(A)$ 是**可逆線性變換**：
$$\mathrm{Aut}(A) = GL(A),\qquad\mathcal{L}_{\mathbb{F}_p}(A,A) = \mathrm{Hom}_{\mathbb{Z}/p\mathbb{Z}}(A,A).$$

## 7. Hom_R(M,N) 是模；End_R(M) 是 R-代數

> **命題 2**（講義 p.8）[▶ 49:00](https://youtu.be/pkDujzEgn0w?t=2940)　$M,N,L$ 是 $R$-模。
> 1. $\varphi$ 是 $R$-模同態 $\iff$ $\varphi(rx+y) = r\varphi(x)+\varphi(y)$。
> 2. $R$ **交換**時，$\mathrm{Hom}_R(M,N)$ 用自然定義是 $R$-模。
> 3. $\varphi\in\mathrm{Hom}_R(L,M)$、$\psi\in\mathrm{Hom}_R(M,N)$ ⇒ $\psi\circ\varphi\in\mathrm{Hom}_R(L,N)$。
> 4. $\mathrm{Hom}_R(M,M)$ 對函數加法和**合成**是有 1 的環；$R$ 交換時是 **$R$-代數**。

- 「這個**令人愉快**——我**最喜歡**的命題，也許。就是**直接的線性代數**。」(1) 是線性變換的**一步判別法**：可加和齊次一次檢查。
- 【課堂討論】[▶ 50:00](https://youtu.be/pkDujzEgn0w?t=3000)「$R$-模同態怎麼**相加**？」學生：「……」「就是**逐點**：$(f+g)(x) = f(x)+g(x)$。永遠是這樣，**微積分預備課**。」
$$(\varphi+\psi)(x) = \varphi(x)+\psi(x),\qquad(r\varphi)(x) = r\varphi(x).$$
- （[▶ 51:30](https://youtu.be/pkDujzEgn0w?t=3090) 有人打翻東西：「喔不！**保護**！」）
- 【口頭】[▶ 52:00](https://youtu.be/pkDujzEgn0w?t=3120)「仔細看會發現 $M$ 其實**不必**是 $R$-模——模結構全來自**陪域** $N$。D&F 順帶提到：假設定義域是 $R$-模只是**敘述方便**，邏輯上不需要。」

**證明片段**（講義 p.8–9，D&F p.347）
- $r_1\varphi$ 滿足 (b)：
$$(r_1\varphi)(r_2m) = r_1\varphi(r_2m) = r_1r_2\varphi(m) = r_2r_1\varphi(m) = r_2(r_1\varphi)(m).$$
  「**這一步**要 $R$ 交換——把 $r_1r_2$ 換成 $r_2r_1$。」
- 合成：$(\psi\circ\varphi)(rx+y) = \psi(r\varphi(x)+\varphi(y)) = r\psi(\varphi(x))+\psi(\varphi(y))$。
- **(4)**：$1 = \mathrm{Id}_M$；$\mathrm{Hom}_R(M,M)$ 是環（通常**不**交換）。

> **定義**（講義 p.9）　$\mathrm{End}_R(M) = \mathrm{Hom}_R(M,M)$ 叫 $M$ 的**自同態環**，元素叫**自同態**。

**$R$-代數結構**（講義 p.10）[▶ 55:30](https://youtu.be/pkDujzEgn0w?t=3330)：$R$ 交換時 $f:R\to\mathrm{End}_R(M)$，$f(r) = r\,\mathrm{Id}_M$；$(r\mathrm{Id}_M)\circ\varphi = \varphi\circ(r\mathrm{Id}_M)$ ⇒ $f(R)$ 在中心。形如 $r\,\mathrm{Id}_M$ 的自同態叫 **純量乘法**（「也許該保留給 $R = F$ 是體的情形」）。$R = F$ 時 $f(R)\cong R$——**體 = 恆等變換的純量倍**。

## 8. 商模、子模的和、同構定理

> **命題 3**（講義 p.11）[▶ 56:00](https://youtu.be/pkDujzEgn0w?t=3360)　$N$ 是 $M$ 的子模。（加法 Abel）商群 $M/N$ 用
> $$r(x+N) = rx+N$$
> 成為 $R$-模；自然投影 $\pi(x) = x+N$ 是 $R$-模同態，$\ker\pi = N$。

- $N$ 是 Abel 群 $M$ 的子群 ⇒ **正規** ⇒ 商群良定義。$R$-作用不依賴代表元（讀者練習）。驗證公理例如 $(r_1r_2)(x+N) = r_1(r_2(x+N))$。
- 「這**很像**商環的構造和自然映射——現在是 $R$-模同態。證明不刺激：就像證明**向量空間除以子空間**是新的向量空間（**商空間**）——得一條條檢查公理，**無聊但顯然對**。」

> **定義／命題**（講義 p.12）[▶ 57:30](https://youtu.be/pkDujzEgn0w?t=3450)　子模 $A,B$ 的**和** $A+B = \{a+b\}$ 是子模。

「你們會高興：這是**夠格當考題**的——有趣但不太難，**正適合**這門課的考試。」**證明**用子模判別法：$0 = 0+0\in A+B$；$x = a_x+b_x$、$y = a_y+b_y$ ⇒
$$rx+y = r(a_x+b_x)+(a_y+b_y) = (ra_x+a_y)+(rb_x+b_y)\in A+B.$$

> **定理 4（模的第一、第二、第三同構定理）**（講義 p.12）[▶ 58:30](https://youtu.be/pkDujzEgn0w?t=3510)
> 1. $\varphi:M\to N$ 模同態 ⇒ $\ker\varphi$ 是子模，$M/\ker\varphi\cong\varphi(M)$。
> 2. $A,B$ 子模 ⇒ $\dfrac{A+B}B\cong\dfrac A{A\cap B}$。
> 3. $A\subseteq B$ 子模 ⇒ $\dfrac{M/A}{B/A}\cong\dfrac MB$。

「**就是你們已經知道的那些**。我忘了寫，但**格同構定理**也還在。我累了，停在這裡可以吧？」學生：「這節**這麼多東西**——」「但都是**無中生有**（much ado about nothing）——全是我們做過的。」

💬 上式前者在 $A$、後者在 $B$。講義寫成 $r(a_x+a_y)+b_x+b_y$，把 $r$ 套錯了位置（應是 $ra_x+a_y$ 和 $rb_x+b_y$）。

## 附：本集一句話總結

> **先證完子模判別法，再定義 $R$-代數：有 1 的環 $A$ 配一個把 $R$ 送進中心的環同態（有 1 的環都是 $\mathbb{Z}$-代數，多項式環、群環、矩陣環都是 $R$-代數，但只有 $R$ 是體時才保證含 $R$ 的副本）；接著 §10.2 把線性變換推廣成模同態——可加且把環元素拉出來，它和環同態是不同的東西；$\mathbb{Z}$-模同態就是群同態，$\mathrm{Hom}_R(M,N)$ 在 $R$ 交換時是模、$\mathrm{End}_R(M)$ 是 $R$-代數；最後商模、子模的和、三個同構定理都和向量空間一模一樣——「無事生非」。**
