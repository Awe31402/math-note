## 1. 範數與歐氏整環

> **定義（範數 norm）**（講義 p.1）[▶ 00:30](https://youtu.be/6gT1aL4h6I0?t=30)　整環 $R$ 上任何函數 $N:R\to\mathbb{N}\cup\{0\}$ 滿足 $N(0) = 0$，叫 $R$ 上的**範數**。若 $N(a)>0$ 對所有 $a\neq0$，叫**正範數**。

> **定義（歐氏整環 Euclidean domain）**（講義 p.1）[▶ 02:00](https://youtu.be/6gT1aL4h6I0?t=120)　整環 $R$ 若有範數 $N$，使得任意 $a,b\in R$、$b\neq0$，存在 $q,r\in R$：
> $$a = qb+r,\quad r = 0\ \text{或}\ N(r)<N(b),$$
> 叫**歐氏整環**。$q$ 叫**商**，$r$ 叫**餘數**。

【課堂討論】[▶ 03:00](https://youtu.be/6gT1aL4h6I0?t=180)「$q$、$r$ 叫什麼？」學生：「商、餘數。」「簡單說：**歐氏整環就是支援除法算法的整環**。」

## 2. 輾轉相除法為什麼會停

[▶ 04:00](https://youtu.be/6gT1aL4h6I0?t=240)（講義 p.1）
$$\begin{aligned}a &= q_0b+r_0\\ b &= q_1r_0+r_1\\ r_0 &= q_2r_1+r_2\\ &\ \vdots\\ r_{n-2} &= q_nr_{n-1}+r_n\quad\leftarrow\text{最後一個非零餘數}\\ r_{n-1} &= q_{n+1}r_n\end{aligned}$$

- 【口頭】[▶ 05:30](https://youtu.be/6gT1aL4h6I0?t=330)「書上**從不給 $b$ 取名字**，我喜歡叫它『除數』。你們叫它什麼？」學生：「**Bob**。」「Bob。好吧，B 開頭，算是個理由。」
- **為什麼一定有最後一個非零餘數**[▶ 06:00](https://youtu.be/6gT1aL4h6I0?t=360)：
$$N(b)>N(r_0)>N(r_1)>\cdots$$
  是非負整數的**嚴格遞減數列**，一定會停。所以除法算法是有限步。
- 【口頭】[▶ 06:30](https://youtu.be/6gT1aL4h6I0?t=390)「元素不是零、範數卻可以是零。所以這**不像線性代數的範數**——用法差很遠，但在這種代數裡是標準用語。」

## 3. 例子

### 3.1 體

**例 1**[▶ 07:30](https://youtu.be/6gT1aL4h6I0?t=450)「有點蠢，但值得提：**每個體都是歐氏整環**。」
- 【課堂討論】「$N(x)$ 該定義成什麼？」學生：「**0**。」「很好，對所有 $x$。」
- $b\neq0$ ⇒ $a = (ab^{-1})b$，商 $ab^{-1}$、餘數 0。
- 「當然**不是每個歐氏整環都是體**。」

### 3.2 整數；餘數不唯一

**例 2**[▶ 09:00](https://youtu.be/6gT1aL4h6I0?t=540)「最典型的例子」：$\mathbb{Z}$，$N(x) = |x|$。
- 取 $b>0$。半開區間 $[kb,(k+1)b)$（$k\in\mathbb{Z}$）**分割實數線**（講義 p.2 有圖）。$a$ 落在某一個：
$$kb\le a<(k+1)b\ ⇒\ 0\le a-kb<b.$$
  取 $q = k$、$r = a-kb$ ⇒ $a = qb+r$，$N(r) = r<b$。
- **餘數不唯一**[▶ 12:00](https://youtu.be/6gT1aL4h6I0?t=720)：若 $a = qb+r$、$0<r<b$，則也有
$$a = (q+1)b+(r-b),\quad N(r-b) = |r-b| = b-r<b.$$
  （【課堂討論】「$b-r$ 是正還是負？」學生答錯方向。「等等，我為什麼要聽你們的？……**都是你們的錯**。」）
- 具體例子[▶ 15:00](https://youtu.be/6gT1aL4h6I0?t=900)：
$$30 = 7\cdot4+2 = 7\cdot5-5.$$
  正餘數版本、負餘數版本。要唯一就**人為規定 $r>0$**。
- 【口頭】[▶ 15:30](https://youtu.be/6gT1aL4h6I0?t=930)「之後會學到：有兩種可能的根本原因是 **$\mathbb{Z}$ 的單位是 $\pm1$**。所以最大公因數其實**不是一個東西，是兩個**——gcd 是 1 也是 −1。讓環論做它自己、不硬規定全取正，數論變簡單，代數卻變醜。」

### 3.3 體上的多項式

**例 3**[▶ 16:30](https://youtu.be/6gT1aL4h6I0?t=990)「這門課**我最喜歡**的例子來源。」$F$ 是體，$R = F[x]$。
- 【課堂討論】[▶ 18:00](https://youtu.be/6gT1aL4h6I0?t=1080)「範數怎麼定？」先給一個例子（$\mathbb{Q}[x]$）：
$$\frac{x^4-5x^2+4}{x^2+1} = x^2-6+\frac{10}{x^2+1},\qquad x^4-5x^2+4 = (x^2-6)(x^2+1)+10.$$
  （學生：「是 $x^4$。」「好眼力，謝謝。」）「餘數範數 0、除數範數 2——這個神秘的 0 和 2 是什麼？」學生：「**導數**？」「不不不。」「……**次數**。」「喔，所以你剛說導數。」[▶ 21:00](https://youtu.be/6gT1aL4h6I0?t=1260)
- $N(p) = \deg p$（$p\neq0$），$N(0) = 0$。除法算法就是**多項式長除法**；良定性用跟上學期一樣的**良序原理**論證。

💬 講義 p.3 寫「$N(r) = \deg(10) = 1$」——常數的次數是 **0**；課堂上老師口頭說的是 0，對的。

【講義補充】講義 p.3 還有：
- $\mathbb{Z}_7[x]$：$x^4+2x^2+4 = (x^2+1)(x^2+1)+3$。
- $\mathbb{Z}_3[x]$ 的例子見 §7。

### 3.4 Gauss 整數與二次整數

**例 4**[▶ 22:00](https://youtu.be/6gT1aL4h6I0?t=1320)：**Gauss 整數** $\mathbb{Z}[i] = \{a+bi : a,b\in\mathbb{Z}\}$，$N(a+bi) = a^2+b^2$。
- 【講義補充】$N(zw) = N(z)N(w)$、$N(1) = 1$；除法算法可以在複平面上**幾何地看**（老師 2018 講義 p.159–160 有明確例子）。
- 更一般：$D$ **無平方因子**時，$\mathbb{Q}(\sqrt D)$ 裡的**二次整數**有範數 $N(a+b\sqrt D) = a^2-Db^2$（D&F p.229）。

【Q&A】[▶ 23:30](https://youtu.be/6gT1aL4h6I0?t=1410) 學生：「我沒聽過『無平方因子』。」老師：「就是 $D$ 沒有平方數的因數。100 不是，因為有 25；35 是——**沒有平方可分（no square to spare）**。」

[▶ 24:00](https://youtu.be/6gT1aL4h6I0?t=1440)
- D&F §7.1 講 $\mathbb{Q}(\sqrt D)$ 裡的整數環。它**有時**是歐氏整環、**有時不是**。$D = -1$ 就是 Gauss 整數（是）。
- $D = -19$：$\mathbb{Z}[(1+\sqrt{-19})/2]$ **不是**歐氏整環——對**任何**範數都寫不出除法算法。證明在 D&F p.277，用「**side divisor**」，本課不講。
- 【口頭】「證明東西**不成立**通常要花多得多的功夫。」

## 4. 相伴、不可約、質

[▶ 25:30](https://youtu.be/6gT1aL4h6I0?t=1530)「歐氏整環裡的理想理論特別好。但為了講清楚，我要介紹三個詞——之前用在理想上，現在用在**元素**上。這是我（2018）講義的 Lecture 27。」

> **定義**（講義 p.5，2018 講義 Def 4.7.1）[▶ 26:00](https://youtu.be/6gT1aL4h6I0?t=1560)　$D$ 整環，$a,b\in D$。
> 1. $a,b$ **相伴（associates）**：存在單位 $u$ 使 $b = au$。
> 2. $a$ **不可約（irreducible）**：$a$ 不是單位，且 $a = cd$ ⇒ $c$ 或 $d$ 是單位。
> 3. $a\neq0$ 是**質元（prime）**：$a$ 不是單位，且 $a\mid bc$ ⇒ $a\mid b$ 或 $a\mid c$。

- 【口頭】[▶ 28:00](https://youtu.be/6gT1aL4h6I0?t=1680)「不可約元**不允許真正的分解**。你可能說 $b = au$ 把 $b$ 分解了——但其實沒有，$u$ 只是單位，**不算數**。這是**假分解**。不可約元不允許任何這種靠單位以外的分解。」
- 【課堂討論】[▶ 29:00](https://youtu.be/6gT1aL4h6I0?t=1740)「$a\mid bc$ 推出什麼？」學生：「$a\mid b$ 或 $a\mid c$。」「有贏家了。」「**質元的定義就是把 Euclid 引理升格成定義**。」
- 【口頭】[▶ 30:00](https://youtu.be/6gT1aL4h6I0?t=1800)「我們在以前的代數裡是不是把『不可約』和『質』**混著用**？大學代數有時把實數上不能分解的二次式叫『質二次式』，我通常叫『不可約二次式』。為什麼可以這樣？」學生：「因為大學代數的學生不在乎。」「……那是**福音真理**。這就是今天的**聖經整合**。」（接著一段「我的果汁在哪」的玩笑和「別害我被炒／被取消營利」——「我得**加強周邊商品**了。」）

【講義補充】講義 p.5 的例子（Gallian p.313）：$\mathbb{Z}[\sqrt{-3}]$ 中
$$(1+\sqrt{-3})(1-\sqrt{-3}) = 4 = 2\cdot2,$$
$1+\sqrt{-3}$ 整除 $2\cdot2$ 但不整除 $2$（$(a-3b)+(a+b)\sqrt{-3} = 2$ 推出 $a = 1/2$）⇒ **不是質元**；但它**不可約**（範數 4，若分解成兩非單位則各有範數 2，而 $a^2+3b^2 = 2$ 無解）。所以**一般環裡質和不可約不等價**。

## 5. 質 ⇒ 不可約

> **定理**（講義 p.7，2018 講義 Thm 4.7.8）[▶ 31:30](https://youtu.be/6gT1aL4h6I0?t=1890)　在整環裡，**每個質元都是不可約元**。

**證明**[▶ 32:00](https://youtu.be/6gT1aL4h6I0?t=1920)：$a$ 是質元，$a = xy$。$a\mid xy$ ⇒ $a\mid x$ 或 $a\mid y$。
- 設 $a\mid x$：$x = ab$。則
$$x\cdot1 = x = ab = (xy)b = x(yb).$$
  整環有**消去律** ⇒ $1 = yb$ ⇒ $y$ 是單位。
- $a\mid y$ 時對稱地 $x$ 是單位。
- 所以 $a$ 的任何分解都含單位 ⇒ $a$ 不可約。$\blacksquare$

【口頭】[▶ 35:30](https://youtu.be/6gT1aL4h6I0?t=2130)「這是那種**好的考題**：很簡單，只需要你真的懂定義。」

## 6. 相伴元生成同一個主理想

> **定理**（講義 p.7，2018 講義 Thm 4.7.9）[▶ 36:30](https://youtu.be/6gT1aL4h6I0?t=2190)　$R$ 是有 1 的交換環。
> 1. $a,b$ 相伴 ⇒ $\langle a\rangle = \langle b\rangle$。
> 2. 若 $R$ 是**整環**、$I = \langle a\rangle$，則 $I$ 的任何其他生成元都和 $a$ 相伴。

（【口頭】「我 421 的講義用 $\langle\ \rangle$ 表示生成，我想我們一直這樣用。」學生：「LaTeX 裡是 `\langle` 和 `\rangle`。」）

**證明**[▶ 49:00](https://youtu.be/6gT1aL4h6I0?t=2940)「這證明我很**享受**走一遍。」
1. $a = bu$ ⇒ $b = au^{-1}$。$x\in\langle a\rangle$ ⇒ $x = ar = b(ur)\in\langle b\rangle$ ⇒ $\langle a\rangle\subseteq\langle b\rangle$；同理反向。「這也是**友善的考題**。」
2. [▶ 50:30](https://youtu.be/6gT1aL4h6I0?t=3030) 設 $\langle c\rangle = \langle a\rangle$。
   - 若是零理想：只能 $a = c = 0$，0 是自己的相伴元，平凡成立。
   - $a\neq0$ ⇒ $c\neq0$。$a,c$ 互在對方的理想裡：$a = rc$、$c = sa$ ⇒ $a = rsa$。
   - $a\neq0$，**整環消去律** ⇒ $rs = 1$ ⇒ $r$ 是單位，$a = rc$ 說明 $a,c$ 相伴。$\blacksquare$

【口頭】[▶ 52:00](https://youtu.be/6gT1aL4h6I0?t=3120)「講義的證明**沒說**我們在哪裡開始假設整環——你們該**扣 20%**。一開始 $R$ 只是有 1 的交換環；第 2 部分要整環，因為**消去**要用它。」

【講義補充】講義 p.7：非整環時第 2 部分**可能**仍成立——$\mathbb{Z}_6$ 中 $\langle2\rangle = \langle4\rangle = \{0,2,4\}$，而 $2\cdot5 = 4$、5 是單位，所以 2、4 相伴。（不成立的例子見講義提到的 Math StackExchange 問答。）

## 7. 多項式的 Bézout 與延伸輾轉相除法

[▶ 40:30](https://youtu.be/6gT1aL4h6I0?t=2430)（老師一度找不到想講的定理：）「我想講 D&F §8.1 的重要定理——**歐氏整環和主理想的關係**——可是手上沒有那段講義，**不想講爛**。下次再來。」「還有一個更大的故事：除法算法怎麼找**最大公因數**、整套 **Bézout 係數**怎麼推廣到現在的脈絡。」

[▶ 44:00](https://youtu.be/6gT1aL4h6I0?t=2640)（講義 p.3）$\mathbb{Z}_3[x]$：$a = x^5+x^2+1$、$b = x^2+1$。
$$\begin{aligned}x^5+x^2+1 &= q_1(x^2+1)+x\\ x^2+1 &= (x)(x)+1\\ x &= (1)(x)+0\end{aligned}$$
- 【口頭】[▶ 45:00](https://youtu.be/6gT1aL4h6I0?t=2700)「餘數 $x$ 不是零也沒關係——它範數是 1，還沒完。$x^2+1 = x\cdot x+1$，1 範數 0，所以 **1 是最後一個非零餘數**。」
- 像 Bézout 定理那樣：
$$(2x)(x^5+x^2+1)+(x^4+2x^2+x+1)(x^2+1) = 1\quad(\text{在 }\mathbb{Z}_3[x]).$$

💬 講義 p.3 寫第一步的商 $q_1 = x^2+2x+1$——次數不對（$x^5\div x^2$ 應是 3 次）。正確是 $q_1 = x^3+2x+1$：在 $\mathbb{Z}_3$ 裡 $(x^3+2x+1)(x^2+1) = x^5+3x^3+x^2+2x+1\equiv x^5+x^2+2x+1$，加上餘數 $x$ 得 $x^5+x^2+3x+1\equiv x^5+x^2+1$ ✓。最後的 Bézout 等式是對的（展開後各項係數都是 3 的倍數，只剩 1），也和 $q_1 = x^3+2x+1$ 一致：$1 = b-x\cdot r_1 = b-x(a-q_1b) = (-x)a+(1+xq_1)b$。

**老師的秘密武器**[▶ 46:30](https://youtu.be/6gT1aL4h6I0?t=2790)：「你們想知道我怎麼算的嗎？」學生：「是網站嗎？」「是網站。」「是你**弟弟**的網站嗎？」「**是**。」搜尋「**Bill Cook math extended Euclidean algorithm**」：輸入 $a(x)$、$b(x)$，它會算 gcd、Bézout 組合，還能改 $\mathbb{Z}_n$。
- 「考試**不能用**，抱歉。但如果考卷上說『順帶一提，這個多項式恆等式成立』——它是真的**機率大增**了。」
- （接著一段關於北卡州立大學「沒有休假年（sabbatical）、只有帶薪行政假」，以及學校「chapel 改名 convocation」的閒聊。）

## 8. PID 中質 ⟺ 不可約（講義）

[▶ 39:00](https://youtu.be/6gT1aL4h6I0?t=2340) 老師寫下定理，[▶ 53:00](https://youtu.be/6gT1aL4h6I0?t=3180)「這個也許**下次**證。時間到了。」

> **定理**（講義 p.7，2018 講義 Thm 4.7.10）　在**主理想整環（PID）**中，元素是質元 $\iff$ 它是不可約元。

【講義補充】證明（講義 p.7–8）：PID 是整環，所以質 ⇒ 不可約（§5）。反過來，$a$ 不可約、$a\mid bc$。令 $I = \{ax+by : x,y\in D\}$（是理想）⇒ $I = \langle d\rangle$。$a\in I$ ⇒ $a = rd$ ⇒ $r$ 或 $d$ 是單位。
- $d$ 是單位 ⇒ $1\in I$ ⇒ $1 = ax+by$ ⇒ $c = acx+(bc)y$ ⇒ $a\mid c$。
- $r$ 是單位 ⇒ $a,d$ 相伴 ⇒ $I = \langle a\rangle\ni b$ ⇒ $a\mid b$。

講義腳註：「PID 讓我們可以**隨便互換**質和不可約——有點像那些**鼓勵你不看路**的新車廣告。」

**例**（講義 p.8，Example 4.7.11）：$\mathbb{Z}$ 是 PID（每個理想是 $n\mathbb{Z}$）；$F$ 是體時 $F[x]$ 是 PID。但不是每個整環都是 PID：$\mathbb{Z}[x]$ 的 $\langle2,x\rangle$ 不是主理想。

## 9. 一頁速查表

### 9.1 定義

| 名詞 | 定義 |
|---|---|
| 範數 | $N:R\to\mathbb{N}\cup\{0\}$，$N(0) = 0$ |
| 歐氏整環 | $a = qb+r$，$r = 0$ 或 $N(r)<N(b)$ |
| 相伴 | $b = au$，$u$ 單位 |
| 不可約 | 非單位，$a = cd$ ⇒ $c$ 或 $d$ 單位 |
| 質元 | 非零非單位，$a\mid bc$ ⇒ $a\mid b$ 或 $a\mid c$ |

### 9.2 例子

| 歐氏整環 | 範數 |
|---|---|
| 體 $F$ | $N\equiv0$ |
| $\mathbb{Z}$ | $\lvert x\rvert$（餘數差一個 $\pm$，不唯一） |
| $F[x]$ | $\deg$ |
| $\mathbb{Z}[i]$ | $a^2+b^2$ |
| **不是**：$\mathbb{Z}[(1+\sqrt{-19})/2]$ | D&F p.277 |

### 9.3 定理

| 定理 | 關鍵一步 |
|---|---|
| 輾轉相除法會停 | $N(b)>N(r_0)>\cdots$ 是遞減非負整數 |
| 整環：質 ⇒ 不可約 | $x = ab = x(yb)$，消去 ⇒ $yb = 1$ |
| 相伴 ⇒ $\langle a\rangle = \langle b\rangle$ | $ar = b(ur)$ |
| 整環：同理想的生成元相伴 | $a = rsa$，消去 ⇒ $rs = 1$ |
| PID：質 ⟺ 不可約（講義） | $\langle a,b\rangle = \langle d\rangle$ 分兩種情形 |
