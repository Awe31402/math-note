## 1. 有限維實結合代數；𝒜-數

> **定義**（論文 Def 4.1；講義 p.6）[▶ 01:30](https://youtu.be/dgaYEErpef0?t=90)　$\mathcal{A}$ 是有限維**實**向量空間，配上「乘法」$\star:\mathcal{A}\times\mathcal{A}\to\mathcal{A}$，滿足：
> 1. **雙線性**：$(cx+y)\star z = c(x\star z)+y\star z$、$x\star(cy+z) = c(x\star y)+x\star z$；
> 2. **結合**：$x\star(y\star z) = (x\star y)\star z$；
> 3. **有 1**：存在 $\mathbb{1}\in\mathcal{A}$ 使 $\mathbb{1}\star x = x = x\star\mathbb{1}$。
>
> $x\in\mathcal{A}$ 叫 **$\mathcal{A}$-數**。若 $x\star y = y\star x$ 恆成立，$\mathcal{A}$ **交換**。

- 【口頭】「我想給一個**獨立**的定義——你們會發現它跟 D&F 的 $R$-代數定義**吻合**。」「雙線性就是左右兩邊**自然的分配律**。」「結合表示 $x\star y\star z$ **有意義**。」
- 【課堂討論】[▶ 05:00](https://youtu.be/dgaYEErpef0?t=300)「$x\star y = y\star x$ 恆成立，$\mathcal{A}$ 就是……」「**交換**的。」
- 【口頭】「我們在**推廣數的概念**。這個定義**很沒特徵**——涵蓋**非常多**東西。所以想懂怎麼**表示**它們很有趣。」（學生：「我得開始用**水槍**噴你們，像對貓那樣。」「**蘋果火焰噴射器**。」）

## 2. 左乘與右乘；左右 𝒜-線性

[▶ 06:30](https://youtu.be/dgaYEErpef0?t=390)「目前這是**抽象**定義的物件：有限維向量空間加乘法。我沒說它是矩陣或向量——它到底**是什麼**？但我們可以看**左乘和右乘映射**。」

> **定義**　$\alpha\in\mathcal{A}$：**左乘** $\ell_\alpha(x) = \alpha\star x$；**右乘** $r_\alpha(x) = x\star\alpha$。

- **線性**[▶ 08:30](https://youtu.be/dgaYEErpef0?t=510)：$\ell_\alpha(cx+y) = c\,\alpha\star x+\alpha\star y = c\ell_\alpha(x)+\ell_\alpha(y)$ ⇒ $\ell_\alpha,r_\alpha$ 是 $\mathcal{A}\to\mathcal{A}$ 的**實線性**映射。
- **更多**[▶ 09:30](https://youtu.be/dgaYEErpef0?t=570)：由**結合律**
$$\ell_\alpha(x\star y) = \alpha\star(x\star y) = (\alpha\star x)\star y = \ell_\alpha(x)\star y,\qquad r_\alpha(y\star x) = y\star r_\alpha(x).$$

> **定義**[▶ 11:00](https://youtu.be/dgaYEErpef0?t=660)　$T:\mathcal{A}\to\mathcal{A}$ 實線性。
> 1. $T(x\star y) = T(x)\star y$ ⇒ $T$ 是**右 $\mathcal{A}$-線性**；
> 2. $T(x\star y) = x\star T(y)$ ⇒ $T$ 是**左 $\mathcal{A}$-線性**。

所以**左乘是右 $\mathcal{A}$-線性**（可以把右邊的乘法拉出來），右乘是左 $\mathcal{A}$-線性。
- 【Q&A】[▶ 12:30](https://youtu.be/dgaYEErpef0?t=750) 學生：「你說的 $\mathbb{R}$-線性是什麼？」「就是一般的實線性——321 那種：可加、能拉出實純量。」「和 $\mathcal{A}$-線性哪裡不同？」「**$\mathcal{A}$ 元素比實數一般**。」
- 記號：右 $\mathcal{A}$-線性映射全體記 **$\mathcal{R}_\mathcal{A}$**。學生：「有大 $\mathcal{L}$ 嗎？」「沒有，**我不在乎**那些。它們是**左**的、**邪惡**的、**左撇子**的。」
- 【口頭】[▶ 14:00](https://youtu.be/dgaYEErpef0?t=840)「挑剔地說，我想實線性那條**可以劃掉**——從 (1)(2) 加上代數的性質就推得出實線性。」

## 3. 右 𝒜-線性映射都是左乘（Thm 4.2）

> **Thm 4.2**[▶ 15:00](https://youtu.be/dgaYEErpef0?t=900)　$T:\mathcal{A}\to\mathcal{A}$ 是右 $\mathcal{A}$-線性 ⇒ 存在**唯一** $\alpha\in\mathcal{A}$ 使 $T = \ell_\alpha$。

「其實兩個方向都對——剛才證了左乘都是右線性。」

**證明**[▶ 16:00](https://youtu.be/dgaYEErpef0?t=960)【課堂討論】「怎麼把 $T(x)$ 變成左乘？」學生：「**乘 1**。」「我喜歡。可以嗎？我想可以。」
$$T(x) = T(\mathbb{1}\star x) = T(\mathbb{1})\star x = \ell_{T(\mathbb{1})}(x).$$
$\alpha = T(\mathbb{1})$，唯一（$T$ 是函數，單值）。$\blacksquare$

【講義補充】論文：「上面這個簡單計算是理解**廣義 Cauchy–Riemann 方程**的關鍵。」（→ [[41-A可微性與A微積分-下]]）

**左右乘交換**[▶ 18:00](https://youtu.be/dgaYEErpef0?t=1080)【課堂討論】「$\ell_\alpha\circ r_\beta = r_\beta\circ\ell_\alpha$？」學生：「我投**是**。」「為什麼？」
$$\ell_\alpha(r_\beta(x)) = \alpha\star(x\star\beta) = (\alpha\star x)\star\beta = r_\beta(\ell_\alpha(x)).$$
「**結合律**就是 $\ell_\alpha\circ r_\beta = r_\beta\circ\ell_\alpha$。」

## 4. 正則表示 ℛ_𝒜 是 gl(𝒜) 的子代數

[▶ 20:30](https://youtu.be/dgaYEErpef0?t=1230)「右 $\mathcal{A}$-線性變換的集合，自然是 $\mathrm{gl}(\mathcal{A}) = \{T:\mathcal{A}\to\mathcal{A}\text{ 實線性}\}$ 的子集。」

> **Thm 4.4**（講義 p.7）　$\mathcal{R}_\mathcal{A}$ 是 $\mathrm{gl}(\mathcal{A})$ 的**子代數**（$\mathrm{gl}(\mathcal{A})$ 以**合成**為乘法）。

- **子空間**[▶ 22:30](https://youtu.be/dgaYEErpef0?t=1350)：老師先用左乘證 $c\ell_\alpha+\ell_\beta = \ell_{c\alpha+\beta}$ 還是左乘，再用 Thm 4.2「右線性都是左乘」推回。（「抱歉，該省點細節——今天有比這更有趣的。」）**非空**：$\mathrm{Id}(v\star w) = v\star w = \mathrm{Id}(v)\star w$ ⇒ $\mathrm{Id}\in\mathcal{R}_\mathcal{A}$。
- 【課堂討論】[▶ 26:30](https://youtu.be/dgaYEErpef0?t=1590)「$\mathrm{gl}(\mathcal{A})$ 在什麼意義下是代數？乘法是什麼？」「**合成**。」
- **對合成封閉**[▶ 27:30](https://youtu.be/dgaYEErpef0?t=1650)（「這次不靠左乘的**拐杖**，直接做」）：
$$(T\circ S)(v\star w) = T(S(v)\star w) = T(S(v))\star w = (T\circ S)(v)\star w.$$

> **定義**（講義 p.1）[▶ 30:30](https://youtu.be/dgaYEErpef0?t=1830)　$\mathcal{R}_\mathcal{A}$ 叫 $\mathcal{A}$ 的**正則表示**（regular representation）。

（學生指出老師黑板上的下標寫法；「**笛卡兒是白痴**。『我思故我在』——**你在跟誰說話**？抱歉，我不是哲學家。」）

## 5. 矩陣正則表示 M_𝒜(β)

> **定義**（講義 p.1；論文 Def 4.5）[▶ 33:00](https://youtu.be/dgaYEErpef0?t=1980)　$\beta = \{v_1,\dots,v_n\}$ 是 $\mathcal{A}$ 的基底。
> $$M_\mathcal{A}(\beta) = \{[T]_{\beta,\beta} : T\in\mathcal{R}_\mathcal{A}\}$$
> 叫相對 $\beta$ 的**（矩陣）正則表示**。$\mathcal{A} = \mathbb{R}^n$、$\beta$ 是標準基底時簡寫 $M_\mathcal{A}$。

- 【口頭】[▶ 35:00](https://youtu.be/dgaYEErpef0?t=2100)「你會問：正則表示**是**線性變換還是矩陣？答案是**是**。我**感受**你的痛——跟代數學家談這個時那是**我的**痛：『**做個選擇**啦』，因為我想要**明確**。」（學生：「有個**明確**的笑話嗎？」「我去過一個數論演講，講者講到一半說：『**警告，前方明確內容**』——下一張投影片**全是方程式**。很成功的笑話。」）

> **Thm 4.6**（講義 p.7–8）[▶ 36:00](https://youtu.be/dgaYEErpef0?t=2160)　$M_\mathcal{A}(\beta)$ 是 $\mathbb{R}^{n\times n}$ 的**子代數**。【課堂討論】「$\mathbb{R}^{n\times n}$ 的乘法？」「**矩陣乘法**。」「有贏家。」

**證明（有趣的部分）**：$M_1 = [T_1]_\beta$、$M_2 = [T_2]_\beta$，$T_i\in\mathcal{R}_\mathcal{A}$。線代：**合成的矩陣 = 矩陣的乘積** ⇒ $M_1M_2 = [T_1\circ T_2]_\beta$；而 $T_1\circ T_2\in\mathcal{R}_\mathcal{A}$（Thm 4.4）⇒ $M_1M_2\in M_\mathcal{A}(\beta)$。子空間部分留給你們。

> **Thm 4.7**[▶ 39:30](https://youtu.be/dgaYEErpef0?t=2370)　基底不同 ⇒ $M_\mathcal{A}(\beta)$ 和 $M_\mathcal{A}(\gamma)$ 是**共軛**的子代數（換基矩陣 $P$：$[T]_\beta = P^{-1}[T]_\gamma P$）。「一個向量空間能選幾組基底？**你想要多少就有多少**。」

## 6. 代數同構：𝒜 ≈ ℛ_𝒜 ≈ M_𝒜(β)

[▶ 40:00](https://youtu.be/dgaYEErpef0?t=2400)【課堂討論】「兩個代數**同構**是什麼意思？」學生：「存在一個從一個到另一個的**同構**。」「我喜歡——**不算錯**。」學生：「**雙射的 $R$-模同態**。」「我想你也對。」

> **定義**[▶ 41:30](https://youtu.be/dgaYEErpef0?t=2490)　$\mathcal{A}\approx\mathcal{B}$（實結合有 1 代數）：存在**線性雙射** $\varphi:\mathcal{A}\to\mathcal{B}$，$\varphi(\mathbb{1}_\mathcal{A}) = \mathbb{1}_\mathcal{B}$，$\varphi(x\star y) = \varphi(x)*\varphi(y)$。

（「這支紅筆**很遜**——**全新**的。Spano 博士在抱怨的就是這個。Expo，**做好一點**。」）

> **Thm 4.8**（講義 p.3；論文）[▶ 43:30](https://youtu.be/dgaYEErpef0?t=2610)　$\mathcal{A}\approx\mathcal{R}_\mathcal{A}\approx M_\mathcal{A}(\beta)$（任一基底 $\beta$）。「**同一個物件的不同圖像**。」

- $\Psi:\mathcal{A}\to\mathcal{R}_\mathcal{A}$，$\Psi(\alpha) = \ell_\alpha$；$\Phi:\mathcal{R}_\mathcal{A}\to M_\mathcal{A}(\beta)$，$\Phi(T) = [T]_{\beta,\beta}$。「同態性質我們**前面的證明已經算過**。」
- 【講義補充】（講義 p.2–3）$\Psi$ 線性；滿射因 $T = \ell_{T(\mathbb{1})}$；保持乘法 $\ell_{\alpha\star\beta} = \ell_\alpha\circ\ell_\beta$（結合律）；$\ker\Psi$：$\ell_\alpha = \mathrm{Id}$ ⇒ 代 $x = \mathbb{1}$ 得 $\alpha = \mathbb{1}$……（講義 p.2 把核寫成 $\Psi(\alpha) = \mathrm{Id}_\mathcal{A}$——作為線性映射的核應是 $\ell_\alpha = 0$ ⇒ $\alpha = \alpha\star\mathbb{1} = 0$，論文 p.9 是這樣寫的。）

**反方向**[▶ 45:30](https://youtu.be/dgaYEErpef0?t=2730)【課堂討論】「從 $M_\mathcal{A}(\beta)$ **回到** $\mathcal{A}$ 怎麼做？」學生：「$\Psi^{-1}\circ\Phi^{-1}$。」「那 $\Psi^{-1}(T)$ 是什麼？」學生：「**$T(\mathbb{1})$**。」「對。」

  第一欄是 $n$ 維向量，座標映射把它變回**抽象**的 $\mathcal{A}$-數——對應 $\mathbb{1}$ 的那個；左乘它就是我們要的變換。」

## 7. 單位、零因子；3-雙曲數

[▶ 50:30](https://youtu.be/dgaYEErpef0?t=3030)「注意三者中**有一個不一樣**：**矩陣**——有 Math 321（甚至 221）的**好工具**。哪個矩陣可逆？」「**行列式不是零**。」
- 【口頭】「每個代數元素（選了基底）對應一個矩陣。可逆 ⇒ 那個元素是**單位**；行列式 0 ⇒ 不是單位。所以**用矩陣表示就能輕易證明**：每個代數元素要嘛是**單位**、要嘛是**零因子**、要嘛是**零**——同構把單位送到單位、零因子送到零因子。」

【講義補充】論文：**Thm 4.13**（同構保持 $\mathbb{1}$、單位、零因子）；**Thm 4.14/Cor 4.15**（$\det\neq0$ ⇒ 反矩陣也在 $M_\mathcal{A}(\beta)$；$\det = 0$ ⇒ 用最小多項式 $m(t) = t(\cdots)$ 得 $AB = 0 = BA$）；**Thm 4.19**：單位群 $\mathcal{A}^\times$ 在 $\mathcal{A}$ 中**稠密**。

**例：3-雙曲數**（論文 Example 4.25）[▶ 52:00](https://youtu.be/dgaYEErpef0?t=3120)：$\mathcal{A} = \mathbb{R}\oplus j\mathbb{R}\oplus j^2\mathbb{R}$，**$j^3 = 1$**——「抱歉，我好像沒說 $j^3 = 1$，這**很重要**，**不該埋了重點**。」其實就是 **3 階循環群的實群代數**。
- 標準基底 $e_1 = 1,e_2 = j,e_3 = j^2$。$\ell_{a+bj+cj^2}$ 作用在 $1,j,j^2$：
$$(a+bj+cj^2)\cdot1,\quad(a+bj+cj^2)j = c+aj+bj^2,\quad(a+bj+cj^2)j^2 = b+cj+aj^2,$$
$$\mathbf{M}(a+bj+cj^2) = \begin{pmatrix}a&c&b\\b&a&c\\c&b&a\end{pmatrix}.$$
- **行列式**[▶ 55:00](https://youtu.be/dgaYEErpef0?t=3300)：老師寫 $(a+b+c)(a^2+b^2+c^2+ab+bc+ac)$，「**可能有負號**，我可能記錯了。」（「我**沒有公式**——**遜**。等等，那是**錯的代數**。」學生：「你**真該隨身帶著**。」「下次再弄清楚。」）
- **零因子**[▶ 57:00](https://youtu.be/dgaYEErpef0?t=3420)：行列式為 0 ⇔ 在**平面** $a+b+c = 0$ 上，或在它的**法線**（$(1,1,1)$ 方向）上。其餘都是單位，反元素可以**解 3×3 反矩陣再追回同構**。

💬 正確的行列式（循環矩陣）：
$$\det = a^3+b^3+c^3-3abc = (a+b+c)(a^2+b^2+c^2-ab-bc-ca),$$
第二個因子 $= \frac12[(a-b)^2+(b-c)^2+(c-a)^2]$，只在 $a = b = c$（法線）時為 0——所以老師的幾何結論正確，只是括號裡應是**負號**。講義也提到 $\mathcal{A}\approx\mathbb{R}\times\mathbb{C}$（$j\mapsto(1,\omega)$）。

【講義補充】論文 §4.1 的其他例子：$\mathbb{C}$（$\mathbf{M}(a+ib) = \begin{pmatrix}a&-b\\b&a\end{pmatrix}$）；**雙曲數** $\mathcal{H}$（$j^2 = 1$，零因子 $a^2 = b^2$，$\mathcal{H}\approx\mathbb{R}\times\mathbb{R}$）；**對偶數** $\mathcal{N}$（$\varepsilon^2 = 0$，零因子 $\varepsilon\mathbb{R}$）；$n$ 階對偶數（下三角 Toeplitz）；$j^4 = 1$ 的代數 $\approx\mathbb{C}\times\mathbb{R}\times\mathbb{R}$；四元數 $\mathbb{H}$；$2\times2$ 矩陣代數；$\mathbb{H}^{2\times2}$；有限群的群代數 $\mathcal{A}_G$，循環群的叫 **$n$-雙曲數**。

## 附：本集一句話總結

> **把「數」推廣成有限維實結合有 1 代數 $\mathcal{A}$：左乘 $\ell_\alpha$ 是右 $\mathcal{A}$-線性的，反過來每個右 $\mathcal{A}$-線性映射都是 $\ell_{T(\mathbb{1})}$（只要乘 1），結合律就是左右乘交換；所有右 $\mathcal{A}$-線性映射構成 $\mathrm{gl}(\mathcal{A})$ 的子代數 $\mathcal{R}_\mathcal{A}$（正則表示），選基底得到矩陣子代數 $M_\mathcal{A}(\beta)$，三者 $\alpha\mapsto\ell_\alpha\mapsto[\ell_\alpha]_\beta$ 互相同構；於是用行列式就能判斷單位與零因子——例如 3-雙曲數 $j^3 = 1$ 的零因子是平面 $a+b+c = 0$ 和它的法線。**
