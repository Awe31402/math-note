# 第 40 集 · L34：實結合代數的正則表示 [▶ 影片](https://www.youtube.com/watch?v=dgaYEErpef0&list=PLBY4G2o7DhF1x_afv1rv_d0hFCoMWEb-j)

## 本集概要

老師自己的研究主題（「$\mathcal{A}$-數」）：
- **有限維實結合有么代數** $\mathcal{A}$：雙線性、結合、有 1。元素叫 **$\mathcal{A}$-數**。
- 左乘 $L_\alpha$、右乘 $R_\alpha$；**右 $\mathcal{A}$-線性**、**左 $\mathcal{A}$-線性**映射。
- 定理：右 $\mathcal{A}$-線性映射都是左乘 $L_{T(1)}$；左乘與右乘交換。
- 右 $\mathcal{A}$-線性映射構成子代數——**正則表示** $\mathcal{R}_\mathcal{A}$；取基底得**矩陣正則表示** $M_\beta(\mathcal{A})$。三者同構。
- 用矩陣判斷單位與零因子（行列式）。
- 例：**三重雙曲數** $\mathbb{R}[\mathbb{Z}_3]$。

> 📘 講義對應：Math422 Lecture 34「Real Associative Algebras」（老師自己的 $\mathcal{A}$-微積分講義 Thm 4.2 等）。

## 筆記

### 1. 定義 [▶ 01:00](https://youtu.be/dgaYEErpef0?t=60)

（老師先去洗馬克筆——「Jacob 用嘴碰過，有小男孩的細菌」。）

> **定義**：$\mathcal{A}$ 是有限維實向量空間，帶乘法 $\star:\mathcal{A}\times\mathcal{A}\to\mathcal{A}$，滿足
> 1. **雙線性**：$(cx+y)\star z = c(x\star z)+y\star z$，$x\star(cy+z) = c(x\star y)+x\star z$；
> 2. **結合**：$(x\star y)\star z = x\star(y\star z)$；
> 3. **有么**：存在 $1_\mathcal{A}$ 使 $1_\mathcal{A}\star x = x = x\star1_\mathcal{A}$。
>
> $x\in\mathcal{A}$ 叫 **$\mathcal{A}$-數**（$\mathcal{A}$-number）——「推廣『數』的概念」。若 $x\star y = y\star x$ 對所有 $x,y$，$\mathcal{A}$ **交換**。

- 這會符合之前 D&F 的 $\mathbb{R}$-代數定義。範圍很廣，「很沒有特色」——所以想了解怎麼**表示**它 [▶ 06:00](https://youtu.be/dgaYEErpef0?t=360)。

### 2. 左乘與右乘 [▶ 07:00](https://youtu.be/dgaYEErpef0?t=420)

$L_\alpha(x) = \alpha\star x$，$R_\alpha(x) = x\star\alpha$。都是實線性的：$L_\alpha(cx+y) = cL_\alpha(x)+L_\alpha(y)$。
- 更多性質（結合律）：
$$L_\alpha(x\star y) = (\alpha\star x)\star y = L_\alpha(x)\star y,\qquad R_\alpha(y\star x) = y\star R_\alpha(x).$$

> **定義**：實線性 $T:\mathcal{A}\to\mathcal{A}$ 是
> 1. **右 $\mathcal{A}$-線性**，若 $T(x\star y) = T(x)\star y$；
> 2. **左 $\mathcal{A}$-線性**，若 $T(x\star y) = x\star T(y)$ [▶ 11:00](https://youtu.be/dgaYEErpef0?t=660)。
>
> 右 $\mathcal{A}$-線性映射的集合記 $\mathcal{R}_\mathcal{A}$。

- 所以**左乘是右 $\mathcal{A}$-線性的**，右乘是左 $\mathcal{A}$-線性的。學生問「$\mathcal{A}$-線性」和實線性差在哪——$\mathcal{A}$-數比實數更一般 [▶ 12:30](https://youtu.be/dgaYEErpef0?t=750)。
- 「有大 $\mathcal{L}$ 嗎？——沒有，不在乎左邊的。它們是邪惡的、左撇子。」

> **定理**（講義 Thm 4.2）：$T$ 是右 $\mathcal{A}$-線性映射，則存在唯一的 $\alpha\in\mathcal{A}$ 使 $T = L_\alpha$。

- 其實實線性可以從條件推出，不用另外假設 [▶ 14:30](https://youtu.be/dgaYEErpef0?t=870)。
- **證明**（學生：「乘 1」）：$T(x) = T(1\star x) = T(1)\star x = L_{T(1)}(x)$。$\alpha = T(1)$ 唯一，因為 $T$ 是函數 [▶ 16:30](https://youtu.be/dgaYEErpef0?t=990)。
- 反過來左乘都是右線性，所以 $\mathcal{R}_\mathcal{A} = \{L_\alpha\mid\alpha\in\mathcal{A}\}$。

**左乘與右乘交換** [▶ 18:00](https://youtu.be/dgaYEErpef0?t=1080)：$L_\alpha R_\beta(x) = \alpha\star(x\star\beta) = (\alpha\star x)\star\beta = R_\beta L_\alpha(x)$。

### 3. 正則表示 [▶ 20:30](https://youtu.be/dgaYEErpef0?t=1230)

$\mathcal{R}_\mathcal{A}$ 是所有實線性映射 $\mathcal{A}\to\mathcal{A}$（老師記作 $GL(\mathcal{A})$，用合成當乘法）的**子代數**：
- **子空間**：$cL_\alpha+L_\beta = L_{c\alpha+\beta}$（老師先繞了遠路，「我想盡量詳細，但有更有趣的要講」）；恆等映射在裡面，所以非空 [▶ 25:30](https://youtu.be/dgaYEErpef0?t=1530)。
- **對合成封閉**（直接證）：$T\circ S(v\star w) = T(S(v)\star w) = T(S(v))\star w$。

> 💬 補充（非課堂內容）：$GL$ 通常指**可逆**線性映射的群；這裡老師指的是所有線性映射 $\mathrm{End}_\mathbb{R}(\mathcal{A})$，它才是對合成構成代數。

> **定義**：$\mathcal{R}_\mathcal{A}$ 叫 $\mathcal{A}$ 的**正則表示**（regular representation）。取基底 $\beta = \{v_1,\dots,v_n\}$，**矩陣正則表示** $M_\beta(\mathcal{A}) = \{[T]_{\beta,\beta}\mid T\in\mathcal{R}_\mathcal{A}\}$。$\mathcal{A} = \mathbb{R}^n$ 用標準基底時直接記 $M(\mathcal{A})$ [▶ 33:00](https://youtu.be/dgaYEErpef0?t=1980)。

- 「正則表示是線性變換還是矩陣？——是。我感受你的痛。」老師跟代數學家討論時也希望他們做個選擇。
- （數論演講的故事：講者說「警告：前方有露骨內容（explicit material）」，下一張投影片全是方程式。）[▶ 35:30](https://youtu.be/dgaYEErpef0?t=2130)
- （學生把子集符號寫成 $\subseteq$ 和 $\le$ 的爭論；「笛卡兒是個白痴，『我思故我在』——你在跟誰說話？」）

> **定理**：$M_\beta(\mathcal{A})$ 是 $\mathbb{R}^{n\times n}$（矩陣乘法）的子代數。

- 核心：$[T_1\circ T_2] = [T_1][T_2]$，而 $T_1\circ T_2\in\mathcal{R}_\mathcal{A}$ [▶ 37:30](https://youtu.be/dgaYEErpef0?t=2250)。
- 換基底：不同基底的矩陣表示**共軛**（相似）。

### 4. 同構 [▶ 40:00](https://youtu.be/dgaYEErpef0?t=2400)

> **定義**：$\mathcal{A}\cong\mathcal{B}$（實結合有么代數），若有線性雙射 $\varphi$ 使 $\varphi(1_\mathcal{A}) = 1_\mathcal{B}$、$\varphi(x\star_\mathcal{A}y) = \varphi(x)\star_\mathcal{B}\varphi(y)$。

（學生：「存在一個同構」——「沒錯。」另一位：「雙射的 $R$-模同態」——「也對」。新的紅色 Expo 馬克筆就已經不太出水。）

> **定理**：$\mathcal{A}\cong\mathcal{R}_\mathcal{A}\cong M_\beta(\mathcal{A})$——同一個物件的不同圖像 [▶ 44:00](https://youtu.be/dgaYEErpef0?t=2640)。

- $\Phi(x) = L_x$；$\Psi(T) = [T]_{\beta,\beta}$（同態性質前面算過）。
- **反方向**：$\Phi^{-1}(T) = T(1)$（學生答出）。$\Psi^{-1}$ 要用基底的細節：取 $v_1 = 1_\mathcal{A}$，則矩陣 $M$ 的**第一欄**就是 $T(1)$ 的座標，所以 $\Theta(M) = $（第一欄的座標反映射）[▶ 48:00](https://youtu.be/dgaYEErpef0?t=2880)。

**用矩陣判斷可逆** [▶ 50:30](https://youtu.be/dgaYEErpef0?t=3030)：每個 $\mathcal{A}$-數對應一個實矩陣，$\det\ne0$ ⇔ 它是**單位**；$\det = 0$ ⇔ 零因子或 0。同構保持單位和零因子，所以「每個元素是單位、零因子或 0」很容易證（第 18 集的三分性）。

### 5. 例：三重雙曲數 [▶ 52:00](https://youtu.be/dgaYEErpef0?t=3120)

$\mathcal{A} = \mathbb{R}\oplus j\mathbb{R}\oplus j^2\mathbb{R}$，$j^3 = 1$——就是循環群 $\mathbb{Z}_3$ 的實群代數（「我沒先說 $j^3 = 1$，埋了重點」）。基底 $e_1 = 1$、$e_2 = j$、$e_3 = j^2$。

$z = a+bj+cj^2$：$z\cdot1 = a+bj+cj^2$，$z\cdot j = c+aj+bj^2$，$z\cdot j^2 = b+cj+aj^2$，所以
$$M(z) = \begin{pmatrix}a&c&b\\b&a&c\\c&b&a\end{pmatrix}.$$
- 行列式含因子 $a+b+c$。老師想不起完整公式（「我好像記得有些負號」），講義翻到的是別的代數 [▶ 55:30](https://youtu.be/dgaYEErpef0?t=3330)。
- 零因子：平面 $a+b+c = 0$，以及它的**法線**（$(1,1,1)$ 方向）。其他元素都可逆，反元素可以由 3×3 矩陣求逆再透過同構拿回來。

> 💬 補充（非課堂內容）：$\det M(z) = (a+b+c)(a^2+b^2+c^2-ab-bc-ca)$。第二個因子 $= \frac12[(a-b)^2+(b-c)^2+(c-a)^2]$，只在 $a = b = c$（法線）時為 0。
