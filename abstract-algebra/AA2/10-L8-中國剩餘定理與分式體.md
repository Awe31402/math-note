## 1. 互極大理想；主理想的乘積

> **定義（互極大 comaximal）**（講義 p.3）[▶ 01:00](https://youtu.be/Z9_n6ipJaYw?t=60)　$R$ 是 $1\neq0$ 的交換環，理想 $A,B$ 若 $A+B = R$，叫**互極大**。

**回顧理想的組合**[▶ 02:30](https://youtu.be/Z9_n6ipJaYw?t=150)
- 和 $A+B$；**積** $AB = \{\sum_{i = 1}^na_ib_i : a_i\in A,b_i\in B\}$——「乘積的有限**線性組合**」。

**主理想的乘積**[▶ 03:30](https://youtu.be/Z9_n6ipJaYw?t=210)：$A = (a)$、$B = (b)$。典型元素：
$$\sum_i(ar_i)(bs_i) = ab\sum_ir_is_i\quad(r_i,s_i\in R)$$
（「不必是同一個環元素，所以用 $s_i$」）⇒ **$(a)(b) = (ab)$**——「把生成元乘起來就好」。
- $k$ 個理想的積 $A_1\cdots A_k$：形如 $a_1a_2\cdots a_k$（$a_j\in A_j$）的乘積的有限和。（「我在**訓練自己**別寫『環係數的線性組合』……那不是重點。」）
- 類似論證：$A_j = (a_j)$ ⇒ $A_1\cdots A_k = (a_1\cdots a_k)$。

## 2. 例：互質整數、(1+x) 與 (1−x)

**例 4：互質 ⇒ 互極大**[▶ 07:30](https://youtu.be/Z9_n6ipJaYw?t=450)「一種**例子的例子**。」$m,n\ge2$（「不然很無聊」），$\gcd(m,n) = 1$。
- 【課堂討論】「**Bézout 定理**說什麼？」學生：「存在 $x,y$……」「我把你們的 $s$ 換成 $x,y$。」**$mx+ny = 1$**。
  - （學生：「它們是交換的。」全班笑。「你聽得到我腦中的聲音嗎？」「聽不到。」「很好。」「那我現在在想什麼？」「這是個**蠢地方**。」）
- $mx\in m\mathbb{Z} = (m)$、$ny\in(n)$ ⇒ $1\in(m)+(n)$。
- 「之前證過：**理想含單位就是整個環**」⇒ $(m)+(n) = \mathbb{Z}$，即 $m\mathbb{Z}+n\mathbb{Z} = \mathbb{Z}$ [▶ 10:00](https://youtu.be/Z9_n6ipJaYw?t=600)。

【口頭】[▶ 10:30](https://youtu.be/Z9_n6ipJaYw?t=630)「互質整數生成的主理想是互極大的。事實上，**互極大理想是把『互質』這個概念用理想的語言形式化**——我們之後該更深入發展這想法。」

**例 5**[▶ 11:00](https://youtu.be/Z9_n6ipJaYw?t=660)：$3\mathbb{Z}+10\mathbb{Z} = \mathbb{Z}$（3、10 互質）；而 $10\mathbb{Z} = (10) = (2\cdot5) = (2)(5) = (2\mathbb{Z})(5\mathbb{Z})$。「耶。」

**例 6：$(1+x)$ 與 $(1-x)$**[▶ 12:00](https://youtu.be/Z9_n6ipJaYw?t=720)「一個你們**可能沒見過**的。」$R$ 交換、有 1；$R[x]$ 也是。
- $I = (1+x) = \{(1+x)f(x)\}$（$1+x$ 的所有倍數）、$J = (1-x)$。都是主理想 ⇒ 理想。
- 【課堂討論】「它們互極大嗎？$1\in I+J$？」[▶ 14:00](https://youtu.be/Z9_n6ipJaYw?t=840)（「想像那是個**大括號**。」學生：「看起來像張臉。」「我該在某些課把大括號重新定義成直線，能省我很多麻煩。」）
- 「我發現例子**不完全一般**：要加個附帶條件——**$1+1 = 2$ 是單位**。」
$$\tfrac12(1+x)+\tfrac12(1-x) = \tfrac12\cdot2 = 1\in I+J\ ⇒\ I+J = R[x].$$
- 「沒有 $\frac12$ 就不能寫——例如在整數環裡不行。」「挑剔的人會說要寫 $2^{-1}$。好，我盡量不當**法利賽人**——還是撒都該人？我不確定該把最在乎數學嚴謹的人歸入哪個宗教階層。大概是法利賽人。」
- 「所以這兩個多項式**互質**——事實上，兩個多項式互質就是**它們生成互極大理想**。」

【Q&A】[▶ 17:00](https://youtu.be/Z9_n6ipJaYw?t=1020) 學生：「互質就一定互極大？」老師：「你說反了？我剛**用互極大定義互質**。你在用雲端裡某個未知的『互質』概念——在互極大之外，你對互質的定義是什麼？」學生：「我們學的那樣。」「那只對**整數**。整數：沒有公因數、最大公因數是 1。」

【口頭】[▶ 18:00](https://youtu.be/Z9_n6ipJaYw?t=1080)「你可能好奇：那兩個 $\frac12$ 怎麼來的？我**憑空**變出來的。但你們有方法找 Bézout 的 $x,y$——**輾轉相除法**。多項式有類似的演算法嗎？」學生：「有。」「**有**是正確答案。我想就叫**多項式的輾轉相除法**。」（全班笑。）「另一堂課講。我只想指出：相似之處比第一眼看到的多。」

## 3. 中國剩餘定理

### 3.1 陳述

[▶ 19:30](https://youtu.be/Z9_n6ipJaYw?t=1170)（中間全班因為字母 $\chi$ 笑——學生：「像 X。」「我前男友叫 Kai。」「真的？」）

> **定理（中國剩餘定理 Chinese Remainder Theorem）**（講義 p.4）[▶ 20:30](https://youtu.be/Z9_n6ipJaYw?t=1230)　$R$ 是 $1\neq0$ 的交換環，$A_1,\dots,A_k$ 是理想。映射
> $$\varphi:R\to R/A_1\times R/A_2\times\cdots\times R/A_k,\quad\varphi(r) = (r+A_1,\ r+A_2,\ \dots,\ r+A_k)$$
> 是**環同態**，$\ker\varphi = A_1\cap A_2\cap\cdots\cap A_k$。
>
> 若 $A_i+A_j = R$ 對所有 $i\neq j$（**兩兩互極大**），則 $\varphi$ **滿射**，而且 $A_1\cap\cdots\cap A_k = A_1A_2\cdots A_k$，所以
> $$\frac{R}{A_1A_2\cdots A_k} = \frac{R}{A_1\cap\cdots\cap A_k}\cong\frac R{A_1}\times\frac R{A_2}\times\cdots\times\frac R{A_k}.$$

【口頭】[▶ 23:30](https://youtu.be/Z9_n6ipJaYw?t=1410)「講義裡我寫 $(A_1A_2\cdots A_k)$ 加了括號——**不需要**。括號表示含那集合的最小理想，那集合本身已經是理想，就已經最小了。」「希望你們不介意我用**整個分數**的記號——書裡**從不**這樣，他們總用**斜著的分數**，好像有點罪惡感。我**沒有**。我覺得比較好讀。」

### 3.2 φ 是環同態，核是交集

[▶ 25:00](https://youtu.be/Z9_n6ipJaYw?t=1500)「第一部分**很放鬆**。」
- $\varphi = (\pi_1,\dots,\pi_k)$，$\pi_j(r) = r+A_j$ 是自然商映射，已知是環同態。
- 一般定理：**映到直積環的映射是環同態 $\iff$ 每個分量函數都是**——理由就是下面的計算 [▶ 26:00](https://youtu.be/Z9_n6ipJaYw?t=1560)：
$$\varphi(r)\varphi(s) = (\pi_1(r),\dots)(\pi_1(s),\dots) = (\pi_1(r)\pi_1(s),\dots) = (\pi_1(rs),\dots) = \varphi(rs).$$
  「直積環的乘法是逐分量的。**我愛這個定理，好酷**。」
- 加法同理：$\pi_j(r+s) = r+s+A_j = (r+A_j)+(s+A_j)$。

**核**[▶ 30:00](https://youtu.be/Z9_n6ipJaYw?t=1800)
- 【口頭】「我跟你們說過我對 **kernel**（念起來像 colonel，**上校**）的看法嗎？有個經典的 **Monty Python** 短劇，黑幫跑去威脅軍隊，在辦公室裡說『要是你外面那些坦克出了什麼事就可惜了』，一直叫他『上校』——很英國。每次我說 kernel 就想到那個短劇，所以 kernel 帶給我快樂。」
- 這裡的核是**加法**的核。直積環的零是 $(A_1,\dots,A_k)$：
$$r\in\ker\varphi\iff r+A_j = A_j\ \forall j\iff r\in A_j\ \forall j\iff r\in\bigcap A_j.$$
- 「這部分證明帶給我快樂——除非**極度睡眠不足**，沒什麼我會搞錯的。」

### 3.3 兩個理想：滿射

[▶ 33:00](https://youtu.be/Z9_n6ipJaYw?t=1980)「我們還沒用互極大。其餘的證明是**歸納法**——先證兩個理想，之後容易歸納。」

設 $A+B = R$，$\varphi(r) = (r+A,\ r+B)$（已知是環同態，核 $A\cap B$）。
- 【口頭】[▶ 34:00](https://youtu.be/Z9_n6ipJaYw?t=2040)「我要停止用 $x$ 當變數……天啊。我改用 $r$。不是錯，只是有點**倒胃口**——因為 $x$ 接下來**不是**任意元素。」
- $1\in R = A+B$ ⇒ **$1 = x+y$**，$x\in A$、$y\in B$（「不唯一——Bézout 的係數通常有很多選擇」）⇒ $1-x = y\in B$、$1-y = x\in A$。
- **算 $\varphi(x)$、$\varphi(y)$**[▶ 37:00](https://youtu.be/Z9_n6ipJaYw?t=2220)（學生糾正幾處字母：「你是說……」「對，你說的那樣。」）
$$\varphi(x) = (x+A,\ x+B) = (A,\ 1-y+B) = (0,\ 1),\qquad\varphi(y) = (y+A,\ y+B) = (1-x+A,\ B) = (1,\ 0).$$
  （$x+B = x+y+B = 1+B$，因為 $y\in B$ 可以加進代表而不改變陪集。）「更好的記號：$(0,1)$ 和 $(1,0)$。**Espeno（西班牙文：我希望）**。」
- **滿射**[▶ 40:00](https://youtu.be/Z9_n6ipJaYw?t=2400)：任取 $(r_1+A,\ r_2+B)$。
$$\varphi(r_2x+r_1y) = \varphi(r_2)\varphi(x)+\varphi(r_1)\varphi(y) = (r_2+A,r_2+B)(0,1)+(r_1+A,r_1+B)(1,0) = (r_1+A,\ r_2+B).$$
  「看它們**翻來覆去**——$x$ 配 $r_2$、$y$ 配 $r_1$，因為它們翻了。」（「$\varphi$ 是個**具體**的函數，不是抽象的……我應該上一步就寫出來。我怎麼了？我兒子。Daniel 以說我們親切地稱為『**Ding 英文**』聞名——由 Daniel 重新定義的英文，我尊重。」）

【課堂討論】[▶ 49:00](https://youtu.be/Z9_n6ipJaYw?t=2940)「你們覺得怎樣？我覺得至少兩個的情況不太壞。」學生：「最難的是看出 $\varphi(x)$、$\varphi(y)$ 分別是 $(0,1)$、$(1,0)$。」「我忘了我說哪個是哪個了。」學生：「跟笛卡兒座標相反。」

### 3.4 兩個理想：A ∩ B = AB

[▶ 43:30](https://youtu.be/Z9_n6ipJaYw?t=2610)
- **$AB\subseteq A\cap B$**：$\tilde x = \sum a_ib_i$。$a_ib_i\in A$（$A$ 是理想，乘 $B$ 的元素）、$a_ib_i\in B$（$B$ 是理想）；和也在 $A$、$B$（子環）⇒ $\tilde x\in A\cap B$。
  - 【口頭】[▶ 46:00](https://youtu.be/Z9_n6ipJaYw?t=2760)「這不在 Dummit & Foote（我在讀 §7.6）——他只宣稱它成立。我替你們補細節。大概是之前的作業題，也許我出過，不記得了。」
- **$A\cap B\subseteq AB$**[▶ 47:00](https://youtu.be/Z9_n6ipJaYw?t=2820)：$c\in A\cap B$（「壞選擇，用 $x$——好吧改用 $c$，貼出前會修」）：
$$c = c\cdot1 = c(x+y) = cx+cy.$$
  $c\in B$、$x\in A$ ⇒ $cx = xc$ 是 $A$、$B$ 元素的乘積；$c\in A$、$y\in B$ ⇒ $cy$ 也是 ⇒ $c\in AB$。
- 所以 $A\cap B = AB$。第一同構定理：
$$R/AB = R/(A\cap B) = R/\ker\varphi\cong R/A\times R/B.$$

### 3.5 歸納到 k 個

[▶ 50:30](https://youtu.be/Z9_n6ipJaYw?t=3030)（投影講義 p.6）設對 $k-1$ 個兩兩互極大的理想成立。令 $A = A_1$、$B = A_2\cdots A_k$。只要證 **$A,B$ 互極大**，就能用兩個的情形。
- 對 $i = 2,\dots,k$：$A_1+A_i = R$ ⇒ 有 $x_i\in A_1$、$y_i\in A_i$，$x_i+y_i = 1$。
- **狡猾的一招**：$x_i+y_i+A_1 = y_i+A_1$（$x_i\in A_1$ 被吸進去）。
- $1 = (x_2+y_2)(x_3+y_3)\cdots(x_k+y_k)$；乘開，凡含某個 $x_i$ 的項都在 $A_1$，只剩 $y_2y_3\cdots y_k\in A_2\cdots A_k$ ⇒ $1\in A_1+A_2\cdots A_k$。
  - 【口頭】[▶ 52:30](https://youtu.be/Z9_n6ipJaYw?t=3150)「為什麼這在那裡面其實**立刻清楚**——我一小時前還會解釋，現在忘了。你們想想。別讓我卡在那，不有趣。」
- 用兩個的情形和歸納假設：
$$\frac R{A_1(A_2\cdots A_k)}\cong\frac R{A_1}\times\frac R{A_2\cdots A_k}\cong\frac R{A_1}\times\frac R{A_2}\times\cdots\times\frac R{A_k}.\ \blacksquare$$

## 4. 推論：單位群與 Euler φ 函數

[▶ 53:30](https://youtu.be/Z9_n6ipJaYw?t=3210)「這定理的應用**非常廣**。」

【口頭】「我沒寫下來：在有 1 的環的脈絡裡，環同態若把 **1 送到 1**，也會把**單位送到單位**。我們這裡就是那個脈絡。」

> **推論**（講義 p.7）　$\gcd(m,n) = 1$ ⇒
> $$(\mathbb{Z}/mn\mathbb{Z})^\times\cong(\mathbb{Z}/m\mathbb{Z})^\times\times(\mathbb{Z}/n\mathbb{Z})^\times.$$
> $n = p_1^{\alpha_1}\cdots p_k^{\alpha_k}$ ⇒
> $$\mathbb{Z}_n\cong\mathbb{Z}_{p_1^{\alpha_1}}\times\cdots\times\mathbb{Z}_{p_k^{\alpha_k}},\qquad\mathbb{Z}_n^\times\cong\mathbb{Z}_{p_1^{\alpha_1}}^\times\times\cdots\times\mathbb{Z}_{p_k^{\alpha_k}}^\times.$$

- 「你們上學期從**群論**知道 $\mathbb{Z}_n$ 那個分解。但這裡還有**乘法結構**可以利用：這裡的單位和各因子的單位，就是單位群的直積。」
- **計數**[▶ 55:00](https://youtu.be/Z9_n6ipJaYw?t=3300)：$|A\times B| = |A||B|$（「若 $A,B$ 無限——去問 **Spano 博士**，那是他的東西。我只是半開玩笑。」）。$|\mathbb{Z}_n^\times| = \varphi(n)$（**Euler $\varphi$ 函數**）⇒
$$\varphi(n) = \varphi(p_1^{\alpha_1})\varphi(p_2^{\alpha_2})\cdots\varphi(p_k^{\alpha_k}).$$
  「這就是讓 Euler $\varphi$ 函數**很好算**的乘性規則之一。」

【講義補充】例（講義 p.7）
- $\varphi(p^\alpha) = p^\alpha-p^{\alpha-1}$：$\varphi(5) = 4$、$\varphi(25) = 20$、$\varphi(125) = 100$。
- $\varphi(100) = \varphi(25)\varphi(4) = 20\cdot2 = 40$（$\mathbb{Z}_4^\times = \{1,3\}$）。
- $\varphi(67) = 66$。

【口頭】[▶ 56:00](https://youtu.be/Z9_n6ipJaYw?t=3360)「之後講到更多章節時，我們會深入這定理的計算和例子。但我覺得今天花時間走完**整個證明**很重要。」

## 5. 分式體的 Dummit & Foote 版本；局部化

[▶ 56:30](https://youtu.be/Z9_n6ipJaYw?t=3390)「我得**懺悔**：上堂課我給你們一個**比較差**的版本——我忙著講一部**動畫**的笑話（領域展開）。你們懂那個梗嗎？好，很好。我其實沒看過那部動畫，是懂的人叫我講的，我接受了任務、執行了。」

「今天我們做了 §7.6；**§7.5 才是分式體**。Dummit & Foote 的版本稍微更一般：不要求整環，而是在交換環裡取**不是零也不是零因子**的元素。」

> **定理**（D&F §7.5 Thm 15，p.261；講義 p.1）　$R$ 交換環，$D\subseteq R$ 非空、不含 0 和零因子、**對乘法封閉**。則存在有 1 的交換環 $Q$，含 $R$ 為子環，且 $D$ 的每個元素在 $Q$ 中都是**單位**。而且：
> 1. $Q$ 的每個元素形如 $rd^{-1}$（$r\in R$、$d\in D$）。特別地，$D = R-\{0\}$ 時 $Q$ 是體。
> 2. $Q$ 是含 $R$、使 $D$ 都變成單位的「**最小**」環：若 $S$ 是有 1 的交換環、$\varphi:R\to S$ 是單射環同態且 $\varphi(d)\in S^\times$，則有單射同態 $\Phi:Q\to S$ 使 $\Phi|_R = \varphi$。

「證明**跟我們做的一模一樣**。」

**例**（講義 p.2）
- E1：$R = \mathbb{Z}$、$D = \mathbb{Z}-\{0\}$ ⇒ $Q = \mathbb{Q}$。
- E2：$R$ 整環 ⇒ $R[x]$ 整環，$R[x]^\times = R^\times$ ⇒ 分式體 = **有理函數** $R(x)$，$(f/g)^{-1} = g/f$。
- E3：$R = 2\mathbb{Z}$（**沒有 1**！）、$D = 2\mathbb{Z}-\{0\}$ ⇒ $Q = \{2a/2b\} = \{a/b\} = \mathbb{Q}$。
  - 【口頭】[▶ 57:30](https://youtu.be/Z9_n6ipJaYw?t=3450)「偶數也能造分式體——那是整環嗎？我們的整環定義要求有 1 嗎？我**一直忘**。」

**局部化**[▶ 58:30](https://youtu.be/Z9_n6ipJaYw?t=3510)：D&F §15.4 有**加強版**——$D$ 可以**含零因子**，還是能造分式環，但有代價。叫 **$D^{-1}R$**，$R$ 在 $D$ 的**局部化（localization）**。「這是更大討論的一部分——我想是**代數幾何**之類的。**更深的魔法**。遠超過這門課。」

### 6.2 中國剩餘定理

$$\varphi(r) = (r+A_1,\dots,r+A_k),\quad\ker\varphi = \bigcap A_j;\quad\text{兩兩互極大 ⇒ }R/(A_1\cdots A_k)\cong\prod R/A_j.$$

| 步驟 | 關鍵一步 |
|---|---|
| 環同態 | 分量 $\pi_j$ 都是 |
| 核 | $r+A_j = A_j\ \forall j$ |
| 滿射（兩個） | $1 = x+y$ ⇒ $\varphi(x) = (0,1)$、$\varphi(y) = (1,0)$；$\varphi(r_2x+r_1y) = (r_1+A,r_2+B)$ |
| $A\cap B = AB$ | $c = cx+cy$ |
| 歸納 | $1 = \prod(x_i+y_i)\in A_1+A_2\cdots A_k$ |

**推論**：$\mathbb{Z}_n\cong\prod\mathbb{Z}_{p_i^{\alpha_i}}$；$\mathbb{Z}_n^\times\cong\prod\mathbb{Z}_{p_i^{\alpha_i}}^\times$；$\varphi(n) = \prod\varphi(p_i^{\alpha_i})$。

## 附：本集一句話總結

> **兩個理想加起來是整個環就叫互極大——這是「互質」在理想語言下的樣子（$\gcd(m,n) = 1$ 時由 Bézout 得 $m\mathbb{Z}+n\mathbb{Z} = \mathbb{Z}$）；中國剩餘定理說 $r\mapsto(r+A_1,\dots,r+A_k)$ 是核為交集的環同態，而兩兩互極大時它滿射、交集等於乘積，所以 $R/(A_1\cdots A_k)\cong\prod R/A_j$——證明關鍵是 $1 = x+y$ 讓 $x,y$ 分別送到 $(0,1)$、$(1,0)$；推論就是 $\mathbb{Z}_n$ 和它的單位群按質數冪分解，Euler $\varphi$ 函數因此是乘性的。**
