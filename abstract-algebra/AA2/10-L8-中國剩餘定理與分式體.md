# 第 10 集 · L8：中國剩餘定理、再談分式體 [▶ 影片](https://www.youtube.com/watch?v=Z9_n6ipJaYw&list=PLBY4G2o7DhF1x_afv1rv_d0hFCoMWEb-j)

## 本集概要

Dummit & Foote §7.6：
- **互極大理想**（comaximal ideals）：$A+B = R$。這是「互質」在理想語言中的版本。
- 主理想的積：$(a)(b) = (ab)$。
- 例：$\gcd(m,n) = 1\Rightarrow m\mathbb{Z}+n\mathbb{Z} = \mathbb{Z}$；$2$ 可逆時 $(1+x)+(1-x) = R[x]$。
- **中國剩餘定理**（Chinese Remainder Theorem）完整證明：$R/(A_1\cdots A_k)\cong R/A_1\times\cdots\times R/A_k$。
- 應用：$U(mn)\cong U(m)\times U(n)$；Euler $\varphi$ 的乘法性。
- 回頭補 D&F §7.5 的**分式環**（$Q = D^{-1}R$）與 §15.4 的**局部化**。

> 📘 講義對應：Math422 Lecture 8「Chinese Remainder Theorem」；D&F §7.5–7.6、§15.4。

## 筆記

### 1. 互極大理想 [▶ 01:00](https://youtu.be/Z9_n6ipJaYw?t=60)

（開場：學生說「我是中國人！」）

> **定義**：$R$ 是交換環，$1\ne0$。理想 $A,B$ 叫**互極大**（comaximal），若 $A+B = R$。

**複習：理想的積** [▶ 02:30](https://youtu.be/Z9_n6ipJaYw?t=150)：$AB = \{\sum_{i=1}^na_ib_i\}$。
- **主理想的積就是生成元的積**：$A = (a)$、$B = (b)$ 時，典型元素 $\sum(ar_i)(bs_i) = ab\sum r_is_i$，所以 $AB = (ab)$ [▶ 04:30](https://youtu.be/Z9_n6ipJaYw?t=270)。
- $k$ 個理想 $A_1\cdots A_k$ 的積：$x_1x_2\cdots x_k$（$x_i\in A_i$）的有限和。全是主理想時，積的生成元是生成元的積 [▶ 06:00](https://youtu.be/Z9_n6ipJaYw?t=360)。

### 2. 互極大的例子 [▶ 07:30](https://youtu.be/Z9_n6ipJaYw?t=450)

**例（$\mathbb{Z}$）**：$m,n\ge2$、$\gcd(m,n) = 1$。由 **Bézout 定理**，有 $x,y$ 使 $mx+ny = 1$ [▶ 08:00](https://youtu.be/Z9_n6ipJaYw?t=480)。$mx\in m\mathbb{Z}$、$ny\in n\mathbb{Z}$，所以 $1\in m\mathbb{Z}+n\mathbb{Z}$。理想含單位就是全部，所以 $m\mathbb{Z}+n\mathbb{Z} = \mathbb{Z}$ [▶ 10:00](https://youtu.be/Z9_n6ipJaYw?t=600)。
- **互極大 = 理想語言的「互質」**。
- $3\mathbb{Z}+10\mathbb{Z} = \mathbb{Z}$；$10\mathbb{Z} = (2)(5) = 2\mathbb{Z}\cdot5\mathbb{Z}$ [▶ 11:00](https://youtu.be/Z9_n6ipJaYw?t=660)。

**例（多項式）** [▶ 12:00](https://youtu.be/Z9_n6ipJaYw?t=720)：$R$ 交換、有 1。$I = (1+x)$、$J = (1-x)$ 在 $R[x]$ 中互極大嗎？
- 需要加條件：**$2 = 1+1$ 是 $R$ 的單位** [▶ 15:00](https://youtu.be/Z9_n6ipJaYw?t=900)。則
$$\tfrac12(1+x)+\tfrac12(1-x) = 1.$$
- 在 $\mathbb{Z}$ 上不能寫 $\frac12$。（「$\frac12$ 其實是 $2^{-1}$——我不想當法利賽人。」）
- 兩個多項式**互質**，就定義成它們生成互極大的理想 [▶ 16:30](https://youtu.be/Z9_n6ipJaYw?t=990)。學生問反過來呢？——除了整數的「最大公因數是 1」，我們還沒有別的「互質」定義。
- $\frac12$ 是怎麼想出來的？整數有**歐幾里得演算法**找 Bézout 係數；多項式也有，之後講 [▶ 18:30](https://youtu.be/Z9_n6ipJaYw?t=1110)。

### 3. 中國剩餘定理 [▶ 19:30](https://youtu.be/Z9_n6ipJaYw?t=1170)

（學生看到 $\varphi$ 寫得像 $\chi$ 笑了：「我前男友叫 Kai」。）

> **定理**（中國剩餘定理）：$R$ 是交換環，$1\ne0$，$A_1,\dots,A_k$ 是理想。映射
> $$\varphi:R\to R/A_1\times R/A_2\times\cdots\times R/A_k,\qquad\varphi(x) = (x+A_1,\dots,x+A_k)$$
> 是環同態，$\ker\varphi = A_1\cap\cdots\cap A_k$。
>
> 若兩兩互極大（$A_i+A_j = R$，$i\ne j$），則 $\varphi$ 是滿射，且 $A_1\cap\cdots\cap A_k = A_1\cdots A_k$，所以
> $$R/(A_1A_2\cdots A_k)\cong R/A_1\times R/A_2\times\cdots\times R/A_k.$$

- 老師喜歡用真正的分數線寫 $\dfrac{R}{A}$，「書上總是用斜線，好像寫成分數有點罪惡感」[▶ 24:30](https://youtu.be/Z9_n6ipJaYw?t=1470)。

**證明：同態** [▶ 25:00](https://youtu.be/Z9_n6ipJaYw?t=1500)：$\varphi = (\pi_1,\dots,\pi_k)$，$\pi_j(x) = x+A_j$ 是自然映射。積環中逐分量運算，所以
$$\varphi(x)\varphi(y) = (\pi_1(x)\pi_1(y),\dots) = (\pi_1(xy),\dots) = \varphi(xy).$$
加法同理。一般地：**映到積環的映射是同態 ⇔ 每個分量都是同態**。「我愛這個定理。」

**證明：核** [▶ 30:30](https://youtu.be/Z9_n6ipJaYw?t=1830)：$\varphi(x) = (A_1,\dots,A_k)$（積環的零）$\iff x+A_i = A_i$ 對每個 $i$ $\iff x\in A_i$ 對每個 $i$ $\iff x\in\bigcap A_i$。「除非極度缺乏睡眠，這部分不可能出錯。」

> 💬 老師說每次講「kernel」都想到 Monty Python 的短劇：黑道威脅軍官「要是那些坦克出了什麼事就可惜了，colonel」[▶ 29:30](https://youtu.be/Z9_n6ipJaYw?t=1770)。

**證明：兩個理想、滿射** [▶ 33:00](https://youtu.be/Z9_n6ipJaYw?t=1980)：$A+B = R$，$\varphi(r) = (r+A,r+B)$。
- 有 $x\in A$、$y\in B$ 使 $1 = x+y$（不唯一，像 Bézout 係數）[▶ 35:00](https://youtu.be/Z9_n6ipJaYw?t=2100)。
- $\varphi(x) = (x+A,x+B) = (A,\ x+y+B) = (0,1)$；$\varphi(y) = (y+A,B) = (x+y+A,\ B) = (1,0)$ [▶ 37:00](https://youtu.be/Z9_n6ipJaYw?t=2220)。
- 任意 $(r_1+A,r_2+B)$：注意交叉配對 [▶ 41:00](https://youtu.be/Z9_n6ipJaYw?t=2460)，
$$\varphi(r_2x+r_1y) = \varphi(r_2)(0,1)+\varphi(r_1)(1,0) = (r_1+A,\ r_2+B).$$
- 「最難的是記得 $\varphi(x)$ 和 $\varphi(y)$ 分別是 $(0,1)$ 和 $(1,0)$。」學生：「跟直角座標相反。」[▶ 49:30](https://youtu.be/Z9_n6ipJaYw?t=2970)

**證明：$A\cap B = AB$** [▶ 44:00](https://youtu.be/Z9_n6ipJaYw?t=2640)（D&F 只說「成立」，這是老師補的細節）
- $AB\subseteq A\cap B$：$a_ib_i$ 在 $A$ 中（$A$ 是理想）也在 $B$ 中，和也是。（這部分不需要互極大。）
- $A\cap B\subseteq AB$：$c\in A\cap B$，$c = c\cdot1 = c(x+y) = cx+cy$。$cx = $（$B$ 的元素）×（$A$ 的元素），$cy = $（$A$ 的）×（$B$ 的），所以 $c\in AB$ [▶ 47:00](https://youtu.be/Z9_n6ipJaYw?t=2820)。

由第一同構定理，$R/(A\cap B) = R/AB\cong R/A\times R/B$ [▶ 50:00](https://youtu.be/Z9_n6ipJaYw?t=3000)。

**$k$ 個理想（歸納）** [▶ 50:30](https://youtu.be/Z9_n6ipJaYw?t=3030)：設 $k-1$ 個成立。令 $A = A_1$、$B = A_2\cdots A_k$，只要證 $A+B = R$。
- 對 $i = 2,\dots,k$，有 $x_i\in A_1$、$y_i\in A_i$ 使 $x_i+y_i = 1$。
- $1 = \prod_{i=2}^k(x_i+y_i)$，展開後除了 $y_2\cdots y_k\in A_2\cdots A_k$ 以外，每一項都含某個 $x_i\in A_1$。所以 $1\in A_1+A_2\cdots A_k$。
- （老師說「一小時前我還會解釋，現在忘了」，留給大家想。）再用兩個理想的情況和歸納假設。

### 4. 應用 [▶ 53:30](https://youtu.be/Z9_n6ipJaYw?t=3210)

- 有 1 的環之間把 1 送到 1 的同態會把單位送到單位。所以 $\gcd(m,n) = 1$ 時
$$\mathbb{Z}_{mn}\cong\mathbb{Z}_m\times\mathbb{Z}_n,\qquad U(mn)\cong U(m)\times U(n).$$
- $n = p_1^{e_1}\cdots p_r^{e_r}$ 時 $\mathbb{Z}_n\cong\mathbb{Z}_{p_1^{e_1}}\times\cdots\times\mathbb{Z}_{p_r^{e_r}}$——上學期學過群的版本，現在多了**乘法結構**可以用。
- 數單位：$|A\times B| = |A||B|$（「無窮的話去問 Spano 博士」）。所以
$$\varphi(n) = \varphi(p_1^{e_1})\cdots\varphi(p_r^{e_r}),$$
Euler $\varphi$ 函數的乘法性 [▶ 55:30](https://youtu.be/Z9_n6ipJaYw?t=3330)。

### 5. 回頭看 D&F §7.5 [▶ 56:30](https://youtu.be/Z9_n6ipJaYw?t=3390)

- 老師承認上次「忙著開動漫的玩笑」講得不夠好（「我沒看過那部動漫，是懂的人叫我講這個梗的」）。今天做的是 §7.6；**§7.5 才是分式體那一節**。
- D&F 更一般：在交換環 $R$ 中，取 $D$ = 非零、非零因子的元素，構造 $Q$，每個元素形如 $rd^{-1}$。$Q$ 是包含 $R$、且讓 $D$ 中元素都變成單位的**最小**環。
- D&F §15.4（超出本課）：連零因子都放進 $D$ 也能做，但有代價——這叫 $R$ 在 $D$ 的**局部化**（localization），是代數幾何的一部分，「更深的魔法」[▶ 59:00](https://youtu.be/Z9_n6ipJaYw?t=3540)。

> 💬 補充（非課堂內容）：D&F §7.5 一般情況下得到的 $Q$ 叫**分式環**（ring of fractions），只有 $R$ 是整環時才是體（分式體）。老師課堂上一律說「field of fractions」。老師也不確定我們的整環定義是否要求有 1——第 5 集的定義是要求的（所以 $2\mathbb{Z}$ 不是整環，但仍可用 D&F 的方法做出分式環 $\mathbb{Q}$）。
