# 第 35 集 · L30：張量代數、對稱代數、外代數 [▶ 影片](https://www.youtube.com/watch?v=qetUDPSDFJQ&list=PLBY4G2o7DhF1x_afv1rv_d0hFCoMWEb-j)

## 本集概要

主要是 D&F §11.5，先補 §11.2 和 §10.4 的尾巴：
- 擴張純量：$K\otimes_FW$ 是 $K$ 上同維數的向量空間，基底 $1\otimes w_i$。
- 線性變換的張量積 $\varphi\otimes\psi$；矩陣是 **Kronecker 積**。
- $R$-代數的張量積；$R^s\otimes R^t\cong R^{st}$。
- **張量代數** $T(M) = \bigoplus_kT^k(M)$，乘法 = 串接；**分級環**、分級理想。
- 例：$T_\mathbb{Z}(\mathbb{Q}/\mathbb{Z}) = \mathbb{Z}\oplus\mathbb{Q}/\mathbb{Z}$；$T_\mathbb{Z}(\mathbb{Z}/n)\cong\mathbb{Z}[x]/(nx)$。
- $\dim T^k(V) = n^k$。**對稱代數** $S(M)$、**外代數** $\bigwedge M$；泛性質；楔積與外積、行列式。

> 📘 講義對應：Math422 Lecture 30「Tensor Algebras, Symmetric & Exterior Algebras」；D&F §11.2（Prop. 15）、§10.4 尾、§11.5（Thm 31、Prop. 33、Thm 34）。

## 筆記

### 1. 向量空間的張量積（§11.2）[▶ 01:00](https://youtu.be/qetUDPSDFJQ?t=60)

（Avery 生病沒來；「Emma 傳染給她的」。）

> **命題 15**（§11.2）：$F\subseteq K$ 是子體，$W$ 是 $F$ 上的 $m$ 維向量空間，基底 $w_1,\dots,w_m$。則 $K\otimes_FW$ 是 $K$ 上的 $m$ 維向量空間，基底 $1\otimes w_1,\dots,1\otimes w_m$。

- 這就是**擴張純量**：把 $F$-向量空間變成 $K$-向量空間，維數不變 [▶ 02:30](https://youtu.be/qetUDPSDFJQ?t=150)。

**線性變換的張量積** [▶ 03:30](https://youtu.be/qetUDPSDFJQ?t=210)：$V,W,X,Y$ 是 $F$ 上的有限維向量空間，基底 $\beta_1 = \{v_i\}$、$\beta_2 = \{w_j\}$、$\epsilon_1 = \{x_p\}$（$r$ 個）、$\epsilon_2 = \{y_q\}$（$s$ 個）。
- $V\otimes W$ 的基底 $\beta = \{v_i\otimes w_j\}$，$X\otimes Y$ 的基底 $\epsilon = \{x_p\otimes y_q\}$，都用**字典序**：$v_1\otimes w_1,v_1\otimes w_2,\dots,v_n\otimes w_m$ [▶ 07:30](https://youtu.be/qetUDPSDFJQ?t=450)。
- $\varphi:V\to X$、$\psi:W\to Y$ 線性，$(\varphi\otimes\psi)(v\otimes w) = \varphi(v)\otimes\psi(w)$——學生猜到 [▶ 14:30](https://youtu.be/qetUDPSDFJQ?t=870)。

> **定義**：$A = (\alpha_{ij})$ 是 $r\times n$、$B$ 是 $s\times m$（係數在交換環中）。**Kronecker 積**（tensor product）$A\otimes B$ 是 $rs\times nm$ 矩陣，由 $r\times n$ 個區塊組成，第 $(i,j)$ 區塊是 $\alpha_{ij}B$ [▶ 08:30](https://youtu.be/qetUDPSDFJQ?t=510)。

**例**：
$$\begin{pmatrix}1&2\\3&4\end{pmatrix}\otimes\begin{pmatrix}1&0\\0&1\end{pmatrix} = \begin{pmatrix}1&0&2&0\\0&1&0&2\\3&0&4&0\\0&3&0&4\end{pmatrix}.$$

> **定理**：$[\varphi\otimes\psi]_\beta^\epsilon = [\varphi]_{\beta_1}^{\epsilon_1}\otimes[\psi]_{\beta_2}^{\epsilon_2}$——這就是 Kronecker 積這樣定義的原因 [▶ 15:30](https://youtu.be/qetUDPSDFJQ?t=930)。

- 講義例 2：$R_2(\alpha+i\beta) = \begin{pmatrix}\alpha&\beta\\-\beta&\alpha\end{pmatrix}$，$R_4 = I_2\otimes R_2(\lambda)+N_2\otimes I_2$、$R_6 = I_3\otimes R_2(\lambda)+N_3\otimes I_2$——實 Jordan 塊。
- 老師想用這套理解 Math 321 的**複化**與複／實 Jordan 形，可能出作業。學生問：線性變換總能寫成矩陣嗎？——有限維時可以 [▶ 16:30](https://youtu.be/qetUDPSDFJQ?t=990)。

**§10.4 的尾巴** [▶ 17:30](https://youtu.be/qetUDPSDFJQ?t=1050)
- $R$-代數的張量積 $A\otimes_RB$ 是 $R$-代數：$(a_1\otimes b_1)(a_2\otimes b_2) = a_1a_2\otimes b_1b_2$（學生答出）。體上時維數相乘。
- $R^s\otimes_RR^t\cong R^{st}$（$R$ 交換）。

### 2. 張量代數（§11.5）[▶ 21:00](https://youtu.be/qetUDPSDFJQ?t=1260)

「很容易，但要真正掌握又很深。」$R$ 交換，$M$ 是 $R$-模（以下 $\otimes = \otimes_R$）：
$$T^0(M) = R,\quad T^1(M) = M,\quad T^2(M) = M\otimes M,\quad\dots,\quad T^k(M) = M\otimes\cdots\otimes M\ (k\text{ 次}).$$
- （學生把「more, M」聽成「more mom」。）每個 $T^k$ 都良定義：$k$ 重笛卡兒積上的自由模，模掉強制多線性的子模——上次的定義 [▶ 23:30](https://youtu.be/qetUDPSDFJQ?t=1410)。

> **定義**：**張量代數** $T(M) = \bigoplus_{k=0}^\infty T^k(M) = R\oplus M\oplus(M\otimes M)\oplus\cdots$（外直和）。它是 $R$-代數。

- 加法：同階的張量相加。**乘法 = 串接** [▶ 25:30](https://youtu.be/qetUDPSDFJQ?t=1530)：
$$(m_1\otimes\cdots\otimes m_i)(m'_1\otimes\cdots\otimes m'_j) = m_1\otimes\cdots\otimes m_i\otimes m'_1\otimes\cdots\otimes m'_j.$$
- 像 Spano 博士講的**自由群**：兩個「字」相乘就是接起來。（學生：「我們有講『字』！」——「所以教學要用標準名稱，不然大家不知道自己學過。」學生反擊：「那你幹嘛一直用 Pac-Man？」——「安靜你的臉。」）

### 3. 分級環 [▶ 28:00](https://youtu.be/qetUDPSDFJQ?t=1680)

> **定義**：
> 1. 環 $S = S_0\oplus S_1\oplus\cdots$（加法群直和）叫**分級環**（graded ring），若 $S_kS_\ell\subseteq S_{k+\ell}$。$S_k$ 叫 $k$ 次**齊次分量**，其元素叫 $k$ 次**齊次元素**。
> 2. 理想 $I$ 是**分級理想**，若 $I = \bigoplus_k(I\cap S_k)$。
> 3. $\varphi:S\to T$ 是**分級環同態**，若 $\varphi(S_k)\subseteq T_k$。

- 下標是標籤不是次方（老師一開始寫成上標；學生：「那要把高等微積分帶回第三次作業嗎？」）[▶ 30:30](https://youtu.be/qetUDPSDFJQ?t=1830)。
- $T(M)$ 是分級環，齊次分量是 $T^k(M)$。

> **命題 33**：$I$ 是分級理想，則 $S/I$ 是分級環，$k$ 次齊次分量 $\cong S_k/I_k$ [▶ 33:30](https://youtu.be/qetUDPSDFJQ?t=2010)。

- $M$ 不必是向量空間；例如流形上的光滑函數構成交換環（不是體——非零函數不一定可逆），其上的模很重要 [▶ 35:00](https://youtu.be/qetUDPSDFJQ?t=2100)。

**例** [▶ 36:00](https://youtu.be/qetUDPSDFJQ?t=2160)
- $R = \mathbb{Z}$、$M = \mathbb{Q}/\mathbb{Z}$：$\mathbb{Q}/\mathbb{Z}\otimes\mathbb{Q}/\mathbb{Z} = 0$，所以 $T^k = 0$（$k\ge2$），$T(M) = \mathbb{Z}\oplus\mathbb{Q}/\mathbb{Z}$。
- $R = \mathbb{Z}$、$M = \mathbb{Z}/n$：$\mathbb{Z}/n\otimes\mathbb{Z}/n\cong\mathbb{Z}/n$，所以 $T(M)\cong\mathbb{Z}\oplus\mathbb{Z}/n\oplus\mathbb{Z}/n\oplus\cdots$。寫成多項式的商？學生猜「$\mathbb{Z}[x]/(x)$」（那只剩 $\mathbb{Z}$），再猜到 **$\mathbb{Z}[x]/(nx)$** [▶ 39:30](https://youtu.be/qetUDPSDFJQ?t=2370)。

> **定理**：$V$ 是 $F$ 上的 $n$ 維向量空間，基底 $v_1,\dots,v_n$。$T^k(V)$ 的基底是 $\{v_{i_1}\otimes\cdots\otimes v_{i_k}\mid1\le i_1,\dots,i_k\le n\}$，所以 $\dim T^k(V) = n^k$ [▶ 41:00](https://youtu.be/qetUDPSDFJQ?t=2460)。

- $k = 0$：體本身，1 維；$k = 1$：$n$ 維；$k = 2$：$n^2$ 維。（「我是向量空間派的——好吧，也涉獵環。」）

### 4. 對稱代數與外代數 [▶ 43:00](https://youtu.be/qetUDPSDFJQ?t=2580)

> **定義**：$C(M)$ = 由 $m_1\otimes m_2-m_2\otimes m_1$ 生成的理想。**對稱代數** $S(M) = T(M)/C(M)$。（有時用 $\odot$ 表示對稱張量積，D&F 沒用。）

> **定義**：$A(M)$ = 由 $m\otimes m$ 生成的理想。**外代數** $\bigwedge M = T(M)/A(M)$；$m_1\otimes\cdots\otimes m_k$ 的陪集記作 $m_1\wedge\cdots\wedge m_k$（**楔積**）[▶ 45:30](https://youtu.be/qetUDPSDFJQ?t=2730)。

- 老師在高等微積分課具體地用多線性映射建構楔積，「從沒真正定義它，只是繞著它講」；這裡的定義簡單得多 [▶ 47:30](https://youtu.be/qetUDPSDFJQ?t=2850)。（學生拿出一個很大的 $\wedge$ 符號。）
- $C(M)$、$A(M)$ 是分級理想嗎？老師「還沒想過」；若是，由命題 33 商也是分級的 [▶ 49:00](https://youtu.be/qetUDPSDFJQ?t=2940)。

**泛性質** [▶ 50:30](https://youtu.be/qetUDPSDFJQ?t=3030)（講義印得太小，老師在省紙——「我一直在印 chat」）
- **Thm 31**：$T(M)$ 是分級 $R$-代數；任何 $R$-模同態 $M\to A$（$A$ 是 $R$-代數）唯一延伸成 $R$-代數同態 $T(M)\to A$。
- **Thm 34**：$S(M)$ 中 $k$-張量可以任意重排；$M^k$ 上的**對稱**多線性映射 ↔ $S^k(M)$ 出發的 $R$-模同態。
- 外代數同理：**交錯**多線性映射 ↔ $\bigwedge^kM$ 出發的模同態。

**例：微積分三的回憶** [▶ 54:30](https://youtu.be/qetUDPSDFJQ?t=3270)：$\omega_a = a_1e_1+a_2e_2+a_3e_3$，
$$\omega_a\wedge\omega_b = (a_2b_3-a_3b_2)\,e_2\wedge e_3+(a_3b_1-a_1b_3)\,e_3\wedge e_1+(a_1b_2-a_2b_1)\,e_1\wedge e_2,$$
- 這是 $a\times b$ 的**通量形式**（flux form）——三維的楔積自動編碼了**外積**。
- 三個相乘：$\omega_a\wedge\omega_b\wedge\omega_c = a\cdot(b\times c)\,e_1\wedge e_2\wedge e_3$——**行列式**。Math 321 花了約一週半用楔積研究行列式 [▶ 57:00](https://youtu.be/qetUDPSDFJQ?t=3420)。
