## 1. PID 中質 ⟺ 不可約

> **定理**（講義 p.1）[▶ 05:30](https://youtu.be/kkhFGMMk9pk?t=330)　在**主理想整環（PID）**中，$a$ 是質元 $\iff$ $a$ 不可約。

「PID 是**每個理想都由一個元素生成**的整環。」（「今天大家**很愛笑**。我怪 Schwitzer 博士。」）

**(⇒)**[▶ 07:30](https://youtu.be/kkhFGMMk9pk?t=450)：PID 是整環，Thm 4.7.8 直接給。「一半的工作上次就做完了。」

**(⇐)**[▶ 08:00](https://youtu.be/kkhFGMMk9pk?t=480)「我們的任務——如果你選擇接受的話——是證 $a$ 是質元。」設 $a$ 不可約、$a\mid bc$。令
$$I = \{ax+by : x,y\in D\}.$$
- $I$ 是理想（「差還是這種形式、吸收乘法——例行公事」）⇒ $I = (d)$。
- $a = a\cdot1+b\cdot0\in I$ ⇒ $a = rd$。$a$ 不可約 ⇒ **$r$ 或 $d$ 是單位**。（學生小聲答。「別擔心，我沒聽到你說什麼。**你的秘密安全了**。」）

**情形 1：$d$ 是單位**[▶ 12:00](https://youtu.be/kkhFGMMk9pk?t=720)：$I = D$ ⇒ 可選 $x,y$ 使 $ax+by = 1$ ⇒
$$c = c(ax+by) = acx+(bc)y.$$
$a\mid acx$、$a\mid bc$ ⇒ $a\mid c$。

**情形 2：$r$ 是單位**[▶ 14:00](https://youtu.be/kkhFGMMk9pk?t=840)：$a = rd$ ⇒ $a$、**$d$** 相伴（學生糾正：老師先寫成 $a$、$r$）⇒ $(d) = (a) = I$。$b = a\cdot0+b\cdot1\in I$ ⇒ $b = a\lambda$ ⇒ $a\mid b$。

所以 $a\mid bc$ ⇒ $a\mid b$ 或 $a\mid c$，$a$ 是質元。$\blacksquare$

💬 講義 p.2 情形 (ii) 也寫「$a$ & $r$ are associates」——應該是 **$a$ 和 $d$** 相伴（$r$ 是單位，所以 $a = rd$ 說的是 $a\sim d$）。

## 2. ℤ[x] 不是 PID

**例 2**[▶ 16:00](https://youtu.be/kkhFGMMk9pk?t=960)：$\mathbb{Z}$ 是 PID，理想都是 $(n)$。
- 「任何環都可以問：**環的性質會不會傳到它的多項式環**？有時會、有時不會。這裡**不會**：$\mathbb{Z}[x]$ 不是 PID。」

**標準例子**：$I = (2,x) = \{2f(x)+xg(x) : f,g\in\mathbb{Z}[x]\}$。

**證明（反證）**[▶ 18:00](https://youtu.be/kkhFGMMk9pk?t=1080)「現在先用**正面對決**；之後會有更多理論工具。」設 $I = (d(x))$。$x,2\in I$ ⇒
$$x = d(x)g(x)\quad(*),\qquad2 = d(x)h(x)\quad(**).$$
- 【口頭】[▶ 19:30](https://youtu.be/kkhFGMMk9pk?t=1170)「記得前幾天 $1+x$、$1-x$ 那個例子——我說在 $\mathbb{Z}[x]$ 上證它們互極大會**有麻煩**。剛剛這種論證就能證明我那時說的。」
- 在 $x = 0$ 代值：$0 = d(0)g(0)$、$2 = d(0)h(0)$ ⇒ $d(0)\neq0$ ⇒ **$g(0) = 0$**（「這個 **Pac-Man** 告訴我們」）⇒ $g(x) = c_1x+\cdots$。
- $x = d(x)(c_1x+\cdots)$ ⇒ 【課堂討論】[▶ 22:00](https://youtu.be/kkhFGMMk9pk?t=1320)「$d(x)$ 能是什麼？」學生：「常數。」⇒ $d(0)c_1 = 1$ ⇒ $d = \pm1$。
- $\pm1$ 生成**整個** $\mathbb{Z}[x]$（「**一整窩貓咪**」）。但 $I$ 裡的多項式常數項都是**偶數**，例如 $3+x\notin I$ ⇒ 矛盾。$\blacksquare$

## 3. 歐氏整環 ⇒ PID

> **命題 1**（講義 p.3）[▶ 25:30](https://youtu.be/kkhFGMMk9pk?t=1530)　**歐氏整環的每個理想都是主理想**。事實上，若 $I\neq0$，則 $I = (d)$，$d$ 是 $I$ 中**範數最小**的任一非零元素。

（「你說抱歉，但我不信。把你的抱歉**裝進袋子**。」）

**證明**[▶ 27:30](https://youtu.be/kkhFGMMk9pk?t=1650)：$D$ 歐氏整環、範數 $N$，$I\neq0$。
- $S = \{N(x) : x\in I\}$ 是 $\mathbb{N}\cup\{0\}$ 的非空子集 ⇒ **良序原理**：有最小元 $s_0$ ⇒ 有 $x_0\in I$、$N(x_0) = s_0$。
- 任取 $z\in I$，除法算法：$z = qx_0+r$，$r = 0$ 或 $N(r)<N(x_0)$。
- $z\in I$、$qx_0\in I$（「**超級封閉**」）⇒ $r = z-qx_0\in I$。
- 【課堂討論】[▶ 32:00](https://youtu.be/kkhFGMMk9pk?t=1920)「這逼出什麼？」學生：「$r = 0$。」否則 $r$ 是範數比最小還小的元素，**和 $x_0$ 的取法矛盾**。
- ⇒ $z = qx_0\in(x_0)$ ⇒ $I\subseteq(x_0)$；$x_0\in I$ ⇒ $(x_0)\subseteq I$。所以 $I = (x_0)$。$\blacksquare$

> **推論**（講義 p.3）　**歐氏整環 ⇒ PID**。

**例 3**[▶ 33:30](https://youtu.be/kkhFGMMk9pk?t=2010)【課堂討論】「$\mathbb{Z}[x]$ 不是一個 ___。$\mathbb{Z}[x]$ 上**不存在任何** ___ ……」學生：「歐氏整環。」「為什麼？」「因為它不是 PID。」
- 「這說得**非常強**：$\mathbb{Z}[x]$ 上可以造的無窮多種範數，**全都注定失敗**，沒有一個能支援除法算法——否則 $\mathbb{Z}[x]$ 就是 PID 了，而我們證了它不是。」

（[▶ 36:00](https://youtu.be/kkhFGMMk9pk?t=2160)「我剛在別班講**彈簧**，所以講得有點快。」學生：「什麼彈簧？」「**慢**的彈簧——因摩擦而慢。」「教科書有這個嗎？」「有。」「你寫的那本？」「我寫的那本。」）

## 4. 最大公因數與理想

> **定義**（講義 p.4）[▶ 36:30](https://youtu.be/kkhFGMMk9pk?t=2190)　$R$ 交換環，$a,b\in R$、$b\neq0$。
> 1. 若 $a = br$，$a$ 是 $b$ 的**倍數**，$b$ **整除** $a$，寫 $b\mid a$。
> 2. $a,b$ 的**最大公因數**是非零 $d$：(i) $d\mid a$、$d\mid b$；(ii) $d'\mid a$、$d'\mid b$ ⇒ $d'\mid d$。
>
> 記號：$\gcd(a,b) = d = (a,b)$——「這記號**預告**了理想的寫法」。

💬 [▶ 37:00](https://youtu.be/kkhFGMMk9pk?t=2220) 老師口頭說「$b$ 是 $a$ 的倍數，此時說 $b$ 整除 $a$」——口誤，應是 **$a$ 整除 $b$**。講義寫法正確。

**理想的語言**[▶ 38:00](https://youtu.be/kkhFGMMk9pk?t=2280)：
$$b\mid a\iff a\in(b)\iff(a)\subseteq(b);\qquad d\mid a,\ d\mid b\ ⇒\ (a,b)\subseteq(d);\qquad d'\mid d\iff(d)\subseteq(d').$$
「注意字母順序**翻過來**，包含關係也反過來。」（「是 Emma 的**後腦勺**看起來很好笑。」「下一個幫我剪頭髮。」「我只會剪平頭。」）

> **命題 2**（講義 p.4）[▶ 39:30](https://youtu.be/kkhFGMMk9pk?t=2370)　$a,b\neq0$，若 $(a,b) = (d)$，則 $d$ 是 $a,b$ 的一個 gcd。

【口頭】[▶ 40:00](https://youtu.be/kkhFGMMk9pk?t=2400)「一般我們該說 **$d\in\gcd(a,b)$**——gcd 是**一個集合**。只是整數的怪癖讓它看起來是一個東西。你說 gcd 是 10，我說是 $\pm10$；你說 67，我說 $\pm67$。」
- （學生接話：「67 是質數。你知道 331 是什麼嗎？」「**第 67 個質數**。很好。」「4489？」「$67^2$。」「19 呢？」「67 是**第 19 個**質數。」「好，**腦腐**到此為止。」）

> **定理**（D&F §8.1 Thm 4，p.275；講義 p.5）[▶ 41:00](https://youtu.be/kkhFGMMk9pk?t=2460)　$R$ 歐氏整環，$a,b\neq0$，$d = r_n$ 是 $a,b$ 輾轉相除法的最後一個非零餘數。則
> 1. $d$ 是 $a,b$ 的一個 gcd；
> 2. $(d) = (a,b)$，所以有 $x,y$ 使 $d = ax+by$；
> 3. $d$ 在**乘上單位**的意義下唯一。

- 「不同的 gcd 選擇正好對應**相伴**。所以整數裡是 $\pm$——$\mathbb{Z}$ 的單位只有 $\pm1$。」
- 「證明在 D&F p.275，就是一般輾轉相除法的證明搬過來，**不值得花時間**。當然我這樣說，**Violet 馬上就會去看**，覺得一定很重要。」（Seinfeld「**Bizarro Jerry**」那集的梗。）

## 5. PID 中非零質理想是極大的；R[x] 是 PID ⇒ R 是體

> **命題 7**（講義 p.5，D&F p.280）[▶ 42:30](https://youtu.be/kkhFGMMk9pk?t=2550)　PID 中每個**非零質理想**都是**極大理想**。

💬 老師說「我們前幾堂證過質 ⇒ 極大」——前幾堂（[[08-L6-理想的性質-上]]、[[09-L7-整環擴張]]）證的是一般交換環中**極大 ⇒ 質**。反方向「非零質 ⇒ 極大」**要 PID 才成立**，這裡沒證，見 D&F p.280。

> **推論 8**（講義 p.5）[▶ 43:00](https://youtu.be/kkhFGMMk9pk?t=2580)　$R$ 交換環，若 $R[x]$ 是 PID（或歐氏整環），則 $R$ **必是體**。

**證明**：
- $R$ 是 $R[x]$ 的子環，$R[x]$ 是整環 ⇒ $R$ 是整環。
- $R[x]/(x)\cong R$ 是整環 ⇒ $(x)$ 是**非零質理想**。
- 命題 7 ⇒ $(x)$ 極大 ⇒ $R\cong R[x]/(x)$ 是體。$\blacksquare$

（例：$\mathbb{Z}$ 不是體，所以 $\mathbb{Z}[x]$ 不是 PID——和 §2 一致。）

## 6. 例：ℤ[√−3]、ℤ[√−5] 不是 PID

[▶ 44:00](https://youtu.be/kkhFGMMk9pk?t=2640)（投影講義 p.6）
- **例 4**：$(2,x)$ 在 $\mathbb{Z}[x]$ 不是主理想（§2 重述）。
- **例 5**：$(2,x)$ 在 $F[x]$（$F$ 體）**是**主理想——$F[x]$ 對次數是歐氏整環 ⇒ PID。（其實 2 是單位，$(2,x) = F[x] = (1)$。）

**例 6：$\mathbb{Z}[\sqrt{-3}]$（警世故事）**[▶ 45:00](https://youtu.be/kkhFGMMk9pk?t=2700)
- 範數 $N(a+b\sqrt{-3}) = a^2+3b^2$。「**有範數不代表是歐氏整環**——要有除法算法。」
- 範數乘性 $N(zw) = N(z)N(w)$、$N(1) = 1$ ⇒ 單位的範數是 1。
- 【課堂討論】[▶ 45:30](https://youtu.be/kkhFGMMk9pk?t=2730)「$a^2+3b^2 = 1$ 的整數解？」學生：「1。」「$a = \pm1$、$b = 0$。」所以單位只有 $\pm1$。對比 Gauss 整數 $a^2+b^2 = 1$ 有**四個**解 ⇒ 四個單位 ⇒ gcd 有四種選擇。
- **$1+\sqrt{-3}$ 不可約**[▶ 46:30](https://youtu.be/kkhFGMMk9pk?t=2790)：$1+\sqrt{-3} = xy$ ⇒ $4 = N(x)N(y)$。兩者都不是單位 ⇒ $N(x) = N(y) = 2$，但 $a^2+3b^2 = 2$ **無整數解** ⇒ $x$ 或 $y$ 是單位。
- **$1+\sqrt{-3}$ 不是質元**[▶ 47:30](https://youtu.be/kkhFGMMk9pk?t=2850)：
$$(1+\sqrt{-3})(1-\sqrt{-3}) = 4 = 2\cdot2,$$
  所以 $1+\sqrt{-3}\mid2\cdot2$。但若 $(1+\sqrt{-3})(a+b\sqrt{-3}) = 2$ ⇒ $a-3b = 2$、$a+b = 0$ ⇒ $4a = 2$ ⇒ $a = \frac12$——「整數這樣**通常不被看好**」。
- ⇒ 不可約但不是質 ⇒ **不是 PID** ⇒ 也**不是歐氏整環**。
- 【口頭】[▶ 49:00](https://youtu.be/kkhFGMMk9pk?t=2940)「還有件怪事：4 有**兩種分解** $2\cdot2$ 和 $(1+\sqrt{-3})(1-\sqrt{-3})$。單位只有 $\pm1$，2 和 $1\pm\sqrt{-3}$ **不相伴**——這不只是乘單位、換順序。**分解有別的事要想**。」

**例 7**[▶ 50:00](https://youtu.be/kkhFGMMk9pk?t=3000)：$\mathbb{Z}[\frac12(1+\sqrt{-19})]$ 是 **PID 但不是歐氏整環**。「證明牽涉頗多（side divisor），**放輕鬆**，我不考細節——除非我出了作業，那我**什麼都不收回**。」

**例 8**[▶ 50:30](https://youtu.be/kkhFGMMk9pk?t=3030)：$\mathbb{Z}[\sqrt{-5}]$ 中 **3 不可約但不是質元**。「感受一下：**3 不是質數**。有點怪，但是真的。」
$$(2+\sqrt{-5})(2-\sqrt{-5}) = 9 = 3^2,$$
3 整除它，但 $3\nmid2\pm\sqrt{-5}$ ⇒ 不是 PID。

## 8. Gauss 整數的輾轉相除法

[▶ 53:00](https://youtu.be/kkhFGMMk9pk?t=3180)（講義 p.8–9，2018 講義 Example 4.8.5，標「discuss in class」）
- **做法**：$\mathbb{Z}[i]$ 的元素是複數，**直接相除**，再挑最近的格點當商。

【講義補充】為什麼可行（講義 p.8–9）：$z = \frac{a+ib}{c+id}$，取 $\mathbb{Z}[i]$ 中最近的格點 $q$，最壞情況 $z$ 在格子中心，距離 $< 1/\sqrt2$ ⇒ $|r|<|c+id|/\sqrt2$ ⇒ $N(r)<N(c+id)/2$。對 $\mathbb{Z}[\sqrt{-d}]$（$d>0$ 大）這幾何論證就壞了。

**例**：$\alpha = 11+3i$、$\beta = 3i+2$。**向量形式的輾轉相除法**[▶ 54:30](https://youtu.be/kkhFGMMk9pk?t=3270)：
$$\begin{aligned}(11+3i,\ 3i+2) &= (\alpha,\ \beta)\\ (3i+2,\ 1+i) &= (\beta,\ \alpha-(2-2i)\beta)\\ (1+i,\ -i) &= (\alpha-(2-2i)\beta,\ \beta-(3+i)[\alpha-(2-2i)\beta])\end{aligned}$$
- 【口頭】「**向量輾轉相除法**你們可能不知道，但**應該知道**：不只寫數字，把 $\alpha,\beta$ 符號一路帶下去，它會**自動**給你 Bézout 係數。我跟 **Smith 博士**學的，他是**貨真價實的數論學家**——沒人教這個讓他很不爽。」
- $-i$ 是單位，停（「就像一般輾轉相除法得到 $\pm1$」）⇒
$$-i = (9-4i)\beta-(3+i)\alpha,\qquad1 = (4+9i)(3i+2)+(1-3i)(11+3i).$$
- gcd 是 $1$（或 $-1,i,-i$）⇒ $\langle11+3i\rangle+\langle3i+2\rangle = \mathbb{Z}[i]$，**互極大**。
- 「在課堂上算數值要半小時。但要做什麼其實很直接——只是**不熟悉**。」

## 9. 預告：Pell 方程、Fermat 最後定理

[▶ 57:30](https://youtu.be/kkhFGMMk9pk?t=3450)
- $\mathbb{Z}[\sqrt d]$（$d$ 無平方因子）這類東西，18 世紀的 **Euler、Lagrange** 就在用。有一整套漂亮的代數解 **Pell 方程**：有一組解，就能用這些環的**群結構**造出更多解。
- 「蠢例子」：$3^2+4^2 = 5^2$ 乘 2 得 $6,8,10$——從一組畢氏三元組造出新的。
- $x^n+y^n = z^n$ 的整數解是 **Fermat 最後定理**（$n\ge3$ 沒有有趣的解）。「它的證明可以用我們正在看的這些環來構造——**其中一個證明假設了唯一分解，結果是錯的**。下次多講。」

## 10. 一頁速查表

### 10.1 定理

| 定理 | 關鍵一步 |
|---|---|
| PID：質 ⟺ 不可約 | $(a,b) = (d)$；$a = rd$；$d$ 單位 ⇒ $a\mid c$，$r$ 單位 ⇒ $a\mid b$ |
| $\mathbb{Z}[x]$ 不是 PID | $(2,x) = (d)$ ⇒ 代 $x = 0$ ⇒ $d = \pm1$，但 $3+x\notin(2,x)$ |
| 歐氏 ⇒ PID | 取範數最小的 $x_0$；$r = z-qx_0\in I$ ⇒ $r = 0$ |
| 最後非零餘數是 gcd | $(d) = (a,b)$，$d = ax+by$，差單位唯一 |
| PID：非零質 ⇒ 極大 | D&F p.280 |
| $R[x]$ 是 PID ⇒ $R$ 是體 | $R[x]/(x)\cong R$ 整環 ⇒ $(x)$ 質 ⇒ 極大 |

### 10.2 例子

| 環 | 是什麼 | 理由 |
|---|---|---|
| $\mathbb{Z}$、$F[x]$、$\mathbb{Z}[i]$ | 歐氏 | 絕對值／次數／$a^2+b^2$ |
| $\mathbb{Z}[\frac12(1+\sqrt{-19})]$ | PID 非歐氏 | D&F |
| $\mathbb{Z}[x]$ | UFD 非 PID | $(2,x)$ |
| $\mathbb{Z}[\sqrt{-3}]$ | 非 PID、非 UFD | $1+\sqrt{-3}$ 不可約非質；$4 = 2\cdot2 = (1+\sqrt{-3})(1-\sqrt{-3})$ |
| $\mathbb{Z}[\sqrt{-5}]$ | 非 PID | $3$ 不可約非質；$9 = (2+\sqrt{-5})(2-\sqrt{-5})$ |

## 附：本集一句話總結

> **PID 中質 ⟺ 不可約（不可約 $a$ 整除 $bc$ 時看 $(a,b) = (d)$，$a = rd$ 中 $d$ 或 $r$ 是單位，分別推出 $a\mid c$ 或 $a\mid b$）；歐氏整環的理想由範數最小的元素生成，所以歐氏 ⇒ PID；$\mathbb{Z}[x]$ 的 $(2,x)$ 不是主理想，所以 $\mathbb{Z}[x]$ 不是 PID、上面沒有任何範數能做除法；gcd 在理想語言下就是 $(a,b) = (d)$，只差單位；$\mathbb{Z}[\sqrt{-3}]$、$\mathbb{Z}[\sqrt{-5}]$ 有不可約卻非質的元素、還有不唯一的分解——由此引出 體 ⊂ 歐氏 ⊂ PID ⊂ UFD ⊂ 整環 的故事線。**
