# 第 12 集 · L10：PID、質元與不可約元 [▶ 影片](https://www.youtube.com/watch?v=kkhFGMMk9pk&list=PLBY4G2o7DhF1x_afv1rv_d0hFCoMWEb-j)

## 本集概要

D&F §8.1–8.3，老師舊講義 Lecture 27–28：
- $\mathbb{Z}_6$ 中 $(2) = (4)$，而且 2、4 相伴——非整環時定理也可能成立。
- **PID 中質元 ⇔ 不可約元**（完整證明）。
- $\mathbb{Z}[x]$ **不是** PID：$(2,x)$ 不是主理想。
- **ED ⇒ PID**（取範數最小的非零元素）。所以 $\mathbb{Z}[x]$ 上**沒有任何**範數能做除法算法。
- gcd 與理想：$(a,b) = (d)$；ED 中最後非零餘數是 gcd。PID 中非零質理想是極大的；$R[x]$ 是 PID ⇒ $R$ 是體。
- 反例：$\mathbb{Z}[\sqrt{-3}]$ 中 $1+\sqrt{-3}$ 不可約但不是質元，$4$ 有兩種分解；$\mathbb{Z}[\sqrt{-5}]$ 中 3 不可約但不是質元。
- 體 ⊂ ED ⊂ PID ⊂ UFD ⊂ 整環。
- Gauss 整數的**向量歐幾里得演算法**例子。

> 📘 講義對應：Math422 Lecture 10「PIDs」；D&F §8.1–8.3（p.275、p.280）；老師 2018 年 421 講義 Lecture 27–28。

**不是整環呢？** [▶ 03:30](https://youtu.be/kkhFGMMk9pk?t=210)：$R = \mathbb{Z}_6$（有零因子 2、3）。$(2) = (4) = \{0,2,4\}$，而 $2\cdot5 = 10 = 4$，5 是單位，所以 2、4 仍相伴。

### 2. PID 中質元 ⇔ 不可約 [▶ 05:30](https://youtu.be/kkhFGMMk9pk?t=330)

> **定理**：在主理想整環（PID：每個理想都是主理想的整環）中，$a$ 是質元 $\iff a$ 是不可約元。

（⇒）已由上次的定理得到（PID 是整環）[▶ 07:30](https://youtu.be/kkhFGMMk9pk?t=450)。

（⇐）[▶ 08:00](https://youtu.be/kkhFGMMk9pk?t=480)：$a$ 不可約，設 $a\mid bc$。令
$$I = \{ax+by\mid x,y\in D\}.$$
$I$ 是理想（差仍在裡面、超封閉），所以 $I = (d)$。$a = a\cdot1+b\cdot0\in I$，所以 $a = rd$。$a$ 不可約，所以 $r$ 或 $d$ 是單位 [▶ 11:30](https://youtu.be/kkhFGMMk9pk?t=690)。
- **$d$ 是單位**：$I = D$，有 $x,y$ 使 $ax+by = 1$。$c = acx+bcy$，$a$ 整除兩項（$a\mid bc$），所以 $a\mid c$ [▶ 12:30](https://youtu.be/kkhFGMMk9pk?t=750)。
- **$r$ 是單位**：$a$、$d$ 相伴，$(a) = (d) = I$。$b = a\cdot0+b\cdot1\in I = (a)$，所以 $a\mid b$ [▶ 14:00](https://youtu.be/kkhFGMMk9pk?t=840)。（學生抓到老師把 $d$ 寫成 $r$。）
- 所以 $a$ 是質元。

（老師說學生今天「笑個不停」，怪 Schwitzer 博士。）

### 3. $\mathbb{Z}[x]$ 不是 PID [▶ 16:30](https://youtu.be/kkhFGMMk9pk?t=990)

$\mathbb{Z}$ 是 PID（理想都是 $n\mathbb{Z}$）。性質會不會傳給多項式環？這裡不會。

**標準例子**：$I = (2,x) = \{2f(x)+xg(x)\}$ [▶ 17:30](https://youtu.be/kkhFGMMk9pk?t=1050)。

**證明**（反證）：設 $I = (d(x))$。則 $x = d(x)g(x)$、$2 = d(x)h(x)$。
- 代 $x = 0$：$0 = d(0)g(0)$、$2 = d(0)h(0)$。第二式 ⇒ $d(0)\ne0$，所以 $g(0) = 0$ [▶ 20:00](https://youtu.be/kkhFGMMk9pk?t=1200)。
- $g(x) = c_1x+\cdots$，$x = d(x)(c_1x+\cdots)$，比較次數 ⇒ $d(x)$ 是常數 $d_0$，且 $d_0c_1 = 1$，所以 $d_0 = \pm1$ [▶ 22:30](https://youtu.be/kkhFGMMk9pk?t=1350)。
- 但 $\pm1$ 生成整個 $\mathbb{Z}[x]$，而 $I$ 的元素常數項都是偶數，例如 $3+x\notin I$。矛盾。
- （上次說 $(1+x)+(1-x)$ 在 $\mathbb{Z}[x]$ 不是全部，也可以用類似的代值論證。）

### 4. ED ⇒ PID [▶ 25:30](https://youtu.be/kkhFGMMk9pk?t=1530)

> **命題 1**（D&F §8.1）：歐氏整環中每個理想都是主理想。事實上，非零理想 $I$ 由其中任何一個**範數最小**的非零元素生成。

**證明** [▶ 27:30](https://youtu.be/kkhFGMMk9pk?t=1650)：$S = \{N(x)\mid x\in I,x\ne0\}$ 是非空的非負整數集合，由**良序原理**有最小元素 $s_0 = N(x_0)$。
- 任取 $z\in I$，除法算法：$z = qx_0+r$，$r = 0$ 或 $N(r)<N(x_0)$ [▶ 30:00](https://youtu.be/kkhFGMMk9pk?t=1800)。
- $qx_0\in I$（超封閉），所以 $r = z-qx_0\in I$。由 $x_0$ 的最小性，$r = 0$。
- 所以 $z\in(x_0)$；反過來 $(x_0)\subseteq I$ 顯然。$I = (x_0)$。

**例 3** [▶ 33:30](https://youtu.be/kkhFGMMk9pk?t=2010)：$\mathbb{Z}[x]$ 不是 ED——而且說得更強：**$\mathbb{Z}[x]$ 上不存在任何**範數能支援除法算法。無窮多種可能的範數全部注定失敗，因為否則 $\mathbb{Z}[x]$ 會是 PID。

> 💬 老師剛教完「彈簧」（另一堂課），學生問是哪種彈簧——「被摩擦減慢的那種」，「我寫的課本裡有」[▶ 36:00](https://youtu.be/kkhFGMMk9pk?t=2160)。

### 5. gcd 與理想 [▶ 36:30](https://youtu.be/kkhFGMMk9pk?t=2190)

- **倍數**：$b = ra$ 時 $b$ 是 $a$ 的倍數，$a\mid b$。
- $d\mid a$ 且 $d\mid b$：**公因數**。若每個公因數 $d'$ 都整除 $d$，$d$ 是**最大公因數** $\gcd(a,b)$，也記 $(a,b)$——這記號預告了理想的寫法 [▶ 37:30](https://youtu.be/kkhFGMMk9pk?t=2250)。
- 理想語言：$b\mid a\iff a\in(b)\iff(a)\subseteq(b)$（**順序反過來**）。$d$ 是公因數 ⇔ $(a,b)\subseteq(d)$；$d'\mid d$ ⇔ $(d)\subseteq(d')$ [▶ 38:30](https://youtu.be/kkhFGMMk9pk?t=2310)。

> 💬 課堂口誤：老師說「$b$ 是 $a$ 的倍數時，說 $b$ 整除 $a$」，應是 **$a$ 整除 $b$**。

> **命題 2**：$a,b\ne0$，若 $(a,b) = (d)$，則 $d$ 是 $a,b$ 的一個 gcd [▶ 39:30](https://youtu.be/kkhFGMMk9pk?t=2370)。

- 應該說「$d$ **是一個** gcd」：gcd 一般不唯一。在 $\mathbb{Z}$ 也是 $\pm$：「你說 gcd 是 67，我說是 $\pm67$。」

> 💬 學生：「67 是質數。你知道 331 是什麼嗎？」——第 67 個質數。$4489 = 67^2$；67 是第 19 個質數。「好，腦腐到此為止。」[▶ 40:30](https://youtu.be/kkhFGMMk9pk?t=2430)

> **定理**（D&F p.275）：$R$ 是 ED，$a,b\ne0$，$d = r_n$ 是歐幾里得演算法的最後非零餘數。
> 1. $d$ 是 $a,b$ 的一個 gcd，且 $(a,b) = (d)$；特別地有 $x,y$ 使 $d = ax+by$。
> 2. $d$ 在差一個單位的意義下唯一（不同選擇都是相伴元）。

- 證明就是一般歐幾里得演算法的證明，不在課堂上講 [▶ 42:00](https://youtu.be/kkhFGMMk9pk?t=2520)。（「我這樣說了，Violet 一定會馬上去看，覺得一定很重要。」——Seinfeld 的「顛倒 Jerry」梗。）

> **命題 7**（D&F p.280）：PID 中每個非零質理想都是極大理想 [▶ 42:30](https://youtu.be/kkhFGMMk9pk?t=2550)。

> 💬 老師說「我們之前證過質 ⇒ 極大」，其實之前證的是**極大 ⇒ 質**（一般成立）；「非零質 ⇒ 極大」需要 PID 這個條件。

> **推論**：$R$ 是交換環，若 $R[x]$ 是 PID，則 $R$ 是體 [▶ 43:00](https://youtu.be/kkhFGMMk9pk?t=2580)。

- 證明：$R\subseteq R[x]$，所以 $R$ 是整環。$R[x]/(x)\cong R$ 是整環，所以 $(x)$ 是質理想（非零）。PID 中它是極大的，所以 $R\cong R[x]/(x)$ 是體。
- 對比：$(2,x)$ 在 $\mathbb{Z}[x]$ 不是主理想；但在體上的 $F[x]$ 裡，任何理想都是主理想（$F[x]$ 是 ED，範數 = 次數）[▶ 44:30](https://youtu.be/kkhFGMMk9pk?t=2670)。

### 6. 反例：$\mathbb{Z}[\sqrt{-3}]$ 與 $\mathbb{Z}[\sqrt{-5}]$ [▶ 45:00](https://youtu.be/kkhFGMMk9pk?t=2700)

**警示故事**：$\mathbb{Z}[\sqrt{-3}]$ 有範數 $N(a+b\sqrt{-3}) = a^2+3b^2$，但**有範數不代表是 ED**——還要有除法算法。
- 這個範數**可乘**：$N(xy) = N(x)N(y)$，且 $N(1) = 1$。所以單位滿足 $a^2+3b^2 = 1$，只有 $\pm1$。（Gauss 整數 $a^2+b^2 = 1$ 有四個解，四個單位。）
- **$1+\sqrt{-3}$ 不可約** [▶ 46:30](https://youtu.be/kkhFGMMk9pk?t=2790)：若 $1+\sqrt{-3} = xy$，則 $4 = N(x)N(y)$。兩個都不是單位就得 $N(x) = N(y) = 2$，但 $a^2+3b^2 = 2$ 沒有整數解。
- **但不是質元** [▶ 48:00](https://youtu.be/kkhFGMMk9pk?t=2880)：$(1+\sqrt{-3})(1-\sqrt{-3}) = 4 = 2\cdot2$，所以 $1+\sqrt{-3}\mid2\cdot2$；但它不整除 2——$(1+\sqrt{-3})(a+b\sqrt{-3}) = 2$ 解出 $a = \frac12$，「整數通常不贊成這樣」。
- 所以 $\mathbb{Z}[\sqrt{-3}]$ 不是 PID，也就不是 ED。
- 而且 $4 = 2\cdot2 = (1+\sqrt{-3})(1-\sqrt{-3})$ 是兩種**本質不同**的分解（2 和 $1\pm\sqrt{-3}$ 不相伴；單位只有 $\pm1$）[▶ 49:30](https://youtu.be/kkhFGMMk9pk?t=2970)。
- D&F：$\mathbb{Z}[\frac{1+\sqrt{-19}}2]$ 是 PID 但不是 ED，證明（泛側因子）不要求 [▶ 50:00](https://youtu.be/kkhFGMMk9pk?t=3000)。
- $\mathbb{Z}[\sqrt{-5}]$：3 不可約但**不是質元**：$(2+\sqrt{-5})(2-\sqrt{-5}) = 9 = 3^2$，3 整除乘積但不整除任一因子 [▶ 50:30](https://youtu.be/kkhFGMMk9pk?t=3030)。

**大圖** [▶ 51:30](https://youtu.be/kkhFGMMk9pk?t=3090)：
$$\text{體}\subsetneq\text{ED}\subsetneq\text{PID}\subsetneq\text{UFD}\subsetneq\text{整環}.$$
- $\mathbb{Z}[x]$：UFD 但不是 PID。
- $\mathbb{Z}[\sqrt{-3}]$：整環但不是 **UFD**（唯一分解整環，unique factorization domain；之後細講）。
- $\mathbb{Z}[\frac{1+\sqrt{-19}}2]$：PID 但不是 ED。ED 一定是 PID。

### 7. Gauss 整數的歐幾里得演算法 [▶ 53:00](https://youtu.be/kkhFGMMk9pk?t=3180)

做法：當複數相除，取最接近的 Gauss 整數當商。

例：$\alpha = 11+3i$、$\beta = 2+3i$。用**向量歐幾里得演算法**（vector Euclidean algorithm）：每一行都把餘數寫成 $\alpha,\beta$ 的組合，最後自動得到 Bézout 係數（老師跟數論學家 Smith 博士學的，他對這方法沒人教很不滿）[▶ 54:30](https://youtu.be/kkhFGMMk9pk?t=3270)。
- $\alpha-(2-2i)\beta = 1+i$。
- $\beta-(3+i)(1+i) = -i$，是單位，可以停（像整數算到 $\pm1$）[▶ 55:30](https://youtu.be/kkhFGMMk9pk?t=3330)。
- 代回：$(9-4i)\beta-(3+i)\alpha = -i$；乘 $i$ 得 1。
- 所以 $\gcd(11+3i,2+3i) = 1$（或 $-1,\pm i$），兩者生成的理想互極大。「在課堂上算要半小時。」

### 8. 預告：代數數論 [▶ 57:00](https://youtu.be/kkhFGMMk9pk?t=3420)

- 18 世紀 Euler、Lagrange 就在用 $\mathbb{Z}[\sqrt d]$ 這類環；例如 **Pell 方程**的解有群結構，可以從一個解生出更多。
- 小例子：$3^2+4^2 = 5^2$ 乘 2 得 $6,8,10$——從一組畢氏三元組生出新的。
- **Fermat 最後定理**：$x^n+y^n = z^n$（$n\ge3$）沒有非平凡整數解。有些證明用到這類環；有一個證明**假設了唯一分解**，所以是錯的。下次繼續 [▶ 59:00](https://youtu.be/kkhFGMMk9pk?t=3540)。
