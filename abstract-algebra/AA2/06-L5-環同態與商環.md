# 第 6 集 · L5：環同態與商環（下雪天在家錄） [▶ 影片](https://www.youtube.com/watch?v=hBT-i7qVve8&list=PLBY4G2o7DhF1x_afv1rv_d0hFCoMWEb-j)

← 上一集：[[05-L4-環、整環與群環]] ｜ [總目錄](../README.md) ｜ 下一集：[[07-L6-理想的性質-下]] →

## 本集概要

又一支下雪天影片（在冷冷的地下室錄）。跟著 Dummit & Foote §7.3：
- **環同態**、核、**環同構**。老師的例子：$R[\mathbb{Z}_2]\cong R\times R$（群環 ≅ **積環**）。
- 環同態**不一定**保持單位、零因子：$\mathbb{Z}_6\to\mathbb{Z}_3$ 把零因子 2 送到單位 2。
- 核對左右乘法「超封閉」⇒ **理想**（ideal）；左理想 / 右理想的矩陣例子。
- **商環** $R/I$、環的**第一同構定理**；每個理想都是自然映射的核。
- 例：$\mathbb{Z}[x]/(x)\cong\mathbb{Z}$；$\mathbb{Z}[x]/(x^2)$ 有冪零元；**求值同態**。
- 第二、三、四同構定理；理想的**和**與**積**；$I^2$ 的元素不一定是單一乘積。

> 📘 講義對應：Math422 Lecture 5「Ring Homomorphisms & Quotient Rings」；Dummit & Foote §7.3（p.244–245 例 5–7、Thm 8）。

## 筆記

### 1. 環同態 [▶ 00:00](https://youtu.be/hBT-i7qVve8?t=0)

> **定義**：$\varphi:R\to S$ 是**環同態**（ring homomorphism），若
> 1. $\varphi(a+b) = \varphi(a)+\varphi(b)$；
> 2. $\varphi(ab) = \varphi(a)\varphi(b)$。
>
> **核** $\ker\varphi = \varphi^{-1}(0)$。雙射的環同態叫**環同構**，記 $R\cong S$。

- 我們的環不預設有 1，所以同態也**不要求** $\varphi(1) = 1$。若研究有么環，大概會想加上這條 [▶ 00:30](https://youtu.be/hBT-i7qVve8?t=30)。
- 環同態就是加法群的群同態，再加上保持乘法。

### 2. 例：$R[\mathbb{Z}_2]\cong R\times R$ [▶ 02:00](https://youtu.be/hBT-i7qVve8?t=120)

（老師自己的「寵物例子」，不在 D&F 裡。）

- **積環**（product ring / direct product）$R\times R$：逐分量加、逐分量乘。$R$ 有 1 時，$(1,1)$ 是單位。
- 群環 $R[\mathbb{Z}_2] = \{a+bj\}$，$j^2 = 1$。
- 怎麼找同構？想想結構該對應什麼 [▶ 04:30](https://youtu.be/hBT-i7qVve8?t=270)：
  - 零因子：群環有 $1\pm j$；積環有 $(1,0)$、$(0,1)$。
  - 平方等於 1、但不是 $\pm1$ 的元素：群環有 $j$；積環中 $(x,y)^2 = (1,1)$ 要 $x,y = \pm1$，選 $(1,-1)$（或 $(-1,1)$，不唯一）。
- 定義
$$\psi(a+bj) = (a+b,\ a-b).$$
  $\psi(1) = (1,1)$、$\psi(j) = (1,-1)$；有明確的反函數（$R$ 中 2 可逆時是 $(x,y)\mapsto\frac{x+y}2+\frac{x-y}2j$）；可加；乘法展開比較即可 [▶ 06:30](https://youtu.be/hBT-i7qVve8?t=390)。所以是環同構。

> 💬 老師把 $j$ 叫做「冪等元」（idempotent），但 $j^2 = 1$ 的元素叫**對合**（involution）；冪等元是 $e^2 = e$，例如 $\frac{1\pm j}2$。另外，反函數需要 2 在 $R$ 中可逆，例如 $R = \mathbb{Z}$ 時 $\psi$ 不是滿射（$a+b$ 和 $a-b$ 奇偶性相同）。（補充，非課堂內容）

> 💬 影片有橫條紋是因為 LED 燈；「白熾燈被國會禁了」。

**一般的積環** [▶ 07:30](https://youtu.be/hBT-i7qVve8?t=450)：$R_1\times\cdots\times R_k$，逐分量運算。全部相同時記 $R^k$。
- 都有 1 時 $(1,\dots,1)$ 是單位；$e_1 = (1,0,\dots)$、$e_2 = (0,1,0,\dots)$ 是零因子（$e_1e_2 = 0$）。
- 各分量都是單位的 $k$ 元組是單位。

### 3. 環同態保持單位、零因子嗎？ [▶ 09:00](https://youtu.be/hBT-i7qVve8?t=540)

（桌上有個組到一半的樂高擋路。）

**不一定**。$\mathbb{Z}_6\to\mathbb{Z}_3$，$[x]_6\mapsto[x]_3$（模 3 約化）[▶ 10:00](https://youtu.be/hBT-i7qVve8?t=600)：良定義、可加、可乘，是環同態。但 2 在 $\mathbb{Z}_6$ 是零因子（$2\cdot3 = 0$），在 $\mathbb{Z}_3$ 是單位。
- 「環同態可以很好，但不一定照你的直覺走。」

### 4. 核是理想 [▶ 11:30](https://youtu.be/hBT-i7qVve8?t=690)

> **命題**：$\varphi:R\to S$ 是環同態。則 $\varphi(R)$ 是 $S$ 的子環；$\ker\varphi$ 是 $R$ 的子環；而且 $r\in R$、$\alpha\in\ker\varphi$ ⇒ $r\alpha,\alpha r\in\ker\varphi$。

- 像：$\varphi(a)-\varphi(b) = \varphi(a-b)$、$\varphi(a)\varphi(b) = \varphi(ab)$，子環測試 [▶ 12:00](https://youtu.be/hBT-i7qVve8?t=720)。
- 核：$\varphi(x-y) = 0-0$、$\varphi(xy) = 0\cdot0$。
- 左右乘：$\varphi(r\alpha) = \varphi(r)\cdot0 = 0$ [▶ 13:30](https://youtu.be/hBT-i7qVve8?t=810)。
- Spano 老師把這種左右都封閉的性質叫「**超封閉**」（uber closure），老師也愛用。

### 5. 理想 [▶ 14:30](https://youtu.be/hBT-i7qVve8?t=870)

D&F 花了大約一頁說明動機：核有這個結構；而要讓商環的乘法良定義，就需要左右封閉。

> **定義**：$rI = \{ra\mid a\in I\}$ 等。子環 $I\subseteq R$ 是
> - **左理想**（left ideal）：$rI\subseteq I$ 對所有 $r\in R$；
> - **右理想**（right ideal）：$Ir\subseteq I$；
> - **理想**（ideal，或雙邊理想 two-sided ideal）：同時是左、右理想。

- 交換環中左右沒差別，只要驗一邊 [▶ 15:30](https://youtu.be/hBT-i7qVve8?t=930)。

**例：左理想但不是右理想** [▶ 16:30](https://youtu.be/hBT-i7qVve8?t=990)：$R = \mathbb{Z}^{n\times n}$。
- $I_1$：第一欄全為 0 的矩陣。$MA$ 的第一欄 $= M\times(A$ 的第一欄$) = 0$，所以 $RI_1\subseteq I_1$——**左理想**。
- $J_1$：第一列全為 0 的矩陣。$AM$ 的第一列 $= (A$ 的第一列$)M = 0$——**右理想**。
- 另一邊乘就跑出去，所以 $I_1$ 不是右理想，$J_1$ 不是左理想 [▶ 18:30](https://youtu.be/hBT-i7qVve8?t=1110)。
- 「考題：舉一個是左理想但不是右理想的例子。答案我剛告訴你了，不客氣。」

### 6. 商環與第一同構定理 [▶ 19:00](https://youtu.be/hBT-i7qVve8?t=1140)

> **命題/定義**：$I$ 是 $R$ 的理想。加法陪集的集合 $R/I$ 用
> $$(a+I)+(b+I) = (a+b)+I,\qquad(a+I)(b+I) = ab+I$$
> 成為環，叫**商環**（quotient ring，或 factor ring）。

- 加法：交換群的子群一定正規，所以陪集本來就成群。乘法良定義要用到 $I$ 是理想（好練習；D&F 有部分證明）[▶ 20:00](https://youtu.be/hBT-i7qVve8?t=1200)。

> **定理**（環的第一同構定理）：$\varphi:R\to S$ 是環同態。則 $\ker\varphi$ 是 $R$ 的理想，$\varphi(R)$ 是 $S$ 的子環，且
> $$R/\ker\varphi\cong\varphi(R).$$

**證明** [▶ 21:00](https://youtu.be/hBT-i7qVve8?t=1260)：前兩點上面證過。群的第一同構定理已經給出保持加法的雙射 $\bar\varphi(a+\ker\varphi) = \varphi(a)$。只要再檢查乘法：
$$\bar\varphi\big((a+K)(b+K)\big) = \bar\varphi(ab+K) = \varphi(ab) = \varphi(a)\varphi(b) = \bar\varphi(a+K)\bar\varphi(b+K).$$
- 環裡沒有「正規子環」——正規子群的角色由**理想**擔任 [▶ 22:30](https://youtu.be/hBT-i7qVve8?t=1350)。

> **定理**：每個理想 $I$ 都是某個滿的環同態的核——**自然映射** $\pi(r) = r+I$ [▶ 24:00](https://youtu.be/hBT-i7qVve8?t=1440)。

- $\pi$ 保持加法和乘法；$0+I = I$ 是 $R/I$ 的零，所以 $\ker\pi = I$。

### 7. 理想的例子 [▶ 26:00](https://youtu.be/hBT-i7qVve8?t=1560)

1. $R$ 和 $\{0\}$ 都是理想。$\{0\}$ 叫**平凡理想**；$\ne R$ 的理想叫**真理想**（proper ideal）。
2. $\mathbb{Z}$ 的理想都是 $n\mathbb{Z}$（$\mathbb{Z}$ 的子群就這些，而且都是理想）。$\mathbb{Z}/n\mathbb{Z} = \mathbb{Z}_n$ 是商環 [▶ 26:30](https://youtu.be/hBT-i7qVve8?t=1590)。
3. **$\mathbb{Z}[x]$ 中沒有常數項的多項式**構成理想 $I$ [▶ 27:30](https://youtu.be/hBT-i7qVve8?t=1650)。$f+I = g+I\iff f,g$ 常數項相同。
   - $\varphi(f) = f(0)$（取常數項）是 $\mathbb{Z}[x]\to\mathbb{Z}$ 的滿環同態，核是 $I$。由第一同構定理 $\mathbb{Z}[x]/I\cong\mathbb{Z}$ [▶ 28:30](https://youtu.be/hBT-i7qVve8?t=1710)。
4. **從 $x^2$ 開始的多項式**構成理想 $J$（D&F）[▶ 29:30](https://youtu.be/hBT-i7qVve8?t=1770)。代表元可以吸掉二次以上的項：$a_0+a_1x+\cdots+J = a_0+a_1x+J$。
   - $(x+J)^2 = x^2+J = J$（零），但 $x+J\ne J$。所以 $x+J$ 是**冪零元**（nilpotent），也是零因子 [▶ 31:00](https://youtu.be/hBT-i7qVve8?t=1860)。
   - $\mathbb{Z}[x]$ 是整環，但商 $\mathbb{Z}[x]/J$ 不是。

> 💬 課堂口誤：例 3 老師說核是「非常數多項式」，應是「**常數項為 0** 的多項式」。例 4 老師想用「二階導數」$f\mapsto f''$ 描述 $J$，但它的核是 $\{a_0+a_1x\}$ 而不是 $J$（而且微分不保持乘法），老師自己也說「腦袋卡住了」就跳過 [▶ 32:00](https://youtu.be/hBT-i7qVve8?t=1920)。

### 8. 求值同態 [▶ 33:00](https://youtu.be/hBT-i7qVve8?t=1980)

> **定義/命題**：$X$ 是集合，$A$ 是環，$R$ = 函數 $X\to A$ 的環。對 $c\in X$，**求值同態**（evaluation homomorphism）
> $$\mathrm{eval}_c(f) = f(c)\quad(\text{D\&F 記 }E_c)$$
> 是環同態。

- $(f+g)(c) = f(c)+g(c)$、$(fg)(c) = f(c)g(c)$——就是函數運算的定義 [▶ 34:00](https://youtu.be/hBT-i7qVve8?t=2040)。
- 它是**滿射**：常數函數 $f\equiv a$ 送到 $a$。所以 $R/\ker(\mathrm{eval}_c)\cong A$ [▶ 35:30](https://youtu.be/hBT-i7qVve8?t=2130)。
- 「求值同態配上第一同構定理的魔法，能做很多事。」D&F p.244–245 例 5–7 很有幫助。

> 💬 「用 D&F 我總有點沮喪——我從來不是增加，幾乎都是刪減。」[▶ 36:30](https://youtu.be/hBT-i7qVve8?t=2190)

### 9. 第二、三、四同構定理 [▶ 37:00](https://youtu.be/hBT-i7qVve8?t=2220)

不證。證明和群的一樣：加法群的部分已經有雙射，再補上「保持乘法」。
- 第二：$A$ 子環、$I$ 理想，$(A+I)/I\cong A/(A\cap I)$，$A\cap I$ 是 $A$ 的理想。
- 第三：巢狀理想的「消去」。
- 第四（對應）：例 $R = \mathbb{Z}$、$I = 12\mathbb{Z}$。$\mathbb{Z}/12\mathbb{Z}$ 的理想 $2\mathbb{Z}/12\mathbb{Z}$、$3\mathbb{Z}/12\mathbb{Z}$、$4\mathbb{Z}/12\mathbb{Z}$、$6\mathbb{Z}/12\mathbb{Z}$……對應 $\mathbb{Z}$ 中包含 $12\mathbb{Z}$ 的理想 $2\mathbb{Z},3\mathbb{Z},4\mathbb{Z},6\mathbb{Z},12\mathbb{Z}$ [▶ 39:00](https://youtu.be/hBT-i7qVve8?t=2340)。

### 10. 理想的和與積 [▶ 39:30](https://youtu.be/hBT-i7qVve8?t=2370)

> **定義**：
> - $I+J = \{x+y\mid x\in I,y\in J\}$；
> - $IJ$ = 形如 $\sum x_iy_i$（$x_i\in I$、$y_i\in J$）的**有限和**；
> - $I^n$ = $n$ 個 $I$ 中元素乘積的有限和。

> **定理**（D&F Thm 8）：$I+J$、$IJ$ 是理想。（421 第三次考試出過，「很可愛的考題」。）

**例** [▶ 40:30](https://youtu.be/hBT-i7qVve8?t=2430)
- $6\mathbb{Z}+10\mathbb{Z} = \{2(3a+5b)\}$。因為 $\gcd(3,5) = 1$，$2\cdot3-5 = 1$，所以 $= 2\mathbb{Z}$。
- $(6\mathbb{Z})(10\mathbb{Z}) = 60\mathbb{Z}$。
- **為什麼積要用有限和** [▶ 41:30](https://youtu.be/hBT-i7qVve8?t=2490)：$\varphi:\mathbb{Z}[x]\to\mathbb{Z}_2$，$\varphi(f) = f(0)\bmod2$（求值再約化），核 $I$ = 常數項為偶數的多項式。$2,x\in I$，所以 $4 = 2\cdot2$、$x^2 = x\cdot x\in I^2$，$x^2+4\in I^2$。但 $x^2+4$ **不能**寫成 $p(x)q(x)$，$p,q\in I$。所以「單一乘積的集合」不夠，必須取和。（老師「強烈懷疑」單一乘積的集合不是理想。）

「真的真的希望週五能上課，這樣好無聊。」
