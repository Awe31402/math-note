## 1. 重根、單根、可分多項式

[▶ 01:00](https://youtu.be/FItuJ2msb1k?t=60)「先重溫舊事——現在比較好，因為有**新玩具**：分裂體。」

**設定**（講義 p.1）：$F$ 體，$f(x)\in F[x]$ 首項係數 $a_n$。存在分裂體，裡面有**相異**的 $\alpha_1,\dots,\alpha_k$ 使
$$f(x) = a_n(x-\alpha_1)^{n_1}(x-\alpha_2)^{n_2}\cdots(x-\alpha_k)^{n_k},\quad n_i\ge1.$$
- 【課堂討論】[▶ 02:00](https://youtu.be/FItuJ2msb1k?t=120)「$n_1+\cdots+n_k = ?$（只是確認你們懂我寫的。D&F 連寫都不寫。）」學生：「$n$。」
- 「這分解**不一定**在 $F[x]$ 裡發生，是在**某個分裂體**裡。我甚至沒給它取名，只說它存在。」

> **定義**（講義 p.1）[▶ 04:00](https://youtu.be/FItuJ2msb1k?t=240)　$n_i\ge2$ 時 $\alpha_i$ 是**重根**，$n_i$ 是它的**重數**；$n_i = 1$ 時是**單根**。

> **定義**[▶ 05:00](https://youtu.be/FItuJ2msb1k?t=300)　$f$ 沒有重根（所有根相異）叫**可分（separable）**；否則叫**不可分（inseparable）**。

【口頭】[▶ 06:00](https://youtu.be/FItuJ2msb1k?t=360)「為什麼我能**這麼隨便**地談根？怎麼知道有根可談？回到上一講：**每個多項式都有分裂體**；而且不同的分裂體同構、保持根的結構——不會一個分裂體裡有重根、另一個裡根都相異。」

**例 1**[▶ 07:00](https://youtu.be/FItuJ2msb1k?t=420)：$x^2-2\in\mathbb{Q}[x]$ **可分**：$(x+\sqrt2)(x-\sqrt2)$，$\sqrt2\neq-\sqrt2$。「你們同意吧？希望同意——因為**下一個例子裡它『有點』相等**。」

## 2. 怪例子：x² − t 在 𝔽₂(t) 上

**例 2**（講義 p.1）[▶ 08:00](https://youtu.be/FItuJ2msb1k?t=480)「這例子**很狂**。」$x^2-t$ 在 $\mathbb{F}_2(t)$ 上——$t$ 的有理函數，係數在 $\mathbb{F}_2 = \mathbb{Z}/2\mathbb{Z}$。特徵 2。
- 【課堂討論】[▶ 09:30](https://youtu.be/FItuJ2msb1k?t=570)「這個體有幾個元素？」（學生亂猜 2、$i$……「你們的答案**都一樣錯**。我很失望還沒人猜 67。」）「**無窮**——$t$ 的有理函數有無窮多個。」「**無窮體**是重點。」
- $x^2-t$ **不可約**：$\sqrt t$ 不在 $\mathbb{F}_2(t)$ 裡。但在分裂體裡，象徵地：
$$(x-\sqrt t)(x+\sqrt t) = (x+\sqrt t)^2 = x^2+2\sqrt t\,x+t = x^2+t = x^2-t\quad(\text{mod }2).$$
  「特徵 2：$-\sqrt t = \sqrt t$，$2\sqrt t = 0$。」
- ⇒ $x^2-t$ **不可約但不可分**——唯一的根 $\sqrt t$ 是二重根。

【Q&A】[▶ 13:00](https://youtu.be/FItuJ2msb1k?t=780) 學生：「你能說服我們 $-t = t$ 嗎？」老師：「可以，因為我們**在模 2**。不管 $\sqrt t$ 是什麼，$\sqrt t\cdot\sqrt t = t$。」（學生：「她喜歡 tea。」「准了。」）

## 3. 形式導數不是環同態

（講義 p.2）[▶ 13:30](https://youtu.be/FItuJ2msb1k?t=810)
$$\frac d{dx}(a_nx^n+\cdots+a_1x+a_0) = na_nx^{n-1}+\cdots+a_1,$$
記 $D_x[f] = \frac{df}{dx} = f'(x)$。「D&F 用 $D_x$，我懂理由——有人會質疑論證不夠形式。但我用 $f'$，比較**順**。」

【課堂討論】[▶ 15:00](https://youtu.be/FItuJ2msb1k?t=900)「$D:F[x]\to F[x]$ 是環同態嗎？」它**加法**沒問題，但
$$(fg)' = f'g+fg'\neq f'g'.$$
「誰知道大一微積分把這**錯得離譜**的學生，其實是在當**抽象代數學家**——他們只是想斷言導數是函數環上的環同態。我們該**多給部分分數**。他們渴望導數是某種漂亮的東西，可惜不是：它得滿足 **Leibniz 律**。而這對我們是**好消息**——它給了理解重根的清楚漂亮的方法。」

💬 講義 p.2 寫「$\ker D_x = F$ 且 $D$ 是滿射」——這**只在特徵 0** 成立。特徵 $p$ 時 $(x^p)' = px^{p-1} = 0$，所以 $\ker D\supsetneq F$；而且 $x^{p-1}$ 不是任何多項式的導數，$D$ 不是滿射。

## 4. 重根 ⟺ 也是導數的根（D&F Prop 33）

> **命題 33**（講義 p.2）[▶ 16:30](https://youtu.be/FItuJ2msb1k?t=990)　$f(x)\in F[x]$ 有重根 $\alpha$ $\iff$ $\alpha$ 也是 $f'(x)$ 的根；即 $f$ 和 $f'$ 都被 $m_{\alpha,F}(x)$ 整除。特別地，$f$ 可分 $\iff$ $f$ 與 $f'$ 互質，$(f,f') = 1$。

「這就是**我前一陣子一直在找**的那個——不知為何想不起來。不過也好，它本來就該在這部分講。」

- [▶ 18:00](https://youtu.be/FItuJ2msb1k?t=1080)「第二句是**免費**的：多項式有某個根，就表示那個根的**最小多項式整除它**——例如 $i$ 是根，在 $\mathbb{C}$ 上就有 $x-i$ 因子，在 $\mathbb{R}$ 上就有 $x^2+1$ 因子。」
- 【課堂討論】「你們想先證哪個方向？」「**正向**。」「好，有點無聊。」「兩個都會證。」

**(⇒)**[▶ 19:30](https://youtu.be/FItuJ2msb1k?t=1170)：$\alpha$ 重數 $\ge2$ ⇒ $f = (x-\alpha)^2g$。
- 「我**很狡猾**地沒說分解在哪裡發生——不用說，**在分裂體裡**。一直寫『在分裂體裡』對論證沒有增加什麼。所以**分裂體那節給了我們偷懶的執照**。你們喜歡偷懶吧？」
- $f' = 2(x-\alpha)g+(x-\alpha)^2g'$ ⇒ $f'(\alpha) = 0+0 = 0$。

（[▶ 21:00](https://youtu.be/FItuJ2msb1k?t=1260) 研究週提案的閒聊：「你們有人該提案。今天截止。」「我有學生拿過獎，講得**相當平淡**。已經有人做到了。」）

**(⇐)**[▶ 23:00](https://youtu.be/FItuJ2msb1k?t=1380)：$f(\alpha) = 0 = f'(\alpha)$。
- $f = (x-\alpha)h$ ⇒ $f' = h+(x-\alpha)h'$。「你們忘了**微積分一**嗎？**怎麼敢**？」
- $f'(\alpha) = h(\alpha)+0$ ⇒ $h(\alpha) = 0$ ⇒ $h = (x-\alpha)h_2$ ⇒ $f = (x-\alpha)^2h_2$，重數至少 2。$\blacksquare$
- 【口頭】[▶ 26:00](https://youtu.be/FItuJ2msb1k?t=1560)「我有點不對勁：**證明裡有微積分我就很享受**。大概因為我待過的形式系統幾乎都牽涉微積分。」

【課堂討論】[▶ 26:30](https://youtu.be/FItuJ2msb1k?t=1590)「我覺得這是很好的考題……」學生：「我**討厭**它，拜託別考。」「別考。好，**我重新考慮**我的立場。」（老師講起有學生抱怨 Henchman Fight 有題太難配分太少：「我說，那上考試時我讓它**配更多分**——而且用你命名，叫『Lawson 的題』。」）

## 5. 例子：xᵖⁿ − x、xⁿ − 1

**例 3**（講義 p.3 E1）[▶ 28:00](https://youtu.be/FItuJ2msb1k?t=1680)：$f = x^{p^n}-x\in\mathbb{F}_p[x]$。
$$f' = p^nx^{p^n-1}-1 = -1\ (\mathrm{mod}\ p)$$
⇒ $f'$ **沒有根** ⇒ $f$ 沒有重根 ⇒ **可分**。「好像**太簡單**了。」

**例 4**（講義 E2）[▶ 29:30](https://youtu.be/FItuJ2msb1k?t=1770)：$f = x^n-1$，$f' = nx^{n-1}$。在 $n\neq0$ 的體裡（$p\nmid n$），$f'$ 唯一的根是 0，但 $f(0) = -1\neq0$ ⇒ **可分**。耶！

**例 5**（講義 E3）[▶ 32:00](https://youtu.be/FItuJ2msb1k?t=1920)「別擔心，這個**不一樣**。」$\mathrm{ch}F = p$、$p\mid n$：$f' = nx^{n-1}\equiv0$ ⇒ **每個數**都是 $f'$ 的根 ⇒ $f$ 的**每個根都是重根**，不可分。

**$\mathbb{Z}_3$ 上的 $x^6-1$**[▶ 34:00](https://youtu.be/FItuJ2msb1k?t=2040)：$f' = 6x^5 = 0$。找根：$f(0) = -1$、$f(1) = 0$、$f(2) = 63 = 0$。「我有點困惑……根是 1 和 2。照定理，$f = (x-1)^{n_1}(x-2)^{n_2}$，$n_1,n_2\ge2$——但具體分解**還要算**。我原本有錯誤的想法。」

💬 具體分解：特徵 3 時 $(a\pm b)^3 = a^3\pm b^3$，所以
$$x^6-1 = (x^3-1)(x^3+1) = (x-1)^3(x+1)^3 = (x-1)^3(x-2)^3\quad\text{in }\mathbb{Z}_3[x].$$

【課堂討論】[▶ 37:00](https://youtu.be/FItuJ2msb1k?t=2220)（老師一度把「$n\neq0$」說成「$n$ 整除特徵」：「我覺得**說得不對**。」）「特徵 $p$ 的體裡，$n\neq0$ 需要什麼？」「$n$ 不是 $p$ 的倍數。」「用整除寫？」「**$p\nmid n$**。」「我**覺得**它錯了，它**真的**錯了。好。」

## 6. 特徵 0、Frobenius、完美體

[▶ 38:00](https://youtu.be/FItuJ2msb1k?t=2280)（學生：「下課要打**任天堂明星大亂鬥**。他帶來了。」老師改投影：「接下來是我**還沒寫出證明**的部分。」）

> **推論 34**（講義 p.4）[▶ 40:30](https://youtu.be/FItuJ2msb1k?t=2430)　**特徵 0** 的體上，每個不可約多項式都**可分**；多項式可分 $\iff$ 它是**相異**不可約多項式的乘積。

「我**很難過**沒時間寫這個證明——我強烈懷疑它跟你們剛才喜歡的那個**風味相似**。我的心願是寫出來再重新掃描。」

**Frobenius**[▶ 41:30](https://youtu.be/FItuJ2msb1k?t=2490)：特徵 $p$，二項式定理
$$(x+y)^p = x^p+px^{p-1}y+\cdots+pxy^{p-1}+y^p.$$
中間的二項式係數**每個都有因數 $p$** ⇒ 模 $p$：
$$(x+y)^p = x^p+y^p.$$
- 「也就是**大一新生之夢**。」「我寧願活在我現在的世界——我的大一新生**有別的夢**。這其實是個**惡夢**：它不對，除非你在特徵 $p$ 這種**怪怪的系統**裡。」

> **命題 35**（講義 p.4）　$\mathrm{ch}F = p$ ⇒ $(a+b)^p = a^p+b^p$、$(ab)^p = a^pb^p$。

> **定義**（講義 p.5）[▶ 44:00](https://youtu.be/FItuJ2msb1k?t=2640)　$\Phi(x) = x^p$ 是 $F$ 的 **Frobenius 自同態**。

- 【課堂討論】「這兩條性質讓它成為什麼？」「**環同態**。」「$p$ 次方是環同態。」學生：「聽起來像**癌症**——你得把 Frobenius 自同態**切掉**？」「你可能說對了什麼。」
- （「紙的顏色變了，是因為我**逃到休息室避難**，從那裡的櫃子拿了紙。辦公室**當時不安全**。」）

> **推論 36**（講義 p.5）[▶ 45:00](https://youtu.be/FItuJ2msb1k?t=2700)　$\mathbb{F}$ 是特徵 $p$ 的**有限**體 ⇒ $\mathbb{F}$ 的每個元素都是某元素的 **$p$ 次方**。

「可以證 Frobenius 是滿射。對我來說**很怪**——有理數不這樣：每個有理數都是另一個有理數的平方？當然不是。」

> **命題 37**（講義 p.5）[▶ 46:00](https://youtu.be/FItuJ2msb1k?t=2760)　**有限體**上每個不可約多項式都可分；多項式可分 $\iff$ 是相異不可約多項式的乘積。

「這跟特徵 0 的情形**一模一樣**。今天稍早有不可約卻不可分的例子——我刻意強調那是**無窮**體，這就是為什麼那可能發生。」

> **定義**（講義 p.5）[▶ 46:30](https://youtu.be/FItuJ2msb1k?t=2790)　特徵 $p$ 的體 $K$ 若每個元素都是 $p$ 次方（$K = K^p$），叫**完美體（perfect）**。特徵 0 的體也叫完美的。

> **定義**　$K$ 的每個元素都是 $F$ 上某個**可分**多項式的根，叫 $K/F$ **可分**；否則不可分。

> **推論 39**（講義 p.5）[▶ 47:30](https://youtu.be/FItuJ2msb1k?t=2850)　完美體的有限擴張都是可分的。特別地，$\mathbb{Q}$ 或有限體的有限擴張都可分。

【口頭】[▶ 48:00](https://youtu.be/FItuJ2msb1k?t=2880)「每個元素都是最小多項式的根；希望最小多項式**也可分**——可分體裡就是這樣。能的話你會想在**完美體**上工作。**不可分**擴張的理論很不愉快——那是 Galois 理論裡**我拒絕在這裡講**的部分。D&F 有一節講，但**不是我的菜**。」

## 7. ℚ(√2, √3) = ℚ(√2 + √3)

[▶ 48:30](https://youtu.be/FItuJ2msb1k?t=2910)（講義 p.6–8）「這是課的**尾聲**，回到那個問題：$\mathbb{Q}(\sqrt2,\sqrt3)$ 是**單擴張**嗎？」學生：「你說可以。」「我說可以，但**怎麼做**？」
- 它是 4 次，所以要找 **4 次**的元素。$\sqrt6$ 不行（最小多項式 $x^2-6$，2 次）。
- 試 $\alpha = \sqrt2+\sqrt3$。【課堂討論】[▶ 49:30](https://youtu.be/FItuJ2msb1k?t=2970)「它的**反元素**？」學生：「$\sqrt2-\sqrt3$。」「差一點。」「$\sqrt3-\sqrt2$。」「對！我本來以為要推導，後來想到**可以猜**。」
$$(\sqrt3+\sqrt2)(\sqrt3-\sqrt2) = 3-2 = 1.$$
- $\mathbb{Q}(\alpha)$ 含 $\alpha$ 和 $\alpha^{-1}$ ⇒ 相加 $2\sqrt3$、相減 $2\sqrt2$ ⇒ $\sqrt2,\sqrt3\in\mathbb{Q}(\alpha)$ ⇒ $\mathbb{Q}(\sqrt2,\sqrt3)\subseteq\mathbb{Q}(\alpha)$。

💬 另一個包含 $\mathbb{Q}(\alpha)\subseteq\mathbb{Q}(\sqrt2,\sqrt3)$ 是**顯然**的（$\alpha = \sqrt2+\sqrt3$ 本來就在右邊），所以其實到這裡**已經證完** $\mathbb{Q}(\sqrt2,\sqrt3) = \mathbb{Q}(\sqrt2+\sqrt3)$。講義和老師都說「還要證另一個包含」，接著去找最小多項式。

**最小多項式**[▶ 51:00](https://youtu.be/FItuJ2msb1k?t=3060)「你們作業有一堆這種。怎麼找？」學生：「**倒推**——平方消根號。」
$$\alpha^2 = 5+2\sqrt6\ ⇒\ \Big(\frac{\alpha^2-5}2\Big)^2 = 6\ ⇒\ \alpha^4-10\alpha^2+1 = 0.$$
- 驗算（講義 p.7）：$\alpha^4 = 49+20\sqrt6$，$49+20\sqrt6-10(5+2\sqrt6)+1 = 0$ ✓。「**不意外**——構造本身就讓它必然成立。」
- ⇒ $[\mathbb{Q}(\alpha):\mathbb{Q}]\le4$。

**不可約？**[▶ 52:00](https://youtu.be/FItuJ2msb1k?t=3120)
- **Eisenstein 沒用**。模 2：$x^4+1$，$f(1) = 0$——「**哎呀**」。
- 模 3：$x^4-x^2+1$，$f(0) = f(1) = f(2) = 1$，沒有根。$\mathbb{Z}_3$ 的不可約二次式只有 $x^2+1$、$x^2+x+2$、$x^2+2x+2$。「我查了——**絕對不是**在學術長官發表重要演講的會議中查的。」長除法後才想到：
$$x^4-10x^2+1 = x^4+2x^2+1 = (x^2+1)^2\quad\text{in }\mathbb{Z}_3[x].$$
  「**可惡**。這不證明它可約，只證明 $\mathbb{Z}_3$ 沒用。」（「有個**支線任務**可以拿 10 分——不是這個，是之前那個。」）
- **用擴張理論**[▶ 53:30](https://youtu.be/FItuJ2msb1k?t=3210)：$[\mathbb{Q}(\alpha):\mathbb{Q}]\le4$，而 $\mathbb{Q}(\alpha)\supseteq\mathbb{Q}(\sqrt2,\sqrt3)$（4 維）⇒ $\mathbb{Q}(\alpha)$ **正好 4 維**。
- 【口頭】[▶ 55:00](https://youtu.be/FItuJ2msb1k?t=3300)「我想如果回頭看對的定理，這其實**證明了**最小多項式不可約。但還有些**缺口**，我還沒完全被說服。我不是總能一次記得所有定理——你們在人生某些領域大概也有這經驗。我閉嘴了。」[▶ 56:00](https://youtu.be/FItuJ2msb1k?t=3360)「想打大亂鬥的……」

💬 補上缺口：$m_{\alpha,\mathbb{Q}}$ 整除 $x^4-10x^2+1$（Prop 9：$\alpha$ 是它的根），而 $\deg m_{\alpha,\mathbb{Q}} = [\mathbb{Q}(\alpha):\mathbb{Q}] = 4$。首一、次數相同、又整除 ⇒ **$m_{\alpha,\mathbb{Q}} = x^4-10x^2+1$**，所以它不可約。（講義 p.8 最後也走向這個論證：若可約，就有更低次的不可約 $f$ 以 $\alpha$ 為根，$\mathbb{Q}(\alpha)\cong\mathbb{Q}[x]/(f)$ 次數 $<4$，矛盾。）

## 附：本集一句話總結

> **多項式在分裂體裡沒有重根就叫可分；特徵 2 的無窮體 $\mathbb{F}_2(t)$ 上 $x^2-t$ 不可約卻是 $(x+\sqrt t)^2$；形式導數不是環同態但滿足 Leibniz 律，正好給出判準：$\alpha$ 是重根 ⟺ $f(\alpha) = f'(\alpha) = 0$，由此 $x^{p^n}-x$ 可分、$x^n-1$ 在 $p\nmid n$ 時可分、$p\mid n$ 時每根都重；特徵 $p$ 有 Frobenius 自同態 $x\mapsto x^p$（大一新生之夢成真），特徵 0 和有限體都是完美體、上面不可約就可分；最後證明 $\mathbb{Q}(\sqrt2,\sqrt3) = \mathbb{Q}(\sqrt2+\sqrt3)$，最小多項式 $x^4-10x^2+1$。**
