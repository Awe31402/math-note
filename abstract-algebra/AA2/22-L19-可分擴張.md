# 第 22 集 · L19：可分與不可分擴張 [▶ 影片](https://www.youtube.com/watch?v=FItuJ2msb1k&list=PLBY4G2o7DhF1x_afv1rv_d0hFCoMWEb-j)

## 本集概要

D&F §13.5：
- 在分裂體中 $f = a_n(x-\alpha_1)^{n_1}\cdots(x-\alpha_k)^{n_k}$；**重根**、**單根**；**可分多項式** = 沒有重根。
- 怪例子：$\mathbb{F}_2(t)$ 上 $x^2-t = (x-\sqrt t)^2$——不可約但**不可分**。
- **形式導數**不是環同態（Leibniz 法則）；**$\alpha$ 是重根 ⇔ $f(\alpha) = f'(\alpha) = 0$**（上次想不起來的命題）。
- 例：$x^{p^n}-x$ 可分；$x^n-1$ 在 $p\nmid n$ 時可分，$p\mid n$ 時每個根都是重根。
- 特徵 0：不可約 ⇒ 可分。**Frobenius 自同態** $x\mapsto x^p$（「新生的美夢」）；有限體中每個元素都是 $p$ 次方；**完全體**；有限體上不可約 ⇒ 可分。
- $\mathbb{Q}(\sqrt2,\sqrt3) = \mathbb{Q}(\sqrt2+\sqrt3)$。

> 📘 講義對應：Math422 Lecture 19「Separable Extensions」；D&F §13.5（Prop. 33、Cor. 34、Prop. 35 等）。

## 筆記

### 1. 重根與可分性 [▶ 01:00](https://youtu.be/FItuJ2msb1k?t=60)

$f\in F[x]$，首項係數 $a_n$。存在分裂體，其中有相異的 $\alpha_1,\dots,\alpha_k$ 使
$$f(x) = a_n(x-\alpha_1)^{n_1}\cdots(x-\alpha_k)^{n_k},\qquad n_i\ge1,\quad n_1+\cdots+n_k = n = \deg f.$$
- 這個分解不在 $F[x]$ 裡發生，而在某個分裂體裡（「我們不用給它取名，只要知道它存在」）。

> **定義**：$n_i\ge2$ 時 $\alpha_i$ 是**重根**（multiple root），$n_i$ 是**重數**；$n_i = 1$ 時是**單根**（simple root）。$f$ 是**可分的**（separable），若它沒有重根（所有根相異）；否則是**不可分的**（inseparable）[▶ 05:00](https://youtu.be/FItuJ2msb1k?t=300)。

- 為什麼能隨意談「根」？上次說過：每個多項式都有分裂體，不同分裂體同構且保持根的結構——不會在一個分裂體有重根、另一個沒有 [▶ 06:00](https://youtu.be/FItuJ2msb1k?t=360)。

**例 1** [▶ 07:00](https://youtu.be/FItuJ2msb1k?t=420)：$x^2-2 = (x+\sqrt2)(x-\sqrt2)$，$\sqrt2\ne-\sqrt2$，**可分**。（老師口誤說成「不可分」。）「你們同意 $\sqrt2\ne-\sqrt2$ 吧？——因為下一個例子裡它們就相等了。」

**例 2**（怪例子）[▶ 08:30](https://youtu.be/FItuJ2msb1k?t=510)：$\mathbb{F}_2(t)$ = 係數在 $\mathbb{F}_2 = \mathbb{Z}_2$ 的 $t$ 有理函數，特徵 2，**無窮**體（學生猜元素個數「2」「$i$」，老師：「你們沒猜 67 我很失望」）。$x^2-t$ 在其上不可約（$\sqrt t$ 不在裡面）。在分裂體中，因為 $2 = 0$、$-1 = 1$：
$$x^2-t = x^2+t = (x+\sqrt t)^2 = (x-\sqrt t)^2.$$
所以 $x^2-t$ **不可約但不可分**——它只有一個根 $\sqrt t$，重數 2 [▶ 12:30](https://youtu.be/FItuJ2msb1k?t=750)。

### 2. 形式導數 [▶ 13:30](https://youtu.be/FItuJ2msb1k?t=810)

$D_x(a_nx^n+\cdots+a_1x+a_0) = na_nx^{n-1}+\cdots+a_1$。D&F 用 $D_x$（對批評「不夠形式」的人有用），老師用 $f'(x)$。

**導數是環同態嗎？** [▶ 15:00](https://youtu.be/FItuJ2msb1k?t=900)：可加，但 $(fg)' = f'g+fg'\ne f'g'$——要滿足 **Leibniz 法則**。
- 「微積分一的新生把 $(fg)' = f'g'$ 寫錯時，其實是在當抽象代數學家——希望導數是環同態。該多給點部分分數。」

> **命題**（D&F Prop. 33）：$f$ 有重根 $\alpha$ $\iff$ $\alpha$ 也是 $f'$ 的根。也就是：$f$ 和 $f'$ 都能被 $m_{\alpha,F}$ 整除 [▶ 16:30](https://youtu.be/FItuJ2msb1k?t=990)。

- 上次找不到的就是這個——「它本來就該在這部分講」。
- 第二句由第一句免費得到：$\alpha$ 是根 ⇔ 最小多項式整除。

**證明** [▶ 19:30](https://youtu.be/FItuJ2msb1k?t=1170)（學生選「先證順向」）
- ⇒：$f = (x-\alpha)^2g$（在分裂體中——「分裂體一節給了我們偷懶的執照」）。$f' = 2(x-\alpha)g+(x-\alpha)^2g'$，所以 $f'(\alpha) = 0$。
- ⇐：$f = (x-\alpha)h$，$f' = h+(x-\alpha)h'$ [▶ 24:00](https://youtu.be/FItuJ2msb1k?t=1440)。$f'(\alpha) = h(\alpha) = 0$，所以 $h = (x-\alpha)h_2$，$f = (x-\alpha)^2h_2$。（「你們忘了微積分一嗎？太過分了。」）
- 「我好像特別喜歡用到微積分的證明。」學生：「拜託別考這個。」——「本來覺得是好考題，現在重新考慮。」

> 💬 研究週提案截止日；學生：「通常是男生求婚（propose）。」——「加分。」老師鼓勵大家去拿研究週的獎金 [▶ 21:00](https://youtu.be/FItuJ2msb1k?t=1260)。

### 3. 例子 [▶ 28:00](https://youtu.be/FItuJ2msb1k?t=1680)

**例 3**：$\mathbb{F}_p$ 上 $f = x^{p^n}-x$。$f' = p^nx^{p^n-1}-1 = -1$（模 $p$）。$f'$ 沒有根，所以 $f$ 沒有重根，**可分**。

**例 4** [▶ 29:30](https://youtu.be/FItuJ2msb1k?t=1770)：$f = x^n-1$，$f' = nx^{n-1}$。在 $n\ne0$ 的體中（即 $p\nmid n$，$p$ 是特徵；老師先寫成「$n$ 不整除特徵」，後來改正）[▶ 37:30](https://youtu.be/FItuJ2msb1k?t=2250)，$f'$ 唯一的根是 0，而 $f(0) = -1\ne0$。所以**可分**。

**例 5** [▶ 32:00](https://youtu.be/FItuJ2msb1k?t=1920)：$\operatorname{char}F = p$、$p\mid n$。$f' = nx^{n-1} = 0$ 恆為零，所以 $f$ 的**每個根都是重根**，不可分。
- 例：$\mathbb{Z}_3$ 上 $x^6-1$，$f' = 6x^5 = 0$。根：$f(0) = -1$、$f(1) = 0$、$f(2) = 63 = 0$，根是 1、2 [▶ 35:00](https://youtu.be/FItuJ2msb1k?t=2100)。老師一時困惑（以為會很怪），結論是：$f = (x-1)^{n_1}(x-2)^{n_2}$，定理說 $n_1,n_2\ge2$，確切是多少還要再算。

> 💬 補充（非課堂內容）：特徵 3 中 $x^3\pm1 = (x\pm1)^3$，所以 $x^6-1 = (x^3-1)(x^3+1) = (x-1)^3(x+1)^3 = (x-1)^3(x-2)^3$，兩個根都是 3 重。

### 4. 特徵 0 與特徵 $p$ [▶ 38:30](https://youtu.be/FItuJ2msb1k?t=2310)

（進度落後，改用投影；下課後有任天堂大亂鬥。）

> **推論**（D&F Cor. 34）：特徵 0 的體上，每個不可約多項式都可分；多項式可分 $\iff$ 它是**相異**不可約多項式的乘積。

- 老師希望之後寫好證明再補掃描（猜它和 Prop. 33 的證明類似）。

**新生的美夢**（freshman's dream）[▶ 42:00](https://youtu.be/FItuJ2msb1k?t=2520)：$\operatorname{char}F = p$。二項式定理
$$(x+y)^p = x^p+px^{p-1}y+\cdots+pxy^{p-1}+y^p = x^p+y^p,$$
中間的二項式係數都含 $p$。另外 $(xy)^p = x^py^p$。
- 「這其實是個惡夢——一般不成立，只在特徵 $p$ 這種古怪系統裡才對。」

> **命題**（D&F Prop. 35）：$\operatorname{char}F = p$，$\varphi(x) = x^p$ 是環同態，叫 **Frobenius 自同態**（Frobenius endomorphism）[▶ 44:00](https://youtu.be/FItuJ2msb1k?t=2640)。

（學生：「聽起來像要開刀拿掉的東西。」紙的顏色變了，因為老師躲到休息室寫講義。）

- **推論**：$F$ 是特徵 $p$ 的**有限**體，則 Frobenius 是滿射：**每個元素都是某個元素的 $p$ 次方**。有理數就不是這樣（不是每個有理數都是平方）[▶ 45:30](https://youtu.be/FItuJ2msb1k?t=2730)。
- **推論**：有限體上不可約多項式都可分；多項式可分 ⇔ 是相異不可約多項式的積——和特徵 0 一樣。例 2 之所以可能，是因為 $\mathbb{F}_2(t)$ 是**無窮**體 [▶ 46:00](https://youtu.be/FItuJ2msb1k?t=2760)。

> **定義**：特徵 $p$ 的體 $K$ 叫**完全體**（perfect field），若 $K = K^p$（每個元素都是 $p$ 次方）。特徵 0 的體也叫完全體。

> **定義**：$K/F$ 是**可分擴張**，若 $K$ 的每個元素都是某個可分多項式的根（等價地：最小多項式可分）；否則不可分。

- **完全體的有限擴張都是可分的** [▶ 47:30](https://youtu.be/FItuJ2msb1k?t=2850)。
- 不可分擴張的 Galois 理論很不舒服，D&F 有一節講，「我拒絕講」。

### 5. $\mathbb{Q}(\sqrt2,\sqrt3)$ 是單擴張 [▶ 48:30](https://youtu.be/FItuJ2msb1k?t=2910)

次數 4，要找一個 4 次的元素。$\sqrt6$ 只有 2 次，不行。試 $\alpha = \sqrt2+\sqrt3$。
- 反元素？學生猜到：$\sqrt3-\sqrt2$（「$\sqrt2-\sqrt3$ 差一點」）——因為 $(\sqrt3+\sqrt2)(\sqrt3-\sqrt2) = 1$ [▶ 49:30](https://youtu.be/FItuJ2msb1k?t=2970)。
- $\mathbb{Q}(\alpha)$ 包含 $\alpha$ 和 $\alpha^{-1}$，相加減得 $2\sqrt3$、$2\sqrt2$，所以 $\mathbb{Q}(\sqrt2,\sqrt3)\subseteq\mathbb{Q}(\alpha)$；另一方向顯然 [▶ 50:30](https://youtu.be/FItuJ2msb1k?t=3030)。
- **最小多項式**：平方消根號，得 $x^4-10x^2+1$。所以 $[\mathbb{Q}(\alpha):\mathbb{Q}]\le4$ [▶ 51:00](https://youtu.be/FItuJ2msb1k?t=3060)。
- 不可約？Eisenstein 不行；模 2 不行；模 3 沒有根，但 $x^4-10x^2+1\equiv x^4+2x^2+1 = (x^2+1)^2$，可約——「模 3 沒用，不代表它可約」。（老師是在「某個重要的長官演講的會議中」查 $\mathbb{Z}_3$ 不可約二次式的。）
- **維數論證** [▶ 54:00](https://youtu.be/FItuJ2msb1k?t=3240)：$\mathbb{Q}(\sqrt2,\sqrt3)\subseteq\mathbb{Q}(\alpha)$，前者 4 維，後者至多 4 維 ⇒ 相等、4 維。老師覺得「還有缺口」，還不完全確信這證明了最小多項式不可約。

> 💬 補充（非課堂內容）：這已足夠：$[\mathbb{Q}(\alpha):\mathbb{Q}] = 4$ 就是 $\alpha$ 最小多項式的次數；$x^4-10x^2+1$ 是首一 4 次且以 $\alpha$ 為根，最小多項式整除它，次數相同，所以兩者相等，它不可約。
