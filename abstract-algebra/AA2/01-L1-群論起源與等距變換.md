# 第 1 集 · L1：群論的起源、Cardano 公式、等距變換 [▶ 影片](https://www.youtube.com/watch?v=AlA9ET7OgjA&list=PLBY4G2o7DhF1x_afv1rv_d0hFCoMWEb-j)

## 本集概要

新學期第一堂。老師講「群論從哪裡來」，分兩條線：
- **解方程式**：二次公式 → 三次（Cardano）→ 四次（Ferrari）→ 五次沒有根式解（Ruffini、Abel、Galois）。對根做**置換**（permutation）是關鍵，「群」這個詞就是這樣來的。
- **幾何的對稱**：Klein 的 Erlangen 綱領——用「允許的變換群」來分類幾何。
- 歐氏空間的**等距變換**（isometry）= 平移 ∘ 正交變換；圖形的**對稱群**；平面上的有限對稱群只有循環群和二面體群。
- 下一堂：群作用（group action）、軌道穩定子定理。

> 📘 講義對應：Math422 Lecture 1「Equations & Symmetries」第 1–15 頁；Dummit & Foote p.610、630–631；Rotman《Advanced Modern Algebra》2nd ed. p.3；Artin《Algebra》第 6 章。

### 2. 二次方程式 [▶ 02:00](https://youtu.be/AlA9ET7OgjA?t=120)

- 二次方程式的故事很古老：**配方法**（completing the square）就得到公式。
- 以前的人不接受負數的平方根——那只代表「這個平面幾何問題沒有解」[▶ 04:00](https://youtu.be/AlA9ET7OgjA?t=240)。

### 3. 三次方程式：Cardano 公式 [▶ 06:30](https://youtu.be/AlA9ET7OgjA?t=390)

**第一步：壓縮**（depress）。$x^3+ax^2+bx+c = 0$，代入 $x = y-\frac a3$，消掉二次項：
$$y^3+py+q = 0,\qquad p = \frac{3b-a^2}{3},\quad q = \frac{2a^3-9ab+27c}{27}.$$

**判別式**（discriminant）：
$$D = -4p^3-27q^2.$$

**公式**（D&F p.630–631，基於 Lagrange 的**預解式**（resolvent）理論）[▶ 08:00](https://youtu.be/AlA9ET7OgjA?t=480)：
$$A = \sqrt[3]{-\tfrac{27}{2}q+\tfrac32\sqrt{-3D}},\qquad B = \sqrt[3]{-\tfrac{27}{2}q-\tfrac32\sqrt{-3D}},$$
立方根要選成 $AB = -3p$。令 $\rho = e^{2\pi i/3}$，三個根是
$$\alpha = \frac{A+B}{3},\qquad \beta = \frac{\rho^2A+\rho B}{3},\qquad \gamma = \frac{\rho A+\rho^2B}{3}.$$

- 這比 Lagrange 早很多，Lagrange 只是給了漂亮的推導 [▶ 10:00](https://youtu.be/AlA9ET7OgjA?t=600)。

**例子** [▶ 11:00](https://youtu.be/AlA9ET7OgjA?t=660)
- $y^3-8 = 0$：$(A+B)/3 = 2$。要很費工才找到那個唯一的實根 [▶ 14:00](https://youtu.be/AlA9ET7OgjA?t=840)；另兩個是複數根。
- $y^3-4y = 0$：三個根 $0,\pm2$，公式算出 $\alpha,\beta,\gamma$ 對得上 [▶ 17:00](https://youtu.be/AlA9ET7OgjA?t=1020)。從「大一代數」的角度這完全不意外——直接因式分解就好。但公式裡會出現複數，才得到實根。
- **作業**：$y^3-7y+6 = 0$（$D = 400$，$(A+B)/3 = -3$）。

### 4. 四次方程式 [▶ 18:30](https://youtu.be/AlA9ET7OgjA?t=1110)

- Ferrari（約 1540）：壓縮成 $x^4+qx^2+rx+s$ 後，問題化成解一個**預解三次式**（resolvent cubic）
$$(j^2)^3+2q(j^2)^2+(q^2-4s)j^2-r^2 = 0.$$
- 好消息：它是三次，我們已經會解。「四次就是這樣解的。」[▶ 20:00](https://youtu.be/AlA9ET7OgjA?t=1200)

### 5. 歷史年表 [▶ 21:00](https://youtu.be/AlA9ET7OgjA?t=1260)

符號本身也很晚才出現：
- 「$\pm$」Widman 1486；「$=$」Recorde 1557；指數 Hume 1636；Viète 1591 開始用字母 [▶ 22:00](https://youtu.be/AlA9ET7OgjA?t=1320)。

解方程式：
| 年份 | 人物 | 事件 |
|---|---|---|
| 約 1515 | del Ferro | 解出壓縮三次式 |
| 1535 | Tartaglia | 重新發現 |
| 1545 | Cardano | 出版三次、四次公式 |
| 1770 | Lagrange | 預解式；用根的**置換**系統化前人的結果 |
| 1799 | Ruffini | 證明（有漏洞）一般五次式不能用根式解 |
| 1815 | Cauchy | 定義置換的乘法，證明 $S_n$ 的基本性質（循環記號、不相交循環分解） |
| 1824 | Abel | 證明不是所有五次式都能用根式解，證明用到根的置換 |
| 1829 | Galois | 給出判斷哪些五次式能用根式解的方法；創造「群」這個詞（$S_n$ 中對合成封閉的子集） |

- 對高於五次的方程式，代換法怎麼做都行不通 [▶ 24:00](https://youtu.be/AlA9ET7OgjA?t=1440)。
- **推動群論的就是解多項式方程式的需要** [▶ 26:00](https://youtu.be/AlA9ET7OgjA?t=1560)。
- Galois 已經有這些想法：共軛、正規子群、商群、單群。
- **Galois 定理**：$\mathbb{Q}$ 上的多項式方程式能用根式解 $\iff$ 它的 Galois 群是**可解的**（solvable）。

> 💬 講義旁註：Galois 理論需要那麼多背景，卻可說是抽象代數的起源——有點好笑。

### 6. 對稱函數 [▶ 27:00](https://youtu.be/AlA9ET7OgjA?t=1620)

> **定義**：不定元 $x_1,\dots,x_n$ 的**初等對稱函數**（elementary symmetric functions）
> $$s_1 = x_1+\cdots+x_n,\quad s_2 = \sum_{i<j}x_ix_j,\quad\dots,\quad s_n = x_1x_2\cdots x_n.$$
> **一般多項式**（general polynomial）$(x-x_1)\cdots(x-x_n)$，根就是這些不定元。

$$(x-x_1)(x-x_2)\cdots(x-x_n) = x^n-s_1x^{n-1}+s_2x^{n-2}-\cdots+(-1)^ns_n.$$

- 係數（差個正負號）就是初等對稱函數。目標：用係數寫出根的公式。
- 它們在 $1,2,3$ 的所有置換下不變——這就是 $S_3$ 出場的地方 [▶ 28:00](https://youtu.be/AlA9ET7OgjA?t=1680)。

### 7. Klein 的 Erlangen 綱領 [▶ 29:00](https://youtu.be/AlA9ET7OgjA?t=1740)

- 19 世紀中，Cayley 把群的概念抽象到置換以外；同時發現了**非歐幾何**——平行線會相交、熟悉的定理變形或消失。
- **Erlangen 綱領**（Erlangen program，1872，Felix Klein）：用一個幾何**允許的變換群**來研究它 [▶ 30:00](https://youtu.be/AlA9ET7OgjA?t=1800)。

| 幾何 | 允許的變換 | 結構 |
|---|---|---|
| 射影幾何 | 射影變換 | 最少 |
| 仿射幾何 | 仿射變換 | 中間 |
| 歐氏幾何 | 歐氏變換 | 最多 |

- **Klein 幾何**用一對 $(G,H)$ 實現：$G$ 是群，$H$ 是子群，空間 $X = G/H$，$G$ 是它的對稱群 [▶ 32:00](https://youtu.be/AlA9ET7OgjA?t=1920)。
  - 仿射空間：$G = \mathrm{Aff}(n)\cong\mathbb{R}^n\rtimes GL(n,\mathbb{R})$，$H = GL(n,\mathbb{R})$。
  - 歐氏空間：$G = \mathrm{Euc}(n)\cong\mathbb{R}^n\rtimes O(n,\mathbb{R})$，$H = O(n,\mathbb{R})$。
  - $\rtimes$ 是**半直積**（semidirect product）。
- 「用保持結構的映射來研究結構」在數學裡一再出現；Klein 的綱領每一代都被重新發明 [▶ 34:00](https://youtu.be/AlA9ET7OgjA?t=2040)。

> **定義**：$S$ 是非空集合。$S$ 上的一個雙射叫做 $S$ 的一個**置換**。

### 8. 歐氏幾何與等距變換 [▶ 36:00](https://youtu.be/AlA9ET7OgjA?t=2160)

在 $\mathbb{R}^n$ 上：$x\cdot y = \sum x_iy_i$，$\|x\| = \sqrt{x\cdot x}$，$d(x,y) = \|y-x\|$。

$\mathbb{R}^n$ 的所有置換多得不得了，歐氏幾何只在乎其中一小部分：

> **定義**：$\varphi:\mathbb{R}^n\to\mathbb{R}^n$ 是**等距變換**（isometry）$\iff \|\varphi(P)-\varphi(Q)\| = \|P-Q\|$ 對所有 $P,Q$。

> **定理**：$\varphi$ 是等距變換。
> 1. $\varphi$ 保內積（$\varphi(x)\cdot\varphi(y) = x\cdot y$）$\iff \varphi(0) = 0$。
> 2. 定義角 $\angle(x,y) = \cos^{-1}\frac{x\cdot y}{\|x\|\|y\|}$，則 $\varphi$ 保角 [▶ 38:00](https://youtu.be/AlA9ET7OgjA?t=2280)。

- **平移**（translation）$T_a(x) = x+a$；**正交變換**（orthogonal transformation）$L_R(x) = Rx$，$R^TR = I$，即 $R\in O(n)$。兩者都容易驗證是等距變換。

> **定理**：$\mathrm{Isom}(\mathbb{R}^n)$ 是 $\mathrm{Perm}(\mathbb{R}^n)$ 的子群；$\mathrm{Trans}(\mathbb{R}^n)$、$\mathrm{Orth}(\mathbb{R}^n)$ 都是 $\mathrm{Isom}(\mathbb{R}^n)$ 的子群。而且每個 $\varphi\in\mathrm{Isom}(\mathbb{R}^n)$ 都能寫成 $\varphi = L_R\circ T_a$。

- 換句話說：保距離的映射只有平移和正交變換（的合成）[▶ 40:00](https://youtu.be/AlA9ET7OgjA?t=2400)。
- 證明的一步（好練習）：**引理** $\varphi\in\mathrm{Isom}$，則 $\varphi\in\mathrm{Orth}\iff\varphi(0) = 0$。
- 部分證明會當作業；細節見 Artin 第 6 章或 O'Neill《Elementary Differential Geometry》，老師也有一支影片講完整證明（「如果你喜歡受苦」）[▶ 42:00](https://youtu.be/AlA9ET7OgjA?t=2520)。
- 要描述「實體物件」的運動（motion），得排除行列式為 $-1$ 的正交矩陣（鏡射）[▶ 44:00](https://youtu.be/AlA9ET7OgjA?t=2640)。

### 9. 對稱群 [▶ 44:30](https://youtu.be/AlA9ET7OgjA?t=2670)

- $\mathbb{R}^2$、$\mathbb{R}^3$ 的等距變換把圓送到圓、直線送到直線、圖形送到同樣的圖形。

> **定義**：$\Omega\subseteq\mathbb{R}^n$ 的**對稱群**（symmetry group）
> $$\Sigma(\Omega) = \{\varphi\in\mathrm{Isom}(\mathbb{R}^n)\mid\varphi(\Omega) = \Omega\}.$$

- 例：邊長 1 的正 $n$ 邊形 $\Omega_n$，$\Sigma(\Omega_n) = D_n$。但算 $D_n$ 通常用表現（presentation）更方便：$D_n = \langle a,b\mid a^n = b^2 = 1,\ bab = a^{-1}\rangle$。

> **定理**（Artin 2nd ed. Cor. 6.4.10，p.167）：$G$ 是 $\mathrm{Isom}(\mathbb{R}^2)$ 的**有限**子群。適當選座標後，$G$ 是循環群或二面體群。

- 老師說可能漏了某個前提，記不清 [▶ 46:00](https://youtu.be/AlA9ET7OgjA?t=2760)。
- Artin 接著分類**離散**（discrete）但無限的子群：平面上有 **17 種晶體群**（crystallographic groups，又叫壁紙群）。
- 「離散」來自拓撲：每個點都能被不相交的鄰域隔開。有限 ⇒ 離散，但也有無限的離散集，例如 $\mathbb{Z}\subseteq\mathbb{R}$、格子 $\mathbb{Z}^2\subseteq\mathbb{R}^2$。它們同構於 $\mathrm{Isom}(\mathbb{R}^2)$ 的某些離散子群（會出作業）。
- 維度：$\dim\mathrm{Isom}(\mathbb{R}^2) = 1+2 = 3$，$\dim\mathrm{Isom}(\mathbb{R}^3) = 3+3 = 6$。

### 10. 往後的故事（「神祕的預告」）[▶ 47:30](https://youtu.be/AlA9ET7OgjA?t=2850)

- **Klein 幾何 / 齊性空間**（homogeneous spaces）：一個群除以子群 [▶ 48:00](https://youtu.be/AlA9ET7OgjA?t=2880)。
- **Cartan 幾何**：加入**聯絡**（connection），描述模型幾何在局部怎麼被扭曲：
  - Riemann 流形 ↔ 歐氏空間；Lorentz 流形 ↔ Minkowski 空間；共形流形 ↔ 共形球面；仿射聯絡流形 ↔ 仿射空間。
- Klein 幾何有整體的對稱；聯絡的**曲率**（curvature）讓群作用的方式逐點變化。精確的語言是主纖維叢。
- 「別擔心，不會考這些流形的胡言亂語。」下一堂：**群作用**——群怎麼「作用」在集合上 [▶ 50:00](https://youtu.be/AlA9ET7OgjA?t=3000)。
