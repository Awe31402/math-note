## 1. 二次方程：配方法

[▶ 01:30](https://youtu.be/AlA9ET7OgjA?t=90)「群論的起源故事，其實要回到**解多項式方程**。這很古老——巴比倫人等古文明都會解二次方程。」

$$f(x) = x^2+bx+c = \left(x+\tfrac b2\right)^2-\tfrac{b^2}4+c.$$
- 令 $y = x+\frac b2$，就**壓低（depress）**了二次式——沒有一次項：$g(y) = y^2-d$。
- $y = \pm\sqrt d$，回代得**二次公式**
$$x = \frac{-b\pm\sqrt{b^2-4c}}2.$$
- 假設領導係數是 1（**首一 monic**）。「只要領導係數非零，除掉就好，故事不變。」
- （「抱歉，我腦子裡的微分方程要清出去——『差分方程』……」）

【口頭】[▶ 03:00](https://youtu.be/AlA9ET7OgjA?t=180)「如果你還沒看，**Veritasium** 有支 15–20 分鐘的影片講配方法，解釋為什麼叫『**配成正方形**』——字面上就是一個幾何問題：用特定邊長**填滿一個正方形**。」

**為什麼古人不在乎負數開根號**[▶ 03:30](https://youtu.be/AlA9ET7OgjA?t=210)
- 代數問題原本都綁著**幾何問題**。$d<0$ 只代表「這個平面幾何的重排問題**物理上不可能**」。
- 「把多項式方程**脫離幾何**來想，在大局裡是**相對新**的——大約 400–500 年。」

**判別式**（講義 p.1）：$d = (x_2-x_1)^2 = s_1^2-4s_2$，用來分類解的類型。$b,c\in\mathbb{Q}$ 時，除非 $d$ 是平方數否則沒有有理解；$d<0$ 沒有實數解。

## 2. 三次方程：Cardano 公式

### 2.1 壓低的三次式與判別式

[▶ 04:30](https://youtu.be/AlA9ET7OgjA?t=270)「你們大概從沒看過三次公式推完，今天也不會看到，但至少給你們看些公式。」

$x^3+ax^2+bx+c$，代 $x = y-\frac a3$，**平方項消失**：
$$g(y) = y^3+py+q,\quad p = \tfrac13(3b-a^2),\ q = \tfrac1{27}(2a^3-9ab+27c).$$
（講義：「這看起來是個**放鬆的作業練習**。」）**解壓低三次式就解了原式**：只差一個平移。

【口頭】[▶ 05:30](https://youtu.be/AlA9ET7OgjA?t=330)「有一次我跟一個學生在處理某個問題——跟循環群的**群代數**上的微分方程有關。他進來說他**很難過（depressed）**。我很困惑。他說：『我很難過，因為我找到解了。』笑點是他的解用到**壓低的（depressed）三次式**——而我**太無知**，不知道什麼是 depressed cubic。所以一個很好的笑話浪費在我身上。」

> **定義（判別式 discriminant）**（講義 p.2）[▶ 07:00](https://youtu.be/AlA9ET7OgjA?t=420)　$(x-x_1)(x-x_2)(x-x_3)$ 的判別式是
> $$D = (x_1-x_2)^2(x_1-x_3)^2(x_2-x_3)^2.$$
> 對 $y^3+py+q$：
> $$D = -4p^3-27q^2.$$

「這**一點也不明顯**——Dummit & Foote p.630–631 有推導，基於 **Lagrange 的預解式理論（theory of resolvents）**。」

【口頭】[▶ 08:00](https://youtu.be/AlA9ET7OgjA?t=480)「很難不深入就描述預解式理論。這樣說吧：它是**利用解之間可能的模式**來解多項式方程的策略——某種意義上像是假設解由兩個東西的和組成，代進去……很複雜。」

（插曲 [▶ 09:00](https://youtu.be/AlA9ET7OgjA?t=540)：「我的雷射筆在哪？……雷射筆裡怎麼有一塊**樂高**？那不該讓它壞掉。不過確實讓人好奇樂高怎麼跑進去的，**Benjamin**。」）

### 2.2 Cardano 公式

[▶ 10:00](https://youtu.be/AlA9ET7OgjA?t=600)「不是 Lagrange 發現的——比 Lagrange **早得多**。只是 Lagrange 有漂亮的推導。」

> **定理（Cardano 公式）**（講義 p.3）　解 $y^3+py+q = 0$：
> $$A = \sqrt[3]{-\tfrac{27}2q+\tfrac32\sqrt{-3D}},\qquad B = \sqrt[3]{-\tfrac{27}2q-\tfrac32\sqrt{-3D}},\qquad AB = -3p.$$
> 三個解：
> $$\alpha = \frac{A+B}3,\quad\beta = \frac{\rho^2A+\rho B}3,\quad\gamma = \frac{\rho A+\rho^2B}3,$$
> 其中 $\rho = -\tfrac12+\tfrac12\sqrt{-3} = e^{2\pi i/3}$（主三次單位根）。

**麻煩**[▶ 10:30](https://youtu.be/AlA9ET7OgjA?t=630)
- 你可能在取**複數**的立方根（$D$ 可能是正的）。
- 複數有**三個**立方根，必須選得讓 $AB = -3p$ [▶ 13:00](https://youtu.be/AlA9ET7OgjA?t=780)。「在我做過的題目裡這不是問題，我想你們作業那題也不是。」

【口頭】[▶ 11:30](https://youtu.be/AlA9ET7OgjA?t=690)「你們記得高中學過這個嗎？我也不記得。但不知為何**我太太高中時推過這個**。哇。」

### 2.3 例 1：y³ − 8 = 0

[▶ 11:30](https://youtu.be/AlA9ET7OgjA?t=690)（講義 E1）「這例子有點痛苦：實數解是 2，就結束了——三次式（非零的）最多一個……」
- $p = 0$、$q = -8$ ⇒ $D = -27\cdot64$，$\sqrt{-3D} = 72$。
- $A = 3\sqrt[3]8$，$B = 0$ ⇒ $AB = 0 = -3p$ ✓。
- $\alpha = \frac{A+B}3 = \sqrt[3]8 = 2$。「**我們很努力才找到那一個實數解**。」
- $\beta = 2e^{4\pi i/3} = 2e^{-2\pi i/3}$、$\gamma = 2e^{2\pi i/3}$——**共軛解**。「這**必須**發生：實係數三次式，複數解成共軛對。」

講義 p.4：$y^3-8 = (y-2)(y^2+2y+4)$，後者不可約、沒實根。

【Q&A】[▶ 14:00](https://youtu.be/AlA9ET7OgjA?t=840) 學生：「$\alpha$ 總是那個實數解嗎？」老師：「**剛好**是這樣，不必然。」

> 📘 講義的 Remark：「顯然一般的代數比 Cardano 公式簡單得多。」

### 2.4 例 2：y³ − 4y = 0

[▶ 15:00](https://youtu.be/AlA9ET7OgjA?t=900)（講義 E2）「跟上一個互補：$p\neq0$、$q = 0$。」
- $p = -4$ ⇒ $D = 256$，$\sqrt{-3D} = 16i\sqrt3$。
- $A = \sqrt[3]{24i\sqrt3} = \sqrt[3]{24\sqrt3}\,e^{\pi i/6}$（$i = e^{\pi i/2}$，開立方 $e^{\pi i/6}$）。
  - 【口頭】「修過**複變**的人可能會說：『沒那麼簡單，還有別的東西。』對。希望那些不礙事。」
- $B = \sqrt[3]{24\sqrt3}\,e^{-\pi i/6}$。
- **檢查** $AB = \sqrt[3]{24\cdot24\cdot3} = 12 = -3p$ ✓ [▶ 16:00](https://youtu.be/AlA9ET7OgjA?t=960)。「要檢查，因為立方根有歧義；選錯了乘積就回不到 12。剛好**天真的選法**行得通。」
- $\alpha = \tfrac23\sqrt[3]{24\sqrt3}\cos\tfrac\pi6 = 2$。
- $\beta = 0$、$\gamma = -2$。

【口頭】[▶ 17:00](https://youtu.be/AlA9ET7OgjA?t=1020)「**三次解很狂的地方**：即使答案是實數，三次公式**不管你喜不喜歡**都帶你進**虛數**的世界。這跟二次公式很不一樣——二次的時候可以說『虛數就是虛的，因為這問題不物理』。但這是 2，是個長度，**必須物理**。然而經由 Cardano 公式的路，不管你喜不喜歡，都經過複數系統。」

「當然從微積分先修的觀點這完全不意外：$y^3-4y = y(y-2)(y+2)$。重點**不是**學更好的分解方法，而是讓你們感受三次公式涉及什麼。」

**作業**[▶ 18:30](https://youtu.be/AlA9ET7OgjA?t=1110)：講義 E3 $y^3-7y+6 = 0$（$D = 400$，$\frac{A+B}3 = -3$），用 Cardano 公式求三個解。「我甚至告訴你們判別式了，耶。」

## 3. 四次方程與歷史

**四次（Ferrari，約 1540）**[▶ 19:00](https://youtu.be/AlA9ET7OgjA?t=1140)（講義 p.6，Descartes 約 1637 的做法）
- 代 $y = x-\frac b4$ 消三次項：$g(y) = y^4+qy^2+ry+s$。
- 假設能分解成 $(y^2+jy+l)(y^2-jy+m)$——這個模式**必須**存在。
- 解出 $j,l,m$ 要解**預解三次式（resolvent cubic）**：
$$(j^2)^3+2q(j^2)^2+(q^2-4s)j^2-r^2 = 0.$$
- 「好消息：它是三次，我們已經會解了。」然後兩個二次因式各自解。
- 【口頭】[▶ 20:00](https://youtu.be/AlA9ET7OgjA?t=1200)「**不客氣**，我沒出四次的作業——除非有人付錢，你**不會想**推那些公式，非常噁心。」

**策略**[▶ 20:30](https://youtu.be/AlA9ET7OgjA?t=1230)：壓低多項式，然後**利用根之間的模式**做特定代換。成功的話，就得到**只用係數**表示根的公式——「這就是『二次公式的推廣』的意思」。

**歷史小知識**（Rotman 引 Cajori《A History of Mathematical Notation》）[▶ 21:30](https://youtu.be/AlA9ET7OgjA?t=1290)
- 字母當變數：**Viète** 1591；等號：**Recorde** 1557；指數：**Hume** 1636；加減號：**Widman** 1486。
- 【口頭】「讀 Rotman 的樂趣之一是那些**歷史小插曲**。這本書差點用在這門課，但有點太進階了。它在某些主題上有**驚人的清晰**。」

**時間線**（講義 p.6–7）

| 年份 | 事件 |
|---|---|
| ≈1515 | Scipione del Ferro：三次的特殊情形 |
| 1535、1545 | Tartaglia、Cardano：一般三次（「有內鬥和不當歸功，**古代數學大戰**」——見 Veritasium 影片） |
| ≈1540 | Ferrari：四次 |
| 1500s–1800 | 很多人找五次公式 |
| 1770 | **Lagrange**：合理的代換產生的預解式，對五次要解**比五次更高**的問題 |
| 1799 | **Ruffini**：有缺口的證明，說五次一般不能用根式解（Rotman 說證明其實是對的，只是有缺口——「我信 Rotman」） |
| 1815 | **Cauchy**：置換的乘法、**循環記號**、互斥循環分解——「你們學過的 $S_n$ 基本事實都是 Cauchy 1815」 |
| 1824 | **Abel**：不是所有五次都能用根式解；證明用到**根的置換** |
| 1829 | **Galois**：給出判斷**哪些**五次能用根式解的方法；創造「**群**」這個詞 |

【口頭】[▶ 23:00](https://youtu.be/AlA9ET7OgjA?t=1380)「我想是 Cardano 的 *Ars Magna* 出版了，大家都看得到。有段時間數學家不分享成果，留著自己的玩具去贏數學競賽。」

**Galois**[▶ 26:00](https://youtu.be/AlA9ET7OgjA?t=1560)
- 把**群**定義成 $S_n$ 中對合成封閉的子集。
- Galois 最初的工作裡**已經有**：共軛、正規子群、商群、單群。「**這就是群論的誕生**——動機是想找二次公式的類比。」
- 證明：（$\mathbb{Q}$ 上）多項式方程能用根式解 $\iff$ 它的 **Galois 群可解（solvable）**。
- 「這門課的**第二條故事線**，我們會走到能對簡單例子理解這個——這是我們的目標之一。」
- 【口頭】「好笑的是：**Galois 理論需要這麼多背景**，卻**可以說是**群論（抽象代數）的起源。」

## 4. 對稱函數與一般多項式

[▶ 27:00](https://youtu.be/AlA9ET7OgjA?t=1620)（講義 p.8）「這頁很有意思，我們之後會回來。」

> **定義（基本對稱函數 elementary symmetric functions）**　不定元 $x_1,\dots,x_n$：
> $$s_1 = x_1+\cdots+x_n,\quad s_2 = \sum_{i<j}x_ix_j,\quad\dots,\quad s_n = x_1x_2\cdots x_n.$$

> **定義（一般多項式 general polynomial）**　$(x-x_1)(x-x_2)\cdots(x-x_n)$，根是不定元 $x_1,\dots,x_n$。
> $$(x-x_1)\cdots(x-x_n) = x^n-s_1x^{n-1}+s_2x^{n-2}-\cdots+(-1)^ns_n.$$

- 例 $n = 3$：$x^3-s_1x^2+s_2x-s_3$；$s_2 = x_1x_2+x_1x_3+x_2x_3$ 在 $\{1,2,3\}$ 的**所有置換**下不變。
- 【口頭】[▶ 28:00](https://youtu.be/AlA9ET7OgjA?t=1680)「這就是預解式機器的很多原料。盯著這個看，你更能體會為什麼**根的置換**會進來：根的洗牌對應方程的分解。」
- 講義：Lagrange 用**利用公式對根置換的對稱性**的系統方法重現前人的結果。

## 5. 對稱與 Klein 的 Erlangen 綱領

[▶ 28:30](https://youtu.be/AlA9ET7OgjA?t=1710)（講義 p.9–10）
- 19 世紀中，**Cayley** 已經把群的概念抽象到**超越置換**。
- 差不多同時發現**非歐幾何**：平行線在無窮遠相交、三角形內角和不是 180°——「各種神聖的歐氏幾何事實都失去了」。「怎麼研究非歐幾何？要有方法。」

> **Erlangen 綱領（Felix Klein，1872）**[▶ 29:30](https://youtu.be/AlA9ET7OgjA?t=1770)　用**允許的變換群**來刻劃、分類幾何。

| 幾何 | 結構 | 允許的變換 |
|---|---|---|
| 射影幾何 | 最少 | 射影變換 |
| 仿射幾何 | 中間 | 仿射變換 |
| 歐氏幾何 | 最多 | 歐氏變換（旋轉、平移……） |

【口頭】[▶ 30:30](https://youtu.be/AlA9ET7OgjA?t=1830)「修過現代幾何的人對這有點熟。射影幾何是空白模板。歐氏幾何裡**角度**有意義，射影幾何沒有——對吧？……沒人同意？你們修過那門課的。這就是**整學期不用座標**的結果——用座標就會記得比較好。」學生：「我們做的是幾何那一邊，不是代數那一邊。」「我以為他喜歡代數。好吧，我不胡鬧了——大概不可能。」

**Klein 幾何（齊性空間）**[▶ 32:00](https://youtu.be/AlA9ET7OgjA?t=1920)：一對 $(G,H)$，$H\le G$，空間 $X = G/H$ 允許 $G$ 的變換。
- **仿射空間** $A(n)\cong\mathbb{R}^n$：$G = \operatorname{Aff}(n)\cong\mathbb{R}^n\rtimes GL(n,\mathbb{R})$，$H = GL(n,\mathbb{R})$。
- **歐氏空間** $E(n)$：$G = \operatorname{Euc}(n)\cong\mathbb{R}^n\rtimes O(n,\mathbb{R})$，$H = O(n,\mathbb{R})$。「某種意義上 $O(n)$ 約掉，剩下的像 $\mathbb{R}^n$——但是**允許正交群自然作用**的 $\mathbb{R}^n$。」
- $\rtimes$ 是**半直積（semi-direct product）**：「你們 421 記得嗎？我也不記得，因為我那裡也沒教。作業有一題，你們會發現它是什麼。」
- 「我在用『**作用**』這個詞好像它有意義——下一講會更精確。」

【口頭】[▶ 33:30](https://youtu.be/AlA9ET7OgjA?t=2010)「用**偏好的映射保持結構**——這模式在數學裡一再出現。去讀 Klein 綱領，你會發現**每一代數學家**都把自己看成在新脈絡裡**實現 Klein 綱領**。」

> **定義**（講義 p.10）[▶ 34:30](https://youtu.be/AlA9ET7OgjA?t=2070)　$S$ 非空集合。$S$ 上的**雙射**叫 $S$ 的**置換（permutation）**。

「我在**大幅推廣**置換的定義——不只是 1 到 $n$。例如實數線有多少置換？**這其實是個很嚇人的問題**。有無窮多——從 $\mathbb{R}$ 到自己的一對一映成映射多得不得了。」

## 6. 歐氏空間的等距變換

[▶ 35:30](https://youtu.be/AlA9ET7OgjA?t=2130)（講義 p.11–12）「我們談對稱時，常以**歐氏幾何**為背景。這門課真正要聚焦的是歐氏幾何——其實只有幾題作業。」

- 內積 $x\cdot y = x_1y_1+\cdots+x_ny_n$；長度 $\|x\| = \sqrt{x\cdot x}$；距離 $d(x,y) = \|y-x\|$。

> **定義（等距變換 isometry）**[▶ 36:30](https://youtu.be/AlA9ET7OgjA?t=2190)　$\varphi:\mathbb{R}^n\to\mathbb{R}^n$ 保持點之間的距離：
> $$\|\varphi(P)-\varphi(Q)\| = \|P-Q\|\quad\forall P,Q.$$

【口頭】「我**不**從一開始就定義等距是雙射——**你們要在作業裡證明它是雙射**。不顯然。希望我鋪了清楚的路；其中一步比另一步難得多。」

> **定理**（講義 p.11，留給讀者）[▶ 37:30](https://youtu.be/AlA9ET7OgjA?t=2250)　$\varphi$ 是等距。
> 1. $\varphi$ 保持內積 $\iff$ $\varphi(0) = 0$。
> 2. 定義角 $\theta = \cos^{-1}\frac{x\cdot y}{\|x\|\|y\|}$，則 $\varphi$ 保持角度。

【口頭】[▶ 38:00](https://youtu.be/AlA9ET7OgjA?t=2280)「我想 (2) 也需要 $\varphi(0) = 0$ 的假設。沒有那條件我對 (2) 有點懷疑。」

【課堂討論】[▶ 38:30](https://youtu.be/AlA9ET7OgjA?t=2310)「你們能想到等距的例子嗎？」
- **平移** $T_a(x) = x+a$：兩點一起平移，距離不變。
- **旋轉、反射**：從中心點到旋轉後的點距離不變。都包在**正交變換** $L_R(x) = Rx$（$R^TR = I$，$R\in O(n)$）裡。「證明它們是等距**不難**，我想是作業。」

> **定理**（講義 p.12）[▶ 39:30](https://youtu.be/AlA9ET7OgjA?t=2370)　$\operatorname{Isom}(\mathbb{R}^n)$ 是 $\operatorname{Perm}(\mathbb{R}^n)$ 的子群；$\operatorname{Trans}(\mathbb{R}^n)$、$\operatorname{Orth}(\mathbb{R}^n)$ 都是它的子群。而且**每個**等距都寫成
> $$\varphi = L_R\circ T_a.$$

- 「有意思的是：**就這些**。平面上所有保距映射，就是平移和正交變換的合成。」
- 兩者都可逆：$L_R^{-1} = L_{R^T}$、$T_a^{-1} = T_{-a}$ ⇒ 合成可逆 ⇒ **每個等距都是雙射**。「我沒定義它們是雙射，但這些定理證明它們是。」[▶ 40:30](https://youtu.be/AlA9ET7OgjA?t=2430)

> **引理**（講義 p.12）　$\varphi\in\operatorname{Isom}(\mathbb{R}^n)$：$\varphi\in\operatorname{Orth}(\mathbb{R}^n)\iff\varphi(0) = 0$。

【口頭】[▶ 41:30](https://youtu.be/AlA9ET7OgjA?t=2490)「這裡有一步**很難**，很多步很簡單。如果你**愛自討苦吃**，我在一支**初等微分幾何**的影片（O'Neill 的課本）裡給過完整證明。另一個地方是某位 **Harvard 教授**在 YouTube 的抽象代數課（Artin 的書）——他花了大約**五講**拆解等距群，非常精湛，比我今天做的好得多。」

**運動 vs. 等距**[▶ 43:00](https://youtu.be/AlA9ET7OgjA?t=2580)
- 等距把圓送到圓、線送到線；剛體送到同一個剛體——「**幾乎**。」
- 「等距也允許把這個**咖啡杯內外翻轉**——標籤從外面翻到裡面。還是同一個點集，但不是同一個杯子，對吧？」學生：「首先，那會**把杯子打破**。」
- **運動（motions）**：物理上對固體合理的等距——要排除正交矩陣**行列式為負**（反射，會把東西內外翻轉）。

## 7. 對稱群；平面的有限與離散對稱群

> **定義（對稱群 symmetry group）**（講義 p.13）[▶ 44:00](https://youtu.be/AlA9ET7OgjA?t=2640)　$\Omega\subseteq\mathbb{R}^n$：
> $$\Sigma(\Omega) = \{\varphi\in\operatorname{Isom}(\mathbb{R}^n) : \varphi(\Omega) = \Omega\}.$$

- 不是 $\Omega$ 上的**對稱群** $S_\Omega$（所有雙射）——那大得多，不在乎距離。

**例**[▶ 45:00](https://youtu.be/AlA9ET7OgjA?t=2700)（講義 E4）：正 $n$ 邊形 $\Omega_n$ ⇒ $D_n = \Sigma(\Omega_n)$。「你們在 421 想過了吧？**二面體群就是正 $n$ 邊形的對稱群**。」
- 講義：用 $D_n = \langle a,b\mid|a| = n,|b| = 2,bab = a^{-1}\rangle$ 計算「幾乎總是比較好」。

> **定理**（Artin Cor 6.4.10，《Algebra》2nd ed. p.167）[▶ 45:30](https://youtu.be/AlA9ET7OgjA?t=2730)　$G$ 是 $\operatorname{Isom}(\mathbb{R}^2)$ 的**有限**子群 ⇒ 適當選座標，$G$ 是**循環群**或**二面體群**。

（老師一開始覺得少了條件：「Artin 接著分類……喔，我的錯，是**有限**子群。」）

**離散子群**[▶ 46:00](https://youtu.be/AlA9ET7OgjA?t=2760)（講義 p.14）
- **離散（discrete）**：點是分開的、不在連續統上——「離散是**拓樸**的概念：能用開集分開點」。有限 ⇒ 離散，但也有無限的離散集。
- 例：$\mathbb{Z}\subseteq\mathbb{R}$、$\mathbb{Z}^2\subseteq\mathbb{R}^2$（單位**格**）是加法的離散子群。
- **在同構意義下只有 17 個**平面的離散（無限）等距子群——**平面晶體群（planar crystallographic groups）**[▶ 46:30](https://youtu.be/AlA9ET7OgjA?t=2790)。「我念不出那個字，你們讀得到。」那些**鑲嵌**——「在歐氏幾何下，平面上你能做的就這些。」
- 講義 Remark：$\dim\operatorname{Isom}(\mathbb{R}^n) = \dim\operatorname{Orth}+\dim\operatorname{Trans}$，例如 $\dim\operatorname{Isom}(\mathbb{R}^2) = 1+2 = 3$、$\dim\operatorname{Isom}(\mathbb{R}^3) = 3+3 = 6$。

## 8. 展望：Klein 幾何、Cartan 幾何

[▶ 47:30](https://youtu.be/AlA9ET7OgjA?t=2850)（講義 p.15）「結論：$\operatorname{Isom}(\mathbb{R}^n)$ 有**豐富的故事**可講。幾個**前瞻性**的評論——有些遠遠超過這門課。」

- **Klein 幾何／齊性空間**：一個群除以另一個，看群乘陪集空間。「相對容易懂。」
- **Cartan 幾何**：引入**聯絡（connection）**，描述模型幾何**局部怎麼扭曲**。變換群處處相同，但在**不同點作用不同**，取決於**曲率（curvature）**。
  - **Riemann 流形**：歐氏空間的變形。
  - **Lorentz 流形**：**Minkowski 空間**（狹義相對論的自然幾何）的變形。
  - **共形流形**：共形球面的變形。
  - **帶仿射聯絡的流形**：仿射空間的變形。
- Klein 幾何是**全域**對稱，Cartan 幾何是**局部**對稱；要講精確需要**主纖維叢（principal fiber bundles）**。「別擔心，我們不會進去。」（講義：「顯然我不考流形論的胡言亂語 ☺」）

**下次**[▶ 50:00](https://youtu.be/AlA9ET7OgjA?t=3000)：**群作用**，以及**軌道穩定子定理**——「讓我們用很妙的方式解一大堆計數問題」。

| 4 | $y = x+\frac b4$ | 分解成兩個二次，解預解三次式 |
| ≥5 | — | 一般不能用根式解（Ruffini、Abel）；Galois：可解 ⟺ Galois 群可解 |

**Cardano**：$\alpha = \frac{A+B}3$、$\beta = \frac{\rho^2A+\rho B}3$、$\gamma = \frac{\rho A+\rho^2B}3$，$\rho = e^{2\pi i/3}$。即使三個根都是實數，公式也要經過複數。
