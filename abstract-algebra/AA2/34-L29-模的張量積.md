## 1. 動機：擴張純量

【重建】[[30-L26-模]] 提過：**限制**純量很容易（$R$-模自動是子環 $S$ 的模），但反過來，把 $S$-模 $N$ 變成 $R$-模不唯一、不簡單。想要一個「最自然」的 $R$-模 $R\otimes_SN$，元素形如 $\sum r_i\otimes n_i$，並滿足
$$(r+r')\otimes n = r\otimes n+r'\otimes n,\quad r\otimes(n+n') = r\otimes n+r\otimes n',\quad rs\otimes n = r\otimes sn\ (s\in S).$$
- 典型例子：$\mathbb{C}\otimes_\mathbb{R}V$——實向量空間的**複化**（[[35-L30-張量代數]] 提到要用它理解 Math 321 的複化與實 Jordan 形）。

---

## 2. 構造

【重建】$N$ 是右 $R$-模、$M$ 是左 $R$-模。
1. 取以 $N\times M$ 為基底的**自由 $\mathbb{Z}$-模**（[[32-L28-生成集、自由模與秩]]、[[33-L28-補充-自由模定理證明]] 的 $F(A)$）。
2. 模掉由下列元素生成的子模：
$$(n+n',m)-(n,m)-(n',m),\qquad(n,m+m')-(n,m)-(n,m'),\qquad(nr,m)-(n,rm).$$
3. 商記作 $N\otimes_RM$，$(n,m)$ 的像記作 $n\otimes m$（**簡單張量**）。一般元素是簡單張量的**有限和**，不一定能寫成單一簡單張量。

---

## 3. 平衡映射、雙線性映射與泛性質

> **定義**【重建】　$\varphi:N\times M\to L$（$L$ 是 Abel 群）是 **$R$-平衡**的：對兩個變數各自可加，且 $\varphi(nr,m) = \varphi(n,rm)$。$R$ 交換時，若還滿足 $\varphi(rn,m) = r\varphi(n,m) = \varphi(n,rm)$，叫 **$R$-雙線性**。

> **定理（泛性質）**【重建】　$\iota(n,m) = n\otimes m$。對任何 $R$-平衡映射 $\varphi:N\times M\to L$，存在**唯一**的群同態 $\Phi:N\otimes_RM\to L$ 使 $\Phi\circ\iota = \varphi$。

- 和 [[32-L28-生成集、自由模與秩]] 自由模的泛性質同一個精神：在「生成元」上定義好，就唯一延伸。

---

## 4. 雙模

> **定義**【重建】　$M$ 同時是左 $R$-模、右 $S$-模，且 $(rm)s = r(ms)$，叫 **$(R,S)$-雙模**（bimodule）。

- $R$ 交換時，左模自動是雙模（[[30-L26-模]] 學生問的就是這個）。
- 若 $N$ 是 $(S,R)$-雙模，$N\otimes_RM$ 是左 $S$-模。特別地，$S\supseteq R$ 時 $S\otimes_RM$ 是 $S$-模——**擴張純量**。

---

## 5. 例子

【重建】（D&F §10.4）
- $\mathbb{Z}/m\mathbb{Z}\otimes_\mathbb{Z}\mathbb{Z}/n\mathbb{Z}\cong\mathbb{Z}/d\mathbb{Z}$，$d = \gcd(m,n)$。例：$\mathbb{Z}/2\otimes\mathbb{Z}/3 = 0$。特別地 $\mathbb{Z}/n\otimes\mathbb{Z}/n\cong\mathbb{Z}/n$（[[35-L30-張量代數]] 用到）。
- $\mathbb{Q}/\mathbb{Z}\otimes_\mathbb{Z}\mathbb{Q}/\mathbb{Z} = 0$（[[35-L30-張量代數]] 用到）：$a\otimes b = a\otimes n(b/n) = na\otimes(b/n)$，取 $n$ 使 $na = 0$。
- $\mathbb{Q}\otimes_\mathbb{Z}\mathbb{Z}/n = 0$。
- $R\otimes_RM\cong M$。
- $R^s\otimes_RR^t\cong R^{st}$（$R$ 交換）——向量空間時就是 $\dim(V\otimes W) = \dim V\cdot\dim W$。
- 張量積對直和分配：$(N\oplus N')\otimes M\cong(N\otimes M)\oplus(N'\otimes M)$。

## 6. 同態的張量積、代數的張量積

【重建】
- $\varphi:M\to M'$、$\psi:N\to N'$ 是模同態，則 $(\varphi\otimes\psi)(m\otimes n) = \varphi(m)\otimes\psi(n)$ 良定義（[[35-L30-張量代數]] 開頭用矩陣表示它：Kronecker 積）。
- $A,B$ 是 $R$-代數，$A\otimes_RB$ 也是 $R$-代數：$(a_1\otimes b_1)(a_2\otimes b_2) = a_1a_2\otimes b_1b_2$（[[35-L30-張量代數]] 回顧）。
