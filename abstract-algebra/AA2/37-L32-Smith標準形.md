## 1. 不變因子、初等因子、準素分解

[▶ 01:00](https://youtu.be/pmeDdms6LH8?t=60)（講義 p.1）回顧：
- **不變因子形式**（D&F Thm 5）：$M\cong R^r\oplus R/(a_1)\oplus\cdots\oplus R/(a_m)$，$a_1\mid\cdots\mid a_m$ 非零非單位——**不變因子**；$r$ 叫 **自由秩**（free rank）。
- **初等因子形式**（Thm 6）[▶ 03:00](https://youtu.be/pmeDdms6LH8?t=180)：
$$M\cong R^r\oplus R/(p_1^{\alpha_1})\oplus\cdots\oplus R/(p_t^{\alpha_t}),$$
  $p_i$ 是質元、**不一定相異**（可以重複）；$p_i^{\alpha_i}$ 叫**初等因子**。（「我寫的是 $M$ 的某個循環子模同構於它。」）

[▶ 05:00](https://youtu.be/pmeDdms6LH8?t=300)「還有一種看法：把**相同質數**放在一起。」

> **定理 7（準素分解定理）**（講義 p.2）[▶ 06:00](https://youtu.be/pmeDdms6LH8?t=360)　$R$ 是 PID，$M$ 是非零**撓** $R$-模（**不一定有限生成**），零化子 $a = up_1^{\alpha_1}\cdots p_n^{\alpha_n}$（$p_i$ 相異質元）。令
> $$N_i = \{x\in M : p_i^{\alpha_i}x = 0\}.$$
> 則 $N_i$ 是零化子為 $p_i^{\alpha_i}$ 的子模，也就是被 $p_i$ **某個冪**零化的元素全體，且
> $$M = N_1\oplus N_2\oplus\cdots\oplus N_n.$$
> 若 $M$ 有限生成，每個 $N_i$ 是有限個循環模的直和，零化子都整除 $p_i^{\alpha_i}$。$N_i$ 叫 $M$ 的 **$p_i$-準素分量**。

- 【口頭】[▶ 10:00](https://youtu.be/pmeDdms6LH8?t=600)「前兩個定理都**假設有限生成**；這個**沒有**。」
- （學生在拉筋扳關節：「Violet 不喜歡**喀喀聲**。」「你把 Violet 變成 **Jill** 了。」）

【講義補充】講義 p.2–3：
- $M = V$（$F[x]$-模，$T$ 誘導）時 $N_i = K_{\lambda_i}$——**廣義特徵空間**（假設 $p_T$ 在 $F$ 上分裂）。
- **D&F §12.1 Thm 9**（p.466）：兩個模 $M_1\cong M_2\iff$ 自由秩相同、且不變因子（或初等因子）的清單相同。

## 2. V 作為 F[x]-模；特徵多項式與最小多項式

[▶ 11:30](https://youtu.be/pmeDdms6LH8?t=690)「有了這些可愛的準素分解定理，問題是：**怎麼實際找出**分解？它的**意義**？——這就是 **Smith 標準形**進場的地方。」
- 「D&F 似乎只對 $F[x]$-模講——由矩陣或線性變換來的。但 Smith 形對 **$\mathbb{Z}$-模**也有意義：一組**關係**定義的 Abel 群，對應的矩陣——下次會看到。今天專注 $F[x]$-模。」
- $T:V\to V$、$f(x)\cdot v = f(T)v$；或矩陣 $A$：$f(x)\cdot v = f(A)v$（$T = L_A$）。上次：$V$ 是**純撓**（有自由部分就會無窮維）：
$$V\cong F[x]/(a_1(x))\oplus\cdots\oplus F[x]/(a_m(x)).$$

> **定義**[▶ 17:00](https://youtu.be/pmeDdms6LH8?t=1020)　**特徵多項式** $p_T(x) = \det(xI-T)$；**最小多項式** $m_T(x)$ = 使 $m_T(T) = 0$ 的最低次首一多項式。

**Math 321 的結果**[▶ 18:30](https://youtu.be/pmeDdms6LH8?t=1110)（「作為**指引**」）：
1. **Cayley–Hamilton**：$p_T(T) = 0$——每個線性變換滿足自己的特徵多項式。
2. $m_T\mid p_T$，兩者有**相同的根**。

> **定理**[▶ 20:30](https://youtu.be/pmeDdms6LH8?t=1230)　$a_m(x) = m_T(x)$——**最大的不變因子就是最小多項式**（也是模的零化子）。不變因子的**乘積**是特徵多項式。

「所以要懂模結構，一大塊就是找最小多項式；反過來，找到模結構就告訴你最小多項式。」

## 3. 例：一個 Jordan 形矩陣的不變因子（現場猜錯又修正）

[▶ 21:30](https://youtu.be/pmeDdms6LH8?t=1290)（老師**現場編**的）
$$A = J_2(3)\oplus J_1(3)\oplus J_2(2)\oplus J_2(2)\oplus J_1(2)\oplus J_1(2).$$
- 【課堂討論】「特徵多項式？」「$(x-3)^3$、$(x-2)^6$。」「最小多項式？」「$(x-3)^2(x-2)^2$。」「每個特徵值取**最大 Jordan 塊**的大小。」
- [▶ 23:00](https://youtu.be/pmeDdms6LH8?t=1380)「如果所有塊都是 $1\times1$？」——最小多項式**分裂成相異一次因式**：Math 321 的結果——**可對角化 ⟺ 最小多項式沒有重根**。
- **不變因子**[▶ 24:00](https://youtu.be/pmeDdms6LH8?t=1440)：老師先猜**三個**（$a_1 = (x-2)^2$、$a_2 = (x-3)(x-2)^2$、$a_3 = m_A$），乘積對得上。
  - 【Q&A】[▶ 27:00](https://youtu.be/pmeDdms6LH8?t=1620) 學生：「這是**唯一**的嗎？你怎麼知道？」「我想是——$a_3$ 一定唯一，不變因子唯一是定理的一部分。」學生：「湊得出來就代表猜對嗎？」「……我卡住了。**可以是 $a_4$ 嗎**？$a_4 = m_A$、$a_3$、$a_2 = x-2$、$a_1 = x-2$？」學生：「不變因子必須**相異**嗎？」「我**沒說**相異。不是我的錯。」
  - [▶ 41:00](https://youtu.be/pmeDdms6LH8?t=2460) 看完後面「$\mathrm{diag}(2,2,3,3)$」的例子後老師改口：「它們**可以相等**。我猜例 1 錯了——應該是**四個**。」
$$a_1 = x-2,\quad a_2 = x-2,\quad a_3 = (x-3)(x-2)^2,\quad a_4 = (x-3)^2(x-2)^2.$$
  乘積 $(x-3)^3(x-2)^6 = p_A$ ✓，$a_1\mid a_2\mid a_3\mid a_4$ ✓。

💬 驗證方法：把初等因子（每個 Jordan 塊一個）按質數分組，再「從大到小一層一層」湊：$x-3$ 的冪 $\{2,1\}$、$x-2$ 的冪 $\{2,2,1,1\}$ ⇒ 最長的一組有 4 個 ⇒ 4 個不變因子；$a_4 = (x-3)^2(x-2)^2$、$a_3 = (x-3)(x-2)^2$、$a_2 = (x-2)$、$a_1 = (x-2)$。三個是不夠的（$(x-2)^6$ 要拆成 4 塊）。

## 4. Smith 標準形

[▶ 29:00](https://youtu.be/pmeDdms6LH8?t=1740)「我在網站上放了『**Smith 標準形的簡單計算**』——**一卡車**的例子。」（「我在更新網站的安全憑證，讓它別再對我的網站**沒安全感**。」）「會有一堆作業練這個。」

> **D&F Thm 21**（講義 p.3）　$A$ 是 $F$ 上 $n\times n$ 矩陣。$F[x]$ 係數的 $xI-A$ 可以用 $F[x]$ 上的**列與行運算**化成對角形
> $$\mathrm{diag}\big(1,\dots,1,a_1(x),a_2(x),\dots,a_m(x)\big),$$
> $a_i$ 首一、次數 $\ge1$，$a_1\mid a_2\mid\cdots\mid a_m$。它們就是 $T = L_A$ 給的 $F[x]$-模的**不變因子**。

**規則**[▶ 30:30](https://youtu.be/pmeDdms6LH8?t=1830)
- 從 $xI-A$ 出發。**列運算**的係數可以是數**或多項式**。
- **也可以做行運算**——「大致對應**重新標記基底**，下次用 Abel 群的關係矩陣說得更明確」。

**例 1（3×3）**[▶ 31:30](https://youtu.be/pmeDdms6LH8?t=1890)
- 列交換 $R_1\leftrightarrow R_3$，把常數項換到左上。$R_2+2R_1$；**$R_3-(x-2)R_1$**——「這是**新招**」。
- 左上有 1 ⇒ 用行運算清掉第一列：$C_2-C_1$、$C_3-(x-5)C_1$。
- （「不管你喜不喜歡都會得到答案。」「Violet 像在說『**我諒你教不會我**』。」）$R_3+R_2$ 讓 $x$ 抵消；$C_3-2C_2$——「**像 Taylor Swift 的歌，消滅了 X**」；行交換、除以 $-9$ 得到 1；再清掉……
- 結果 $\mathrm{diag}(1,1,x(x-3)(x-6))$：最小多項式 $x(x-3)(x-6)$ **沒有重根** ⇒ **可對角化**，特徵值 0、3、6。
- **驗算**[▶ 36:00](https://youtu.be/pmeDdms6LH8?t=2160)：跡是 9，$0+3+6 = 9$。（學生起鬨：「**10**。」）
- 【口頭】「D&F 有個演算法，沿著行運算**追回**特徵基底。**我強烈建議不要學**——太可怕了。可以寫成程式。」學生：「寫程式有加分嗎？」「你會得到成為**全人口 0.003%** 能懂的人的**滿足感**。」

## 5. 更多 Smith 形的例子

[▶ 36:30](https://youtu.be/pmeDdms6LH8?t=2190)（網站講義）
- **對角** $\mathrm{diag}(2,3)$：Smith 形給出最小多項式 $(x-2)(x-3)$——「本來就該料到」。
- **2×2 Jordan 塊** $J_2(\lambda)$：$\mathrm{diag}(1,(x-\lambda)^2)$。
- **沒有實特徵值**的矩陣（$x^2+1$ 的**伴隨矩陣**）：$\mathrm{diag}(1,x^2+1)$。【口頭】「Smith 形裡只有**一個**非單位因子時，**最小多項式 = 特徵多項式**。」
- **$\mathrm{diag}(2,2,3,3)$**[▶ 40:00](https://youtu.be/pmeDdms6LH8?t=2400)：中途得 $\mathrm{diag}(1,1,x-2,x-3)$——「**哎呀**，忘了：這**不是** Smith 形，因為 $x-2\nmid x-3$。不允許。」再做下去得
$$\mathrm{diag}\big(1,1,(x-2)(x-3),(x-2)(x-3)\big).$$
  最小多項式 $(x-2)(x-3)$，特徵多項式 $(x-2)^2(x-3)^2$——**不變因子可以相等**（所以 §3 該是四個）。
- **4×4 實 Jordan 塊**（特徵值 $2\pm3i$ 重複）[▶ 42:30](https://youtu.be/pmeDdms6LH8?t=2550)：用行交換把 1 帶上來（「寫講義時我比較聰明」），「有了左上的 1，就是**把其他都刪掉的執照**」，得到 $((x-2)^2+9)^2$——實數上的最小多項式。
- 實 3×3 Jordan 塊、兩個實 Jordan 塊的例子（「這些**都有點同一個例子**，可惜我沒有更好的」）。
- **$J_2(3)$ 加上特徵值 4、5**[▶ 45:00](https://youtu.be/pmeDdms6LH8?t=2700)（「這個**怪怪的**，希望我做得完」）：最小多項式必須含 $(x-4)$、$(x-5)$，但**不需要平方**——沒有 4 或 5 的 2×2 塊，$x-4$ 就足以殺掉特徵值 4。

**考試三**[▶ 37:00](https://youtu.be/pmeDdms6LH8?t=2220)：「可能考：『算這個矩陣的 Smith 標準形』。如果題目說**不用寫步驟**，你寫『這個 $\sim$ 那個』我就開心。你們已經修了**四門理論代數**，該學會：**矩陣可對角化 ⟺ 最小多項式分裂成相異一次因式**。」

## 6. 伴隨矩陣與有理標準形

[▶ 46:30](https://youtu.be/pmeDdms6LH8?t=2790)（網站講義）
- **循環子空間** $\langle\!\langle v\rangle\!\rangle = \mathrm{span}\{v,Tv,T^2v,\dots\}$（「不是 D&F 的記號」）。$T$ 限制在上面，用這組基底的矩陣是**伴隨矩陣**。

> **定義（伴隨矩陣 companion matrix）**　首一 $p(x) = x^k+b_{k-1}x^{k-1}+\cdots+b_0$ 的 $C(p)$：**次對角線全是 1**，最後一欄是 $-b_0,-b_1,\dots,-b_{k-1}$。它的特徵多項式就是 $p(x)$。

- 例 [▶ 48:30](https://youtu.be/pmeDdms6LH8?t=2910)：$x^2+1 = x^2+0x+1$ ⇒ $C(x^2+1) = \begin{pmatrix}0&-1\\1&0\end{pmatrix}$；$x^2-2$、$x^3-2$ 類似。
- 【口頭】「Math 321 你們**算過**伴隨矩陣的特徵多項式就是 $p(x)$。」學生：「**我才沒做**。」「那是 321 吧？」「是。」「我不知道怎麼回應。」學生：「Jordan 形你只講了**一週**。」「一週**就夠了**。」
- 【口頭】正負號放哪各書不同：「我比較傾向讓多項式那邊**保持正號**、把負號放在矩陣裡，**比較不會惹麻煩**。」

## 7. 三種分解，同一個例子

[▶ 51:00](https://youtu.be/pmeDdms6LH8?t=3060)（回到 §3 的 $A$）
- **初等因子** ↔ **Jordan 塊**（每塊一個）：
$$(x-3)^2,\ (x-3),\ (x-2)^2,\ (x-2)^2,\ (x-2),\ (x-2).$$
- **有理標準形** ↔ **不變因子**的伴隨矩陣直和[▶ 52:30](https://youtu.be/pmeDdms6LH8?t=3150)：
$$C(x-2)\oplus C(x-2)\oplus C\big((x-3)(x-2)^2\big)\oplus C\big(m_A(x)\big).$$
  「有理標準形在不同書**意思略不同**；這是一種結構方式。」它的好處：**即使沒有特徵值也有意義**；不變因子唯一，所以它**唯一**。
- **Jordan 形**嚴格說只在特徵值都在體裡時才有定義。「$\mathbb{R}$ 上我用**實 Jordan 形**——複化後再回來：實 Jordan 塊配上**旋轉伸縮塊**（可能夾著 $I$）。」Jordan 塊的**順序不唯一**，就像初等因子清單。
- **準素分解** ↔ **廣義特徵空間**：特徵值 3、2 各一個廣義特徵空間——對應 $F[x]$ 中的**質元** $x-3$、$x-2$。

【口頭】[▶ 55:30](https://youtu.be/pmeDdms6LH8?t=3330)「很難找到真的講**實 Jordan 形**的代數書——代數學家**不喜歡把東西弄醜**。我問過一兩次，得到『那很醜，你自己推就好』。不，**我想要查得到**——這才是重點。」

[▶ 57:00](https://youtu.be/pmeDdms6LH8?t=3420)「下次更多例子。你們現在有 **AI** 了，可以自己想出來——我**不用教了**，乾脆收攤。」「你們覺得伊朗的戰爭結束了嗎？」學生：「**同時是也不是**。」

## 8. 一頁速查表

| 概念 | 內容 |
|---|---|
| 不變因子 | $a_1\mid\cdots\mid a_m$，可以相等 |
| 初等因子 | 質數冪，可重複 |
| 準素分解 | $N_i = \{x : p_i^{\alpha_i}x = 0\}$，不需有限生成 |
| $F[x]$-模 $V$ | 純撓；$a_m = m_T$，$\prod a_i = p_T$ |
| 可對角化 | $m_T$ 分裂成相異一次因式 |
| **Smith 形** | $xI-A$ 用多項式列＋行運算化成 $\mathrm{diag}(1..1,a_1..a_m)$ |
| 只有一個非單位因子 | $m_T = p_T$ |
| 伴隨矩陣 $C(p)$ | 次對角 1、最後一欄 $-b_i$ |
| 有理標準形 | $\bigoplus C(a_i)$，唯一 |
| Jordan 形 | ↔ 初等因子 |
| 準素分量 | ↔ 廣義特徵空間 |

**例**：$A = J_2(3)\oplus J_1(3)\oplus J_2(2)^{\oplus2}\oplus J_1(2)^{\oplus2}$：不變因子 $x-2,\ x-2,\ (x-3)(x-2)^2,\ (x-3)^2(x-2)^2$。

| 中文 | English |
|---|---|
| 自由秩 | free rank |
| 準素分解；$p$-準素分量 | primary decomposition; $p$-primary component |
| 特徵多項式；最小多項式 | characteristic / minimal polynomial |
| Cayley–Hamilton 定理 | Cayley–Hamilton theorem |
| Smith 標準形 | Smith normal form |
| 伴隨矩陣 | companion matrix |
| 循環子空間 | cyclic subspace |
| 有理標準形 | rational canonical form |
| 實 Jordan 形 | real Jordan form |
| 廣義特徵空間 | generalized eigenspace |

## 附：本集一句話總結

> **PID 上有限生成模有三種等價描述——不變因子（$a_1\mid\cdots\mid a_m$，可以相等）、初等因子（質數冪，可重複）、準素分解（按質數分組，不需有限生成）；對 $F[x]$-模 $V$，最大不變因子是最小多項式、乘積是特徵多項式，而具體算法是把 $xI-A$ 用多項式係數的列＋行運算化成 Smith 標準形 $\mathrm{diag}(1,\dots,1,a_1,\dots,a_m)$；不變因子的伴隨矩陣直和就是唯一的有理標準形，初等因子對應 Jordan 塊，準素分量就是廣義特徵空間——老師現場也示範了不變因子數錯、再用例子修正的過程。**
