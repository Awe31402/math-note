# 第 16 集 · L13：除法算法、不可約多項式的開始 [▶ 影片](https://www.youtube.com/watch?v=TjcdPWa-0DY&list=PLBY4G2o7DhF1x_afv1rv_d0hFCoMWEb-j)

## 本集概要

- 依上次承諾，完整證明**多項式除法算法**——而且在任意有 1 的環上成立，只要除式的首項係數是**單位**（證明取自 Nicholson 的書，對次數歸納）。
- 警示：非交換環上「代入」和「分解」不相容：$(x-a)(x+b)$ 在 $a$ 的值是 $ba-ab$。
- 老師 421 講義 Lecture 26：整環上多項式的**可約 / 不可約**；**要說「在哪裡」不可約**：$x^2+1$ 在 $\mathbb{R}$ 上不可約、在 $\mathbb{C}$ 上可約；$3x+6$ 在 $\mathbb{Z}$ 上可約、在 $\mathbb{Q}$ 上不可約。
- 體上一次式不可約（整環上不一定）。
- **2、3 次多項式在體上可約 ⇔ 在體中有根**。

> 📘 講義對應：Math422 Lecture 13「Polynomials and Factoring」；Nicholson《Introduction to Abstract Algebra》p.201；老師 2018 年 421 講義 Lecture 26（Thm 4.6.6）。

### 1. 除法算法（一般環） [▶ 01:30](https://youtu.be/TjcdPWa-0DY?t=90)

> **定理**（除法算法）：$R$ 是有 1 的環，$f,g\in R[x]$，$f\ne0$，且 **$f$ 的首項係數是 $R$ 的單位**。則存在唯一的 $q,r\in R[x]$ 使
> 1. $g = qf+r$；
> 2. $r = 0$ 或 $\deg r<\deg f$。

- 老師原本以為可以用良序原理證——那是證「$F[x]$ 是 PID」的方法（取次數最小的元素），這裡不一樣 [▶ 04:00](https://youtu.be/TjcdPWa-0DY?t=240)。「有些人會很高興」——**歸納法**（「安靜，歸納男孩」）。

**存在性**（對 $m = \deg g$ 歸納）[▶ 05:30](https://youtu.be/TjcdPWa-0DY?t=330)
- 若 $g = 0$ 或 $\deg g<\deg f$：$g = 0\cdot f+g$，取 $q = 0$、$r = g$。
- 否則 $m\ge n = \deg f$。寫 $f = ux^n+ax^{n-1}+\cdots$（$u$ 是單位）、$g = bx^m+cx^{m-1}+\cdots$（「m 是 mummy 的 m，n 是 nanu 的 n」）[▶ 08:30](https://youtu.be/TjcdPWa-0DY?t=510)。
- 令 $g_1 = g-bu^{-1}x^{m-n}f$——**消掉 $g$ 的最高次項** [▶ 10:00](https://youtu.be/TjcdPWa-0DY?t=600)。注意我們沒有除以 $b$，只是乘 $f$ 首項係數的反元素。
$$g_1 = (c-bu^{-1}a)x^{m-1}+\cdots,$$
  所以 $g_1 = 0$ 或 $\deg g_1\le m-1$。
- 歸納假設：$g_1 = q_1f+r$，$r = 0$ 或 $\deg r<\deg f$ [▶ 15:00](https://youtu.be/TjcdPWa-0DY?t=900)。
- 於是 $g = g_1+bu^{-1}x^{m-n}f = (q_1+bu^{-1}x^{m-n})f+r$ [▶ 16:30](https://youtu.be/TjcdPWa-0DY?t=990)。

**唯一性** [▶ 18:30](https://youtu.be/TjcdPWa-0DY?t=1110)：$g = qf+r = q_2f+r_2$。則 $r-r_2 = (q_2-q)f$。
- 若 $q_2-q\ne0$：因為 $f$ 的首項係數是**單位**，$(q_2-q)f$ 的首項係數不會是 0。（反例：在 $\mathbb{Z}_6$ 上，首項係數 2 和 3 相乘得 0。）[▶ 21:30](https://youtu.be/TjcdPWa-0DY?t=1290)
- 所以 $\deg(r-r_2) = \deg(q_2-q)+\deg f\ge\deg f$。但 $r,r_2$ 的次數都小於 $\deg f$，矛盾。
- 故 $q = q_2$，$r = r_2$。
- （學生糾正「thus, thus」——「文法納粹」，老師說他在努力讓影片被取消營利。）

**證明的意義** [▶ 25:00](https://youtu.be/TjcdPWa-0DY?t=1500)：它就是演算法本身——每次從被除式減掉能塞進去的最大倍數，這就是長除法。

> 💬 老師推薦 Nicholson 的書（p.201）。他希望每門課都用免費教材，因為學校收課程費後學生只能用電子書，「一邊辦數位健康月、一邊逼你們全部讀電子版，太說不過去」[▶ 26:30](https://youtu.be/TjcdPWa-0DY?t=1590)。

### 2. 非交換環上代入的陷阱 [▶ 27:30](https://youtu.be/TjcdPWa-0DY?t=1650)

證明中**沒有用到交換律**，所以除法算法在非交換環也成立。但 Nicholson 的警示故事：

$f(x) = (x-a)(x+b)$，$a,b\in R$（不一定交換）。直覺上「代 $a$」得 $(a-a)(a+b) = 0$。但乘開
$$f(x) = x^2+(b-a)x-ab,$$
$$f(a) = a^2+ba-a^2-ab = ba-ab,$$
不一定是 0 [▶ 31:30](https://youtu.be/TjcdPWa-0DY?t=1890)。
- 非交換時，**求值與分解不相容**，要區分左乘和右乘。我們只在交換環上證明求值是環同態，原因就在這裡。
- 「非交換多項式的求值理論是什麼？我其實不知道。」「這本來可以是很可怕的作業題。」

### 3. 可約與不可約多項式 [▶ 32:30](https://youtu.be/TjcdPWa-0DY?t=1950)

（老師 421 講義 Lecture 26。）

> 💬 老師一度說「每個整環都是 UFD」，馬上改口：包含是真包含，所以有不是 UFD 的整環（例如 $\mathbb{Z}[\sqrt{-5}]$）。「我閉嘴。這段剪掉。」[▶ 34:00](https://youtu.be/TjcdPWa-0DY?t=2040)

> **定義**：$D$ 是整環，$f\in D[x]$ 非零、非單位。若 $f = gh$（$g,h\in D[x]$）時 $g$ 或 $h$ 是單位，則 $f$ 在 $D$ 上**不可約**（irreducible over $D$）。非零、非單位、不是不可約的，叫**可約**（reducible）[▶ 35:00](https://youtu.be/TjcdPWa-0DY?t=2100)。

- 這其實就是之前「不可約元」的定義，套到 $D[x]$ 上。

**要說在哪裡** [▶ 38:30](https://youtu.be/TjcdPWa-0DY?t=2310)
- $x^2+1 = (x+i)(x-i)$：在 $\mathbb{C}$ 上可約；在 $\mathbb{R}$ 上不可約。
- $3x+6 = 3(x+2)$ [▶ 40:00](https://youtu.be/TjcdPWa-0DY?t=2400)：
  - 在 $\mathbb{Z}$ 上**可約**：3 和 $x+2$ 都不是 $\mathbb{Z}[x]$ 的單位。
  - 在 $\mathbb{Q}$ 上**不可約**：3 是 $\mathbb{Q}$ 的單位（$\mathbb{Q}^\times = \mathbb{Q}\setminus\{0\}$），這個分解是「蠢的」。

> 💬 老師問「你們把我當小丑嗎？」學生：「我比較喜歡說弄臣。」——「在其他場合，走進房間講一小時數學，你會孤單一人。」[▶ 38:00](https://youtu.be/TjcdPWa-0DY?t=2280)

### 4. 一次式 [▶ 44:00](https://youtu.be/TjcdPWa-0DY?t=2640)

（學生提醒「下課了」——「才 45 分鐘吧？」）

> **引理**：$F$ 是體，$m\ne0$，則 $mx+b$ 在 $F$ 上不可約。

**證明**：$mx+b = f(x)g(x)$。$m\ne0$ 是兩個首項係數的乘積，所以 $f,g\ne0$，且 $\deg f+\deg g = 1$。不失一般性 $f = c_1x+c_2$、$g = c_3$，$c_3\ne0$。$F[x]$ 的單位就是 $F$ 的非零元素，所以 $g$ 是單位 [▶ 48:00](https://youtu.be/TjcdPWa-0DY?t=2880)。

**能弱化成整環嗎？** [▶ 49:00](https://youtu.be/TjcdPWa-0DY?t=2940)：學生想「也許整環就夠」。但 $\mathbb{Z}$ 是整環，而 $3x+6$ 在 $\mathbb{Z}$ 上可約。哪裡壞掉？$m = c_1c_3$ 不能推出 $c_3$ 是單位。
- 「養成好習慣：問自己能不能弱化假設、證明還成不成立，不成立的話壞在哪。」[▶ 51:00](https://youtu.be/TjcdPWa-0DY?t=3060)

### 5. 2、3 次多項式的判別法 [▶ 52:30](https://youtu.be/TjcdPWa-0DY?t=3150)

「這個定理很重要，能解很多作業題——但**只到 3 次**。」

> **定理**（421 講義 Thm 4.6.6）：$F$ 是體，$f\in F[x]$，$\deg f = 2$ 或 $3$。則 $f$ 在 $F$ 上可約 $\iff f$ 在 $F$ 中有根（某個 $c\in F$ 使 $f(c) = 0$）。

- 應用：$x^2+1$ 在 $\mathbb{R}$ 上沒有根（根是 $\pm i$），所以不可約 [▶ 54:30](https://youtu.be/TjcdPWa-0DY?t=3270)。在更大的世界裡證明「沒有實根」最容易；而體上多項式的根是確定的——不會「有 $\pm i$ 兩個根，另外還藏著別的實根」。

**證明** [▶ 55:30](https://youtu.be/TjcdPWa-0DY?t=3330)
- ⇒：可約就有非單位的分解。次數 2 或 3 拆成兩個正次數的因式，至少一個是**一次**的，即 $(x-c)$ 的倍數（體上一次式可以變成首一）。所以 $f(c) = (c-c)g(c) = 0$。「這次跟剛才的警示故事相反，沒問題。」
- ⇐：$f(c) = 0$，由**因式定理**（上次用除法算法證的）$f = (x-c)g$，$\deg g = \deg f-1\ge1$，兩個因式都不是單位，所以可約 [▶ 57:00](https://youtu.be/TjcdPWa-0DY?t=3420)。
- 4 次以上不行：可能拆成兩個二次式而沒有根。
