## 1. 除法算法（首項係數是單位）

> **定理（除法算法）**（講義 p.1，Nicholson p.201）[▶ 01:30](https://youtu.be/TjcdPWa-0DY?t=90)　$R$ 是**任意**有 1 的環，$f(x),g(x)\in R[x]$，$f\neq0$ 且 **$f$ 的首項係數是 $R$ 的單位**。則存在**唯一**的 $q(x),r(x)\in R[x]$：
> 1. $g(x) = q(x)f(x)+r(x)$；
> 2. $r(x) = 0$ 或 $\deg r<\deg f$。

【口頭】[▶ 04:00](https://youtu.be/TjcdPWa-0DY?t=240)「我本來想用**良序原理**證——那很蠢，不是這樣證的。我搞混的是『體上多項式是 PID』的證明：那裡取理想裡次數最小的。這裡是**不同的動物**。有些人會很高興——」學生：「**歸納法**，冷靜。」「安靜，**歸納男孩**。」

### 1.1 存在：對 m 歸納

[▶ 05:30](https://youtu.be/TjcdPWa-0DY?t=330)
- **若 $g = 0$ 或 $\deg g<\deg f$**：$g = 0\cdot f+g$。【課堂討論】「$q$、$r$ 是什麼？」學生：「$q = 0$、$r = g$。」「我准了。」
  - （中間學生起身拿水壺。老師講了一段當研究生時和俄國、義大利留學生一起改幾百份物理考卷的往事：他們邊改邊喝啤酒，「改到後來**每個人都扣 20 分**」。）
- **否則**[▶ 08:00](https://youtu.be/TjcdPWa-0DY?t=480)：$m = \deg g\ge n = \deg f$（「n as in **nanu nanu**，m as in **mummy**」——「你們很容易被逗樂」），**對 $m$ 歸納**。寫
$$f = ux^n+ax^{n-1}+\cdots\ (u\in R^\times),\qquad g = bx^m+cx^{m-1}+\cdots.$$
- 令[▶ 10:00](https://youtu.be/TjcdPWa-0DY?t=600)
$$g_1 = g-bu^{-1}x^{m-n}f = (bx^m+cx^{m-1}+\cdots)-bu^{-1}x^{m-n}(ux^n+ax^{n-1}+\cdots) = 0\cdot x^m+(c-bu^{-1}a)x^{m-1}+\cdots.$$
  - 【課堂討論】[▶ 11:00](https://youtu.be/TjcdPWa-0DY?t=660)「這一步在做什麼？」學生：「消掉 $g$ 的**最高次項**。」「注意我們**沒有除以 $b$**，只乘了 $f$ 首項係數的**反元素**。」
- ⇒ $g_1 = 0$ 或 $\deg g_1<m$（**可能更小**——$c-bu^{-1}a$ 也可能是 0）。
- **歸納假設**[▶ 14:30](https://youtu.be/TjcdPWa-0DY?t=870)：$g_1 = q_1f+r$，$r = 0$ 或 $\deg r<\deg f$。則
$$g = g_1+bu^{-1}x^{m-n}f = \left[q_1+bu^{-1}x^{m-n}\right]f+r.$$
  （「我的講義有的 $r$ 帶下標 1、有的沒有……我要**擦掉那些 1**。我知道，很抱歉。」）

### 1.2 唯一

[▶ 18:30](https://youtu.be/TjcdPWa-0DY?t=1110)（相機一直沒移，「我在中間那塊白板講了五分鐘」——「如果我開了 **Patreon**，就會更努力移相機。」）

設 $g = qf+r = q_2f+r_2$ ⇒
$$r-r_2 = (q_2-q)f.$$
- 【課堂討論】[▶ 21:00](https://youtu.be/TjcdPWa-0DY?t=1260)「若 $q_2-q\neq0$，為什麼 $(q_2-q)f\neq0$？用了什麼假設？」老師自答：「想想 $\mathbb{Z}_6$——$f$ 首項係數是 2、$q_2-q$ 首項係數是 3，乘起來是 0。重點是 **$f$ 的首項係數是單位**，所以乘積的首項非零。」
- ⇒ $\deg(r-r_2) = \deg(q_2-q)+\deg f\ge\deg f$——但 $\deg r,\deg r_2<\deg f$，**矛盾**。
- 所以 $q_2 = q$ ⇒ $r = r_2$。$\blacksquare$
- （中間學生糾正「thus, thus」，老師稱他們是「**文法警察**」，接著一串玩笑：「我在努力讓這支影片**被取消營利**。」）

【口頭】[▶ 25:00](https://youtu.be/TjcdPWa-0DY?t=1500)
- 「我不覺得這證明特別刺激。但它**真的展示了演算法**：盡量從被除式減掉除式的**最大倍數**——這就是**長除法**的基礎。」
- 「證明取自 **Nicholson 的抽象代數**，很棒的書。」（**講台**：「我不想再讓任何課**指定要買書**——那樣學校收課程費，你們被迫用**電子書**，老實說比較差。你們應該有**實體書**。我們怎麼能一邊辦『**數位健康月**』，一邊說你們所有課本都只能讀電子版？」）
- [▶ 27:00](https://youtu.be/TjcdPWa-0DY?t=1620)「他聰明地用**更一般**的形式陳述——我上次說要對體上多項式證。看：整個證明哪裡用到環的**交換性**？**沒有**。所以除法算法對**非交換環**也成立。」

## 2. 警世故事：非交換環的代值

[▶ 28:00](https://youtu.be/TjcdPWa-0DY?t=1680)（Nicholson 的例子）「**代入**在非交換環裡很**棘手**。」學生：「不漂亮。」「不，是**棘手**。」

$R$ 可能不交換，$a,b\in R$，$f(x) = (x-a)(x+b)$。
- **看起來**：$f(a) = (a-a)(a+b) = 0$。「這本來可以是個**很惡毒的作業題**，可惜太晚了。」
- 但代值是對**展開後**的多項式定義的：
$$f(x) = x^2+(b-a)x-ab\ ⇒\ f(a) = a^2+(b-a)a-ab = ba-ab,$$
  **不一定是 0**。
- 「我上次只宣稱代值在**交換**有 1 的環上是環同態——原因就在這。非交換時，**代值和分解不能好好配合**；要處理左乘和右乘的差別。那套理論是什麼？**我其實不知道**。但會很有趣。我只是覺得這例子很酷，想跟你們分享。」

## 3. 不可約／可約多項式

[▶ 32:30](https://youtu.be/TjcdPWa-0DY?t=1950)「進入我的 Lecture 26：不可約 vs. 可約多項式。這應該從**國中**——好，高中——就有點熟悉。讓我活在幻想裡。」

【口頭】[▶ 33:30](https://youtu.be/TjcdPWa-0DY?t=2010)（老師回顧 體 ⊂ 歐氏 ⊂ PID ⊂ UFD ⊂ 整環，講到一半自己繞暈：「所以每個整環都是 UFD，但……等等。該死。我要閉嘴。我得剪掉最後一分鐘。**我會把這題放進考試**，讓你們自己想。」）

💬 正確方向：每個 UFD 都是整環，但**不是**每個整環都是 UFD（例：$\mathbb{Z}[\sqrt{-5}]$，見 [[13-L11-代數數論故事與UFD]]）。

> **定義**（講義 p.3，2018 講義 Def 4.6.1）[▶ 35:00](https://youtu.be/TjcdPWa-0DY?t=2100)　$D$ 是整環。$f(x)\in D[x]$ 非零、非單位，若 $f = gh$（$g,h\in D[x]$）⇒ $g$ 或 $h$ 是**單位**，則 $f$ **在 $D$ 上不可約**。$D[x]$ 中非零、非單位、不是不可約的元素叫**在 $D$ 上可約**。
>
> 「換句話說，多項式如果**不是不可約**，就是可約。」（講義原文：「if a polynomial is not not reducible then it's reducible」）

- 「這其實是之前**不可約元**定義的重複，只是放在整環上的多項式這個脈絡。」
- （「你們想從我這裡得到什麼？我只是逗你們樂的**小丑**嗎？」學生：「我比較喜歡說**弄臣**。」「好吧。在所有小丑工作裡，這份大概**薪水最高**。在人生其他場合，你走進房間講一小時數學，最後會**只剩你一個人**。」）

**例：context 很重要**[▶ 38:30](https://youtu.be/TjcdPWa-0DY?t=2310)
- $x^2+1 = (x+i)(x-i)$：在 $\mathbb{C}$ 上**可約**；在 $\mathbb{R}$ 上**不可約**。「不能只說可約或不可約，要說**在哪裡**。」
- [▶ 40:00](https://youtu.be/TjcdPWa-0DY?t=2400)【課堂討論】「$3x+6$ 可約還是不可約？」學生：「**在哪裡上**？」「對，你們看穿我了。」$3x+6 = 3(x+2)$：
  - 在 $\mathbb{Z}$ 上**可約**：3 和 $x+2$ 都不是 $\mathbb{Z}$ 的單位。
  - 在 $\mathbb{Q}$ 上**不可約**：3 是 $\mathbb{Q}$ 的單位，這只是個**蠢分解**。（「蠢」——學生：「跟蠢蛋在一起。」「這樣說同學不太好。」）

【講義補充】講義 p.3 的其他例子：
- $2x+4 = 2(x+2)$：$\mathbb{Z}$ 上可約，$\mathbb{Q}$、$\mathbb{R}$ 上不可約。
- $x^2-7 = (x-\sqrt7)(x+\sqrt7)$：$\mathbb{R}$ 上可約，$\mathbb{Q}$、$\mathbb{Z}$ 上不可約。
- $x^2+1$ 在 $\mathbb{Z}_3$：$f(0) = 1$、$f(1) = 2$、$f(2) = 5 = 2$，沒有根 ⇒ 不可約。在 $\mathbb{Z}_5$：$f(2) = 5 = 0$ ⇒ $x^2+1 = x^2-4 = (x-2)(x+2)$，可約。

## 4. 一次式在體上不可約

[▶ 44:00](https://youtu.be/TjcdPWa-0DY?t=2640)（老師把板擦弄掉：「我**殺了她**。喔不。我釋懷了。」學生：「下課了嗎？」「才 45 分鐘。」）

> **引理**[▶ 45:00](https://youtu.be/TjcdPWa-0DY?t=2700)　$F$ 體，$m\neq0$ ⇒ $mx+b\in F[x]$ 不可約。

**證明**：$mx+b = f(x)g(x)$。
- $f$ 或 $g$ 是 0 會和 $m\neq0$ 矛盾 ⇒ 兩者非零，$m$ 是兩者首項係數的積 ⇒ $\deg f+\deg g = 1$。
- 不失一般性 $\deg f = 1$、$\deg g = 0$：$f = c_1x+c_2$、$g = c_3$，$c_1,c_3\neq0$。
- $F[x]$ 的單位就是 $F$ 的非零元素（之前證過：整環上多項式環的單位 = 係數環的單位）⇒ $g = c_3$ 是單位 ⇒ 不可約。$\blacksquare$

【課堂討論】[▶ 49:00](https://youtu.be/TjcdPWa-0DY?t=2940)「真的需要**體**嗎？」學生：「我覺得可以放寬到**整環**。」「我們想想……次數公式在整環上也成立……」另一位學生：「$\mathbb{Z}$ 是整環，所以**不可能成立**——」「對，謝謝。$3x+6$。」
- **壞在哪**：$m = c_1c_3$ **不會**逼 $c_3$ 是單位——例如 $6 = 3\cdot2$，2 不是 $\mathbb{Z}$ 的單位。
- 【口頭】[▶ 51:00](https://youtu.be/TjcdPWa-0DY?t=3060)「**好習慣**：想想我們證的定理，問自己能不能**弱化假設**還成立；不行的話，**壞在哪裡**。」

## 5. 2、3 次多項式：可約 ⟺ 有根

[▶ 52:30](https://youtu.be/TjcdPWa-0DY?t=3150)「下一個定理**很重要**，能幫你們解很多作業題。但要小心：**只對 3 次以下有效**。」

> **定理**（講義 p.3，2018 講義 Thm 4.6.6）[▶ 53:30](https://youtu.be/TjcdPWa-0DY?t=3210)　$F$ 體，$f(x)\in F[x]$，$\deg f = 2$ 或 $3$。則 $f$ 在 $F$ 上可約 $\iff$ $f$ 在 $F$ 中有根（即有 $c\in F$ 使 $\mathrm{eval}_c(f) = f(c) = 0$）。

**應用**[▶ 54:30](https://youtu.be/TjcdPWa-0DY?t=3270)：$x^2+1$ 在 $\mathbb{R}$ 上不可約——它沒有實根（根是 $\pm i$）。
- 【口頭】「在**更大的脈絡**裡證明沒有實根比較容易——有複數可用的話很簡單。因為體上二次式的根若存在就是**確定的**：不會『有兩個複根 $\pm i$，另外還有我們不知道的實根』。」

**證明**[▶ 55:30](https://youtu.be/TjcdPWa-0DY?t=3330)
- (⇒) $f$ 可約 ⇒ 分解成兩個非單位（次數 $\ge1$）的因子，次數加起來是 2 或 3 ⇒ **至少有一個一次因子** $x-c$（「不能有 3 次因子乘一個非單位常數——在體上，常數都是單位。這裡做不出 $6 = 2\cdot3$ 那種事」）⇒ $f = (x-c)g$ ⇒ $f(c) = (c-c)g(c) = 0$。（「**跟剛才的警世故事相反**，這裡可以代值。」）
- (⇐) $f(c) = 0$ ⇒ 因式定理 $f = (x-c)g$，$\deg g = 1$ 或 $2$——**不是單位** ⇒ $f$ 可約。$\blacksquare$

[▶ 59:00](https://youtu.be/TjcdPWa-0DY?t=3540)「下次用這些做一堆例子。」

## 6. 一頁速查表

| 定理 | 關鍵一步 |
|---|---|
| 除法算法（任意有 1 環，$f$ 首項係數 $u$ 是單位） | $g_1 = g-bu^{-1}x^{m-n}f$ 消掉首項，對 $m$ 歸納 |
| 唯一性 | $r-r_2 = (q_2-q)f$；首項是單位 ⇒ 乘積次數 $\ge\deg f$ |
| 非交換環代值不保持乘法 | $(x-a)(x+b)$ 在 $a$ 的值是 $ba-ab$ |
| 體上一次式不可約 | 次數公式 + $F[x]^\times = F^\times$；整環上不行（$3x+6$） |
| 2、3 次：可約 ⟺ 有根 | 必有一次因子；因式定理 |

**例**：$x^2+1$：$\mathbb{C}$ 可約、$\mathbb{R}$ 不可約、$\mathbb{Z}_3$ 不可約、$\mathbb{Z}_5$ 可約。$3x+6$：$\mathbb{Z}$ 可約、$\mathbb{Q}$ 不可約。

| 中文 | English |
|---|---|
| 除法算法 | division algorithm |
| 長除法 | long division |
| 在 $D$ 上不可約／可約 | irreducible / reducible over $D$ |
| 根、零點 | zero, root |
| 代入、代值 | substitution, evaluation |

## 附：本集一句話總結

> **多項式除法算法其實只需要除式的首項係數是單位（任意有 1 的環，甚至不必交換）：用 $bu^{-1}x^{m-n}f$ 消掉最高次項再對次數歸納，唯一性靠首項係數是單位；但在非交換環裡代值和分解不配合（$(x-a)(x+b)$ 在 $a$ 的值是 $ba-ab$）；接著定義多項式在 $D$ 上可約／不可約——要說「在哪裡上」（$x^2+1$、$3x+6$）——證明體上一次式不可約（整環上不行），以及 2、3 次多項式在體上可約 ⟺ 有根。**
