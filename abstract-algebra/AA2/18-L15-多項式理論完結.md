## 筆記

### 1. 重數與形式導數 [▶ 00:30](https://youtu.be/TymydecXNBs?t=30)

> **定義**：$R$ 是整環。$a$ 是 $f\in R[x]$ 的 $k$ **重根**，若 $f(x) = (x-a)^kg(x)$ 且 $g(a)\ne0$。

- 學生問要不要「$k$ 最大」——用 $g(a)\ne0$ 的版本自動最大；用「$(x-a)^k\mid f$」的版本才需要加「最大」[▶ 02:00](https://youtu.be/TymydecXNBs?t=120)。

> **定義**：$f = a_nx^n+\cdots+a_1x+a_0$ 的**形式導數** $f' = na_nx^{n-1}+\cdots+2a_2x+a_1$；$f^{(0)} = f$，$f^{(n+1)} = \frac{d}{dx}f^{(n)}$ [▶ 04:00](https://youtu.be/TymydecXNBs?t=240)。

- 純代數，沒有極限；容易驗證線性和乘積法則 [▶ 06:30](https://youtu.be/TymydecXNBs?t=390)。
- 老師想寫「$a$ 是 $k$ 重根 ⇔ $f^{(j)}(a) = 0$，$j = 0,\dots,k-1$」，試 $(x-a)^2g$ 和 $x^k$（$k$ 階導數是 $k!$）後不確定，「這個定理我留了位置但還沒證，可能只好放進考試了」[▶ 11:00](https://youtu.be/TymydecXNBs?t=660)。

> 💬 補充（非課堂內容）：一般只有「$k\ge2$ 重根 ⇒ $f(a) = f'(a) = 0$」；完整的「$f^{(j)}(a) = 0$（$j<k$）且 $f^{(k)}(a)\ne0$ ⇔ 恰 $k$ 重」需要特徵 0（或特徵 $>k$），因為 $f^{(k)}(a) = k!\,g(a)$。

### 2. Prop. 16：用中國剩餘定理拆 $F[x]/(g)$ [▶ 15:00](https://youtu.be/TymydecXNBs?t=900)

$g$ 非常數、首一，$F[x]$ 是 UFD：$g = f_1^{n_1}\cdots f_k^{n_k}$（$f_i$ 互異不可約）。不同不可約式互質 ⇒ 理想互極大 ⇒
$$F[x]/(g)\cong F[x]/(f_1^{n_1})\times\cdots\times F[x]/(f_k^{n_k}).$$

**例 1** [▶ 19:00](https://youtu.be/TymydecXNBs?t=1140)：$x^4-1 = (x^2+1)(x-1)(x+1)$（一次式在體上不可約；$x^2+1$ 無實根）。
$$\mathbb{R}[x]/(x^4-1)\cong\mathbb{C}\times\mathbb{R}\times\mathbb{R}.$$
（模 $x-1$ 相當於令 $x = 1$，只剩常數，就是 $\mathbb{R}$。）

**例 2** [▶ 21:30](https://youtu.be/TymydecXNBs?t=1290)：$x^3-1 = (x-1)\big((x+\frac12)^2+\frac34\big)$（「沒想到今天會配方吧」）。$\mathbb{R}[x]/(x^3-1)\cong\mathbb{R}\times\mathbb{C}$。
- 為什麼 $\mathbb{R}[x]/((x+\frac12)^2+\frac34)\cong\mathbb{C}$？令 $\alpha = x+I$，$\alpha^2 = -\alpha-1$，元素都化成 $a\alpha+b$。由 $(\alpha+\frac12)^2 = -\frac34$，$\frac2{\sqrt3}(\alpha+\frac12)$ 平方是 $-1$，它扮演 $i$。同構送 1 到 1、這個元素到 $i$ [▶ 31:00](https://youtu.be/TymydecXNBs?t=1860)。對任意不可約二次式證明可能更容易（老師和學生 Shane 的論文已更一般地證過）。

### 3. Bill Cook 講義的定理 [▶ 33:00](https://youtu.be/TymydecXNBs?t=1980)

> **三分性**（trichotomy）：$R$ 是 PID，$I$ 是非零理想。$R/I$ 的每個元素是 0、單位或零因子。

- 證明：$I = (r)$，$r$ 非單位。對 $x+I\ne0$，令 $(x,r) = (d)$，$d = ax+br$。$d$ 是單位 ⇒ $x+I$ 是單位；否則可證是零因子 [▶ 35:00](https://youtu.be/TymydecXNBs?t=2100)。

> **有理根定理**：$R$ 是整環，$F$ 是分式體，$f = a_nx^n+\cdots+a_0\in R[x]$。若 $p/q\in F$（最簡）是根，則 $p\mid a_0$、$q\mid a_n$ [▶ 36:30](https://youtu.be/TymydecXNBs?t=2190)。

- 證明：代入乘 $q^n$：$a_np^n+a_{n-1}p^{n-1}q+\cdots+a_0q^n = 0$。除首項外每項含 $q$，所以 $q\mid a_np^n$；$p,q$ 互質 ⇒ $q\mid a_n$。另一邊同理把 $p$ 提出 [▶ 39:00](https://youtu.be/TymydecXNBs?t=2340)。（老師口說「$p,q$ 是相異質數」，應是「互質」。）

**推論** [▶ 40:30](https://youtu.be/TymydecXNBs?t=2430)：$p$ 質數，$\sqrt p$ 無理：$x^2-p$ 的可能有理根只有 $\pm1,\pm p$，都不是。$\sqrt[3]p$ 同理。$\sqrt[n]p$（$n>1$）用 Eisenstein（$x^n-p$）。Math 200 要費點力證 $\sqrt2$ 無理，這裡很簡單。
- （學生爭論 criteria 是單數還是複數；「我選擇不參與。」）

**約化判別法的一般版** [▶ 45:00](https://youtu.be/TymydecXNBs?t=2700)：$R$ 是 UFD，$I$ 是理想，$f\in R[x]$ 係數 gcd 為 1，若 $f$ 在 $(R/I)[x]$ 中的約化不可約（且次數不變），則 $f$ 不可約。

> **定理**：$R$ 是**無窮**整環。$f(r) = g(r)$ 對所有 $r\in R$ ⇔ $f = g$ 作為多項式 [▶ 46:30](https://youtu.be/TymydecXNBs?t=2790)。

- $h = f-g$ 若非零，至多 $\deg h$ 個根，但它有無窮多個根，矛盾。
- 所以「多項式 ≠ 多項式函數」是有限環（如 $\mathbb{Z}_3$）的現象；在微積分裡混用完全沒問題 [▶ 49:30](https://youtu.be/TymydecXNBs?t=2970)。

### 4. 體的乘法群的有限子群是循環群 [▶ 50:30](https://youtu.be/TymydecXNBs?t=3030)

（D&F §9.5；老師說不會考。）
- 證明：有限交換群分解成 $\mathbb{Z}_{n_1}\times\cdots\times\mathbb{Z}_{n_k}$，$n_i\mid n_{i+1}$。若因子超過一個，$x^{n_k}-1$ 的根會超過 $n_k$ 個，矛盾。
- 所以 $\mathbb{Z}_p^\times$ 是循環群；$\varphi(p^\alpha) = p^{\alpha-1}(p-1)$ 等公式也可由此看出。
