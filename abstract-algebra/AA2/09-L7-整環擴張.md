## 1. 收尾：R/A 是體 ⇒ A 極大

[▶ 00:00](https://youtu.be/Z3JZbXUJQhw?t=0)「我說過要回到這個證明，因為它挺重要。」【課堂討論】「我上次證了哪個方向？」學生：「你兩個方向都證了。」「好吧——但我**證得很爛**，對吧？」

> **定理**　$R$ 有 1 的交換環，$A$ 是理想。$R/A$ 是體 $\iff$ $A$ 是極大理想。

【口頭】[▶ 01:00](https://youtu.be/Z3JZbXUJQhw?t=60)「Dummit & Foote 的證明大概**兩句話**，大概是合法的——它用**格同構定理**。但我覺得我們做比較**不高科技**的證明比較好，就是我以前在 421 期待的那種。」

**證明（⇐）**[▶ 02:00](https://youtu.be/Z3JZbXUJQhw?t=120)：設 $R/A$ 是體。取理想 $B$，$A\subseteq B$、$A\neq B$。
- 【課堂討論】「$A\neq B$ 給我們什麼？」學生：「$B$ 裡有不在 $A$ 的東西。」⇒ 存在 $x\in B$、$x\notin A$。
- 「我們的目標？」**極大**：包含 $A$ 的理想只能是 $A$ 或整個環。「若假設它不等於 $A$，證明它等於 $R$ 就完成了——邏輯上。」[▶ 04:00](https://youtu.be/Z3JZbXUJQhw?t=240)
- $x\notin A$ ⇒ $x+A\neq A$ ⇒ $x+A$ 在 $R/A$ 中**非零** ⇒ $R/A$ 是體 ⇒ $x+A$ 是**單位**。
- 存在 $y+A$ 使 $(y+A)(x+A) = $ ……【課堂討論】學生：「$A$？」「那會是 **0**——那就糟了。」「想想你的**另一個**單位元。」——$1+A$。「別把加法和乘法單位元搞混。」[▶ 05:30](https://youtu.be/Z3JZbXUJQhw?t=330)
- $yx+A = 1+A$ ⇒ $1-yx\in A$。
- $x\in B$、$B$ 是理想 ⇒ $yx\in B$ [▶ 06:30](https://youtu.be/Z3JZbXUJQhw?t=390)。
- $A\subseteq B$ ⇒ $1-xy\in B$。（「紅色劃線的這個不是從旁邊推出來的——只是因為已知 $1-xy\in A$、$A\subseteq B$。」）【Q&A】學生問為什麼 $yx$ 變 $xy$——「交換環。沒什麼好理由，就是發生了。」
- $xy$ 和 $1-xy$ 都在 $B$，$B$ 是子環 ⇒ $1 = xy+(1-xy)\in B$ [▶ 08:00](https://youtu.be/Z3JZbXUJQhw?t=480)。
- 【課堂討論】「$1\in B$、$B$ 是理想，$B$ 等於什麼？」——$B = R$。$\blacksquare$

【口頭】[▶ 09:00](https://youtu.be/Z3JZbXUJQhw?t=540)「另一方向上次講了，不重複。考試前你們最好把兩個方向都走一遍。如果要考，我**通常不問**『若且唯若』——一個方向就**夠受了**。相對地，『$R/A$ 是整環 $\iff A$ 是質理想』兩個方向都可以考，不太難。」
- 【課堂討論】[▶ 10:00](https://youtu.be/Z3JZbXUJQhw?t=600)「其實證了這個，另一個……」學生：「體是整環。」「對：**體自動是整環**，但不是每個整環都是體——那需要**領域展開**（插入迷因）。」所以**極大理想一定是質理想**，反之不然。

## 2. 特徵

[▶ 11:00](https://youtu.be/Z3JZbXUJQhw?t=660)「Lecture 7：**領域展開！**」【Q&A】學生：「那是階乘嗎？」「那是**強調**——領域展開，哇，很刺激。」學生：「領域展開乘領域展開減一……」「我沒說那個。這跟階乘無關。**停止並終止**。你在階乘化。停。」

「在講這集**動作片**的刺激結局（領域展開）之前，先講一些比較簡單的東西——我不是指技術意義的『單（simple）』，是比喻意義。」

> **定義（特徵 characteristic）**（講義 Def 4.1.37）[▶ 12:00](https://youtu.be/Z3JZbXUJQhw?t=720)　使 $n\cdot x = 0$ 對**所有** $x\in R$ 成立的**最小正整數** $n$，記 $\operatorname{char}(R) = n$。若不存在，$\operatorname{char}(R) = 0$。

（學生指出板書有字是白色的看不到：「你們太開心我犯錯了。我覺得如果我哪天**只**犯錯，那會是你們最愛的一天。」「絕對是 Violet。」）

**$n\cdot x$ 的意思**[▶ 13:30](https://youtu.be/Z3JZbXUJQhw?t=810)：$x$ 加自己 $n$ 次。$1\cdot x = x$、$2\cdot x = x+x$；遞迴 $(n+1)\cdot x = n\cdot x+x$。負的：$(-1)\cdot x = -x$、$(-2)\cdot x = (-x)+(-x)$……「所以對任何整數都能嚴格定義 $n\cdot x$。」

> **定理**（講義 Thm 4.1.38）[▶ 15:00](https://youtu.be/Z3JZbXUJQhw?t=900)　$R$ 有 1。若 1 的加法階無限，$\operatorname{char}R = 0$；若 1 的加法階是 $n$，$\operatorname{char}R = n$。

「基本上**1 怎樣，其他一切就怎樣**。」

**證明**[▶ 16:00](https://youtu.be/Z3JZbXUJQhw?t=960)
- **關鍵計算**：
$$n\cdot x = \underbrace{x+\cdots+x}_n = 1x+\cdots+1x = (1+\cdots+1)x = (n\cdot1)x.$$
  （「我做了**恰好相反**的事——我是想……」「天啊，為什麼我在做的時候去看太陽，現在眼前有個點。」）
- **無限階**[▶ 20:30](https://youtu.be/Z3JZbXUJQhw?t=1230)：若某 $n$ 使 $n\cdot x = 0$ 對所有 $x$，取 $x = 1$ 得 $n\cdot1 = 0$，矛盾 ⇒ 特徵 0。「如果對 1 不行，那就死了——因為要對**所有** $x$。」
- **有限階 $n$**[▶ 21:30](https://youtu.be/Z3JZbXUJQhw?t=1290)：$n\cdot x = (n\cdot1)x = 0\cdot x = 0$ 對所有 $x$；而且 $n$ 最小（對 $x = 1$）⇒ $\operatorname{char}R = n$。$\blacksquare$

【口頭】[▶ 22:00](https://youtu.be/Z3JZbXUJQhw?t=1320)「如果我今天能**證明自己走出一個濕紙袋**，那也不難。這是很簡單的定理。」（中間：「我要改週一的行程，我不再在中午跟 Jacob 談了，因為行不通。」）

**例**【課堂討論】[▶ 22:30](https://youtu.be/Z3JZbXUJQhw?t=1350)
- **特徵 0**：$\mathbb{R},\mathbb{Q},\mathbb{C},\mathbb{Z}$；這些的**矩陣**（非交換也行）。（學生：「$R$ 不是環？」「$R$ 是我的泛用環字母。」「喔，我是說……」「我來寫**雙槓** $\mathbb{R}$。」）
- **特徵 $n$**：$\mathbb{Z}_n$；$\mathbb{Z}_n$ 上的矩陣；$\mathbb{Z}_n$ 係數的多項式（一個或多個變數）——「任何東西加自己 $n$ 次，係數就變 $n$ 份，在 $\mathbb{Z}_n$ 裡自動是 0。」「我們接下來要花一整週講**多項式**。」

## 3. 整環的特徵是 0 或質數

> **定理**（講義 Thm 4.1.39）[▶ 26:00](https://youtu.be/Z3JZbXUJQhw?t=1560)　**整環的特徵是 0 或質數。**

**證明**
- 1 的階無限 ⇒ 特徵 0，完成。
- 否則 $n\cdot1 = 0$，$n$ 是 1 的加法階。設 $n = st$，$1\le s,t\le n$ [▶ 27:30](https://youtu.be/Z3JZbXUJQhw?t=1650)。
- 【課堂討論】
$$0 = n\cdot1 = (st)\cdot1 = (s\cdot1)(t\cdot1).$$
- 整環 ⇒ $s\cdot1 = 0$ 或 $t\cdot1 = 0$ ⇒ 由加法階的定義 $s = n$ 或 $t = n$ [▶ 29:00](https://youtu.be/Z3JZbXUJQhw?t=1740)。
- $n$ 的分解只有 $1\cdot n$ ⇒ **$n$ 是質數**。$\blacksquare$

【課堂討論】[▶ 29:30](https://youtu.be/Z3JZbXUJQhw?t=1770)「**體**的特徵有哪兩種選擇？」——0 或質數 $p$。「我說兩種——是兩**類**。第二類有幾種？很多。」

## 4. ℤ 或 ℤₙ 坐在每個有 1 的環裡

[▶ 30:00](https://youtu.be/Z3JZbXUJQhw?t=1800)「接下來幾個我**跳過證明**，留時間給領域展開——那更重要。如果我太罪惡，改天回來補。但我要你們有這些**顯然的**定理，它們是今天故事的一部分。」

「今天的故事是：**怎麼把整數塞進環裡**。有 1 就好像有 2、3、4……——可以一直加 1 或減 1，在環裡**造出一份整數**。但如果特徵不是 0，那**不真是整數**——是 **$\mathbb{Z}_n$**。我說『**同構意義下**』——在矩陣環裡，是某些矩陣在一切意義上表現得像整數或模 $n$ 整數。」

> **定理**（講義 Thm 4.4.10）[▶ 32:30](https://youtu.be/Z3JZbXUJQhw?t=1950)　$R$ 有 1 ⇒ $\varphi:\mathbb{Z}\to R$，$\varphi(n) = n\cdot1$ 是**環同態**。

證明（Gallian p.274–275）歸結到 $(m+n)\cdot1 = m\cdot1+n\cdot1$、$(m\cdot1)(n\cdot1) = (mn)\cdot1$。
- 【口頭】[▶ 34:00](https://youtu.be/Z3JZbXUJQhw?t=2040)「$n\cdot1$ 是『**小心**』的記號，有時我們就寫 $n$——例如 $2\cdot1$ 就寫 2。我們沒那麼**愛打官司**。」

> **推論**（講義 Cor 4.4.11）[▶ 33:30](https://youtu.be/Z3JZbXUJQhw?t=2010)　$R$ 有 1。$\operatorname{char}R = n>0$ ⇒ $R$ 含同構於 $\mathbb{Z}_n$ 的子環；$\operatorname{char}R = 0$ ⇒ 含同構於 $\mathbb{Z}$ 的子環。

**證明**[▶ 35:00](https://youtu.be/Z3JZbXUJQhw?t=2100)：$S = \{k\cdot1 : k\in\mathbb{Z}\}$ 是 $\varphi$ 的像。
- $\ker\varphi = \{k : k\cdot1 = 0\}$——$\mathbb{Z}$ 的理想。
- 第一同構定理：$\mathbb{Z}/\ker\varphi\cong S\subseteq R$。（「看，你讓我也這樣了，Shane——你讓我**雙槓**我的 $R$。」）
- 核 $= 0$（特徵 0）⇒ $S\cong\mathbb{Z}$；特徵 $n$ ⇒ $\ker\varphi = n\mathbb{Z}$ ⇒ $S\cong\mathbb{Z}/n\mathbb{Z} = \mathbb{Z}_n$。$\blacksquare$
- 【口頭】[▶ 38:00](https://youtu.be/Z3JZbXUJQhw?t=2280)「題外話：kernel 要大寫還是小寫？答案是**是**。characteristic 呢？也是**是**。抱歉，就是這樣。」「我今天**組不出句子**。」

【講義補充】
- **Cor 4.4.12**：$\mathbb{Z}\to\mathbb{Z}_m$，$x\mapsto[x]_m$ 是環同態（$[x]_m = x\cdot[1]_m$）。這也是 $\mathbb{Z}_n\to\mathbb{Z}_k$ 的同態形如 $[x]_n\mapsto[mx]_k$（$k\mid mn$）的核心。
- **Cor 4.4.13（Steinitz 1910）**：特徵 $p$ 的體含 $\mathbb{Z}_p$；特徵 0 的體含 $\mathbb{Q}$（$S_{\mathbb{Q}} = \{ab^{-1} : a,b\in S,b\neq0\}$）。
- **Def 4.4.14（質子體 prime subfield）**：含於所有子體中的那個子體——$\mathbb{Q}$ 或 $\mathbb{Z}_p$。

## 5. 領域展開：分式體

[▶ 40:30](https://youtu.be/Z3JZbXUJQhw?t=2430)「我們**終於**到了領域展開的部分。」

整環 $D$：有 1 的交換環，$ab = 0$ ⇒ $a = 0$ 或 $b = 0$。
- 「但我們**想要更多**。我們**不滿足**於領域的範圍，我們想要**展開**我們的領域。我們想要**反元素**。」
- 例：整數裡 2 沒有反元素；整係數多項式也一樣。「怎麼造這些東西的分數？答案是**領域展開**。」

（插曲 [▶ 42:30](https://youtu.be/Z3JZbXUJQhw?t=2550)：「我要用 $D$ 代表 domain，跟講義一致——我今天沒什麼精神。」學生：「Jacob 的錯。」「**是 Jacob 的錯**。我在找這門課的筆記——綠色資料夾。記得我衝進休息室說『**綠色那個呢**』嗎？」學生：「在你辦公室的書上面。」「對，你說得對。……我走回走廊，去我早上教你的地方找，Shane——不在。回辦公室、打開書包，blah blah。大概十分鐘後 Jacob 出現。」）

**構造**（講義 Thm 4.4.15，Gallian p.277–278）[▶ 43:30](https://youtu.be/Z3JZbXUJQhw?t=2610)
$$S = \{(a,b) : a,b\in D,\ b\neq0\},\qquad(a,b)\sim(c,d)\iff ad = bc.$$

**$\sim$ 是等價關係**
- **反身**：$ab = ba$（$D$ 交換）。
- **遞移**（「我為什麼先證遞移？我怎麼了」）[▶ 45:00](https://youtu.be/Z3JZbXUJQhw?t=2700)：設 $(a,b)\sim(c,d)$、$(c,d)\sim(e,f)$（學生：「EF？」「沒什麼想像力，但我收了。」另一學生：「epsilon？」「我就用你的 E、F。」）即 $ad = bc$、$cf = de$。
$$adf = bcf = bde\ ⇒\ d(af) = d(be).$$
  「**我們的願望清單**：$af = be$。」整環 $d\neq0$ ⇒ **消去律** ⇒ $af = be$ ⇒ $(a,b)\sim(e,f)$。
  - 【口頭】[▶ 47:00](https://youtu.be/Z3JZbXUJQhw?t=2820)「上學期你們就證過整環的消去律——**你們好棒**。我知道你們證過，因為那很好玩。**抽象代數教授對消去律，就像飛蛾撲火**——你就是得做。」
- **對稱**[▶ 47:30](https://youtu.be/Z3JZbXUJQhw?t=2850)：$ad = bc$ ⇒ $cb = da$ ⇒ $(c,d)\sim(a,b)$。「對稱有點**蠢**——用等式定義等價關係時，對稱總是很蠢。」

【課堂討論】[▶ 48:30](https://youtu.be/Z3JZbXUJQhw?t=2910)「這代表什麼？」學生：「**分割**。」「它分割 $S$。很好。」
- 等價類 $[a,b] = \{(c,d) : (a,b)\sim(c,d)\} = \{(c,d) : ad = bc\}$。
- （「我**很氣**我今天卡在這些——這些不難，應該很簡單。」學生：「怪 Jacob。」「對——其實不完全，大概主要是我。」學生：「我很確定沒有一件事是你的錯。」「我喜歡這說法。你有考慮去當**心理諮商師**嗎？」）

**運算**[▶ 51:00](https://youtu.be/Z3JZbXUJQhw?t=3060)「我給你們看**簾子後面的人**：$(a,b)$ 就是 **$a/b$ 的模型**。」學生：「我們早知道了。」「為什麼？」「$b\neq0$ 是線索。」「好吧。」
$$[a,b]+[c,d] = [ad+bc,\ bd],\qquad[a,b][c,d] = [ac,\ bd].$$
- 「你們知道怎麼合併分數。」$bd\neq0$，所以還在 $S$ 裡。
- **要證跟代表無關**[▶ 52:30](https://youtu.be/Z3JZbXUJQhw?t=3150)——「這**真的**有東西要證：一個分數有多少種代表？」學生：「無限多。」「太對了。」

【講義補充】良定義（講義 p.5）：$(a,b)\sim(a',b')$、$(c,d)\sim(c',d')$，即 $ab' = ba'$、$cd' = dc'$。
$$(ad+bc)b'd' = (ab')(dd')+(cd')(bb') = (ba')(dd')+(dc')(bb') = bd(a'd'+b'c');$$
$$(ac)(b'd') = (ab')(cd') = (ba')(dc') = (bd)(a'c').$$

**單位元與反元素**[▶ 53:00](https://youtu.be/Z3JZbXUJQhw?t=3180)
- $[a,b][1,1] = [a,b]$ ⇒ **$[1,1]$ 是乘法單位元**。
- 【課堂討論】「$[a,b]$ 的乘法反元素？」學生：「$[b,a]$。」「你知道**作弊碼**。」$[a,b][b,a] = [ab,ba] = [1,1]$（$a\neq0$）。
- 【講義補充】零是 $[0,x]$（$x\neq0$）；$[ax,bx] = [a,b]$；結合律、分配律留給讀者。$x\mapsto[x,1]$ 是**單射**環同態 ⇒ $D\cong\varphi(D)$。

> **定義（分式體 field of fractions / field of quotients）**（講義 Def 4.4.16）　上面構造的體，記 $a/b$ 代表 $[a,b]$：
> $$F = \left\{\frac ab : a,b\in D,\ b\neq0\right\},\quad\frac ab+\frac cd = \frac{ad+bc}{bd},\quad\frac ab\cdot\frac cd = \frac{ac}{bd}.$$

【口頭】[▶ 54:00](https://youtu.be/Z3JZbXUJQhw?t=3240)「**任何整環**都能造分式體。沒有單位？你總能做**領域展開**，得到一個更大的環，裡面有所有你要的分數。」
- 「修補有零因子的環還有別的方法——**我哥**對那個有一套說法，我還沒內化。」

## 6. 1/2 = 3/6？

[▶ 55:00](https://youtu.be/Z3JZbXUJQhw?t=3300)「這都回到這個討論：**$\frac12 = \frac36$ 嗎？**有時你會聽到代數人說『那不是真的等於，它們不一樣』。**我用我身上每一根纖維拒絕這個說法。**」
- 「它們**相等**，因為在實數系裡我們處理的是**分數的等價類**。我們不是把 $\frac12$ 加到 $\frac36$，是在加 $\frac12$ 的等價類——**那是同一個等價類**。」
- 「從整數開始，造分式體，得到有理數——那些就是等價類。你們**從小**就在處理這個等價關係：一碰到分數就躲不掉這個歧義。**無可逃避**。」
- 講義 p.7：「一個有理數有很多不同的**分數**代表它嗎？是。$(1,2)\neq(3,6)$。但**等價類總是與我們同在，無論我們懂不懂**。」（推薦 Paul Garrett 的文章。）

**數系的展開**[▶ 56:00](https://youtu.be/Z3JZbXUJQhw?t=3360)：正整數 → 加上負數 → $\mathbb{Z}$ → 分式體 → $\mathbb{Q}$ → $\mathbb{R}$ → $\mathbb{C}$。「怎麼到 $\mathbb{R}$？怎麼到 $\mathbb{C}$？那是**另一個故事**——我們之後會講一部分。**學會怎麼擴張體**，是這門課接下來主要感興趣的事之一。」

【講義補充】例子（講義 p.7）：
- $D = \mathbb{Z}[x]$ ⇒ 分式體 $\{f(x)/g(x)\}$。
- $D = F[x]$ ⇒ **有理函數體** $F(x)$；$F = \mathbb{R}$ 就是一般的有理函數。
- $\mathbb{Z}_p(x)$：**特徵 $p$ 的無限體**——「在別的場合我可能會同意有限特徵的體是有限體——這例子**顯然**說明那是錯的！」

**結尾**[▶ 57:00](https://youtu.be/Z3JZbXUJQhw?t=3420)：「至少我沒搞砸領域展開——我很小心，沒進太多細節。」學生：「你做得很棒。」「喔謝謝，我很感激。」

## 7. 一頁速查表

| 定理 | 證明關鍵一步 |
|---|---|
| $R/A$ 體 ⇒ $A$ 極大 | $(y+A)(x+A) = 1+A$ ⇒ $1 = xy+(1-xy)\in B$ |
| 極大 ⇒ 質 | 體是整環 |
| $\operatorname{char}R$ = 1 的加法階 | $n\cdot x = (n\cdot1)x$ |
| 整環特徵是 0 或質數 | $0 = (s\cdot1)(t\cdot1)$ |
| $n\mapsto n\cdot1$ 是環同態 | $(mn)\cdot1 = (m\cdot1)(n\cdot1)$ |
| 有 1 ⇒ 含 $\mathbb{Z}$ 或 $\mathbb{Z}_n$ | 第一同構定理：$\mathbb{Z}/\ker\cong S$ |
| Steinitz | 體含 $\mathbb{Q}$ 或 $\mathbb{Z}_p$（質子體） |
| 分式體 | $(a,b)\sim(c,d)\iff ad = bc$；遞移靠消去律 |

**分式體**：$[a,b]+[c,d] = [ad+bc,bd]$、$[a,b][c,d] = [ac,bd]$；$[1,1]$ 是 1；$[a,b]^{-1} = [b,a]$；$x\mapsto[x,1]$ 嵌入 $D$。

**例**：$\mathbb{Z}\to\mathbb{Q}$；$F[x]\to F(x)$；$\mathbb{Z}_p(x)$ 是特徵 $p$ 的無限體。

## 附：本集一句話總結

> **環的特徵就是 1 要加自己幾次才回到 0（整環的特徵只能是 0 或質數），而 $n\mapsto n\cdot1$ 是環同態，所以每個有 1 的環裡都坐著一份 $\mathbb{Z}$ 或 $\mathbb{Z}_n$（體裡坐著 $\mathbb{Q}$ 或 $\mathbb{Z}_p$）；「領域展開」就是分式體：把非零分母的配對用 $ad = bc$ 分類（遞移律靠消去律），定義分數的加乘，就得到包含整環的體——這也是為什麼 $\frac12 = \frac36$：它們是同一個等價類。**
