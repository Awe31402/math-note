# 第 9 集 · L7：領域展開！特徵、分式體 [▶ 影片](https://www.youtube.com/watch?v=Z3JZbXUJQhw&list=PLBY4G2o7DhF1x_afv1rv_d0hFCoMWEb-j)

## 本集概要

- 先補完 L6：$R/A$ 是體 ⇒ $A$ 極大（「上次兩個方向都做了，但做得很爛」）。極大理想都是質理想，反之不然。
- **特徵**（characteristic）：由 $1$ 的加法階決定；**整環的特徵是 0 或質數**。
- 有 1 的環裡藏著一份 $\mathbb{Z}$ 或 $\mathbb{Z}_n$：$k\mapsto k\cdot1$ 是環同態。
- **「領域展開」**（Domain Expansion，咒術迴戰梗）：用 $(a,b)$ 的等價類，從整環造出**分式體**（field of fractions）。

> 📘 講義對應：Math422 Lecture 7「Domain Expansion」；老師 2018 年 421 講義 Lecture 24（Thm 4.4.10）。

## 筆記

### 1. 補完 L6：$R/A$ 是體 ⇒ $A$ 極大 [▶ 00:30](https://youtu.be/Z3JZbXUJQhw?t=30)

D&F 的證明只有兩句（用格同構定理），老師改做 421 要求的「比較不高科技」的版本 [▶ 01:30](https://youtu.be/Z3JZbXUJQhw?t=90)。

$R$ 是有 1 的交換環，$R/A$ 是體。設 $A\subseteq B$、$A\ne B$，目標 $B = R$。
1. 取 $x\in B\setminus A$，則 $x+A\ne A$，即 $x+A$ 在 $R/A$ 中非零 [▶ 04:00](https://youtu.be/Z3JZbXUJQhw?t=240)。
2. $R/A$ 是體，所以有 $y+A$ 使 $(y+A)(x+A) = 1+A$。（「別把加法單位和乘法單位搞混」。）
3. $yx+A = 1+A$ ⇒ $1-yx\in A\subseteq B$ [▶ 06:00](https://youtu.be/Z3JZbXUJQhw?t=360)。
4. $x\in B$、$B$ 是理想 ⇒ $xy\in B$。
5. $xy+(1-xy) = 1\in B$ ⇒ $B = R$ [▶ 08:30](https://youtu.be/Z3JZbXUJQhw?t=510)。

- 考試通常只考一個方向（「那已經夠痛苦了」）。「$R/A$ 是整環 ⇔ $A$ 質」兩個方向都可能考，不太難 [▶ 09:30](https://youtu.be/Z3JZbXUJQhw?t=570)。
- 體都是整環，所以**極大理想都是質理想**；反之不然，因為整環不一定是體——「那需要**領域展開**」[▶ 10:00](https://youtu.be/Z3JZbXUJQhw?t=600)。

### 2. 特徵 [▶ 11:00](https://youtu.be/Z3JZbXUJQhw?t=660)

（學生把「Domain Expansion!」接成階乘：「領域展開 × (領域展開 − 1)」——「停止階乘化！」）

> **定義**：環 $R$ 的**特徵** $\operatorname{char}(R)$ 是使 $n\cdot x = 0$ 對所有 $x\in R$ 成立的最小正整數 $n$。若沒有這樣的 $n$，特徵是 0 [▶ 12:00](https://youtu.be/Z3JZbXUJQhw?t=720)。

- $n\cdot x = x+\cdots+x$（$n$ 次），遞迴定義 $(n+1)\cdot x = n\cdot x+x$；$(-1)\cdot x = -x$，所以任意整數倍都有定義 [▶ 14:00](https://youtu.be/Z3JZbXUJQhw?t=840)。

> **定理**：$R$ 有 1。若 1 的加法階是無窮，$\operatorname{char}R = 0$；若 1 的加法階是 $n$，$\operatorname{char}R = n$ [▶ 15:00](https://youtu.be/Z3JZbXUJQhw?t=900)。

- 關鍵：$n\cdot x = x(1+\cdots+1) = x\,(n\cdot1)$ [▶ 17:30](https://youtu.be/Z3JZbXUJQhw?t=1050)。
- 1 的階無窮：若 $n\cdot x = 0$ 對所有 $x$，取 $x = 1$ 就矛盾。
- 1 的階是 $n$：$n\cdot x = x(n\cdot1) = 0$ 對所有 $x$（而更小的 $m$ 對 $x = 1$ 就失敗）。
- 「一切由 1 決定。」（老師說今天腦袋不靈光，怪罪中午跟 Jacob 的會面。）

**例** [▶ 23:00](https://youtu.be/Z3JZbXUJQhw?t=1380)
- 特徵 0：$\mathbb{Z},\mathbb{Q},\mathbb{R},\mathbb{C}$；它們的矩陣環（不交換也行）；多項式環 $\mathbb{R}[x]$、$\mathbb{R}[x,y]$。
- 特徵 $n$：$\mathbb{Z}_n$；$\mathbb{Z}_n$ 上的矩陣、多項式（每個係數加 $n$ 次都變 0）[▶ 25:30](https://youtu.be/Z3JZbXUJQhw?t=1530)。

> **定理**：整環的特徵是 0 或質數 [▶ 26:00](https://youtu.be/Z3JZbXUJQhw?t=1560)。

**證明**：若 1 的階無窮，特徵 0。否則設階為 $n$，$n = st$（$1\le s,t\le n$）。
$$0 = n\cdot1 = (st)\cdot1 = (s\cdot1)(t\cdot1).$$
整環無零因子，所以 $s\cdot1 = 0$ 或 $t\cdot1 = 0$，由階的定義 $s = n$ 或 $t = n$。$n$ 只有平凡分解，是質數 [▶ 29:00](https://youtu.be/Z3JZbXUJQhw?t=1740)。
- 所以**體的特徵是 0 或質數 $p$**——兩「類」選擇（第二類有無窮多個）。

### 3. 環裡的整數 [▶ 30:30](https://youtu.be/Z3JZbXUJQhw?t=1830)

（其他幾個顯然的定理先跳過證明，留時間給領域展開。）

有 1 的環裡，$1,1+1,1+1+1,\dots$ 和它們的負數好像一份整數。但特徵 $n$ 時其實是一份 $\mathbb{Z}_n$——在同構意義下；例如矩陣環裡是「表現得像整數的矩陣」[▶ 31:30](https://youtu.be/Z3JZbXUJQhw?t=1890)。

> **定理**（2018 講義 Thm 4.4.10）：$R$ 有 1。$\varphi:\mathbb{Z}\to R$，$\varphi(k) = k\cdot1$ 是環同態 [▶ 32:30](https://youtu.be/Z3JZbXUJQhw?t=1950)。

- 常把 $k\cdot1$ 簡寫成 $k$（例如 $2\cdot1$ 寫成 $2$）——「我們不那麼斤斤計較」。
- $\ker\varphi = \{k\mid k\cdot1 = 0\}$ 是 $\mathbb{Z}$ 的理想 [▶ 35:30](https://youtu.be/Z3JZbXUJQhw?t=2130)。由第一同構定理 $\mathbb{Z}/\ker\varphi\cong\varphi(\mathbb{Z})\subseteq R$。
  - 特徵 0：$\ker\varphi = 0$，$R$ 含一份 $\mathbb{Z}$。
  - 特徵 $n$：$\ker\varphi = n\mathbb{Z}$，$R$ 含一份 $\mathbb{Z}_n$ [▶ 39:00](https://youtu.be/Z3JZbXUJQhw?t=2340)。
- 「kernel 和 characteristic 該大寫還是小寫？答案是：是。」

### 4. 領域展開：分式體 [▶ 40:30](https://youtu.be/Z3JZbXUJQhw?t=2430)

整環 $D$：交換、有 1、$ab = 0\Rightarrow a = 0$ 或 $b = 0$。但我們不滿足於領域的大小——想要**反元素**。例：$\mathbb{Z}$ 中 2 沒有反元素；$\mathbb{Z}[x]$ 也一樣 [▶ 41:30](https://youtu.be/Z3JZbXUJQhw?t=2490)。

（插曲：老師找綠色講義夾找了十分鐘，學生說在辦公室的書上面——對了。）

**構造** [▶ 43:30](https://youtu.be/Z3JZbXUJQhw?t=2610)：$S = \{(a,b)\mid a,b\in D,\ b\ne0\}$，定義
$$(a,b)\sim(c,d)\iff ad = bc.$$

**這是等價關係** [▶ 44:30](https://youtu.be/Z3JZbXUJQhw?t=2670)
- 自反：$ab = ba$（$D$ 交換）。
- 遞移（老師先做了這個，「我怎麼先證遞移？」）：$ad = bc$、$cf = de$。$adf = bcf = bde$，所以 $d(af) = d(be)$。$d\ne0$，用**消去律**得 $af = be$，即 $(a,b)\sim(e,f)$ [▶ 46:30](https://youtu.be/Z3JZbXUJQhw?t=2790)。（「抽象代數教授碰到消去律，就像飛蛾撲火。」）
- 對稱：$ad = bc\Rightarrow cb = da$。「用等式定義的關係，對稱性總是很蠢。」[▶ 47:30](https://youtu.be/Z3JZbXUJQhw?t=2850)

所以 $\sim$ 分割 $S$。等價類 $[(a,b)] = \{(c,d)\mid ad = bc\}$ [▶ 50:00](https://youtu.be/Z3JZbXUJQhw?t=3000)。

**運算**——「讓你們看看布幕後的人」：$(a,b)$ 就是 $a/b$ 的模型（「$b\ne0$ 是線索」）[▶ 51:30](https://youtu.be/Z3JZbXUJQhw?t=3090)。
$$[(a,b)]+[(c,d)] = [(ad+bc,\ bd)],\qquad[(a,b)]\cdot[(c,d)] = [(ac,\ bd)].$$
- $bd\ne0$（整環），所以結果仍在 $S$ 中。
- 要證明與代表元的選擇無關——每個分數有無窮多個代表 [▶ 52:30](https://youtu.be/Z3JZbXUJQhw?t=3150)。
- 單位元 $[(1,1)]$；$[(a,b)]$ 的反元素是 $[(b,a)]$（$a/b\cdot b/a = 1/1$）[▶ 53:30](https://youtu.be/Z3JZbXUJQhw?t=3210)。

> **定義**：以上得到的體叫 $D$ 的**分式體**（field of fractions）。任何整環都能這樣「領域展開」。

> 💬 補充（非課堂內容）：反元素 $[(b,a)]$ 需要 $a\ne0$，也就是 $[(a,b)]$ 不是零元 $[(0,1)]$。

- 修補有零因子的環有其他辦法，老師的哥哥有一套說法 [▶ 54:30](https://youtu.be/Z3JZbXUJQhw?t=3270)。
- **$\frac12 = \frac36$ 是真的「等於」** [▶ 55:00](https://youtu.be/Z3JZbXUJQhw?t=3300)：有些代數人說那不算等號，老師「用身上每一根纖維反對」——有理數就是分數的等價類，$\frac12$ 和 $\frac36$ 是同一個類。你從小處理分數就已經在處理這個等價關係。
- 數系的擴張：正整數 →（加負數）→ $\mathbb{Z}$ →（分式體）→ $\mathbb{Q}$ → $\mathbb{R}$ → $\mathbb{C}$？後兩步是另一個故事。**擴張體**是這門課的主線之一 [▶ 56:30](https://youtu.be/Z3JZbXUJQhw?t=3390)。

「至少領域展開沒搞砸。」學生：「你做得很好。」
