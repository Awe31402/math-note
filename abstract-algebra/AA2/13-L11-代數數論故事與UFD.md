## 1. Pell 方程

**例 1**[▶ 01:00](https://youtu.be/tfTqIajtVAw?t=60)：給定 $n\in\mathbb{N}$，找 $x^2-ny^2 = 1$ 的整數解。「古老的問題。印度數學家 **Brahmagupta**（約西元 600 年）就知道解法——我念錯了，向**半個網路**道歉。」

> **定理**（講義 p.1）[▶ 02:00](https://youtu.be/tfTqIajtVAw?t=120)　$(x_1,y_1)$、$(x_2,y_2)$ 解 $x^2-ny^2 = 1$ ⇒ $(x_3,y_3)$ 也是解，其中
> $$x_3 = x_1x_2+ny_1y_2,\qquad y_3 = x_1y_2+x_2y_1.$$

（「講義有個筆誤，不過我還沒貼出來，我**不該告訴你們**的。從紀錄中刪掉。這下我得剪片了。我不喜歡剪片，所以**不剪**。」）

**用 $\mathbb{Z}[\sqrt n]$ 證明**[▶ 04:00](https://youtu.be/tfTqIajtVAw?t=240)
- $N(a+b\sqrt n) = a^2-nb^2$，整數值（要正就取絕對值，「我不在乎」）。
- 共軛 $\overline{a+b\sqrt n} = a-b\sqrt n$——「**不是**複數共軛（$n<0$ 時才可能是）。之後會學到它在某些脈絡下是**體自同構**。」
- $N(z) = z\bar z$，共軛保持乘法 ⇒ **$N(zw) = N(z)N(w)$**（「這也許是作業，我不解了」）。
- Pell 方程就是 $N(x+y\sqrt n) = 1$。$N(z_1) = N(z_2) = 1$ ⇒ $N(z_1z_2) = 1$，而
$$z_1z_2 = (x_1+y_1\sqrt n)(x_2+y_2\sqrt n) = \underbrace{x_1x_2+ny_1y_2}_{x_3}+\underbrace{(x_1y_2+x_2y_1)}_{y_3}\sqrt n.\ \blacksquare$$
- 「古印度數學家應該**不是這樣做**的——那早於符號代數。他是從數字的**模式**看出來的。」「叫 Pell 方程其實是**誤稱**，不是 Pell 的。」

**例**[▶ 10:00](https://youtu.be/tfTqIajtVAw?t=600)：$x^2-3y^2 = 1$ 最小解 $(2,1)$。
$$(2+\sqrt3)^2 = 7+4\sqrt3\ ⇒\ (7,4);\qquad(2+\sqrt3)^3 = 26+15\sqrt3\ ⇒\ (26,15).$$
「別讓我講太快：$49-3\cdot16 = 1$。」
- 【口頭】[▶ 11:30](https://youtu.be/tfTqIajtVAw?t=690)「解集有**無限階循環群**的結構，一個生成全部。問題是：怎麼知道生成元是 $(2,1)$？那複雜得多。我 2015、16 年數論課的影片沒講怎麼找最小解，**留言區一片怨聲**——我一陣子沒搞懂他們在問什麼。那留給代數數論課。」
- 【口頭】[▶ 13:00](https://youtu.be/tfTqIajtVAw?t=780)「很多是從 **John Stillwell** 的書來的。我喜歡他的文筆，但他有點像**騙子**——讀起來很順，做題時常覺得工具箱少了東西。他更在乎**故事**，而不是給你一個能用的產品。」

## 2. Gauss 整數與 Gauss 質數

**例 2**[▶ 14:00](https://youtu.be/tfTqIajtVAw?t=840)（講義 p.2）：$\mathbb{Z}[i]$，$N(a+bi) = a^2+b^2$，$N(zw) = N(z)N(w)$。
- 【講義補充】$N(a+bi) = 1\iff a+bi = \pm1,\pm i$——**4 個單位**。
- 「想懂**平方和**的事，Gauss 整數會告訴你。」
- 【課堂討論】[▶ 15:30](https://youtu.be/tfTqIajtVAw?t=930)「質元怎麼定義的？」學生：「整除乘積就整除其中一個。」這就是 **Gauss 質數**。

> **定理**（講義 p.2）[▶ 16:30](https://youtu.be/tfTqIajtVAw?t=990)　普通質數 $p$ 是 Gauss 質數 $\iff$ $p\neq a^2+b^2$。

**部分證明**[▶ 17:00](https://youtu.be/tfTqIajtVAw?t=1020)：若 $p = a^2+b^2$（$a,b\neq0$），在 $\mathbb{Z}[i]$ 裡可以分解
$$p = (a+bi)(a-bi),$$
$a\pm bi$ 不是單位 ⇒ $p$ **不可約元都不是** ⇒ 不是質元。
- 【課堂討論】[▶ 18:30](https://youtu.be/tfTqIajtVAw?t=1110)「上次證了在什麼脈絡下不可約 ⟺ 質？」學生：「PID。」「Gauss 整數有輾轉相除法 ⇒ **歐氏整環 ⇒ PID**。」（其實「質 ⇒ 不可約」在任何整環都成立，這裡用的是它的逆否：不是不可約 ⇒ 不是質。）

[▶ 20:00](https://youtu.be/tfTqIajtVAw?t=1200)（以下投影老師數論課講義）
- 「如果我今天多一小時，就會把這些寫好在黑板上講。但系上有個**生物**，你們知道是誰，我還沒找到方法馴服他。」
- $a+bi$ 是 Gauss 質數 $\iff$ $a-bi$ 是（用範數證，「本來可以當作業」——學生：「還可以考。」「列入考慮。」）
- 數論課證過：**$4k+3$ 型質數不是兩平方和** ⇒ 它們是 Gauss 質數（例：7）。$4k+1$ 型質數**是**兩平方和：$5 = 1^2+2^2$；【課堂討論】「13 呢？」學生：「$3^2+2^2$。」「耶。」
- $8n+1$、$8n+3$ 型質數 $\iff$ 可寫成 $x^2+2y^2$——$\mathbb{Z}[\sqrt{-2}]$ 告訴你這類質數的事。

> **Fermat 二平方定理**（講義 p.2）[▶ 25:30](https://youtu.be/tfTqIajtVAw?t=1530)　$p = 4n+1$ 是質數 ⇒ $p = a^2+b^2$。

- 證明靠 **Lagrange 引理**：存在 $m$ 使 $p\mid m^2+1$ ⇒ $p\mid(m+i)(m-i)$，再用 Gauss 整數的除法算法……「我不期待你們學這定理或證明，只想讓你們看到：論證**真的用到** Gauss 整數的輾轉相除法。」（找這定理找了好一陣：「**怪 Jacob**。全都是 Jacob 的錯，一路到底。」）

## 3. 二平方、四平方；歷史

**二平方恆等式**（講義 p.2）：$z = x+iy$、$w = a+ib$，$|zw|^2 = |z|^2|w|^2$ 給
$$(xa-yb)^2+(xb+ya)^2 = (x^2+y^2)(a^2+b^2).$$
「公式很古老，但它跟**複數**的連結就是 $\mathbb{Z}[i]$ 自然實現 $N(zw) = N(z)N(w)$ 的原因。」

💬 講義 p.2 框起來的式子寫成 $(xa-yb)^2+(xa+yb)^2$，第二項應是 **$(xb+ya)^2$**（$zw = (xa-yb)+i(xb+ya)$）。講義上方算 $zw$ 時也寫成 $xa-yb+i(xa+yb)$，同一個筆誤。

**歷史**[▶ 28:00](https://youtu.be/tfTqIajtVAw?t=1680)
- 「我們的二平方定理證明其實是 **Dedekind** 的。Fermat 宣稱用**無窮遞降法**證過但沒寫下來；**Euler** 花了好幾年才真的用遞降法證出來。Fermat 說有證明卻沒寫、別人花好多年——這是數學史上的**模式**。有時是好事：Fermat 最後定理打開了整片數論新天地，Langlands 綱領之類。」
- 「Euler 大概**沒用** Gauss 整數；**Lagrange** 用了——比 Gauss 19 世紀初的大作早幾十年。Gauss 自己知道這些代數數論技巧，但**不用**：他的算術大作滿是**模算術**、互反律。」

【講義補充】講義 p.5（2018 講義）：Gauss 可能意識到唯一分解的危險（後來 Kummer 講明），所以用**暴力**（顯式的 $\mathbb{Z}$ 中代數、同餘）解 Euler 和 Lagrange 用更優雅方式處理的問題。

> **四平方定理**（講義 p.4）[▶ 31:30](https://youtu.be/tfTqIajtVAw?t=1890)　每個 $n\in\mathbb{N}$ 都可寫成 $a^2+b^2+c^2+d^2$。

💬 講義 p.4 框裡寫「$n^2 = a^2+b^2+c^2+d^2$」——應是 **$n = $**（老師口頭讀的也是 $n$）。

- [▶ 30:00](https://youtu.be/tfTqIajtVAw?t=1800) 證明用 **Hurwitz 整數**：四元數 $i,j,k$ 的整數格點「分得太開」沒有除法算法，**加入半整數**就幾乎是歐氏整環——只是**不交換**（「**斜**歐氏整環，不管那是什麼」）。範數就是四元數範數、乘性 ⇒ $p$ 在 Hurwitz 意義下不是質數時可寫成四平方和。
- 【課堂討論】[▶ 32:00](https://youtu.be/tfTqIajtVAw?t=1920) 學生：「你們不知道這個？」學生：「**歸納法**？」「不，歸納法辦不到。歸納法**有它的極限**。」
- **四平方恆等式**（Euler 1748，沒用四元數）：
$$(a_1^2+b_1^2+c_1^2+d_1^2)(a_2^2+b_2^2+c_2^2+d_2^2) = (\cdots)^2+(\cdots)^2+(\cdots)^2+(\cdots)^2.$$
  來源：四元數 $\eta = t+xi+yj+zk$，$\eta\bar\eta = t^2+x^2+y^2+z^2 = N(\eta)$，$N(\alpha\beta) = N(\alpha)N(\beta)$。
- 【口頭】[▶ 33:00](https://youtu.be/tfTqIajtVAw?t=1980)「二平方恆等式來自**複數**的『積的共軛 = 共軛的積』，四平方恆等式來自**四元數**的同一件事。」二平方恆等式 Diophantus 約西元 200 年就知道，1593 年又被重新發現（⚠️ 逐字稿缺字：人名沒聽出）；四平方 Euler 約 1750，接著 Rodrigues、Hamilton 四元數、Hurwitz 整數。
- 【口頭】[▶ 34:00](https://youtu.be/tfTqIajtVAw?t=2040)「**Hurwitz 定理**在可能的特別主題清單上：唯一的**賦範結合可除代數**只有 $\mathbb{R}$、$\mathbb{C}$、四元數。（八元數**不結合**，只是冪結合；再上面還有 Cayley–Dickson 那些更**陰險**的東西。）」

**例 3**（講義 p.4）：用二平方恆等式造畢氏三元組：
$$(3^2+4^2)(5^2+12^2) = |(3+4i)(5+12i)|^2 = |-33+56i|^2\ ⇒\ 65^2 = 33^2+56^2.$$

## 4. Eisenstein 整數、Lamé 的錯誤證明、理想數

[▶ 35:00](https://youtu.be/tfTqIajtVAw?t=2100)（講義 p.3）
- 分解：$x^2+y^2 = (x-yi)(x+yi)$；$x^3+y^3 = (x+y)(x+\zeta_3y)(x+\zeta_3^2y)$，$\zeta_3 = e^{2\pi i/3} = \frac{-1+\sqrt{-3}}2$。
- **$\mathbb{Z}[\sqrt{-3}]$ 不是 UFD**：$(1+\sqrt{-3})(1-\sqrt{-3}) = 4 = 2\cdot2$，$1\pm\sqrt{-3}$ 和 2 不相伴。所以也**不是歐氏整環**（歐氏 ⇒ PID ⇒ UFD）。「只是因為格點**分得太開**。」
- 加入半整數 ⇒ **Eisenstein 整數** $\mathbb{Z}[\zeta_3]$：歐氏整環 ⇒ PID ⇒ UFD。在這裡分解 $x^3+y^3$ 可證 **$x^3+y^3 = z^3$ 沒有正整數解**。
- 【講義補充】$\mathbb{Z}[\sqrt{-5}]$ 也不是 UFD，而且**不像** $\mathbb{Z}[\sqrt{-3}]$ 那樣加點就能修好。

**Fermat 最後定理**[▶ 37:30](https://youtu.be/tfTqIajtVAw?t=2250)：$x^n+y^n = z^n$，$n\ge3$ 沒有整數解。「Fermat 說他在**頁邊**寫不下證明——沒人真的相信那是證明。」
- 自然的做法：在**分圓整數** $\mathbb{Z}[\zeta_n]$ 中
$$x^n+y^n = (x+y)(x+\zeta_ny)(x+\zeta_n^2y)\cdots(x+\zeta_n^{n-1}y)$$
- **Lamé**「（他是法國人，念 Lamé）**不是開玩笑**」給了一個基於**假設唯一分解**的證明。「只有一個問題：**$\mathbb{Z}[\zeta_n]$ 不是 UFD**。所有仿照 Eisenstein 整數的正確論證**全部崩潰**。」
- [▶ 39:00](https://youtu.be/tfTqIajtVAw?t=2340)「**Kummer** 發現問題，引入**理想數**：把數換成它們的**理想**，就能**找回唯一分解**——分解的不一致被洗掉了。Dedekind 整理了這些，也證明了許多 $n$ 的 Fermat 最後定理；那些例外的 $n$ 困難得多，直到最近 **Andrew Wiles** 用相當進階的技巧才證完。」

💬 對許多 $n$（**正則質數**）證明 Fermat 最後定理的是 **Kummer**（1847 年前後），不是 Dedekind；Dedekind 是把理想數發展成**理想**理論（講義 p.3 寫「as pioneered by Dedekind to prove FLT for many cases ≈1890's」，也把兩人混在一起）。

## 6. PID 的升鏈條件

> **定理（升鏈條件 ascending chain condition）**（講義 p.5，2018 講義 Thm 4.8.7）[▶ 47:00](https://youtu.be/tfTqIajtVAw?t=2820)　在 PID 中，任何**嚴格遞增**的理想鏈 $I_1\subset I_2\subset\cdots$ 長度都是**有限**的。

**證明**：
- $I = \bigcup_jI_j$ 是理想（「好的作業題，我該出的」）⇒ $I = (d)$。
- $d\in I$ ⇒ $d\in I_n$（某個 $n$）。
- 對所有 $i$：$I_i\subseteq I = (d)\subseteq I_n$ ⇒ $I_n$ 是鏈的**終點**。$\blacksquare$

「**簡單得驚人**。」

## 7. PID ⇒ UFD

> **定理**（講義 p.6，2018 講義 Thm 4.8.8）[▶ 48:30](https://youtu.be/tfTqIajtVAw?t=2910)　**每個 PID 都是 UFD**。

【講義補充】講義 p.6：「這大概是本學期**最有趣**的證明。」

**證明**[▶ 49:00](https://youtu.be/tfTqIajtVAw?t=2940)：$D$ 是 PID，單位集合 $U$。取 $a_0\neq0$、$a_0\notin U$。
- 【口頭】「單位不在討論內：單位可以**一直拆**——$1 = (-1)(-1) = (-1)(-1)(-1)(-1)\cdots$，可以拆一整天。」
- **計畫**：(1) $a_0$ 的分解**至少含一個**不可約元；(2) $a_0$ 能分解成不可約元的積；(3) 在相伴下唯一。

**(1)**[▶ 50:00](https://youtu.be/tfTqIajtVAw?t=3000) $a_0$ 不可約就完成。否則 $a_0 = a_1b_1$，$a_1$ 非單位、$b_1$ 非單位。$a_1$ 不可約就完成；否則 $a_1 = a_2b_2$……得到
$$a_n = a_{n+1}b_{n+1}\ ⇒\ \langle a_n\rangle\subset\langle a_{n+1}\rangle,$$
**嚴格**遞增（$b_{n+1}$ 不是單位）。升鏈條件 ⇒ 停在某個 $\langle a_k\rangle$，$a_k$ 不允許分解成非單位 ⇒ **$a_k$ 不可約**，$a_0 = ra_k$。

**(2)**[▶ 51:30](https://youtu.be/tfTqIajtVAw?t=3090)「記得整數的質因數分解怎麼證嗎？先證**有一個**質因數，提出來，剩下的又是數，又有質因數……最後**分完**。」
- $a_0$ 不可約就完成。否則由 (1)：$a_0 = p_1c_1$，$p_1$ 不可約、$c_1$ 非單位。$c_1$ 不可約就完成；否則 $c_1 = p_2c_2$……
- 又一條升鏈 $\langle a_0\rangle\subset\langle c_1\rangle\subset\langle c_2\rangle\subset\cdots$，必停在某處，最後一個 $c$ 本身不可約 ⇒
$$a_0 = p_1p_2\cdots p_t.$$

💬 講義 p.6 把這條鏈寫成 $\langle a_0\rangle\subset\langle p_1\rangle\subset\langle p_2\rangle\subset\cdots$——遞增的應該是**餘因子** $c_i$ 生成的理想：$c_{i} = p_{i+1}c_{i+1}$、$p_{i+1}$ 非單位 ⇒ $\langle c_i\rangle\subsetneq\langle c_{i+1}\rangle$。

**(3) 唯一性**[▶ 53:30](https://youtu.be/tfTqIajtVAw?t=3210)「看起來很可怕，其實跟剛才差不多——喔，**歸納法**。所以我說錯了，其實**很不一樣**。」設 $a_0 = p_1\cdots p_t = q_1\cdots q_s$，對 $t$ 歸納。
- $t = 1$：$p_1 = q_1\cdots q_s$，不可約元不能分解成兩個以上不可約元的積 ⇒ $s = 1$。
- 歸納步：$p_1\mid q_1\cdots q_s$。PID 中不可約 = 質 ⇒ $p_1\mid q_j$（某個 $j$）。$q_j$ 不可約 ⇒ $p_1 = u_jq_j$。代入，**整環消去** $q_j$：
$$u_jp_2\cdots p_t = q_1\cdots\widehat{q_j}\cdots q_s,$$
  左邊 $t-1$ 個不可約元 ⇒ 歸納假設：右邊也是 $t-1$ 個，在相伴與排序下相同。$\blacksquare$

**推論**[▶ 55:30](https://youtu.be/tfTqIajtVAw?t=3330)
- **$F[x]$ 是 UFD**：長除法 ⇒ 歐氏 ⇒ PID ⇒ UFD。「**多項式的唯一分解**就由這論證得到。」
- **每個歐氏整環都是 UFD**。「歐氏 ⇒ PID 我們上堂課證了——**兩堂課前**我想不起來、很懊惱的就是這個。」
- 「現在我們有了蘊含開頭那串包含關係的**所有理論**。」

【講義補充】講義 p.7：$\mathbb{Z}[x]$ 是 UFD 但不是 PID——上面的蘊含**不可逆**。PID 非歐氏的例子較難找（講義連結 Tom Oldfield 的構造和 Bill Dubuque 的回答）。「我期待你們**知道**這些結果，但不期待你們能造出 PID 非歐氏的例子。而『$\mathbb{Z}[x]$ 是 UFD 但不是 PID』正是你們**該知道**的那種事。」

## 8. 例：ℤ[√−5] 不是 UFD

[▶ 56:30](https://youtu.be/tfTqIajtVAw?t=3390)（講義 p.8，2018 講義 Example 4.8.12，標「discuss」）
$$46 = 2\cdot23 = (1+3\sqrt{-5})(1-3\sqrt{-5}).$$
- $N(a+b\sqrt{-5}) = a^2+5b^2$；$a^2+5b^2 = 1$ 只有 $(\pm1,0)$ ⇒ 單位只有 $\pm1$ ⇒ 這四個因子**兩兩不相伴**。
- ⇒ 兩個不等價的分解 ⇒ 不是 UFD ⇒ 不是 PID ⇒ 不是歐氏整環。
- 【口頭】[▶ 57:00](https://youtu.be/tfTqIajtVAw?t=3420)「好吧，嚴格說還沒證完——要證那些因子都是**不可約元**。我比較喜歡用不可約來想——想**化約**比想『整除乘積』自然。」

【講義補充】不可約的證明：$2 = xy$ 非單位 ⇒ $N(x) = N(y) = 2$，$a^2+5b^2 = 2$ 無解；23 ⇒ 需 $a^2+5b^2 = 23$，試一下無解；$1+3\sqrt{-5}$ 範數 46 ⇒ 需範數 2 或 23 的因子，同樣無解。

【講義補充】講義 p.8 開頭還有 **Eisenstein 判別法**的一個優雅證明（Gallian 歸功於 Richard Singer），留到 [[17-L14-約化法與Eisenstein判別法]]。

[▶ 57:30](https://youtu.be/tfTqIajtVAw?t=3450)「下堂課進入**多項式**，我很高興——這裡材料太多了，總是很想……」

## 附：本集一句話總結

> **先玩代數數論：$\mathbb{Z}[\sqrt n]$ 的範數乘性讓 Pell 方程的解可以相乘、Gauss 整數解釋哪些質數是平方和、四元數的 Hurwitz 整數證四平方定理、Eisenstein 整數證 $x^3+y^3 = z^3$ 無解——而 Lamé 誤以為 $\mathbb{Z}[\zeta_n]$ 唯一分解，Kummer 用理想數補救；然後定義 UFD（分解成不可約元、在排序和相伴下唯一），用 PID 的升鏈條件證明每個 PID 都是 UFD，所以 $F[x]$ 和所有歐氏整環都是 UFD，而 $\mathbb{Z}[\sqrt{-5}]$ 中 $46 = 2\cdot23 = (1+3\sqrt{-5})(1-3\sqrt{-5})$ 說明它不是。**
