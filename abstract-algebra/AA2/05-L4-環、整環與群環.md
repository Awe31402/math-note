## 1. 環的定義；有沒有 1 的慣例

> **定義（環 ring）**（Dummit & Foote §7.1；講義 p.1）[▶ 00:00](https://youtu.be/ybay3nyMQ28?t=0)　集合 $R$ 有兩個運算 $+$ 和 $\times$：
> 1. $(R,+)$ 是**交換群**；
> 2. $\times$ **結合**；
> 3. **分配律**：$(a+b)c = ac+bc$、$a(b+c) = ab+ac$。
>
> - **交換環**：$ab = ba$ 對所有 $a,b$。
> - **有單位元 1**：$1a = a1 = a$。有 1 的環叫 **unital ring**。

【口頭】[▶ 00:30](https://youtu.be/ybay3nyMQ28?t=30)「我們幾乎總用**並列**表示乘法，幾乎不寫乘號——**在微積分裡學生用乘號從來不是好兆頭**，順帶一提。」

**慣例**[▶ 01:00](https://youtu.be/ybay3nyMQ28?t=60)
- 有些書**預設 $1\in R$**；那些書把沒有 1 的叫 **rng**。
- Dummit & Foote **不**預設有 1。
- 「**有疑問就問我**——我出的有些題來自假設有 1 的書。文獻兩種都有。」
- 對照老師 2018 年 421 Lecture 21 的筆記 [▶ 03:00](https://youtu.be/ybay3nyMQ28?t=180)：「那裡我**假設** $1\in R$——我想是跟著 Gallian。」（「我的印表機有點爛，印得很像鬼。」）

> **定義（除環、體）**[▶ 01:30](https://youtu.be/ybay3nyMQ28?t=90)　有 1 且 $1\neq0$ 的環，若每個非零 $a$ 都有乘法反元素 $a^{-1}$（$a^{-1}a = aa^{-1} = 1$），叫**除環（division ring）**。**體（field）**是交換的除環。

## 2. 環的例子

**例 1**（講義 p.1）[▶ 02:00](https://youtu.be/ybay3nyMQ28?t=120)
- $2\mathbb{Z}$：**沒有 1** 的環（在 D&F 語言就是「環」）。
- $\mathbb{Z},\mathbb{Q},\mathbb{R},\mathbb{C},\mathbb{Z}_n$：有 1 的交換環。
- $\mathbb{Q},\mathbb{R},\mathbb{C}$ 是體；$\mathbb{Z}_n$ 是體 $\iff n = p$ 質數（$\mathbb{Z}_6$ 不是）。

**例 2：四元數 $\mathbb{H}$**[▶ 04:00](https://youtu.be/ybay3nyMQ28?t=240)
$$\mathbb{H} = \{a+bi+cj+dk : a,b,c,d\in\mathbb{R}\},\quad i^2 = j^2 = k^2 = -1,\ ij = k = -ji,\ jk = i = -kj,\ ki = j = -ik.$$
- 作為向量空間是四維，本質上是 $\mathbb{R}^4$ 配上基底 $e_1,\dots,e_4$ 的一個好乘法規則。
- 【講義補充】$(a+bi+cj+dk)^{-1} = \dfrac{a-bi-cj-dk}{a^2+b^2+c^2+d^2}$——每個非零四元數都可逆。
- 「四元數**幾乎是體**，只是不交換——所謂**斜體（skew field）**。它算是**唯一這樣的例子**。」

**例 3：函數環 $\mathcal F(S,T)$**[▶ 05:00](https://youtu.be/ybay3nyMQ28?t=300)：$T$ 是環、$S$ 是**任意集合**（不必是環），$f:S\to T$ 的函數用逐點加乘。
- $1\in T$ ⇒ 常數函數 1 是乘法單位元；$T$ 交換 ⇒ $\mathcal F(S,T)$ 交換。
- 「這是**例子的例子**——可以由它產生一大堆例子。」

**例 4：矩陣環 $R^{n\times n} = \operatorname{Mat}_n(R)$**[▶ 06:00](https://youtu.be/ybay3nyMQ28?t=360)：$(A+B)_{ij} = A_{ij}+B_{ij}$，$(AB)_{ij} = \sum_kA_{ik}B_{kj}$。
- 即使 $R$ 交換，$n\ge2$ 時也不交換。（字幕說「$n$ 大於 2」。）
- **後設例子**[▶ 06:30](https://youtu.be/ybay3nyMQ28?t=390)：$R$ 可以不交換——例如 $R = 2\times2$ 矩陣，那 $R^{2\times2}$ 就是「$2\times2$ 矩陣的 $2\times2$ 矩陣」。「矩陣環的想法可能**比你想的更一般**。」

**例 5：多項式環 $R[x]$**[▶ 07:00](https://youtu.be/ybay3nyMQ28?t=420)「對這門課**特別重要**。」
$$R[x] = \left\{\sum_{n = 0}^\infty c_nx^n : c_n\in R,\text{ 只有有限多個 }c_n\neq0\right\}.$$
- 【口頭】「我說**不定元** $x$，是**故意不說**這是多項式**函數**的集合。多項式是**表達式**，跟函數有某種對應，但說『唯一』大概是錯的詞。不定元和函數有區別——今天不精確化，但那個區別在你們以前的學習裡大概被**混為一談**了。」

## 3. 零因子與單位

> **定義**（講義 p.3）[▶ 08:00](https://youtu.be/ybay3nyMQ28?t=480)
> 1. $a\neq0$ 是**零因子（zero divisor）**：存在 $b\neq0$ 使 $ab = 0$ **或** $ba = 0$。
> 2. $R$ 有 1（$1\neq0$）時，$u$ 是**單位（unit）**：存在 $v$ 使 $uv = vu = 1$，記 $v = u^{-1}$。單位的集合記 $R^\times$（或 $U(R)$）。

- 「交換環裡不需要兩邊，但有非交換環裡 $ab = 0$ 和 $ba = 0$ 有區別。」
- 「我們寫 $u^{-1}$，**不寫** $1/u$——除非恰當，例如有理數、實數。」
- $R^\times$ 是 D&F 的記號；$U(R)$ 是另一個常見記號（U 代表 units），老師 421 筆記用這個。

**例**（講義 p.3）
1. $\mathbb{Z}_n^\times = U(n) = \{x\in\mathbb{Z}_n : \gcd(x,n) = 1\}$ [▶ 10:00](https://youtu.be/ybay3nyMQ28?t=600)。（「嚴格說，gcd 是看 $x$ 的一個整數代表。」）
2. $F$ 體 ⇒ $F^\times = F-\{0\}$——「基本上就是體的定義」[▶ 11:00](https://youtu.be/ybay3nyMQ28?t=660)。
3. **函數環的零因子**[▶ 11:30](https://youtu.be/ybay3nyMQ28?t=690)：**特徵函數** $\chi_U(x) = 1$（$x\in U$）、$0$（$x\notin U$）。$S_1,S_2$ 非空、不相交 ⇒ $\chi_{S_1}\chi_{S_2} = 0$，但兩個都非零 ⇒ 零因子。
   - 【口頭】「特徵函數在各種有趣的證明裡超有用——那些我**自己大概想不到**，我的腦袋不太這樣運作。」
   - 「不難想像：一處為零、另一處非零的函數，相乘得零——都是零因子。函數只要在某處取 0 就不可能是單位……嗯，我得小心。」
4. $\mathbb{Z}^\times = \{\pm1\}$，$\mathbb{Z}$ 沒有零因子。
5. **$R$ 交換、$1\neq0$：$A\in R^{n\times n}$ 是單位 $\iff\det A\in R^\times$**[▶ 13:30](https://youtu.be/ybay3nyMQ28?t=810)。
   - 「講義沒證，我用話說：反矩陣公式是**古典伴隨矩陣**除以行列式——那就變成乘以行列式的反元素。所以**反矩陣公式在交換環的脈絡裡還是有意義**。」

（插曲 [▶ 10:30](https://youtu.be/ybay3nyMQ28?t=630)：「嘿 Ben，怎麼了？」「我要喝水。」「你在忙什麼？」「做好雪。」「好，我要回到我的課了。」）

## 4. 整環；消去律

> **定義（整環 integral domain）**（講義 p.4）[▶ 14:00](https://youtu.be/ybay3nyMQ28?t=840)　$1\neq0$ 的**交換環**，沒有零因子。

> **命題**　$R$ 交換、$1\neq0$。
> 1. $a$ 不是零因子、$ab = ac$ ⇒ $a = 0$ 或 $b = c$。
> 2. 整環中 $ab = ac$、$a\neq0$ ⇒ $b = c$（**消去律**）。
> 3. 零因子不是單位；單位不是零因子。

「讓我們證一次，以後不用再證。當然這是很好的考題，因為**超簡單**。」

**證明**[▶ 15:00](https://youtu.be/ybay3nyMQ28?t=900)
1. $ab-ac = 0$ ⇒ $a(b-c) = 0$；$a$ 不是零因子 ⇒ $b-c = 0$。
2. 整環沒有零因子 ⇒ 由 (1)。
3. 設 $ab = 0$，$a,b\neq0$，又 $a^{-1}$ 存在：$a^{-1}ab = 1\cdot b = b$，另一邊 $a^{-1}\cdot0 = 0$ ⇒ $b = 0$，矛盾 [▶ 16:00](https://youtu.be/ybay3nyMQ28?t=960)。反過來同樣論證。

【口頭】[▶ 16:30](https://youtu.be/ybay3nyMQ28?t=990)「這是在 $1\neq0$ 的環裡。如果 $1 = 0$……我**就是不在乎**。抱歉。你可以去讀 Dummit & Foote 那段，我就是**沒辦法**在乎那個環。」

## 5. 有限整環是體

> **定理**（講義 p.5）[▶ 17:00](https://youtu.be/ybay3nyMQ28?t=1020)　**有限整環是體。**

「你們在 421 大概證過，是很好玩的東西。」

**證明**
- 整環已經是有 1、$1\neq0$ 的交換環——「**我們已經走了一半**」。剩下：每個非零元素可逆。
- 寫 $R = \{0,x_2,\dots,x_n\}$。（「我不必寫出來，但寫了讓我感覺好一點。看，**這麼有限**，耶。」）
- 取 $a\neq0$，定義 $f(x) = ax$——「又是上週那個**左乘**」[▶ 18:00](https://youtu.be/ybay3nyMQ28?t=1080)。
- $f(x) = f(y)$ ⇒ $ax = ay$ ⇒ $x = y$（消去律）⇒ **單射**。
- 有限集合上的單射就是**滿射**——「有限集合之間的函數就是這樣運作」。
- 所以存在 $x$ 使 $ax = 1$ ⇒ $x = a^{-1}$。$a$ 任意 ⇒ 體。$\blacksquare$

【口頭】[▶ 19:00](https://youtu.be/ybay3nyMQ28?t=1140)（投影 2018 筆記 Thm 4.1.33，p.127）「那裡我列出 $a$ 的冪、繞回來、再用有限性。你可以看看。**我比較喜歡我剛給你們的證明，我覺得比較好。**」

## 6. 子環：ring vs. rng

> **定義（子環 subring）**（講義 p.5）[▶ 20:00](https://youtu.be/ybay3nyMQ28?t=1200)　$R$ 的子環：$(R,+)$ 的子群，且對乘法封閉。（若要求 $1\in R$，子環也必須含 1。）

> **定理（子環判別法）**　$S\subseteq R$，若對 $a,b\in S$ 有 $a-b,\ ab\in S$，則 $S$ 是子環。

【口頭】「用我之前筆記的語言，**剛才念的這個定義其實是 sub-rng 的定義**。」講義：「總之，**我們的『ring』就是我那份筆記的『rng』**。」

**對照 2018 筆記**[▶ 21:00](https://youtu.be/ybay3nyMQ28?t=1260)（「我把它放大一點，也許看得到，也許不行。我會貼連結。」）
- Thm 4.1.14（子環判別法）還要求 $1\in S$。所以那裡 $2\mathbb{Z}$ **不是**子環，只是 sub-rng。
- **Ex 4.1.15**[▶ 22:00](https://youtu.be/ybay3nyMQ28?t=1320)：$2\mathbb{Z}\subseteq\mathbb{Z}$：差、積還在裡面 ⇒ D&F 意義下是子環；但沒有 1。**奇數**連 sub-rng 都不是——奇數相加不是奇數。「如果有人要你舉『**對乘法封閉但對加法不封閉**』的子集，奇數就是好例子。」
- **Ex 4.1.16：$2\mathbb{Z}_6 = \{0,2,4\}$**[▶ 23:00](https://youtu.be/ybay3nyMQ28?t=1380)：看 Cayley 表，$4\cdot s = s\cdot4 = s$——**4 是 $2\mathbb{Z}_6$ 的乘法單位元**。
  - 「所以這個子環**是一個有單位元的環**——但**不是**有單位元意義下的子環，因為它的單位元 4 **不是** $\mathbb{Z}_6$ 的單位元 1。」
  - 「這很怪，對吧？運算都一樣——還是模 6——只是 **4 在這裡扮演 1**。」（「這就是那種**彆扭**——其中一部分。」）
- **Ex 4.1.17**：$m\mathbb{Z}_n$ 總是 sub-rng，不一定是有 1 的子環。「到這裡我對 sub-ring、sub-rng 講累了，就停了。」

## 7. 子環的例子；S[x] ⊆ R[x]

**例**（講義 p.6）[▶ 26:00](https://youtu.be/ybay3nyMQ28?t=1560)
1. $\mathbb{Z}\subset\mathbb{Q}\subset\mathbb{R}\subset\mathbb{C}$；$\mathbb{Q}[\sqrt2] = \{a+b\sqrt2 : a,b\in\mathbb{Q}\}\subset\mathbb{R}$。
   - D&F §7.1 花了些時間分析 $\mathbb{Q}[\sqrt d]$（$d$ 無平方因子）——「之後大概會回來」。
   - 乘積 $(a+b\sqrt2)(c+d\sqrt2) = (ac+2bd)+(ad+bc)\sqrt2$，「還是有理數」。
2. $n\mathbb{Z}$（$n\ge2$）是 $\mathbb{Z}$ 的子環，但**沒有 1**。**$\mathbb{Z}_n = \mathbb{Z}/n\mathbb{Z}$ 不是** $\mathbb{Z}$ 的子環——「連運算都不一樣：陪集加法不是整數加法，有關但不一樣」[▶ 27:00](https://youtu.be/ybay3nyMQ28?t=1620)。
3. **函數空間**[▶ 27:30](https://youtu.be/ybay3nyMQ28?t=1650)：$C^\infty(\mathbb{R})\subset C^2(\mathbb{R})\subset C^1(\mathbb{R})\subset C^0(\mathbb{R})\subset\mathcal F(\mathbb{R})$，每個都是所有函數環的子環。（$C^k$ = $k$ 次連續可微。）
4. $S\le R$ ⇒ $S[x]\le R[x]$。
5. $S\le R$ ⇒ $M_n(S)\le M_n(R)$。
6. **上三角矩陣** $UT_n(R)$ 是 $M_n(R)$ 的子環 [▶ 29:00](https://youtu.be/ybay3nyMQ28?t=1740)：差、積還是上三角。（「Benjamin 又回來了——要點心？」「不是點心。媽說我們可以用這些碗——做雪球。」「很好，Benjamin。」）

**證明 $S[x]\le R[x]$**（講義 p.7）[▶ 30:00](https://youtu.be/ybay3nyMQ28?t=1800)「它們都很基本，但這個值得多談一點——主要是為了**多談多項式的記號**。」
- $a(x) = \sum a_nx^n$、$b(x) = \sum b_nx^n$，$a_n,b_n\in S$，只有有限多個非零。
  - 「沒規定一定要用同一個字母，我只是不想搞混。」「多項式是有限的——我只是**加了無限多個 0**，這樣就不用操心。」
- **差**：$a(x)-b(x) = \sum(a_n-b_n)x^n$；$S$ 是子環 ⇒ $a_n-b_n\in S$。
- **積**[▶ 32:00](https://youtu.be/ybay3nyMQ28?t=1920)（我想這叫 **Cauchy 積**，只是有限的）：
$$a(x)b(x) = \sum_{n = 0}^\infty\left(\sum_{k = 0}^na_kb_{n-k}\right)x^n = \sum_n(a_0b_n+a_1b_{n-1}+\cdots+a_nb_0)x^n.$$
  每個 $a_kb_{n-k}\in S$（$S$ 對乘法封閉），和也在 $S$（$S$ 是加法群）⇒ 每個係數在 $S$。
- 子環判別法。$\blacksquare$

**術語**（D&F §7.2，「很好的總整理」）[▶ 34:00](https://youtu.be/ybay3nyMQ28?t=2040)：$a(x) = a_nx^n+\cdots+a_0$，$a_n\neq0$：**次數** $\deg a(x) = n$，$a_n$ 是**領導項（leading term）**；$a_n = 1$ 叫**首一（monic）**——「這學期研究多項式時會用很多首一多項式」。

## 8. 整環上的多項式

> **命題**（講義 p.8）[▶ 35:00](https://youtu.be/ybay3nyMQ28?t=2100)　$R$ 是整環，$p(x),q(x)\in R[x]$ 非零。
> 1. $\deg(p(x)q(x)) = \deg p+\deg q$；
> 2. $R[x]$ 的單位就是 $R^\times$（看成常數多項式）；
> 3. $R[x]$ 是整環。

「證明全靠**領導項**的分解。」寫 $p = a_mx^m+\cdots+a_0$、$q = b_nx^n+\cdots+b_0$，$a_m,b_n\neq0$。

1. $pq = a_mb_nx^{m+n}+\cdots+a_0b_0$。$a_m,b_n\neq0$、$R$ 無零因子 ⇒ $a_mb_n\neq0$ 是 $pq$ 的領導項 ⇒ $\deg(pq) = m+n$ [▶ 36:30](https://youtu.be/ybay3nyMQ28?t=2190)。
2. 若 $pq = 1$：**比較係數**——只有常數項非零 ⇒ $a_m,b_n = 0$（$m,n\ge1$），$a_0b_0 = 1$ ⇒ $a_0,b_0\in R^\times$，$p = a_0$、$q = b_0$ [▶ 37:30](https://youtu.be/ybay3nyMQ28?t=2250)。
3. $pq = 0$、$p,q\neq0$ ⇒ $a_mb_n = 0$——但 $a_m,b_n\neq0$，與 $R$ 無零因子矛盾 [▶ 39:00](https://youtu.be/ybay3nyMQ28?t=2340)。

【口頭】[▶ 38:00](https://youtu.be/ybay3nyMQ28?t=2280)「我用了『**比較係數**』，這引出一個問題：對任意環，你**確定**可以這樣嗎？這需要**構造多項式**——之後會回來。答案是可以：比較係數是我們所謂『多項式』的**基本成分之一**。我們之後會把多項式構造成某種**序列**，多項式乘法就具體地用有限多個非零項的序列相乘來建模。我想在 Dummit & Foote 第 9 章。」

## 9. 群環

[▶ 39:30](https://youtu.be/ybay3nyMQ28?t=2370)「**群環是今天我最愛的東西**。我想你們沒見過，所以是個真正的新例子。而且不只是一個例子——它產生**一大堆**例子。它需要一些可能會**偷襲你**的想法。」

> **定義（群環 group ring）**（D&F §7.2；講義 p.9）[▶ 40:00](https://youtu.be/ybay3nyMQ28?t=2400)　$G = \{g_1,\dots,g_n\}$ 有限群，$R$ 是 $1\neq0$ 的交換環。
> $$RG = \{a_1g_1+a_2g_2+\cdots+a_ng_n : a_i\in R\}$$
> （環元素對群元素的**形式線性組合**；若 $g_1 = e$ 可寫成 $a_1+a_2g_2+\cdots$）。
> - **加法**：對應係數相加，$\sum a_ig_i+\sum b_ig_i = \sum(a_i+b_i)g_i$。
> - **乘法**：照**分配律**乘開，$(ag_i)(bg_j) = ab\,g_k$，其中 $g_ig_j = g_k$。

【口頭】[▶ 41:00](https://youtu.be/ybay3nyMQ28?t=2460)「就像平常那樣乘——我通常這樣告訴學生。但**小心**：群可能不交換，$g_1g_2$ 不一定是 $g_2g_1$。誰知道它們是什麼？我**知道** $g_3g_5$ 是某個 $g$，因為是有限群。」「$n$ 個乘 $n$ 個——**$n^2$ 項**，哇。」

> **定理**　$RG$ 對上述加法、乘法是**環**；$RG$ 交換 $\iff$ $G$ 交換。

「我們假設係數環 $R$ 交換。原則上也可以用非交換環造群環，但我們不做——我們把交換性**烤進蛋糕裡**了。」

**$R = \mathbb{R}$ 時**[▶ 43:00](https://youtu.be/ybay3nyMQ28?t=2580)「我最感興趣的是實數，因為**我喜歡保持真實（keep it real）**。」
$$\mathbb{R}G = g_1\mathbb{R}\oplus\cdots\oplus g_n\mathbb{R}\cong\mathbb{R}^n,\quad g_j\leftrightarrow e_j.$$
- 所以 $\{g_1,\dots,g_n\}$ 在 $\mathbb{R}G$ 中**線性獨立**——「這就是**形式和**的意思的一部分：群元素之間**沒有相依**。如果你想的那個群原本就實現在某個有相依的東西裡，就會出問題——等一下有個例子。」

> **定理**（講義 p.10）[▶ 44:30](https://youtu.be/ybay3nyMQ28?t=2670)　$|G|>1$ ⇒ $RG$ **有零因子**。

**證明**：取 $g$，階 $m>1$。
$$(1-g)(1+g+\cdots+g^{m-1}) = 1-g^m = 1-1 = 0.$$
（交錯相消，像望遠鏡。）$1-g\neq0$（$g\neq1$）；$1+g+\cdots+g^{m-1}\neq0$——說它是 0 就是說 $1,g,\dots$ 線性相依，但構造上群元素獨立。所以 $1-g$ 是零因子。$\blacksquare$「**很酷**。」

**例**（講義 p.10）[▶ 46:00](https://youtu.be/ybay3nyMQ28?t=2760)
1. $\mathbb{Z}G$：**整群環**；$\mathbb{Q}G$：**有理群環**。
2. **雙曲數（hyperbolic numbers）**[▶ 46:30](https://youtu.be/ybay3nyMQ28?t=2790)「我最愛的例子之一」：$G = \{1,j\}$，$j^2 = 1$。
$$\mathbb{R}G = \{a+bj : a,b\in\mathbb{R}\}.$$
   $(1+j)(1-j) = 1-j^2 = 0$ ⇒ 零因子，「正如定理所說」。
3. **$\mathbb{R}Q_8\neq\mathbb{H}$**[▶ 47:00](https://youtu.be/ybay3nyMQ28?t=2820)「記號可能偷襲你的例子」：$Q_8 = \{\pm1,\pm i,\pm j,\pm k\}$（乘法群，是四元數的離散子群）。
   - $\mathbb{R}Q_8$ **不可能**是四元數：四元數沒有零因子（有反元素公式），而 $\mathbb{R}Q_8$ 由定理有零因子。
   - 原因：在 $\mathbb{R}Q_8$ 裡，**$1$ 和 $-1$ 線性獨立**，$i$ 和 $-i$ 線性獨立……。在四元數本身裡它們**顯然不是**。「它們只在你取**形式和**的意義下獨立。所以形式和這語言要小心——它就是它的意思。」

**結尾**[▶ 48:30](https://youtu.be/ybay3nyMQ28?t=2910)：「享受雪吧。希望週三能回來——**這比當面教你們花的時間長多了**。謝謝。」

## 10. 一頁速查表

### 10.1 定義

| 名詞 | 定義 |
|---|---|
| 環 | $(R,+)$ 交換群、乘法結合、分配律（D&F：不必有 1） |
| rng | 沒有 1 的「環」（有些書的用法） |
| 除環 | 有 $1\neq0$，非零元素都可逆 |
| 體 | 交換除環 |
| 零因子 | $a\neq0$，有 $b\neq0$ 使 $ab = 0$ 或 $ba = 0$ |
| 單位 | $uv = vu = 1$；集合 $R^\times = U(R)$ |
| 整環 | $1\neq0$ 的交換環，無零因子 |
| 子環判別法 | $a-b,\ ab\in S$ |
| 群環 $RG$ | $\sum a_ig_i$，$(ag_i)(bg_j) = ab\,g_ig_j$ |

### 10.2 定理

| 定理 | 證明關鍵一步 |
|---|---|
| 整環消去律 | $a(b-c) = 0$ |
| 零因子 ≠ 單位 | 乘 $a^{-1}$ ⇒ $b = 0$ |
| 有限整環是體 | $x\mapsto ax$ 單射 ⇒ 滿射 ⇒ $ax = 1$ |
| $S[x]\le R[x]$ | 積的係數 $\sum a_kb_{n-k}\in S$ |
| $R$ 整環 ⇒ $\deg(pq) = \deg p+\deg q$ | 領導係數 $a_mb_n\neq0$ |
| $R[x]^\times = R^\times$ | 比較係數 |
| $R$ 整環 ⇒ $R[x]$ 整環 | 領導係數 |
| $A$ 可逆 $\iff\det A\in R^\times$ | 古典伴隨公式 |
| $\lvert G\rvert>1$ ⇒ $RG$ 有零因子 | $(1-g)(1+g+\cdots+g^{m-1}) = 0$ |

## 附：本集一句話總結

> **環是加法交換群加上結合的乘法和分配律（Dummit & Foote 不要求有 1，所以 $2\mathbb{Z}_6$ 這種「子環的單位元是 4」的怪事要小心）；整環沒有零因子，所以有消去律，有限整環用左乘映射是雙射就證出是體；整環上的多項式環還是整環（領導係數相乘不為零），單位就是常數單位；而群環 $RG$ 是群元素的形式線性組合，只要群不平凡就有零因子 $(1-g)(1+g+\cdots+g^{m-1}) = 0$——所以 $\mathbb{R}Q_8$ 不是四元數。**
