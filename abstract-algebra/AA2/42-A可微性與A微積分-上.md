# 第 42 集 · $\mathcal{A}$-可微性、$\mathcal{A}$-微積分的一些結果 [▶ 影片](https://www.youtube.com/watch?v=9ikAAELnUe0&list=PLBY4G2o7DhF1x_afv1rv_d0hFCoMWEb-j)

← 上一集：[[41-A可微性與A微積分-下]] ｜ [總目錄](../README.md) ｜ 下一集：[[43-複習-BossFight3-下]] →

## 本集概要

最後一堂新內容：老師自己的研究——**結合代數上的微積分**。
- **$\mathcal{A}$-可微**：實可微 + 微分落在正則表示裡。$J_f$ 的各欄由第一欄生成：$\partial_jf = (\partial_1f)\,e_j$——**廣義 Cauchy–Riemann 方程**；$f' = df_p(1)$。
- 文獻中常見的「刪去差商」定義（D2）vs. 老師的定義（D1）：D2 下連恆等函數都不可微；交換半單代數上兩者一致（Wedderburn）。
- 和、純量倍、乘積法則；**非交換時兩個可微函數的積可以不可微**（上三角 3×3 矩陣代數的例子，Robert Bryant 指點）。$(\zeta^n)' = n\zeta^{n-1}$。
- 起源：學生 Min 想分解三維 Laplace 算子；**共軛變數**、Wirtinger 微積分；代數方程 ↔ 偏微分方程（$i^2+1 = 0$ ↔ Laplace 方程、$j^2 = 1$ ↔ 波方程）；用代數推出 **d'Alembert 解**。
- 把非線性 PDE 系統寫成代數上的 ODE；$\mathcal{A}$-積分與微積分基本定理。結尾在第 41 集。

> 📘 講義對應：老師的 $\mathcal{A}$-微積分論文（未發表部分）、與 Lopez Gonzalez 的合作、Waterhouse (1992)。

## 筆記

### 1. 實可微回顧 [▶ 01:00](https://youtu.be/9ikAAELnUe0?t=60)

（再講代數結構怕不小心解了作業，所以改講微積分。）

$\mathcal{A}$ 作為點集是 $\mathbb{R}^n$，$f:\mathcal{A}\to\mathcal{A}$ 也是 $\mathbb{R}^n\to\mathbb{R}^n$。
- **微分** $df_p(h) = J_f(p)h$：在 $p$ 點變化量的最佳線性近似；$J_f(p) = [\partial_1f(p)\,|\cdots|\,\partial_nf(p)]$ 是它的標準矩陣。
- **Fréchet（實）可微**：$\displaystyle\lim_{h\to0}\frac{f(p+h)-f(p)-df_p(h)}{\|h\|} = 0$ [▶ 04:00](https://youtu.be/9ikAAELnUe0?t=240)。
- （學生把兩支不同顏色的馬克筆蓋子互換——「我喜歡」。）

### 2. $\mathcal{A}$-可微 [▶ 05:30](https://youtu.be/9ikAAELnUe0?t=330)

> **定義**：$f:\mathcal{A}\to\mathcal{A}$ 在 $p$ **$\mathcal{A}$-可微**，若 $f$ 在 $p$ 實可微，且 $df_p\in\mathcal{R}_\mathcal{A}$（正則表示，第 40 集）。

- 對比：一般 $\mathbb{R}^n\to\mathbb{R}^n$ 的導數是 $n$ 個彼此無關的偏導數，不再是一個函數；但微積分一裡 $f:\mathbb{R}\to\mathbb{R}$ 的導數還是一個函數。$\mathcal{A}$-可微讓導數又能成為一個函數 [▶ 06:30](https://youtu.be/9ikAAELnUe0?t=390)。
- $df_p(v\star w) = df_p(v)\star w$。取 $e_1 = 1$（本講假設），$df_p(e_j) = \partial_jf(p)$，所以
$$\partial_jf(p) = df_p(1\star e_j) = df_p(1)\star e_j = \partial_1f(p)\star e_j.$$
  $J_f$ 的各欄**都由第一欄生成**——$J_f$ 就是 $\partial_1f$ 的矩陣表示 [▶ 09:30](https://youtu.be/9ikAAELnUe0?t=570)。
- 對複數這就是上次的 **Cauchy–Riemann 方程**；一般代數叫**廣義 Cauchy–Riemann 方程**。
- **導數** $f'(p) := df_p(1)$ [▶ 14:30](https://youtu.be/9ikAAELnUe0?t=870)。

### 3. 兩種定義 [▶ 10:30](https://youtu.be/9ikAAELnUe0?t=630)

微積分一用差商 $\lim\frac{f(p+h)-f(p)}h$。代數裡的問題：**零因子**（例如雙曲數中 $1\pm j$ 的生成線）不能除。
- 很多論文（「大概一百年前就有」）用**刪去差商**：只讓 $h$ 取單位趨近 0。老師稱它 **D2**；他自己的定義是 **D1**。
- **D2 不蘊含 D1** [▶ 18:30](https://youtu.be/9ikAAELnUe0?t=1110)：Dirichlet 式的函數——單位上取 0、非零零因子上取 1。差商恆為 0，D2 可微、導數 0；但不連續，所以不實可微，不是 D1。
- 老師的定理（7.x）：若 $f$ 在開集 $U$ 上處處 D2，則在 $U$ 上 D1 [▶ 21:30](https://youtu.be/9ikAAELnUe0?t=1290)。
- **反方向會壞**：對偶數（null numbers，$\epsilon^2 = 0$），**恆等函數**處處不是 D2——「如果恆等函數不可微，大概不是好定義」；但它是 D1 的 [▶ 22:30](https://youtu.be/9ikAAELnUe0?t=1350)。
- 「D2 的好處是對初學者熟悉，不用拖進高等微積分和 Jacobian；代價是它是個壞定義。」
- **定理**：在**交換、半單、有限維實代數**的開集上，D1 函數 = D2 函數。證明用 **Wedderburn 定理**：這種代數同構於 $\mathbb{R}^n\times\mathbb{C}^m$，逐分量檢查 [▶ 25:00](https://youtu.be/9ikAAELnUe0?t=1500)。這涵蓋作業中除了偶數以外的例子；偶數有冪零元（非平凡 **Jacobson 根**），不是半單的（「別讓我定義它」）。
- （投影機一直歪：「我需要一台懸浮在教室裡的投影無人機。」）

### 4. 微分法則 [▶ 27:00](https://youtu.be/9ikAAELnUe0?t=1620)

- 和與 $\mathcal{A}$-純量倍：$(f+g)' = f'+g'$、$(cf)' = cf'$——因為正則表示是子空間（其實是 $\mathcal{A}$-子模）。
- **乘積法則**：$f,g$ $\mathcal{A}$-可微時 $(fg)' = f'g+fg'$——**$\mathcal{A}$ 交換時**成立。證明裡 $w$ 要能越過 $g$ 才能提出來；不交換就卡住 [▶ 30:00](https://youtu.be/9ikAAELnUe0?t=1800)。
- **非交換反例** [▶ 32:30](https://youtu.be/9ikAAELnUe0?t=1950)：$\mathcal{A} = \mathbb{R}^6$，乘法來自 3×3 **上三角矩陣**（第一列放 3 個、第二列 2 個、第三列 1 個）。有 $f,g$ 都 $\mathcal{A}$-可微，$fg = g$ 可微，但 $gf$ 的 Jacobian 在 $(2,6)$ 位置非零，不在正則表示裡，**不可微**。原因：上三角矩陣的中心……零化一切的元素。
  - 是 **Robert Bryant** 告訴他去找這種例子的——70 年代初在 NC State 念大學，老師的指導教授說他「在黑板寫完全錯的證明，然後『這樣呢？』寫出漂亮又完全正確的」；在 MathOverflow 回答了上百人的技術問題，非常慷慨（「兩個名字都像名字」）。
  - 老師在墨西哥的合作者 Lopez Gonzalez 用左右混合的定義處理非交換情形，也許能避開這個問題。
- $(\zeta^n)' = n\zeta^{n-1}$；也有連鎖律；同構的代數之間，可微函數可以透過同構互相轉換 [▶ 36:30](https://youtu.be/9ikAAELnUe0?t=2190)。

### 5. 起源：分解 Laplace 算子 [▶ 37:30](https://youtu.be/9ikAAELnUe0?t=2250)

- 2011 年學生 **Min** 想在夏天寫線性代數論文——老師說他不做線代研究，就一起看他的博士論文（超數學）。途中讀到一篇蘇聯時期的俄文短論文（作者大概是 Volikov），四頁全是結論，談代數上的可微性。老師的論文就是超數上的可微：實可微 + 微分是「超線性」的；有限維版本「是個快樂的地方」。
- Min 的問題：複變中 $\partial_x^2+\partial_y^2 = 4\partial_z\partial_{\bar z}$——怎麼分解**三維** Laplace 算子 $\partial_x^2+\partial_y^2+\partial_z^2$？答案：不行。但嘗試的過程導出了 $\mathcal{A}$-微積分。後來明白：三維以上的代數需要**多個共軛**，不只一個 [▶ 40:00](https://youtu.be/9ikAAELnUe0?t=2400)。
- 這部分還沒發表（「我不知道去哪發表蠢東西」）。學生願意幫忙找錯——一個實際錯誤一塊錢；「複數錯誤付虛數錢」——「但所有錢都是虛的」[▶ 40:30](https://youtu.be/9ikAAELnUe0?t=2430)。

### 6. 共軛變數與廣義 Cauchy–Riemann [▶ 42:00](https://youtu.be/9ikAAELnUe0?t=2520)

- 取可逆基底，$v_1 = 1$。**第 $j$ 個共軛** $\bar\zeta^{(j)}$ = 變數減去兩倍的 $v_j$ 分量（複數時 $\bar z = x+iy-2iy$）。
- $\partial_z = \frac12(\partial_x-i\partial_y)$、$\partial_{\bar z} = \frac12(\partial_x+i\partial_y)$，$4\partial_z\partial_{\bar z} = \Delta$——**Wirtinger 微積分**（「名字我大概唸錯」）。
- 推廣後：$\partial\zeta/\partial\zeta = 1$、共軛對自己的導數 1、交叉偏導數 0——「我希望一組獨立變數該滿足的形式微積分」。$1_\mathcal{A}$ 寫成 $\mathbb{1}$ 以區分實數 1 [▶ 44:00](https://youtu.be/9ikAAELnUe0?t=2640)。
- 複變中：$f$ 全純 $\iff\partial f/\partial\bar z = 0$（$f$ 只是 $z$ 的函數）。（「Daniel 摀住耳朵，你還沒修複變。」）
- **Thm 6.6**（交換情形）：$f$ 是 $\mathcal{A}$-可微 $\iff$ 對所有共軛變數的導數都是 0。用**結構常數** $v_iv_j = \sum_kC_{ij}^kv_k$ 也能寫出廣義 Cauchy–Riemann 方程 [▶ 46:30](https://youtu.be/9ikAAELnUe0?t=2790)。
- 三重雙曲數上相應的算子乘起來沒什麼好結果——不是一個 Laplace 方程，而是一整組。

### 7. 代數方程 ↔ 偏微分方程 [▶ 49:00](https://youtu.be/9ikAAELnUe0?t=2940)

- 高階導數：$\partial_{i_1}\cdots\partial_{i_k}f = (\partial_1^kf)\star v_{i_1}\cdots v_{i_k}$——**偏微分變成代數乘法**。
- 所以代數中的關係 $\sum b_{ij}v_iv_j = 0$ 給出每個 $\mathcal{A}$-可微函數都滿足的 PDE $\sum b_{ij}\partial_i\partial_jf = 0$：
  - 複數：$i^2+1 = 0$ ⇒ $f_{yy}+f_{xx} = 0$——全純函數的分量滿足 **Laplace 方程**。
  - 雙曲數：$j^2-1 = 0$ ⇒ $f_{yy}-f_{xx} = 0$——一維**波方程** [▶ 50:30](https://youtu.be/9ikAAELnUe0?t=3030)。
- **d'Alembert 解** [▶ 51:30](https://youtu.be/9ikAAELnUe0?t=3090)：波方程 $c^2u_{xx} = u_{tt}$。取代數 $W_c = \mathbb{R}\oplus k\mathbb{R}$，$k^2 = c^2$。$W_c\cong$ 雙曲數（重新縮放 $jt\leftrightarrow cjt$）$\cong\mathbb{R}\times\mathbb{R}$（第 6 集的同構）。$\mathbb{R}\times\mathbb{R}$-可微函數就是 $(F(u),G(v))$——各自只依賴一個變數。透過同構轉回去得到
$$u(x,t) = F(x-ct)+G(x+ct),$$
  左行波 + 右行波。Waterhouse（1992）也有，但老師覺得自己的推法簡單得多。也有多變數 Taylor 定理。

### 8. 非線性 PDE 與積分 [▶ 54:00](https://youtu.be/9ikAAELnUe0?t=3240)

- 雙曲數上 $\frac{dw}{dz} = w^2$，$w = u+jv$，展開成非線性系統 $u_x = u^2+v^2$、$v_x = 2uv$。在代數上分離變數、積分就解出來，再取「實部」和「j 虛部」（jaginary——「我說了」）。
- 還有用張量積的 **tableau**，老師證明它也延伸到 $\mathcal{A}$-微積分（「沒人在乎，我在乎」）。
- **開放問題**：給一個 PDE 系統，什麼時候能改寫成代數上的 ODE（系統）？老師與 Oelli 在平面上一大類代數有部分答案（論文貼在辦公室門外）[▶ 56:30](https://youtu.be/9ikAAELnUe0?t=3390)。
- **$\mathcal{A}$-積分**：像 Riemann 和但沒有標記分割，$\sum f(\zeta_i)\Delta\zeta_i$（乘法在代數中做）的極限；曲線**可求長**時沒問題。參數化後 $\int_Cf\,d\zeta = \int f(\gamma(t))\star\gamma'(t)\,dt$——就是線積分、也就是複變的定義。有 FTC2，也（「受了點苦」之後）有 FTC1 [▶ 57:30](https://youtu.be/9ikAAELnUe0?t=3450)。
- 最後談另一篇微分方程論文：雙曲數中 $e^{jz} = \frac12(1+j)e^z+\frac12(1-j)e^{-z}$……（「Jay-Z」——接第 41 集）。
