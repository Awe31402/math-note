# 隨堂筆記製作規則

這裡只放**所有課都通用**的規則。每門課自己的細節（講者、逐字稿路徑、講義與課本、檔名規則、進度檔）放在該課資料夾的 `BRIEF.md`，那份優先。

## 流程

1. **讀 BRIEF**：讀該課的 `BRIEF.md` 和進度檔（例如 `進度.md`）。沒有 BRIEF → 先用 `define-task` 和使用者一起建一份，存成該課資料夾的 `BRIEF.md`，再往下做。
2. **交大綱**：列出目錄，每節一行。使用者確認 OK 才寫全文。
3. **樣品**：新課或新類型（例如第一次碰到習題課）先只做一集當樣品，確認後才批次做。
4. **寫全文**：照 [TEMPLATE.md](TEMPLATE.md) 的結構寫，套用下面所有規則。
5. **收尾**：更新進度檔（狀態、待確認數）。commit、push 等使用者開口。

做完的標準：結構每一段都在、每個標記都有依據、每條待確認都列進清單、進度檔已更新。

## 資料來源

1. **主要**：該集逐字稿。筆記骨架照影片順序。
2. **次要**：講義或課本（BRIEF 指定），補定義、定理、證明、例子。
3. **舊筆記**：只拿來找待確認項，事實一律回逐字稿和講義查。
4. **只用** BRIEF 列出的來源，網路上別人的筆記和文章不用。
5. **查不到 → 寫「待補」**，留空比編一個像樣的答案好。
6. **來源衝突 → 兩邊都寫**，標明出處。

## 內容

- **讀者**：會基本數學但沒學過這門課（BRIEF 可改）。數學步驟一步一步寫，證明寫完整。
- **語言**：繁體中文；術語第一次出現附英文。
- **範圍**：只寫這一集講到的；最後一節可列「後面哪一集會用到」。
- **改寫**：用自己的話寫，定義和公式可照用原文。
- **Q&A**：只寫逐字稿裡真的有的學生提問。
- **習題課、答疑課**：只寫課堂上真的解過的題，結構是「題目＋解法」。
- **速查表**：放公式、定理，**加上證明或推導的關鍵一步**，不只列名詞。

## 標記

開頭的「標記說明」只列本集有用到的。

| 標記 | 意思 |
|---|---|
| `【口頭】` | 講者口頭補充、講義和課本沒有 |
| `【Q&A】` | 學生主動提問與回答 |
| `【課堂討論】` | 講者問、學生答 |
| `【<次要來源>補充】` | 次要來源有、課堂沒講。名字照 BRIEF，例如 `【課本補充】`、`【講義補充】` |
| `⚠️ 逐字稿缺字` | 字幕聽錯或掉字，依次要來源補；寫出原字幕和修正 |
| `⚠️ 待確認` | 查不清楚的地方；同時列進筆記最後的「⚠️ 待確認清單」 |
| `[▶ mm:ss](https://youtu.be/ID?t=秒)` | 可點的影片時間點 |

**推論的內容**：逐字稿沒有答案、是 Claude 自己推出來的，要先寫明「以下**不是逐字稿內容**，是依 ○○ 推論的」，再寫答案。

**待確認項**：查清楚才能刪；刪了要同步更新進度檔的待確認數。

## 數學語法（Typst 相容）

筆記之後會轉成 Typst，所以：

- 模運算寫 `\ (\mathrm{mod}\ n)`，例如 `a\equiv b\ (\mathrm{mod}\ n)`。
- 可伸縮括號寫 `\left( … \right)`、`\left[ … \right]`。
- `\bigcup`、`\bigcap`、`\bigoplus`、`\bigwedge` 這類大型運算子照常用。

## 事後補答

使用者讀完筆記又問問題時：

- 答案寫進**該集筆記的相關段落**，不另開檔案。
- 原本寫「待補」或 `⚠️` 的地方，補上答案後改寫那句說明，舊的「待補」字樣拿掉。
- 答案不是來自逐字稿 → 照上面「推論的內容」標明。
- 若解決了待確認項，同步更新待確認清單和進度檔。
