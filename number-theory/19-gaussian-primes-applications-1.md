## 1. 高斯質數整除乘積 ⇒ 整除其中一個

[▶ 00:32](https://youtu.be/TCiZSJDcOhs?t=32)

> **引理**（Conrad 6.5）：$\pi$ 是 $\mathbb{Z}[i]$ 的質數，$\alpha_1,\dots,\alpha_r\in\mathbb{Z}[i]$。若
> $$\pi\mid\alpha_1\alpha_2\cdots\alpha_r,$$
> 則 $\pi\mid\alpha_j$ 對某個 $j$ 成立。

（$\pi$ 在這裡是變數名稱，不是圓周率。）可能整除不只一個。

Conrad 在講義第 13 頁證兩個因數的情況，多個因數「是直接的歸納法」。

> 以下**不是逐字稿內容**，是補上兩個因數的證明想法（跟第 5 集整數的 Lemma 2.1(b) 一樣）：設 $\pi\mid\alpha\beta$、$\pi\nmid\alpha$。$\pi$ 是質數，它的因數只有單位和 $\pi$ 的相伴元，而 $\pi\nmid\alpha$，所以 $\pi,\alpha$ 的公因數只有單位——互質。由第 17 集推論 5.7，$\pi\mid\beta$。

## 2. 唯一分解（差單位、差順序）

[▶ 02:04](https://youtu.be/TCiZSJDcOhs?t=124)

**先看整數** [▶ 02:34](https://youtu.be/TCiZSJDcOhs?t=154)：若 $ab = cd$，$a,b,c,d$ 都是質數，能說 $a=c$ 或 $a=d$ 嗎？**不能**：$3\cdot 5 = (-3)(-5)$。

- 我們以前沒碰到這個麻煩，是因為**只看正的質因數**——「用權宜的方式只討論正整數，避開了這個模糊」。
- $-3 = (-1)\cdot 3$，差的是單位 $-1$。$\mathbb{Z}$ 的單位是 $\pm1$；$\mathbb{Z}[i]$ 的單位多了 $\pm i$。

**所以在 $\mathbb{Z}[i]$** [▶ 04:35](https://youtu.be/TCiZSJDcOhs?t=275)：若 $\pi_1\pi_2 = \pi_1'\pi_2'$（都是高斯質數），只能說：
- $\pi_1' = u_1\pi_1$、$\pi_2' = u_2\pi_2$，**或者**
- $\pi_1' = u_3\pi_2$、$\pi_2' = u_4\pi_1$，

其中 $u_j$ 是單位。要嘛對應、要嘛交叉，但都可能差一個單位。

**例子** [▶ 06:13](https://youtu.be/TCiZSJDcOhs?t=373)：$5 = 1^2+2^2$，所以
$$5 = (1+2i)(1-2i).$$
兩個因數範數都是 5（質數），所以都是高斯質數（第 18 集定理 6.3）。

【課堂討論】講者問怎麼證它們是質數，學生答：範數是質數。講者補充：反過來不成立，$N(3)=9$ 不是質數但 3 是高斯質數——「哎呀，我在解你們的作業了」。

**用一種有趣的方式乘以 1** [▶ 07:17](https://youtu.be/TCiZSJDcOhs?t=437)：第一個乘 $i$、第二個乘 $-i$（$i\cdot(-i) = 1$）：
$$5 = (1+2i)i\cdot(1-2i)(-i) = (-2+i)(-2-i).$$
「一個醜陋的分解，但仍然是分解成質數的乘積。」它跟原本的分解只差單位。

> **唯一分解定理**（Conrad 6.6）[▶ 08:25](https://youtu.be/TCiZSJDcOhs?t=505)：若
> $$\pi_1\pi_2\cdots\pi_r = \pi_1'\pi_2'\cdots\pi_s'$$
> （都是 $\mathbb{Z}[i]$ 的質數），則 $r=s$，而且重新編號後，每個 $\pi_i' = u_i\pi_i$（$u_i$ 是單位）。

【口頭】Lemma 6.5 和定理 6.6 的證明「跟整數幾乎是同一套」，只是要細分情況、對範數歸納。講者跳過，說在講義第 14–15 頁。

> 【課本補充】§10.2（p. 198）：**Euclid 整環**裡，每個非零非單位的元素都是不可約元素的冪的乘積，而且在「排列順序」和「換成相伴元」之外唯一。$R=\mathbb{Z}$ 時就是算術基本定理。課本說一般 Euclid 整環的證明「非常類似」，省略。$\mathbb{Z}[i]$ 是 Euclid 整環（第 15 集），所以有唯一分解。

## 3. 怎麼分解：3 + 4i

[▶ 09:27](https://youtu.be/TCiZSJDcOhs?t=567)

講者：「我不知道一般的健全理論，Conrad 只給一些小提示，我照他的做。」

**Step 1：用範數縮小範圍** [▶ 10:28](https://youtu.be/TCiZSJDcOhs?t=628)

若 $3+4i = \gamma\delta$，則 $N(\gamma)N(\delta) = N(3+4i) = 9+16 = 25 = 5^2$。非平凡分解需要 $N(\gamma) = N(\delta) = 5$。

**Step 2：列出範數 5 的高斯整數** [▶ 11:32](https://youtu.be/TCiZSJDcOhs?t=692)

$a^2+b^2 = 5$：$|a|,|b|$ 是 $1,2$ 的某種排列。

【課堂討論】學生答：$1+2i$、$2+i$。講者補上正負號。完整清單是 8 個：
$$\pm1\pm2i,\qquad\pm2\pm i.$$
（講者列的時候漏了幾個，又說「乘 $i$ 會繞回來」「我出了名的不會組合計數，別信我，自己想」。）

**Step 3：試** [▶ 14:12](https://youtu.be/TCiZSJDcOhs?t=852)

講者和學生試了幾組都不對：

- $(1+2i)(1-2i) = 5$——「這是 5，我是笨蛋」。
- $(2-i)(1+2i) = 4+3i$——「我們剛剛分解了 $4+3i$，這是你的一根羽毛」，但不是 $3+4i$。
- $(-2+i)(\dots)$ 得到 $-5$——「恭喜你分解了 $-5$」。

**關鍵** [▶ 17:31](https://youtu.be/TCiZSJDcOhs?t=1051)：「兩個因數一定要不同嗎？」試**平方**：
$$(1-2i)^2 = 1-4i+4i^2 = -3-4i.$$
差一個負號，所以
$$3+4i = -(1-2i)^2 = (-1+2i)(1-2i).$$

> 以下**不是逐字稿內容**，是補一個更乾淨的寫法：$(2+i)^2 = 4+4i+i^2 = 3+4i$。而 $2+i = i(1-2i)$，跟上面只差單位，符合唯一分解。

**實務** [▶ 19:06](https://youtu.be/TCiZSJDcOhs?t=1146)：「即使這麼簡單的數，要分解也滿痛苦的。」講者寄了一個**會分解高斯整數的網站**給大家，「一週前才更新的」。但它只說給你「一個分解」，**不保證**是質數分解。

【口頭】Conrad 第 15 頁還有一個更難的例子（Conrad 承認他不是手算的），跳過。第 7 節**高斯整數的模運算**也跳過——Conrad 在那裡證了 Fermat 小定理等基本結果的高斯整數版。講者說進入環論後可能會回來看。

## 4. 應用的核心：a² + b² = (a + bi)(a − bi)

[▶ 20:45](https://youtu.be/TCiZSJDcOhs?t=1245)

講者：這一節的**核心公式**就是
$$a^2+b^2 = (a+bi)(a-bi).$$
「看起來是小事，但其實不是。」接下來會看到：

1. 質數寫成兩平方和，**本質上只有一種寫法**。
2. **本原畢氏三元數組**的分類。
3. $a^2+b^2 = c^3$ 的本原解的分類。
4. $y^2 = x^3-1$ 的整數解**只有** $(1,0)$——數論的古老結果。
5. 有系統地造出**有好幾種兩平方和寫法**的整數。

## 5. 質數寫成兩平方和，本質上只有一種寫法

[▶ 22:22](https://youtu.be/TCiZSJDcOhs?t=1342)

> **定理**（Conrad 8.1）：若質數 $p$ 是兩平方和，則寫法**本質上唯一**：$p = a^2+b^2$ 的 $a,b$ 在「交換順序」和「改正負號」之外是唯一的。

**「本質上唯一」的意思** [▶ 23:25](https://youtu.be/TCiZSJDcOhs?t=1405)：
$$5 = 1^2+2^2 = 2^2+1^2 = (-1)^2+(-2)^2 = (-2)^2+(-1)^2 = \cdots$$
這些都算同一種，「就這樣」。

**證明** [▶ 24:35](https://youtu.be/TCiZSJDcOhs?t=1475)

1. $p = a^2+b^2 = (a+bi)(a-bi)$。所以 $p$ 在 $\mathbb{Z}[i]$ 裡是**合數**。
2. 取範數：$N(p) = p^2 = N(a+bi)\,N(a-bi)$。兩個範數都 $>1$（否則是平凡分解），由整數的唯一分解，$N(a\pm bi) = p$。
3. $p$ 是質數，所以 $a\pm bi$ 是高斯質數（定理 6.3）。
4. **假設還有另一種寫法** [▶ 26:05](https://youtu.be/TCiZSJDcOhs?t=1565)：$p = c^2+d^2 = (c+di)(c-di)$，同理 $c\pm di$ 也是高斯質數。
5. 於是 $p$ 有兩個質數分解：
   $$(a+bi)(a-bi) = (c+di)(c-di).$$
6. 由唯一分解 [▶ 27:12](https://youtu.be/TCiZSJDcOhs?t=1632)，要嘛
   - $a+bi = u_1(c+di)$、$a-bi = u_2(c-di)$，要嘛
   - $a+bi = u_3(c-di)$、$a-bi = u_4(c+di)$。
7. $u_j\in\{\pm1,\pm i\}$。逐一檢查 [▶ 28:13](https://youtu.be/TCiZSJDcOhs?t=1693)。例如 $u_1 = i$：$i(c+di) = -d+ci$，所以 $a = -d$、$b = c$——**同樣的數，交換順序、改正負號**。
8. 每種情況都是：$u=\pm1$ 時 $a,b$ 對應 $c,d$（可能差正負）；$u=\pm i$ 時交換。∎

【口頭】講者說寫出所有情況「不會有趣」，「希望我給你們看的夠讓人相信」。

【口頭】[▶ 29:43](https://youtu.be/TCiZSJDcOhs?t=1783) 講者說他喜歡這個證明，因為「不只是歸納法」。很多歸納法證明「證完了我除了證明本身沒得到什麼直覺」，線性代數也是；給一個**構造式**的證明，「也許我就得到一種計算方法。也許我就是個構造主義者。」

## 6. Fermat 數 F₅：兩種寫法 ⇒ 不是質數

[▶ 30:43](https://youtu.be/TCiZSJDcOhs?t=1843)（Conrad Example 8.2）

**定理 8.1 的逆否**：如果一個數能用**兩種本質上不同的方式**寫成兩平方和，它就**不是質數**。

$F_5 = 2^{2^5}+1 = 2^{32}+1 = 4294967297$（第 6 集）。

- 一種寫法：$2^{32} = (2^{16})^2$，所以 $F_5 = (2^{16})^2+1^2$。
- **Euler** 找到另一種：
  $$F_5 = 62264^2+20449^2.$$

所以 $F_5$ 不是質數。Euler 確實發現 $F_5 = 641\times 6700417$（第 6 集）。

⚠️ 逐字稿缺字：講者先講 $F_5$ 是 $(2^{16})^2+1^2$，接著改說「第六個 Fermat 數 $2^{2^6}+1$」，再講 Euler 的 $62264^2+20449^2$ 和 $641\times6700417$。依數字，這些全是 **$F_5$**：$62264^2+20449^2 = 4294967297 = 2^{32}+1 = 641\times 6700417$（已驗算）。講者還說「你可以證明 $F_5$ 是質數」，這是口誤——$F_5$ 不是質數。

【口頭】「Euler 一定買了很多計算機電池吧？當然不對，他們沒有計算機，他們有的是**時間**，還有**沒有網路**。Euler 是特別的人。」

## 7. 本原畢氏三元數組

[▶ 33:59](https://youtu.be/TCiZSJDcOhs?t=2039)

> **定理**（Conrad 8.3）：每組**本原**畢氏三元數組 $(a,b,c)$（$a,b,c$ 沒有公因數），設 $a$ 是奇數，都可以寫成
> $$a = m^2-n^2,\qquad b = 2mn,\qquad c = m^2+n^2,$$
> 其中 $m>n>0$ 互質、$m\not\equiv n\ (\mathrm{mod}\ 2)$。反過來，每組這樣的 $m,n$ 都給出本原三元數組，不同的 $m,n$ 給出不同的三元數組。

（Conrad 前一頁論證 $a,b$ 至少一個是奇數，所以「設 $a$ 奇」只是命名。）

講者：「我們以前看過，但之前只是**宣稱**，這裡給了證明。」

- **反方向**（公式給出三元數組）是作業題，代進去驗算（第 1 集）。
- **每組都長這樣**是新的。

**證明大意** [▶ 37:16](https://youtu.be/TCiZSJDcOhs?t=2236)（講者說省略很多細節，在 Conrad 第 26–27 頁）：

1. $a$ 奇、$b$ 偶、$c$ 奇。分解：
   $$(a+bi)(a-bi) = c^2.$$
2. 可以證 $a+bi$ 和 $a-bi$ **互質**（第 26 頁）。
3. **互質的兩個數乘起來是平方** ⇒ 由唯一分解，**每個都是平方乘一個單位**（第 5 集 Lemma 2.4 的高斯整數版）[▶ 39:45](https://youtu.be/TCiZSJDcOhs?t=2385)：
   $$a+bi = u\,(m+ni)^2.$$
4. 單位的處理 [▶ 40:46](https://youtu.be/TCiZSJDcOhs?t=2446)：$u=1$ 沒事；$u=-1 = i^2$ 可以吸進平方裡、重新命名 $m,n$；$u=\pm i$ 要另外排除（第 27 頁）。所以可以設
   $$a+bi = (m+ni)^2 = (m^2-n^2) + 2mn\,i.$$
5. 比較實部、虛部：$a = m^2-n^2$、$b = 2mn$。再驗 $a^2+b^2 = (m^2+n^2)^2$，所以 $c = m^2+n^2$。

**講者的整數例子**（說明第 3 步）[▶ 39:45](https://youtu.be/TCiZSJDcOhs?t=2385)：$900 = 30^2 = 100\times 9 = 10^2\times 3^2$。互質的因數乘起來是平方，每個因數就得是平方（它們不必是質數）。

（第 2 集講者說「用高斯整數會簡單得多」——就是指這個。）

> 【課本補充】§11.5 Theorem 11.3（p. 223）陳述同一個定理，但用的是**整數的因數分解**證法：$b$ 偶，$\left(\frac b2\right)^2 = \frac{c+a}2\cdot\frac{c-a}2$，兩個因數互質，所以各是平方（見[第 1 集 2.2 節](01-history-of-numbers.md#22-euclid-的公式)）。比較：課本在 $\mathbb{Z}$ 裡分解 $c^2-a^2$，這裡在 $\mathbb{Z}[i]$ 裡分解 $a^2+b^2$。

## 8. a² + b² = c³

[▶ 43:31](https://youtu.be/TCiZSJDcOhs?t=2611)

> **定理**（Conrad 8.4）：$a^2+b^2 = c^3$、$a,b$ 互質，則（對某些整數 $m,n$）
> $$a = m^3-3mn^2,\qquad b = 3m^2n-n^3,\qquad c = m^2+n^2.$$

講者說他「把細節粉刷掉，直接講重點」。

**證明大意** [▶ 44:04](https://youtu.be/TCiZSJDcOhs?t=2644)：

1. $(a+bi)(a-bi) = c^3$，兩個因數互質。
2. 由唯一分解，$a+bi = u\,(m+ni)^3$。
3. **立方比平方簡單**：**每個單位都是立方** [▶ 44:35](https://youtu.be/TCiZSJDcOhs?t=2675)：
   $$1 = 1^3,\quad -1 = (-1)^3,\quad i = (-i)^3,\quad -i = i^3.$$
   所以 $u$ 可以吸進立方裡、重新命名。可設 $a+bi = (m+ni)^3$。
4. 展開 [▶ 46:13](https://youtu.be/TCiZSJDcOhs?t=2773)：
   $$(m+ni)^3 = (m^3-3mn^2) + (3m^2n-n^3)\,i.$$
5. 實部、虛部就是 $a,b$。可驗 $a^2+b^2 = (m^2+n^2)^3$。

（$i = (-i)^3$：【課堂討論】學生答出來，因為 $(-i)^3 = -i^3 = -(-i) = i$。）

**歷史** [▶ 47:19](https://youtu.be/TCiZSJDcOhs?t=2839)：

- 【口頭】「把平方和拆成高斯整數的乘積，這想法太聰明了。」
- **Euler 那個時代的漏洞**：他們**還沒證明唯一分解**，就假設它在這些數裡成立。下一集會看到：**超出高斯整數之後，唯一分解會失敗**。「他們把房子蓋在沙上。」
- 講者說 **Gauss** 知道這一點，所以在《算術研究》裡**不用**這些方法，改用技術性的同餘論證，「因為他不信任它們——在證明某些事之前它們本來就不可信」。講者說那是 Gauss「19 歲時、1801 年」寫的書。
- 【口頭】「如果你想對自己的數學成就感覺良好，別花太多時間研究 Gauss，除非你是世上大約 10 個人之一。」

（講者在第 1 集說《算術研究》時 Gauss 21 歲，這裡說 19 歲。以下**不是逐字稿內容**：Gauss 生於 1777 年，1801 年是 24 歲；第 1 集講者說的 1798 年完成時是 21 歲。）

## 9. y² = x³ − 1 只有 (1, 0)

[▶ 48:21](https://youtu.be/TCiZSJDcOhs?t=2901)

> **定理**（Conrad 8.5）：$y^2 = x^3-1$ 的整數解只有 $(x,y) = (1,0)$。

講者跳過證明，只講方法 [▶ 49:35](https://youtu.be/TCiZSJDcOhs?t=2975)（Conrad 第 29 頁）：

1. 改寫成 $x^3 = y^2+1 = (y+i)(y-i)$。
2. 證 $y+i$ 和 $y-i$ 互質。
3. 所以它們都是立方。
4. 逐一看可能的情況，「在故事某處推出矛盾」。

「其實跟前面三個定理是**同一招**。」

**趣聞** [▶ 50:06](https://youtu.be/TCiZSJDcOhs?t=3006)：**Lebesgue** 證明了 $y^2 = x^d-1$ 對所有 $d\ge 2$ **沒有** $x,y$ 都非零的解。（$(1,0)$ 的 $y=0$，不算。）

## 10. 造出有好幾種兩平方和寫法的數

[▶ 50:37](https://youtu.be/TCiZSJDcOhs?t=3037)（Conrad Remark 8.6，作業相關）

**例子：65** [▶ 51:08](https://youtu.be/TCiZSJDcOhs?t=3068)

$$5 = (1+2i)(1-2i),\qquad 13 = (2+3i)(2-3i),$$
所以
$$65 = (1+2i)(2+3i)(1-2i)(2-3i).$$

**把四個質因數用不同方式配對**：

- $(1+2i)(2+3i) = -4+7i$，它的共軛 $(1-2i)(2-3i) = -4-7i$。所以
  $$65 = (-4+7i)(-4-7i) = 4^2+7^2.$$
- $(1+2i)(2-3i) = 8+i$，共軛 $(1-2i)(2+3i) = 8-i$。所以
  $$65 = (8+i)(8-i) = 8^2+1^2.$$

（講者這段算錯了好幾次——漏了一個 2、把 $65$ 寫成 $65^2$、把 $8^2$ 寫成 $64^2$，「抱歉，我現在傳達任何東西的能力都在衰退」。上面是整理後的結果，已驗算。）

**原理** [▶ 57:00](https://youtu.be/TCiZSJDcOhs?t=3420)：把數字建成**很多個高斯質數的乘積**，然後**洗牌重新配對**，每種配對給出一種兩平方和寫法。（第 16 集講者說能控制做出 10 種寫法的數，就是這個方法。）

**作業提示** [▶ 57:30](https://youtu.be/TCiZSJDcOhs?t=3450)：Conrad 第 30 頁給了一個有**三種**寫法的數；作業要找**四種**的。「別重新發明輪子：在他的例子上再加一個因數。」（作業不做解答。）

## 11. 一頁速查表（含被切斷的 Lemma 9.1 開頭）

[▶ 58:31](https://youtu.be/TCiZSJDcOhs?t=3511) 最後講者開始講 Lemma 9.1：若 $\pi$ 是高斯質數，則 $\pi$ 整除某個正整數質數 $p$。Conrad 的提示：$\pi$ 一定整除某個正整數——它的範數 $N(\pi) = \pi\bar\pi$。（影片在這裡被切斷，接第 20 集。）

**Lemma 6.5**：高斯質數 $\pi\mid\alpha_1\cdots\alpha_r$ ⇒ $\pi\mid$ 某個 $\alpha_j$。

**唯一分解**（6.6）：質數分解在「順序」和「乘單位」之外唯一。例：$5 = (1+2i)(1-2i) = (-2+i)(-2-i)$。

**分解技巧**：先算範數、看因數的範數；列出那個範數的所有高斯整數；試（包括平方）。例：$3+4i = (2+i)^2 = -(1-2i)^2$。

**應用（都靠 $a^2+b^2 = (a+bi)(a-bi)$ + 唯一分解）**

| 定理 | 內容 | 關鍵一步 |
|---|---|---|
| 8.1 | 質數的兩平方和寫法本質唯一 | 兩個質數分解只差單位 |
| 8.2 | 兩種寫法 ⇒ 不是質數；$F_5 = 2^{32}+1 = 62264^2+20449^2$ | 8.1 的逆否 |
| 8.3 | 本原畢氏三元數組 $= (m^2-n^2,\,2mn,\,m^2+n^2)$ | $a+bi = (m+ni)^2$ |
| 8.4 | $a^2+b^2=c^3$ ⇒ $a+bi = (m+ni)^3$ | 每個單位都是立方 |
| 8.5 | $y^2=x^3-1$ 只有 $(1,0)$ | $(y+i)(y-i)=x^3$ |
| 8.6 | 多種寫法：$65 = 4^2+7^2 = 8^2+1^2$ | 重新配對高斯質因數 |

**歷史**：Euler 時代沒證唯一分解就用了它；Gauss 不信任，改用同餘。

## 附：本集一句話總結

> **高斯整數有唯一分解（只差順序和單位）。把 $a^2+b^2$ 拆成 $(a+bi)(a-bi)$，再用唯一分解，一口氣得到：質數的兩平方和寫法本質唯一、本原畢氏三元數組的公式、$a^2+b^2=c^3$ 的公式、$y^2=x^3-1$ 只有 $(1,0)$；重新配對高斯質因數，還能造出有很多種兩平方和寫法的數。**
