## 1. 二次整數 Z[√d] 與它的範數

[▶ 00:03](https://youtu.be/AA4HgRiI-TE?t=3)

$d$ 是**無平方因子**（square-free，不被任何大於 1 的平方數整除）的整數：
$$\mathbb{Z}[\sqrt d] = \{\,a+b\sqrt d : a,b\in\mathbb{Z}\,\}.$$

**範數** [▶ 01:05](https://youtu.be/AA4HgRiI-TE?t=65)：

| 情況 | 元素 | 範數 |
|---|---|---|
| $d>0$ | $a+b\sqrt d$ | $a^2-db^2$ |
| $d<0$（寫成 $\sqrt{-d} = i\sqrt d$） | $a+bi\sqrt d$ | $a^2+db^2$ |

$d<0$ 時仍然有 $N(\alpha) = \alpha\bar\alpha$，所以範數**還是乘性的**。講者說證明「可能當作業，聽起來是很有趣的作業」。（範數的性質都來自複數共軛的性質，所以「範數整除」那些定理都還在。）

$\mathbb{Z}[i]$ 就是 $d=-1$ 的情況。

講者說：這類數系「量身訂做來解別的問題」。

## 2. Euler 解 y³ = x² + 2

[▶ 02:41](https://youtu.be/AA4HgRiI-TE?t=161)（講者說「這論證你會覺得眼熟」）

**歷史**（講者照 Stillwell 講）：

| 誰 | 時間 | 做了什麼 |
|---|---|---|
| Diophantus | 古代 | 找到很多**有理數解**，也找到整數解 $x=5$、$y=3$ |
| Fermat | 1657 | 宣稱**沒有其他**整數解 |
| Euler | 1770 | 證明了，但**假設了 $\mathbb{Z}[\sqrt{-2}]$ 有唯一分解** |

（驗算：$5^2+2 = 27 = 3^3$。）

**Euler 的論證** [▶ 04:17](https://youtu.be/AA4HgRiI-TE?t=257)

**Step 1：分解**。在 $\mathbb{Z}[\sqrt{-2}] = \mathbb{Z}[i\sqrt2]$ 裡：
$$y^3 = x^2+2 = (x+i\sqrt2)(x-i\sqrt2).$$

**Step 2：互質 ⇒ 各自是立方**。可以證 $x\pm i\sqrt2$ 互質（講者說在他講義第 3–4 頁）。講者說「需要一個名字——叫它們**代數數**吧」。互質的兩個數乘起來是立方，由唯一分解，各自是立方（單位只有 $\pm1$，都是立方）：
$$x-i\sqrt2 = (a+bi\sqrt2)^3.$$

**Step 3：展開** [▶ 06:19](https://youtu.be/AA4HgRiI-TE?t=379)：
$$(a+bi\sqrt2)^3 = (a^3-6ab^2) + i\sqrt2\,(3a^2b-2b^3).$$

**Step 4：比較兩邊**：
$$x = a^3-6ab^2,\qquad -1 = 3a^2b-2b^3 = b\,(3a^2-2b^2).$$

講者一開始以為虛部有 $y$，「喔我是白痴，沒有 $y$——這其實很有意思」：虛部那條式子說 **$b$ 整除 $-1$**，所以 $b=\pm1$。

**Step 5：分情況** [▶ 08:45](https://youtu.be/AA4HgRiI-TE?t=525)：

- $b=1$：$3a^2-2 = -1$，$3a^2 = 1$，沒有整數解。
- $b=-1$：$-(3a^2-2) = -1$，$3a^2 = 3$，$a = \pm1$。

**Step 6：算 $x,y$** [▶ 12:19](https://youtu.be/AA4HgRiI-TE?t=739)：$x = a^3-6ab^2 = a-6a = -5a = \mp5$。然後
$$y^3 = x^2+2 = 25+2 = 27,\qquad y = 3.$$

所以**唯一的整數解是 $x=\pm5$、$y=3$**。

【口頭】講者算的時候搞錯了好幾次符號和數字（一度得到 $-5$ 或 $7$、$y^3 = 23$），在學生幫忙下改正。他也困惑過「Stillwell 怎麼選 $a=-1$」，最後發現 $a=\pm1$ 都可以，對應 $x=\mp 5$。

**但是** [▶ 14:39](https://youtu.be/AA4HgRiI-TE?t=879)：「這是 Euler 的證明，但它**假設了唯一分解**。為什麼我一直說這要擔心？讓我給你們看。」

（講者說他跳過講義第 2 頁：證明 $\mathbb{Z}[\sqrt{-2}]$ **有除法定理**，證法跟高斯整數很像。所以 $\mathbb{Z}[\sqrt{-2}]$ 其實真的有唯一分解，Euler 的結論是對的——只是當時沒證。）

## 3. 單位：Z[√−2] 只有 ±1，Z[√2] 有無限多個

**$\mathbb{Z}[\sqrt{-2}]$ 的單位** [▶ 15:39](https://youtu.be/AA4HgRiI-TE?t=939)：單位的範數是 1（跟高斯整數同一個論證）：
$$a^2+2b^2 = 1.$$
$b\neq 0$ 就太大，所以 $b=0$、$a=\pm1$。**單位只有 $\pm1$，兩個。**（高斯整數有四個。）

講者：單位的個數「會隨數系變化，但一定至少有 $1$ 和 $-1$，這沒得爭」。

**$\mathbb{Z}[\sqrt2]$ 的單位** [▶ 17:45](https://youtu.be/AA4HgRiI-TE?t=1065)：範數 $a^2-2b^2$。單位要
$$a^2-2b^2 = 1.$$

【課堂討論】學生說：「那個負號……」講者：對，這把我們帶回第一次考試前講了一小時的 **Pell 方程**（第 14 集），$d=2$。**有無限多解，所以有無限多個單位。**

（例如 $3+2\sqrt2$：$9-8 = 1$。它的所有次方都是單位。這一句**不是逐字稿內容**。）

【口頭】講者說他說的好東西大多適用於**添加 $i\sqrt d$**（虛的）的情況；添加實的平方根「其實醜得多，而且還有未解的問題，我相信那個領域的未解問題比較多」。

## 4. Z[√−3]：唯一分解失敗

[▶ 19:20](https://youtu.be/AA4HgRiI-TE?t=1160)

講者：回到「快樂的地方」——「雖然沒有前兩個那麼快樂」。

$$\mathbb{Z}[\sqrt{-3}] = \mathbb{Z}[i\sqrt3] = \{a+bi\sqrt3\},\qquad N(a+bi\sqrt3) = a^2+3b^2.$$

（講者特別說：**方括號**很重要，$\mathbb{Z}[\ ]$ 是「添加後形成的環」，用圓括號是別的意思。）

**範數是質數 ⇒ 是質數**，在這裡還是成立（同一個證明）；反過來還是不成立。

**兩種分解** [▶ 21:56](https://youtu.be/AA4HgRiI-TE?t=1316)：
$$4 = 2\cdot 2 = (1+i\sqrt3)(1-i\sqrt3).$$

（驗算：$(1+i\sqrt3)(1-i\sqrt3) = 1+3 = 4$。）

**這些因數都不能再分解** [▶ 22:26](https://youtu.be/AA4HgRiI-TE?t=1346)：

- 「範數是質數 ⇒ 質數」幫不上忙：$N(2) = 4$、$N(1\pm i\sqrt3) = 1+3 = 4$，4 不是質數。（講者一度把 $N(1+i\sqrt3)$ 算錯，學生糾正。）
- **單位** [▶ 24:35](https://youtu.be/AA4HgRiI-TE?t=1475)：$a^2+3b^2=1$ ⇒ $b=0$，單位只有 $\pm1$。
- **直接論證**：若 $2 = \alpha\beta$ 非平凡，$N(\alpha)N(\beta) = 4$，兩個都 $>1$，所以 $N(\alpha) = N(\beta) = 2$。但 $a^2+3b^2 = 2$ **沒有整數解**。所以 2 不能分解。同理 $1\pm i\sqrt3$（範數也是 4）也不能分解。

【口頭】[▶ 28:33](https://youtu.be/AA4HgRiI-TE?t=1713) 講者照 Stillwell 的講法試著用模 4 論證，中途搞混（「為什麼不能 $a=0$、$b=1$？那是 $i\sqrt3$……」），最後說「有一堆情況要檢查，我老實說沒什麼興趣，抱歉」，直接陳述結論。上面用範數 2 無解的論證是同一件事。

**不相伴** [▶ 31:48](https://youtu.be/AA4HgRiI-TE?t=1908)：單位只有 $\pm1$，而 $2\neq\pm(1\pm i\sqrt3)$。所以 $2$ 和 $1\pm i\sqrt3$ **不是差一個單位**。

> **結論**：$\mathbb{Z}[\sqrt{-3}]$ 裡，$4$ 有兩種**本質上不同**的不可分解因數的分解。**唯一分解失敗。**

**這很要緊** [▶ 32:18](https://youtu.be/AA4HgRiI-TE?t=1938)：「它基本上殺死了我們一直在用的論證——拆成質數的乘積，然後說『質數的立方表示那邊是立方』等等。」

## 5. 修補：Eisenstein 整數 Z[ω]

[▶ 32:18](https://youtu.be/AA4HgRiI-TE?t=1938)

講者：修補的方法叫 **Eisenstein 整數**。

【口頭】還記得 **Eisenstein 判別法**嗎？（之後會看到。）講者相信是同一個 Eisenstein，「大概是 Gauss 那個時代、19 世紀的人」。

### 5.1 三次單位根 ω

[▶ 33:22](https://youtu.be/AA4HgRiI-TE?t=2002)

$$\omega = \frac{-1+i\sqrt3}{2} = \cos\frac{2\pi}3+i\sin\frac{2\pi}3 = e^{2\pi i/3}.$$

這是**主三次單位根**（principal third root of unity）。

**在單位圓上** [▶ 33:53](https://youtu.be/AA4HgRiI-TE?t=2033)：

| | 角度 | 值 |
|---|---|---|
| $\omega$ | $2\pi/3$ | $\dfrac{-1+i\sqrt3}{2}$ |
| $\omega^2$ | $4\pi/3$ | $\dfrac{-1-i\sqrt3}{2} = \bar\omega$ |
| $\omega^3$ | $2\pi$ | $1$ |

（平方就是把 $\omega$ 對實軸翻過去，得到共軛。）

**關鍵觀察** [▶ 34:54](https://youtu.be/AA4HgRiI-TE?t=2094)：
$$2\omega = -1+i\sqrt3\quad\Longrightarrow\quad i\sqrt3 = 2\omega+1.$$
所以添加 $\omega$ 就自動得到 $i\sqrt3$：
$$\mathbb{Z}[\sqrt{-3}]\subseteq\mathbb{Z}[\omega] = \{\,a+b\omega : a,b\in\mathbb{Z}\,\}.$$

### 5.2 格子變密，除法定理回來了

[▶ 36:39](https://youtu.be/AA4HgRiI-TE?t=2199)

講者說他講義裡花了很多時間畫這些圖。

**$\mathbb{Z}[\sqrt{-3}]$ 的格子** [▶ 37:20](https://youtu.be/AA4HgRiI-TE?t=2240)：橫向間距 1、縱向間距 $\sqrt3\approx1.7$ 的長方形格子。照高斯整數的幾何論證（第 15–16 集），最壞的點是長方形的**中心**。

【課堂討論】學生算中心 $\frac12+\frac{\sqrt3}2 i$ 的範數。講者和學生算出「10/4」。

> 以下**不是逐字稿內容**，是更正這個數字：中心 $\frac12+\frac{\sqrt3}{2}i$ 到最近格點（例如 $0$）的距離平方是 $\left(\frac12\right)^2+\left(\frac{\sqrt3}2\right)^2 = \frac14+\frac34 = 1$。所以餘數的範數可能**等於** 1，而除數（例如 $1$）的範數也是 1，做不到「餘數範數 < 除數範數」。**除法定理在 $\mathbb{Z}[\sqrt{-3}]$ 失敗**，結論跟講者一樣。（講者說的「10/4」把範數公式 $a^2+3b^2$ 用在了非整數的 $b$ 上，算法混了。）

**加入 Eisenstein 整數後** [▶ 40:35](https://youtu.be/AA4HgRiI-TE?t=2435)：多了「半整數」點，例如 $-\frac12+\frac{\sqrt3}2 i$（就是 $\omega$），「把縫隙填起來」，格子變成**三角形格子**。離所有格點最遠的點在三角形中間。講者說那裡的範數「算出來是一半」，小於 1，所以除法定理成立（講義第 6 頁有不等式）。

> 以下**不是逐字稿內容**，是更正這個數字：三角形格子的邊長是 1，最遠的點是等邊三角形的**外心**，到頂點距離 $\frac1{\sqrt3}$，距離平方是 $\frac13$。不管是 $\frac12$ 還是 $\frac13$，都小於 1，結論一樣：$\mathbb{Z}[\omega]$ 有除法定理，所以有唯一分解。

【口頭】[▶ 42:09](https://youtu.be/AA4HgRiI-TE?t=2529) 「你可能會開始困擾：裡面有一半，怎麼還叫**整數**？」——第 6 節解釋。

### 5.3 範數與六個單位

[▶ 42:39](https://youtu.be/AA4HgRiI-TE?t=2559)

**範數**：$a+b\omega$ 當複數的**長度平方**（講者說「跟之前用的其實一樣」）。

$$a+b\omega = a+b\cdot\frac{-1+i\sqrt3}2 = \frac{2a-b}{2}+i\,\frac{b\sqrt3}{2},$$
$$N(a+b\omega) = \frac{(2a-b)^2+3b^2}{4} = a^2-ab+b^2.$$

（講者一開始想直接用 $|\omega|=1$ 算，「感覺不對」，改成展開。）

**單位**：$a^2-ab+b^2 = 1$ [▶ 45:21](https://youtu.be/AA4HgRiI-TE?t=2721)。

（講者推導時寫成 $(2a-b)^2+3b^2 = 4$，展開 $4a^2-4ab+4b^2 = 4$，「看我們多好運」，得到 $a^2-ab+b^2=1$。）

| $(a,b)$ | $a+b\omega$ |
|---|---|
| $(1,0)$ | $1$ |
| $(-1,0)$ | $-1$ |
| $(0,1)$ | $\omega$ |
| $(0,-1)$ | $-\omega$ |
| $(1,1)$ | $1+\omega = -\omega^2$ |
| $(-1,-1)$ | $-1-\omega = \omega^2$ |

**六個單位**：$\pm1,\ \pm\omega,\ \pm\omega^2$。講者：「滿妙的。」

（講者列的時候混了幾次，看單位圓上的圖才確定：$\omega+1$ 是 $\omega$ 往右移 1，落在 $-\omega^2$ 的位置。）

（$1+\omega+\omega^2 = 0$ 所以 $1+\omega = -\omega^2$。這一句**不是逐字稿內容**。）

## 6. 為什麼叫「整數」：代數整數

[▶ 49:28](https://youtu.be/AA4HgRiI-TE?t=2968)

> **定義**：複數 $\alpha$ 叫**代數整數**（algebraic integer），如果它是某個**首一整係數多項式**的根：
> $$\alpha^n+a_{n-1}\alpha^{n-1}+\cdots+a_1\alpha+a_0 = 0,\qquad a_j\in\mathbb{Z}.$$
> （**首一**，monic：最高次項係數是 1。）
>
> 若 $n=2$，即 $\alpha^2+a_1\alpha+a_0 = 0$，叫**二次整數**（quadratic integer）。

**例子** [▶ 51:47](https://youtu.be/AA4HgRiI-TE?t=3107)：

- $\sqrt{-3}$：滿足 $\alpha^2+3 = 0$。是二次整數。
- **$\omega$**（擔心它不是？）[▶ 52:18](https://youtu.be/AA4HgRiI-TE?t=3138)：$\omega^3 = 1$，所以
  $$\omega^3-1 = (\omega-1)(\omega^2+\omega+1) = 0.$$
  $\omega\neq 1$，所以 $\omega^2+\omega+1 = 0$。**$\omega$ 是二次整數**，所以 Eisenstein 整數配得上「整數」這個名字。

> **事實**（講者不證，時間不夠）[▶ 52:53](https://youtu.be/AA4HgRiI-TE?t=3173)：**有理數的代數整數就是普通整數。**

講者描述證明想法：把有理數寫成最簡分數，代進多項式，推出分母一定是 $\pm1$（講義第 7 頁）。「越看越想證它，其實不難。」

> 以下**不是逐字稿內容**，是補上那個證明：設 $\frac pq$（最簡，$q>0$）滿足 $x^n+a_{n-1}x^{n-1}+\cdots+a_0 = 0$。乘 $q^n$：
> $$p^n = -q\left(a_{n-1}p^{n-1}+a_{n-2}p^{n-2}q+\cdots+a_0q^{n-1}\right).$$
> 所以 $q\mid p^n$。$\gcd(p,q)=1$，所以 $q$ 跟 $p^n$ 也互質（第 5 集），只能 $q=1$。

所以「代數整數」推廣了「整數」：放在有理數裡看，它就是普通的整數。

## 7. 計程車數與 Fermat 最後定理 n = 3

[▶ 55:01](https://youtu.be/AA4HgRiI-TE?t=3301)

Eisenstein 整數跟 $x^3+y^3 = z^3+w^3$ 有關。

**計程車數** [▶ 55:01](https://youtu.be/AA4HgRiI-TE?t=3301)（講者念 Stillwell 引用的故事）：

> Littlewood 說每個正整數都是 Ramanujan 的私人朋友。Hardy 去 Putney 探望生病的 Ramanujan，坐的計程車車號是 **1729**，他說這數字好無聊，希望不是壞兆頭。Ramanujan 說：「不，這是很有趣的數。它是**能用兩種方式寫成兩個立方和的最小數**。」

$$1729 = 1^3+12^3 = 9^3+10^3.$$

（數字和等式**不是逐字稿內容**——字幕沒唸出 1729 和分解，是依故事補上的。）

講者：「這才是數論學家。」【口頭】講者說 Ramanujan 吃不慣英國的食物（他習慣素食），幾乎無法在那裡活下去；他基本上自學，重新發現了歐洲發現的大部分東西還不止，「有些東西我們到現在還不太懂他怎麼做到的」，他對今天研究的尖點形式（cusp forms）之類的東西有某種洞見。

**更早的例子** [▶ 56:36](https://youtu.be/AA4HgRiI-TE?t=3396)：講者說 1657 年有人（字幕寫「bro brancher」）給出
$$9^3+15^3 = 2^3+16^3 = 4104,$$
還有另一個講者唸成「34 312」的數。（驗算：$729+3375 = 4104 = 8+4096$。）

⚠️ 逐字稿缺字：1657 年那位的名字聽不清楚。以下**不是逐字稿內容**：這個時期研究這類問題的是 **Frénicle de Bessy**（跟 Fermat 通信）。第二個數「34 312」對不上已知的兩立方和兩種寫法，可能是 **39312**（$=2^3+34^3 = 15^3+33^3$）。見待確認清單。

講者猜這些人怎麼想到的：「我們最近一直在看把整數寫成兩平方和的不同方式，也許這是下一步。」

**Fermat 最後定理 $n=3$** [▶ 57:38](https://youtu.be/AA4HgRiI-TE?t=3458)：這一節剩下的部分是 $x^3+y^3 = z^3$。

【課堂討論】講者問：什麼是「沒意思的解」？學生答：像 $1,1$ 和 $0$ 那種。學生也指出：這就是 **Fermat 最後定理**。講者：對，$x^n+y^n = z^n$ 在 $n\ge3$ 沒有有意思的解（$n=2$ 有，畢氏三元數組）。**$n=3$ 的情況可以用 Eisenstein 整數證明**——Stillwell 就是用它把問題拆開。（影片在這裡被切斷，接第 23 集。）

> 【課本補充】§11.1 Theorem 11.1（p. 218）：對整數 $n\ge 3$，$a^n+b^n = c^n$ **沒有正整數解** $a,b,c$。（第 1 集講過「正」這個條件排除了 0 那種沒意思的解。）

## 8. 一頁速查表

**二次整數** $\mathbb{Z}[\sqrt d]$（$d$ 無平方因子）：$d>0$ 範數 $a^2-db^2$；$d<0$ 範數 $a^2+|d|b^2 = \alpha\bar\alpha$（乘性）。

**Euler：$y^3 = x^2+2$ 只有 $(\pm5,3)$**

1. $(x+i\sqrt2)(x-i\sqrt2) = y^3$，互質 ⇒ $x-i\sqrt2 = (a+bi\sqrt2)^3$。
2. 虛部：$-1 = b(3a^2-2b^2)$ ⇒ $b=\pm1$ ⇒ $b=-1$、$a=\pm1$。
3. $x = a^3-6ab^2 = \mp5$，$y = 3$。

需要 $\mathbb{Z}[\sqrt{-2}]$ 的唯一分解（它有除法定理，所以成立）。

**單位**

| 數系 | 範數 = 1 | 單位 |
|---|---|---|
| $\mathbb{Z}[i]$ | $a^2+b^2=1$ | $\pm1,\pm i$（4 個） |
| $\mathbb{Z}[\sqrt{-2}]$ | $a^2+2b^2=1$ | $\pm1$（2 個） |
| $\mathbb{Z}[\sqrt{-3}]$ | $a^2+3b^2=1$ | $\pm1$（2 個） |
| $\mathbb{Z}[\omega]$ | $a^2-ab+b^2=1$ | $\pm1,\pm\omega,\pm\omega^2$（6 個） |
| $\mathbb{Z}[\sqrt2]$ | $a^2-2b^2=1$（Pell） | 無限多個 |

**唯一分解失敗**：$\mathbb{Z}[\sqrt{-3}]$ 裡 $4 = 2\cdot2 = (1+i\sqrt3)(1-i\sqrt3)$。**關鍵一步**：$a^2+3b^2 = 2$ 無解 ⇒ 範數 4 的元素不能再分；單位只有 $\pm1$ ⇒ 不相伴。

**Eisenstein 整數** $\mathbb{Z}[\omega]$，$\omega = \frac{-1+i\sqrt3}2 = e^{2\pi i/3}$，$\omega^2+\omega+1=0$。

- $i\sqrt3 = 2\omega+1$ ⇒ $\mathbb{Z}[\sqrt{-3}]\subseteq\mathbb{Z}[\omega]$。
- 三角形格子更密 ⇒ 有除法定理 ⇒ 有唯一分解。

**代數整數**：首一整係數多項式的根。有理數的代數整數 = 整數。

**計程車數** $1729 = 1^3+12^3 = 9^3+10^3$；$4104 = 2^3+16^3 = 9^3+15^3$。

## 附：本集一句話總結

> **高斯整數的方法能推廣：Euler 在 $\mathbb{Z}[\sqrt{-2}]$ 裡分解 $x^2+2$，解出 $y^3=x^2+2$ 只有 $(\pm5,3)$——但前提是唯一分解。$\mathbb{Z}[\sqrt{-3}]$ 裡 $4=2\cdot2=(1+\sqrt{-3})(1-\sqrt{-3})$，唯一分解失敗；加入三次單位根 $\omega$ 得到 Eisenstein 整數，格子變密、除法定理回來，唯一分解也回來了。$\omega$ 滿足首一方程 $\omega^2+\omega+1=0$，所以是「代數整數」。**
