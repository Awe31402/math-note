## 1. D 怎麼住在分式體裡

[▶ 00:00](https://youtu.be/1uoSyglHXTM?t=0)

在 $F = \{a/b\}$ 裡想要「拿回 $a$」，就看 $a/1$：
$$\tilde D = \left\{\frac a1 : a\in D\right\}\subseteq F.$$

（$a/1$ 是等價類 $[a,1]$ 的簡寫。）這個子集合**同構於 $D$**。

講者：**同構**是一個從一邊到另一邊的**雙射**同態，保持加法和乘法。

> 【講義補充】Theorem 4.4.15 證明的最後（p. 141）：$\varphi:D\to F$、$\varphi(x) = [x,1]$。
> - $\varphi(x+y) = [x+y,1] = [x\cdot1+1\cdot y,\ 1\cdot1] = [x,1]+[y,1]$。
> - $\varphi(xy) = [xy,1] = [x,1][y,1]$。
> - $\varphi(x) = [x,1] = 0$ ⇒ $x = 0$，所以 $\ker\varphi = \{0\}$，單射。
>
> 由第一同構定理，$D\cong D/\{0\}\cong\varphi(D)$。
>
> **Definition 4.4.16**：這樣造出的 $F$ 叫 $D$ 的**商體**（field of quotients），用 $a/b$ 或 $\frac ab$ 表示 $[a,b]$：
> $$\frac ab+\frac cd = \frac{ad+bc}{bd},\qquad\frac ab\cdot\frac cd = \frac{ac}{bd}.$$
> 講義說這證明了有理數所有平常的性質：$\frac0a = 0$、$\frac ab\cdot\frac ba = 1$、$\frac{ax}{bx} = \frac ab$。

## 2. 1/2 和 3/6 是同一個數嗎？

[▶ 01:36](https://youtu.be/1uoSyglHXTM?t=96)

【課堂討論】一位學生說：有人會爭論 $\frac12$ 和 $\frac36$ 是不是一樣，「有時候 3/6 和 1/2 不是同一個東西」。講者：「我要不同意。」

**講者的立場** [▶ 02:12](https://youtu.be/1uoSyglHXTM?t=132)：取 $D = \mathbb{Z}$，$F = \{a/b : a,b\in\mathbb{Z},\ b\neq0\}$——**這就是有理數**，而且是**從零形式地造出來的**，沒有假設它存在，「是整數的等價類」。

在這個構造下，**一定有** $(1,2)\sim(3,6)$，因為 $1\cdot 6 = 2\cdot 3$。所以
$$\frac12 = \frac36.$$

- 「沒有爭議，它們是**同一個數**。」說到有理數，你已經同意你在處理分數的**等價類**。
- 你可以說它們是「不同的分數」——但「跟還不會因式分解、更不懂等價類的代數學生談這個很危險」。所以：**它們是等價的分數，但是同一個數。**
- 【口頭】「你可以跟我爭，但你會錯。」

**反方想說什麼** [▶ 03:47](https://youtu.be/1uoSyglHXTM?t=227)：他們想用某個中間詞指「構成分數的那對數」，說 $(1,2)$ 和 $(3,6)$ 是不同的數對。「但他們不說『數對』，因為想讓不太懂的學生更困惑，於是說『分數 $\frac12$ 跟分數 $\frac36$ 不同』。可是你整個童年教育都在學 $\frac12 = \frac36$。來個老師告訴你相反的，那不酷。」

（學生說他沒碰過；另一位說他的數學經驗裡常有學生推翻多年來教的東西，講者：「我們不該那樣做。」）

> 【講義補充】講義（p. 142）的說法：「一方面，這個證明說明了給定 $\mathbb{Z}$ 就有 $\mathbb{Q}$；另一方面，它讓我們能構造抽象的體，對給定的整環扮演 $\mathbb{Q}$ 對 $\mathbb{Z}$ 的角色。我個人認為這個構造、以及它帶給『有理數是什麼』的清晰，是**抽象代數的高點**。$1/2$ 和 $3/6$ 是同一個數嗎？我斷然說是……一個有理數有很多分數表示它嗎？是的，我們也都同意。數對 $(1,2)\neq(3,6)$。總之要記得：**不管我們懂不懂，等價類一直都在。**」講義還推薦了 Paul Garrett 的一篇文章。

## 3. 例子

### 3.1 D = Z：有理數

$F = \mathbb{Q}$。「最大的例子。」

### 3.2 D = Z[x]

[▶ 04:47](https://youtu.be/1uoSyglHXTM?t=287)（講義 Example 4.4.17）

$\mathbb{Z}[x]$ 是整環（可交換、有單位元素、沒有零因子）。分式體是
$$F = \left\{\frac{a(x)}{b(x)} : a(x),b(x)\in\mathbb{Z}[x],\ b(x)\neq 0\right\}.$$

- **這不是有理數**，但它是一個體。
- 【課堂討論】[▶ 05:28](https://youtu.be/1uoSyglHXTM?t=328) 講者問：它的質子體是什麼？特徵是多少？學生一度說 $n$，後來改 0。它含有一份 $\mathbb{Z}$，所以**特徵 0，質子體是 $\mathbb{Q}$**。
- 這是一部分**有理函數**——分子分母是**整係數**多項式的。所以有些有理函數不在裡面 [▶ 07:00](https://youtu.be/1uoSyglHXTM?t=420)，例如
  $$\frac{\sqrt2\,x+7}{\pi+ex}\notin F.$$

【口頭】講者問「我時間到了嗎？」，學生說「沒有」，講者：「提早下課？這幾個字對我沒有意義。」學生說他的鹿有作息表，他在消磨時間。

### 3.3 D = R[x]：有理函數

[▶ 07:34](https://youtu.be/1uoSyglHXTM?t=454)（講義 Example 4.4.18）

$D = \mathbb{R}[x]$ 時，分式體**就是**實係數**有理函數**的全體：
$$\mathbb{R}(x) = \left\{\frac{f(x)}{g(x)} : f,g\in\mathbb{R}[x],\ g\neq 0\right\}.$$

- 非零的有理函數都有乘法反元素（倒過來）。
- 常數函數 1 是乘法單位元素。

> 【講義補充】Example 4.4.18（p. 142）一般化：任何體 $\mathbb{F}$，$\mathbb{F}[x]$ 的分式體記作 $\mathbb{F}(x)$——**圓括號**是有理函數，方括號是多項式。

### 3.4 D = Z_p[x]：特徵 p 的無限體

[▶ 08:04](https://youtu.be/1uoSyglHXTM?t=484)（講義 Example 4.4.19）

$D = \mathbb{Z}_p[x]$（係數在 $\mathbb{Z}_p$ 的多項式），也是整環。分式體是
$$\mathbb{Z}_p(x) = \left\{\frac{f(x)}{g(x)} : f,g\in\mathbb{Z}_p[x],\ g\neq 0\right\}.$$

- $\mathbb{Z}_p\subseteq\mathbb{Z}_p[x]\subseteq F$——講者加上「引號」：嚴格說是**同構的副本**在 $F$ 裡，因為 $F$ 的元素是等價類。
- 【課堂討論】[▶ 09:08](https://youtu.be/1uoSyglHXTM?t=548) 講者問特徵是多少？學生先說 0，又改 $p$。講者：**是 $p$**，因為分數是用 $\mathbb{Z}_p$ 的材料做的，任何東西加自己 $p$ 次就是 0。

> **重點**：$\mathbb{Z}_p(x)$ 是一個**無限的體，特徵卻是 $p$**。

【口頭】[▶ 09:38](https://youtu.be/1uoSyglHXTM?t=578) 學生：「這正是我看到這個構造之前的感覺——我以為特徵 $p$ 就是有限體。」講者：「不對，有無限體特徵是 $p$。」**沒有特徵 0 的有限體**——這是對的；但不代表特徵非零的就一定有限，「邏輯不是這樣走的」。

（講者寫的 $\mathbb{Z}_p(x)$ 被學生說像憤怒鳥，「加了引號的那個在對自己尖叫」，講者說他該多玩憤怒鳥。）

> 【講義補充】講義（p. 142）：「在這段討論之外，我也許會同意特徵有限的體就是有限體。我們最後這個例子清楚說明這是錯的！」
>
> 以下**不是逐字稿內容**，是補一句為什麼沒有特徵 0 的有限體：特徵 0 表示 $1,1+1,1+1+1,\dots$ 永遠不會是 0，也互不相同（若 $m\cdot1 = n\cdot1$，$m>n$，則 $(m-n)\cdot1 = 0$），所以體裡有無限多個元素。

## 5. 一頁速查表

**$D\hookrightarrow F$**：$x\mapsto x/1 = [x,1]$，單射環同態，$D\cong\{a/1\}$。

**$\frac12 = \frac36$**：在分式體的構造下，$(1,2)\sim(3,6)$ 因為 $1\cdot6 = 2\cdot3$。**同一個數**；數對 $(1,2)\neq(3,6)$ 是不同的代表元。

**例子**

| $D$ | 分式體 | 特徵 | 質子體 |
|---|---|---|---|
| $\mathbb{Z}$ | $\mathbb{Q}$ | 0 | $\mathbb{Q}$ |
| $\mathbb{Z}[x]$ | 整係數有理函數 | 0 | $\mathbb{Q}$ |
| $\mathbb{R}[x]$ | $\mathbb{R}(x)$（有理函數） | 0 | $\mathbb{Q}$ |
| $\mathbb{Z}_p[x]$ | $\mathbb{Z}_p(x)$ | $p$ | $\mathbb{Z}_p$ |

**$\mathbb{Z}_p(x)$**：特徵 $p$ 的**無限**體。特徵 0 的體一定無限；特徵 $p$ 的體不一定有限。

## 附：本集一句話總結

> **整環 $D$ 透過 $a\mapsto a/1$ 住在它的分式體裡；取 $D=\mathbb{Z}$ 就從零造出了有理數，而且 $\frac12=\frac36$ 是同一個數（等價類），只是代表的數對不同。$\mathbb{R}[x]$ 的分式體是有理函數；$\mathbb{Z}_p[x]$ 的分式體 $\mathbb{Z}_p(x)$ 是無限的、特徵卻是 $p$——特徵 $p$ 不代表有限。**
