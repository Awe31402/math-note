## 1. 3D 表面的兩種表示法

[▶ 04:33](https://youtu.be/QsfybIs774o?t=273)

| | **顯式（explicit）／參數式（parametric）** | **隱式（implicit）／體積式（volumetric）** |
|---|---|---|
| 離散 | **點雲**、**網格（mesh）**（三角形構成的圖） | **體素（voxel）／格點**，例如**佔據格（occupancy grid）** |
| 連續 | 樣條曲面、atlas 映射 | **神經場（neural field）**：符號距離場（SDF）、輻射場（radiance field） |

**顯式（參數式）表面** [▶ 08:07](https://youtu.be/QsfybIs774o?t=487)：

$$
f:\Omega\subset\mathbb{R}^2\to S\subset\mathbb{R}^3
$$

- 把 2D 參數域 $\Omega$ 映射到 3D 表面 $S$。
- 可行的理由：3D 表面是**二維流形（2-manifold）**——不管表面多複雜，局部走起來都是二維的，就像站在地球上。
- 問題：不一定總能找到這樣的映射。例如**不可能把平面無失真地映到球面**，所以攤開的世界地圖有些地方會變形（下週詳談）。

**隱式表面** [▶ 11:14](https://youtu.be/QsfybIs774o?t=674)：**純量函數的零水平集**：

$$
S=\left\{\mathbf{x}\in\mathbb{R}^3\ \middle|\ f(\mathbf{x})=0\right\}
$$

- **佔據值**：每個格子 0（空）或 1（被佔據），通常放寬成 $[0,1]$。
- **符號距離（signed distance）**：表面上為 0；物體內部為**負**、外部為**正**；任一點的值是到最近表面的距離。
- 例子：佔據格、SDF、輻射場、自適應資料結構如**八元樹（octree）**——2D 時是四元樹：只在有東西的地方繼續細分，空的區域一整塊表示，不浪費空間；3D 時每層把立方體分成 8 塊。

**用圓當例子** [▶ 13:55](https://youtu.be/QsfybIs774o?t=835)【口頭】：

- 參數式 $(r\cos t,r\sin t)$：直接把輸入 $t$ 映到曲線上的點 → 顯式。
- $x^2+y^2=r^2$：要解方程式（找零水平集）才得到曲線 → 隱式。

⚠️ 逐字稿缺字 [▶ 14:16](https://youtu.be/QsfybIs774o?t=856)：講者口誤把參數式說成「implicit representation」，接著又說它「直接把輸入映到表面」；依他自己的定義，參數式應是**顯式**。Whisper 也把 radiance field 寫成 “radiance view”、octree 寫成 “Op3”。

【口頭】[▶ 07:03](https://youtu.be/QsfybIs774o?t=423) 輻射場只能做體積渲染、SDF 只能做表面渲染；早期 SDF 需要 3D 表面當監督，輻射場可以用影像自我監督。有幾篇論文把 SDF 轉成輻射場，就能用新視角影像監督 SDF（下週講）。

## 2. 點雲

[▶ 15:20](https://youtu.be/QsfybIs774o?t=920)

- 點雲是顯式表示：從 2D 流形表面**取樣**一些點。
- 資料結構就是 $N\times3$ 矩陣，每列 $(x,y,z)$。
- 也可以是 $N\times(3+D)$：後面 $D$ 維放其他特徵，例如**表面法向量**、**RGB**（有紋理的點雲），或兩者都放。

**資料來源** [▶ 17:13](https://youtu.be/QsfybIs774o?t=1033)：

| 來源 | 原理 |
|---|---|
| **光達（LiDAR）** | 雷射感測器；發射雷射、量反射回來的**相位差**算距離（不是直接量飛行時間） |
| **RGB-D 相機**（如 Kinect） | 投射紅外線圖案，從圖案的扭曲推算深度 |
| **CAD 模型** | SolidWorks、Pro/E、AutoCAD 等（.obj、.ply），在表面上取樣 |
| **SfM**、深度影像 | 前面幾講 |

【口頭】很早期的 3D 視覺題目「shape from X」（例如 shape from silhouette）也是從投影的扭曲推形狀，課程沒時間講。

**應用** [▶ 20:10](https://youtu.be/QsfybIs774o?t=1210)：土地測量、攝影測量（3D 視覺很多東西「偷」自攝影測量）、都市規劃、建築結構監測、【口頭】鑑識科學（保存犯罪現場）、文物保存（史丹佛 2002–2003 年的 SIGGRAPH 計畫數位化米開朗基羅的大衛像）、計量、機器人與自駕車。

## 3. 點雲的優缺點

[▶ 22:53](https://youtu.be/QsfybIs774o?t=1373)

**優點**：

1. 有**真正的 3D 資訊**和**絕對尺度**（SfM 不知道場景大小時沒有尺度）。
2. 數學上**簡單**：每個點只要 $(x,y,z)$，卻能表示任意複雜的表面。
3. 光達重建比影像重建**準確得多**（例如德國某城市的光達地圖 vs. SfM）。

**缺點** [▶ 23:44](https://youtu.be/QsfybIs774o?t=1424)：

1. **稀疏**：再密也比網格稀疏（網格是水密的）。
2. **不規則**：沒有結構，找最近鄰比影像貴得多（影像像素排成規則陣列，8 個鄰居一目了然）。要用 **kd 樹**或近似最近鄰函式庫（FLANN）。
3. **沒有紋理**：原始形式只有點。
4. **無序**：$\{\mathbf{x}_1,\mathbf{x}_2,\mathbf{x}_3\}$ 怎麼排都是同一個點雲（3 個點有 $3!=6$ 種排法）→ 對深度學習有害（§4）。
5. **旋轉等變／不變**問題 [▶ 26:45](https://youtu.be/QsfybIs774o?t=1605)：
   - 用正立的椅子訓練的網路，椅子倒過來就不行——CNN 對平移等變，但對旋轉不是。
   - **不變（invariant）**：輸入旋轉，輸出**不變**。
   - **等變（equivariant）**：輸入旋轉，輸出**跟著旋轉**；把旋轉還原後和原本一致。
   - 【口頭】$SO(3)$ 是一個群，講者實驗室用群論研究這問題，但他認為還沒完全解決。

## 4. PointNet：排列不變性

[▶ 29:56](https://youtu.be/QsfybIs774o?t=1796)

**PointNet**（CVPR 2017）：輸入 $N\times3$ 點雲，可做**分類**、**場景語意分割**、**部件分割**（例如分出飛機的機翼、機身、尾翼）。

⚠️ 逐字稿缺字 [▶ 30:11](https://youtu.be/QsfybIs774o?t=1811)：Whisper 把 PointNet 作者的名字寫成 “Steve Adloff”，人名聽錯，以投影片為準。

**問題：MLP、CNN 不是排列不變的** [▶ 31:06](https://youtu.be/QsfybIs774o?t=1866)：

- 一個神經元 $h=f\left(\mathbf{w}^\mathsf{T}\mathbf{x}\right)$（線性映射 + 非線性啟動）。
- 設 $f$ 是恆等，輸入三個點 $(\mathbf{x}_1,\mathbf{x}_2,\mathbf{x}_3)$：$\mathbf{w}_1^\mathsf{T}\mathbf{x}_1+\mathbf{w}_2^\mathsf{T}\mathbf{x}_2+\mathbf{w}_3^\mathsf{T}\mathbf{x}_3$。
- 換成 $(\mathbf{x}_3,\mathbf{x}_1,\mathbf{x}_2)$：還是同一個點雲，但輸出完全不同——權重是照原本的順序訓練的。
- 影像沒這問題：像素永遠排成規則陣列。

**暴力解** [▶ 33:52](https://youtu.be/QsfybIs774o?t=2032)：把訓練資料擴增成所有 $N!$ 種排列 → 階乘複雜度，不可行。

**PointNet 的解法** [▶ 34:19](https://youtu.be/QsfybIs774o?t=2059)：

1. 每個點**獨立**通過**同一個**（權重共享的）MLP：$\mathbb{R}^3\to\mathbb{R}^{1024}$，得 $N\times1024$。
2. 用**最大池化（max pooling）**沿點的方向取每一維的最大值 → **全域特徵**。
3. 再接分類或分割。

$$
g\left(\{\mathbf{x}_1,\dots,\mathbf{x}_N\}\right)=\gamma\left(\max_{i=1,\dots,N}h\left(\mathbf{x}_i\right)\right)
$$

（式子是依講者口述的架構寫成的示意；$h$ 是共享 MLP、$\gamma$ 是後面的網路、$\max$ 逐維取。）

**為什麼排列不變** [▶ 36:04](https://youtu.be/QsfybIs774o?t=2164)：$\max$ 和順序無關；前面每個點又是獨立處理的 → 整個網路排列不變。

【口頭】概念很簡單，論文被引用約一萬次；講者實驗室看到後也投入很多點雲研究。

**限制** [▶ 37:42](https://youtu.be/QsfybIs774o?t=2262)：

- CNN 經過多層卷積，**感受野（receptive field）**逐漸變大，越大越能蒐集資訊。
- PointNet 每個點獨立、最後才 max pool → 只有一個感受野（全部的點）：有全域形狀，卻**完全忽略局部結構**。

## 5. PointNet++：加入局部結構

[▶ 39:07](https://youtu.be/QsfybIs774o?t=2347)

同一位作者的後續（講者實驗室也有類似的 SO-Net）。

**步驟**：

1. **最遠點取樣（farthest point sampling，FPS）**：挑出 $n$ 個點，每個點都離已選的點最遠——電腦圖學的標準演算法，最能代表形狀。
2. 以每個取樣點為局部中心，找 **$k$ 近鄰**分組。
3. 每組的點先**減掉中心**（局部座標），再通過一個小 PointNet → 局部特徵。
4. 在較粗的點集上**重複**取樣、分組、PointNet → 類似多層 CNN 的階層結構。
5. **多解析度分組**，最後一層的輸出和前面層的輸出串接——類似 ResNet 的跳接（skip link）。

⚠️ 逐字稿缺字：Whisper 寫 “PointN pass pass”、“SolNets”。

【口頭】[▶ 42:41](https://youtu.be/QsfybIs774o?t=2561) 點雲深度學習約五年前很熱，現在熱潮轉向輻射場；點雲現在的研究方向之一是自我監督表示學習（對比損失等）。

## 6. 任務一：點雲地點辨識

[▶ 44:04](https://youtu.be/QsfybIs774o?t=2644)

**問題（「我在哪裡？」）**：

- 有整個城市的 3D 點雲地圖（例如 Oxford 資料集），每個部分都有 GPS/INS 座標。
- 自駕車上的光達只看到局部 → 一個查詢點雲。
- 在地圖中找到最相似的位置 → 知道自己在哪。這是機器人導航最重要的問題。

**轉成檢索問題** [▶ 46:14](https://youtu.be/QsfybIs774o?t=2774)：

- 把地圖切成很多**子地圖**，各自標上地理座標，降取樣（省計算和儲存）。
- 查詢子地圖 ≈ 查詢影像；子地圖資料庫 ≈ 影像資料庫 → 和第 27 集的影像檢索一樣。

**PointNetVLAD** [▶ 47:46](https://youtu.be/QsfybIs774o?t=2866)（講者實驗室，第一篇點雲檢索）：

- 前半段是 PointNet；把最後的 max pool 換成更強的 **NetVLAD** 層。
- **NetVLAD**（原本用在影像）：像視覺詞袋（第 27 集），但把「數頻率」的**硬指派**換成 softmax **軟指派**；視覺詞（中心 $\mathbf{c}_k$）和 $\mathbf{w}_k$、$b_k$ 都是可學參數：

$$
V(k)=\sum_{i=1}^N\frac{e^{\mathbf{w}_k^\mathsf{T}\mathbf{p}_i'+b_k}}{\sum_{k'}e^{\mathbf{w}_{k'}^\mathsf{T}\mathbf{p}_i'+b_{k'}}}\left(\mathbf{p}_i'-\mathbf{c}_k\right)
$$

（式子依講者對各項的說明整理成 NetVLAD 的常見寫法；投影片原式沒唸。）

**排列不變的證明** [▶ 50:46](https://youtu.be/QsfybIs774o?t=3046)：對 $i$ **求和** → 點怎麼排都一樣 → 可用在點雲。

⚠️ 逐字稿缺字 [▶ 50:54](https://youtu.be/QsfybIs774o?t=3054)：講者說「PointNet 用 softmax 讓這部分排列不變」，依 §4 應是 **max pooling**。

**訓練：度量學習、三元組** [▶ 52:09](https://youtu.be/QsfybIs774o?t=3129)：

- 同一個網路複製三份：**錨點（anchor）**、**正樣本**（同一地點）、**負樣本**（不同地點）。
- 正樣本必須是**不同時間**經過同一地點拍的（有細微變化），否則網路只會過擬合、損失永遠為 0。
- 【口頭】講者團隊開著裝光達的自駕車在 NUS 和西海岸一帶連續開了三十多小時蒐集資料（資料集分成大學區、住宅區等區域；講者說很多人引用時用縮寫，卻不知道是哪裡）。

**惰性三元組損失（lazy triplet loss）** [▶ 55:02](https://youtu.be/QsfybIs774o?t=3302)：

- 拉近 $\delta(\mathbf{f}_a,\mathbf{f}_{\text{pos}})$、推遠 $\delta(\mathbf{f}_a,\mathbf{f}_{\text{neg}})$；只這樣會有平凡解（全部輸出 0）→ 加**邊界（margin）**$\alpha$ 放進**合頁損失（hinge loss）** $[\cdot]_+=\max(\cdot,0)$。
- 理想上要用**最難的負樣本**（和錨點最像卻不是同一地點）。但網路每次迭代都在變，每次都搜整個資料庫太慢 → 只在**這個 batch 裡**找最難的負樣本（所以叫「惰性」）。

$$
\mathcal{L}_{\text{lazyTrip}}=\max_j\left[\alpha+\delta\left(\mathbf{f}_a,\mathbf{f}_{\text{pos}}\right)-\delta\left(\mathbf{f}_a,\mathbf{f}_{\text{neg},j}\right)\right]_+
$$

（式子依口述整理。）

- **四元組損失（quadruplet）** [▶ 58:19](https://youtu.be/QsfybIs774o?t=3499)：推開負樣本時，可能不小心把錨點推向另一個負樣本 → 同時取 batch 中**最難**和**第二難**的負樣本。

**結果** [▶ 59:14](https://youtu.be/QsfybIs774o?t=3554)：

- 當時只能和 PointNet 比（這個任務是他們首創的）；現在早被超越。
- 意外的好處：同一地點**白天 vs. 晚上、冬天 vs. 春天**，影像外觀差很多，影像檢索會失敗；點雲結構不變，檢索照樣成功。
- 失敗例：停著的車開走了，網路檢索到另一個結構相似的地方 → 網路學的是**結構**。

## 7. 任務二：關鍵點偵測與描述子

[▶ 1:02:14](https://youtu.be/QsfybIs774o?t=3734)

- 影像（例如 SIFT）：關鍵點是視角改變時仍能穩定偵測的點；描述子是它的「指紋」（SIFT 是 128 維）。
- 點雲：**沒有紋理**，只有 $xyz$。之前有學描述子的工作，但**沒有人用深度學習做關鍵點偵測**——因為**無法監督**：誰能標出點雲上哪裡是關鍵點？

### 3DFeat-Net（ECCV 2018，弱監督）

[▶ 1:04:44](https://youtu.be/QsfybIs774o?t=3884)

- **弱監督**：只需要和 PointNetVLAD 一樣的三元組（錨點、同地點不同時間的正樣本、負樣本），不必標關鍵點。
- **步驟**：
  1. FPS 取樣，每個取樣點用 $k$ 近鄰分群。
  2. **偵測器**（小 PointNet）每群輸出兩樣東西：**注意力權重**（這群是不是關鍵點）和**方向**（讓局部對齊到正立）。
  3. **描述子網路**：用方向把群轉正，再過 PointNet（max pool + 串接）→ 每群一個描述子。
  4. **相似度矩陣** [▶ 1:08:52](https://youtu.be/QsfybIs774o?t=4132)：錨點的每個關鍵點，在正樣本中取**最近**的描述子距離（要最小化）；在負樣本中也取最近的（最難的負樣本，要最大化）→ 放進合頁損失。
  5. 每項損失用正規化後的**注意力權重**加權：不是關鍵點的群，權重變小。
- **結果** [▶ 1:11:27](https://youtu.be/QsfybIs774o?t=4287)：勝過傳統幾何方法（ISS 等）。注意力集中在**結構有意義**的地方，平坦路面幾乎沒有；ISS 在路面上有很多誤偵測。

### USIP（ICCV 2019，自我監督）

[▶ 1:13:20](https://youtu.be/QsfybIs774o?t=4400)

- 連 GPS/INS 都不要了，**完全自我監督**。
- **步驟**：
  1. 隨機產生一個轉換 $T$，把點雲 $X$ 變成 $\tilde X$。
  2. 兩者都過**特徵提議網路**（受 SO-Net 啟發）→ 關鍵點 $Q$、$\tilde Q$，以及每點的不確定度 $\sigma$。
  3. 用 $T^{-1}$ 把 $\tilde Q$ 轉回來，應該和 $Q$ 對上 → 自我監督。
- **退化** [▶ 1:16:23](https://youtu.be/QsfybIs774o?t=4583)：網路可以學成輸出**形心**或**主軸**上的點——不管怎麼轉都一樣。論文有正式證明。解法很簡單：**限制感受野**，窄到不足以學到全域的形心、主軸。
- **機率式 Chamfer 損失** [▶ 1:17:43](https://youtu.be/QsfybIs774o?t=4663)：直接用 Chamfer 距離是硬指派，而且不是每個提議都一樣顯著（例如落在無特徵的平面）→ 讓網路輸出 $\sigma$，用指數分佈的負對數概似取代：$\sigma$ 不需監督，學出來就代表該點有多顯著。
- **點到點損失** [▶ 1:19:11](https://youtu.be/QsfybIs774o?t=4751)：3DFeat-Net 的關鍵點必須是點雲中的某個點 → 有**量化誤差**（取樣本身就是量化）。USIP 讓關鍵點可以在 3D 空間任何位置，但加一個損失要它到點雲最近點的距離小，否則會飄走。
- **結果** [▶ 1:21:04](https://youtu.be/QsfybIs774o?t=4864)：可重複性大幅勝過所有方法，包括他們自己的 3DFeat-Net。

> 以下**不是逐字稿內容**，是「指數分佈的負對數概似」的一種寫法，說明 $\sigma$ 為什麼能自己學：若距離 $d_i\sim$ 尺度為 $\sigma_i$ 的指數分佈，負對數概似是 $\ln\sigma_i+d_i/\sigma_i$。$\sigma_i$ 大會讓 $d_i/\sigma_i$ 變小（容忍大誤差），但 $\ln\sigma_i$ 會懲罰它——所以只有真的對不準的點才會學到大的 $\sigma$。

⚠️ 逐字稿缺字：Whisper 把 3DFeat-Net 寫成 “3D FITNET”、“3D feednet”、“3D peanut”；USIP 寫成 “UCIT”；chamfer loss 寫成 “chamfer long”。

## 8. 任務三：3D 物體偵測（VoteNet）

[▶ 1:22:13](https://youtu.be/QsfybIs774o?t=4933)

**任務**：在點雲中找出物體，框上**最緊的 3D 邊界框**，7 個參數：

$$
\left(x,y,z,\ h,w,l,\ \theta\right)
$$

- $(x,y,z)$ 框中心；$(h,w,l)$ 高、寬、長；假設物體正立，只有一個**偏航角（yaw）**$\theta$。
- 加上每個框的語意類別。

**為什麼比 2D 偵測難** [▶ 1:23:10](https://youtu.be/QsfybIs774o?t=4990)：

- 點雲很稀疏。
- **非模態感知（amodal perception）**：只看得到物體朝向感測器的那一面，背面完全沒有點（被自己的「影子」擋住）。
- 7 個參數比 2D 框多。

**VoteNet**（PointNet 同一位作者）[▶ 1:24:55](https://youtu.be/QsfybIs774o?t=5095)：

1. **種子**：用 PointNet++ 產生 $M$ 個種子，每個有位置 $\mathbf{x}$ 和 $C$ 維特徵 $\mathbf{f}$。
2. **Hough 投票** [▶ 1:29:52](https://youtu.be/QsfybIs774o?t=5392)：MLP 吃 $\mathbf{f}$，輸出位移 $\Delta\mathbf{x}$ 和特徵變化 $\Delta\mathbf{f}$：
$$
\mathbf{y}=\mathbf{x}+\Delta\mathbf{x}\ (\text{指向最近物體中心}),\qquad\mathbf{g}=\mathbf{f}+\Delta\mathbf{f}
$$
   有真值物體中心，可以直接監督 $\Delta\mathbf{x}$（投票迴歸損失）。
3. **分群** [▶ 1:31:15](https://youtu.be/QsfybIs774o?t=5475)：對所有票做 FPS 取 $K$ 張當中心，半徑 $r$ 內的票歸成一群。
4. **局部化**：群內每張票的位置減掉群中心 $\mathbf{z}_j$、除以 $r$：$\mathbf{z}_i'=(\mathbf{z}_i-\mathbf{z}_j)/r$。
5. **提議** [▶ 1:33:08](https://youtu.be/QsfybIs774o?t=5588)：兩層 MLP 輸出：**物體性分數**（0 到 1，接近 1 表示有物體；0 則其他參數不管）、邊界框參數、語意分類分數。

**為什麼不直接迴歸絕對座標** [▶ 1:26:07](https://youtu.be/QsfybIs774o?t=5167)：

- 深度網路不擅長預測**無界**的數（$-\infty$ 到 $\infty$）。
- 像 Fast/Faster R-CNN 的**錨框（anchor box）**：預測**相對**於錨（這裡是票的群中心）的偏差 → 有界、誤差空間小。
- 損失：分類用交叉熵；框用迴歸損失，監督的是相對真值的偏差。

【口頭】[▶ 1:35:33](https://youtu.be/QsfybIs774o?t=5733) **多個目標要調權重**：兩個損失尺度差很多時，要把小的放大到和大的同一量級，否則永遠只在最佳化主導的那個。這不只是深度學習的問題——3D 視覺常同時最小化 3D 空間（公制距離）和像素空間（無單位）的誤差，兩者不在同一個世界，不能直接相加。

## 9. 任務四：弱監督 3D 語意分割

[▶ 1:37:42](https://youtu.be/QsfybIs774o?t=5862)

**任務**：給點雲每個點標上 $K$ 類之一（不區分個體；區分個體的是**實例分割**，實例 + 背景是**全景分割（panoptic）**）。

**為什麼要弱監督** [▶ 1:39:48](https://youtu.be/QsfybIs774o?t=5988)：

- 3D 標註比 2D 繁瑣得多：形狀分割每個物體要標 1k–10k 點；室內場景每個要標上百萬點。
- 人眼不習慣看點雲（我們比較擅長看輪廓）。
- 還能用大量未標註的資料；現在也有人研究合成資料到真實資料的轉移。

**講者實驗室 2020 年的方法**：只標**很少的點**——甚至每類只標 **1 個點**就夠。四個分支：

1. **不完全監督分支** [▶ 1:43:44](https://youtu.be/QsfybIs774o?t=6224)：有標籤的點遮罩為 1、沒有的為 0，只在有標籤處算損失。
2. **孿生（Siamese）自我監督分支**：點雲做擴增（翻轉、旋轉等），兩份通過同一個編碼器，用 L2 距離讓兩邊的輸出一致（類似、但不到對比學習那麼完整——沒有用負樣本正規化）。
3. **不精確監督分支** [▶ 1:45:10](https://youtu.be/QsfybIs774o?t=6310)：受**多示例學習（multi-instance learning）**啟發，一整袋（bag）點共用標籤。
4. **平滑分支**（最重要）[▶ 1:45:58](https://youtu.be/QsfybIs774o?t=6358)：
   - 建 **$k$ 近鄰圖**：分別依**空間**和**顏色**各建一次，兩組權重（指數函數，壓到 0 到 1）取平均。
   - 平滑損失：相鄰的點特徵應該相同（相鄰的點多半屬於同一語意）：
$$
\mathcal{L}_{\text{smo}}=\sum_{(i,j)}w_{ij}\left\|f\left(\mathbf{x}_i\right)-f\left(\mathbf{x}_j\right)\right\|^2
$$
     （式子依口述整理。）
   - 論文中證明它等價於半監督學習的**標籤傳播（label propagation）** [▶ 1:49:03](https://youtu.be/QsfybIs774o?t=6543)：把 $W$ 變成 Markov 矩陣，從沒標籤的點出發「像醉漢一樣」隨機漫步，碰到第一個有標籤的點就拿它的標籤——最後化成特徵值／特徵向量問題（和 PageRank 概念相同），可用 Laplace 矩陣表示。

**結果** [▶ 1:51:52](https://youtu.be/QsfybIs774o?t=6712)：只用 10% 標籤就幾乎等於全監督，有些甚至更好；1 點監督也接近全監督。講者說現在大概會直接換成對比學習。

## 10. 任務五：點雲配準

[▶ 1:54:44](https://youtu.be/QsfybIs774o?t=6884)

**任務**：兩個點雲各自在自己的座標系，求讓它們對齊的 $R$、$\mathbf{t}$（例如拼成整個房間）。

- 推廣到多個點雲就是**旋轉平均**（第 28 集的全域 SfM）；但點雲有絕對尺度，沒有平移尺度模糊。【口頭】可以利用旋轉矩陣的低秩性質做強健估計。本講只講兩兩配準。

**應用** [▶ 1:56:22](https://youtu.be/QsfybIs774o?t=6982)：

- **自駕車定位兩步驟**：地點辨識（§6）只給**粗略**位置 → 再用點雲配準求**精確**位姿。
  - 對比影像：先用詞彙樹／NetVLAD 檢索縮小範圍，再在小範圍內找 2D–3D 對應做 PnP（第 20–22 集）——直接在上百萬張影像、上億個關鍵點裡找對應不可能。
- **變化偵測**：同一條路在很久之後再跑一次，先配準，再比對找出場景變化。

### ICP

[▶ 2:00:06](https://youtu.be/QsfybIs774o?t=7206)

**迭代最近點（iterative closest point，ICP）**：剛體配準的經典。

**在解什麼**：

$$
\min_{R,\mathbf{t}}\sum_i\left\|R\mathbf{p}_i+\mathbf{t}-\mathbf{q}_i\right\|^2
$$

$\mathbf{p}_i$ 是來源點，$\mathbf{q}_i$ 是它目前在參考點雲中的最近點。

**步驟**：

1. 對每個點用 **kd 樹**找參考點雲中的最近鄰，當作對應。
2. 用這些對應解上式——就是 SVD（第 21 集的絕對定向）。
3. 套用 $R$、$\mathbf{t}$ 移動一點，重新找最近鄰。
4. 重複到誤差不再變化。

⚠️ 逐字稿缺字 [▶ 2:01:46](https://youtu.be/QsfybIs774o?t=7306)：講者說投影片的「加 $\mathbf{t}$」那裡「應該是減」；上式寫成標準形式 $R\mathbf{p}_i+\mathbf{t}-\mathbf{q}_i$。

**什麼時候會失敗** [▶ 2:03:08](https://youtu.be/QsfybIs774o?t=7388)：

- **局部最小值**：像梯度下降一樣，**收斂盆地很窄** → 初值必須接近正確解。
- 有**離群值**時可能整個壞掉。

### RPM-Net

[▶ 2:04:06](https://youtu.be/QsfybIs774o?t=7446)

**強健點匹配網路**，基於舊方法 RPM，用資料學特徵。

1. **特徵**：用 **PPF（point pair features）**：FPS 取點、取鄰域，算鄰點相對位置 $\Delta(x,y,z)$ 和法向量之間的夾角 → 捕捉局部幾何。
2. **匹配矩陣** [▶ 2:04:58](https://youtu.be/QsfybIs774o?t=7498)：
   - 硬指派 = **置換矩陣**（像工作指派問題：每列、每行恰好一個 1）——不可微分。
   - 軟指派 = **雙隨機矩陣（doubly stochastic）**：每列、每行加總為 1，元素可以是任何非負數。
   - **Sinkhorn 層** [▶ 2:06:53](https://youtu.be/QsfybIs774o?t=7613)：從一個元素全為正的矩陣開始，**交替正規化列和行**，最後會收斂成雙隨機矩陣，而且**可微分**。分數用 $e^{-\beta d}$（距離越小越大、一定為正），$\beta$ 是可學參數。
3. **處理離群值** [▶ 2:10:26](https://youtu.be/QsfybIs774o?t=7826)：兩邊點數不一定相同、可能有離群值 → 加一列、一行**垃圾桶（slack）**，配不上的點丟進去，Sinkhorn 照樣運作。
   - 退化：可能全部丟進垃圾桶 → 加一個門檻，門檻也不是超參數，而是放進損失讓網路學。
4. **結果**：誤差比 ICP、RPM、PointNetLK 都低。重疊區域的權重最高——合理，因為只有重疊處才會互相匹配。

⚠️ 逐字稿缺字：Whisper 把 PPF 寫成 “PPS”、“PPSNet”。

【口頭】[▶ 2:12:57](https://youtu.be/QsfybIs774o?t=7977) 講者實驗室後來的 **REGTR**（CVPR，講者說「去年」）：用 Transformer——自注意力捕捉每個點雲內部的關係，交叉注意力捕捉兩個點雲之間的關係；不再顯式建匹配矩陣，直接預測來源點在參考座標系中的位置（反之亦然）。

## 11. 任務六：影像對點雲配準

[▶ 2:16:03](https://youtu.be/QsfybIs774o?t=8163)

- 就是 PnP（第 20 集的投影片）：3D 點在世界座標，影像在相機座標，求相機位姿。
- SfM 的做法：3D 點存著 SIFT/SURF 描述子，影像抽同樣的關鍵點來匹配。但**外觀劇烈變化**（白天建圖、晚上定位；晴、雨、陰）時，描述子對不上——比地點辨識更難；資料也不夠、不知道怎麼標。

**動機** [▶ 2:19:05](https://youtu.be/QsfybIs774o?t=8345)【口頭】（講者十年前在博士論文就寫過這個想法）：

- 用**光達**建參考地圖：最準，但貴（講者說約 7 萬美元；Whisper 把型號寫成 “Velo 964”）、有旋轉零件、難維護。
- 部署時用**相機**：便宜（約一百新幣）、耐摔。建圖只需要一台光達跑一次；整個車隊都裝相機。
- → **跨模態**：點雲沒有 SIFT 描述子，怎麼建立 2D–3D 對應？對應錯了，PnP 就全壞。

**第一次嘗試（2D3D-MatchNet）** [▶ 2:22:10](https://youtu.be/QsfybIs774o?t=8530)：

- 資料集的光達和相機已校準 → 可把 3D 點反投影到影像上得到真值對應。
- 3D 用 ISS 或 3DFeat-Net 抽關鍵點、2D 用 SIFT，用三元組損失學**跨模態描述子**。
- 首開先例，但匹配數很低——兩種模態本質不同。

**DeepI2P：把問題轉個彎** [▶ 2:23:36](https://youtu.be/QsfybIs774o?t=8616)：

1. **分類**：不學跨模態描述子，改成對每個 3D 點做 **0/1 二元分類**——它在不在這台相機的**視野**內？
   - 網路：點雲編碼器 + 影像編碼器，用注意力融合，解碼器輸出每點的標籤。
   - 【口頭】現在大概會用 Transformer：影像切 $16\times16$ patch，點雲用 FPS 分群當 token。
2. **最佳化位姿** [▶ 2:25:08](https://youtu.be/QsfybIs774o?t=8708)：用 **Gauss–Newton**（第 29 集）。不是最小化重投影誤差，而是移動相機位姿 $G$，讓被標成 1 的點盡量投影到影像內：
$$
\max_G\sum_i\left(\mathbb{1}\left[\pi\left(G,\mathbf{P}_i\right)\in\text{影像}\right]-0.5\right)\left(l_i-0.5\right)
$$
   - 兩個括號都對時同號、乘積為正；任一個錯就為負 → 最大化等於讓投影結果和網路標籤一致。
   - 實際上要用指數映射、對數映射轉成無約束最佳化，推導很複雜，論文有細節。

（式子依講者口述的兩項整理；「在影像內」的指示函數實際要換成可微的形式，逐字稿沒講。）

- **結果** [▶ 2:29:43](https://youtu.be/QsfybIs774o?t=8983)：網路標的點（綠色）很準；Gauss–Newton 第 0、40、80 次迭代逐漸移到正確位姿。
- 【口頭】講者的觀點：深度學習只負責一部分，其餘照正確的最佳化和數學來做，不要把一切丟進黑箱——RPM-Net 的 Sinkhorn 層也是同樣的精神（它就是在做指派矩陣）。

⚠️ 逐字稿缺字：講者說 DeepI2P「2019 年發表」，Whisper 把 bundle adjustment 寫成 “bandai adjustment”。

## 13. 一頁速查表

### 表示法

| | 顯式（參數式） | 隱式（體積式） |
|---|---|---|
| 定義 | $f:\Omega\subset\mathbb{R}^2\to S\subset\mathbb{R}^3$ | $S=\{\mathbf{x}\mid f(\mathbf{x})=0\}$ |
| 例 | 點雲、網格、樣條 | 佔據格、SDF（內負外正）、輻射場、八元樹 |

### 網路

| 方法 | 關鍵一步 |
|---|---|
| PointNet | 共享 MLP 逐點 → **max pool**（排列不變） |
| PointNet++ | FPS → $k$NN 分組 → 局部 PointNet，階層化 |
| NetVLAD | 軟指派到可學中心，殘差**求和**（排列不變） |

### 任務

| 任務 | 方法 | 關鍵想法 |
|---|---|---|
| 地點辨識 | PointNetVLAD | 子地圖檢索；惰性三元組（batch 內最難負樣本）、四元組 |
| 關鍵點 | 3DFeat-Net（弱監督）、USIP（自監督） | 注意力加權三元組；$T$ 前後關鍵點一致、限制感受野防退化、$\sigma$ 機率 Chamfer、點到點損失 |
| 物體偵測 | VoteNet | 種子投票 $\mathbf{y}=\mathbf{x}+\Delta\mathbf{x}$ → 分群 → 相對群中心迴歸 7 參數框 |
| 語意分割 | 弱監督（1 點／10%） | 不完全、孿生、不精確、平滑（= 標籤傳播）四分支 |
| 點雲配準 | ICP、RPM-Net、REGTR | ICP：最近鄰 + SVD 迭代（窄收斂盆地）；Sinkhorn 雙隨機 + 垃圾桶列行 |
| 影像對點雲 | 2D3D-MatchNet、DeepI2P | 視野內外分類 + Gauss–Newton 位姿 |

## 附：本集一句話總結

> **3D 表面可以顯式（點雲、網格：從 2D 參數域映到表面）或隱式（佔據、SDF、輻射場：純量函數的零水平集）表示；點雲簡單、有絕對尺度，但稀疏、不規則、無序，所以 PointNet 用共享 MLP 逐點處理再 max pool 達成排列不變、PointNet++ 再用 FPS 與 $k$NN 分組補回局部結構——在此基礎上，講者介紹了點雲檢索（PointNetVLAD）、弱／自監督關鍵點（3DFeat-Net、USIP）、投票式物體偵測（VoteNet）、弱監督分割、配準（ICP、Sinkhorn 的 RPM-Net）以及把影像對點雲配準轉成「視野內外分類 + Gauss–Newton」的 DeepI2P。**
