## 0. 這堂課要做什麼

真實情況：**不知道**哪個點對應哪個點。這集講 **ICP**（iterative closest point）：反覆「猜對應 → 用 2-07 的 SVD 解對齊」，以及讓 ICP 更快、更穩健的各種變體。

---

## 1. 複習：已知對應的解

[▶ 02:23](https://youtu.be/ktRqKxddjJk?t=143)

- 已知對應時（2-07）：直接解、不需初始猜測、最佳。這個問題算是**解決了**。
- $H = \sum p_n (x_n - x_0)(y_n - y_0)^{\mathsf T}$，SVD $H = UDV^{\mathsf T}$，$R = VU^{\mathsf T}$，$t = y_0 - Rx_0$。
- 直覺：先把兩組點的加權重心移到一起，再繞重心旋轉。

**未知對應** [▶ 05:29](https://youtu.be/ktRqKxddjJk?t=329)：

- **沒有**直接或最佳的解。
- 只能**迭代**：需要初始猜測；「最佳」也很難說，因為不知道資料關聯。

## 2. ICP 的基本想法

[▶ 06:16](https://youtu.be/ktRqKxddjJk?t=376)

- ICP：已有將近 30 年，是機器人、電腦視覺、電腦圖學等很多領域對齊點雲的標準演算法。
- 不知道對應就不能一步算出轉換。但可以**猜**對應，用 2-07 的方法算一個對齊。猜得不太差的話，對齊結果雖不完美，但比起點接近多了。
- **重複**：從新的位置重新猜對應、重新對齊……直到兩個表面對齊。

**前提** [▶ 08:49](https://youtu.be/ktRqKxddjJk?t=529)：要有某種**初始猜測**。離正解太遠，很可能不收斂。

- 初始猜測可以是：點在共同座標系中的位置（可能帶不確定性），例如平台的輪子編碼器估計掃描是在哪裡拍的。
- 或：一些可能的對應，例如空間中有明顯的點或特徵。
- 掃描的結構越複雜，越需要初始猜測。

**ICP 名稱的由來** [▶ 10:04](https://youtu.be/ktRqKxddjJk?t=604)：最簡單的做法：點雲 1 的每個點，找點雲 2 裡**最近的點**當作對應 → 算剛體轉換 → 對齊 → 重複，直到資料關聯不再改變。

只有初始組態「夠近」時才有效，而「夠近」事先很難說清楚。

【十四講補充】十四講 §7.9（書頁 196）的說法：3D-3D 位姿估計沒有用到相機模型。雷射 SLAM 裡雷射資料的特徵不夠豐富，不知道兩組點之間的匹配關係，只能把**距離最近**的兩點當作同一個點，所以叫「迭代最近點」。視覺裡特徵點提供了比較好的匹配關係，問題就簡單得多。十四講接下來用 ICP 指「**已匹配好**的兩組點之間的運動估計」。

## 3. Vanilla ICP 演算法

[▶ 11:39](https://youtu.be/ktRqKxddjJk?t=699)

```
Algorithm vanilla_ICP(Y, X):
  X̄ = X
  e = ∞
  while e decreased and e > threshold do
    C = 找對應(Y, X̄)                    // 例如最近點
    (R, t) = 已知對應的 SVD 解(Y, X̄, C)  // 2-07
    X̄ = R X̄ + t                         // 執行對齊
    e = Σ_{(i,j)∈C} ‖y_i - x̄_j‖²         // 重新算誤差
  endwhile
  return 累積的轉換
```

- 每一輪都用**更新後**的點雲找對應，希望找到更好的對應。
- 找不到更好的對應時，誤差不再下降 → 停止。

**兔子例子** [▶ 13:02](https://youtu.be/ktRqKxddjJk?t=782)：用歐氏距離找最近點，逐步對齊；這是講者的 **simple ICP** 專案（網路上有多種語言版本，教學用）。

**Vanilla ICP 的缺點** [▶ 13:51](https://youtu.be/ktRqKxddjJk?t=831)：

1. 依初始組態不同，可能要**很多次迭代**才收斂（兔子例子已經很接近了，還要跑一陣子）。
2. 對應不好時，結果可能**對錯**。

所以後來提出了大量 ICP 變體。

## 4. ICP 的四個可調整處

[▶ 14:50](https://youtu.be/ktRqKxddjJk?t=890)

| # | 調整處 | 問題 |
|---|---|---|
| 1 | **選哪些點** | 點雲很大（例如地面雷射掃描儀）時全部用太慢；怎麼選子集會大大影響結果 |
| 2 | **資料關聯** | 最近點是最好的嗎？不是 |
| 3 | **權重** | 比較確定的對應給較高權重 |
| 4 | **剔除離群值** | 可能錯的對應降權甚至權重設 0 |

想改善的指標：

- **速度**；
- **穩定性**、對感測雜訊和離群值的**容忍度**；
- **收斂域**（basin of convergence）：離最終組態多遠還能找到精確的參數，也就是**最大初始錯位**，對真實應用很重要。

## 5. 選哪些點：子取樣

[▶ 17:01](https://youtu.be/ktRqKxddjJk?t=1021)

| 策略 | 說明 |
|---|---|
| 全部的點 | 不丟任何資訊 |
| **均勻子取樣** | 空間上均勻的密度（不是每 10 點取 1 點）。感測器在近處點密、遠處點疏，所以要依距離調整取樣 |
| 隨機子取樣 | — |
| **特徵式** | 像影像的關鍵點和描述子；只取有特定性質、適合對齊的點（例如角落） |
| **法向空間取樣**（normal space sampling） | 大片平滑表面、法向量變化少時，在法向量變化的地方取多一點 |

**例子** [▶ 19:06](https://youtu.be/ktRqKxddjJk?t=1146)：

- Andreas Nüchter 的地下環境 3D 掃描：均勻子取樣、增量對齊（藍色是目前觀測），只用一部分點也能建出準確地圖。
- 法向空間取樣：大平面上只有小結構（突出的物體、彎曲處、雕刻）。在平面上點雲可以**滑動**而誤差不變；給有曲率的區域更高的權重，對齊得更好。這是特殊應用，一般掃描匹配通常不用。
- 特徵式：3D 場景中抽特徵（也做分類：建築表面、植被、桿子），依「在特徵空間中多有趣」取樣 → 一小組很獨特的點，簡化找對應，也可能更準。前提是特徵抽取器要好。

**實務** [▶ 22:16](https://youtu.be/ktRqKxddjJk?t=1336)：機器人應用（例如車子以 10、20 Hz 拿點雲）密度通常不高，大多用所有（可能有對應的）點。地面雷射掃描這種超密點雲才需要子取樣。

## 6. 資料關聯策略

[▶ 22:55](https://youtu.be/ktRqKxddjJk?t=1375)

【口頭】講者認為**找對資料關聯是最棘手的部分**，值得花大量腦力：一旦有正確的資料關聯，最佳解很容易就算出來。資料關聯影響收斂性、速度（要一直重估就要很多次迭代）和結果品質。

### 6.1 最近點

[▶ 25:03](https://youtu.be/ktRqKxddjJk?t=1503)

- 從藍色點雲選點，在紅色點雲找**最近的點**。
- 用 **k-d 樹**可以有效率地找（樸素搜尋是平方時間）。
- 普遍適用、很容易做；但不一定很好，常要很多次迭代。
- 需要**初始對齊**；完全不知道兩組點在哪時，在歐氏空間找最近點很麻煩。
- 這是 vanilla ICP 的度量，提出新方法時都要和它比較。

**沒有初始猜測時** [▶ 27:25](https://youtu.be/ktRqKxddjJk?t=1645)：

- 算兩組點的**重心**，把它們移到一起；甚至可以做**主成分分析**（PCA）得到朝向的初始猜測。
- 然後最近鄰搜尋（忽略距離太遠的對應）→ 對齊 → 再找對應……重複 20、30、50 次，最後完美重疊。

### 6.2 相容的最近點

[▶ 29:16](https://youtu.be/ktRqKxddjJk?t=1756)

- 如果點有更多資訊，只配對**相容**的點。
- 例：有相機看到顏色 → 只讓紅色配紅色，不讓紅色配藍色。也可以用法向量、曲率，或其他感測器的資訊。
- 也可以先只對齊相容的點，得到好的初始對齊，再用全部點。

### 6.3 法向射擊

[▶ 30:22](https://youtu.be/ktRqKxddjJk?t=1822)

- **法向射擊**（normal shooting）：沿一個點的表面法向量射一條射線，和另一個表面的交點當作對應。
- 平滑表面多時收斂稍好；場景複雜或距離量測雜訊大時反而**更差** → 現在不太流行了。

### 6.4 投影式資料關聯

[▶ 31:13](https://youtu.be/ktRqKxddjJk?t=1873)

- 依感測器位置的初始猜測，把一個點沿射線**投影**向感測器（相機的投影中心），看它和另一個表面的交點，當作對應。
- RGB-D 相機（同時給顏色和深度）普及後又流行起來，例如 **KinectFusion**。

### 6.5 點到平面

[▶ 31:50](https://youtu.be/ktRqKxddjJk?t=1910)

- 今天最常用。
- 還是找最近點，但誤差不用歐氏距離，而是投影到**法向量**上的距離。

| | 點到點（point-to-point） | 點到平面（point-to-plane） |
|---|---|---|
| 誤差 | $\| y_n - (Rx_n + t) \|^2$ | $\bigl( (Rx_n + t - y_n)^{\mathsf T} n_n \bigr)^2$ |
| 幾何意義 | 兩點的距離 | 點到「過 $y_n$、法向量 $n_n$ 的平面」的距離 |

（公式依講者口述「點到點的誤差向量和對應法向量做內積」整理。）

- 表面是用點雲取樣的，最近的點不一定是表面上真正對應的位置；投影到法向量上，誤差變小，表面可以沿切向滑動。
- **收斂快很多** [▶ 34:05](https://youtu.be/ktRqKxddjJk?t=2045)：兔子例子裡，點到平面很快就達到完美結果、不再變化，點到點還在迭代。
- 大部分 3D 對齊方法用點到平面。

**例子** [▶ 34:48](https://youtu.be/ktRqKxddjJk?t=2088)：

- 車上掃描儀：用里程計當初始猜測，用 ICP 對齊兩次掃描，得到拍攝位置之間的剛體轉換，串起來建地圖。
- 羅馬地下墓穴機器人：前方的深度相機，用點到平面對齊各次深度掃描，建 3D 模型。
- **投影式資料關聯＋點到平面** 通常一起用（KinectFusion）：已經建好模型，看射線和模型的交點當對應，再用點到平面對齊。
- 也能用在光達 SLAM：車子每秒 10 次把掃描對齊（投影式 ICP＋點到平面），就能建地圖、定位、規劃。只靠**增量掃描匹配**就能走很遠；回到已知區域時再做 SLAM 的**閉合迴圈**修正。

**小結** [▶ 37:34](https://youtu.be/ktRqKxddjJk?t=2254)：資料關聯是 ICP 成功的關鍵；有初始猜測一定要用；經驗法則：用法向量的度量（例如點到平面）通常比點到點好。

## 7. 權重

[▶ 38:28](https://youtu.be/ktRqKxddjJk?t=2308)

- 2-07 已經把權重 $p_n$ 放進加權重心和交叉共變異數矩陣，額外資訊可以直接放進去。
- 例：**雙眼相機**的 3D 重建，點越遠不確定性越大（取決於基線）→ 兩點都很確定的對應給高權重。（雷射比較不需要。）
- 也可以把可能是離群值或來自移動物體的點**完全丟掉**（權重 0）。

## 8. 剔除離群值

[▶ 40:15](https://youtu.be/ktRqKxddjJk?t=2415)

今天要做穩健的 ICP，一定需要某種離群值剔除或降權。

| 方法 | 說明 |
|---|---|
| **距離太大就丟** | 有好的初始猜測時，先忽略點對距離很大的對應，只用距離小的算初始對齊；之後對應可能會改變。最簡單 |
| **鄰點相容性** | 兩個在紅色表面上很近的點，對應到藍色表面上很遠的兩處 → 可能錯了 |
| **Trimmed ICP** | 依誤差排序，丟掉最差的一定比例（例如 10% 或 20%），只用最好的 80%。比例和預期離群值比例、掃描重疊程度有關，可能很難設定：設太多（例如丟 50%），在離群值多、重疊少時可能找不到正確對應而失敗 |
| **強健核**（robust kernel） | 強健最小平方常用的核函數，降低大誤差的影響。固定的核（例如 **Huber** 核），或**自適應**地線上估計核的形狀 |

- 強健核：一般最小平方是二次函數；其他核對遠的點給比較小的權重 → 算出的權重係數就直接當作 $p_n$ 放進最小化 [▶ 43:17](https://youtu.be/ktRqKxddjJk?t=2597)。詳見 2-15。
- `⚠️ 逐字稿缺字`：Whisper 寫 “Hoover kernel”、“Hooper kernel”，應為 **Huber kernel**。

**KITTI 高速公路例子** [▶ 43:52](https://youtu.be/ktRqKxddjJk?t=2632)：

- 車子在高速公路上，周圍結構很少，有其他車超車。
- 超車的車在動，卻提供很好的對齊特徵。ICP 如果「承諾」對齊那台車 → 失敗：固定（調過參數的）核下，車子看起來在**倒退**，因為對齊到往前開的車。
- 自適應核：那時核的值降得很低，等於剔除了大量離群值 → 對齊正確。
- `⚠️ 逐字稿缺字`：Whisper 寫 “kitty highway”，應為 **KITTI**（資料集）。

**實務** [▶ 45:13](https://youtu.be/ktRqKxddjJk?t=2713)：常常多管齊下：一些啟發式（假設環境裡不會發生的事）加強健核（簡單的用 Huber，進階的用自適應核）。也可以利用自運動的假設：裝在車上時，車子不太可能橫移。

**學習式：移動物體分割** [▶ 46:07](https://youtu.be/ktRqKxddjJk?t=2767)：

- 學出移動物體長什麼樣、在哪裡移動，再從對齊中排除。
- 例：點雲裡兩台車，一台停著（好特徵），一台在動。做**移動物體分割**（moving object segmentation），把掃描分成動態和靜態部分，當遮罩用 → 只在靜態點上找對應。
- 結果：有幾個被多標成移動的物體，但移動的部分都正確分割出來了。

**不用學習：從殘差找動態物體** [▶ 47:14](https://youtu.be/ktRqKxddjJk?t=2834)：

- RGB-D 相機建 3D 模型。世界靜態時很好；有人走過時，對齊出錯，模型完全損壞、無法使用。
- 做法：先用強健核做初步對齊，看新掃描和模型之間的**殘差**分布：大部分誤差很小，還有一個小峰通常是動態物體 → 用門檻剔除，只用靜態部分對齊。
- 單一影格的殘差圖可以清楚看出人在哪；用影像處理做出遮罩，只在黑色（靜態）區域對齊。
- 結果：模型一致，人沒有被整合進模型（有一點模糊，但好很多）；甚至可以把原本坐在椅子上、後來被認出會動的人從模型中移除，在更新模型和改善位姿之間反覆迭代。

## 9. 完整的 ICP 流程

[▶ 51:18](https://youtu.be/ktRqKxddjJk?t=3078)

```
repeat until convergence:
  1. （可選）子取樣，希望留下好的點
  2. 找對應（點到平面或其他方法）
  3. 剔除離群值、計算權重
  4. 用 2-07 的方法算旋轉和平移
  5. 套用到點雲，計算誤差
```

預告：下一部分（2-10）不用 SVD，改用**最小平方**解。

---

## 10. 一頁速查表

### 10.1 ICP

| 項 | 內容 |
|---|---|
| 核心迴圈 | 找對應 → SVD 對齊 → 套用 → 重複到誤差不再下降 |
| 前提 | 要有初始猜測（里程計、特徵、或至少對齊重心＋PCA） |
| 缺點 | 收斂慢；初始猜測太差或對應錯 → 對錯 |

### 10.2 四個可調整處

| 調整處 | 常見選擇 |
|---|---|
| 選點 | 全部、空間均勻、隨機、特徵、法向空間 |
| 資料關聯 | 最近點（k-d 樹）、相容點、法向射擊、投影式、**點到平面** |
| 權重 | 依不確定性（例如雙眼相機的距離）、強健核給的權重 |
| 離群值 | 距離門檻、鄰點相容性、trimmed、Huber／自適應核、移動物體分割、殘差門檻 |

### 10.3 誤差度量

| 度量 | 誤差 | 特點 |
|---|---|---|
| 點到點 | $\|y_n - (Rx_n + t)\|^2$ | vanilla，收斂慢 |
| 點到平面 | $((Rx_n + t - y_n)^{\mathsf T}n_n)^2$ | 可沿表面滑動，收斂快，最常用 |
