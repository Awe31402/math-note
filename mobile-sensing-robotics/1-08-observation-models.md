## 1. 觀測模型在貝氏濾波裡的位置

[▶ 00:37](https://youtu.be/SfwxLpdFB-o?t=37)

貝氏濾波兩步（1-03）：

| 步驟 | 公式 | 用的模型 |
|---|---|---|
| 預測 | $\overline{bel}(x_t) = \int p(x_t \mid x_{t-1}, u_t)\, bel(x_{t-1})\, dx_{t-1}$ | 運動模型（1-07） |
| 修正 | $bel(x_t) = \eta\, p(z_t \mid x_t)\, \overline{bel}(x_t)$ | **觀測模型**（本集） |

**觀測模型的意思** [▶ 02:01](https://youtu.be/SfwxLpdFB-o?t=121)：已知在某個狀態，得到某個觀測的**似然**（likelihood）。實際用法是：拿**真的拿到的**觀測 $z_t$，問「如果我在狀態 $x_t$，拿到這個觀測有多可能？」

【課本補充】課本 §6.1（書頁 122）：精確的感測器模型常常做不到，因為 (1) 建模很花時間，(2) 可能需要不知道的狀態變數（例如表面材質）。機率方法把觀測寫成條件分布 $p(z_t \mid x_t)$ 而不是確定的函數 $z_t = f(x_t)$，模型的不準就被吸收進隨機性裡。所以「實務上可以用非常粗糙的模型」，這是機率方法相對傳統方法的關鍵優點。

## 2. 測距感測器

[▶ 02:31](https://youtu.be/SfwxLpdFB-o?t=151)

**測距感測器**（range sensor）：給出到最近障礙物的距離。

| 例子 | 原理 |
|---|---|
| 2D 雷射掃描儀 | 量雷射脈衝來回的時間（time of flight，飛行時間），換算距離 |
| 3D 光達（Ouster） | 同上，但給 3D 資訊 |
| 雙眼相機 | 兩張影像的視差 |
| 主動式（結構光） | 投射紅外線圖樣，用相機看圖樣 |
| 聲納 | 用超音波而不是光 |

`⚠️ 逐字稿缺字`：[▶ 02:44](https://youtu.be/SfwxLpdFB-o?t=164) Whisper 寫 “the 6 scanner” 和 “Oyster 3D lighter”。依發音推測是 **SICK** 雷射掃描儀和 **Ouster** 3D 光達（lidar）。

- 不同感測器有不同參數和雜訊特性；這集只看最簡單的 **2D 雷射掃描儀**。
- 一次掃描給**一串**距離讀數：例如每 1° 或 0.5° 一個，每個讀數對應掃描儀座標系裡的一個方向 [▶ 03:52](https://youtu.be/SfwxLpdFB-o?t=232)。

## 3. 光束之間條件獨立

[▶ 04:22](https://youtu.be/SfwxLpdFB-o?t=262)

一次掃描 $z_t$ 有 $K$ 個讀數 $z_t^1, \dots, z_t^K$。假設：**已知感測器位置和地圖時**，各光束互相獨立：

$$
p(z_t \mid x_t, m) = \prod_{k=1}^{K} p(z_t^k \mid x_t, m)
$$

- 這是**條件**獨立，不是一般的獨立。條件是知道位姿 $x_t$ 和地圖 $m$。
- 把地圖 $m$ 明寫出來：例如手上有佔用網格或特徵地圖，要建一個能用來**定位**的觀測模型。
- 好處：只要會算**單一光束**的似然，整個掃描就是相乘。

**例子** [▶ 05:53](https://youtu.be/SfwxLpdFB-o?t=353)：

- 聲納掃描：有些光束剛好停在障礙物上，有些好像穿過障礙物，有些在機器人附近就反射回來。聲納比雷射雜訊大。
- 雷射掃描（前後各一台）：光束很密、解析度很高。
- 問題都是：如果機器人在這裡，拿到這次掃描有多可能？

【課本補充】課本 §6.1（書頁 123）指出這個獨立假設只在理想情況下成立。造成相依的原因包括：人（常常同時擋住好幾條相鄰光束）、地圖 $m$ 的誤差、後驗分布的近似等。

## 4. 最簡單的 ray-cast 模型

[▶ 07:21](https://youtu.be/SfwxLpdFB-o?t=441)

在佔用網格地圖上：

1. 從感測器位置沿光束方向**畫一條射線**，直到碰到第一個障礙物 → 得到**期望距離** $z^{k*}$（expected distance）：「依地圖，我應該量到多遠」。
2. 在期望距離周圍放一個**高斯**，代表量測雜訊。

- 「沿射線找障礙物」叫 **ray casting**（射線投射），所以這叫 **ray-cast 模型**。

**為什麼不夠** [▶ 09:07](https://youtu.be/SfwxLpdFB-o?t=547)：

- 【口頭】例子：你站在牆前面，牆在 10 公尺外；掃描儀很準，標準差 3 公釐。量到 1 公尺的機率是多少？依高斯，**幾乎是零**。
- 但這真的會發生：有人走過來站在機器人前面，擋住了牆。
- 你可以說這違反了靜態世界假設，但現實就是這樣。**不處理的話，系統會「慘烈地」失敗。**
- 一條光束的機率接近零 → 整個掃描（相乘）也接近零 → 正確的位姿被判成不可能。

## 5. 進階光束模型：四種成分的混合

[▶ 10:15](https://youtu.be/SfwxLpdFB-o?t=615)

圖上的分布形狀乍看很怪：期望距離附近有高斯峰，前面有一段衰減的函數、一個「小凹口」，整段有一個常數底，最右邊還有一根尖峰。它其實是**四個分布的加權和**：

| 成分 | 對應的情況 | 形狀 |
|---|---|---|
| $p_{\text{hit}}$ | 一般的量測雜訊 | 以期望距離為中心的高斯 |
| $p_{\text{short}}$ | 地圖上沒有的動態物體擋住 | 從 0 開始指數衰減，到期望距離截止 |
| $p_{\text{rand}}$ | 完全無法解釋的隨機讀數 | 整個量測範圍均勻 |
| $p_{\text{max}}$ | 最大距離讀數（沒收到回波） | 在 $z_{\max}$ 的尖峰 |

### 5.1 量測雜訊（高斯）

[▶ 12:05](https://youtu.be/SfwxLpdFB-o?t=725)

- 就是第 4 節的 ray-cast 模型：平均值 = 期望距離 $z^{k*}$，標準差 = 感測器的不確定性 $\sigma_{\text{hit}}$。
- 聲納的變異數比雷射大。【口頭】距離相機（range camera）的雜訊可能還會隨距離變化，形狀可以很複雜；但對一個給定的期望距離，它是固定的。

【課本補充】公式（課本式 (6.4)–(6.6)，書頁 126）：

$$
p_{\text{hit}}(z^k \mid x, m) =
\begin{cases}
\eta\, \mathcal{N}(z^k;\, z^{k*},\, \sigma_{\text{hit}}^2) & 0 \le z^k \le z_{\max} \\
0 & \text{otherwise}
\end{cases}
$$

$\eta$ 讓 $[0, z_{\max}]$ 上的積分等於 1：$\eta = \left( \int_0^{z_{\max}} \mathcal{N}(z;\, z^{k*},\, \sigma_{\text{hit}}^2)\, dz \right)^{-1}$。

### 5.2 意外障礙物（指數衰減）

[▶ 13:20](https://youtu.be/SfwxLpdFB-o?t=800)

處理「有人走過、擋住視線，量到比預期短的距離」。

**為什麼在期望距離截止**（那個「小凹口」的由來）[▶ 14:01](https://youtu.be/SfwxLpdFB-o?t=841)：

- 動態物體只有在**機器人和地圖上的障礙物之間**才看得到。
- 人走在你和牆**之間** → 擋住光束，被量到。
- 人走在牆**後面** → 根本看不到。
- 所以超過期望距離後機率掉到 0。
- 【口頭】如果你認為牆可能被拆掉，那後面就不該是 0 而是一個小值；但這裡忽略這種情況。

【課本補充】公式（課本式 (6.7)–(6.10)，書頁 127）：

$$
p_{\text{short}}(z^k \mid x, m) =
\begin{cases}
\eta\, \lambda_{\text{short}}\, e^{-\lambda_{\text{short}} z^k} & 0 \le z^k \le z^{k*} \\
0 & \text{otherwise}
\end{cases}
$$

正規化常數的推導：

$$
\int_0^{z^{k*}} \lambda_{\text{short}}\, e^{-\lambda_{\text{short}} z}\, dz
= \Bigl[ -e^{-\lambda_{\text{short}} z} \Bigr]_0^{z^{k*}}
= 1 - e^{-\lambda_{\text{short}} z^{k*}}
\quad\Rightarrow\quad
\eta = \frac{1}{1 - e^{-\lambda_{\text{short}} z^{k*}}}
$$

### 5.3 為什麼是指數衰減：位元串論證

[▶ 15:39](https://youtu.be/SfwxLpdFB-o?t=939)

講者說這是「物理上說得通」的模型，用位元串（bit string）解釋：

**假設**：

1. 動態物體在空間中**均勻分布**，沒有偏好的位置。
2. **只有最近的那個物體重要**：兩個人走過，光束只會被第一個人擋住，後面那個不管。

**一維、四格的例子** [▶ 17:09](https://youtu.be/SfwxLpdFB-o?t=1029)：感測器在左邊往右看。每格 0 = 空，1 = 有物體。所有可能的組態都同樣可能（數量不限：可能沒人、一個人、兩個人……）。

| 第一個物體在 | 位元串樣式 | 有幾種組態 |
|---|---|---|
| 第 1 格 | `1 ? ? ?` | $2^3 = 8$ |
| 第 2 格 | `0 1 ? ?` | $2^2 = 4$ |
| 第 3 格 | `0 0 1 ?` | $2^1 = 2$ |
| 第 4 格 | `0 0 0 1` | $2^0 = 1$ |
| 沒有物體 | `0 0 0 0` | 1 |
| 合計 | | $16 = 2^4$ |

- `?` 表示不在乎（後面有沒有人都一樣，因為已經被前面擋住）。
- 第一個物體在第 1 格的組態有 8 種，佔一半（50%），比其他所有情況加起來（$4 + 2 + 1 = 7$）還多。
- 第一個物體在第 $k$ 格的機率 $\propto 2^{-k}$：每遠一格，機率減半 → **指數衰減**。

結論：在這兩個假設下，量到**近**的回波比量到**遠**的回波可能得多，這就是指數衰減函數。衰減的參數可以從真實資料學：人多的環境和沒人的環境數值不同，但形狀都是指數衰減。

【課本補充】課本 §6.3.1（書頁 126）用兩個人的例子說明同一件事：兩個人以同樣的機率獨立出現，距離分別是 $z_1 < z_2$。只要第一個人在，就量到 $z_1$；要量到 $z_2$，必須第二個人在**而且**第一個人不在。所以 $z_1$ 比較可能。

### 5.4 隨機量測（均勻）

[▶ 21:45](https://youtu.be/SfwxLpdFB-o?t=1305)

- 完全沒建模到的事：例如牆被拆了、有人在牆後走動，或其他怪情況。
- 加一個小的**均勻分布**，所有距離機率一樣。
- 目的：不要因為某件沒考慮到的事，讓一條光束的機率變成 0，進而讓**整個掃描**作廢。

【課本補充】$p_{\text{rand}}(z^k \mid x, m) = \frac{1}{z_{\max}}$，當 $0 \le z^k < z_{\max}$（課本式 (6.12)）。課本舉的例子：聲納在牆之間來回反彈，或感測器之間的串擾（cross-talk）產生幻影讀數。

### 5.5 最大距離讀數

[▶ 22:26](https://youtu.be/SfwxLpdFB-o?t=1346)

- 感測器沒收到回波時，回報它的**最大量程** $z_{\max}$。這是一個「無效」讀數。
- 原因：障礙物太遠（例如量程只有 2 公尺，在空曠大廳裡）；全反射（光束被反射走，回不來）；其他掃描儀錯誤。
- 用一個固定機率表示。

【課本補充】課本 §6.3.1（書頁 127）補充失敗的原因：聲納以很斜的角度量光滑表面；雷射量**黑色、吸光**的物體，或在強光下量測。模型是在 $z_{\max}$ 的**點質量**：$p_{\max}(z^k) = I(z^k = z_{\max})$（$I$ 是指示函數，條件成立為 1，否則為 0）。嚴格說它沒有密度函數，畫圖時把它畫成 $z_{\max}$ 處一個很窄的均勻分布。

### 5.6 混合起來

[▶ 23:02](https://youtu.be/SfwxLpdFB-o?t=1382)

$$
p(z^k \mid x, m) = z_{\text{hit}}\, p_{\text{hit}} + z_{\text{short}}\, p_{\text{short}} + z_{\max}\, p_{\max} + z_{\text{rand}}\, p_{\text{rand}}
$$

$$
z_{\text{hit}} + z_{\text{short}} + z_{\max} + z_{\text{rand}} = 1
$$

（混合權重的記號依課本式 (6.13)。課本把第三個權重也寫作 $z_{\max}$，和最大量程同名，閱讀時要分清楚。）

- 四個權重，因為要正規化成 1，實際上是三個自由參數 [▶ 23:36](https://youtu.be/SfwxLpdFB-o?t=1416)。
- 另外還有各成分自己的參數（例如高斯的寬度 $\sigma_{\text{hit}}$、指數的 $\lambda_{\text{short}}$）。

**演算法**（課本表 6.1，書頁 129）：

```
Algorithm beam_range_finder_model(z_t, x_t, m):
  q = 1
  for k = 1 to K do
    用 ray casting 算出 z_t^k 的期望距離 z_t^{k*}
    p = z_hit · p_hit + z_short · p_short + z_max · p_max + z_rand · p_rand
    q = q · p
  return q
```

### 5.7 從資料學參數

[▶ 23:20](https://youtu.be/SfwxLpdFB-o?t=1400)

- 有些參數好拿：純量測雜訊，感測器規格書可能有；或在受控實驗裡把感測器放在牆前面量很多次，配一個高斯。
- 有些難拿：指數衰減的參數、各成分的權重。
- 做法：在**有代表性**的環境錄原始感測資料，從資料學參數。

**例子** [▶ 24:31](https://youtu.be/SfwxLpdFB-o?t=1471)：

- 感測器放在牆前 3 公尺，錄單一光束的時間序列；環境裡很多人走來走去。
- 畫成直方圖（每個距離出現幾次），再調整模型參數，讓參數化曲線盡量貼近直方圖。
- 結果顯示**隨機事件真的會發生**。資料越多、環境越有代表性，離群的點越少，模型越平滑。
- 這只對應「期望距離 3 公尺」；對其他期望距離（例如 4 公尺）要另外配。

**聲納** [▶ 26:10](https://youtu.be/SfwxLpdFB-o?t=1570)：聲納通常比雷射不準，但同一個模型也能用，只是參數不同。

**用法例子** [▶ 26:38](https://youtu.be/SfwxLpdFB-o?t=1598)：固定一次真實觀測和地圖，**改變位姿** $x$，畫出 $p(z \mid x, m)$。越暗的地方越可能是拍到這個觀測的位置。只靠一次觀測，就能看出最可能在某條走廊上；真實位置確實在那裡。也有其他幾個位置能解釋這個觀測：都是「站在兩扇開著的門前」，這在那個環境裡很常見。

【課本補充】課本 §6.3.2（書頁 129–134）給了一個學內在參數的演算法（表 6.2，基於最大似然），本集只說「從資料學」，沒講演算法細節。

## 6. 光束端點模型（似然場）

[▶ 27:57](https://youtu.be/SfwxLpdFB-o?t=1677)

**光束端點模型**（beam endpoint model），又叫**似然場模型**（likelihood field model）。

- **物理上說不通**：只看光束的**端點**，不管光束路徑上有沒有障礙物。
- 優點：**非常簡單、非常快**，而且效果出奇地好。

**做法** [▶ 28:31](https://youtu.be/SfwxLpdFB-o?t=1711)：

1. 用 $\sin$、$\cos$ 算出光束端點在地圖上的座標。
2. 最簡單版：問「那裡有障礙物嗎？」是或否。
3. 加上雜訊：問「端點離**最近的障礙物**多遠？」
   - 端點落在很空曠的地方 → 機率很低。
   - 端點落在牆附近 → 機率高。

**為什麼快** [▶ 29:29](https://youtu.be/SfwxLpdFB-o?t=1769)：

- 可以預先建一張**查表**：
  - 二值版：白格 = 空，灰格 = 障礙物。
  - 平滑版：把障礙物和高斯核做**卷積**（convolution），或用衰減函數「擴張」障礙物。
- 用二值影像的**歐氏距離轉換**（Euclidean distance transform）算出每格到最近障礙物的距離，很有效率。
- 拿到量測時，只要**查一格**就得到似然。
- 所以需要做大量評估的系統很愛用，例如**粒子濾波**（1-14）。

**沿一條光束看** [▶ 30:45](https://youtu.be/SfwxLpdFB-o?t=1845)：查表沿光束方向的亮暗，就是「在不同距離收到回波的機率」。但實際評估時，距離已經量到了，只要在這個函數上查**一個點**。

**從佔用網格到似然場** [▶ 31:30](https://youtu.be/SfwxLpdFB-o?t=1890)：

1. 對佔用網格的每一格，用歐氏距離轉換算到最近障礙物的距離。
2. 把距離丟進高斯衰減函數 → 得到地圖的「抹開版」。
3. 圖上通常反過來畫：亮 = 高機率，暗 = 低機率。
4. 給定位姿，算端點、查表，越亮似然越高。

【課本補充】端點座標（課本式 (6.33)，書頁 140）：機器人位姿 $(x, y, \theta)$，感測器在機器人座標系的位置 $(x_{k,\text{sens}}, y_{k,\text{sens}})$、光束相對朝向 $\theta_{k,\text{sens}}$：

$$
\begin{bmatrix} x_{z^k} \\ y_{z^k} \end{bmatrix}
=
\begin{bmatrix} x \\ y \end{bmatrix}
+
\begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}
\begin{bmatrix} x_{k,\text{sens}} \\ y_{k,\text{sens}} \end{bmatrix}
+ z^k
\begin{bmatrix} \cos(\theta + \theta_{k,\text{sens}}) \\ \sin(\theta + \theta_{k,\text{sens}}) \end{bmatrix}
$$

（感測器位置先從機器人座標轉到世界座標，再沿光束方向走 $z^k$。）

【課本補充】課本的似然場模型（§6.4，書頁 141–143）：
- 三種成分：$p_{\text{hit}}$ = 以 0 為中心、對「端點到最近障礙物的距離」的高斯；$p_{\max}$；$p_{\text{rand}}$。沒有 $p_{\text{short}}$。
- **最大距離讀數直接丟掉**（端點座標沒有物理意義）。
- 每條光束：$q \leftarrow q \cdot \left( z_{\text{hit}} \cdot \mathrm{prob}(\mathrm{dist}^2, \sigma_{\text{hit}}^2) + \frac{z_{\text{random}}}{z_{\max}} \right)$。

【課本補充】課本 §6.4.1（書頁 139–140）說明光束模型的兩個缺點，也就是似然場的優點：
1. **不平滑**：在桌椅很多的房間，位姿稍微動一點（特別是朝向），光束可能從打到桌腳變成打到後面的牆，似然劇烈跳動。近似的 belief 可能錯過正確狀態；爬山法容易卡在局部極值。似然場用歐氏距離，位姿小變化只造成似然小變化。
2. **計算量**：每條光束都要 ray casting。預先算好要涵蓋 3D 的位姿空間 $(x, y, \theta)$，表格很大；似然場只要在 2D 預先算。

| | 光束模型（ray cast） | 端點模型（似然場） |
|---|---|---|
| 物理意義 | 有（沿光束找第一個障礙物） | 沒有（只看端點） |
| 計算 | 每條光束要 ray casting | 查一格 |
| 預先計算 | 3D 位姿空間（大） | 2D 地圖（小） |
| 對位姿的平滑度 | 在雜亂環境不平滑 | 平滑 |
| 動態物體 | 有 $p_{\text{short}}$ | 沒有專門成分 |

## 7. 地標的觀測模型

[▶ 32:33](https://youtu.be/SfwxLpdFB-o?t=1953)

地圖是一串**地標**（landmark，特徵點）的位置。

### 7.1 距離—方位感測器

[▶ 32:57](https://youtu.be/SfwxLpdFB-o?t=1977)

- **距離—方位感測器**（range-bearing sensor）：例如旋轉的雷射測距儀，每個讀數都有距離和角度。從掃描裡抽出地標，就得到地標的距離和方位。
- 已知機器人位姿 $(x, y, \theta)$ 和地圖上地標 $j$ 的位置 $(m_{j,x}, m_{j,y})$，**期望**觀測是：

$$
\hat{r} = \sqrt{(m_{j,x} - x)^2 + (m_{j,y} - y)^2}
$$

$$
\hat\phi = \operatorname{atan2}(m_{j,y} - y,\; m_{j,x} - x) - \theta
$$

  - 距離：機器人到地標的歐氏距離。
  - 方位：從機器人指向地標的方向角，**減掉機器人自己的朝向**（因為感測器量的是相對於機器人前方的角度）。
- 再加上高斯雜訊（可以是一個聯合高斯，也可以距離、角度各一個，看怎麼建模）：

$$
\begin{bmatrix} r \\ \phi \end{bmatrix} = \begin{bmatrix} \hat r \\ \hat\phi \end{bmatrix} + \begin{bmatrix} \varepsilon_{\sigma_r^2} \\ \varepsilon_{\sigma_\phi^2} \end{bmatrix}
$$

【課本補充】課本 §6.6.2–6.6.3（書頁 148–150）：
- 特徵還可以帶一個**簽名**（signature）$s$，例如平均顏色、地標類型，同樣加高斯雜訊。
- 多個特徵之間假設條件獨立，可以一個一個處理。
- 需要**對應變數** $c_t^i$：第 $i$ 個觀測到的特徵對應地圖上第幾個地標。$c_t^i = N + 1$ 表示不對應任何已知地標（假地標，或建圖時看到的新地標）。
- 已知對應時的似然（表 6.4）：$q = \mathrm{prob}(r - \hat r, \sigma_r^2) \cdot \mathrm{prob}(\phi - \hat\phi, \sigma_\phi^2) \cdot \mathrm{prob}(s - s_j, \sigma_s^2)$。
- （草稿版表 6.4 第 4 行算 $\hat\phi$ 時漏了 $-\theta$，和式 (6.41) 不一致；以式 (6.41) 為準。）

**例子：RoboCup** [▶ 34:28](https://youtu.be/SfwxLpdFB-o?t=2068)：

- 機器人足球比賽，要估計機器人相對場邊幾根柱子（地標）的位置。三根柱子 1、2、3。
- 觀測到柱子 1 → 可能的位置是以柱子 1 為中心的一個圓（距離固定）。
- 觀測到柱子 2、3 → 各自另一個圓。
- 結合三個觀測 → 交在一處，正是機器人真正的位置。
- 重點：**單一觀測**可能無法決定完整狀態，但**多個觀測結合**就能定出位置。
- 這是 Dieter Fox 在早期 RoboCup 比賽做的機器人定位例子。用的模型和上面類似但不完全一樣。
- `⚠️ 逐字稿缺字`：Whisper 寫 “Robocop”、“data Fox”，應為 **RoboCup**、**Dieter Fox**。

### 7.2 只有方位的感測器

[▶ 35:52](https://youtu.be/SfwxLpdFB-o?t=2152)

- **只有方位**（bearing-only）：只能量角度，不知道距離。例如相機（講者舉一維的線相機為例）。
- 模型更簡單：

$$
\hat\phi = \operatorname{atan2}(m_{j,y} - y,\; m_{j,x} - x) - \theta
$$

  再加上高斯雜訊。
- 這是 2D 的情況，很容易推廣到 3D。

## 8. 總結

[▶ 36:53](https://youtu.be/SfwxLpdFB-o?t=2213)

- 貝氏濾波：遞迴狀態估計，用觀測模型和運動模型。實作有粒子濾波、Kalman 濾波、EKF、直方圖濾波等，常用本集的模型。
- 本集講了幾個常用的測距觀測模型，主要對付真實世界的問題：**動態物體**和**不完美的地圖**。
- 【口頭】如果你很了解感測器，可以花更多工夫校正參數。例如要極度精確地校正**地面雷射掃描儀**（terrestrial laser scanner），會用不同的方法。本集的模型是給**移動平台**用的：要很常評估，所以在簡單和處理現實問題之間取捨。
- 用相機或特徵地圖時：通常就是在**像素座標**上的高斯，對校正過的相機來說等於方位資訊。
- 用網格地圖：比較複雜，可能要預先計算，通常建查表以求效率。
- 延伸閱讀：《Probabilistic Robotics》第 6 章。

## 9. 一頁速查表

### 9.1 通用

| 項 | 公式 | 說明 |
|---|---|---|
| 光束獨立 | $p(z_t \mid x_t, m) = \prod_k p(z_t^k \mid x_t, m)$ | 給定位姿和地圖的條件獨立 |

### 9.2 光束模型（四成分混合）

| 成分 | 公式（課本） | 物理意義 |
|---|---|---|
| hit | $\eta\, \mathcal{N}(z^k; z^{k*}, \sigma_{\text{hit}}^2)$，$0 \le z^k \le z_{\max}$ | 量測雜訊 |
| short | $\eta\, \lambda e^{-\lambda z^k}$，$0 \le z^k \le z^{k*}$；$\eta = (1 - e^{-\lambda z^{k*}})^{-1}$ | 動態物體擋住；只在期望距離之前 |
| max | $I(z^k = z_{\max})$ | 沒收到回波 |
| rand | $1/z_{\max}$ | 無法解釋的讀數 |
| 混合 | $z_{\text{hit}} p_{\text{hit}} + z_{\text{short}} p_{\text{short}} + z_{\max} p_{\max} + z_{\text{rand}} p_{\text{rand}}$，權重和 = 1 | — |

**指數衰減的關鍵一步**：$n$ 格中第一個物體在第 $k$ 格的組態有 $2^{n-k}$ 種 → 機率 $\propto 2^{-k}$。

### 9.3 似然場

| 步驟 | 內容 |
|---|---|
| 1 | 端點座標 $= (x, y) + \mathrm{Rot}(\theta)(x_{\text{sens}}, y_{\text{sens}}) + z^k(\cos(\theta + \theta_{\text{sens}}), \sin(\theta + \theta_{\text{sens}}))$ |
| 2 | 查表：端點到最近障礙物的距離（歐氏距離轉換，預先算好） |
| 3 | $p = z_{\text{hit}}\, \mathcal{N}(\mathrm{dist}; 0, \sigma^2) + z_{\text{rand}}/z_{\max}$；丟掉最大距離讀數 |

### 9.4 地標

| 感測器 | 期望觀測 |
|---|---|
| 距離—方位 | $\hat r = \sqrt{(m_x - x)^2 + (m_y - y)^2}$，$\hat\phi = \operatorname{atan2}(m_y - y, m_x - x) - \theta$ |
| 只有方位 | $\hat\phi = \operatorname{atan2}(m_y - y, m_x - x) - \theta$ |
| 雜訊 | 各加一個零平均高斯 |
