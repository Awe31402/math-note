## 1. 這門課在講什麼

[▶ 00:22](https://youtu.be/ylMpdejm4mo?t=22)

- 這門課同時開給兩個碩士班：英文的 Geodetic Engineering（大地工程）和德文的 Geodesy and Geo-Information（大地測量與地理資訊）。課號開頭不同（MSR 或 M），內容一樣。
- 研究對象：**在環境中移動的系統**。它們要
  1. **感知**（perceive）環境，
  2. **建模**（model）環境，
  3. **做動作**（take actions）去達成目標，例如走到某個位置、或用感測器把整個區域掃過一遍（coverage）。
- 這門課講的是**基礎**：基本的狀態估計（state estimation）、遞迴濾波（recursive filtering）、定位（localization）、基本控制、路徑規劃（planning）。

[▶ 01:28](https://youtu.be/ylMpdejm4mo?t=88) 「自主移動系統」可以指：

| 例子 | 說明 |
|---|---|
| 小型自走車 | 裝著感測器在環境裡移動 |
| 無人機（UAV） | 飛在空中觀測地面 |
| 衛星 | 也在「感知資料」。差別是資料常在**事後離線**分析，但估計方法本身沒有不同【口頭】 |
| 行星探測車（planetary rover） | 所有運算都在車上完成，要自己看懂周圍、自己導航 |
| 自駕車 | 移動的感測平台，目標是到達某個位置 |

【口頭】講者強調：衛星資料離線處理、機器人線上處理，**對狀態估計演算法來說沒有本質差別**。

## 2. 移動機器人的兩個基本問題

[▶ 02:42](https://youtu.be/ylMpdejm4mo?t=162)

> **問題一：世界現在是什麼狀態？**（What is the state of the world?）
> **問題二：要做什麼動作，才能到達想要的目標狀態？**（Which action should I execute to reach a desired goal state?）

### 問題一 → 狀態估計（state estimation）

[▶ 03:04](https://youtu.be/ylMpdejm4mo?t=184)

- 輸入：感測器資料。輸出：有用的資訊。
- 系統關心的是某些**狀態變數**（state variables），例如：
  - 自己的位置，
  - 環境裡 3D 點的位置，
  - 其他能從感測資料推出來的資訊。
- 結果可以是一個值，也可以是一個**機率分布**，描述「狀態大概長怎樣」[▶ 03:29](https://youtu.be/ylMpdejm4mo?t=209)。這個分布後面叫做 belief（信念），見 1-03 集。

### 問題二 → 動作選擇（action selection）

[▶ 03:45](https://youtu.be/ylMpdejm4mo?t=225)

- 知道（或大概知道）世界的狀態後，決定怎麼把世界帶到另一個狀態。
- 「改變世界的狀態」可以是：
  - 機器人移動自己到另一個地方（導航指令），
  - 也可以是去搬動環境裡的物體。
- 目標：每一步都讓現在的狀態**更接近**想要的狀態。
- 工具：規劃（planning）技術；處理「動作執行有不確定性」時，用**決策過程**（decision processes，指 Markov decision process，見 1-19 集）[▶ 04:49](https://youtu.be/ylMpdejm4mo?t=289)。

### 兩個問題的關係

```
感測資料 ──► [狀態估計] ──► belief（對世界狀態的機率描述）──► [動作選擇] ──► 動作 ──► 世界改變 ──► 新的感測資料 …
```

（流程圖是筆記整理，講者是口頭描述這個順序。）

【課本補充】課本 §1.1 把「為什麼需要機率」講得更直接：機器人缺乏完成任務所需的關鍵資訊時，就有**不確定性**（uncertainty）。不確定性有五個來源（書頁 2，PDF 頁 14）：

1. **環境**：真實世界本來就難預測。
2. **感測器**：量測範圍和解析度有限，而且有雜訊。
3. **機器人本身**：馬達有控制雜訊、會磨損。
4. **模型**：模型是對真實世界的簡化，一定不完全準。
5. **計算**：要即時反應，只能用近似演算法。

課本 §1.2 的核心想法：**不要只存一個「最好的猜測」，而是存整個可能狀態空間上的機率分布**（書頁 3，PDF 頁 15）。

## 3. 離線估計 vs. 線上（遞迴）估計

[▶ 04:08](https://youtu.be/ylMpdejm4mo?t=248)

- 講者說：多數學生以前已經學過狀態估計，就是**最小平方法**（least squares）。
  - 做法：讓「實際觀測到的」和「在某個狀態下預期會觀測到的」盡量吻合。
  - 這是**離線**（offline）估計：資料全部收齊後一次算。
  - `⚠️ 逐字稿缺字`：Whisper 寫 “These squares problems”，依上下文是 **least squares problems**。
- 這門課重點是**線上**（online）估計：資料一筆一筆來，邊收邊更新。
  - 用的是**濾波**（filtering）技術：Kalman 濾波器（Kalman filter）、粒子濾波器（particle filter）。
  - 關鍵字是**遞迴**（recursive）：新的估計只用「舊的估計 + 新資料」算出來，不用把所有歷史資料重算一遍。

| | 離線（如最小平方） | 線上（如 Kalman、粒子濾波） |
|---|---|---|
| 資料 | 全部收齊再算 | 一筆一筆進來 |
| 算法 | 一次解一個大問題 | 每步遞迴更新 |
| 本課 | 假設學過；MSR2 再深入 | **主角** |

（筆記補充，講者本集沒提）最小平方法在 MSR2 會回來，用在 SLAM 和 ICP（見 2-05 集以後）。

## 4. 語意感知 vs. 幾何感知

[▶ 05:09](https://youtu.be/ylMpdejm4mo?t=309)

感知有兩大類問題：

1. **語意資訊**（semantic information）：影像裡哪個部分屬於哪一類。講者的例子：分出影像中哪些是作物（小麥植株）。
   - **本課不講**。這通常要用機器學習，之後的學期才講 [▶ 05:33](https://youtu.be/ylMpdejm4mo?t=333)。
2. **幾何資訊**（geometric information）：3D 點在哪、物體在世界的哪個位置。
   - **本課講這個**。

### 5.1 佔用網格地圖的直覺

[▶ 06:52](https://youtu.be/ylMpdejm4mo?t=412)

- 問的是：環境的這一塊，有沒有被障礙物佔住？是或否。
- 用途：路徑規劃的基本地圖。
- 【口頭】可以想成**建築平面圖**：牆和主要結構畫出來，空白的地方就是可以走的空間。差別是佔用網格是**從感測資料建出來的**，反映的是環境現在的樣子。

### 5.2 為什麼要先學運動模型和觀測模型

[▶ 07:40](https://youtu.be/ylMpdejm4mo?t=460)

- 要定位，先要懂系統**怎麼移動**。
- 也要懂**感測資料的意思**和它的不確定性。
- 理由：實作貝氏濾波時，需要兩個模型 [▶ 08:09](https://youtu.be/ylMpdejm4mo?t=489)：
  1. 一個動作會造成什麼結果 → **運動模型**；
  2. 一筆觀測代表什麼 → **觀測模型**。

這兩個模型就是 1-03 集貝氏濾波裡的 $p(x_t \mid u_t, x_{t-1})$ 和 $p(z_t \mid x_t)$（記號是筆記先預告，講者本集沒寫公式）。

### 5.3 為什麼要學這些基礎

[▶ 09:06](https://youtu.be/ylMpdejm4mo?t=546)

【口頭】今天任何機器人系統，自駕車也好、掃地機器人也好，都用到這門課的元素：怎麼在環境裡移動、怎麼估計自己的狀態、怎麼感知世界。進階系統的方法更複雜、更針對應用，但底層原理是一樣的。

【課本補充】課本 §1.2 用「全域定位」（global localization）舉例說明機率方法（書頁 3–4，PDF 頁 15–16）：機器人一開始不知道自己在哪，belief 是均勻分布；看到一扇門後，belief 在三扇門的位置各有一個高峰；移動後 belief 跟著平移、而且變得比較平滑（因為移動有不確定性）；再看到一扇門，機率就集中到其中一個位置。這個例子在 1-03 集貝氏濾波會再出現。

## 6. 課務規定

[▶ 09:41](https://youtu.be/ylMpdejm4mo?t=581)

  - 在 eCampus 發布和繳交，有截止日，要遵守。
  - 有正當理由要延期，**提早**講，不要截止當天才講。
  - **作業平均拿到 50% 才能參加考試**（[▶ 11:46](https://youtu.be/ylMpdejm4mo?t=706)）。

  - 【口頭】講者原話大意：寧可不交，也不要抄；做不完可以來談。

  - 為什麼不用 Matlab？Python 已是科學計算和快速原型（prototyping）的標準。

  - 有外部的 Python 教學影片清單（講者投影片上有網址，逐字稿沒有唸出來）。看懂講課不需要 Python，做作業需要。

## 7. 一頁速查表

本集沒有公式，只放名詞對照。

| 中文 | 英文 | 一句話 |
|---|---|---|
| 狀態估計 | state estimation | 從感測資料推出「世界現在的狀態」 |
| 動作選擇 | action selection | 決定做什麼才能更接近目標狀態 |
| 信念 | belief | 對狀態的機率分布，不只一個猜測值 |
| 遞迴濾波 | recursive filtering | 新估計 = f（舊估計, 新資料），不重算歷史 |
| 離線估計 | offline estimation | 資料收齊再一次算，例如最小平方法 |
| 線上估計 | online estimation | 資料邊來邊更新，例如 Kalman 濾波 |
| 語意資訊 | semantic information | 「這是什麼東西」——本課不講 |
| 幾何資訊 | geometric information | 「東西在哪裡」——本課主角 |
| 佔用網格地圖 | occupancy grid map | 每一格記「被障礙物佔住」的機率 |
| 運動模型 | motion model | 做了動作後，狀態怎麼變（含不確定性） |
| 觀測模型 | observation model | 在某狀態下，會量到什麼（含不確定性） |
| 不確定性的五個來源【課本】 | uncertainty | 環境、感測器、機器人、模型、計算 |
