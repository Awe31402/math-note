## 1. 作業的幾件事

[▶ 00:05](https://youtu.be/whE03c84ahA?t=5)

**解答很長，你不必那樣寫** [▶ 00:05](https://youtu.be/whE03c84ahA?t=5)：官方解答通常比期待你寫的詳細得多，「也許過不了數學系那關，但很接近」，很多是原本題目沒要求證明的。不用處理那些邊界情況。

**CVXPY 不是打字機前的猴子** [▶ 01:07](https://youtu.be/whE03c84ahA?t=67)

【口頭】不要把 CVXPY 作業當成「打一堆東西進去，不行就想辦法讓 CVXPY 接受我寫的」。「這跟我們要的完全相反，被我們發現會讓我們很火大。」**規範凸規劃（DCP）的前提是你知道自己在做什麼**：輸入一個非凸的東西，然後在論壇問「CVXPY 不接受我的 something squared == 3 約束」——「在這門課，這非常不酷」。

可以接受的錯誤：
- 宣告了變數 `x`，解完後以為 `x` 就是數值向量，其實要用 `x.value`。
- 混淆 `=`（Python 指派）和 `==`。在 CVXPY 裡，兩個 CVXPY 運算式之間的 `==` 被**多載成約束**；你可以隨便建立它，但要能解，兩邊都得是仿射的。

**怎麼知道做對了** [▶ 03:41](https://youtu.be/whE03c84ahA?t=221)：題目通常設計成可以**直覺地檢查**。有時會要你和某個簡單解比較，如果簡單解比你的好，就有問題。例：能源儲存的題目，「就算你是統計或生物背景，也該清楚：給你儲能，成本應該下降」。花五分鐘想一下：「酷，我在便宜時存電、貴時放電，省了錢。」

【Q&A】[▶ 07:48](https://youtu.be/whE03c84ahA?t=468) 學生問：為什麼實務上可能得到比簡單解差的結果？答：如果解的是**完全同一個問題**，那不可能，老師口誤了。可能的是**沒有改善**：「我有個好主意，加個儲能裝置」——結果完全沒幫助。

**題目的設計：「隱形」題** [▶ 05:46](https://youtu.be/whE03c84ahA?t=346)

【口頭】我們不會教完對偶就出「求這個問題的對偶」——那是高中程度，像「這是分部積分，求 $\int t^2\sin t\,dt$」。很多「**隱形題**」靠對偶解，但題目裡**不會出現 D 開頭那個字**。因為現實就是這樣：實習或新創裡沒人會說「救救我，我想可以用擇一定理解這個問題」，而是「天啊，這太複雜了，我們有這個估計器、那些估計值要結合……」，你的工作是找個安靜的地方想一想，然後說「哇！這能解」——而且是透過對偶。

**期中考 ChatGPT 的表現** [▶ 08:18](https://youtu.be/whE03c84ahA?t=498)：學生說 **43 分拿 12 分**。老師：「執行摘要是：很爛，我很高興宣布。但我相信它寫得很漂亮、很有條理、聽起來很對。」

## 2. 重新表述會改變對偶

[▶ 10:24](https://youtu.be/whE03c84ahA?t=624)

接續上次的圖：$P$ 與 $\tilde P$ 等價，$D$、$\tilde D$ 分別是它們的對偶。

- 大家說「**the** Lagrange 對偶」，但其實你有權先做一些小轉換再取對偶；做法不同，對偶也不同，有些還有人名（例如 QP 的某某對偶）。
- 強對偶下（「從現在起我們就這樣假設，這不是數學課」）它們最佳值相同。
- **結論：即使是極簡單的轉換，也可能得到截然不同的對偶** [▶ 11:57](https://youtu.be/whE03c84ahA?t=717)。

### 2.1 引入新變數

[▶ 12:27](https://youtu.be/whE03c84ahA?t=747)

$$P:\quad\text{minimize }f_0(Ax+b)\qquad(f_0\text{ 凸})$$

**無約束問題的 Lagrange 對偶**：沒有約束 → Lagrangian 就是目標 → 對偶函數沒有對偶變數，就是 $\inf f_0=p^\star$。

【口頭】[▶ 12:58](https://youtu.be/whE03c84ahA?t=778)「它確實是 $p^\star$ 的下界，也**完全沒用**。」「有人說『我需要最佳值的下界』，你說『我有個很棒的下界：最佳值』。」好幾個笑話的梗都是這樣：「那些人一定是數學家——答案完全正確，也完全沒用。」

**無辜的轉換** [▶ 14:00](https://youtu.be/whE03c84ahA?t=840)：

$$\tilde P:\quad\text{minimize }f_0(y)\quad\text{s.t.}\quad Ax+b-y=0$$

$$\tilde D:\quad\text{maximize }b^T\nu-f_0^*(\nu)\quad\text{s.t.}\quad A^T\nu=0$$

這個對偶**有意思**，而且裡面出現了共軛。

【課本補充】§5.7.1 推導：
$$g(\nu)=\inf_{x,y}\left(f_0(y)-\nu^Ty+\nu^TAx+b^T\nu\right)$$
對 $x$ 的下確界：$A^T\nu\ne0$ 時 $-\infty$，否則 0；對 $y$ 的下確界：$\inf_y(f_0(y)-\nu^Ty)=-f_0^*(\nu)$。所以 $g(\nu)=b^T\nu-f_0^*(\nu)$（若 $A^T\nu=0$）。

### 2.2 範數近似的對偶

[▶ 15:01](https://youtu.be/whE03c84ahA?t=901)

$$\text{minimize }\|Ax-b\|\ \longrightarrow\ \text{minimize }\|y\|\quad\text{s.t.}\quad y=Ax-b$$

對偶：

$$\text{maximize }b^T\nu\quad\text{s.t.}\quad A^T\nu=0,\ \|\nu\|_*\le1$$

- 對 $y$ 最小化 $\|y\|-\nu^Ty$ 得到**對偶範數的指示函數**（第 7 集 §3.4 的結果）。
- 若改用 $\|Ax-b\|^2$ 會得到**不同的**對偶（留給你自己試）。
- 有人會說「這個問題的對偶是那個」，也有人會說「無約束問題的對偶很蠢」；大家允許你這種權宜。

**對偶中該預期看到的模式** [▶ 16:33](https://youtu.be/whE03c84ahA?t=993)

【口頭】
- 原問題出現某函數 → 對偶裡**預期看到它的共軛**。原問題有 KL 散度、相對熵 → 還沒算就該預期對偶有**指數、log-sum-exp**；沒出現就該回頭檢查。
- 原問題有 $A$ → 對偶出現 $A^T$（伴隨）毫不意外。
- 【課堂討論】[▶ 17:39](https://youtu.be/whE03c84ahA?t=1059) 原問題有 $\ell_\infty$ 範數，對偶該有什麼？學生：**$\ell_1$ 範數**。對。
- 有人會做成對照表，老師覺得把它當成「你該預先載入的模式」比較好。

### 2.3 把約束藏進目標：盒約束 LP

[▶ 18:12](https://youtu.be/whE03c84ahA?t=1092)

$$\text{minimize }c^Tx\quad\text{s.t.}\quad Ax=b,\ -\mathbf{1}\preceq x\preceq\mathbf{1}$$

（$-1\le x_i\le1$ 叫**盒約束**，box constraint。）

**方法 1：直接取對偶**（LP 的對偶）：
$$\text{maximize }-b^T\nu-\mathbf{1}^T\lambda_1-\mathbf{1}^T\lambda_2\quad\text{s.t.}\quad c+A^T\nu+\lambda_1-\lambda_2=0,\ \lambda_1,\lambda_2\succeq0$$

**方法 2：把盒約束做成指示函數放進目標**（**部分對偶化**、partial Lagrangian）[▶ 18:42](https://youtu.be/whE03c84ahA?t=1122)：
$$\text{minimize }f_0(x)=\begin{cases}c^Tx&-\mathbf{1}\preceq x\preceq\mathbf{1}\\\infty&\text{否則}\end{cases}\quad\text{s.t.}\quad Ax=b$$

盒約束從**明確**變成**隱含**（不可行時目標回傳 $+\infty$）。現在要在盒子上最小化一個仿射函數 [▶ 19:45](https://youtu.be/whE03c84ahA?t=1185)：

$$g(\nu)=\inf_{-\mathbf{1}\preceq x\preceq\mathbf{1}}\left(c^Tx+\nu^T(Ax-b)\right)=-b^T\nu+\inf_{-\mathbf{1}\preceq x\preceq\mathbf{1}}(A^T\nu+c)^Tx=-b^T\nu-\|A^T\nu+c\|_1$$

（老師說這像 Cauchy–Schwarz，叫 **Hölder 不等式**：向量某分量為正就取 $x_i=-1$，為負就取 $+1$，最小值是絕對值和取負號。）

$$\text{maximize }-b^T\nu-\|A^T\nu+c\|_1$$

- 盒約束就是 $\|x\|_\infty\le1$，對偶出現 $\ell_1$——符合上面的「模式」。
- **這次 $D$ 和 $\tilde D$ 很接近** [▶ 21:16](https://youtu.be/whE03c84ahA?t=1276)：方法 1 裡 $\lambda_1,\lambda_2\ge0$、差為 $c+A^T\nu$（的負），要最大化 $-\mathbf{1}^T(\lambda_1+\lambda_2)$；盯久了會發現最佳值恰好是 $-\|A^T\nu+c\|_1$，方法 2 寫成 LP 就是方法 1。

## 3. 廣義不等式的對偶

[▶ 21:50](https://youtu.be/whE03c84ahA?t=1310)

$$\text{minimize }f_0(x)\quad\text{s.t.}\quad f_i(x)\preceq_{K_i}0,\ i=1,\dots,m,\quad h_i(x)=0$$

（$f_i(x)$ 是向量，例如可以表示「某矩陣半負定」。）「記號設計得好，一切都照常運作。」

- Lagrangian 用**內積**：$L=f_0(x)+\sum_i\lambda_i^Tf_i(x)+\sum_i\nu_ih_i(x)$。
- 要求 $\lambda_i\succeq_{K_i^*}0$（在**對偶錐**中非負）。
- 下界性質同樣成立 [▶ 23:26](https://youtu.be/whE03c84ahA?t=1406)：純量時用「非負數乘非正數 ≤ 0」；這裡用「**對偶錐中的向量和錐中非正向量的內積 ≤ 0**」（$\lambda\in K^*$、$-f_i\in K$ ⇒ $\lambda^T(-f_i)\ge0$，由對偶錐定義）。之後所有東西都照常運作。

**例：SDP 的對偶** [▶ 24:26](https://youtu.be/whE03c84ahA?t=1466)

【口頭】「25、30 年前沒人知道這個，那會很驚人。」

$$\text{minimize }c^Tx\quad\text{s.t.}\quad x_1F_1+\cdots+x_nF_n+G\preceq0$$

- 乘數改叫 $Z$（對稱矩陣，$Z\succeq0$，因為 $\mathbf{S}^k_+$ 自對偶）。$\mathrm{tr}(Z\cdot)$ 讀作**內積**，對應純量時的 $\lambda^Tf_1(x)$。
- $L=c^Tx+\mathrm{tr}\left(Z(x_1F_1+\cdots+x_nF_n+G)\right)$，對 $x$ 是仿射；線性部分不為零就 $-\infty$：$x_1$ 的係數是 $c_1+\mathrm{tr}(ZF_1)$，必須為 0 [▶ 26:00](https://youtu.be/whE03c84ahA?t=1560)。

$$\text{maximize }\mathrm{tr}(GZ)\quad\text{s.t.}\quad Z\succeq0,\ \mathrm{tr}(F_iZ)+c_i=0,\ i=1,\dots,n$$

- 弱對偶完全直接；**強對偶不顯然**（課本：原問題嚴格可行時成立）。

## 4. 擇一定理（可行性問題的對偶）

[▶ 27:05](https://youtu.be/whE03c84ahA?t=1625)

老師說這個課堂沒正式講，但期待你懂。

【Q&A】[▶ 27:35](https://youtu.be/whE03c84ahA?t=1655) 學生問：是不是那題選擇權定價的題目？老師：「是的，對不起，你**現在**就會遇到了。我剛把答案洩露了，沒關係。」

**可行性問題寫成最佳化**：
$$\text{minimize }0\quad\text{s.t.}\quad f_i(x)\le0,\ h_i(x)=0$$
$p^\star\in\{0,+\infty\}$（不可行時 $\inf\varnothing=+\infty$）。取對偶得 $d^\star$，**弱對偶 $d^\star\le p^\star$ 永遠成立**，凸不凸都一樣。

【課堂討論】[▶ 28:36](https://youtu.be/whE03c84ahA?t=1716)
- 原問題是一組**非凸**不等式，若對偶**無上界**（$d^\star=+\infty$），能說什麼？學生：**原問題不可行**。老師扮演反對者：「判斷那組不等式是否可行是 NP-hard 耶！」學生：（因為它是）**下界**。對，這完全基本。
- 甚至只要找到一個對偶可行點，代入得 $d=1$，能結論什麼？——**不可行**。因為 $p^\star$ 只能是 0 或 $+\infty$；1 是它的下界，所以只能是 $+\infty$。

**擇一定理**（theorems of alternatives）[▶ 29:46](https://youtu.be/whE03c84ahA?t=1786)：凸情況下，「這組不等式有解 $\iff$ 另一組沒有解」。線性不等式的有名版本叫 **Farkas 引理**。

【口頭】[▶ 30:47](https://youtu.be/whE03c84ahA?t=1847) 這是很多古典經濟和金融的基礎：能投資的東西若**在所有情況下都不賠、某些情況會賺**，就叫**套利**；古典金融說這不可能（價格會調整、有人會去利用它）。「我在避險基金的朋友會向你保證它會發生。」有位朋友說他們看到履歷上某個系就直接丟掉：**經濟系**。「電機、應用物理、數學都很棒。」「為什麼不要經濟？」「為什麼要雇一個來自『最根深蒂固的信念就是**沒有套利**』這種領域的人？套利正是我們在做的事。」「我們都笑了，大部分是玩笑，但不完全是。」

## 5. 近似與擬合：範數近似

[▶ 32:19](https://youtu.be/whE03c84ahA?t=1939)

「這結束了課程第一部分（全部理論）。接下來三週看應用，分類組織；過一陣子它們看起來都一樣——因為它們**就是**一樣的。」

$$\text{minimize }\|Ax-b\|\qquad(A\in\mathbb{R}^{m\times n},\ m\ge n,\ \|\cdot\|\text{ 任意範數})$$

**解釋** [▶ 33:22](https://youtu.be/whE03c84ahA?t=2002)：

| 觀點 | 意思 |
|---|---|
| 幾何 | $Ax^\star$ 是 $\mathcal{R}(A)$ 中（以這個範數）離 $b$ 最近的點 |
| 估計 | 線性量測模型 $y=Ax+v$，見下 |
| 最佳設計 | $x$ 是設計變數，$Ax$ 是結果，$x^\star$ 讓結果最接近目標 $b$ |

**估計的解釋** [▶ 33:52](https://youtu.be/whE03c84ahA?t=2032)（先不用統計）：
- $x$：要估計但不能直接量的參數。例：引爆炸藥、用地震檢波器量；或飛一台磁異常偵測器量極微小的磁場變化，想知道地下一公里有什麼。
- $A$：叫**模型**或**正向模型**（forward model），通常來自物理：「如果這裡有這些點源，照物理擴散，我們在各地會量到這些 CO₂ 濃度。」
- $v$：量測誤差（至少有感測器誤差，「CO₂ 量得多準？正負 3 ppm 之類」）。
- 你知道 $y$，不知道 $x$、$v$。因為沒說任何關於 $v$ 的事，**任何 $x$ 都可能**（令 $v=y-Ax$）。

【口頭】[▶ 35:56](https://youtu.be/whE03c84ahA?t=2156) 有人把 $y-Ax$ 叫**物理殘差**（physics residual），「很美的名字」。你可以說「我決定根本沒有 CO₂ 源。」「那這些量測是什麼？」「量測誤差而已。」——技術上合法但荒謬。所以需要衡量 $v$ 的**可信度**：之後用統計（分布、最大概似），現在就用**範數**表示「量測誤差有多不可信」。

**設計的解釋** [▶ 37:59](https://youtu.be/whE03c84ahA?t=2279)：$x$ 是衛星推進器點火序列，要把衛星移到目標。到得了，範數為 0，那就是解；到不了，範數表示「錯過目標你最不開心的方式」——2 範數就是「盡量靠近目標軌跡上的點，最小化離軌道幾公尺」。

**例子** [▶ 38:34](https://youtu.be/whE03c84ahA?t=2314)：

| 範數 | 名字 | 解法 |
|---|---|---|
| $\|\cdot\|_2$（平方） | 最小平方 | 正規方程 $A^TAx=A^Tb$ |
| $\|\cdot\|_\infty$ | **Chebyshev 近似**（極小極大） | 化成 LP |
| $\|\cdot\|_1$ | 絕對殘差和 | 化成 LP |

【口頭】[▶ 39:37](https://youtu.be/whE03c84ahA?t=2377) 現在不用知道怎麼化成 LP：在 CVXPY 一行就好，大致是 `Problem(Minimize(norm(A @ x - b, 1))).solve()`，「加上正確數量的右括號」。

## 6. 懲罰函數近似

[▶ 40:07](https://youtu.be/whE03c84ahA?t=2407)

【口頭】「這非常重要，**不要過度解讀**，它就是聽起來那麼簡單蠢，但也非常有用。」

$$
\begin{aligned}
\text{minimize}\quad & \phi(r_1)+\cdots+\phi(r_m)\\
\text{subject to}\quad & r=Ax-b
\end{aligned}
$$

$\phi:\mathbb{R}\to\mathbb{R}$ 是凸的**懲罰函數**（penalty function）；目標是**可分的**（separable）：各分量函數的和。

### 6.1 常見懲罰函數與數值例子

| 懲罰 | $\phi(u)$ | 備註 |
|---|---|---|
| 二次 | $u^2$ | 最小平方 |
| 絕對值 | $\lvert u\rvert$ | $\ell_1$ 近似 |
| **死區線性**（deadzone-linear） | $\max\{0,\lvert u\rvert-a\}$ | $\lvert u\rvert\le a$ 完全不在乎，外面線性增長 |
| **對數障礙**（log barrier） | $-a^2\log\left(1-(u/a)^2\right)$，$\lvert u\rvert<a$；否則 $\infty$ | 小殘差時很接近二次，接近 $\pm a$ 衝到無窮大 |

（名字不是標準的，「但大家都懂」。）

**擬人化** [▶ 41:44](https://youtu.be/whE03c84ahA?t=2504)：「$\phi(r)$ 告訴你殘差那麼大時**你有多煩**。就這麼簡單蠢。」

【課堂討論】[▶ 42:15](https://youtu.be/whE03c84ahA?t=2535) 什麼時候「誤差在 $\pm a$ 內完全不在乎」合理？學生舉外送（DoorDash）準時的例子，老師沒完全聽懂。老師的例子：量測用 **5 位元**轉換器，只有 32 個可能值，落在某個小區間的量測都會映到同一個值；比 **LSB**（最低有效位元）還小的差異「完全是虛構的，毫無意義」，所以用死區。

> 老師先說 5 位元轉換器（32 個值），後面又說「6-bit a to d converter」；前後不一致，不影響論點。

【Q&A】[▶ 43:48](https://youtu.be/whE03c84ahA?t=2628) 學生問能不能用在不等式上？答：可以，「如果你對違反不等式有奇怪的個人看法」，做法完全一樣。

**數值例子**（課本 Figure 6.2）[▶ 44:18](https://youtu.be/whE03c84ahA?t=2658)：$A\in\mathbb{R}^{100\times30}$ 隨機產生。畫各懲罰下殘差的直方圖：

| 懲罰 | 殘差分布 | 擬人化 |
|---|---|---|
| 二次 | 很多小殘差、少數較大 | 小殘差的代價是「小的平方，非常小」；有些大殘差「那一個很痛」 |
| 對數障礙（$a=1$） | 和二次類似，但**全部在 $\pm1$ 內** | 「最小平方加了個夾子，把夾子鎖緊」；殘差變大時比二次更煩 |
| 死區線性（$a=0.5$） | 一堆殘差**擠在 $\pm0.5$ 邊界** | 見下 |
| $\ell_1$ | **很多殘差恰好是 0**（30 多個） | 見下 |

【課堂討論】[▶ 47:23](https://youtu.be/whE03c84ahA?t=2843) 死區線性為什麼一堆殘差擠在 $\pm a$？學生：再往內「對我沒好處」。對：把殘差推到「不在乎」的邊界就停了，何必再花力氣？

**$\ell_1$ 為什麼產生 0** [▶ 48:24](https://youtu.be/whE03c84ahA?t=2904)：
- 二次：殘差 9→10 差很多，1→2 差很少（平方一下就知道）；殘差變小時你**在乎得越來越少**（「很佛系」）。
- 絕對值：9→10 和 1→2 的差**完全一樣**；**縮小殘差的邊際好處一直維持到 0**。
- **懲罰函數在 0 有尖角 ⇒ 預期解有很多 0**。在壓縮感知等領域有人造出極複雜的理論，「但重點就只是邊際改善維持到 0」。

**大殘差端** [▶ 50:27](https://youtu.be/whE03c84ahA?t=3027)：懲罰函數在大值處的增長告訴你對大殘差有多在意。**線性增長** = 對幾個大殘差比較「佛系」（殘差 10：二次是 100，絕對值只是 10）。這會導向**強健估計器**。

【Q&A】[▶ 51:28](https://youtu.be/whE03c84ahA?t=3088) 學生問：$\phi$ 在 0 附近還是會隨距離增加，為什麼對數障礙和二次的殘差沒有更集中在 0？答：「我保證這些就是最佳解，資料是隨機的。如果能更集中，它就會。」

### 6.2 擬人化地設計懲罰函數

[▶ 52:28](https://youtu.be/whE03c84ahA?t=3148)

【課堂討論】老師畫一個**不對稱**的分段線性懲罰（正側斜率約是負側的 4 倍），問什麼意思？學生：「你偏向低估。」對：**正殘差讓你煩的程度大約是負殘差的 4 倍**。老師說這個函數之後做**分位數估計**（quantile estimation）時會出現。

【課堂討論】[▶ 53:34](https://youtu.be/whE03c84ahA?t=3214)「殘差在 $\pm0.5$ 內完全不在乎（量測沒那麼準），而且很不希望殘差大於 0.5」——學生建議：同樣的死區，但右側更陡。再加上「很負的殘差也越來越煩」→ 在左側加上曲率，往上彎。「用 CVXPY 打進去兩行，我可以弄成一行。」

### 6.3 Huber 懲罰與強健迴歸

[▶ 55:07](https://youtu.be/whE03c84ahA?t=3307)

【口頭】「每個人都該知道，我甚至會把它放進這門課你該帶走的前 10 名。」

$$\phi_M(u)=\begin{cases}u^2&\lvert u\rvert\le M\\M(2\lvert u\rvert-M)&\lvert u\rvert>M\end{cases}$$

閾值 $M$ 內是二次，外面**線性增長**（銜接處連續可微）。

【課堂討論】[▶ 55:40](https://youtu.be/whE03c84ahA?t=3340)「用文字、不要數學」解釋用 Huber 做迴歸是什麼感覺？學生：小殘差像二次，大了以後比較不在意。老師：「我有點想做最小平方；但**如果非有大殘差不可**，我比最小平方佛系得多。」線性尾巴讓它成為**強健**（robust）懲罰／估計器。

**例：直線擬合**（課本 Figure 6.5）[▶ 57:13](https://youtu.be/whE03c84ahA?t=3433)：42 個點，其中兩個是離群值。

【課堂討論】最小平方擬合（虛線）為什麼被扭過去？學生：那兩點的平方殘差很大，所以它努力縮小它們。對：兩個巨大殘差給了很強的誘因去改變擬合，結果被「扭轉」。

**力學解釋** [▶ 58:13](https://youtu.be/whE03c84ahA?t=3493)：把懲罰當成彈簧的**位能**。
- 二次 = **Hooke 彈簧**（對稱，位能是位移平方）。想像擬合直線上掛著垂直的彈簧，處於力學平衡。兩個離群點的彈簧拉力很大——一個往上拉、一個往下拉——產生巨大的**力矩**，其他點只貢獻幾牛頓。
- Huber = 拉到某點後位能**線性**增長的彈簧，也就是之後施加**定力**，不再隨距離增加。所以離群點拉不動它。

【口頭】[▶ 59:46](https://youtu.be/whE03c84ahA?t=3586)
- 這個例子很蠢（$\mathbb{R}$ 上的點，用眼睛畫線就好），但在一點也不顯然的情況下效果一樣。
- 「大多數人擬合資料時大概都**應該用 Huber，而不是最小平方**。」有驚人的例子：20%、30% 的資料點是瘋狂的離群值，它照樣能用。
- 以統計學家 **Peter Huber** 命名，他是從未知分布等第一原理推出這個函數的。「我們業餘的解釋：小殘差和最小平方一樣，大殘差增長溫和得多——比較佛系，不會因為一個大殘差就抓狂、產生那個力矩。」

**可以隨意組合** [▶ 1:01:21](https://youtu.be/whE03c84ahA?t=3681)：範數近似加任何凸約束都還是凸的。【課堂討論】「**Huber 單調迴歸**」是什麼？——用 Huber 懲罰做迴歸，加上 $x_1\le x_2\le\cdots$。「大概有五篇論文在講它，幾乎肯定在某個應用超有用。」有人說「我知道一個很花俏的演算法」——「停，別再說了，你在讓自己難堪，我們知道 50 種解法，全都比你的好。」

## 7. 最小範數問題

[▶ 1:02:27](https://youtu.be/whE03c84ahA?t=3747)

$$\text{minimize }\|x\|\quad\text{s.t.}\quad Ax=b\qquad(A\in\mathbb{R}^{m\times n},\ m\le n)$$

幾何：$x^\star$ 是仿射集 $\{x\mid Ax=b\}$ 中離原點最近的點（要投影到別的點就用 $\|x-x_0\|$）。

| 解釋 | 例子 |
|---|---|
| **估計**：量測很準（或非常準），但**不夠多** | 晶片上有溫度感測器，夠準；但想知道沒裝感測器的點的溫度。$x$ = 所有點的溫度，$Ax=b$ = 符合量測，但不足以決定 $x$。需要可信度量測：$\|x\|$ 小 |
| **設計**：$Ax=b$ 是要求，最小化 $\|x\|$ | 最省燃料運動：把衛星移回該在的位置 |

- 最小平方版本你已經知道；$\ell_1$ 版本是燃料消耗的初步模型。
- **最小懲罰**（課本 §6.2）[▶ 1:05:07](https://youtu.be/whE03c84ahA?t=3907)：$\min\sum\phi(x_i)$ s.t. $Ax=b$。【口頭】問推進器專家：他們給你一本這麼厚的手冊，「看燃料、看這看那」，你問「產生多少牛頓要用多少燃料？能畫張圖嗎？」——那條曲線幾乎一定是凸的，那就是你的懲罰；這樣就非常接近實際的最省燃料軌跡設計。

## 8. 正則化近似

[▶ 1:06:07](https://youtu.be/whE03c84ahA?t=3967)

$$\text{minimize (w.r.t. }\mathbb{R}^2_+)\quad\left(\|Ax-b\|,\ \|x\|\right)$$

雙準則問題（兩個範數可以不同，實務上常常不同）。

**為什麼要 $x$ 小？**
1. **估計**：線性量測模型 $y=Ax+v$，先驗認為 $v$ 小、**也認為 $x$ 小**。
2. **設計**：例（老師說「社會不太正面」）[▶ 1:07:14](https://youtu.be/whE03c84ahA?t=4034)：控制飛向目標的飛彈，$\|Ax-b\|$ 是最後離目標多近（$\mathbb{R}^3$ 的範數），另一個範數是別的東西。「10 公尺內就夠了；2 公尺？沒差。」——【課堂討論】那是什麼懲罰？學生：**死區**。「超過 100 公尺不如別發射」——某種**障礙**，「照你的模型到不了 100 公尺內就別浪費，它們很貴」。
3. **強健性** [▶ 1:09:24](https://youtu.be/whE03c84ahA?t=4164)：「你有 $x$ 小的先驗嗎？」「沒有。」「那為什麼？」「**我不太知道 $A$**。」（幾乎所有應用都是。）【課堂討論】$A$ 晃動時，若 $x=0$，影響多大？「完全沒有。」$x$ 很大時？「很大。」所以 $x$ 越小，$Ax$ 對 $A$ 的變動越**不敏感**。「不要把它想得很複雜，它就是我說的那麼蠢。」之後會有很多相關內容。

**純量化** [▶ 1:10:57](https://youtu.be/whE03c84ahA?t=4257)：$\min\|Ax-b\|+\gamma\|x\|$，$\gamma$ 加權次要目標。實務上通常解

$$\text{minimize }\|Ax-b\|_2^2+\delta\|x\|_2^2,\qquad x^\star=(A^TA+\delta I)^{-1}A^Tb$$

叫 **Tikhonov 正則化**；西方統計叫**嶺回歸**（ridge regression），可能還有其他名字。

【課堂討論】[▶ 1:12:00](https://youtu.be/whE03c84ahA?t=4320) 做統計時怎麼選 $\delta$？「有錯的答案。」學生：**交叉驗證**（cross-validation）。「漂亮，那是對的答案。錯的答案是開始講一長串高斯、漸近理論——雖然那些觀察很有趣。」或者就是**樣本外驗證**。

【口頭】[▶ 1:13:01](https://youtu.be/whE03c84ahA?t=4381) 很多時候純量化是**人**憑直覺做的：「我要效率也要乘坐品質，怎麼取捨？」「不知道，給我看幾個選擇。」然後有人決定。沒有像交叉驗證那樣簡單可辯護的方法（「總不能讓人坐完車說『背好痛，但這趟能源很便宜』」）。影像處理裡這很普遍：大家轉旋鈕直到看起來滿意；控制也是。

## 9. 例：最佳輸入設計

[▶ 1:14:03](https://youtu.be/whE03c84ahA?t=4443)（課本 §6.3.3）

- 輸入時間序列 $u(t)$，輸出 $y(t)$，兩者以**卷積**相關：
$$y(t)=\sum_{\tau=0}^{t}h(\tau)u(t-\tau),\quad t=0,1,\dots,N$$
  （電機／機械方言叫**線性動態系統**；數學說 $h$ 是卷積核。）
- 三個目標：
  - **追蹤誤差**：$J_{\text{track}}=\sum_t(y(t)-y_{\text{des}}(t))^2$
  - **輸入大小**：$J_{\text{mag}}=\sum_tu(t)^2$
  - **輸入平滑度**（差分平方和）：$J_{\text{der}}=\sum_t(u(t+1)-u(t))^2$
- 正則化最小平方：
$$\text{minimize}\quad J_{\text{track}}+\delta J_{\text{der}}+\eta J_{\text{mag}}$$
  追蹤誤差是主要目標，$\delta$、$\eta$ 表示你多在乎輸入「不要太晃」、「不要太大」。

【口頭】[▶ 1:16:04](https://youtu.be/whE03c84ahA?t=4564) 同樣的問題在**金融**也出現：主要目標「追蹤這個債券組合正負 30 個基點」，差分項變成**周轉率**（turnover，交易量），大小項意義不同。「這個問題在 50 個領域重複出現。」之後會把這些換成其他懲罰，問你會發生什麼。

**結果**（課本 Figure 6.6）[▶ 1:17:04](https://youtu.be/whE03c84ahA?t=4624)：目標 $y_{\text{des}}$ 是方波（某種「先到這裡、再到那裡、再回來」的機動，老師忘了名字）。

| 設定 | 輸入 | 追蹤 |
|---|---|---|
| 頂：$\delta,\eta$ 很小 | 很晃、很大（$-9$ 到 $+5$） | 追得非常好 |
| 中：調大 $\eta$ | 小了大約三倍 | 追蹤誤差變大 |
| 底：再調大 $\delta$ | 平滑 | 追蹤誤差再變大 |

【口頭】機械系的朋友會說「很聰明，它用剛好的方式激發高頻模態，所以真正動作時就不會激發……」——「他們彼此之間看起來很懂。」實務上就是來回調：「追蹤誤差太大，退一點；太晃；太大……直到你**無聊或滿意**。」這叫**超參數調整**（hyperparameter tweaking）：「你覺得機器學習很糟？控制更糟。」

## 10. 一頁速查表

### 重新表述與對偶

| 原問題 → 轉換 | 對偶 |
|---|---|
| $\min f_0(Ax+b)$（無約束） | 平凡：$g=p^\star$ |
| → $\min f_0(y)$ s.t. $y=Ax+b$ | $\max b^T\nu-f_0^*(\nu)$ s.t. $A^T\nu=0$ |
| $\min\|y\|$ s.t. $y=Ax-b$ | $\max b^T\nu$ s.t. $A^T\nu=0$，$\|\nu\|_*\le1$ |
| 盒約束 LP，盒子放進目標 | $\max-b^T\nu-\|A^T\nu+c\|_1$ |
| SDP $\min c^Tx$ s.t. $\sum x_iF_i+G\preceq0$ | $\max\mathrm{tr}(GZ)$ s.t. $Z\succeq0$，$\mathrm{tr}(F_iZ)+c_i=0$ |

- 模式：函數 ↔ 共軛；$A$ ↔ $A^T$；$\ell_\infty$ ↔ $\ell_1$；KL ↔ log-sum-exp。
- 廣義不等式：$\lambda_i\succeq_{K_i^*}0$，Lagrangian 用內積。
- 可行性問題：對偶可行點的值 $>0$ ⇒ 原問題不可行（$p^\star\in\{0,\infty\}$）；擇一定理、Farkas、無套利。

### 近似

| 問題 | 形式 |
|---|---|
| 範數近似 | $\min\|Ax-b\|$：$\ell_2$（正規方程）、$\ell_\infty$（Chebyshev，LP）、$\ell_1$（LP） |
| 懲罰近似 | $\min\sum\phi(r_i)$，$r=Ax-b$ |
| 最小範數 | $\min\|x\|$ s.t. $Ax=b$ |
| 正則化 | $\min\|Ax-b\|+\gamma\|x\|$；Tikhonov：$x=(A^TA+\delta I)^{-1}A^Tb$ |

### 懲罰函數的形狀 → 解的性質

| 形狀 | 效果 |
|---|---|
| 0 處有尖角（$\lvert u\rvert$） | 很多殘差恰為 0（稀疏） |
| 0 附近平坦（$u^2$） | 小殘差不在乎、很多小殘差 |
| 死區 | 殘差擠到死區邊界 |
| 障礙 | 殘差全在範圍內 |
| 大值處線性（$\lvert u\rvert$、Huber） | 容忍少數大殘差 → 強健 |
| 不對稱 | 偏向某一側（分位數） |

Huber：$\phi_M(u)=u^2$（$|u|\le M$），$M(2|u|-M)$（否則）；力學上是「超過閾值後定力」的彈簧。

## 附：本集一句話總結

> **先做一個無辜的轉換（例如替 $Ax+b$ 取名）再取對偶，可能從毫無用處的對偶變成有內容的對偶；對偶裡會出現共軛、轉置、對偶範數這些可預期的模式，廣義不等式則把乘數放進對偶錐。近似問題的核心是懲罰函數的形狀：0 處的尖角產生稀疏、死區讓殘差停在邊界、線性尾巴（Huber）讓擬合不怕離群值——用「它讓你多煩」來擬人化地設計懲罰就對了。**
