## 1. 作業提醒：定義域與稀疏版

[▶ 00:05](https://youtu.be/Sx7TKDFJjmk?t=5)

- 再說一次（「超重要」）：梯度 $-1/x$、Hessian $\mathbf{diag}(1/x_i^2)$ 的公式在 $x_i<0$ 時**照樣算得出來**，但在這個問題裡**完全沒有意義**（函數只定義在 $x>0$）。線搜尋要先確保 $x+tv>0$（不是就 $t:=\beta t$），**然後**才檢查殘差。否則「很可能算得出來、全部是錯的，之後不會有好事，會是一場災難」。

- 【課堂討論】[▶ 02:46](https://youtu.be/Sx7TKDFJjmk?t=166) 多少人開始做了？已經跑起來的？「太棒了。其他人：頭號 bug 就是定義域。」除錯三四個小時就該放手，「除非變成一種個人尊嚴的執念——其實也該是」。重點是**去神秘化**。

## 2. 怎麼處理不等式約束

[▶ 03:48](https://youtu.be/Sx7TKDFJjmk?t=228)（課本 §11.1）

$$\text{minimize }f_0(x)\quad\text{s.t.}\quad f_i(x)\le0,\ i=1,\dots,m,\quad Ax=b$$

所有函數光滑。沒有不等式的話我們會解（Newton 法的幾種變形）。

寫成：$\text{minimize }f_0(x)+\sum_iI_-(f_i(x))$，$I_-$ 是負數的指示函數（$u>0$ 時 $+\infty$）。

**錯誤做法 1：直接用 Newton 法** [▶ 05:24](https://youtu.be/Sx7TKDFJjmk?t=324)。「我可以把它講得很有說服力：『那只是數學家在囉嗦，試試看嘛』」——會**慘敗**，完全不會動（更別說落到不可行點會怎樣）。「這次不只是數學家的問題，是真的有問題。」

**錯誤做法 2：用砂紙磨掉角** [▶ 06:24](https://youtu.be/Sx7TKDFJjmk?t=384)：做一個光滑近似，「這樣收斂警察就沒話說了」——**會動**，但 Newton 法要跑幾億次。

【課堂討論】[▶ 06:56](https://youtu.be/Sx7TKDFJjmk?t=416) 為什麼？學生：「看起來一點也不二次。」對：三階導數很大。越光滑 Newton 法越好。

這個故事的開頭和 Lagrange 對偶一樣——那次是「用一條直線近似」，更荒謬，結果卻有好結局。這次也會有好結局。

## 3. 對數障礙

[▶ 07:56](https://youtu.be/Sx7TKDFJjmk?t=476)（課本 §11.2.1）

用 $-\frac1t\log(-u)$ 近似 $I_-(u)$：

$$\text{minimize}\quad f_0(x)-\frac1t\sum_{i=1}^m\log(-f_i(x))\quad\text{s.t.}\quad Ax=b$$

- 圖（課本 Figure 11.1）：近似函數在 $u=-1$ 處都等於 0，在負的一側略為負，接近 0 時衝到 $+\infty$。
- 這是**光滑**、有等式約束的問題——「Newton 已經準備好了」，你作業寫的程式就能解。
- **$t$ 是近似精度的參數**：$t$ 越大越像指示函數，直覺上越接近原問題（等下會精確化）。但**$t$ 越大，Newton 法要跑越久**。問題是這兩者怎麼互動。
- 叫**障礙**（barrier）是因為它要求**嚴格可行**、在邊界衝到無窮大。

【口頭】[▶ 10:30](https://youtu.be/Sx7TKDFJjmk?t=630) 另一整套版本是**懲罰函數**（penalty）：在可行區裡為 0、外面快速上升，可以越來越陡。懲罰給**外**近似，障礙給**內**近似。

**對數障礙函數**：

$$\phi(x)=-\sum_{i=1}^m\log(-f_i(x)),\qquad\mathbf{dom}\,\phi=\{x\mid f_i(x)<0\}$$

凸（$-\log(-u)$ 凸且遞增，合成凸函數）。導數 [▶ 11:34](https://youtu.be/Sx7TKDFJjmk?t=694)：

$$\nabla\phi(x)=\sum_{i=1}^m\frac{1}{-f_i(x)}\nabla f_i(x)$$

$$\nabla^2\phi(x)=\sum_{i=1}^m\frac{1}{f_i(x)^2}\nabla f_i(x)\nabla f_i(x)^T+\sum_{i=1}^m\frac{1}{-f_i(x)}\nabla^2f_i(x)$$

$-f_i(x)$ 是**餘裕**。Hessian 有兩項：各約束的 Hessian 乘上 1/餘裕，加上一堆秩 1 項（乘上 1/餘裕平方）。「對角加低秩之類的東西應該存在你腦中以備利用。」

## 4. 中心路徑

[▶ 12:35](https://youtu.be/Sx7TKDFJjmk?t=755)（課本 §11.2.2）

把 $t$ 乘進去（等價問題）：

$$\text{minimize}\quad tf_0(x)+\phi(x)\quad\text{s.t.}\quad Ax=b$$

假設對每個 $t>0$ 有唯一解 $x^\star(t)$。這條以 $t$ 為參數的曲線叫**中心路徑**（central path）。

**圖**（課本 Figure 11.2，LP）[▶ 13:36](https://youtu.be/Sx7TKDFJjmk?t=816)：
- $t\to0$：只最小化對數障礙 → 起點是**解析中心**（最大化餘裕乘積）。
- $t$ 增大：$tc^Tx$ 的份量變大，沿著路徑往最佳點移動（LP 說「在多面體裡沿 $-c$ 盡量走」）。
- 「當然你得想像在一千維裡，但這張圖夠讓你抓到概念。」

### 4.1 中心路徑上的對偶點與間隙 m/t

[▶ 15:40](https://youtu.be/Sx7TKDFJjmk?t=940)

$x^\star(t)$ 的最佳性條件：存在 $\hat w$ 使

$$t\nabla f_0(x)+\sum_{i=1}^m\frac{1}{-f_i(x)}\nabla f_i(x)+A^T\hat w=0,\qquad Ax=b$$

除以 $t$，盯著看 [▶ 16:44](https://youtu.be/Sx7TKDFJjmk?t=1004)：$\frac{1}{-tf_i(x)}$ 是**正數**（$f_i<0$），所以這表示 $x^\star(t)$ **最小化 Lagrangian**，對應的對偶變數是

$$\lambda_i^\star(t)=\frac{1}{-tf_i(x^\star(t))},\qquad\nu^\star(t)=\frac{\hat w}{t}$$

既然最小化了 Lagrangian，就等於**評估了對偶函數** [▶ 17:17](https://youtu.be/Sx7TKDFJjmk?t=1037)：

$$g(\lambda^\star(t),\nu^\star(t))=f_0(x^\star(t))+\sum_i\lambda_i^\star(t)f_i(x^\star(t))=f_0(x^\star(t))-\frac mt$$

（每個 $\lambda_i^\star f_i=-1/t$，加 $m$ 個。）所以

$$f_0(x^\star(t))-p^\star\le\frac mt$$

**解讀** [▶ 18:22](https://youtu.be/Sx7TKDFJjmk?t=1102)：解這個光滑問題時，**不管你要不要**，都會順便產生**對偶可行點**，它們給出 $p^\star$ 的下界，而且間隙**恰好是 $m/t$**。這完全證實了「$t$ 大就接近原問題」的揮手論證：$t\to\infty$ 就解出問題了。

【Q&A】[▶ 19:52](https://youtu.be/Sx7TKDFJjmk?t=1192) 學生問：這和直接拿原問題的 Lagrangian 開始做有什麼不同？答：很多問題（LP 就是）**隨便挑對偶變數，對偶函數是 $-\infty$**——除非等式約束這種很特定的條件成立。這裡是先解一個光滑的等式約束問題，從中**保證**得到對偶可行的變數，下界不是 $-\infty$，而是「目前值減 $m/t$」。對偶函數定義域是全空間的問題可以直接更新對偶變數，經濟學叫**價格導向**方法；但對 LP 之類完全不行，那些「價格」必須滿足極特定的性質。

### 4.2 KKT 解釋

[▶ 21:26](https://youtu.be/Sx7TKDFJjmk?t=1286)

（「中心化」這個動詞：你**中心化**了，算出中心路徑上的點 $x^\star(t)$。）$x=x^\star(t)$、$\lambda=\lambda^\star(t)$、$\nu=\nu^\star(t)$ 滿足：

| 條件 | 中心路徑 | 原問題 KKT |
|---|---|---|
| 原始可行 | $f_i(x)<0$（嚴格），$Ax=b$（免費） | $f_i\le0$，$Ax=b$ |
| 對偶可行 | $\lambda\succ0$（嚴格） | $\lambda\succeq0$ |
| 互補鬆弛 | $-\lambda_if_i(x)=1/t$ | $-\lambda_if_i(x)=0$ |
| Lagrangian 梯度為零 | 是 | 是 |

**唯一的差別是互補鬆弛的右邊從 0 換成 $1/t$**。$t$ 越大越接近 KKT。「很多推導從這裡開始：寫下 KKT，把 0 換成 $1/t$——那怎麼解？現在你知道了：做中心化。」

### 4.3 力場解釋

[▶ 24:29](https://youtu.be/Sx7TKDFJjmk?t=1469)（課本 §11.2.3）

（先忽略等式約束。）把 $x$ 想成某系統的廣義位置：$tf_0$ 是一個力場的位能，每個 $-\log(-f_i)$ 是另一個力場的位能。中心點上**所有力平衡**（梯度加起來為零）。

**LP**（課本 Figure 11.3）[▶ 25:34](https://youtu.be/Sx7TKDFJjmk?t=1534)：
- 目標的力：$-tc$，**定力**，像重力但不一定朝下，「請往這個方向走」。
- 每條約束：**斥力**，直接背向那個面，大小和到面的距離（餘裕）成**反比**。離面很近時極強，遠時很弱。
- $t$ 乘 3 → 目標的力強 3 倍 → 系統移到新的平衡點（沿中心路徑）；靠近某個面時，它的斥力變大，所有力（例如 6 個）加起來為零。

**多餘的不等式會改變中心路徑嗎？** [▶ 28:37](https://youtu.be/Sx7TKDFJjmk?t=1717)

【課堂討論】加一條**多餘**的不等式（在多面體外面、不影響可行集）。學生：不會，因為是多餘的。老師：「我喜歡你的論證——很簡短，這永遠是優點。它也有一個缺點，同樣簡短：**它是錯的**。」每條約束都產生斥力，在外面它也感覺得到。在某處放 10 條多餘約束 → 學生：「路徑會更往下彎。」對，但它仍會溜到解。

【口頭】「等我們看它們實際怎麼運作時，沒人懂它們怎麼運作；但如果你想假裝懂，這是張好圖。」

## 5. 歷史與同倫法

[▶ 31:15](https://youtu.be/Sx7TKDFJjmk?t=1875)

**歷史** [▶ 31:15](https://youtu.be/Sx7TKDFJjmk?t=1875)

【口頭】很多是 1960 年代做出來的：有障礙法，有名的是 Fiacco 和 McCormick 的 **SUMT**（Sequential Unconstrained Minimization Technique）。後來發現蘇聯有人在 **1967 年**就寫出了完全現代的演算法——老師在莫斯科的朋友說「在莫斯科被忽略，在西方沒人知道」：二十年後登上**紐約時報頭版**的東西，都在「某個偏遠省份的人 1967 年的論文裡」。

> ⚠️ 待確認 [▶ 31:45](https://youtu.be/Sx7TKDFJjmk?t=1905)：字幕寫「someone named **Deakin** in the Soviet Union」，可能是 Dikin，無法從課本確認。

**UMT** [▶ 32:48](https://youtu.be/Sx7TKDFJjmk?t=1968)：你已經知道怎麼解那個光滑問題，解出來就有原始、對偶候選解，間隙恰好 $m/t$。「要多準？$10^{-5}$。好，你的 $m$ 是多少？」選 $t=m/\epsilon$，**帶著精度證明**回傳近似解。老師叫它 **UMT**（Unconstrained Minimization Technique，沒有正式名字）。「好笑的是，這方法對**很多實際問題完全夠用**。」但要小心選 $t$：$t$ 越大越準，Newton 步也越多。要高精度（甚至中等精度）時要幾百、幾千步，而且有數值誤差時大概不收斂。

**同倫法**（homotopy methods）[▶ 34:49](https://youtu.be/Sx7TKDFJjmk?t=2089)

【口頭】「每個人都該知道，非常酷的想法。」你要解一個問題（常常是非線性方程組）。引入參數（傳統範圍 0 到 1）：$t=1$ 是你真正想解的問題，$t=0$ 是你**已經知道解**的問題。從 $t=0$ 開始，把 $t$ 調高一點，**從上一個解出發**用 Newton 法解，一路走到 $t=1$。一本書的副標題叫「通往解的路徑」（pathways to solutions），「幾乎有詩意」。

**例：SPICE 電路模擬**（「方言時間，給懂電路的人」）[▶ 37:24](https://youtu.be/Sx7TKDFJjmk?t=2244)：
- 要找電路的平衡點（偏壓點）：解十億個非線性方程（KCL、KVL 是線性的物理，元件方程是非線性的）。
- 【課堂討論】同倫參數是什麼？老師：**電源電壓**。電源電壓為 0 時，「你的專長就算是遺傳學也解得出來」：所有電壓、電流都是 0。
- 調到 50 毫伏：沒有電壓能打開任何電晶體，晶片看起來就像電阻 → 線性，一兩步 Newton（傳統是一步）。再 100 毫伏……直到 2 伏。

【課堂討論】[▶ 40:26](https://youtu.be/Sx7TKDFJjmk?t=2426) 從 $t=0.05$ 調到 0.1，Newton 法完全失敗，怎麼辦？學生：**0.075**。「完美，完全同意。」代表你太激進、問題變太多。一般同倫法還可能出現病態：路徑**分岔**，或路徑突然**中斷**。**我們沒有這些問題**：只有一條路徑，從任何地方都能回到它，唯一的問題是要幾步 Newton。

## 6. 障礙法

[▶ 41:58](https://youtu.be/Sx7TKDFJjmk?t=2518)（課本 §11.3）

這就是一個同倫法。

- **在解什麼**：光滑凸不等式約束問題，從嚴格可行點出發。
- **步驟**：給嚴格可行的 $x$、$t:=t^{(0)}>0$、$\mu>1$、容許誤差 $\epsilon>0$；重複：
  1. **中心化**：從目前 $x$ 出發，計算 $x^\star(t)$（在 $Ax=b$ 下最小化 $tf_0+\phi$，用 Newton 法）。
  2. 更新 $x:=x^\star(t)$。
  3. **停止**：若 $m/t<\epsilon$ 就停。
  4. **增加 $t$**：$t:=\mu t$。
- **什麼時候會失敗**：理論上不會（不管 $t$ 增加得多激進，Newton 法都會解出這個光滑問題，只是可能步數多）；實務上可能因數值原因失敗。需要嚴格可行的起點（見 Phase I）。

**$\mu$ 的意義** [▶ 42:28](https://youtu.be/Sx7TKDFJjmk?t=2548)：間隙是 $m/t$，所以 $\mu$ 是**每次把間隙要求收緊幾倍**。$\mu=1.05$：剛算完中心點，$t$ 只加 5%，新問題和剛解的很像，一兩步 Newton 就好。有些方法讓增量小到只需要**一步** Newton（叫 short-step 方法）。

- 理論派：$\mu$ 很小，例如 $1+1/\sqrt m$ 之類。
- 實務：$\mu=10,20,50,100$——相當大。

**收斂分析** [▶ 44:31](https://youtu.be/Sx7TKDFJjmk?t=2671)：
- 每次中心化後間隙精確地除以 $\mu$，**沒有驚喜**：「很多演算法是做完所有計算後，一陣鼓聲，算一下對偶函數，抬頭說『天啊，我已經可證明地只差 1% 了』——這裡沒有，間隙就是 $m/t$，你直接撥定它。」
- **外迴圈（中心化）次數**：$\left\lceil\dfrac{\log(m/(\epsilon t^{(0)}))}{\log\mu}\right\rceil$（加上第一次中心化）。
- 真正的成本是總 Newton 步數。**古典分析**預測 $t$ 越大，每次中心化的 Newton 步數會**驚人地增長**（Lipschitz 常數和強凸常數都跟著放大），湊起來得不到多項式時間。但那個分析**就是錯的**：**實驗上每次中心化的步數不會隨 $t$ 增加**——關鍵是從上一個點出發。自和諧分析會證實這點。

【Q&A】[▶ 46:34](https://youtu.be/Sx7TKDFJjmk?t=2794) 學生問：每次不完全解完中心化問題會怎樣？反正不需要更好的點。答：完全對。中心化的最後兩步 Newton 是**完全浪費時間**——「你在幹嘛？」「我要用雙精度回到路徑上。」「老兄，路徑是什麼？我叫你解 SOCP 或 QP，我為什麼要在乎路徑？」路徑只是我們用來找到解的**建構物**。真正的方法不會這樣做：一進入二次收斂區就更新 $t$。

【Q&A】[▶ 48:36](https://youtu.be/Sx7TKDFJjmk?t=2916) 學生問：中心化比直接用一個很大的 $t$ 解好多少？答：「實務上通常是**無限**倍。」理論上不是無限，只是大得不可思議。要六位有效數字就 $t=10^7$，理論上直接跑 Newton 也行，但會遇到數值問題、根本不會動；就算動了也要極多步。

【Q&A】[▶ 49:08](https://youtu.be/Sx7TKDFJjmk?t=2948) 學生問：所以如果只在乎 $p^\star$，解一個 $t$ 然後加上 $m/t$ 就好？答：對，那就是 UMT。但要 $10^{-7}$ 精度時 $t=10^9$——對應「拿砂紙磨掉角就說『光滑了，用你的 Newton 法吧』」的人。

## 7. 數值例子：20 到 50 步

[▶ 51:14](https://youtu.be/Sx7TKDFJjmk?t=3074)（課本 §11.3.2）

**LP（50 個變數、100 條不等式）**（課本 Figure 11.4）：
- **階梯圖**：橫軸 Newton 步數、縱軸對偶間隙（對數）。每一階的**寬度**是那次中心化的 Newton 步數；**落差**是間隙除以 $\mu$（對數圖上固定高度）。
- $\mu=50$：很激進，第一次中心化約 11 步，之後每次約 10–11 步，每次間隙降 50 倍。
- $\mu=2$：小碎步，每階很窄（問題容易，兩三步 Newton 就好）。「好笑的是理論要的是 $\mu=1.0001$。」
- **總步數 vs $\mu$**（右圖）：$\mu$ 從 2 到大約 150，總步數幾乎不變；$\mu$ 再大才開始上升。

【口頭】[▶ 54:19](https://youtu.be/Sx7TKDFJjmk?t=3259) 把間隙降低 $10^8$ 倍，只用了大約 37 步 Newton。「想想這代表什麼：$\mathbb{R}^{50}$ 裡 100 個面的多面體，頂點數天文數字，其中一個是解——30 幾步 Newton 就得到極高精度的解。」每一步：查詢約束和目標、組 KKT 矩陣、解線性系統得到方向、做線搜尋。「維度變成 5,000 也是一樣的圖。在 5,000 維裡你只停下來問路 35 次——$\mathbb{R}^{5000}$ 是個很大的地方。」

【Q&A】[▶ 56:53](https://youtu.be/Sx7TKDFJjmk?t=3413) 學生問：右圖為什麼有小跳動（例如 148 附近）？答：不知道，可能是隨機擾動，碰巧落在某處只需很少步——笨運現象。「這大概是單一問題實例；如果平均很多個，那些凸起也許還會在。」

**$\mu$ 的取捨互相抵消** [▶ 57:24](https://youtu.be/Sx7TKDFJjmk?t=3444)：$\mu$ 小，每次 1–2 步但只進步 5%；$\mu=10$，間隙降 10 倍但每次較多步。**兩個效應基本上抵消**——「這超好：$\mu$ 的選擇只要在合理值的幾百倍內就**完全沒差**」，在很多其他情況也被證實。

**GP**（課本 Figure 11.6）[▶ 58:56](https://youtu.be/Sx7TKDFJjmk?t=3536)：一樣 30 幾步。「25–30 年前大家還在發表解 GP 的花俏客製方法。這些東西開始看起來都一樣。」

**一族標準形式 LP**（課本 Figure 11.8）[▶ 59:27](https://youtu.be/Sx7TKDFJjmk?t=3567)：「這正是你作業要實作的。」$m$ 從 10 到 1000，每個大小解 100 個隨機問題。
- 步數在 **20 到 25** 之間，最大 30。
- CVXPY 呼叫的解法器（例如 ECOS）會回報迭代次數：通常 20 到 50，「我想從沒超過 50」。
- 「這讓很多人困惑：先說像 $\sqrt m$，又有人說像 $\log m$，最後成為**經驗事實**：**$O(1)$**——障礙法就是 20 到 50 步，任何維度都一樣。」

【口頭】[▶ 1:01:02](https://youtu.be/Sx7TKDFJjmk?t=3662) 當然每步（解 KKT 系統）的時間會隨問題變大，「我不是說解 100 變數和一百萬變數一樣快，是說**迭代次數**一樣」。老師在愛丁堡的朋友用基本的障礙法解一個 LP，大約 **20 億個變數、5 億條約束**（在某台超級電腦上，很久以前）。「要幾次迭代？」「和小問題一樣，22、23，一直都是。」「一次迭代多久？」「大概 25 分鐘。」老師加油添醋：「每次迭代開始時，愛丁堡的燈會暗一下。」——「那部分當然不是真的。」

**含意** [▶ 1:02:41](https://youtu.be/Sx7TKDFJjmk?t=3761)：二十幾步 Newton，每步就是在等式約束下最小化凸二次——**一切都歸結到線性代數**。「演算法基本上已經完美了（比我給你看的更精緻，但很接近），所有進步都在線性代數。」

**登上紐約時報** [▶ 1:04:12](https://youtu.be/Sx7TKDFJjmk?t=3852)

【口頭】1960 年代就有前身（包括實作），但退流行、被忽略（例如 1967 年那篇）。1980 年代末、90 年代初被**重新發現**（「重新發現時當然變得複雜得多」），登上**紐約時報頭版**——因為這是證明 **LP 可以多項式時間求解**的方法。「它的實務後果恰好是零」：解 LP 的人那時已經用單純形法解了 40 年，效果好得不可思議。報導還暗示「大量排程和分配問題現在可以解了」，「完全錯誤」。大約十年後有人挖出 1960 年代的 Fortran 程式碼（在打孔卡上），讀進來、升級成 F90，**和當時最好的解法器有得拚**——「這告訴你學術界有流行，很多完全可用的東西因為勢利或無知被忽略了，這對整個領域很尷尬。」

## 8. 可行性與 Phase I

[▶ 1:06:18](https://youtu.be/Sx7TKDFJjmk?t=3978)（課本 §11.4）

障礙法需要**嚴格可行**的起點。實際用的方法把 Phase I 和 Phase II 合在一起（「如果這門課多一週，你會實作那個，大概多五行」），但這本身也很有用。

**古典流程**：Phase I 找可行點；Phase II 跑演算法找最佳點。「老派，但你可能會遇到受老派訓練的人；現在很多人聽到 phase I、phase II 會說『你在講什麼』。」

**基本 Phase I** [▶ 1:07:51](https://youtu.be/Sx7TKDFJjmk?t=4071)：

$$\text{minimize }s\quad\text{s.t.}\quad f_i(x)\le s,\ i=1,\dots,m,\quad Ax=b$$

- 變數 $(x,s)$。**一旦得到 $s<0$ 就停**：那是嚴格可行點，跳回障礙法。
- 這個問題本身很容易起步：取任何滿足 $Ax=b$（且在 $f_i$ 定義域內）的 $x$，令 $s=\max_if_i(x)+1$，就嚴格可行了，可以直接用障礙法。

**不可行時** [▶ 1:08:56](https://youtu.be/Sx7TKDFJjmk?t=4136)：最佳值例如 $s^\star=1.3$——解讀：「你的不等式不能同時滿足；但全部放寬到 $f_i(x)\le1.3$，我有一個點給你。」= **最小化最大約束違反量**（類似 $\ell_\infty$）。

【課堂討論】[▶ 1:09:28](https://youtu.be/Sx7TKDFJjmk?t=4168) 那時 $f_i$ 們長什麼樣？學生：**很多會在那個值**。對：「擬人化：你在所有函數上面放一塊平板 $s$，往下壓，直到卡住、它反推得比你還用力。卡住時會有好幾個、一般是一大堆約束剛好違反 1.3。」應用：「壞消息：沒有設計能滿足所有規格；好消息：全部放寬 0.3 就可行。」

**不可行量總和** [▶ 1:11:00](https://youtu.be/Sx7TKDFJjmk?t=4260)：

$$\text{minimize }\mathbf{1}^Ts\quad\text{s.t.}\quad f_i(x)\le s_i,\ s\succeq0,\ Ax=b$$

最小化約束違反量 $f_i(x)_+$ 的**和**（類似 $\ell_1$）。

【課堂討論】最小化 $\ell_1$ 範數通常會怎樣？學生：**稀疏**。「這開始變得超有趣：『你給我 50 個規格，壞消息，做不到——而且我能證明（用擇一定理的憑證）。』『但我們總得做出產品。』『沒問題，我找到一個滿足你 50 個規格中 47 個的設計。』」

**圖**（課本 Figure 11.9）[▶ 1:13:01](https://youtu.be/Sx7TKDFJjmk?t=4381)：約束餘裕的直方圖（要推到 0 以上）。
- 基本 Phase I：一大堆擠在最差的值（約 $-0.2$）。
- 不可行量總和：大約 55 個滿足，只有少數不能滿足——「又是我們的老朋友 $\ell_1$ 稀疏化器」，在很多應用已經很有用。

**例：一族 LP** [▶ 1:14:31](https://youtu.be/Sx7TKDFJjmk?t=4471)（課本 Figure 11.10–11.11）：$Ax\preceq b+\gamma\Delta b$，$\gamma=0$ 時多面體退化成零體積；$\gamma<0$ 不可行，$\gamma>0$ 可行並長大。Phase I（找點或證明不可行）的步數：**大約 30–40 步，除非剛好在可行與不可行的邊界**。要很小心調資料才會超過 30、40 步。
- 左邊：明顯不可行，有很多不可行憑證，很快證明。
- 右邊：多面體很大，很快找到可行點。
- 只有在**邊界附近**步數才上升——「實務上就是不會發生」。

## 9. 預告：自和諧下的複雜度

[▶ 1:16:34](https://youtu.be/Sx7TKDFJjmk?t=4594)（課本 §11.5）

**假設**：$tf_0+\phi$ 對 $t\ge t^{(0)}$ 是**自和諧**的。

- 例：有不等式約束的最大熵問題本身**不是**自和諧的；但加上一條**多餘**的 $x\succeq0$（目標的定義域本來就要求它），它的對數障礙 $-\sum\log x_i$ 加進去後就自和諧了。
- 【口頭】「接下來的東西超酷，但**實務含意完全不清楚**。理論含意很清楚。」每隔幾年就震盪一次：有人實作用自和諧障礙、和理論吻合的解法器；然後發現某個技巧讓它快很多，「我們不在乎」；理論家幾年後才跟上。「我遇過奇怪的人說『天啊，你用的障礙不是自和諧的』——演算法複雜度警察又不在這裡，有逮捕你的令狀嗎？」

**分析的結構** [▶ 1:18:38](https://youtu.be/Sx7TKDFJjmk?t=4718)：
- 總 Newton 步數 = 中心化次數（$\propto\log(\cdot)/\log\mu$）× 每次中心化的最多步數。
- 每次中心化：從 $x^\star(t)$ 到 $x^\star(\mu t)$，自和諧的 Newton 法上界大致是
$$\frac{(\mu tf_0+\phi)(x)-(\mu tf_0+\phi)(x^+)}{\gamma}+c$$
  （$c$ 其實是 $\log\log$ 某個東西，大約 5，甚至更小。）
- 尷尬又出現：要算上界得先知道最佳值——「先用 Newton 法解出來再代進去？我都解完了，不需要你的蠢上界。」但它只需要那個值的一個**下界**。

【課堂討論】[▶ 1:21:15](https://youtu.be/Sx7TKDFJjmk?t=4875)「在還沒解之前，下界會從哪裡來？大家一起說？你只有一次機會。」學生：**對偶**。「好，這就是故事的高潮，下次完成。」

## 10. 一頁速查表

### 障礙法核心

| 項目 | 式子 |
|---|---|
| 對數障礙 | $\phi(x)=-\sum\log(-f_i(x))$ |
| 梯度 | $\nabla\phi=\sum\frac{1}{-f_i}\nabla f_i$ |
| Hessian | $\sum\frac{1}{f_i^2}\nabla f_i\nabla f_i^T+\sum\frac{1}{-f_i}\nabla^2f_i$ |
| 中心化問題 | $\min tf_0+\phi$ s.t. $Ax=b$ |
| 對偶點 | $\lambda_i^\star=\frac{1}{-tf_i(x^\star)}$，$\nu^\star=\hat w/t$ |
| 間隙 | $f_0(x^\star(t))-p^\star\le m/t$ |
| 修正的 KKT | 互補鬆弛 $-\lambda_if_i=1/t$（原本 0） |
| 力場 | 目標定力 $-t\nabla f_0$，約束斥力 $\propto1/\text{餘裕}$；多餘約束**會**改變路徑 |

### 演算法

| 演算法 | 內容 |
|---|---|
| UMT | 選 $t=m/\epsilon$ 解一次（中等精度可用，高精度不行） |
| 障礙法 | 中心化 → $m/t<\epsilon$ 停 → $t:=\mu t$；外迴圈 $\lceil\log(m/(\epsilon t^{(0)}))/\log\mu\rceil$ 次 |
| 實務 | $\mu=10$–$100$；總步數對 $\mu$ 不敏感；**20–50 步，與維度無關** |
| 同倫法 | 從已知解的問題出發，調參數、從前一解熱啟動；失敗就退一半 |

### Phase I

| 版本 | 問題 | 不可行時 |
|---|---|---|
| 基本 | $\min s$ s.t. $f_i(x)\le s$ | 很多約束同時違反 $s^\star$（$\ell_\infty$） |
| 不可行量總和 | $\min\mathbf{1}^Ts$ s.t. $f_i(x)\le s_i$，$s\succeq0$ | 大多數滿足、少數違反（$\ell_1$ 稀疏） |

- 起點：$s=\max_if_i(x)+1$；得到 $s<0$ 就停。
- 只有在可行/不可行邊界附近步數才會增加。

## 附：本集一句話總結

> **把硬約束換成 $-\frac1t\log(-f_i)$ 的對數障礙，中心路徑上的每一點都順便給出對偶可行點，間隙恰好是 $m/t$——就是把 KKT 的互補鬆弛從 0 換成 $1/t$。障礙法是一個同倫法：中心化、把 $t$ 乘 $\mu$、從上一點熱啟動，實務上不管問題多大都是 20 到 50 步 Newton，所以一切的速度都取決於線性代數。找起點用 Phase I：最小化最大違反量，或最小化違反量總和（得到稀疏的違反）。**
