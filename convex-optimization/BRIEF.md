# 任務說明：EE364A 凸最佳化 隨堂筆記

> 確認日期：2026-11-11

## 範圍

- 播放清單：<https://www.youtube.com/playlist?list=PLoROMvodv4rMJqxxviPa4AmDClvcbHi6h>（18 部影片）
- 課程：Stanford **EE364A Convex Optimization I**（2023），主講 **Stephen Boyd**。每集開頭要從逐字稿確認講者（可能有代課）
- 切法：**一部影片 = 一份筆記**，檔名用**英文**（小寫、單字用連字號），例如 `01-introduction.md`
- 順序：先做**第 1 集**當樣品 → OK 後剩下 17 集**一次做完**再交

## 1. Purpose（用途）

給自己自學、複習用。看完筆記就懂這一集，不用重看影片。

- 老師口頭多講、課本沒有的內容，標 `【口頭】`。
- 速查表放**公式＋推導的關鍵一步**，不只列名詞。
- 遇到演算法（梯度下降、Newton 法、內點法……），要寫清楚：**它在解什麼問題、步驟是什麼、什麼時候會失敗**。

## 2. Situation（背景）

- **英文授課**。筆記用**繁體中文**，術語第一次出現附英文。
- 每集約 1 小時 15–22 分。
- 逐字稿：YouTube 人工字幕（`en-US`），放 `_work/subs/`；轉成帶時間點的純文字放 `_work/txt/NN.txt`。
- 課本：Boyd & Vandenberghe《Convex Optimization》，`bv_cvxbook.pdf`。**PDF 頁碼 = 書頁 + 14**。章節對應做到時從逐字稿判斷。
- 讀者**會線性代數、微積分、基本機率；沒學過凸最佳化** → 最佳化名詞（凸集、錐、對偶、KKT 等）第一次出現要停下來解釋。

## 3. Inputs（資料）

1. **主要**：該集逐字稿。筆記骨架照影片順序。
2. **次要**：課本 `bv_cvxbook.pdf`，補定義、定理、推導、例子。標 `【課本補充】`，註明章節（例如 §2.3）。
3. **不用**：網路上其他筆記或文章、投影片檔、影片截圖。
4. 投影片公式字幕沒唸出 → 從口述和課本重建；重建不出來寫「待補」。
5. 抓不到、查不到 → 寫「待補」，**不亂編**。
6. 逐字稿與課本不一致 → 兩邊都寫，標明出處。

## 4. Limits（不能做）

- 只寫該集講到的內容；最後一節可列「後面哪一集會用到」。
- 老師跳過的課本內容：**重要的**（定義、主要定理、與本集主題直接相關的例子）標 `【課本補充】` 補進來；次要的只寫一行「課本 §x.y 還有 ○○，本集沒講」。
- 不整段抄課本，用自己的話重寫；定義、公式可照用。
- **不寫程式碼**（CVXPY 等只描述用法）；演算法用步驟或虛擬碼說明。
- 作業、考試題目**不做解答**。
- 不編 `【Q&A】`：逐字稿裡真的有學生提問才寫。
- ⚠️ 待確認項：沒查清楚前不能刪。
- 數學語法照 `lecture-notes` skill 的 Typst 相容規則；**不用 `\underset`、`\overset`**（改用 `\min_{x}` 等）。
- 沒問過不 commit、不 push。

## 5. Done-when（完成條件）

- **檢查點**：第 1 集先交目錄大綱 → 確認 OK 才寫全文 → 樣品確認後，剩下 17 集一次做完再交。
- **每份筆記結構**：照 `lecture-notes` skill 的 `TEMPLATE.md`，另外每個演算法都要有「在解什麼／步驟／什麼時候會失敗」。
- **進度檔**：`PROGRESS.md` 與 `README.md`（總目錄）；每集做完更新狀態與待確認數。
- 18 集都完成 = 任務完成。
