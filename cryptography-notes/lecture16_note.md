## 1. 為什麼要用橢圓曲線

### 1.1 兩個方向：服務 vs 數學

`[00:03]`【口頭】DL 問題很酷有兩個理由，可以看成**兩個軸**：

```
             服務（security services）
               金鑰交換   加密      數位簽章
DL in Z_p*      DH      Elgamal   Elgamal 簽章/DSA   ← 到目前為止做的
DL on EC        ECDH    EC-Elgamal ECDSA              ← 今天開始
  ↑
數學結構
```

- **橫軸（服務）**：用 DL 能做的三件事：**金鑰交換**、**加密**（「其實最不有趣」）、**數位簽章**（兩週後開始）。
- **縱軸（數學）**：「**可能更酷**」：不一定要在 $\mathbb{Z}_p$ 做 DL，可以用**完全不同的數學**建立類似的協定。

### 1.2 金鑰長度對照表

`[00:08]`（課本 Table 6.1）

| 演算法家族 | 例子 | 80 bit | **128 bit** | 192 bit | 256 bit |
|---|---|---|---|---|---|
| 整數分解 | RSA | 1024 | **3072** | 7680 | 15360 |
| 離散對數 | DH、DSA、Elgamal | 1024 | **3072** | 7680 | 15360 |
| **橢圓曲線** | ECDH、ECDSA | 160 | **256** | 384 | 512 |
| 對稱式 | AES、3DES | 80 | **128** | 192 | 256 |

（安全等級 $n$ bit = 已知最好的攻擊要 $2^n$ 步。）

【口頭】
- 「實務上標準的 AES 是 128 bit。RSA 要一樣安全就要 **3000 bit**。**祝你好運** —— 意思是**超慢**、很痛苦。」
- `[00:10]`「我們其實不太在意長度本身，**在意的是計算**。光是兩個 3000 bit 的數相乘就很糟。」

【口頭】一個例子：
> 「45 分鐘前我才跟博士生 Stefan 聊過。他在智慧卡上那種**很小的 8 bit 微處理器**上做 600 bit 的算術（他的系統是 code-based cryptography，很怪的東西）。他基本上只需要做**一次乘法**，就已經要大約 **1 萬次運算**。那才 600 bit，這裡是 3000 bit。」

**橢圓曲線**：要 128 bit 安全性，**256 bit** 就夠。

> 【口頭】`[00:11]`「這一張表就是橢圓曲線的**大承諾**：計算上有效率得多、小得多。現代智慧型手機、BlackBerry、美國的衛星廣播等『**性感的新應用**』，大部分沒內建 RSA，**用的是橢圓曲線**。要小心，不是全部，但很多。」
> 「它是**未來的密碼系統**。而且是一個**家族**：金鑰交換、加密、數位簽章，**全部都能用橢圓曲線做**。」

【課本補充】
- ECC 從 **1980 年代中期**就有了，是三大公鑰家族中**最新**的。
- 很多情況下 ECC 有**效能優勢**（計算少）和**頻寬優勢**（簽章和金鑰較短）。
- 但用**短公鑰的 RSA 運算**（加密、驗章，第 12 講）**還是比 ECC 快很多**。
- 長期安全（幾十年）建議選 **128 bit** 安全等級。
- 公鑰運算比對稱運算**慢 2～3 個數量級**很常見。
- ⚠️ 橢圓曲線**不是橢圓**。它們跟計算橢圓的周長有關，所以才有這個名字。

### 1.3 想法：找另一個 DLP 很難的循環群

`[00:13]`
- 找循環群其實**很容易**。【口頭】「記得兩週前那題作業嗎？mod $p$ 的**加法**群，是循環群，有各種好性質 —— 但**很糟**，DLP 太簡單，不能拿來做密碼系統。」
- 我們要的是：**DLP 非常非常難**的循環群。最好**比 $\mathbb{Z}_p^*$ 更難**。

`[00:15]`【口頭】為什麼 $\mathbb{Z}_p^*$ 要 3000 bit？
> 「因為有相當強的攻擊 —— **Index Calculus**。它逼我們這些好人（例如造 BlackBerry 的人）要用到 3000 bit。所以 $\mathbb{Z}_p^*$ 的 DLP **是難的，但沒有你想要的那麼難**。」
> 「**橢圓曲線不一樣。**對橢圓曲線最好的攻擊**弱得多**。用最好的攻擊，256 bit 的曲線還是要 $2^{128}$ 步。」

> **答案：可以用橢圓曲線建立另一個 DLP，而且比 mod $p$ 難得多。**
> 問題是：**它比較複雜**。

【口頭】`[00:16]`「如果 1 是完全睡著、10 是非常清醒，現在是 **3**。……好，**4**。慢慢醒來。」

## 2. 從圓到橢圓曲線

### 2.1 圓上的點

`[00:17]`【口頭】「我們從一個**看起來跟密碼學無關**的東西開始：多項式。聽起來像 10、11 年級的高中數學。」

【課堂討論】$x^2 + y^2 = r^2$ 讓你想到什麼？→ **圓**，半徑 $r$。

【口頭】`[00:18]`「第一次要醒來，很簡單，高中就做過了。」

**為什麼某個點 $P$ 在圓上？**
- 看它的座標 $(x, y)$。
- 代進方程式，**方程式成立** → 這個點屬於這條曲線。

**另一個點 $V$ 為什麼不在圓上？**
- 代進方程式，**不成立**。

> **世界上的點分兩種：滿足方程式的（在曲線上）、和其他所有點。**

【課本補充】例：$(r, 0)$ 在圓上；$(r/2, r/2)$ 不在。

### 2.2 橢圓曲線的定義

`[00:19]`【課堂討論】在圓的方程式加上係數 $a, b$（$ax^2 + by^2 = c$）會怎樣？→ **橢圓**。

【口頭】這些都是在**實數**上（$x, y$ 軸是實數，不是 mod $p$、不是複數平面）。

**密碼學要的是 mod $p$**（`[00:21]`）。

【口頭】「我直接給你定義。它看起來很嚇人，你會覺得『Paar 教授在幹嘛』。接下來 60 分鐘再解釋。有時候我喜歡慢慢推導，這次反過來，先跳進去。」

> **定義（橢圓曲線，課本 9.1.1）**：$\mathbb{Z}_p$（$p > 3$）上的橢圓曲線，是所有滿足
> $$\boxed{y^2 \equiv x^3 + a \cdot x + b \ (\mathrm{mod}\ p)}$$
> 的點 $(x, y) \in \mathbb{Z}_p \times \mathbb{Z}_p$ 的集合，**再加上一個虛擬的無窮遠點 $\mathcal{O}$**，其中 $a, b \in \mathbb{Z}_p$，且滿足條件
> $$4a^3 + 27b^2 \not\equiv 0 \ (\mathrm{mod}\ p)$$

【口頭】
- `[00:23]`「這個方程式**非常重要**。想過這門課，**你得記得它**。」
- 「它跟剛剛的方程式很像。但**不只是點**，還需要另一樣東西 —— **一個虛擬的點**。」用花體 $\mathcal{O}$ 表示。（「你在工程數學的分析課可能看過。」）
- `[00:25]` 最後那個條件：「**對這門課不太重要**，但為了完整。某些曲線有**不想要的性質**，不能用在密碼學。不滿足這條件的就不是我們要用的橢圓曲線。這門課通常不用檢查。」

【課本補充】那個條件確保曲線**非奇異（nonsingular）**：幾何上，圖形**沒有自交點或尖點**。也就是判別式 $-16(4a^3 + 27b^2) \ne 0$。

### 2.3 先在實數上畫圖

`[00:26]`【口頭】「純數學地看會很難懂、很抽象、很隨意。好消息是：**整個橢圓曲線有非常漂亮的幾何解釋**。現在慢慢醒來。」

- 密碼學要 **mod $p$**。但一旦用 mod 運算，**就畫不出圖了**。
- 好消息：可以拿**同一個方程式**先在**實數 $\mathbb{R}$** 上看、建立直覺，之後再對 mod $p$ 做**完全一樣的事**。
- 「mod 運算下，這個圖形解釋**完全崩潰**。」

**例**：$y^2 = x^3 - 3x$ 在 $\mathbb{R}$ 上（`[00:28]`）。
【口頭】形狀有點像大寫的 E（elliptic），「或者像一隻鯨魚，我不知道。」

> ⚠️ 逐字稿的例子是 $y^2 = x^3 - 3x$；課本 Figure 9.3 的例子是 $y^2 = x^3 - 3x + 3$。

**性質：對 $x$ 軸對稱**（`[00:29]`）

【課堂討論】對哪個軸對稱？→ **$x$ 軸**。為什麼？

$$y = \pm\sqrt{x^3 + ax + b}$$

開根號會得到**正負兩個解**。所以如果 $(x, y)$ 在曲線上，$(x, -y)$ 也在。

【課本補充】
- 課本的例子跟 $x$ 軸有**一個**交點：$y = 0$ 時是一個三次方程，有一個實根（另外兩個是複數根，圖上看不到）。
- 也有跟 $x$ 軸交**三次**的橢圓曲線。

## 4. 群運算：點的加法

`[00:35]`【口頭】「這是你**接下來一輩子**都超級重要的圖 —— 好吧，**這門課剩下的時間**。需要大約三分之一頁。」
「**先別抄**，10 分鐘後我說可以再抄。點放在這裡還是那裡**很微妙**，放錯圖就不對。」

`[00:38]`【口頭】「我可以嚇你一下：故事的結尾就是黑板上那個**很嚇人的公式框**。壞教授會現在就寫公式。我想當好教授 —— 有一個**很漂亮的幾何解釋**。（當然是在**實數**上，不是 mod $p$。）**別看公式，看我。**」

### 4.1 幾何解釋：點加法 $P + Q$

`[00:39]`（$P \ne Q$）

```
              y
              │        • R' ← 第三個交點
              │      ╱
              │    ╱
         P •──┼──•────────── 割線
              │  Q
──────────────┼────────────── x
              │
              │        • R = P + Q  ← R' 對 x 軸鏡射
              │
```

**用尺和紙的做法**：
1. 畫一條**通過 $P$ 和 $Q$ 的直線**（**割線**，德文 Sekante）
2. 這條直線會跟曲線交於**第三個點**
3. 把第三個交點**對 $x$ 軸鏡射**
4. 鏡射後的點**按定義**就是 $R = P + Q$

【口頭】「（我很不會畫圖。）」「**按定義**。這沒有什麼『自然』的理由，就是定義。」

### 4.2 幾何解釋：點倍增 $P + P$

`[00:41]`【口頭】要算 $P + P$（「像 3 + 3，在 mod $p$ 裡我們可以做」）時，**上面的方法不能用**：一個點怎麼畫一條線？

【課堂討論】回到分析課：如果 $Q$ 沿著曲線**越來越靠近** $P$，割線會怎樣？
- 割線開始轉動……
- 當 $Q$ 變成 $P$ 的時候 → 學生答：**切線（tangent）**！

**做法**：
1. 畫通過 $P$ 的**切線**
2. 切線跟曲線交於**第二個點**（不是第三個）
3. 對 $x$ 軸**鏡射**
4. 得到 $2P$

> 【口頭】「這就是橢圓曲線**漂亮**的部分：一個很有趣的幾何構造。」

| 情況 | 名稱 | 畫什麼 |
|---|---|---|
| $P \ne Q$ | **點加法（point addition）** | 割線（通過 $P$、$Q$） |
| $P = Q$ | **點倍增（point doubling）** | 切線（通過 $P$） |

【課本補充】
- 這個「**切線與割線法（tangent-and-chord）**」歷史上是用來：已知兩個點，**只用加減乘除**找出第三個點。
- 結果用這種方式加點，點的集合會滿足群的大部分條件。
- 「加法」這個名字**完全是任意的**，也可以叫乘法。

### 4.3 解析公式

`[00:45]`【口頭】「**BlackBerry 怎麼做？**你不會想在 BlackBerry 上畫圖吧。所以手機、筆電、伺服器、特殊硬體都要**只用計算**來做同樣的構造。我們需要**解析式**，也就是**公式**。」

> **橢圓曲線的點加法與點倍增**：$P = (x_1, y_1)$、$Q = (x_2, y_2)$、$R = P + Q = (x_3, y_3)$
> $$x_3 = s^2 - x_1 - x_2 \bmod p$$
> $$y_3 = s(x_1 - x_3) - y_1 \bmod p$$
> 其中
> $$s = \begin{cases} \dfrac{y_2 - y_1}{x_2 - x_1} \bmod p & \text{若 } P \ne Q \text{（點加法）} \\[2ex] \dfrac{3x_1^2 + a}{2y_1} \bmod p & \text{若 } P = Q \text{（點倍增）} \end{cases}$$

- $s$ 是**斜率**：點加法時是割線的斜率，點倍增時是切線的斜率。
- 這些公式**只用四則運算** → 可以在**任何體**上做，不只實數。所以可以拿到 $GF(p)$ 上用。
- 【口頭】「你一輩子都看過 $y_2 - y_1$ 除以 $x_2 - x_1$，**九年級**的東西，沒那麼嚇人。」

### 4.4 公式怎麼來的（概要）

`[00:46]`【口頭】「推導公式要花掉今天大部分時間，所以我**快速粗略**地講，讓你有個概念。習題課 Marcus 大概會慢慢做。」

**步驟 1：通過 $P$、$Q$ 的直線**（`[00:48]`）

$$y = s \cdot x + m$$

【課堂討論】$s$ 叫什麼？→ **斜率（slope）**，德文 Steigung。「公式框裡有 $s$ 嗎？有。」
「兩點決定一條直線，九年級的東西。」

**步驟 2：直線和曲線的交點**（`[00:50]`）
【課堂討論】有兩個幾何物件，怎麼找交點？→ **聯立 / 代入**：

$$(sx + m)^2 = x^3 + ax + b$$

**步驟 3：解三次方程**（`[00:52]`）
- 【課堂討論】未知數是？→ $x$（$a, b, s, m$ 都是參數）。
- 【課堂討論】幾次方程？→ **三次**。
- 【課堂討論】有幾個解？→ 代數基本定理：**3 個**。
- 一般來說解三次方程**很難**。但這裡為什麼不難？→ 【課堂討論】**已經知道兩個解了**：$x_1$ 和 $x_2$！
- 只要找**第三個解 $x_3$**。

【口頭】`[00:54]`「慢慢做完所有步驟，大概要 30 分鐘以上，習題課可能會做。最後就會得到這些公式。**這就是你 BlackBerry 裡在做的事。**」

**實際計算順序**（`[00:55]`）：
1. 算 $s$（模反元素、模乘法）。實務上是 **200 bit 左右**的數。
2. $s^2 - x_1 - x_2$ → $x_3$
3. $s(x_1 - x_3) - y_1$ → $y_3$

【口頭】「**就是代公式**。」「formulae 是 formula 的拉丁文複數，好的英文會這樣寫。」

【口頭】`[01:13]` 點倍增的斜率公式「如果你很厲害，會看出它跟**微分**有關（隱函數微分）」，教授沒有展開。

## 5. 群的性質

`[00:59]` 有了群運算（「很怪的加法」），要檢查它滿足**群的規則**（第 7 講，課本 p.92）。

### 5.1 封閉性、結合律

| 規則 | 成立嗎 |
|---|---|
| **封閉性**：$P + Q$ 也在曲線上 | 【課堂討論】✔ 「我們一直在談**交點**，不可能得到平面上別的地方的點」→ 構造方法**內建**了封閉性 |
| **結合律** | ✔ 「看不出來，但**相信我**」 |

### 5.2 單位元素：無窮遠點

`[01:00]`【口頭】「規則 3 和 4 比較痛苦。」

需要一個**單位元素**（加法群裡叫「零」）$\mathcal{O}$，使

$$P + \mathcal{O} = P \qquad \text{對所有 } P$$

**問題**：用幾何構造試試看，**曲線上沒有任何點能當單位元素**。「這很令人沮喪。」

**解法**（`[01:02]`）：
> 【口頭】「我們用一個**非常非常髒的技巧**。這也是這部分不好教的原因。請在『**定義**』底下**畫線**：我們**定義**一個『**無窮遠點**』$\mathcal{O}$。」

**幾何上大致說得通**（`[01:04]`）：
- 想像 $\mathcal{O}$ 在 $y$ 軸方向的**正無窮或負無窮**遠處，「天空很高很高的地方」。
- 從 $P$ 連到天上那個點：如果點不夠高、偏右一點，線會斜斜的；**到了無窮遠，割線就變成一條垂直線**。
- 垂直線跟曲線的第三個交點 → 就在 $P$ 的**正下方（鏡射位置）**。
- 再對 $x$ 軸鏡射 → **回到 $P$**！✔
- 「有點手舞足蹈、不太精確，但幫助理解。」

### 5.3 反元素

`[01:05]` 對每個點 $P$，需要一個 $-P$ 使

$$P + (-P) = \mathcal{O}$$

【口頭】「加法寫法很不幸。之前乘法群我們寫 $a^{-1}$，這裡加法群寫 $-P$。」
「但 $-P$ **不是**什麼奇怪的無窮遠點，它是**很實在的點，有真正的座標**。」

**用幾何構造**（`[01:07]`）：連接 $P$ 和 $\mathcal{O}$ → 垂直線 → 第三個交點就是 $P$ 正下方的點 → **那就是 $-P$**。

$$\boxed{-P = (x, -y)}$$

**只要把 $P$ 對 $x$ 軸鏡射，就得到反元素。**

【課本補充】在 $GF(p)$ 上：$-y \equiv p - y \ (\mathrm{mod}\ p)$，所以

$$-P = (x_p, \; p - y_p)$$

#### 【口頭】為什麼這很好

`[01:09]`
- **在橢圓曲線上求反元素超簡單。**
- 對比 mod $p$：求反元素要用**擴展歐幾里得**，很費工。
- 「第五學期我有一門『**密碼學實作**』課，可以看成這門課的延續。有一些**特別快的橢圓曲線運算方法**，正是利用了『求點的反元素很容易』這個性質。」

### 5.4 ⚠️ 兩種不同的「負號」

`[01:09]`【口頭】「專心 60 秒。現在要讓你看看我們在做的事有多**怪**。」

$$-P = (x, \; -y)$$

**這兩個負號是完全不同的東西！**

| 負號 | 意思 |
|---|---|
| **右邊** $-y$ | 你從小學就會的負號（其實是 **mod $p$ 的負號**）。從 10 月第一講就在用 |
| **左邊** $-P$ | 從**群運算**來的、很怪的「反元素」 |

【口頭】「很不幸它們用同一個符號。等你開始做作業，某個時候你會說：『**喔對，他講過那個負號**，是完全不同的東西。』」

## 6. 例子：在 mod 17 上算 2P

`[01:11]`（課本 Example 9.4，教授在投影片上帶過）

**曲線**：$E: y^2 \equiv x^3 + 2x + 2 \ (\mathrm{mod}\ 17)$（$a = 2$、$b = 2$）
**點**：$P = (5, 1)$
**要算**：$2P = P + P$

#### ⚠️ 常見錯誤

`[01:12]`【口頭】
> 「**很睡的人**會怎麼做？說 $(5, 1) + (5, 1) = (10, 2)$。**這是非常非常錯的**。這**不是向量加法**。這就是為什麼跟我在這裡花 90 分鐘很好 —— **你不會犯這個蠢錯**。」

#### 正確做法

$P = Q$，所以用**點倍增**的斜率：

$$s = \frac{3x_1^2 + a}{2y_1} = (2 \cdot 1)^{-1}(3 \cdot 5^2 + 2) = 2^{-1} \cdot 77$$

- $77 \bmod 17 = 77 - 68 = 9$
- $2^{-1} \bmod 17 = 9$（因為 $2 \times 9 = 18 \equiv 1$）
- $s = 9 \times 9 = 81 \equiv 81 - 68 = \mathbf{13} \ (\mathrm{mod}\ 17)$

$$x_3 = s^2 - x_1 - x_2 = 13^2 - 5 - 5 = 169 - 10 = 159 \equiv 159 - 153 = \mathbf{6} \ (\mathrm{mod}\ 17)$$

$$y_3 = s(x_1 - x_3) - y_1 = 13(5 - 6) - 1 = -14 \equiv \mathbf{3} \ (\mathrm{mod}\ 17)$$

$$\boxed{2P = (5, 1) + (5, 1) = (6, 3)}$$

【口頭】「加兩個點，得到**另一個點**。」

#### 好習慣：檢查結果在曲線上

`[01:15]`【口頭】「做作業或 9 月考試時很容易算錯。一個好檢查：**結果一定要在曲線上**。」

【課堂討論】怎麼檢查？→ **代回方程式**：

$$y^2 = 3^2 = 9 \qquad x^3 + 2x + 2 = 216 + 12 + 2 = 230 = 13 \times 17 + 9 \equiv 9 \ (\mathrm{mod}\ 17) \;✔$$

【口頭】「課本當然沒算錯，所以成立。**從現在開始每次作業都要做這些公式。你會恨它。**」

## 7. 循環群

`[01:16]`【口頭】最後一個定理。下週三早上還有一週橢圓曲線。

【課堂討論】DLP 需要的不是隨便一個群，是什麼形容詞？→ **循環（cyclic）**群。

> **定理（課本 9.2.1）**：橢圓曲線上的點加上 $\mathcal{O}$ 有**循環子群**。在某些條件下，**所有點**形成一個循環群。

【口頭】「證明大概要學一年數論。所以就只是一個定理。『子群』我們還沒介紹。」

**例**（`[01:18]`，課本 p.246，「下週會重講，但作業恐怕需要」）：
同一條曲線 $y^2 \equiv x^3 + 2x + 2 \ (\mathrm{mod}\ 17)$，$P = (5, 1)$：

$$P,\; 2P,\; 3P,\; 4P,\; \ldots,\; 18P,\; 19P = \mathcal{O}$$

- 一共 **19 個元素**（18 個點 + $\mathcal{O}$）。
- 這是一個**循環群**，$P$ 是**原根（生成元）**。
- 【口頭】「跟以前一樣：以前是 $a^2, a^3, a^4, \ldots$ 一直**乘**，直到 $a^{10} = 1$。現在是 $2P, 3P, 4P, \ldots$ 一直**加 $P$**，看什麼時候變成**無窮遠點**。」

> 加法群裡的「$P$ 的 $k$ 次方」寫成 $kP$；「$= 1$」變成「$= \mathcal{O}$」。（回扣第 14 講的寫法提醒。）

【口頭】「今天到這裡。**好好享受作業。**」

## 8. 一頁速查表

### 8.1 定義

$$E: \; y^2 \equiv x^3 + ax + b \ (\mathrm{mod}\ p), \qquad 4a^3 + 27b^2 \not\equiv 0, \qquad \text{加上 } \mathcal{O}$$

| 項目 | 內容 |
|---|---|
| 群元素 | 曲線上的點 $(x, y)$ + 無窮遠點 $\mathcal{O}$ |
| 群運算 | 點加法「+」 |
| 單位元素 | $\mathcal{O}$（**定義**出來的） |
| 反元素 | $-P = (x, -y) = (x, p - y)$ |
| 對稱 | 對 $x$ 軸對稱 |

### 8.2 群運算公式

$$x_3 = s^2 - x_1 - x_2, \qquad y_3 = s(x_1 - x_3) - y_1 \ (\mathrm{mod}\ p)$$

| 情況 | 幾何 | 斜率 $s$ |
|---|---|---|
| $P \ne Q$（點加法） | 割線 → 第三交點 → 鏡射 | $\dfrac{y_2 - y_1}{x_2 - x_1}$ |
| $P = Q$（點倍增） | 切線 → 第二交點 → 鏡射 | $\dfrac{3x_1^2 + a}{2y_1}$ |

除法 = 乘以**模反元素**（擴展歐幾里得）

### 8.3 例子

$y^2 \equiv x^3 + 2x + 2 \ (\mathrm{mod}\ 17)$，$P = (5, 1)$：
- $s = 13$，$2P = (6, 3)$ ✔（不是 $(10, 2)$！）
- 群大小 19，$19P = \mathcal{O}$

### 8.4 金鑰長度

| 安全等級 | RSA / DH | **ECC** | AES |
|---|---|---|---|
| 80 | 1024 | **160** | 80 |
| 128 | 3072 | **256** | 128 |
| 192 | 7680 | **384** | 192 |
| 256 | 15360 | **512** | 256 |

**為什麼差這麼多**：$\mathbb{Z}_p^*$ 有 Index Calculus；ECC 只有平方根攻擊（第 14 講）。

### 8.5 三個提醒

1. **點加法不是向量加法。**
2. **$-P$ 的負號跟 $-y$ 的負號是兩回事。**
3. **算完代回曲線方程式檢查。**

## 附：本講一句話總結

> **橢圓曲線 $y^2 = x^3 + ax + b \bmod p$ 上的點，配上「割線（或切線）找第三交點再對 $x$ 軸鏡射」這個人為定義的加法，再定義一個無窮遠點當作零，就形成一個循環群 —— 它的 DLP 比 $\mathbb{Z}_p^*$ 難得多，所以 256 bit 的曲線就能達到 RSA 3072 bit 的安全性。**
