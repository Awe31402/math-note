## 9.1 判別式條件

**題目摘要**：證明曲線 $y^2 \equiv x^3 + 2x + 2 \bmod 17$ 滿足 $4a^3 + 27b^2 \neq 0 \bmod p$。
（⚠️ PDF 轉文字時「≠」變成了「=」；課本定義橢圓曲線要求的是 **≠ 0**。）

$a = 2$，$b = 2$：
$$4a^3 + 27b^2 = 4 \cdot 8 + 27 \cdot 4 = 32 + 108 = 140 = 8 \cdot 17 + 4 \equiv \mathbf{4} \neq 0 \ (\mathrm{mod}\ 17) \;✔$$

> 條件成立，所以這是一條「非奇異（nonsingular）」的橢圓曲線，點加法有定義。

**出處**：📖 §9.1.1（橢圓曲線的定義 9.1.1）；📝 L16 §2.2（橢圓曲線的定義）

## 9.2 點加法與倍增

**題目摘要**：在 $y^2 \equiv x^3 + 2x + 2 \bmod 17$ 上算 (1) $(2, 7) + (5, 2)$；(2) $(3, 6) + (3, 6)$。

⚠️ **題目有問題**：這三個點**都不在這條曲線上**：

| 點 | $x^3 + 2x + 2 \bmod 17$ | $y^2 \bmod 17$ | 在曲線上？ |
|---|---|---|---|
| (2, 7) | $8 + 4 + 2 = 14$ | $49 \equiv 15$ | ✘ |
| (5, 2) | $125 + 10 + 2 = 137 \equiv 1$ | 4 | ✘ |
| (3, 6) | $27 + 6 + 2 = 35 \equiv 1$ | $36 \equiv 2$ | ✘ |

（課本例 9.5 列出了這條曲線所有 19 個點，x = 2 根本不在其中；x = 3 和 x = 5 的點是 (3, 1)、(3, 16)、(5, 1)、(5, 16)。）
下面還是**照公式**算出結果，練習用，但結果不是群運算上有意義的點。

### (1) $(2, 7) + (5, 2)$（點加法）

- $s = \dfrac{2 - 7}{5 - 2} = \dfrac{-5}{3}$；$3^{-1} \bmod 17 = 6$（$3 \cdot 6 = 18$）→ $s = -5 \cdot 6 = -30 \equiv 4$
- $x_3 = 4^2 - 2 - 5 = 9$
- $y_3 = 4(2 - 9) - 7 = -35 \equiv 16$

> 公式結果：**(9, 16)**（這個點剛好在曲線上，是 $5P$，但輸入點不在曲線上，所以這只是巧合）

### (2) $(3, 6) + (3, 6)$（點倍增）

- $s = \dfrac{3 \cdot 3^2 + 2}{2 \cdot 6} = \dfrac{29}{12} \equiv \dfrac{12}{12} = 1$
- $x_3 = 1^2 - 3 - 3 = -5 \equiv 12$
- $y_3 = 1 \cdot (3 - 12) - 6 = -15 \equiv 2$

> 公式結果：**(12, 2)**（不在曲線上：$12^3 + 24 + 2 \equiv 3$，$2^2 = 4$）

**如果改用曲線上的點練習**，例如課本例 9.4：$(5, 1) + (5, 1) = (6, 3)$。

**出處**：📖 §9.1.2（公式）、例 9.4、例 9.5（點的列表）；📝 L16 §4.3（解析公式）、§6（例子：在 mod 17 上算 2P）

## 9.3 驗證 Hasse 定理

**題目摘要**：$y^2 \equiv x^3 + 2x + 2 \bmod 17$ 有 $\#E = 19$。驗證 Hasse 定理。

Hasse 定理：$p + 1 - 2\sqrt{p} \le \#E \le p + 1 + 2\sqrt{p}$

$p = 17$，$\sqrt{17} \approx 4.12$：
$$18 - 8.25 \le \#E \le 18 + 8.25 \;\Rightarrow\; 9.75 \le 19 \le 26.25 \;✔$$

**出處**：📖 §9.2（定理 9.2.2 Hasse 定理）；📝 L17 §1.7（群有多大：Hasse 定理）

## 9.4 為什麼所有點都是原根

**題目摘要**：為什麼 $y^2 \equiv x^3 + 2x + 2 \bmod 17$ 上的點都是原根？

**因為群的大小 $\#E = 19$ 是質數。**
- 每個元素的階都整除群的大小（📖 定理 8.2.3）。
- 19 的因數只有 1 和 19。
- 只有單位元素 $\mathcal{O}$ 的階是 1，所以**其他每個點的階都是 19**，都能生成整個群 → 都是原根。

（課本例 9.5：「For this specific curve the group order is a prime and, according to Theorem 8.2.4, every element is primitive.」）

**出處**：📖 §9.2（例 9.5）、§8.2.2（定理 8.2.3、8.2.4）；📝 L16 §7（循環群）、L13 §3.7

## 9.5 Z₇ 上的曲線

**題目摘要**：$E: y^2 = x^3 + 3x + 2$ over $\mathbb{Z}_7$。(1) 找出所有點；(2) 群的階；(3) $\alpha = (0, 3)$ 的階，是原根嗎？

### (1) 所有點

**mod 7 的平方**：$0^2 = 0$，$1^2 = 6^2 = 1$，$2^2 = 5^2 = 4$，$3^2 = 4^2 = 2$。平方剩餘：{1, 2, 4}。

| $x$ | $x^3 + 3x + 2 \bmod 7$ | 是平方？ | $y$ | 點 |
|---|---|---|---|---|
| 0 | 2 | ✔ | 3, 4 | (0, 3), (0, 4) |
| 1 | $1 + 3 + 2 = 6$ | ✘ | | |
| 2 | $8 + 6 + 2 = 16 \equiv 2$ | ✔ | 3, 4 | (2, 3), (2, 4) |
| 3 | $27 + 9 + 2 = 38 \equiv 3$ | ✘ | | |
| 4 | $64 + 12 + 2 = 78 \equiv 1$ | ✔ | 1, 6 | (4, 1), (4, 6) |
| 5 | $125 + 15 + 2 = 142 \equiv 2$ | ✔ | 3, 4 | (5, 3), (5, 4) |
| 6 | $216 + 18 + 2 = 236 \equiv 5$ | ✘ | | |

（判別式：$4 \cdot 27 + 27 \cdot 4 = 216 \equiv 6 \neq 0$ ✔）

### (2) 群的階

8 個點 + 無窮遠點 $\mathcal{O}$ → **$\#E = 9$**
（Hasse：$8 - 2\sqrt{7} \approx 2.7 \le 9 \le 13.3$ ✔）

### (3) $\alpha = (0, 3)$ 的階

| 倍數 | 計算 | 結果 |
|---|---|---|
| $\alpha$ | | (0, 3) |
| $2\alpha$ | 倍增：$s = \frac{3 \cdot 0 + 3}{2 \cdot 3} = 3 \cdot 6^{-1} = 3 \cdot 6 = 18 \equiv 4$；$x = 16 - 0 \equiv 2$；$y = 4(0 - 2) - 3 = -11 \equiv 3$ | **(2, 3)** |
| $3\alpha$ | $(2, 3) + (0, 3)$：$s = \frac{0}{-2} = 0$；$x = 0 - 2 - 0 \equiv 5$；$y = 0 - 3 \equiv 4$ | **(5, 4)** |
| $4\alpha$ | $(5, 4) + (0, 3)$：$s = \frac{-1}{-5} = 5^{-1} = 3$；$x = 9 - 5 - 0 = 4$；$y = 3(5 - 4) - 4 = -1 \equiv 6$ | **(4, 6)** |
| $5\alpha$ | $(4, 6) + (0, 3)$：$s = \frac{-3}{-4} = 3 \cdot 4^{-1} = 3 \cdot 2 = 6$；$x = 36 - 4 \equiv 4$；$y = 6 \cdot 0 - 6 \equiv 1$ | **(4, 1)** = $-4\alpha$ |

階一定整除 9（1、3 或 9）。$3\alpha = (5, 4) \neq \mathcal{O}$，所以階不是 1 或 3 → **$\text{ord}(\alpha) = 9$**。
（另外 $5\alpha = -4\alpha$，也就是 $9\alpha = \mathcal{O}$，一致。）

> **$\alpha$ 的階是 9 = 群的大小 → $\alpha$ 是原根。**

（每個點都代回曲線檢查：例如 (5, 4)：$16 \equiv 2$，$x^3 + 3x + 2 = 142 \equiv 2$ ✔）

**出處**：📖 §9.1（點的定義）、§9.1.2（公式）、§8.2.2（階整除群大小）；📝 L16 §4.3、§7（循環群）、L17 §1.1

## 9.6 Double-and-Add 的步驟與成本

**題目摘要**：(1) 以 $P$ 為變數，示範 $a = 19$ 和 $a = 160$ 的 Double-and-Add；(2) $n$ bit 的純量平均要幾次加法、幾次倍增？(3) $n = 160$，每次群運算 20 μs，一次點乘法要多久？

### (1)

**$a = 19 = (10011)_2$**

| 步驟 | 處理的位元 | 運算 | 結果 | 純量（二進位） |
|---|---|---|---|---|
| 0 | 1 | 初始 | $P$ | 1 |
| 1 | 0 | DOUBLE | $2P$ | 10 |
| 2 | 0 | DOUBLE | $4P$ | 100 |
| 3 | 1 | DOUBLE | $8P$ | 1000 |
| | | ADD | $9P$ | 1001 |
| 4 | 1 | DOUBLE | $18P$ | 10010 |
| | | ADD | $19P$ | 10011 |

→ 4 次倍增、2 次加法

**$a = 160 = (10100000)_2$**

| 步驟 | 位元 | 運算 | 結果 |
|---|---|---|---|
| 0 | 1 | 初始 | $P$ |
| 1 | 0 | DOUBLE | $2P$ |
| 2 | 1 | DOUBLE → ADD | $4P$ → $5P$ |
| 3 | 0 | DOUBLE | $10P$ |
| 4 | 0 | DOUBLE | $20P$ |
| 5 | 0 | DOUBLE | $40P$ |
| 6 | 0 | DOUBLE | $80P$ |
| 7 | 0 | DOUBLE | $160P$ |

→ 7 次倍增、1 次加法

### (2) 平均次數（$n$ bit）

- 倍增：每個位元（除了最高位）一次 → 約 **$n$ 次**（精確地說 $n - 1$）
- 加法：只有位元是 1 時，平均一半 → 約 **$n / 2$ 次**

（總共約 $1.5n$ 次群運算，跟 Square-and-Multiply 一樣。）

### (3) $n = 160$

$$(160 + 80) \times 20\ \mu s = 240 \times 20 = 4800\ \mu s = \mathbf{4.8 \text{ ms}}$$

**出處**：📖 §9.2（Double-and-Add 演算法、例 9.7、平均 1.5t）；📝 L17 §3.2（Square-and-Multiply → Double-and-Add）、§3.3（例：26P）

## 9.8 用已知點 Q 減少運算

**題目摘要**：同 9.7 的曲線，$\#E = 37$，已知 $Q = 15P = (14, 23)$。用最少的群運算算：(1) $16P$；(2) $38P$；(3) $53P$；(4) $14P + 4Q$；(5) $23P + 11Q$。

**兩個技巧**：
- $37P = \mathcal{O}$（群的大小是 37，而且是質數），所以純量可以 **mod 37**。
- $-P = (8, -10) = (8, 19)$，取負號不用計算。

### (1) $16P = Q + P$

**1 次點加法**：$(14, 23) + (8, 10)$
- $s = \frac{10 - 23}{8 - 14} = \frac{-13}{-6} = 13 \cdot 6^{-1} = 13 \cdot 5 = 65 \equiv 7$
- $x = 49 - 14 - 8 = 27$
- $y = 7(14 - 27) - 23 = -114 \equiv 2$

> **$16P = (27, 2)$**

（交叉驗證：用 9.7 的 $8P = (13, 6)$ 倍增：$s = \frac{3 \cdot 169 + 4}{12} \equiv 18 \cdot 17 = 306 \equiv 16$，$x = 256 - 26 = 230 \equiv 27$，$y = 16(13 - 27) - 6 = -230 \equiv 2$ → 一樣是 (27, 2) ✔，這也證實了 $Q = 15P$。）

### (2) $38P$

$38 \bmod 37 = 1$ → **$38P = P = (8, 10)$**（0 次運算）

### (3) $53P$

$53 \bmod 37 = 16$ → **$53P = 16P = (27, 2)$**（用 (1) 的結果，1 次運算）

### (4) $14P + 4Q$

$14 + 4 \cdot 15 = 74 = 2 \cdot 37$ → **$\mathcal{O}$**（0 次運算）

### (5) $23P + 11Q$

$23 + 11 \cdot 15 = 188$，$188 \bmod 37 = 188 - 185 = 3$ → $3P = 2P + P$

**2 次運算**：$2P = (0, 22)$（9.7 已算），再加 $P$：
- $s = \frac{10 - 22}{8 - 0} = \frac{-12}{8} = \frac{-3}{2} = -3 \cdot 15 = -45 \equiv 13$
- $x = 169 - 0 - 8 = 161 \equiv 16$
- $y = 13(0 - 16) - 22 = -230 \equiv 2$

> **$3P = (16, 2)$**（檢查：$16^3 + 64 + 20 \equiv 4 = 2^2$ ✔）

| 題 | 化簡 | 群運算次數 | 結果 |
|---|---|---|---|
| (1) | $Q + P$ | 1 | (27, 2) |
| (2) | $38 \equiv 1$ | 0 | (8, 10) |
| (3) | $53 \equiv 16$ | 1 | (27, 2) |
| (4) | $74 \equiv 0$ | 0 | $\mathcal{O}$ |
| (5) | $188 \equiv 3$ | 2 | (16, 2) |

**出處**：📖 §9.2（循環群、$-P$、例 9.5 的「繞一圈」）、§8.2.2；📝 L17 §1.2（18P 就是 −P）、§1.3（繞一圈回來）、L16 §5.3（反元素）

## 9.9 ECDH 會期金鑰

**題目摘要**：曲線 $y^2 \equiv x^3 + x + 6 \bmod 11$。你的私鑰 $a = 6$，Bob 的公鑰 $B = (5, 9)$。算會期金鑰。

會期金鑰 $T_{AB} = aB = 6B$。$6 = (110)_2$。
（$B$ 在曲線上：$125 + 5 + 6 = 136 \equiv 4$，$81 \equiv 4$ ✔）

| 步驟 | 運算 | 計算 | 結果 |
|---|---|---|---|
| 0 | 初始 | | $B = (5, 9)$ |
| 1a | DOUBLE | $s = \frac{3 \cdot 25 + 1}{18} \equiv 10 \cdot 7^{-1} = 10 \cdot 8 = 80 \equiv 3$；$x = 9 - 10 \equiv 10$；$y = 3(5 - 10) - 9 = -24 \equiv 9$ | $2B = (10, 9)$ |

檢查：$(10, 9)$：$1016 \equiv 4$，$81 \equiv 4$ ✔；$(7, 2)$：$356 \equiv 4$ ✔；$(2, 7)$：$8 + 2 + 6 = 16 \equiv 5$，$49 \equiv 5$ ✔

> **會期金鑰 $T_{AB} = (2, 7)$**（實務上通常只取 x 座標再雜湊）

## 9.10 驗證課本的 ECDH 例子

**題目摘要**：驗證課本例 9.8 中 Alice 做的兩個點乘法，列出中間結果。

例 9.8：曲線 $y^2 \equiv x^3 + 2x + 2 \bmod 17$，$P = (5, 1)$，Alice 的 $a = 3$，Bob 的公鑰 $B = (7, 11)$。

### Alice 的第一個：$A = 3P$

- $2P = (6, 3)$（課本例 9.4）
- $3P = (6, 3) + (5, 1)$：$s = \frac{1 - 3}{5 - 6} = \frac{-2}{-1} = 2$；$x = 4 - 6 - 5 = -7 \equiv 10$；$y = 2(6 - 10) - 3 = -11 \equiv 6$

> $A = 3P = $ **(10, 6)** ✔（跟課本一樣）

### Alice 的第二個：$T_{AB} = 3B = 3 \cdot (7, 11)$

- $2B$：$s = \frac{3 \cdot 49 + 2}{22} \equiv 13 \cdot 5^{-1} = 13 \cdot 7 = 91 \equiv 6$；$x = 36 - 14 = 22 \equiv 5$；$y = 6(7 - 5) - 11 = 1$ → $2B = (5, 1)$
  （有趣：$B = 10P$，$2B = 20P = P$，因為群的大小是 19。）
- $3B = (5, 1) + (7, 11)$：$s = \frac{11 - 1}{7 - 5} = 5$；$x = 25 - 5 - 7 = 13$；$y = 5(5 - 13) - 1 = -41 \equiv 10$

> $T_{AB} = 3B = $ **(13, 10)** ✔（跟課本一樣，也跟課本例 9.5 的 $11P = (13, 10)$ 一致，因為 $3 \cdot 10 = 30 \equiv 11 \ (\mathrm{mod}\ 19)$）

**出處**：📖 §9.3（例 9.8）、例 9.4、例 9.5；📝 L17 §2.5（數字例子）

## 9.11 用座標雜湊產生金鑰的弱點

**題目摘要**：ECDH 後雙方有共同點 $R = (x, y)$，模數是 64 bit 質數。會期金鑰 $K_{AB} = h(x \| y)$ 給 128 bit 區塊密碼用。描述對對稱密碼的有效暴力攻擊；有幾個金鑰 bit 是真的隨機的？（假設有 mod $p$ 開平方根的函數。）

### 觀察

- $x$ 最多 64 bit。
- **$y$ 由 $x$ 決定**（只差正負號）：$y = \pm\sqrt{x^3 + ax + b} \bmod p$（課本 §9.3 也指出兩個座標不是獨立的）。
- 所以 $(x, y)$ 的可能組合大約只有 $p \approx 2^{64}$ 種（約一半的 $x$ 有兩個 $y$，另一半沒有點）。

### 攻擊步驟

需要一組已知明文–密文 $(m, c)$。

```
for x = 0, 1, …, p − 1:
    z = x³ + a·x + b mod p
    if z 不是平方剩餘: 跳過
    y = sqrt(z) mod p
    for y' in {y, p − y}:
        K = h(x ‖ y')
        if Decrypt_K(c) == m: 找到金鑰，結束
```

工作量約 $2^{64}$ 次「雜湊 + 解密」，遠小於 $2^{128}$。

> **只有約 64 個 bit 是真的隨機的**（金鑰的熵最多約 $\log_2(\#E) \approx 64$ bit）。雜湊函數輸出雖然是 128 bit，但不會增加熵。

**教訓**：ECC 的安全等級約是位元長度的一半（64 bit 的曲線只有約 32 bit 的 ECDLP 安全性），而且導出的對稱金鑰熵也受曲線大小限制。要產生 128 bit 的 AES 金鑰，至少要用約 256 bit 的曲線（課本表 6.1）。

**出處**：📖 §9.3（兩個座標不獨立，只用一個來導出金鑰）、§9.4（安全性）、§6.2.4（表 6.1）；📝 L17 §2.4（拿共享點來加密）、§1.9（ECDLP 有多難）

## 9.12 推導點加法公式

**題目摘要**：給 $P = (x_1, y_1)$、$Q = (x_2, y_2)$，推導 $R = P + Q = (x_3, y_3)$。提示：先寫出通過兩點的直線，代入曲線方程式；三次多項式 $x^3 + a_2 x^2 + a_1 x + a_0$ 的三個根滿足 $x_0 + x_1 + x_2 = -a_2$。

### 點加法（$P \ne Q$）

**步驟 1：直線**
$$y = s x + m, \qquad s = \frac{y_2 - y_1}{x_2 - x_1}, \qquad m = y_1 - s x_1$$

**步驟 2：代入曲線** $y^2 = x^3 + ax + b$
$$(sx + m)^2 = x^3 + ax + b$$
$$x^3 - s^2 x^2 + (a - 2sm)\,x + (b - m^2) = 0$$

**步驟 3：用根的和**
這個三次方程式的三個根就是直線和曲線的三個交點的 x 座標：$x_1$、$x_2$、和第三個交點 $x_3'$。
$x^2$ 的係數是 $a_2 = -s^2$，所以：
$$x_1 + x_2 + x_3' = s^2 \;\Rightarrow\; x_3' = s^2 - x_1 - x_2$$

**步驟 4：第三個交點的 y 座標**（在直線上）
$$y_3' = s x_3' + m = s x_3' + y_1 - s x_1 = -\left(s(x_1 - x_3') - y_1\right)$$

**步驟 5：對 x 軸鏡射**（點加法的定義）
$$x_3 = x_3' = s^2 - x_1 - x_2, \qquad y_3 = -y_3' = s(x_1 - x_3) - y_1 \qquad \blacksquare$$

### 點倍增（$P = Q$）

直線改成**切線**。對曲線方程式隱函數微分：
$$2y \frac{dy}{dx} = 3x^2 + a \;\Rightarrow\; s = \frac{3x_1^2 + a}{2y_1}$$
切線跟曲線在 $x_1$ 處相切（**重根**，算兩次），所以根的和變成 $x_1 + x_1 + x_3' = s^2$，$x_3 = s^2 - 2x_1$。
其餘步驟相同，得到同一組公式（$x_2 = x_1$）。

> 這些步驟只用到加、減、乘、除，所以在任何體（包括 GF(p)）上都能用 —— 這就是課本說的「把幾何作圖變成公式」。

**出處**：📖 §9.1.2（幾何解釋與公式）；📝 L16 §4.1–4.4（點加法、點倍增、解析公式、公式怎麼來的）
