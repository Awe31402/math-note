## 1. 動機：AES 裡面全是「奇怪的算術」

`[00:02]`

```
          128 bit 明文
               ↓
          ┌─────────┐
 金鑰 →   │   AES   │     金鑰：128 / 192 / 256 bit
          └─────────┘
               ↓
          128 bit 密文
```

- 跟 DES 很大的差別：**支援三種金鑰長度**，而且都**比 DES 長很多**。
- 【口頭】幾乎每個瀏覽器、很多提款機、WAN 路由器、Wi-Fi 路由器裡都有 AES。

**問題**：AES 也有 S-box、也有類似置換的東西，跟 DES 有點像。但**AES 裡所有的內部運算，都是在一種很不尋常的數字系統裡做計算**。

所以今天不談密碼學本身，而是談一塊**離散數學**：**有限體（finite field）**。

【口頭】`[00:05]`「有限體」聽起來已經很炫，但它還有一個更好聽的同義詞：**伽羅瓦體（Galois Field）**。
> 「回家想讓女朋友、男朋友或媽媽印象深刻，就說：『**我今天學了伽羅瓦體**。』」

【口頭】`[00:06]` 「不檢查的作業：去維基百科查 **Évariste Galois**。故事很精彩 —— 他 **21 歲死於一場決鬥**。不會考。」

## 2. 有限體入門

### 2.1 群、環、體

`[00:06]`【口頭】要懂有限體，得先知道什麼是**體（field）**；要懂體，得知道**環（ring）**；要懂環，得知道**群（group）**。三個基本的**代數結構**：

| 結構 | 運算 | 說明 |
|---|---|---|
| **群（Group）** | 一種運算（例如 +），以及它的反運算（−） | 最簡單的結構 |
| **環（Ring）** | +、−、× | 第 2 講學過。**不是每個元素都有乘法反元素** → 常常不能除 |
| **體（Field）** | +、−、×、**÷（求逆）** | **四則運算全部都有** |

【課堂討論】在數學課學過群嗎？→ 沒有。「很好，明年離散數學會講更多。」

#### 群的四（五）條規則【課本補充】

一個集合 $G$ 加上一個運算 $\circ$，如果滿足：

1. **封閉性**：$a \circ b \in G$
2. **結合律**：$a \circ (b \circ c) = (a \circ b) \circ c$
3. **單位元素**：存在 $1$ 使 $a \circ 1 = a$
4. **反元素**：每個 $a$ 都有 $a^{-1}$ 使 $a \circ a^{-1} = 1$
5. （額外）**交換律** $a \circ b = b \circ a$ → 叫**阿貝爾群（abelian group）**

例：$\mathbb{Z}_m$ 配上 **mod $m$ 加法**是一個群（單位元素 0）；但配上**乘法就不是**，因為很多元素沒有反元素。

### 2.2 體的定義

`[00:10]`【口頭】優雅的寫法（課本定義 4.3.2）：拿一個集合，說它**對加法是一個群、對乘法也是一個群**。

> **體 $F$**：
> - 所有元素對「+」形成一個**加法群**，單位元素是 0。
> - **除了 0 以外**的所有元素對「×」形成一個**乘法群**，單位元素是 1。
> - 兩種運算混在一起時，**分配律**成立：$a(b + c) = ab + ac$。

**白話**：體就是一個「**可以加、減、乘、除**」的集合。

| 例子 | 是體嗎 | 理由 |
|---|---|---|
| 實數 $\mathbb{R}$ | ✔ | 四則運算都可以 |
| 複數 $\mathbb{C}$ | ✔ | 【口頭】「我們是電機系，所以很熟複數」 |
| 自然數 $\mathbb{N}$、整數 $\mathbb{Z}$ | ✘ | 大部分數字**沒有乘法反元素**，不能除 |

#### 【Q&A】0 有反元素嗎？

`[00:41]`（這段在講質數體時出現，放在這裡比較好理解）

**學生指出**：$0 \times$ 任何數都不會等於 1。

**教授答**：「**超棒的觀察。**」回去看定義那一行：**「除了 0 以外的所有元素」**形成乘法群。
> 「我剛說體由兩個群組成，那**不是全部的真相**。加法群要**全部**元素；乘法群是**除了 0 以外**的元素。」

### 2.3 密碼學要的是「有限」體

`[00:14]` 實數、複數都有**無限多**個元素。

> **密碼學幾乎永遠只想處理有限個數字。**

【口頭】`[00:16]`「**信不信由你**，AES 要在一個**剛好 256 個元素**的集合裡做計算。」—— 比實數少很多。「怎麼用 256 個元素做計算？」

【口頭】`[00:17]`「請聽好。90 分鐘的內容很多。**週末不要自己啃第 4 章**，那不會只花 90 分鐘。」

### 2.4 存在定理：只有 $p^m$ 個元素的有限體存在

`[00:18]`【口頭】「這是一個**非常奇怪**的敘述。」

> **定理**：有 $n$ 個元素的有限體**存在，若且唯若** $n = p^m$，其中 $p$ 是**質數**、$m$ 是**正整數**。
> 這個有限體記作 $GF(p^m)$。$p$ 叫這個體的**特徵（characteristic）**。

【課本補充】元素個數也叫體的**階（order）**。

**例子**（`[00:19]`）：

| 元素個數 | 寫成 $p^m$ | 存在嗎 | 記法 |
|---|---|---|---|
| 11 | $11^1$ | ✔ | $GF(11)$ |
| 81 | $3^4$ | ✔ | $GF(81)$ |
| 9 | $3^2$ | ✔ | $GF(9)$ |
| **256** | $2^8$ | ✔ | $GF(2^8)$ ←【口頭】「我叫它**AES 體**」 |
| **12** | $2^2 \times 3$ | ✘ | — |

> ⚠️ 逐字稿把 81 的分解聽成「$p = 3$，指數 3」，正確是 $81 = 3^4$。

【課堂討論】`[00:21]` $p$ 最小可以是多少？→ **2**，最小的質數。這種體在實務上**超級超級重要**。

**為什麼 12 不行**（`[00:23]`）：$12 = 2^2 \times 3$ 是**兩個不同質數**的乘積，不是 $p^m$ 的形式。
> 【口頭】「你可以叫這 12 個元素 A、B、C……L，但**你不可能**定出一套組合規則，滿足體所需要的所有條件。」

【口頭】「這個 AES 體就在你的瀏覽器裡，不管你喜不喜歡。有一個小小的函式庫在做這個體的算術。」

### 2.5 兩大類：質數體與擴張體

`[00:25]`

| 情況 | 名稱 | 記法 |
|---|---|---|
| $m = 1$ | **質數體（prime field）** | $GF(p)$ |
| $m \ge 2$ | **擴張體（extension field）** | $GF(p^m)$ |
| 特例：$p = 2$ | 二元擴張體 | $GF(2^m)$ ← **AES 用的** |

【口頭】
- 密碼學**兩種都很愛**。
- 「我的**博士論文**就是做 $GF(2^m)$ 的，很久很久以前。」
- 【口頭】`[00:27]` 德文的正確說法是 **Endlicher Körper** 或 **Galois-Körper**，不是「Galois Feld」。

**今天的策略**（`[00:28]`）：
- 這門課沒時間講完整的有限體理論（之後有一整學期 14 週的有限體課程，我們只有一週）。
- AES 只需要**一個**體：$GF(2^8)$。
- 先學**質數體**（很簡單）建立感覺，再學**擴張體**。

## 3. 質數體 $GF(p)$ 的算術

`[00:30]`【口頭】這節更精確的標題是「**怎麼在質數體裡計算**」。

### 3.1 元素

$$GF(p) = \{0, 1, 2, \ldots, p - 1\}$$

【口頭】`[00:32]`「這看起來太簡單了，對吧？為什麼 Paar 教授要寫這個？**10～15 分鐘後切到擴張體時，元素突然就不是數字了。**你們被警告了。」

### 3.2 四種運算

`[00:33]` 設 $a, b \in GF(p)$：

| 運算 | 做法 |
|---|---|
| **加法** | $c \equiv a + b \ (\mathrm{mod}\ p)$ |
| **減法** | $d \equiv a - b \ (\mathrm{mod}\ p)$ |
| **乘法** | $e \equiv a \cdot b \ (\mathrm{mod}\ p)$ |
| **求逆** | 找 $a^{-1}$ 使 $a \cdot a^{-1} \equiv 1 \ (\mathrm{mod}\ p)$ |

- 就是**一般整數運算 + mod $p$**，第 2 講學過了。
- 這樣算，**體的所有條件都滿足**。例如封閉性：$a + b$ 可能太大，但 mod $p$ 之後又回到集合裡。
- 【口頭】`[00:37]`「我沒有證明。每個數學家都討厭我的課。」

**求逆怎麼算？**

`[00:38]`
- 第 2 講仿射密碼時是**試出來的**（暴力法）。
- 正式方法是**擴展歐幾里得演算法**（課本第 6 章，**聖誕節前最後一週**講 → 第 11 講）。

【課本補充】
> **定理**：$p$ 是質數時，整數環 $\mathbb{Z}_p$ 就是質數體 $GF(p)$。**所有非零元素都有反元素。**

回扣第 2 講：$\mathbb{Z}_m$ 是環；**當 $m$ 剛好是質數時，它不只是環，還是體**。（因為對質數 $p$，任何 $1 \le a < p$ 都有 $\gcd(a, p) = 1$。）

#### 例：$GF(5)$ 的乘法與反元素【課本補充】

| × | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| **0** | 0 | 0 | 0 | 0 | 0 |
| **1** | 0 | 1 | 2 | 3 | 4 |
| **2** | 0 | 2 | 4 | 1 | 3 |
| **3** | 0 | 3 | 1 | 4 | 2 |
| **4** | 0 | 4 | 3 | 2 | 1 |

反元素：$1^{-1} = 1$、$2^{-1} = 3$、$3^{-1} = 2$、$4^{-1} = 4$、$0^{-1}$ 不存在。

#### 最小的體：$GF(2)$

| + | 0 | 1 |  | × | 0 | 1 |
|---|---|---|---|---|---|---|
| **0** | 0 | 1 |  | **0** | 0 | 0 |
| **1** | 1 | 0 |  | **1** | 0 | 1 |

- $GF(2)$ 的**加法 = XOR**（第 3 講）
- $GF(2)$ 的**乘法 = AND**

`[00:43]`【口頭】「你可能覺得前面一大堆定義沒什麼用，**而真正的計算超簡單**。但世界有時很壞心：**AES 不是建立在質數體上**，是建立在 $GF(2^8)$ 這個**擴張體**上。抓穩了，擴張體的算術**非常不一樣**。」

## 4. 擴張體 $GF(2^m)$ 的算術

`[00:45]`【口頭】
> 「請安靜。**這是到目前為止這門課智力上最有挑戰的部分**，相信我。專心 45 分鐘。如果你很累、太晚睡，睡著沒關係，**但不要講話**，不要打擾其他 100 個同學。」

### 4.1 元素是多項式！

`[00:46]`【口頭】「這是我們第一次碰到一個**元素不是無聊的整數**的有限體。」

> **$GF(2^m)$ 的元素是多項式：**
> $$A(x) = a_{m-1}x^{m-1} + \cdots + a_1 x + a_0, \qquad a_i \in GF(2) = \{0, 1\}$$

- 最高次方是 $m - 1$ → 一共 **$m$ 個係數**。
- 係數只能是 0 或 1，屬於 $GF(2)$。$GF(2)$ 是這個擴張體的**子體（subfield）**。

【課堂討論】`[00:49]` $GF(2)$ 是擴張體嗎？→ 不是，它是**質數體**。「一個非常小、非常無聊的質數體，只有 0 和 1。」

**AES 的情況**：$m = 8$，每個元素有 8 個係數 $a_0, \ldots, a_7$：

$$A(x) = a_7 x^7 + a_6 x^6 + \cdots + a_1 x + a_0$$

【課本補充】
- 剛好 $2^8 = 256$ 個這樣的多項式，它們的集合就是 $GF(2^8)$。
- **每個元素剛好可以存成 1 個 byte**：$A = (a_7, a_6, \ldots, a_0)$。不用存 $x^7$、$x^6$，從位置就知道是哪個次方。
- 這正是 AES 選 $GF(2^8)$ 的原因：**AES 把內部資料的每一個 byte 都當成 $GF(2^8)$ 的元素**。

### 4.2 例：$GF(2^3)$ 的 8 個元素

`[00:50]` 每個元素長這樣：$a_2 x^2 + a_1 x + a_0$，每個係數是 0 或 1。

【口頭】「忘掉代數、體、定理。從**電腦科學**的角度看元素：它就是一個 **3 bit 的向量**。」

【課堂討論】3 bit 能表示幾個不同的東西？→ $2 \times 2 \times 2 = 8$。所以這是 $GF(8)$。

| bit 向量 $(a_2 a_1 a_0)$ | 多項式 |
|---|---|
| 000 | $0$ |
| 001 | $1$ |
| 010 | $x$ |
| 011 | $x + 1$ |
| 100 | $x^2$ |
| 101 | $x^2 + 1$ |
| 110 | $x^2 + x$ |
| 111 | $x^2 + x + 1$ |

$$GF(2^3) = \{0,\; 1,\; x,\; x+1,\; x^2,\; x^2+1,\; x^2+x,\; x^2+x+1\}$$

【口頭】`[00:56]`「這不是什麼深奧的有限體理論，只是剛好得到你需要的元素個數。**真正的問題是：怎麼用這些多項式做計算？**」

### 4.3 加法與減法

`[01:01]`【口頭】「你用瀏覽器加密信用卡號、連到 eBay 或 Amazon 時，裡面就是這些代表數字的多項式。」

> **加法與減法 = 一般的多項式加減，係數 mod 2。**
> $$C(x) = A(x) \pm B(x) = \sum_{i=0}^{m-1} c_i x^i, \qquad c_i \equiv a_i + b_i \ (\mathrm{mod}\ 2)$$

- 就是**同次方的係數相加**，非常直覺。
- 唯一的細節：**係數的運算在子體 $GF(2)$ 裡做 → mod 2**。
- mod 2 的加法 = 減法 = **XOR**（第 3 講）。所以**加法和減法結果一樣**。

#### 例（`[01:06]`）：$GF(2^3)$ 中

$$\begin{aligned}
A(x) &= x^2 + 1 & &(101) \\
B(x) &= x^2 + x + 1 & &(111) \\
\hline
A + B &= (1+1)x^2 + x + (1+1) = x & &(010)
\end{aligned}$$

【口頭】「一般會得到 $2x^2 + x + 2$。但 $GF(2)$ 是質數體，係數要 mod 2，$1 + 1 = 0$。」

**在電腦上**：就是 bit 向量的 **XOR**：`101 ⊕ 111 = 010` ✔

【課本補充】$GF(2^8)$ 的例子：

$$\begin{aligned}
A(x) &= x^7 + x^6 + x^4 + 1 \\
B(x) &= x^4 + x^2 + 1 \\
\hline
C(x) &= x^7 + x^6 + x^2
\end{aligned}$$

AES 的**金鑰加法層**用的就是這個加法。

### 4.4 乘法：問題來了

`[01:09]`【口頭】「這堂課越來越極端、越來越複雜、越來越有趣。**接下來 10 分鐘你不想錯過**，不然下週三就得自己在家硬做作業。」

直覺：加法就是多項式加法，那**乘法就是多項式乘法**吧？試試看：

**例**：$GF(2^3)$ 中，$A(x) = x^2 + 1$，$B(x) = x^2 + x + 1$

$$\begin{aligned}
A \cdot B &= x^2(x^2 + x + 1) + 1 \cdot (x^2 + x + 1) \\
&= x^4 + x^3 + x^2 + x^2 + x + 1 \\
&= x^4 + x^3 + (1+1)x^2 + x + 1 \\
&= x^4 + x^3 + x + 1
\end{aligned}$$

【口頭】`[01:13]`「這是七年級數學，不複雜。**問題在哪？為什麼這不是正確答案？**」

【課堂討論】學生答：**它不在體裡！** 體只有 8 個元素，最高到 $x^2$。$x^4 + x^3 + x + 1$ 不是其中之一。

> **這就是為什麼擴張體的乘法很複雜。**

### 4.5 解法：mod 不可約多項式

`[01:14]`【課堂討論】回想質數體：在 $GF(7)$ 中 $3 \times 4 = 12$，12 不在體裡。怎麼辦？→ **mod 7**。

同樣的想法用在擴張體：**做模約減**。但不是 mod 一個數字，而是 **mod 一個多項式**。

【課堂討論】要 mod 什麼樣的多項式？
- 質數體 mod 的 7 是什麼樣的數？**質數**。
- 所以要的是「**像質數一樣**」的多項式：**不能分解**的多項式。
- 【口頭】「它們不叫『質多項式』—— 雖然那樣命名很合理 —— 而是叫**不可約多項式（irreducible polynomial）**。」
  - 7 不能分解；15 = 3 × 5 可以。
  - 不可約多項式也**不能分解**成更小的多項式相乘。

> **擴張體乘法**：設 $P(x)$ 是一個 $m$ 次的**不可約多項式**，係數在 $GF(2)$。
> $$C(x) \equiv A(x) \cdot B(x) \bmod P(x)$$

【課本補充】例：$x^4 + x^3 + x + 1 = (x^2 + x + 1)(x^2 + 1)$ 可以分解 → **不可約** ✘ → 不能用來建 $GF(2^4)$。

#### 例（續）：用 $P(x) = x^3 + x + 1$ 約減

`[01:19]` 中間結果 $C'(x) = x^4 + x^3 + x + 1$。用長除法（「四年級的直式除法」）：

```
                x + 1                 ← 商（不重要）
             ┌────────────────────
 x³ + x + 1  │ x⁴ + x³       + x + 1
               x⁴      + x² + x        ← x · P(x)
               ─────────────────────   （加 = 減，因為在 GF(2)）
                    x³ + x²     + 1
                    x³      + x + 1    ← 1 · P(x)
                    ─────────────────
                         x² + x        ← 餘數 = 答案
```

`[01:22]`【口頭】「一般要減，但因為係數在 $GF(2)$，**加跟減一樣**，寫加法比較方便。」

$$\boxed{(x^2 + 1)(x^2 + x + 1) \equiv x^2 + x \ (\mathrm{mod}\ x^3 + x + 1)}$$

驗算：bit 向量 `101 × 111 = 110`。

【課本補充】另一個約減技巧：**個別處理最高次項**。$P(x) = x^3 + x + 1$ 表示 $x^3 \equiv x + 1$，所以 $x^4 = x \cdot x^3 \equiv x^2 + x$。代回去：

$$x^4 + x^3 + x + 1 \equiv (x^2 + x) + (x + 1) + x + 1 = x^2 + x \;✔$$

#### 【課本補充】⚠️ 不要跟整數乘法搞混

課本 Example 4.6（$GF(2^4)$，$P(x) = x^4 + x + 1$）：

$$(x^3 + x^2 + 1)(x^2 + x) \equiv x^3$$

在 bit 層級：`1101 · 0110 = 1000`。

但如果當成**整數**：$13 \times 6 = 78 = 1001110_2$。**完全不一樣！**
→ 就算元素在電腦裡存成整數型別，也**不能用 CPU 的整數乘法**。

### 4.6 不可約多項式不只一個

`[01:24]`【口頭】

> **對同一個體，可能有好幾個不可約多項式。**

- 這跟質數體很不一樣：$GF(7)$ 只有一個質數 7，「沒有什麼 7B」。
- 例：$GF(2^3)$ 可以用 $x^3 + x + 1$，也可以用 $x^3 + x^2 + 1$。

> ⚠️ 逐字稿缺字：教授寫的第二個不可約多項式字幕沒抓到，上面的 $x^3 + x^2 + 1$ 是 $GF(2^3)$ 另一個不可約多項式（筆者補充，可驗證它沒有根 0 或 1，所以三次多項式不可約）。

**重要後果**：
> 【口頭】「同一個體 $GF(2^3)$，**計算結果取決於你用哪個不可約多項式**。如果我叫你在 $GF(2^3)$ 裡算東西，卻沒給你不可約多項式，**你沒辦法算**。」

**AES 規定的不可約多項式**（`[01:27]`）：

$$\boxed{P(x) = x^8 + x^4 + x^3 + x + 1}$$

【口頭】「這不是完全不重要。不一定要背，但背起來也沒壞處。」

> ⚠️ 逐字稿只聽到「x⁸ … + x + 1」，完整式子依課本與 AES 規格補上。

【課本補充】第 4 講的**原始多項式**是不可約多項式的特例，所以課本 Table 2.3 裡的多項式也可以拿來建 $GF(2^m)$。

### 4.7 反元素（求逆）

`[01:28]`【課堂討論】還缺哪個運算？→ **求逆（除法）**。

【口頭】「你們會鬆一口氣：**我們這裡不做除法**。只給定義，因為它確實有用。」

> **定義**：非零元素 $A(x)$ 的反元素 $A^{-1}(x)$ 滿足
> $$A^{-1}(x) \cdot A(x) \equiv 1 \ (\mathrm{mod}\ P(x))$$

- 求逆是**透過乘法定義**的。乘法又是 mod $P(x)$ 的多項式乘法。
- 怎麼算？又是**擴展歐幾里得演算法**（第 11 講）。

【課本補充】
- **求逆是 AES S-box 的核心運算**（下一講）。
- 對小的體（實務上通常是 $2^{16}$ 個元素以下），常用**查表**：預先算好所有元素的反元素。
- 0 沒有反元素，但 AES 的 S-box 需要每個輸入都有輸出，所以設計者規定 **0 對應到 0**。
- 例：$(C2)_{hex} = 1100\,0010_2 = x^7 + x^6 + x$，查表得反元素 $(2F)_{hex} = x^5 + x^3 + x^2 + x + 1$。可以驗證兩者相乘 mod $P(x)$ 等於 1。

【口頭】最後：「**你們今天表現很棒。謝謝。**」

## 5. 一頁速查表

### 5.1 代數結構

| 結構 | 運算 |
|---|---|
| 群 | 一種運算 + 反運算 |
| 環 | +、−、×（÷ 有時候） |
| **體** | +、−、×、÷（0 除外） |

### 5.2 有限體

| 項目 | 內容 |
|---|---|
| 存在條件 | 元素個數 $= p^m$（$p$ 質數，$m \ge 1$） |
| 記法 | $GF(p^m)$，也叫 Galois Field |
| 質數體 | $m = 1$：$GF(p) = \{0, \ldots, p-1\}$，運算 mod $p$ |
| 擴張體 | $m \ge 2$：元素是多項式 |
| **AES 用的** | $GF(2^8)$，256 個元素，每個 = 1 byte |
| 不存在的例子 | 12 個元素（$2^2 \cdot 3$） |

### 5.3 $GF(2)$

| | 等同於 |
|---|---|
| 加法 | **XOR** |
| 乘法 | **AND** |

### 5.4 $GF(2^m)$ 算術

| 運算 | 做法 | 電腦上 |
|---|---|---|
| 元素 | $a_{m-1}x^{m-1} + \cdots + a_0$，$a_i \in \{0,1\}$ | $m$ bit 向量 |
| **加 / 減** | 係數相加 mod 2（加 = 減） | **XOR** |
| **乘** | 多項式相乘，再 **mod $P(x)$** | **不是**整數乘法 |
| **逆** | $A \cdot A^{-1} \equiv 1 \bmod P(x)$ | 擴展歐幾里得 / 查表 |

### 5.5 重要多項式

| 體 | 不可約多項式 |
|---|---|
| $GF(2^3)$ | $x^3 + x + 1$（或 $x^3 + x^2 + 1$） |
| $GF(2^4)$ | $x^4 + x + 1$ |
| **$GF(2^8)$（AES）** | $\boldsymbol{x^8 + x^4 + x^3 + x + 1}$ |

### 5.6 本講例子

$GF(2^3)$，$P(x) = x^3 + x + 1$：
- $(x^2 + 1) + (x^2 + x + 1) = x$　（`101 ⊕ 111 = 010`）
- $(x^2 + 1)(x^2 + x + 1) = x^4 + x^3 + x + 1 \equiv x^2 + x$

## 附：本講一句話總結

> **有限體只在元素個數為 $p^m$ 時存在；質數體 $GF(p)$ 就是 mod $p$ 的整數運算，但 AES 用的擴張體 $GF(2^8)$ 的元素是 8 個係數的多項式（剛好一個 byte）—— 加法是 XOR，乘法是多項式相乘後 mod 不可約多項式 $x^8 + x^4 + x^3 + x + 1$。**
