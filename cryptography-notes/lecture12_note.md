## 1. 公鑰密碼學入門

### 1.1 對稱式的問題

`[00:02]` 到目前為止都是**對稱式**密碼，而且只講**資料加密**。

```
Alice ──→ [ e_k ] ──→ 不安全通道 ──→ [ d_k ] ──→ Bob
             ↑                           ↑
             k ←──────── 安全通道 ────────→ k
```

【課堂討論】為什麼叫「對稱」？→ **兩邊用同一把金鑰**。「那就是對稱軸，左右一樣。」

【課堂討論】最大的實務問題？→ **金鑰分配**。需要安全通道，「很痛苦、很花錢，尤其在**大型網路**像網際網路上很不好用」。

### 1.2 保險箱的比喻

`[00:05]`（課本的圖，「大部分書都有，有點用」）

**對稱式 = 一個保險箱，Alice 和 Bob 有同一把鑰匙。**
- Alice 用鑰匙打開、放文件進去、鎖上 → 加密
- Bob 用**同一把**鑰匙打開、拿出文件 → 解密

【口頭】「從約 4000 年前的古埃及到 **1977 年**，至少在公開領域，大家都以為只能這樣做。」

**公鑰的基本想法**（`[00:06]`）：
> 「發明者最初的想法是：**加密真的需要鑰匙嗎？**加密本身沒那麼關鍵，**真正關鍵的是解密**。」

所以 Bob 有**兩把鑰匙**：

| 鑰匙 | 用途 | 保密嗎 |
|---|---|---|
| **公鑰（public key）** | **加密**（任何人都能把東西放進保險箱） | **公開**。放網站上、放「電話簿」裡（1970 年代的原始比喻） |
| **私鑰（private key）** | **解密**（只有 Bob 能打開） | 保密 |

【口頭】「我的公鑰**真的就放在我的網站上**，你可以去下載。」

### 1.3 公鑰的基本協定

`[00:09]`【口頭】「這是新概念，**醒來**。以前每個人有一把鑰匙，剛好是同一把；現在 **Bob 有兩把**。」

```
   Alice                               Bob
                                  k_pub, k_pr
              ←──── k_pub ────         （產生金鑰對）
 y = e_{k_pub}(x)
              ───── y ───────→
                                  x = d_{k_pr}(y)
```

- 公鑰送給 Alice（或更實際地，**Alice 自己從網站抓**）。不是秘密。
- **Oscar 也拿得到公鑰。**「有趣的地方在這：以前只要 Oscar 拿到金鑰，他就贏了；**這次 Oscar 讀到公鑰也沒用**（希望如此）。」
- Alice 用公鑰加密，送出密文；Oscar 看得到密文。
- Bob 用**私鑰**解密。

> 【口頭】「這就是 **5 分鐘的公鑰密碼學**。大問題是：$e$ 和 $d$ 是什麼？RSA 是一個漂亮的答案。」

### 1.4 RSA 的背景

`[00:11]`

| 項目 | 內容 |
|---|---|
| 發明者 | **R**ivest、**S**hamir、**A**dleman（名字由來） |
| 時間 | **1977** |
| 起因 | 間接受到 **Diffie & Hellman 1976 年**論文的啟發 |
| 真正的公鑰發明者 | Diffie、Hellman，加上 **Ralph Merkle** |
| 專利 | 只在**美國**有專利，**2000 年**到期 |

【口頭】這兩篇論文（1976 DH、1977 RSA）開啟了公鑰密碼學。DH 下週或寒假後講。

【課本補充】
- 實務上 RSA 最常用在：(1) **加密少量資料，尤其是金鑰傳輸（key transport）**；(2) **數位簽章**（第 18 講），例如網路上的數位憑證。
- **RSA 不是用來取代對稱密碼的**：它比 AES 慢好幾倍。實務上 RSA 常跟 AES 一起用，**AES 負責大量資料加密**。
- RSA 背後的**單向函數**：**整數分解問題** —— 兩個大質數相乘很容易（紙筆就行），但把乘積分解回去非常難。

### 1.5 實務上只有三大家族

`[00:13]`【口頭】「公鑰密碼學有個好處：

- 對稱式：區塊密碼大概有幾百個，串流密碼大概也上百個。**不可能在一門課全部講完。**
- 公鑰：**實務上只有三大家族**。」

| 家族 | 講次 | 教授猜的市佔 |
|---|---|---|
| **RSA**（整數分解） | 今天 | 約 70～80% |
| **離散對數系統**（Diffie-Hellman、Elgamal、DSA） | 第 13–15 講（2～3 週） | 約 20～30% |
| **橢圓曲線密碼學（ECC）** | 第 16–17 講（1～2 週） | |

> 【口頭】「到 5 月底，你就會知道**實務上需要知道的所有公鑰密碼系統**。還有一堆更異國風的，但實務上就這三個。」「我沒有確切數字，可能猜錯。」

## 2. RSA 金鑰產生

`[00:16]`【口頭】「前 20 分鐘沒那麼糟吧？」

挑戰：要用 Oscar 也知道的公鑰加密，但 Oscar 不能解密，只有 Bob 能。「隨便亂攪資料誰都會，難的是 Bob 要能解、Oscar 不能。」

`[00:17]` 跟對稱式的大差別：
> 【口頭】「這句話最重要的字可能是**計算（computation）**。公私鑰對**要算出來**。不像 AES 或 DES，你大概不想『算』一把秘密金鑰，而是用亂數產生器。這裡**有數學**，而且相當硬。」

【口頭】例如橢圓曲線，**產生好的曲線有時要算好幾個小時**。RSA 沒那麼糟，但這是對稱密碼沒有的步驟。

【課本補充】所有非對稱方案都有一個**建置階段（set-up phase）**來計算公私鑰；區塊密碼和串流密碼通常沒有這個問題。

### 2.1 五個步驟

`[00:19]`

> **RSA 金鑰產生**
> 1. 選兩個**大質數** $p$、$q$
> 2. 計算 $n = p \cdot q$
> 3. 計算 $\Phi(n) = (p - 1)(q - 1)$
> 4. 選公開指數 $e \in \{1, 2, \ldots, \Phi(n) - 1\}$，使 $\gcd(e, \Phi(n)) = 1$
> 5. 計算私鑰 $d$，使 $d \cdot e \equiv 1 \ (\mathrm{mod}\ \Phi(n))$
>
> **公鑰** $k_{pub} = (n, e)$　　**私鑰** $k_{pr} = d$

逐步說明：

| 步驟 | 說明 |
|---|---|
| 1 | 【口頭】幾乎所有文獻都叫 $p$ 和 $q$。「$p$ 是 prime，$q$ 是字母表下一個字母。」 |
| 2 | $n$ 叫**模數（modulus）**，「可能是 RSA 最重要的參數」 |
| 3 | **Euler phi 函數**（「7 天前還很奇怪」）。【課堂討論】什麼條件下很好算？→ 知道**質因數分解**。兩個質數的乘積就是 $(p-1)(q-1)$。「記得有一題作業嗎？現在派上用場了。」 |
| 4 | 公鑰通常用小寫 $e$（**e**ncryption，因為公鑰負責加密）。⚠️ 跟對稱密碼很不同：對稱金鑰**必須隨機**（要擲硬幣產生 128 bit），但這裡**只是「選」**，**不必隨機、不必保密**。只有一個條件：**$e$ 和 $\Phi(n)$ 互質** |
| 5 | 【課堂討論】如果 $\gcd(e, \Phi(n)) = 1$，什麼東西一定存在？→ **反元素**！$e$ 的反元素**就是私鑰** $d$ |

#### ⚠️ 很容易犯的錯

`[00:25]`【口頭】
> 「金鑰產生時，**運算是 mod $\Phi(n)$**。但 5 分鐘後你會看到，**真正做 RSA 加解密時，永遠是 mod $n$**。你的大腦會習慣『看到 RSA 就 mod $n$』—— **只有金鑰產生這個步驟要 mod $\Phi(n)$**，而且只在一開始做一次。」

【口頭】`[00:26]`「這五個步驟看起來很隨便，但如果你在這裡念完書，它們會**一再一再出現**。多做幾個例子，它會變成你的**一般常識（Allgemeinbildung）**。」

### 2.2 備註

`[00:27]`

**「大」質數是多大？**
- 【口頭】$p$、$q$ 至少 **512 bit**，很常見是兩倍 **1024 bit**（約 300 位十進位數）。
- 【課堂討論】$p$、$q$ 各 512 bit，$n$ 多長？→ **相加**：1024 bit。
- 【口頭】「今天，原因如果有時間最後會講，你需要**兩倍**：$n$ 要 **2048 bit**。數字變很長，軟體實作會變慢。」

**怎麼算 $d$？**（`[00:29]`）
【課堂討論】我們最愛的演算法？→ **擴展歐幾里得演算法**！「對照上週、對照你昨晚或今早做的作業。**這就是我們學它的原因**。」

【課本補充】實務做法：先選 $e$，用擴展歐幾里得演算法對 $(\Phi(n), e)$ 計算：

$$\gcd(\Phi(n), e) = s \cdot \Phi(n) + t \cdot e$$

- 如果 gcd = 1，$e$ 合法，而且 **$d = t \bmod \Phi(n)$**（$s$ 用不到）。
- 如果 gcd ≠ 1，換一個 $e$ 再試。

**真正難的是步驟 1**（產生大質數），見 §6。

### 2.3 【Q&A】RSA-1024 指的是哪個數字？

`[00:29]`

**學生問**：像 PGP 可以選金鑰長度，例如「RSA 1024」，這個 1024 是指哪一個？

**教授答**：「非常好的問題。」**永遠是指 $n$ 的長度。**$n$ 是安全參數，越長越安全。說「RSA 至少 1024 bit」就是 $n$ 有 1024 bit；除以二就是兩個質數的長度。

#### 【Q&A】$e$ 怎麼選？試誤法嗎？

`[00:59]`（這段出現在後面，放這裡比較好理解）

**學生問**：$e$ 要怎麼找？試誤法？

**教授答**：
- 對，基本上是試的。實務上有幾個**很流行的小 $e$**，例如 **17**。
- $p - 1$ 或 $q - 1$ 剛好有 17 這個質因數的機率很低。當然要檢查。
- 或者隨便挑一個再檢查，多半一次就成功。
- 「**選 $e$ 不難。難的是找 $p$ 和 $q$**，但這不是今天要講的。」

## 3. RSA 加密與解密

### 3.1 公式

`[00:31]`【口頭】「金鑰產生有點複雜又看似隨意。RSA 的美在於：**概念上超簡單**。加密是一個很簡單的運算，解密是另一個很簡單的運算。」

> **RSA 加密**：給定公鑰 $(n, e)$ 和明文 $x \in \mathbb{Z}_n = \{0, 1, \ldots, n-1\}$
> $$\boxed{y = e_{k_{pub}}(x) \equiv x^e \bmod n}$$
>
> **RSA 解密**：給定私鑰 $d$ 和密文 $y \in \mathbb{Z}_n$
> $$\boxed{x = d_{k_{pr}}(y) \equiv y^d \bmod n}$$

【口頭】
- 「現在你知道為什麼 $n$ 叫**模數**了。」
- 「這是今天的**紅框公式**。**簡單到可笑**：就是一次**指數運算**。」
- 「至少概念上很簡單。之後還有很多要說。」

【課本補充】
- $e$ 也叫**加密指數 / 公開指數**；$d$ 也叫**解密指數 / 私密指數**。
- 實務上 $x, y, n, d$ 都很長，通常 **1024 bit 以上**。
- 要求：(1) 從 $e, n$ **算不出** $d$；(2) 一次 RSA 加密**最多只能加密 $l$ bit**（$l$ = $n$ 的長度），因為 $x$ 只在 $n$ 以內唯一；(3) 加解密要算得快 → 需要**快速指數運算**；(4) 同一個 $n$ 要有很多組金鑰對，免得被暴力搜尋（這很容易滿足）。

### 3.2 【課堂討論】為什麼 Oscar 算不出 $d$？

`[00:36]`（一位學生已經講出了安全性的關鍵，教授說「他太聰明了，你可以回家了」）

- Oscar 看到密文 $y$，想解密。他缺的**唯一資訊**是 $d$。
- $d$ 怎麼算？擴展歐幾里得演算法 ——「他看了影片、買了我的書、或去維基百科（比較便宜），**他會算**」。
- 他也知道 $e$（公鑰）。
- 【課堂討論】**問題在哪？** → 他不知道 **$\Phi(n)$**！
- 「但 $\Phi(n)$ 有公式啊，很快？」→ 前提是**知道 $p$ 和 $q$**。

> 【口頭】`[00:37]`「如果我給你一個 1024 bit 的數（大約 300 位十進位數），**你分解不了，世界上沒有人分解得了**。分解紀錄大概是 650 bit 左右。2048 bit 我們**絕對**做不到。」
> 「一旦 Oscar **分解**了 $n$，他就能算 $\Phi(n)$，再加上公開的 $e$，就能算出 $d$。」
> 「**這就是為什麼現代公鑰密碼學和整數分解關係這麼密切。**」

> ⚠️ 「650 bit 左右」是教授課堂上的口述。課本 Table 7.3 有更精確的分解紀錄（課本出版時的紀錄是 768 bit，2009 年）。

### 3.3 玩具例子

`[00:39]`【口頭】「這是**食譜**，很無聊，幾乎不值得在大學做。但我們還是做：用小數字跑一次五個步驟。」

**Bob 產生金鑰：**

| 步驟 | 計算 |
|---|---|
| 1 | $p = 3$，$q = 11$ |
| 2 | $n = 3 \times 11 = 33$ |
| 3 | $\Phi(n) = (3-1)(11-1) = 2 \times 10 = 20$（「不用超級電腦」） |
| 4 | 選 $e = 3$。檢查 $\gcd(3, 20) = 1$ ✔ |
| 5 | $d \equiv 3^{-1} \equiv 7 \ (\mathrm{mod}\ 20)$。檢查 $3 \times 7 = 21 \equiv 1 \ (\mathrm{mod}\ 20)$ ✔ |

【口頭】`[00:40]`「$e = 3$ 剛好等於 $p$，這是巧合，**$e$ 不必等於 $p$**。我很努力想找一個全程能心算的 RSA 例子，不容易。4 跟 20 不互質、5 不互質、6 不互質，只有 7 —— 那數字就變大了，所以選 3。」

**協定：**

```
   Alice                                   Bob
  x = 4                            p=3, q=11, n=33, Φ=20
                                   e=3, d=7
             ←──── k_pub = (33, 3) ────
  y = 4³ = 64 ≡ 31 (mod 33)
             ────── y = 31 ──────→
                                   x = 31⁷ mod 33 = 4 ✔
```

【課堂討論】`[00:43]` $4^3 = 64$，$64 \bmod 33 = 31$。

### 3.4 心算小技巧：用負數

`[00:45]`【口頭】「$31^7$ 是唯一需要計算機的地方。現在教你一個**跟 RSA 無關**的小技巧。討厭心算的可以睡 2 分鐘、開筆電看 YouTube。」

**觀察**：31 很接近 33。回想第 2 講的**等價類**：

$$31 \equiv -2 \ (\mathrm{mod}\ 33)$$

所以：

$$31^7 \equiv (-2)^7 = -128 \ (\mathrm{mod}\ 33)$$

【口頭】「我請你們背 2 的次方 —— 2、4、8、16、32、64、128、256、512、1024。晚上醒著或太早醒的時候就在腦中跑一遍。**我自己早上醒太早時就這樣做。**」

$$-128 + 4 \times 33 = -128 + 132 = 4 \;✔$$

【口頭】「不需要計算機。只要你在模運算上有點**創意**，就能心算。」

### 3.5 【課本補充】正確性證明

`[00:50]`【口頭】「這有點奇怪：我把 $x$ 取一個次方得到 31，再把 31 取**另一個**次方，又拿回原本的值。**兩次指數運算互相抵銷**，這不直觀。」
「要證明這**永遠**成立（只要 $d$、$e$ 互為 mod $\Phi(n)$ 的反元素），這叫**正確性證明（proof of correctness）**，在**習題課**做，或看課本第 178 頁。」

**證明概要**：

要證 $d_{k_{pr}}(e_{k_{pub}}(x)) = (x^e)^d = x^{de} \equiv x \ (\mathrm{mod}\ n)$。

由 $de \equiv 1 \ (\mathrm{mod}\ \Phi(n))$，可寫成 $de = 1 + t \cdot \Phi(n)$（$t$ 為某整數）：

$$x^{de} = x^{1 + t\Phi(n)} = \left(x^{\Phi(n)}\right)^t \cdot x$$

**情況 1：$\gcd(x, n) = 1$**
用 **Euler 定理**（第 11 講）：$x^{\Phi(n)} \equiv 1 \ (\mathrm{mod}\ n)$，所以：

$$x^{de} \equiv 1^t \cdot x = x \ (\mathrm{mod}\ n) \;✔$$

**情況 2：$\gcd(x, n) \ne 1$**
因為 $p, q$ 是質數，$x$ 一定是其中一個的倍數，例如 $x = r \cdot p$（$r < q$），所以 $\gcd(x, q) = 1$。
- 在 mod $q$ 下用 Euler 定理：$(x^{\Phi(n)})^t = ((x^{q-1})^t)^{p-1} \equiv 1 \ (\mathrm{mod}\ q)$
- 寫成 $(x^{\Phi(n)})^t = 1 + u \cdot q$，兩邊乘 $x$：
$$x \cdot (x^{\Phi(n)})^t = x + r \cdot p \cdot u \cdot q = x + r u n \equiv x \ (\mathrm{mod}\ n) \;✔$$

課本說：如果用**中國餘數定理**證明會更簡單。

### 3.6 真實世界的數字有多長

`[00:52]`【口頭】課本第 177 頁有一組**真實的** 1024 bit RSA 參數（由合著者 Jan Pelzl 計算），用十六進位寫，$p, q$ 各約 128 個十六進位數字，$n, e, d$ 各約 256 個。「我不想寫在黑板上，你知道為什麼。**一輩子看過一次也好。**」

【口頭】`[00:53]`
> 「據我所知，**沒有其他技術應用**需要處理這麼長的數字。你手機裡有很多複雜的演算法：資料壓縮、錯誤更正、建立連線……**沒有一個**需要用這麼長的數字做算術。**這是現代密碼學獨有的。**」

## 4. 快速指數運算

`[00:55]`【口頭】
> 「作業會有很多這種例子，你要用計算機手算 500 個。我們**真的希望你們恨這三個紅框**。好的恨法就是做 50 次。」
> 「像禪宗說的：要把事情做好，要做 3 萬次。我們 20 次就夠了。」
> 「就像小學背九九乘法表 —— 我第三個孩子現在三年級，他們練兩年。做越多次越有感覺。」

`[00:56]`【口頭】「對我這個老師來說，**今天好玩的部分**是快速指數運算。」

### 4.1 為什麼需要

`[00:57]`
- **金鑰產生只做一次**。例如有 RSA 的智慧卡，參數幾乎是**在工廠製造時**就燒進去了。
- 但**每次**你連到 Amazon、eBay 建立安全連線，都要做**加密 / 解密的指數運算**。
- 所以要**做得夠好**。

$$y = x^e \bmod n \qquad x = y^d \bmod n$$

【口頭】`[01:00]`「指數運算本身不難。難的是我們要對**長得荒謬的數字**做。」

### 4.2 暖身：指數是 2 的次方

`[01:01]`【口頭】「**醒來，接下來 10 分鐘很重要**，你不會想從課本學。」

#### 例 1：$x^4$

| 方法 | 步驟 | 次數 |
|---|---|---|
| 天真 | $x \cdot x = x^2$，$x^2 \cdot x = x^3$，$x^3 \cdot x = x^4$ | 3 |
| 【課堂討論】更好 | $x \cdot x = x^2$，$x^2 \cdot x^2 = x^4$ | **2** |

【口頭】「一開始只能 $x \cdot x$。然後同學說：**為什麼要乘 $x$？直接拿 $x^2$ 自己乘**。」

#### 例 2：$x^8$

| 方法 | 次數 |
|---|---|
| 天真（「這是『笨方法』的禮貌說法」）| 7 |
| 一直平方：$x \to x^2 \to x^4 \to x^8$ | **3** |

#### 例 3：$x^{2^{1024}}$

`[01:05]`

| 方法 | 次數 |
|---|---|
| 天真 | $2^{1024} - 1$ |
| 一直平方 | **1024** |

【口頭】
- 「誰說 1024 我就把他踢出這所大學。」（天真法是 $2^{1024}$，不是 1024）
- 「就算我活得很老、太陽冷卻，我也會**用光粉筆**。已知宇宙只有大約 $2^{300}$ 個原子，**連寫下來都不夠**。」
- 「一直平方的話，大概兩三小時能寫完，盒子裡的粉筆夠用。」

> **天真法是指數的線性複雜度；平方法是對數複雜度。**
> 「1024 次跟宇宙壽命，你的瀏覽器選哪個？」

#### 問題

`[01:09]`【課堂討論】這招為什麼不能直接用在 $e$？→ 不只是偶數 —— **指數必須是 2 的次方**。4、8、$2^{1024}$ 都是「超級罕見的數」。我們要一個對**任意**指數都能用的方法。

### 4.3 一般情況：$x^{26}$

`[01:10]`【口頭】「現在是酷的部分。它幾乎跟這招一樣快，對所有數都適用，而且**你們大概沒人知道**。」（這時教授開始發教學評鑑表，「先別填，最後 5 分鐘再填」。）

這個方法叫 **二元法（binary method）** 或 **square-and-multiply**（教授比較喜歡後者）。

`[01:12]` 先示範怎麼做：

$$x \xrightarrow{\text{SQ}} x^2 \xrightarrow{\text{MUL}} x^3 \xrightarrow{\text{SQ}} x^6 \xrightarrow{\text{SQ}} x^{12} \xrightarrow{\text{MUL}} x^{13} \xrightarrow{\text{SQ}} x^{26}$$

- 天真法要 **25** 次；這裡只要 **6** 次（4 次平方 + 2 次乘法）。
- 【口頭】「如果你問我怎麼快速算 $x^{26}$，我會說：**平方、乘、平方、平方、乘、平方**。」
- 如果把某個乘換成平方，結果就錯了。所以**關鍵是知道正確的順序**。
- 「它只有兩種操作：平方和乘（以 $x$）。所以叫 square-and-multiply，不叫 square-and-Fourier-transform。」

### 4.4 看二進位就懂了

`[01:15]`【口頭】「我可以給你偽碼，但你看了也不知道在幹嘛。有一個很好的解釋方法：**規則取決於指數的二進位表示**。」

$$26 = 16 + 8 + 2 = 11010_2$$

**兩個基本操作對二進位指數的影響**（`[01:18]`）：

| 操作 | 對指數 | 對二進位指數 |
|---|---|---|
| **平方** $(x^a)^2 = x^{2a}$ | 乘 2 | **左移一位，右邊補 0** |
| **乘以 $x$** $x^a \cdot x = x^{a+1}$ | 加 1 | **最右邊那個 0 變成 1** |

【口頭】「九年級的規則：$(\alpha^a)^b = \alpha^{ab}$。二進位乘 2 就是左移，就像十進位乘 10：$33 \times 10 = 330$。」

**逐步追蹤指數**（目標 `11010`）：

| 步驟 | 操作 | 結果 | 指數（二進位） |
|---|---|---|---|
| 0 | 初始 | $x$ | `1` |
| 1a | **SQ** | $x^2$ | `10` |
| 1b | **MUL** | $x^3$ | `11` ← 跟目標前 2 位一樣 ✔ |
| 2a | **SQ** | $x^6$ | `110` ← 前 3 位 ✔ |
| 2b | （不乘） | | |
| 3a | **SQ** | $x^{12}$ | `1100` ← 但目標第 4 位是 1 ✘ |
| 3b | **MUL** | $x^{13}$ | `1101` ← 前 4 位 ✔ |
| 4a | **SQ** | $x^{26}$ | `11010` ← 完成 ✔ |
| 4b | （不乘） | | |

【口頭】「如果一直平方，會得到 `110000…` —— 不是我們要的。」

### 4.5 Square-and-Multiply 演算法

`[01:23]` **規則**：從指數的**最高位（左邊）往右**掃描每個 bit：

1. **每一個 bit 都平方**（「無條件，不問任何問題」）
2. **如果這個 bit 是 1**，平方之後**再乘以 $x$**

【口頭】`[01:25]`「答得出乘法規則的人，今天的學習體驗就很完美。」

**偽碼**（課本 p.182）：

```
輸入：底數 x、指數 H = (h_t h_{t-1} … h_0)₂（h_t = 1）、模數 n
輸出：x^H mod n

r = x
FOR i = t-1 DOWNTO 0:
    r = r² mod n           ← 1.1 每個 bit 都平方
    IF h_i = 1:
        r = r · x mod n    ← 1.2 bit 是 1 才乘
RETURN r
```

【口頭】`[01:27]` 要小心：**忽略最高位** $h_t$。它按慣例一定是 1，所以初始值 $r = x$ 已經處理了它。$x^{26}$ 的例子裡，我們是從最左邊**下一個** bit 開始。

【課本補充】**每次平方和乘法後都 mod $n$**，讓中間結果保持很小（第 2 講的技巧）。

### 4.6 【課本補充】複雜度

指數 $H$ 有 $t + 1$ bit：

| 操作 | 次數 |
|---|---|
| 平方（SQ） | $t$（**固定**，跟 $H$ 的值無關） |
| 乘法（MUL） | = 指數中 **1 的個數**（Hamming weight）。密碼學的指數通常很隨機，平均約 $0.5t$ |
| **總計（平均）** | $\approx 1.5t$ |

**例**：1024 bit 指數
- 天真法：$2^{1024} \approx 10^{300}$ 次 → **完全不可能**
- Square-and-multiply：$1.5 \times 1024 = $ **1536 次**

注意：每一次平方或乘法本身都是 **1024 bit 數字**的運算，CPU 實際做的整數運算遠多於 1536 次，但現代電腦做得到。

## 5. 【課本補充】RSA 加速技巧

### 5.1 短的公開指數

用**很小的** $e$ 加速**公鑰運算**（加密、驗證簽章）：

| $e$ | 二進位 | 平方 + 乘法次數 |
|---|---|---|
| 3 | `11` | 2 |
| 17 | `10001` | 5 |
| $2^{16} + 1$ | `1 0000 0000 0000 0001` | 17 |

- 這不會降低安全性。
- 但**私鑰 $d$ 仍然是完整長度**，不能也選短的：如果 $d$ 太短，攻擊者可以直接暴力搜尋；就算 128 bit 也有已知攻擊。$d$ 至少要有 $0.3t$ bit（$t$ 是 $n$ 的長度）。

### 5.2 用中國餘數定理（CRT）加速解密

**擁有私鑰的人也知道 $p$ 和 $q$。**

想法：不要做一次 mod $n$（長）的指數運算，改做**兩次 mod $p$ 和 mod $q$（短）**的指數運算，最後再組合回來。

三個步驟：
1. **轉到 CRT 領域**：$x_p = x \bmod p$，$x_q = x \bmod q$
2. **在 CRT 領域做指數運算**：$y_p = x_p^{d_p} \bmod p$，$y_q = x_q^{d_q} \bmod q$，其中 $d_p = d \bmod (p-1)$、$d_q = d \bmod (q-1)$
3. **轉回來**：用 CRT 組合出 $y$（係數可以預先算好）

**加速比**：
- 數字長度只有一半（$t/2$ bit）。
- 乘法複雜度跟長度**平方**成正比 → 每次乘法快 4 倍。
- 指數也只有一半長 → 總共約快 **4 倍**。
- 例：智慧卡上 1024 bit RSA 原本 3 秒，用 CRT 不到 1 秒。

## 6. 【課本補充】產生大質數

金鑰產生的**步驟 1 才是真正難的**。

### 6.1 做法

```
TRNG → 產生隨機整數 p̃ → 質數測試 → 是質數 → 輸出 p
                              ↓
                          不是 → 重來
```

$p$、$q$ 必須是**隨機**的（如果攻擊者能猜到其中一個，RSA 就被破了）。

### 6.2 質數有多常見？

- 隨機整數 $\tilde{p}$ 是質數的機率約 $1 / \ln(\tilde{p})$。
- 只測奇數的話機率加倍：$2 / \ln(\tilde{p})$。
- **例**：512 bit 的 $\tilde{p}$：$\dfrac{2}{\ln(2^{512})} = \dfrac{2}{512 \ln 2} \approx \dfrac{1}{177}$

→ 平均測 **177 個**奇數就會找到一個質數。就算到 4096 bit，質數密度仍然夠高。

### 6.3 質數測試

- **不能用分解**來判斷 —— RSA 用的數字就是選來**分解不了**的。
- 用**質數測試**：計算上比分解容易得多。例如 **Fermat 測試**、**Miller–Rabin 測試**。
- 這些測試是**機率性演算法**，輸出：
  - 「$\tilde{p}$ 是合數」→ **一定正確**
  - 「$\tilde{p}$ 是質數」→ **只是很高的機率**正確
- 重複測試多次，錯誤機率可以降到非常低。

## 7. 【課本補充】實務上的 RSA：Padding

課本把直接套公式的 RSA 叫 **schoolbook RSA（教科書 RSA）**，它有幾個弱點：

| 弱點 | 說明 |
|---|---|
| **確定性** | 金鑰固定時，同一明文永遠得到同一密文 → 攻擊者能做統計分析、比對（回想第 9 講的 ECB） |
| **小明文** | 如果 $x = 0$、$1$ 或 $-1$，密文就是 $0$、$1$、$-1$ |
| **小指數 + 小明文** | 可能有攻擊 |
| **可塑性（malleable）** | 攻擊者能把密文改成另一個密文，使解密後的明文以**已知方式**改變 —— 而且不需要解密。例：把 $y$ 乘上 $s^e$，解密後得到 $s \cdot x$ |

**解法：Padding（填充）**
- 加密前，在明文裡嵌入**隨機的結構**。
- 標準做法：**OAEP（Optimal Asymmetric Encryption Padding）**，規範在 **PKCS#1**。
- OAEP 用到**雜湊函數**（第 20 講）。
- 解密端要**檢查解密後訊息的結構**是否正確。

## 8. 【課本補充】對 RSA 的攻擊

三大類：

### 8.1 協定攻擊

- 利用 RSA **被使用的方式**的弱點，例如利用可塑性。
- 大多可以用 **padding** 避免。
- 照著現代安全標準的規範使用，協定攻擊就不太可能。

### 8.2 數學攻擊

- **已知最好的數學攻擊是分解模數 $n$**。
- 分解 $n$ → 算 $\Phi(n)$ → 用 $e$ 算出 $d$。
- **這是 RSA 模數需要 1024 bit 以上的唯一原因。**
- 分解紀錄的進步，**主要來自分解演算法的改進**，其次才是電腦技術。
- RSA 發明者當年估計，以當時的演算法分解某個 129 位數要 **40 兆年**；實際上不到 30 年就被分解了。
- 課本當時的看法：1024 bit 也許在 10～15 年內能被分解，情報單位可能更早。**長期安全建議 2048～4096 bit**。

### 8.3 旁通道攻擊

- 利用實體通道洩漏的私鑰資訊（回想第 1 講）：**耗電量、執行時間**等。攻擊者通常要能**直接接觸**到實作，例如手機或智慧卡。
- 課本的例子：微處理器上 RSA 解密的**耗電曲線**。
  - 高活動區間就是平方或乘法；有些區間**大約長一倍**。
  - 原因在 square-and-multiply：bit 是 0 → 只做**平方**（短）；bit 是 1 → **平方 + 乘法**（長）。
  - 所以**看曲線就能直接讀出私鑰**：長區間 = 1，短區間 = 0。課本從圖上讀出 12 個 bit；真實情況下可以讀出完整的 1024 或 2048 bit。
- 旁通道攻擊是很大的研究領域，課本說超出範圍，沒有展開對策。

## 9. 一頁速查表

### 9.1 公鑰 vs 對稱

| | 對稱 | 公鑰 |
|---|---|---|
| 金鑰 | 一把，兩邊一樣 | 每人兩把：公鑰 + 私鑰 |
| 加密用 | 共享金鑰 | **對方的公鑰** |
| 解密用 | 共享金鑰 | **自己的私鑰** |
| 金鑰分配 | 需要安全通道 | 公鑰可以公開 |
| 速度 | 快 | 慢很多 |
| 實務 | 大量資料加密 | 金鑰傳輸、數位簽章 |
| 演算法數量 | 幾百個 | **三大家族**：RSA、離散對數、ECC |

### 9.2 RSA

| 步驟 | 內容 |
|---|---|
| 1 | 選大質數 $p, q$ |
| 2 | $n = pq$ |
| 3 | $\Phi(n) = (p-1)(q-1)$ |
| 4 | 選 $e$，$\gcd(e, \Phi(n)) = 1$ |
| 5 | $d \equiv e^{-1} \ (\mathrm{mod}\ \Phi(n))$（擴展歐幾里得） |
| **加密** | $y \equiv x^e \bmod n$ |
| **解密** | $x \equiv y^d \bmod n$ |
| 公鑰 / 私鑰 | $(n, e)$ / $d$ |

⚠️ 金鑰產生 **mod $\Phi(n)$**；加解密 **mod $n$**

**玩具例子**：$p=3, q=11, n=33, \Phi=20, e=3, d=7$；$x=4 \to y=31 \to x=4$

### 9.3 安全性

| 項目 | 內容 |
|---|---|
| 單向函數 | 整數分解 |
| Oscar 缺什麼 | $\Phi(n)$ → 需要分解 $n$ |
| 金鑰長度（$n$） | 1024 短期；**2048～4096 長期** |
| 實務必須 | **Padding（OAEP）** |

### 9.4 Square-and-Multiply

```
r = x
for 每個 bit（從最高位的下一位往右）:
    r = r²         ← 每個 bit 都做
    if bit == 1:
        r = r · x  ← bit 是 1 才做
```

| 操作 | 對二進位指數 |
|---|---|
| 平方 | 左移，補 0 |
| 乘 $x$ | 最右位 0 → 1 |

複雜度：$t$ 次平方 + 約 $0.5t$ 次乘法 ≈ $1.5t$（1024 bit → 約 1536 次）

### 9.5 加速

| 技巧 | 用在 | 加速 |
|---|---|---|
| 短 $e$（3、17、$2^{16}+1$） | 加密、驗章 | 很大 |

## 附：本講一句話總結

> **RSA 的加解密只是 $x^e \bmod n$ 和 $y^d \bmod n$ 兩次指數運算，$d$ 是 $e$ 在 mod $\Phi(n)$ 下的反元素 —— 攻擊者算不出 $d$ 是因為他無法分解 $n$ 來得到 $\Phi(n)$；而讓這些 2048 bit 的指數運算可行的關鍵，是 square-and-multiply：每個 bit 都平方、遇到 1 再乘，把天文數字的運算降到幾千次。**
