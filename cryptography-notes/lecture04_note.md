## 1. LFSR 入門

### 1.1 為什麼要學：小小的硬體

`[00:04]` 目標：做一個**很小**的金鑰串流產生器。歷史上說「小」，主要是指**硬體很小**。

【口頭】
> 「我們也拿電機導論折磨你們，對吧？如果你在想『為什麼要學這個』，**今天就是答案**。今天會看到電機和密碼學直接相關的地方。」

你手機裡的 GSM **A5 密碼**就是用 **3 個 LFSR** 組成的。「80 分鐘後你會更懂它怎麼運作。」

### 1.2 正反器（Flip-Flop）

`[00:08]`【課堂討論】正反器是什麼？學生答：**存東西的**。

- 正反器**存 1 個 bit**。
- 有一個**輸入**、一個**輸出**、一個**時脈（clock）輸入**。
- 時脈決定**什麼時候存**：時脈**上升邊緣**時，正反器把當下的輸入值存起來。
- 存起來之後，就算輸入改變，**輸出維持不變**，直到下一個時脈。

【口頭】一台 Pentium 筆電裡有幾千萬個電晶體、幾萬個正反器。

### 1.3 移位暫存器

`[00:13]` 把 **3 個正反器串起來**，最右邊的輸出就是 $s_i$。

```
  ┌────┐   ┌────┐   ┌────┐
→ │FF2 │ → │FF1 │ → │FF0 │ → 輸出 s_i
  └────┘   └────┘   └────┘
```

- 初始值：$(\text{FF2}, \text{FF1}, \text{FF0}) = (1, 0, 0)$。可以選**任何非全零**的值。
- 每來一個時脈，每個正反器存下左邊的值 → **所有 bit 往右移一格**。

**問題**：只有移位的話，時脈三次後就把 `0, 0, 1` 推完了，然後就沒了。【口頭】「這是很笨的亂數產生器。遊戲結束。」

### 1.4 加上回授：3 位元 LFSR

`[00:17]` 想法：**每個時脈，替最左邊的正反器算出一個新的輸入 bit。**

做法：把 **FF1 和 FF0 的輸出 XOR 起來**，回授（feedback）到 FF2 的輸入。

```
        ┌──────────── ⊕ ←─────────┐
        │             ↑            │
        ↓             │            │
      ┌────┐   ┌────┐ │   ┌────┐   │
      │FF2 │ → │FF1 │─┴─→ │FF0 │ ──┴──→ 輸出 s_i
      └────┘   └────┘     └────┘
```

這就湊齊了 **L**inear **F**eedback **S**hift **R**egister：
- **Shift Register**：移位暫存器
- **Feedback**：回授
- **Linear**：回授只用 XOR，XOR 是**線性**運算

【口頭】`[00:20]` 教授算了前 3 個時脈，給全班 2 分鐘自己算後 5 個。

**完整狀態表**（初始值 1, 0, 0）：

| 時脈 | FF2 | FF1 | FF0 = 輸出 $s_i$ |
|---|---|---|---|
| 0 | 1 | 0 | **0** |
| 1 | 0 | 1 | **0** |
| 2 | 1 | 0 | **1** |
| 3 | 1 | 1 | **0** |
| 4 | 1 | 1 | **1** |
| 5 | 0 | 1 | **1** |
| 6 | 0 | 0 | **1** |
| 7 | 1 | 0 | 0 ← 跟時脈 0 一樣！ |
| 8 | 0 | 1 | 0 ← 跟時脈 1 一樣 |

（驗算時脈 1→2：新的 FF2 = FF1 ⊕ FF0 = 1 ⊕ 0 = 1 ✔）

> ⚠️ 逐字稿缺字：教授口述的部分序列不完整，上表依課本 Table 2.2。

### 1.5 週期

`[00:24]`【課堂討論】把每一列看成一個 3 bit 的「字」：
- 3 bit 一共有 8 種組合。
- 表裡出現了 7 種。**少了哪一個？** → **全零 `000`**。

`[00:26]`【課堂討論】時脈 7 的狀態有什麼特別？→ **跟時脈 0 一樣**。下一個是什麼？不用看正反器也知道 → `010`，因為 `100` 下一步一定是 `010`。

→ 進入**循環（cycle）**。輸出永遠是：

$$\underbrace{0010111}\;\underbrace{0010111}\;\underbrace{0010111}\;\ldots$$

**週期（period）= 7。**【口頭】所有**確定性**的產生器都是週期性的。

### 1.6 數學描述

`[00:28]`【口頭】「這些看起來很像電機的東西 —— 正反器、訊號、時間軸、脈波。但它們背後其實有**很強大的數學描述**。」

- $s_0, s_1, s_2$ 是**初始值**，教授說它們「非常無聊（langweilig）」，只是被載進去而已，沒有數學。
- 從 $s_3$ 開始才有趣：$s_3$ 是當初 FF1 和 FF0 的 XOR。

$$s_3 \equiv s_1 + s_0, \qquad s_4 \equiv s_2 + s_1, \qquad s_5 \equiv s_3 + s_2 \ (\mathrm{mod}\ 2)$$

看出規律了：

$$\boxed{s_{i+3} \equiv s_{i+1} + s_i \ (\mathrm{mod}\ 2)}$$

`[00:33]`【口頭】問題：週期 7 太短了。手機每 7 個 bit 就重複一次？我們想要**幾十億、幾兆**的週期。→ 好消息：要變長**非常容易**。

## 2. 一般的 LFSR

### 2.1 m 個正反器 + 開關

`[00:34]` 推廣兩件事：

1. **正反器個數**從 3 變成任意 $m$。$m$ 叫 LFSR 的**度數（degree）**。編號從左到右是 $\text{FF}_{m-1}, \ldots, \text{FF}_1, \text{FF}_0$，最右邊是 $\text{FF}_0$。
2. **回授要接哪幾個**也可以自由選。剛剛只接了 FF1、FF0，其實每一個正反器的輸出都可以選擇接或不接。

【口頭】直覺做法：每個正反器輸出接一個**開關（switch）**，開或關。

```
  ┌──────── ⊕ ←──── ⊕ ←── … ←── ⊕ ←─────┐
  │         ↑        ↑             ↑       │
  │        ⊗p_{m-1}  ⊗p_{m-2}      ⊗p_1    ⊗p_0
  │         │        │             │       │
  ↓         │        │             │       │
┌──────┐   ┌──────┐       ┌────┐   ┌────┐  │
│FF_m-1│ → │FF_m-2│ → … → │FF_1│ → │FF_0│ ─┴→ 輸出
└──────┘   └──────┘       └────┘   └────┘
```

### 2.2 為什麼用「乘法器」表示開關

`[00:38]`【口頭】「不要殺我，我們用**乘法器**代替開關。兩分鐘後你就知道為什麼這是好主意。」

每個開關變成「乘上一個 bit $p_j$」：

| $p_j$ | 輸出 $b = p_j \cdot a$ | 等同於 |
|---|---|---|
| 1 | $1 \cdot a = a$ | **開關閉合**（訊號通過） |
| 0 | $0 \cdot a = 0$ | **開關打開**（訊號不通，XOR 0 沒影響） |

$p_0, p_1, \ldots, p_{m-1}$ 叫**回授係數（feedback coefficients）**，德文叫開關變數（Schaltvariable）。

好處：**可以寫成數學式**。等一下講攻擊時，「數學就是我們的朋友」。

### 2.3 通用公式

`[00:42]` 初始值 $s_0, \ldots, s_{m-1}$ 由外部給定（例如 GSM 協定）。第一個「有內容」的輸出是 $s_m$：

$$s_m \equiv s_{m-1} p_{m-1} + \cdots + s_1 p_1 + s_0 p_0 \ (\mathrm{mod}\ 2)$$

下一個，所有東西往右移一格：

$$s_{m+1} \equiv s_m p_{m-1} + \cdots + s_2 p_1 + s_1 p_0 \ (\mathrm{mod}\ 2)$$

規律：**$p$ 不動，$s$ 的下標每次加 1。** 所以：

$$\boxed{s_{i+m} \equiv \sum_{j=0}^{m-1} p_j \cdot s_{i+j} \ (\mathrm{mod}\ 2), \qquad s_i, p_j \in \{0, 1\}, \quad i = 0, 1, 2, \ldots}$$

> 【口頭】「這可能是**今天最重要的一條式子**。」

**驗算**：3 位元例子，$m = 3$，$p_2 = 0, p_1 = 1, p_0 = 1$ → $s_{i+3} = s_{i+1} + s_i$ ✔（跟 §1.6 一樣）

#### 【Q&A】$p_j$ 從哪裡來？

`[00:47]`

**學生問**：這些 $p_j$ 是哪裡來的？

**教授答**：「非常好的問題 —— 我沒付他錢喔。」$p_j$ 是**設計者要選的**。例如 GSM 裡是**固定寫死的**。「這基本上就是設計者能做的最大選擇。」**選不同的 $p_j$，會得到非常不同的性質。**

【課本補充】LFSR 有時也叫**線性遞迴（linear recurrence）**：每個輸出都是前面幾個輸出的組合。

### 2.4 最大週期 $2^m - 1$

`[00:50]`【課堂討論】3 個正反器得到週期 7。7 和 3 有什麼關係？學生答：$2^3 - 1$。
- $2^3 = 8$ 是 3 bit 所有可能的組合。
- 減掉的那 1 個是**全零**。

> **定理**：度數 $m$ 的 LFSR，**最大**輸出序列長度（最大週期）是 $2^m - 1$。

**為什麼**（教授的直觀證明，`[00:52]`）：

1. LFSR 的**狀態** = 正反器裡存的 $m$ 個 bit。
2. 給定一個狀態，**下一個狀態完全確定**（移位 + XOR）。
3. $m$ bit 最多只有 $2^m$ 種狀態。
4. **只要某個狀態第二次出現，就進入循環。**
5. 所以最長的情況是「把所有狀態走一遍才重複」。
6. **全零狀態要排除**：一旦進入全零，XOR 出來永遠是 0，**永遠卡在那裡**。
7. → 最多 $2^m - 1$ 個不同狀態。

【口頭】「這很粗略、不嚴謹，但抓到重點。」

### 2.5 不是每種接法都能達到最大週期

`[00:56]`

> **只有某些回授設定 $(p_0, \ldots, p_{m-1})$ 能產生最大長度的序列。**

**例 1**：$m = 4$，$(p_3, p_2, p_1, p_0) = (0, 0, 1, 1)$
→ 週期 **15** = $2^4 - 1$ ✔ **最大長度**

**例 2**：$m = 4$，$(p_3, p_2, p_1, p_0) = (1, 1, 1, 1)$（全部開關都閉合）
→ 週期只有 **5** ✘

`[01:01]`【口頭】
> 「我的直覺總是說：全部接起來**看起來比較複雜**、攪得比較亂吧？**不是。**統計上它反而比較差。不管初始值放什麼，它都只會在 5 個狀態之間繞。不信的話，等作業吧。」

### 2.6 用多項式表示 LFSR

`[01:02]` 要完整描述一個 LFSR，只需要兩樣東西：
1. **度數 $m$**
2. **回授係數向量** $(p_{m-1}, \ldots, p_1, p_0)$

【口頭】「GSM 裡的 LFSR 長度大約在 19 到 23 之間。」

但「因為某些奇怪的數學理由」，大家習慣寫成**多項式**：

$$P(x) = x^m + p_{m-1} x^{m-1} + \cdots + p_1 x + p_0$$

**例**：

| LFSR | 係數 $(p_3, p_2, p_1, p_0)$ | 多項式 | 週期 |
|---|---|---|---|
| 例 1 | (0, 0, 1, 1) | $x^4 + x + 1$ | 15 |
| 例 2 | (1, 1, 1, 1) | $x^4 + x^3 + x^2 + x + 1$ | 5 |

> 【口頭】「**從今以後你的人生改變了。**有人給你一個多項式，說我們在講串流密碼和 LFSR，你腦中應該立刻浮現**那張電路圖**。在這個脈絡下，**多項式 = 電路圖**。」

#### 為什麼用多項式：原始多項式（Primitive Polynomial）

`[01:07]` 用多項式表示，就能用**多項式的性質**判斷 LFSR 的行為。

> **只有回授多項式是「原始多項式（primitive polynomial）」的 LFSR，才能產生最大長度序列。**

- 什麼是原始多項式？【口頭】「第一學期講太早了。」粗略地說，跟**質數**有點像：**不能分解**成更小的因式（這叫**不可約 irreducible**），再加上一個額外性質。
- 課本 Table 2.3 列了 $m = 2$ 到 $128$ 每個度數的一個原始多項式。寫法例如 `(0, 1, 4)` 代表 $x^4 + x + 1$ —— 就是例 1。
- 【口頭】教授寫書時請數學系的 Roberto Avanzi 幫忙算出這張表。
- 【課本補充】每個度數其實有**很多**原始多項式，例如 $m = 31$ 就有 69,273,666 個。

### 2.7 LFSR 的優點

`[01:10]`

| 優點 | 說明 |
|---|---|
| **週期超長** | $m = 100$ → 週期 $2^{100}$。【口頭】「全地球的電腦跑 1 萬年大概也只能做到 $2^{70}$～$2^{80}$，**永遠跑不完一圈**。」 |
| **硬體超小** | 100 個正反器排成一列「非常非常短」，不需要一間教室大的電腦 |
| **統計特性很好** | 就算只有長度 20，輸出也很像擲硬幣的結果 |

`[01:12]`【口頭】
> 「所以現在很誘人：直接拿來用在手機或 email 加密吧！接下來 10 分鐘，我證明給你看它們**非常容易破解**。」

**它們有很好的「隨機性」，但沒有不可預測性。** → 回想上一講：這是個**很好的 PRNG，但密碼學上很糟**。

## 3. 攻擊單一 LFSR（已知明文攻擊）

`[01:13]`【口頭】「這可能是這門課**數學上最有趣、最有挑戰的一段**。睡著的人醒來。」

### 3.1 Oscar 知道什麼

`[01:14]` Oscar 知道我們用的是 LFSR 串流密碼（Kerckhoffs 原則），他的目標是算出所有 $s_i$。

| Oscar 知道 | 說明 |
|---|---|
| **全部密文** $y_i$ | 理所當然。【口頭】「不知道密文的話，那是讀心術了。」 |
| **度數 $m$** | 不知道也沒關係，攻擊**超快**，每個 $m$ 都猜一次就好 |
| **前 $2m$ 個明文 bit** $x_0, \ldots, x_{2m-1}$ | **最強的假設**。但很實際 → |

【課堂討論】`[01:16]` 為什麼會知道開頭的明文、卻不知道後面的？學生答：**檔頭（header）**。用十六進位編輯器打開 Word 檔，前面有很長一段固定的標頭。

**Oscar 不知道的**：回授係數 $p_0, \ldots, p_{m-1}$。**這就是金鑰。**

### 3.2 攻擊步驟

**步驟 1：算出前 $2m$ 個金鑰串流 bit。**

$$s_i \equiv x_i + y_i \ (\mathrm{mod}\ 2), \qquad i = 0, 1, \ldots, 2m - 1$$

**步驟 2：用通用公式列方程式。**

`[01:19]` 拿 §2.3 的公式，$i = 0$：

$$s_m \equiv p_{m-1} s_{m-1} + \cdots + p_1 s_1 + p_0 s_0 \ (\mathrm{mod}\ 2)$$

- **好消息**：所有 $s$ 都已知，**未知數只有 $p_0, \ldots, p_{m-1}$**，而且全部都在這條式子裡。
- **壞消息**：一條線性方程式、$m$ 個未知數 → 不夠。需要 **$m$ 條**。

【課堂討論】`[01:22]` 第二條從哪來？學生答：**讓 $i$ 繼續往下跑**。未知數 $p_j$ 不變，只是 $s$ 往後移：

$$\begin{aligned}
i = 0: \quad & s_m &\equiv\;& p_{m-1} s_{m-1} + \cdots + p_1 s_1 + p_0 s_0 \\
i = 1: \quad & s_{m+1} &\equiv\;& p_{m-1} s_m + \cdots + p_1 s_2 + p_0 s_1 \\
& \;\;\vdots & & \qquad\vdots \\
i = m-1: \quad & s_{2m-1} &\equiv\;& p_{m-1} s_{2m-2} + \cdots + p_1 s_m + p_0 s_{m-1}
\end{aligned} \ (\mathrm{mod}\ 2)$$

→ **$m$ 條線性方程式、$m$ 個未知數。** 這正是為什麼需要 $2m$ 個 bit：最後一條用到 $s_{2m-1}$。

**步驟 3：解聯立方程式。**

【課堂討論】`[01:24]` 用什麼演算法解？學生答：**高斯消去法（Gaussian elimination）**。或矩陣求逆。
【課本補充】就算 $m$ 很大，一般 PC 也能輕鬆解。

**步驟 4：重建 LFSR，產生所有金鑰串流。**

`[01:26]`【口頭】「我們還沒完。Oscar 拿到 $p_j$ 之後要做什麼？他其實不在乎 $p_j$，他要**明文**。」
- $p_j$ **完全描述了 LFSR**（哪些開關開、哪些關）→ Oscar 可以**自己造一個**。
- 載入已知的 $m$ 個連續輸出 bit 當初始值，開始時脈 → 產生 $s_{2m}, s_{2m+1}, \ldots$

**步驟 5：解密全部。**

$$x_i \equiv y_i + s_i \ (\mathrm{mod}\ 2), \qquad \text{對所有 } i$$

### 3.3 本節的教訓

> **只要知道度數 $m$ 的 LFSR 的 $2m$ 個輸出 bit，就能用解線性方程組精確算出回授係數，進而重建整個金鑰串流。**

【課本補充】
- 用 LFSR 當串流密碼時，**秘密金鑰就是回授係數向量**。
- 根本原因：LFSR 是**線性**的。線性在通訊系統裡是優點（好分析），但**如果密碼系統裡的金鑰只出現在線性關係中，那就是極不安全的密碼**。
- 單一 LFSR 是「**統計特性好、密碼學特性糟**」的典型例子。

【口頭】跟上一講的 LCG 攻擊是**同一個套路**：已知明文 → 金鑰串流 → 列線性方程式 → 解出金鑰。

## 4. 結論：單一 LFSR 不安全，但組合起來可以

`[01:28]`【口頭】
> 「過去 90 分鐘：我教你們怎麼做出週期超長的東西，告訴你們統計特性很好、很容易造、有奇怪的數學描述。最後我說：**喔對了，它們完全不安全，不要用。**你可以說這很蠢。」
>
> 「但如果**組合起來用** —— 就像每個人手機裡的 GSM，**用 3 個不同的 LFSR，而且不規則地打時脈（clock them irregularly）** —— 它們就變得**相當難破解**。把它們當積木、多個一起用，就能造出非常安全的東西。」

【課本補充】GSM 的現況：
- **A5/1** 原本是保密的，但 1998 年被逆向工程並公開在網路上。課本寫時（2010）它「**勉強算安全**」。
- **A5/2** 有更嚴重的缺陷。
- 以今天的密碼分析來看，**兩個都不推薦**。3G 改用 **A5/3（KASUMI）**，那是一個**區塊密碼**。

## 5. 【課本補充】Trivium

這一節課堂沒講，課本 §2.3.3 有。它是「把移位暫存器組合起來 + 加入非線性」的現代例子。

### 5.1 結構

- **80 bit 金鑰**。
- **3 個移位暫存器** A、B、C，長度分別是 **93、84、111**，合起來 **288 bit**，排成一個圈：每個暫存器的輸出接到**另一個**暫存器的輸入。
- 金鑰串流 $s_i$ = 三個暫存器輸出的 XOR。

| 暫存器 | 長度 | 回授 bit | 前饋 bit | AND 輸入 |
|---|---|---|---|---|
| A | 93 | 69 | 66 | 91, 92 |
| B | 84 | 78 | 69 | 82, 83 |
| C | 111 | 87 | 66 | 109, 110 |

每個暫存器：
- **輸入** = 另一個暫存器的輸出 ⊕ 自己某一個位置的 bit（回授）
- **輸出** = 最右邊的 bit ⊕ 某一個位置的 bit（前饋）⊕ **兩個 bit 的 AND**

### 5.2 為什麼 AND 很關鍵

- mod 2 下，**AND = 乘法**。
- 兩個未知數相乘 → 方程式**不再是線性的**。
- 這就擋掉了 §3 那種「列線性方程式解出來」的攻擊。

### 5.3 IV（初始向量）

幾乎所有現代串流密碼都有兩個輸入：
- **金鑰 $k$**：一般的秘密金鑰。
- **IV（Initialization Vector，初始向量）**：**不用保密**，但**每次加密都要換**。也叫 **nonce**（number used once，只用一次的數）。

**為什麼要 IV**：如果兩次加密用同一個金鑰串流，攻擊者從第一次的已知明文算出金鑰串流，**第二次就能直接解密**。

### 5.4 執行步驟

| 階段 | 做法 |
|---|---|
| **初始化** | 80 bit IV 載入 A 最左邊 80 格；80 bit 金鑰載入 B 最左邊 80 格；C 最右邊 3 格設為 1；其他全部 0 |
| **暖機（warm-up）** | 時脈 $4 \times 288 = 1152$ 次，**不輸出**。讓金鑰串流充分依賴金鑰和 IV |
| **加密** | 第 1153 個時脈開始的輸出才是金鑰串流 |

### 5.5 效能

- 硬體約 **3500～5500 個等效閘（gate equivalent）**，比大多數區塊密碼（如 AES）小很多。
- 例：4000 閘的設計每時脈產生 16 bit，以 125 MHz 計算 → **2 Gbit/s**。
- 軟體：1.5 GHz Intel CPU 上約 **1 Gbit/s**。
- 課本寫作時沒有已知攻擊，但它**還很新**，未來可能出現攻擊。

### 5.6 eSTREAM 計畫

歐洲 ECRYPT 主辦（2004–2008），徵選新的串流密碼，34 個候選：
- **軟體導向**最終選出：HC-128、Rabbit、Salsa20/12、SOSEMANUK
- **硬體導向**最終選出：Grain v1、MICKEY v2、**Trivium**
- 注意：ECRYPT **不是標準組織**，地位不能跟 AES 比。

## 6. 一頁速查表

### 6.1 LFSR 基本

| 項目 | 內容 |
|---|---|
| 組成 | $m$ 個正反器 + XOR 回授 |
| 度數 | $m$（正反器個數） |
| 金鑰（用作密碼時） | 回授係數 $(p_{m-1}, \ldots, p_0)$ |
| 通用公式 | $s_{i+m} \equiv \sum_{j=0}^{m-1} p_j s_{i+j} \ (\mathrm{mod}\ 2)$ |
| 開關 = 乘法器 | $p_j = 1$ 閉合；$p_j = 0$ 打開 |
| 最大週期 | $2^m - 1$（排除全零狀態） |
| 達到最大週期的條件 | 回授多項式是**原始多項式** |
| 多項式寫法 | $P(x) = x^m + p_{m-1}x^{m-1} + \cdots + p_1 x + p_0$ |

### 6.2 例子

| $m$ | 係數 | 多項式 | 週期 |
|---|---|---|---|
| 3 | $(p_2, p_1, p_0) = (0, 1, 1)$ | $x^3 + x + 1$ | 7（最大） |
| 4 | $(0, 0, 1, 1)$ | $x^4 + x + 1$ | 15（最大） |
| 4 | $(1, 1, 1, 1)$ | $x^4 + x^3 + x^2 + x + 1$ | 5 |

3 位元例子（初始 1,0,0）輸出：`0010111 0010111 …`

### 6.3 攻擊單一 LFSR

| 步驟 | 做法 |
|---|---|
| 需要 | 密文 + 度數 $m$ + **前 $2m$ 個明文 bit** |
| 1 | $s_i = x_i \oplus y_i$，$i = 0..2m-1$ |
| 2 | 用通用公式列 $m$ 條方程式（$i = 0..m-1$） |
| 3 | 高斯消去法解出 $p_0..p_{m-1}$ |
| 4 | 重建 LFSR，產生後面所有 $s_i$ |
| 5 | $x_i = y_i \oplus s_i$，全部解密 |

### 6.4 三句話

1. **LFSR：週期長、硬體小、統計好 —— 但線性，所以可預測。**
2. **金鑰只出現在線性關係裡 = 極不安全。**
3. **多個 LFSR 組合 + 非線性（不規則時脈、AND）才可能安全**（A5/1、Trivium）。
