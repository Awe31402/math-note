## 1. 公鑰密碼學能做什麼：總覽表

`[00:02]`【口頭】「之前幾次都沒時間講，現在給一個**總覽**。我覺得這對**實務很重要**。只是事實知識，沒什麼要理解的。」

公鑰密碼學提供的三大**安全機制（security mechanisms）**：

| 演算法家族 | **金鑰交換** | **數位簽章** | **加密** |
|---|---|---|---|
| **整數分解**（RSA） | RSA 金鑰傳輸（用 RSA 加密一把 session key） | RSA 簽章 | RSA 加密 |
| **離散對數 $\mathbb{Z}_p^*$** | **Diffie-Hellman** | Elgamal 簽章、**DSA** | **Elgamal** ← 今天 |
| **離散對數：橢圓曲線** | **ECDH** | **ECDSA** | EC-Elgamal |

【口頭】
- 「實務上真正的大家族只有兩個：**RSA** 和**離散對數**。離散對數又分兩種：mod $p$ 和**橢圓曲線**。」
- 「**橢圓曲線能做 mod $p$ 能做的一切。**」
- 這門課會做：Elgamal 加密（今天）、**ECDH**（接下來兩次）、**RSA 簽章**（約四週後），時間夠的話還有 Elgamal 簽章。
- 「**ECDSA 我們不講**，課本裡有，有興趣可以自學。」

### 【口頭】其他公鑰家族：後量子密碼學

`[00:08]`
- 除了這三族，還有**大約四族**其他的公鑰演算法。
- 大多在 **1970、1980 年代**提出。沒人用的原因：**很慢**、**金鑰超大**（一把金鑰可能好幾 MB）。
- 現在正在**復興（Renaissance）**，大家重新考慮它們。目前實務上沒用，**可能幾年後會用**。
- 「它們有個很炫的名字叫**後量子密碼學（post-quantum cryptography）**。為什麼這樣叫，之後會告訴你。」碩士班有 V 教授的進階課。
- 「入門課不講。」（→ 但這個系列後來在第 23–24 講講了以雜湊為基礎的後量子簽章。）

## 2. 用離散對數加密的基本想法

`[00:10]` 回想 DH：Alice 和 Bob 協商出一把 session key $k_{AB}$，通常拿去當 **AES 的金鑰**。

**現在的目標**：不用對稱演算法，**只用 DL 問題本身（mod 運算）來加密**。

【口頭】教授快速重畫一次 DH（「第三次了，應該很無聊」）：

```
   Alice                              Bob
   a, A = α^a                         b, B = α^b
             ───── A ─────→
             ←──── B ──────
   k_AB = B^a                         k_AB = A^b
```

【課堂討論】`[00:13]` 有了 $k_{AB}$，怎麼用它加密一筆資料（例如信用卡號）？
- 學生答：**XOR**。
- 教授：「很好的例子，我也不太確定為什麼大家不用 XOR，它應該也行。但**比加法再複雜一點**的是什麼？→ **乘法**。他們就是這麼做的。」

**加密**：用 $k_{AB}$ 當**乘法遮罩**

$$y \equiv x \cdot k_{AB} \pmod p$$

【課堂討論】`[00:15]` Bob 怎麼拿掉這個乘法？→ **乘反元素**（「除」，但其實是乘反元素）。

$$x \equiv y \cdot k_{AB}^{-1} \pmod p$$

> 【口頭】`[00:16]`「**這很重要：Elgamal 基本上就是這樣。**做一個普通的 DH，得到 session key，發送方乘上它（一種**遮罩 masking**），接收方乘上反元素。」
> 「如果你看課本或其他書，Elgamal 看起來**複雜得多、很不一樣**。其實不是。他們只做了兩件事：」
> 1. 「**改變數名稱**，取一些很炫的名字 —— 這只會讓你困惑，**很蠢**。」
> 2. 「**重新安排通訊順序** —— 這**不蠢**，會讓事情更有效率。」
>
> 「**Elgamal 沒什麼神秘的，它不是完全不同的密碼系統，只是 DH 的一個小變形。**」

【課本補充】
- 循環群的一個性質：給定任何 $k_M \in \mathbb{Z}_p^*$，每個訊息乘上它都會對到**不同**的密文。
- 如果 $k_M$ 是從 $\mathbb{Z}_p^*$ 隨機選的，每個密文 $y \in \{1, \ldots, p-1\}$ **出現的機率都一樣**。

## 3. Elgamal 加密協定

### 3.1 名字與背景

`[00:18]`
- 由 **Taher Elgamal** 在 **1985 年**提出。
- 【口頭】名字拼法大概各占一半：**ElGamal**（大寫 G）或 **Elgamal**。教授以前寫大寫 G，寫書時做了研究，發現 **Elgamal** 似乎是比較正式的拼法。
- 「跟 DH **很像，但重新排序了**。」

【課本補充】可以用在任何 DL 和 DH 問題很難的循環群，例如 $GF(2^m)$ 的乘法群。Elgamal 是 **GnuPG、OpenSSL、PGP** 等軟體的一部分。

### 3.2 Bob 先建立金鑰

`[00:20]`【口頭】回想**信箱的比喻**：公鑰加密時，**Bob 是接收者**。他產生兩把金鑰（私鑰自己留、公鑰發出去），所以是**從 Bob 發起**的，不是雙方一起來。

**所以 $\alpha$ 和 $p$ 不再是「大家共用的領域參數」，而是 Bob 自己選的。**

| 步驟 | Bob 做的事 |
|---|---|
| (a) | 選大質數 $p$，選原根 $\alpha \in \mathbb{Z}_p^*$（或 $\mathbb{Z}_p^*$ 的子群） |
| (b) | 選**私鑰** $d \in \{2, \ldots, p-2\}$ |
| (c) | 算**公鑰** $\beta \equiv \alpha^d \pmod p$ |
| (d) | 送出（或公布）$k_{pub} = (p, \alpha, \beta)$ |

【課堂討論】`[00:22]` 為什麼私鑰叫 $d$？→ 「他最後要拿它來**解密（decrypt）**。」跟 RSA 一樣：$d$ = decryption 指數。

【口頭】`[00:23]` **DL 系統的通則**：
> 「**指數裡的東西通常是私鑰**（因為它很難算出來 —— 就是離散對數）；**結果通常是公鑰**，或至少不是秘密。」

【課堂討論】`[00:25]` Bob 只送 $\beta$ 就夠了嗎？→ 還要送 **$p$ 和 $\alpha$**。以前它們是領域參數，大家都知道；現在是 Bob 選的，**他得告訴 Alice**。

【課本補充】跟 DH 比，**不需要可信第三方來選質數和原根**，Bob 自己產生，放在資料庫或網站上。

### 3.3 Alice 加密

`[00:26]`

| 步驟 | Alice 做的事 | DH 裡對應的 |
|---|---|---|
| (e) | 選 $i \in \{2, \ldots, p-2\}$ | Alice 的私鑰 $a$ |
| (f) | 算**臨時金鑰（ephemeral key）** $k_E \equiv \alpha^i \pmod p$ | Alice 的公鑰 $A$ |
| (g) | 算**遮罩金鑰（masking key）** $k_M \equiv \beta^i \pmod p$ | session key $k_{AB}$ |
| (h) | **加密** $y \equiv x \cdot k_M \pmod p$ | |
| (i) | 送出 $(k_E, y)$ | |

#### 什麼是「ephemeral」？

`[00:27]`【課堂討論】有人學過希臘文或拉丁文嗎？（「100 個聰明的高中畢業生……」）
→ **ephemeral = 臨時的、短暫的**。不是長期的金鑰，只存在很短的時間。【口頭】「這是密碼學的**標準術語**，我們第一次用到。」

#### 為什麼叫 masking key？

`[00:29]`【口頭】有人猜 $k_M$ 的 M 是 **master key** —— 「之後會講 master key，但**不是**。」M 是 **mask（遮罩）**，因為它拿來乘在明文上，像一個面具蓋住明文。

> 「這些名字不一定是 Elgamal 原本的叫法，是我們課本的叫法。我覺得**很有用**。」

#### 重新排序在哪？

`[00:32]`【課堂討論】照 DH 的順序，Alice 到這裡會送出 $y$。還缺什麼？→ **Alice 的公鑰還沒送出去！**

> **Elgamal 的重新排序**：把 Alice 的公鑰 $k_E$ 和密文 $y$ **一起**送出去。

【課本補充】這樣 Alice **只要送一次訊息**給 Bob，不用像 DH 版本那樣送兩次。

### 3.4 Bob 解密

`[00:34]`【課堂討論】Bob 最後要算 $k_M$ 的反元素來解除遮罩。但**在那之前**要先做什麼？→ 先**算出 $k_M$**。

| 步驟 | Bob 做的事 | DH 裡對應的 |
|---|---|---|
| (j) | $k_M \equiv k_E^{\,d} \pmod p$ | $k_{AB} = A^b$ |
| (k) | **解密** $x \equiv y \cdot k_M^{-1} \pmod p$ | |

### 3.5 對照：Elgamal 就是重新排列的 DH

```
   Alice                                         Bob
                                         選 p, α；私鑰 d
                                         β = α^d
             ←──── k_pub = (p, α, β) ────
  選 i
  k_E = α^i         （臨時金鑰 ≈ DH 的 A）
  k_M = β^i         （遮罩金鑰 ≈ DH 的 k_AB）
  y = x · k_M
             ────── (k_E, y) ──────────→
                                         k_M = k_E^d
                                         x = y · k_M⁻¹
```

> 【口頭】`[00:37]`「我希望顏色不會太多。我講得很慢，用顏色把這點傳達清楚：**這兩個協定本質上一樣**。你只是取了不同的、令人困惑的名字（臨時金鑰、遮罩金鑰），並重新安排了通訊。但**一步一步對照，兩個協定做的事一模一樣**。」
> 「**很重要。大部分書沒告訴你這點。**它們講完 DH 就說『這是一個全新的協定，它能加密』。不是的，**它幾乎就是 DH**。」

| DH | Elgamal |
|---|---|
| 領域參數 $\alpha, p$（大家共用） | Bob 選 $\alpha, p$ |
| Bob 私鑰 $b$、公鑰 $B$ | Bob 私鑰 $d$、公鑰 $\beta$ |
| Alice 私鑰 $a$、公鑰 $A$ | Alice 的 $i$、臨時金鑰 $k_E$ |
| $k_{AB}$ | 遮罩金鑰 $k_M$ |
| Alice 送 $A$，再送 $y$ | Alice **一次送** $(k_E, y)$ |

### 3.6 正確性證明

`[00:37]`【口頭】「我們很少做證明，但這次做。」

要證：Bob 在步驟 (k) 算出的就是 Alice 加密的 $x$。

$$\begin{aligned}
y \cdot k_M^{-1} &\equiv y \cdot (k_E^{\,d})^{-1} & &\text{（代入 Bob 算的 } k_M\text{）} \\
&\equiv (x \cdot k_M) \cdot (k_E^{\,d})^{-1} & &\text{（代入 } y\text{）} \\
&\equiv x \cdot \beta^i \cdot (\alpha^{i})^{-d} & &\text{（代入 Alice 的 } k_M \text{ 和 } k_E\text{）} \\
&\equiv x \cdot (\alpha^d)^i \cdot (\alpha^i)^{-d} & &\text{（代入 } \beta\text{）} \\
&\equiv x \cdot \alpha^{di - di} \\
&\equiv x \cdot 1 \equiv x \pmod p \;✔
\end{aligned}$$

【口頭】`[00:41]`「策略是：我們要證明它等於 $x$，所以那一堆其他東西**必須變成 1**。」「這基本上就是**證明 DH 有效**的同一個證明。」

### 3.7 【課本補充】數字例子

Bob 產生金鑰，Alice 加密 $x = 26$：

| 誰 | 步驟 | 計算 |
|---|---|---|
| Bob | 產生參數 | $p = 29$，$\alpha = 2$ |
| Bob | 私鑰 | $d = 12$ |
| Bob | 公鑰 | $\beta = 2^{12} \bmod 29 = 7$ |
| Alice | 選 | $i = 5$ |
| Alice | 臨時金鑰 | $k_E = 2^5 \bmod 29 = 3$ |
| Alice | 遮罩金鑰 | $k_M = 7^5 \bmod 29 = 16$ |
| Alice | 加密 | $y = 26 \times 16 = 416 \equiv 10 \pmod{29}$ |
| Bob | 遮罩金鑰 | $k_M = 3^{12} \bmod 29 = 16$ ✔ |
| Bob | 反元素 | $16^{-1} \equiv 20 \pmod{29}$（$16 \times 20 = 320 = 11 \times 29 + 1$） |
| Bob | 解密 | $x = 10 \times 20 = 200 \equiv 26 \pmod{29}$ ✔ |

（自己驗算：$2^5 = 32 \equiv 3$；$2^{12} = 2^{10} \cdot 4 \equiv 9 \cdot 4 = 36 \equiv 7$；$7^2 = 49 \equiv 20$，$7^4 \equiv 400 \equiv 23$，$7^5 \equiv 23 \cdot 7 = 161 \equiv 16$ ✔）

## 4. 幾點說明

`[00:44]`【口頭】「到目前為止我講得太簡單了。其實有不少東西可以討論。」

### 4.1 Bob 的公鑰固定，Alice 的要每次換

`[00:44]`【口頭】跟「直接的 DH 加密」（§2 那個版本）比：
- 只加密**一次**的話，計算量**完全一樣**（同樣的步驟、同樣多次指數運算）。
- 但如果 Bob 收到**很多訊息**（從 Alice、從 Christine……）：直接 DH 版本**每次都要全部重來**。Elgamal 中 **Bob 的公鑰 $\beta$（以及 $\alpha, p$）固定不變**。「這可能是 Elgamal 的一個優點。$\alpha, p$ 由他選，我不確定這算不算優點，也許說是**差別**比較好。」

`[00:46]` **另一把公鑰 $k_E$ 必須每次換！**

| 公鑰 | 換不換 |
|---|---|
| Bob 的 $\beta$ | **固定**，可以加密很多訊息 |
| Alice 的 $k_E$（也就是 $i$） | **每則訊息都要換** ← 這就是為什麼叫 ephemeral |

【口頭】「**不要讓它一樣。**會有作業題，今天我大概也會講為什麼。」（→ §6.2）

### 4.2 Elgamal 是機率性加密

`[00:48]`【課堂討論】你今天用信用卡號 $x$ 在 Amazon 買東西，一小時後又借了另一本很棒的密碼學書，又加密同一個 $x$。兩次的 $y$ 會一樣嗎？

→ **不會。** 因為 $i$ 每次都不同 → $k_M$ 每次都不同 → $y$ 每次都不同。

【口頭】「**這是 AES 會發生的事**（ECB 模式下）。這裡不會。即使加密同樣的值兩次，輸出也不同，**密碼學上非常好**。」

**加密模型的改變**（`[00:51]`）：

```
對稱式：  x, k                     → y
Elgamal： x, k_pub(β), 隨機的 i      → y
                         ↑
                    隨機化參數（randomizer）
```

> **Elgamal 是機率性（probabilistic）加密方案。**（跟課本版的 RSA 不同，那是確定性的。）

【口頭】「（黑板上 probabilistic 拼錯了，謝謝指正。）**更現代、更理論的密碼學**正是想要這個性質。」

【課堂討論】`[00:53]` 對稱加密的操作模式裡，什麼參數有類似的角色？→ **IV（初始向量）**！每次加密換一個 IV（第 9 講）。

【口頭】`[00:54]`「**這是今天最重要的部分。**之後的你可以回去睡了。我有點誇張，但這是我今天主要想教的。」

【課本補充】這也**事先避免了對 $x$ 的暴力搜尋**（攻擊者不能把猜的 $x$ 加密後拿去比對密文）。

### 4.3 【課本補充】密文是明文的兩倍長

- 密文有兩部分：$(k_E, y)$，各約 $\log_2 p$ bit。
- 所以 Elgamal 的**訊息擴張因子（message expansion factor）是 2**。

## 5. 計算面

### 5.1 用到哪些演算法

`[00:55]`

| 計算 | 誰 | 演算法 |
|---|---|---|
| $\beta = \alpha^d$ | Bob（一次） | **Square-and-multiply** |
| $k_E = \alpha^i$ | Alice | Square-and-multiply |
| $k_M = \beta^i$ | Alice | Square-and-multiply |
| $y = x \cdot k_M$ | Alice | 一次模乘法（「很簡單」） |
| $k_M = k_E^{\,d}$ | Bob | Square-and-multiply |
| $k_M^{-1}$ | Bob | **擴展歐幾里得** |
| $x = y \cdot k_M^{-1}$ | Bob | 一次模乘法 |

【口頭】「square-and-multiply 很無聊，六週前就講過了。」

【課本補充】
- **金鑰產生**：$p$ 至少 **1024 bit**，用第 12 講的質數產生方法；私鑰要用 **TRNG** 產生。
- 所有運算元都約 $\log_2 p$ bit。

### 5.2 解密的小技巧：用 Fermat 小定理省掉求逆

`[00:57]`【口頭】最後兩步（算 $k_M$、再求反元素）可以用個小技巧**合併**。

天真做法：先 square-and-multiply 算 $k_M$，再用擴展歐幾里得求逆。
「可以只做**一次** square-and-multiply 就好。」

**Fermat 小定理**（`[00:59]`）：

【課堂討論】「有人記得 Fermat 定理嗎？我從沒要你們背，但如果有記性很好的聰明學生記得，會**讓我很開心**。……沒有？好，你們不必讓我開心。」

> **Fermat 小定理**：對所有 $k_E \in \mathbb{Z}_p^*$，$\quad k_E^{\,p-1} \equiv 1 \pmod p$

**推導**（`[01:01]`）：

$$\begin{aligned}
k_M^{-1} &\equiv (k_E^{\,d})^{-1} \\
&\equiv (k_E^{\,d})^{-1} \cdot \underbrace{k_E^{\,p-1}}_{=1} & &\text{（乘以 1）} \\
&\equiv k_E^{\,p - 1 - d} \pmod p
\end{aligned}$$

$$\boxed{k_M^{-1} \equiv k_E^{\,p-d-1} \pmod p}$$

→ **一次指數運算就同時算出 $k_M$ 並求逆**，省掉擴展歐幾里得。

**驗算**（用 §3.7 的數字）：$k_E^{\,29 - 12 - 1} = 3^{16} \bmod 29$
$3^2 = 9$，$3^4 = 81 \equiv 23$，$3^8 \equiv 529 \equiv 7$，$3^{16} \equiv 49 \equiv 20$ ✔（就是 $16^{-1}$）

### 5.3 【課本補充】可以預先計算

- Alice 的兩次指數運算（$k_E$ 和 $k_M$）**跟明文無關**。
- 所以可以在**系統閒的時候先算好存起來**，等真的要加密時直接用。實務上這可能是很大的優點。

## 6. 攻擊

`[01:03]`【口頭】「還有時間，來談攻擊，10 分鐘以內。」

### 6.1 攻擊 1：解離散對數

`[01:04]` Oscar 是**被動攻擊者**，能看通道，想算出 $x$。
他知道所有公開參數。【課堂討論】他**不知道**哪兩個秘密？→ **$d$** 和 **$i$**。（「跟 DH 類似，就是那兩個秘密指數。」）

**兩條路**：

| 路線 | 解什麼 DLP | 然後 |
|---|---|---|
| 1 | $d = \log_\alpha \beta \bmod p$ | 像 Bob 一樣：$k_M = k_E^{\,d}$，解密 |
| 2 | $i = \log_\alpha k_E \bmod p$ | $k_M = \beta^i$，解密 |

兩條路**都要解 DLP**。

【課堂討論】`[01:08]` 怎麼確保用計算機算不出來？→ **$p$ 要很長**，至少 **1024 bit**。

【口頭】
- 「上週講過，對 $p$ 和 $\alpha$ 還有一堆其他要求，例如**小心小子群**等。我們這裡不講。但對第二學期的課來說，主要就是 **$p$ 要大**。」
- 「不能選 100 bit 的 $p$。1980 年代初有個 **DEC** 的產品選了 128 bit 質數，**被破了**，連當時都太容易破。」

【課本補充】
- Elgamal 對被動攻擊的安全性依賴 **DHP** 的困難度；目前除了算離散對數，**沒有已知的其他方法**解 DHP。
- 在 $\mathbb{Z}_p^*$ 上可以用更強的 **Index Calculus**（不像橢圓曲線）→ $p$ 至少 1024 bit。
- **小子群攻擊（small subgroup attack）**：實務上用**生成質數階子群**的 $\alpha$。在這種群裡所有元素都是原根，沒有小子群。

### 6.2 攻擊 2：重複使用臨時指數 $i$

`[01:09]`【口頭】「這種事**在實務上發生得多得多**。」

**情境**：Alice 需要每次產生新的 $i$，通常來自很強的亂數產生器。但：
- TRNG 通常是從**電路層級的物理現象**萃取的，**電路可能故障**。
- 可能每次都輸出**同一個** $i$ —— 而且看起來是很漂亮、很隨機的 1024 bit 數。
- 如果軟體**沒檢查**，就會一直用同一個 $i$ 加密。
- 或者單純是**軟體 bug**，每次回傳同一個 $i$。

**兩次通訊**（`[01:12]`）：

| | 明文 | 送出 |
|---|---|---|
| 第 1 次 | $x_1$ | $(k_E, y_1)$ |
| 第 2 次 | $x_2$ | $(k_E, y_2)$ |

【課堂討論】`[01:13]` Oscar 會發現 $i$ 重複了嗎？投票 → 會！為什麼？→ **$k_E$ 一樣！**「如果 $i$ 變了，你會看到不同的臨時金鑰。」

【口頭】「如果 Oscar 能**故意**讓智慧卡故障就更有趣了，例如他能接觸到裝置，把它**過熱**之類的。」

**攻擊**：假設 Oscar **知道 $x_1$**（已知明文攻擊），不知道 $x_2$。

- $i$ 一樣 → **$k_M$ 也一樣**。
- 從兩次加密：
$$k_M \equiv y_1 \cdot x_1^{-1} \equiv y_2 \cdot x_2^{-1} \pmod p$$
- 只有 $x_2$ 未知，是一條**線性方程式**：

$$\boxed{x_2 \equiv y_2 \cdot y_1^{-1} \cdot x_1 \pmod p}$$

【口頭】`[01:16]`「當然不只 $x_2$，**$x_3$、$x_4$、$x_5$ 也一樣**。Alice 用她壞掉的亂數產生器加密的所有東西，只要 Oscar **知道一則明文**，就能算出其他所有明文。**這很糟。**」

【課本補充】例如用 CSPRNG（第 3 講）但**每次 session 都用同樣的種子**，就會產生同樣的一串 $i$，Oscar 可以利用。

【口頭】「好消息：**下週沒課**。」

### 6.3 【課本補充】其他攻擊

**主動攻擊：公鑰的真實性**
- 跟所有非對稱方案一樣，要確保 Alice 拿到的**真的是 Bob 的公鑰**。
- 如果 Oscar 能讓 Alice 相信他的公鑰是 Bob 的，就能輕易攻擊。→ 用**憑證**（第 27 講）。

**主動攻擊：可塑性（malleability）**
- Oscar 把 $(k_E, y)$ 換成 $(k_E, s \cdot y)$。
- Bob 解密得到 $s \cdot y \cdot k_M^{-1} = s \cdot x$。
- Oscar **解不開**密文，但能**以特定方式竄改**，例如把金額變成兩倍、三倍。
- 跟 RSA 一樣（第 12 講）。實務上**不用教科書版的 Elgamal**，要加 padding。

**更強的變形**：Cramer–Shoup、DHAES 等跟 Elgamal 相關的方案，在某些假設下能抵抗選擇密文攻擊。

## 7. 一頁速查表

### 7.1 Elgamal 協定

| 階段 | 誰 | 計算 |
|---|---|---|
| 建立 | Bob | 選 $p$、$\alpha$、私鑰 $d$；公鑰 $\beta = \alpha^d \bmod p$；公布 $(p, \alpha, \beta)$ |
| 加密 | Alice | 選新的 $i$；$k_E = \alpha^i$；$k_M = \beta^i$；$y = x \cdot k_M$；送 $(k_E, y)$ |
| 解密 | Bob | $k_M = k_E^{\,d}$；$x = y \cdot k_M^{-1}$ |
| 解密捷徑 | Bob | $k_M^{-1} = k_E^{\,p-d-1}$（Fermat） |

### 7.2 名詞

| 名詞 | 符號 | 意思 |
|---|---|---|
| 私鑰 | $d$ | Bob 的長期私鑰（**d**ecryption） |
| 公鑰 | $\beta$ | Bob 的長期公鑰 |
| 臨時金鑰（ephemeral key） | $k_E = \alpha^i$ | Alice **每次換**的公開值 |
| 遮罩金鑰（masking key） | $k_M = \beta^i = k_E^d$ | 相當於 DH 的 session key |
| 隨機化參數 | $i$ | 讓加密變成機率性的 |

### 7.3 Elgamal ≈ DH

| DH | Elgamal |
|---|---|
| $A = \alpha^a$ | $k_E = \alpha^i$ |
| $B = \alpha^b$ | $\beta = \alpha^d$ |
| $k_{AB} = \alpha^{ab}$ | $k_M = \alpha^{di}$ |
| — | $y = x \cdot k_M$ |

差別：(1) 換名字；(2) $\alpha, p$ 由 Bob 選；(3) Alice **一次送** $(k_E, y)$

### 7.4 性質

| 性質 | 內容 |
|---|---|
| 機率性 | ✔ 同一明文 → 不同密文（每次新的 $i$） |
| 密文長度 | 明文的 **2 倍** |
| 預先計算 | ✔ $k_E$、$k_M$ 跟明文無關 |
| 安全性 | DHP / DLP；$p \ge 1024$ bit |
| 可塑性 | ✘ 需要 padding |

### 7.5 攻擊

| 攻擊 | 條件 | 結果 |
|---|---|---|
| 解 DLP | 求出 $d$ 或 $i$ | $p$ 夠大就不可行 |
| **重用 $i$** | 知道一組 $x_1$ | $x_2 = y_2 \cdot y_1^{-1} \cdot x_1$，**全部破解** |
| 偵測重用 | — | 看到同樣的 $k_E$ |
| 可塑性 | 主動攻擊者 | $(k_E, sy) \to sx$ |
| 公鑰不真實 | 主動攻擊者 | → 需要憑證 |

### 7.6 公鑰三大用途

| | 金鑰交換 | 簽章 | 加密 |
|---|---|---|---|
| RSA | 金鑰傳輸 | RSA 簽章 | RSA |
| DL（$\mathbb{Z}_p^*$） | DH | Elgamal 簽章、DSA | **Elgamal** |
| DL（EC） | ECDH | ECDSA | EC-Elgamal |

## 附：本講一句話總結

> **Elgamal 其實就是重新排列的 Diffie-Hellman：Bob 的長期公鑰 $\beta = \alpha^d$ 固定，Alice 每次選新的臨時指數 $i$，把 DH 算出的遮罩金鑰 $k_M = \beta^i$ 乘在明文上，再把臨時金鑰 $k_E = \alpha^i$ 和密文一起送出 —— 這讓它天生是機率性加密，但只要 $i$ 被重複使用一次，知道一則明文就能解出所有密文。**
