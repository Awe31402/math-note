## 1. 橢圓曲線離散對數問題（ECDLP）

### 1.1 看一個循環群的實例

`[00:03]` 上週最後一個定理：**在某些條件下，橢圓曲線的點形成循環群**。【口頭】「你們昨晚做作業時已經碰過了，但我想再跟你們一起做一次，**讓它活起來**。」

**曲線**（課本一直用的那條）：

$$E: \; y^2 \equiv x^3 + 2x + 2 \pmod{17}$$

【口頭】`[00:05]` 這條曲線剛好**所有的點**都形成一個循環群。「**不是一定都這樣**，但這是一個教學上容易的例子，所以我們選它。」

【課堂討論】`[00:06]`「沒聽到答案我不繼續：循環群需要什麼？」→ **生成元**（= 原根）。

**原根** $P = (5, 1)$。不斷把 $P$ 加到自己身上，就能生成整個群：

| $kP$ | 點 | $kP$ | 點 |
|---|---|---|---|
| $P$ | (5, 1) | $11P$ | (13, 10) |
| $2P$ | (6, 3) | $12P$ | (0, 11) |
| $3P$ | (10, 6) | $13P$ | (16, 4) |
| $4P$ | (3, 1) | $14P$ | (9, 1) |
| $5P$ | (9, 16) | $15P$ | (3, 16) |
| $6P$ | (16, 13) | $16P$ | (10, 11) |
| $7P$ | (0, 6) | $17P$ | (6, 14) |
| $8P$ | (13, 7) | $18P$ | **(5, 16)** |
| $9P$ | (7, 6) | $19P$ | **$\mathcal{O}$** |
| $10P$ | (7, 11) | | |

【口頭】`[00:07]`「$2P$ 是你昨晚 11 點做作業時算的，用那個有斜率 $s$ 的複雜公式。用計算機大概要 5 分鐘。$3P = 2P + P$，又 5 分鐘……我們不全部做。」

### 1.2 $18P$ 就是 $-P$

`[00:08]` 看 $18P = (5, 16)$ 和 $P = (5, 1)$：
- **$x$ 座標一樣**（都是 5）
- 【課堂討論】16 和 1 有什麼關係？→ **mod 17 下互為加法反元素**：$-1 \equiv 16 \pmod{17}$
- 所以 $18P = (5, -1) = $ **$-P$**

【口頭】`[00:10]`「**逼你們做作業真好。**我保證沒人記得 166 小時前（上週三）講的東西，如果沒做作業的話。」

【口頭】再次提醒：這個式子裡有**兩種負號**，「一個是 mod $p$ 的負號，一個是群運算的負號，**完全不同的野獸**。它們看起來都是無辜的小橫線。」

### 1.3 繞一圈回來

`[00:11]` 繼續加 $P$：

**$19P = 18P + P$**：
- ⚠️ 用公式**之前**要先手動檢查：兩個點的 $y$ 座標是不是互為反元素？是的（16 和 1）。
- 【課堂討論】那結果是？→ **單位元素**（$\mathcal{O}$）。【口頭】「很好，沒人說『無窮遠點』，你說了『單位元素』，正是這樣。」
- $\mathcal{O}$ **沒有座標**，不用計算機、不用算任何東西。「一個點加上它的反元素就是無窮遠點，你**不能**拿公式算。」

**$20P = 19P + P = \mathcal{O} + P = P$**
**$21P = 20P + P = P + P = 2P$**
**$22P = 3P$** ……

> 【口頭】`[00:15]`「重點是：**19 個 $P$ 之後，我回到開頭了。**開始繞圈 —— 這正是循環群的性質。」
> 「我真正喜歡的是：這跟用整數的循環群**非常不同**。這裡是一個**完全病態的**群運算（在曲線上加點），結果卻得到**跟整數一模一樣的行為**。有時候**推廣**能讓你得到更深的理解。」

【課本補充】
- 這個群的大小 $\#E = 19$，是**質數**。
- 根據第 14 講的定理：**質數階**的群裡，**每個非單位元素都是原根**。

### 1.4 ECDLP 的定義

`[00:17]`【口頭】「我們不是為了循環結構本身著迷。我們要**用它建密碼系統** → 建 DL 問題。」

> **定義（橢圓曲線離散對數問題，ECDLP）**：給定橢圓曲線 $E$、原根 $P$、另一個點 $T$。找整數 $d$（$1 \le d \le \#E$），使
> $$\underbrace{P + P + \cdots + P}_{d \text{ 次}} = dP = T$$

- 代數結構不是 mod $p$ 了，而是**橢圓曲線**。
- 為什麼一定存在 $d$？因為 $P$ 是原根，**能生成所有點**，包括 $T$。

### 1.5 圖像化解釋：在曲線上跳了幾次

`[00:20]`【口頭】「這有一個**非常好的圖像化解釋**，比 mod $p$ 好得多。**所有的書都沒告訴你**。」

```
          y
          │      • 3P
          │   •P         • 5P
          │        • 4P
  ────────┼───────────────────── x
          │  • 2P
          │            • T = dP   ← 跳了 d 次之後停在這裡
          │
```

- 從起點 $P$ 開始。
- 做群運算 $P + P$ → 跳到 $2P$；再加 → 跳到 $3P$；→ $4P$；→ $5P$……
- **一直在曲線上跳來跳去**，最後停在某個點 $T$。

> **ECDLP**：「醒來，**10 秒**。我給你**起點**（原根 $P$）和**終點**（公鑰 $T$），**你告訴我我跳了幾次。**」

【課堂討論】跳的次數在密碼學上叫什麼？→ **私鑰**。

> 【口頭】「給你起點和終點，**很難**看出我跳了幾次才到那裡。」

**例**（`[00:23]`）：用上面那條曲線，$P = (5, 1)$，給你 $T = (16, 4)$，$d$ 是多少？
- 有人說 19 → 不對，$19P$ 是無窮遠點。
- 「就算這麼小的例子，**你也做不到**。」除非查表 → $13P = (16, 4)$，所以 **$d = 13$**。

> ⚠️ 逐字稿中教授一度把點寫錯又更正（「又一個錯，抱歉」）。依課本 Example 9.6：$13P = (16, 4)$。

### 1.6 私鑰是整數，公鑰是點

`[00:27]`

| | 是什麼 | 資料型別 |
|---|---|---|
| **私鑰 $d$** | 跳的**次數**（群運算做了幾次） | 【課堂討論】複數？微分方程？矩陣？有理數？→ **整數** |
| **公鑰 $T$** | 終點 | 【課堂討論】→ 這個例子是**兩個整數**；一般來說是**曲線上的點** $(x_T, y_T)$ |

> 【口頭】`[00:28]`「**所有** DL 問題都這樣：
> - **私鑰永遠是一個乖乖的整數**。不管用什麼曲線、什麼群。『小學一年級，數三隻泰迪熊』那種。
> - **公鑰是你在用的那個奇怪東西**。橢圓曲線你覺得怪？還有更怪的：代數簇（algebraic varieties）、超橢圓曲線……」

【課本補充】
- 在 $\mathbb{Z}_p^*$ 的 DLP 裡，**兩把金鑰都是整數**；ECC 裡私鑰是整數、**公鑰是點**。
- $dP$ 叫**點乘法（point multiplication）**，但這個名字**會誤導**：我們**不能**直接把整數 $d$ 乘上一個點。$dP$ 只是「重複做群運算」的方便寫法。
- 如果當初選**乘法寫法**，ECDLP 會寫成 $P^d = T$，跟 $\mathbb{Z}_p^*$ 的 DLP 會更一致。

### 1.7 群有多大：Hasse 定理

`[00:30]`【口頭】實務上做 DL 問題，有個問題**一定要回答**（跟攻擊有關）：**群裡有幾個元素？**

這叫**群的基數（cardinality）**，也叫**階（order）**。記作 $\#E$。

【課堂討論】`[00:31]` 剛剛的例子有幾個點？→ **19**。「小心，你完全對：有 18 個**真正的點**，再加上**無窮遠點** —— 它也算，**單位元素當然是群的一部分**。」

> **Hasse 定理（Hasse 界）**：mod $p$ 的橢圓曲線，點的個數 $\#E$ 滿足
> $$p + 1 - 2\sqrt{p} \;\le\; \#E \;\le\; p + 1 + 2\sqrt{p}$$

【口頭】`[00:35]`「我看到很多困惑的臉，**很好**。」

**很粗略的工程解釋**：

$$\#E \approx p$$

- 這個式子其實是 $p + 1 \pm 2\sqrt{p}$；那個 $+1$ 不用管。
- $\sqrt{p}$ 看起來很大，**絕對值**上也確實很大，但**相對於 $p$** 很小。

**例**：$p$ 是 160 bit。
- 【課堂討論】$\sqrt{p}$ 有幾 bit？→ **80 bit**（開根號 bit 數減半）。
- 乘 2 只多 1 bit。
- 所以 $\#E$ 是 160 bit 數，**上下最多差個 80 bit 的數**，影響只在**下半部的 bit**。

【口頭】`[00:38]`「就像**中了 100 萬**：修正項是 $\sqrt{1{,}000{,}000} = 1000$。你中了 100 萬歐元，**根本不在乎**是 100 萬 1000 還是 99 萬 9000。」

【課本補充】實務意義：如果需要一條有約 $2^{160}$ 個點的曲線，就要用約 **160 bit** 的質數。

#### 但精確數字很難算

`[00:39]`
- Hasse 界給了**粗略**的大小，這對擋**暴力攻擊和平方根攻擊**很重要。
- 但**有些攻擊**（例如 Pohlig-Hellman，第 14 講）需要知道**精確的** $\#E$，到最後一個 bit。Hasse 給不了。
- **求精確的點數很難**，需要「相當進階的數論」。【口頭】「如果你很沮喪：『要用的時候 Paar 教授就不講了』—— 其實也沒那麼難，有函式庫可以算。」

### 1.8 實務：用標準曲線

`[00:42]` 因為找好曲線、算點數很難，實務上**很常用標準化的曲線**：

| 標準 | 說明 |
|---|---|
| **NIST 曲線** | 美國國家標準與技術研究院提出，「大概 14 條左右」，很多人用。英文維基百科有條目 |
| **BSI 曲線** | 德國聯邦資訊安全辦公室提出，安全 |
| 【課本補充】Brainpool、SECG | 其他替代選擇 |

標準裡會給：係數 $a, b$、質數 $p$、原根、**群的大小**，以及其他我們沒講的參數。

#### 【Q&A】標準曲線公開了原根，對攻擊者有幫助嗎？

`[00:46]`

**學生問**：標準曲線什麼都給了，包括原根，這不會幫到攻擊者嗎？

**教授答**：「當然沒幫助。」
- 標準曲線基本上就是給你**曲線和起點**。「從那裡開始，**祝你好運**。」
- 你寫一個有安全功能的新 App 想賺錢：拿這條曲線、拿這個生成元，**自己選一個隨機的 $d$**，算出公鑰，就能建密碼系統。
- 「攻擊者**事先知道曲線和起點，沒有任何好處**。你**不能預先算出所有的點**，能的話那就是暴力攻擊了。」

### 1.9 ECDLP 有多難

`[00:44]` DH、ECDSA 等協定**依賴 ECDLP 的困難度**：要破協定，就得解這個問題；希望就算地球上所有超級電腦也解不了。

【口頭】`[00:47]`「長話短說：**ECDLP 非常非常難**。這對我們這些設計者來說很好 —— 我們不是 Oscar，我們要造安全的東西。」

**前提**：曲線要**仔細選**，檢查各種數學性質。這也是為什麼大家用標準曲線。

> **如果曲線選得好，已知最好的 ECDLP 演算法需要大約 $\sqrt{\#E}$ 步。**

【口頭】`[00:49]`「**提醒**：這個 $\sqrt{\phantom{x}}$ 跟 Hasse 定理裡的 $\sqrt{\phantom{x}}$ **沒有數學上的關係**，是同一個數只是**純屬巧合**。這來自最好的攻擊 —— 三週前我們叫它們**平方根攻擊**。」

**例**：160 bit 的曲線 → 最好的攻擊要 $\sqrt{2^{160}} = 2^{80}$ 步。

#### 【口頭】COPACOBANA 上的實驗

`[00:51]`
- Güneysu 教授（第一講展示 COPACOBANA 的那位）大約五年前的碩士/學位論文，就是**在 COPACOBANA 上實作這些最好的 ECC 攻擊**。
- 用那台特製硬體，一年大概能做 $2^{35}$ 次運算左右（教授說「大概」）。
- 由此推估：用目前的硬體做 $2^{80}$ 大概要 **100 萬年**。
- 考慮硬體越來越快（Moore 定律），粗估：**15～20 年後**，花 **100 萬歐元**買電腦，就能做 $2^{80}$ 次群運算 → 160 bit 曲線被破。
- 「所以大家說 **160 bit 大約有 15～20 年的安全性**。這是**下限**。大部分商業產品**現在都改用 192 或 256 bit** 了。」

> ⚠️ 「$2^{35}$ 一年」是教授口述的大略數字，原話含糊（「or something」），待查證。

#### 【口頭】老師的小遺憾

`[00:53]`「這部分有點可惜：有很多**很深、很進階**的數學。我們不想講 Hasse 定理從哪來，不想講 DLP 的攻擊細節……很多東西我只能**給你們事實**，作為老師有時候有點沮喪。第二部分就不一樣了，**比較多演算法，做真正的密碼學**。」

## 2. 橢圓曲線 Diffie-Hellman（ECDH）

### 2.1 新群 = 馬上有所有協定

`[00:54]`【口頭】「希望你開始**欣賞離散對數問題的美**：所有 DL 協定看起來都很像。**一旦你給我一個新的循環群**（橢圓曲線），你就可以回去看二月（寒假前）講的 DH 金鑰交換，**做一模一樣的協定**，只是換成橢圓曲線。」

> 「所以一有新群，**馬上就有所有密碼應用**：金鑰交換、之後的數位簽章、加密（Elgamal 也能用橢圓曲線做，有點技巧但基本上一樣）。」

> **ECDH = 從 $\mathbb{Z}_p$ 的 DH 直接（straightforward）移植過來。**
> 【口頭】「straightforward 是**一個字**。學士論文裡**很常見的錯誤**。」

### 2.2 領域參數

`[00:56]`

| | $\mathbb{Z}_p$ 的 DH | ECDH |
|---|---|---|
| 代數結構 | 給 $p$ 就知道 $\mathbb{Z}_p$（例如 $p = 31$ → $\mathbb{Z}_{31}$） | **橢圓曲線** $E: y^2 \equiv x^3 + ax + b \pmod p$ |
| 原根 | $\alpha$ | **點** $P = (x_P, y_P)$ |
| 領域參數 | $p, \alpha$ | $p, a, b, P$ |

【課本補充】實務上**找合適的曲線相對困難**，曲線要有某些性質才安全。

### 2.3 協定

`[00:59]`【口頭】情境：「Alice 和 Bob 有很快的 AES 實作，AES 很安全。他們下載了**非法的**好萊塢新片想傳給對方，要用 128 bit 的 AES 加密，所以要**協商一把金鑰**。Alice 住在 Bochum，Bob 住在慕尼黑，不想專程坐火車跑一趟。他們**上過我的課**，知道怎麼做。」

```
         Alice                                  Bob
  （先約定曲線，例如用標準曲線）
  選 a ∈ {2, …, #E − 1}                  選 b ∈ {2, …, #E − 1}
  A = a·P = (x_A, y_A)                   B = b·P = (x_B, y_B)
                  ────────── A ──────────→
                  ←───────── B ───────────
  T_AB = a·B                             T_AB = b·A
```

| 步驟 | 說明 |
|---|---|
| 私鑰 $a$、$b$ | 【課堂討論】私鑰通常怎麼產生？→ **隨機**。「越隨機越好」 |
| 範圍 | 不要用到 $\#E$：如果 $a = \#E$，$aP$ 就是**單位元素**，你不會想要這樣 |
| 公鑰 $A = aP$ | **點乘法**（scalar multiplication）。【課堂討論】$A$ 是整數還是點？→ **點**。「私鑰是 918,711 之類的無聊整數，公鑰是曲線上的點」 |
| 交換公鑰 | 公開的，不用保密 |
| 共享秘密 | Alice：$aB$；Bob：$bA$ |

#### 【Q&A】私鑰可以選 2 嗎？

`[01:02]`

**學生問**：上週定義橢圓曲線時說 $p$ 不能是 2（$p > 3$），那私鑰可以選 2 嗎？

**教授答**：那是兩回事。理論上私鑰選 2 也可以，一切照常運作。

> ⚠️ 學生問題的完整內容字幕沒抓到，上面依教授回答推斷。

### 2.4 拿共享點來加密

`[01:07]` 共享秘密 $T_{AB} = (x_{AB}, y_{AB})$ 是一個**點**。怎麼拿來當 AES 金鑰？

- 可以用 $x$ 座標或 $y$ 座標。
- 實務上 $x$ 太長（例如 160 bit），AES 只要 128 bit → 取**前 128 bit**，丟掉其他 32 bit。
- 【口頭】「實務上更複雜一點，**通常建議先雜湊**，但我不想講。」

$$c = AES_{x_{AB}}(m), \qquad m = AES^{-1}_{x_{AB}}(c)$$

【口頭】密文這裡叫 $c$，不叫 $y$，「不然會跟 $x$、$y$ 座標搞混」。

【課本補充】
- $x_{AB}$ 和 $y_{AB}$ **不是獨立的**：知道 $x$ 就能代進曲線方程式算出 $y$。所以**只能用其中一個座標**來推導 session key。
- 實務上常把 $x$ 座標**雜湊**後當對稱金鑰。例：160 bit ECC，用 SHA-1 雜湊 $x$ 座標得到 160 bit，取其中 128 bit 當 AES 金鑰。

### 2.5 數字例子

`[01:10]`（課本 Example 9.8）曲線、原根都跟前面一樣：$y^2 \equiv x^3 + 2x + 2 \pmod{17}$，$\#E = 19$，$P = (5, 1)$。

| | Alice | Bob |
|---|---|---|
| 私鑰 | $a = 3$ | $b = 10$ |
| 公鑰 | $A = 3P = (10, 6)$ | $B = 10P = (7, 11)$ |
| 共享點 | $aB = 3 \cdot (7, 11) = (13, 10)$ | $bA = 10 \cdot (10, 6) = (13, 10)$ |

【口頭】「**當當當**，兩邊算出同一個點。$x$ 座標 13 可以當輸入 —— 當然只是個 4、5 bit 的數，實務上不會用這麼小的數，但大數一樣能運作。」

（可以用 §1.1 的表檢查：$3P = (10, 6)$ ✔、$10P = (7, 11)$ ✔、$3 \cdot 10 = 30 \equiv 11 \pmod{19}$，$11P = (13, 10)$ ✔）

### 2.6 正確性

`[01:12]`

$$\text{Alice: } aB = a(bP) \qquad \text{Bob: } bA = b(aP)$$

因為點加法有**結合律**（群的性質之一），兩邊都等於 $abP$：

$$\boxed{T_{AB} = abP}$$

## 3. 計算面：Double-and-Add

### 3.1 點乘法不是真的乘法

`[01:14]`【口頭】要做的運算：
- **群運算**（點加法、點倍增）→ 上週講過，作業做過。
- **點乘法 / 純量乘法（point / scalar multiplication）**：$aP$、$aB$ → **今天新的**。

`[01:16]`【口頭】

> 「**沒有直接把純量乘上點的自然方法。**它看起來像乘法，但根本不存在『整數乘點』這種算術運算。」

類比：$37^5$
- 沒人覺得有什麼神奇的算術運算能直接算。
- 你知道它就是 $37 \times 37 \times 37 \times 37 \times 37$，只是**簡寫**。
- $aP$ 也一樣：就是 $P + P + \cdots + P$ 的**簡寫**。

### 3.2 Square-and-Multiply → Double-and-Add

`[01:17]`【課堂討論】$\mathbb{Z}_p$ 裡怎麼有效率地算指數？→ **Square-and-multiply**。

> 【口頭】「**美妙的地方：square-and-multiply 在橢圓曲線上一模一樣**，只是換名字。」

| $\mathbb{Z}_p^*$（乘法群） | 橢圓曲線（加法群） |
|---|---|
| **平方** $x \cdot x$ | **倍增** $P + P$ |
| **乘** $x \cdot \alpha$ | **加** $T + P$ |
| Square-and-Multiply | **Double-and-Add** |

**演算法**（課本 p.248）：

```
輸入：曲線 E、點 P、純量 d = (d_t d_{t-1} … d_0)₂（d_t = 1）
輸出：T = d·P

T = P
FOR i = t-1 DOWNTO 0:
    T = T + T            ← 每個 bit 都倍增
    IF d_i = 1:
        T = T + P        ← bit 是 1 才加
RETURN T
```

【口頭】也叫**由左至右法（left-to-right method）**，因為從純量的左邊掃描。

【課本補充】$t+1$ bit 的隨機純量，平均需要約 **$1.5t$ 次**倍增和加法。

### 3.3 例：26P

`[01:19]`
- 笨方法：$P + P + \cdots$，**25 次**群運算。
- $26 = 11010_2$

| 步驟 | 操作 | 結果 | 純量（二進位） |
|---|---|---|---|
| #0 | 初始 | $P$ | `1` |
| #1a | **DOUBLE** | $2P$ | `10` |
| #1b | **ADD**（$d_3 = 1$） | $3P$ | `11` |
| #2a | **DOUBLE** | $6P$ | `110` |
| #2b | （$d_2 = 0$，不加） | | |
| #3a | **DOUBLE** | $12P$ | `1100` |
| #3b | **ADD**（$d_1 = 1$） | $13P$ | `1101` |
| #4a | **DOUBLE** | $26P$ | `11010` ✔ |
| #4b | （$d_0 = 0$，不加） | | |

【口頭】`[01:22]`「把你的螢光筆準備好，需要很多顏色。」「我沒顏色了。」

- **倍增** = 純量**左移一位、補 0**
- **加 $P$** = 把最右邊的 0 **變成 1**

【口頭】`[01:25]`「**每次都倍增**；如果正在處理的 bit 是 1，**不只倍增還要加**。**同樣的演算法，同樣的複雜度。**」

## 4. 【課本補充】安全性與實作

### 4.1 安全性

- Oscar 知道 $E, p, P, A, B$，想算 $T_{AB} = abP$ → **橢圓曲線 Diffie-Hellman 問題（ECDHP）**。
- 似乎**只有一種方法**：解 ECDLP（$a = \log_P A$ 或 $b = \log_P B$）。
- 曲線選得好的話，最好的 ECDLP 攻擊**比 $\mathbb{Z}_p$ 的 DLP 攻擊和 RSA 的分解攻擊弱得多**。
- **Index Calculus 不適用於橢圓曲線。** 只剩**通用 DL 演算法**：Baby-Step Giant-Step、**Pollard Rho**（第 14 講）。
- 這些攻擊約需 $\sqrt{\#E}$ 步 → 群大小至少 $2^{160}$ → 依 Hasse 定理，$p$ 約 **160 bit** → 約 $2^{80}$ 步，**中期安全**。
- 實務上常用到 **256 bit**，最高 **128 bit** 安全等級。
- ⚠️ 只有**密碼學上強的曲線**才有這種安全性。有些曲線家族有弱點，例如**超奇異曲線（supersingular curves）**，但容易辨認。

### 4.2 實作的四層結構

```
┌──────────────────────────────┐
│ 4. 協定（ECDH、ECDSA）        │
├──────────────────────────────┤
│ 3. 純量乘法（Double-and-Add） │
├──────────────────────────────┤
│ 2. 群運算（點加法、點倍增）    │
├──────────────────────────────┤
│ 1. 模運算（GF(p) 的 + − × ⁻¹） │
└──────────────────────────────┘
```

**注意**：ECC 裡有**兩個完全不同的有限代數結構**：曲線定義在其上的**有限體 $GF(p)$**，以及曲線上的點形成的**循環群**。

實務上的核心要求：點形成的循環群（或子群）要有**質數階**。

### 4.3 效能

| 平台 | 256 bit 點乘法 |
|---|---|
| 軟體（高度最佳化，3 GHz 64 bit CPU） | 約 **2 ms** |
| 軟體（一般） | 約 10 ms |
| 硬體（最快） | 約 **40 μs** |
| 硬體（常見） | 幾百 μs |
| **RFID 等輕量級** | 約 **10,000 等效閘**，幾十 ms |

- ECC 是**輕量級應用最有吸引力的公鑰演算法**：比 3DES 等對稱密碼大很多，但**比 RSA 小很多**。

### 4.4 為什麼 ECC 擴充性比較好

- ECC 的計算複雜度是位元長度的**三次方**（模乘法是平方 × 純量乘法是線性）。所以 bit 數加倍 → 慢約 $2^3 = 8$ 倍。RSA 和 DL 也一樣是三次方。
- **但 ECC 的參數長得慢得多**：要讓攻擊者的工作量**加倍**：
  - ECC 只要多 **2 bit**
  - RSA / DL 要多 **20～30 bit**
- 原因：ECC 只有通用攻擊，RSA 和 DL 有更強的演算法。

### 4.5 歷史與現況

- ECC 由 **Neal Koblitz（1987）** 和 **Victor Miller（1986）** 各自獨立發明。
- 1990 年代對其安全性和實用性有很多猜測；經過密集研究，現在看來**跟 RSA 和 DL 一樣安全**。
- ANSI 銀行標準分別在 1999、2001 年納入 ECC 簽章和金鑰建立 → 建立信心的重要一步。
- NSA 的 **Suite B**（美國政府系統用的演算法集合）**只允許 ECC** 作為非對稱演算法。
- ECC 也用在 **IPsec、TLS** 等商業標準。
- 課本寫作時，**RSA 和 DL 的部署還是比 ECC 多得多**（歷史原因，以及某些 ECC 變形的專利狀況很複雜）。但新應用，尤其**嵌入式系統、行動裝置**，常偏好 ECC。
- 諷刺的是：ECC 發明後頭幾年，大家以為它**比 RSA 更慢**；回頭看，它其實**通常比其他公鑰方案快**。

### 4.6 加速技巧（概要）

| 層 | 技巧 |
|---|---|
| 模運算 | **廣義 Mersenne 質數**，例如 $p = 2^{192} - 2^{64} - 1$，mod 約減超簡單 |
| 群運算 | 從**仿射座標**改成**射影座標 $(x, y, z)$** → 群運算中**不需要求逆**（但乘法變多） |
| 純量乘法 | 改良版 Double-and-Add：利用「**加或減一個點的成本幾乎一樣**」（因為求 $-P$ 很簡單，回扣第 16 講） |
| 曲線 | **Koblitz 曲線**（$GF(2^m)$ 上、係數為 0 或 1）能特別快地做點乘法 |

## 5. 一頁速查表

### 5.1 ECDLP

| 項目 | 內容 |
|---|---|
| 定義 | 給 $P$（原根）和 $T$，求 $d$：$dP = T$ |
| 圖像 | 從 $P$ 在曲線上**跳了幾次**到 $T$ |
| 私鑰 $d$ | **整數**（跳的次數） |
| 公鑰 $T$ | **點** $(x_T, y_T)$ |
| 群大小 | $\#E$（包含 $\mathcal{O}$） |
| Hasse | $p + 1 - 2\sqrt{p} \le \#E \le p + 1 + 2\sqrt{p}$，即 $\#E \approx p$ |
| 最好的攻擊 | $\approx \sqrt{\#E}$ 步（Pollard Rho） |
| 160 bit 曲線 | $2^{80}$ 步，約 15～20 年安全 |
| 實務 | NIST、BSI 等**標準曲線**；趨勢 192～256 bit |

### 5.2 例子：$y^2 \equiv x^3 + 2x + 2 \pmod{17}$，$P = (5, 1)$

| 重點 | 值 |
|---|---|
| $\#E$ | 19（質數 → 每個點都是原根） |
| $18P$ | $(5, 16) = -P$ |
| $19P$ | $\mathcal{O}$ |
| $20P$ | $P$（繞回來了） |
| $13P$ | $(16, 4)$ |

### 5.3 ECDH

| Alice | Bob |
|---|---|
| $a$ 隨機，$A = aP$ | $b$ 隨機，$B = bP$ |
| $T_{AB} = aB$ | $T_{AB} = bA$ |

$T_{AB} = abP$；取 $x$ 座標（通常先雜湊）當 AES 金鑰。

例：$a = 3$、$b = 10$ → $A = (10, 6)$、$B = (7, 11)$、$T_{AB} = (13, 10)$

### 5.4 Double-and-Add

| 乘法群 | 加法群（EC） | 對二進位純量 |
|---|---|---|
| Square | **Double** | 左移、補 0 |
| Multiply | **Add** | 最右位 0 → 1 |

每個 bit 都 double；bit = 1 再 add。平均 $1.5t$ 次運算。

### 5.5 DL 系統的通則

| | $\mathbb{Z}_p^*$ | EC |
|---|---|---|
| 群元素 | 整數 | 點 |
| 私鑰 | 整數 | 整數 |
| 公鑰 | 整數 | **點** |
| 「指數」 | $\alpha^d$ | $dP$ |
| 快速演算法 | Square-and-Multiply | Double-and-Add |
| 最強攻擊 | Index Calculus | Pollard Rho |
