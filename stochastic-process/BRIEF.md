## 1. Purpose（用途）

給自己自學、複習用。看完筆記就懂這一集，不用重看影片。

- 老師口頭多講、課本沒有的，標 `【口頭】`。
- 速查表放**定理＋證明或推導的關鍵一步**。
- 每個重要觀念（平穩、相關函數、功率頻譜、遍歷性…）：寫清楚**它在算什麼、推導、一個算到底的例子**。

## 2. Situation（背景）

- **中文授課**（台灣口音，夾英文術語）。筆記用繁體中文，術語第一次出現附英文。
- 逐字稿：YouTube **沒有字幕** → 下載音訊到 `_work/audio/`（`NN-<id>.m4a`），用 whisper large-v3-turbo 轉成 `_work/subs/*.vtt`，再轉成帶時間點的純文字 `_work/txt/`。腳本：`_work/scripts/`。筆記「來源」註明 whisper。
- whisper 中文常聽錯同音字和公式符號 → 依課本修正，標 `⚠️ 逐字稿缺字`。
- 課本：Papoulis & Pillai《Probability, Random Variables and Stochastic Processes》4th ed.（McGraw-Hill, 2002），`papoulis.pdf`。文字層是 OCR，雜訊多；全文抽到 `_work/papoulis.txt`，公式看不清時直接看 PDF 頁面。**PDF 頁碼 = 書頁 + 10**。
- 讀者：會微積分、線性代數、基本機率（隨機變數、期望值、聯合分布）；沒學過隨機過程。證明一步一步寫。

## 3. Inputs（資料）

1. **主要**：該部影片逐字稿。骨架照影片順序。
2. **次要**：課本 Papoulis，標 `【課本補充】`，註明章節、式號與書頁（例如 §9-1，式 (9-1)，p. 373）。
3. 投影片上沒唸出的公式 → 從口述和課本重建；重建不出來寫「待補」。
4. 不用網路上的其他筆記、文章。

## 4. Limits（不能做）

- 只寫該部影片講到的內容；最後一節可列「後面哪一集會用到」。
- 老師跳過的課本內容：重要的標 `【課本補充】` 補；次要的寫一行帶過。
- 不整段抄課本。
- 作業題目不做解答（課堂示範的除外）。
- 不編 `【Q&A】`。
- 數學語法照 `lecture-notes` skill 的 Typst 相容規則；不用 `\underset`、`\overset`。
- 沒問過不 commit、不 push。
