## 1. 更正：那個集合不是遍歷集合

[▶ 00:00](https://youtu.be/dyfjz8bdqnA?t=0) 上次上課有同學指出：老師舉的那個集合其實**不是** ergodic，例子要修正。

- ergodic 的定義是在 **inverse**（pseudo-inverse $T^{-1}$）上：$T^{-1}A=A$。
- 老師舉例時用**正向**（砍掉第一個，$T$）直接推，是數學上的錯誤；要用**反向**（補回來）推，才是 ergodic 的定義。
- 所以那個集合不是 ergodic set，要重新舉例。老師說：數學上實在非常 tricky。

以下**不是逐字稿內容**，是依第 30 集的定義推論的：逐字稿沒說是哪個集合。第 30 集 §7 用的 $A=\{100100\cdots,\ 001001\cdots,\ 010010\cdots\}$ 正向砍確實封閉（$TA=A$）；但反向補一個符號時，例如在 $001001\cdots$ 前面補 1 得到 $1001001\cdots$ 在 $A$ 裡，補 0 得到 $0001001\cdots$ 卻**不在** $A$ 裡，所以 $T^{-1}A\ne A$。應該就是這個例子。

## 2. 這一章要做什麼：估計

[▶ 01:02](https://youtu.be/dyfjz8bdqnA?t=62) 這一章講**估計**（Spectrum Estimation）。工程上做估計非常重要：量測之後一定有目的，要用量測的資料做預測——股票市場、大數據（人在 social network 的行為）、溫度變化、河川流量，都是估計。

**為什麼要講 ergodic**：很多時候量測**量不準**。要了解為什麼、什麼時候量得準、要量什麼。老師用範例把數學和實際狀況串起來——不是純粹講數學（那是數學系在做的，不是我們真正的目的）。

## 3. 例：$X=c$，量不到期望值

[▶ 02:33](https://youtu.be/dyfjz8bdqnA?t=153) Example 12-1 的物理意義：

- $c$ 是隨機變數，$+1$ 或 $-1$，機率各 $\frac12$，期望值 0。
- 高中數學的直觀：量很多次做平均，應該趨近期望值 0。
- **事實上不對**：機率是**事前**的。還沒發生前有機率（買股票會賺或賠、骰子 1–6 都有可能）；一旦發生就是事實（賺了就賺了、丟出 3 點就是 3 點）。
- 一旦發生，你永遠量到的都是 $+1$，平均就是 $+1$。量再多資料也沒用，量不到 0，永遠不知道期望值是多少。

所以在時間軸上看，和某個時間點的期望值是有誤差的——不是一樣的東西。機率學家才開始探討這個問題。

## 4. 通訊的例子：AM 傳輸

[▶ 05:35](https://youtu.be/dyfjz8bdqnA?t=335) 老師說是故意舉的，但還算貼切：

- $c$ 是 $3$ 或 $1$（機率各 $\frac12$，平均 2）。AM 傳輸不需要有正有負（之後可能用 envelope detector 量），乘上載波往外送——載波高度 3 或 1。
- 在 $0$ 到 $T$ 之間送波形（例如 1.8 或 1.9 GHz 的高頻），快速取樣很多點再平均，預期接近 2。
- **不對**：沒有保證是 2。取樣都取到 3，平均就是 3——這是時間平均，不是期望值。量再多也沒用。

所以日常應用中做量測，要思考你到底量到的平均是什麼。

## 5. 兩個人量出來不一樣

[▶ 07:36](https://youtu.be/dyfjz8bdqnA?t=456) 量同一條河川的流量：你每 1 秒量一次，另一個同學每 0.7 秒量一次，兩人的平均不一樣。誰量錯？好像都對。

原因：**我們量的現象大部分是 non-ergodic**。這時才會對 ergodic 有感覺——為什麼很多書特別拿出來講。

**第一個條件：時間平均至少要收斂到一個常數。** 量 $+1,-1,+1,-1,\dots$ 一直震盪，不知道平均在哪裡。
- mean-ergodic：目的是量期望值。
- variance-ergodic：目的是量變異數。

要保證不管誰量、怎麼取樣，量出來都一樣，首先量測的對象要 ergodic——量出來都是那個常數。這是 ergodic 這個概念的重要性。

## 6. Ergodic 的工程意義

[▶ 10:13](https://youtu.be/dyfjz8bdqnA?t=613)

- **Slutsky 定理**的重要性在這裡：自共變異的總積分平均趨近 0（if and only if）。要量測的對象必須滿足它，才能準確量到那個常數。
- 雜訊若不是 ergodic，幾乎無法量測，也不知道它的統計特性，只能假設。
- 雜訊若不是 variance-ergodic，就**沒辦法量它的能量**。有些接收端需要量雜訊大小（$N_0$）來做設計；雜訊 non-ergodic 就量不準，用它去修正傳輸方式就要好好考量這個問題。

**留下來的重要觀念**：機率學家提出很多觀念，重要的慢慢留下來。stationary（工程上強調 WSS，每本課本都教，表示一、二階的穩態對工程很重要）和 ergodic 都是。

**股票的例子** [▶ 13:49](https://youtu.be/dyfjz8bdqnA?t=829)：很多學機率、數學的人後來去華爾街。你有一個 policy，要透過長期操作、長期資料預測平均效益。平均量不量得準？股市要滿足：自共變異的總積分平均趨近 0。

## 7. Stationary 的工程意義

[▶ 10:43](https://youtu.be/dyfjz8bdqnA?t=643)

- **設計的角度**：針對某個統計現象設計手機，設計好之後統計性質變了，手機就不適用那個環境。所以要假設衰落、雜訊是 stationary，這樣設計用在那個系統才對。
- **量測的角度**：stationary **又** ergodic，才能保證那個常數**就是期望值**——用不同時間大量量測平均，確實趨近期望值。這才是把概念串在一起的實作意義。

## 8. 自共變異的操作意義

[▶ 14:19](https://youtu.be/dyfjz8bdqnA?t=859) 同學要嘗試想：自共變異的**操作意義**是什麼？

- delay $\tau$ 之後，**能量上的殘餘影響**（二階動差，有能量的概念）。
- $\tau=0$ 自己和自己的影響最大，慢慢衰減。
- 影響在 $\tau=0.1$ 秒就衰減掉 → 自共變異直接掉下來 → 影響性很小。
- $\tau$ 要很久才掉下來 → 糾結很強。
- 我們要的是**糾結的總積分平均是 0**。比較有感覺的充分條件：時間拉很長時，能量的影響一定要消失，才有辦法量測。拉很長還不消失，就不要量了——量不準、量出來不是期望值，而且每個人量可能不一樣。

**老師的提醒**【口頭】：數學要了解，但考完試可能就忘了，而且應該忘掉，不然腦子會爆炸。要記得有用的概念：十年後記得什麼是 ergodic、用口語講得出來就好。大部分現象的自共變異在 $\tau\to\infty$ 時都是 0——沒有理由一個巨大的影響不會隨時間慢慢消化掉。

## 9. 一頁速查表

| 問題 | 答案 |
|---|---|
| 遍歷集合怎麼判斷 | 用反向 $T^{-1}A=A$（補回來），不是只看正向 $TA\subseteq A$ |
| 為什麼量不準 | 量的現象 non-ergodic：時間平均不收斂到常數，或收斂到隨機變數 |
| $X=c=\pm1$ | 一旦發生永遠量到同一個值，量不到期望值 0 |
| 能量測的條件 | ergodic（時間平均 → 常數），Slutsky：$\frac1T\int_0^TC\to0$ |
| 常數 = 期望值 | 還要 stationary |
| 自共變異的意義 | delay $\tau$ 後的能量殘餘影響；$\tau\to\infty$ 要消失才能量 |

## 附：本集一句話總結

> **ergodic 的意義是「能不能用時間平均量到一個大家都一樣的常數」：像 $X=c$ 這種一旦發生就固定的過程，量再多也量不到期望值；要量得準，自共變異（delay 後的能量殘餘影響）的面積平均要趨近 0，而要那個常數是期望值，還要 stationary。**
