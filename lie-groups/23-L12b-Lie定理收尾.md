## 0. 這堂課要做什麼

接上一集最後的 Thm. 3.17，結束 Hall 第 3 章，然後預告下一個主題：**齊性空間**。

## 1. 李子群的警告

[▶ 00:05](https://youtu.be/eP_R7A4Scj4?t=5) Thm. 3.17：連通李子群 $H\subseteq G$ 可以賦予李群結構，使包含映射是李群同態。「這裡有點微妙。」

【口頭】老師的警告：**以後如果要寫關於李子群的東西，得先做功課**。子群的概念碰到**子流形**（submanifold）的概念，而子流形很微妙。（例如上一集的無理直線：作為子群的拓樸和作為 $T^2$ 子集的拓樸不同。）

> 【課本補充】Hall p.85 Thm. 3.18：每個有限維實李代數都同構於某個李群的李代數。（Thm. 3.17 ＋ Ado 定理。）

## 2. 接下來：表示論（不講）

[▶ 00:37](https://youtu.be/eP_R7A4Scj4?t=37) 第 3 章到此結束。第 4 章是**表示論**，「Bradley 改天會跟我們講」（學生打算拿它做演講課的報告）。

【口頭】[▶ 01:13](https://youtu.be/eP_R7A4Scj4?t=73) 更深的結果都要用第 4 章建的機器。表示論最終是在處理**半單李代數**：它給你一種方法，搞清楚某一類李代數有哪些可能。「李代數的分類是一個想得很透的問題，理論很漂亮。」

## 3. Lie 第三定理

[▶ 01:51](https://youtu.be/eP_R7A4Scj4?t=111) 【口頭】老師的博士論文做過類似的事：
- [▶ 02:23](https://youtu.be/eP_R7A4Scj4?t=143) 這是 **Lie 第三定理**的一種：給李群和它李代數的子代數，存在一個李子群以這個子代數為李代數——**在合適的定義下**。

## 4. 齊性空間：先看例子

[▶ 03:30](https://youtu.be/eP_R7A4Scj4?t=210) 【口頭】過了這一步，研究李群要嘛得**更小心打地基**（標準課程會做的），要嘛看**應用**。李群在**齊性空間**（homogeneous space）上的應用特別漂亮，這也是李群研究**一開始的動機之一**。

[▶ 04:35](https://youtu.be/eP_R7A4Scj4?t=275) 老師先不給定義，只列例子（John Lee 的書 p.553，「有蛋糕但不推導」）：

| 空間 | 寫成商 |
|---|---|
| [▶ 05:46](https://youtu.be/eP_R7A4Scj4?t=346) 球面 $S^{n-1}$ | $O(n)/O(n-1)$ |
| [▶ 06:30](https://youtu.be/eP_R7A4Scj4?t=390) 球面 $S^{n-1}$（$n\ge 2$） | $SO(n)/SO(n-1)$ |
| [▶ 07:06](https://youtu.be/eP_R7A4Scj4?t=426) $\mathbb{R}^n$ | $E(n)/O(n)$，$E(n)$ 是歐氏運動群 |
| [▶ 08:17](https://youtu.be/eP_R7A4Scj4?t=497) 上半平面 $\mathbb{H}$ | $SL(2, \mathbb{R})/SO(2)$ |
| [▶ 09:22](https://youtu.be/eP_R7A4Scj4?t=562) 圓 $S^1$ | $SO(2)/SO(1)$ |

說明：
- [▶ 07:06](https://youtu.be/eP_R7A4Scj4?t=426) 「$\mathbb{R}^n$ 是我最愛的例子。」**商**就像商群：把子群裡的東西壓成單位元素。兩個點如果差一個 $O(n)$ 的元素，在商裡就算同一點。
- [▶ 07:42](https://youtu.be/eP_R7A4Scj4?t=462) $E(n)$ 是**平移和旋轉的半直積**（semidirect product），$O(n)$ 是它的子群。除掉 $O(n)$，剩下的就對應平移，也就是 $\mathbb{R}^n$。
- [▶ 08:17](https://youtu.be/eP_R7A4Scj4?t=497) $SL(2, \mathbb{R})$ 用 **Möbius 變換**遞移地作用在上半平面；點 $i$ 的**迷向群**（isotropy group）是形如 $\begin{pmatrix}a & b\\ -b & a\end{pmatrix}$、$a^2 + b^2 = 1$ 的矩陣，正好是 $SO(2)$。【口頭】「這太內行了，先忘掉。」
- [▶ 09:58](https://youtu.be/eP_R7A4Scj4?t=598) $SO(2)/SO(1)$：圓和旋轉同胚（每一點對應「轉到那一點」的旋轉）。$SO(1)$ 只有 $\{1\}$，「是個很蠢的商」。

[▶ 11:07](https://youtu.be/eP_R7A4Scj4?t=667) 【口頭】重點：這給我們一種刻畫空間的方式：**用作用在空間上的同一個群來建造空間**。研究空間的變換性質時很好用，因為空間本身就是一組變換。「全都交織在一起。」

[▶ 11:43](https://youtu.be/eP_R7A4Scj4?t=703) 下次從基本原理講：群作用。老師也考慮過用 Karl-Hermann Neeb 的書（《Structure and Geometry of Lie Groups》，作者是無窮維李群的活躍研究者），第 10 章有 Grassmannian、旗流形等例子，「像飛蛾撲火」。

## 5. 一頁速查表

| 敘述 | 關鍵 |
|---|---|
| 李子群牽涉子流形，很微妙 | 無理直線 |
| 每個有限維實李代數都是某李群的李代數 | Thm. 3.17 ＋ Ado |
| $S^{n-1} = O(n)/O(n-1) = SO(n)/SO(n-1)$ | |
| $\mathbb{R}^n = E(n)/O(n)$ | $E(n)$ = 平移 ⋊ 旋轉 |
| $\mathbb{H} = SL(2, \mathbb{R})/SO(2)$ | Möbius 變換；$i$ 的迷向群 |
