## 0. 這堂課要做什麼

[▶ 00:03](https://youtu.be/79EDZ5ADpIA?t=3) 「抵擋住看 Neeb 那本（大概更棒的）書的誘惑」，照 John Lee《Introduction to Smooth Manifolds》第 21 章講**齊性流形**（homogeneous manifold）。

## 1. 插曲：商空間與「定義得好」

【口頭】[▶ 01:10](https://youtu.be/79EDZ5ADpIA?t=70)–[▶ 04:29](https://youtu.be/79EDZ5ADpIA?t=269) 和學生聊商（quotient）：
- 拓樸的**商拓樸**：把空間的一部分壓成一點，得到新空間。
- 線性代數的**商空間** $V/W$：陪集 $v + W$ 的集合。學生說表示論的書裡，商空間是「左理想的陪集」。
- 抽象代數：乘法陪集要能形成群，子群必須**正規**（第 3 集）。但**交換群的子群都正規**，向量空間對加法是交換群，所以商空間「很容易」。
- [▶ 03:27](https://youtu.be/79EDZ5ADpIA?t=207) 真正的細節在**定義得好**（well-defined）：用陪集定義映射時，陪集有很多代表元（陪集像一個平面，平面上任何一點都能代表它），要確定答案不依賴代表元的選擇。

## 2. Lee 第 21 章的動機

[▶ 00:36](https://youtu.be/79EDZ5ADpIA?t=36) 老師唸 Lee 的開頭：
- 第 4 章說明**光滑淹沒**（smooth submersion）在流形理論中扮演的角色，類似拓樸裡的商映射。
- 但沒回答：**光滑流形的哪些商本身還是光滑流形？**
- [▶ 05:06](https://youtu.be/79EDZ5ADpIA?t=306) 一般的商空間「太廣，沒有好理論」。但有一類講得出很多東西：**李群光滑作用**得到的商。
- [▶ 05:38](https://youtu.be/79EDZ5ADpIA?t=338) 壞消息：很多李群作用的商**不是**流形，要加條件。主定理（**商流形定理**，quotient manifold theorem）：李群**光滑、自由、真**地作用在光滑流形上，商空間是光滑流形。
- [▶ 09:47](https://youtu.be/79EDZ5ADpIA?t=587) 然後研究**齊性空間**：帶有**遞移**光滑李群作用的光滑流形，並證明它們等價於「**李群除以閉子群**」。

## 3. 群作用、自由、真、遞移

[▶ 06:11](https://youtu.be/79EDZ5ADpIA?t=371) **群作用**：群 $G$ 作用在集合 $S$ 上，就是把 $(g, p)$ 送到 $S$ 裡的另一點 $g\cdot p$，滿足
- $e\cdot p = p$（單位元素什麼都不做）；
- [▶ 14:40](https://youtu.be/79EDZ5ADpIA?t=880) $g\cdot(h\cdot p) = (gh)\cdot p$。

[▶ 13:31](https://youtu.be/79EDZ5ADpIA?t=811) 寫成映射：$\theta: G\times M\to M$，$\theta(g, p) = g\cdot p$。

【Q&A】[▶ 14:05](https://youtu.be/79EDZ5ADpIA?t=845) 學生：$S$ 是 $G$ 的子集嗎？老師：不是。$S$ 不是群，只是一個點集，透過 $\theta$ 和 $G$ 連起來。【口頭】群作用是抽象代數要講的，「應該花一兩週講，聽別人講比自學好」。

【課堂討論】[▶ 15:16](https://youtu.be/79EDZ5ADpIA?t=916) 學生：這看起來就是群乘法的結合律。老師：對，一個特例就是**群作用在自己身上**（$S = G$），「有點無聊但很重要，研究它會導向 Sylow 定理等等」。

**例**：$SO(2)$ 旋轉平面。

**自由**（free）　[▶ 06:45](https://youtu.be/79EDZ5ADpIA?t=405) 群作用**沒有不動點**：除了單位元素，沒有群元素固定任何點。
【課堂討論】$SO(2)$ 作用在平面上**不自由**：原點被所有旋轉固定。

**真**（proper）　[▶ 08:28](https://youtu.be/79EDZ5ADpIA?t=508) Lee 的直覺說法：每個緊緻子集被群裡**大部分**元素移離它自己。【口頭】「他用 proper 這個字定義真作用，但我回頭找他第一次說 proper 的地方，找了三四分鐘找不到。」

**遞移**（transitive）　[▶ 09:47](https://youtu.be/79EDZ5ADpIA?t=587) 對任意 $p, q\in S$，存在 $g\in G$ 使 $g\cdot p = q$。（任何點都能被送到任何點。）

## 4. 軌道與軌道空間

[▶ 12:59](https://youtu.be/79EDZ5ADpIA?t=779) $p$ 在 $G$ 下的**軌道**（orbit）：

$$
G\cdot p = \{\,g\cdot p : g\in G\,\}.
$$

它定義了 $S$ 上的**等價關係**（$p\sim q\iff q\in G\cdot p$）。

[▶ 17:57](https://youtu.be/79EDZ5ADpIA?t=1077) **軌道空間** $M/G$：把每個軌道看成一個點，所有軌道的集合。

【Q&A】[▶ 18:44](https://youtu.be/79EDZ5ADpIA?t=1124) 學生：$G\cdot p$ 到底對點做了什麼？老師：看情況，通常以某種幾何上有意義的方式把它送到別的點。例子會說明。

> 對照（Stillwell §2.1，第 3 集）：群作用在自己身上，$H$ 的陪集 $gH$ 就是右乘作用 $h\cdot g = gh$ 的軌道。

## 5. 例子

### 5.1 平凡作用

[▶ 17:21](https://youtu.be/79EDZ5ADpIA?t=1041) $g\cdot p = p$ 對所有 $g, p$。每個軌道只有一點，軌道空間就是 $M$。【口頭】Lee 說它是光滑流形，「理由很蠢」。

### 5.2 ℝᵏ 平移 ℝᵏ × ℝⁿ

[▶ 19:52](https://youtu.be/79EDZ5ADpIA?t=1192) Lee：「最簡單的非平凡例子」。$G = \mathbb{R}^k$（加法群），作用在 $\mathbb{R}^k\times\mathbb{R}^n$ 上：

$$
v\cdot(x, y) = (v + x, y).
$$

[▶ 24:34](https://youtu.be/79EDZ5ADpIA?t=1474) 圖像：一疊平行的 $k$ 維平面，$G$ 讓點**水平移動**。軌道 $G\cdot(x_0, y_0)$ 就是過該點的那片 $\mathbb{R}^k$。

[▶ 25:56](https://youtu.be/79EDZ5ADpIA?t=1556) 軌道空間同胚於 $\mathbb{R}^n$。【課堂討論】[▶ 27:34](https://youtu.be/79EDZ5ADpIA?t=1654) 自然的座標：每個軌道用它和 $\{0\}\times\mathbb{R}^n$ 的交點 $y$ 標記。

【口頭】[▶ 28:10](https://youtu.be/79EDZ5ADpIA?t=1690) 不是每個群作用都能這樣**光滑地**標記軌道。

> 對照：這就是第 4 集的 $\mathbb{R}^3/(xz\text{ 平面})\cong\mathbb{R}$。

### 5.3 S¹ 旋轉平面

[▶ 28:42](https://youtu.be/79EDZ5ADpIA?t=1722) 「軌道空間不是流形、但差一點」的例子。$S^1$（單位複數）作用在 $\mathbb{C} = \mathbb{R}^2$：

$$
z\cdot w = zw.
$$

[▶ 31:53](https://youtu.be/79EDZ5ADpIA?t=1913) $e^{i\theta}\cdot|w|e^{i\beta} = |w|e^{i(\theta + \beta)}$：角度平移，就是旋轉。

[▶ 32:28](https://youtu.be/79EDZ5ADpIA?t=1948) 軌道是**圓**，除了原點（原點是不動點，作用**不自由**）。

[▶ 33:00](https://youtu.be/79EDZ5ADpIA?t=1980) 【口頭】技巧：畫一條**截面**（cross section），每個軌道只穿過一次，它通常告訴你座標。這裡用射線，座標是 $|w|$：

$$
\mathbb{C}/S^1\cong[0, \infty).
$$

[▶ 33:43](https://youtu.be/79EDZ5ADpIA?t=2023) 因為**含 0**（端點），它**不是流形**。[▶ 34:31](https://youtu.be/79EDZ5ADpIA?t=2071) 拿掉原點，$(\mathbb{C}\setminus\{0\})/S^1\cong(0, \infty)$，是流形（拓樸上同胚於 $\mathbb{R}$）。

### 5.4 GL(n) 作用在 ℝⁿ

[▶ 35:56](https://youtu.be/79EDZ5ADpIA?t=2156) $A\cdot x = Ax$。

【Q&A】[▶ 37:15](https://youtu.be/79EDZ5ADpIA?t=2235) 學生問記號。【口頭】[▶ 37:55](https://youtu.be/79EDZ5ADpIA?t=2275) 有**左作用**和**右作用**。群交換的話沒差；不交換時，例如設定**主纖維叢**（principal fiber bundle），用左作用或右作用會得到不同的變換規則。文獻裡兩種都有，要知道每個作者用哪種。

**軌道**：
- $\{0\}$（$A0 = 0$）。
- [▶ 39:05](https://youtu.be/79EDZ5ADpIA?t=2345) 非零向量：任兩個非零向量 $p, q$，有沒有可逆矩陣把 $p$ 送到 $q$？

【課堂討論】[▶ 39:50](https://youtu.be/79EDZ5ADpIA?t=2390)–[▶ 46:23](https://youtu.be/79EDZ5ADpIA?t=2783)
- [▶ 41:03](https://youtu.be/79EDZ5ADpIA?t=2463) $q$ 不能是 0（$Ap = 0$、$A$ 可逆 ⟹ $p = 0$）。
- [▶ 42:18](https://youtu.be/79EDZ5ADpIA?t=2538) 先看 $p = e_1$：要 $Ae_1 = q$，就把 $q$ 放在 $A$ 的第一行，[▶ 44:04](https://youtu.be/79EDZ5ADpIA?t=2644) 其他行補上線性獨立的向量，讓 $A$ 可逆。
- [▶ 44:41](https://youtu.be/79EDZ5ADpIA?t=2681) 一般的 $p$：先找 $M$ 把 $p$ 送到 $e_1$（同樣的構造取反），再接上去。
- [▶ 45:14](https://youtu.be/79EDZ5ADpIA?t=2714) 學生：也可以先**伸縮**到單位球面，再用**旋轉**。這引出問題：$SO(n)$ 在單位球面上遞移嗎？（見 5.5。）

[▶ 47:15](https://youtu.be/79EDZ5ADpIA?t=2835) 所以有**兩個軌道**：$\{0\}$ 和 $\mathbb{R}^n\setminus\{0\}$。

[▶ 36:34](https://youtu.be/79EDZ5ADpIA?t=2194) 軌道空間是兩點集合。商拓樸下的開集是 $\varnothing$、全部、以及其中一個單點（$\mathbb{R}^n\setminus\{0\}$ 那點）。所以它**連 Hausdorff 都不是**，更別說流形。

> 推論（不是逐字稿內容）：$\{0\}$ 那一點不是開集，因為它的原像 $\{0\}$ 在 $\mathbb{R}^n$ 不是開集；$\mathbb{R}^n\setminus\{0\}$ 那點是開集。兩點無法用不相交的開集分開。

### 5.5 O(n) 作用在 ℝⁿ

[▶ 49:28](https://youtu.be/79EDZ5ADpIA?t=2968) 限制到 $O(n)$：$R\cdot x = Rx$，$R^TR = I$。

[▶ 50:03](https://youtu.be/79EDZ5ADpIA?t=3003) 軌道：$\{0\}$，以及以原點為中心的**球面**。

**$O(n)$ 在球面上遞移**　[▶ 50:47](https://youtu.be/79EDZ5ADpIA?t=3047) Lee 的論證（老師：「很貪心、我很愛，而且剛好回答你們剛剛的問題」）：
- 兩個非零向量 $v, v'$，[▶ 51:25](https://youtu.be/79EDZ5ADpIA?t=3085) 先正規化成 $\frac{v}{|v|}$、$\frac{v'}{|v'|}$。
- 各自**延伸**成正交規範基底 $\beta$、$\beta'$（Gram–Schmidt、補全基底）。
- [▶ 52:01](https://youtu.be/79EDZ5ADpIA?t=3121) 令 $A$、$A'$ 是以 $\beta$、$\beta'$ 為行的矩陣（正交矩陣），則 $A'A^{-1}$ 把 $\frac{v}{|v|}$ 送到 $\frac{v'}{|v'|}$。
- [▶ 52:44](https://youtu.be/79EDZ5ADpIA?t=3164) 再接一個伸縮。「很不幾何，純代數的論證。」

[▶ 54:58](https://youtu.be/79EDZ5ADpIA?t=3298) 正交變換**不改變到原點的距離**，跑遍所有旋轉會連起該半徑的所有點。所以 $O(n)\cdot p$ 是半徑 $|p|$ 的球面。

[▶ 55:33](https://youtu.be/79EDZ5ADpIA?t=3333) 軌道空間 $\mathbb{R}^n/O(n)\cong[0, \infty)$，拿掉原點就是 $(0, \infty)$。

### 5.6 O(n) 作用在 Sⁿ⁻¹

[▶ 56:11](https://youtu.be/79EDZ5ADpIA?t=3371) $O(n)\times S^{n-1}\to S^{n-1}$，$(R, p)\mapsto Rp$（長度 1 的向量轉完還是長度 1）。

這個作用**遞移**，所以[▶ 56:52](https://youtu.be/79EDZ5ADpIA?t=3412)**軌道空間只有一點**：只有一個軌道。

## 7. 一頁速查表

| 概念 | 定義 / 例子 |
|---|---|
| 群作用 $\theta: G\times M\to M$ | $e\cdot p = p$；$g\cdot(h\cdot p) = (gh)\cdot p$ |
| 自由 | 非單位元素沒有不動點；$SO(2)$ 作用在 $\mathbb{R}^2$ 不自由（原點） |
| 真 | 緊緻集被大部分元素移開 |
| 遞移 | 任兩點都能互相送到 |
| 軌道 $G\cdot p$；軌道空間 $M/G$ | 軌道是等價類 |
| $\mathbb{R}^k$ 平移 $\mathbb{R}^k\times\mathbb{R}^n$ | 軌道空間 $\cong\mathbb{R}^n$ |
| $S^1$ 旋轉 $\mathbb{C}$ | 軌道空間 $[0,\infty)$，不是流形；去掉 0 是 $(0,\infty)$ |
| $GL(n)$ 作用 $\mathbb{R}^n$ | 兩個軌道；軌道空間不是 Hausdorff |
| $O(n)$ 作用 $\mathbb{R}^n$ | 軌道是球面；$A'A^{-1}$ 把單位向量互送 |
| $O(n)$ 作用 $S^{n-1}$ | 遞移，軌道空間一點 |

## 附：本集一句話總結

> **群作用把群元素和點配成新的點，軌道是一個點能被送到的所有點；把軌道當點得到的軌道空間有時是流形（平移的例子），有時差一點（旋轉平面、要去掉原點），有時連 Hausdorff 都不是（$GL(n)$ 作用在 $\mathbb{R}^n$）；而 $O(n)$ 在球面上是遞移的，這就是齊性空間的起點。**
